# Core Compile 文件结构

本范式仅适用于 Core 的 `compile/` 子树，通用约束继承 [Core 工作指南](../../AGENTS.md)。

- **功能目录**：按领域或产物划分，各模块维护自己的布局与绘制逻辑
- **`compile.ts`**：提供统一的 `compileXxx` 入口，组合布局、绘制及准备好的阶段产物
- **`layout.ts`**：负责测量、尺寸计算、排版与定位；领域根级文件协调各功能模块的整体布局
- **`emit.ts`**：消费布局结果，生成图元与资源；领域根级文件协调各功能模块的整体输出
- **`types.ts` / `constants.ts`（可选）**：维护类型与常量，具体组织遵循[命名规范](../../../../../.agents/skills/standard-name/SKILL.md)
- **`helpers.ts`（可选）**：维护模块内复用的纯逻辑
- **语义算法文件（可选）**：维护职责独立的算法，例如[文本基线](./text/baseline.ts)、[文本宽度](./text/width.ts)
- **`index.ts`**：作为目录 barrel，统一导出模块能力

阶段文件按模块实际职责设置，类型、常量和辅助逻辑就近维护，跨模块共享能力归入共同的语义 owner。
