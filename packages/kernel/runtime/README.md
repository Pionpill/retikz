# @retikz/runtime

Domain-neutral runtime contracts for retikz ownership, transactions, computation execution, scheduling, and tracing. The package depends only on `@retikz/foundation` at runtime and does not know Core IR, Scene, renderers, UI frameworks, or domain-specific operations.

retikz 的领域中立运行时契约，负责 ownership、transaction、computation execution、scheduling 与 tracing。该包只直接依赖 `@retikz/foundation`，不理解 Core IR、Scene、renderer、UI 框架或领域 operation。

## Install

```bash
pnpm add @retikz/runtime
```

This package is ESM-only and requires Node.js 22.12.0 or newer.
