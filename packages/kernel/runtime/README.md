# @retikz/runtime

Domain-neutral runtime contracts for retikz ownership, transactions, program execution, scheduling, and tracing. The package has no runtime dependencies and does not know Core IR, Scene, renderers, UI frameworks, or domain-specific operations.

retikz 的领域中立运行时契约，负责 ownership、transaction、program execution、scheduling 与 tracing。该包没有运行时依赖，也不理解 Core IR、Scene、renderer、UI 框架或领域 operation。

## Install

```bash
pnpm add @retikz/runtime
```

This package is ESM-only and requires Node.js 24 or newer.
