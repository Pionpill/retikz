# @retikz/reconciler 工作指南

全仓规则见根 [AGENTS.md](../../../AGENTS.md)，Kernel 分组规则见 [AGENTS.md](../AGENTS.md)。以下为包职责边界。

- **解决的问题**：统一完整与增量编译执行，支持局部输入变化、缓存复用与事务发布
- **拥有的契约**：完整编译 API、执行环境、树遍历、Composite probe / replay、资源与来源组装、Weave 编译会话、跨次缓存与身份关联、候选状态与单目标提交、运行时快照及 Scene Patch
- **不拥有的能力**：Core 绘图语义与几何算法、后端绘制、框架 authoring 与领域算法
- **输入与输出**：接收 Core 输入、编译选项及更新信息，输出与会话 revision 一致的编译结果和更新产物
- **依赖与缺口流向**：单向依赖 Core、Foundation、Math；绘图能力缺口回 Core，输出事务由会话协调，绘制与作者入口分别由 Render 和 adapter 承担

- 全量与增量首轮共用执行器；Weave 保存 Core 实际阶段产物及复用依据，不维护简化的平行编译模型。非增量模式不保留 Weave，后续批次仅作用于增量模式的作者基础元素

## Weave 三层解析与复用

以下为后续演进约束，不表示现有实现已完成三层拆分；Core 拥有 resolve / compile 语义与产物契约，Reconciler 拥有阶段调度、比较、缓存与拓扑传播。

- **input**：保留稀疏输入，不为比较补默认值；先以浅比较及属性取值比较检查输入与 resolve 上下文，相同则复用 canon。嵌套对象引用变化可进入 resolve；必须使用不可变输入或独立快照，避免原地修改漏检。省略属性与显式默认值可在此层判为不同，由 canon 比较消除语义等价更新
- **canon**：由 resolve 产出当前上下文下语义完整的 compile 输入，补全默认值、继承及可确定的单位等属性；仅在缺失本身具有语义时保留可选字段。允许携带通过 registry 上下文绑定的 Definition 等编译能力，不留给 compile 重复补全，也不在 compile 后回填。比较包含属性与能力绑定；Definition 按稳定身份或版本比较，不对含函数的对象做 JSON 比较
- **compiled**：仅保存最终计算结果，不持有完整 canon、原始输入或 Definition，也不以捕获 Definition 的闭包规避该边界。按实际消费者拆分布局、连接面与锚点、文字排版、绘制样式等结果，支持细粒度比较；后续几何查询需要能力绑定时，显式结合 canon 与 compiled，或消费足以独立计算的最终几何
- Weave 分别持有三层产物及各阶段复用依据。input 或 resolve 上下文变化时重算 canon；canon 与 compile 上下文、依赖均相同时复用 compiled，否则执行 compile；不因输入不同直接判定最终结果变化
- 拓扑变化从实际受影响的最早阶段开始重新计算与比较；仅向依赖已变化结果的消费者传播，结果相同即停止该分支传播。例如绘制颜色变化不应触发只依赖连接几何的路径重算。复用必须同时保持诊断、资源及候选状态提交的事务一致性
