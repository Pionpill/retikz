# kernel v0 Roadmap

验证通用声明式绘图底座，为领域包提供稳定的公开扩展能力。

## 版本方向

| 版本                      | 重点方向                           |
| ------------------------- | ---------------------------------- |
| [v0.1](./v0.1/roadmap.md) | 基础绘图与首条稳定线               |
| [v0.2](./v0.2/roadmap.md) | 分组、继承与开放扩展               |
| [v0.3](./v0.3/roadmap.md) | 多后端、跨宿主与时间轴动画         |
| [v0.4](./v0.4/roadmap.md) | 计算、公式、路径与扩展契约         |
| [v0.5](./v0.5/roadmap.md) | 跨图元机制、组合与增量运行时       |
| v1+                       | 核心契约稳定后的更广生态与工具体验 |

## 后续方向

- Retained 实现性能优化：消除 SVG 首屏挂载中重复复制子节点列表、全量更新中按图元反复扫描完整拓扑等近二次复杂度开销，降低首屏与全量回退成本。保持公开 API、编译结果和事务语义不变，独立于通用节点级增量更新架构推进；以相同口径对比静态与保留模式的首屏、局部更新和全量回退性能。具体版本另行安排。
- 上层增量接入：Kernel [v0.5](./v0.5/roadmap.md) 完成 Reconciler 同步增量编译计算层及接入契约后，Vanilla、React、Plot 等包按实际需求接入并逐步优化；领域数据与布局算法的增量化由对应 owner 承担。

## 边界与依赖

Core 聚焦后端中立的通用绘图契约；领域布局、专用图形与编辑体验由对应 owner 承担。完整 calc、projection syntax、复杂 decorations 与 TikZ library loading 不作为当前承诺。
