# 场景表示、绘制顺序与后端边界

## 设计目的

SVG、Canvas 和离屏导出需要共享同一套图形语义。编译器输出结构化场景而不直接生成 SVG；图元的声明顺序也不能因前向引用晚于邻居解析而改变。这样后端只需决定如何呈现，不重新决定画什么、以什么顺序画。

## 决策

### 场景图元与中立几何

`ScenePrimitive` 是可绘制图元的判别联合；`SceneResources` 保存这些图元引用的场景资源。

路径保存结构化绘制命令，组保存按顺序应用的变换；SVG 字符串、Canvas 指令都是同一场景的后端投影，不是公共数据格式。

公开几何以屏幕坐标、路径命令、文字锚点等中立术语定义；只有明确描述某个后端格式时才使用其属性名。

已编译图形的布局边界不应以 SVG 属性命名。布局矩形用 x、y、width、height 表示，后端自行转换为取景参数。

显式视窗属于可序列化输入，不是某个 renderer 的临时选项。提供时取代自动包围盒作为输出布局；省略时继续按内容计算。

meta 是可序列化的来源对象，与可寻址的 id 不同。它不参与默认值继承、连接、布局或包围盒，不为匿名数据制造可见或可命中图元。

图元参考应分别说明可见范围和命中范围：投影可能扩展视觉范围，却不会扩大 hit area。矩形、椭圆和路径的图元级效果不能被读成 Text 或 Group 整体效果；SVG 的 filter region 需要覆盖投影后的绘制范围。

### 图元声明与绘制顺序

`IRScope` 与 `IRPath` 的 zIndex 指定它们在所属容器内的层叠次序。

同一层中，路径需要延后解析引用，不能因此从它声明的位置漂到最后绘制。没有显式栈序覆盖时，应保持 IR 的兄弟声明顺序。

显式层叠值是有限整数，省略时按零处理；同一容器内部按值排序，同值保留声明顺序。嵌套组作为整体参与父层排序，不把某个子项提升到组外。

### 类型与编译职责

`IRChild` 是子项的判别联合；`ScenePrimitive` 是编译后供后端消费的图元，两者不应混用。

Core 的可观察输出是结构化命令和变换，不是序列化后的 SVG；维护者可以重组内部编译阶段，而不改变后端消费的几何。

### 后端选择与离屏导出

`Scene` 是后端共同消费的编译结果；`SvgNode` 是 SVG 后端的描述节点，不是持久化 IR。

SVG 字符串、SSR 与 React 消费同一份 SVG 描述树，资源 id 前缀由宿主隔离。描述符使用 SVG 拼写；React 只转换需要适配的属性名，不重新决定几何、资源或顺序。

Canvas 后端接收已经编译的 Scene。绘制到已有 context 与设置画布尺寸、DPR、取景变换是两层职责；一次绘制不持有图、不启动时钟，也不生成 SVG 描述树。

SVG 和 Canvas 共享 Render 包，通过后端子路径分别导入。选择 Canvas 不需要先构造 SVG 描述树；没有必要为了复用基础 Scene 而聚合全部后端。

`@retikz/render/canvas-node` 通过 `renderSceneToImage` 输出 PNG、JPEG 或 WebP buffer。它使用与浏览器相同的 `drawScene`；指定时刻即可导出该帧，无需运行播放循环。

`@napi-rs/canvas` 是 optional peer，仅由 Node 子入口动态加载；浏览器入口不引用它，未安装时调用导出应明确提示安装。字体需在绘制前注册，只影响字形，不重新度量已编译的布局，也不保证跨平台逐像素一致。

## 历史记录

- Kernel v0.1：结构化命令、变换与布局边界（ADR-004、ADR-008、ADR-019）；明确公开联合、字段清单和行为验证边界（ADR-009、ADR-013、ADR-017、ADR-018）。
- Kernel v0.2：区分图形布局与显式视窗（ADR-029）；稳定保留声明顺序并允许显式层叠顺序（ADR-008、ADR-009）。
- Kernel v0.3：引入与渲染无关的来源元数据（ADR-016）；分离 SVG 描述符、Canvas 单帧绘制和 Node 图像导出（ADR-001、ADR-002、ADR-005、ADR-025）。
- Kernel v0.4：统一图元公开参考边界（ADR-031）；以能力归属组织绘图契约与编译阶段（ADR-028、ADR-035）。
