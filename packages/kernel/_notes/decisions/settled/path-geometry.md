# 路径构造与平滑

## 设计目的

一条路径可以混合直线、圆弧、矩形和平滑曲线。每一步都须确定它向同一路径追加什么、游标最后停在哪里，后续步骤与沿线标签才能接在正确的位置。

## 决策

`IRStep` 是路径步骤的判别联合，`IRArcStep` 是其中描述圆弧的分支。

构造路径时依次推进游标，复用最近一次有效绘制的位置，不为每个步骤从头寻找前驱。未提供新端点的步骤不能冒充最近的显式目标。这样既保留位置语义，也避免长路径的二次扫描。厚度词汇与线宽表须相互完备，不能因增加枚举项留下没有宽度的值。

圆弧支持显式圆心与椭圆半径，不强迫作者通过相邻步骤模拟圆心；省略中心时使用步骤的隐含基点，末端按弧的实际终点继续。

没有角度限制时绘制完整圆或椭圆；给定起止角后只画对应弧段，闭合方式决定开放弧、弦段或扇形。扫角简写应还原为起止角，不与之重复持久化。

矩形步骤以对角点定义，可指定圆角；它向当前路径追加闭合轮廓，而不是生成一个脱离宿主路径的独立矩形图元。

曲线出入方向、自环及路径整体变换描述的是路径本身的几何；沿线标记是附着内容，不应成为另一条几何路径。

出入角控制曲线离开起点和接近终点的方向，looseness 控制控制点距离；起终点重合时不能仅以零弦长计算控制点，否则自环会退化。

相邻直线的接缝可以倒圆角，半径按两侧可用线段长度夹紧；闭合路径也处理首尾接缝。曲线接缝不因同一设置自动变成直线 fillet。

lineJoin 只改变描边接缝，不能代替会改变中心线、弧长和标签位置的几何倒角。

光滑步骤以当前游标为首个结点，依次经过至少一个给定点，结束于最后一点；以向心 Catmull–Rom 生成三次曲线，张力默认 1。没有前置游标时不能凭空补起点。
