# 文本测量与字体尺寸

## 设计目的

文字测量既影响节点尺寸，也决定何时换行。若宿主各自解释字号和宽度，同一图会得到不同布局；因此先确定有效字号与换行上限，再进行测量和绘制。

## 决策

`IRTextBlock` 表达文字内容，`IRFont` 描述测量与绘制共用的字体设置。

带文字或旋转的节点中，形状与文字作为一组参与变换和堆叠；无旋转的纯几何不必为此增加一层分组。

文本自动折行的阈值是上限而非强制段落宽度：短文本不因给出上限而被撑满，长文本由共用测量和换行规则决定行数。

字号可以是数值、Web 预设或相对单位。em 相对继承的字号，数字使用绘图单位，rem 相对根字号（默认 16）；先解析到数值再测量和绘制，后端不应各自按浏览器默认值解释。
