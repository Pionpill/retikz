# 节点定位、锚点与连接面

## 设计目的

节点定位和路径端点必须能引用同一套坐标与锚点，否则同一条连线会因写法不同而改变落点。但视觉轮廓、连接面和布局占位不是同一概念：调大外间距，不应把标签一起推远。

## 决策

### 节点定位与坐标引用

`IRPosition` 是位置声明；`IROffsetPosition` 与 `IRBetweenPosition` 分别表达偏移和两点插值。

相对定位保存“相对于谁、往哪个方向、相距多少”，而不是在作者侧固化最终坐标。八方向中的对角向量归一化，令同一个距离在对角与正交方向上有相同的几何长度。

Coordinate 是带 id 的可引用位置，不绘制图元、不扩展内容包围盒。连接到坐标时使用该点本身，不制造有面积的节点轮廓。

偏移相对于基准点求值。基准可以是具名节点、笛卡尔点或极坐标；平移不改变被引用点。点位和步骤目标使用相同的偏移语义。

相对坐标先在可见命名范围内找到参照，再在一致的坐标系中计算距离和方向。嵌套变换不能重复施加于已经解析的点；局部命名空间只改变能引用谁，不改变长度单位。

跨 Scope 引用时先将参照点从全局坐标变换到当前 Scope 的局部坐标，在局部施加偏移，再映回全局。旋转容器中的“向右”因此沿局部轴，而不是屏幕轴。

节点引用以 id、可选锚点与偏移表达；命名方位、数值角度和边上比例是不同的锚点语义。作者字符串简写应解析为结构化目标。

两点间的位置先将两个绝对目标解析到同一坐标系再插值；端点可继续嵌套插值，但不能使用依赖当前路径游标的目标，使节点和步骤能共享此表达。

### 锚点、连接面与布局占位

`IRAnchorRef` 描述要取哪个锚点，`BoundaryDefinition` 定义连接面如何求交。

边上点在形状真实边界求值。上下边从西向东、左右边从北向南，比例范围是 [0,1]；形状不支持这种引用时报告错误，不能退回矩形近似。

视觉轮廓与连接面可以不同：同一节点可以画成一个形状，却让连线按另一个边界求交；单个端点的选择不应改变节点怎样绘制。

外间距非负、默认 0。自动连接端点、显式罗盘方向和数字角度都在外扩后的连接面上求交，同一节点不会因引用方式不同出现两条连接边界。

布局占位与 viewBox 计入视觉包围盒四周的外间距；借用另一种连接面只改变交点，不改变占位。中心、形状命名特征点、边上指定点和标签附着点仍取视觉形状；标签距离不重复叠加外间距。

连接面提供者按名称与可序列化参数求边界点，可选提供命名锚点。内置与自定义走同一解析；形状自身的连接面仍可作为边界来源，不由 renderer 采样像素。

连接面拟合默认为 tight、gap 为零；bounds 使用视觉外框。缺少形状紧包络能力时 tight 退回 bounds 并报告警告。gap 在拟合后施加，允许有限负值；半轴非正、非有限或圆形不等轴须拒绝。作用仅限连接面，不改变布局占位。

## 历史记录

- Kernel v0.1：相对定位、坐标占位与平移偏移（ADR-001、ADR-002、ADR-007）。
- Kernel v0.2：局部坐标下的目标引用与两点插值（ADR-004、ADR-016、ADR-027）；按侧与比例解析真实轮廓上的边点（ADR-017）。
- Kernel v0.3：分开视觉轮廓与连接面（ADR-014）；为避免两种引用得到不同落点，让自动端点和显式方向锚点统一计入外间距，但标签仍贴视觉轮廓（ADR-029）。
- Kernel v0.4：明确边界提供者和基于形状的连接面拟合（ADR-026、ADR-041）。
