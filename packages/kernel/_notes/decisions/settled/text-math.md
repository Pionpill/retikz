# 数学排版与行内公式

## 设计目的

公式可以独立占据节点，也可以嵌在一行普通文字中。数学字形与基线需要专门排版，但节点边框、位置和普通文本不应因此依赖整套 TeX 引擎。

## 决策

`IRMathSegment` 表达行内数学片段，与 `IRTextSegment` 一起组成分段文本。

可选 TeX 包负责数学语法、排版和字形降解，最终输出基础图形；普通文字与节点布局不应依赖完整 TeX 引擎，renderer 也不解析公式。

缺少公式 lowerer 与公式本身无效应分别报告。失败只影响相关公式片段，不能令同一节点中的普通文本或整幅图消失。

公式可以作为节点内容参与测量，边框仍由节点形状产生，不能为了“带框公式”让 TeX 接管节点外观。

文本与公式可以作为同一行的不同片段。文本片段保留字体和填充，公式片段经 TeX 排版为字形路径；行内与展示公式的基线、测量和换行不能按普通字符串宽度近似。
