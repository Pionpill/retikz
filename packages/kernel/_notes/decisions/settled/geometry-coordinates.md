# 纯几何与坐标变换

## 设计目的

绘制、测量和连接若各自换算局部坐标，同一形状的边界就可能算出不同位置。纯几何应共享；只有依赖节点名称或绘图上下文的解释才留在 Core。

## 决策

`Vector2` 表达平面点或向量；`IRPosition` 则允许尚待编译上下文解析的位置声明。

局部与世界坐标的转换应复用同一组平移、旋转及其逆运算，否则不同形状的绘制和锚点会使用不同几何。形状共享同一锚点词汇时，无需另设含义相同的类型。通用计算归数学层，形状只决定自己的局部几何。

Math 提供零运行时依赖的纯几何计算；坐标、向量、弧与求交不需要理解节点 id、IR 或 Zod。Core 消费这些计算，而不公开另一份同义实现。

Math 持有点、向量、变换、圆弧、轮廓与求交，不依赖 Core 或 Scene。Core 解释形状锚点、引用与错误；不把纯函数再导出一份。相邻弧段无法求圆角时由几何层返回无解。

极坐标原点可以递归解析；具名节点必须由编译上下文解析，纯数学库不能访问节点索引。
