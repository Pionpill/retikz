# 时间轴与播放控制

## 设计目的

同一张图既要能静态导出，也要能在浏览器里播放和响应触发。若把时钟写进图形声明，离线绘制就会依赖运行环境；因此轨道描述变化，宿主管播放，后端只负责呈现某一时刻。

## 决策

`IRAnimationTrack` 描述随时间变化的属性，`IRKeyframe` 表达轨道上的关键帧。

动画轨道是可序列化的时间到属性值的描述，与宿主事件 handler 分开。Scene 必须同时包含完整静止图；布局和包络不随播放瞬间重算。不能播放轨道不等于删去图元。

viewBox 轨道与元素属性分别属于场景根和具体图元。

SVG 的 load 轨道可用内联 CSS 播放，让静态输出不依赖 JavaScript；visible、manual 与事件驱动的播放需要挂载后的宿主接线。没有播放器时仍可显示静止图。

Canvas 后端按给定时间绘制一帧，不在绘制函数中启动 rAF 或保存共享播放状态。时钟与触发由宿主管理；画出的 base 不因后端不支持某个动画而消失。

具名预设应当是返回可序列化轨道的纯工厂，而不是只在某个框架中才能执行的组件；作者可以直接组合结果或手写等价轨道。

缺省和 `load` 轨道自动播放；`manual`、`visible` 和 `{ onEvent }` 未激活时不施加轨道，保留基础图形。runtime 管理激活态和局部时间，不写入 IR。一个 id 下的非自动播放轨道共享局部时间；播放、暂停、重启、停止或跳转不改变其他 id 的进度。

手动控制由事件上下文按 id 执行，组件外的播放句柄仍控制整图。事件命中先激活目标再调用用户回调；可见触发按图元映射到视口后的几何范围判定，无 DOM 时不自动激活。Canvas renderer 只对传入时刻求一帧。

动画开关是三态：未指定时跟随系统减弱动画偏好，显式 true 强制开启，false 强制关闭。React 与 Vanilla 的宿主设置使用同一优先级。
