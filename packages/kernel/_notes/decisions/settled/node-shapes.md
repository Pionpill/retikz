# 节点形状与参数几何

## 设计目的

增加一个可连接形状，不应要求分别给布局器、SVG 和 Canvas 加特例。形状定义共享参数化轮廓，使绘制、测量与求交描述的是同一个形状。

## 决策

`IRShapeRef` 保存形状引用；`ShapeDefinition` 提供该形状的几何能力。

内置与自定义节点形状共用 Definition 注册入口。形状负责轮廓、连接锚点和绘制几何，不能把文字测量与容器布局复制进每个 provider。

形状引用应保存可序列化的注册身份和参数，而不把函数或实例放进 IR；简单形状可省略参数。参数如何决定轮廓和锚点属于该形状。

发射图形、锚点和边界求交使用同一局部坐标系。外接框若不能容纳实际轮廓，绘制、裁切与连线就会相互矛盾。

圆可视为等半轴椭圆的预设。包含相同内容时，等半轴约束不能简单裁掉矩形内容的角；绘制轮廓和连接锚点使用同一几何。

在最初的矩形内容模型中，equal 的两个半轴均取内容半宽与半高的斜边长度；proportional 各自将半宽、半高乘以 √2。等半轴不是简单取两边中较大的一边。

扇区由内外半径和起止角决定；内半径非负，外半径为正，内半径零时为实心扇片。独立圆弧可开放或以弦闭合。0° 指向右、90° 指向屏幕下方，绘制与连接使用相同角度约定。

矩形的拐角与正多边形的边数、方向都是形状参数。正多边形至少三边；菱形可复用四边形几何，连接锚点须与实际轮廓一致。

星形至少三个尖角，内外半径为正且内小于外；默认第一个尖角指向正 x。旋转后的实际顶点决定包围盒、绘制轮廓和射线交点。

形状圆角只改变确实可求解的相邻轮廓接缝；按可用段长夹紧，无解保留尖角。绘制和连接使用同一条圆角轮廓，从明确的射线起点取最近正向交点。

contour 用至少三个局部点定义隐式闭合环，可倒圆角。以顶点包围盒中心对齐节点位置；连接与绘制共享轮廓，不因局部点原点不同产生位移。
