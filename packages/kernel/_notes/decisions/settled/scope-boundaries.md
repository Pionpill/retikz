# 作用域的名称、继承与裁剪

## 设计目的

把图元放进同一组，可能是为了共同移动、隐藏内部名称、继承样式，或裁剪子树。这些选择必须独立：仅为了统一样式而分组时，不应同时改变引用的可见范围。

## 决策

### 局部坐标与名称可见性

`IRScope` 是可命名的分组声明；`IRNodeTarget` 是对具名目标的引用，不是对其内部名称表的访问。

Scope 是可嵌套的容器：子项共享局部坐标、变换与继承环境，容器整体仍占父容器中的一个声明位置。是否隔离名字与是否形成一个图形组是两件事。

默认情况下，嵌套 Scope 不隐藏子项 id；显式 localNamespace 才让子项名字只在局部可见。内部从最近作用域向外查找，局部同名可遮蔽外层。Scope 自身的 id 在父作用域登记，不因隐藏子项而丢失外部引用入口。

同一作用域内重复登记 id 应发出诊断，按后登记者解析；不同局部作用域中的遮蔽不算重复。

带 id 的 Scope 以内容包络对外提供一个可定位的整体，无需把内部节点全部暴露给父作用域。局部名字隔离不隐藏 Scope 本身；空包络不应凭空增加可见面积。

命名作用域默认使用子树外包矩形；圆形包络使用相同点集的最小外接圆。包络用于外部连接，不生成可见的边框图元。

### 样式继承与子树裁剪

`IRScopeDefaults` 表达传给后代的默认值；`IRClip` 描述子树裁剪，而非可继承的绘制样式。

容器可以向后代提供稀疏的默认样式。局部显式值优先于继承值；隔离默认样式不应同时切断坐标、变换或名称查找。

Scope 的裁剪在局部坐标中解释，作用于其子树；图元引用后端中立的裁剪资源，SVG 或 Canvas 各自执行，不以 CSS 或 DOM 作为设计输入。

Layout 能为根下的图形提供与 Scope 一致的样式环境，避免作者仅为统一样式而额外包装一层容器。

Scope.clip 依 kind 选择统一的 ClipDefinition。内置与自定义裁剪走同一注册和输出路径，renderer 只消费已经生成的 Scene 裁剪几何。
