# 图元与组效果

## 设计目的

阴影会扩大可见范围，却不一定扩大命中区域；逐个绘制子项也不等于把整组先合成再混合。区分这些边界，是为了让布局、命中和不同后端对同一效果有一致解释。

## 决策

`ScenePrimitiveEffects` 描述图元级效果，`IRDropShadow` 是投影的声明结构。

阴影属于可绘制图元，影响视觉范围而不创造新的可命中形状。SVG 和 Canvas 应实现同一阴影语义，不让作者分别编写后端 filter。

预设提供一组默认值，显式字段逐项覆盖；颜色 alpha 与阴影透明度共同决定最终透明度。偏移与模糊使用绘图单位，不改变原图形的命中区域。

混合模式描述图元如何与已经绘制的背景合成；省略或使用 normal 时不改变正常合成结果；不接受词汇表以外的任意后端模式。混合不是布局测量或命中测试规则。

对一组子元素逐个施加效果，与先把整组栅格化再施加效果会得到不同像素。前者可由后代默认值表达；后者涉及离屏缓冲、边界与混合隔离，不能用同一选项暗示支持。
