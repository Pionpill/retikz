# 标签附着与定位

## 设计目的

标签应跟随它标注的图元，而不是依靠一个碰巧相邻的屏幕坐标。节点按轮廓附着，路径按沿线位置附着；这两种位置语义不能合并，但文字排版和样式可以共享。

## 决策

### 节点标签与引线

`IRNodeLabel` 描述节点上的标签；`IRNodeLabelSidePosition` 指定沿边界的附着位置。

标签随节点定位，不是另一个参加布局的同级节点；移动节点不应要求作者同步移动标签。文字排版与标签挂在宿主哪一侧是不同决策。

标签的附着位置与标签文字绕自身中心旋转分别计算。节点已有旋转时不能再把同一次变换施加到标签位置，否则方向和边界距离会失真。

文字可保持水平、沿径向、沿切向或指定角度。keepUpright 只在旋转后的文字倒置时翻转 180°，恰好垂直时不翻。

标签引线复用标签的布局结果。未指定或 false 不绘制，true 采用默认线样式，对象则指定线的外观；不为引线创建一个独立标签。

标签默认在外侧，也可选择向内放置。中心仍是几何中心；边界比例按指定边界解释。内部标签不能使用外部引线。

### 沿路径标注

`IRStepLabel` 与 `IRPathLabel` 分别对应步骤上的标签和整条路径的标签。

七个关键词是归一化比例的简写：at-start、very-near-start、near-start、midway、near-end、very-near-end、at-end 分别对应 0、⅛、¼、½、¾、⅞、1。数值允许精确定位，不必增加关键词。

路径步骤的标签可以指定文字外观，不必继承线条的全部绘制属性。作者没有指定的文字字段才进入相应继承与默认计算。

带上的标签应附着于产生几何的宿主，不另叠一个脱离来源与命中关系的文本节点。路径定位与文字内容分别处理。
