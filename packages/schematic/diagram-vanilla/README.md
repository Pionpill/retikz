# @retikz/diagram-vanilla

`@retikz/diagram-vanilla` is the framework-free authoring adapter reserved for
`@retikz/diagram`.

The Alpha1 package shell is released with an intentionally empty public API.
The shared authoring contract and the first FlowDiagram builder are planned for
Alpha2.

This package is ESM-only and requires Node.js 24 or newer.
本包仅发布 ES modules，要求 Node.js 24 或更高版本。
