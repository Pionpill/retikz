# @retikz/diagram

`@retikz/diagram` is the framework-agnostic Schematic package reserved for
automatic diagram layout, routing, and geometry over `@retikz/graph` data.

The package shell is initialized, but its public API is intentionally empty
until the Diagram roadmap and ADR define the first capability contract.

This package is ESM-only and requires Node.js 24 or newer.
本包仅发布 ES modules，要求 Node.js 24 或更高版本。
