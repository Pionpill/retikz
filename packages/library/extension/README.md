# @retikz/extension

Optional node shapes, arrows, clips, Ribbon definitions, and animation effect presets for Retikz.

```ts
import { CrossShapeDefinition, DiamondArrowDefinition, pulse } from '@retikz/extension';
```

Pass the selected definitions explicitly to your drawing host's `shapes`, `arrows`, `clips` or `pathKinds` options. Importing this package does not register anything globally.

Documentation: https://pionpill.github.io/retikz/library/extension
