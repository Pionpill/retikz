# standard v0 Roadmap

提供可选安装的官方跨领域绘图扩展。

## 版本方向

| 版本                      | 重点方向                                                  |
| ------------------------- | --------------------------------------------------------- |
| [v0.1](./v0.1/roadmap.md) | 通用图形、Legend、Surface 与按需能力接入                  |
| v0.2                      | 基于真实复用需求评估 Dimension、BraceLabel 与扩展绘图目录 |

## 边界与依赖

排版归 Layout，关系语义归 Graph；只消费 Core 公开契约，不拥有领域数据、自动图布局、Editor 或 renderer。
