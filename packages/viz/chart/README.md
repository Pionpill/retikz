# @retikz/chart

`@retikz/chart` provides canonical `chart.chart` IR, typed Chart recipes, and
ordered title, subtitle, note, and source presentation over `@retikz/plot`.

Use `@retikz/chart-react` for JSX authoring or `@retikz/chart-vanilla` for
plain-data and server-side rendering helpers.

This package is ESM-only and requires Node.js 24 or newer.
