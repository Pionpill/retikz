# plot v0 Roadmap

以图形语法表达数据可视化，并通过 Core 绘制。

## 版本方向

| 版本                      | 重点方向                                 |
| ------------------------- | ---------------------------------------- |
| [v0.1](./v0.1/roadmap.md) | 完整静态图形语法                         |
| [v0.2](./v0.2/roadmap.md) | 主题、空间映射、结构化可视化、性能与交互 |
| v0.3                      | 渐进式 AI 生成与跨域组合                 |

## 边界与依赖

通用数据处理归 Data，图表 recipe 归 Chart；Plot 不自带 renderer。性能与交互依赖 Kernel，跨域组合复用 Core，不另建聚合 adapter；地图归属仍待独立决策。
