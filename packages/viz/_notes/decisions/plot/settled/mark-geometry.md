# 图元几何与标签

## 设计目的

Plot 的基础图元应表达点、路径和区间，而非为柱状图、热图等各造一种结构。这样坐标投影、标签附着与缺失值处理可以围绕几何语义复用。

## 决策

`IRPlotMark` 是图元的判别联合；`IRPlotPathMark` 与 `IRPlotIntervalMark` 分别承载路径与区间几何。

底层图元按几何语义而非图表成品分类。例如柱形、径向柱与热图格都可由区间边界结合坐标投影得到，不要求每种图表都有独立 mark。

React 与 Vanilla 应暴露相同的几何图元，图表名保留给上层配方。字段编码与固定图形属性必须能清楚区分，不能由同一个字符串猜测含义。

扇区外移沿其中分角平移，距离以最终绘图单位计，零表示不移动。它改变区间图元的视觉位置，不改写源数据，也不改变其它扇区的角度分配。

标签附着方式由宿主几何决定，作者不必额外声明“节点标签”或“路径标签”。文本排版是共享能力，落点、切向和距离由具体宿主处理。

开放路径遇无效观测默认断开；启用 connectNulls 后，仅连接连续缺口两侧的有效点，不外推首尾缺失。正常段保留原样式，连接段继承描边，默认虚线 [6,4]，可覆盖；不借此改变数据、排序、曲线或填充。
