# 轴、网格与刻度布局

## 设计目的

轴线、刻度、刻度文字与网格通常共享尺度，却不必同时出现或按同一密度绘制。将候选位置、可见标记和文字布局分开，才能在简化轴的外观时保留其数值含义。

## 决策

`IRPlotAxisGuide` 描述轴及其部件，`IRPlotGuideTickSource` 描述刻度候选的来源。

同一条轴可以生成不同叠放层：网格在数据图元下方，轴线、刻度和文字可以在其上方。它们均降为 Core 图形，而非 renderer 特有的 axis。

极坐标下角角色决定绕圆弧的位置，半径角色决定离中心的距离。角轴与径轴、射线与同心网格采用相应投影，不把笛卡尔水平或竖直轴旋转后冒充极坐标轴。

轴的可见域、显示的刻度与刻度文字分别负责不同事情。扩展数据域以留白不等于增减 tick，也不应擅自改写作者给出的明确 padding。

单值域需先形成有效跨度，再按尺度语义处理两端留白。ticks.count 是提示，ticks.values 是显式刻度位置；格式化文字不会改变这些位置。

轴按 line、ticks、tickLabels、title 和 grid 分部件；启用、外观和局部几何归对应部件。改变网格样式不改刻度文字，不用一个混合 style 对象同时控制整条轴。

轴基线的跨度、位置、线端与端点箭头是几何配置，不与 tick 的来源或文字样式捆绑。轴线应降为 Core 路径，而非专门的 renderer primitive。

先由显式值、间隔或数量生成候选刻度，再按密度确定可见集合，最后按 mark 决定每处形状；稀疏显示不能改变数据域。三角标记的方向须相对于轴而非固定屏幕方向解释。

标签布局可以旋转、避让重叠和处理边界；显式固定角度优先于自动旋转。隐藏标签只影响文字，不删除对应刻度或网格；端点对齐应按旋转后的文字范围计算。

轴标题的沿轴位置、向外留白、文字旋转、锚点、位移与布局分开控制；位移不改变其语义位置。装饰占位按实际放置后的标题计算。

网格是 axis 的一个部件，拥有自己的来源与样式。显式指定主、次网格的位置不应改变轴的 tick 展示策略，也不应训练新的数据域。
