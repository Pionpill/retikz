# 图例映射与符号布局

## 设计目的

图例应解释图中真正使用的映射。若自行推断颜色范围，或用固定色块代替实际大小符号，图例就会与图元对不上；其数据来源与布局因此要分别约束。

## 决策

`IRPlotLegendGuide` 描述图例；它消费图元使用的尺度，不另行创建映射。

图例解释非位置映射，是否绘制图例不应暗中创建一条轴。离散色块、连续色带和分档标注承载不同读法。

图例应消费图元实际使用的颜色和通道范围，不应另拟合一份域或重新分配色板。显式 range 或 scheme 优先，领域配色用于未指定的默认。

大小图例默认将最大符号适配到指定符号盒，preserve 则保留图元的尺寸关系，并可整体缩放。条目按实际符号包围盒排版，不把所有符号当作固定大小的色块。

ordinal 色板索引按 (i × step + offset) 对有效色板长度取模，step 默认为 1 且须为正整数，offset 默认为 0 且非负。显式范围优先于主题色板。复合图例符号依声明顺序叠加，不另行分配颜色。
