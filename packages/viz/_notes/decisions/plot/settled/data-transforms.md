# 数据视图、变换与统计几何

## 设计目的

分组、拟合或密度估计产生的是数据结果，不是某种图形的专属算法。区分共享数据视图与图元局部变换，才能让不同图元复用统计结果而不互相污染。

## 决策

`IRPlotMarkTransform` 表达图元局部变换；共享的数据操作声明见 `IRDataTransformDeclaration`。

normalize、derive-interval、jitter 表达的是保留行身份的数据操作：分别形成归一化量、派生区间和可复现的扰动。调用者显式声明顺序，不因图元类型隐式重排数据操作。

normalize 在同组内计算 fraction 或 percent；组和为零时不应产生 NaN。百分比堆叠是先归一化、再堆叠，而非改变 stack 本身的定义。

数据声明只保存有序操作，不嵌入实现函数；注册身份、匹配定义和执行计算是不同职责。相同操作在 Plot 与其它数据宿主上应有相同的数据语义。

派生关联行、选择端点与决定路径路由是不同层次。关联行应保留数据来源，不能把屏幕坐标写回数据来代替寻址。

根级变换先生成共享视图，mark-local 变换只作用于当前图元，不能反向污染同图的其它图元。两层应共享相同的数据操作语义。

聚合、行选择、关系派生及统计输出是有序的数据操作，而非图元 lowering 的副作用。输出模型与来源必须能供多个图元复用；不为每张统计图另造一种计算过程。

分位带 reducer 产生组的统计量，离群值 selector 选择原始行并保留其身份。箱体、中位数和离群点可由图元组合绘制，统计操作不拥有箱线图布局。

分位带以可配置的上下分位数、中心和 spread 描述箱体；须区分实际观测的 whisker 与判定离群点的 fence。按系数确定范围时，历史默认系数为 1.5。

density 按组从数值样本生成密度估计的采样行。输出可由路径图元作为曲线或区域消费，而非把 KDE 算法嵌入 Path。

高斯 KDE 按组计算，可用 Silverman 规则或显式正带宽。采样范围与采样点数控制输出网格，生成行保留分组与生成字段，并通过组来源关联输入样本，不复制任意一行充当来源。

smooth 从分组观测得到拟合结果，趋势线消费它生成的数据；绘制图元不参与模型选择。最早的实现只覆盖线性回归，这不是统计与几何分工的上限。

输入是同组有效的有限数值对；生成的是预测采样行而非图元，未指定采样区间时沿观测 x 范围取样。拟合和置信带是两个不同的统计契约。

统计图形由两类可分别复用的能力组成：transform/reducer/selector 决定数据，几何图元决定如何展示。移除某个图元并不应使数据能力失效。

Plot 从 Data 根入口消费字段、格式、统计与来源能力，不为已迁出的 Data-only 类型做兼容转发。Plot 仍负责把数据结果与坐标、图元和 guide 组合。
