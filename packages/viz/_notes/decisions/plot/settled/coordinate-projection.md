# 坐标角色与局部投影

## 设计目的

同一组数据可以画在直角坐标或极坐标中。坐标角色与投影应由 frame 解释，而不是让每种图元重复猜测方向、带宽以及区间在屏幕上的形状。

## 决策

`IRPlotCoordinate` 保存坐标声明；`CoordinateDefinition` 提供投影及可选几何能力。

笛卡尔坐标把两个角色的尺度结果投影到同一绘图区；坐标负责屏幕方向，尺度负责数据映射。这使改变绘图区尺寸不必改变数据模型。

投影应由 coordinate frame 负责。极坐标把角度和半径映射到平面；图元不应为了同一组数据手写笛卡尔版和极坐标版。

frame 以有序角色描述坐标维度，使投影和辅助线不局限于 x、y 两个键。角色是否完整应由实际坐标契约判断。

cartesian1D 将一个角色投影到直线，polar1D 将一个角色投影到圆周。两者不需要伪造第二个数据字段，轴的方向应服从实际一维空间。

直角一维投影的未用维度落在基线；极坐标一维以一个角度角色与固定半径投影，半径按可用半径的比例给出，角度区间可以不是整圆。

React、Vanilla 与 JSON 应能表达同一一维笛卡尔或极坐标，不让 adapter 拥有额外投影语义。

曲线轴需要在某个位置取得局部原点与切向，才能正确放置刻度和标签。局部标架是几何需求，不取决于坐标是否内置。

区间图元先构造角色空间中的 Cell，由 frame.projectCell 投影几何。可精确表示为矩形或扇区时保留闭式结果，曲线边界需要采样时以轮廓表达；不应让每个 mark 重写同一坐标特例。缺少所需角色不是零宽 Cell，不能静默补值。

坐标声明是纯 JSON，运行时定义提供 schema、角色与投影；内置与自定义走同一注册路径。坐标未提供的 guide 或 cell 能力不能由图元假设存在。

内置坐标提供一维和二维笛卡尔与极坐标。三变量投影需注册定义，并声明角色、投影及可选的轴与 cell 能力，不维护内置三角坐标的专用图元分支。
