# 尺度映射与视觉通道

## 设计目的

同一字段可以用于位置、颜色或分档。尺度决定数据如何映射；通道决定哪个图元属性能消费映射结果。将两者分开，轴与图元才能共享域解释，同时避免把任意映射结果交给不支持它的宿主。

## 决策

### 尺度选择与数值映射

`IRPlotScale` 保存尺度声明；`PositionScale` 是位置映射的消费契约。

命名线性尺度把数据域映射到绘图范围，让坐标与消费图元共享同一映射。显式域优先于从数据推断的域，线性映射并不专属于某一图元。

采用 d3-scale 是为了让域映射、刻度位置和格式化使用一致的数值及时间规则，而不是分别在轴和图元中手写近似公式。

band 尺度将有序类别放入带宽内，point 尺度只给出位置。区间图元需要带宽时不能仅用类别中心猜出边界。

ordinal 以离散域按顺序选择离散输出；颜色是典型消费方，但“枚举映射”与“绘制成什么颜色”是两层语义。显式范围可固定类别与视觉值的对应。

时间域以可序列化的时间值表达；按 UTC 产生刻度和格式，避免同一张图因宿主时区而得到不同边界。时间位置需要真实的日历间隔，不是给线性轴换一组字符串。

作者显式绑定的尺度优先；没有显式选择时，依据字段测量类型与消费角色选择默认映射，让轴、标签与图元能共享域解释。

log、pow、sqrt 表示不同的连续域映射。对数尺度有域的符号与零值限制；几何需要基线时不能假设任一连续映射都能有意义地计算零点。

sequential 将数值位置映射为连续颜色，diverging 还需要语义中点。命名色板可序列化，作者也可显式指定颜色范围；离散类别与连续数值不是同一种颜色选型。

quantize 按等宽区间分档，threshold 依显式断点分档，quantile 依样本分布分档。三者均把连续输入映射到离散输出，但不能相互替代。

内置与自定义尺度应沿相同注册路径，不能为每种算法在坐标或视觉通道中再开分支。注册映射本身不自动赋予某个位置或通道新的语义。

### 视觉通道与属性交付

`IRPlotChannel` 表达视觉通道输入；`ChannelDefinition` 定义如何解析并交付结果。

视觉通道决定字段如何解析、需要何种输出，以及如何把结果交付给图元。数学映射本身不能决定输出是否是半径、颜色还是形状。

自定义视觉通道与内置通道应走同一条解析及交付路径，只把结果送入已有的 Core 图形能力。新增绘制语义不是注册一个通道就能绕开 Core 的理由。

通道只覆盖宿主确实能消费的图形属性；不能仅因某个字段存在于 Core 就允许任意 mark 编码它。改变数据拓扑或几何构造也不是普通样式通道。
