# data v0 Roadmap

提供多个可视化包共享的数据契约、处理与追溯底座。

## 版本方向

| 版本                      | 重点方向                                            |
| ------------------------- | --------------------------------------------------- |
| [v0.1](./v0.1/roadmap.md) | 共享数据层、公开命名与 runtime lineage              |
| v0.2                      | 以精确 Source schema 约束开放数据操作并消除重复解析 |

## 边界与依赖

只接收已验证的共享数据需求，不拥有 renderer、layout 或绘图语义；新增 adapter 与共享 data-view 能力以稳定复用需求为前提。
