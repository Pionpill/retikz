# table v0 Roadmap

把数据或显式内容组织为可绘制、可追溯的二维表格。

## 版本方向

| 版本                      | 重点方向                       |
| ------------------------- | ------------------------------ |
| [v0.1](./v0.1/roadmap.md) | 完整静态表格语法               |
| v0.2                      | 大表可见区、虚拟滚动与交互宿主 |

## 边界与依赖

不拥有单元格编辑、电子表格计算、服务端分页或异步缓存；运行时窗口状态不写入 Table IR。
