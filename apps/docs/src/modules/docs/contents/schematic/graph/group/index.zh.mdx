Group 用可见边界表达“这些内容属于同一组”。它保留 children 的相对布局；需要主动纵向排列内容时使用 [Block](/schematic/graph/block)。本文保持单页，可从用法直接回查 API 与 Schema。安装与宿主初始化见[快速开始](/schematic/graph/get-start)。

## 接入方式

四种写法绘制同一个分组。Vanilla 需要已有 `<div id="diagram"></div>`，卸载时调用 `view.dispose()`。

## 基础用法

### 标题与说明

`caption` 是外框内部的标题与说明区域，支持放在 body 上方或下方，并可按横向或纵向排列。下方控制面板可以调整位置、排列方向和间距。title 默认使用 `sm` 字号且不加粗，description 默认使用 `xs` 字号与较低透明度

### 标签

`labels` 是附着在 Group 外框周围的 Core Node labels。控制面板可以分别调整三个标签的位置；也可以使用方向、边界比例或省略 position。省略时默认位于外框下方左侧，且不改变外框的内容布局

## 扩展用法

嵌套 Group 可表达子系统边界。为外层和内层分别设置 id 后，Relation 可以连接整体外框；内部 Entity 的 id 不会自动加分组前缀。重复实例需要隔离内部名称时，在各实例开启 localNamespace，并在各自内部编写连接。

<ComponentPreview files="group-nested" size="sm" />

需要排列一组对象时，把 FlexLayout / GridLayout 放入 Group children；布局容器决定相对位置，Group 再围住结果。图的整体排布可使用 [Flow](/schematic/diagram/flow/basic)。`Entity.group` 分类色 key 与 Group 容器没有自动关联。

## 错误与限制

- caption 至少提供 title / description 之一；文本使用 `{ text: ... }` 对象。labels 一旦提供必须非空。
- Group 不负责避障、标签碰撞或自动连接。id 必须满足当前命名空间唯一性。
- graphDefaults / graphRules 影响可见后代，不改变当前外框、caption 或边界标签。当前外框用 background / border 设置。
- overflow 只约束 Surface 内容；外围标签仍参与最终视觉边界，不能据此假定标签已被裁剪。

## 实现原理

### 内容与主题

- `children` 直接使用 Core `IRChild`，可以放 Entity、Relation、Group、Node、Path、Scope、Layout、Plot 或其它已注册 composite
- `defaults.node`、`defaults.path`、`defaults.label`、Core `theme`、transform、placement、clip 与 namespace 都保持 Scope 语义
- 命名 Graph Theme 会为 Group 根外框提供 `background`、`border` 与 `cornerRadius` 基线；Source 显式字段最终优先，并对对应 Theme 对象执行完整顶层字段替换，不在 `border` 或 `background` 内部深合并
- `graphDefaults` 影响可见后代 Entity / Relation 与后代 Group / Block 外框；`graphRules` 只匹配后代 Entity / Relation。两者不影响当前 Group 自身外框、caption、boundary labels 或普通 Core children
- 切换内容的 `theme` 或设置 Core `defaults.reset` 不清除作者默认值与规则；当前外框使用传入的主题与祖先默认值
- Group 不自动堆栈 children，不做 routing、避障或 label collision；需要普通排版时，在 children 中显式放入 FlexLayout、GridLayout 或 OverlayLayout
- Group 的显式 `id` 对应外框包络，可以继续通过 Core `IRNodeTarget` 被 Relation 引用

### 外框与标签下沉

Group lowering 会把 caption 与 authored children 组合为 Surface 的唯一内容，把外框下沉为 Standard Surface，并用透明 Core Node 承载 boundary labels。caption 参与外框内部的 allocation；labels 只扩展最终 visual bounds，不改变 Relation 连接 Group 时使用的外框边界。Graph 与 Group 都不保存自动布局结果，也不会为 labels 建立第二套位置或边界类型
