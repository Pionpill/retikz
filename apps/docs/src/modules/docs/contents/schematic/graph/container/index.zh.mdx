`Container` 是 Graph 中组织局部结构的复合元素。它提供外壳、可选 header 与有序 section，但仍复用 Layout 的布局能力；基础用法关注外壳写法，扩展用法覆盖嵌套、继承、直接 IR 与 Vanilla

## 职责一览

| 内容     | 负责什么                                  | 适合场景                            |
| -------- | ----------------------------------------- | ----------------------------------- |
| 基础用法 | 外壳、header、section 与基础布局参数      | 将多个子内容组织成一个区域          |
| 扩展用法 | Entity 继承、嵌套组合、直接 IR 与 adapter | 构建可复用 recipe 或接入非 JSX 输入 |
