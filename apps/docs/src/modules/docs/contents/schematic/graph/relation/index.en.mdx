`Relation` connects authored identities in Graph. It reuses the Core Path contracts for Steps, targets, labels, and marks. Start with React `<Step>` children in basic usage, then move to Draw ways, direct IR, and Vanilla in extended usage

## Responsibilities at a glance

| Content        | Covers                                        | Use it when                           |
| -------------- | --------------------------------------------- | ------------------------------------- |
| Basic usage    | Steps, targets, labels, and common routes     | You connect Entity values in React    |
| Extended usage | Draw ways, canonical IR, Definitions, Vanilla | You use another authoring entry point |
