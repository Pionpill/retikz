`Container` 为局部图式结构提供外壳。基础用法由一个可选 `ContainerHeader`、零个或多个 `ContainerSection` 以及常用的 padding / gap 参数组成

## 用法

```tsx
import { Layout, Node } from '@retikz/react';
import { Container, ContainerHeader, ContainerSection } from '@retikz/graph-react';
```

```tsx
<Layout width={360} height={180}>
  <Container id="order">
    <ContainerHeader>
      <Node position={[0, 0]} text="Order" />
    </ContainerHeader>
    <ContainerSection sectionKey="input">
      <Node position={[0, 0]} text="Input" />
    </ContainerSection>
  </Container>
</Layout>
```

marker 必须是 `Container` 的直接子节点，每个 marker 只拥有一个可绘制 child。脱离 JSX 时，可以传 JSON-safe 的 `header` 与 `sections` props

### 基础布局参数

`padding` 控制外壳与区域内容的内边距，`rowGap` 控制相邻区域之间的间距，`overflow` 控制内容是否可以绘制到外壳之外。Container 复用 Layout 的布局能力，不提供第二套布局 DSL

## API 参考

| 属性        | 类型                                     | 默认值      | 描述                                   |
| ----------- | ---------------------------------------- | ----------- | -------------------------------------- |
| `id`        | `string`                                 | —           | 供 Relation target 使用的稳定 identity |
| `header?`   | `{ child: IRChild; padding? }`           | 省略        | 一个可选 header 区域                   |
| `sections`  | `Array<{ key, role?, child, padding? }>` | `[]`        | 有序且 key 唯一的区域                  |
| `padding?`  | `number` 或 `IRBoxSpacing`               | `8`         | 区域默认内边距                         |
| `rowGap?`   | `number`                                 | `0`         | 相邻区域之间的空白                     |
| `overflow?` | `'visible' \| 'clip'`                    | `'visible'` | 外层内容可见性策略                     |
