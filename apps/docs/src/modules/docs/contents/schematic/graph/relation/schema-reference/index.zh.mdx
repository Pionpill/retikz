本页使用 `@retikz/graph` 公开 schema。Relation 引用的 Core NodeTarget、GeometryLabel、Step 和共享 Graph predicate / status 保留所属 schema 名称，不在此复制定义。Definition 中的函数和参数 schema 属于运行时装配，见[自定义用法](/schematic/graph/relation/custom)。

可解析不等于可绘制：role / kind / predicate 的注册与归属、有效方向，以及端点是否存在仍需运行时验证。省略可选字段不会在 Source 中自动写入主题值。

## RelationRoleSchema

<ZodSchema name="RelationRoleSchema" description="开放关系角色 key，内置值提供提示，自定义 key 必须注册" />

内置角色为 association、dependency、generalization、flow、influence。role 不是自由的展示字符串。

## RelationKindSchema

<ZodSchema name="RelationKindSchema" description="开放关系子类型 key，使用时必须匹配所属 role" />

kind key 在关系 registry 内全局唯一。内置 UML kind 的具体方向与 marker 见[基础用法](/schematic/graph/relation/usage)。

## RelationDirectionSchema

<ZodSchema name="RelationDirectionSchema" description="none、forward、reverse、both 四种语义方向" />

Schema 提供完整词汇，role 与 kind 可以收窄允许集合；none 不代表没有端点或没有路径。

## GraphRelationMarkerAppearanceSchema

<ZodSchema
  name="GraphRelationMarkerAppearanceSchema"
  description="端点 marker 的稀疏外观覆盖"
  descriptions={{
    color: 'marker 主色，缺省随关系主色',
    fill: '填充颜色、主色权重或画笔，缺省跟随已解析的 marker color',
    opacity: 'marker 不透明度',
    lineWidth: 'marker 描边宽度',

这里只控制已有 marker 的外观，不能创建 marker、选择 shape 或改变长度与宽度。结构由 role / kind / predicate 决定。

## GraphRelationRouteStepSchema

复用 Core StepSchema 的位置与几何能力，但拒绝任何 step.label；关系标签统一放在 Relation.labels。RelationSchema 额外要求 route 至少包含两个 step。共享 Step 各变体见 [Path Schema 参考](/kernel/components/path/schema-reference)。
