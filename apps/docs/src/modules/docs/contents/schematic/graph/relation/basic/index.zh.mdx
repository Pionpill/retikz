---
title: Relation 基础用法
description: 用一个精简 record 连接任意 Core target，并编写 direction、labels 与可选 route。
---

`Relation` 通过 Core `NodeTarget` 连接任意命名目标。endpoint、role、direction、labels 与可选 route 直接保存在同一个 Source record 中，最终独立 lower 为一个普通 Core `Path`

## 用法

```tsx
import { Entity, Relation } from '@retikz/graph-react';
import { Layout, Node } from '@retikz/react';
```

```tsx
<Layout width={420} height={160}>
  <Node id="source" position={[90, 80]}>
    输入
  </Node>
  <Entity id="target" role="resource" position={[330, 80]}>
    输出
  </Entity>
  <Relation role="flow" source={{ id: 'source' }} target={{ id: 'target' }} />
</Layout>
```

`source` 与 `target` 是语义真源，不从 route、marker 或视觉方向反推。它们可以指向 Core Node、Coordinate、已解析 Scope，或 lower 后发布这些 target 的上层 composite。省略 `route` 时直接连接 source 与 target；`way` 是 Vanilla/React authoring sugar，会在入口归一为直接 `route`

Relation 直接复用大部分 Core Path 字段。role、kind、predicate 与 Theme 只提供默认；Relation 显式 `stroke`、`dashPattern` 等 Path 字段最终优先，每个 label 也可以单独设置 `textColor`、`font` 与 `opacity`

## 例子

五个内置 role 定义关系的上位语义、source / target 基础解释、允许 direction 与 marker family。Relation **没有内置 predicate**；只有先在当前 provider assembly 注册 predicate definition，才能使用对应 `predicate.name` 和 params

Relation 的整体外观统一由 Theme 管理。下面的 controls 只开放当前 role 真正支持的 kind、direction 和精确 Relation 颜色；页面顶部的 Theme selector 负责切换整体视觉风格

### endpoint、label 与 route

同一 Scope 可以混用省略 route 的直连、直接 `route`、`way` 与 `<Step>` authoring。labels 不进入 route steps；Relation 不根据 endpoint 坐标计算自定义 route，也不比较 authored route 是否连接 endpoint

### association：一般关联

`association` 表示两个对象之间的一般关联。source 与 target 只是稳定记录顺序，默认没有语义方向；显式选择 `forward`、`reverse` 或 `both` 时，kite marker 出现在对应 endpoint

- **默认 / 允许 direction：** `none` / `none`、`forward`、`reverse`、`both`
- **内置 kind：** `uml.aggregation` 与 `uml.composition`，都把 source 解释为 whole、target 解释为 part，并把 direction 固定为 `none`
- **内置 predicate：** 无；领域扩展可以注册 cardinality predicate，并用 params schema 校验 source / target 基数

### dependency：依赖关系

`dependency` 表示 source 依赖 target：source 是依赖方，target 是被依赖方。它固定为 `forward`，基础 marker family 为 target 端的 stealth

- **默认 / 允许 direction：** `forward` / 仅 `forward`
- **内置 kind：** `provenance.derivation`，把 source 细化为派生结果、target 细化为来源记录，并使用 openStealth
- **内置 predicate：** 无；扩展可以声明 `{ optional: boolean, reason: string }` 等 params，具体字段和值域由 predicate definition 决定

### generalization：泛化关系

`generalization` 表示 source 是 target 的更具体类型：source 是 subtype，target 是 supertype。它固定为 `forward`，基础 marker family 为 target 端的 normal

- **默认 / 允许 direction：** `forward` / 仅 `forward`
- **内置 kind：** `uml.realization`，把 source 解释为 implementation、target 解释为 specification，并使用 open marker
- **内置 predicate：** 无；类型系统扩展可以用 params 表达 discriminator 或约束，但 Graph 不执行类型检查

### flow：对象之间的流动

`flow` 表示对象、活动或状态之间发生传递、推进或状态流转。source 与 target 是稳定 route endpoints，有效 direction 决定 circle marker 位于哪一端

- **默认 / 允许 direction：** `forward` / `forward`、`reverse`、`both`
- **内置 kind：** 无；`workflow.branch`、`workflow.feedback` 等领域分类需要自行注册
- **内置 predicate：** 无；工作流扩展可以声明 `{ expression: string, priority: number }` 等条件 params，Graph 只校验和保存，不执行条件

### influence：影响关系

`influence` 表示一个对象对另一个对象产生作用，不要求它们之间存在数据传递或执行依赖。有效 direction 决定 square marker 位于 source、target 或两端

- **默认 / 允许 direction：** `forward` / `forward`、`reverse`、`both`
- **内置 kind：** 无；影响类型由拥有该领域的上层注册
- **内置 predicate：** 无；分析模型可以声明 `{ weight: number, confidence: number }` 等 params，并通过 Theme selector 选择 appearance

## 技术原理

<ComponentAlert
  type="tip"
  title="上手阶段可跳过本节"
  description="需要排查 endpoint 或 authored route 诊断时再回来阅读。"
/>

Relation resolve 只处理 role、kind、predicate、direction 与 Theme，随后 lower 为 Core Path。endpoint 的查找、任意 NodeTarget 引用和 unresolved / duplicate-id 诊断都由 Core namespace 统一负责。省略 route 时 lowering 生成 `move(source) → line(target)`；显式 route 使用完整 Core Position language，并原样交给 Core Path

`RelationSchema` 从 Core `PathBaseSchema` 只排除冲突字段：Path discriminator / kind、`children` / `label`、任意 `marks` 与 fill family。其余 identity、metadata、animation、stacking、paint、stroke、effect、dash、line cap/join、圆角与变换字段保持 Core 名称和语义。`labels` 直接使用 Core `IRGeometryLabel`；label 的显式字体子字段与 Relation 默认字体按字段合并

## API 参考

| 属性                   | 类型                                                                                                                               | 默认值             | 描述                                                                                                                                                      |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id?`                  | `string`                                                                                                                           | —                  | 可选稳定 Core Path id；省略时不维护 Relation 自身 identity                                                                                                |
| `source`               | `IRNodeTarget`<br />- `id: string`<br />- `anchor?: IRAnchorRef`<br />- `offset?: [number, number]`<br />- `boundary?: IRBoundary` | —                  | Core 起点引用<br />- Node、Coordinate、已解析 Scope 或 composite 发布的 target id<br />- 可选 anchor<br />- 可选 world-space 偏移<br />- 可选连接边界覆盖 |
| `target`               | `IRNodeTarget`<br />- `id: string`<br />- `anchor?: IRAnchorRef`<br />- `offset?: [number, number]`<br />- `boundary?: IRBoundary` | —                  | Core 终点引用<br />- Node、Coordinate、已解析 Scope 或 composite 发布的 target id<br />- 可选 anchor<br />- 可选 world-space 偏移<br />- 可选连接边界覆盖 |
| `role`                 | `string`                                                                                                                           | —                  | 已注册的开放关系语义 key                                                                                                                                  |
| `kind?`                | `string`                                                                                                                           | —                  | role 内已注册的稳定子类型                                                                                                                                 |
| `predicate?`           | `{ name: string; params?: IRJsonObject }`                                                                                          | —                  | 已注册 predicate 与 JSON-safe 参数                                                                                                                        |
| `direction?`           | `'none' \| 'forward' \| 'reverse' \| 'both'`                                                                                       | 由 role 决定       | 显式语义方向，必须在 role/kind 允许集合内                                                                                                                 |
| `labels?`              | `Array<IRGeometryLabel>`                                                                                                           | —                  | 完整 Core Geometry Label；每个 label 的显式颜色、字体与透明度覆盖 Relation 默认                                                                           |
| `route?`               | `Array<IRGraphRelationRouteStep>`                                                                                                  | source→target 直连 | 完整 Core Path step sequence；route step 不承载 label                                                                                                     |
| `dashPattern?`         | `Array<number>`                                                                                                                    | 由 role/kind 决定  | 显式 Path dash pattern，最终覆盖关系结构默认                                                                                                              |
| `labelTextForeground?` | `string`                                                                                                                           | 由 Theme 决定      | Relation labels 的默认文本颜色                                                                                                                            |
| `labelFont?`           | `IRFont`                                                                                                                           | 由 Theme 决定      | Relation labels 的默认字体；单个 label 按子字段覆盖                                                                                                       |
| `labelOpacity?`        | `number`                                                                                                                           | 由 Theme 决定      | Relation labels 的默认不透明度；单个 label 显式值优先                                                                                                     |
| `way?`                 | `InputPathWay`                                                                                                                     | —                  | Vanilla/React sugar；入口归一为 `route`                                                                                                                   |
| `children?`            | Core `Step` declarations                                                                                                           | —                  | React route authoring；与 `route`/`way` 互斥                                                                                                              |
| `meta?`                | `IRJsonObject`                                                                                                                     | —                  | Graph 不解释的 JSON-safe 元信息                                                                                                                           |

除上表的 Relation 专属入口外，还可直接使用非冲突 Core Path 字段；需要 area fill、任意 path mark 或其它 Path kind 时，改用 Core `Path`
