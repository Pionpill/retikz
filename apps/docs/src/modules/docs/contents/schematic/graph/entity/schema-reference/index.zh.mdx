本页直接展示 `@retikz/graph` 公开 Zod schema。Entity 拥有 EntitySchema 和 EntityRoleSchema；共享的文字、颜色、位置、predicate 与 status schema 保留名称引用，不在此复制完整定义。React props 和运行时 Definition 见 [API 参考](/schematic/graph/entity/api-reference)。

Source 允许省略 id 和 position，但两者语义不同：id 只在被引用时需要，position 必须在实际绘制前补齐。可选字段省略不代表 schema 已写入主题默认；角色注册、参数适用范围和布局闭环仍由运行时验证。

## EntityRoleSchema

<ZodSchema name="EntityRoleSchema" description="开放角色 key；内置值提供提示，自定义 key 仍须注册" />

内置角色为 participant、activity、event、state、gateway、resource、concept。开放 schema 接受自定义 key，但不会自动注册它；定义与接入见[自定义用法](/schematic/graph/entity/custom)。
