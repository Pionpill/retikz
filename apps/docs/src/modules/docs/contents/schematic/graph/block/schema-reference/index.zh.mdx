---
title: Schema 参考
description: 查询 Block 家族与 CodeBlock 领域数据的公开持久化字段。
---

本页收录 `@retikz/graph` 的 Block、Header、Section、Row、文字输入与 CodeBlock 专属数据输入。共享 Scope、Surface、Theme 字段保留其所属类型，不重复展开。首次使用见[基础用法](/schematic/graph/block/usage)。

尺寸必须非负；同时设置 width 与 minWidth 时，minWidth 不得大于 width。编译期默认值不自动写回 Source。CodeBlockPropsSchema 不含判别字段与 children，自定义实体通过 safeExtend 增加稳定 namespace / type 和领域字段。
