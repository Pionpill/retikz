title: Graph
description: Compose an optional Graph Scope, Block, Group, Entity, Relation, and arbitrary Core content.
---

Graph is an optional context shell. It reuses the complete Core `Scope` surface and adds local `graphTheme` rules for visible Entity and Relation descendants. Automatic layout, routing algorithms, and rendering remain outside Graph.

Block, Group, Entity, and Relation are independent Tier 2 composites that can appear directly in Layout, Scope, or any other Core-child position. Block models code and engineering objects through a fixed Header, Section, Row, and Cell structure. Graph maintains neither a member collection nor an identity index; Core namespace owns references and duplicate-id diagnostics.

## Two host modes

As a top-level React component, Graph creates one Scene host like Layout, Plot, or Table. It does not need an outer Layout:

```tsx
<Graph width={420} height={160}>
  <Entity id="service" role="activity" position={[120, 80]}>
    Service
  </Entity>
</Graph>
```

When an outer Layout already exists, Graph lowers to one Scope that affects only local content and creates no second SVG or Canvas:

```tsx
<Layout width={800} height={220}>
  <Graph transforms={[{ kind: 'translate', x: 80, y: 40 }]}>
    <Entity role="activity" position={[120, 80]}>
      Local content
    </Entity>
  </Graph>
</Layout>
```

Fields such as `theme`, `nodeDefault`, `pathDefault`, `labelDefault`, `arrowDefault`, `resetStyle`, `transforms`, `placement`, `zIndex`, and `clip` belong directly to `IRGraph` and retain Core Scope semantics. `width`, `height`, renderer, runtime, and DOM props belong only to the standalone Scene host; move them to the outer Layout when Graph is embedded.

## Responsibilities

| Member     | Responsibility                                                        | Does not own                                 |
| ---------- | --------------------------------------------------------------------- | -------------------------------------------- |
| Graph      | Core Scope surface and local Graph Theme                              | Member indexes, layout, or routing           |
| Block      | Structured objects, local Flex layout, and addressable Section / Row  | Port models, execution, or automatic routing |
| Group      | Visible arbitrary-content boundary, caption, and boundary labels      | Automatic layout, routing, or avoidance      |
| Entity     | Node semantics and independent lowering to one Core Node              | Generated ids or arbitrary drawing children  |
| Relation   | Core NodeTarget endpoints, relation semantics, and Core Path lowering | Graph membership checks or automatic routing |
| Core child | Free author-ordered composition with Entity and Relation              | Graph-local semantic rules                   |
