title: Entity
description: Represent an actor, task, resource or concept as a semantic node with text.
---

An Entity represents one object in a graph: an actor, a task, a resource or a concept. Choose a `role` for its structure, then supply text and a position. Add an `id` when a relation needs to refer to it.

<ComponentPreview files="/schematic/graph/entity/usage/entity-minimal" size="xs" hideCode />

## Responsibilities and boundaries

Entity contains text, not arbitrary drawing children. Use [Block](/schematic/graph/block) for structured content, or [Group](/schematic/graph/group) to place several elements inside a visible boundary. Graph provides local context when entities share definitions or appearance rules.
