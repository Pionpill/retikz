`Entity` is a targetable graph subject in Graph. Its `role` describes the subject's flow semantics, while a stable `id` lets `Relation` address it explicitly. The pages below separate first-use authoring from cross-element composition and non-React inputs

## Responsibilities at a glance

| Content        | Covers                                              | Use it when                                 |
| -------------- | --------------------------------------------------- | ------------------------------------------- |
| Basic usage    | Roles, default shapes, text, and common variants    | You need a first runnable graph subject     |
| Extended usage | Scope inheritance, recipes, direct IR, and adapters | You compose elements or use non-React input |
