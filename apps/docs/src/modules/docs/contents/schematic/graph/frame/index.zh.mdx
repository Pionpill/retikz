---
title: 复合单元
description: 使用可复用的复合图式元素组织多个子内容、区域和局部结构。
---

复合单元把多个子内容组织成一个可复用的图式元素。它负责自身的组合语义与内部结构，但仍复用 Core 图元和 Layout 布局，不引入独立的几何或布局机制。

当前由 `GraphFrame` 提供带 header 和有序 section 的逻辑外壳。后续需要跨多个基础单元复用的组合，也会归入这一分组。
