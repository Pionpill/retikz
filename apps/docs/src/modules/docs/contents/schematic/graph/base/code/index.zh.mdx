`Entity` 是保留 `graph` namespace 的轻量语义 IR。它通过 `role` 区分 terminal、stage、decision 与 junction，持久化数据对工具和 LLM 保留这一层语义；lower 时每个节点下沉为同 id 的 Core `Node`

## 用法

```tsx
import { Layout, Text } from '@retikz/react';
import { Entity } from '@retikz/graph-react';
```

```tsx
<Layout width={440} height={180}>
  <Entity id="start" role="terminal" position={[20, 70]}>
    Start
  </Entity>
  <Entity id="step" role="stage" position={[130, 70]}>
    Process
  </Entity>
  <Entity id="check" role="decision" position={[250, 70]}>
    <Text>Ready?</Text>
  </Entity>
  <Entity id="join" role="junction" position={[380, 80]} />
</Layout>
```

字符串 children 会成为 Node 文本，也可以像 Core `Node` 一样使用 `<Text>`。适用的 Node props（例如 `color`、`fill`、`padding`、`minimumSize` 和 `position`）继续透传；`role` 提供默认 shape，显式 `shape` 可以覆盖该默认值

| `role`     | 默认 shape           | 逻辑职责           | 默认几何                                     |
| ---------- | -------------------- | ------------------ | -------------------------------------------- |
| `terminal` | capsule（圆角矩形）  | 流程起点或终点     | minimum `48 × 24`，padding `{ x: 12, y: 6 }` |
| `stage`    | 圆角矩形，radius `8` | 流程中的处理或动作 | padding `8`                                  |
| `decision` | 扁菱形，宽高比 `1.8` | 条件或分支         | padding `{ x: 3, y: 2 }`                     |
| `junction` | circle               | 分叉、汇合或延续点 | minimum `8 × 8`，padding `0`                 |

## 视觉变体

逻辑节点使用 Graph 自有的五值 `EntityVariant`，不消费 Core 或 Viz 的全局 Theme Style。`variant` 是单个节点的显式基线；省略时使用最近 `Container.entityVariant`，没有 Frame 作用域时使用 `default`

| variant     | 文本           | 边框             | 背景             |
| ----------- | -------------- | ---------------- | ---------------- |
| `default`   | `currentColor` | `currentColor`   | `none`           |
| `primary`   | `contrast`     | `currentColor`   | `currentColor`   |
| `secondary` | `currentColor` | `none`           | 主要色预合成 10% |
| `outline`   | `currentColor` | 主要色预合成 60% | `none`           |
| `vibrant`   | `currentColor` | `currentColor`   | 主要色预合成 15% |

`secondary` 不带边框。10% / 15% / 60% 是在 Light 的 `#ffffff` 或 Dark 的 `#000000` 上预合成的颜色，不会生成 renderer opacity。显式 `textColor`、`stroke`、`fill` 按字段覆盖 variant 基线，`color` 是主要色；省略时 Light 为 `#000000`、Dark 为 `#ffffff`

## Container 继承

`Container.entityVariant` 为 header、sections、嵌套 `Container` 和 Core `Scope` 子树中的 Entity 设置默认值。嵌套 Frame 建立新的作用域，节点显式 `variant` 优先；`variant="default"` 可以重置外层值。Frame 外壳、divider、Relation 和兄弟分支不受影响

```tsx
import { Container, ContainerSection, Entity } from '@retikz/graph-react';

<Container id="order" entityVariant="secondary">
  <ContainerSection sectionKey="input">
    <Entity id="load" role="stage" position={[0, 0]} />
  </ContainerSection>
  <ContainerSection sectionKey="important">
    <Entity id="validate" role="stage" position={[0, 0]} variant="primary" />
  </ContainerSection>
</Container>;
```

## Direct、React 与 Vanilla 接线

三种入口共享同一份 Graph IR 和 variant lowering 逻辑。直接 IR 使用 package assembly；React 与 Vanilla adapter 不需要传入 ThemeStyle 或额外的 variant registry

```ts
import { compileToScene } from '@retikz/core';
import { createGraphDefinitions, createEntity } from '@retikz/graph';

const node = createEntity({
  id: 'step',
  role: 'stage',
  position: [0, 0],
  text: 'Process',
  color: '#2563eb',
  variant: 'primary',
});
const scene = compileToScene({ version: 1, type: 'scene', children: [node] }, { composites: createGraphDefinitions() });
```

Entity 拥有可持久化的图式身份、role、默认 shape、主要色解释和 `EntityVariant`。它不拥有 graph store、自动布局、障碍规避、交互或领域 recipe。Core 负责 Node 布局、target、编译和 Scene 输出；Graph 只在 lowering 时把有效 variant 投影为普通 Node paint，role 在此边界被丢弃

## API 参考

| API                                  | 包                      | 作用                                                      |
| ------------------------------------ | ----------------------- | --------------------------------------------------------- |
| `role: EntityRoleValue`              | `Entity` 与 IR          | 区分 terminal、stage、decision 与 junction 语义           |
| `variant?: EntityVariantValue`       | `Entity` 与 IR          | 设置节点视觉变体；省略时继承 Frame 默认值或使用 `default` |
| `shape?: NodeShapeInput`             | `Entity` 与 IR          | 覆盖 role 提供的默认 shape                                |
| `entityVariant?: EntityVariantValue` | `Container`             | 设置后代 Entity 的默认变体                                |
| `createEntity()`                     | `@retikz/graph`         | 创建规范 Entity IR                                        |
| `createGraphDefinitions()`           | `@retikz/graph`         | 为直接 IR 创建完整的 Graph Definition 集合                |
| `createGraphReactAdapters()`         | `@retikz/graph-react`   | 创建 Container、Entity、Relation 三个 adapter             |
| `createGraphVanillaAdapters()`       | `@retikz/graph-vanilla` | 创建 Container、Entity、Relation 三个 adapter             |
