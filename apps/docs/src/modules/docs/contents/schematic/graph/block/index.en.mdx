---
title: Block
description: Use an open-content vertical layout container for code and engineering objects, with optional independent structure composites.
---

`Block` is a vertical content container with Graph identity. It accepts arbitrary children; Header, Section, and Row are optional independent composites, and higher-level semantics such as class diagrams can lower through Block

## Responsibilities

| Topic          | Responsibility                                              | Reach for it when            |
| -------------- | ----------------------------------------------------------- | ---------------------------- |
| Basic usage    | Open content, common structures, connections, and styles    | Creating your first Block    |
| Extended usage | Independent code entities, shared content, and theme tokens | Building reusable code nodes |
