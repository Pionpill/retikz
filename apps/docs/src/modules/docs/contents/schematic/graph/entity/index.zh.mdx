`Entity` 是 Graph 中可被 target 的图式对象。它用 `role` 表达对象在流程中的语义，用稳定的 `id` 与 `Relation` 建立显式关系；页面分为基础用法和扩展用法，分别覆盖上手写法与跨元素组合

## 职责一览

| 内容     | 负责什么                                    | 适合场景                      |
| -------- | ------------------------------------------- | ----------------------------- |
| 基础用法 | role、默认形状、文本与常用视觉变体          | 第一个可运行的图式对象        |
| 扩展用法 | 作用域继承、组合 recipe、直接 IR 与 adapter | 跨元素组装或接入非 React 输入 |
