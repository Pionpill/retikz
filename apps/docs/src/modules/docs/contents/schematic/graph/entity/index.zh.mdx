title: Entity · 实体

---

Entity 表达图中的一个对象：它可以是参与者、正在执行的任务，也可以是资源或概念。选择 `role` 决定基础结构，添加文字和位置即可绘制；需要让关系连接它时再提供 `id`。

## 职责一览

| 能力                 | 负责什么                   | 何时使用                     |
| -------------------- | -------------------------- | ---------------------------- |
| role                 | 对象的主要语义与基础轮廓   | 表达参与者、任务、资源等对象 |
| kind / predicate     | 已注册的子类型与带参数语义 | 为多个实体复用领域含义       |
| status / group       | 状态与分类色默认值         | 标记对象状态或语义分组       |
| id / position / text | 引用身份、位置与文字内容   | 放置对象并作为关系端点       |

<ComponentPreview files="/schematic/graph/entity/usage/entity-minimal" size="xs" hideCode />

示例用 activity 表达一个任务。role 提供轮廓，文字说明任务内容，position 决定它出现的位置；连接关系由独立的 Relation 编写。

## 职责与边界

Entity 的内容是文字，不是任意绘图容器。包含多行结构化内容时使用 [Block · 结构块](/schematic/graph/block)；需要把多个元素圈在一个可见边界中时使用 [Group · 分组](/schematic/graph/group)。多个实体共享定义或外观规则时，由 Graph 提供局部上下文。
