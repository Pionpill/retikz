Relation 扩展只定义关系语义、方向约束与 marker/dash 结构，不建立新的 route 或 marker geometry 系统。内置与自定义项共享 Graph registry、resolve、Core Path 与 Arrow provider 路径

## 适用边界

当多个 Relation 共享稳定的关系含义、方向约束或 marker/dash recipe 时注册 Definition。一次性 route 与 labels 直接写在 Relation record；自动 routing 和 compound-edge 算法属于 Diagram，而不是 Relation Definition

## 定义能力

| Definition                | 职责                                                                 |
| ------------------------- | -------------------------------------------------------------------- |
| `defineRelationRole`      | 定义主要语义、默认/允许 direction 与每个 direction 的完整结构 recipe |
| `defineRelationKind`      | 在 role 内收窄 direction，并提供稀疏结构 delta                       |
| `defineRelationPredicate` | 校验 JSON params，并可从 Canonical params 解析稀疏结构 delta         |

role 必须覆盖允许的 direction；kind 只能收窄不能扩大。自定义 marker shape 是 Core Arrow provider key，Graph 不拥有平行 marker registry

## 注入宿主

React 可以把 `relationRoles`、`relationKinds` 与 `relationPredicates` 直接传给使用它们的 `<Relation>`；多个后代共享 definitions 与局部 `graphTheme` 时，再由 `<Graph>` 统一提供。Vanilla 可把相同 arrays 传给 `relation(id, input)` 或 `graph(id, input)`；直接 IR compile 使用 `createGraphDefinitions(options)` 或 `createGraphProviders(options)`

```tsx
<Graph relationKinds={[feedbackKind]} relationPredicates={[priorityPredicate]}>
  <Relation
    id="feedback"
    role="flow"
    kind="workflow.feedback"
    predicate={{ name: 'workflow.priority', params: { urgent: true } }}
    source={{ id: 'review' }}
    target={{ id: 'revise' }}
    way={['review', 'revise']}
  />
</Graph>
```

## 执行机制

Relation 先校验有效 direction，再按 role、kind 与 predicate 解析完整 marker/dash 结构，并按 Theme rules 解析 appearance。endpoint identity 由 Core namespace 在 Path 编译时解析；authored route 原样进入 Core `Path`，marker 缩短、provider lookup 与 renderer 输出仍由 Core/Render 拥有

## 错误与限制

- 重复 key、覆盖内置 key、未注册 role/kind/predicate 或 role 归属不匹配时 fail-loud
- role 的默认 direction 不在 allowed set、缺少对应完整 recipe，或 kind 扩大 allowed set 时 Definition 创建失败
- predicate params 未通过自身 Zod schema 时，resolver 不会执行
- Relation 不根据 endpoint 坐标计算 authored route，也不比较 route 首尾；省略 route 时生成 source→target 直连
- 缺少自定义 Arrow provider 时通过 Core registry 报错，不回退到内置 marker

## API 参考

| 公开导出                                                       | 用途                                                        |
| -------------------------------------------------------------- | ----------------------------------------------------------- |
| `defineRelationRole` / `RelationRoleDefinition`                | 定义方向约束与完整 role recipe                              |
| `defineRelationKind` / `RelationKindDefinition`                | 定义 role 内稳定子类型与方向收窄                            |
| `defineRelationPredicate` / `RelationPredicateDefinitionInput` | 定义带类型安全 JSON params 的 predicate                     |
| `RelationRole` / `RelationKind` / `RelationDirection`          | 查询内置语义与 direction 词汇                               |
| `GraphDefinitionOptions`                                       | 在 Graph 包族 provider assembly 中装配 Relation definitions |
