当 React `<Step>` children 不是唯一作者入口时，Relation 仍只保存一份 canonical IR。Draw way 在入口归一为 Step，直接 IR 使用 canonical `children`，Vanilla adapter 则把 embed 接入同一条 Definition lowering 路径

## 扩展边界

Relation 扩展用法适合直接生成 JSON-safe 图式数据、复用 Draw 的 way DSL，或从 Vanilla 组装 figure。它不提供自动路由、障碍规避、独立 route model 或 Relation 专属几何

## Draw way

`way` 是作者输入，不属于 `RelationSchema`。factory、React 或 Vanilla 会通过 Core 的 `parseWay()` 将它归一为 canonical `children`；`children` 与 `way` 必须且只能提供一个

```ts
import { DrawWay } from '@retikz/core';
import { createRelation } from '@retikz/graph';

const relation = createRelation({
  id: 'edge',
  role: 'flow',
  way: ['start', DrawWay.Hv, 'step'],
});
```

同时提供或同时省略两个入口都会 fail-loud；归一后持久化数据只保留 `children`

## 直接 IR 与 Definition 注入

直接 JSON 必须写 canonical Step 序列，并显式注入 `RelationDefinition`，或使用完整的 Graph Definition 集合

```ts
import { compileToScene } from '@retikz/core';
import { createGraphDefinitions, createRelation } from '@retikz/graph';

const relation = createRelation({
  id: 'edge',
  role: 'flow',
  children: [
    { kind: 'move', to: 'start' },
    { kind: 'line', to: 'step', label: { text: 'next' } },
  ],
});

const scene = compileToScene(
  { version: 1, type: 'scene', children: [relation] },
  { composites: createGraphDefinitions() },
);
```

`role` 只保留在 Graph IR，不会隐式写入 Path `meta` 或 Scene primitive

## Vanilla adapter

Vanilla 使用 embed id 编写，`RelationInputEmbedAdapter` 会在内部派生 canonical `id` 并接入同一份 Relation Definition

```ts
import { RelationInputEmbedAdapter, relation } from '@retikz/graph-vanilla';

const embed = relation('edge', { role: 'flow', way: ['start', 'step'] });
const adapters = [RelationInputEmbedAdapter];
```

## 技术原理

  type="tip"
  title="上手阶段可跳过本节"

`RelationDefinition` 只移除 Graph namespace、语义 `type` 与 authored-only `role`，其它字段原样交给 Core stroke Path，并保留 authored `id`。因此 target、label、mark、stroke、变换与错误诊断都沿用 Core Path，而不会出现第二套关系语义

## API 参考

| API                         | 包                      | 作用                                     |
| --------------------------- | ----------------------- | ---------------------------------------- |
| `createRelation()`          | `@retikz/graph`         | 创建并归一 Relation IR                   |
| `createGraphDefinitions()`  | `@retikz/graph`         | 创建直接 IR 所需的 Graph Definition 集合 |
| `RelationInputEmbedAdapter` | `@retikz/graph-vanilla` | 将 Relation embed 接入 Core compile      |
| `relation()`                | `@retikz/graph-vanilla` | 创建带 authored id 的 Relation embed     |
| `way?: WayDSL`              | Relation author input   | 与 `children` 互斥的 Draw 作者语法       |
