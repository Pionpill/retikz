---
title: Graph · 图式
description: 用 Graph、Block、Group、Entity 与 Relation 组合可读、可引用的结构化图式。
---

Graph 用一组可组合组件描述领域中的对象、边界和关系。`Entity` 表达对象，`Relation` 负责可引用的连接，`Group` 划出任意内容的可见边界，`Block` 组织代码和工程对象；可选的 `Graph` 根节点把它们放进同一个局部语义和样式上下文。

Graph 不自动排布成员或规划连线。为对象给出位置后，可以按需接入专门的布局或连线能力。

## 职责一览

| 成员     | 职责                               | 何时阅读                       |
| -------- | ---------------------------------- | ------------------------------ |
| Graph    | 默认值、条件样式与 Theme 上下文    | 多个图式组件需要共享规则时     |
| Entity   | 具有 role、文本和位置的领域对象    | 描述图中的对象                 |
| Relation | 指向已命名对象的关系与连接语义     | 连接两个对象或可见边界         |
| Group    | 任意内容的可见边界、caption 与标签 | 表达范围、阶段或责任边界       |
| Block    | 代码和工程对象的结构化纵向内容     | 需要 Header、Section 与 Row 时 |

## 整体认识

下面的最小图式先声明两个可引用的 Entity，再用 Relation 表达调用。它展示 Graph 的基本协作：对象保留自己的语义与位置，关系只引用对象 id；后续可以用 Group 表达边界，或用 Block 替换需要结构化内容的对象。

## 从哪里开始

- 第一次创建一张对象关系图，从[快速开始](/schematic/graph/get-start)完成一个可运行的最小闭环
- 需要判断 Graph 是否适合当前问题时，先读[简介](/schematic/graph/introduction)
- 已经知道要表达的对象类型时，直接进入 Entity、Relation、Group 或 Block
- 需要自动排布、避障或 routing 时，选择对应的专门能力
