Graph 是 Schematic 领域中可复用图式元素的统一入口。首批元素覆盖常见的逻辑链路：`GraphFrame` 管理可复用外壳与区域；`GraphNode` 通过 `role` 表达终点、步骤、判断与汇合；`GraphConnector` 表达关系。

Graph 负责图中元素的语义与绘制契约，不拥有 `GraphModel`、自动布局、自动避障、命中测试或交互状态。请用 Core 坐标或 Layout 布局放置单元，再用稳定的 `id` 表达显式 target。

## 职责一览

| 成员             | 拥有                                        | 不拥有             |
| ---------------- | ------------------------------------------- | ------------------ |
| `GraphFrame`     | 外壳、header、有序 section 与可复用区域布局 | 图拓扑或自动放置   |
| `GraphNode`      | 中性形状、content、尺寸与语义 role          | 领域状态机         |
| `GraphConnector` | 一条 Core Path 路由和可选的末步 label       | 自动路由或自动避障 |

所有成员都下沉为既有 Core 图元，可通过 React、直接 JSON/IR 或 Vanilla embed 编写。Definition 按 figure 注入，不进入持久化 JSON。
