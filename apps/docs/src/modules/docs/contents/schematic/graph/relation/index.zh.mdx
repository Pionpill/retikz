---
title: Relation
description: 用 Core Path 的作者语法表达对象之间的显式关系，并在需要时接入直接 IR 或 Vanilla。
---

`Relation` 是 Graph 中连接 authored identity 的关系元素。它复用 Core Path 的 Step、target、label 和 mark 契约；基础用法从 React 的 `<Step>` children 开始，扩展用法再进入 Draw way、直接 IR 与 Vanilla

## 职责一览

| 内容     | 负责什么                                      | 适合场景                          |
| -------- | --------------------------------------------- | --------------------------------- |
| 基础用法 | Step、target、label 与常见路径写法            | 在 React 图中连接 Entity          |
| 扩展用法 | Draw way、canonical IR、Definition 与 Vanilla | 接入其它作者入口或排查 lower 边界 |
