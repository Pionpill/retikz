---
title: Relation
description: 用一个 record 保存通用 Core endpoint、关系语义、label 与可选 route。
---

Relation 负责表达“谁与谁存在什么关系”。它通过 Core NodeTarget 引用 Node、Coordinate、Scope 或上层 composite 发布的 target，保存 source/target、role、direction 与可选 kind/predicate；route 只描述怎么画，最终独立 lower 为普通 Core Path。Graph 是可选上下文，不是 Relation 的成员容器

## 职责一览

| 主题     | 职责                                          | 何时查阅            |
| -------- | --------------------------------------------- | ------------------- |
| 基础用法 | endpoint、direction、label 与 route authoring | 连接任意命名 target |
| 扩展用法 | 自定义 role、kind、predicate 与 marker recipe | 建立领域关系语义    |
