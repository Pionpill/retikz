`Block` 是可以被关系引用的开放内容容器。它按声明顺序纵向排列任意 Core 或 Tier 2 child，适合承载代码结构、工程对象或自定义节点内容；Header、Section、Row 与 Cell 只是可选的常见组合

## 用法

```tsx
import { Block, BlockCell, BlockHeader, BlockRow, BlockSection } from '@retikz/graph-react';
import { Node } from '@retikz/react';
```

```tsx
<Block id="user">
  <BlockHeader title={{ text: 'User' }} description={{ text: '领域实体' }} />
  <Node position={[0, 0]}>任意自定义内容</Node>
  <BlockSection title={{ text: '字段' }}>
    <BlockRow id="user.name">
      <BlockCell itemKey="name" grow={1}>
        <Node position={[0, 0]}>name</Node>
      </BlockCell>
    </BlockRow>
  </BlockSection>
</Block>
```

`Block` 不要求 Header 或 Section，也不会按 child 类型重排内容。`BlockHeader`、`BlockSection` 与 `BlockRow` 是可独立使用的 Graph composite；只有 `BlockCell` 必须放在 `BlockRow` 内，并且恰好承载一个 child

### 开放内容

### 布局组合

Block 把 authored children 交给纵向 FlexLayout，再由 Standard Surface 提供外框。Header 使用横向布局，Section 使用纵向布局，Row 把每个 Cell 映射为横向 Flex item；它们各自拥有 Definition 和 provider，因此也能脱离 Block 独立编译

Block、Section 与 Row 的 `gap`、padding 和外观默认在 lowering 时生效，不写回稀疏 Source IR。空 children 仍保留稳定的 Scope → Surface → Flex 根形状

### Identity 与主题

Block、Section 与 Row 支持完整的 Core Scope，包括 `localNamespace`。显式 `id` 发布到实际 Core namespace，且不会自动添加 Block 前缀；重复 id、不可见 target、anchor 与 boundary 失败继续由 Core 诊断

`graphTheme` 只穿过已知的 Graph、Group、Block、Header、Section、Row 和 Core Scope 内容边界，投影到可见 Entity / Relation。它不会直接样式化结构 shell、普通 Core child 或未知 Tier 2 composite

## API 参考

Direct IR、React 与 Vanilla 入口会产出相同的 JSON-safe Source。Block、Section 与 Row 复用完整 Core Scope 和 Standard Surface 字段；下表只展开本页组件增加或重新约束的字段

### Block

| 属性            | 类型                         | 默认值          | 描述                                      |
| --------------- | ---------------------------- | --------------- | ----------------------------------------- |
| `children?`     | `ReadonlyArray<IRChild>`     | —               | 任意有序 children；React 中为 `ReactNode` |
| `graphTheme?`   | `IRGraphThemeLayer`          | —               | Block 局部 Graph Theme                    |
| `width?`        | `number`                     | —               | 包含水平 padding 的外层固定总宽度         |
| `minWidth?`     | `number`                     | —               | 包含水平 padding 的外层最小总宽度         |
| `gap?`          | `number`                     | `8`             | children 之间的纵向间距                   |
| `padding?`      | `SurfaceInput['padding']`    | `8`             | 外层内边距                                |
| `background?`   | `SurfaceInput['background']` | transparent     | 外层背景                                  |
| `border?`       | `SurfaceInput['border']`     | lightgray / `1` | 外层边框                                  |
| `cornerRadius?` | `number`                     | `8`             | 外层圆角                                  |
| `overflow?`     | `'visible' \| 'clip'`        | `'visible'`     | Surface overflow 语义                     |

### BlockHeader

| 属性           | 类型          | 默认值 | 描述                                     |
| -------------- | ------------- | ------ | ---------------------------------------- |
| `icon?`        | `IRChild`     | —      | 文字列左侧至多一个任意 child             |
| `title`        | `IRBlockText` | 必填   | 主标题；默认 `sm`、普通字重、opacity `1` |
| `description?` | `IRBlockText` | —      | 次要说明；默认 `xs`、opacity `0.7`       |
| `trailing?`    | `IRChild`     | —      | 文字列右侧至多一个任意 child             |

### BlockSection

| 属性        | 类型                     | 默认值 | 描述                     |
| ----------- | ------------------------ | ------ | ------------------------ |
| `title?`    | `IRBlockText`            | —      | children 之前的可选标题  |
| `children?` | `ReadonlyArray<IRChild>` | —      | 任意有序 children        |
| `gap?`      | `number`                 | `4`    | Section items 的纵向间距 |

Section 默认使用 `8` padding、`lightgray / 0.04` 背景、`lightgray / 1` 边框与 `8` 圆角，并复用完整 Scope / Surface 字段

### BlockRow 与 BlockCell

| 属性                                          | 类型                         | 默认值      | 描述                                       |
| --------------------------------------------- | ---------------------------- | ----------- | ------------------------------------------ |
| `row.children?`                               | `ReadonlyArray<IRBlockCell>` | —           | 有序 Row-local Flex items                  |
| `row.gap?`                                    | `number`                     | `8`         | Cell 之间的横向间距                        |
| `cell.key`                                    | `string`                     | 必填        | Row 内 Flex item key；React 使用 `itemKey` |
| `cell.child`                                  | `IRChild`                    | 必填        | 恰好一个任意 child                         |
| `cell.margin?`                                | Flex item margin             | `0`         | 复用 FlexLayout item 契约                  |
| `cell.basis?`                                 | Flex item basis              | `'content'` | 复用 FlexLayout item 契约                  |
| `cell.grow?`                                  | `number`                     | `0`         | 剩余空间增长权重                           |
| `cell.shrink?`                                | `number`                     | `1`         | 空间不足时收缩权重                         |
| `cell.min?` / `cell.max?` / `cell.alignSelf?` | Flex item fields             | —           | 复用 FlexLayout item 契约                  |

Row 默认使用 `8` padding 与 `8` gap，背景透明且不设置边框或圆角，并复用完整 Scope / Surface 字段
