`Block` 是可以被关系引用的开放内容容器。它按声明顺序纵向排列任意 Core 或 Tier 2 child，适合承载代码结构、工程对象或自定义节点内容；Header、Section 与 Row 只是可选的常见组合

## 用法

```tsx
import { Block, BlockHeader, BlockRow, BlockSection } from '@retikz/graph-react';
```

```tsx
<Block id="user">
  <BlockHeader title="User" description="领域实体" />
  <BlockSection title="字段">
    <BlockRow content={['name', 'string']} />
  </BlockSection>
</Block>
```

`Block` 提供 `BlockHeader`、`BlockSection` 与 `BlockRow` 等内置组件，同时也允许放置任意 retikz 组件

## 例子

### 内置组件

Block family 提供四个常用的内置组件：

| 元素           | 职责                                                        |
| -------------- | ----------------------------------------------------------- |
| `Block`        | 提供可被关系引用的外层纵向布局与可见边界                    |
| `BlockHeader`  | 展示必填 title 与可选 description，并提供 icon / trail slot |
| `BlockSection` | 为一组有序内容提供可选标题与独立边界                        |
| `BlockRow`     | 用 `content` 横向排列一个或多个文本项                       |

下面的 playground 只使用内置组件组合最小数据结构。第一个 Section 始终存在；controls 可以为它添加额外 Row，或添加第二个 Section，并分别调整 Block 直接 children、Section 内部 items 与 Row 内容项之间的间距。Row 使用横向 Flex 布局：一个内容项占满可用宽度，两个内容项按 1:1 均分，三个内容项按 1:1:1 均分；每项既可以是字符串，也可以是带局部文字样式的 `IRBlockText` 对象。Row content 默认使用 `sm` 字号；等分所需的 `basis: 0`、`grow: 1`、`shrink: 1` 与 `min: 0` 是 lowering 默认值，不会写回输入 Source IR

### 布局组合

Block 把 authored children 交给纵向 FlexLayout，再由 Standard Surface 提供外框。Header 外层始终按 icon → 文本区 → trail 横向排列，文本区中的 title 与 description 默认纵向，也可以改为横向；Section 使用纵向布局。Row 的 `content` 复用 Header / Section 的 `IRBlockText`，在 lowering 中生成无外框的普通 Core Node 并保留显式文字样式；`children` 则把任意直接 child 映射为横向等分的 Flex item。它们各自拥有 Definition 和 provider，因此也能脱离 Block 独立编译

Block 的有效 `minWidth` 默认是 `240`；`gap`、padding、外观与尺寸默认都在 resolve / lowering 时生效，不写回稀疏 Source IR。显式 `width` 或 `minWidth` 优先，空 children 仍保留稳定的 Scope → Surface → Flex 根形状

### Identity 与主题

Block、Section 与 Row 支持完整的 Core Scope，包括 `localNamespace`。显式 `id` 发布到实际 Core namespace，且不会自动添加 Block 前缀；重复 id、不可见 target、anchor 与 boundary 失败继续由 Core 诊断

命名 Graph Theme 会为 Block 根外框提供 `background`、`border` 与 `cornerRadius` 基线。Block 上显式编写的对应 Source 字段最终优先，并执行完整顶层字段替换，不会把显式 `border` 与 Theme 中的 dash、opacity 或 width 深合并

`graphTheme` 只穿过已知的 Graph、Group、Block、Header、Section、Row 和 Core Scope 内容边界，投影到可见 Entity / Relation。它不会直接样式化结构 shell、普通 Core child 或未知 Tier 2 composite

## API 参考

Direct IR、React 与 Vanilla 入口会产出相同的 JSON-safe Source。Block、Section 与 Row 复用完整 Core Scope 和 Standard Surface 字段；文本字段的 `IRBlockText` 支持直接传入字符串，也支持带样式覆盖的文本对象；下表只展开本页组件增加或重新约束的字段

Block 外框表中的外观默认值来自 Neutral Graph Theme；同名 Graph Theme Definition 可以替换省略字段的基线，但不会写回 Source

### IRBlockText

| 属性            | 类型          | 默认值 | 描述                                        |
| --------------- | ------------- | ------ | ------------------------------------------- |
| `text`          | `IRTextBlock` | 必填   | 单行字符串或多行文本内容                    |
| `align?`        | Core 文本对齐 | —      | 多行文本块的对齐方式                        |
| `lineHeight?`   | `number`      | —      | 文本行高                                    |
| `maxTextWidth?` | `number`      | —      | 触发换行的最大文本宽度                      |
| `textColor?`    | Core 文本颜色 | —      | 文本颜色覆盖                                |
| `font?`         | `IRFont`      | —      | 字体 family、size、weight 与 style 的局部值 |
| `opacity?`      | `number`      | —      | 文本透明度                                  |

直接字符串等价于只设置 `text`。该对象只开放文本内容与文字样式，不包含 Node identity、position、padding、fill 或 stroke

### Block

| 属性            | 类型                         | 默认值                       | 描述                                             |
| --------------- | ---------------------------- | ---------------------------- | ------------------------------------------------ |
| `children?`     | `ReadonlyArray<IRChild>`     | —                            | 任意有序 children；React 中为 `ReactNode`        |
| `graphTheme?`   | `IRGraphThemeLayer`          | —                            | Block 局部 Graph Theme                           |
| `width?`        | `number`                     | —                            | 包含水平 padding 的外层固定总宽度                |
| `minWidth?`     | `number`                     | `240`                        | 包含水平 padding 的外层最小总宽度；不写回 Source |
| `gap?`          | `number`                     | `8`                          | children 之间的纵向间距                          |
| `padding?`      | `SurfaceInput['padding']`    | `8`                          | 外层内边距                                       |
| `background?`   | `SurfaceInput['background']` | transparent                  | 外层背景                                         |
| `border?`       | `SurfaceInput['border']`     | `currentColor` / `0.2` / `1` | 外层边框                                         |
| `cornerRadius?` | `number`                     | `8`                          | 外层圆角                                         |
| `overflow?`     | `'visible' \| 'clip'`        | `'visible'`                  | Surface overflow 语义                            |

### BlockHeader

| 属性              | 类型                         | 默认值       | 描述                                                        |
| ----------------- | ---------------------------- | ------------ | ----------------------------------------------------------- |
| `icon?`           | `IRChild`                    | —            | 文本区左侧至多一个任意 child                                |
| `title`           | `IRBlockText`                | 必填         | 支持字符串或文本对象；主标题默认 `base`、粗体、opacity `1`  |
| `description?`    | `IRBlockText`                | —            | 支持字符串或文本对象；次要说明默认 `xs`、opacity `0.7`      |
| `direction?`      | `'horizontal' \| 'vertical'` | `'vertical'` | title 与 description 文本区的排列方向；不改变外层 slot 顺序 |
| `itemGap?`        | `number`                     | `4`          | title 与 description 之间的最小物理间距                     |
| `justifyContent?` | Flex 主轴分布                | `'start'`    | 文本区的主轴剩余空间分布；直接复用 FlexLayout 语义          |
| `trail?`          | `IRChild`                    | —            | 文本区右侧至多一个任意 child                                |

### BlockSection

| 属性        | 类型                     | 默认值 | 描述                           |
| ----------- | ------------------------ | ------ | ------------------------------ |
| `title?`    | `IRBlockText`            | —      | 支持字符串或文本对象的可选标题 |
| `children?` | `ReadonlyArray<IRChild>` | —      | 任意有序 children              |
| `gap?`      | `number`                 | `4`    | Section items 的纵向间距       |

Section 默认使用 `8` padding、`currentColor / 0.037` 背景、无边框与 `8` 圆角，并复用完整 Scope / Surface 字段。背景随当前前景色适配明暗主题，显式 `background` / `border` 优先

### BlockRow

| 属性            | 类型                           | 默认值 | 描述                                                     |
| --------------- | ------------------------------ | ------ | -------------------------------------------------------- |
| `row.content?`  | `IRBlockText \| IRBlockText[]` | —      | 字符串或文本对象；单个占满，多个均分；与 `children` 互斥 |
| `row.children?` | `ReadonlyArray<IRChild>`       | —      | 任意直接 child；单个占满，多个按相同默认值均分           |
| `row.gap?`      | `number`                       | `8`    | Row items 之间的横向间距                                 |

Row 默认不提供 padding（`0`），横向 gap 为 `8`，content 字号为 `sm`，背景透明且不设置边框或圆角，并复用完整 Scope / Surface 字段。显式 `content.font.size` 优先；常规文本及局部文字样式优先使用 `content`，需要完整 Node 外壳、其它 composite 或任意自定义内容时直接使用 `children`。每个直接 child 在 lowering 中使用 `basis: 0`、`grow: 1`、`shrink: 1` 与有效 `min: 0`，这些值不会写回 Source
