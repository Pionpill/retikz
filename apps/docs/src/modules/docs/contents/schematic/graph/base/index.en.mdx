title: Base Units
description: Express logical subjects with Entity and relationships with Relation.
---

Logic nodes are foundational graph elements that can be placed directly in a diagram. `Entity` uses `role` for terminal, stage, decision, and junction semantics while keeping a stable `id`; `Relation` links those authored identities. Use them independently or combine them into a complete local logic flow.

## Responsibilities

| Member   | Expresses                                          | Useful for                                |
| -------- | -------------------------------------------------- | ----------------------------------------- |
| `Entity` | `role`: terminal, stage, decision, or junction     | Starts, ends, steps, decisions, and joins |
| Relation | Explicit relationships between authored identities | Flows, dependencies, and labeled links    |
