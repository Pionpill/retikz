---
title: 结构块
description: 用开放内容的纵向布局容器承载代码和工程对象，并按需组合独立结构组件。
---

结构块（`Block`）表达一个具有 Graph identity 的纵向内容容器。它接受任意 child；Header、Section 与 Row 是可选且可独立使用的组合组件，更高层的类图等语义可以继续下沉到 Block

## 职责一览

| 主题     | 职责                               | 何时查阅         |
| -------- | ---------------------------------- | ---------------- |
| 基础用法 | 组织任意内容、常见结构、连接与样式 | 第一次创建结构块 |
| 内置实现 | 了解结构块的内置语义与默认组合     | 查阅内置实现细节 |
| 扩展用法 | 接入自定义结构、语义与扩展能力     | 建立领域结构语言 |
