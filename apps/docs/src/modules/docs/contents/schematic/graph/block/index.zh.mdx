Block 把一组内容组织成可被关系连接的对象。它按声明顺序纵向布局 children，并提供可见外框；Header、Section 和 Row 是可选的组合组件，也可以独立使用。

## 职责一览

| 组件         | 负责什么                                | 何时使用                           |
| ------------ | --------------------------------------- | ---------------------------------- |
| Block        | 纵向排列任意内容，提供外框和可选引用 id | 数据结构、工程对象或自定义内容节点 |
| BlockHeader  | icon、标题 / 说明、trail 三个区域       | 描述对象身份与摘要                 |
| BlockSection | 带可选标题和背景的纵向区域              | 对字段、方法或步骤分区             |
| BlockRow     | 横向等分文本项或任意 child              | 一行展示名称、类型或多个值         |

Header 描述 User，Section 将字段收在一起，Row 并列显示字段名与类型。外层 Block 决定整体纵向布局与连接边界。

## 职责与边界

只展示一个带文字的语义对象时使用 [Entity](/schematic/graph/entity)。只需要围住已放置内容、保留原有位置时使用 [Group](/schematic/graph/group)。Block 会主动排列内容，但不解释类、接口或函数的业务含义。

需要持久化领域数据并复用同一种结构时，可用 CodeBlock Definition 把数据组合为 Block 内容。连接仍复用 Core 目标引用，不额外建立 Port 模型。
