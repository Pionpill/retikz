`Container` is Graph's composite element for local structure. It provides a shell, an optional header, and ordered sections while reusing Layout for placement. Basic usage covers the shell; extended usage covers nesting, inheritance, direct IR, and Vanilla

## Responsibilities at a glance

| Content        | Covers                                         | Use it when                                          |
| -------------- | ---------------------------------------------- | ---------------------------------------------------- |
| Basic usage    | Shells, headers, sections, and layout props    | You organize several children as a region            |
| Extended usage | Entity inheritance, nesting, recipes, adapters | You build reusable compositions or use non-JSX input |
