This page is generated from public package entry points. It covers the Entity component and props, Vanilla entity and input types, Source factories, role/kind/predicate definitions and assembly entries needed to consume Entity IR directly. See [Basic usage](/schematic/graph/entity/usage) for examples and [Schema reference](/schematic/graph/entity/schema-reference) for persistent fields and constraints.

Definitions are runtime registrations, not Entity IR fields. In React and Vanilla authoring, pass `GraphDefinitionOptions` to Graph only; Entity props and embed input reference registered keys. EntityRoleSchema is an open-key schema; accepting a string does not mean that role is registered. Graph host capabilities remain owned by Graph documentation; Entity interfaces can be looked up here independently.
