This page covers public `@retikz/graph` inputs for Block, Header, Section, Row, text, and CodeBlock domain data. Shared Scope, Surface, and Theme fields retain their owning types. Start with [Basic usage](/schematic/graph/block/usage).

Dimensions must be nonnegative. When width and minWidth are both provided, minWidth cannot exceed width. Compile defaults do not mutate Source. CodeBlockPropsSchema excludes discriminators and children; custom entities add stable namespace / type and domain fields through safeExtend.
