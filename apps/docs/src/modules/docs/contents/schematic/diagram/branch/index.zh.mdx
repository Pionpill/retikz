Branch 表达连续主线、分叉与汇合。节点目录定义标记，分支按顺序引用节点，相邻引用自动连接。不同分支引用同一 ID，就会复用同一个节点。

## 职责一览

| 内容           | 职责                   | 何时阅读       |
| -------------- | ---------------------- | -------------- |
| 基础用法       | 节点、标签、主线与支线 | 第一次绘图     |
| 扩展用法       | 排布、外观与展示说明   | 将图示放入文档 |
| 实现原理与参考 | 内部机制与公开契约     | 排查或接入     |

下面的专题支线与版本主线共享起点和汇合点，每个共享版本始终只有一个标记。
