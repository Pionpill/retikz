This reference covers the three public branch subpaths. Signatures and descriptions are generated from their exports and JSDoc. See [basic usage](/schematic/diagram/branch/usage) for authoring, and [Schema reference](/schematic/diagram/branch/schema-reference) for persistent fields.

Layout definitions are synchronous runtime options, not persistent Source fields. Built-in lanes and custom definitions share registration and output validation. The artifact contains reference routes; clipped and rounded drawing commands belong to Scene. A dash in a default column means no declared default or not applicable.
