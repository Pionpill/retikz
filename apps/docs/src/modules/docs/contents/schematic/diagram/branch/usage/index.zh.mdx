## 接入方式

示例提供 React、Vanilla 和 IR 源码。React 从 `@retikz/diagram-react/branch` 导入组件；Vanilla 使用 `@retikz/diagram-vanilla/branch` 的 `branchDiagram()` 和 `BranchDiagramInputEmbedAdapter`。Direct IR 使用 `namespace: 'diagram', type: 'branch'`，由 `createBranchDiagramProviderContribution()` 注册编译能力。

React 声明保持平级，分支通过 `nodes` 引用节点 ID：

```text
BranchDiagram
├── BranchNode
└── Branch
```

## 节点、标签与主线

`mainBranch` 指定一条已声明分支，使它的节点保持同轨。切换下面的主线，观察 B 是否进入直线主轨；省略时不会按名称推断主线。

标记默认为直径 10 的圆。外侧 `labels` 不会撑大标记，可设置文字、位置、距离及字体。示例将标签放在下方，默认位置则在上方。调整标记尺寸或隐藏标签，观察占位对自动排布的影响。

## 错误与限制

节点和分支各自的 ID 必须唯一。分支不能为空，引用必须存在；同一分支不能重复经过节点，合成路径也不能成环。每个节点必须被引用，独立节点用单节点分支表达。

`BranchNode` 不接受手工位置或正文卡片。`Branch` 不嵌套节点，也没有独立 relations 输入。完整形状与样式字段见参考页。
