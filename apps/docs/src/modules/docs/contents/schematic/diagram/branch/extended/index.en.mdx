## Direction, spacing, and appearance

`layout.direction` accepts right, left, down, and up, defaulting to right. `nodeGap` and `laneGap` both default to 48. They measure clear space along progression and between lanes, including outside-label occupancy, not center-to-center distance. Zero allows occupied bounds to touch.

The preview fixes the A/B/C topology and changes direction, gaps, and branch color. Same-lane routes are straight; cross-lane routes use rounded orthogonal turns. Node occupancy does not overlap, but complex routes are not guaranteed to avoid all crossings or labels.

A shared directed segment is drawn once. Equal effective styles merge; conflicting styles fail instead of using the last declaration.

## Presentation

`presentation` supplies title, description, and legend. `frame` controls the outer frame and region spacing. Authors supply the legend explicitly. Toggle each region below: omission removes its content and occupancy, and enabling it restores the region. The legend circle represents the blue topic node.

## Scenario comparison

These examples reuse the declarations above without adding business-specific APIs.

**Commit history**: commits are nodes and display paths are branches. Consumers convert their parent DAG into ordered paths; Git branch/tag refs may be labels. This example explicitly progresses downward.

**Reading routes**: previous and next articles form the main path; ordered additional reading forms side paths. Arbitrary related or backward links remain page navigation, not cyclic progression paths.
