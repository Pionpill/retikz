## 方向、间距与样式

`layout.direction` 支持 right、left、down、up，默认向右。`nodeGap` 和 `laneGap` 默认均为 48，分别控制推进方向与轨道之间的净距，已考虑外侧标签占位，不是节点中心距；设为 0 允许占位相接。

下面固定 A、B、C 的拓扑，只改变方向、间距和支线颜色。同轨直连，跨轨使用圆角正交过渡。节点占位不会重叠，但不保证复杂连线全局无交叉或避开所有标签。
