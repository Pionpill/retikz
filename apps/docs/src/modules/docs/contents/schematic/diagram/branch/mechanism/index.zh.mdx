## 标签影响占位，不改变标记尺寸

每个节点先作为真实图元测量。markerBounds 描述标记分配边界，visualBounds 包含外侧标签。布局根据可见包络计算净距，连接仍指向标记边界，因此文字测量和绘制消费同一下层契约。

## 主线得到连续轨道

内置 lanes 先给主分支分配轨道，再按分支声明顺序分配未定位节点；共享节点保留已有位置。节点按稳定拓扑序推进，间距考虑标签。同轨段为直线，跨轨段输出正交参考点与半径 8；这不是全局避障算法。

自定义回调收到隔离的测量与拓扑输入。结果必须完整覆盖节点和唯一相邻段，坐标有限，保留推进顺序、主线与净距；通过校验后才能绘制。

## 参考路由与最终路径分工

同一份有效布局同时生成 Graph 连接和 Branch artifact。共享有向段比较有效外观后只绘制一次。Diagram Foundation 装配标题、说明、图例和外框；artifact 坐标统一计入一次装配偏移，世界坐标查询使用空间句柄。

artifact 的 segments 保存参考点和请求圆角半径。Core 将端点裁剪到标记边界，并将圆角展开为 Scene 命令。因此参考端点可以是节点中心，实际接点则位于边界。消费最终绘制几何时读取 Scene，不把 artifact 点列当作最终路径命令。
