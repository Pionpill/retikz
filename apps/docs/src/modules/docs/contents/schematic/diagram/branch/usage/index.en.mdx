## Using this topic

The preview provides React, Vanilla, and IR source. Import React components from `@retikz/diagram-react/branch`. Vanilla uses `branchDiagram()` and `BranchDiagramInputEmbedAdapter` from `@retikz/diagram-vanilla/branch`. Direct IR uses `namespace: 'diagram', type: 'branch'` and registers compilation through `createBranchDiagramProviderContribution()`.

React declarations are siblings. Branches reference node IDs through `nodes`:

```text
BranchDiagram
├── BranchNode
└── Branch
```

## Nodes, labels, and the main branch

`mainBranch` identifies an existing branch whose nodes stay on one lane. Switch it below to see B join the straight main lane. Omitting this field does not infer a main branch from its name.

Markers default to circles with diameter 10. Outside `labels` do not enlarge markers and can specify text, position, distance, and font. This example places labels below; their default position is above. Change marker size or hide labels to observe their effect on layout occupancy.

## Errors and limitations

Node IDs and branch IDs must each be unique. Branches must be nonempty and reference existing nodes. A branch cannot repeat a node, and combined paths must be acyclic. Every node must be referenced; use a single-node branch for an isolated node.

`BranchNode` does not accept authored positions or body cards. `Branch` does not contain nested nodes or independent relations. See the references for the full shape and style surface.
