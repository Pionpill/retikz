---
title: Schema 参考
description: 查询 Branch 持久化输入的字段、默认值与结构约束。
---

这些 Schema 从 `@retikz/diagram/branch` 导出，描述可序列化 Source。首次使用见[基础用法](/schematic/diagram/branch/usage)。运行时回调与布局结果见 [API 参考](/schematic/diagram/branch/api-reference)。

默认值在解析或补全省略配置时应用。形状和标记最小尺寸默认分别为 circle、10；省略 layout 时向右推进，两种净距均为 48。引用、环和共享段样式冲突在编译时结合完整图示校验。
