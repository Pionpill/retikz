本页展示 `@retikz/diagram/flow` 公开的 Flow Source schema。它描述作者可保存和传递的输入；运行时 Layout Definition 属于 [API 参考](/schematic/diagram/flow/api-reference)，不写入 Source。首次编写图示见[基础用法](/schematic/diagram/flow/usage)。

Source 省略由布局计算的位置和路径。运行时选择的 Definition 默认值不会自动写回原始 Source；直接解析 schema 得到的默认字段则是已物化的解析结果。

## FlowLayoutSchema

纵向 linear 布局按直接子容器的最大自然宽度分配空间；子容器为横向行或只有一个横向内容根的 Group。 数值固定直接 Entity 宽度；match-largest 令其最终等宽；fill 在有父级分配的横向行内均分剩余空间，保留自然宽度差异。

`linear` 沿一个方向排列直接子项；`grid` 按物理行列放置。两者都不生成可见外壳，也不能作为 Relation 端点。

## FlowRoutingSchema

`smooth` 仅用于 Relation：`points` 是至少一个有序中间 Target，自动追加关系 target；`tension` 是正数倍率，省略时使用 1。它不搜索或修改经过点。

省略所有控制点表示自动；完整提供表示显式；cubic 只填一个点或填写 mode 均拒绝。贝塞尔仅限 Relation。
