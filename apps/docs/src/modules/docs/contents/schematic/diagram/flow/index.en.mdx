---
title: Flow Diagram
description: Describe site logic as flat, serializable relations, then let a replaceable layout Definition derive positions, group bounds, and routes.
---

Flow Diagram targets site architecture, data flow, and business-process diagrams. Source declares Entities, visible Groups, and shell-free Layouts in separate flat catalogs, while root and container `children` id lists carry containment and order. It keeps root relations and sparse configuration but omits positions and routes that layout can derive.

Graph still owns the drawing semantics of Entity, Group, and Relation. Flow measures them, invokes a layout Definition, then assembles one Scene, artifact, and spatial index. Graph Block structure and connection contracts are not stable yet, so Block is not currently part of Flow Source.
