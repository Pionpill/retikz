Flow is suited to site architecture, data flows, and business processes. Declare the Entities and the Relations connecting them. Add a Group for a visible boundary or a Layout for a fixed row or column arrangement. Flow computes positions and routes, so the Source does not need authored coordinates.

Graph owns the appearance and drawing semantics of Entities, Groups, and Relations. Flow organizes them into a complete diagram. React and Vanilla share the same serializable Flow Source.

The Kernel architecture figure below is drawn with Flow: inputs converge on IR, compilation produces a Scene, and a renderer outputs SVG or Canvas. Its Entities represent the stages, a Group marks the Core boundary, Layout arranges the inputs and outputs, and Relations connect the main data flow and optional supporting capabilities.
