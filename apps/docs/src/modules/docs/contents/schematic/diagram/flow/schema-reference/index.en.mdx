This page displays public Flow Source schemas from `@retikz/diagram/flow`. They describe input an author can save and pass between systems. Runtime Layout Definitions are covered by the [API reference](/schematic/diagram/flow/api-reference) and are not stored in Source. Start with [Basic usage](/schematic/diagram/flow/usage) to author a diagram.

Source omits positions and routes derived by layout. Runtime Definition defaults do not write back to the original Source. Defaults materialized by a direct schema parse are part of that parsed result.

## FlowLayoutSchema

`linear` arranges direct children along one direction. `grid` places them in physical rows and columns. Neither creates a visible shell or acts as a Relation endpoint.

## FlowRoutingSchema

Relation-only `smooth` requires at least one ordered intermediate Target in `points` and appends the relation target automatically. `tension` is a positive multiplier, default 1. It never searches or moves waypoints.

Omit all controls for automatic routing; complete controls select explicit routing. Partial cubic controls and a mode field are rejected. Bezier routing is Relation-only.

For orthogonal routing, `turnPosition` locks 0.25, 0.5 or 0.75 of the source-to-target gap. Omission inherits within orthogonal routing or searches midpoint-first. Aligned endpoints remain straight without avoidance.
