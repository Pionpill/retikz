title: Flow · 流程图
description: 用实体、分组和关系描述流程，由 Flow 自动排布并生成可渲染的流程图。
---

Flow 适合表达站点架构、数据流和业务流程。先声明有哪些 Entity、哪些 Relation 连接它们；需要可见边界时加入 Group，需要固定行列顺序时加入 Layout。Flow 根据这些声明计算位置和连线路径，无须在 Source 中手写坐标。

Graph 负责 Entity、Group 与 Relation 的外观和绘制语义；Flow 将它们组织成完整图示。React 与 Vanilla 使用同一份可序列化的 Flow Source。

下图是用 Flow 绘制的 Kernel 架构示例：输入汇入 IR，经编译得到 Scene，再由 renderer 输出 SVG 或 Canvas。图中的 Entity 表示各环节，Group 标出 Core 边界，Layout 排列输入与输出，Relation 连接主数据流与可选辅助能力。
