## Current repository versions

| Package           | Version | Notes                                                                                                                 |
| ----------------- | ------- | --------------------------------------------------------------------------------------------------------------------- |
| `@retikz/math`    | `0.4.0` | Zero-dependency computational geometry base reused by core and domain packages                                        |
| `@retikz/core`    | `0.4.0` | IR schemas, geometry, parsers, and Scene compiler; zero React / zero DOM                                              |
| `@retikz/render`  | `0.4.0` | SVG descriptors/strings, Canvas 2D, hydration helpers, and animation runtime utilities                                |
| `@retikz/react`   | `0.4.0` | React adapter with SVG / Canvas renderers                                                                             |
| `@retikz/vanilla` | `0.4.0` | Framework-neutral InputScene, processing, SVG / Canvas mounting, hydration, animation controls, and SVG string output |
| `@retikz/tex`     | `0.4.0` | Optional LaTeX lowering via MathJax SVG glyph paths into the core Scene model                                         |

`0.4.0` is the current stable release: it completes the shape-aware boundary `fit` / `gap` convergence and Canvas shadow-opacity fix from the RC phase, then enters SemVer maintenance after release acceptance. No public capability or breaking change was added after `0.4.0-rc.1`. See [Versioning](/about/releases/versioning).

## Feedback

retikz is in the v0.4 RC acceptance phase. Feedback should focus on boundary-fit and spacing compatibility, installation and package-composition issues, unreproducible examples, documentation accuracy, and other compatibility bugs; new capabilities belong in a later release discussion.
