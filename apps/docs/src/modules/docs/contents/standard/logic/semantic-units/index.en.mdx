title: Semantic units
description: Use Terminal, Stage, Decision, and Junction as neutral content-bearing logic units.

The semantic-unit family gives common logic nodes a stable meaning without coupling them to a domain graph. Every unit has an authored `id`, a neutral appearance, and Core-child content where appropriate.

## Usage

```tsx
import { Layout, Node, Scope } from '@retikz/react';
import { Decision, Junction, Stage, Terminal } from '@retikz/standard-react';
```

```tsx
<Layout width={440} height={180}>
  <Scope transforms={[{ kind: 'translate', x: 20, y: 70 }]}>
    <Terminal id="start" role="start">
      <Node position={[0, 0]} text="Start" />
    </Terminal>
  </Scope>
  <Scope transforms={[{ kind: 'translate', x: 130, y: 70 }]}>
    <Stage id="step">
      <Node position={[0, 0]} text="Process" />
    </Stage>
  </Scope>
  <Scope transforms={[{ kind: 'translate', x: 250, y: 70 }]}>
    <Decision id="check">
      <Node position={[0, 0]} text="Ready?" />
    </Decision>
  </Scope>
  <Scope transforms={[{ kind: 'translate', x: 380, y: 80 }]}>
    <Junction id="join" />
  </Scope>
</Layout>
```

`Terminal` content is optional, `Stage` and `Decision` content is required, and `Junction` content is optional. `role` and `category` remain authored fields; they do not invoke a hidden registry.

Direct IR uses `createTerminal`, `createStage`, `createDecision`, or `createJunction` plus the matching Definition. Vanilla uses the corresponding builder and adapter; the adapter derives canonical identity from its embed id.

```ts
import { StageDefinition, createStage } from '@retikz/standard';

const stage = createStage({ id: 'step', content: { type: 'node', position: [0, 0], text: 'Process' } });
const compile = { composites: [StageDefinition] };
```

```ts
import { StageVanillaAdapter, stage } from '@retikz/standard-vanilla';

const embed = stage('step', { content: { type: 'node', position: [0, 0], text: 'Process' } });
const adapters = [StageVanillaAdapter];
```

## How it works

<ComponentAlert
  type="tip"
  title="Optional for everyday use"
  description="Use this section when checking content requirements or neutral appearance defaults."
/>

All four units lower through the same Core child and layout contracts. The semantic type selects defaults and artifact kind; it does not select a domain registry or automatic graph behavior.

## API Reference

### Terminal

| Field         | Type                      | Default                                                                                                          | Description                                                  |
| ------------- | ------------------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| `id`          | `string`                  | —                                                                                                                | Stable authored Terminal identity                            |
| `role`        | `'start' \| 'end'`        | —                                                                                                                | Closed terminal role                                         |
| `content?`    | `IRChild`                 | omitted                                                                                                          | Optional Core child placed inside the capsule                |
| `appearance?` | `TerminalAppearanceInput` | size min `48 × 24`, padding `{ x: 12, y: 6 }`, capsule, visible, neutral style, `boundary: 'shape'`, `zIndex: 0` | Sizing, shape, boundary, style, dash, and stacking overrides |

### Stage

| Field         | Type                   | Default                                                                                                   | Description                                                  |
| ------------- | ---------------------- | --------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| `id`          | `string`               | —                                                                                                         | Stable authored Stage identity                               |
| `category?`   | `string`               | omitted                                                                                                   | Open authored category                                       |
| `content`     | `IRChild`              | —                                                                                                         | Required Core child placed inside the rounded rectangle      |
| `appearance?` | `StageAppearanceInput` | content size, padding `8`, rectangle radius `8`, visible, neutral style, `boundary: 'shape'`, `zIndex: 0` | Sizing, shape, boundary, style, dash, and stacking overrides |

### Decision

| Field         | Type                      | Default                                                                                       | Description                                                  |
| ------------- | ------------------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| `id`          | `string`                  | —                                                                                             | Stable authored Decision identity                            |
| `content`     | `IRChild`                 | —                                                                                             | Required Core child placed inside the diamond                |
| `appearance?` | `DecisionAppearanceInput` | content size, padding `12`, diamond, visible, neutral style, `boundary: 'shape'`, `zIndex: 0` | Sizing, shape, boundary, style, dash, and stacking overrides |

### Junction

| Field         | Type                      | Default                                                                                                                                                          | Description                                                  |
| ------------- | ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| `id`          | `string`                  | —                                                                                                                                                                | Stable authored Junction identity                            |
| `role?`       | `string`                  | omitted                                                                                                                                                          | Open authored role                                           |
| `content?`    | `IRChild`                 | omitted                                                                                                                                                          | Optional Core child; omission selects dot appearance         |
| `appearance?` | `JunctionAppearanceInput` | without content: size min `8 × 8`, padding `0`, circle, dot style (`fill: currentColor`), visible, `boundary: 'shape'`, `zIndex: 0`; with content: neutral style | Sizing, shape, boundary, style, dash, and stacking overrides |

The `appearance` object is a top-level field on each unit input; `size`, `padding`, `overflow`, `shape`, `boundary`, `style`, `dash`, and `zIndex` are fields inside `appearance`. Direct JSON must use Core children, not React nodes.
