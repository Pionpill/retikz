Standard Logic is split by responsibility: `@retikz/standard` provides canonical JSON, schemas, and factories; `@retikz/standard-react` provides React sugar; `@retikz/standard-vanilla` provides Vanilla builders and adapters for composites that still lower at runtime

## Public exports

| Capability | Standard                                                                       | React                                                 | Vanilla                                  |
| ---------- | ------------------------------------------------------------------------------ | ----------------------------------------------------- | ---------------------------------------- |
| LogicFrame | `LogicFrameSchema`, `IRLogicFrame`, `createLogicFrame`, `LogicFrameDefinition` | `LogicFrame`, `LogicFrameHeader`, `LogicFrameSection` | `logicFrame`, `LogicFrameVanillaAdapter` |
| Terminal   | `TerminalSchema`, `IRTerminal`, `createTerminal`                               | `Terminal`                                            | `terminal` (returns a Node)              |
| Stage      | `StageSchema`, `IRStage`, `createStage`                                        | `Stage`                                               | `stage` (returns a Node)                 |
| Decision   | `DecisionSchema`, `IRDecision`, `createDecision`                               | `Decision`                                            | `decision` (returns a Node)              |
| Junction   | `JunctionSchema`, `IRJunction`, `createJunction`                               | `Junction`                                            | `junction` (returns a Node)              |
| Connector  | `ConnectorSchema`, `IRConnector`, `createConnector`, `ConnectorDefinition`     | `Connector`                                           | `connector`, `ConnectorVanillaAdapter`   |
| Callout    | `CalloutSchema`, `IRCallout`, `createCallout`, `CalloutDefinition`             | `Callout`                                             | `callout`, `CalloutVanillaAdapter`       |

The four semantic `IRXxx` types are aliases for Core `IRNode`; they no longer have separate Definitions or artifact schemas

## Semantic Node inputs

The four semantic components accept Core Node props. `id` and `position` are required, string children or `<Text>` become Node text, and `shape` is fixed by the component

```tsx
<Stage id="step" position={[0, 0]}>Process</Stage>
<Decision id="check" position={[80, 0]}><Text>Ready?</Text></Decision>
```

Vanilla builders return canonical `IRNode` values directly and preserve the supplied id

```ts
const step = stage('step', { position: [0, 0], text: 'Process' });
// step.id === 'step'
```

## Definition loading

Only LogicFrame, Connector, and Callout still need runtime Definitions. A Core-only Node scene needs no Standard composite registration

```ts
import { compileToScene } from '@retikz/core';
import { CalloutDefinition, ConnectorDefinition, LogicFrameDefinition } from '@retikz/standard';

compileToScene(scene, { composites: [LogicFrameDefinition, ConnectorDefinition, CalloutDefinition] });
```

## Vanilla identity

Semantic builders use the original id. Connector and Callout targets reference that id directly. LogicFrame, Connector, and Callout adapters retain their own adapter identity rules
