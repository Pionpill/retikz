---
title: Extensions
description: Explicitly select Standard capabilities for direct IR, tooling, and different hosts while reusing Core definitions and registries.
---

The Standard extension layer answers which official capabilities a host should connect. It does not redefine composites or create a second registry. Callers pass the selected Core Definitions directly to existing Core compile entry points.

## Responsibilities

| Topic              | Responsibility                                                      | Reach for it when                                                      |
| ------------------ | ------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Definition loading | Select Definitions, inject Core options, and separate host adapters | Compiling persisted IR or managing the current figure's capability set |
