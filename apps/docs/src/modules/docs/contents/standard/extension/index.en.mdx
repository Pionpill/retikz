---
title: Extensions
description: Explicitly select Standard capabilities for direct IR, tooling, and different hosts while reusing Core definitions and registries.
---

The Standard extension layer answers which official capabilities a host should load. It does not redefine composites or create a second registry. A capability module only groups Core definitions, and a bundle passes selected definitions to existing Core compile entry points.

## Responsibilities

| Topic              | Responsibility                                              | Reach for it when                                            |
| ------------------ | ----------------------------------------------------------- | ------------------------------------------------------------ |
| Capability loading | Combine modules, inject bundles, and separate host adapters | Compiling persisted IR or managing partial and full catalogs |
