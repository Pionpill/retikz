This page uses one Grid to show all three entry points. React and Vanilla are authoring surfaces; the persistence path restores JSON configuration from a database, file, or `localStorage`.

## React

Install the React entry point and its host:

<PackageManagerInstall packages="@retikz/standard-react @retikz/react react react-dom" />

`<Grid>` loads `GridDefinition` locally into the current `Layout`; no manual registration is needed.

```tsx
import { Layout } from '@retikz/react';
import { Grid } from '@retikz/standard-react';
import { createRoot } from 'react-dom/client';

const container = document.querySelector('#diagram');
if (container === null) throw new Error('Missing #diagram container');

createRoot(container).render(
  <Layout width={280} height={170}>
    <Grid bounds={{ start: [20, 20], end: [260, 150] }} line={{ spacing: 20, style: { stroke: 'lightgray' } }} />
  </Layout>,
);
```

## Vanilla

Install the Vanilla authoring entry point and Kernel runtime:

<PackageManagerInstall packages="@retikz/standard-vanilla @retikz/vanilla" />

`grid()` creates a plain-spec embed. `GridVanillaAdapter` contributes the same `GridDefinition` while normalizing the current figure.

```ts
import type { VanillaFigureSpec } from '@retikz/vanilla';

import { grid, GridVanillaAdapter } from '@retikz/standard-vanilla';
import { mountSvg } from '@retikz/vanilla';

const figure = {
  type: 'figure',
  version: 1,
  viewBox: { x: 0, y: 0, width: 280, height: 170 },
  children: [
    grid('paper-grid', {
      bounds: { start: [20, 20], end: [260, 150] },
      line: { spacing: 20, style: { stroke: 'lightgray' } },
    }),
  ],
} satisfies VanillaFigureSpec;

const container = document.querySelector('#diagram');
if (container === null) throw new Error('Missing #diagram container');

mountSvg(container, figure, {
  adapters: [GridVanillaAdapter],
  output: { width: 280, height: 170 },
});
```

Keep this partial array when loading only Grid. To support every current Standard Vanilla embed, import and pass `StandardVanillaAdapters` from the same root entry.

## Load Persisted JSON

When working with IR directly, install the Library source of truth, Core schemas, and your chosen runtime:

<PackageManagerInstall packages="@retikz/standard @retikz/core @retikz/vanilla" />

Persist a complete `IRGrid` rather than only `GridInput`. Complete IR includes `namespace` and `type`, so hosts and tools can identify its capability. A Definition contains functions and cannot enter JSON, so the host must inject it while loading.

```ts
import { SceneSchema } from '@retikz/core';
import { createGrid, GridDefinition, GridSchema } from '@retikz/standard';
import { mountSvg } from '@retikz/vanilla';

const storageKey = 'retikz:grid';

localStorage.setItem(
  storageKey,
  JSON.stringify(
    createGrid({
      bounds: { start: [20, 20], end: [260, 150] },
      line: { spacing: 20, style: { stroke: 'lightgray' } },
    }),
  ),
);

const raw = localStorage.getItem(storageKey);
if (raw === null) throw new Error('Missing persisted Grid');

const storedGrid = GridSchema.parse(JSON.parse(raw));
const scene = SceneSchema.parse({
  type: 'scene',
  version: 1,
  viewBox: { x: 0, y: 0, width: 280, height: 170 },
  children: [storedGrid],
});
const gridCompile = { composites: [GridDefinition] };

const container = document.querySelector('#diagram');
if (container === null) throw new Error('Missing #diagram container');

mountSvg(container, scene, {
  compile: gridCompile,
  output: { width: 280, height: 170 },
});
```

If `GridDefinition` is not provided, Core emits `COMPOSITE_NOT_REGISTERED` and skips the Grid. Other registered or native Core children still compile. When a figure needs more Standard composites, place the corresponding Definitions in the same `composites` array

## Logic Components

The Logic family uses the same three loading paths. React components contribute local Definitions; direct IR injects only the Definitions used by the scene; Vanilla adapters lower embeds and derive canonical IDs.

```tsx
import { Layout, Node, Scope } from '@retikz/react';
import { Connector, Stage, Terminal } from '@retikz/standard-react';

<Layout width={360} height={140}>
  <Scope transforms={[{ kind: 'translate', x: 24, y: 50 }]}>
    <Terminal id="start" role="start">
      <Node position={[0, 0]} text="Start" />
    </Terminal>
  </Scope>
  <Scope transforms={[{ kind: 'translate', x: 190, y: 50 }]}>
    <Stage id="step">
      <Node position={[0, 0]} text="Step" />
    </Stage>
  </Scope>
  <Connector id="edge" from={{ id: 'start' }} to={{ id: 'step' }} label={{ text: 'next' }} />
</Layout>;
```

The equivalent Vanilla target is `{ id: 'start/terminal' }` because `terminal('start', input)` derives `start/terminal`; `stage('step', input)` similarly derives `step/stage`.

```ts
import {
  connector,
  ConnectorVanillaAdapter,
  stage,
  StageVanillaAdapter,
  terminal,
  TerminalVanillaAdapter,
} from '@retikz/standard-vanilla';
import { figure, renderToSvgString, scope } from '@retikz/vanilla';

const input = figure({
  viewBox: { x: 0, y: 0, width: 360, height: 140 },
  children: [
    scope({ transforms: [{ kind: 'translate', x: 24, y: 50 }] }, [
      terminal('start', { role: 'start', content: { type: 'node', position: [0, 0], text: 'Start' } }),
    ]),
    scope({ transforms: [{ kind: 'translate', x: 190, y: 50 }] }, [
      stage('step', { content: { type: 'node', position: [0, 0], text: 'Step' } }),
    ]),
    connector('edge', { from: { id: 'start/terminal' }, to: { id: 'step/stage' }, label: { text: 'next' } }),
  ],
});

const svg = renderToSvgString(input, {
  adapters: [TerminalVanillaAdapter, StageVanillaAdapter, ConnectorVanillaAdapter],
  output: { width: 360, height: 140 },
});
```

For persisted logic IR, parse `TerminalSchema`, `StageSchema`, or another member schema and pass the matching `*Definition` values in `CompileOptions.composites`. See [Logic API Reference](/standard/logic/api-reference) for the complete mapping.

## Next: replace handwritten coordinates with a layout container

Layout JSX uses `FlexLayout`, `GridLayout`, `OverlayLayout`, and direct `LayoutItem` children. The three containers share one `standard.layout` contribution. Direct IR can inject `[FlexLayoutDefinition, GridLayoutDefinition, OverlayLayoutDefinition]`, while Vanilla can pass `StandardLayoutVanillaAdapters`

```tsx
import { Layout, Node, Scope } from '@retikz/react';
import { FlexLayout, LayoutItem } from '@retikz/standard-react';

<Layout width={320} height={120}>
  <FlexLayout gap={8}>
    <LayoutItem kind="flex" itemKey="label" grow={1}>
      <Node position={[0, 0]} text="Label" />
    </LayoutItem>
    <LayoutItem kind="flex" itemKey="value" shrink={0}>
      <Node position={[0, 0]} text="42%" />
    </LayoutItem>
  </FlexLayout>
</Layout>;
```
