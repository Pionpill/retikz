`<Frame>` is Standard's semantic grouping container. It encloses a set of Core Nodes with a default border and `padding`, while preserving an optional title and description as distinct parts in IR. The two parts are horizontal by default and can be switched to a vertical arrangement.

Frame owns only the group boundary and header arrangement; it does not rearrange the body. When Node positions or text sizes change, the border follows the final bounds without duplicate rectangle coordinates.

## Usage

```tsx
import { Layout, Node } from '@retikz/react';
import { Frame, FrameDescription, FrameTitle } from '@retikz/standard-react';
```

```tsx
<Layout width={360} height={210}>
  <Frame id="contract">
    <FrameTitle>Extension contract</FrameTitle>
    <FrameDescription>Builtins and extensions share one Definition</FrameDescription>
    <Node position={[120, 145]} text="Builtin" />
    <Node position={[245, 145]} text="Extension" />
  </Frame>
</Layout>
```

`FrameTitle` and `FrameDescription` are semantic parts consumed directly by `Frame`. They retain Node text, shape, style, font, label, meta, and animation behavior while leaving `position` to Frame; the body accepts at least one direct `Node` child.

| Scenario         | Public entry point                                                                                                        |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------- |
| React            | `Frame`, `FrameTitle`, and `FrameDescription` from `@retikz/standard-react`                                               |
| Vanilla          | `frame`, `frameTitle`, `frameDescription`, and `FrameVanillaAdapter` from `@retikz/standard-vanilla`                      |
| IR / persistence | `FrameSchema`, `FrameTitleSchema`, `FrameDescriptionSchema`, `createFrame`, and `FrameDefinition` from `@retikz/standard` |

See [Get Started](/standard/get-start) for complete Vanilla mounting and persistence flows. This page focuses on Frame composition, styling, and lowering semantics.

### From Frame IR to Core IR

Frame JSON IR does not become a new renderer primitive. `FrameDefinition` validates and matches `standard.frame`, then lowering emits only the `Scope`, `Path`, and `Node` types already understood by Core.

<ComponentPreview files="frame-lowering" hideCode size="xs" />

Frame's responsibility ends at Core IR. A hand-authored `IRFrame` without `FrameDefinition` produces `COMPOSITE_NOT_REGISTERED` and is skipped instead of being guessed by a renderer.

### Bounds, headers, and reserved ids

Lowering places the body in a `${frameId}/content` Scope. Horizontal mode aligns the Title's bottom-left anchor above the body's top-left, then attaches the Description's bottom-left to the Title's bottom-right. Vertical mode lowers Description first and places Title above it, producing the visual Title, Description, body sequence. A single header part aligns directly to the body. Core resolves these anchors after Node text, shape, padding, margin, scale, and rotate layout.

The border is a rectangle Path inside the outer Scope and expands the final header and body bounds by `padding`. `cornerRadius` applies one radius to all four corners; omitting it or setting it to `0` keeps sharp corners, while Core clamps positive values to half the shorter side. Border, body, and headers default to internal `zIndex` values of `-1`, `0`, and `1`; an explicit header `zIndex` is preserved, while Frame's own `zIndex` applies to the complete outer Scope.

Omitted header ids derive `${frameId}/title` and `${frameId}/description`. Frame rejects a body or header that explicitly occupies `frameId`, `${frameId}/content`, or either derived id; other duplicate ids continue to use Core diagnostics.

## API Reference

React, IR, and Vanilla are all validated into `IRFrame` by `FrameSchema`. React declares headers as direct child parts, while IR and Vanilla use JSON-safe `title` and `description` object fields.

### React: `FrameProps`

| Prop               | Type                        | Default        | Description                                                                                                                   |
| ------------------ | --------------------------- | -------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `id`               | `string`                    | —              | Stable identity of the outer Scope                                                                                            |
| `padding?`         | `number \| IRBoxSpacing`    | `8`            | Border spacing around final bounds; precedence is side > axis > default                                                       |
| `gap?`             | `number`                    | `4`            | Gap between adjacent header parts and between the header and body                                                             |
| `headerDirection?` | `FrameHeaderDirectionValue` | `horizontal`   | Horizontal or vertical Title and Description arrangement                                                                      |
| `stroke?`          | `IRPath['stroke']`          | `currentColor` | Border stroke                                                                                                                 |
| `strokeWidth?`     | `number`                    | `1`            | Border stroke width                                                                                                           |
| `cornerRadius?`    | `number`                    | —              | Uniform border corner radius; omitted or `0` keeps sharp corners, with the effective maximum clamped to half the shorter side |
| `strokeOpacity?`   | `number`                    | —              | Border stroke opacity                                                                                                         |
| `dashPattern?`     | `Array<number>`             | —              | Border dash lengths                                                                                                           |
| `dashOffset?`      | `number`                    | —              | Border dash offset                                                                                                            |
| `lineCap?`         | `IRPath['lineCap']`         | —              | Border endpoint style                                                                                                         |
| `lineJoin?`        | `IRPath['lineJoin']`        | —              | Border corner style                                                                                                           |
| `fill?`            | `IRPath['fill']`            | —              | Border interior fill                                                                                                          |
| `fillOpacity?`     | `number`                    | —              | Border fill opacity                                                                                                           |
| `fillRule?`        | `IRPath['fillRule']`        | —              | Border fill rule                                                                                                              |
| `zIndex?`          | `number`                    | —              | Stacking order of the complete Frame Scope                                                                                    |
| `children`         | `ReactNode`                 | —              | At most one Title, one Description, and a non-empty direct Node body                                                          |

### React: `FrameTitleProps` / `FrameDescriptionProps`

| Prop                | Type                           | Default                                                                 | Description                                                 |
| ------------------- | ------------------------------ | ----------------------------------------------------------------------- | ----------------------------------------------------------- |
| `children` / `text` | `ReactNode` / `IRNode['text']` | —                                                                       | Uses Node text conversion and must produce valid Node text  |
| `id?`               | `string`                       | Title: `${frameId}/title`<br />Description: `${frameId}/description`    | May override the derived id without occupying a reserved id |
| `shape?`            | `NodeProps['shape']`           | `rectangle`                                                             | Header Node shape                                           |
| `stroke?`           | `NodeProps['stroke']`          | `none`                                                                  | Header stroke                                               |
| `fill?`             | `NodeProps['fill']`            | `none`                                                                  | Header fill                                                 |
| `padding?`          | `NodeProps['padding']`         | `0`                                                                     | Header Node padding                                         |
| `font?`             | `NodeProps['font']`            | Title: `{ size: 'sm', weight: 600 }`<br />Description: `{ size: 'xs' }` | Shallow-merges with the default font                        |
| `opacity?`          | `number`                       | Title: —<br />Description: `0.7`                                        | Opacity of the complete header Node                         |
| `zIndex?`           | `number`                       | `1`                                                                     | Header stacking order inside Frame                          |

Both also accept public `NodeProps` except `position` and hydration event props, including margin, scale, rotate, label, meta, and animation. Explicit values keep Node semantics and override the defaults above. See [Node](/kernel/components/node/overview) for the complete shared contract.

### IR / persistence: `FrameInput`

| Prop               | Type                        | Default      | Description                                                     |
| ------------------ | --------------------------- | ------------ | --------------------------------------------------------------- |
| `id`               | `string`                    | —            | Outer Scope identity persisted in `IRFrame`                     |
| `headerDirection?` | `FrameHeaderDirectionValue` | `horizontal` | Horizontal or vertical header arrangement                       |
| `title?`           | `FrameTitleInput`           | —            | JSON-safe Node-like Title without `type` or `position`          |
| `description?`     | `FrameDescriptionInput`     | —            | JSON-safe Node-like Description without `type` or `position`    |
| `children`         | `Array<IRNode>`             | —            | Non-empty direct Core Node body; other Frame fields match above |

`FrameHeaderDirection` is the public closed set with `Horizontal: 'horizontal'` and `Vertical: 'vertical'`. `FrameInput` does not accept discriminators. `createFrame(input)` applies schema defaults and returns `IRFrame` with fixed `namespace: 'standard'` and `type: 'frame'`.

### Vanilla: `frame()`

| Prop    | Type                | Default | Description                                                                  |
| ------- | ------------------- | ------- | ---------------------------------------------------------------------------- |
| `id`    | `string`            | —       | Embed identity; the outer Scope id derives as `${id}/frame`                  |
| `input` | `FrameVanillaInput` | —       | Equivalent to `FrameInput` without `id`, including headers and the Node body |

`frameTitle(input)` and `frameDescription(input)` validate and return `IRFrameTitle` and `IRFrameDescription` for reuse in the JSON-safe input passed to `frame()`.
