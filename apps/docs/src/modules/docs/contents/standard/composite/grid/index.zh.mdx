`<Grid>` 是 Standard 的可选 Tier 2 组件。它把范围、格距、对齐、主线和边框保留为少量可持久化的 JSON 字段；只有当前图加载了 `GridDefinition`，它才会下沉为 Core `Path`。

## 用法

```tsx
import { Layout } from '@retikz/react';
import { Grid } from '@retikz/standard-react';
```

```tsx
<Layout width={280} height={170}>
  <Grid bounds={{ min: [20, 20], max: [260, 150] }} spacing={20} lines={{ style: { stroke: 'lightgray' } }} />
</Layout>
```

React 入口会在当前 `Layout` 局部贡献 `GridDefinition`。持久化或非 React 场景可从 `@retikz/standard` 使用 `createGrid`，并在 Core compile options 中显式传入 `GridDefinition`。

| 场景        | 公开入口                                                           |
| ----------- | ------------------------------------------------------------------ |
| React       | `Grid`（`@retikz/standard-react`）                                 |
| Vanilla     | `grid`、`GridVanillaAdapter`（`@retikz/standard-vanilla`）         |
| IR / 持久化 | `GridSchema`、`createGrid`、`GridDefinition`（`@retikz/standard`） |

完整的 Vanilla 挂载与持久化加载流程统一见[快速开始](/standard/get-start)；本页只展开 Grid 自身的字段与语义。

## 示例

### 基础网格

定义网格只需要两个必填属性：

- `bounds` 用 `min` 和 `max` 两个角限定网格覆盖的矩形。两个轴上的 `min` 都必须小于 `max`；默认情况下，网格线只在这个范围内延伸
- `spacing` 决定相邻格线的距离。传数字时，竖线和横线使用相同间距；传 `{ x, y }` 时，`x` 控制相邻竖线的距离，`y` 控制相邻横线的距离

下面的网格覆盖 `[20, 20]` 到 `[260, 150]`，两个方向每隔 20 个用户单位生成一条线。

<ComponentPreview files="grid-basic" size="sm" />

在此基础上，可选属性负责四类决策：

- `origin`：移动格点的对齐基准，也是主线计数的起点
- `lines`：选择竖线、横线、范围边界和普通线样式
- `major`：每隔若干格突出一条主线，并覆盖普通线的部分样式
- `border`：增加独立外框，控制外扩距离、绘制顺序以及网格线是否延伸到外框

## 技术原理

<ComponentAlert
  type="tip"
  title="上手阶段可跳过本节"
  description="只有在直接读写 Grid IR 或排查编译诊断时才需要理解 lowering。"
/>

Grid 的 IR 不直接成为新的渲染图元。lowering 先规范化范围、原点和间距，再分别枚举 x/y 方向的格点，以相对于 `origin` 的索引判断主线，最后按边框顺序组装普通 Core `Path`。

下图从左到右展示这条确定性转换链。输出到达 `Core Path[]` 后，Grid 的职责就结束了。

<ComponentPreview files="grid-lowering" hideCode size="xs" />

每条网格线都会成为一条 `move + line` 路径，边框则成为闭合路径。后续仍由 Core 的既有 compile 与 renderer 消费，因此 renderer 不需要识别 Grid。

未加载 definition 的手写 `IRGrid` 不会被静默解释：Core 会给出 `COMPOSITE_NOT_REGISTERED` 诊断并跳过它。这样 Standard 仍保持按能力动态加载，而不会污染其它图的编译行为。

## API 参考

| 属性      | 类型                                                                                                                               | 默认值       | 描述                                        |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------ | ------------------------------------------- |
| `bounds`  | `{ min: Position; max: Position }`                                                                                                 | —            | 严格二维范围，两个轴上 `min` 必须小于 `max` |
| `spacing` | `number \| { x: number; y: number }`                                                                                               | —            | 统一或分轴的正格距                          |
| `origin`  | `Position`                                                                                                                         | `bounds.min` | 格点与主线计数的对齐基准                    |
| `lines`   | `{ vertical?: boolean;`<br />`horizontal?: boolean;`<br />`includeBoundary?: boolean;`<br />`style?: IRStandardPathStrokeStyle }`  | 两方向可见   | 普通线的方向、补边界与样式                  |
| `major`   | `{ every: number;`<br />`offset?: number;`<br />`style?: IRStandardPathStrokeStyle }`                                              | —            | 主线间隔、索引偏移和浅覆盖样式              |
| `border`  | `{ padding?: number;`<br />`order?: 'behind' \| 'front';`<br />`extendLines?: boolean;`<br />`style?: IRStandardPathBorderStyle }` | —            | 可选边框的外扩、顺序、线段延长和样式        |
