`<Grid>` 是 Standard 的可选 Tier 2 组件。它把范围、格距、对齐、主线和边框保留为少量可持久化的 JSON 字段；只有当前图加载了 `GridDefinition`，它才会下沉为 Core `Path`。

## 用法

```tsx
import { Layout } from '@retikz/react';
import { Grid } from '@retikz/standard-react';
```

```tsx
<Layout width={280} height={170}>
  <Grid bounds={{ min: [20, 20], max: [260, 150] }} spacing={20} lines={{ style: { stroke: 'lightgray' } }} />
</Layout>
```

React 入口会在当前 `Layout` 局部贡献 `GridDefinition`。持久化或非 React 场景可从 `@retikz/standard` 使用 `createGrid`，并在 Core compile options 中显式传入 `GridDefinition`。

### 对齐、边界和边框

`origin` 是格点的对齐基准；`includeBoundary` 只补足未命中的范围边；边框可独立置后并向外延长线段。

## 技术原理

Grid 的 IR 不直接成为新的渲染图元。lowering 先按 `origin` 枚举 x/y 轴格点，并以 origin-relative lattice index 判断主线；随后输出普通 `Path`，最后由 Core 的既有 compile 与 renderer 消费。

未加载 definition 的手写 `IRGrid` 不会被静默解释：Core 会给出 `COMPOSITE_NOT_REGISTERED` 诊断并跳过它。这样 Standard 仍保持按能力动态加载，而不会污染其它图的编译行为。

## API Reference

| 属性      | 类型                                                                                                                               | 默认值       | 描述                                        |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------- | ------------ | ------------------------------------------- |
| `bounds`  | `{ min: Position; max: Position }`                                                                                                 | —            | 严格二维范围，两个轴上 `min` 必须小于 `max` |
| `spacing` | `number \| { x: number; y: number }`                                                                                               | —            | 统一或分轴的正格距                          |
| `origin`  | `Position`                                                                                                                         | `bounds.min` | 格点与主线计数的对齐基准                    |
| `lines`   | `{ vertical?: boolean;`<br />`horizontal?: boolean;`<br />`includeBoundary?: boolean;`<br />`style?: IRStandardPathStrokeStyle }`  | 两方向可见   | 普通线的方向、补边界与样式                  |
| `major`   | `{ every: number;`<br />`offset?: number;`<br />`style?: IRStandardPathStrokeStyle }`                                              | —            | 主线间隔、索引偏移和浅覆盖样式              |
| `border`  | `{ padding?: number;`<br />`order?: 'behind' \| 'front';`<br />`extendLines?: boolean;`<br />`style?: IRStandardPathBorderStyle }` | —            | 可选边框的外扩、顺序、线段延长和样式        |
