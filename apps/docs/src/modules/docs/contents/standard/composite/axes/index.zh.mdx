`<Axes>` 是 Standard 的可选 Tier 2 组件。它把两条坐标轴及其共同原点、箭头、刻度、轴名和背景网格保留为一个紧凑配置，再下沉为 Core `Path` 与 `Node`。

## 用法

```tsx
import { Layout } from '@retikz/react';
import { Axes } from '@retikz/standard-react';

<Layout width={280} height={170}>
  <Axes bounds={{ x: { min: 30, max: 250 }, y: { min: 30, max: 140 } }} origin={[140, 90]} />
</Layout>;
```

React 入口会在当前 `Layout` 局部贡献 `AxesDefinition`。`bounds` 使用直接的用户坐标，不包含 Plot 的数据 scale、formatter 或 guide 语义。

## 示例

### 基础坐标轴

轴线默认在正向端带箭头，轴名默认为 `x` / `y`。`ticks` 与可选 `grid` 都按同一个 `origin` 对齐。

<ComponentPreview files="axes-basic" size="sm" />

格线样式可先写共同的 `grid.style`，再用 `vertical` / `horizontal` 分方向浅覆盖。它只复用 Grid 的格点枚举 helper，不要求当前图同时加载 `GridDefinition`。

## 工作原理

### Vanilla 与直接 IR

```ts
import { axes, AxesVanillaAdapter } from '@retikz/standard-vanilla';

const plane = axes('plane', {
  bounds: { x: { min: -6, max: 6 }, y: { min: -4, max: 4 } },
  ticks: { x: 1, y: 1 },
});
```

持久化场景可从 `@retikz/standard` 调用 `createAxes`，并在 Core compile options 中显式传入 `AxesDefinition`。未加载 definition 的手写 `IRAxes` 会保留 Core 的 `COMPOSITE_NOT_REGISTERED` 诊断。

## API 参考

| 属性     | 类型                                                  | 默认值               | 描述                                     |
| -------- | ----------------------------------------------------- | -------------------- | ---------------------------------------- |
| `bounds` | `{ x: { min; max }; y: { min; max } }`                | —                    | 两个轴的严格范围，默认原点必须落在范围内 |
| `origin` | `Position`                                            | `[0, 0]`             | 轴、格线和刻度的共同原点                 |
| `grid`   | `{ spacing; style?; vertical?; horizontal? }`         | —                    | 可选格线及共同样式、分方向浅覆盖         |
| `axes`   | `{ arrows?: 'none' \| 'positive' \| 'both'; style? }` | 正向箭头             | 两条轴的箭头模式和共同样式               |
| `ticks`  | `{ x?: number; y?: number; size?: number; style? }`   | `size: 6`            | 可按轴启用的正间距刻度，不生成数值文本   |
| `labels` | `{ x?: string \| null; y?: string \| null }`          | `{ x: 'x', y: 'y' }` | 轴名；`null` 只关闭对应方向              |
