title: 布局容器
description: 用 FlexLayout、GridLayout 与 OverlayLayout 替代手写坐标，组合出可复用的通用图形布局。
---

Standard 布局容器把“如何排布子图形”从手写坐标中提取出来。它们分别处理线性分配、二维轨道和同一区域叠放，并能递归组合；Plot、Table、甘特图等领域包可以在内部复用这些能力，同时继续拥有自己的领域语义。

给定相同的可用空间与子图形测量结果，布局求解是确定的，并且不依赖具体渲染后端。文字尺寸仍取决于宿主提供的测量器、字体和字体加载状态。

下面先用弹性布局分行、网格布局分列，再在右侧单元内用叠加布局放置徽标，展示三种容器如何作为普通子图形递归组合。

这个示例使用 `@retikz/standard-react/inspect` 的 `StandardInspectLayout` 装配布局检查器，再用 `InspectFlexLayout`、`InspectGridLayout` 与 `InspectOverlayLayout` 选择具体实例。需要阻止某段 authored 子树继承检查请求时，用 `StandardInspectScope request={false}` 建立硬屏障。基础 Standard 入口不依赖检查包。

## 职责一览

| 组件            | 核心模型                   | 适合解决的问题                     |
| --------------- | -------------------------- | ---------------------------------- |
| `FlexLayout`    | 单主轴、伸展/收缩、换行    | 图例条目、标签带、工具条、线性注释 |
| `GridLayout`    | 二维轨道、跨轨道、自动放置 | 面板、矩阵、刻度区、结构化图形区域 |
| `OverlayLayout` | 同一区域内对齐或局部定位   | 徽标、浮层、注释、叠放图形         |

容器负责通用尺寸分配、间距、对齐、溢出和可观察结果；数据通道、图表语义、表格规则与算法布局仍由对应领域包负责。
