title: FlexLayout

---

`FlexLayout` 沿一个主轴排布任意子图形。它可以把剩余空间分给可伸展项、在空间不足时收缩或换行，同时让固定几何保持真实尺寸、让文本按分配宽度重新排版。

## 用法

```tsx
import { Layout, Node } from '@retikz/react';
import { FlexLayout, LayoutItem } from '@retikz/standard-react';
```

```tsx
<Layout width={360} height={120}>
  <FlexLayout columnGap={8}>
    <LayoutItem kind="flex" itemKey="label" grow={1}>
      <Node position={[0, 0]} text="标签" />
    </LayoutItem>
    <LayoutItem kind="flex" itemKey="value" shrink={0}>
      <Node position={[0, 0]} text="42%" />
    </LayoutItem>
  </FlexLayout>
</Layout>
```

`itemKey` 是布局容器内的 authored identity，不读取 React 保留的 `key`。每个 `LayoutItem` 恰好接受一个 drawable child，或用 `ir` 显式传一个 `IRChild`。

| 场景        | 公开入口                                                                                   |
| ----------- | ------------------------------------------------------------------------------------------ |
| React       | `FlexLayout`、`LayoutItem`（`@retikz/standard-react`）                                     |
| Vanilla     | `flexLayout`、`FlexLayoutVanillaAdapter`（`@retikz/standard-vanilla`）                     |
| IR / 持久化 | `FlexLayoutSchema`、`createFlexLayout`、`IRFlexLayout`、`FlexLayoutDefinition`（Standard） |

### Overflow 与 clip

slot 与真实 allocation 是两个量。固定几何拒绝较小 slot 时，`visible` 保留完整视觉；`clip` 只改变可见区域，typed artifact 仍保留真实 bounds 与 `clipped` 状态。

## 技术原理

<ComponentAlert
  type="tip"
  title="上手阶段可跳过本节"
  description="只有在排查文本重排、固定几何 overflow 或 baseline 行为时才需要理解 probe/replay。"
/>

FlexLayout 先用 `intrinsic.minimum` 与 `intrinsic.natural` probe child，再在主轴 slot 冻结后使用 `exact` 重新 probe。文本可以据此在较窄宽度下增加高度；固定几何也可以让真实 allocation 超出 slot，而不会触发第二轮主轴分配。

每条 line 独立执行有界 grow/shrink：item 命中 `min` 或 `max` 后冻结，剩余空间继续分给未冻结项。最终只 replay 被选中的 probe；未选候选不会发布 primitive、resource、namespace 或 artifact。

## API 参考

`FlexLayoutInput` 是 factory 的作者输入；`IRFlexLayout` 是应用默认值后的 JSON-safe 持久化形态。

React 的 `FlexLayoutProps` 对应下表容器字段，但把 `children` 改为直属 `LayoutItem`；`FlexLayoutItemProps` 把 JSON 的 `key` 命名为 `itemKey`，并要求 `children` 与 `ir` 二选一。

### `FlexLayoutInput`

| 属性              | 类型                                     | 默认值                | 描述                                                                |
| ----------------- | ---------------------------------------- | --------------------- | ------------------------------------------------------------------- |
| `size?`           | `LayoutSizeInput`                        | `content` / `content` | 双轴 allocation 策略；`fixed` 保留作者尺寸，`fill` 需要有限父级空间 |
| `padding?`        | `number` \| `IRBoxSpacing`               | `0`                   | allocation box 到 content box 的内边距                              |
| `overflow?`       | <ApiValues name="LayoutOverflow" />      | `'visible'`           | `clip` 在 container allocation 上创建一个 Scope clip                |
| `direction?`      | <ApiValues name="FlexLayoutDirection" /> | `'row'`               | 主轴及正反向遍历                                                    |
| `wrap?`           | <ApiValues name="FlexLayoutWrap" />      | `'nowrap'`            | 单 line、换行或反向 cross placement                                 |
| `columnGap?`      | `number`                                 | `0`                   | 物理水平方向 item 或 line gap                                       |
| `rowGap?`         | `number`                                 | `0`                   | 物理垂直方向 item 或 line gap                                       |
| `justifyContent?` | `FlexMainDistributionValue`              | `'start'`             | 每条 line 的主轴剩余空间分布                                        |
| `alignItems?`     | <ApiValues name="LayoutAlignment" />     | `'stretch'`           | 默认 cross alignment；column 方向不接受 baseline                    |
| `alignContent?`   | <ApiValues name="LayoutDistribution" />  | `'start'`             | 多 line 的 cross 剩余空间分布                                       |
| `children?`       | `Array<FlexLayoutItemInput>`             | `[]`                  | authored item；同一容器内 `key` 必须唯一                            |

### `FlexLayoutItemInput`

| 属性         | 类型                                 | 默认值        | 描述                                                                        |
| ------------ | ------------------------------------ | ------------- | --------------------------------------------------------------------------- |
| `kind`       | `'flex'`                             | —             | item discriminator；可使用 `LayoutItemKind.Flex`                            |
| `key`        | `string`                             | —             | 当前容器内稳定且非空的 authored identity                                    |
| `child`      | `IRChild`                            | —             | 参与布局的任意 JSON-safe Core child                                         |
| `margin?`    | `number` \| `IRBoxSpacing`           | `0`           | slot 外边距；不进入 child proposal                                          |
| `basis?`     | `'content'` \| `number`              | `'content'`   | 自然主轴 contribution 或有限非负 authored base slot                         |
| `grow?`      | `number`                             | `0`           | 接收正 free space 的有限非负 factor                                         |
| `shrink?`    | `number`                             | `1`           | 乘以 unclamped basis 后用于回收负 free space                                |
| `min?`       | `number`                             | child minimum | 显式值替代 automatic child minimum；child 拒绝时以 allocation overflow 表达 |
| `max?`       | `number`                             | 无上限        | authored main slot 硬上限                                                   |
| `alignSelf?` | <ApiValues name="LayoutAlignment" /> | `alignItems`  | 覆盖当前 item 的 cross alignment                                            |
