The API reference covers stable contracts rather than introductory teaching. The input contract documents the JSON-safe schemas for all three containers and `LayoutItem`. The artifact contract records resolved container, item, and container-specific results. The runtime page explains how definitions, capability presets, Core compilation, React, and Vanilla converge on one execution path.

> This is the reference layer. Start with [Layout containers](/standard/layout), then choose [FlexLayout](/standard/layout/flex-layout), [GridLayout](/standard/layout/grid-layout), or [OverlayLayout](/standard/layout/overlay-layout) for task-oriented guidance.

## Responsibilities

| Topic               | Responsibility                                                       | When to read                                    |
| ------------------- | -------------------------------------------------------------------- | ----------------------------------------------- |
| Contract - Input    | Container configuration, the `LayoutItem` union, and persisted child | Generating, persisting, or validating layout IR |
| Contract - Artifact | Container geometry, item occupancy, overflow, and resolved results   | Reading compile artifacts or diagnosing layout  |
| Runtime             | Definitions, presets, probe/replay, and React or Vanilla wiring      | Integrating a host or loading layout capability |
