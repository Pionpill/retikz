## LayoutItem 联合

### LayoutItemSchema

<ZodSchema
  name="LayoutItemSchema"
  description="由 kind 判别的 FlexLayoutItem、GridLayoutItem 与 OverlayLayoutItem 闭合联合。"
/>

所有 item 共享以下基础字段；具体容器页记录各自增加的分配字段。

| 字段      | 类型                            | 默认值 | 描述                                            |
| --------- | ------------------------------- | ------ | ----------------------------------------------- |
| `kind`    | `'flex' \| 'grid' \| 'overlay'` | —      | 选择拥有该 item 的布局容器                      |
| `key`     | `string`                        | —      | 当前容器内唯一且非空的 authored identity        |
| `child`   | `IRChild`                       | —      | 参与布局的 JSON-safe Core 或已注册 Tier 2 child |
| `margin?` | `number` \| `IRBoxSpacing`      | `0`    | slot 外围间距，不进入 child proposal            |

## Artifact 通用字段

`LayoutArtifactSchema` 是三个具体 payload 的闭合联合。它只描述布局可观察结果，不保存 proposal、probe、replay token、solver 对象或 child 私有 IR。

### LayoutArtifactSchema

<ZodSchema name="LayoutArtifactSchema" description="由 kind 判别的三个 Standard typed layout artifact payload 联合。" />

每个具体 artifact 的 `container` 都包含：

| 字段               | 类型                         | 描述                                                |
| ------------------ | ---------------------------- | --------------------------------------------------- |
| `allocationBounds` | `LayoutArtifactRect`         | 容器最终 allocation rectangle                       |
| `contentBounds`    | `LayoutArtifactRect`         | 扣除 padding 后的 content rectangle                 |
| `visualBounds`     | `LayoutArtifactRect`         | 所有已平移 item visual bounds 的并集                |
| `visibleBounds`    | `LayoutArtifactRect \| null` | overflow policy 后仍可见的并集；无正面积时为 `null` |

每个 `items[]` 条目共享：

| 字段               | 类型                              | 描述                                                  |
| ------------------ | --------------------------------- | ----------------------------------------------------- |
| `key`              | `string`                          | 对应 authored item identity                           |
| `sourceIndex`      | `number`                          | 连续、从零开始的 authored 顺序                        |
| `marginBounds`     | `LayoutArtifactRect`              | resolved margin 包围的完整父级分配区域                |
| `slotBounds`       | `LayoutArtifactRect`              | 不含 margin 的父级分配 slot                           |
| `allocationBounds` | `LayoutArtifactRect`              | child 接受或拒绝 slot 后的真实布局占用                |
| `visualBounds`     | `LayoutArtifactRect`              | stroke、label 等效果形成的保守视觉包络                |
| `visibleBounds`    | `LayoutArtifactRect \| null`      | clipping 后仍可见的视觉区域                           |
| `translation`      | `{ x: number, y: number }`        | replay 前应用的 container-local 平移                  |
| `overflow`         | `{ allocation, visual, clipped }` | 双轴真实占用、视觉包络与裁切状态                      |
| `alignmentGuide?`  | `{ name, position, fallback }`    | 实际用于 placement 的 baseline guide 或 edge fallback |

`slotBounds`、`allocationBounds` 与 `visualBounds` 不能互换：父级分配的 slot 可以被固定几何拒绝，而视觉包络还可能因 stroke 或 label 继续扩大。

## 读取 Artifact

Core artifact envelope 负责 occurrence、namespace 与 composite type；Standard schema 只解析其中的 `value` payload。

```ts
import { compileToScene } from '@retikz/core';
import { FlexLayoutArtifactSchema, StandardLayoutPreset } from '@retikz/standard';

const output = compileToScene(scene, StandardLayoutPreset.compile);
const envelope = output.artifacts.find(
  artifact => artifact.kind === 'composite' && artifact.namespace === 'standard' && artifact.type === 'flexLayout',
);
const artifact = FlexLayoutArtifactSchema.parse(envelope?.value);
```
