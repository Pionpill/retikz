This page is the authoritative contract for persisted Standard layout input. React props and Vanilla builders both produce the canonical JSON described here. The three containers share sizing, padding, overflow, and base item semantics, then add flex distribution, two-dimensional tracks, or overlay positioning.

> This page covers persisted and validated input. See [Runtime](/standard/layout/reference/runtime) for definitions, presets, and host wiring, or [Contract - Artifact](/standard/layout/reference/contract-artifact) for observable solved results.

Every item shares these base fields. Each container page documents its additional distribution fields.

| Field     | Type                            | Default | Description                                               |
| --------- | ------------------------------- | ------- | --------------------------------------------------------- |
| `kind`    | `'flex' \| 'grid' \| 'overlay'` | —       | Selects the layout container that owns this item          |
| `key`     | `string`                        | —       | Non-empty authored identity unique within the container   |
| `child`   | `IRChild`                       | —       | JSON-safe Core or registered Tier 2 child being laid out  |
| `margin?` | `number` \| `IRBoxSpacing`      | `0`     | Spacing around the slot, excluded from the child proposal |

In React, write JSON `key` as `itemKey` and provide `child` through one drawable child or `ir`. `LayoutItem` represents only a direct container item and emits no primitive by itself.
