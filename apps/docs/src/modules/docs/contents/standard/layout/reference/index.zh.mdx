API 参考用于查询稳定契约，不承担入门教学。输入契约集中说明三个容器与 `LayoutItem` 的 JSON-safe schema；产物契约记录求解后的容器、子项和专属布局结果；运行时页说明 Definition、Core 编译、React 与 Vanilla 如何汇入同一条执行链。

> 这里是参考层。开始使用布局容器请从[布局容器](/standard/layout)阅读，再根据排布模型进入[弹性布局](/standard/layout/flex-layout)、[网格布局](/standard/layout/grid-layout)或[叠加布局](/standard/layout/overlay-layout)。

## 职责一览

| 主题        | 职责                                             | 何时查阅                               |
| ----------- | ------------------------------------------------ | -------------------------------------- |
| 契约 - 输入 | 容器配置、`LayoutItem` 联合与可持久化子图形      | 生成、持久化或校验布局 IR              |
| 契约 - 产物 | 容器几何、子项占用、溢出状态与容器专属求解结果   | 读取同次编译的布局产物或排查布局结果   |
| 运行时      | Definition、测量/回放、React 与 Vanilla 适配接线 | 集成宿主、接入能力或理解布局的执行过程 |
