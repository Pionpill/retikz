`<Axes>` is an optional Standard Tier 2 component. It retains a pair of coordinate axes, their shared origin, arrows, ticks, labels, and background grid as one compact configuration, then lowers them to Core `Path` and `Node` primitives.

## Usage

```tsx
import { Layout } from '@retikz/react';
import { Axes } from '@retikz/standard-react';

<Layout width={280} height={170}>
  <Axes bounds={{ x: { min: 30, max: 250 }, y: { min: 30, max: 140 } }} origin={[140, 90]} />
</Layout>;
```

The React entry contributes `AxesDefinition` locally to the current `Layout`. `bounds` uses direct user coordinates and does not introduce Plot data scales, formatters, or guide semantics.

## Examples

### Basic axes

Axis lines have positive-end arrows by default, and labels default to `x` / `y`. Both `ticks` and the optional `grid` align to the same `origin`.

<ComponentPreview files="axes-basic" size="sm" />

Grid lines may start with shared `grid.style` fields and then shallowly override them through `vertical` / `horizontal`. Axes only reuses Grid's lattice helper; it does not require `GridDefinition` to be loaded in the figure.

## How it works

### Vanilla and direct IR

```ts
import { axes, AxesVanillaAdapter } from '@retikz/standard-vanilla';

const plane = axes('plane', {
  bounds: { x: { min: -6, max: 6 }, y: { min: -4, max: 4 } },
  ticks: { x: 1, y: 1 },
});
```

For persisted scenes, call `createAxes` from `@retikz/standard` and explicitly pass `AxesDefinition` to Core compile options. A handwritten `IRAxes` without a loaded definition preserves Core's `COMPOSITE_NOT_REGISTERED` diagnostic.

## API Reference

| Prop     | Type                                                  | Default              | Description                                                         |
| -------- | ----------------------------------------------------- | -------------------- | ------------------------------------------------------------------- |
| `bounds` | `{ x: { min; max }; y: { min; max } }`                | —                    | Strict ranges for both axes; the default origin must be inside them |
| `origin` | `Position`                                            | `[0, 0]`             | Shared origin for axes, grid lines, and ticks                       |
| `grid`   | `{ spacing; style?; vertical?; horizontal? }`         | —                    | Optional grid with shared style and directional shallow overrides   |
| `axes`   | `{ arrows?: 'none' \| 'positive' \| 'both'; style? }` | positive arrows      | Arrow mode and shared style for both axes                           |
| `ticks`  | `{ x?: number; y?: number; size?: number; style? }`   | `size: 6`            | Optional positive tick spacing per axis; no numeric labels          |
| `labels` | `{ x?: string \| null; y?: string \| null }`          | `{ x: 'x', y: 'y' }` | Axis labels; `null` suppresses only that direction                  |
