The Library group contains official drawing capabilities that should not enter minimal Core but remain reusable across domains. Presentation components such as Grid, Axes, Frame, and Legend lower compact configuration to Core primitives. FlexLayout, GridLayout, and OverlayLayout provide generic containers on the Core layout-aware composite contract. Standard Logic adds a domain-neutral vocabulary of `LogicBlockBase`, semantic units, `Connector`, and `Callout`.

## Boundary with Core

The Library extends Core horizontally; it is not another drawing kernel. Each Tier 2 capability owns a JSON-safe schema and lowering logic without introducing parallel base IR, geometry foundations, or renderer semantics.

As a result:

- Kernel installation, compilation, and rendering stay unchanged when the Library is unused.
- Capabilities load per figure. Definitions are not registered globally and never enter persisted JSON.
- Library IR still lowers through Core compile and uses the existing SVG, Canvas, and other renderers.

## Three Packages

| Package                    | Responsibility                                 | Use it when                                        |
| -------------------------- | ---------------------------------------------- | -------------------------------------------------- |
| `@retikz/standard`         | Schemas, factories, Definitions, and lowering  | Validating or persisting IR and compiling directly |
| `@retikz/standard-react`   | Presentation and layout React DSL              | Authoring inside `@retikz/react` `Layout`          |
| `@retikz/standard-vanilla` | Plain-spec helpers and Vanilla Tier 2 adapters | Authoring in browsers or scripts without React     |

All three packages share the same schemas and lowering from `@retikz/standard`. React and Vanilla only connect their authoring surfaces to those capabilities; they do not duplicate semantics.

## Loading Model

| Scenario     | How the capability is loaded                                                                               |
| ------------ | ---------------------------------------------------------------------------------------------------------- |
| React        | A component contributes its Definition locally; `ir` mode receives explicit `composites`                   |
| Vanilla      | An embed uses a partial adapter list or `StandardVanillaAdapters`; direct IR receives explicit definitions |
| Persisted IR | A schema validates JSON and the host selects and injects definitions through `CompileOptions.composites`   |

See [Get Started](/standard/get-start) for all three paths, browse [Presentation](/standard/composite) or [Layout Containers](/standard/layout), combine resolved samples with meaning in [Legend](/standard/composite/legend), and learn how to pass the current figure's Definitions to Core in [Definition Loading](/standard/extension/capability-loading).

See [Logic Components](/standard/logic) for the logic family. It owns authored target contracts, explicit routes, and target-relative placement, but not a `GraphModel`, automatic layout, obstacle avoidance, or interaction.
