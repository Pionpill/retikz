---
title: 表格
description: Table 组件把外部记录或显式 Cell 组织成固定轨道表格，并通过同一份 TableSpec 接入 React、Vanilla 与 SSR。
---

Table 适合二维行列内容：`DetailTable` 把每条外部记录映射成一行，`ManualTable` 直接声明行列与 Cell，`Table` 则消费已经构造好的完整 spec。三种 React 入口最终使用同一套结构、布局和下沉逻辑。

## 用法

```tsx
import { DetailTable } from '@retikz/table-react';
```

```tsx
<DetailTable
  dataRef="scores"
  data={rows}
  columns={[
    { id: 'name', field: 'name', header: '姓名' },
    { id: 'score', field: 'score', header: '分数' },
  ]}
/>
```

有逐条记录的数据时优先用 `DetailTable`；表头、摘要或其它显式网格用 `ManualTable`；持久化或外部生成的完整 TableSpec 用 `Table`。

## 例子

### 明细表

`DetailTable` 按 `columns` 的顺序读取每条记录。列头字符串会自动变成 value Cell；数据仍通过 `data` 在运行时注入，不写入 spec。

### 手工表

`ManualTable` 适合没有外部数据集的显式网格。Cell 地址从 `0` 开始；`rowKinds` 可把一行标记为列头或正文。

### Vanilla 与 SSR

Vanilla API 使用 plain helper，不建立 fluent builder。`detailTable()` / `manualTable()` 只构造 TableSpec；浏览器组合走 `embedTable()` + `createTableAdapter()`，一次性 SSR 走 `renderTable()`。

```ts
import { createTableAdapter, detailTable, embedTable, manualTable, renderTable } from '@retikz/table-vanilla';
import { figure, layer, mount } from '@retikz/vanilla';

const detailSpec = detailTable({
  id: 'scores',
  dataRef: 'scores',
  columns: [
    { id: 'name', field: 'name', header: '姓名' },
    { id: 'score', field: 'score', header: '分数' },
  ],
});

const manualSpec = manualTable({
  rows: 1,
  columns: 1,
  cells: [{ address: { row: 0, column: 0 }, payload: { kind: 'value', value: '合计' } }],
});

const adapter = createTableAdapter();
const view = mount(
  container,
  figure({ layers: [layer('content', [embedTable('scores-panel', detailSpec, { data: { scores: rows } })])] }),
  { adapters: [adapter] },
);

view.update(
  figure({ layers: [layer('content', [embedTable('scores-panel', detailSpec, { data: { scores: nextRows } })])] }),
);
const svg = renderTable(detailSpec, { data: { scores: rows } });
const { manifest } = renderTable(manualSpec, { artifacts: true });
```

### 一份规范，多种入口

React sugar 与 Vanilla helper 都委托 `@retikz/table` 的 `createDetailTableSpec()` / `createManualTableSpec()`，先得到 JSON 可序列化的 TableSpec，再交给同一条 lowering（下沉）管线。外部数据、带函数的自定义 definition 与额外 composite 都属于运行时输入，不会写入 TableSpec。

| 入口                            | 构造结果         | 运行位置              |
| ------------------------------- | ---------------- | --------------------- |
| `DetailTable` / `detailTable()` | detail TableSpec | React 或 Vanilla host |
| `ManualTable` / `manualTable()` | manual TableSpec | React 或 Vanilla host |
| `Table`                         | 已有 TableSpec   | React host            |

单独渲染 React 组件时可以省略 TableSpec `id`，嵌入父级 `Layout` 时则必须提供。Vanilla 嵌入要求 `embedTable(id, ...)` 的 embed id 非空；TableSpec 自身仍可匿名，此时下沉根 id 为 `${embedId}/table`。

### 固定轨道与 manifest

alpha.1 使用统一的 `columnWidth`、`rowHeight` 和可选 `headerHeight`，不会按 Cell 内容自动改变列宽或行高。省略时列宽为 `120`、正文行高为 `32`、间距为 `0`；内容测量、span 与完整 border 属于后续能力。

`onManifest` 只用于 standalone React 组件，并在布局内容变化后通知。SSR 可用 `renderTable(spec, { artifacts: true })` 同时取得 SVG 与相同布局的 manifest。

## API 参考

### Table

| 属性                      | 类型                                           | 默认值  | 描述                                       |
| ------------------------- | ---------------------------------------------- | ------- | ------------------------------------------ |
| `spec`                    | `IRTableSpec`                                  | —       | 完整且可序列化的 Table spec                |
| `data`                    | `ExternalDatasets`                             | `{}`    | 按 spec reference 索引的外部数据集         |
| `structureDefinitions`    | `ReadonlyArray<AnyTableStructureDefinition>`   | `[]`    | 自定义结构 definitions                     |
| `presentationDefinitions` | `ReadonlyArray<AnyCellPresentationDefinition>` | `[]`    | 自定义 Cell presentation definitions       |
| `composites`              | `ReadonlyArray<CompositeDefinition>`           | `[]`    | Cell 内嵌 Tier 2 内容所需 definitions      |
| `onManifest`              | `(manifest: TableLayoutManifest) => void`      | —       | standalone 布局产物通知；嵌入时不支持      |
| `width` / `height`        | `number \| string`                             | —       | SVG 或 Canvas 宿主显示尺寸；不改变固定轨道 |
| `renderer`                | `'svg' \| 'canvas'`                            | `'svg'` | 渲染后端                                   |
| `className` / `style`     | `string`<br />`CSSProperties`                  | —       | 透传给渲染宿主                             |

| 字段        | 类型                        | 默认值         | 描述                                      |
