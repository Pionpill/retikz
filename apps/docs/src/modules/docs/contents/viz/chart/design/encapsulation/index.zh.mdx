---

想画散点图时，作者通常先确定横轴、纵轴和颜色分别对应哪些字段，而不是先逐项组装 Point 图元、比例尺与图例。Chart 让具体图形类型成为入口，由该类型的 `recipe` 补齐常见组合。

## 降低学习与生成成本

直接编写 Plot 时，需要理解图元、通道、比例尺、坐标与辅助元素怎样协作。使用 Chart 时，先选择图形类型，再提供该类型要求的数据字段；常见的 Plot 结构由 recipe 生成。初次使用者可以从熟悉的“散点图”“气泡图”等名称入手，需要定制时再逐步了解底层语法。

让 LLM 直接理解并生成完整的 GoG 图形语法，需要同时推理图元、通道、比例尺和坐标之间的约束，耗费更多推理计算时间，也增加了逐项校验配置的成本。即使配置有效，也未必处理好了特定图形的细节。例如点图需要根据点的大小和位置自动补齐边缘留白；仅要求 LLM 用通用语法自行拼装，难以稳定得到满意的效果。

Chart 尽量减少作者需要提供的配置，并把这些细节封装到具体类型中。点图通过 `recipe.properties.autoPadding` 选择自动留白策略，Chart 将其转换为 Plot 的留白配置，实际绘图仍复用 Plot。LLM 因而可以先判断图形家族和具体类型，再依据精确 schema 填写必需字段与少量选项：散点图需要 `x`、`y`，气泡图还需要 `size`。生成的 Source 可按该类型的 schema 校验；最终效果仍取决于数据、选型和字段映射是否正确。

## 选定类型即可直接使用

根 `type` 表示图形家族，`recipe.chartType` 选择具体类型。每个类型带有自己的字段要求、常量属性和默认图元组合：散点图以点表达观测，连接散点图还需要路径，回归图还包含趋势。作者只需提供数据与对应类型的配置，就能得到包含必要绘图结构的图表，再按需调整属性或组合该类型允许的图元。

保存的 Source 仍是类型、数据和作者选项，不是展开后的 Plot 图元清单。更换字段或调整属性时，同一 recipe 会重新形成所需的绘图配置，作者不必维护生成后的细节。

## Plot 纵向扩展，Chart 横向扩展

Plot 沿图形语法的各层扩展能力：增加图元、数据通道、比例尺、坐标或辅助元素，让新的绘图能力可被不同图形复用。Chart 则沿图形类型横向扩展：用已有的 Plot 能力组合出散点图、气泡图等可直接调用的类型，并为每个类型提供精确的 recipe。新增类型应组合已有能力；遇到缺失的通用绘图能力，再由 Plot 扩展。

| 扩展方向         | 解决的问题           | 例子                   |
| ---------------- | -------------------- | ---------------------- |
| Plot · 纵向能力  | 数据怎样映射并绘制   | 新图元、通道或坐标     |
| Chart · 横向类型 | 某种图形怎样直接使用 | 散点图、气泡图、回归图 |

Chart 的 recipe 负责类型级字段解释、默认值和图元编排；实际的图元、通道、比例尺、坐标、轴与图例由 Plot 提供。Chart 还通过 Standard Surface 与 Layout 组织标题、注记、来源等整图内容。需要快捷配置未覆盖的 Plot 片段时，可使用 `plotExtension`；需要自由组合底层语法时，可直接使用 Plot。
