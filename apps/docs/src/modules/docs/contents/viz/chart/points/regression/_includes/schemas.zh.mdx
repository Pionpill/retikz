#### RegressionExtraMethodSchema

每项必须指定拟合方法，采样与外观沿用上方配置；只生成趋势线。数组顺序决定额外趋势的绘制顺序，不自动分配方法颜色或方法图例。任意一条趋势拟合失败都会使整张图失败。

<ZodSchema
  name="RegressionExtraMethodSchema"
  description="共享观测的额外拟合配置。"
  shallow
  descriptions={{
    method: '必需的拟合方法',
    sampleCount: '覆盖当前组合的采样数量',
    extent: '覆盖当前组合的拟合区间',
    trend: '逐项覆盖当前组合的趋势外观',
  }}
/>

#### RegressionChartMarkSchema

`encodings` 只允许 x、y，各项均可省略且仅接受字段名字符串，不接受 recipe 的完整映射对象。`properties` 复用上方属性的含义与成员结构，但不包含 `autoPadding`、`domainPadding`；省略的配置沿用当前图形可继承的映射与属性。
