线图适合沿时间、数值或有序类别阅读变化。连线依赖序列顺序；输入行顺序、连接顺序和坐标轴顺序需要分别考虑。

## 如何选择

| 图形                                              | 什么时候用                   | 需要的数据                     |
| ------------------------------------------------- | ---------------------------- | ------------------------------ |
| [折线图](/viz/chart/lines/line)                   | 观察一个或多个系列的指标变化 | 位置、指标，可选系列和排序字段 |
| [坡度图](/viz/chart/lines/slope)                  | 比较同一实体两个阶段的变化   | 实体、起点值和终点值           |
| [连接散点图](/viz/chart/points/connected-scatter) | 追踪二维观测的行进轨迹       | 两个坐标和明确的连接顺序       |
