A strip chart organizes observations by category and spreads points near each category center to reduce overlap. It compares distributions, outliers and dense regions across groups. Exactly one position role must be discrete and the other continuous; spread is not another measured variable.

## Using this topic

After [installation and first rendering](/viz/chart/get-start), choose one of the four equivalent inputs below. They share data and configuration.

## Basic usage

The following snippets compare where React JSX, Vanilla API, and direct IR place each configuration. Each section shows only the part relevant to its task. The previews share the barley data and let you adjust the configuration interactively.

### Strip encodings

Encodings assign categories and continuous values; the resolved discrete axis determines the jitter direction.

This dataset contains 120 barley observations across six Minnesota sites: ten varieties over two years. The category axis separates sites; the continuous axis retains yield. Jitter reveals points that would otherwise overlap.

- `x`: By default, bind site to a discrete point scale.
- `y`: By default, bind yield to a continuous linear scale.

Switch the discrete axis to exchange the category and yield directions. Point marks use only category centers; band width does not change point positions here, so this example uses a point scale. Compare ranges and concentrations along the continuous axis; jitter along the category axis does not rank varieties or imply time order.

### Strip properties

Properties control jitter span, distribution, and constant point appearance.

<DocTabs defaultValue="react-jsx">
<DocTab value="react-jsx" label="React + JSX">

```tsx
<StripProperties
  jitter={{ span: { kind: 'ratio', value: 0.3 }, distribution: { kind: 'uniform' }, seed: 0 }}
  size={5}
  opacity={0.75}
/>
```

</DocTab>
<DocTab value="vanilla-api" label="Vanilla API">

```ts
properties: {
  jitter: { span: { kind: 'ratio', value: 0.3 }, distribution: { kind: 'uniform' }, seed: 0 },
  size: 5,
  opacity: 0.75,
},
```

</DocTab>
<DocTab value="direct-ir" label="IR">

```ts
recipe: {
  properties: {
    jitter: { span: { kind: 'ratio', value: 0.3 }, distribution: { kind: 'uniform' }, seed: 0 },
    size: 5,
    opacity: 0.75,
  },
},
```

</DocTab>
</DocTabs>

This example fixes site on x with a point scale and yield on y. Each site has twenty observations, with some similar yields. Spread and point radius jointly affect overlap while leaving every yield value unchanged.

- `jitter.span`: Control total width, not one-sided displacement.
- `jitter.distribution`: Choose uniform or center-concentrated normal placement.
- `jitter.seed`: Change placement; a fixed seed makes it reproducible.
- `size`: Adjust point radius.

Keep seed fixed when comparing distributions. Wider jitter does not mean higher variance in the measured data. In Polar coordinates, this example places sites on the angular axis: the `jitter.span` ratio sets an angular spread relative to the spacing between sites. The same angular span makes a longer arc at a larger radius, so its visible width varies with radius rather than staying fixed in pixels. See [Polar jitter](#polar-jitter) below for a concrete example.

### Strip marks

Marks can override jitter and appearance while retaining the chart’s coordinate roles.

<DocTabs defaultValue="react-jsx">
<DocTab value="react-jsx" label="React + JSX">

```tsx

  properties={{
    jitter: { span: { kind: 'ratio', value: 0.6 }, distribution: { kind: 'normal', sigma: 0.4 }, seed: 7 },
    shape: 'diamond',
    size: 4,
  }}
/>
```

</DocTab>
<DocTab value="vanilla-api" label="Vanilla API">

```ts

  kind: 'strip',
  override: true,
  properties: {
    jitter: { span: { kind: 'ratio', value: 0.6 }, distribution: { kind: 'normal', sigma: 0.4 }, seed: 7 },
    shape: 'diamond',
    size: 4,
  },
}],
```

</DocTab>
<DocTab value="direct-ir" label="IR">

```ts
recipe: {
  marks: [{
    kind: 'strip',
    override: true,
    properties: {
      jitter: { span: { kind: 'ratio', value: 0.6 }, distribution: { kind: 'normal', sigma: 0.4 }, seed: 7 },
      shape: 'diamond',
      size: 4,
    },
  }],
},
```

</DocTab>
</DocTabs>

Replace the default mark with diamonds and more concentrated normal jitter. Data and position mappings stay fixed; only mark appearance and placement change.

- `override`: Replace the default point mark.
- `properties.jitter`: Set ratio 0.6, normal distribution and seed 7.
- `properties.shape`: Use diamond.
- `properties.size`: Set the point radius of this mark directly in the controls.

The mark inherits coordinate roles and cannot introduce a local scale. Changing jitter does not change a continuous role into a discrete one.

## Extended usage

### Polar jitter

Sites map to the angular axis and yield maps to the radial axis. This example sets the total angular jitter span to 0.7 of the spacing between sites. A normal distribution with a smaller sigma concentrates points near each site's center angle. Jitter changes only the angle; the radius still represents yield.

In the table below, `coordinate` belongs to the chart root; encodings and properties belong to IR `recipe`. React and Vanilla use the corresponding inputs described above.

| Group        | Property                | Type                            | Description                                  |
| ------------ | ----------------------- | ------------------------------- | -------------------------------------------- |
| `coordinate` | `type`                  | `polar2D`                       | Project positions into angle and radius      |
| `encodings`  | `x / y`                 | direct fields and scale objects | Site sets angle; yield sets radius           |
| `properties` | `jitter.span`           | ratio object                    | Angular span is 0.7 of the site tick spacing |
|              | `jitter.distribution`   | normal object                   | sigma 0.35; offsets stay within the span     |
|              | `jitter.seed / opacity` | number                          | Fix seed and use opacity to reveal overlap   |

Compare inner and outer points with the same angular offset: arc length equals radius times angle in radians, so a larger radius produces a longer visible arc. Changing the jitter ratio changes the angle range rather than a fixed pixel width. Keep seed fixed to compare settings without mistaking random placement for a yield change.

## Errors and limitations

- Exactly one resolved position scale must be discrete and one continuous; use Scatter for two continuous variables.
- Only direct mappings are supported; Strip does not support `row`, `column`, or `facet`. Use Plot for other compositions.
- Jitter does not modify rows. Reproducibility also requires identical row order, scales and placement settings.
- Insufficient discrete-role space fails explicitly rather than silently shrinking or clipping points.

In React, supplying the same configuration field through both the root `recipe` and a child component raises an error.

`point-aware` supports discrete axes and uses actual positions after jitter. Fully explicit `domainPadding` bypasses point-aware solving. See [shared point-chart configuration](/viz/chart/points#shared-configuration) for properties and precedence.

### Chart construction

Chart resolves a strip mark to a Plot Point and puts jitter settings in that Point's position adjustments. The table lists only strip-specific conversions.

| Group      | `@retikz/chart`        | `@retikz/plot`             | Description                                                               |
| ---------- | ---------------------- | -------------------------- | ------------------------------------------------------------------------- |
| Encodings  | `x`, `y`               | `encoding.x`, `encoding.y` | Keeps category and value fields; resolved scales choose the discrete axis |
| Properties | `jitter`               | `placement.adjustments`    | Adds a Jitter adjustment whose settings Plot applies                      |
| Mark       | `StripChartMarkSchema` | `PointMarkSchema`          | Resolves each strip mark to one Plot Point with jitter                    |

### Choose the discrete role automatically

Strip inspects the resolved scales to identify one discrete category axis and one continuous numeric axis, then applies jitter along the discrete axis. Callers cannot specify a separate jitter axis; when the current style shows default grids, they follow only the continuous axis. Each group below originally has only three distinct positions.
