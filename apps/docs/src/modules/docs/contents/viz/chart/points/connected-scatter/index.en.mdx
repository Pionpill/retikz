Connected Scatter shows discrete observations and trajectories together. Use [Scatter](/viz/chart/points/scatter) for point distributions, or [Regression](/viz/chart/points/regression) for fitted trends rather than observation-to-observation connections.

## `ConnectedScatterChart`

The root `recipe` uses Connected Scatter's exact slots. Component identity supplies the Point family and `chartType: 'connected-scatter'`:

```tsx
<ConnectedScatterChart
  rows={rows}
  recipe={{
    encodings: { x: 'year', y: 'value', order: 'year', series: 'country' },
    properties: { path: { connectNulls: true } },
  }}
/>
```

`ConnectedScatterEncodings`, `ConnectedScatterProperties`, and `ConnectedScatterMark` are headless JSX sugar for the same recipe slots. Root-only authoring can omit `children`; different slots can mix, while two sources for the same slot fail loudly.

## Data roles

`x`, `y`, and `order` are required. Path sorts by the `order` field instead of incidental array order. Optional `series` splits independent trajectories and shares one categorical color scale across Path, Point, and legend.

When `series` and explicit member colors are omitted, Path and Point share one sequential slot from Plot's `palette.series` instead of falling back to CSS `currentColor`. Explicit `path.stroke` and Point color properties still take precedence for their respective members.

Each semantic group fixes `[Path, Point]`, so lines paint before points. Whether appended or used with `override`, `ConnectedScatterMark` always resolves the complete group.

## Missing values

Point skips rows that cannot be projected. Path segments at invalid rows by default; `path.connectNulls: true` skips that row and joins adjacent valid observations. Chart does not impute or clean data.

## API Reference

### `ConnectedScatterEncodingsProps`

| Prop             | Type                                                                       | Default | Description                                  |
| ---------------- | -------------------------------------------------------------------------- | ------- | -------------------------------------------- |
| `x` / `y`        | Point position mapping                                                     | —       | Required position field mappings             |
| `order`          | direct field mapping                                                       | —       | Required within-series connection order      |
| `series?`        | direct field mapping with optional ordinal scale                           | —       | Recipe-only grouping, color, and legend role |
| `row` / `column` | `string`, `IRPlotPartitionDimension`, or `Array<IRPlotPartitionDimension>` | —       | Optional facet dimensions                    |
| `facet?`         | `IRPlotFacetOptions`                                                       | —       | Facet options; requires row or column        |

### `ConnectedScatterPropertiesProps`

| Prop             | Type                                                                    | Default                    | Description                                                          |
| ---------------- | ----------------------------------------------------------------------- | -------------------------- | -------------------------------------------------------------------- |
| `point?`         | `IRConnectedScatterPointProperties`                                     | Point                      | Constant Point appearance without zIndex                             |
| `path?`          | `IRConnectedScatterPathProperties`                                      | Path                       | Open-path appearance and `connectNulls`; never closes                |
| `domainPadding?` | `number` \| `{ kind?, default?, x?, y?, left?, right?, top?, bottom? }` | largest final Point radius | Configures continuous position-scale range or explicit ratio padding |

### `ConnectedScatterMarkProps`

| Prop          | Type                                         | Default   | Description                                                      |
| ------------- | -------------------------------------------- | --------- | ---------------------------------------------------------------- |
| `override?`   | `boolean`                                    | `false`   | Replaces the complete Path + Point group                         |
| `encodings?`  | `{ x?: string; y?: string; order?: string }` | inherited | Overrides direct fields, never series                            |
| `properties?` | `ConnectedScatterMarkProps['properties']`    | inherited | Merges member appearance and rejects recipe-only `domainPadding` |
