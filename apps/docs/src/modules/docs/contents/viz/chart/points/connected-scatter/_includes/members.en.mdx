React uses `ConnectedScatterChart` with its `recipe` prop or dedicated child components. The Vanilla API uses `connectedScatterChart` with direct `encodings`, `properties`, and `marks` options. Direct IR places these fields inside `recipe` and sets `recipe.chartType: 'connected-scatter'`. React and the Vanilla API supply the chart type automatically.

In React, each configuration field must be supplied through either root props or a child component, not both. Different fields may use different forms. For shared data, layout, and presentation, see [General Structure](/viz/chart/model/general-structure).

#### ConnectedScatterEncodings

Corresponds to `ConnectedScatterEncodings`, Vanilla `encodings` and IR `recipe.encodings`.

| Channel        | Input form                   | Description                                                                |
| -------------- | ---------------------------- | -------------------------------------------------------------------------- |
| `x / y`        | Field name, position mapping | Required observation positions                                             |
| `order`        | Field name, direct mapping   | Required within-group connection order; not array order                    |
| `series`       | Field name, direct mapping   | Split trajectories and categorical colors/legend; accepts an ordinal scale |
| `row / column` | Field name, facet dimension  | Create row or column facets                                                |
| `facet`        | `IRPlotFacetOptions`         | Configures facets; requires at least one of `row` and `column`             |

Shared mapping parameters are not expanded here; see the [encoding schema](#connectedscatterencodings--irconnectedscatterchartencodings--connectedscatterchartencodingsschema) for exact inputs.

#### ConnectedScatterProperties

Corresponds to `ConnectedScatterProperties`, Vanilla `properties` and IR `recipe.properties`.

| Category   | Property            | Type                                                     | Description                                                                                                                                                                                                        |
| ---------- | ------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Appearance | `point`             | `IRConnectedScatterPointProperties`                      | Sets observation point appearance; excludes `zIndex`                                                                                                                                                               |
|            | `path`              | `IRConnectedScatterPathProperties`                       | Sets open-path appearance                                                                                                                                                                                          |
|            | `colorMode`         | `'series'`, `'mark'`, `'muted'`                          | Defaults to `series` (shared point/path color); `mark` assigns adjacent palette colors to each series point/path. `muted` shares colors with 60% default path opacity. Explicit paints and opacity take precedence |
| Connection | `path.curve`        | `PathCurve`                                              | Defaults to `linear`; supports linear, step, stepBefore, stepAfter, basis, cardinal, catmullRom, monotoneX, monotoneY, natural                                                                                     |
| Connection | `path.connectNulls` | boolean or stroke object                                 | Break by default; `true` or `{}` bridges gaps with a dashed stroke. Supports stroke, strokeWidth, strokeOpacity, dashPattern, dashOffset, lineCap, and lineJoin                                                    |
| Padding    | `autoPadding`       | `false`, `'max-radius'`, `'point-aware'`, `object`       | Automatic padding strategy; the object form uses kind for the strategy and clearance for edge clearance                                                                                                            |
|            | `domainPadding`     | `number`, `IRBoxSpacing & { kind?: 'range' \| 'ratio' }` | Explicit position-domain padding takes precedence over automatic padding                                                                                                                                           |

See the [properties schema](#connectedscatterproperties--irconnectedscatterchartproperties--connectedscatterchartpropertiesschema) for the full structure; shared appearance configuration is not expanded here.

#### ConnectedScatterMark

Corresponds to `ConnectedScatterMark`, Vanilla `marks` and IR `recipe.marks`.

| Property     | Type                                      | Description                                                      |
| ------------ | ----------------------------------------- | ---------------------------------------------------------------- |
| `override`   | `boolean`                                 | Replace the complete path-and-point group, otherwise append      |
| `encodings`  | `ConnectedScatterChartMark['encodings']`  | Override direct fields only; series is always inherited          |
| `properties` | `ConnectedScatterChartMark['properties']` | Merge appearance per member; chart padding policies are excluded |
