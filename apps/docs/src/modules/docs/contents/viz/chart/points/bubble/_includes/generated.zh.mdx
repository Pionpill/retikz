React 使用 `BubbleChart`，可通过 `recipe` 属性或专属子组件提供配置。Vanilla API 使用 `bubbleChart`，直接提供 `encodings`、`properties`、`marks`；直接 IR 将这些配置放在 `recipe` 中，并设置 `recipe.chartType: 'bubble'`。React 与 Vanilla API 会补齐图形类型。

React 中，同一项配置不能同时通过根属性与子组件声明；不同配置项可以混用两种写法。公共数据、布局与标题配置见 [通用结构](/viz/chart/model/general-structure)。

以下 Schema 从 `@retikz/chart/point` 导出，描述可持久化的 JSON IR。根结构与公共配置仅保留类型名称；当前图形的配方、映射、属性和图元在下方依次说明。React 与 Vanilla 编写入口见 API 参考。

对应 `BubbleMark`、Vanilla `marks` 和 IR `recipe.marks`。

| 属性         | 类型                            | 说明                                                              |
| ------------ | ------------------------------- | ----------------------------------------------------------------- |
| `override`   | `boolean`                       | 为 true 时替换主气泡图元，否则追加                                |
| `encodings`  | `BubbleChartMark['encodings']`  | 覆盖 x、y、color、shape、opacity；每项为字段名字符串，不开放 size |
| `properties` | `BubbleChartMark['properties']` | 覆盖本节常量外观，不接受 size、domainPadding、autoPadding         |

<DocTab value="schema" label="Schema">

`encodings` 只允许 x、y、color、opacity、shape，各项均可省略且仅接受字段名字符串，不接受 recipe 的完整映射对象。`properties` 复用上方属性的含义与成员结构，但不包含 `autoPadding`、`domainPadding`；省略的配置沿用当前图形可继承的映射与属性。 Bubble 的尺寸来自 recipe.encodings.size 映射，图元不能单独覆盖 size。
