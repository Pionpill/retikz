---
title: Chart
description: Chart 在 Plot 之上组织具体图形类型，并提供标题、来源、画布和主题等整图能力。
---

Chart 面向“完整图形”：根 `type` 是便于发现的 family，嵌套 `recipe.chartType` 选择具体 recipe。Chart 还提供标题、来源、画布与主题；Plot 持续拥有数据、图元、通道、比例尺、坐标、辅助元素与变换。Chart 不建立第二套图形语法。

| 层次  | 负责什么                                                     | 不负责什么                     |
| ----- | ------------------------------------------------------------ | ------------------------------ |
| Chart | family、chartType、Chart Source、整图展示、画布和 Theme      | 重新定义 Plot 的图元与编码语法 |
| Plot  | 数据、变换、图元、通道、比例尺、坐标、轴、图例和其它辅助元素 | Scatter 等图形类型产品语义     |

## 一个最小 Point Chart

具体图形使用 typed Chart 入口。下面的 `ScatterChart` 会产生 `type: 'point'`、`recipe.chartType: 'scatter'` 的 Source；`encodings` 绑定字段，`properties` 写常量。

```tsx
import { ScatterChart } from '@retikz/chart-react/point/scatter';

const rows = [
  { x: 1, y: 2 },
  { x: 2, y: 3 },
  { x: 3, y: 5 },
];

<ScatterChart
  data={rows}
  encodings={{ x: 'x', y: 'y' }}
  properties={{ size: 8 }}
  title="两个变量的关系"
  source="示例数据"
  layout={{ width: 640, height: 360 }}
/>;
```

## React 宿主与嵌入

每个具体 Chart 组件都默认提供 Layout 能力。直接渲染 `<ScatterChart>` 时只建立一个 `Layout` / Scene host；放入已有 `<Layout>` 时，Chart 只贡献 Chart → Plot → Core 的 Scope/composite，并继承外层 effective Theme，不创建第二个 SVG。

`width`、`height`、CSS、renderer/runtime、动画和 compile callback 都属于 `ChartHostProps`，只在 standalone 模式合法。embedded Chart 如果自带其中任何字段——包括显式 `undefined`——会 fail-loud，应把字段移动到外层 `<Layout>`。Chart Source 的 `layout` 仍独立控制图表 border-box，不会被 host `width` / `height` 写入或覆盖；Chart `id` 也保持可选。

如果已经有符合当前精确 schema 的 JSON Source，应由应用层根据 `type` 与
`recipe.chartType` 选择对应的具体入口或 compile adapter；Chart 不提供一个
会动态加载所有 family 的 generic `<Chart source={...}>` 组件。需要直接组合轴、图例或独立 Plot mark 时，应把内容写入 Source 的 `plotExtension` fragment，或直接使用 Plot。
