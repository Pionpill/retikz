本页介绍当前图形的专属入口与约束；公共配置的 React 组件写法见 [快速开始示例](/viz/chart/get-start#最小结果)。

React 使用 `ScatterChart`，可通过 `recipe` 属性提供配置，也可使用下方的专属子组件。Vanilla API 使用 `scatterChart`，直接提供 `encodings`、`properties`、`marks`；直接 IR 将这些配置放在 `recipe` 中，并设置 `recipe.chartType: 'scatter'`。React 与 Vanilla API 会补齐该图形类型。

React 可以混用不同配置项的根属性与子组件写法，但同一项配置不能重复声明。例如，`recipe.encodings` 与 `ScatterEncodings` 不能同时提供，否则报错。仅通过根属性配置时，无需添加子组件。

#### ScatterEncodings

React 使用 `ScatterEncodings`，Vanilla API 使用 `encodings`，直接 IR 使用 `recipe.encodings`。

| 通道             | 输入形式             | 说明                                        |
| ---------------- | -------------------- | ------------------------------------------- |
| `x` / `y`        | 字段名、位置映射     | 必填；决定散点位置                          |
| `color`          | 字段名、颜色映射     | 按分类、连续数值着色                        |
| `size`           | 字段名、尺寸映射     | 输出连续数值；命名尺寸尺度仅支持 `sqrt`     |
| `opacity`        | 字段名、透明度映射   | 输出连续数值；命名透明度尺度仅支持 `linear` |
| `shape`          | 字段名、直接映射     | 按分类区分形状，不接受命名尺度              |
| `row` / `column` | 字段名、分面维度     | 按行列分面，支持有序层级                    |
| `facet`          | `IRPlotFacetOptions` | 配置分面；须配合 `row`、`column` 中至少一项 |

映射对象可按通道支持情况引用尺度或聚合数据。内置与自定义 transform 由 Data 或 `plotExtension.transform` 执行，映射只绑定输出字段。精确输入结构见下方 [Schema 参考](#scatterencodings--irscatterchartencodings--scatterchartencodingsschema)，组合限制见[错误与限制](#错误与限制)。

#### ScatterProperties

React 使用 `ScatterProperties`，Vanilla API 使用 `properties`，直接 IR 使用 `recipe.properties`。属性设置常量外观；随数据变化的取值应放在映射中。

| 分类       | 属性             | 类型                                                     | 说明                                                             |
| ---------- | ---------------- | -------------------------------------------------------- | ---------------------------------------------------------------- |
| 形状与尺寸 | `size`           | `number`                                                 | 统一点半径，必须大于或等于 0                                     |
|            | `shape`          | `string`                                                 | 已注册的形状名                                                   |
| 颜色与填充 | `color`          | `string`                                                 | 设置主色                                                         |
|            | `fill`           | `string`、`JsonObject`                                   | 设置填充颜色、画笔                                               |
| 描边       | `stroke`         | `string`、`JsonObject`                                   | 设置描边颜色、画笔                                               |
|            | `strokeWidth`    | `number`                                                 | 描边宽度，必须大于或等于 0                                       |
|            | `dashed`         | `boolean`                                                | 启用虚线描边                                                     |
|            | `dotted`         | `boolean`                                                | 启用点线描边                                                     |
|            | `dashPattern`    | `Array<number>`                                          | 自定义虚线序列；至少一项，各项非负                               |
| 透明度     | `opacity`        | `number`                                                 | 整体透明度，范围 0–1                                             |
|            | `opacity.fill`   | `number`                                                 | 填充透明度，范围 0–1                                             |
|            | `opacity.stroke` | `number`                                                 | 描边透明度，范围 0–1                                             |
| 留白       | `autoPadding`    | `false`、`'max-radius'`、`'point-aware'`、`object`       | 自动留白策略；对象写法通过 kind 选择策略、clearance 设置外缘净空 |
|            | `domainPadding`  | `number`、`IRBoxSpacing & { kind?: 'range' \| 'ratio' }` | 显式位置域留白，优先于自动策略                                   |

其余字体、标签、变换与阴影等公共外观不在这里逐项解释，完整字段见 [属性 Schema](#scatterproperties--irscatterchartproperties--scatterchartpropertiesschema)。留白策略的触发条件和边界见[PointMark 边缘留白](/viz/plot/mark/point#边缘留白)。

#### ScatterMark

React 使用 `ScatterMark`，Vanilla API 使用 `marks`，直接 IR 使用 `recipe.marks`。React 中须作为 `ScatterChart` 的直接子组件；Vanilla / IR 图元需声明 `kind: 'scatter'`。

| 属性         | 类型                             | 说明                                                                     |
| ------------ | -------------------------------- | ------------------------------------------------------------------------ |
| `override`   | `boolean`                        | 省略时追加；为 `true` 时原位替换默认散点图元                             |
| `encodings`  | `ScatterChartMark['encodings']`  | 支持 `x`、`y`、`color`、`size`、`opacity`、`shape`，不接受完整映射对象   |
| `properties` | `ScatterChartMark['properties']` | 沿用上方属性含义，但不接受 `domainPadding`；`autoPadding` 可覆盖图表策略 |

未指定的映射与属性沿用当前图形可继承的配置。替换未命中时仍追加，并通过 `onWarn` 报告 `CHART_MARK_OVERRIDE_TARGET_NOT_FOUND`。完整结构见 [图元 Schema](#scattermark--scatterchartmarkschema)。
