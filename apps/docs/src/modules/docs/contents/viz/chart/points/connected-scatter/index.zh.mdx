连接散点图用点表达观测，再按明确的顺序连接成轨迹。横纵轴可以都是指标，时间只负责连接顺序；适合观察两个指标如何共同变化，以及不同对象的路径差异。连线连接实际观测，不是回归趋势。

## 接入方式

完成 [安装与首次渲染](/viz/chart/get-start) 后，可用以下四种入口。示例共用同一数据与配置。

100 个月的建筑业失业率，month 同时决定横坐标和连接顺序。

图中每个点是一个国家某年的城镇化率与预期寿命。六个国家在 1990–2020 年每五年取一条观测，横轴不是时间，因此需要另一个字段明确连接顺序。

- `x / y`：分别绑定 urbanization 和 lifeExpectancy。
- `order`：绑定 year，按年份连接同一国家的观测。
- `series`：绑定 country，使国家之间不发生连线。

沿各国轨迹观察指标如何共同变化；时间由连接顺序表达，不对应横轴。

### 连接散点属性

属性分别控制观测点与连接线，也决定如何显示数据缺口。

<DocTabs defaultValue="react-jsx">
<DocTab value="react-jsx" label="React + JSX">

```tsx
<ConnectedScatterProperties
  colorMode="series"
  point={{ size: 4, opacity: 1 }}
  path={{ curve: 'linear', connectNulls: false, strokeOpacity: 1, strokeWidth: 2 }}
/>
```

</DocTab>
<DocTab value="vanilla-api" label="Vanilla API">

```ts
properties: {
  colorMode: 'series',
  point: { size: 4, opacity: 1 },
  path: { curve: 'linear', connectNulls: false, strokeOpacity: 1, strokeWidth: 2 },
},
```

</DocTab>
<DocTab value="direct-ir" label="IR">

```ts
recipe: {
  properties: {
    colorMode: 'series',
    point: { size: 4, opacity: 1 },
    path: { curve: 'linear', connectNulls: false, strokeOpacity: 1, strokeWidth: 2 },
  },
},
```

</DocTab>
</DocTabs>

密集轨迹同时包含观测点和连接线。本例将两层外观分别配置，保留点的位置与连接顺序，便于突出离散观测或整体走向。

- `point.size`：调整观测点半径。
- `path.strokeWidth`：调整连接线宽度。
- `path.connectNulls`：决定遇到缺失观测时分段还是桥接。
- `path.curve`：选择直线、阶梯或平滑曲线，默认 `linear`。切换“连接方式”只改变连线，点的位置与连接顺序不变；`basis` 不保证经过所有中间观测点，X/Y 单调插值适用于对应方向单调的数据，在极坐标中沿用 Plot 的直线回退行为。

南非 2005 年寿命值被人为置空用于演示。桥接只改变线，缺失观测不会变成一个有效点。

`colorMode="mark"` 让同一序列的点和线使用相邻的两种色板颜色，图例同步显示这两种颜色；默认 `series` 保持点线同色。`muted` 同样按序列同色，将连线默认透明度设为 60%，点的外观不变；显式 `path.strokeOpacity` 优先。

### 连接散点图元

每个图元同时包含连接线与观测点，追加和替换都作用于完整组合。

<DocTab value="react-jsx" label="React + JSX">

```tsx

  override
  properties={{
    point: { fillOpacity: 0.1, strokeWidth: 2 },
    path: { dashPattern: [6, 4] },
  }}
/>
```

</DocTab>
<DocTab value="vanilla-api" label="Vanilla API">

```ts
marks: [
  {
    kind: 'connected-scatter',
    override: true,
    properties: {
      point: { fillOpacity: 0.1, strokeWidth: 2 },
      path: { dashPattern: [6, 4] },
    },
  },
],
```

</DocTab>
<DocTab value="direct-ir" label="IR">

```ts
recipe: {
  marks: [
    {
      kind: 'connected-scatter',
      override: true,
      properties: {
        point: { fillOpacity: 0.1, strokeWidth: 2 },
        path: { dashPattern: [6, 4] },
      },
    },
  ],
},
```

</DocTab>
</DocTabs>

下面用空心点和虚线替换默认轨迹样式。每个国家仍是一组完整的“路径＋观测点”，不会只替换线而遗留另一套点。

- `override`：设为 true，替换完整组合。
- `properties.point`：降低填充透明度并添加轮廓。
- `properties.path`：使用 dashPattern 区分连接线样式。

每组先绘制连接线，再绘制观测点，避免线盖住点。两层默认共用分类颜色或默认色，也可分别用 `point.color`、`point.fill` 与 `path.stroke` 覆盖。 图元中省略的成员属性继续继承 recipe。需要只操作独立 Path 时，应使用 Plot 的图元能力。

## 扩展用法

### 缺值连接

多国时间轨迹经常包含缺失年份。保留国家分组和年份排序，再选择是否跨过缺值连接，可以避免把数据缺口误读成没有变化。

下表分组均为 IR `recipe` 内的属性；React 与 Vanilla 使用上文对应入口。

| 分组         | 属性名                          | 类型               | 说明                                                  |
| ------------ | ------------------------------- | ------------------ | ----------------------------------------------------- |
| `encodings`  | `x / y / order`                 | 字段映射           | 指标位置与 year 顺序                                  |
|              | `series`                        | string             | country 使各国独立连接                                |
| `properties` | `path.connectNulls`             | boolean 或描边对象 | `true` 或 `{}` 启用默认虚线桥接；对象只覆盖缺值连接段 |
|              | `path.connectNulls.dashPattern` | `Array<number>`    | 缺值连接段的虚线节奏，默认 [6, 4]；正常段样式不变     |

正常观测之间保持实线，仅缺值两侧用虚线连接。可在控件中单独调整缺值段的线宽、不透明度与虚线长度；关闭连接后保留缺口。连续缺值合并为一个缺口，首尾缺值不外推，桥接不会补出观测点。

## 错误与限制

- order 必填，不能用输入行顺序代替。series 只能在 recipe 中指定。
- 路径保持开放，图元替换针对完整点线组合，不提供单成员替换。
- 无效观测不绘制 Point；connectNulls 不补值、不清洗数据。

React 中，同一项配置不能同时通过根 `recipe` 与子组件声明，否则报错。

`point-aware` 支持内置连续与分类位置尺度，以及二维笛卡尔和极坐标。全部方向显式指定 `domainPadding` 时不启动逐点求解。公共属性和覆盖规则见 [点图公共配置](/viz/chart/points#公共配置)。

### 图形构建

Chart 将一个连接散点图元解析为一条开放的 Plot Path 和一组 Plot Point。下表只列点线组合特有的转换。

| 分组 | `@retikz/chart`          | `@retikz/plot`                      | 描述                                                     |
| ---- | ------------------------ | ----------------------------------- | -------------------------------------------------------- |
| 映射 | `order`、`series`        | `order`、`series`                   | 将排序字段与分组字段写入 Path，依次连接各序列的点        |
| 属性 | `point`、`path`          | `Point` 外观、`Path` 外观           | 分别应用观测点与连接路径的外观；`connectNulls` 传给 Path |
|      | `colorMode`              | `color`、`stroke`、`strokeOpacity`  | 决定点线共享序列色、分开取色或减弱路径透明度             |
| 图元 | `IRConnectedScatterMark` | `IRPlotPathMark`、`IRPlotPointMark` | 一个 Chart 图元产生一组开放 Path 与 Point                |

## API 参考

React 使用 `ConnectedScatterChart`，可通过 `recipe` 属性或专属子组件提供配置。Vanilla API 使用 `connectedScatterChart`，直接提供 `encodings`、`properties`、`marks`；直接 IR 将这些配置放在 `recipe` 中，并设置 `recipe.chartType: 'connected-scatter'`。React 与 Vanilla API 会补齐图形类型。

React 中，同一项配置不能同时通过根属性与子组件声明；不同配置项可以混用两种写法。公共数据、布局与标题配置见 [通用结构](/viz/chart/model/general-structure)。

#### ConnectedScatterEncodings

对应 `ConnectedScatterEncodings`、Vanilla `encodings` 和 IR `recipe.encodings`。

| 通道           | 输入形式             | 说明                                              |
| -------------- | -------------------- | ------------------------------------------------- |
| `x / y`        | 字段名、位置映射     | 必需；观测坐标，决定点的位置                      |
| `order`        | 字段名、直接映射     | 必需；组内连接顺序，不依赖数组顺序                |
| `series`       | 字段名、直接映射     | 拆分轨迹并生成分类颜色和图例，可绑定 ordinal 尺度 |
| `row / column` | 字段名、分面维度     | 按行、列建立分面                                  |
| `facet`        | `IRPlotFacetOptions` | 配置分面；须配合 `row`、`column` 中至少一项       |

公共映射参数不在这里展开；精确输入结构见 [映射 Schema](#connectedscatterchartencodingsschema)。

#### ConnectedScatterProperties

对应 `ConnectedScatterProperties`、Vanilla `properties` 和 IR `recipe.properties`。

| 分类 | 属性                | 类型                                                     | 说明                                                                                                                                       |
| ---- | ------------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| 外观 | `point`             | `IRConnectedScatterPointProperties`                      | 设置观测点外观；不开放 `zIndex`                                                                                                            |
|      | `path`              | `IRConnectedScatterPathProperties`                       | 设置开放路径外观                                                                                                                           |
|      | `colorMode`         | `'series'`、`'mark'`、`'muted'`                          | 默认 `series`：同一序列的点线同色；`mark`：每个序列的点线依次使用色板中相邻的两色，`muted` 同色且连线默认透明度 60%；显式颜色与透明度优先  |
| 连接 | `path.curve`        | `PathCurveValue`                                         | 默认 `linear`；支持 linear、step、stepBefore、stepAfter、basis、cardinal、catmullRom、monotoneX、monotoneY、natural                        |
| 连接 | `path.connectNulls` | boolean 或描边对象                                       | 默认断开；`true` 或 `{}` 用虚线连接缺口两侧有效点。对象支持 stroke、strokeWidth、strokeOpacity、dashPattern、dashOffset、lineCap、lineJoin |
| 留白 | `autoPadding`       | `'max-radius'`、`'point-aware'`、`object`                | 自动留白策略；对象写法通过 kind 选择策略、clearance 设置外缘净空                                                                           |
|      | `domainPadding`     | `number`、`IRBoxSpacing & { kind?: 'range' \| 'ratio' }` | 显式位置域留白，优先于自动策略                                                                                                             |

完整属性结构见 [属性 Schema](#connectedscatterchartpropertiesschema)；公共外观配置不在这里展开。

#### ConnectedScatterMark

对应 `ConnectedScatterMark`、Vanilla `marks` 和 IR `recipe.marks`。

| 属性         | 类型                                      | 说明                                       |
| ------------ | ----------------------------------------- | ------------------------------------------ |
| `override`   | `boolean`                                 | 替换完整路径与观测点组合，否则追加组合     |
| `encodings`  | `ConnectedScatterChartMark['encodings']`  | 只覆盖已有直接字段；series 始终继承 recipe |
| `properties` | `ConnectedScatterChartMark['properties']` | 按成员合并外观，不接受图表留白策略         |
