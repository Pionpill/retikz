React uses `RegressionChart` with its `recipe` prop or dedicated child components. The Vanilla API uses `regressionChart` with direct `encodings`, `properties`, and `marks` options. Direct IR places these fields inside `recipe` and sets `recipe.chartType: 'regression'`. React and the Vanilla API supply the chart type automatically.

In React, each configuration field must be supplied through either root props or a child component, not both. Different fields may use different forms. For shared data, layout, and presentation, see [General Structure](/viz/chart/model/general-structure).

#### RegressionEncodings

Corresponds to `RegressionEncodings`, Vanilla `encodings` and IR `recipe.encodings`.

| Channel        | Input form                   | Description                                                                               |
| -------------- | ---------------------------- | ----------------------------------------------------------------------------------------- |
| `x / y`        | Field name, position mapping | Required predictor and response                                                           |
| `series`       | Field name, direct mapping   | Fit groups separately with shared categorical colors and legend; accepts an ordinal scale |
| `row / column` | Field name, facet dimension  | Fit independently within each panel                                                       |
| `facet`        | `IRPlotFacetOptions`         | Configures facets; requires at least one of `row` and `column`                            |

Shared mapping parameters are not expanded here; see the [encoding schema](#regressionencodings--irregressionchartencodings--regressionchartencodingsschema) for exact inputs.

#### RegressionProperties

Corresponds to `RegressionProperties`, Vanilla `properties` and IR `recipe.properties`.

| Category   | Property        | Type                                                     | Description                                                                                             |
| ---------- | --------------- | -------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Fitting    | `method`        | `IRRegressionChartProperties['method']`                  | Selects the fitting method and parameters                                                               |
|            | `extraMethods`  | `Array<IRRegressionExtraMethod>`                         | Ordered additional trends sharing the observations; omitted means none                                  |
|            | `sampleCount`   | `number`                                                 | Prediction count per group; integer at least 2, default 64                                              |
|            | `extent`        | `[number, number]`                                       | Increasing prediction interval; defaults to that group’s finite x range                                 |
| Appearance | `point`         | `IRRegressionPointProperties`                            | Sets observation point appearance                                                                       |
| Trend      | `trend.curve`   | `IRRegressionTrendProperties['curve']`                   | Default `catmullRom`; inherited by extra trends unless overridden                                       |
|            | `trend`         | `IRRegressionTrendProperties`                            | Sets trend appearance without changing the fit                                                          |
| Padding    | `autoPadding`   | `false`, `'max-radius'`, `'point-aware'`, `object`       | Automatic padding strategy; the object form uses kind for the strategy and clearance for edge clearance |
|            | `domainPadding` | `number`, `IRBoxSpacing & { kind?: 'range' \| 'ratio' }` | Explicit position-domain padding takes precedence over automatic padding                                |

See the [properties schema](#regressionproperties--irregressionchartproperties--regressionchartpropertiesschema) for the full structure; shared appearance configuration is not expanded here.

#### RegressionMark

Corresponds to `RegressionMark`, Vanilla `marks` and IR `recipe.marks`.

| Property     | Type                                | Description                                                                                                                                       |
| ------------ | ----------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `override`   | `boolean`                           | Replace the complete observation-and-trend group, otherwise append                                                                                |
| `hidePoints` | `boolean`                           | Defaults to `false`; `true` omits this mark’s observation points while retaining the main and additional trends.                                  |
| `encodings`  | `RegressionChartMark['encodings']`  | Override direct fields in the same data; series cannot be overridden                                                                              |
| `properties` | `RegressionChartMark['properties']` | Replace method, sampleCount or extent; merge point/trend members; replace extraMethods as a whole, with [] clearing it; excludes padding policies |
