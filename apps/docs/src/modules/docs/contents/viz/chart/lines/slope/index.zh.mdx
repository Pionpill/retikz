---
title: 坡度图
description: 比较同一实体在两个阶段的数值变化，支持端点、实体标签。
---

坡度图用一条线连接同一实体在两个阶段的值。向上表示增加，向下表示减少；两端使用相同的数值尺度。每行数据就是一组配对，适合前后对比。多个阶段的趋势请使用 [折线图](/viz/chart/lines/line)。

## 基础用法

### 坡度映射

每行同时提供实体名称、起点值和终点值。调整起终字段可以交换比较方向；调整行顺序不会改变配对。

<DocTabs defaultValue="react-jsx">
<DocTab value="react-jsx" label="React + JSX">

```tsx
<SlopeEncodings entity="entity" start="previous" end="current" />
```

</DocTab>
<DocTab value="vanilla-api" label="Vanilla API">

```ts

```

</DocTab>
<DocTab value="direct-ir" label="IR">

```json
{ "recipe": { "encodings": { "entity": "entity", "start": "previous", "end": "current" } } }
```

</DocTab>
</DocTabs>

| 属性名          | 类型             | 说明                                           |
| --------------- | ---------------- | ---------------------------------------------- |
| `entity`        | 字段名、直接映射 | 必填，名称与默认分类颜色                       |
| `start` / `end` | 字段名、直接映射 | 必填，两个阶段的值；可指定同一尺度，不隐式聚合 |
| `color`         | 字段名、直接映射 | 可选分类颜色；省略使用 entity                  |

A、B、C、E、F、G、H、I 共八个实体，各占一行，previous 与 current 是前后两次观测。

- `entity`：绑定 entity，区分八条连线。
- `start` / `end`：分别绑定 previous 与 current，两端共用数值轴。

打开“交换阶段”观察比较方向；“打乱行顺序”只改变绘制顺序，不改变两端的对应关系。

### 坡度属性

默认 y 尺度通过 `domainPadding: 32` 在上下两端各留 32 个绘图单位，为端点标签提供空间。显式声明数值尺度时使用该尺度自己的留白配置；设置 `domainPadding: 0` 可关闭。

点、标签和路径可分别设置。隐藏点后，实体标签仍可保留。

每端只显示一个标签，内容固定取 `entity`。`label: false` 关闭，`true` 或配置对象开启；省略 `position` 时起点向左、终点向右，显式方向同时作用于两端。不提供标签数组或独立端点配置。

<DocTab value="react-jsx" label="React + JSX">

```tsx
<SlopeProperties point={{ size: 4 }} label={{ position: 'top', distance: 8 }} path={{ strokeWidth: 2 }} />
```

</DocTab>
<DocTab value="vanilla-api" label="Vanilla API">

```ts
properties: { point: { size: 4 }, label: { position: 'top', distance: 8 }, path: { strokeWidth: 2 } }
```

</DocTab>
<DocTab value="direct-ir" label="IR">

```json
{
  "recipe": {
    "properties": {
      "point": { "size": 4 },
      "label": { "position": "top", "distance": 8 },
      "path": { "strokeWidth": 2 }
    }
  }
}
```

</DocTab>

| 属性名   | 类型               | 说明                                                                    |
| -------- | ------------------ | ----------------------------------------------------------------------- |
| `stages` | 两个字符串         | 自定义左右阶段名称，必须不同；省略使用字段名                            |
| `point`  | boolean 或样式对象 | 默认 true；对象设置半径、形状、填色、描边与透明度                       |
| `label`  | boolean 或配置对象 | 默认 true；每端一个 entity 标签，支持方向、距离、字体、颜色等单标签配置 |
| `path`   | 描边样式对象       | 默认线宽 2，只绘制两阶段直线                                            |

本例保留八个实体的原始配对，集中比较表现设置。

- `point.size`：初始为 4，设为 0 可观察零半径。
- `label`：默认显示 entity；方向初始向外，距离为 8，可调整方向与距离。
- `path.strokeWidth`：初始为 2。

关闭观测点时标签仍保留；切换标签方向或调整距离，观察两端同时变化，重置后恢复初始配置。

| 属性名       | 类型         | 说明                                           |
| ------------ | ------------ | ---------------------------------------------- |
| `override`   | boolean      | 默认追加；true 替换整个内建组                  |
| `encodings`  | 直接字段覆盖 | 可覆盖 start、end，不改变实体或阶段名称        |
| `properties` | 稀疏成员属性 | path、point、label 按字段继承；false 与 0 保留 |

紫色虚线使用同一组配对值，与内建实线叠加。

- `path`：紫色、线宽 2、虚线节奏 [5, 4]。
- `point` / `label`：追加组默认关闭，避免重复标签。
- `override`：默认 false。

打开“替换内建图元”，实线、原有点和标签一起被替换；打开“显示追加点”可显示新组的端点。

### 缺失端点

一个阶段没有观测时，不补零、不画该行连线；另一阶段的有效点与标签保留。

| 分组         | 属性名          | 类型    | 说明                 |
| ------------ | --------------- | ------- | -------------------- |
| `encodings`  | `start` / `end` | 字段名  | 从同一行读取两个阶段 |
| `properties` | `label`         | boolean | 控制有效端点的标签   |

B 的 previous 初始为空，右侧仍保留 current=62。关闭“移除 B 的起点”恢复完整连线。

## 错误与限制

- 输入为配对宽表；长表需先整理。同名多行仍是独立比较单元，不自动去重或聚合。
- 阶段名称必须不同；两端显式尺度必须一致，不能使用两个独立数值轴。
- 缺失观测不连线，但缺失字段声明、错误尺度引用、非法常量和坐标投影错误仍会报错。
- 标签不自动避让；密集数据可筛选、调整字体或分面。

### 图形构建

| 分组 | `@retikz/chart`      | `@retikz/plot`                  | 描述                             |
| ---- | -------------------- | ------------------------------- | -------------------------------- |
| 映射 | start、end           | Path encodings.from/to          | 每行生成一条完整端点路径         |
|      | entity、color        | color、label                    | 实体名与分类颜色不决定配对       |
| 属性 | stages               | point scale domain              | 固定左右两个阶段                 |
|      | point、label         | Point properties、label         | 点隐藏时仍可用零尺寸宿主承载标签 |
| 图元 | SlopeChartMarkSchema | PathMarkSchema、PointMarkSchema | 一组包含连线与两个独立端点       |

两端位置都使用同一个 y 尺度。Plot 在字段值无法映射时跳过该行路径；独立端点仍消费原始数据，因此有效一端不会随连线消失。
