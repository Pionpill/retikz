A ranged dot chart shows two endpoints per category and a connector between them. Use it for before/after change, bounds or paired measurements. Each row supplies a category and both endpoints; field roles never swap simply because values reverse.

## Using this topic

After [installation and first rendering](/viz/chart/get-start), choose one of the four equivalent inputs below. They share data and configuration.

Minimum and maximum temperatures across 20 consecutive days in Seattle; one row per day.

## Basic usage

### Ranged dot encodings

Encodings assign row categories and paired values while preserving start and end roles.

<DocTabs defaultValue="react-jsx">
<DocTab value="react-jsx" label="React + JSX">

```tsx
<RangedDotEncodings category="country" start="forestArea2000" end="forestArea2022" />
```

</DocTab>
<DocTab value="vanilla-api" label="Vanilla API">

```ts
encodings: {
  category: 'country',
  start: 'forestArea2000',
  end: 'forestArea2022',
},
```

</DocTab>
<DocTab value="direct-ir" label="IR">

```ts
recipe: {
  encodings: {
    category: 'country',
    start: 'forestArea2000',
    end: 'forestArea2022',
  },
},
```

</DocTab>
</DocTabs>

Compare forest area as a percentage of land in eighteen countries in 2000 and 2022. Each row is one country; the horizontal span between its two endpoints shows the difference.

- `category`: Use country for the vertical category.
- `start`: Bind forestArea2000 by default; blue identifies the start.
- `end`: Bind forestArea2022 by default; orange identifies the end.

With the default mappings, an end to the left indicates a decrease; to the right, an increase. Swapping the fields exchanges the years represented by the two colors while preserving the measured positions and connector span. Rows are sorted by the 2022 value, not by change magnitude.

Keep the forest data unchanged and focus on distinguishing the two years. Endpoint colors identify roles; the connector supplies a visual reference between them.

- `point.size`: Set a shared endpoint radius.
- `startPoint.color / endPoint.color`: Identify 2000 and 2022 separately.
- `range.strokeWidth`: Adjust connector width without changing the difference.

Smaller radii help when endpoints are close. Changing endPoint leaves startPoint unchanged, which is useful for emphasizing the latest measurement.

A replacement mark changes the 2022 endpoint to a larger diamond. Color and shape jointly distinguish years while the start and connector retain inherited settings.

- `override`: Set true to replace this paired group.
- `properties.endPoint`: Override the end shape and radius.
- `properties.range`: Set connector width.

This is a local appearance override within a whole-group replacement. Two PointMarks draw the endpoints using different fields from the same data row.

## Extended usage

### Daylight hours on a circular clock

Place the 24 hours of a day around the circle, with six concentric rings for sunrise and sunset on the 15th of every other month in Tokyo in 2024. Blue endpoints mark sunrise, orange endpoints mark sunset, and connecting arcs show daylight hours. The data comes from the Open-Meteo Historical Weather API in Tokyo local time.

The `coordinate` group belongs to the Chart root; the other settings belong to IR `recipe`. React and Vanilla use the corresponding inputs described above.

| Group        | Property                        | Type             | Description                                                           |
| ------------ | ------------------------------- | ---------------- | --------------------------------------------------------------------- |
| `coordinate` | `type / startAngle / endAngle`  | polar settings   | Maps 0–24 hours clockwise around the circle, with 0 at top            |
|              | `innerRadius / interpolation`   | polar settings   | Leaves a center hole and connects sunrise to sunset around the circle |
| `encodings`  | `category`                      | field mapping    | Places each month on a concentric ring                                |
|              | `start / end`                   | fields and scale | Shares a fixed `[0, 24]` angular scale for sunrise and sunset         |
| `properties` | `startPoint / endPoint / range` | appearance       | Distinguishes time endpoints and draws their connector                |

Compare the angular spans for January and July to see how daylight hours change. Compare angles rather than pixel arc lengths across rings of different radii.

## Errors and limitations

- category maps to y; start and end share x. These roles are fixed.
- A missing or unprojectable endpoint causes the connector path to raise an error. Clean missing values before supplying the data. Equal endpoints remain coincident.
- Different explicit endpoint scale names fail. Member appearance does not create independent field scales.

In React, supplying the same configuration field through both the root `recipe` and a child component raises an error.

`point-aware` supports both categorical and continuous axes and protects each endpoint. Fully explicit `domainPadding` bypasses point-aware solving. See [shared point-chart configuration](/viz/chart/points#shared-configuration) for properties and precedence.

### Chart construction

Chart expands a ranged-dot mark into one PathMark and two PointMarks. The path connects the endpoints; the points read the start and end fields separately and render above the connector. All three belong to one Chart semantic group and are replaced together by a mark override.

| Group      | `@retikz/chart`                   | `@retikz/plot`                                      | Description                                                                                  |
| ---------- | --------------------------------- | --------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| Encodings  | `category`, `start`, `end`        | Path `from` / `to` and Point `position`             | Uses `start` and `end` for the two x values and `category` for their shared y row            |
| Properties | `range`                           | Path `properties`                                   | Sets connector color, width, and stroke style                                                |
|            | `point`, `startPoint`, `endPoint` | Each Point's `properties`                           | Merges shared and individual appearance, including shape, size, color, and automatic padding |
| Mark       | `IRRangedDotMark`                 | `IRPlotPathMark` and two `IRPlotPointMark` elements | Emits the connector, start point, and end point in that order                                |

For each valid row, Plot emits one Core `Path` and two endpoint `Node` elements to draw the connector and dots.
