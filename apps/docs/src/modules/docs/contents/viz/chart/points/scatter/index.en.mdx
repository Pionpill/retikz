This API section lists only Scatter-specific field mappings and mark behavior. Shared Chart props, field types, transforms, scales, presentation, and Plot extensions are not repeated here; see [Chart Model](/viz/chart/model).

## `ScatterChart.encodings`

`ScatterChartEncodingsSchema` is the runtime source of truth for Scatter encodings, and `IRScatterChartEncodings` is derived from it. React `ScatterChartProps.encodings`, Vanilla input, and JSON Source all use this exact table.

| Slot             | Supported Scatter mappings                                                            | Scatter-specific constraint                                                                       |
| ---------------- | ------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------- |
| `x`              | `string`, direct, aggregate, derived (`bin`, `normalize`, `jitter`, custom transform) | Required; `jitter` can target only x; `bin` cannot be combined with a facet                       |
| `y`              | `string`, direct, aggregate, derived (`bin`, `normalize`, `jitter`, custom transform) | Required; `jitter` can target only y; `bin` cannot be combined with a facet                       |
| `color`          | `string`, direct, aggregate                                                           | Optional; binds Scatter's color consumer and accepts a compatible categorical or continuous scale |
| `size`           | `string`, direct, aggregate, derived (`normalize`, custom transform)                  | Optional; output must be continuous, and named scales currently accept only `sqrt`                |
| `opacity`        | `string`, direct, aggregate, derived (`normalize`, custom transform)                  | Optional; output must be continuous, and named scales currently accept only `linear`              |
| `shape`          | `string`, direct                                                                      | Optional; binds categorical shape and does not accept a named scale                               |
| `row` / `column` | `string`, `IRPlotPartitionDimension`, `Array<IRPlotPartitionDimension>`               | Optional; either dimension creates a facet, and an array expresses ordered facet hierarchy        |
| `facet`          | `IRPlotFacetOptions`                                                                  | Optional; configures `empty`, `header`, `resolve`, and `spacing`; requires `row` or `column`      |

Scatter rejects `series`, `detail`, `order`, `text`, and ordinary slot arrays without a defined consumer. Field types and scale compatibility are handled by the existing Data / Plot contracts and are not expanded here.

### Facet

`row` / `column` / `facet` are Scatter's facet mappings. `facet` cannot be used without `row` or `column`, and x/y `bin` mappings are rejected when a facet is present.

```tsx
encodings={{
  x: 'billLengthMm',
  y: 'flipperLengthMm',
  column: { field: 'species', order: ['Adelie', 'Chinstrap', 'Gentoo'] },
  facet: { header: { column: true }, spacing: { panelGap: 20 } },
}}
```

`row` / `column` partition panels; they do not choose a mark type. Scatter continues to use its point mark. Plot owns facet panel arrangement, scale resolution, and location, so Source does not repeat derived panel ids or coordinates.

## `ScatterMark`

`ScatterMark` is Scatter's direct-child mark API. `ScatterMarkProps` is the props type exported by `@retikz/chart-react/point/scatter`; the component identity is fixed to Scatter, so callers do not provide `kind`. Shared Point mark nested fields are not repeated here.

| `ScatterMarkProps` property | Type                             | Default | Scatter-specific behavior                                                                                                                                               |
| --------------------------- | -------------------------------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `override?`                 | `boolean`                        | `false` | When `true`, replaces the implicit primary `scatter` mark in place; if no target exists, it appends and reports `CHART_MARK_OVERRIDE_TARGET_NOT_FOUND` through `onWarn` |
| `encodings?`                | `ScatterMarkProps['encodings']`  | —       | Overrides inherited point field mappings from the current Scatter recipe; available fields follow the shared Point mark encoding contract                               |
| `properties?`               | `ScatterMarkProps['properties']` | —       | Overrides inherited point styling from the current Scatter recipe; available fields follow the shared Point properties contract                                         |
