## Point Mark

### Position and coordinate scope

The main example binds two continuous variables through `PointMark.x` / `PointMark.y`, then lets Plot resolve their 2D positions through its coordinate and scale pipeline.

| Prop                  | Type                                     | Default | Description                                            |
| --------------------- | ---------------------------------------- | ------- | ------------------------------------------------------ |
| `x` / `y`             | `PointMarkProps['x' \| 'y']`             | —       | Two-dimensional position fields; Scatter requires both |
| `z`                   | `PointMarkProps['z']`                    | —       | Third position role for a custom coordinate            |
| `xAxisId` / `yAxisId` | `PointMarkProps['xAxisId' \| 'yAxisId']` | —       | Authoring shortcuts for named-axis binding             |
| `coordinateView`      | `PointMarkProps['coordinateView']`       | —       | Direct composition-view binding                        |
| `facetId` / `trackId` | `PointMarkProps['facetId' \| 'trackId']` | —       | Facet or shared-track binding                          |

### Visual encoding and glyph

Strings may represent fields; use an explicit `{ kind: 'constant', value }` when a constant must be unambiguous. Field bindings continue through Plot scales, legends, channel definitions, and diagnostics.

| Prop                                        | Type                                                            | Default         | Description                                                          |
| ------------------------------------------- | --------------------------------------------------------------- | --------------- | -------------------------------------------------------------------- |
| `color` / `textColor`                       | `PointMarkProps['color' \| 'textColor']`                        | Palette         | Glyph or text color                                                  |
| `size`                                      | `PointMarkProps['size']`                                        | Built-in radius | Map a numeric field through a sqrt scale or provide the final radius |
| `shape`                                     | `PointMarkProps['shape']`                                       | Circle          | Categorical or explicit shape                                        |
| `fill` / `stroke`                           | `PointMarkProps['fill' \| 'stroke']`                            | Theme           | Fill and stroke paint                                                |
| `strokeWidth`                               | `PointMarkProps['strokeWidth']`                                 | Theme           | Stroke width                                                         |
| `fillOpacity` / `strokeOpacity` / `opacity` | `PointMarkProps['fillOpacity' \| 'strokeOpacity' \| 'opacity']` | `1`             | Layer-specific or whole-node opacity                                 |
| `rotate`                                    | `PointMarkProps['rotate']`                                      | `0`             | Glyph rotation angle                                                 |
| `minimumSize`                               | `PointMarkProps['minimumSize']`                                 | —               | Minimum visual size before the size channel                          |
| `zIndex`                                    | `PointMarkProps['zIndex']`                                      | —               | Per-datum drawing-order hint                                         |

| `cornerRadius` / `scale`                | `PointMarkProps['cornerRadius' \| 'scale']`                 | Theme   | Corner radius and node scale                    |
| `padding` / `margin`                    | `PointMarkProps['padding' \| 'margin']`                     | Theme   | Inner and outer spacing                         |

| `boundary`                              | `PointMarkProps['boundary']`                                | Shape   | Node boundary strategy                          |
| `shadow` / `blendMode`                  | `PointMarkProps['shadow' \| 'blendMode']`                   | —       | Shadow and blend mode                           |

### Text, datum labels, and identity

| Prop                                            | Type                                                                 | Default                | Description                                                     |
| ----------------------------------------------- | -------------------------------------------------------------------- | ---------------------- | --------------------------------------------------------------- |
| `text` / `displayFormat`                        | `PointMarkProps['text' \| 'displayFormat']`                          | —                      | Turn the Point into a borderless text node and format its value |
| `dx` / `dy`                                     | `PointMarkProps['dx' \| 'dy']`                                       | `0`                    | Text offset from the projected anchor                           |
| `label` / `labelDisplayFormat`                  | `DatumLabelProps['label' \| 'labelDisplayFormat']`                   | —                      | Attach a separate datum label and format it                     |
| `labelPosition` / `labelDistance` / `labelPin`  | `DatumLabelProps['labelPosition' \| 'labelDistance' \| 'labelPin']`  | `top` / `12` / `false` | Label position, distance, and leader line                       |

| `labelRotate` / `labelKeepUpright`              | `DatumLabelProps['labelRotate' \| 'labelKeepUpright']`               | `'none'` / `false`     | Label rotation and upright policy                               |
| `resolveLabel`                                  | `DatumLabelProps['resolveLabel']`                                    | —                      | Runtime-only custom label; requires an explicit `id`            |
| `channels`                                      | `DatumLabelProps['channels']`                                        | `{}`                   | Field or constant bindings for registered extension channels    |
| `transform`                                     | `PointMarkProps['transform']`                                        | `[]`                   | Data transforms local to this Point                             |
| `layer`                                         | `PointMarkProps['layer']`                                            | —                      | Semantic layer for the Point scope                              |
| `id` / `anchorId`                               | `PointMarkProps['id' \| 'anchorId']`                                 | Auto                   | Mark handle and stable per-datum node id                        |
