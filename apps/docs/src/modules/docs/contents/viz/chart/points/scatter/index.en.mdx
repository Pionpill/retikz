  Scatter uses the exact `ScatterChartSchema` while following Chart's consistent field layout. Its `config` supplies type-specific encodings such as x/y and implicitly creates the primary Point mark, two-dimensional scales, and coordinate; `plot` continues to receive Plot-owned data, transforms, legends, and other explicit extensions.

All examples on this page use `ScatterChart` from `@retikz/chart-react/point`. The `/point` entry only organizes imports and source files; the component still enters the shared Chart resolution and adapter mainline. Chart owns the title, subtitle, source, and note inside the chart. Axes, grids, and color or shape legends remain Plot-owned guide extensions, so they are authored with `Axis` and `Legend`.
