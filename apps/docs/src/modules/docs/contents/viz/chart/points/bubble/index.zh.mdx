## 尺寸与面积

气泡图保留散点的二维位置，再把第三个定量字段交给 `PointMark.size`。Plot 使用 sqrt scale 计算半径，使屏幕上的气泡面积随数值变化，避免把半径线性放大造成视觉夸张。

| 属性   | 类型                     | 默认值 | 描述                                             |
| ------ | ------------------------ | ------ | ------------------------------------------------ |
| `size` | `PointMarkProps['size']` | —      | 定量字段映射到气泡半径；气泡视图始终使用字段绑定 |

字段尺寸为缺失值、`null`、`NaN` 或无穷值时，该行不生成 Point glyph；字段 descriptor 与可选 legend 属于数据集级信息，仍会保留。负数尺寸会直接报错，不会被跳过或截断。气泡需要 glyph 承载面积，因此本预设不使用 `text`；需要文字时使用 `label`，让标签与气泡同时存在。

## Point Mark

除尺寸语义外，气泡继续复用完整的公开 Point 能力。位置、颜色、形状、透明度、标签、transform 与自定义坐标 role 都由 `PointMark` 控制。

| 属性                           | 类型                                              | 默认值 | 描述                           |
| ------------------------------ | ------------------------------------------------- | ------ | ------------------------------ |
| `x` / `y`                      | `PointMarkProps['x' \| 'y']`                      | —      | 二维位置字段                   |
| `color` / `shape` / `opacity`  | `PointMarkProps['color' \| 'shape' \| 'opacity']` | 主题值 | 分类与视觉样式                 |
| `label` / `labelPosition`      | `DatumLabelProps['label' \| 'labelPosition']`     | —      | 保留气泡并附加 datum 标签      |
| `transform` / `coordinateView` | `PointMarkProps['transform' \| 'coordinateView']` | —      | 当前 mark 的数据变换与坐标视图 |
| `channels` / `z` / `facetId`   | `PointMarkProps['channels' \| 'z' \| 'facetId']`  | —      | 扩展 channel 与组合坐标 role   |
