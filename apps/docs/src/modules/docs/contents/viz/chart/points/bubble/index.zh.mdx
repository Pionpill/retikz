## `BubbleChart`

`BubbleChart` 固定 Point family 与 Bubble recipe 身份。根 `recipe` 直接使用 Bubble 的 exact slots，组件身份会补齐 `chartType: 'bubble'`：

```tsx
<BubbleChart
  rows={rows}
  recipe={{
    encodings: { x: 'gdpPerCapita', y: 'lifeExpectancy', size: 'population', color: 'continent' },
    properties: { fillOpacity: 0.7 },
  }}
/>
```

`BubbleEncodings`、`BubbleProperties` 与 `BubbleMark` 是同三个 slots 的等价 JSX sugar。只用根配置时可以省略 `children`；同一 slot 的根配置与 declaration 不会互相覆盖，而是 fail-loud。

Bubble 与 Scatter 都下沉为 Plot Point，但 Bubble 把第三个字段映射固定为不可撤销的核心角色。常量半径的点图仍应使用 Scatter，packed bubble 则不属于本 chartType。

## `BubbleEncodings`

`BubbleEncodingsProps` 精确复用 schema 派生的 `IRBubbleChartEncodings`。Vanilla input 与 JSON Source 使用相同 payload；React 通过独立 declaration 编写。

| Slot             | 支持的 Bubble mapping                                                                  | Bubble 专属约束                                                                               |
| ---------------- | -------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `x`              | `string`、direct、aggregate、derived（`bin`、`normalize`、`jitter`、custom transform） | 必填；位置尺度沿用 Point compatibility；`jitter` 只能作用于 x；`bin` 不能与 facet 组合        |
| `y`              | `string`、direct、aggregate、derived（`bin`、`normalize`、`jitter`、custom transform） | 必填；位置尺度沿用 Point compatibility；`jitter` 只能作用于 y；`bin` 不能与 facet 组合        |
| `size`           | `string`、direct、aggregate、derived（`normalize`、custom transform）                  | 必填且只能是字段映射；输出必须 continuous；省略 scale 时使用 sqrt，命名 scale 也只接受 `sqrt` |
| `color`          | `string`、direct、aggregate                                                            | 可选；接受兼容的分类或连续颜色 scale                                                          |
| `opacity`        | `string`、direct、aggregate、derived（`normalize`、custom transform）                  | 可选；输出必须 continuous，命名 scale 当前只接受 `linear`                                     |
| `shape`          | `string`、direct                                                                       | 可选；绑定分类形状，不接受命名 scale                                                          |
| `row` / `column` | `string`、`IRPlotPartitionDimension`、`Array<IRPlotPartitionDimension>`                | 可选；声明任一维度即可生成 facet，数组表示有序分面层级                                        |
| `facet`          | `IRPlotFacetOptions`                                                                   | 可选；配置 `empty`、`header`、`resolve`、`spacing`；必须同时存在 `row` 或 `column`            |

默认情况下，`size` 绑定进入 Plot 的 sqrt 尺寸尺度并生成 size legend。Bubble 不接受常量 `size`，也不能通过 mark 覆盖或删除 recipe 的尺寸字段；这保证同一 Source 始终保留 Bubble 的第三数据角色。

```tsx
<BubbleEncodings
  x={{ field: 'gdpPerCapita', scale: { operation: { type: 'log', name: 'income' } } }}
  y="lifeExpectancy"
  size="population"
/>
```

`row` / `column` / `facet` 沿用 Point 分面契约。分区只改变面板组织，不改变 Bubble 的 mark 身份与必需 size mapping。

## `BubbleProperties`

`BubbleProperties` 声明 recipe 级常量。它复用 Point 常量属性，但明确排除固定半径 `size`；数据驱动尺寸必须来自 `BubbleEncodings.size`。

Bubble 默认使用 `fillOpacity={0.7}` 和 `1px` 同色描边。`color` 同时驱动默认填充与描边；显式 `fill`、`stroke` 或透明度属性仍可分别覆盖。

| 字段                                                                                        | 值域与说明                                                                                                                              |
| ------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `color`、`textColor`、`fill`、`stroke`、`shape`                                             | 颜色、paint 或可扩展 shape 名称                                                                                                         |
| `minimumSize`、`scale`、`rotate`、`dx`、`dy`、`padding`、`margin`、`cornerRadius`           | 通用 Point 几何常量，不替代必需的 size 字段映射                                                                                         |
| `strokeWidth`、`fillOpacity`、`strokeOpacity`、`opacity`、`dashed`、`dotted`、`dashPattern` | 描边、透明度与虚线常量                                                                                                                  |
| `zIndex`、`align`、`lineHeight`、`maxTextWidth`、`font`、`label`                            | 绘制顺序、文本与标签配置                                                                                                                |
| `boundary`、`shadow`、`blendMode`                                                           | 边界、阴影与混合模式                                                                                                                    |
| `domainPadding?`                                                                            | `number` 或 `{ kind?, default?, x?, y?, left?, right?, top?, bottom? }`；默认按字段尺寸 sqrt range 的最大半径留白，省略 range 时为 `20` |

## `BubbleMark`

`BubbleMark` 是 Bubble 独有的直接子级 mark API。组件身份固定为 `bubble`，调用方不传 `kind`；普通 mark 追加额外气泡，`override` mark 原位替换 recipe 的隐式主气泡。

| `BubbleMarkProps` 属性 | 类型                            | 默认值  | Bubble 专属行为                                                                                                       |
| ---------------------- | ------------------------------- | ------- | --------------------------------------------------------------------------------------------------------------------- |
| `override?`            | `boolean`                       | `false` | 为 `true` 时原位替换隐式主 `bubble` mark；未命中时仍追加，并通过 `onWarn` 报告 `CHART_MARK_OVERRIDE_TARGET_NOT_FOUND` |
| `encodings?`           | `BubbleMarkProps['encodings']`  | —       | 可覆盖继承的 x、y、color、opacity、shape 字段，但不包含 `size`                                                        |
| `properties?`          | `BubbleMarkProps['properties']` | —       | 可覆盖 Bubble 允许的常量样式，但不包含固定半径 `size`                                                                 |

普通与 override `BubbleMark` 都从 recipe 继承同一个核心 size mapping，因此不能把 Bubble 改写成没有第三字段尺寸语义的普通 Scatter。
