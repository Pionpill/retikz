  这是基于公开 Plot API 的概念预览，用于解释 Bubble 的面积语义。页面使用 `@retikz/plot-react` 根入口公开的 `Plot`、`PointMark` 与 `Axis` 组合 API，图表尺寸固定为 `800 × 400`。

在 Chart 结构中，Bubble 使用精确的 `BubbleChartSchema`。它通过 `config` 接收 x/y/size 等专属编码，并隐含生成承载面积的主 `Point` 图元；数据、变换、比例尺、辅助元素和显式附加图元仍放在 `plot` 中。

## 尺寸与面积

气泡图保留散点的二维位置，再把第三个定量字段交给尺寸编码。Bubble 的类型解析逻辑将它映射到 `PointMark.size`；Plot 使用平方根比例尺计算半径，使屏幕上的气泡面积随数值变化，避免把半径线性放大造成视觉夸张。

| 属性   | 类型                     | 默认值 | 描述                                             |
| ------ | ------------------------ | ------ | ------------------------------------------------ |
| `size` | `PointMarkProps['size']` | —      | 定量字段映射到气泡半径；气泡视图始终使用字段绑定 |

字段尺寸为缺失值、`null`、`NaN` 或无穷值时，该行不生成 `Point` 图元；字段描述信息与可选图例属于数据集级信息，仍会保留。负数尺寸会直接报错，不会被跳过或截断。气泡需要图形符号承载面积，因此本类型方案不使用 `text`；需要文字时使用 `label`，让标签与气泡同时存在。

## Point 图元

除尺寸语义外，气泡继续复用完整的公开 Point 能力。位置、颜色、形状、透明度、标签、变换与自定义坐标角色都由 `PointMark` 控制。

| 属性                           | 类型                                              | 默认值 | 描述                         |
| ------------------------------ | ------------------------------------------------- | ------ | ---------------------------- |
| `x` / `y`                      | `PointMarkProps['x' \| 'y']`                      | —      | 二维位置字段                 |
| `color` / `shape` / `opacity`  | `PointMarkProps['color' \| 'shape' \| 'opacity']` | 主题值 | 分类与视觉样式               |
| `label` / `labelPosition`      | `DatumLabelProps['label' \| 'labelPosition']`     | —      | 保留气泡并附加 datum 标签    |
| `transform` / `coordinateView` | `PointMarkProps['transform' \| 'coordinateView']` | —      | 当前图元的数据变换与坐标视图 |
| `channels` / `z` / `facetId`   | `PointMarkProps['channels' \| 'z' \| 'facetId']`  | —      | 扩展通道与组合坐标角色       |
