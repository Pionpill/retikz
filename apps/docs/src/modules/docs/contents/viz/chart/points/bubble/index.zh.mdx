气泡图在 `x`、`y` 位置通道之外，增加必需的数值通道 `size`，用于将数据字段绑定到气泡大小。每行数据对应一个气泡，也可通过 `color` 区分类别。

## 接入方式

完成 [安装与首次渲染](/viz/chart/get-start) 后，可用以下四种入口。示例共用同一数据与配置。

- `x`：将 gdpPerCapita 映射到线性横轴，直接比较数值差异。

### 气泡属性

固定属性控制气泡外观，不替代必需的数值大小映射。气泡大小通常不统一，因此默认使用 `autoPadding: 'point-aware'`，按各气泡的实际位置与半径计算留白。策略说明与效果对比见 [点图总览：自动补齐边缘留白](/viz/chart/points#自动补齐边缘留白)。

同一数据中，人口较大的气泡可能盖住邻近国家。本节用透明填充和轮廓调整可读性，位置与人口映射保持不变。

- `fillOpacity`：设为 0.35，降低填充不透明度，让重叠区域更容易辨认。
- `stroke`：为轮廓选取颜色，帮助辨认相邻气泡。
- `strokeWidth`：设为 1.5，突出轮廓；调为 0 可比较无描边的效果。
- `shape`：改变绘制形状，不提供固定 size。

使用下方控件比较填充和描边的组合。不要用固定半径调整人口编码；需要相同大小的点时应使用散点图。

下面仍展示收入、寿命与人口，但将主气泡替换为低透明度填充和较粗轮廓。图中不会因这次替换增加第二套人口数据。

- `override`：设为 true，原位替换主图元。
- `properties.fillOpacity`：设置为 0.15，减轻大气泡的遮挡。
- `properties.strokeWidth`：设置为 2，让轮廓更清晰。

替换前后 size 都来自 recipe 的 population 字段。Bubble 图元没有 size 覆盖入口，因此不会无意中失去第三个数值角色。

## 扩展用法

### 对数映射

收入跨度很大时，线性横轴容易把多数国家挤在一侧。使用对数横轴可以展开较低数值区间，便于比较不同数量级的收入。

下表分组均为 IR `recipe` 内的属性；React 与 Vanilla 使用上文对应入口。

| 分组         | 属性名        | 类型         | 说明                       |
| ------------ | ------------- | ------------ | -------------------------- |
| `encodings`  | `x.scale`     | log 尺度对象 | 人均 GDP 必须为正          |
|              | `size`        | string       | 以 population 表示人口规模 |
|              | `color`       | string       | continent 分类             |
| `properties` | `fillOpacity` | number       | 减轻重叠遮挡               |

切换横轴尺度时，观察国家之间的水平距离如何改变；不要把对数轴的等距读成相同美元差额。

### 分面比较

当分类颜色仍不足以分清密集区域时，用 continent 拆分面板。共享坐标和尺寸尺度，才能比较不同洲的收入范围与人口大小。

下表分组均为 IR `recipe` 内的属性；React 与 Vanilla 使用上文对应入口。

| 分组         | 属性名         | 类型     | 说明                               |
| ------------ | -------------- | -------- | ---------------------------------- |
| `encodings`  | `x / y / size` | 字段映射 | 收入、寿命和人口                   |
|              | `row`          | string   | 按 continent 建立行面板            |
|              | `facet`        | 分面选项 | 保留共享尺度，显示行标题并设置间距 |
| `properties` | `fillOpacity`  | number   | 以半透明填充呈现重叠               |

对照同一横坐标区间中的各面板，区分组内分布和洲之间的差异。面板中气泡数量不代表人口总量。

## 错误与限制

- size 必须来自数值字段；`BubbleEncodings.size` 不能被常量属性或图元覆盖移除。
- 命名尺寸尺度只接受 sqrt。面积的定量比例还受 domain、range 和形状影响；不是所有自定义配置都保持面积正比。
- 分面选项需要 row 或 column；bin 位置映射不能与分面组合。

React 中，同一项配置不能同时通过根 `recipe` 与子组件声明，否则报错。

全部方向显式指定 `domainPadding` 时不启动逐点求解。公共属性和覆盖规则见 [点图公共配置](/viz/chart/points#公共配置)。

### 图形构建

Chart 将气泡图元解析为 Plot Point，以数值字段控制点的大小。下表只列气泡图特有的转换。

| 分组 | `@retikz/chart`              | `@retikz/plot`               | 描述                                                  |
| ---- | ---------------------------- | ---------------------------- | ----------------------------------------------------- |
| 映射 | `size`                       | `size`                       | 将必需的数值字段映射到点尺寸；尺寸尺度默认使用 `sqrt` |
| 属性 | `fillOpacity`、`strokeWidth` | `fillOpacity`、`strokeWidth` | 先应用 0.7 和 1 的默认外观，再由显式属性覆盖          |
| 图元 | `BubbleChartMarkSchema`      | `PointMarkSchema`            | 每个气泡图元解析为一个 Plot Point                     |

## API 参考

React 使用 `BubbleChart`，可通过 `recipe` 属性或专属子组件提供配置。Vanilla API 使用 `bubbleChart`，直接提供 `encodings`、`properties`、`marks`；直接 IR 将这些配置放在 `recipe` 中，并设置 `recipe.chartType: 'bubble'`。React 与 Vanilla API 会补齐图形类型。

React 中，同一项配置不能同时通过根属性与子组件声明；不同配置项可以混用两种写法。公共数据、布局、标题与指南配置见 [编写与解析](/viz/chart/model/authoring)。

#### BubbleEncodings

对应 `BubbleEncodings`、Vanilla `encodings` 和 IR `recipe.encodings`。

| 通道           | 输入形式             | 说明                                             |
| -------------- | -------------------- | ------------------------------------------------ |
| `x / y`        | 字段名、位置映射     | 必需；位置字段决定点的位置                       |
| `size`         | 字段名、尺寸映射     | 必需数值字段；使用 sqrt 尺寸尺度，不能传常量半径 |
| `color`        | 字段名、颜色映射     | 分类、连续颜色映射                               |
| `shape`        | 字段名、直接映射     | 分类形状；不接受命名尺度                         |
| `opacity`      | 字段名、透明度映射   | 数值透明度，使用 linear 尺度                     |
| `row / column` | 字段名、分面维度     | 行列分面；数组定义有序分组层级                   |
| `facet`        | `IRPlotFacetOptions` | 配置分面；须配合 `row`、`column` 中至少一项      |

公共映射参数不在这里展开；精确输入结构见 [映射 Schema](#bubblechartencodingsschema)。

#### BubbleProperties

对应 `BubbleProperties`、Vanilla `properties` 和 IR `recipe.properties`。

| 分类       | 属性            | 类型                                                     | 说明                                                                               |
| ---------- | --------------- | -------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 形状       | `shape`         | `string`                                                 | 已注册的形状名                                                                     |
| 颜色与填充 | `color`         | `string`                                                 | 设置主色                                                                           |
|            | `fill`          | `string`、`JsonObject`                                   | 设置填充颜色、画笔                                                                 |
| 描边       | `stroke`        | `string`、`JsonObject`                                   | 设置描边颜色、画笔                                                                 |
|            | `strokeWidth`   | `number`                                                 | 描边宽度，必须大于或等于 0；默认 1                                                 |
|            | `dashed`        | `boolean`                                                | 启用虚线描边                                                                       |
|            | `dotted`        | `boolean`                                                | 启用点线描边                                                                       |
|            | `dashPattern`   | `Array<number>`                                          | 自定义虚线序列；至少一项，各项非负                                                 |
| 透明度     | `opacity`       | `number`                                                 | 整体透明度，范围 0–1                                                               |
|            | `fillOpacity`   | `number`                                                 | 填充透明度，范围 0–1；默认 0.7                                                     |
|            | `strokeOpacity` | `number`                                                 | 描边透明度，范围 0–1                                                               |
| 变换       | `rotate`        | `number`                                                 | 旋转角度                                                                           |
|            | `dx`            | `number`                                                 | 水平偏移                                                                           |
|            | `dy`            | `number`                                                 | 垂直偏移                                                                           |
| 留白       | `autoPadding`   | `'max-radius'`、`'point-aware'`、`object`                | 自动留白策略，默认 point-aware；对象写法通过 kind 选择策略、clearance 设置外缘净空 |
|            | `domainPadding` | `number`、`IRBoxSpacing & { kind?: 'range' \| 'ratio' }` | 显式位置域留白，优先于自动策略                                                     |

完整属性结构见 [属性 Schema](#bubblechartpropertiesschema)；公共外观配置不在这里展开。

#### BubbleMark

对应 `BubbleMark`、Vanilla `marks` 和 IR `recipe.marks`。

| 属性         | 类型                            | 说明                                                              |
| ------------ | ------------------------------- | ----------------------------------------------------------------- |
| `override`   | `boolean`                       | 为 true 时替换主气泡图元，否则追加                                |
| `encodings`  | `BubbleChartMark['encodings']`  | 覆盖 x、y、color、shape、opacity；每项为字段名字符串，不开放 size |
| `properties` | `BubbleChartMark['properties']` | 覆盖本节常量外观，不接受 size、domainPadding、autoPadding         |

#### BubbleChartMarkSchema
