---
title: 编写与解析
description: 理解 React、Vanilla 与 JSON 如何形成精确 Source IR，并经 recipe 和 resolveChart 收敛为 IRBaseChart。
---

Chart 把“方便编写”与“稳定执行”分成两个阶段。React 和 Vanilla 负责把各自的输入形态规范化为精确 Source IR；对应类型的入口再绑定匹配的 recipe，并解析成统一的 `IRBaseChart`。

## 一条共享主链

<ComponentPreview files="chart-authoring-pipeline" hideCode size="sm" />

| 阶段              | owner                   | 结果                                               |
| ----------------- | ----------------------- | -------------------------------------------------- |
| React props / JSX | `@retikz/chart-react`   | 转换为 Vanilla Input，不直接拼 Source IR           |
| Plain input       | `@retikz/chart-vanilla` | `normalizeXxxChart` 生成精确、可序列化的 Source IR |
| JSON              | 精确 Chart schema       | 解析对应类型的 Source IR                           |
| recipe bind       | 精确 Chart 入口         | 保存基础字段与延迟的 `createPlot`                  |
| resolve           | `resolveChart`          | 应用主题和 recipe，产出 `IRBaseChart`              |

JSON 是输入旁路，不跳过 schema。`base` 输入可以交给根入口的 `bindChart`；Point 输入则从 `@retikz/chart/point` 选择与 `type` 匹配的精确 schema 和 recipe，例如先用 `ScatterChartSchema` 解析，再用 `ScatterChartRecipe.bind` 绑定。根 `bindChart` 不负责未知类型的总分发。成功绑定后，各类型都进入同一个 `resolveChart`，Core 最终只消费 `chart.base`。

## 三套包，各自只做一段

根 `@retikz/chart` 公开 Base Chart 的 Source IR、schema、recipe、`bindChart`、`resolveChart` 和 canonical presentation；`@retikz/chart/point` 公开各个 Point Chart 的精确 IR、schema 与 recipe。plain `InputChart`、`InputScatterChart`、`normalizeChart` 与对应创建函数属于 `@retikz/chart-vanilla`。React 组件解析 JSX 子节点和展示标记后，复用相同 normalizer，因此 React 与 Vanilla 不维护平行的 Source IR 组装规则。

| 入口                    | 对应 `type`         | 导入位置                    |
| ----------------------- | ------------------- | --------------------------- |
| `Chart` / `createChart` | `base`              | 各包根入口                  |
| `ScatterChart`          | `scatter`           | `@retikz/chart-react/point` |
| `BubbleChart`           | `bubble`            | `@retikz/chart-react/point` |
| `ConnectedScatterChart` | `connected-scatter` | `@retikz/chart-react/point` |

Vanilla 的类型创建函数分别为 `createScatterChart`、`createBubbleChart` 与 `createConnectedScatterChart`，从 `@retikz/chart-vanilla/point` 导入。它们返回保留运行时主题信息的编写结果；最终渲染仍复用共享 Chart 适配与解析主链。
