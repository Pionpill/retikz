Line charts show change across time, numeric positions, or ordered categories. Keep input row order, connection order, and axis order distinct.

## Choosing a chart

| Chart                                                    | When to use it                                          | Required data                                          |
| -------------------------------------------------------- | ------------------------------------------------------- | ------------------------------------------------------ |
| [Line](/viz/chart/lines/line)                            | Follow a measure across one or more series              | Position and measure; optional series and order fields |
| [Slope](/viz/chart/lines/slope)                          | Compare two stages for each entity                      | Entity, start value, and end value                     |
| [Connected Scatter](/viz/chart/points/connected-scatter) | Trace a trajectory through two-dimensional observations | Two coordinates and an explicit connection order       |
