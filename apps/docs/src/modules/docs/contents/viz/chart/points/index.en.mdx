---

Point charts use one or more data points as their visual subject. This group helps readers choose a chart by visual structure and remains a source-directory and `/point` multi-entry import boundary. It does not introduce a `PointChartSchema`, a Point-specific resolver, or a runtime dispatch layer. Start with Scatter when you only need to compare two continuous variables.

Scatter and Bubble own `ScatterChartSchema` and `BubbleChartSchema`, respectively. They follow the same `namespace: 'chart'`, `plot`, and chart-wide presentation layout, while exact `type` and `config` contracts preserve their unique encodings. Bubble is not a styling pattern of Scatter, but a distinct type that requires a third quantitative size role.

## Responsibilities

| Chart                                    | Responsibility                                                           | Use it when                                             |
| ---------------------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------- |
| [Scatter](/viz/chart/points/scatter)     | Show the relationship between two continuous variables                   | Inspecting distributions, clusters, outliers, or trends |
| [Bubble Chart](/viz/chart/points/bubble) | Add a third quantitative variable through area while preserving position | Comparing relationships and magnitude                   |
