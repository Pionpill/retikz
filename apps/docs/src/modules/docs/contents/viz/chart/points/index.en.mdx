Point charts use one or more data points as their visual subject. This family organizes common types by stable chart structure; start with a scatter plot when you only need to compare two continuous variables. Scatter and Bubble are sibling Canonical Types in the Scatter & Points family: Bubble is not a styling Pattern of Scatter, but a distinct type that requires a third quantitative size role.

## Responsibilities

| Chart                                    | Responsibility                                                           | Use it when                                             |
| ---------------------------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------- |
| [Scatter](/viz/chart/points/scatter)     | Show the relationship between two continuous variables                   | Inspecting distributions, clusters, outliers, or trends |
| [Bubble Chart](/viz/chart/points/bubble) | Add a third quantitative variable through area while preserving position | Comparing relationships and magnitude                   |
