#### RegressionExtraMethodSchema

Each entry requires a fitting method and inherits sampling and appearance settings from its group. It generates only a trend line. Array order determines drawing order; method colors and legends are not assigned automatically. A failed fit aborts the whole chart.

<ZodSchema name="RegressionExtraMethodSchema" shallow />

#### RegressionChartMarkSchema

`encodings` accepts only optional field-name strings for x, y, not the full recipe mapping objects. `properties` follows the meanings and member structure above, excluding `domainPadding`; `autoPadding` can override the chart policy. Omitted settings inherit the applicable chart mappings and properties.
