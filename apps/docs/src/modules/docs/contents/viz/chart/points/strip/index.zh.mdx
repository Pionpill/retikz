Strip Chart 用一个离散位置角色组织类别，再在该刻度附近散布每条观测。它适合查看组内分布、重叠和离群值；如果 x、y 都是连续变量，使用 [Scatter](/viz/chart/points/scatter)。

## `StripChart`

根 `recipe` 必须同时声明 x 与 y，并让最终位置 scale 恰好一个是离散、一个是连续。组件身份自动补齐 Point family 与 `chartType: 'strip'`：

```tsx
<StripChart
  rows={rows}
  recipe={{
    encodings: {
      x: { field: 'group', scale: { operation: { type: 'point', name: 'group' } } },
      y: { field: 'value', scale: { operation: { type: 'linear', name: 'value' } } },
    },
    properties: { jitter: { span: { kind: 'ratio', value: 0.3 }, seed: 0 } },
  }}
/>
```

`StripEncodings`、`StripProperties` 与 `StripMark` 是相同 recipe slots 的等价 JSX sugar。root-only 写法可以省略 `children`；不同 slot 可以混用，同一 slot 双来源会 fail-loud。

## 位置角色与散布

`x` 与 `y` 只接受 direct field mapping。scale 可以直接写 operation，也可以引用 `plotExtension.scales` 中的命名 scale；Chart 通过 Scale Definition 的 `continuity` 判断拓扑，因此自定义离散 scale 与内建 scale 走同一 registry 路径。

`jitter.span` 是**总散布宽度**。数字直接使用当前位置角色的输出单位；`{ kind: 'ratio', value }` 使用离散刻度间距的 `0..1` 比例。`distribution` 默认是 `{ kind: 'uniform' }`；切换为 `{ kind: 'normal', sigma }` 后，偏移仍以类别中心为零点，但会更集中在中心，并在 `[-span / 2, span / 2]` 内截断。`sigma` 相对于散布半宽，默认 `0.5`。省略时由 Plot 使用 `0.3`，`seed` 省略时为 `0`。相同有序数据、scale、span、distribution 与 seed 会得到相同位置。

Strip 使用的是 placement jitter：它只改变离散 role 上的绘制位置，不修改 rows 或连续值。若要在比例尺前派生字段，应使用 [Data transform](/viz/plot/transform) 的 `jitter`；Strip 不把两者混为一个配置。

默认 grid 只跟随连续角色。`domainPadding` 也只应用于连续位置 scale；离散边界的安全距离由 Plot placement 根据半个散布宽度与实际 glyph 外扩共同收窄 range，点不会被 clamp、缩小或绘制到坐标边界外。空间不足时会明确报错。

极坐标仍按角色空间散布后再投影：x 是 angle，y 是 radius。因此离散 x 沿圆弧移动，同一角度偏移在不同半径上产生不同弧长；离散 y 则沿径向移动。

## API 参考

### `StripEncodingsProps`

| 属性       | 类型                                    | 默认值 | 描述                                                |
| ---------- | --------------------------------------- | ------ | --------------------------------------------------- |
| `x` / `y`  | `IRStripXEncoding` / `IRStripYEncoding` | —      | 必需 direct mapping；最终必须恰好一个离散、一个连续 |
| `color?`   | `IRStripColorEncoding`                  | —      | 可选 direct 颜色字段与 scale binding                |
| `size?`    | `IRStripSizeEncoding`                   | —      | 可选 direct 半径字段与 sqrt scale binding           |
| `opacity?` | `IRStripOpacityEncoding`                | —      | 可选 direct 透明度字段与 linear scale binding       |
| `shape?`   | `IRStripShapeEncoding`                  | —      | 可选 direct 形状字段                                |

### `StripPropertiesProps`

| 属性                         | 类型                                                                    | 默认值                                                 | 描述                                                          |
| ---------------------------- | ----------------------------------------------------------------------- | ------------------------------------------------------ | ------------------------------------------------------------- |
| `jitter?`                    | `IRStripChartJitter`                                                    | `{ span: ratio(0.3), distribution: uniform, seed: 0 }` | 沿唯一离散位置角色确定性散布；Chart 不接受手写 `role`         |
| `jitter.distribution?`       | `IRPlotRandomDistribution`                                              | `{ kind: 'uniform' }`                                  | 选择均匀散布或集中于中心的截断正态分布                        |
| `jitter.distribution.kind`   | `'uniform' \| 'normal'`                                                 | `uniform`                                              | 随机分布判别值                                                |
| `jitter.distribution.sigma?` | `number`                                                                | `0.5`                                                  | 仅 normal 使用；相对于 jitter 半宽的标准差，必须大于 `0`      |
| `domainPadding?`             | `number` \| `{ kind?, default?, x?, y?, left?, right?, top?, bottom? }` | 最终最大 Point 半径                                    | 只配置连续位置 scale；离散 containment 由 Plot placement 负责 |
| Point 外观                   | `IRPointProperties`                                                     | Point 默认                                             | `size`、`shape`、颜色、描边、透明度等常量外观                 |

### `StripMarkProps`

| 属性          | 类型                         | 默认值  | 描述                                                         |
| ------------- | ---------------------------- | ------- | ------------------------------------------------------------ |
| `override?`   | `boolean`                    | `false` | 原位替换完整 Strip Point mark                                |
| `encodings?`  | `IRPointMarkEncoding`        | 继承    | 只覆盖 direct 字段；不能声明 mark-local scale                |
| `properties?` | `IRStripChartMarkProperties` | 继承    | 覆盖 Point 外观与 jitter；不接受 recipe-only `domainPadding` |
