条带图按类别组织观测，并在类别中心附近散布点，以减轻重叠。它适合比较各组数值分布、离群值与样本密集区域；位置映射必须恰好包含一个离散角色和一个连续角色。散布宽度不表示新的数值变量。

## 接入方式

完成 [安装与首次渲染](/viz/chart/get-start) 后，可用以下四种入口。示例共用同一数据与配置。

三种企鹅各 30 条观测，物种是离散位置，鳍长是连续位置。

本例固定横轴为地点、纵轴为产量，使用 point 离散尺度。同一地点有二十个观测，部分产量相近。散布范围与点半径共同决定遮挡程度，但这些设置不会改变任何一个产量值。

- `jitter.span`：控制总散布宽度，而不是单侧偏移。
- `jitter.distribution`：选择均匀或更集中在中心的正态散布。
- `jitter.seed`：改变散布位置，固定值可复现。
- `size`：调整点半径。

用固定 seed 比较分布形式，避免把随机位置变化当作数据变化。较宽的散布并不表示样本的测量方差更大。切换为极坐标后，本例的地点落在角度轴上：`jitter.span` 的 ratio 按相邻地点的角度间距确定散布角度，同一角度跨度在较大半径处对应更长的弧线，因此画面上的散布宽度会随半径变化，不是固定的像素宽度。具体用法见下方[极坐标散布](#极坐标散布)。

## 扩展用法

### 极坐标散布

地点映射到角度轴，产量映射到半径轴。这里把散布总宽设为相邻地点角度间距的 0.7 倍，并用 normal 与较小的 sigma 让点更集中在各地点的中心角附近。散布只改变角度，不改变产量对应的半径。

下表的 `coordinate` 位于图形根层，映射与属性位于 IR `recipe`；React 与 Vanilla 使用上文对应入口。

| 分组         | 属性名                  | 类型               | 说明                              |
| ------------ | ----------------------- | ------------------ | --------------------------------- |
| `coordinate` | `type`                  | `polar2D`          | 以角度和半径投影位置              |
| `encodings`  | `x / y`                 | 直接字段与尺度对象 | 地点为角度，产量为半径            |
| `properties` | `jitter.span`           | ratio 对象         | 角度总宽为地点刻度间距的 0.7 倍   |
|              | `jitter.distribution`   | normal 对象        | sigma 为 0.35，偏移仍截断在范围内 |
|              | `jitter.seed / opacity` | number             | 固定 seed 并用透明度识别重叠      |

沿同一角度偏移观察内外圈：弧长等于半径乘以弧度，外圈半径更大，点在画面上沿圆弧的间距也更大。调节散布比例改变的是角度范围，不是固定像素宽度；固定 seed 后可比较不同散布参数，而不把随机位置误认为产量变化。

## 错误与限制

- 最终位置尺度必须恰好一个离散、一个连续；两个连续变量应使用 Scatter。
- 只支持直接字段映射；不支持 `row`、`column`、`facet`。需要其他组合时使用 Plot。
- 散布不修改原始 rows；固定 seed 的复现还要求输入顺序和尺度等配置相同。
- 离散方向没有足够空间容纳散布与图元时明确报错，不靠缩小或裁切点掩盖问题。

React 中，同一项配置不能同时通过根 `recipe` 与子组件声明，否则报错。

`point-aware` 支持离散位置轴，并使用散布后的实际点位置计算留白。全部方向显式指定 `domainPadding` 时不启动逐点求解。公共属性和覆盖规则见 [点图公共配置](/viz/chart/points#公共配置)。

Chart 将条带图元解析为 Plot Point，并把散布配置放入该 Point 的位置调整。下表只列条带图特有的转换。

| 分组 | `@retikz/chart`        | `@retikz/plot`             | 描述                                           |
| ---- | ---------------------- | -------------------------- | ---------------------------------------------- |
| 映射 | `x`、`y`               | `encoding.x`、`encoding.y` | 保留原始类别与数值字段，由最终尺度确定离散方向 |
| 属性 | `jitter`               | `placement.adjustments`    | 添加 Jitter 位置调整，散布参数由 Plot 应用     |
| 图元 | `StripChartMarkSchema` | `PointMarkSchema`          | 每个条带图元解析为一个带散布配置的 Plot Point  |

## API 参考

React 使用 `StripChart`，可通过 `recipe` 属性或专属子组件提供配置。Vanilla API 使用 `stripChart`，直接提供 `encodings`、`properties`、`marks`；直接 IR 将这些配置放在 `recipe` 中，并设置 `recipe.chartType: 'strip'`。React 与 Vanilla API 会补齐图形类型。

React 中，同一项配置不能同时通过根属性与子组件声明；不同配置项可以混用两种写法。公共数据、布局与标题配置见 [通用结构](/viz/chart/model/general-structure)。

#### StripEncodings

对应 `StripEncodings`、Vanilla `encodings` 和 IR `recipe.encodings`。

| 通道      | 输入形式         | 说明                                                 |
| --------- | ---------------- | ---------------------------------------------------- |
| `x / y`   | 字段名、直接映射 | 必需；只接受直接映射，最终尺度恰好一个离散、一个连续 |
| `color`   | 字段名、直接映射 | 直接颜色字段，可绑定兼容颜色尺度                     |
| `size`    | 字段名、直接映射 | 直接数值字段，尺寸使用 sqrt 尺度                     |
| `opacity` | 字段名、直接映射 | 直接数值字段，透明度使用 linear 尺度                 |
| `shape`   | 字段名、直接映射 | 直接分类形状字段                                     |

公共映射参数不在这里展开；精确输入结构见 [映射 Schema](#stripchartencodingsschema)。

#### StripProperties

对应 `StripProperties`、Vanilla `properties` 和 IR `recipe.properties`。

| 分类       | 属性                  | 类型                                                     | 说明                                                             |
| ---------- | --------------------- | -------------------------------------------------------- | ---------------------------------------------------------------- |
| 形状与尺寸 | `size`                | `number`                                                 | 统一点半径，必须大于或等于 0                                     |
|            | `shape`               | `string`                                                 | 已注册的形状名                                                   |
| 颜色与填充 | `color`               | `string`                                                 | 设置主色                                                         |
|            | `fill`                | `string`、`JsonObject`                                   | 设置填充颜色、画笔                                               |
| 描边       | `stroke`              | `string`、`JsonObject`                                   | 设置描边颜色、画笔                                               |
|            | `strokeWidth`         | `number`                                                 | 描边宽度，必须大于或等于 0                                       |
|            | `dashed`              | `boolean`                                                | 启用虚线描边                                                     |
|            | `dotted`              | `boolean`                                                | 启用点线描边                                                     |
|            | `dashPattern`         | `Array<number>`                                          | 自定义虚线序列；至少一项，各项非负                               |
| 透明度     | `opacity`             | `number`                                                 | 整体透明度，范围 0–1                                             |
|            | `fillOpacity`         | `number`                                                 | 填充透明度，范围 0–1                                             |
|            | `strokeOpacity`       | `number`                                                 | 描边透明度，范围 0–1                                             |
| 散布       | `jitter.span`         | `IRStripChartJitter['span']`                             | 总散布宽度；数字使用角色输出单位，ratio 使用刻度间距的 0–1 比例  |
|            | `jitter.distribution` | `IRStripChartJitter['distribution']`                     | 均匀、截断正态分布；sigma 大于 0，相对散布半宽                   |
|            | `jitter.seed`         | `number`                                                 | 相同有序数据与配置下稳定复现散布；省略为 0                       |
| 留白       | `autoPadding`         | `'max-radius'`、`'point-aware'`、`object`                | 自动留白策略；对象写法通过 kind 选择策略、clearance 设置外缘净空 |
|            | `domainPadding`       | `number`、`IRBoxSpacing & { kind?: 'range' \| 'ratio' }` | 显式位置域留白，优先于自动策略                                   |

完整属性结构见 [属性 Schema](#stripchartpropertiesschema)；公共外观配置不在这里展开。

#### StripMark

对应 `StripMark`、Vanilla `marks` 和 IR `recipe.marks`。

| 属性         | 类型                           | 说明                                                                       |
| ------------ | ------------------------------ | -------------------------------------------------------------------------- |
| `override`   | `boolean`                      | 替换完整条带点图元，否则追加                                               |
| `encodings`  | `StripChartMark['encodings']`  | x、y、color、size、opacity、shape 各项使用字段名字符串，不声明图元局部尺度 |
| `properties` | `StripChartMark['properties']` | 覆盖散布与外观；不接受 domainPadding / autoPadding                         |
