---
title: 折线图
description: 以开放路径连接序列观测，支持多系列、可选观测点、曲线、阶梯与缺值连接。
---

折线图把一个指标沿序列的变化连接起来。路径是主体，点是可选的观测标记；它不执行回归，也不会补出缺失数据。二维观测的行进轨迹可使用 [连接散点图](/viz/chart/points/connected-scatter)。

## 基础用法

### 折线映射

映射决定观测位置、系列身份和连接顺序。系列身份独立于颜色；指定相同颜色不会合并不同系列。

<DocTabs defaultValue="react-jsx">
<DocTab value="react-jsx" label="React + JSX">

```tsx
<LineEncodings x="x" y="y" series="series" />
```

</DocTab>
<DocTab value="vanilla-api" label="Vanilla API">

```ts
encodings: { x: 'x', y: 'y', series: 'series' }
```

</DocTab>
<DocTab value="direct-ir" label="IR">

```json
{ "recipe": { "encodings": { "x": "x", "y": "y", "series": "series" } } }
```

</DocTab>
</DocTabs>

| 属性名          | 类型                 | 说明                                   |
| --------------- | -------------------- | -------------------------------------- |
| `x`、`y`        | 字段名、位置映射对象 | 必填；支持直接字段、单值聚合与显式尺度 |
| `series`        | 字段名、直接映射对象 | 分开连接各系列，默认分配系列颜色       |
| `order`         | 字段名、直接映射对象 | 稳定升序；省略时保留数据行顺序         |
| `row`、`column` | 字段名、分面维度     | 按行列划分面板                         |
| `facet`         | `IRPlotFacetOptions` | 分面配置，须配合 row 或 column         |

数据记录 A、B 两组的六次观测；x 是采样位置，y 是指标值。B 的第三次观测缺失。

- `x`、`y`：分别绑定同名字段，确定样本位置。
- `series`：绑定 series，将 A、B 分开连接。
- `order`：默认不设置，保留输入顺序。

本例默认保留原始输入顺序。打开“打乱输入顺序”会打乱 A 的前三条记录，连线随之出现折返；关闭后恢复。关闭系列分组会把两组数据视为同一序列。

### 折线属性

属性控制连接形态和观测点外观，不改变字段绑定。平滑、阶梯和带点展示均属于折线图的配置。

<DocTabs defaultValue="react-jsx">
<DocTab value="react-jsx" label="React + JSX">

```tsx
<LineProperties point={false} path={{ curve: 'linear', strokeWidth: 2, connectNulls: false }} />
```

</DocTab>
<DocTab value="vanilla-api" label="Vanilla API">

```ts
properties: { point: false, path: { curve: 'linear', strokeWidth: 2, connectNulls: false } }
```

</DocTab>
<DocTab value="direct-ir" label="IR">

```json
{
  "recipe": {
    "properties": { "point": false, "path": { "curve": "linear", "strokeWidth": 2, "connectNulls": false } }
  }
}
```

</DocTab>
</DocTabs>

| 属性名              | 类型                               | 说明                                                                        |
| ------------------- | ---------------------------------- | --------------------------------------------------------------------------- |
| `point`             | `boolean`、`IRLinePointProperties` | 默认 false；true 或样式对象显示点，对象可设置半径、形状、填充、描边及透明度 |
| `path`              | `IRLinePathProperties`             | 路径外观与连接方式                                                          |
| `path.curve`        | 曲线名、曲线配置                   | 默认 linear，支持 Plot 阶梯与平滑曲线                                       |
| `path.strokeWidth`  | `number`                           | 默认 2，可显式设为 0                                                        |
| `path.connectNulls` | `boolean`、桥接配置                | 默认 false，跨缺值连接但不补充观测值                                        |

`point: true` 使用默认样式，`point: { size: 4, fill: '#fff' }` 显示点并设置样式；空对象 `{}` 也会显示点。

沿用两组采样数据，对比直线、阶梯和平滑连接。

- `point`：默认 false；打开后使用 `{ size: 4 }`，通过“点半径”调节样本标记大小。
- `path.curve`：默认 linear，切换连接方式时样本位置不变。
- `path.strokeWidth`：默认 2，调节线宽观察路径辨识度。

下拉框列出 Path 的全部 10 种连接方式。B 样条通常不穿过所有中间样本；X / Y 单调插值适合对应轴递增的数据。打开观测点后比较路径与样本的位置关系。

### 折线图元

图元可在内建折线之外追加线／点组合，也可以替换内建组合。它继承配方的映射与属性，只需声明差异。

<DocTabs defaultValue="react-jsx">
<DocTab value="react-jsx" label="React + JSX">

```tsx
<LineMark properties={{ point: false, path: { curve: 'step', stroke: '#a855f7' } }} />
```

</DocTab>
<DocTab value="vanilla-api" label="Vanilla API">

```ts
marks: [lineMark({ properties: { point: false, path: { curve: 'step', stroke: '#a855f7' } } })];
```

</DocTab>
<DocTab value="direct-ir" label="IR">

```json
{
  "recipe": {
    "marks": [{ "kind": "line", "properties": { "point": false, "path": { "curve": "step", "stroke": "#a855f7" } } }]
  }
}
```

</DocTab>
</DocTabs>

| 属性名       | 类型             | 说明                                    |
| ------------ | ---------------- | --------------------------------------- |
| `override`   | `boolean`        | 默认追加；true 替换同 kind 的完整内建组 |
| `encodings`  | 直接字段覆盖对象 | 可覆盖 x、y、order，不改变系列或分面    |
| `properties` | 稀疏成员属性     | 覆盖 path、point，其余继承配方          |

示例在 A、B 原始直线上追加紫色阶梯线，使用相同数据与位置映射。

- `properties.path.curve`：设为 step，与内建直线对照。
- `properties.path.stroke`：设为紫色，区分追加组合与内建组合。
- `override`：默认 false，保留两组；打开后只保留阶梯组合。

打开“显示追加观测点”，再切换替换开关。替换以完整语义组为单位，不是仅替换一条 Plot Path。

## 扩展用法

以下分组均位于 IR 的 recipe 中，属性名相对于各自分组。

### 标识缺失观测

采集中断时，可以保留缺口或连接前后样本。桥接不是插值，不代表缺失位置的实测值。

| 分组         | 属性名              | 类型                | 说明                        |
| ------------ | ------------------- | ------------------- | --------------------------- |
| `encodings`  | `series`            | 字段名、映射对象    | 在各系列内部处理缺口        |
| `properties` | `path.connectNulls` | `boolean`、桥接配置 | true 使用默认虚线桥接       |
|              | `point`             | `boolean`           | 本例设为 true，标出实际样本 |

B 在 x=3 处没有观测。打开“连接缺口”，比较 x=2 与 x=4 之间的路径：出现虚线，但 x=3 处仍没有点。

### 分面比较系列

将重叠的系列拆成独立面板。分面改变分组和布局，不改变样本值。

| 分组        | 属性名                                     | 类型             | 说明                 |
| ----------- | ------------------------------------------ | ---------------- | -------------------- |
| `encodings` | `column` / `row`                           | 字段名、分面维度 | 按 series 分列或分行 |
|             | `series`                                   | 字段名、映射对象 | 保留系列身份与颜色   |
|             | `facet.header.column` / `facet.header.row` | `boolean`        | 控制分面标题         |

宽屏左右、窄屏上下分别展示 A 和 B；窄屏改用 row 分面以保留横轴空间。关闭“按系列分面”回到同一面板，比较叠加与分面的阅读效果；分面开启时可切换标题。

## 错误与限制

- 输入顺序、排序字段和轴 domain 是不同的配置，不会相互推断。
- 不补齐整行、不插值观测值、不自动聚合重复位置；缺值桥接只改变路径。
- 路径保持开放，不支持面积填充或闭合；Slope、Bump 和面积系列不属于 Line。
- 同一 React slot 不能同时使用根 recipe 与子声明；错误的字段或尺度引用由对应 owner 报错。

## 实现原理

<ComponentAlert type="tip" title="选读" description="只需要使用图表时可以跳过本节。" />

### 图形构建

| 分组 | `@retikz/chart`       | `@retikz/plot`                        | 描述                              |
| ---- | --------------------- | ------------------------------------- | --------------------------------- |
| 映射 | `x`、`y`              | `encodings.position`                  | 绑定 Path 与可选 Point 的同源位置 |
|      | `series`、`order`     | `encodings.series`、`encodings.order` | 在系列内按指定顺序连接路径        |
| 属性 | `path`                | Path 的 `properties`                  | 路径恒为开放路径，默认线宽 2      |
|      | `point`               | Point 的 `properties`                 | 开启 point 时加入观测点           |
| 图元 | `LineChartMarkSchema` | `PathMarkSchema`、`PointMarkSchema`   | 一组 Line 解析为路径与可选点      |

Line 配方把位置、顺序、系列和常量属性映射到 Plot Path；启用 point 时，再加入同源 Point。Plot 在各分面和系列内连接数据，负责投影、曲线与缺口几何，最后沿 Core 主链生成 Scene。Chart 不另建排序或曲线算法。
