---
title: 点图
description: 用点的位置及点之间的关系展示单个观测，并按图表结构选择合适的点图。
---

点图以一个或多个数据点为视觉主体。这个分组既帮助读者按视觉结构选择图表，也保留为源码目录与 `/point` 多入口导入边界；它不对应 `PointChartSchema`、Point 专属解析器或运行时分发层级。如果只需要比较两个连续变量，从散点图开始。

散点图与气泡图分别拥有 `ScatterChartSchema` 与 `BubbleChartSchema`。它们采用一致的 `namespace: 'chart'`、`plot` 和整图展示结构，但各自用精确 `type` 与 `config` 表达独有编码：气泡图不是散点图的样式，而是额外要求第三个定量尺寸角色的独立类型。

## 职责一览

| 图表                                | 职责                                 | 适合场景                         |
| ----------------------------------- | ------------------------------------ | -------------------------------- |
| [散点图](/viz/chart/points/scatter) | 用二维位置展示两个连续变量的关系     | 查看分布、聚类、离群点或相关趋势 |
| [气泡图](/viz/chart/points/bubble)  | 在二维位置上用面积补充第三个定量变量 | 同时比较关系与量级               |
