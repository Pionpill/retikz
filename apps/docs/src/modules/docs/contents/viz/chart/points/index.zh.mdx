---
title: 点图
description: 用点的位置及点之间的关系展示单个观测，并按图表结构选择合适的点图。
---

点图以一个或多个数据点为视觉主体。这个分组按稳定的图表结构组织常用类型；如果只需要比较两个连续变量，从散点图开始。散点图与气泡图是 Scatter & Points family 下并列的 Canonical Type；气泡图不是散点图的样式 Pattern，而是额外要求第三个定量尺寸角色的独立类型。

## 职责一览

| 图表                                | 职责                                 | 适合场景                         |
| ----------------------------------- | ------------------------------------ | -------------------------------- |
| [散点图](/viz/chart/points/scatter) | 用二维位置展示两个连续变量的关系     | 查看分布、聚类、离群点或相关趋势 |
| [气泡图](/viz/chart/points/bubble)  | 在二维位置上用面积补充第三个定量变量 | 同时比较关系与量级               |
