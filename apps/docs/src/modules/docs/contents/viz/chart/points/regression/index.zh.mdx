回归图在原始观测点上叠加拟合趋势，用来概括两个连续变量的关系。每行数据提供一对观测值；可按 series 分别拟合。趋势不会经过所有点，也不代表因果关系或预测已经过验证。

## 基础用法

### 回归映射

React 通过 `RegressionEncodings` 声明，Vanilla API 使用 `encodings`，直接 IR 使用 `recipe.encodings`。映射确定拟合使用的两个变量，以及是否按类别分别拟合。

Iris 数据包含 150 条鸢尾花观测。横轴为萼片长度，纵轴为花瓣长度；不同物种可能有不同的分布范围，因此分组决定了趋势线在概括哪些样本。

- `x / y`：分别绑定 sepalLengthCm 和 petalLengthCm。
- `series`：绑定 species，让物种分别拟合。

切换分组观察整体趋势和组内趋势的差别。整体相关性可能部分来自组间差异，不能直接代替每个物种内部的关系。

### 回归属性

React 通过 `RegressionProperties` 声明，Vanilla API 使用 `properties`，直接 IR 使用 `recipe.properties`。属性选择拟合方法与绘制采样，并分别设置观测点和趋势线外观。

本例固定横纵轴映射，默认将全部观测合并拟合，也可开启“按物种分别拟合”，比较相同方法在各组上的趋势。分组后点与趋势线使用物种分类颜色，不再显示统一颜色控件。同一批观测可用不同方法进行拟合。方法控制模型形式，采样数只决定绘制趋势时使用多少预测点；二者不是同一件事。

- `method`：选择线性、二次或其他支持的方法。
- `sampleCount`：增加曲线绘制采样，不增加原始样本。
- `point / trend`：分别调整观测和趋势的视觉权重。

增加 sampleCount 不会提高模型阶数，也不会修复样本不足。选择方法前应检查该方法对正值与样本数量的要求。

### 回归图元

React 通过 `RegressionMark` 声明，Vanilla API 使用 `marks`，直接 IR 使用 `recipe.marks`。 React 不传 `kind`；Vanilla / IR 图元对象使用 `kind: 'regression'`。每个图元包含观测点、主趋势与额外趋势，可用于替换整个组合或叠加不同位置映射。同一观测的多方法比较使用 `extraMethods`，见下方扩展用法。

- `override`：替换主回归组合。
- `properties.method`：设为 quadratic。
- `properties.trend.strokeWidth`：加粗趋势方便辨认。

RegressionMark 始终继承 series，不能在同一个图元里改成另一套分组规则。

## 扩展用法

### 分面比较

将 species 同时用于分组与面板，可以把密集观测拆开，并检查每个物种的趋势是否由足够的组内变化支撑。

### 拟合方法比较

保留整体线性趋势，通过 `extraMethods` 追加多项式拟合，观察模型形式如何影响同一数据上的趋势。观测点只绘制一次，各条趋势共享位置映射和分组；示例默认使用三次多项式，可通过控件调整阶数。

下表分组均为 IR `recipe` 内的属性；React 与 Vanilla 使用上文对应入口。

| 分组         | 属性名                 | 类型                             | 说明                                       |
| ------------ | ---------------------- | -------------------------------- | ------------------------------------------ |
| `encodings`  | `x / y`                | 字段映射                         | 两个模型使用相同观测                       |
| `properties` | `trend`                | 路径外观对象                     | 主模型使用蓝色实线                         |
|              | `extraMethods`         | `Array<IRRegressionExtraMethod>` | 追加多项式趋势，不重复绘制观测点           |

## 错误与限制

各方法的方程、样本数量与值域要求见 [拟合方法](#拟合方法)。

- 任一分组样本不足、秩退化或预测非有限时，整张图明确失败，不静默退化成散点图。
- 非有限 x / y 对先过滤；对数、指数与幂方法的正值条件仍需满足。
- 自定义方法必须注入当前运行的 registry；方法名不能与内置或其他注入项重复。
- 默认过点曲线可能在采样点之间过冲；它改善视觉连续性，不保证点间严格等于模型，也不替代预测验证。

React 中，同一项配置不能同时通过根 `recipe` 与子组件声明，否则报错。

`point-aware` 仅支持二维笛卡尔坐标、linear/time 位置尺度且无散布的组合。全部方向显式指定 `domainPadding` 时不启动逐点求解。公共属性和覆盖规则见 [点图公共配置](/viz/chart/points#公共配置)。

## 实现原理

### 拟合方法

Regression 通过 Plot 的 `smooth` 变换拟合趋势。每个分面、每个 `series` 分组独立计算；先过滤非有限的 x / y 数据对，再用剩余的 $N$ 对观测 $(x_i,y_i)$ 求解模型。`method` 和 `extraMethods` 中的每种方法都执行这一过程。

| 名称       | 方法          | 方程                          | 有效样本与值域                            | 拟合时间复杂度 |
| ---------- | ------------- | ----------------------------- | ----------------------------------------- | -------------- |
| 线性       | `linear`      | $\hat y=a+bx$                 | 至少两对且至少两个不同 x                  | $O(N)$         |
| 二次多项式 | `quadratic`   | $\hat y=a+bx+cx^2$            | 至少三对、三个不同 x，且拟合满秩          | $O(N)$         |
| 多项式     | `polynomial`  | $\hat y=\sum_{k=0}^{n}c_kx^k$ | 至少 n + 1 对、n + 1 个不同 x，且拟合满秩 | $O(Nn^2+n^3)$  |
| 对数       | `logarithmic` | $\hat y=a+b\ln x$             | 至少两对、不同 x；x 与采样范围为正        | $O(N)$         |
| 指数       | `exponential` | $\hat y=ae^{bx}$              | 至少两对、不同 x；y 为正                  | $O(N)$         |
| 幂         | `power`       | $\hat y=ax^b$                 | 至少两对、不同 x；x、y 和采样范围为正     | $O(N)$         |

其中 $\hat y$ 是预测值。`polynomial` 的阶数 $n$ 由 `order` 指定，省略为 3，允许 2–6 的整数。

表中复杂度针对当前实现中单组、单个模型的参数求解，$N$ 为过滤后的有效样本数，$n$ 为多项式阶数；按固定精度数值运算计，不包含分组、趋势采样及渲染。多个分组、多个拟合方法的计算开销分别累加。

#### 线性拟合

`linear` 寻找一条直线，使观测值与预测值之间的纵向残差平方和最小：

$$
\min_{a,b}\sum_{i=1}^{N}\left(y_i-a-bx_i\right)^2
$$

先计算横纵坐标的均值 $\bar x$、$\bar y$，再得到斜率与截距：

$$
b=\frac{\sum_{i=1}^{N}(x_i-\bar x)(y_i-\bar y)}{\sum_{i=1}^{N}(x_i-\bar x)^2},\qquad a=\bar y-b\bar x
$$

如果所有 x 都相同，分母为零，无法确定斜率，因此拟合失败。

**时间复杂度：** 求均值、方差和协方差只需常数次遍历样本，因此参数求解为 $O(N)$；求得系数后，单次预测为 $O(1)$。

#### 二次与多项式拟合

`quadratic` 固定使用二阶多项式；`polynomial` 使用指定阶数。两者都求解原始 y 空间中的最小二乘问题。为减轻高次幂带来的数值问题，实现先将 x 平移、缩放到 $[-1,1]$：

$$
m=\frac{x_{\min}+x_{\max}}{2},\qquad s=\max_i\lvert x_i-m\rvert,\qquad z_i=\frac{x_i-m}{s}
$$

以 $1,z_i,z_i^2,\ldots,z_i^n$ 作为设计矩阵 $V$ 的第 i 行，求归一化坐标下的系数向量 $\boldsymbol\beta$：

$$
\min_{\boldsymbol\beta}\sum_{i=1}^{N}\left(y_i-\sum_{k=0}^{n}\beta_kz_i^k\right)^2,
\qquad
(V^{\mathsf T}V)\boldsymbol\beta=V^{\mathsf T}\mathbf y
$$

实现使用带缩放选主元的高斯消元与回代求解该方程组，并以 Horner 法计算预测值。预测时仍先将输入 x 转换为 z；归一化不改变拟合的多项式阶数。样本不足、不同 x 数量不足或数值上秩退化时会报错，不自动降低阶数。

**时间复杂度：** 累加正规方程矩阵需要 $O(Nn^2)$，消元求解需要 $O(n^3)$，合计 $O(Nn^2+n^3)$；Horner 法单次预测为 $O(n)$。二次拟合的阶数固定为 2，因此拟合为 $O(N)$、单次预测为 $O(1)$。当前多项式阶数限定为 2–6，固定阶数时也随样本数线性增长。

#### 对数、指数与幂拟合

这三种方法先变换数据，再复用线性拟合中的斜率、截距计算，最后将结果转换回原始 y 空间：

| 方法          | 用于线性拟合的数据            | 还原预测值                       |
| ------------- | ----------------------------- | -------------------------------- |
| `logarithmic` | $(u_i,v_i)=(\ln x_i,y_i)$     | $\hat y=\alpha+\beta\ln x$       |
| `exponential` | $(u_i,v_i)=(x_i,\ln y_i)$     | $\hat y=\exp(\alpha+\beta x)$    |
| `power`       | $(u_i,v_i)=(\ln x_i,\ln y_i)$ | $\hat y=\exp(\alpha+\beta\ln x)$ |

指数与幂模型中的系数为 $a=e^\alpha$、$b=\beta$。它们最小化的是对数 y 空间中的残差平方和，因此通常与直接最小化原始 y 残差的非线性拟合结果不同。取对数的字段必须为正；仅将坐标轴设置为 log 尺度不会改变拟合方法。

**时间复杂度：** 对数变换与后续线性拟合均为 $O(N)$，因此这三种方法的参数求解各为 $O(N)$；单次预测只需固定次数的算术与对数、指数运算，为 $O(1)$。

#### 从模型得到趋势线

求得系数后，在 `extent` 指定的范围内均匀选取 `sampleCount` 个 x，再代入模型得到预测值。省略范围时使用当前组有效 x 的最小值与最大值；采样数默认 64。设范围为 $[L,U]$、采样数为 $M$：

$$
x_j=L+\frac{j}{M-1}(U-L),\qquad \hat y_j=f(x_j),\qquad j=0,\ldots,M-1
$$

趋势线默认用 `catmullRom` 过点曲线按 x 顺序连接预测点，经三次贝塞尔绘制。`trend.curve: 'linear'` 改为逐点折线；其他取值复用 Plot Path 的连接方式。增加采样数只让曲线绘制更细致，不改变拟合系数，也不会增加原始样本。超出观测范围的 `extent` 会产生外推结果，其可靠性需要另行判断。

所有拟合方法统一使用完整的固定采样与所选连接方式，不单独简化线性拟合。在线性坐标下，共线预测点经过默认过点曲线连接后仍呈现直线；非线性坐标下按投影后的采样点连接。

**采样时间复杂度：** 生成 $M$ 个预测点时，线性、二次、对数、指数与幂模型为 $O(M)$，n 阶多项式为 $O(Mn)$。加上参数求解，前五种方法合计 $O(N+M)$，多项式合计 $O(Nn^2+n^3+Mn)$；这些是拟合与数值采样开销，不代表整张图的渲染复杂度。

### 自定义拟合

自定义方法只需定义参数 schema 和 `fit`：schema 用唯一的字面量 `kind` 标识方法，负责参数约束与默认值；`fit(pairs, operation)` 接收当前组的有效观测与已解析参数，返回带 `predict(x)` 的模型。Data 不生成绘图路径，Plot 负责按 `extent`、`sampleCount` 采样，再用 `trend.curve` 连接预测点。

用 `@retikz/data` 的 `defineRegression` 定义方法，再通过 `lowerOptions.regressionDefinitions` 注入。内置与外部方法使用同一注册与执行流程；JSON 只保存方法名和参数，不保存函数。

下面实现一个**固定斜率拟合算法**：调用方给定斜率，算法根据观测数据自动求解截距，使残差平方和最小。它适合斜率已由先验关系确定、只需估计整体偏移的情况。

与同时估计斜率和截距的内置线性回归不同，这个方法只拟合截距。`slope` 是自定义参数，省略时由 schema 补为 `1`。

固定斜率 $b$ 后，只需求解截距 $a$：

$$
a=\frac{1}{N}\sum_{i=1}^{N}(y_i-bx_i),\qquad \hat y=a+bx
$$

这个例子的拟合复杂度为 $O(N)$，单次预测为 $O(1)$。使用下面的三对观测并设置 `slope: 2`，得到 $a=4/3$；在 $x=0,1,2$ 处的预测值分别为 $4/3,10/3,16/3$。斜率由调用方指定，截距仍由当前组数据计算。

```ts
import { defineRegression, RetikzDataError } from '@retikz/data';
import { literal, number, strictObject } from 'zod';

export const fixedSlopeFit = defineRegression({
  schema: strictObject({
    kind: literal('fixed-slope'),
    slope: number().default(1),
  }),
  fit: (pairs, { slope }) => {
    if (pairs.length === 0) throw new RetikzDataError('fixed-slope requires at least one observation');
    const intercept = pairs.reduce((sum, pair) => sum + pair.y - slope * pair.x, 0) / pairs.length;
    return { predict: x => intercept + slope * x };
  },
});

export const lowerOptions = { regressionDefinitions: [fixedSlopeFit] };
export const rows = [
  { x: 0, y: 1 },
  { x: 1, y: 4 },
  { x: 2, y: 5 },
];
```

import { RegressionChart } from '@retikz/chart-react/point';

<RegressionChart

Vanilla 使用同一份 Definition、数据和方法参数：

```ts
import { regressionChart } from '@retikz/chart-vanilla/point';

const chart = regressionChart({
  data: rows,
  encodings: { x: 'x', y: 'y' },
  properties: { method: { kind: 'fixed-slope', slope: 2 } },
  lowerOptions,
});
```

</DocTab>

直接 IR 在 `recipe.properties.method` 保存同一 JSON 对象，并将同一 `lowerOptions` 分别交给 `createRegressionChartProviderContribution([], lowerOptions)` 与 `createPlotProviderContribution({ rows }, lowerOptions)`。这些入口分别从 `@retikz/chart/point` 与 `@retikz/plot` 导入。

`extraMethods[].method` 也可以引用自定义方法。每个分组独立拟合，`fit` 必须是同步纯函数，不修改观测；输出非有限值、未知参数、未注册或重复方法都会报错。需要特殊预测域时使用 `validateExtent(operation, extent)`。

## API 参考

React 使用 `RegressionChart`，可通过 `recipe` 属性或专属子组件提供配置。Vanilla API 使用 `regressionChart`，直接提供 `encodings`、`properties`、`marks`；直接 IR 将这些配置放在 `recipe` 中，并设置 `recipe.chartType: 'regression'`。React 与 Vanilla API 会补齐图形类型。

React 中，同一项配置不能同时通过根属性与子组件声明；不同配置项可以混用两种写法。公共数据、布局、标题与指南配置见 [编写与解析](/viz/chart/model/authoring)。

### 回归映射

对应 `RegressionEncodings`、Vanilla `encodings` 和 IR `recipe.encodings`。

| 通道           | 输入形式             | 说明                                                    |
| -------------- | -------------------- | ------------------------------------------------------- |
| `x / y`        | 字段名、位置映射     | 必需；自变量与因变量，决定点的位置                      |
| `series`       | 字段名、直接映射     | 分别拟合各组，并共享分类颜色与图例；可绑定 ordinal 尺度 |
| `row / column` | 字段名、分面维度     | 按当前面板数据独立拟合                                  |
| `facet`        | `IRPlotFacetOptions` | 配置分面；须配合 `row`、`column` 中至少一项             |

公共映射参数不在这里展开；精确输入结构见 [映射 Schema](#regressionchartencodingsschema)。

### 回归属性

对应 `RegressionProperties`、Vanilla `properties` 和 IR `recipe.properties`。

| 分类 | 属性            | 类型                                                     | 说明                                                             |
| ---- | --------------- | -------------------------------------------------------- | ---------------------------------------------------------------- |
| 拟合 | `method`        | `IRRegressionChartProperties['method']`                  | 选择拟合方法及参数                                               |
|      | `extraMethods`  | `Array<IRRegressionExtraMethod>`                         | 有序追加拟合趋势，共享观测点；省略不追加                         |
|      | `sampleCount`   | `number`                                                 | 每组预测点数，至少为 2 的整数；省略为 64                         |
|      | `extent`        | `[number, number]`                                       | 递增的预测范围；省略使用该组有限 x 范围                          |
| 外观 | `point`         | `IRRegressionPointProperties`                            | 设置观测点外观                                                   |
| 趋势 | `trend.curve`   | `IRRegressionTrendProperties['curve']`                   | 默认 `catmullRom`，额外趋势继承并可覆盖                          |
|      | `trend`         | `IRRegressionTrendProperties`                            | 设置趋势线外观，不改变拟合方法                                   |
| 留白 | `autoPadding`   | `'max-radius'`、`'point-aware'`、`object`                | 自动留白策略；对象写法通过 kind 选择策略、clearance 设置外缘净空 |
|      | `domainPadding` | `number`、`IRBoxSpacing & { kind?: 'range' \| 'ratio' }` | 显式位置域留白，优先于自动策略                                   |

完整属性结构见 [属性 Schema](#regressionchartpropertiesschema)；公共外观配置不在这里展开。

### 回归图元

对应 `RegressionMark`、Vanilla `marks` 和 IR `recipe.marks`。

| 属性         | 类型                                | 说明                                                                                                              |
| ------------ | ----------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `override`   | `boolean`                           | 替换完整观测＋趋势组合，否则追加                                                                                  |
| `hidePoints` | `boolean`                           | 默认 `false`；为 `true` 时不生成当前图元的散点，保留主趋势和额外趋势。                                            |
| `encodings`  | `RegressionChartMark['encodings']`  | 覆盖同一数据中的直接字段；不覆盖 series                                                                           |
| `properties` | `RegressionChartMark['properties']` | method、sampleCount、extent 按字段覆盖，point / trend 内逐项合并；extraMethods 整体替换，空数组清空；不含留白策略 |
