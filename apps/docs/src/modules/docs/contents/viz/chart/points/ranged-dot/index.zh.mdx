范围点图在每个类别上放置两个端点，并用连接线表达两值之间的距离。它适合比较前后变化、上下界或两次测量；每行数据必须同时包含类别、起点值和终点值。端点角色由字段决定，不随数值大小交换。

## 接入方式

完成 [安装与首次渲染](/viz/chart/get-start) 后，可用以下四种入口。示例共用同一数据与配置。

## 基础用法

### 范围点映射

映射确定每行类别与成对数值，起点和终点保留各自的数据含义。

<DocTab value="react-jsx" label="React + JSX">

```tsx

```

</DocTab>
<DocTab value="vanilla-api" label="Vanilla API">

```ts

  category: 'country',
  start: 'forestArea2000',
  end: 'forestArea2022',
},
```

</DocTab>
<DocTab value="direct-ir" label="IR">

```ts
recipe: {
  encodings: {
    category: 'country',
    start: 'forestArea2000',
    end: 'forestArea2022',
  },
},
```

</DocTab>
</DocTabs>

下面比较十八个国家 2000 与 2022 年的森林覆盖率。每行是一国，两个端点表示森林面积占国土的百分比；线段的水平跨度显示两期差额。

- `category`：用 country 确定纵向类别。
- `start`：默认绑定 forestArea2000，蓝色端点代表起点。
- `end`：默认绑定 forestArea2022，橙色端点代表终点。

默认映射下，终点在起点左侧表示覆盖率下降，右侧表示上升。交换起终点字段后，颜色所代表的年份随之交换，但两个测量位置与线段跨度不变。数据按 2022 年数值排列，不能把排列顺序当作变化幅度排名。

</DocTab>

本节保持森林覆盖率数据不变，只强调两个年份的辨识。端点使用不同颜色，连接线承担两点之间的参照作用。

- `point.size`：统一设置两个端点半径。
- `startPoint.color / endPoint.color`：分别标识 2000 年和 2022 年。
- `range.strokeWidth`：调整连接线宽度，不改变差值。

端点靠得很近时可以适当减小半径。只改变 endPoint 不会改变 startPoint，因此适合突出最近一次测量。

下面通过一个替换图元将 2022 年端点改成较大的菱形。颜色与形状共同区分年份，线段和起点继续继承原有配置。

- `override`：设为 true，替换这一套成对图形。
- `properties.endPoint`：覆盖终点形状和半径。
- `properties.range`：设置连接线宽度。

这是整组替换中的局部外观覆盖。起点和终点分别由 PointMark 绘制，读取同一数据行中的不同字段。

## 扩展用法

### 白昼时段的环形比较

把一天的 24 小时排在圆周上，用六个同心环表示东京 2024 年隔月 15 日的日出与日落。蓝色端点是日出，橙色端点是日落；连接弧表示当天的白昼时段。数据来自 Open-Meteo Historical Weather API，时间采用东京当地时区。

下表中 `coordinate` 位于 Chart 根，其余配置位于 IR `recipe`；React 与 Vanilla 使用上文对应入口。

| 分组         | 属性名                          | 类型       | 说明                                           |
| ------------ | ------------------------------- | ---------- | ---------------------------------------------- |
| `coordinate` | `type / startAngle / endAngle`  | 极坐标配置 | 将 0–24 小时按顺时针映射到完整圆周，0 点在顶部 |
|              | `innerRadius / interpolation`   | 极坐标配置 | 留出中心空白，沿圆周连接日出与日落             |
| `encodings`  | `category`                      | 字段映射   | 用月份确定同心环                               |
|              | `start / end`                   | 字段与尺度 | 日出与日落共用固定 `[0, 24]` 的角度尺度        |
| `properties` | `startPoint / endPoint / range` | 外观对象   | 区分两个时间端点并绘制时段连接线               |

对比 1 月与 7 月的角度跨度，观察白昼时段如何变化。不同半径上的线条像素长度不能直接用来比较时长，应按角度跨度读图。

## 错误与限制

- category 固定映射 y，start / end 固定共用 x，不通过交换字段改变图形方向。
- 任一端点缺失或无法投影时，连接路径报错；请在传入数据前清理缺值。相等端点保持重合，不人为展开。
- 显式声明两个不同的端点尺度名会失败。成员外观不建立独立字段尺度。

React 中，同一项配置不能同时通过根 `recipe` 与子组件声明，否则报错。

`point-aware` 同时支持分类轴与连续轴，分别保护起点和终点。全部方向显式指定 `domainPadding` 时不启动逐点求解。公共属性和覆盖规则见 [点图公共配置](/viz/chart/points#公共配置)。

### 图形构建

Chart 将一个范围点图元展开为一个 PathMark 和两个 PointMark：路径连接两端，两个点分别读取起点和终点字段，并覆盖在线条上方。三者属于同一 Chart 语义组，图元覆盖会整组替换。

| 分组 | `@retikz/chart`                   | `@retikz/plot`                              | 描述                                                                 |
| ---- | --------------------------------- | ------------------------------------------- | -------------------------------------------------------------------- |
| 映射 | `category`、`start`、`end`        | Path 的 `from`、`to` 与 Point 的 `position` | `start` 和 `end` 分别提供两端的 x 值，`category` 提供共用的 y 行位置 |
| 属性 | `range`                           | Path 的 `properties`                        | 设置连接线的颜色、线宽和描边样式                                     |
|      | `point`、`startPoint`、`endPoint` | 两个 Point 的 `properties`                  | 合并共享与独立端点外观，分别设置形状、大小、颜色和自动留白           |
| 图元 | `IRRangedDotMark`                 | `IRPlotPathMark`、两个 `IRPlotPointMark`    | 按连接线、起点、终点的顺序生成图元                                   |

Plot 对每行有效数据输出一条 Core `Path` 和两个端点 `Node`，分别绘制连接线与两个点。
