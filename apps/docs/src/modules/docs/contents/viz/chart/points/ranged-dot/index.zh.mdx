Ranged Dot 固定横向：`category` 映射 y，`start` 与 `end` 映射同一 x scale。若两个端点都显式声明 scale binding，名称必须一致；可以由一端声明 operation、另一端引用该名称。它适合比柱长更强调两个端点、又需要显示变化方向的比较。

## `RangedDotChart`

根 `recipe` 使用 Ranged Dot 的 exact slots；组件身份自动补齐 Point family 与 `chartType: 'ranged-dot'`：

```tsx
<RangedDotChart
  rows={rows}
  recipe={{
    encodings: { category: 'category', start: 'before', end: 'after', color: 'group' },
    properties: { range: { strokeWidth: 2 } },
  }}
/>
```

`RangedDotEncodings`、`RangedDotProperties` 与 `RangedDotMark` 是相同 recipe slots 的等价 JSX sugar。root-only 写法可以省略 `children`；不同 slot 可以混用，同一 slot 双来源会 fail-loud。

## 原子行语义

一个 Ranged Dot semantic group 只生成一个 projected Relation operation。Plot 在同一次投影中得到两端，按“连接线、起点、终点”绘制；任一端缺失、null 或无法投影时，整行一起跳过，不留下孤立端点。

`start > end` 不交换角色；`start === end` 仍保留零长度连接线和两个重合 glyph。空数据是合法空结果。

## 样式优先级

`point` 设置两个端点的共同常量外观，`startPoint` 与 `endPoint` 再覆盖各自端点。`range` 只影响连接线。可选 `color` 字段同时驱动三者和分类图例；member properties 不建立独立字段尺度。

省略 `color` 和成员颜色属性时，连接线与两个端点共同使用 Plot `palette.series` 的顺序默认色，不会回退为 CSS `currentColor`。

## API 参考

### `RangedDotEncodingsProps`

| 属性             | 类型                                                                      | 默认值 | 描述                         |
| ---------------- | ------------------------------------------------------------------------- | ------ | ---------------------------- |
| `category`       | Point position mapping                                                    | —      | 必需类别字段，固定映射 y     |
| `start` / `end`  | Point position mapping                                                    | —      | 必需端点字段，共用 x scale   |
| `color?`         | Point color mapping                                                       | —      | 三成员共享颜色与图例         |
| `row` / `column` | `string`、`IRPlotPartitionDimension` 或 `Array<IRPlotPartitionDimension>` | —      | 可选分面维度                 |
| `facet?`         | `IRPlotFacetOptions`                                                      | —      | 分面选项；需要 row 或 column |

### `RangedDotPropertiesProps`

| 属性             | 类型                                     | 默认值 | 描述                                                   |
| ---------------- | ---------------------------------------- | ------ | ------------------------------------------------------ |
| `point?`         | `IRRangedDotPointProperties`             | Point  | 两个端点的共同常量外观                                 |
| `startPoint?`    | `IRRangedDotPointProperties`             | 继承   | 起点覆盖                                               |
| `endPoint?`      | `IRRangedDotPointProperties`             | 继承   | 终点覆盖                                               |
| `range?`         | `IRRangedDotRangeProperties`             | Path   | 连接线颜色、线宽、透明度与线型                         |
| `domainPadding?` | `number` \| `{ x?: number; y?: number }` | `0.02` | 配置连续 x scale 的 domain 留白；分类 y scale 不受影响 |

### `RangedDotMarkProps`

| 属性          | 类型                                                  | 默认值  | 描述                                                       |
| ------------- | ----------------------------------------------------- | ------- | ---------------------------------------------------------- |
| `override?`   | `boolean`                                             | `false` | 替换完整 ranged-dot group                                  |
| `encodings?`  | `{ category?: string; start?: string; end?: string }` | 继承    | 覆盖 direct 字段，不能改 color                             |
| `properties?` | `RangedDotMarkProps['properties']`                    | 继承    | 按 member 合并常量外观；不接受 recipe-only `domainPadding` |
