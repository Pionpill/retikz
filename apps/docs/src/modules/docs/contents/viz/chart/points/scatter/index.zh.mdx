title: 散点图
description: 用散点比较两个连续变量，并通过颜色和形状编码区分分类数据。
---

散点图用每个点的位置表达两个连续变量，适合观察相关性、分布与离群点。颜色和形状可以继续区分类别；需要逐组比较时，可将同一份数据拆成分面。图中的相关性本身不说明因果关系。

## 接入方式

完成 [安装与首次渲染](/viz/chart/get-start) 后，可选择以下四种入口。示例使用相同的电影数据和坐标映射；React 与 Vanilla API 自动组装图表定义，直接 IR 则显式提供图表定义和外部数据。

## 基础用法

### 散点映射

React 可通过 `ScatterEncodings` 声明字段映射，Vanilla API 使用 `encodings`，直接 IR 使用 `recipe.encodings`。映射决定数据如何影响散点的位置、颜色、形状、大小和透明度。

下面使用世界银行 2022 年的 186 个经济体数据，每个点代表一个经济体，通过生育率与女性劳动参与率观察不同收入组的分布与重叠情况。

- `x`：映射到 `fertilityRate`，用横坐标表示生育率。
- `y`：映射到 `femaleLaborParticipation`，用纵坐标表示女性劳动参与率。
- `color`：映射到 `incomeGroup`，用不同颜色区分收入组。
- `shape`：同样映射到 `incomeGroup`，用不同形状辅助识别同一分类。

颜色和形状提供两种识别收入组的线索。使用下方控件分别关闭颜色或形状映射，比较类别是否仍容易辨认；这些切换不会改变点的位置。

### 散点属性

React 可通过 `ScatterProperties` 设置统一外观，Vanilla API 使用 `properties`，直接 IR 使用 `recipe.properties`。未显式设置的外观由默认绘图配置决定。

下面继续展示同一批经济体的生育率与女性劳动参与率，坐标和收入组分类保持不变。本节关注如何让这些观测更容易辨认：当多个经济体的指标接近时，散点会相互遮挡；点的外观会影响读者判断密集区域和识别相邻点的难易程度。

- `size`：本例设为 `8`，统一设置点半径。增大后单个点更醒目，但也会增加密集区域的遮挡。
- `opacity`：本例设为 `0.4`，统一设置透明度。降低后可以透过上层散点观察叠加区域。
- `stroke`、`strokeWidth`：使用灰色描边，宽度设为 `1.5`，帮助区分相邻点的轮廓；将宽度调为 `0` 可隐藏描边。

这些值作用于整组散点，不表示经济体的第三项数值指标。使用下方控件调整上述属性，对比密集区域与孤立点，选择两者都清楚的外观。

### 散点图元

React 可通过 `ScatterMark` 追加或覆盖散点图元，Vanilla API 使用 `marks` 数组，直接 IR 使用 `recipe.marks` 数组；数组中的散点图元需要设置 `kind: 'scatter'`。图形默认生成散点，常规绘图无需额外声明图元。

下面用 100 部电影的 IMDb 与烂番茄评分演示图元叠加：横轴为 IMDb 评分，纵轴为烂番茄评分，在每部电影的位置绘制一个浅色大点和一个实心小点。

本例先用 `ScatterProperties` 将默认散点的半径设为 `8`、透明度设为 `0.25`，再通过 `ScatterMark` 配置叠加图元：

- `encodings`：省略，继承原来的数据与位置映射，使两层散点落在相同位置。
- `properties`：设置 `size: 3` 与 `opacity: 1`，在较大的半透明散点中心绘制较小的实心点。
- `override`：默认关闭（`false`），使用追加行为；若设为 `true`，则替换默认散点，只留下小点。

浅色外围保留点的覆盖范围，实心中心标出准确位置。两层表示的是同一批电影，并非两组不同的数据。React 中 `ScatterMark` 须作为 `ScatterChart` 的直接子组件。

## 扩展用法

### 分面比较

将分类拆成独立面板，可以逐组比较分布。下面组合字段映射、分面布局与散点属性；映射项放在 `recipe.encodings`，散点属性放在 `recipe.properties`，也可使用对应的 React 子组件声明。

| 分组         | 属性名                   | 类型                       | 说明                                                          |
| ------------ | ------------------------ | -------------------------- | ------------------------------------------------------------- |
| `encodings`  | `x`、`y`                 | 字段名、映射对象           | 映射生育率与女性劳动参与率，各面板保持相同轴含义              |
|              | `column`                 | 字段名、分组对象、分组数组 | 按收入组拆列；对象中的 `field` 指定字段，`order` 指定类别顺序 |
|              | `facet.header.column`    | `boolean`、文字样式对象    | 本例设为 `true`，显示各列的收入组标题                         |
|              | `facet.spacing.panelGap` | `number`                   | 本例设为 `20`，控制面板间距                                   |
| `properties` | `size`                   | `number`                   | 本例使用半径 `4`，适应较窄的分面                              |
|              | `opacity`                | `number`                   | 本例设为 `0.65`，减轻重叠遮挡                                 |

下面沿用世界银行 2022 年的经济体数据，以 `incomeGroup` 分成 HIC、UMC、LMC、LIC 四列，共享位置尺度。先比较各组散点集中在哪些区间，再观察组内的离散程度；分面改变分组方式，不改变每条记录的数值。需要纵向排列时可改用 `row`，分面选项 `facet` 必须配合 `row` 或 `column` 使用。

### 空间坐标

当字段记录的是场地位置时，可以将散点图扩展为事件分布图。除了位置与分类映射，本例还组合了散点样式、坐标轴开关和绘图区背景。下表的 `encodings`、`properties`、`guides` 位于 IR 的 `recipe` 中，`plotExtension` 位于图形根配置；属性名均相对于所在分组。

| 分组            | 属性名                       | 类型                   | 说明                                            |
| --------------- | ---------------------------- | ---------------------- | ----------------------------------------------- |
| `encodings`     | `x`、`y`                     | 字段名、映射对象       | 绑定射门起点的场地坐标，位于 `recipe.encodings` |
|                 | `color`                      | 字段名、映射对象       | 绑定 `outcome`，用颜色区分射门结果              |
| `properties`    | `size`                       | `number`               | 调节点半径，便于辨认相邻事件                    |
|                 | `shape`                      | 形状名字符串           | 设置射门位置的统一点形状                        |
|                 | `stroke`                     | 颜色字符串、paint 对象 | 按需添加描边，提高点与背景的区分度              |
|                 | `opacity`                    | `number`               | 调整透明度，便于观察重叠位置                    |
| `guides`        | `axis`                       | `boolean`              | 本例设为 `false`，隐藏默认坐标轴                |
| `plotExtension` | `plotDefaults.plotArea.fill` | paint 对象             | 用 `kind: 'image'` 与 `href` 配置球场背景图     |

下面使用 StatsBomb 的 2022 年世界杯射门数据，每个点表示 Messi 的一次射门起点，颜色表示射门结果。把 `x`、`y` 绑定到位置字段，再添加球场背景，可以结合场地参照观察射门集中区域。使用下方控件调整点的大小、形状、描边和透明度，比较事件在背景上的辨识度。这里应按空间位置阅读，不能把两轴解释为统计指标的相关性；更换数据或底图时，还需核对坐标范围、方向与比例是否一致。

## 错误与限制

- `jitter` 的作用轴须与所属位置通道一致：`x` 映射只作用于 x 轴，`y` 映射只作用于 y 轴。
- 不支持 `series`、`detail`、`order`、`text` 通道或无对应消费规则的普通映射数组。

- `x` 和 `y` 必填；字段和比例尺需要匹配。
- `facet` 不能脱离 `row` 或 `column`；当前不能组合分面与 x/y 的 `bin` 映射。
- 根 `recipe.encodings` 与 `ScatterEncodings` 等同一配置项的写法不能同时提供，发生冲突会报错。
- Scatter 不连接数据点。需要表达连接顺序时，使用 [连接散点图](/viz/chart/points/connected-scatter)。
- 重叠点可能遮挡观测。透明度只能改善可见性，不能保证逐点辨认。

## API 参考

本页介绍当前图形的专属入口与约束；公共配置的 React 组件写法见 [快速开始示例](/viz/chart/get-start#最小结果)。

React 使用 `ScatterChart`，可通过 `recipe` 属性提供配置，也可使用下方的专属子组件。Vanilla API 使用 `scatterChart`，直接提供 `encodings`、`properties`、`marks`；直接 IR 将这些配置放在 `recipe` 中，并设置 `recipe.chartType: 'scatter'`。React 与 Vanilla API 会补齐该图形类型。

React 可以混用不同配置项的根属性与子组件写法，但同一项配置不能重复声明。例如，`recipe.encodings` 与 `ScatterEncodings` 不能同时提供，否则报错。仅通过根属性配置时，无需添加子组件。

### 散点映射

React 使用 `ScatterEncodings`，Vanilla API 使用 `encodings`，直接 IR 使用 `recipe.encodings`。

| 通道             | 输入形式             | 说明                                        |
| ---------------- | -------------------- | ------------------------------------------- |
| `x` / `y`        | 字段名、位置映射     | 必填；决定散点位置                          |
| `color`          | 字段名、颜色映射     | 按分类、连续数值着色                        |
| `size`           | 字段名、尺寸映射     | 输出连续数值；命名尺寸尺度仅支持 `sqrt`     |
| `opacity`        | 字段名、透明度映射   | 输出连续数值；命名透明度尺度仅支持 `linear` |
| `shape`          | 字段名、直接映射     | 按分类区分形状，不接受命名尺度              |
| `row` / `column` | 字段名、分面维度     | 按行列分面，支持有序层级                    |
| `facet`          | `IRPlotFacetOptions` | 配置分面；须配合 `row`、`column` 中至少一项 |

映射对象可按通道支持情况引用尺度、聚合或转换数据，本节不展开公共转换的参数。精确输入结构见下方 [Schema 参考](#scatterchartencodingsschema)，组合限制见[错误与限制](#错误与限制)。

### 散点属性

React 使用 `ScatterProperties`，Vanilla API 使用 `properties`，直接 IR 使用 `recipe.properties`。属性设置常量外观；随数据变化的取值应放在映射中。

| 分类       | 属性            | 类型                                                     | 说明                                                             |
| ---------- | --------------- | -------------------------------------------------------- | ---------------------------------------------------------------- |
| 形状与尺寸 | `size`          | `number`                                                 | 统一点半径，必须大于或等于 0                                     |
|            | `shape`         | `string`                                                 | 已注册的形状名                                                   |
| 颜色与填充 | `color`         | `string`                                                 | 设置主色                                                         |
|            | `fill`          | `string`、`JsonObject`                                   | 设置填充颜色、画笔                                               |
| 描边       | `stroke`        | `string`、`JsonObject`                                   | 设置描边颜色、画笔                                               |
|            | `strokeWidth`   | `number`                                                 | 描边宽度，必须大于或等于 0                                       |
|            | `dashed`        | `boolean`                                                | 启用虚线描边                                                     |
|            | `dotted`        | `boolean`                                                | 启用点线描边                                                     |
|            | `dashPattern`   | `Array<number>`                                          | 自定义虚线序列；至少一项，各项非负                               |
| 透明度     | `opacity`       | `number`                                                 | 整体透明度，范围 0–1                                             |
|            | `fillOpacity`   | `number`                                                 | 填充透明度，范围 0–1                                             |
|            | `strokeOpacity` | `number`                                                 | 描边透明度，范围 0–1                                             |
| 留白       | `autoPadding`   | `'max-radius'`、`'point-aware'`、`object`                | 自动留白策略；对象写法通过 kind 选择策略、clearance 设置外缘净空 |
|            | `domainPadding` | `number`、`IRBoxSpacing & { kind?: 'range' \| 'ratio' }` | 显式位置域留白，优先于自动策略                                   |

其余字体、标签、变换与阴影等公共外观不在这里逐项解释，完整字段见 [属性 Schema](#scatterchartpropertiesschema)。留白策略的触发条件和边界见[点图公共留白原理](/viz/chart/points#自动补齐边缘留白)。

### 散点图元

React 使用 `ScatterMark`，Vanilla API 使用 `marks`，直接 IR 使用 `recipe.marks`。React 中须作为 `ScatterChart` 的直接子组件；Vanilla / IR 图元需声明 `kind: 'scatter'`。

| 属性         | 类型                             | 说明                                                                   |
| ------------ | -------------------------------- | ---------------------------------------------------------------------- |
| `override`   | `boolean`                        | 省略时追加；为 `true` 时原位替换默认散点图元                           |
| `encodings`  | `ScatterChartMark['encodings']`  | 支持 `x`、`y`、`color`、`size`、`opacity`、`shape`，不接受完整映射对象 |
| `properties` | `ScatterChartMark['properties']` | 沿用上方属性含义，但不接受 `autoPadding`、`domainPadding`              |

未指定的映射与属性沿用当前图形可继承的配置。替换未命中时仍追加，并通过 `onWarn` 报告 `CHART_MARK_OVERRIDE_TARGET_NOT_FOUND`。完整结构见 [图元 Schema](#scatterchartmarkschema)。
