---
title: 散点图
description: 用散点比较两个连续变量，并通过颜色和形状编码区分分类数据。
---

散点图用每个点的位置表达两个连续变量，适合观察相关性、分布与离群点。颜色和形状可以继续区分类别；需要逐组比较时，可将同一份数据拆成分面。图中的相关性本身不说明因果关系。

## 接入方式

完成 [安装与首次渲染](/viz/chart/get-start) 后，可选择以下四种入口。示例使用相同的电影数据和坐标映射；React 与 Vanilla API 自动组装图表定义，直接 IR 则显式提供图表定义和外部数据。

下面继续展示同一批经济体的生育率与女性劳动参与率，坐标和收入组分类保持不变。本节关注如何让这些观测更容易辨认：当多个经济体的指标接近时，散点会相互遮挡；点的外观会影响读者判断密集区域和识别相邻点的难易程度。

- `size`：本例设为 `8`，统一设置点半径。增大后单个点更醒目，但也会增加密集区域的遮挡。
- `opacity`：本例设为 `0.4`，统一设置透明度。降低后可以透过上层散点观察叠加区域。
- `stroke`、`strokeWidth`：使用灰色描边，宽度设为 `1.5`，帮助区分相邻点的轮廓；将宽度调为 `0` 可隐藏描边。

这些值作用于整组散点，不表示经济体的第三项数值指标。使用下方控件调整上述属性，对比密集区域与孤立点，选择两者都清楚的外观。

## 扩展用法

### 分面比较

将分类拆成独立面板，可以逐组比较分布。下面组合字段映射、分面布局与散点属性；映射项放在 `recipe.encodings`，散点属性放在 `recipe.properties`，也可使用对应的 React 子组件声明。

| 分组         | 属性名                   | 类型                       | 说明                                                          |
| ------------ | ------------------------ | -------------------------- | ------------------------------------------------------------- |
| `encodings`  | `x`、`y`                 | 字段名、映射对象           | 映射生育率与女性劳动参与率，各面板保持相同轴含义              |
|              | `column`                 | 字段名、分组对象、分组数组 | 按收入组拆列；对象中的 `field` 指定字段，`order` 指定类别顺序 |
|              | `facet.header.column`    | `boolean`、文字样式对象    | 本例设为 `true`，显示各列的收入组标题                         |
|              | `facet.spacing.panelGap` | `number`                   | 本例设为 `20`，控制面板间距                                   |
| `properties` | `size`                   | `number`                   | 本例使用半径 `4`，适应较窄的分面                              |
|              | `opacity`                | `number`                   | 本例设为 `0.65`，减轻重叠遮挡                                 |

### 空间坐标

当字段记录的是场地位置时，可以将散点图扩展为事件分布图。除了位置与分类映射，本例还组合了散点样式、坐标轴开关和绘图区背景。下表的 `encodings`、`properties`、`guides` 位于 IR 的 `recipe` 中，`plotExtension` 位于图形根配置；属性名均相对于所在分组。

| 分组            | 属性名                      | 类型                   | 说明                                            |
| --------------- | --------------------------- | ---------------------- | ----------------------------------------------- |
| `encodings`     | `x`、`y`                    | 字段名、映射对象       | 绑定射门起点的场地坐标，位于 `recipe.encodings` |
|                 | `color`                     | 字段名、映射对象       | 绑定 `outcome`，用颜色区分射门结果              |
| `properties`    | `size`                      | `number`               | 调节点半径，便于辨认相邻事件                    |
|                 | `shape`                     | 形状名字符串           | 设置射门位置的统一点形状                        |
|                 | `stroke`                    | 颜色字符串、paint 对象 | 按需添加描边，提高点与背景的区分度              |
|                 | `opacity`                   | `number`               | 调整透明度，便于观察重叠位置                    |
| `guides`        | `axis`                      | `boolean`              | 本例设为 `false`，隐藏默认坐标轴                |
| `plotExtension` | `defaultPlot.plotArea.fill` | paint 对象             | 用 `kind: 'image'` 与 `href` 配置球场背景图     |

下面使用 StatsBomb 的 2022 年世界杯射门数据，每个点表示 Messi 的一次射门起点，颜色表示射门结果。把 `x`、`y` 绑定到位置字段，再添加球场背景，可以结合场地参照观察射门集中区域。使用下方控件调整点的大小、形状、描边和透明度，比较事件在背景上的辨识度。这里应按空间位置阅读，不能把两轴解释为统计指标的相关性；更换数据或底图时，还需核对坐标范围、方向与比例是否一致。

## 错误与限制

- `jitter` 的作用轴须与所属位置通道一致：`x` 映射只作用于 x 轴，`y` 映射只作用于 y 轴。
- 不支持 `series`、`detail`、`order`、`text` 通道或无对应消费规则的普通映射数组。

- `x` 和 `y` 必填；字段和比例尺需要匹配。
- `facet` 不能脱离 `row` 或 `column`；当前不能组合分面与 x/y 的 `bin` 映射。
- 根 `recipe.encodings` 与 `ScatterEncodings` 等同一配置项的写法不能同时提供，发生冲突会报错。
- Scatter 不连接数据点。需要表达连接顺序时，使用 [连接散点图](/viz/chart/points/connected-scatter)。
- 重叠点可能遮挡观测。透明度只能改善可见性，不能保证逐点辨认。

### 图形构建

Chart 将散点图元解析为 Plot Point。下表概括散点位置与外观如何进入该图元。

| 分组 | `@retikz/chart`            | `@retikz/plot`             | 描述                                   |
| ---- | -------------------------- | -------------------------- | -------------------------------------- |
| 映射 | `x`、`y`                   | `encoding.x`、`encoding.y` | 将两个字段分别用于点的水平和垂直位置   |
|      | `size`、`shape`、`opacity` | `size`、`shape`、`opacity` | 将字段映射用于点的大小、形状和透明度   |
| 属性 | `size`、`shape`、`opacity` | `size`、`shape`、`opacity` | 将常量外观应用到点；对应映射优先于常量 |
| 图元 | `ScatterChartMarkSchema`   | `PointMarkSchema`          | 每个散点图元解析为一个 Plot Point      |
