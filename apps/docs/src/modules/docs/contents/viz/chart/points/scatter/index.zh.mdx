## Point Mark

### 位置与坐标作用域

主示例通过 `PointMark.x` / `PointMark.y` 绑定两个连续变量，并由 Plot 的坐标与 scale 管线解析二维位置。

| 属性                  | 类型                                     | 默认值 | 描述                               |
| --------------------- | ---------------------------------------- | ------ | ---------------------------------- |
| `x` / `y`             | `PointMarkProps['x' \| 'y']`             | —      | 二维位置字段；Scatter 必须同时提供 |
| `z`                   | `PointMarkProps['z']`                    | —      | 自定义坐标系的第三位置 role        |
| `xAxisId` / `yAxisId` | `PointMarkProps['xAxisId' \| 'yAxisId']` | —      | 绑定命名轴的 authoring 快捷方式    |
| `coordinateView`      | `PointMarkProps['coordinateView']`       | —      | 直接绑定组合坐标视图               |
| `facetId` / `trackId` | `PointMarkProps['facetId' \| 'trackId']` | —      | 绑定分面或共享轨道                 |

### 视觉编码与 glyph

字符串既可表示字段，也可通过显式 `{ kind: 'constant', value }` 固定常量。字段绑定会继续使用 Plot 的 scale、legend、channel definition 与诊断。

| 属性                                        | 类型                                                            | 默认值   | 描述                                                 |
| ------------------------------------------- | --------------------------------------------------------------- | -------- | ---------------------------------------------------- |
| `color` / `textColor`                       | `PointMarkProps['color' \| 'textColor']`                        | palette  | glyph 或文本颜色                                     |
| `size`                                      | `PointMarkProps['size']`                                        | 内置半径 | 数值字段经 sqrt scale 映射为半径，也可直接给最终半径 |
| `shape`                                     | `PointMarkProps['shape']`                                       | circle   | 分类形状或显式 shape                                 |
| `fill` / `stroke`                           | `PointMarkProps['fill' \| 'stroke']`                            | 主题值   | 填充与描边 paint                                     |
| `strokeWidth`                               | `PointMarkProps['strokeWidth']`                                 | 主题值   | 描边宽度                                             |
| `fillOpacity` / `strokeOpacity` / `opacity` | `PointMarkProps['fillOpacity' \| 'strokeOpacity' \| 'opacity']` | `1`      | 分层或整体透明度                                     |
| `rotate`                                    | `PointMarkProps['rotate']`                                      | `0`      | glyph 旋转角度                                       |
| `minimumSize`                               | `PointMarkProps['minimumSize']`                                 | —        | size 通道之前的最小视觉尺寸                          |
| `zIndex`                                    | `PointMarkProps['zIndex']`                                      | —        | datum 绘制顺序提示                                   |

### Node 样式

| 属性                                    | 类型                                                        | 默认值  | 描述                     |
| --------------------------------------- | ----------------------------------------------------------- | ------- | ------------------------ |
| `align` / `lineHeight` / `maxTextWidth` | `PointMarkProps['align' \| 'lineHeight' \| 'maxTextWidth']` | 主题值  | 文本对齐、行高与换行宽度 |
| `cornerRadius` / `scale`                | `PointMarkProps['cornerRadius' \| 'scale']`                 | 主题值  | 圆角与节点缩放           |
| `padding` / `margin`                    | `PointMarkProps['padding' \| 'margin']`                     | 主题值  | 内外边距                 |
| `dashed` / `dotted` / `dashPattern`     | `PointMarkProps['dashed' \| 'dotted' \| 'dashPattern']`     | `false` | 描边虚线与自定义间隔     |
| `font`                                  | `PointMarkProps['font']`                                    | 主题值  | datum 驱动或固定字体     |
| `boundary`                              | `PointMarkProps['boundary']`                                | shape   | 节点边界策略             |
| `shadow` / `blendMode`                  | `PointMarkProps['shadow' \| 'blendMode']`                   | —       | 阴影与混合模式           |

### 文本、datum 标签与 identity

| 属性                                            | 类型                                                                 | 默认值                 | 描述                                        |
| ----------------------------------------------- | -------------------------------------------------------------------- | ---------------------- | ------------------------------------------- |
| `text` / `displayFormat`                        | `PointMarkProps['text' \| 'displayFormat']`                          | —                      | 把 Point 转为无边框文本节点，并格式化字段值 |
| `dx` / `dy`                                     | `PointMarkProps['dx' \| 'dy']`                                       | `0`                    | 文本相对投影锚点的微调                      |
| `label` / `labelDisplayFormat`                  | `DatumLabelProps['label' \| 'labelDisplayFormat']`                   | —                      | 挂载独立 datum 标签及其格式                 |
| `labelPosition` / `labelDistance` / `labelPin`  | `DatumLabelProps['labelPosition' \| 'labelDistance' \| 'labelPin']`  | `top` / `12` / `false` | 标签位置、距离与引线                        |
| `labelTextColor` / `labelOpacity` / `labelFont` | `DatumLabelProps['labelTextColor' \| 'labelOpacity' \| 'labelFont']` | 主题值                 | 标签视觉样式                                |
| `labelRotate` / `labelKeepUpright`              | `DatumLabelProps['labelRotate' \| 'labelKeepUpright']`               | `'none'` / `false`     | 标签旋转与正向保持                          |
| `resolveLabel`                                  | `DatumLabelProps['resolveLabel']`                                    | —                      | runtime-only 自定义标签；需显式 `id`        |
| `channels`                                      | `DatumLabelProps['channels']`                                        | `{}`                   | 注册扩展 channel 的字段或常量绑定           |
| `transform`                                     | `PointMarkProps['transform']`                                        | `[]`                   | 只作用于当前 Point 的数据变换               |
| `layer`                                         | `PointMarkProps['layer']`                                            | —                      | Point scope 的语义图层                      |
| `id` / `anchorId`                               | `PointMarkProps['id' \| 'anchorId']`                                 | 自动                   | mark 句柄与逐 datum 稳定节点 id             |
