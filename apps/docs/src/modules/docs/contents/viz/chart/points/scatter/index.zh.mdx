  Scatter 使用精确的 `ScatterChartSchema`，同时遵循 Chart 一致的字段布局。它通过 `config` 接收 x/y 等专属编码，并隐含生成主 `Point` 图元、二维比例尺和坐标；`plot` 继续接收 Plot 拥有的数据、变换、图例和其它显式扩展。

本页示例统一使用 `@retikz/chart-react/point` 的 `ScatterChart`。`/point` 只负责多入口导入与文件组织，组件仍进入统一 Chart 解析和适配主链。Chart 在图内处理标题、副标题、来源和注记；坐标轴、网格和颜色或形状图例仍是 Plot 的辅助元素扩展，因此由 `Axis` 与 `Legend` 负责。
