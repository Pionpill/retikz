本页只展开 Scatter 私有的 recipe slots 与 declarations。`ChartData`、`ChartLayout`、`ChartCoordinate`、`ChartExtension`、presentation 与公共根接线不在此重复，详见 [Chart 公共 API](/viz/chart)。

## `ScatterChart`

`ScatterChart` 固定 Point family 与 Scatter recipe 身份。根 `recipe` 直接使用 Scatter 的 exact `encodings`、`properties` 与 `marks` 结构；组件身份会补齐 `chartType: 'scatter'`：

```tsx
<ScatterChart
  rows={rows}
  data={{ reference: 'chart.data' }}
  recipe={{
    encodings: { x: 'fertility', y: 'work', color: 'incomeGroup' },
    properties: { size: 8 },
  }}
/>
```

下面三个 declarations 分别是这些 recipe slots 的等价 JSX sugar。只用根配置时可以省略 `children`；跨 slot 可以混用，根与 declaration 同时提供同一 slot 时会 fail-loud。

## `ScatterEncodings`

`ScatterEncodingsProps` 精确复用 schema 派生的 `IRScatterChartEncodings`。Vanilla input 与 JSON Source 继续使用相同 encoding payload，只是 React 把它写成独立 declaration。

| Slot             | 支持的 Scatter mapping                                                                 | Scatter 专属约束                                                                   |
| ---------------- | -------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| `x`              | `string`、direct、aggregate、derived（`bin`、`normalize`、`jitter`、custom transform） | 必填；`jitter` 只能作用于 x 轴；`bin` 不能与 facet 组合                            |
| `y`              | `string`、direct、aggregate、derived（`bin`、`normalize`、`jitter`、custom transform） | 必填；`jitter` 只能作用于 y 轴；`bin` 不能与 facet 组合                            |
| `color`          | `string`、direct、aggregate                                                            | 可选；绑定 Scatter 的 color consumer，可使用兼容的分类或连续颜色 scale             |
| `size`           | `string`、direct、aggregate、derived（`normalize`、custom transform）                  | 可选；输出必须是 continuous，命名 scale 当前只接受 `sqrt`                          |
| `opacity`        | `string`、direct、aggregate、derived（`normalize`、custom transform）                  | 可选；输出必须是 continuous，命名 scale 当前只接受 `linear`                        |
| `shape`          | `string`、direct                                                                       | 可选；绑定分类形状，不接受命名 scale                                               |
| `row` / `column` | `string`、`IRPlotPartitionDimension`、`Array<IRPlotPartitionDimension>`                | 可选；声明任一维度即可生成 facet，数组表示有序的分面层级                           |
| `facet`          | `IRPlotFacetOptions`                                                                   | 可选；配置 `empty`、`header`、`resolve`、`spacing`；必须同时存在 `row` 或 `column` |

Scatter 不接受 `series`、`detail`、`order`、`text` 或没有明确 consumer 的普通 slot 数组。字段类型与 scale compatibility 由既有 Data / Plot 契约处理，本页不展开。

### Facet

`row` / `column` / `facet` 是 Scatter 的分面映射。`facet` 不能脱离 `row` 或 `column`；带 facet 的 x/y `bin` 也会被拒绝。

```tsx
<ScatterEncodings
  x="billLengthMm"
  y="flipperLengthMm"
  column={{ field: 'species', order: ['Adelie', 'Chinstrap', 'Gentoo'] }}
  facet={{ header: { column: true }, spacing: { panelGap: 20 } }}
/>
```

`row` / `column` 只决定面板分区，不决定 mark 类型；Scatter 仍使用自己的点 mark。Facet 的面板排列、尺度解析和定位交给 Plot，Source 不重复保存可推导的 panel id 或坐标。

## `ScatterProperties`

`ScatterProperties` 声明 recipe 级常量，不接受字段 mapping；字段驱动的视觉变化应写在 `ScatterEncodings`。`ScatterPropertiesProps` 的字段分组如下。

| 字段                                                                                        | 值域                                                                                                              |
| ------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `color`、`textColor`、`fill`、`stroke`、`shape`                                             | 颜色、paint 或可扩展 shape 名称                                                                                   |
| `size`、`minimumSize`、`scale`、`rotate`、`dx`、`dy`、`padding`、`margin`、`cornerRadius`   | 有限数值或对应 JSON-safe 结构                                                                                     |
| `strokeWidth`、`fillOpacity`、`strokeOpacity`、`opacity`、`dashed`、`dotted`、`dashPattern` | 描边、透明度与虚线常量                                                                                            |
| `zIndex`、`align`、`lineHeight`、`maxTextWidth`、`font`、`label`                            | 绘制顺序、文本与标签配置                                                                                          |
| `boundary`、`shadow`、`blendMode`                                                           | 边界、阴影与混合模式                                                                                              |
| `domainPadding?`                                                                            | `number` 或 `{ kind?, default?, x?, y?, left?, right?, top?, bottom? }`；默认按最终最大 Point 半径使用 range 留白 |

## `ScatterMark`

`ScatterMark` 是 Scatter 独有的直接子级 mark API。`ScatterMarkProps` 是 `@retikz/chart-react/point` 导出的 props 类型；组件身份固定为 Scatter，不需要传入 `kind`。公共 Point mark 的嵌套字段不在本页重复。

| `ScatterMarkProps` 属性 | 类型                             | 默认值  | Scatter 专属行为                                                                                                                     |
| ----------------------- | -------------------------------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| `override?`             | `boolean`                        | `false` | 为 `true` 时原位替换 recipe 隐式生成的主 `scatter` mark；未命中时仍追加，并通过 `onWarn` 报告 `CHART_MARK_OVERRIDE_TARGET_NOT_FOUND` |
| `encodings?`            | `ScatterMarkProps['encodings']`  | —       | 覆盖当前 Scatter recipe 继承的点字段映射；可用字段由公共 Point mark encoding 契约决定                                                |
| `properties?`           | `ScatterMarkProps['properties']` | —       | 覆盖当前 Scatter recipe 继承的点样式；字段列表由公共 Point properties 契约决定                                                       |
