These four transforms retain detail rows. See [Transforms](/viz/plot/transform) for authoring and scopes; Data owns the full parameter contracts. Parameters belong to `operation.params`, and marks read the resulting fields.

## Interval derivation

`derive-interval` produces a lower and upper bound for each row. `IntervalMark` binds them to `bounds.y` to draw task intervals or bars starting at a baseline.

| Parameter   | Use and constraints in this demo                                                                     |
| ----------- | ---------------------------------------------------------------------------------------------------- |
| `startFrom` | Start field in the two-field mode; pairs with `endFrom`.                                             |
| `endFrom`   | End field in the two-field mode; pairs with `startFrom`.                                             |
| `from`      | Endpoint value field in the baseline mode; this demo switches between the two forms.                 |
| `baseline`  | Fixed start in the baseline mode; explicit start/end fields take precedence over this configuration. |

## Data jitter

`jitter` perturbs a continuous field in data units to separate overlapping points. This demo modifies only the horizontal `dose` field and retains each response value.

| Parameter | Use and constraints in this demo                          |
| --------- | --------------------------------------------------------- |
| `axis`    | Fixed to `'x'` to jitter only the horizontal field.       |
| `xField`  | Read and overwrite the `'dose'` field in this demo.       |
| `amount`  | Perturbation magnitude in data units; 0 disables jitter.  |
| `seed`    | The same input, amount, and seed produce the same result. |

## Stacking

`stack` accumulates series values within each horizontal group and generates lower and upper bounds. Marks read `y0` / `y1` to draw stacked product revenue for each quarter.

| Parameter | Use and constraints in this demo                                                                                                              |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| `x`       | Use `quarter` to accumulate within each quarter.                                                                                              |
| `y`       | Read `revenue` as the value to accumulate.                                                                                                    |
| `groupBy` | Use `product` to identify each series.                                                                                                        |
| `offset`  | `zero` accumulates values; `normalize` makes a proportional stack; `center` centers the stack on zero; `overlap` starts each segment at zero. |

## Normalization

`normalize` divides values by their group total and writes a share field. This demo creates `share`, then stacks the shares to compare revenue composition by quarter or across all records.

| Parameter | Use and constraints in this demo                                                    |
| --------- | ----------------------------------------------------------------------------------- |
| `field`   | Read `amount` as the input value.                                                   |
| `as`      | Write shares to `share`, retaining the original value.                              |
| `groupBy` | Compute a separate total for each quarter; omit it to use the total of all records. |
| `basis`   | `fraction` produces 0–1 shares; `percent` produces 0–100 percentages.               |
