Plot draws data records as points, lines, or intervals. You choose which fields control position, color, and size, then add guides such as axes and legends. These docs follow the parts of the grammar. New users can start with [Introduction](/viz/plot/introduction) and [Quick start](/viz/plot/get-start).

## Responsibilities at a glance

| Section       | Responsibility                                                                 | When to read                                              |
| ------------- | ------------------------------------------------------------------------------ | --------------------------------------------------------- |
| Channels      | Bind fields or constants to position, color, size, and other visual properties | Choose how data appears in the graphic                    |
| Transforms    | Process data into the results needed for plotting                              | Derive, aggregate, or calculate statistics before drawing |
| Marks         | Draw records as points, paths, intervals, and other shapes                     | Choose or layer drawing forms                             |
| Scales        | Convert data ranges into positions or styles                                   | Adjust numeric ranges, category order, and color mappings |
| Coordinates   | Place positions on a plane, in polar coordinates, or in composed views         | Change the spatial representation                         |
| Guides        | Explain mappings through axes and legends                                      | Help readers interpret values and categories              |
| Plot Lineage  | Connect drawing results to data and processing steps                           | Explain why a particular mark appears                     |
| API Reference | Collect field contracts and runtime entry points                               | Look up exact parameters and calls                        |

## Installation and usage

Use `@retikz/plot-react` in React projects or `@retikz/plot-vanilla` in plain TypeScript projects. Both can produce a graphic on their own. [Quick start](/viz/plot/get-start) includes the dependencies, imports, and mounting code. To save or validate JSON configurations, see the [Plot spec contract](/viz/plot/reference/plot) provided by `@retikz/plot`.

## Where to start

Choose a mark, then bind fields to its channels. When the default mapping does not fit your task, adjust scales, coordinates, and guides. Read about transforms when the data needs processing.

If you already know which chart type you need and prefer whole-chart configuration, see [Chart](/viz/chart/introduction). [Data](/viz/data/introduction) provides reusable cleaning and statistics; [Table](/viz/table) presents data in cells.
