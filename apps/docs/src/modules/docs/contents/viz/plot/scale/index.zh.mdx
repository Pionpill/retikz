---

比例尺把数据域映射到输出范围。数学算法由 [Data 比例尺](/viz/data/scale)提供；Plot 根据通道选择默认配置，并将结果用于位置、颜色、尺寸、透明度或形状。

## 位置与图元属性

| 消费入口                                        | 负责什么                           | 配置方式                                                       |
| ----------------------------------------------- | ---------------------------------- | -------------------------------------------------------------- |
| [位置比例尺](/viz/plot/scale/position)          | 坐标投影、坐标轴、网格和布局范围   | coordinate role 引用命名比例尺；React 可用 PlotScale dimension |
| [图元属性映射](/viz/plot/scale/mark-attributes) | 颜色、尺寸、透明度、描边宽度和形状 | encodings 中使用字段字符串或 `{ field, scale }`                |

位置单独说明，因为它还参与坐标轴和布局。颜色属于图元属性映射的一种应用，不是独立的数学比例尺家族。同一分档算法可以输出颜色，也可以输出尺寸；不同通道分别检查结果是否适用。

固定视觉属性直接使用目标值，不参与比例尺训练。字段字符串采用通道默认处理；显式 scale 引用优先，名称不存在时报错。透明度的三个因子分别绑定在 `encodings.opacity.overall / fill / stroke`。

## 默认选择

| 字段类型    | 位置        | 颜色       |
| ----------- | ----------- | ---------- |
| continuous  | linear      | sequential |
| temporal    | time（UTC） | sequential |
| categorical | band        | ordinal    |

尺寸默认使用 sqrt，将非负数映射为半径；透明度和描边宽度使用各自范围的 linear。形状默认按分类分配主题形状序列。旋转等原本直接取数值的属性不会因为存在比例尺机制而自动归一化。

通道支持的映射由输入语义与输出约束共同决定。数值结果不能直接证明它能作为位置：位置连续性、零基线许可和布局能力仍需消费方明确声明。图元、轴和图例使用实际解析结果，隐藏图例不改变映射。

## 扩展与阅读顺序

新算法使用 Data 的 `defineScale`，通过 `definitions.scales` 注入 Plot；不需要再定义一套 Plot 数学比例尺。已有通道可直接消费适用的新算法。新增属性交付或位置消费语义时，在[自定义通道](/viz/plot/channel/custom-channel)中声明策略。
