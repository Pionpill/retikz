---
title: 堆叠与占比
description: 堆叠与占比保留每一条明细行，同时补出 plot 绘图需要的堆叠区间或占比字段。
---

这一组是 plot 注册的保行绘图变换：图元仍然画明细行，但每行会多出一组为图形服务的派生字段。它们不会把多行压成一行，也不会丢掉原始行。

组统计广播属于数据能力，见[数据变换 / annotate](/viz/data/transform/operations#统计标注-annotate)。

| kind        | 行数  | 常见输出             |
| ----------- | ----- | -------------------- |
| `stack`     | N → N | `y0` / `y1`          |
| `normalize` | N → N | 占比字段或覆盖原字段 |

## 堆叠 stack

`stack` 在每个 `x` 分组内按系列累加数值，给每行补出下界和上界。默认输出是 `y0` / `y1`，正好对接 `IntervalMark` 的区间消费方式。

<ComponentPreview files={['transform-stack', 'transform-stack.data.ts']} />

`<IntervalMark stack>` / `<IntervalMark angle>` 的自动堆叠只是快捷写法；当管线里已经存在匹配的显式 `stack` 时，自动堆叠会被抑制，避免二次堆叠。

`IRPlotStackTransform` 的 `kind` 固定为 `'stack'`。

| prop                        | 类型                             | 默认值      | 说明                             |
| --------------------------- | -------------------------------- | ----------- | -------------------------------- |
| `x?`                        | `string`                         | 单组累积    | 分组键；同一值内累积             |
| `y`                         | `string`                         | —           | 被累加的数值字段                 |
| `groupBy?`                  | `string`                         | 数据行顺序  | 系列字段，按系列出现序决定段顺序 |
| `startField?` / `endField?` | `string`                         | `y0` / `y1` | 输出上下界字段                   |
| `offset?`                   | <ApiValues name="StackOffset" /> | `'zero'`    | 堆叠基线与归一化策略             |

## 归一化 normalize

`normalize` 把每行的数值除以所在组的总和，得到组内占比。`basis` 可以是 `fraction`（0 到 1）或 `percent`（0 到 100）；`as` 省略时原位覆盖输入字段。

<ComponentPreview files={['transform-normalize', 'transform-normalize.data.ts']} />

normalize 和 stack 组合就是百分比堆叠：先把每组转成占比，再对占比做堆叠。

`IRPlotNormalizeTransform` 的 `kind` 固定为 `'normalize'`。

| prop       | 类型                                | 默认值       | 说明                 |
| ---------- | ----------------------------------- | ------------ | -------------------- |
| `field`    | `string`                            | —            | 求组内占比的数值字段 |
| `groupBy?` | `Array<string>`                     | 全行单组     | 分组键，支持复合键   |
| `basis?`   | <ApiValues name="NormalizeBasis" /> | `'fraction'` | 输出比例尺度         |
| `as?`      | `string`                            | 原位覆盖     | 输出字段名           |
