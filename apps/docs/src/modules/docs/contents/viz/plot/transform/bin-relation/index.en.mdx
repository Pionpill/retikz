Binning and pairing generate result rows, so marks must bind fields from those results. See [Transforms](/viz/plot/transform) for authoring and scopes. The sections below cover plotting parameters; the final Data links provide the full contracts.

## Binning

`bin` assigns continuous observations to intervals and produces one row per bin. `IntervalMark.x0` / `x1` read the boundaries, while `y` reads the count, producing a histogram with actual interval widths.

| Parameter    | Use and constraints in this demo                                       |
| ------------ | ---------------------------------------------------------------------- |
| `field`      | Bin `measurement` in this demo.                                        |
| `count`      | Use a target bin count; mutually exclusive with the other strategies.  |
| `step`       | Set a bin width; mutually exclusive with the other strategies.         |
| `thresholds` | Set internal boundaries; mutually exclusive with the other strategies. |
| `extent`     | Fixed to `[0, 20]` in this demo to keep the binning range stable.      |

## Relation generation

`relate` selects a source and target in each group and produces rows for `PathMark`. This demo retains the lines and observations, applying the transform only to the connecting path.

| Parameter         | Use and constraints in this demo                                             |
| ----------------- | ---------------------------------------------------------------------------- |
| `groupBy`         | Pair records separately by series; omit it to pair across all records.       |
| `source.selector` | Choose a source using the minimum, maximum, first, or last row in this demo. |
| `target.selector` | Choose the target independently using the same options.                      |
| `source.fields`   | Project source IDs to `sourceId` for anchor references.                      |
| `target.fields`   | Project target IDs to `targetId` for anchor references.                      |
| `measures`        | Compute the difference between endpoint values and create the link label.    |
