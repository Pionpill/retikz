---
title: 2D Coordinates
description: '2D coordinates use two positional dimensions for cartesian or polar charts, including sectors, radar, and polar lines.'
---

2D coordinates decide how two position channels land on a plane. Data fields first bind to `x` / `y` and pass through position scales; the coordinate then projects the result into horizontal / vertical positions or angle / radius. It does not accumulate data, choose mark shapes, or style axes.

## Start with a Coordinate Switch

The playground below keeps the data, size, and `<IntervalMark>` fixed. Switch the coordinate first to see the same `x` / `y` bindings turn ordinary bars into radial bars, then use the plot-area controls to adjust each outer margin.

| Channel | `cartesian2D`       | `polar2D`                      |
| ------- | ------------------- | ------------------------------ |
| `x`     | Horizontal position | Angular position around center |
| `y`     | Vertical position   | Radial distance from center    |

Use the default `cartesian2D` when positions and values should share straight axes. Use `polar2D` when direction, cycles, or closed dimensions need angular and radial roles. Both coordinates keep the same marks and field bindings.

`margin` is the top, right, bottom, and left distance from the chart edge to the plot area. In polar coordinates, `innerRadius` is a fraction of the outer radius in `0 <= value < 1`; `0` keeps a solid center, while larger values create a ring.

## Sector Charts

Pies and donuts are not ordinary `x` / `y` charts. `<IntervalMark angle="value" />` is the React DSL sector shortcut, and it works in four steps:

1. `angle="value"` selects the field that determines each sector's share.
2. An automatic stack transform turns every `value` into cumulative lower and upper bounds.
3. The interval uses those bounds to form adjacent sectors.
4. `polar2D` projects the sectors into angles and radii.

Increase `innerRadius` to turn a pie into a donut.

The public configuration uses `startAngle` / `endAngle` in degrees. `0` is at the right side of the chart and positive angles sweep clockwise. The playground's sweep angle is a teaching control: it passes `endAngle = startAngle + sweepAngle`.

## Radar

Radar still uses `x` / `y`: the dimension field runs around the angle, and the score field maps to radius. `closed` connects the final point back to the first.

## Polar Lines

An open `<PathMark>` can represent wind direction, cycles, and similar data. Here `angle` binds to `x`, `speed` binds to `y`, and `order` controls the connection sequence.
