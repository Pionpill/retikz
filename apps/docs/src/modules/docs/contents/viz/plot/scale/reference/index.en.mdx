This page covers `PlotScale` from `@retikz/plot-react`, authoring inputs from `@retikz/plot-vanilla`, and position mapping contracts and schemas from `@retikz/plot`. See [position scales](/viz/plot/scale/position) and [mark attribute mapping](/viz/plot/scale/mark-attributes) for usage. Algorithm definitions, registration, and evaluation belong to the [Data scale API reference](/viz/data/scale/reference).

Schema defaults are values filled in when parsing configuration directly. Domain inference, coordinate ranges, and mark padding depend on the current data and layout; see position scale usage for these rules. They are distinct from static schema defaults.
