---
title: 维度坐标系
description: 根据位置字段的数量选择直角或极坐标投影，在平面、直线或圆周上定位图元。
---

坐标系决定位置字段如何落到画布上。字段先绑定到位置通道并经过比例尺，再由坐标系投影；两个位置字段可以表示水平与垂直位置，也可以表示角度与半径。只有一个位置字段时，可以沿直线或圆周定位，无需补一个没有意义的第二字段。

在 Plot 的 `coordinate` 中选择投影。下表中的一维、二维指参与定位的位置维度数量，与坐标轴是否显示无关。

| 定位目标               | `coordinate`  | 位置通道                       |
| ---------------------- | ------------- | ------------------------------ |
| 在平面上比较位置与高低 | `cartesian2D` | `x` 为水平位置，`y` 为垂直位置 |
| 围绕中心比较角度与距离 | `polar2D`     | `x` 为角度，`y` 为半径         |
| 沿直线排列事件或节点   | `cartesian1D` | `x` 为沿线位置                 |
| 沿圆周排列周期事件     | `polar1D`     | `x` 为角度                     |

不同形态复用字段绑定与比例尺。需要先了解字段绑定时，可阅读[通道](/viz/plot/channel)；需要双轴、分面或共享轨道时，阅读[坐标组合](/viz/plot/coordinate/composition)。

## 二维坐标系

二维坐标系使用两个位置维度，分别控制水平与垂直位置，或角度与半径。

### 直角坐标系

笛卡尔坐标系把 `x` 映射到水平方向、把 `y` 映射到垂直方向，适合沿共享直线轴比较分类与数值。下面的试验场固定坐标系和六行数据，可以切换图元，并控制 y 网格的显示：

- 点使用 `<PointMark>` 显示每行数据的位置。
- 线使用开放的 `<PathMark>` 按 `order` 连接这些位置。
- 面使用 `<IntervalMark>` 占据分类带宽，并从 `y = 0` 的 x 轴基线向上延伸。

### 极坐标系

极坐标系把 `x` 映射为绕中心的角向位置，把 `y` 映射为离中心的径向距离。它仍复用相同数据与图元，但投影后的关系会发生变化：

- 点沿角向分布，半径由数值决定。
- 线使用闭合的 `<PathMark>`，把最后一点连回第一点。
- 面仍由 `<IntervalMark>` 实现，形成按分类分隔的径向区间。

`interpolation` 决定相邻极坐标位置之间的连接空间。省略时，连续角向比例尺使用 `polar`，在角度 / 半径输出空间插值后再投影；离散角向比例尺使用 `chord`，直接连接投影顶点。coordinate 的显式值会同时作用于网格与可继承图元；PathMark 和 IntervalMark 可以再局部覆盖，PointMark 没有连接边界，因此不提供该配置。

试验场可以控制坐标系的插值模式，并调整 `innerRadius`、起始角度和扫过角度。扫过角度是面板中的教学参数，实际传给 coordinate 的 `endAngle` 等于 `startAngle + sweepAngle`。

## 一维坐标系

一维坐标系使用一个位置维度，把事件或节点放到直线或固定半径的圆周上。

位置字段始终绑定到 `x`，仍可使用 linear、log 或 time 等比例尺。下面两个示例使用同一组事件时刻，并将小时 domain 固定为 `[0, 24]`。

`<PointMark>` 可以直接使用一维投影定位；柱、扇区和面积需要二维区域，不能使用一维坐标系。

### 直线投影

`cartesian1D` 把位置映射到一条直线上。`orientation` 控制直线方向，默认横向；切换为纵向后，字段仍绑定到 `x`。

| 方向 | 坐标配置                                                        |
| ---- | --------------------------------------------------------------- |
| 横向 | `coordinate="cartesian1D"`                                      |
| 纵向 | `coordinate={{ type: 'cartesian1D', orientation: 'vertical' }}` |

### 圆形投影

`polar1D` 把位置映射为角度，所有点共用一个固定半径。`radius` 是可用外半径的比例，取值为 `0 < radius <= 1`，默认 `1`；角度使用度数，默认从 `0` 到 `360`。

| 形态     | 坐标配置                                                           |
| -------- | ------------------------------------------------------------------ |
| 完整圆周 | `coordinate="polar1D"`                                             |
| 部分圆周 | `coordinate={{ type: 'polar1D', startAngle: 180, endAngle: 360 }}` |

控件中的“扫过角度”用来调整圆弧覆盖范围，传入坐标系时换算为 `endAngle = startAngle + sweepAngle`。在默认的完整圆周上，`22` 小时对应 `330°`。

## 自定义坐标系

内置投影无法表达目标空间时，可以定义新的位置角色与投影方式，并注册到 Plot 中。自定义坐标系沿用位置通道与比例尺的绑定机制，具体维度由它声明的角色决定。

完整的定义、注入与使用示例见[自定义坐标系](/viz/plot/coordinate/custom-coordinate)。如果只需要改变数据值到位置值的映射，可使用[比例尺](/viz/plot/scale)。
