title: 契约 - 辅助
description: 查询 Plot 坐标轴、刻度、网格、标题、图例及其精确子组件 schema。
---

辅助层从已解析比例尺和坐标角色派生可读的坐标轴、网格和图例。样式字段只控制外观；刻度源、放置、投影目标和通道引用仍属于 guide 语义。
