Plot reads `style` and `mode` from the Core effective Theme at its current Scene or Scope position. It always builds a default baseline from the mode and Core shared categorical palette first; an explicit `style` then selects the same-named domain definition and overrides only the defaults and Axis rules that definition returns. Published packages include no named styles; this site injects Academic, Vibrant, and Clean reference presets through the public Core and Plot definition contracts. `IRPlot` does not repeat Core `style` or `mode`; themes affect visual defaults only, not data, coordinates, Axis creation, minor tick sources, or mark structure.

<ComponentPreview files="theme-tokens" size="lg" />

The example sets the string master `plotDefaults.typography.textColor` to `#2563EB`, then derives the Plot-area background with `0.08` and the grid stroke with `0.25`; the categorical palette remains a list of string colors. The defaults use the same nested Source fields as Plot IR; contextual colors and opacity remain separate fields.

React, Vanilla, and plain JSON pass the same defaults and rules to the Plot resolver without adapter-owned presets. The structured `plotArea.fill` field fills only the two-dimensional Plot area after axis, legend, and layout reserves are removed. One-dimensional lines and circles expose only a projection path, so they emit neither a fillable Plot area nor a grid layer across one.

The site's Vibrant reference preset uses a light blue-gray Plot area in Light mode and a dark Plot area in Dark mode; the default baseline, Academic, and Clean remain transparent. Explicit `plotDefaults.plotArea.fill` values still override the preset through the normal cascade.

## Named styles

Use definePlotThemeStyle with a name and resolve callback to register a runtime style. The callback receives the effective Core Theme and returns sparse defaults and ordered Axis rules. Inject definitions through plotThemeStyles on Plot, lowerPlots, or renderPlot, or with PlotThemeProvider.

The Core theme prop selects the host style and mode. Plot defaults are persisted Plot Source fields and use the same nested paths in IRPlot, InputPlot, and runtime inputs.

## Cascade and boundaries

The resolver applies the Core Neutral baseline, the named Plot style, Chart forwarded defaults, local IRPlot plotDefaults and plotRules, then explicit Axis, Legend, mark, and scale configuration. Objects merge at their formal nested fields. Arrays, scalars, false, and changed discriminators replace the prior value. Rules match existing axes and never create an axis or grid.
