Plot reads `style` and `mode` from the Core effective Theme at its current Scene or Scope position, then selects the complete domain preset with the same name. `PlotSpec` does not repeat Core `style` or `mode`; themes affect visual defaults only, not data, coordinates, guide creation, or mark structure.

<ComponentPreview files="theme-tokens" size="lg" />

The example writes plot-area background, grid, and categorical palette values through `PlotThemeToken`. The corresponding structured-theme field is `plotArea.fill`; it fills only the Plot area after axis, legend, and layout reserves are removed, while axis-label regions, facet gaps, and the outer Chart canvas remain transparent. React, Vanilla, and plain JSON pass the same `plotThemeTokens` to the Plot resolver without adapter-owned presets; the Core Theme provides the effective `style` / `mode` and shared colors.

## Extensible styles

Define a runtime Plot preset with `definePlotThemeStyle({ name: 'brand', resolve: theme => tokens })`, then inject it through `plotThemeStyles` on `lowerPlots`, `<Plot>`, or `renderPlot()`. The resolver function and complete token map never enter `PlotSpec`; it persists only `theme.style = 'brand'`. Pass the same-named Core definition through `themeStyles` in the same figure or Core or Plot fails loudly. When Chart is used, `createChartComposites({ chartThemeStyles, plotThemeStyles })` also needs same-named Chart and Plot definitions.

## Cascade and atomic replacement

```text
Core effective Theme
  → Plot style definition
  → inherited Core categorical
  → local PlotSpec.plotThemeTokens
  → local PlotSpec.plotTheme
  → explicit guide / mark / scale config
```

- `plotThemeTokens` is a strict sparse canonical map; unknown keys, explicit `undefined`, and invalid values fail
- native `plotTheme` is closer to the formal Plot structure and may carry legal fields not represented by tokens
- arrays, scalars, `false`, and objects whose discriminator changes replace whole values; compatible closed objects merge legal fields
- explicit scale `range` / `scheme` and local axis, legend, and mark configuration always win

## Canonical tokens

`PlotThemeToken` exports 38 stable keys. Plot owns their semantics, while their value contracts reuse Core paint / font / opacity atoms, Plot guide / scale schemas, and Standard Legend gap atoms.

| Group           | Canonical keys                                                                                                                                                                                                                                                                                                                           |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Plot area       | `plot.area.fill`                                                                                                                                                                                                                                                                                                                         |
| Typography      | `plot.typography.foreground`, `plot.typography.font.family`, `plot.typography.font.size`                                                                                                                                                                                                                                                 |
| Axis line       | `axis.line.enabled`, `axis.line.stroke`, `axis.line.strokeWidth`, `axis.line.drawOpacity`                                                                                                                                                                                                                                                |
| Axis tick       | `axis.tick.mark`                                                                                                                                                                                                                                                                                                                         |
| Axis tick label | `axis.tickLabel.enabled`, `axis.tickLabel.foreground`, `axis.tickLabel.font.size`, `axis.tickLabel.gap`                                                                                                                                                                                                                                  |
| Axis title      | `axis.title.foreground`, `axis.title.font.size`, `axis.title.font.weight`                                                                                                                                                                                                                                                                |
| Axis grid       | `axis.grid.stroke`, `axis.grid.strokeWidth`, `axis.grid.drawOpacity`                                                                                                                                                                                                                                                                     |
| Legend          | `legend.title.foreground`, `legend.title.font.size`, `legend.title.font.weight`, `legend.label.foreground`, `legend.label.font.size`, `legend.swatch.size`, `legend.swatch.gap`, `legend.entry.gap`, `legend.title.gap`, `legend.ramp.length`, `legend.ramp.thickness`, `legend.symbol.size`, `legend.symbol.scale`, `legend.symbol.fit` |
| Palette         | `plot.palette.categorical`, `plot.palette.series`, `plot.palette.sector`, `plot.palette.sequential`, `plot.palette.diverging`                                                                                                                                                                                                            |

`axis.line.enabled` changes the baseline default of an existing Axis only. Grid and legend creation are Chart recipe or explicit guide semantics, not Plot tokens. Legacy `data.palette.*`, bare `axis.enabled`, `axis.grid.enabled`, and `legend.enabled` are not canonical Plot keys.

## PlotResolvedThemeTokensSchema

`PlotResolvedThemeTokensSchema` uses the exact same 38-field contract with every field required. All eight built-in presets and the `tokens` returned by `resolvePlotTheme()` must pass it, so sparse, resolved, and preset maps cannot drift into separate field lists.

## Inspection

`resolvePlotTheme(effectiveTheme, input)` is a public pure resolver. It returns `IRPlotThemeResolution`, validated by `PlotThemeResolutionSchema`:

| Field               | Meaning                                                         |
| ------------------- | --------------------------------------------------------------- |
| `style` / `mode`    | Effective Core Theme environment selecting the preset           |
| `tokens`            | Complete token map after the cascade                            |
| `tokenSources`      | One winning source and stable path for every canonical token    |
| `authoredOverrides` | Record for the authored native `plotTheme` entry                |
| `plotTheme`         | Complete mapped and validated native Plot theme                 |
| `palette`           | Final palettes and schemes shared by scales, marks, and legends |

`tokenSources[].kind` answers only whether a token is projected directly from the upper effective Theme (`inherit`) or built by the Plot style definition or current Plot input (`local`); it does not encode cascade priority. The stable `path` identifies the winning entry: `$style/...` for the Plot style baseline, `$theme/colors/categorical` for the Core shared categorical projection, and `$spec/plotThemeTokens/...` or `$spec/plotTheme/...` for Plot-local inputs. The `plotTheme` record in `authoredOverrides` is also `local`.

Chart may call this resolver to read a transient series palette needed by a recipe, but it does not write the fully resolved theme back into `PlotSpec` or relabel Plot tokens as Chart-owned.
