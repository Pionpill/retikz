This page covers coordinate authoring inputs from `@retikz/plot-vanilla`, plus coordinate configuration, extension definitions, and runtime projection contracts from `@retikz/plot`. See [coordinate dimensions](/viz/plot/coordinate/dimension) for usage and [custom coordinates](/viz/plot/coordinate/custom-coordinate) for extension steps.

Plot layout serves the plotting body: composition configures padding, while axes, legends, and facets own their spatial contracts. `IRPlot` has no top-level `layout` or `labels`; [Chart](/viz/chart/introduction) organizes chart-wide titles, subtitles, and sources.
