---
title: 契约 - 规格
description: 查询 PlotSpec 根、坐标视图、Facet 与 Tracks 组合的 JSON schema。
---

`PlotSpecSchema` 是 Plot Tier 2 composite 的根契约。它引用外部 dataset，声明变换、比例尺、坐标系、图元和辅助层；lowering 再将其展开为 Kernel IR。

## PlotSpecSchema

  name="PlotSpecSchema"
  description="Plot IR 根：只保存 JSON-safe 语法与数据引用的 plot composite。"
  descriptions={{
    namespace: '固定为 plot，用于把 Tier 2 节点路由到 Plot lowering。',
    type: '固定为顶层 plot composite 类型。',
    id: '可选稳定 Plot id，同时用作外层 Scope id 和锚点目标。',
    data: '外部 dataset 引用与可选数据模型；实际数据不进入 IR。',
    'data.reference': '在 lowering 时从 datasets 中解析的数据集名。',
    'data.model': '可选字段模型，为通道、比例尺与辅助提供类型信息。',
    transform: '在比例尺推断和图元 lowering 前按顺序执行的数据变换。',
    scales: '具名比例尺操作；内置变体在此校验，自定义变体在 lowering 时校验。',
    colors: '兼容性调色板简写；显式 theme palette 或 scale range / scheme 优先级更高。',
    theme: 'Plot lowering 消费的 JSON-safe 视觉默认值。',
    layout: 'Plot 标签、图例和辅助预留空间的布局策略。',
    labels: '标题、说明、来源等静态 Plot 文本。',
    width: '图区内在宽度；省略时回退到 lowering 全局宽度和内置默认值。',
    height: '图区内在高度；省略时回退到 lowering 全局高度和内置默认值。',
    coordinate: '单坐标系简写；未使用 composition 时必需。',
    composition: '为图元和坐标轴注册多个坐标视图及其组合。',
    marks: '图元层，数组顺序就是稳定的绘制顺序。',
    guides: '坐标轴和图例辅助层；省略表示不生成辅助。',
    meta: '原样复制到 Kernel IR 的 JSON-safe 源元数据。',
  }}
/>

`coordinate` 与 `composition` 必须且只能出现一个。同一 Plot 中的 scale name 、view id 和 arrangement id 必须唯一，图元或坐标轴引用的 `coordinateView` 必须已注册。
