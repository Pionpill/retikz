Plot transforms reshape normalized data rows for drawing. They produce intervals, stack boundaries, bins, density samples, trend samples, or relation fields for scales and marks to consume.

Sorting, summarizing, selecting, annotating, and custom data transforms belong to [Data Transforms](/viz/data/transform). This group covers Plot-registered drawing transforms and their scope and pipeline semantics, plus how Plot injects and consumes a custom Data transform.

## Scopes & Pipeline

Root transforms rewrite the data shared by the whole Plot. A mark-local transform creates a data view for the current mark only. Choose the scope before choosing a transform kind.

| entry point              | scope        | use it when                                        |
| ------------------------ | ------------ | -------------------------------------------------- |
| `<Transform ... />`      | Plot root    | Declare shared transforms in JSX order             |
| `dataTransforms={[...]}` | Plot root    | Generate a shared transform array programmatically |
| A mark's `transform`     | Current mark | Derive, aggregate, or sample one layer only        |

Root transforms run first, and every mark reads their result. A mark-local transform runs afterward and replaces only the rows visible to that mark. Automatic transforms generated by mark shortcuts join the same root pipeline.

Input fields read by a transform must still satisfy `model`; derived output fields do not need to be declared in a strict model. Final mark-local data views still participate in shared scale and legend inference.

See the [Data Transform Component](/viz/data/transform/overview) for the `<Transform>` API and complete root-entry assembly order. See [Plot Lineage](/viz/data/provenance/plot) to trace rows and mark outputs across transforms.

## Responsibilities

| page              | Plot members or entry point | output shape                            |
| ----------------- | --------------------------- | --------------------------------------- |
| Derive & Jitter   | `derive-interval`, `jitter` | One output row for each input row       |
| Stacking & Shares | `stack`, `normalize`        | Detail rows plus bounds or share fields |
| Binning           | `bin`                       | One output row for each bin             |
| Density & Trend   | `density`, `smooth`         | A batch of sampled rows for each group  |
| Row Pairing       | `relate`                    | Zero or one relation row for each group |
| Custom Transforms | `transformDefinitions`      | Defined by the runtime Definition       |
