title: Transforms

Transforms process data rows before marks read their result fields. For example, normalize values into shares, then bind those shares to vertical positions. [Data](/viz/data/transforms) owns the definitions, parameters, and computation; Plot connects declarations, organizes plotting scopes, and consumes the results.

## Using transforms

Complete the [Plot quick start](/viz/plot/get-start) first. This example normalizes three values into `share` and draws three points at y = 0.2, 0.3, and 0.5. A declaration wraps `{ kind, params }` in `operation`.

Prepare `<div id="plot"></div>` in HTML and choose one of the following entries.

<DocTabs defaultValue="react-jsx">
<DocTab value="react-jsx" label="React + JSX">

Declare a root transform with `PlotTransform`. Import transform types from `@retikz/data` and plotting components from `@retikz/plot-react`.

```tsx
import { Plot, PlotAxis, PlotScale, PlotTransform, PointMark } from '@retikz/plot-react';
import { createRoot } from 'react-dom/client';

const rows = [
  { month: 1, value: 20 },
  { month: 2, value: 30 },
  { month: 3, value: 50 },
];

createRoot(document.getElementById('plot')!).render(
  <Plot data={rows} width={360} height={220}>
    <PlotTransform operation={{ kind: 'normalize', params: { field: 'value', as: 'share' } }} />
    <PlotScale dimension="x" type="linear" domain={[0.5, 3.5]} />
    <PlotScale dimension="y" type="linear" domain={[0, 1]} />
    <PointMark x="month" y="share" size={6} />
    <PlotAxis dimension="x" />
    <PlotAxis dimension="y" />
  </Plot>,
);
```

</DocTab>
<DocTab value="react-ir" label="React + IR">

Write declarations in `IRPlot.transform` and pass the IR to React `Plot` through `spec`.

```tsx
import type { IRPlot } from '@retikz/plot';
import { Plot } from '@retikz/plot-react';
import { createRoot } from 'react-dom/client';

const rows = [
  { month: 1, value: 20 },
  { month: 2, value: 30 },
  { month: 3, value: 50 },
];

const spec: IRPlot = {
  namespace: 'plot',
  type: 'plot',
  data: { reference: 'rows' },
  transform: [{ operation: { kind: 'normalize', params: { field: 'value', as: 'share' } } }],
  scales: [
    { type: 'linear', name: 'x', domain: [0.5, 3.5] },
    { type: 'linear', name: 'y', domain: [0, 1] },
  ],
  coordinate: { type: 'cartesian2D', x: 'x', y: 'y' },
  marks: [
    { type: 'point', encoding: { x: { field: 'month' }, y: { field: 'share' } }, size: { kind: 'constant', value: 6 } },
  ],
  guides: [
    { type: 'axis', dimension: 'x' },
    { type: 'axis', dimension: 'y' },
  ],
};

createRoot(document.getElementById('plot')!).render(<Plot spec={spec} data={{ rows }} width={360} height={220} />);
```

</DocTab>

## Data scopes

Transforms can be added in two places: at the **root**, on the Plot, to share processed data across all marks; or **locally**, on one mark’s `transform` property, to process only that mark’s data. Use a root transform to normalize data for the whole plot, or a local transform to jitter just one point layer.

The examples below reuse `rows` from the authoring example and jitter `month` to show where each declaration goes.

<DocTabs defaultValue="react">
<DocTab value="react" label="React">

For a root transform, place `<PlotTransform>` directly under `<Plot>`, alongside the marks. For a local transform, pass the declaration array to the target mark’s `transform` prop.

```text
Plot
├── PlotTransform
├── PointMark
└── PointMark
```

```tsx
import type { IRDataJitterTransform } from '@retikz/data';
import { Plot, PlotTransform, PointMark } from '@retikz/plot-react';

const operation: IRDataJitterTransform = {
  kind: 'jitter',
  params: { axis: 'x', xField: 'month', amount: 0.2, seed: 7 },
};

// Root: both point layers read the jittered month
const rootExample = (
  <Plot data={rows}>
    <PlotTransform operation={operation} />
    <PointMark x="month" y="value" fill="gray" />
    <PointMark x="month" y="value" fill="dodgerblue" />
  </Plot>
);

// Local: only the blue points read the jittered month
const localExample = (
  <Plot data={rows}>
    <PointMark x="month" y="value" fill="gray" />
    <PointMark x="month" y="value" fill="dodgerblue" transform={[{ operation }]} />
  </Plot>
);
```

</DocTab>
<DocTab value="vanilla" label="Vanilla / IR">

Both `plot(...)` and direct IR declarations use the same placement: root transforms go on the Plot’s `transform`, and local transforms go on the target mark’s `transform`. These configuration fragments show the placement; set up data, scales, coordinates, and rendering as described in the authoring section.

```ts
import type { IRDataJitterTransform } from '@retikz/data';

const operation: IRDataJitterTransform = {
  kind: 'jitter',
  params: { axis: 'x', xField: 'month', amount: 0.2, seed: 7 },
};
const transform = [{ operation }];

// Root: put transform on the Plot configuration
const rootConfig = {
  transform,
  marks: [
    { type: 'point', encoding: { x: { field: 'month' }, y: { field: 'value' } } },
    { type: 'point', encoding: { x: { field: 'month' }, y: { field: 'value' } } },
  ],
};

// Local: add transform only to the second mark
const localConfig = {
  marks: [
    { type: 'point', encoding: { x: { field: 'month' }, y: { field: 'value' } } },
    { type: 'point', transform, encoding: { x: { field: 'month' }, y: { field: 'value' } } },
  ],
};
```

</DocTab>
</DocTabs>

When both are present, root transforms run first, then local transforms continue from each mark’s input view. Local results replace only the rows that mark sees, but still contribute to shared scale and legend inference. The available declaration forms are:

| Entry                               | Scope                                                                 |
| ----------------------------------- | --------------------------------------------------------------------- |
| `<PlotTransform operation={...} />` | React root declarations, collected in order.                          |
| `Plot.dataTransforms`               | React root declaration array, executed before JSX child declarations. |
| `IRPlot.transform`                  | Root declaration array in IR / Vanilla.                               |
| Mark `transform`                    | Declaration array applied only to the current mark.                   |

The demo has two fixed layers: gray circles for A and blue diamonds for B. Switch the jitter scope to move only B or both layers.

## Custom transforms

Define custom Definitions and Implementations with `@retikz/data`. Plot accepts them through `definitions.transforms` and `implementations.transforms`; declarations retain the same `operation` structure. See [Data extensions](/viz/data/transform/extensions) for the full definition process.

<DocTabs defaultValue="react">
<DocTab value="react" label="React">

This snippet shows only injection points. `definition`, `implementation`, and the matching `operation` come from an existing Data extension.

```tsx
<Plot data={rows} definitions={{ transforms: [definition] }} implementations={{ transforms: [implementation] }}>
  <PlotTransform operation={operation} />
  {/* Marks bind the outputs declared by this transform */}
</Plot>
```

</DocTab>
<DocTab value="vanilla" label="Vanilla">

Store declarations in IR and pass runtime dependencies in `renderPlot` options.

```ts
renderPlot(
  spec,
  { rows },
  { definitions: { transforms: [definition] }, implementations: { transforms: [implementation] } },
);
```

</DocTab>
</DocTabs>
