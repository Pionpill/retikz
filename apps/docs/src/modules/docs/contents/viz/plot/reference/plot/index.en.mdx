`PlotSpecSchema` is the root contract for the Plot Tier 2 composite. It references an external dataset and declares transforms, scales, coordinates, marks, and guides; lowering expands the result into Kernel IR.

## PlotSpecSchema

<ZodSchema name="PlotSpecSchema" />

Exactly one of `coordinate` and `composition` must be present. Scale names, view ids, and arrangement ids must be unique within one Plot; every `coordinateView` referenced by a mark or axis must already be registered.
