---

API Reference is for stable contracts, not introductory teaching. Ten contract pages cover the public schemas of Plot Tier 2 IR, while Runtime Overview explains how hosts construct specs, inject data and Definitions, lower to Core IR, and receive rendered or side-channel results.

> This is the reference layer. Start with [Plot Grammar](/viz/plot) to build a plot, or read [Plot Lineage](/viz/data/provenance/plot) for runtime auditing.

## Responsibilities

| Topic                 | Responsibility                                   | Consult it when                                         |
| --------------------- | ------------------------------------------------ | ------------------------------------------------------- |
| Contract - Plot Spec  | Root spec, coordinate views, and composition     | Generating or validating an `IRPlot`                    |
| Contract - Encoding   | Field, constant, and channel bindings            | Mapping data columns to position and style              |
| Contract - Transform  | Ordered Plot-domain data transforms              | Declaring stack, bin, density, or trend steps           |
| Contract - Mark       | Marks, relations, references, and path closure   | Selecting geometry and exact configuration              |
| Contract - Scale      | Positional, ordinal, radial, and color scales    | Validating domains, ranges, and scale options           |
| Contract - Coordinate | 1D, 2D, and custom coordinate operations         | Defining positional roles and scale ownership           |
| Contract - Guide      | Axes, grids, ticks, titles, and legends          | Configuring guides and precise subcomponents            |
| Contract - Layout     | Composition padding and ownership boundary       | Configuring drawing spacing or checking Chart ownership |
| Contract - Layer      | Semantic-layer zIndex override                   | Adjusting lowered primitive stacking                    |
| Contract - Theme      | Background, text, axes, legends, and palettes    | Defining JSON-safe visual defaults                      |
| Runtime Overview      | Host entry points, lowering, Scene, and sidecars | Integrating React, Vanilla, SSR, or tools               |
