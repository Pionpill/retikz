Density and trend transforms generate sample rows from observations. Path marks then connect those samples. See [Transforms](/viz/plot/transform) for authoring and scopes; this page covers plotting results, while Data explains the algorithms and full parameters.

## Density

`density` produces sampling positions and density values from continuous observations. This demo binds `densityX` / `density` to the path’s `x` / `y` channels and draws a curve for each group.

| Parameter     | Use and constraints in this demo                                                                       |
| ------------- | ------------------------------------------------------------------------------------------------------ |
| `field`       | Read observations from `value`.                                                                        |
| `groupBy`     | Estimate density separately by `group`.                                                                |
| `bandwidth`   | Use an automatic rule or an explicit value; a smaller explicit bandwidth retains more local variation. |
| `sampleCount` | Set the number of output samples.                                                                      |
| `xAs`         | Sampling position output, named `densityX` here.                                                       |
| `densityAs`   | Density output, named `density` here.                                                                  |

The x axis is fixed to 1–10; the y axis uses 0–0.7. The path orders points by `densityX` and closes to the zero baseline. Closure and fill are mark settings.

## Trends

`smooth` fits observations and generates prediction samples. This demo uses linear fitting and retains the original points. The trend path and hollow sample points each consume a local transform result.

| Parameter     | Use and constraints in this demo                                                  |
| ------------- | --------------------------------------------------------------------------------- |
| `x`           | Read the independent variable from `time`.                                        |
| `y`           | Read observations from `value`.                                                   |
| `groupBy`     | Fit separately by `series`.                                                       |
| `method`      | Fixed to `{ kind: 'linear' }` in this demo.                                       |
| `sampleCount` | Set prediction sample count without changing the linear model.                    |
| `extent`      | Omit it to sample over the observed range; the demo can also extend to `[-1, 5]`. |
| `xAs`         | Sampling position output, named `trendX` here.                                    |
| `yAs`         | Prediction output, named `trendY` here.                                           |
