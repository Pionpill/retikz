---
title: Coordinates
description: 'Coordinates place data on a line, plane, or circle and can combine several coordinate regions in one chart.'
---

Coordinates determine the spatial shape of a chart. Scales first convert field values into drawable positions; the coordinate system then projects those positions onto a line, plane, or circle.

If you only need to adjust ticks, labels, or grid lines, see [Axis](/viz/plot/guide/axis). To add a new projection, see [Custom Coordinates](/viz/plot/coordinate/custom-coordinate).

## Responsibilities

| Topic                  | Responsibility                                      | Use it for                               |
| ---------------------- | --------------------------------------------------- | ---------------------------------------- |
| 2D coordinates         | Project x / y positional dimensions onto a plane    | Bars, lines, pies, and radar charts      |
| 1D coordinates         | Project one positional dimension onto a line/circle | Rugs, timelines, and cyclic events       |
| Coordinate composition | Organize several coordinate regions in one Plot     | Dual axes, facets, and shared tracks     |
| Custom coordinates     | Register new roles, projections, and capabilities   | Spatial mappings beyond built-in systems |
