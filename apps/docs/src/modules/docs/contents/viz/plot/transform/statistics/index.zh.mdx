---
title: 密度与趋势
description: 密度与趋势是 plot 注册的采样统计变换，把原始样本变成可由 PathMark 绘制的曲线或面积。
---

有些统计不是“给每组一个值”，而是直接生成一批新的采样行。`density` 读取一维连续字段，用 KDE 生成 `xAs` / `densityAs` 输出字段；`smooth` 读取 `(x, y)` 样本，用回归模型生成 `xAs` / `yAs` 预测字段。它们都输出普通 rows，再交给 `PathMark` 画曲线或面积。

通用 reducer / selector、`summarize`、`select` 和自定义 transform definition 见[数据变换](/viz/data/transform)。

## 趋势 smooth

`smooth` 把散点或时间序列中的 `(x, y)` 样本拟合成趋势线采样行。首轮 `method` 只有 `{ kind: 'linear' }`，默认不外推；输出行通常交给 `PathMark` 按 `order` 连接。

<ComponentPreview files={['transform-smooth', 'transform-smooth.data.ts']} />

`IRPlotSmoothTransform` 的 `kind` 固定为 `'smooth'`。

`method.kind` 的公开闭合集合由 <ApiValues name="SmoothMethodKind" /> 提供。

| prop           | 类型                                                                                                                                                      | 默认值          | 说明                                            |
| -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------- | ----------------------------------------------- |
| `x` / `y`      | `string`                                                                                                                                                  | —               | 回归输入字段                                    |
| `groupBy?`     | `Array<string>`                                                                                                                                           | 全局单组        | 按组分别拟合趋势线                              |
| `method?`      | `IRPlotSmoothMethodSpec`<br />`Extract<IRPlotSmoothMethodSpec, { kind: typeof SmoothMethodKind.Linear }>`<br />- `kind:` `typeof SmoothMethodKind.Linear` | `linear`        | 平滑方法<br />线性回归分支<br />- linear 判别值 |
| `sampleCount?` | `number`                                                                                                                                                  | `64`            | 每组输出的预测采样点数量，至少为 2              |
| `extent?`      | `[number, number]`                                                                                                                                        | 有限 x 观测范围 | 采样区间；显式传入可做外推                      |
| `xAs` / `yAs`  | `string`                                                                                                                                                  | —               | 输出预测采样位置和 y 值的字段名                 |

`smooth` 对不可拟合输入会 fail-loud：每组至少需要两个有限 `(x, y)` 点，并且 x 不能全相同。原始散点和趋势线应分成两层 mark：散点继续读源数据，趋势线读 `smooth` 生成的采样行。

## 与数据流的关系

`density` 和 `smooth` 之所以留在绘图语法中，是因为它们的主要输出就是给 plot 曲线 / 面积图消费的采样字段。它们仍然运行在 data canonical 行之上，也会沿用数据层的字段解析、校验与 provenance 规则。
