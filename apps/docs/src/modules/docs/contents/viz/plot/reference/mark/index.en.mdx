Marks are the geometry-output layer of the graphics grammar. Point, Path, Interval, and Relation form a closed discriminated union. Unknown mark types are rejected at the schema boundary.

Fixed `fill` / `stroke` reuse Core PaintValue: CSS colors, a master color weight from 0 to 1, or structured Paint. `opacity` accepts a number (equivalent to `overall`) or an object with independent `overall` / `fill` / `stroke` factors. Relation primitive styles follow the same rules.

Every mark can use `defaultColorGroup` to declare a shared fallback color. A named group consumes one `palette.series` slot at its first appearance and reuses it for later members; ungrouped marks each consume the next slot in declaration order. Explicit color encodings and constant paints still take precedence.

## Mark labels

Fixed labels use an optional `text` field. When omitted, `encodings.label.text` at the same index can provide the content. A label is omitted if neither source supplies valid text. String shorthand follows the same rules.

Node and path labels both use the Core text block: a string with line breaks or a non-empty array of lines. Per-line styles and mixed segments belong inside that array. One text block still represents one label.
