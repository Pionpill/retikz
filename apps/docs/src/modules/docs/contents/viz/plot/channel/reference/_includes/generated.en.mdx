#### <ApiSourceLink label={"ChannelDefinitionKind"} path={"packages/viz/plot/src/contract/channel.ts"} startLine={55}>ChannelDefinitionKind</ApiSourceLink>

Classifies channels by their consumer: coordinate roles consume position channels, mark lowering consumes mark channels, and scope, node, and path channels write directly to core IRScope, IRNode, and IRPath.

```ts
export const ChannelDefinitionKind = {
  Position: 'position',
  Label: 'label',
  Mark: 'mark',
  Scope: 'scope',
  Node: 'node',
  Path: 'path',
} as const;

export type ChannelDefinitionKind = ValueOf<typeof ChannelDefinitionKind>;
```
