Plot's `transform` consumes `IRDataTransform` from the `@retikz/data` package root. Data owns the schemas, definitions, and computation of all twelve built-in operations. Complete field contracts are in [Data Contract](/viz/data/reference/contract#datatransformschema).

## Data scopes

| Entry                                | Input and result                                                                   |
| ------------------------------------ | ---------------------------------------------------------------------------------- |
| Plot root `transform`                | Ordered operations over the shared data view; marks and domains consume the result |
| Mark `transform`                     | A local result from that mark's input view; other marks keep their data            |
| `<PlotTransform>` / `dataTransforms` | Authoring forms assembled into Plot's root operation array                         |

Operations execute in declaration order. After row or field changes, subsequent marks must reference fields present in the result. Data `jitter` uses data units; projected [position adjustment](/viz/plot/reference/mark#jitterpositionadjustmentschema) remains a separate Plot capability.

## Contract entry points

Import `TransformSchema`, `BuiltinDataTransform`, and concrete `IRDataXxxTransform` types from `@retikz/data`. Plot does not re-export these data contracts.
