---
title: IntervalMark
description: IntervalMark 表达各位置维度上的区间积；柱、直方、热图、径向柱、饼图和环图都是它的不同投影。
---

`<IntervalMark>` 不是“柱图元”，而是区间图元。它为每条数据构造一个或多个位置维度上的区间，再交给坐标系投影：cartesian 下常是矩形，polar 下可以是径向柱或扇区。

默认写 `x` / `y` 时，`x` 走 band 区间、`y` 从 baseline `0` 延伸到数值；显式写 `bounds` 时，可以把任一维声明为 `band` / `span` / `extent` / `proportional` / `full`。表里的 `FieldName` 表示数据字段名或字段路径，例如 `quarter` / `sales.revenue`。

## 用法

```tsx
import { IntervalMark, Plot } from '@retikz/plot-react';
```

```tsx
<Plot data={revenue}>
  <IntervalMark x="quarter" y="value" />
</Plot>
```

普通柱只需要 `x` / `y`。可变宽柱使用 `width` 表达比例宽度区间；直方图使用 `x0` / `x1` 表达连续区间；热图用 `bounds` 声明双 band；饼图 / 环图用 `angle` 让 React DSL 自动累积角区间。

### 何时使用

IntervalMark 是底层 cell mark：它只负责把每行数据变成一个正交区间 cell，再由坐标系把 cell 投影成矩形、扇区或轮廓。柱、直方、热图、径向柱、饼图和环图不是不同的底层 mark，而是同一个 IntervalMark 在不同 `bounds`、`series`、`stack` 和 `coordinate` 下的表现形态。

| 表现形态     | 关键属性                                  | 说明                                                    |
| ------------ | ----------------------------------------- | ------------------------------------------------------- |
| 柱           | `x` / `y`                                 | `x` 分类槽给宽度，`y` 从 `0` 延伸到数值                 |
| 横向柱       | `direction="horizontal"`                  | `x` 改为数值长度，`y` 改为分类 band                     |
| 可变宽柱     | `x` / `width`                             | `width` 按数据顺序累加成连续比例区间，`x` 提供轴标签    |
| 分组柱       | `arrangement="dodge"` / `group`           | 同一分类槽内按分组字段切子带                            |
| 堆叠柱       | `arrangement="stack"` / `group`           | stack transform 产出 `y0` / `y1`，数值 role 改为 extent |
| 百分比堆叠柱 | `arrangement="normalize-stack"` / `group` | 先按分类归一化为百分比，再堆叠                          |
| 直方         | `x0` / `x1` / `y`                         | `x0` / `x1` 提供连续 x 区间，`y` 提供高度               |
| 热图 / 网格  | `bounds`                                  | `bounds.x` 和 `bounds.y` 都声明为 `band`                |
| 饼 / 环      | `angle` / `coordinate`                    | `angle` 累积成角向 extent，半径方向使用 full            |

## 例子

下面前四个示例都可以在“坐标系”中切换笛卡尔与极坐标。IntervalMark 的区间配置保持不变：笛卡尔坐标通常把 cell 投影成矩形，极坐标通常把同一个 cell 投影成扇区或环形网格。

### 基础用法

`x` / `y` 是最小柱形写法：`x` 绑定分类字段，`y` 绑定数值字段。坐标系会把分类字段解释为 band，把数值字段解释为从 `0` 到值的 span。

在笛卡尔坐标中，`direction="horizontal"` 会交换分类与数值角色；极坐标没有横向柱语义，因此切换到极坐标后仍使用 `x` 作为角向 band、`y` 作为径向 span。

同一个 playground 继续提供柱间距、圆角、透明度、描边、标签和阴影。它们只装饰最终生成的 core `Node`，不会改变区间来源。

### 系列排列

`arrangement` 控制多个系列如何共享一个分类 band：`dodge` 切成并排子带，`stack` 累积为连续 extent，`normalize-stack` 先按分类归一化再堆叠。`group` 决定编排分组，`color` 决定视觉着色。

切换坐标系只改变这些区间的投影方向：并排、堆叠和百分比堆叠的编排关系保持不变。`stackOffset` 只在普通堆叠下显示，可切换从零、归一化、正负分离、居中或重叠基线。

### 连续区间

`x0` / `x1` 是连续 extent 写法。直方图先用 bin transform 产出 `binStart` / `binEnd`，IntervalMark 再把它们作为 x 区间；比例宽度模式则用 `width` 按 GDP 分配连续区间宽度。

在极坐标中，连续 x 区间成为连续角区间，y 仍表达径向长度。通过 control 切换区间来源，箱数只在直方图模式下显示；左右、上下留白继续作用于对应的连续比例尺。

### 二维 cell

`bounds` 用来覆盖默认推断。热图需要两个方向都是 band，因此显式写 `bounds={{ x: { kind: 'band' }, y: { kind: 'band' } }}`；把 y 改为 `full` 时，每个 x band 会占满另一维。

同一套二维区间在笛卡尔坐标中形成矩形网格，在极坐标中形成环形 cell。关闭颜色映射只会改成统一填充，不会改变 cell 边界。

### 饼图与环图

`angle` 是饼图 / 环图的便捷入口：它会把份额字段累积成角向 extent，半径方向使用 full。环图不是新的 mark，只是 polar 坐标系配置了 `innerRadius`。

这个入口只在极坐标下有效，因此不提供无效的坐标切换。`padAngle` 留出真实角向间隔；`pull` 沿扇区中线静态外移。下面用饼图、环图和突出扇区三个 preset 共享同一个场景。

## 技术原理

<ComponentAlert
  type="tip"
  title="上手阶段可跳过本节"
  description="需要排查便捷属性如何变成 bounds、分组与堆叠顺序，或不同坐标系如何生成 cell 几何时再回来读。"
/>

`<IntervalMark>` 不是“柱图专用组件”。它把每行数据描述成各位置角色上的区间，再要求当前坐标帧通过 `projectCell` 把这些区间投影成矩形、扇区或 contour；不提供 cell 投影能力的坐标系会直接报错。

下面这条主链只关注 IntervalMark 的职责边界：便捷属性或显式 `bounds` 先归一为各 role 的区间，再按比例尺输出构造逻辑 Cell。真正的几何形态由当前坐标帧决定。

<ComponentPreview files="interval-cell-flow" hideCode size="sm" />

`series` / `group` 与 `arrangement` 会在进入这条主链前准备并排、堆叠或百分比堆叠所需的字段与 bounds。进入 `projectCell` 后，cartesian 通常得到 rect，polar 通常得到 sector，自定义坐标帧也复用同一个 Cell 投影契约；最终几何才装配成 core `Node` 图层。

`padAngle` 会收缩 sector 的角向边界，`pull` 沿最终扇区中线移动其中心；二者改变的是投影后的视觉几何，不会改写原始数据。
