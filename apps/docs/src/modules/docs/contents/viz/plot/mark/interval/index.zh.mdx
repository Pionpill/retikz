---
title: IntervalMark · 区间图元
description: 用 IntervalMark 定义数据区间，通过坐标投影绘制柱、直方图、热图、饼图与环图。
---

`IntervalMark` 把每行数据变成一个区域：先确定各维度的起止边界，再由坐标系决定区域的形状。分类区间与数值区间可以组成柱，两个分类区间可以组成热图单元，角度区间与半径区间可以组成扇区。

本页从普通柱开始，再介绍系列排列、连续区间和极坐标扇区。字段写法见[通道绑定](/viz/plot/channel/binding)，安装与宿主接入见[快速开始](/viz/plot/get-start)。

只需绘制一次的常量参考点、参考线或区域，使用[独立标注](/viz/plot/mark/annotation)。

## 基础用法

### 位置与方向

默认的 `x` 提供分类槽，`y` 提供从 0 到值的区间。分类槽的宽度由 band 比例尺决定；可以通过比例尺的 `paddingInner` 调整柱间距。

横向柱使用 `direction="horizontal"`，同时把数值字段放在 `x`、分类字段放在 `y`。示例切换到极坐标后使用角向分类和径向数值，不提供横向柱选项。调整圆角、描边、透明度与标签，可以观察区域外观的变化。

| 属性                               | 含义         | 说明                                             |
| ---------------------------------- | ------------ | ------------------------------------------------ |
| `x`、`y`                           | 位置字段     | 字段名或字段路径；极坐标中分别对应角向与径向     |
| `direction`                        | 柱方向       | 默认 `vertical`；`horizontal` 交换分类与数值角色 |
| `color`、`fill`                    | 区域颜色     | `color` 绑定颜色字段；`fill` 支持字段或常量      |
| `cornerRadius`                     | 圆角         | 装饰投影后的区域，不改变数据区间                 |
| `stroke`、`strokeWidth`、`opacity` | 描边与透明度 | 控制最终区域的外观                               |
| `label`                            | 数据标签     | 字符串绑定字段，也可传节点标签配置或有序数组     |

### 系列排列

同一分类下有多个系列时，`group` 指定排列分组，`color` 指定着色字段。`series` 也可作为分组来源，省略 `color` 时会用于颜色绑定。

`dodge` 把分类槽切成并排子带；`stack` 把数值累积为相接的区间；`normalize-stack` 先按分类归一化为百分比再堆叠。坐标切换改变区域形状，分组和累积关系保持不变。

| 属性               | 含义     | 说明                                                               |
| ------------------ | -------- | ------------------------------------------------------------------ |
| `group`、`series`  | 系列字段 | 标识同一分类中的不同系列；`group` 优先用于排列                     |
| `arrangement`      | 排列策略 | `dodge`、`stack`、`normalize-stack`                                |
| `stackOffset`      | 堆叠基线 | 普通堆叠可选 `zero`、`normalize`、`diverging`、`center`、`overlap` |
| `stack`、`percent` | 便捷写法 | 分别选择堆叠、百分比堆叠；建议直接用 `arrangement` 表达意图        |

## 扩展用法

### 连续区间

直方图先通过 bin 变换生成箱的起点、终点和计数，再用 `x0`、`x1`、`y` 绑定这些字段。IntervalMark 绘制已有区间，分箱工作由变换完成。

如果宽度本身代表数据，可用 `width` 按行顺序累加非负权重。例如宽度对应 GDP、高度对应成本，各行会占据相邻的连续区间。切换示例的区间来源，可以比较显式端点与比例宽度；极坐标中它们都映射为角区间。

| 属性        | 含义     | 说明                                                      |
| ----------- | -------- | --------------------------------------------------------- |
| `x0`、`x1`  | 区间端点 | 必须成对提供，展开为 `bounds.x` 的 `extent`               |
| `y`         | 区间高度 | 直方图中通常绑定计数或聚合结果                            |
| `width`     | 比例宽度 | 按行累积；负值报错，不与 `x0` / `x1` 混用                 |
| `transform` | 数据准备 | 可在图元局部执行变换；示例用 PlotTransform 在图层之前分箱 |

### 二维区间

`bounds` 显式指定每个位置维度如何产生区间。以下五种形式描述边界来源：

| `kind`         | 含义     | 说明                                      |
| -------------- | -------- | ----------------------------------------- |
| `band`         | 分类槽   | 取该类别的完整带宽，可用 `group` 分成子带 |
| `span`         | 基线到值 | 从 `baseline`（默认 0）延伸到位置字段值   |
| `extent`       | 显式端点 | 用 `from` / `to` 字段指定上下界           |
| `proportional` | 累计权重 | 用 `field` 指定非负宽度字段，按行累积     |
| `full`         | 完整范围 | 覆盖该位置维度的映射范围                  |

热图用 `bounds={{ x: { kind: 'band' }, y: { kind: 'band' } }}` 构成二维分类网格。示例把第二维改为 `full` 后，每个区间占满另一维；多行具有相同第一维时，这些区域会重叠。切换极坐标，可观察矩形网格变成环形网格。

| 属性     | 含义         | 说明                                         |
| -------- | ------------ | -------------------------------------------- |
| `bounds` | 各维区间来源 | 显式覆盖默认的 x band / y span 推断          |
| `x`、`y` | 位置字段     | 热图中都绑定分类字段                         |
| `color`  | 数值着色     | 将单元格的数值映射为颜色；关闭后使用统一填充 |

### 饼图与环图

`angle` 绑定份额字段，按行累积为角区间，半径方向占满范围。在极坐标上设置 `innerRadius` 即可形成环图；它是坐标配置，不是 IntervalMark 属性。

`padAngle` 在相邻扇区之间留出角度间隔，`pull` 沿扇区中线向外平移。示例提供饼图、环图和突出扇区预设，也可以直接调整各项参数。

| 属性       | 含义     | 说明                                     |
| ---------- | -------- | ---------------------------------------- |
| `angle`    | 份额字段 | 饼图 / 环图便捷入口，使用极坐标          |
| `padAngle` | 角向间隔 | 单位为度；在区域投影之前收缩角区间       |
| `pull`     | 外拉距离 | 非负绘图单位，可绑定字段或常量           |
| `label`    | 扇区标签 | 使用节点标签配置，绑定来源字段或指定内容 |

## 错误与限制

- `x0` / `x1` 必须配对，且不能与横向柱或系列排列混用。
- `width` 不能与显式 `bounds`、`x0` / `x1` 或系列排列配置混用。复杂排布可以预计算端点，再使用 `extent`。
- `angle` 不能与 `x` / `y`、`x0` / `x1`、`width`、`direction`、堆叠或 `bounds` 混用。
- 显式 `bounds` 不与 `direction` 混用；直接通过各维边界表达方向。堆叠需要 `group` 或 `series` 标识各段，`normalize-stack` 不接受额外 `stackOffset`。
- `interpolation` 和 `pull` 的显式配置仅支持 polar2D。自定义坐标系必须提供 `projectCell` 才能绘制区间。
- 位置映射无效或投影几何不可渲染时会跳过；`extent` 的端点字段必须是有限数值，否则报错。比例宽度为负、累计溢出或外拉距离为负 / 非有限数也会报错。
- `resolveLabel` 是运行时回调，需要图元 `id`，不会序列化到 IR。区域形状由投影生成，不能把 Node 的全部几何能力当作 IntervalMark 属性使用。

## 实现原理

### 区间解析

三种图元对坐标系的使用范围不同。PointMark 主要投影定位，点的形状和尺寸仍在绘图空间中表达；方向可另行对齐坐标系。PathMark 投影连接路径，连续角度下的线可以沿极坐标弯曲。IntervalMark 投影整个区域，包括它的边界和内部：矩形区间可以变成扇区。PathMark 表达连接线，IntervalMark 表达区间面；闭合路径也可以填充，但区域来源仍由路径的闭合方式决定。

<ComponentPreview files="interval-resolution-flow" hideCode type="flow" size="md" />

便捷输入先归一化：普通柱得到分类 `band` 与数值 `span`；`x0` / `x1` 变成 `extent`；`angle` 生成累计角度端点与另一维的 `full`。系列排列会准备分组子带或堆叠变换。随后按比例尺把每行各维的边界组成 Cell，即“每个位置角色对应一对起止值”的逻辑区域。

坐标帧的 `projectCell` 接收 Cell，返回矩形、扇区或轮廓几何。IntervalMark 再把几何装配成 Node，附加样式、数据标签和可引用锚点，交给后续编译与渲染。

下面跟踪同一个区间，按三个几何阶段理解投影。上排是笛卡尔坐标的矩形，下排是极坐标的环形扇区；各列的区间端点保持不变。

<ComponentPreview files="interval-projection" hideCode type="illustration" size="xxl" />

1. **确认坐标轴法向**：在各区间端点处，确定垂直于轴切线的局部方向。橙色箭头表示 x / 角度轴的法向，蓝色箭头表示 y / 半径轴的法向。
2. **沿辅助边界确定区域**：笛卡尔坐标的辅助边界是水平线和竖直线，围出矩形。极坐标的角度端点对应径向射线，半径端点对应同心圆弧，围出环形扇区。半径轴的法向只给出圆弧在该处的切向，不能一直沿直线延伸。
3. **在区域内绘制**：确定区域后应用填充、描边与圆角。图中保留原始辅助边界，便于比较圆角如何修饰转角；区间端点没有改变。描边以边界为中心，因此较粗描边仍可能伸到区域外。

这些辅助线用于解释几何关系。当前实现直接用 Cell 的区间端点计算矩形或扇区，并不实际构造法向或求辅助线交点；圆角由投影后生成的形状处理。下排采用 `polar` 弧形边界。
