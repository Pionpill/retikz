Visual channels in `encodings` bind fields; fixed visual values belong to `properties`. Positions use `{ field }`, `{ value }`, or `{ edge }`, with scales selected by coordinate roles. Supply consecutive roles: `x`, `x/y`, or `x/y/z`; z cannot appear without y.
