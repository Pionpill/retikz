---
title: Scales
description: Data defines mathematical mappings; Plot channels own defaults, attribute constraints, axes, and legends.
---

A scale maps a data domain to an output range. [Data scales](/viz/data/scale) supply the algorithms. Plot channels select defaults and consume the results as positions, colors, sizes, opacity, or shapes.

## Positions and mark attributes

| Consumer                                                  | Responsibility                                        | Configuration                                                                    |
| --------------------------------------------------------- | ----------------------------------------------------- | -------------------------------------------------------------------------------- |
| [Position scales](/viz/plot/scale/position)               | Coordinate projection, axes, grids, and layout ranges | Coordinate roles reference named scales; React also provides PlotScale dimension |
| [Mark attribute mapping](/viz/plot/scale/mark-attributes) | Color, size, opacity, stroke width, and shape         | A field string or `{ field, scale }` in encodings                                |

Positions have a separate page because they also affect axes and layout. Color is one use of mark attribute mapping, not a separate mathematical scale family. The same binning algorithm can output colors or sizes; each channel checks whether those outputs are suitable.

Fixed visual properties bypass scales. Field strings use channel defaults. An explicit scale reference takes precedence, and an unknown name is an error. Opacity factors bind separately through `encodings.opacity.overall / fill / stroke`.

## Defaults

| Field type  | Position   | Color      |
| ----------- | ---------- | ---------- |
| continuous  | linear     | sequential |
| temporal    | time (UTC) | sequential |
| categorical | band       | ordinal    |

Size uses sqrt to map nonnegative magnitudes to radii. Opacity and stroke width use linear mappings with their own ranges. Shape assigns the theme's shapes to categories. Attributes that directly consume numbers, such as rotation, do not start normalizing values automatically.

Supported mappings depend on both input semantics and output constraints. Numeric output alone does not grant position compatibility: continuity, baseline permission, and layout requirements must be declared by the consumer. Marks and guides use the resolved mapping; hiding a legend does not change it.

## Extensions and next steps

Define new algorithms with Data's `defineScale` and pass them through `definitions.scales`. Plot has no second mathematical definition API. Existing channels can consume suitable new algorithms directly. Define a [custom channel](/viz/plot/channel/custom-channel) when adding attribute delivery or position consumption semantics.
