---
title: 比例尺契约
description: 查询 Plot 的连续、离散、径向、颜色与自定义比例尺 schema。
---

比例尺是数据值到位置或视觉值的具名映射。坐标角色通过坐标操作引用位置比例尺，颜色等非位置通道通过编码的 `scale` 字段引用。

## ScaleOperationSchema

<ZodSchema name="ScaleOperationSchema" description="内置比例尺或运行时注册自定义比例尺的联合。" />

## 连续位置比例尺

连续位置比例尺共用 `domainPadding` 和 `singleValueSpan`：推断 domain 时默认保留少量边界，显式 domain 则默认不扩展。
