---
title: Coordinate Composition
description: Coordinate composition organizes dual axes, data facets, and shared tracks inside one Plot while preserving clear relationships between regions.
---

A chart sometimes needs different units in one plot area, small multiples split by category, or several metric tracks aligned to one time axis. Coordinate composition provides three direct structures: extra axes, `<Facet>`, and `<Scaffold>` with shared tracks.

## Choose a Structure First

| Relationship in your data                  | Recommended structure | Why it fits                                           |
| ------------------------------------------ | --------------------- | ----------------------------------------------------- |
| Layers overlap but use different units     | Dual axes             | Keep one plot area and select an axis per layer       |
| Rows split by region, product, or category | Facet                 | Group rows and generate panels automatically          |
| Metrics align along one time/category axis | Shared tracks         | Share one direction and divide the other into bands   |
| Charts are independent                     | Multiple Plots        | Let an outer layout place them; no composition needed |

## Dual Axes

Each direction has one default axis. Only an extra axis needs an `id`; a mark selects it with `xAxisId` or `yAxisId`. Layers can then share one direction while using different units in the other.

This axis-id shortcut only supports `cartesian2D`. Polar angle and radius are not independent top/bottom or left/right axes; use the `<Scaffold>` / `<Track>` structure below when composing several polar regions.

### Two Y-Axes

Temperature uses the default y-axis, while rainfall uses the right-side `rainfall` axis. Use the data panel to compare their different magnitudes.

  size="md"
  caption="Both lines share the day x-axis; the rainfall layer selects the right y-axis with yAxisId."

| Goal                   | Configuration                                 | Result                         |
| ---------------------- | --------------------------------------------- | ------------------------------ |
| Declare another y-axis | `<Axis id="rainfall" dimension="y" ... />`    | Create a selectable y-axis     |
| Place it on the right  | `placement={{ kind: 'side', side: 'right' }}` | Render it beside the plot area |
| Use it for a layer     | `yAxisId="rainfall"`                          | Draw that layer in its range   |

## Facets

A facet splits data into panels by field values. Put axes and marks inside `<Facet>` to reuse them in every panel; each panel receives only its matching rows.

### Facet Playground

Start with a single row of facets, then switch to a row-column grid. In grid mode, you can keep missing combinations and compare a shared y range with independent panel ranges.

<ComponentPreview
  files={['coordinate-composition-facet', 'coordinate-composition-facet.data.ts']}
  size="lg"
  caption="The data omits P2 + T2; change the empty-panel policy to hide or keep that panel."
/>

| Goal                            | Configuration                               | Effect                                       |
| ------------------------------- | ------------------------------------------- | -------------------------------------------- |
| Split into columns only         | `column={{ field: 'product' }}`             | Create one row of small charts               |
| Split into rows and columns     | Add `row={{ field: 'tier' }}`               | Create a two-dimensional panel grid          |
| Keep combinations without data  | `empty="show"`                              | Preserve empty panels from explicit order    |
| Give each panel its own y range | `resolve={{ scale: { y: 'independent' } }}` | Fill each panel despite different magnitudes |
| Show row and column headers     | `header={{ row: true, column: true }}`      | Label each panel's groups                    |

By default, combinations without rows are hidden and the same direction shares one range across panels, making heights directly comparable.

### Multi-Level Facets

`row` and `column` can also receive arrays of field configurations. Array order defines the hierarchy from outer to inner, which fits nested dimensions such as region then channel.

  size="lg"
  caption="Columns group first by region and then channel; rows group first by business and then metric."

## Shared Tracks

Shared tracks fix the scale and axis for one direction, then divide the other direction into bands. `<Scaffold>` owns the shared parts, while each `<Track>` contains its local axis and marks.

### Cartesian Tracks

Three metrics share the trading-day x-axis and draw in separate vertical spaces, which fits operational metrics that must stay time-aligned.

<ComponentPreview
  files={['coordinate-composition-tracks', 'coordinate-composition-tracks.data.ts']}
  size="lg"
  caption="Trend, drawdown, and signal align to the same day; supporting data starts collapsed to keep the track structure prominent."
/>

The key declaration is `<Scaffold sharedRoles={['x']}>`. Put the shared x-axis in `Scaffold`, each local y-axis and mark in its `<Track>`, and use the band's `start` / `end` values to assign vertical space.

### Polar Tracks

Shared tracks also work with `polar2D`. Several radial tracks then share angular categories, while each track occupies a different radius band.

<ComponentPreview
  files={['coordinate-composition-tracks-polar', 'coordinate-composition-tracks-polar.data.ts']}
  size="lg"
  caption="Journey areas share angular positions; signal, capacity, and outer sectors use separate radial bands."
/>

The container relationship stays the same after changing coordinates: the shared axis remains in `<Scaffold>`, and local marks remain in their `<Track>`.

## Public Types

All three Props types are public exports of `@retikz/plot-react`. This table keeps only the fields most useful when assembling coordinate structures.

| Type            | Key fields                                                                   | Responsibility                                |
| --------------- | ---------------------------------------------------------------------------- | --------------------------------------------- |
| `FacetProps`    | `id`, `row`, `column`, `empty`, `header`, `resolve`, `spacing`, `children`   | Declare facet panels generated from data      |
| `ScaffoldProps` | `id`, `coordinate`, `sharedRoles`, `frame`, `resolve`, `spacing`, `children` | Declare shared roles, coordinates, and tracks |
| `TrackProps`    | `id`, `band`, `view`, `order`, `coordinate`, `header`, `children`            | Declare one track's band and local content    |
