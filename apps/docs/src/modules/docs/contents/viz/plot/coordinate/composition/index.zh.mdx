---
title: 坐标组合
description: 坐标组合在一张 Plot 中组织双轴、数据分面与共享轨道，让多组尺度或多个对齐区域保持明确关系。
---

一张图有时需要同时表达不同单位、按类别拆成多个小图，或让多条指标轨道共享同一条时间轴。坐标组合提供三种直接写法：额外坐标轴、`<Facet>` 分面和 `<Scaffold>` 共享轨道。

## 先选择结构

| 你的数据关系                   | 推荐结构  | 适合原因                           |
| ------------------------------ | --------- | ---------------------------------- |
| 图层重叠，但某个方向单位不同   | 双轴      | 保留一个绘图区，只为图层选择不同轴 |
| 按地区、产品等字段拆成小图     | 分面      | 自动分组数据并生成面板             |
| 多项指标要沿同一时间或类别对齐 | 共享轨道  | 共享一个方向，另一个方向分成多条带 |
| 图表彼此独立                   | 多个 Plot | 不需要坐标组合，交给外层布局排列   |

## 双轴

每个方向都有一个默认轴。只有新增的轴需要 `id`；mark 通过 `xAxisId` 或 `yAxisId` 选择它。这样可以让图层共享一个方向，同时在另一个方向使用不同单位。

这组轴 id 快捷绑定只支持 `cartesian2D`。极坐标中的角度与半径不是上下左右两套独立坐标轴；需要组合多个极坐标区域时，使用后文的 `<Scaffold>` / `<Track>`。

### 两个纵轴

温度使用默认纵轴，降雨量使用右侧的 `rainfall` 纵轴。数据面板可以用来对照两个指标的量级。

<ComponentPreview
  files={['coordinate-composition-scopes', 'coordinate-composition-scopes.data.ts']}
  size="md"
  caption="两条线共享 day 横轴；降雨图层用 yAxisId 选择右侧纵轴。"
/>

| 要做什么     | 写法                                          | 结果                   |
| ------------ | --------------------------------------------- | ---------------------- |
| 声明额外纵轴 | `<Axis id="rainfall" dimension="y" ... />`    | 创建可引用的纵轴       |
| 放到右侧     | `placement={{ kind: 'side', side: 'right' }}` | 轴显示在绘图区右侧     |
| 让图层使用它 | `yAxisId="rainfall"`                          | 该图层按降雨量范围绘制 |

### 两个横轴

完成线使用底部的经过天数，预测线使用顶部的日历日期。两条线仍共享完成度纵轴。

## 分面

分面按数据字段自动拆出多个面板。把轴和 mark 写在 `<Facet>` 内部，它们会在每个面板中复用，并只接收该面板对应的数据行。

### 分面试验场

先尝试单行分面，再切换为行列网格。网格模式下可以保留缺失组合，并比较统一纵轴范围与各面板独立范围。

<ComponentPreview
  files={['coordinate-composition-facet', 'coordinate-composition-facet.data.ts']}
  size="lg"
  caption="数据中没有 P2 + T2 组合；切换空组合策略可以观察该面板是隐藏还是保留。"
/>

| 目标               | 配置                                        | 说明                           |
| ------------------ | ------------------------------------------- | ------------------------------ |
| 只按列拆分         | `column={{ field: 'product' }}`             | 生成一排小图                   |
| 同时按行列拆分     | 再加 `row={{ field: 'tier' }}`              | 生成二维面板网格               |
| 保留无数据组合     | `empty="show"`                              | 按显式顺序保留空面板           |
| 各面板独立纵轴范围 | `resolve={{ scale: { y: 'independent' } }}` | 让量级差异大的面板填满各自空间 |
| 显示行列标题       | `header={{ row: true, column: true }}`      | 标出每个面板所属分组           |

默认情况下，缺少数据的组合会被隐藏，同一位置方向的范围会在面板间统一，便于直接比较高低。

### 多级分面

`row` 和 `column` 也可以接收字段配置数组。数组顺序决定从外到内的分组层级，适合“地区 → 渠道”这类嵌套维度。

## 共享轨道

共享轨道把同一方向的尺度和坐标轴固定下来，再把另一方向切成多条带。`<Scaffold>` 管理共享部分，`<Track>` 放每条轨道自己的轴和 mark。

### 直角坐标轨道

三个指标共享交易日横轴，各自在独立纵向空间中绘制，适合时间对齐的运行指标。

<ComponentPreview
  files={['coordinate-composition-tracks', 'coordinate-composition-tracks.data.ts']}
  size="lg"
  caption="趋势、回撤和信号沿同一交易日对齐；背景数据默认收起，避免遮挡轨道结构。"
/>

关键写法是 `<Scaffold sharedRoles={['x']}>`。共享横轴写在 `Scaffold` 中，每条局部纵轴和 mark 写在对应的 `<Track>` 中；每条轨道占据的起止比例由 `band.start` / `band.end` 决定。

### 极坐标轨道

共享轨道也能使用 `polar2D`。此时多条径向轨道共享角度分类，每条轨道占据不同半径区间。

<ComponentPreview
  files={['coordinate-composition-tracks-polar', 'coordinate-composition-tracks-polar.data.ts']}
  size="lg"
  caption="各业务环节共享角度位置；信号、容量和外环扇区分别使用不同半径带。"
/>

坐标形态变化后，容器关系不变：共享轴仍放在 `<Scaffold>`，局部图形仍放在对应 `<Track>`。

## 公开类型

下面三个 Props 类型都从 `@retikz/plot-react` 公开导出。表格只列组织坐标结构时最常查的字段。

| 类型            | 关键字段                                                                     | 职责                               |
| --------------- | ---------------------------------------------------------------------------- | ---------------------------------- |
| `FacetProps`    | `id`、`row`、`column`、`empty`、`header`、`resolve`、`spacing`、`children`   | 声明按数据字段生成的分面面板       |
| `ScaffoldProps` | `id`、`coordinate`、`sharedRoles`、`frame`、`resolve`、`spacing`、`children` | 声明共享角色、坐标与多条轨道的骨架 |
| `TrackProps`    | `id`、`band`、`view`、`order`、`coordinate`、`header`、`children`            | 声明单条轨道的占位区间与局部内容   |
