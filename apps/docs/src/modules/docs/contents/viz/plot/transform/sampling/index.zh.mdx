密度与趋势变换从观测数据生成采样行，再由路径图元连接这些采样点。接入与作用域见 [transform · 变换](/viz/plot/transform)；本页关注结果的绘制，算法和完整参数由 Data 说明。

## 密度

`density` 从连续样本生成采样位置与密度值。本例将 `densityX` / `density` 绑定到路径的 `x` / `y`，按组绘制密度曲线。

| 参数          | 本例用途与约束                                       |
| ------------- | ---------------------------------------------------- |
| `field`       | 本例读取 `value` 作为观测值。                        |
| `groupBy`     | 本例使用 `group` 分别估计密度。                      |
| `bandwidth`   | 自动规则或显式数值；显式带宽较小会保留更多局部起伏。 |
| `sampleCount` | 控制输出采样点数量。                                 |
| `xAs`         | 采样位置输出名，本例为 `densityX`。                  |
| `densityAs`   | 密度输出名，本例为 `density`。                       |

示例固定横轴为 1–10，纵轴为 0–0.7。路径按 `densityX` 排序，并闭合到零基线；闭合与填充是图元配置。

## 趋势

`smooth` 拟合观测值并生成预测采样行。本例使用线性拟合；原始点保留，趋势路径和空心采样点分别消费局部变换的结果。

| 参数          | 本例用途与约束                                 |
| ------------- | ---------------------------------------------- |
| `x`           | 本例读取 `time` 作为自变量。                   |
| `y`           | 本例读取 `value` 作为观测值。                  |
| `groupBy`     | 本例使用 `series` 分别拟合。                   |
| `method`      | 本例固定为 `{ kind: 'linear' }`。              |
| `sampleCount` | 控制预测采样点数量，不改变线性拟合模型。       |
| `extent`      | 省略时使用观测范围，本例也可扩展到 `[-1, 5]`。 |
| `xAs`         | 采样位置输出名，本例为 `trendX`。              |
| `yAs`         | 预测值输出名，本例为 `trendY`。                |
