---
title: 坐标系
description: 坐标系决定数据值如何投影到画布：二维负责平面与极坐标，一维负责单轴数据，三元负责三分量配比，自定义坐标系把投影函数交给运行时扩展。
---

坐标系是 `<Plot>` 把字段值放到画布上的最后一步。比例尺先把数据值映射到连续或离散空间，坐标系再决定这些值落成直线、圆周、扇区、三角形内部的点，还是自定义投影下的曲线位置。

如果只想给图加刻度、标签或网格，看[坐标轴](/viz/plot/guide/axis)；如果想理解 `coordinate` 为什么能把同一个 mark 从平面图变成径向图、rug、三元图，就从这里开始。

## 职责一览

| 主题         | 坐标系                          | 职责                         | 适合场景                         |
| ------------ | ------------------------------- | ---------------------------- | -------------------------------- |
| 二维坐标系   | `cartesian2D` / `polar2D`       | 处理常规 x/y 图与极坐标图    | 柱、折线、面积、饼图、环图、雷达 |
| 一维坐标系   | `cartesian1D` / `polar1D`       | 只投影一个位置通道           | rug、timeline、周期事件点        |
| 三元坐标系   | `ternary2D`                     | 把 x/y/z 三分量投影到三角形  | 成分比例、三方此消彼长的数据     |
| 自定义坐标系 | `{ type: 'bridge', ...config }` | 用运行时定义接入自己的投影   | 曲线轴、特殊空间、实验性投影     |
| 坐标组合     | `composition`                   | 在一张图里组织多个坐标 scope | 双轴叠加、分面、共享轨道         |
