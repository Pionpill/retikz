title: coordinate · 坐标系

坐标系决定图形的空间形态。比例尺先把字段值转换为可绘制的位置，坐标系再把这些位置投影到直线、平面或圆周中。

本组文档围绕三个问题展开：一个位置字段或两个位置字段怎样定位，多个图层或绘图区怎样组织，以及内置投影不够用时怎样扩展。通常先选择投影，再决定是否需要坐标组合。

## 职责一览

| 主题         | 职责                             | 适合场景                     |
| ------------ | -------------------------------- | ---------------------------- |
| 维度坐标系   | 将一个或两个位置维度投影到画布   | 点、线、区间、沿线或圆周事件 |
| 坐标组合     | 在一张 Plot 中组织多个坐标区域   | 双轴、分面、共享轨道         |
| 自定义坐标系 | 注册新的角色集合、投影与坐标能力 | 内置坐标无法表达的空间映射   |

## 投影与组合

维度坐标系关注单个绘图区中的位置。二维直角坐标把两个位置维度映射为水平与垂直位置，二维极坐标则映射为角度与半径；一维坐标只需要一个位置字段，适合沿直线或圆周排列事件。选择哪种投影，取决于数据关系适合怎样在空间中表达。

坐标组合关注多个图层或区域之间的关系。双轴让同一绘图区中的图层使用不同单位，分面按数据字段拆出多个小图，共享轨道则让多项指标沿同一方向对齐。各区域中的点、路径和区间仍由[图元](/viz/plot/mark)表达。

例如，展示一天的温度与降雨时，可以先用直角坐标沿时间排列数据，再用双轴分别表示温度和雨量。要比较多个城市，可以按城市分面；要把温度、雨量分别放在上下区域并对齐时间，则可以使用共享轨道。

## 选择与阅读顺序

从[维度坐标系](/viz/plot/coordinate/dimension)开始，了解四种内置投影及其参数；需要双轴、分面或共享轨道时，再阅读[坐标组合](/viz/plot/coordinate/composition)。只有目标空间无法由内置投影表达时，才需要[自定义坐标系](/viz/plot/coordinate/custom-coordinate)，声明位置角色、投影方式并注册到 Plot。

[比例尺](/viz/plot/scale)负责数据值到位置值的映射；[坐标轴](/viz/plot/guide/axis)负责刻度、标签和网格的呈现。调整值域、刻度或网格时，从对应章节入手，无需重新定义坐标系。
