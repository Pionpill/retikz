---
title: 坐标系
description: 坐标系决定数据如何落到直线、平面或圆周中，并支持在一张图里组合多组坐标区域。
---

坐标系决定图形的空间形态。比例尺先把字段值转换为可绘制的位置，坐标系再把这些位置投影到直线、平面或圆周中。

如果只想调整刻度、标签或网格，请看[坐标轴](/viz/plot/guide/axis)；如果要接入新的投影方式，请看[自定义坐标系](/viz/plot/coordinate/custom-coordinate)。

## 职责一览

| 主题       | 职责                             | 适合场景                   |
| ---------- | -------------------------------- | -------------------------- |
| 二维坐标系 | 把 x / y 两个位置维度投影到平面  | 柱、折线、饼图、雷达       |
| 一维坐标系 | 把一个位置维度投影到直线或圆周   | rug、时间线、周期事件点    |
| 坐标组合   | 在一张 Plot 中组织多个坐标区域   | 双轴、分面、共享轨道       |
| 自定义坐标 | 注册新的角色集合、投影与坐标能力 | 内置坐标无法表达的空间映射 |
