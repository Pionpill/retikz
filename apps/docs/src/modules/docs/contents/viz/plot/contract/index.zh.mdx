description: 查询 @retikz/plot 公开 IR 的 JSON schema，覆盖 Plot 根、编码、变换、图元、比例尺、坐标系、辅助、布局、图层与主题。
---

这一分组是 Plot Tier 2 IR 的数据契约。页面直接源自 `@retikz/plot` 导出的 Zod schema，用于生成 JSON、校验外部输入、构建 LLM Tool schema，以及实现自定义 Definition。

> Plot IR 只保存 JSON-safe 的语法声明和数据引用；实际 dataset 在 lowering 时注入，不进入 IR。

## 职责一览

| 主题       | 职责                             | 何时查阅                         |
| ---------- | -------------------------------- | -------------------------------- |
| Plot       | 根规格、坐标视图与组合           | 生成或校验整份 PlotSpec          |
| Encoding   | 字段、常量与通道绑定             | 把数据列映射到位置和视觉变量     |
| Transform  | Plot 领域的有序数据变换          | 声明堆叠、分箱、密度、趋势等操作 |
| Mark       | 图元、关系、参考线与路径闭合     | 选择几何输出及其精确配置         |
| Scale      | 位置、序数、径向和颜色比例尺     | 校验 domain / range 与比例尺参数 |
| Coordinate | 一维、二维与自定义坐标操作       | 确定位置角色与比例尺归属         |
| Guide      | 坐标轴、网格、刻度、标题与图例   | 配置辅助信息和精确组件           |
| Layout     | 外边距、标签放置与空间预留       | 控制 Plot 外框及静态文本         |
| Layer      | 语义图层的 zIndex 覆盖           | 调整 lowering 生成图元的叠放顺序 |
| Theme      | 背景、字体、轴、图例与色板默认值 | 创建 JSON-safe 的整图视觉默认值  |
