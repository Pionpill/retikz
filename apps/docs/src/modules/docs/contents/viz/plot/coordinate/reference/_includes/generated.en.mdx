Coordinate operations define positional roles and scale ownership. Two-dimensional coordinates consume `x / y`; one-dimensional coordinates consume only `x`; the selected coordinate Definition maps those roles into geometry.

React / Vanilla authoring preserves omitted fields. The single coordinate schema declares the `polar2D` defaults: start angle `0`, end angle `360`, and inner-radius fraction `0`. Calling `parse()` materializes these defaults; Plot coordinate resolution reuses them without rewriting authored configuration.

**Position projection constraints**

A frame that supports Position Adjustment splits placement into two capabilities from the same projection model. `mapRoles(values)` performs position-scale mapping only, and `projectMappedRoles(values)` projects that mapped role tuple to screen space. `projectRoles(values)` remains the ordinary composed entry.

| Capability           | Purpose                                                        |
| -------------------- | -------------------------------------------------------------- |
| `roleScales`         | Read final `PositionScale`, range, bandwidth, and step by role |
| `mapRoles`           | Raw role values → scale-output tuple                           |
| `projectMappedRoles` | Scale-output tuple → screen position                           |
| `projectRoles`       | One-step composed projection without adjustments               |
| `placementBoundary`  | Cyclic roles, boundary normals, and glyph-to-role conversion   |

A custom coordinate can keep only `projectRoles` when placement is unused. Point placement requires both split projection functions; automatic containment additionally requires `roleScales` and `placementBoundary`, and missing capabilities fail loudly.

## Position projection

#### <ApiSourceLink label={"CoordinateFrame"} path={"packages/viz/plot/src/contract/coordinate/types.ts"} startLine={28}>CoordinateFrame</ApiSourceLink>

The coordinate layer projects scale outputs to 2D points. Built-in Cartesian and polar frames and registered custom frames share this contract. Built-in frames add specialized fields and can be narrowed using provider guards.
