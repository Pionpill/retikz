title: axis · 坐标轴
description: 用 <PlotAxis> 解释位置 scale：为 cartesian 或 polar 坐标系绘制轴线、刻度、标签和网格。
---

`<PlotAxis>` 是位置 scale 的可视化身。`dimension` 选择要解释的坐标维度：cartesian 使用 `x` / `y`，polar 使用 `x`（角向）/ `y`（径向）。维度与坐标系不匹配时会直接报错。

`<Plot>` 不会自动补轴。需要哪条轴，就在 `<Plot>` 中显式声明对应的 `<PlotAxis>`。轴线、刻度、刻度文字、标题和网格都是同一条 PlotAxis guide 的配置槽位。

## 接入方式

从 `@retikz/plot-react` 导入组件，用子组件声明图元、比例尺与辅助。

```tsx
import { Plot, PlotAxis, PlotScale, PointMark } from '@retikz/plot-react';
import { createRoot } from 'react-dom/client';

const rows = [
  { gdp: 400, life: 76, region: 'A' },
  { gdp: 900, life: 81, region: 'B' },
  { gdp: 1600, life: 84, region: 'A' },
];

createRoot(document.getElementById('plot')!).render(
  <Plot data={rows} width={360} height={220}>
    <PlotScale dimension="x" type="linear" domainPadding={{ kind: 'ratio', lower: 0.15, upper: 0.15 }} />
    <PlotScale dimension="y" type="linear" domainPadding={{ kind: 'ratio', lower: 0.15, upper: 0.15 }} />
    <PointMark encodings={{ position: { x: { field: 'gdp' }, y: { field: 'life' } } }} properties={{ size: 6 }} />
    <PlotAxis dimension="x" />
    <PlotAxis dimension="y" grid />
  </Plot>,
);
```

从 `@retikz/plot` 导入配置类型，将完整 IR 传给 React `Plot` 的 `spec`。

```tsx
import { Plot } from '@retikz/plot-react';
import type { IRPlot } from '@retikz/plot';
import { createRoot } from 'react-dom/client';

const rows = [
  { gdp: 400, life: 76, region: 'A' },
  { gdp: 900, life: 81, region: 'B' },
  { gdp: 1600, life: 84, region: 'A' },
];

const spec: IRPlot = {
  namespace: 'plot',
  type: 'plot',
  data: { reference: 'rows' },
  scales: [
    { type: 'linear', name: 'x', domainPadding: { kind: 'ratio', lower: 0.15, upper: 0.15 } },
    { type: 'linear', name: 'y', domainPadding: { kind: 'ratio', lower: 0.15, upper: 0.15 } },
  ],
  coordinate: { type: 'cartesian2D', x: 'x', y: 'y' },
  marks: [
    { type: 'point', encodings: { position: { x: { field: 'gdp' }, y: { field: 'life' } } }, properties: { size: 6 } },
  ],
  guides: [
    { type: 'axis', dimension: 'x' },
    { type: 'axis', dimension: 'y', grid: true },
  ],
};

createRoot(document.getElementById('plot')!).render(<Plot spec={spec} data={{ rows }} width={360} height={220} />);
```

## 基础用法

### 坐标系与轴职责

先从同一份数据和同一个 `<PathMark>` 出发。切换 `cartesian2D` / `polar2D` 时，`dimension="x"` 分别解释横向 / 角向位置，`dimension="y"` 分别解释纵向 / 径向位置；`grid` 仍属于生成它的 PlotAxis。

极坐标的角向维度为离散分类时，默认采用直弦连接，等值网格呈多边形。径向轴的轴线、刻度和标签使用相同投影，因此刻度对齐多边形边，而不是按外接圆半径继续延伸。显式使用 `interpolation: 'polar'` 时，仍按圆形投影。

## 扩展用法

### 刻度、标签与原点轴

掌握轴的基本职责后，再在笛卡尔坐标系中集中调整完整配置。连续轴场景覆盖 `ticks.interval`、`ticks.density` 以及独立的主 / 次网格来源；分类轴场景用于观察 `tickLabels.layout` 的旋转、隐藏和边界处理。

标签留白与避让使用 Core 的文字布局结果，字体、字重、换行和行高会参与测量。通过 `CompileOptions.measureText` 注入的宿主测量器同时服务 Plot 布局和最终文字绘制；未注入时沿用 Core 的默认测量。极坐标角向标签的半径预留、图例条目的文字间距也复用这条测量路径。

轴与图例标签显式使用 `em` 时，继承外层字号。例如外层字号为 `16`，`1.5em` 按 `24` 测量与绘制；Plot 不另设相对字号基准。

切到原点场景时，两条轴通过 `placement.kind="origin"` 穿过另一维的 0。这个摆放不会扩展 domain；`crossing` 控制交点标签，`line.arrow` 与 `ticks.endpoint` 分别控制端点箭头和附近刻度避让。

## 错误与限制

`dimension` 必须属于当前坐标系。原点轴及轴线端点箭头等笛卡尔配置不应套用到极坐标；原点轴不会自动扩展比例尺 domain，交叉值需要落在可见范围内。

### 刻度与网格来源

PlotAxis 先按 `ticks.values > ticks.interval > ticks.count` 的优先级生成候选 tick，再应用 `density` 得到可见 tick。网格默认复用这批结果；只有配置 `grid.ticks` 时才单独生成候选位置，因此网格密度可以独立于轴标签。`grid.includeDomain` 会在上述解析完成后追加缺失的 effective scale domain 首尾位置，并按最终投影坐标去重；它不会改变轴 tick，也不会为次网格自动追加端点。该字段的 guide 局部默认是 `false`，Theme 可以为已启用的 major grid 提供默认：未声明 style 的默认 baseline 对 x / y PlotAxis 为 `true`，本站注入的三个参考风格为 `false`。Theme 端点 token 不会单独启用 grid，guide 显式 boolean 最终优先。次网格仍从 `grid.minor.ticks` 生成，并过滤与主网格重合的位置。

### 语义图层

坐标轴默认位于 mark 之上，网格位于 mark 之下。`layer={{ zIndex }}` 只覆盖轴 scope 的层级；grid 始终使用独立网格层，避免背景线盖住数据。默认顺序是网格 `-300`、mark `0`、轴 `200`、Facet 标签 `300`、图例 `500`。
