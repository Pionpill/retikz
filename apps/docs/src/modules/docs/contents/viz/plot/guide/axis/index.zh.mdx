---
title: 坐标轴
description: 用 <Axis> 解释位置 scale：为 cartesian 或 polar 坐标系绘制轴线、刻度、标签和网格。
---

`<Axis>` 是位置 scale 的可视化身。`dimension` 选择要解释的坐标维度：cartesian 使用 `x` / `y`，polar 使用 `x`（角向）/ `y`（径向）。维度与坐标系不匹配时会直接报错。

`<Plot>` 不会自动补轴。需要哪条轴，就在 `<Plot>` 中显式声明对应的 `<Axis>`。轴线、刻度、刻度文字、标题和网格都是同一条 Axis guide 的配置槽位。

## 用法

```tsx
import { Axis, PathMark, Plot } from '@retikz/plot-react';
```

```tsx
<Plot data={rows}>
  <PathMark x="month" y="revenue" order="month" />
  <Axis dimension="x" />
  <Axis dimension="y" grid />
</Plot>
```

### 笛卡尔坐标轴试验场

掌握轴的基本职责后，再在笛卡尔坐标系中集中调整完整配置。连续轴场景覆盖 `ticks.interval`、`ticks.density`、`ticks.mark` 以及独立的主 / 次网格来源；分类轴场景用于观察 `tickLabels.layout` 的旋转、隐藏和边界处理。

切到原点场景时，两条轴通过 `placement.kind="origin"` 穿过另一维的 0。这个摆放不会扩展 domain；`crossing` 控制交点标签，`line.arrow` 与 `ticks.endpoint` 分别控制端点箭头和附近刻度避让。

### 刻度与网格来源

Axis 先按 `ticks.values > ticks.interval > ticks.count` 的优先级生成候选 tick，再应用 `density` 得到可见 tick。网格默认复用这批结果；只有配置 `grid.ticks` 时才单独生成候选位置，因此网格密度可以独立于轴标签。次网格从 `grid.minor.ticks` 生成，并过滤与主网格重合的位置。

### 语义图层

坐标轴默认位于 mark 之上，网格位于 mark 之下。`layer={{ zIndex }}` 只覆盖轴 scope 的层级；grid 始终使用独立网格层，避免背景线盖住数据。默认顺序是网格 `-300`、mark `0`、轴 `200`、整图文案 `400`、图例 `500`。

## API 参考

| 属性          | 类型                      | 默认值   | 描述                                                                                            |
| ------------- | ------------------------- | -------- | ----------------------------------------------------------------------------------------------- |
| `dimension`   | `AxisProps['dimension']`  | —        | 要解释的维度：cartesian / polar 使用 x / y；必须匹配当前坐标系                                  |
| `scale?`      | `PositionScaleType`       | 自动派生 | 位置 scale 快捷类型；等价于同维度的 `<Scale dimension="..." type="..." />`                      |
| `placement?`  | `AxisProps['placement']`  | 自动推断 | 轴线摆放；分支 `kind` 见 <ApiValues name="AxisPlacementKind" />；`origin` 仅适用于 cartesian    |
| `line?`       | `AxisProps['line']`       | 默认轴线 | 轴线样式与端点几何；`extent` 和 `arrow` 目前仅适用于 cartesian                                  |
| `crossing?`   | `AxisProps['crossing']`   | 正常刻度 | 交叉值处的 tick / label 策略；`label:'corner'` 可把共享原点标签移到角落                         |
| `ticks?`      | `AxisProps['ticks']`      | 默认刻度 | 候选 tick 来源、可见密度、端点避让和刻度标记外观                                                |
| `tickLabels?` | `AxisProps['tickLabels']` | `true`   | 刻度文字开关、格式和样式；显式 `rotate` 优先于 `layout.rotate`，`layout:false` 关闭自适应避让   |
| `title?`      | `AxisProps['title']`      | —        | 轴标题内容、间距、沿轴位置、方向和局部偏移                                                      |
| `grid?`       | `AxisProps['grid']`       | `false`  | 网格开关、样式和独立 tick 来源；`minor` 生成次网格，`applyTo/select` 控制组合或分面中的投放目标 |
| `layer?`      | `AxisProps['layer']`      | 轴层     | 覆盖轴 scope 的语义层级；不改变 grid 的背景层级                                                 |
| `id?`         | `AxisProps['id']`         | —        | 可选 guide 句柄，用于稳定标识轴及其派生网格                                                     |

### 关键对象字段

| 对象字段            | 类型                                                | 默认值           | 作用                                                                          |
| ------------------- | --------------------------------------------------- | ---------------- | ----------------------------------------------------------------------------- |
| `placement.kind`    | <ApiValues name="AxisPlacementKind" />              | 自动推断         | 选择自动、四边、坐标系原生边或笛卡尔原点轴                                    |
| `placement.side`    | `'top' \| 'right' \| 'bottom' \| 'left'`            | —                | `kind:'side'` 的必填四边位置                                                  |
| `placement.edge`    | `string`                                            | —                | `kind:'edge'` 的必填坐标系原生边 id                                           |
| `placement.origin`  | `string \| number`                                  | `0`              | `kind:'origin'` 时另一维的交叉数据值                                          |
| `ticks.values`      | `Array<string \| number>`                           | —                | 显式候选值，优先级高于 `interval` 和 `count`                                  |
| `ticks.interval`    | `{ kind:'number' \| 'time' \| 'category'; ... }`    | —                | 固定数值步长、UTC 时间单位或分类索引步长                                      |
| `ticks.count`       | `number`                                            | scale 默认       | 未提供 `values` / `interval` 时的目标候选数量                                 |
| `ticks.density`     | `{ kind:'all' \| 'sample'; ... }`                   | 全部候选         | sample 分支按 `maxCount` 或 `minGap` 抽稀可见 tick                            |
| `ticks.mark`        | `false \| { kind; ... }`                            | 线刻度           | 选择 line / 内置 shape / custom 标记；不与 `ticks.length` / `ticks.line` 同用 |
| `ticks.endpoint`    | `false \| { hideWhenArrow?; distance?; affect? }`   | 箭头端点自动避让 | 控制端点箭头附近隐藏刻度标记，`affect` 可把标签一并隐藏                       |
| `tickLabels.format` | `string`                                            | 自动格式         | 数值使用 d3-format，时间使用 UTC d3-time-format                               |
| `tickLabels.rotate` | `number`                                            | 自适应           | 固定旋转角；显式值优先于 `layout.rotate`                                      |
| `tickLabels.layout` | `false \| { rotate?; hide?; bounds?; sampleSize? }` | 自适应布局       | 控制自动旋转、重叠隐藏与轴范围边界处理                                        |
| `grid.ticks`        | `{ values?; interval?; count? }`                    | 复用可见轴 tick  | 为主网格指定独立候选来源                                                      |
| `grid.density`      | `{ kind:'all' \| 'sample'; ... }`                   | 全部网格候选     | 只抽稀网格，不改变轴 tick                                                     |
| `grid.minor`        | `false \| { ticks; density?; bandPosition?; ... }`  | `false`          | 用独立来源生成次网格，并自动移除与主网格重合的位置                            |
| `grid.applyTo`      | `'local' \| 'all' \| 'none' \| 'selected'`          | 组合策略         | 决定网格投放到当前视图、共享目标或显式选中目标                                |
| `grid.select`       | `{ view?; facet?; track? }`                         | —                | `applyTo:'selected'` 时必填，用 view / facet / track 条件选择目标             |

`coordinateView`、`facetId`、`scaffoldId` 和 `trackId` 是组合 / 分面流程用于定位轴归属的高级字段。普通单图无需设置；需要组合轴时请查看[坐标组合](/viz/plot/coordinate/composition)。

视觉样式分别写在 `line`、`ticks`、`tickLabels`、`title` 和 `grid` 中；例如 `dashPattern` / `dashOffset` 控制虚线，文字样式放在对应文本槽位，不需要额外的样式组件。
