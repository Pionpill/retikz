Guides are the explanatory layer of the graphic grammar. Marks draw the data; Axis and Legend tell readers what those positions, colors, sizes, or shapes mean.

## Responsibilities

| Component | Responsibility                                                 | When to use it                                     |
| --------- | -------------------------------------------------------------- | -------------------------------------------------- |
| Axis      | Explain positional scales with lines, ticks, labels, and grids | To explain x / y positions or show a grid          |
| Legend    | Explain non-positional scales with colors or graduated symbols | To explain color, size, opacity, or shape mappings |

## Topics

Choose the page by the visual channel you need to explain: axes for position, legends for other visual channels.
