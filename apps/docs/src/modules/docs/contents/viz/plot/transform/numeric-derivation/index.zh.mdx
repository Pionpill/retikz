## 派生区间

`derive-interval` 为每行生成下界和上界。`IntervalMark` 将输出字段绑定到 `bounds.y`，绘制任务区间或从基线开始的柱。

| 参数        | 本例用途与约束                                     |
| ----------- | -------------------------------------------------- |
| `startFrom` | 双字段模式的起点字段，与 `endFrom` 配合。          |
| `endFrom`   | 双字段模式的终点字段，与 `startFrom` 配合。        |
| `from`      | 单字段模式的终点值字段；本例在两种写法之间切换。   |
| `baseline`  | 单字段模式的固定起点；显式起止字段优先于这组配置。 |

## 数据抖动

`jitter` 在数据单位中扰动连续字段，帮助分开重叠点。本例只修改横向字段 `dose`，纵向响应值保持不变。

| 参数     | 本例用途与约束                           |
| -------- | ---------------------------------------- |
| `axis`   | 本例固定为 `'x'`，只扰动横向字段。       |
| `xField` | 本例读取并覆盖 `'dose'` 字段。           |
| `amount` | 控制数据空间中的扰动幅度，0 表示不扰动。 |
| `seed`   | 相同输入、幅度和种子产生相同结果。       |

## 堆叠

`stack` 按横向分组累加系列值，生成每行的上下边界。图元绑定 `y0` / `y1`，将同一季度的产品收入绘制为堆叠区间。

| 参数      | 本例用途与约束                                                                         |
| --------- | -------------------------------------------------------------------------------------- |
| `x`       | 本例使用 `quarter`，在每个季度内累加。                                                 |
| `y`       | 本例读取 `revenue` 作为累加值。                                                        |
| `groupBy` | 本例使用 `product` 标识各系列。                                                        |
| `offset`  | `zero` 普通累加；`normalize` 归一化堆叠；`center` 围绕零居中；`overlap` 每段从零开始。 |

## 归一化

`normalize` 将数值除以组内总和，写入占比字段。本例先生成 `share`，再堆叠这些占比，比较每季度或全部记录的收入构成。

| 参数      | 本例用途与约束                                          |
| --------- | ------------------------------------------------------- |
| `field`   | 本例读取 `amount` 作为归一化输入。                      |
| `as`      | 本例将占比写入 `share`，保留原值。                      |
| `groupBy` | 按季度计算各自总和；省略时使用全部记录的总和。          |
| `basis`   | `fraction` 输出 0–1 比例；`percent` 输出 0–100 百分比。 |
