Plot 将数据记录绘制为点、线或区间。你决定哪些字段控制位置、颜色和尺寸，并组合坐标轴、图例等辅助元素。这里按图形语法的组成部分组织文档；首次使用可从[简介](/viz/plot/introduction)与[快速开始](/viz/plot/get-start)进入。

## 职责一览

| 章节      | 职责                                         | 何时阅读                         |
| --------- | -------------------------------------------- | -------------------------------- |
| 通道      | 把字段或常量绑定到位置、颜色、尺寸等视觉属性 | 确定数据怎样表现在图上           |
| 变换      | 处理数据并形成绘图所需的结果                 | 绘图前需要派生、汇总或统计       |
| 图元      | 将记录绘制为点、路径、区间等形状             | 选择或叠加绘制形式               |
| 比例尺    | 将数据范围换算为位置或样式                   | 调整数值范围、分类顺序与颜色映射 |
| 坐标系    | 将位置映射到平面、极坐标或组合视图           | 改变图形的空间表达               |
| 辅助      | 用坐标轴与图例解释映射                       | 帮助读者读出数值和分类           |
| Plot 溯源 | 将绘制结果关联回数据及处理过程               | 解释某个图元为什么出现在这里     |
| API 参考  | 汇集字段契约和运行时入口                     | 查询准确的参数与调用方式         |

## 安装与使用

React 项目使用 `@retikz/plot-react`，普通 TypeScript 项目使用 `@retikz/plot-vanilla`。两种入口都可以独立生成图形，所需依赖、完整导入和挂载代码见[快速开始](/viz/plot/get-start)。需要保存或校验 JSON 配置时，再查阅 `@retikz/plot` 的[规格契约](/viz/plot/reference/plot)。

## 从哪里开始

先选择图元，再配置字段与通道。默认映射不能满足任务时，继续调整比例尺、坐标系和辅助元素；需要处理数据时再阅读变换。

若已确定具体图表类型，希望直接配置整张图，先看 [Chart](/viz/chart/introduction)。可复用的数据清洗与统计由 [Data](/viz/data/introduction) 提供；以单元格组织数据则使用 [Table](/viz/table)。
