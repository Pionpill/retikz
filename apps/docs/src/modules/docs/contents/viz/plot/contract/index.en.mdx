This section is the data contract for Plot Tier 2 IR. Each page is sourced directly from the Zod schemas exported by `@retikz/plot`, for JSON generation, external-input validation, LLM tool schemas, and custom Definition implementations.

> Plot IR stores only JSON-safe grammar declarations and data references. Dataset values are injected during lowering and never enter the IR.

## Responsibilities

| Topic      | Responsibility                                  | Consult it when                                 |
| ---------- | ----------------------------------------------- | ----------------------------------------------- |
| Plot       | Root spec, coordinate views, and composition    | Generating or validating a complete PlotSpec    |
| Encoding   | Field, constant, and channel bindings           | Mapping data columns to position and appearance |
| Transform  | Ordered Plot-domain data transforms             | Declaring stack, bin, density, or trend steps   |
| Mark       | Marks, relations, references, and path closure  | Selecting geometry and its exact configuration  |
| Scale      | Positional, ordinal, radial, and color scales   | Validating domains, ranges, and scale options   |
| Coordinate | 1D, 2D, and custom coordinate operations        | Defining positional roles and scale ownership   |
| Guide      | Axes, grids, ticks, titles, and legends         | Configuring guides and precise subcomponents    |
| Layout     | Padding, label placement, and space reservation | Controlling the plot frame and static text      |
| Layer      | Semantic-layer zIndex override                  | Adjusting generated primitive stacking          |
| Theme      | Background, text, axes, legends, and palettes   | Defining JSON-safe visual defaults              |
