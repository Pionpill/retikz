---
title: 位置比例尺
description: 位置比例尺把数值、时间和分类字段映射成坐标、长度或半径，并在默认线性映射不够时提供对数、对称对数、面积感知和分类位置选择。
---

位置比例尺回答「这个字段在画布上放到哪里、占多长或取多大半径」。`<Plot>` 会从字段类型推导 `linear`、`time` 或 `band` 默认值；当数据跨数量级、穿过零点、编码面积，或分类图元需要点位而非格宽时，再显式换 scale。

## 怎么选择

| 数据与任务                 | 推荐 scale       | 关键区别                         |
| -------------------------- | ---------------- | -------------------------------- |
| 普通连续数值               | `linear`         | 等距映射，也是默认值             |
| 全为正且跨多个数量级       | `log`            | 每个数量级占相同距离             |
| 非负值，需要弱化大值       | `sqrt`           | 开方后压缩大值差异               |
| 跨零且两端跨度很大         | `symlog`         | 零附近线性，两端对数             |
| 极坐标半径需要面积正比于值 | `radial`         | 允许 interval / 闭合面积使用基线 |
| 时间字段                   | `time`           | 刻度落在人类可读时间边界         |
| 分类柱状 / 分类折线        | `band` / `point` | 一格宽度 / 一个点位              |

`pow` 提供自定义幂指数，但当前 React `<PlotScale>` 不暴露该类型，需要写入完整 `IRPlot.scales`。

## 连续数值

`linear`、`log`、`sqrt` 与 `symlog` 共享同一张可交互图表。先在 controls 中选择数据，再切换 scale 并调整对应参数，可以直接观察映射变化。

<ComponentPreview
  size="lg"
  files={['scale-continuous', 'scale-continuous.data.ts']}
  caption="切换正值与跨零数据，比较四种连续位置 scale；log 可调底数，symlog 可调线性区，domain padding 控制数据与边界的留白。"
/>

| 类型                | 适合场景                 | 关键行为与参数                                                      |
| ------------------- | ------------------------ | ------------------------------------------------------------------- |
| `linear`<br />`log` | 普通连续值；正值跨数量级 | `log` 让每个数量级等距；`base` 默认 `10`，须大于 `1`，可用 `Math.E` |
| `sqrt`<br />`pow`   | 弱化大值；自定义幂指数   | `sqrt` 使用固定开方；`pow.exponent` 通过 full spec 配置             |
| `symlog`            | 跨零且跨度大的数值       | 零附近保持线性；`constant` 默认 `1`，调大可扩展线性区               |

`size` 通道也使用 `sqrt` 让点面积更接近数值比例，但它属于[内置通道](/viz/plot/channel/builtin)的大小映射，不由位置用的 `<PlotScale dimension>` 配置。

### 径向

`radial` 把值映射成半径，并让扇形或圆环的**面积**正比于值。它从零基线起算，专门服务极坐标径向值轴，因此可以配 interval 或 path closure；同为开方型映射的 `sqrt` 不允许这样使用。

  caption="选择数据分布，并排比较同一数值在 linear 下的半径线性与 radial 下的面积线性；两图共用最大半径。"

### 非线性 scale 与基线

`log`、`pow`、`sqrt`、`symlog` 不允许作为柱状、面积或 path closure 的值轴，因为这些图元的基线也参与映射；改用开放的 point / line，或保留线性值轴。`radial` 是明确的例外，它拥有从零起算的面积感知基线。

## 时间

`temporal` 字段的位置通道默认使用 `time`。它仍是连续映射，但刻度会落在月初、季度、整点等时间边界，标签也按时间格式化；把字段在 model 中声明为 `temporal` 后无需手写 `<PlotScale>`。

<ComponentPreview
  size="lg"
  files={['scale-time', 'scale-time.data.ts']}
  caption="横轴没有显式声明 PlotScale；model 中的 temporal 字段会自动派生 time scale，并把季度日期格式化到可读的时间边界。"

日期值可以是 ISO 字符串或时间戳，解析规则见[数据接入](/viz/data/model/intake)。时间字段绑定 `color` 时会自动派生连续的 `sequential` 色带，见[颜色比例尺](/viz/plot/scale/color)。

## 分类：band 与 point

分类字段没有连续数值顺序。默认 `band` 给每个类别一格宽度，适合柱状图；分类折线或散点只需要点位，应显式换成 `point`。

| 类型    | 摆放                       | 适合图元           |
| ------- | -------------------------- | ------------------ |
| `band`  | 每类一格，可提供格宽       | 柱状、热力单元     |
| `point` | 每类一个等距点，不提供格宽 | 分类折线、分类散点 |

<ComponentPreview
  size="lg"
  files={['scale-band', 'scale-band.data.ts']}
  caption="切换比例尺：band 为 interval 提供格宽，point 只为折线和散点提供等距点位；面板只显示当前类型对应的 padding。"
/>

分类折线可显式使用点位：

```tsx
<Plot data={rows} model={[{ name: 'segment', type: 'categorical' }]}>
  <PathMark x="segment" y="revenue" order="segment" />
  <PlotScale dimension="x" type="point" />
  <PlotAxis dimension="x" />
</Plot>
```

## 技术原理

位置 scale 在 lowering 时才拥有完整上下文。图中的 `derive` 先结合字段类型、图元结构与显式 `<PlotScale>` 选择类型；`validate` 检查字段兼容性、合法值域和基线约束；随后从绑定数据或显式配置解析 domain，并把坐标系提供的可用范围作为 range。

<ComponentPreview files="scale-position-flow" size="xs" hideCode />

最后得到的 scale 同时服务图元和 guide：连续 scale 产出数值坐标，`band` 额外提供格宽，`point` 只提供离散点位；Axis 再从同一个已解析 scale 生成 tick。这样图元位置、格宽和坐标轴不会各自维护一套映射。

## API 参考

React `<PlotScale>` 是常用位置类型的声明入口；`band` 可以由 interval 结构自动派生，也可以显式配置柱间距与外侧留白。`pow` 和完整 IR 字段写入 `IRPlot.scales`。`PlotAxis.scale` 是同维度常用类型的快捷入口。

| 属性               | 类型                                | 默认值            | 说明                                                                   |
| ------------------ | ----------------------------------- | ----------------- | ---------------------------------------------------------------------- |
| `dimension`        | `'x' \| 'y'`                        | —                 | 坐标维度；polar 中仍用 `x` / `y` 表示角向 / 径向                       |
| `type`             | `PlotScaleProps['type']`            | —                 | `linear`、`time`、`band`、`point`、`log`、`sqrt`、`symlog` 或 `radial` |
| `domain?`          | `PlotScaleProps['domain']`          | 从数据推断        | 连续输入范围，或 `band` / `point` 的有序分类列表                       |
| `domainPadding?`   | `PlotScaleProps['domainPadding']`   | 推断时 `5%`       | 连续 domain 两端的比例留白；显式 domain 默认不留白                     |
| `singleValueSpan?` | `PlotScaleProps['singleValueSpan']` | 按类型推断        | 单值 domain 展开时使用的最小跨度                                       |
| `base?`            | `PlotScaleProps['base']`            | `10`              | 仅用于 `log`，必须大于 `1`                                             |
| `constant?`        | `PlotScaleProps['constant']`        | `1`               | 仅用于 `symlog`，控制零附近线性区宽度                                  |
| `paddingInner?`    | `number`                            | `0.1`             | 仅用于 `band`；相邻 band 间距占 step 的比例，范围 `0..1`               |
| `paddingOuter?`    | `number`                            | 同 `paddingInner` | 仅用于 `band`；首尾外侧留白占 step 的比例，范围 `0..1`                 |
| `padding?`         | `number`                            | `0.5`             | 仅用于 `point`；首尾外侧留白占 step 的比例，范围 `0..1`                |
| `align?`           | `number`                            | `0.5`             | 用于 `band` / `point`；控制首尾留白在范围两端的分配，范围 `0..1`       |

完整 `IRPlotScale` 还允许给 scale 命名、显式设置输出 `range`，并配置 React DSL 没有暴露的 `pow.exponent`、`nice` 与 `clamp`。各变体和自定义 scale operation 都遵循这一公开 IR 契约；这些 `IRPlot*` 类型与 schema 从 `@retikz/plot` 导入。
