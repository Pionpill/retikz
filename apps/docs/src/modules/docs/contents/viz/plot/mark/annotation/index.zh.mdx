title: Annotation · 标注
description: 用显式点、路径和区间标记信息，位置可使用常量、数据字段或视图边界，并支持局部数据变换。

标注用于在绘图区域中用几何元素标记信息，例如目标点、参考线和背景区间。标注的几何绘制能力与几何图元相同，也分为 point、path、interval 三类。

标注的位置经过 Plot 的比例尺与[坐标系](/viz/plot/coordinate)投影。仅使用常量、且省略 `transform` 时，每个声明在当前视图中生成一个实例；位置绑定字段或显式提供 `transform` 时，每个结果行生成一个完整几何对象。三类入口如下：

| 几何         | React                | Vanilla              | Source IR                              |
| ------------ | -------------------- | -------------------- | -------------------------------------- |
| 单点或文字   | `PointAnnotation`    | `pointAnnotation`    | `type: 'point', kind: 'annotation'`    |
| 显式端点路径 | `PathAnnotation`     | `pathAnnotation`     | `type: 'path', kind: 'annotation'`     |
| 区间区域     | `IntervalAnnotation` | `intervalAnnotation` | `type: 'interval', kind: 'annotation'` |

## 接入方式

三种 Annotation 的位置都支持以下输入，可以在同一个几何中混合使用：

| 输入方式 | 写法                                   | 含义                                                                 |
| -------- | -------------------------------------- | -------------------------------------------------------------------- |
| 常量     | `50`、`'A'` 或 `{ value: 50 }`         | 数据空间中的固定位置，字符串始终是字面值                             |
| 数据字段 | `{ field: '字段名' }`                  | 读取当前结果行的字段                                                 |
| 视图边界 | `{ edge: 'start' }`、`{ edge: 'end' }` | 当前坐标角色最终映射范围的两端，跟随范围反转，不是数据最小值和最大值 |

局部 `transform` 与 Mark 使用相同声明，消费根级变换后的数据；在分面中消费当前分区。统计计算使用[聚合变换](/viz/data/transforms/aggregation-annotation)，输出字段再绑定到几何位置。局部变换不会改变兄弟图元的数据。

| 声明                          | 实例数量                             |
| ----------------------------- | ------------------------------------ |
| 常量或 edge，省略 `transform` | 当前视图中一个实例                   |
| 任意位置包含 `{ field }`      | 每个结果行一个实例                   |
| 显式 `transform`，包括 `[]`   | 每个结果行一个实例，即使位置都是常量 |

结果为空时，数据驱动的标注不生成图形。样式、文字和标签仍使用常量；字段只绑定位置。

下面的示例绑定空数组，并显式指定两轴的范围。它仍绘制一条参考线、一段背景区域和一个文字点；数据行数不决定标注数量。

import type { IRPlot } from '@retikz/plot';
import { Plot } from '@retikz/plot-react';

const spec: IRPlot = {

  type: 'plot',

  coordinate: { type: 'cartesian2D', x: 'x', y: 'y' },

    { type: 'linear', name: 'x', domain: [0, 100], domainPadding: 0 },
    { type: 'linear', name: 'y', domain: [0, 100], domainPadding: 0 },

    {
      type: 'interval',
      kind: 'annotation',
      bounds: {
        x: { from: 20, to: 40 },
        y: { from: { edge: 'start' }, to: { edge: 'end' } },
      },
      fill: '#dbeafe',
    },
    {
      type: 'path',
      kind: 'annotation',

## 点标注

点标注在指定位置绘制一个形状或一段文字。它沿用点图元的形状、外观与标签能力，位置可绑定数据字段，文字内容使用常量。使用 `text` 时文字本身就是点标注；使用 `label` 时文字附着在形状上，可以调整方向和间距。

Annotation 比较特殊的属性包括：

| 属性       | 作用                                                     |
| ---------- | -------------------------------------------------------- |
| `x`        | 第一个坐标角色的位置绑定                                 |
| `y`        | 第二个坐标角色的位置绑定                                 |
| `position` | 完整角色映射，与 `x`、`y` 简写互斥；自定义角色使用此形式 |

用“预设”切换几何形状与纯文本。几何形状支持尺寸与附着标签，纯文本支持字号调整。所有演示默认使用笛卡尔坐标，也可以切换连续角度或离散角度的极坐标：连续模式将横向位置的 0–100 换算为 0–360°，离散模式使用 A–F 分类。

## 路径标注

路径标注用 `from` 和 `to` 指定两个完整位置，适合参考线和两点之间的连接。两端都经过比例尺和坐标投影，描边与沿线标签沿用路径的绘制能力。

Annotation 比较特殊的属性包括：

| 属性         | 作用                                                            |
| ------------ | --------------------------------------------------------------- |
| `from`       | 起点的完整角色映射                                              |
| `to`         | 终点的完整角色映射                                              |
| `connection` | 默认 `coordinate` 沿坐标系连接；`straight` 直接连接投影后的两端 |

默认显示笛卡尔坐标中的水平连接。切换连续角度的极坐标后，可以切换连接方式，观察蓝线如何从圆弧变为弦，橙色端点保持不变。离散角度下，沿坐标系连接会依次经过中间类别，例如 A→C 经过 B；直线连接只连接两个端点。移动标签，观察它沿当前路径定位。

`connection` 也适用于自定义坐标系，由坐标系提供沿坐标几何连接的能力。此入口描述两个端点之间的路径，不提供数据路径的系列、排序或缺值连接配置。路径标签的更多说明见[路径图元](/viz/plot/mark/path)。

需要跨越整个绘图区时，可以在端点的对应角色使用 `{ edge: 'start' }` 和 `{ edge: 'end' }`，如接入示例中的水平参考线。它们表示角色最终映射范围的两端，会跟随范围反转，不是数据最小值和最大值。

`PathAnnotation` 的 `from`、`to` 分别绑定同一行的端点。示例用 `summarize` 计算纵轴统计量，以及横轴的 `min`、`max`。开启分组后得到两行结果，绘制两条独立参考线，不会把两组端点连接起来；蓝色和橙色区分两组，参考线与同组观测点保持同色。切换到极坐标后，参考线沿固定半径绘制为圆弧。

打开“横向使用整个视图范围”，端点的 x 改为 edge，y 仍绑定统计字段。组内数据范围和完整视图范围由不同输入明确表达。

## 区间标注

区间标注为每个坐标角色指定起止范围，并把这个区域投影到绘图区。直角坐标中是矩形，极坐标中可以是扇形或环带；填充、描边与标签沿用区间图元的绘制能力。

Annotation 比较特殊的属性包括：

| 属性         | 作用                                                              |
| ------------ | ----------------------------------------------------------------- |
| `x`          | 第一个角色的 `{ from, to }` 范围                                  |
| `y`          | 第二个角色的 `{ from, to }` 范围                                  |
| `bounds`     | 完整角色范围映射，与 `x`、`y` 简写互斥                            |
| `connection` | 默认 `coordinate` 沿坐标边界连接；`straight` 直接连接投影后的角点 |

调整横向起止范围，观察区域宽度的变化。打开“铺满纵向范围”后，纵向边界改用 `edge`，区域延伸到该角色范围的两端。标签可以放在上方、中央或下方。

每个角色都必须给出范围，省略角色不会自动铺满。更多区域形状与边界说明见[区间图元](/viz/plot/mark/interval)。

离散角度下，默认 B–E 区间的内外边界依次经过 C、D，形成多边形区域。切换为 `straight` 时只连接投影后的四个角点；相对角度可能使角点共线，区域退化成线。路径与区间均遵循映射后的起止顺序，不自动选择跨接缝的最短路线。

`IntervalAnnotation` 的每个边界都可绑定字段。示例计算 x、y 的最小值和最大值，绘制包含观测范围的矩形。开启分组后，每组各占一个区域，以蓝色和橙色区分，区域与同组观测点保持同色，填充透明度为 0.2；横向改用 edge 后，各区域铺满视图宽度，纵向仍由数据范围决定。切换到极坐标后，区域按角度与半径范围绘制。

## 补充说明

- Plot 根级 `data` 与实际绑定始终必需，只有标注也不能省略。显式空数组可以使用，但比例尺仍须具备有效域。
- 数据标注复用 Mark 的 `dataExecution.marks` 执行策略；需要外部执行器的变换使用异步准备入口。独立标注不执行局部数据链，也不生成 datum 来源；数据标注支持结果行与聚合来源查询。
- `contributeToDomain` 默认是 `false`。设为 `true` 时，普通常量和最终结果行的位置值参与比例尺域推导；`edge` 始终不参与。
- 缺失角色、未知角色、无法映射的位置或坐标缺少必要投影能力都会报错。示例中的颜色、透明度和显式域用于展示效果。
