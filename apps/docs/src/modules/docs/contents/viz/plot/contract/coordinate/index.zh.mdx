---
title: 坐标系契约
description: 查询 Plot 的直角、极坐标、一维与自定义坐标操作 schema。
---

坐标操作定义位置角色及其比例尺归属：二维坐标需要 `x / y`，一维坐标只使用 `x`，具体角色再由坐标 Definition 映射到几何空间。

## CoordinateSchema

<ZodSchema name="PlotCoordinateSchema" description="内置坐标系联合：cartesian2D、polar2D、cartesian1D 或 polar1D。" />

## Cartesian2DSchema

<ZodSchema
  name="Cartesian2DSchema"
  description="二维直角坐标系。"
  descriptions={{
    type: '二维直角坐标系判别值，x 水平、y 垂直。',
    x: 'x 位置角色的比例尺名；省略时按绑定字段类型派生。',
    y: 'y 位置角色的比例尺名；省略时按绑定字段类型派生。',
  }}
/>

## Polar2DSchema

<ZodSchema
  name="Polar2DSchema"
  description="二维极坐标系。"
  descriptions={{
    type: '二维极坐标判别值，angle 绕中心旋转、radius 向外延伸。',
    angle: '角度角色的比例尺名；省略时按字段类型派生。',
    radius: '半径角色的比例尺名；省略时按字段类型派生。',
    startAngle: '角度范围起点（度），0 表示 +x 方向。',
    endAngle: '角度范围终点（度），默认 360。',
    innerRadius: '内圆半径占外半径的比例，0 表示无中孔。',
  }}
/>

<ZodSchema

<ZodSchema
