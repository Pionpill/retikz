title: transform · 变换
description: 在 Plot 中接入 Data 变换，选择共享或图元局部作用域，并将结果字段绑定到图元。
---

变换先处理数据行，图元再读取结果字段绘图。例如，先将数值转成占比，再把占比绑定到纵向位置。变换的定义、参数和计算由 [Data](/viz/data/transforms) 提供；Plot 负责接入声明、组织绘图数据作用域并消费结果。

## 接入方式

先完成 [Plot 快速开始](/viz/plot/get-start)。本例将三行数值归一化为 `share`，再绘制三个点；输出纵坐标为 0.2、0.3、0.5。变换声明用 `operation` 包裹 `{ kind, params }`。

<DocTab value="react-jsx" label="React + JSX">

通过 `PlotTransform` 声明根级变换；变换类型从 `@retikz/data` 导入，绘图组件从 `@retikz/plot-react` 导入。

```tsx
import { Plot, PlotAxis, PlotScale, PlotTransform, PointMark } from '@retikz/plot-react';
import { createRoot } from 'react-dom/client';

const rows = [
  { month: 1, value: 20 },
  { month: 2, value: 30 },
  { month: 3, value: 50 },
];

createRoot(document.getElementById('plot')!).render(
  <Plot data={rows} width={360} height={220}>
    <PlotTransform operation={{ kind: 'normalize', params: { field: 'value', as: 'share' } }} />
    <PlotScale dimension="x" type="linear" domain={[0.5, 3.5]} />
    <PlotScale dimension="y" type="linear" domain={[0, 1]} />
    <PointMark x="month" y="share" size={6} />
    <PlotAxis dimension="x" />
    <PlotAxis dimension="y" />
  </Plot>,
);
```

</DocTab>
<DocTab value="react-ir" label="React + IR">

将变换声明写入 `IRPlot.transform`，通过 `spec` 传给 React `Plot`。

```tsx
import type { IRPlot } from '@retikz/plot';
import { Plot } from '@retikz/plot-react';
import { createRoot } from 'react-dom/client';

const rows = [
  { month: 1, value: 20 },
  { month: 2, value: 30 },
  { month: 3, value: 50 },
];

const spec: IRPlot = {
  namespace: 'plot',
  type: 'plot',
  data: { reference: 'rows' },
  transform: [{ operation: { kind: 'normalize', params: { field: 'value', as: 'share' } } }],
  scales: [
    { type: 'linear', name: 'x', domain: [0.5, 3.5] },
    { type: 'linear', name: 'y', domain: [0, 1] },
  ],
  coordinate: { type: 'cartesian2D', x: 'x', y: 'y' },
  marks: [
    { type: 'point', encoding: { x: { field: 'month' }, y: { field: 'share' } }, size: { kind: 'constant', value: 6 } },
  ],
  guides: [
    { type: 'axis', dimension: 'x' },
    { type: 'axis', dimension: 'y' },
  ],
};

createRoot(document.getElementById('plot')!).render(<Plot spec={spec} data={{ rows }} width={360} height={220} />);
```

用 `plot` 创建配置，交给 `renderPlot` 渲染。

```ts
import { plot, renderPlot } from '@retikz/plot-vanilla';

const rows = [
  { month: 1, value: 20 },
  { month: 2, value: 30 },
  { month: 3, value: 50 },
];

const spec = plot({
  data: { reference: 'rows' },
  transform: [{ operation: { kind: 'normalize', params: { field: 'value', as: 'share' } } }],
  scales: [
    { type: 'linear', name: 'x', domain: [0.5, 3.5] },
    { type: 'linear', name: 'y', domain: [0, 1] },
  ],
  coordinate: { type: 'cartesian2D', x: 'x', y: 'y' },
  marks: [
    { type: 'point', encoding: { x: { field: 'month' }, y: { field: 'share' } }, size: { kind: 'constant', value: 6 } },
  ],
  guides: [
    { type: 'axis', dimension: 'x' },
    { type: 'axis', dimension: 'y' },
  ],
});

document.getElementById('plot')!.innerHTML = renderPlot(spec, { rows }, { width: 360, height: 220 });
```

## 数据作用域

变换有两种添加位置：**根级**加在 Plot 上，供所有图元共享处理后的数据；**局部**加在某个图元的 `transform` 上，只处理这个图元的数据。例如，要统一归一化所有图元的数据，就使用根级变换；只想让一层点抖动，就使用局部变换。

下面沿用接入示例的 `rows`，对 `month` 添加抖动，比较两种添加方式。

<DocTabs defaultValue="react">
<DocTab value="react" label="React">

根级将 `<PlotTransform>` 放在 `<Plot>` 的直接子级，与图元并列；局部将声明数组传给目标图元的 `transform`。

```text
Plot
├── PlotTransform
├── PointMark
└── PointMark
```

```tsx
import type { IRDataJitterTransform } from '@retikz/data';
import { Plot, PlotTransform, PointMark } from '@retikz/plot-react';

const operation: IRDataJitterTransform = {
  kind: 'jitter',
  params: { axis: 'x', xField: 'month', amount: 0.2, seed: 7 },
};

// 根级：两层点都读取抖动后的 month
const rootExample = (
  <Plot data={rows}>
    <PlotTransform operation={operation} />
    <PointMark x="month" y="value" fill="gray" />
    <PointMark x="month" y="value" fill="dodgerblue" />
  </Plot>
);

// 局部：只有蓝色点读取抖动后的 month
const localExample = (
  <Plot data={rows}>
    <PointMark x="month" y="value" fill="gray" />
    <PointMark x="month" y="value" fill="dodgerblue" transform={[{ operation }]} />
  </Plot>
);
```

</DocTab>
<DocTab value="vanilla" label="Vanilla / IR">

`plot(...)` 与直接声明 IR 使用相同的配置位置：根级写在 Plot 的 `transform`，局部写在目标图元的 `transform`。下面是配置片段，展示声明应放在哪里；数据、比例尺、坐标系和渲染入口按前面的接入方式设置。

```ts
import type { IRDataJitterTransform } from '@retikz/data';

const operation: IRDataJitterTransform = {
  kind: 'jitter',
  params: { axis: 'x', xField: 'month', amount: 0.2, seed: 7 },
};
const transform = [{ operation }];

// 根级：将 transform 放在 Plot 配置中
const rootConfig = {
  transform,
  marks: [
    { type: 'point', encoding: { x: { field: 'month' }, y: { field: 'value' } } },
    { type: 'point', encoding: { x: { field: 'month' }, y: { field: 'value' } } },
  ],
};

// 局部：只在第二个图元上添加 transform
const localConfig = {
  marks: [
    { type: 'point', encoding: { x: { field: 'month' }, y: { field: 'value' } } },
    { type: 'point', transform, encoding: { x: { field: 'month' }, y: { field: 'value' } } },
  ],
};
```

</DocTab>
</DocTabs>

同时使用两种变换时，根级先执行，局部再从该图元的输入视图继续处理。局部结果只替换当前图元看到的行，但仍参与共享比例尺和图例推断。各入口的对应关系如下：

| 入口                                | 作用域                                      |
| ----------------------------------- | ------------------------------------------- |
| `<PlotTransform operation={...} />` | React 根级声明，按顺序收集。                |
| `Plot.dataTransforms`               | React 根级声明数组，在 JSX 子声明之前执行。 |
| `IRPlot.transform`                  | IR / Vanilla 的根级声明数组。               |
| 图元 `transform`                    | 仅对当前图元执行的声明数组。                |

示例固定两层点：灰色圆点为图层 A，蓝色菱形为图层 B。切换扰动作用域，观察只移动蓝点还是两层一起移动。

## 自定义变换

自定义 Definition 和 Implementation 从 `@retikz/data` 定义，Plot 通过 `transformDefinitions` 与 `transformImplementations` 接收它们，声明仍使用同一 `operation` 结构。完整定义过程见 [Data 扩展机制](/viz/data/transform/extensions)。

<DocTabs defaultValue="react">
<DocTab value="react" label="React">

下面仅展示注入位置；`definition`、`implementation` 和匹配的 `operation` 来自已有的 Data 扩展。

```tsx
<Plot data={rows} transformDefinitions={[definition]} transformImplementations={[implementation]}>
  <PlotTransform operation={operation} />
  {/* 图元绑定该变换声明的输出字段 */}
</Plot>
```

</DocTab>
<DocTab value="vanilla" label="Vanilla">

IR 中保存变换声明；运行时依赖放在 `renderPlot` 的 options 中。

```ts
renderPlot(
  spec,
  { rows },
  {
    transformDefinitions: [definition],
    transformImplementations: [implementation],
  },
);
```
