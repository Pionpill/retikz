Plot 变换把规范化后的数据行改造成适合绘图的行。它们生成区间、堆叠边界、分箱、密度采样、趋势采样或关系字段，随后由比例尺和图元消费。

排序、汇总、筛选、注解和自定义数据变换属于[数据变换](/viz/data/transform)。本分组只说明 Plot 注册的绘图变换，以及它们在 Plot 中的作用域和管线语义。

## 作用域与管线

根级变换改写整张 Plot 共享的数据；图元局部变换只为当前图元建立数据视图。先确定作用域，再选择具体的 transform kind。

| 入口                     | 作用域    | 何时使用                     |
| ------------------------ | --------- | ---------------------------- |
| `<Transform ... />`      | Plot 根级 | 在 JSX 中按顺序声明共享变换  |
| `dataTransforms={[...]}` | Plot 根级 | 程序化生成共享变换数组       |
| mark 的 `transform`      | 当前图元  | 只为一层图元派生、汇总或采样 |

根级变换先运行，所有图元都读取它的结果；图元局部变换随后运行，只替换当前图元看到的行。图元快捷写法生成的自动变换也会进入同一条根级管线。

变换读取的输入字段仍需符合 `model`，派生输出字段不需要预先写进 strict model。图元局部变换的最终数据视图仍会参与共享比例尺和图例推断。

`<Transform>` API 与根级入口的完整装配顺序见[数据变换组件](/viz/data/transform/overview)；需要追踪变换前后的行与图元输出时，见 [Plot 来源追溯](/viz/plot/lineage)。

## 职责一览

| 页面       | Plot 成员                   | 输出形态                         |
| ---------- | --------------------------- | -------------------------------- |
| 派生与抖动 | `derive-interval`、`jitter` | 每个输入行对应一个输出行         |
| 堆叠与占比 | `stack`、`normalize`        | 保留明细行并补充边界或占比字段   |
| 分箱       | `bin`                       | 每个分箱对应一个输出行           |
| 密度与趋势 | `density`、`smooth`         | 每个分组生成一批连续采样行       |
| 行配对     | `relate`                    | 每个分组生成零个或一个关系输出行 |
