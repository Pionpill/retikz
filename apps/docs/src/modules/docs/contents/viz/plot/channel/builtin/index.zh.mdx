---
title: 内置通道
description: 按通道类型说明 plot 内置通道、通道值写法、底层落点和图例能力。
---

内置通道把数据映射为位置、样式、文本和路径等视觉结果。在 React DSL 中，直接通过 mark props 声明通道，例如 `<PointMark x="gdp" color="region" />`；先按下面的视觉目标选择通道，再到对应小节查看取值方式、落点和图例支持。

| 类型     | 通道                                                                         | 说明                             |
| -------- | ---------------------------------------------------------------------------- | -------------------------------- |
| 位置     | `x` / `y` / `z`                                                              | 字段决定坐标角色                 |
| 样式     | `color` / `fill` / `stroke` / `textColor`<br />`opacity` / `size` / `shape`  | 颜色、透明度、大小和形状         |
| 节点几何 | `padding` / `cornerRadius`<br />`rotate` / `minimumSize`                     | node 尺寸、间距和变换            |
| 文本     | `text` / `label`                                                             | 节点内文本和节点外 label         |
| 路径     | `strokeWidth` / `lineCap` / `lineJoin`<br />`roundedCorners` / `dashPattern` | 路径描边、端点、连接、圆角和虚线 |
| 效果     | `shadow` / `blendMode`                                                       | 阴影和混合模式                   |
| 其他     | `zIndex` / `order` / `series`                                                | 绘制顺序、排序和系列拆分         |

## 位置

位置通道声明数据行里的哪些字段参与坐标投影。`x` / `y` / `z` 不等于固定屏幕方向；坐标系会重新解释它们，例如 `cartesian2D` 把 `x` / `y` 当水平 / 垂直，`polar2D` 把它们当角度 / 半径。

<ComponentPreview files="builtin-position" size="md" />

| 通道 | 通道值              | 含义         | 落点            |
| ---- | ------------------- | ------------ | --------------- |
| `x`  | 字段：`x = "field"` | 第一位置角色 | coordinate role |
| `y`  | 字段：`y = "field"` | 第二位置角色 | coordinate role |
| `z`  | 字段：`z = "field"` | 第三位置角色 | coordinate role |

## 样式

样式通道控制 mark 的可见外观。颜色、透明度、大小和形状都属于样式；在面板中切换作用通道并调整数值，可以直接比较它们在同一组点上的差异。

### 颜色

| 通道        | 通道值                                                     | 含义       | 落点 / 图例                                                   |
| ----------- | ---------------------------------------------------------- | ---------- | ------------------------------------------------------------- |
| `color`     | 字段：`color = "field"`<br />常量：`color = "red"`         | 主语义颜色 | mark 选择 fill / stroke / text color；字段值支持 color legend |
| `fill`      | 字段：`fill = "field"`<br />常量：`fill = "red"`           | 填充颜色   | mark fill；node-backed mark 可写 node `fill`                  |
| `stroke`    | 字段：`stroke = "field"`<br />常量：`stroke = "red"`       | 描边颜色   | mark stroke；path-backed mark 可写 path stroke                |
| `textColor` | 字段：`textColor = "field"`<br />常量：`textColor = "red"` | 文本颜色   | core node `textColor`                                         |

### 透明度

整体透明度会同时影响填充和描边；填充透明度只弱化内部；描边透明度只弱化外框。

| 通道            | 通道值                                                             | 含义       | 落点 / 图例                                                                     |
| --------------- | ------------------------------------------------------------------ | ---------- | ------------------------------------------------------------------------------- |
| `opacity`       | 字段：`opacity = "field"`<br />常量：`opacity = {0.45}`            | 整体透明度 | `IRScope.opacity`、`IRNode.opacity` 或 `IRPath.opacity`；字段值支持 ramp legend |
| `fillOpacity`   | 字段：`fillOpacity = "field"`<br />常量：`fillOpacity = {0.7}`     | 填充透明度 | scope / node / path fill opacity                                                |
| `strokeOpacity` | 字段：`strokeOpacity = "field"`<br />常量：`strokeOpacity = {0.7}` | 描边透明度 | scope / node / path stroke opacity                                              |

### 大小

`size` 通道适合表达数量大小。字段值默认走 sqrt scale，让面积感更接近数据差异。

| 通道   | 通道值                                         | 含义       | 落点 / 图例                                                 |
| ------ | ---------------------------------------------- | ---------- | ----------------------------------------------------------- |
| `size` | 字段：`size = "field"`<br />常量：`size = {8}` | glyph 大小 | node `minimumSize`；字段值默认 sqrt scale，支持 size legend |

### 形状

`shape` 通道适合表达分类。分类字段会映射到内置 glyph 形状，并可以生成 symbol legend。

| 通道    | 通道值                                                | 含义       | 落点 / 图例                            |
| ------- | ----------------------------------------------------- | ---------- | -------------------------------------- |
| `shape` | 字段：`shape = "field"`<br />常量：`shape = "circle"` | glyph 形状 | node `shape`；字段值支持 symbol legend |

## 节点、文本与效果

这一组通道都作用在 mark 生成的 node 上。面板固定同一组文本节点，让尺寸、排版、外侧标签和效果可以连续调整，而不再拆成四张静态图。

### 节点几何

节点几何通道控制 node 自身的尺寸约束、内边距、圆角和旋转。它们更像 core node 属性下沉，而不是数据可视化中的颜色或大小 encoding。

| 通道                 | 通道值                                                                              | 含义          | 落点                       |
| -------------------- | ----------------------------------------------------------------------------------- | ------------- | -------------------------- |
| `minimumSize`        | 字段：`minimumSize = "field"`<br />常量：`minimumSize = {54}`                       | node 尺寸约束 | core node size fields      |
| `padding` / `margin` | 字段：`padding = "field"`<br />常量：`padding = {8}` / `padding = {{ x: 8, y: 4 }}` | node 内外间距 | core node spacing fields   |
| `cornerRadius`       | 字段：`cornerRadius = "field"`<br />常量：`cornerRadius = {8}`                      | 矩形圆角      | core node `cornerRadius`   |
| `rotate` / `scale`   | 字段：`rotate = "field"`<br />常量：`rotate = {18}`                                 | node 变换提示 | core node transform fields |

### 节点内文本

`text` 会让 point mark 生成文本 node。`textColor`、`align`、`lineHeight`、`maxTextWidth`、`font` 控制这个文本 node 的排版和颜色。

| 通道                                                | 通道值                                                                                             | 含义                         | 落点                                |
| --------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ---------------------------- | ----------------------------------- |
| `text`                                              | 字段：`text = "field"`                                                                             | 文本类 point mark 的可见文字 | mark assembly 后写入 core node text |
| `align` / `lineHeight`<br />`maxTextWidth` / `font` | 字段：`maxTextWidth = "field"`<br />常量：`maxTextWidth = {54}`<br />常量：`font = {{ size: 13 }}` | 文本排版                     | core node text layout fields        |

### 节点 label

`label` 不替代节点内容，而是给 datum host node 挂外侧标签。`labelPosition`、`labelDistance`、`labelPin` 决定标签的位置和引线。

| 通道                                              | 通道值                                                          | 含义            | 落点                   |
| ------------------------------------------------- | --------------------------------------------------------------- | --------------- | ---------------------- |
| `label`                                           | 字段：`label = "field"`                                         | datum host 标签 | core node `label`      |
| `labelPosition` / `labelDistance`<br />`labelPin` | 常量：`labelPosition = "top"`<br />常量：`labelDistance = {16}` | label 布局      | core node label fields |

### 效果

效果通道是共享视觉提示。`shadow` 改变节点投影，`blendMode` 在图形重叠时改变颜色合成；`boundary` 属于高级边界覆盖，保留在表格中查询。

| 通道        | 通道值                                                                   | 含义           | 落点                       |
| ----------- | ------------------------------------------------------------------------ | -------------- | -------------------------- |
| `shadow`    | 字段：`shadow = "field"`<br />常量：`shadow = "xl"`                      | 阴影预设或对象 | core node/path `shadow`    |
| `blendMode` | 字段：`blendMode = "field"`<br />常量：`blendMode = "multiply"`          | 混合模式       | core node/path `blendMode` |
| `boundary`  | 字段：`boundary = "field"`<br />常量：`boundary = {{ shape: "circle" }}` | node 边界覆盖  | core node `boundary`       |

## 路径

路径通道作用在下沉为 core path 的 mark 上，例如折线、relation、区域边界和参考线。端点箭头不是 plot channel；需要箭头时在对应 path 配置中写 `marks`。

### 路径样式

| 通道                                   | 通道值                                                             | 含义           | 落点 / 图例                                                  |
| -------------------------------------- | ------------------------------------------------------------------ | -------------- | ------------------------------------------------------------ |
| `strokeWidth`                          | 字段：`strokeWidth = "field"`<br />常量：`strokeWidth = {4}`       | 描边宽度       | scope / node / path `strokeWidth`；字段值默认范围 `[0.5, 4]` |
| `roundedCorners`                       | 字段：`roundedCorners = "field"`<br />常量：`roundedCorners = {8}` | path 圆角提示  | core path `roundedCorners`                                   |
| `lineCap`<br />`lineJoin`              | 字段：`lineCap = "field"`<br />常量：`lineCap = "round"`           | 线端和连接样式 | core path line fields                                        |
| `dashPattern` / `dashed`<br />`dotted` | 字段：`dashPattern = "field"`<br />常量：`dashPattern = {[7, 4]}`  | 描边虚线样式   | core node/path dash fields                                   |

## 其他

其他通道不直接描述颜色、位置或路径形状，而是控制绘制顺序、数据排序和系列拆分。

<ComponentPreview files="builtin-other" size="md" />

| 通道     | 通道值                                             | 含义             | 落点                         |
| -------- | -------------------------------------------------- | ---------------- | ---------------------------- |
| `zIndex` | 字段：`zIndex = "field"`<br />常量：`zIndex = {1}` | 绘制顺序提示     | scope / node / path `zIndex` |
| `order`  | 字段：`order = "field"`                            | path 的连接顺序  | mark 读取字段后排序 datum    |
| `series` | 字段：`series = "field"`                           | 多系列拆分或分组 | mark 读取字段后拆分图元      |

`order` 和 `series` 不属于 `encoding` 对象，但它们仍然是字段驱动的通道入口。用户在 React DSL 里同样把它们写成 mark props。
