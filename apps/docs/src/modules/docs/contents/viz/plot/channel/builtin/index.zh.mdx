学会[通道绑定](/viz/plot/channel/binding)后，本页帮助你选择合适的内置通道：用位置比较数值，用颜色和形状区分类别，用大小表达数量，再为图形补充文字和路径样式。

下面的属性表以示例图元为范围，不表示所有图元支持同一组属性。标签布局、路径排序和系列分组会影响最终图形，但需要与视觉通道分别理解。

## 位置

位置通道选出参与坐标计算的字段。在本例的二维直角坐标系中，x 是横向位置，y 是纵向位置；切换字段即可改变比较关系。

| 属性 | 取值   | 作用与约束                                                     |
| ---- | ------ | -------------------------------------------------------------- |
| `x`  | 字段名 | 第一个位置角色；本例表示横坐标。                               |
| `y`  | 字段名 | 第二个位置角色；本例表示纵坐标。                               |
| `z`  | 字段名 | 供自定义坐标系消费的第三位置角色；本例的内置二维坐标系不使用。 |

选择“订单量与销量”预设，再分别切换横轴和纵轴字段。数据行保持不变，点的位置由新字段重新计算。

位置输入统一写入 `encodings.position`：字段使用 `{ field: '字段名' }`，常量使用 `{ value: 50 }`，视图边界使用 `{ edge: 'start' }` 或 `{ edge: 'end' }`。

## 视觉编码

颜色用于区分类别，大小用于比较数量，形状为分类提供另一种辨识方式。固定样式适合统一外观，字段绑定让样式随记录变化。

| 属性             | 取值                   | 作用与约束                                                  |
| ---------------- | ---------------------- | ----------------------------------------------------------- |
| `color`          | 字段名或显式颜色常量   | 主颜色；具体影响的视觉属性由图元决定。                      |
| `fill`           | 字段名或颜色、填充对象 | 控制内部填充。                                              |
| `stroke`         | 字段名或颜色、描边对象 | 控制外轮廓的描边颜色。                                      |
| `opacity`        | 字段名、0–1 或分组对象 | 简写设置整体不透明度，对象可细调各成员。                    |
| `opacity.fill`   | 字段名或 0–1           | 只改变填充透明度。                                          |
| `opacity.stroke` | 字段名或 0–1           | 只改变描边透明度。                                          |
| `size`           | 数值字段或非负半径     | 字段默认映射为平方根半径；数字常量是最终点半径。            |
| `shape`          | 分类字段或显式形状常量 | 字段按类别分配形状；示例常量为 circle、rectangle、diamond。 |
| `strokeWidth`    | 数值字段或非负数字     | 控制描边宽度，与描边颜色分别设置。                          |

<ComponentAlert
  type="tip"
  title="透明度相乘"
  description="opacity.overall、opacity.fill 和 opacity.stroke 的值表示不透明度：0 为完全透明，1 为完全不透明。整体不透明度与填充或描边不透明度相乘。例如 opacity: { overall: 0.5, fill: 0.5 } 时，填充的有效不透明度为 0.5 × 0.5 = 0.25，即 25% 不透明、75% 透明；描边同理使用 overall × stroke。这里假设颜色自身完全不透明，且没有父级透明度叠加。"
/>

通常只需设置 `opacity: 0.5`；需要分别控制时，使用 `opacity: { overall: 0.5, fill: 0.5, stroke: 1 }`。各成员都可绑定字段或使用常量；省略的成员继续继承已有配置，没有继承值时为 1。数字简写只设置 overall。

切换颜色作用通道，再调整透明度、半径与形状，比较同一组点的变化。这个试验场使用常量；字段驱动的颜色和大小可在通道绑定页对照。

### 节点

节点样式控制形状的尺寸、圆角、旋转、缩放和阴影。本例不设置 text，观察重点是节点本身的外观。

| 属性           | 取值                                   | 作用与约束                                           |
| -------------- | -------------------------------------- | ---------------------------------------------------- |
| `minimumSize`  | 非负数字或尺寸对象                     | 节点最小尺寸约束；使用 size 时，数据点的 size 优先。 |
| `padding`      | 数字或间距对象                         | 节点内边距。                                         |
| `cornerRadius` | 非负数字                               | 矩形圆角半径。                                       |
| `rotate`       | 数字                                   | 节点旋转角度。                                       |
| `scale`        | 数字或轴向缩放对象                     | 缩放节点外观，不改变位置字段绑定。                   |
| `shadow`       | 本例 none、sm、md、lg、xl              | 阴影预设；none 关闭阴影，其余预设呈现不同投影。      |
| `blendMode`    | 本例 normal、multiply、screen、overlay | 重叠区域的颜色合成模式，效果取决于背景和重叠。       |

调整最小尺寸与圆角，再尝试旋转、缩放和阴影，观察三个矩形节点的变化。

### 文字

设置 text 后，PointMark 以字段文字显示数据点。本例单独展示文字颜色、字体、对齐与换行；这些文字不是图元外侧的 label 标签。

| 属性           | 取值                        | 作用与约束                 |
| -------------- | --------------------------- | -------------------------- |
| `text`         | 字段名                      | 将点图元主体改为字段文字。 |
| `textColor`    | 字段名或显式颜色常量        | 节点内文字颜色。           |
| `align`        | start、middle、end          | 节点内文字的水平对齐方式。 |
| `font`         | 字体对象，如 `{ size: 14 }` | 字体大小、字重等设置。     |
| `lineHeight`   | 正数                        | 文本行高。                 |
| `maxTextWidth` | 正数                        | 文本最大宽度，影响换行。   |

缩小最大文字宽度观察换行，再调整字号、行高与对齐方式。

### 标签

label 在图元旁附加说明文字，保留节点主体的形状。它适合给数据点标注名称或数值；节点内文字仍由 text 设置。

| 属性              | 取值                          | 作用与约束                             |
| ----------------- | ----------------------------- | -------------------------------------- |
| `label`           | 字段名、详细对象或数组        | 为图元添加外侧标签；省略时不生成标签。 |
| `label.position`  | 本例 top、right、bottom、left | 标签相对节点的位置配置。               |
| `label.distance`  | 数字                          | 标签与节点的距离配置。                 |
| `label.pin`       | 布尔值                        | 是否显示标签引线。                     |
| `label.textColor` | 颜色                          | 标签文字颜色配置。                     |

字段标签写作 `encodings.label: { text: 'name' }`，布局写作 `properties.label: { position: 'top', distance: 12, pin: true }`。固定文字写入 `properties.label.text`；多条标签的编码与属性按数组索引对应。

示例使用 tag 字段标注三个节点。切换标签位置、调整距离或关闭引线，观察标签变化；节点主体和数据位置保持不变。

### 路径

路径样式控制线条的颜色、宽度、虚线、端点与折点。先选择希望改变的线条特征，再调整对应属性。

| 属性             | 取值                 | 作用与约束                                        |
| ---------------- | -------------------- | ------------------------------------------------- |
| `stroke`         | 字段名或显式颜色常量 | 线条颜色。                                        |
| `strokeWidth`    | 数值字段或非负数字   | 线条宽度。                                        |
| `opacity`        | 字段名或 0–1         | 整条路径的透明度。                                |
| `dashPattern`    | 数字数组             | 交替指定线段与间隔长度；本例用 [7, 4] 和 [1, 4]。 |
| `lineCap`        | butt、round、square  | 分别为平头、圆头、向外延伸的方头。                |
| `lineJoin`       | miter、round、bevel  | 分别为尖角、圆角、斜角连接。                      |
| `roundedCorners` | 非负数字             | 对路径折点做几何圆角。                            |

先把路径圆角设为 0，对比三种连接方式；再增加圆角半径。切换虚线与点线时，可同时观察端点样式的影响。

## 排序与分组

绘制顺序、连接顺序和系列分组解决不同问题：zIndex 决定重叠时谁在上方，order 决定路径按哪个字段排列记录，series 将记录拆成多个系列。

| 属性     | 取值         | 作用与约束                                       |
| -------- | ------------ | ------------------------------------------------ |
| `zIndex` | 字段名或数字 | 同一绘制层内控制数据点的前后关系；较大的值在上。 |
| `order`  | 字段名       | 路径按该字段排序后连接；省略时使用输入顺序。     |
| `series` | 字段名       | 按字段拆分系列，各系列分别生成路径。             |

输入行刻意打乱。开关排序可比较输入顺序与 step 顺序；开关分组可比较一条路径与两条系列路径。A、B 在 step=2 处重叠，调整 B 的绘制层级观察遮挡变化。

order 和 series 位于图元配置顶层，不在 encoding 中。它们组织图元消费的数据，不是颜色或位置这类视觉编码。zIndex 只调整绘制次序，不改变路径连接或数据排序。

<ComponentAlert
  type="tip"
  title="与数据层 transform 的区别"
  description="数据层 transform 先处理数据：sort 调整输出行的顺序，groupBy 划定当前操作的分组范围，可用于组内排序、汇总、筛选或回填计算结果。图元的 order 和 series 在数据处理后决定如何连线、拆成几条路径，不做聚合，也不改变上游数据。transform 分组不会自动生成多条路径，仍需用 series 指定系列；已排序的数据可以省略 order，再设置 order 则会在构建路径时重新排序。"
/>

## 错误与限制

- **先确认图元支持范围。** 点、路径和区间图元的属性形态并不完全相同；不要直接把一个图元的配置复制到另一个图元。
- **按来源分组。** `encodings` 只读字段，`properties` 只保存固定值；同一目标由编码优先，无效编码不回退。
- **区分数据映射与直接值。** 点的 size 字段默认经过平方根比例尺，常量 size 是半径；shape 字段应为分类类型。透明度范围为 0–1，半径和描边宽度不能为负。
- **明确颜色的作用位置。** 需要独立控制填充和描边时，用 fill 和 stroke。textColor 控制节点文字，label.textColor 控制外侧标签。
- **给大尺寸与标签留空间。** domainPadding 扩展位置比例尺的数据域；较大的半径、旋转或标签可能还需要更多留白，超出画面时先检查尺寸与坐标域。
