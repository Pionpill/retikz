---
title: 契约 - 图元
description: 查询 Plot 点、路径、区间、参考、关系与自定义图元 schema。
---

图元是图形语法的几何输出层。内置图元使用精确判别联合，自定义图元则保留 JSON-safe 开放配置，并在 lowering 时由对应 `MarkDefinition` 校验。
