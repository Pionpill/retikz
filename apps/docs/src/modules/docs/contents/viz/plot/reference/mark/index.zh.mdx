title: 契约 - 图元
description: 查询 Plot 点、路径、区间与关系图元 schema。
---

图元是图形语法的几何输出层。仅支持 Point、Path、Interval、Relation 四类内置图元，未知类型在 schema 入口被拒绝。

固定样式的 `fill` / `stroke` 复用 Core 的 PaintValue：支持 CSS 颜色、0 到 1 的主色权重或结构化 Paint。`opacity` 支持数值（等同于 `overall`）或独立的 `overall` / `fill` / `stroke` 因子对象；Relation 的固定图元样式遵循相同规则。

目标位置接受 Core 绘图坐标、Plot 数据位置或图元引用；贝塞尔控制点只接受绝对坐标或数据位置。详细写法见[路径构造](/viz/plot/mark/path#路径构造)。

## MarkSchema

<ZodSchema name="MarkSchema" description="Point、Path、Interval 与 Relation 内置图元的判别联合。" />

所有图元都可用 `defaultColorGroup` 声明默认颜色共享关系。同名组只按首次出现位置消费一个 `palette.series` 槽位；未分组图元各自按声明顺序消费。显式颜色编码或常量 paint 仍然优先。

## 图元标签

固定标签使用可选的 `text` 字段；省略时可由同一索引的 `encodings.label.text` 提供内容。两处均未提供有效文字时不生成标签，字符串简写保持相同语义。

节点与路径标签的 `text` 均复用 Core 文本块，支持包含换行的字符串或非空行数组。逐行样式与混排片段放在行数组内；一个文本块仍对应一个标签。
