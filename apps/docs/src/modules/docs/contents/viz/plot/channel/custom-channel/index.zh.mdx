在学会[字段与常量绑定](/viz/plot/channel/binding)后，可以定义自己的通道名和取值规则。本页用 `intensity` 将 `score` 映射为点的透明度：分数越高，点越不透明；切换为常量后，所有点使用同一透明度。

## 适用边界

- 需要新的 `encodings.<name>`，并希望它参与字段绑定、逐行求值和图例描述时，定义自定义通道。
- 只改变数学映射时，使用 [Data 自定义比例尺](/viz/data/scale/custom-scale)，通过 `definitions.scales` 注入。已有通道可直接消费适用的新算法；属性校验、交付和图例仍由通道负责。
- 字段准备、聚合或筛选属于[数据扩展](/viz/data/model/extensions)，不放进通道 resolver。

## 定义能力

用 `defineScopeChannel`、`defineNodeChannel`、`definePathChannel` 或通用 `defineChannel` 声明 definition：

| 字段      | 作用                                                                            |
| --------- | ------------------------------------------------------------------------------- |
| `channel` | 唯一注册名，对应 `encodings.<name>`                                             |
| `output`  | 声明输出类型及可选的 range / palette / clamp 元数据；不会自动映射或截断值       |
| `legend?` | 声明图例形态                                                                    |
| `resolve` | 读取字段或常量绑定，自行完成映射与 clamp，并返回逐行 resolver 和可选 descriptor |
| `deliver` | 把解析后的值写入既有 Core 属性                                                  |

本例选择 `defineNodeChannel`，因为透明度需要逐点交付。下面是完整定义，由 React 和 Vanilla 宿主共用：

```ts
import { channelField, defineNodeChannel, markChannelEncoding } from '@retikz/plot';

/** 自定义 intensity 通道：字段值映射到 opacity，固定透明度使用 properties.opacity */
export const intensityChannel = defineNodeChannel<number>({
  channel: 'intensity',
  output: { outputKind: 'number', range: [0.3, 1], clamp: true },
  legend: 'ramp',
  resolve: (ctx, mark) => {
    const binding = markChannelEncoding(mark, 'intensity');
    if (binding === undefined) return undefined;
    const field = channelField(binding);
    const values = ctx.rows.map(row => Number(row[field])).filter(Number.isFinite);
    if (values.length === 0) return undefined;

    const mapping = ctx.resolveScaleMapping(
      { type: 'linear', name: 'intensity', range: [0.3, 1], clamp: true },
      { values },
    );
    const map = (value: number): number => Number(mapping.map(value));

    return {
      resolver: row => {
        const value = Number(row[field]);
        return Number.isFinite(value) ? map(value) : undefined;
      },
      descriptor: {
        channel: 'intensity',
        scaleType: 'linear',
        domain: mapping.domain,
        range: mapping.range,
        mapping,
        field,
        fieldType: ctx.model.find(definition => definition.name === field)?.type,
      },
    };
  },
  deliver: (node, value) => {
    node.style = { ...node.style, opacity: value };
  },
});
```

`resolve` 先读取当前图元的 `intensity` 绑定：字段模式用数据的最小值、最大值映射到 `[0.3, 1]`，常量模式直接把数值限制到这个范围。返回的 `resolver` 给出每行的透明度；字段模式还返回 `descriptor`，供图例读取数据范围和视觉范围。`output.range` 和 `output.clamp` 只声明元数据，实际映射与截断由这段定义完成。

最后，`deliver` 将解析后的透明度写入节点的 `style.opacity`。

## 错误与限制

- 自定义名称不能覆盖内置名或重复注册；未注册、未消费的编码目标会报错。
- 字段编码只接受非空白字段名，或必填 field/scale 的对象；数值常量放在图元支持的 properties 中。
- 本例的 intensity 只负责字段到透明度的映射。固定模式直接设置 opacity.overall，不声明新的固定属性。
- resolve 不修改数据或生成几何，deliver 只写入宿主支持的属性；definition 留在运行时，不进入 JSON。

## 消费数学映射

通道可调用 `ctx.resolveScaleMapping(operation, context)`，使用 Plot 当前注册的 Data 定义。通道确定默认配置和输入字段语义，检查返回值是否符合属性约束，再通过 `deliver` 写入 Core 属性。图例描述符的 `mapping` 保留同一次解析结果，避免按类型重新计算尺寸或透明度。

本页 intensity 示例使用该入口完成线性映射。`output` 和 `legend` 声明消费语义，本身不会替通道执行映射或校验。

## 自定义位置消费

位置通道通过 `scales` 按数学 type 声明策略。`continuity` 指定连续或离散位置，`allowsBaseline` 指定零基线许可；省略策略的自定义映射不能用于坐标角色。`role` 对应坐标角色，`pick` 读取该角色的字段绑定。数学定义与位置通道分别通过 `definitions.scales` 和 `definitions.channels` 注入。
