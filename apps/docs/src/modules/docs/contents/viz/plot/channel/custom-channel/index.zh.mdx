---

在学会[字段与常量绑定](/viz/plot/channel/binding)后，可以定义自己的通道名和取值规则。本页用 `intensity` 将 `score` 映射为点的透明度：分数越高，点越不透明；切换为常量后，所有点使用同一透明度。

## 适用边界

- 需要新的 `encoding.channels.<name>`，并希望它参与字段 / 常量绑定、逐行求值和图例描述时，定义自定义通道。
- 只改变“值 → 坐标”或“值 → 颜色”规则时，使用[自定义比例尺](/viz/plot/scale/custom-scale)；大小、透明度等其它视觉属性仍由对应通道负责求值和交付。
- 字段准备、聚合或筛选属于[数据扩展](/viz/data/model/extensions)，不放进通道 resolver。

## 定义能力

用 `defineScopeChannel`、`defineNodeChannel`、`definePathChannel` 或通用 `defineChannel` 声明 definition：

| 字段      | 作用                                                                            |
| --------- | ------------------------------------------------------------------------------- |
| `channel` | 唯一注册名，对应 `encoding.channels.<name>`                                     |
| `output`  | 声明输出类型及可选的 range / palette / clamp 元数据；不会自动映射或截断值       |
| `legend?` | 声明图例形态                                                                    |
| `resolve` | 读取字段或常量绑定，自行完成映射与 clamp，并返回逐行 resolver 和可选 descriptor |
| `deliver` | 把解析后的值写入既有 Core 属性                                                  |

本例选择 `defineNodeChannel`，因为透明度需要逐点交付。下面是完整定义，由 React 和 Vanilla 宿主共用：

```ts
import { defineNodeChannel } from '@retikz/plot';

type ExtensionChannelBinding = { field?: string; value?: unknown };

const extensionChannelsOf = (mark: {
  encoding?: { channels?: Partial<Record<string, ExtensionChannelBinding>> };
}): Partial<Record<string, ExtensionChannelBinding>> => mark.encoding?.channels ?? {};

const clampIntensity = (value: number): number => Math.min(1, Math.max(0.3, value));

/** 自定义 intensity 通道：字段值自行映射到 opacity，常量值自行截断后直接交付 */
export const intensityChannel = defineNodeChannel<number>({
  channel: 'intensity',
  output: { outputKind: 'number', range: [0.3, 1], clamp: true },
  legend: 'ramp',
  resolve: (ctx, mark) => {
    const binding = extensionChannelsOf(mark).intensity;
    if (binding === undefined) return undefined;
    if (binding.value !== undefined) {
      if (typeof binding.value !== 'number' || !Number.isFinite(binding.value)) {
        throw new Error('lowerPlots: intensity constant must be a finite number');
      }

      const value = clampIntensity(binding.value);

      return { resolver: () => value };
    }

    if (binding.field === undefined) return undefined;

    const field = binding.field;
    const values = ctx.rows.map(row => Number(row[field])).filter(Number.isFinite);
    if (values.length === 0) return undefined;

    const lo = Math.min(...values);
    const hi = Math.max(...values);
    const map = (value: number): number => clampIntensity(0.3 + (hi === lo ? 0.5 : (value - lo) / (hi - lo)) * 0.7);

    return {
      resolver: row => {
        const value = Number(row[field]);
        return Number.isFinite(value) ? map(value) : undefined;
      },
      descriptor: {
        channel: 'intensity',
        scaleType: 'linear',
        domain: [lo, hi],
        range: [0.3, 1],
        field,
        fieldType: ctx.model.find(definition => definition.name === field)?.type,
      },
    };
  },
  deliver: (node, value) => {
    node.style = { ...node.style, opacity: value };
  },
});
```

`resolve` 先读取当前图元的 `intensity` 绑定：字段模式用数据的最小值、最大值映射到 `[0.3, 1]`，常量模式直接把数值限制到这个范围。返回的 `resolver` 给出每行的透明度；字段模式还返回 `descriptor`，供图例读取数据范围和视觉范围。`output.range` 和 `output.clamp` 只声明元数据，实际映射与截断由这段定义完成。

最后，`deliver` 将解析后的透明度写入节点的 `style.opacity`。

## 注入与使用

React 和 Vanilla 共用前面的 definition，选择与你的项目一致的宿主即可。完整示例在预览的 React / Vanilla 源码视图中；下面只列注入位置的差异。

<DocTab value="react" label="React">

在 `Plot` 上注入 definition，在子图元的 `channels` 中按注册名引用：

```tsx
<Plot data={customChannelPoints} channelDefinitions={[intensityChannel]}>
  <PointMark x="x" y="y" channels={{ intensity: 'score' }} />
</Plot>
```

React DSL 的字符串值表示字段名，常量使用 `{ kind: 'constant', value }`：

```tsx
<PointMark channels={{ intensity: 'score' }} />
<PointMark channels={{ intensity: { kind: 'constant', value: 0.65 } }} />
```

<DocTab value="vanilla" label="Vanilla">

在 `renderPlot` 的第三个参数中注入。这里的 `spec` 是预览 Vanilla 源码中的 Plot 配置，已经通过 `encoding.channels.intensity` 绑定 score：

```ts
const svg = renderPlot(
  spec,
  { points: customChannelPoints },
  {
    channelDefinitions: [intensityChannel],
  },
);
```

Vanilla 示例直接使用 Plot IR：字段绑定写为 `{ field }`，常量绑定写为 `{ value }`：

```ts
import type { IRPlotChannel } from '@retikz/plot';

const fieldBinding: IRPlotChannel = { field: 'score' };
const constantBinding: IRPlotChannel = { value: 0.65 };
```

## 错误与限制

- 自定义 `channel` 不能覆盖内置名，也不能重复注册；绑定未注册通道时 lowering 会直接报错。
- 每个 binding 必须在 `field` 与 `value` 中恰好选择一个；常量还必须是 JSON value。
- definition 决定接受哪些值类型。示例的 `intensity` 常量只接受有限数，并在自己的 `resolve` 中执行 clamp。
- `resolve` 不应修改数据或生成几何；`deliver` 只能写入对应 Core 图元已经支持的属性。
- IR 中只保存字段或 JSON 常量绑定，不能包含函数或 definition。

下面的 binding 会在 schema 校验时失败，因为同时设置了字段和常量：

```ts
encoding: {
  channels: { intensity: { field: 'score', value: 0.65 } },
}
```
