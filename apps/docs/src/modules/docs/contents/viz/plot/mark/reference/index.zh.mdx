---

`<ReferenceMark>` 在数据空间声明参考约束。默认绑 `y` 得到水平参考，绑 `x` 得到竖直参考；只给下界是线，配 `xTo` / `yTo` 是单轴带。设 `kind="region"` 时，ReferenceMark 使用 `x` / `xTo` 与 `y` / `yTo` 构造二维区域。`number` 表示常量，`FieldName` 表示字段名或字段路径，并按每行数据生成一条参考。

它和 `<PointMark>` / `<IntervalMark>` 一样参与同一坐标系内的叠放顺序，但不从点、线、面维度出发，而是先确定一个固定轴值，再沿对侧轴域展开。

## 用法

```tsx
import { Plot, ReferenceMark } from '@retikz/plot-react';
```

```tsx
<Plot data={scores}>
  <ReferenceMark y={60} color="crimson" />
  <ReferenceMark y={60} yTo={80} color="#fde68a" />
</Plot>
```

默认 line / band 写法里 `x` 和 `y` 必须二选一。`xTo` 只能和 `x` 配对，`yTo` 只能和 `y` 配对；对侧部分长度则用 `extentField` / `extentToField` 成对声明。区域写法要显式设 `kind="region"`，并同时给出 `x` / `xTo` 与 `y` / `yTo`。

### 何时使用

ReferenceMark 是底层参考 mark：它负责把一个固定轴值解释成 line，把单轴区间解释成 band，或把双轴区间解释成 region。表现层看到的“阈值线”“容差带”“参考环”“扇形楔”“框选区域”不是不同 mark，而是同一个 ReferenceMark 在不同坐标系和边界配置下的显示形态。

取向由绑定的轴决定，形态由是否给上界决定：

| 表现形态     | 关键属性                                    | 说明                               |
| ------------ | ------------------------------------------- | ---------------------------------- |
| 水平参考线   | `y`                                         | 固定 y 值，跨满 x 域               |
| 竖直参考线   | `x`                                         | 固定 x 值，跨满 y 域               |
| 水平参考带   | `y` / `yTo`                                 | 固定 y 区间，填充 `y∈[y,yTo]`      |
| 竖直参考带   | `x` / `xTo`                                 | 固定 x 区间，填充 `x∈[x,xTo]`      |
| 二维参考区域 | `kind="region"` + `x` / `xTo` / `y` / `yTo` | 同时固定 x 与 y 区间，填充二者交集 |

在 `polar2D` 下，同一组属性会被坐标系重解释：`y` 是常半径参考环，`y` / `yTo` 是环带；`x` 是径向参考线，`x` / `xTo` 是扇形楔；`kind="region"` 同时限制角度和半径，得到一个环扇区。

## 例子

以下五个示例都可以在“坐标系”中切换笛卡尔与极坐标。ReferenceMark 的边界配置保持不变，坐标系负责把同一个轴值或区间重新投影成直线、圆环、带或扇区。

### 基础参考线

单个 `x` 或 `y` 常量会生成一条跨满对侧轴域的参考线。切换“参考轴”可以比较水平线与竖直线；再切到极坐标，同一配置分别变成参考环与径向线。

<ComponentPreview files={['rule-threshold', 'rule-threshold.data.ts']} size="lg" />

### 参考带

给同轴上界后，ReferenceMark 从线变成填充带。`y` / `yTo` 在极坐标中形成环带，`x` / `xTo` 则形成扇形楔；带通常先声明，再叠加数据图元。

<ComponentPreview files={['rule-band', 'rule-threshold.data.ts']} size="lg" />

`xTo` 与 `yTo` 对称：绑 `x` 时用 `xTo` 得到竖直带。上界必须匹配绑定轴，否则会在构造或 lowering 阶段报错。

### 二维参考区域

`kind="region"` 让 ReferenceMark 从单轴约束变成坐标 cell 区域。笛卡尔坐标下它围出矩形区域；极坐标下同一份 `x` / `xTo` / `y` / `yTo` 会被解释成角度区间 + 半径区间，围出环扇区。

<ComponentPreview files={['rule-region', 'rule-region.data.ts']} size="lg" />

### 逐行参考

`y="threshold"` 是字段轴值，表示每行数据各生成一条参考线。此时 `color="tier"` 会被当作颜色字段，按类别分组上色。

<ComponentPreview files={['rule-per-datum', 'rule-per-datum.data.ts']} size="lg" />

在 React 写法中，`color` 的字符串语义由下界 `x` / `y` 决定：下界是数字时按常量颜色处理，下界是字段时按颜色字段处理。即使字段上界或 extent 让 reference 逐行生成，只要下界仍是数字，`color` 仍是常量颜色。

### 局部参考

默认 line / band 跨满对侧轴域。设置 `extentField` / `extentToField` 后，每行可以从两个字段读取对侧 role 的起止值，把参考约束截成局部线段或局部带；两者必须成对出现。

<ComponentPreview files={['rule-extent', 'rule-extent.data.ts']} size="lg" />

extent 只改变参考在对侧轴上的覆盖范围，不改变 `x` / `y` 绑定的参考轴值。在 `polar2D` 下，对侧 role 会相应解释为角度跨度或半径跨度。

## 技术原理

  type="tip"
  title="上手阶段可跳过本节"

`<ReferenceMark>` 进入 `PlotSpec` 前先校验边界组合，错误配置不会被静默猜测。lowering 再根据下界、上界与 `kind` 区分 line、band 和 region。

下图在 ReferenceMark 的职责边界内展示两条下沉路径：line 直接生成路径 steps，band / region 则先形成逻辑 Cell，再交给坐标帧投影。

<ComponentPreview files="reference-lowering-flow" hideCode size="sm" />

形态分类同时决定迭代方式：边界全为常量且没有 extent 时只生成一份；任一位置、上界或 extent 来自字段时按数据行处理。两条路径最终都停在 core primitive，不重复展开全局 Scene 编译流程。

| 阶段     | 可观察行为                                                                                                        |
| -------- | ----------------------------------------------------------------------------------------------------------------- |
| 校验     | 默认形态必须只绑定 `x` 或 `y`；上界必须与同一 role 配对；region 必须给齐当前坐标系所需边界                        |
| 决定行数 | 全常量参考只生成一份几何；轴值、上界或 extent 来自字段时按有效数据行生成                                          |
| 投影     | line 在 cartesian2D / polar2D 下生成 core `Path`；band / region 通过坐标帧 `projectCell` 生成可填充的 core `Node` |
| 装饰     | line 使用 Path 样式与 geometry label；band / region 使用 Node 样式与 node label；颜色字段按 datum 分组            |

字段颜色不能绑定到一个完全常量的 reference，因为没有数据行可供逐行取值；此时应使用常量颜色，或把参考位置绑定到字段。

## API 参考

下面只列 ReferenceMark 特有或在本页重新定义语义的属性。字段与常量绑定见[通道绑定](/viz/plot/channel/binding)，局部 `transform` 与图层属性见[变换](/viz/plot/transform)，坐标视图相关属性见[坐标系](/viz/plot/coordinate)。line 的共享视觉属性沿用 [Path 样式](/kernel/components/draw/path#样式)，band / region 的共享视觉属性沿用 [Node 样式](/kernel/components/node/overview#视觉样式-api)。

| 属性                              | 类型                                   | 默认值     | 描述                                                                                                    |
| --------------------------------- | -------------------------------------- | ---------- | ------------------------------------------------------------------------------------------------------- |
| `x?` / `y?`                       | `number` / `FieldName`                 | —          | 默认形态的参考轴值，必须二选一；数字生成常量参考，字段按行生成                                          |
| `xTo?` / `yTo?`                   | `number` / `FieldName`                 | —          | 与同 role 下界配对的上界；给出后 line 变为 band                                                         |
| `kind?`                           | <ApiValues name="ReferenceMarkKind" /> | —          | 设为 `region` 时，使用多个 role 的上下界构造区域                                                        |
| `extentField?` / `extentToField?` | `FieldName`                            | 对侧轴满域 | 把 line / band 限制在对侧 role 的逐行起止范围内，必须成对                                               |
| `color?`                          | `string`                               | 默认图层色 | 下界 `x` / `y` 为数字时直接设色；下界为字段时解释为逐行颜色字段                                         |
| `label?`                          | `ReferenceMarkProps['label']`          | —          | line 下沉为 geometry label，band / region 下沉为 node label；内容写在 `content.field` / `content.value` |
