Plot 从当前位置的 Core effective Theme 读取 `style` 与 `mode`，选择同名的完整领域 preset。`PlotSpec` 不重复声明 Core 的 `style` / `mode`；主题只控制视觉默认，不改变数据、坐标、guide 是否存在或 mark 结构。

<ComponentPreview files="theme-tokens" size="lg" />

示例通过 `PlotThemeToken` 写入 surface、grid 与 categorical palette。React、Vanilla 和 plain JSON 都把同一 `plotThemeTokens` 原样交给 Plot resolver，adapter 不补自己的 preset；Core Theme 提供 effective `style` / `mode` 与 shared colors。

## 可扩展 style

用 `definePlotThemeStyle({ name: 'brand', resolve: theme => tokens })` 定义 Plot 的运行时 preset，并通过 `plotThemeStyles` 注入 `lowerPlots`、`<Plot>` 或 `renderPlot()`。完整 token map 和 resolver 函数不进入 `PlotSpec`；它只持久化 `theme.style = 'brand'`。在同一图中还要把同名 Core definition 传给 `themeStyles`，否则 Core 或 Plot 任一层都会 fail-loud。Chart 使用时，`createChartComposites({ chartThemeStyles, plotThemeStyles })` 还需要接收同名 Chart 与 Plot definitions。

## 级联与原子替换

```text
Core effective Theme
  → Plot style definition
  → inherited Core categorical
  → local PlotSpec.plotThemeTokens
  → local PlotSpec.plotTheme
  → explicit guide / mark / scale config
```

- `plotThemeTokens` 是严格、稀疏的 canonical token map；未知 key、显式 `undefined` 和非法值会失败
- 原生 `plotTheme` 更接近 Plot 正式结构，可以设置 token 没有表达的合法字段
- 数组、scalar、`false` 与 discriminator 改变的对象整体替换；同一结构的闭合对象才按合法字段合并
- 显式 scale `range` / `scheme` 与局部 axis、legend、mark 配置始终优先

## Canonical token

`PlotThemeToken` 公开 38 个稳定 key。key 的 owner 是 Plot；值约束复用 Core paint / font / opacity 原子、Plot guide / scale schema 与 Standard Legend gap 原子。

| 分组            | Canonical keys                                                                                                                                                                                                                                                                                                                           |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Surface         | `plot.surface.fill`                                                                                                                                                                                                                                                                                                                      |
| Typography      | `plot.typography.foreground`、`plot.typography.font.family`、`plot.typography.font.size`                                                                                                                                                                                                                                                 |
| Axis line       | `axis.line.enabled`、`axis.line.stroke`、`axis.line.strokeWidth`、`axis.line.drawOpacity`                                                                                                                                                                                                                                                |
| Axis tick       | `axis.tick.mark`                                                                                                                                                                                                                                                                                                                         |
| Axis tick label | `axis.tickLabel.enabled`、`axis.tickLabel.foreground`、`axis.tickLabel.font.size`、`axis.tickLabel.gap`                                                                                                                                                                                                                                  |
| Axis title      | `axis.title.foreground`、`axis.title.font.size`、`axis.title.font.weight`                                                                                                                                                                                                                                                                |
| Axis grid       | `axis.grid.stroke`、`axis.grid.strokeWidth`、`axis.grid.drawOpacity`                                                                                                                                                                                                                                                                     |
| Legend          | `legend.title.foreground`、`legend.title.font.size`、`legend.title.font.weight`、`legend.label.foreground`、`legend.label.font.size`、`legend.swatch.size`、`legend.swatch.gap`、`legend.entry.gap`、`legend.title.gap`、`legend.ramp.length`、`legend.ramp.thickness`、`legend.symbol.size`、`legend.symbol.scale`、`legend.symbol.fit` |
| Palette         | `plot.palette.categorical`、`plot.palette.series`、`plot.palette.sector`、`plot.palette.sequential`、`plot.palette.diverging`                                                                                                                                                                                                            |

`axis.line.enabled` 只决定已有 Axis 的 baseline 默认；grid 和 legend 是否创建属于 Chart recipe 或显式 guide 语义，不是 Plot token。旧 `data.palette.*`、裸 `axis.enabled`、`axis.grid.enabled` 与 `legend.enabled` 都不是 Plot canonical key。

## PlotResolvedThemeTokensSchema

`PlotResolvedThemeTokensSchema` 使用完全相同的 38 个字段契约，但每个字段都必需。八套内置 preset 与 `resolvePlotTheme()` 的 `tokens` 输出都必须通过它；sparse、resolved 与 preset 因而不会维护三份同义字段清单。

## Inspection

`resolvePlotTheme(effectiveTheme, input)` 是公开纯 resolver，返回 `IRPlotThemeResolution`，其 schema 是 `PlotThemeResolutionSchema`：

| 字段                | 含义                                              |
| ------------------- | ------------------------------------------------- |
| `style` / `mode`    | 选择 preset 的 effective Core Theme 环境          |
| `tokens`            | 级联后的完整 token map                            |
| `tokenSources`      | 每个 canonical token 的唯一胜出来源与稳定 path    |
| `authoredOverrides` | 记录原生 `plotTheme` 入口                         |
| `plotTheme`         | 已映射并校验的完整原生 Plot theme                 |
| `palette`           | scale、mark 与 legend 共享的最终 palette / scheme |

`tokenSources[].kind` 只回答 token 是从上层 effective Theme 直接投影（`inherit`），还是由 Plot style definition 或当前 Plot 输入构建（`local`），不表示级联优先级。具体胜出入口由 `path` 区分：`$style/...` 表示 Plot style baseline，`$theme/colors/categorical` 表示 Core shared categorical 投影，`$spec/plotThemeTokens/...` 与 `$spec/plotTheme/...` 表示 Plot-local 输入。`authoredOverrides` 中的 `plotTheme` 也记录为 `local`。

Chart 可以调用这个 resolver 读取 recipe 需要的瞬时 series palette，但不会把完整 resolved theme 写回 `PlotSpec`，也不会把 Plot token 标记为 Chart-owned。
