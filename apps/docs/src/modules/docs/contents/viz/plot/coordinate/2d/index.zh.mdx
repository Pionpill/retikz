---
title: 二维坐标系
description: 二维坐标系用两个位置维度绘制直角坐标图或极坐标图，并支持扇区、雷达与极坐标折线。
---

二维坐标系决定两个位置通道如何落到平面。数据字段先绑定到 `x` / `y` 并经过位置比例尺，coordinate 再把结果投影为水平 / 垂直位置或角度 / 半径；它不负责累计数据、选择 mark 形状或设置 axis 样式。

## 先看坐标切换

下面的试验场固定数据、尺寸和 `<IntervalMark>`。先切换 coordinate，观察同一组 `x` / `y` 绑定如何从普通柱变成径向柱，再用绘图区 controls 调整四边留白。

| 通道 | `cartesian2D` | `polar2D`        |
| ---- | ------------- | ---------------- |
| `x`  | 水平位置      | 绕中心的角向位置 |
| `y`  | 垂直位置      | 离中心的径向位置 |

沿共享直线轴比较位置和数值时使用默认的 `cartesian2D`；方向、周期或闭合维度需要角向 / 径向表达时使用 `polar2D`。两者继续使用同一套 mark 和字段绑定。

`margin` 表示整图边缘到绘图区的上、右、下、左留白。极坐标下的 `innerRadius` 是内半径占外半径的比例，范围为 `0 <= value < 1`；`0` 是实心中心，大于 `0` 时形成圆环。

## 扇区图

饼图与环形图不是普通的 `x` / `y` 图。`<IntervalMark angle="value" />` 是 React DSL 的扇区快捷写法，按以下顺序工作：

1. `angle="value"` 选择决定扇区占比的数据字段。
2. 自动加入的 stack transform 把每个 `value` 变成累计上下界。
3. interval 根据上下界形成首尾相接的扇区。
4. `polar2D` 把扇区投影为角度和半径。

调大 `innerRadius` 就能从饼图变成环形图。

公开配置使用 `startAngle` / `endAngle`，单位为度；`0` 位于画面右侧，正角度顺时针展开。试验场里的“扫过角度”是教学 control，实际传入的 `endAngle` 等于 `startAngle + sweepAngle`。

## 雷达图

雷达图仍使用 `x` / `y`：维度字段沿角向排列，评分字段映射到半径。`closed` 把折线末点连回首点。

## 极坐标折线

不闭合的 `<PathMark>` 可以表示风向、周期等数据。这里 `angle` 绑定到 `x`，`speed` 绑定到 `y`，`order` 决定连点顺序。
