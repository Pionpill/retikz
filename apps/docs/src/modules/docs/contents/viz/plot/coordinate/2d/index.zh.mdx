---
title: 二维坐标系
description: 二维坐标系把 x 与 y 位置通道投影到笛卡尔或极坐标平面，并让点、线、面图元复用同一组数据绑定。
---

二维坐标系决定两个位置通道如何落到平面。数据字段先绑定到 `x` / `y` 并经过位置比例尺，再由 coordinate 投影为水平 / 垂直位置或角度 / 半径；切换图元不会改变这组绑定。

## 笛卡尔二维坐标系

笛卡尔坐标系把 `x` 映射到水平方向、把 `y` 映射到垂直方向，适合沿共享直线轴比较分类与数值。下面的试验场固定坐标系和六行数据，可以切换图元，并调整绘图区留白与 y 网格：

- 点使用 `<PointMark>` 显示每行数据的位置。
- 线使用开放的 `<PathMark>` 按 `order` 连接这些位置。
- 面使用 `<IntervalMark>` 占据分类带宽，并从 `y = 0` 的 x 轴基线向上延伸。

## 极坐标二维坐标系

极坐标系把 `x` 映射为绕中心的角向位置，把 `y` 映射为离中心的径向距离。它仍复用相同数据与图元，但投影后的关系会发生变化：

- 点沿角向分布，半径由数值决定。
- 线使用闭合的 `<PathMark>`，把最后一点连回第一点。
- 面仍由 `<IntervalMark>` 实现，形成按分类分隔的径向区间。

`interpolation` 决定相邻极坐标位置之间的连接空间。省略时，连续角向比例尺使用 `polar`，在角度 / 半径输出空间插值后再投影；离散角向比例尺使用 `chord`，直接连接投影顶点。coordinate 的显式值会同时作用于网格与可继承图元；PathMark 和 IntervalMark 可以再局部覆盖，PointMark 没有连接边界，因此不提供该配置。

试验场可以分别控制 coordinate 与当前图元的插值模式，也可以调整 `innerRadius`、起始角度和扫过角度。扫过角度是面板中的教学参数，实际传给 coordinate 的 `endAngle` 等于 `startAngle + sweepAngle`。
