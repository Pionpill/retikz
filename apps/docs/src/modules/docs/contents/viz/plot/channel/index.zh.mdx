---
title: 通道
description: '通道把字段或常量绑定到位置、颜色、大小等视觉角色，让坐标系、图元和辅助元素共享同一份取值来源。'
---

通道只描述两件事：值从哪里来，以及它属于哪个视觉角色。例如，`x="gdp"` 表示位置读取 `gdp` 字段，`color="region"` 表示颜色读取 `region` 字段；字段清洗由 Data 负责，最终图形语义和渲染仍由 Core 与 renderer 负责。

React DSL 里的 mark prop 会形成 PlotSpec 中 JSON-safe 的字段或常量绑定。运行时，位置绑定由 coordinate definition 的 roles 读取；其余视觉通道从 channel registry 找到对应 definition，再解析为图元属性或图例描述。

<ComponentPreview files="channel-flow" size="lg" hideCode />

PlotSpec 只保存绑定，不保存函数。位置角色随坐标系定义，其余内置与自定义 definition 进入同一 registry，再与绑定一起交给解析器。这样扩展视觉通道不需要新增一套平行 IR 或消费流程。

## 职责一览

| 主题     | 职责                                         | 何时查阅                                             |
| -------- | -------------------------------------------- | ---------------------------------------------------- |
| 通道绑定 | 解释字段或常量如何进入 mark prop 与 PlotSpec | 想确认 `x="date"`、`color="region"`、`y={80}` 的含义 |
| 内置通道 | 按视觉任务列出可用通道、默认 scale 与落点    | 想选择 `color`、`size`、`strokeWidth` 等通道         |

需要新增项目特有的视觉通道时，继续阅读[自定义通道](/viz/plot/extend/channel)。自定义能力通过 `channelDefinitions` 注入，仍与内置通道共用 registry、解析和交付路径。
