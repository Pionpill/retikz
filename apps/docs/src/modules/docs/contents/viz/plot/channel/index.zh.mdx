---
title: 通道
description: '通道把字段或固定值连接到位置、颜色、大小等视觉结果。'
---

通道只描述两件事：值从哪里来，以及它控制什么视觉结果。例如，`x="gdp"` 表示用 `gdp` 字段决定位置，`color="region"` 表示用 `region` 字段决定颜色。

## 职责一览

| 主题     | 解决的问题                               | 何时查阅                                             |
| -------- | ---------------------------------------- | ---------------------------------------------------- |
| 通道绑定 | 字段或固定值如何直接写在图元属性上       | 想确认 `x="date"`、`color="region"`、`y={80}` 的含义 |
| 内置通道 | 位置、颜色、大小、文本和路径有哪些可选项 | 想选择 `color`、`size`、`strokeWidth` 等通道         |

## 技术原理（首次阅读可跳过）

React 图元属性会被整理成 `IRPlotSpec`（一份可以序列化和保存的绘图配置）。位置通道交给坐标系解释；其他通道通过统一的通道注册表查找处理规则，再转换为可见属性或图例信息。

<ComponentPreview files="channel-flow" size="lg" hideCode />

`IRPlotSpec` 只保存字段或常量绑定，不保存函数。内置通道与通过 `channelDefinitions` 注入的自定义通道共用同一套注册、解析和交付流程，因此扩展通道不需要增加另一套配置格式。
