---

`<PathMark>` 为一组数据行生成一条 1D 轨迹。它先把每行数据投影成点，再按 `order` 排序并连接成 core `Path`；在 cartesian2D 下常表现为折线，在 polar2D 下可以表现为极坐标路径或雷达线框。

`x` / `y` 绑定位置通道，`order` 决定连接顺序，`series` 决定是否拆成多条路径，`curve` 决定相邻点的连接方式，`closure` 决定路径是否按 baseline 或首尾闭合。当前 PathMark 支持二维笛卡尔坐标系和二维极坐标系。

## 用法

```tsx
import { PathMark, Plot } from '@retikz/plot-react';
```

```tsx
<Plot data={revenue}>
  <PathMark x="month" y="revenue" order="month" />
</Plot>
```

`order` 推荐显式写。否则 PathMark 会按数据数组顺序连点，只要数据排序变化，路径形状也会变化。

### 何时使用

PathMark 是底层线 mark：它只负责把一组有序锚点连接成一条 1D 轨迹。它不关心这条轨迹最终被命名为折线图、趋势线、轮廓线还是雷达线框；这些都是表现层对同一个 PathMark 的解释。

表现层的差异主要来自三类配置：位置通道决定点从哪里来，系列通道决定拆成几条线，几何属性决定路径只是闭合线框，还是闭合成可填充区域。

| 表现形态 | 关键属性            | 说明                                                                             |
| -------- | ------------------- | -------------------------------------------------------------------------------- |
| 折线     | `x` / `y` / `order` | 每行投影成点，按顺序连接成一条轨迹                                               |
| 多系列线 | `series` / `color`  | 先按系列拆分数据，再分别生成多条路径                                             |
| 雷达线框 | `polar2D`           | 极坐标下默认首尾相接；需要开放路径时写 `closed={false}`                          |
| 路径区域 | `closure` / `fill`  | 按首尾、常量 baseline 或逐行 stack baseline 闭合路径；显式设置 `fill` 后填充结果 |

`curve` 决定相邻点如何连接，描边色、线宽、虚线和透明度只改变路径外观。灰色数据点是固定参照，可以帮助判断曲线是否穿过原始位置；`monotoneX` / `monotoneY` 在 polar2D 下会降级为 `linear`。

### 闭合与填充

开放路径只描绘轨迹；`cycle` 让末点回连首点，`baseline` 再把路径返回到固定基线。`closure` 只构造可填充边界，仍需显式设置 `fill` 才能看到区域。

<ComponentPreview
  files={['line-closure', 'line-closure.data.ts']}
  controls={{ name: 'line-closure' }}
  size="lg"
  caption="在两种坐标系中比较开放、首尾闭合和基线闭合，并调整填充与比例尺留白。"
/>

`baseline` 省略时会跟随值轴：0 在 domain 内时使用 0，否则使用离 0 最近的 domain 边界。逐行堆叠下边界则使用 `closure={{ kind: 'stack', baselineField: ... }}`。

### 缺失值处理

某一行无法投影成有效点时，PathMark 默认在这里断开，并把前后连续数据分别生成 core `Path`。`connectNulls` 可以跨过空值连接；区域填充也遵循同一分段规则，不会默认铺满缺口。

## 技术原理

<ComponentAlert
  type="tip"
  title="上手阶段可跳过本节"
  description="需要排查系列拆分、缺失值中断、极坐标默认闭合或 anchorId 产物时再回来读。"
/>

`<PathMark>` 进入 `IRPlotSpec` 后由 mark registry 分派给 path lowering。它只接受 cartesian2D 与 polar2D，因为这两类坐标帧能为有序位置角色提供路径轨迹；不支持的坐标系会直接报错。

| 阶段       | 可观察行为                                                                                                   |
| ---------- | ------------------------------------------------------------------------------------------------------------ |
| 排序与分组 | 先按 `series` 拆路径，再按 `order` 排序；没有 `series` 时，分类 `color` 可隐式拆成多条路径                   |
| 投影与分段 | 每行投影成一个点；无效点默认切断连续段，`connectNulls` 才会跨过缺口                                          |
| 连接与闭合 | `curve` 决定相邻点连接方式；`closed` 回连首尾，`closure` 再构造 cycle、baseline 或 stack 的闭合区域          |
| 下沉       | 每个连续段生成 core `Path`，系列形成独立子层；设置 `anchorId` 时，有效顶点另外生成可引用的 core `Coordinate` |

系列子层在不同 renderer 中保持同一语义分组；缺失值还会把每个系列进一步拆成一个或多个连续 Path 段。

`fill` 只决定已经闭合的路径是否可见填充，不会自动创建闭合边界。缺失值产生多个连续段时，每段分别闭合和填充，不会跨过空档。

## API 参考

下面只列 PathMark 特有或在本页重新定义语义的属性。字段与常量绑定见[通道绑定](/viz/plot/channel/binding)，局部 `transform` 与图层属性见[变换](/viz/plot/transform)，坐标视图相关属性见[坐标系](/viz/plot/coordinate)。描边、填充、箭头、虚线、圆角、阴影等共享属性沿用 [Path 样式](/kernel/components/draw/path#样式)，不在这里重复。

| 属性            | 类型                                                                                                                                      | 默认值                                                     | 描述                                                                                                                          |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `id?`           | `string`                                                                                                                                  | —                                                          | mark 句柄；使用 `resolveLabel` 时必填                                                                                         |
| `x` / `y`       | `PathMarkProps['x']`                                                                                                                      | 必填                                                       | 轨迹的位置角色字段；cartesian2D 解释为平面位置，polar2D 解释为角向与径向                                                      |
| `order?`        | `PathMarkProps['order']`                                                                                                                  | 数据顺序                                                   | 每个系列内部的连接顺序字段                                                                                                    |
| `series?`       | `PathMarkProps['series']`                                                                                                                 | —                                                          | 把数据拆成多条独立路径                                                                                                        |
| `color?`        | `PathMarkProps['color']`                                                                                                                  | `series`                                                   | 路径颜色字段；没有显式 `series` 时，分类颜色字段也可拆系列                                                                    |
| `curve?`        | <ApiValues name="PathCurve" />                                                                                                            | `linear`                                                   | 相邻点的连接方式；polar2D 下 `monotoneX` / `monotoneY` 回退为 `linear`                                                        |
| `connectNulls?` | `boolean`                                                                                                                                 | `false`                                                    | 是否跨过无法投影的行继续连接                                                                                                  |
| `closed?`       | `boolean`                                                                                                                                 | cartesian2D: `false`<br />polar2D: `true`                  | 是否把最后一个点连回第一个点                                                                                                  |
| `closure?`      | `IRPlotPathClosure`<br />- `kind: 'cycle' \| 'baseline' \| 'stack'`<br />- `baseline?: number`<br />- `baselineField: PathMarkProps['x']` | —<br />必填<br />0 或离 0 最近的值域边界<br />`stack` 必填 | 构造可填充边界<br />选择首尾闭合、常量基线或逐行基线<br />仅 `baseline` 使用的常量下边界<br />仅 `stack` 使用的逐行下边界字段 |
| `label?`        | `PathMarkProps['label']`                                                                                                                  | —                                                          | 路径或路径段标签；内容与位置字段由 `PathMarkProps['label']` 的 TypeScript 输入契约定义                                        |
| `resolveLabel?` | `(row: ExternalRow) => string`                                                                                                            | —                                                          | 运行时标签函数；不进入 IR，必须同时提供 `id`                                                                                  |
| `anchorId?`     | `IRPlotAnchorIdSpec`                                                                                                                      | —                                                          | 为每个有效路径顶点生成稳定的 core Coordinate id                                                                               |
