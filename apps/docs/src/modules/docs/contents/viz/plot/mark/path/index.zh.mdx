description: PathMark 是有序点形成的一维轨迹；折线、闭合路径、多系列线和雷达线框都是它在不同配置下的表现形态。
---

`<PathMark>` 为一组数据行生成一条 1D 轨迹。它先把每行数据投影成点，再按 `order` 排序并连接成 core `Path`；在 cartesian2D 下常表现为折线，在 polar2D 下可以表现为极坐标路径或雷达线框。

`x` / `y` 绑定位置通道，`order` 决定连接顺序，`series` 决定是否拆成多条路径，`curve` 决定相邻点的连接方式，`closure` 决定路径是否按 baseline 或首尾闭合。当前 PathMark 支持二维笛卡尔坐标系和二维极坐标系。

## 用法

```tsx
import { PathMark, Plot } from '@retikz/plot-react';
```

```tsx
<Plot data={revenue}>
  <PathMark x="month" y="revenue" order="month" />
</Plot>
```

`order` 推荐显式写。否则 PathMark 会按数据数组顺序连点，只要数据排序变化，路径形状也会变化。

### 何时使用

PathMark 是底层线 mark：它只负责把一组有序锚点连接成一条 1D 轨迹。它不关心这条轨迹最终被命名为折线图、趋势线、轮廓线还是雷达线框；这些都是表现层对同一个 PathMark 的解释。

表现层的差异主要来自三类配置：位置通道决定点从哪里来，系列通道决定拆成几条线，几何属性决定路径只是闭合线框，还是闭合成可填充区域。

| 表现形态 | 关键属性            | 说明                                                                             |
| -------- | ------------------- | -------------------------------------------------------------------------------- |
| 折线     | `x` / `y` / `order` | 每行投影成点，按顺序连接成一条轨迹                                               |
| 多系列线 | `series` / `color`  | 先按系列拆分数据，再分别生成多条路径                                             |
| 雷达线框 | `polar2D`           | 极坐标下默认首尾相接；需要开放路径时写 `closed={false}`                          |
| 路径区域 | `closure` / `fill`  | 按首尾、常量 baseline 或逐行 stack baseline 闭合路径；显式设置 `fill` 后填充结果 |

## 例子

### 连接一条基础轨迹

`x` / `y` 决定路径经过哪些点，`order` 决定这些点的连接顺序。示例数据刻意打乱了月份行；切换“连接顺序”可以直接比较数据数组顺序与显式 `order="month"`。左侧是二维笛卡尔坐标，右侧是二维极坐标，两边使用同一组行数据。

### 拆分多条路径

给 `series` 一个字段，数据会先按该字段拆成多组，每组独立排序和连接。这个例子显式按 `city` 拆分，左侧看多系列折线，右侧看同一组系列在极坐标下形成的线框。

<ComponentPreview files={['line-series', 'line-series.data.ts']} size="md" />

不写 `series`、只给 `color` 一个分类字段时，PathMark 也会按该字段隐式拆系列。这个例子换成另一组数据，突出“颜色字段本身就是系列字段”的紧凑写法。

<ComponentPreview files={['line-color-split', 'line-series.data.ts']} size="md" />

### 只变换当前路径层

`transform` 写在 PathMark 上时，只改变这条路径层看到的数据。下面的点层始终保留每个渠道的原始值；路径层可以对全部数据拟合一条整体趋势，也可以通过 `groupBy` 按渠道拟合两条趋势线。切换拟合方式时，点层不会随路径层一起变换。

<ComponentPreview files={['line-transform', 'line-transform.data.ts']} size="md" />

### 设置路径 paint

`stroke` 和 `fill` 都可以写成 `IRPaintSpec`。在同一张图中切换“纯色线”“渐变线”和“渐变面积”，可以比较 paint 作用于描边与填充时的区别；渐变面积会用 `closure={{ kind: 'baseline' }}` 构造可填充边界，并叠加一条只描边的 PathMark 作为上边界。

<ComponentPreview files={['line-paint', 'line-basic.data.ts']} size="md" />

### 在极坐标中闭合

`closed` 会让末点回连首点。在 `polar2D` 下，PathMark 省略 `closed` 时也默认闭合。示例左侧固定闭合，右侧默认开放；切换“闭合右侧路径”可以直接比较两种连接结果。

<ComponentPreview files={['line-radar', 'line-radar.data.ts']} size="md" />

### 调整相邻点的连接方式

`curve` 控制相邻点之间如何连接。左侧是二维笛卡尔坐标，右侧是二维极坐标；切换连接方式时，两边会同步更新。默认叠加灰色数据点，便于判断曲线是否穿过原始位置；关闭“显示数据点”可以只观察路径轮廓。极坐标下不额外设置内部半径，PathMark 会按角向和径向位置直接投影。`monotoneX` / `monotoneY` 依赖投影后的屏幕 x / y 单调，在 polar2D 下会自动降级为 `linear`，避免闭合区域产生过长控制柄。

<ComponentPreview files={['line-curve', 'line-curve.data.ts']} size="md" />

| 值           | 说明     | 表现                                                              |
| ------------ | -------- | ----------------------------------------------------------------- |
| `linear`     | 直线连接 | 最忠实于相邻点之间的折线关系，适合强调逐段变化                    |
| `step`       | 中点阶梯 | 在两个 x 位置中间切换 y 值，适合状态或库存类数据                  |
| `stepBefore` | 前置阶梯 | 先切换到新值，再沿 x 方向推进，适合“新值立即生效”的序列           |
| `stepAfter`  | 后置阶梯 | 先保持旧值，到下一个 x 位置再切换，适合“旧值持续到下一时刻”的序列 |
| `basis`      | 平滑样条 | 曲线最柔和，但不保证穿过每个中间点，适合表现整体趋势              |
| `cardinal`   | 基数样条 | 穿过数据点，曲率比直线自然，但局部极值可能略有过冲                |
| `catmullRom` | 穿点平滑 | 穿过数据点，并更多保留局部形状，适合一般平滑折线                  |
| `monotoneX`  | 横向单调 | x 单调时尽量避免曲线超过相邻点的 y 极值，BI 趋势线优先用它        |
| `monotoneY`  | 纵向单调 | y 单调时尽量避免曲线超过相邻点的 x 极值，适合竖向轨迹             |
| `natural`    | 自然样条 | 整体连续且端点更放松，适合追求连续曲率的趋势表达                  |

### 构造可填充区域

`closure` 只让 PathMark 闭合成可填充路径，不会自动开启填充。`stroke` 默认开启，写 `stroke="none"` 可以关闭边框线；`fill` 默认关闭，写具体颜色或 paint 后才填充内容。左侧的面积效果由两层 PathMark 组合：一层 `baseline + fill + stroke="none"` 负责填充，另一层普通 path 负责上边界描边；右侧使用 `cycle + fill` 填充雷达多边形。使用“基线值”可以调整左侧面积的回程下边界，右侧的循环闭合不受影响；“横向留白”控制首尾分类点与 y 轴的距离，“纵向留白”控制推断值域在上下两端的额外空间，把两者都调到 `0` 时面积会贴到 y 轴和 x 轴。

<ComponentPreview files={['line-closure', 'line-closure.data.ts']} size="md" />

`baseline` 省略时会跟随值轴：0 落在值轴 domain 内就使用 0；如果显式 domain 不包含 0，例如 `[30, 80]`，则使用离 0 最近的 domain 边界 30。需要固定到其它值时再显式传 `closure={{ kind: 'baseline', baseline: ... }}`。

堆叠面积可以把上边界绑定到 `y`，再把下边界字段交给 `closure.baselineField`。这个字段可以来自 stack transform，也可以像示例一样来自预先算好的 `y0` / `y1`；示例同样用填充层和描边层组合出面积图效果。设置 `curve` 时，上下两条边界都会按同一种方式连接。

<ComponentPreview files={['line-stack-area', 'line-stack-area.data.ts']} size="md" />

### 保留数据缺口

当某一行无法投影成有效点时，PathMark 默认会在这里断开，并为前后两段分别生成 core `Path`。如果路径同时设置了 `closure` 和 `fill`，填充也按同样的段落拆开，不会跨过缺失点铺满中间空档。

这个例子里 `Yasin` 的 2019 年数据缺失，因此线和填充都会在 2018 到 2020 之间断开。确实需要跨过缺口连接时，再显式设置 `connectNulls`。

## 技术原理

<ComponentAlert
  type="tip"
  title="上手阶段可跳过本节"

`<PathMark>` 进入 `PlotSpec` 后由 mark registry 分派给 path lowering。它只接受 cartesian2D 与 polar2D，因为这两类坐标帧能为有序位置角色提供路径轨迹；不支持的坐标系会直接报错。

| 阶段       | 可观察行为                                                                                                   |
| ---------- | ------------------------------------------------------------------------------------------------------------ |
| 排序与分组 | 先按 `series` 拆路径，再按 `order` 排序；没有 `series` 时，分类 `color` 可隐式拆成多条路径                   |
| 投影与分段 | 每行投影成一个点；无效点默认切断连续段，`connectNulls` 才会跨过缺口                                          |
| 连接与闭合 | `curve` 决定相邻点连接方式；`closed` 回连首尾，`closure` 再构造 cycle、baseline 或 stack 的闭合区域          |
| 下沉       | 每个连续段生成 core `Path`，系列形成独立子层；设置 `anchorId` 时，有效顶点另外生成可引用的 core `Coordinate` |

系列子层在不同 renderer 中保持同一语义分组；缺失值还会把每个系列进一步拆成一个或多个连续 Path 段。

`fill` 只决定已经闭合的路径是否可见填充，不会自动创建闭合边界。缺失值产生多个连续段时，每段分别闭合和填充，不会跨过空档。
