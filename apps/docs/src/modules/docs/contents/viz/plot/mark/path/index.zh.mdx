`PathMark` 把多行数据的位置按顺序连成路径。`x`、`y` 决定路径经过哪里，`order` 决定先连哪个点，`series` 可以把数据拆成多条独立路径。折线、雷达轮廓和闭合区域都可以用它表达。

本页从一条折线开始，再介绍分组、曲线、闭合和缺失值。字段绑定见[通道绑定](/viz/plot/channel/binding)，安装和宿主接入见[快速开始](/viz/plot/get-start)。

## 基础用法

### 位置与顺序

`x`、`y` 是位置字段，`order` 是排序字段。例如 `x="month"`、`y="revenue"`、`order="month"` 表示按月份连接营收位置。省略 `order` 时沿用数据数组顺序，PathMark 不会自动按横坐标排序。

示例故意打乱月份行。切换“连接顺序”，比较折返的路径与按月排列的路径；坐标切换后，极坐标中的 `x` 表示角向、`y` 表示径向。

| 属性              | 含义     | 说明                                                                 |
| ----------------- | -------- | -------------------------------------------------------------------- |
| `x`、`y`          | 位置字段 | 指定字段名或字段路径；笛卡尔坐标对应横向和纵向，极坐标对应角向和径向 |
| `order`           | 连接顺序 | 按字段排序后连线；省略时保留数据数组顺序                             |
| `Plot.coordinate` | 坐标系   | 决定位置含义；示例在 `cartesian2D` 与 `polar2D` 之间切换             |

### 系列与标签

多家门店的数据混在一起时，用 `series` 指定门店字段，每家门店分别排序、连线。`color` 绑定分类字段可以区分颜色；省略 `series` 时，分类颜色字段也会拆分路径。未指定 `color` 时，颜色跟随 `series`。

`label` 沿路径几何放置标签。示例可切换单条路径、显式系列和按颜色拆分，并开关系列标签。

| 属性           | 含义     | 说明                                                                    |
| -------------- | -------- | ----------------------------------------------------------------------- |
| `series`       | 系列字段 | 按字段值拆分独立路径，各系列内部单独排序                                |
| `color`        | 分类颜色 | 按分类字段着色；没有 `series` 时也按此字段拆分路径，省略时跟随 `series` |
| `label`        | 路径标签 | 支持单个或多个标签，沿路径几何放置                                      |
| `resolveLabel` | 标签回调 | 运行时生成标签文字，需同时提供图元 `id`；不存入 IR                      |

标签位置用 `0–1` 表示沿路径的比例。所在侧选“自动”时，不旋转的标签位于上方；开启“沿路径旋转”后，标签居中沿切向摆放，此时切换“截断路径”可以观察文字下方的路径缺口。截断影响描边，不会截短文字。显式选择所在侧后，可用偏移距离把标签移到路径旁。

### 连接与样式

`curve` 决定相邻点如何连接。直线和阶梯线强调观测间的变化，平滑曲线改变点之间的走向；不同曲线不一定都穿过原始点。灰色数据点仅用于比较曲线和原始位置。

描边色、线宽、虚线和透明度控制路径外观。极坐标下 `monotoneX`、`monotoneY` 按 `linear` 处理。

| 属性                  | 含义             | 说明                                                                                      |
| --------------------- | ---------------- | ----------------------------------------------------------------------------------------- |
| `curve`               | 连接方式         | 默认 `linear`；可选择阶梯或平滑曲线。极坐标中的 `monotoneX`、`monotoneY` 按 `linear` 处理 |
| `dashOffset`          | 虚线偏移         | 有限正负数；与 `dashPattern` 配合，支持固定属性和字段编码                                 |
| `lineCap`、`lineJoin` | 描边端点与连接角 | 线帽为 butt / round / square，连接角为 miter / round / bevel；支持固定属性和字段编码      |
| `stroke`              | 描边颜色         | 支持字段或常量；需要强制常量时使用 `{ kind: 'constant', value }`                          |
| `strokeWidth`         | 描边宽度         | 支持常量或字段映射，值非负                                                                |
| `dashPattern`         | 虚线间隔         | 数值数组交替指定实线段与间隔长度；示例的虚线开关控制此属性                                |
| `opacity`             | 透明度           | 控制整体或填充、描边的不透明度                                                            |
| `closed`              | 首尾连接         | 是否把末点连回首点；不决定两点之间采用哪种曲线                                            |

固定 `fill`、`stroke` 可使用 CSS 颜色、结构化 Paint 或 0–1 的主色权重（`0` 也是有效值）。固定 `opacity: 0.6` 等价于 `{ overall: 0.6 }`；`encodings.opacity` 仍按 `overall`、`fill`、`stroke` 分量绑定，只覆盖对应的固定分量。

## 扩展用法

### 闭合与填充

`closed` 决定是否把末点连回首点：笛卡尔坐标默认开放，极坐标默认闭合。需要指定区域的下边界时使用 `closure`，再用 `fill` 设置填充颜色。

下面比较开放路径、首尾闭合和固定基线。`baseline` 省略时，值轴 domain 包含 0 就使用 0，否则使用离 0 最近的边界。

| 属性                    | 含义         | 说明                                                            |
| ----------------------- | ------------ | --------------------------------------------------------------- |
| `closed`                | 首尾连接     | 笛卡尔坐标默认 `false`，极坐标默认 `true`                       |
| `closure`               | 闭合边界     | `cycle` 回到首点，`baseline` 回到固定基线，`stack` 回到逐行基线 |
| `closure.baseline`      | 固定基线值   | 仅 `baseline` 使用；省略时取 0 或离 0 最近的值域边界            |
| `closure.baselineField` | 逐行基线字段 | `stack` 必填，指定每行下边界的字段                              |
| `fill`                  | 区域填充     | 设置闭合区域的颜色或 Paint；`none` 隐藏填充                     |

### 缺失值处理

数据行无法投影成有效位置时，默认在这里断开。开放且无填充的路径设置 `connectNulls` 后，用虚线连接缺口两侧的有效点，正常段保持原来的样式。

`connectNulls={true}` 和 `connectNulls={{}}` 都使用默认虚线 `[6, 4]`；对象可以单独设置缺口的描边属性。连续多个缺值只桥接一次，首尾缺值不外推。

闭合、设置了 `closure` 或带填充的路径只接受 boolean，此时 `true` 将有效点连成整体，不另画虚线桥接。下面的填充开关叠加了一个基线闭合图层：填充区域按整体连接，原来的开放描边仍用虚线标记缺口。

| 属性                        | 含义           | 说明                                                                                                                          |
| --------------------------- | -------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `connectNulls`              | 跨缺值连接     | 默认 `false`。开放无填充路径中，`true` 或 `{}` 使用默认虚线 `[6, 4]` 桥接缺口                                                 |
| `connectNulls` 描边对象     | 缺口样式       | 可设置 `stroke`、`strokeWidth`、`strokeOpacity`、`dashPattern`、`dashOffset`、`lineCap`、`lineJoin`；仅用于开放且无填充的路径 |
| `closed`、`closure`、`fill` | 连接行为的条件 | 闭合、配置闭合边界或带填充时，`connectNulls` 只接受 boolean，连接全部有效点而不另画桥接段                                     |

### 极坐标插值

极坐标将 `x` 映射为角度、`y` 映射为半径。两个端点位置相同，连接它们的路线仍可能不同：

| 插值    | 两点之间如何连接                                       |
| ------- | ------------------------------------------------------ |
| `chord` | 直接连接屏幕上的两个投影点                             |
| `polar` | 在角度与半径之间补充位置，再逐个投影；同半径时形成圆弧 |

默认插值由坐标系决定：连续角轴使用 `polar`，离散角轴使用 `chord`。PathMark 的 `interpolation` 可覆盖本条路径的选择；网格仍使用坐标系设置。下面两图显式设置不同的坐标插值，因此切换时路径与网格一起变化。

| 属性                            | 含义         | 说明                                                                                               |
| ------------------------------- | ------------ | -------------------------------------------------------------------------------------------------- |
| `Plot.coordinate.interpolation` | 坐标插值     | `chord` 直连投影点；`polar` 在角度和半径之间采样后投影。连续角轴默认 `polar`，离散角轴默认 `chord` |
| `interpolation`                 | 路径插值覆盖 | 仅适用于 `polar2D`；省略时继承坐标系，显式值只影响当前路径                                         |
| `closed`                        | 首尾连接     | 控制是否补上末点到首点的连接；与插值方式独立                                                       |

## 错误与限制

- 内置二维笛卡尔与极坐标支持路径及闭合区域；通用坐标帧只支持未设置 `closure` 且 `closed` 不为 `true` 的开放路径。
- `interpolation` 只能用于极坐标；其他坐标系下显式设置会报错。
- `color` 用于分类颜色，不接受连续或时间字段。
- 闭合或填充路径不能给 `connectNulls` 传描边对象；改用 boolean。
- 一段路径需要至少两个有效位置；孤立点应使用 [PointMark](/viz/plot/mark/point) 展示。
- `resolveLabel` 是运行时回调，必须同时提供图元 `id`，不会存入 Source IR。

### 路径解析

点、路径和区间图元与坐标系的关系，可以从它们各自表达的几何理解：

- **点图元表达一个位置**：坐标系负责把点放到对应位置，点上的圆、矩形或文字保持自身形状，不会随坐标映射弯曲。方向对齐可以额外借用坐标系方向旋转节点。
- **路径图元表达一条线**：坐标系不仅决定各个点的位置，还可能决定点之间的连接路线。例如在连续极坐标中，采用 `polar` 插值连接两个半径相同、角度不同的位置时，路径沿圆周经过中间角度；采用 `chord` 插值时，则直接连接投影后的端点，形成弦。
- **区间图元表达一块面**：坐标系影响整个区域的边界和形状，例如直角坐标中的矩形区间，在极坐标中可以成为扇区或环形扇区。它与路径图元都需要将几何映射到坐标空间，区别在于路径描述线的走向，区间描述面的范围。路径也可以闭合并填充，但仍由连接路线生成边界。

因此，路径图元需要知道多个位置之间的连接关系。一组数据经过分系列、排序和缺值分段后，才能确定从哪里起笔、经过哪些位置、在哪里结束。坐标系与插值策略确定连接路线后，PathMark 将结果转换为底层 [Path](/kernel/components/path/step) 的路径步骤，由 Path 编译并渲染。

下面跟随同一组有序位置观察三个阶段：上排为直角坐标，下排为连续极坐标。橙色点和编号表示原始数据位置，灰色点线用于辅助定位；蓝线表示连接路线，第 2、3 步中的小灰点表示原始数据位置之间补充的采样点。

<ComponentPreview files="path-projection" hideCode type="illustration" size="xxl" />

1. **定位**：按 `series` 或隐式颜色分组，各组按 `order` 排序，没有排序字段时保留行顺序。检查位置能否投影，再按 `connectNulls` 决定断开、桥接或跳过缺值；基线闭合还要求下边界有效。比例尺和坐标系共同确定每个有效数据顶点的屏幕位置。
2. **绘制**：直角坐标和 `chord` 插值直接使用投影点，图中上排以直线连接；连续极坐标的 `polar` 插值先在角度与半径之间采样，再投影并连接，包含需要闭合的最后一段。`curve` 决定屏幕点之间的连接方式，`closure` 补齐返回边界。下排在相邻原始位置之间各插入三个示意采样点，再以短直线依次连接，近似等半径圆弧；示意点数不代表实际采样密度，具体采样过程见下一节。
3. **细节处理**：为连续段与缺口桥接生成底层 Path，应用描边和路径标签，再编译为 Scene 交给 SVG 或 Canvas。图中以加粗描边、圆形端点和转角、沿线标签展示这些细节；它们不会改变原始数据顶点的位置。系列保留各自的分组；配置 `anchorId` 时，有效数据顶点还生成可引用的 Coordinate。

### 路径采样

在极坐标中，只把两个数据位置投影到屏幕再连线，得到的是一条直线。要让路径沿着角度和半径的变化弯曲，需要先在两个位置之间补充中间点，再逐个投影。

例如，两个位置经过尺度映射后分别为“0°、半径 100”和“90°、半径 100”。采用 `polar` 插值时，生成路径的过程如下：

1. **取得角度与半径**：先经过尺度映射，得到两个端点的角度和绘图半径，采样在这些映射后的值之间进行。
2. **补充中间位置**：将这一段等分，在每个分点分别对角度和半径做线性插值。本例半径始终为 100，角度从 0° 逐步增加到 90°；如果两端半径不同，半径也随之变化。
3. **投影到绘图空间**：把每个中间位置转换为屏幕坐标。本例得到的点都落在同一个四分之一圆周上。
4. **连接采样点**：默认 `curve="linear"` 用多条短直线逼近圆弧；选择其他 `curve` 时，再按对应连接算法生成路径步骤。因此，极坐标采样与过点平滑是先后两个阶段。

对于走直线连接分支的情况，不需要补充这些中间点：笛卡尔坐标或极坐标 `chord` 插值直接投影原始位置，在 `curve="linear"` 时绘制为直线段。分类角轴默认使用弦连接，连续角轴默认使用极坐标采样；需要闭合时，极坐标采样也覆盖末点返回首点的一段。

橙点是原始端点，蓝点是补充的采样点，灰色点线是圆弧参考。右图用少量采样点突出短直线的连接方式，点数仅为教学示意，不代表实际采样数量。

目前 `polar` 分支按固定数量采样，没有逐段检测是否退化为直线，也不会根据曲率自适应调整采样密度。例如两端角度相同、只有半径变化时，虽然结果是一条径向直线，当前仍会生成中间采样点。

极坐标的默认连接方式取决于角度轴表达的含义：

- **离散角度默认直线连接**：每个角度代表一个独立类别，例如雷达图中的“速度、力量、耐力”。相邻类别之间没有可插值的中间类别，直接连接投影后的数据位置，可以突出各类别的数值及其对比，形成雷达图常见的折线轮廓。
- **连续角度默认采样连接**：角度轴上的中间位置也有意义，例如从 0° 到 90° 之间存在连续的角度。对角度和半径插值后再投影，才能表现沿角度变化的路径；同半径的两个位置由此沿圆周连接，而不会被一条直线抄近路。

这是根据角度尺度选择的默认策略，不是坐标系的强制限制。可以通过 `interpolation` 显式选择 `chord` 或 `polar`；采样后的点如何连接，仍由 `curve` 决定。
