title: legend · 图例
description: 用 <PlotLegend> 解释颜色、大小、透明度、形状和自定义非位置通道；颜色 scale 或通道定义决定图例形态。
---

`<PlotLegend>` 是非位置 scale 的可视化身。`channel` 选择要解释的视觉通道；内置通道包括 `color`、`size`、`opacity` 和 `shape`，注册的自定义通道也使用同一组件。

图例形态不是 `<PlotLegend>` 自己指定的：颜色通道由绑定的 scale 决定，其他内置或自定义通道由注册 definition 的 `legend` 声明决定。分类色生成逐项色块，连续色和 opacity 生成平滑色带，分箱色生成区间块，size / shape 生成渐变尺寸或形状条目。

图例只解释已有的数据映射。先在 mark 上把字段绑定到通道，再声明 `<PlotLegend>`；连续字段还应通过 `model` 标成 `continuous`，避免被按分类值处理。坐标轴与图例彼此独立，仍需用 `<PlotAxis>` 显式声明位置 guide。

<DocTab value="react-jsx" label="React + JSX">

从 `@retikz/plot-react` 导入组件，用子组件声明图元、比例尺与辅助。

```tsx
import { Plot, PlotAxis, PlotLegend, PlotScale, PointMark } from '@retikz/plot-react';
import { createRoot } from 'react-dom/client';

const rows = [
  { gdp: 400, life: 76, region: 'A' },
  { gdp: 900, life: 81, region: 'B' },
  { gdp: 1600, life: 84, region: 'A' },
];

createRoot(document.getElementById('plot')!).render(
  <Plot data={rows} width={360} height={220}>
    <PlotScale dimension="x" type="linear" domainPadding={{ kind: 'ratio', lower: 0.15, upper: 0.15 }} />
    <PlotScale dimension="y" type="linear" domainPadding={{ kind: 'ratio', lower: 0.15, upper: 0.15 }} />
    <PointMark
      encodings={{
        position: { x: { field: 'gdp' }, y: { field: 'life' } },
        color: 'region',
      }}
      properties={{ size: 6 }}
    />
    <PlotAxis dimension="x" />
    <PlotAxis dimension="y" />
    <PlotLegend channel="color" />
  </Plot>,
);
```

<DocTab value="react-ir" label="React + IR">

从 `@retikz/plot` 导入配置类型，将完整 IR 传给 React `Plot` 的 `spec`。

```tsx
import { Plot } from '@retikz/plot-react';
import type { IRPlot } from '@retikz/plot';
import { createRoot } from 'react-dom/client';

const rows = [
  { gdp: 400, life: 76, region: 'A' },
  { gdp: 900, life: 81, region: 'B' },
  { gdp: 1600, life: 84, region: 'A' },
];

const spec: IRPlot = {
  namespace: 'plot',
  type: 'plot',
  data: { reference: 'rows' },
  scales: [
    { type: 'ordinal', name: 'color' },
    { type: 'linear', name: 'x', domainPadding: { kind: 'ratio', lower: 0.15, upper: 0.15 } },
    { type: 'linear', name: 'y', domainPadding: { kind: 'ratio', lower: 0.15, upper: 0.15 } },
  ],
  coordinate: { type: 'cartesian2D', x: 'x', y: 'y' },
  marks: [
    {
      type: 'point',
      encodings: {
        position: { x: { field: 'gdp' }, y: { field: 'life' } },
        color: { field: 'region', scale: 'color' },
      },
      properties: { size: 6 },
    },
  ],
  guides: [
    { type: 'legend', channel: 'color' },
    { type: 'axis', dimension: 'x' },
    { type: 'axis', dimension: 'y' },
  ],
};

createRoot(document.getElementById('plot')!).render(<Plot spec={spec} data={{ rows }} width={360} height={220} />);
```

## 基础用法

### 色彩形态

分类字段使用 ordinal 色阶并生成逐项色块；连续数值使用 sequential 色阶并生成平滑色带；quantize 等离散化 scale 则把连续数值切成区间色块。切换形态后，控件只显示当前图例适用的参数。

### 符号与透明度

#### 尺寸梯度

`size` 绑定连续字段时会通过平方根 scale 映射半径，图例选取代表值生成渐变符号。`position="bottom"` 可以把图例移到底部。

#### 形状与透明度

`shape` 适合分类字段，`opacity` 适合连续字段。每个 `<PlotLegend>` 只解释一个通道，因此同一张图可以同时放置多个图例。

透明度图例的色带和色块沿用关联 mark 的单一颜色，包括默认主题色。mark 使用多色、渐变填充，或共享该透明度比例尺的多个 mark 颜色不一致时，图例使用中性色，只表达透明度变化。

## 错误与限制

先绑定数据驱动的通道，再声明对应图例。同一通道绑定多个比例尺时，需用 `scale` 指定名称。ramp 接受完整刻度来源；size 仅使用 `ticks.count`，分类色块、分箱和 shape 不读取该配置。

## 实现原理

<ComponentAlert
  type="tip"
  title="先绑定通道，再生成图例"
  description="日常使用只需保证 mark 上存在数据驱动的通道绑定；这一节说明 PlotLegend 如何复用通道和 scale 已生成的描述信息。"

PlotLegend 会按 `channel` 和可选 `scale` 找到通道描述与 scale。颜色形态来自 scale，其它通道形态来自同一 registry 中的 `ChannelDefinition.legend`，因此自定义通道不需要单独的 PlotLegend 分支。样式由 `Plot.defaultPlot.legend` 提供默认值，单个图例可以用 `style` 局部覆盖。

<ComponentPreview files="legend-lowering-flow" size="lg" hideCode type="flow" />

选择出的形态会在 `position` 对应的预留带中下沉为独立 PlotLegend scope。图例默认使用 `500` 层级，位于坐标轴、Facet 标签和 mark 之上；`layer={{ zIndex }}` 只移动整个 scope，不改变内部条目的顺序。
