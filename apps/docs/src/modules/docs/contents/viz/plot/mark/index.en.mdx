title: Marks
description: Use Point, Path, and Interval marks to express positions, paths, and ranges, then combine them into charts.
---

A mark determines the geometry used to display data. Plot provides three built-in marks: Point places nodes at positions, Path expresses trajectories and connections, and Interval expresses position ranges. Use them individually or layer them in the same plot.

Choose a mark from the relationship you want to show. For monthly revenue, Point can mark each month's value, Path can show the trend, and Interval can compare bar heights measured from zero.

## Responsibilities at a glance

| Mark           | What it expresses                                                | Common uses                                          |
| -------------- | ---------------------------------------------------------------- | ---------------------------------------------------- |
| `PointMark`    | A node at a specified position                                   | Scatter points, bubbles, shapes, text                |
| `PathMark`     | A path through ordered positions or between specified endpoints  | Lines, closed areas, node connections, ribbons       |
| `IntervalMark` | A region defined by intervals on one or more position dimensions | Bars, histograms, heatmaps, radial bars, pies, rings |

Path can close and fill a region or form a ribbon around a centerline. Interval derives its geometry from position ranges. Choose based on how the data defines the geometry; the visible distinction between points, lines, and areas alone does not determine the mark.

## Combining marks

A line chart with data points can use Path for the trend and Point for each observation. To connect two nodes, use Point for their shapes and Path with references to those nodes as its endpoints. Each mark controls its own appearance while contributing to the same data relationship.

Marks work with the other parts of the grammar: [channel bindings](/viz/plot/channel/binding) specify where position, color, and size values come from; [scales](/viz/plot/scale) map those values to visual ranges; [coordinates](/viz/plot/coordinate) determine their positions on the canvas; and [guides](/viz/plot/guide) provide axes and legends.

The same mark can produce different shapes in different coordinate systems. Interval can express bars or rectangular cells in Cartesian coordinates, and radial bars or sectors in polar coordinates.
