Plot 的 `transform` 消费 `@retikz/data` 根入口提供的 `IRDataTransform`。十二种内置操作的 schema、定义和计算由 Data 统一拥有，完整字段契约见 [Data 契约](/viz/data/reference/contract#datatransformschema)。

## 数据作用域

| 入口                                 | 输入与结果                                             |
| ------------------------------------ | ------------------------------------------------------ |
| Plot 根 `transform`                  | 对共享数据视图执行有序操作，结果供图元及数据域计算使用 |
| 图元 `transform`                     | 从该图元输入视图生成局部结果，不改变其它图元的数据     |
| `<PlotTransform>` / `dataTransforms` | 作者入口组装为 Plot 根 operation 数组                  |

操作按声明顺序执行。行数或字段集合发生变化后，后续图元必须使用结果中仍存在的字段。数据 `jitter` 的 amount 使用数据单位；投影后的 [position adjustment](/viz/plot/reference/mark#jitterpositionadjustmentschema) 由 Plot 独立处理。

## 契约入口

从 `@retikz/data` 导入 `TransformSchema`、`DataTransform` 和具体 `IRDataXxxTransform` 类型；Plot 不转发这些数据契约。
