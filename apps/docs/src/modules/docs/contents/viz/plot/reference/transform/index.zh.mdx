---
title: 契约 - 变换
description: 查询 Plot 的堆叠、分箱、关联、归一化、区间派生、抖动、密度与趋势 schema。
---

`TransformSchema` 按数组顺序执行，联合通用 `@retikz/data` 变换、Plot 专用内置变换和运行时注册的扩展变换。会改变行数的操作应放在依赖其输出字段的图元之前。
