Mark 是图形语法里的几何层。它回答“每行或每组数据要生成什么几何”，例如点、路径、区间、参考约束，或连接两个目标的关系路径。

选择图元时先看数据要表达的几何关系，不必先决定最终图表名称。同一个 `IntervalMark` 可以组成柱图、热图或饼图，同一个 `PointMark` 也可以表现为散点、气泡或文本点。

## 职责一览

| 分类 | 图元            | 负责表达                         | 常见用途                         |
| ---- | --------------- | -------------------------------- | -------------------------------- |
| 主体 | `PointMark`     | 每行数据对应的一个位置或节点     | 散点、气泡、形状标记、文本点     |
|      | `PathMark`      | 一组有序数据形成的一维轨迹       | 折线、面积边界、雷达线框         |
|      | `IntervalMark`  | 一个或多个位置维度上的区间积     | 柱、直方、热图、径向柱、饼 / 环  |
| 辅助 | `ReferenceMark` | 不属于主体数据几何的参考位置区间 | 阈值线、参考环、容差带、参考区域 |
| 关系 | `RelationMark`  | 两个可定位目标之间的连接         | 箭头、依赖关系、带状流向         |

图元只拥有“数据如何形成几何”的契约：

- [比例尺](/viz/plot/scale)负责把字段值映射到位置、颜色或尺寸等视觉值
- [坐标系](/viz/plot/coordinate)负责解释位置角色并投影到画布
- [Guide](/viz/plot/guide)负责轴、图例等阅读辅助
- renderer 负责把 lowering 后的 core 几何输出为 SVG、Canvas 等目标

内置图元最终会下沉为 [@retikz/core](/kernel/introduction) 的 Node、Path 等 Kernel IR，但使用内置图元时不需要手动处理这些底层对象。需要注册新的图元类型时，从[自定义图元](/viz/plot/mark/custom-mark)开始。
