Mark 决定数据以什么几何形式呈现。Plot 提供三种内置图元：Point 表达位置上的节点，Path 表达轨迹与连接，Interval 表达位置范围。它们可以单独使用，也可以叠加在同一张图中。

选择图元时，从要表达的数据关系出发。例如，同一组月度营收可以用 Point 标出各月数值，用 Path 展示变化趋势，也可以用 Interval 比较各月从零开始的柱高。

## 职责一览

| 图元           | 负责表达                           | 常见用途                           |
| -------------- | ---------------------------------- | ---------------------------------- |
| `PointMark`    | 在指定位置放置节点                 | 散点、气泡、形状标记、文本         |
| `PathMark`     | 连接有序位置或指定端点，构造路径   | 折线、闭合区域、节点连线、带状路径 |
| `IntervalMark` | 由一个或多个位置维度的区间形成区域 | 柱、直方、热图、径向柱、饼与环     |

Path 可以闭合并填充，也可以沿中心线形成带状区域；Interval 则由位置区间确定几何范围。因此，选择时要看几何如何由数据构成，不能只按最终画面中的点、线、面来区分。

## 图元组合

一张带数据点的折线图可以由 Path 绘制趋势、Point 标出每个观测位置。连接两个节点时，也可以由 Point 绘制两端的形状，再由 Path 引用节点作为端点。各图元分别控制自身的样式，共同表达同一组数据关系。

图元与其他图形语法能力配合工作：[通道绑定](/viz/plot/channel/binding)指定位置、颜色和尺寸从哪里取值，[比例尺](/viz/plot/scale)将这些值映射到视觉范围，[坐标系](/viz/plot/coordinate)决定它们在画布上的位置，[辅助](/viz/plot/guide)提供轴与图例。

同一个图元在不同坐标系下可以形成不同图形。例如，Interval 在直角坐标系下可以表达柱或矩形单元，在极坐标系下可以表达径向柱或扇区。
