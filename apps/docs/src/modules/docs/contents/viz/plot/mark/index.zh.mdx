Mark 是图形语法里的几何层。它回答“每行或每组数据要生成什么几何”，例如点、路径、区间，或连接两个目标的关系路径。

选择图元时先看数据要表达的几何关系，不必先决定最终图表名称。同一个 `IntervalMark` 可以组成柱图、热图或饼图，同一个 `PointMark` 也可以表现为散点、气泡或文本点。

当图元未指定颜色时，`defaultColorIndex` 可选择 `defaultPlot.palette.series` 中的默认颜色索引，从 0 开始并循环取色。它优先于 `defaultColorGroup`，不占用其他图元的自动分组槽位，也不覆盖显式颜色或字段映射。

## 职责一览

| 分类 | 图元           | 负责表达                     | 常见用途                        |
| ---- | -------------- | ---------------------------- | ------------------------------- |
| 主体 | `PointMark`    | 每行数据对应的一个位置或节点 | 散点、气泡、形状标记、文本点    |
|      | `PathMark`     | 一组有序数据形成的一维轨迹   | 折线、面积边界、雷达线框        |
|      | `IntervalMark` | 一个或多个位置维度上的区间积 | 柱、直方、热图、径向柱、饼 / 环 |

图元只拥有“数据如何形成几何”的契约：

- [比例尺](/viz/plot/scale)负责把字段值映射到位置、颜色或尺寸等视觉值
- [坐标系](/viz/plot/coordinate)负责解释位置角色并投影到画布
- [Guide](/viz/plot/guide)负责轴、图例等阅读辅助
- renderer 负责把 lowering 后的 core 几何输出为 SVG、Canvas 等目标

内置图元最终会下沉为 [@retikz/core](/kernel/components/introduction) 的 Node、Path 等 Kernel IR，但使用内置图元时不需要手动处理这些底层对象。

## 位置输入与参考标记

Point、Path 和 Interval Mark 统一支持以下位置输入：

| 输入 | 写法                                    | 含义                             |
| ---- | --------------------------------------- | -------------------------------- |
| 字段 | `{ field: 'x' }`                        | 读取最终结果行                   |
| 常量 | `{ value: 50 }`                         | 数据空间数值或分类字符串         |
| 边界 | `{ edge: 'start' }` / `{ edge: 'end' }` | 最终映射范围的两端，跟随范围反转 |

位置统一写入 `encodings`，几何样式写入 `properties`。存在有效字段依赖时按最终结果行生成图元；只用常量和 edge 时，在每个实际视图中生成一个实例。空结果表不会产生数据实例。`transforms: []` 与省略相同；没有字段依赖时不能声明非空变换。
