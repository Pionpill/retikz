---
title: RelationMark
description: RelationMark 把数据行里的 source / target 关系下沉为 core Path，并通过 kind 区分线状路径与带状关系。
---

`<RelationMark>` 表达两个目标之间可绘制的 source-target 关系：每一行关系数据都会生成一条 core `Path`；默认是线状路径，`kind="ribbon"` 时则生成带状 Path。

目标可以是已有 core id，也可以是 `PointMark` / `IntervalMark` / `PathMark` 通过 `anchorId` 生成的稳定 id，还可以是从当前关系数据行投影出来的坐标点。数据组合与布局继续由 transform 和 arrangement 负责。

## 用法

```tsx
import { Plot, PointMark, RelationMark } from '@retikz/plot-react';
```

```tsx
<Plot data={edges}>
  <PointMark x="sourceX" y="sourceY" anchorId={{ prefix: 'node', field: 'sourceId' }} />
  <PointMark x="targetX" y="targetY" anchorId={{ prefix: 'node', field: 'targetId' }} />
  <RelationMark
    source={{ anchorId: { prefix: 'node', field: 'sourceId' } }}
    target={{ anchorId: { prefix: 'node', field: 'targetId' } }}
    path={{ options: { marks: [{ pos: 1, mark: { kind: 'arrow' } }] } }}
  />
</Plot>
```

`RelationMark` 通常和带 `anchorId` 的位置 mark 搭配使用。位置 mark 负责把数据行投影成 core `Node` / `Coordinate` 并生成稳定 id，relation mark 只用同一套规则从自己的数据行里算出 source / target id，然后降低成 core `Path`。如果边数据还不存在，可以用 `transform` 只为当前 relation mark 动态派生关系行。

### 何时使用

RelationMark 是底层关系路径 mark：它不重新发明箭头、标签或折线路由，而是把关系数据转换成 core `Path.children` 的 step 序列。表现层上看到的依赖线、流程线、引用线和带标签的连接线，都是同一类 source-target path 的不同配置。

| 表现形态         | 关键属性                            | 说明                                                                          |
| ---------------- | ----------------------------------- | ----------------------------------------------------------------------------- |
| 点到点关系       | `source` / `target`                 | 按 id 或生成规则引用已有节点，再用默认 `move -> line` 路径连接                |
| 带中间点路径     | `path.via` / `path.route[].to`      | 中间投影点会生成 core `Coordinate`，后续也能继续被 id 引用                    |
| 几何标签         | `label`                             | 降低到 core `Path.label`；path 和 ribbon 共享同一套 host label                |
| step 标签        | `path.label` / `path.route[].label` | 降低到 core step label；显式 step label 优先于 shorthand                      |
| core Path 能力   | `path.options`                      | 透传箭头、圆角、marks 等 path-only 能力                                       |
| Path ribbon kind | `kind="ribbon"` / `ribbon`          | 把 source-target 行降低成 `kind: 'ribbon'` 的 core `Path`，用来画桑基带状关系 |
| 共享样式         | `style`                             | path 和 ribbon 都能复用的填充、描边和透明度字段                               |

## 例子

### 已有关系数据

#### 散点关系

每个散点行同时声明 `id` 和 `target`。关系已经在原始数据里，因此 RelationMark 只需按 `anchorId` 规则解析两端，再生成点到点路径；切换路由方式可以在同一关系上比较直线、弯曲和正交连接。

#### 桑基带状关系

桑基关系仍使用同一套 `source` / `target` 引用，但将 `kind` 设为 `ribbon`，并用 `ribbon.width` 声明带宽。填充和透明度继续放在 path / ribbon 共用的 `style` 中。

<ComponentPreview files={['relation-sankey', 'relation-sankey.data.ts']} size="lg" />

### 从主体数据派生关系

#### 气泡关系

气泡层通过 `anchorId` 生成可引用 id；RelationMark 的局部 `relate` 再选择 `value` 最大与 `y` 最高的气泡，并派生两端 id 和路径标签。`boundary` 让连接线停在气泡边界上。

<ComponentPreview files={['relation-bubble', 'relation-bubble.data.ts']} size="lg" />

#### 路径极值

PathMark 为每个顶点注册可引用坐标，RelationMark 的局部 `relate` 从同一批点中选择极小值和极大值。切换 control 可以观察选择字段如何改变两端，bend 路由则把关系画成曲线。

<ComponentPreview files={['relation-path-extremes', 'relation-path-extremes.data.ts']} size="lg" />

#### 区间关系

两个 RelationMark 分别从 before / after 区间行派生减少与增加关系，再用正交路由连接柱顶。“高度偏移”只改变派生的中转高度，不改两端；其余 controls 用于比较线型、线宽、关系标签位置以及区间标签方位和颜色。

## 技术原理

<ComponentAlert
  type="tip"
  title="上手阶段可跳过本节"

/>

`<RelationMark>` 每行读取一组 `source` / `target`，把它们解析成 core 可以定位的目标，再生成普通路径或 ribbon。局部 `transform` 在 plot 级变换之后运行，因此可先从主体数据派生关系行，再让目标、标签、样式和宽度读取这些派生字段。

下图在 RelationMark 的职责边界内展示这条主链：目标解析由 path 与 ribbon 共用，分支只决定怎样构造几何，最终产物仍是 core `Path`。

<ComponentPreview files="relation-lowering-flow" hideCode size="xs" />

| 阶段       | 可观察行为                                                                                                                 |
| ---------- | -------------------------------------------------------------------------------------------------------------------------- |
| 解析目标   | `{ id }` 引用已有目标，`{ anchorId }` 按当前行生成目标 id，`{ project }` 把当前行的坐标 role 投影成新坐标                  |
| 构造路径   | 默认从 source 直连 target；`path.via` 插入中间点，`path.routing` 选择 line / bend / orthogonal，`path.route` 提供显式 step |
| 生成几何   | 默认关系生成 core `Path`；`kind="ribbon"` 使用 `ribbon.width` / `endWidth` 生成带状 Path，不消费路径路由                   |
| 装饰与诊断 | 顶层 `label` 挂到最终 Path，step label 挂到对应路径段；缺失目标 id 与重复生成的 anchor id 会带 mark 和数据行上下文报错     |

`path.route` 与 `path.routing` 互斥。默认直连、line 与 bend 路由会把 `path.label` 放到最后一个可绘制 step；orthogonal 路由默认使用 `labelStep="main"`，把标签放到最长主线段，只有 `labelStep="last"` 才放到最后一段。显式 `path.route[].label` 优先级更高。

## API 参考

下面只列 RelationMark 特有或在本页重新定义语义的属性。React 使用者可以从 `@retikz/plot-react` 导入 `RelationMarkProps`；表中的 `IRPlot*` 与 `RelationPathGeometryInput` 类型从 `@retikz/plot` 导入。局部 `transform` 及 `relate` 变换见[变换](/viz/plot/transform)，自定义字段通道见[通道绑定](/viz/plot/channel/binding)，坐标投影目标见[坐标系](/viz/plot/coordinate)。path 与 ribbon 共用的颜色、描边、透明度、阴影等样式放在 `style`；只属于普通路径的箭头、虚线和圆角放在 `path.options`。

| 属性                | 类型                                      | 默认值      | 描述                                                              |
| ------------------- | ----------------------------------------- | ----------- | ----------------------------------------------------------------- |
| `source` / `target` | `RelationMarkProps['source']`             | 必填        | 起点与终点；可直接引用 id、按行生成 anchor id，或从当前行投影坐标 |
| `kind?`             | <ApiValues name="RelationGeometryKind" /> | `path`      | 每行生成普通 Path 或 ribbon Path                                  |
| `label?`            | `RelationMarkProps['label']`              | —           | 整条关系的 geometry label                                         |
| `path.via?`         | `RelationPathGeometryInput['via']`        | —           | 默认或算法路由经过的中间目标                                      |
| `path.routing?`     | `RelationPathGeometryInput['routing']`    | `line`      | `line`、`bend` 或 `orthogonal` 路由；与 `path.route` 互斥         |
| `path.route?`       | `RelationPathGeometryInput['route']`      | —           | 显式 core-like step 序列；最后一步省略 `to` 时指向 target         |
| `path.label?`       | `RelationPathGeometryInput['label']`      | —           | 默认或算法路径的 step label 便捷写法                              |
| `path.options?`     | `RelationPathGeometryInput['options']`    | —           | 普通路径专属的 marks、dash、roundedCorners、lineCap 与 lineJoin   |
| `ribbon.width`      | `IRPlotRelationRibbonOptions['width']`    | ribbon 必填 | source 侧宽度；省略 `endWidth` 时也是整条带宽                     |
| `ribbon.endWidth?`  | `IRPlotRelationRibbonOptions['endWidth']` | —           | target 侧宽度                                                     |
| `ribbon.options?`   | `IRPlotRelationRibbonOptions['options']`  | —           | 对齐、采样与宽度插值选项                                          |
| `style?`            | `RelationMarkProps['style']`              | —           | path / ribbon 共享的视觉样式                                      |
| `color?`            | `RelationMarkProps['color']`              | —           | 字段驱动的关系颜色通道                                            |
