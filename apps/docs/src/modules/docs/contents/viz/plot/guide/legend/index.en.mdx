---
title: Legend
description: Use <Legend> to explain color, size, opacity, shape, and custom non-positional channels; a color scale or channel definition determines the form.
---

`<Legend>` is the visual counterpart of a non-positional scale. `channel` selects the visual channel to explain. Built-in channels include `color`, `size`, `opacity`, and `shape`; registered custom channels use the same component.

`<Legend>` does not select its own form. Color channels derive it from the bound scale; other built-in or custom channels use the registered definition's `legend` declaration. Categorical color produces item swatches, continuous color and opacity produce smooth ramps, binned color produces interval blocks, and size / shape produce graduated-size or shape entries.

A legend only explains an existing data mapping. Bind a field to a channel on the mark before declaring `<Legend>`. Also mark continuous fields as `continuous` through `model` so they are not treated as categories. Axes remain independent and still require explicit `<Axis>` declarations.

## Usage

```tsx
import { Legend, Plot, PointMark } from '@retikz/plot-react';
```

```tsx
<Plot data={cities}>
  <PointMark x="lng" y="lat" color="region" size="pop" />
  <Legend channel="color" />
  <Legend channel="size" position="bottom" />
</Plot>
```

## How it works

<ComponentAlert
  type="tip"
  title="Bind a channel before generating its legend"
  description="For everyday use, make sure the mark has a data-driven channel binding. This section explains how Legend reuses descriptors already produced by the channel and scale."
/>

Legend resolves a channel descriptor and an optional named scale from `channel` and `scale`. Color forms come from the scale; other channel forms come from `ChannelDefinition.legend` in the same registry, so custom channels do not need a separate Legend branch. `Plot.plotTheme.legend` provides visual defaults, and one legend can override them locally with `style`.

<ComponentPreview files="legend-lowering-flow" size="sm" hideCode />

The selected form lowers into an independent Legend scope inside the band reserved by `position`. Legends use zIndex `500` by default, above axes, marks, and plot-level labels; `layer={{ zIndex }}` moves the whole scope without changing entry order inside it.

## API Reference

| Prop          | Type                                | Default       | Description                                                                                                                                                                   |
| ------------- | ----------------------------------- | ------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `channel`     | `LegendProps['channel']`            | —             | Non-positional channel to explain; built-ins are color / size / opacity / shape, and registered custom channels work the same way                                             |
| `scale?`      | `LegendProps['scale']`              | unique scale  | Named scale used to disambiguate when one channel has several scales; failure to resolve one uniquely is an error                                                             |
| `title?`      | `LegendProps['title']`              | none          | Legend title; accepts strings, multiple lines, and structured text                                                                                                            |
| `position?`   | <ApiValues name="LegendPosition" /> | `'right'`     | Edge that contains the legend; layout reserves a legend band on that edge                                                                                                     |
| `orient?`     | <ApiValues name="LegendOrient" />   | by `position` | Item direction; left/right default to vertical, while top/bottom default to horizontal                                                                                        |
| `ticks?`      | `LegendProps['ticks']`              | by form       | Ramps support the complete tick source; size currently reads `count` only; categorical swatches and shape ignore it                                                           |
| `tickLabels?` | `LegendProps['tickLabels']`         | `true`        | Hide labels with `false`; `format` applies to ramp tick labels                                                                                                                |
| `style?`      | `LegendProps['style']`              | theme legend  | Local visual tokens for swatch / ramp size, gaps, and text. Size symbols default to `symbolFit:'fit'` inside the `symbolSize` box; use `'preserve'` to retain rendered radius |
| `layer?`      | `LegendProps['layer']`              | legend layer  | Override the semantic layer of the whole legend scope                                                                                                                         |

### Tick support matrix

| Legend form                              | `ticks` support                            | `tickLabels.format` |
| ---------------------------------------- | ------------------------------------------ | ------------------- |
| Continuous color / opacity / custom ramp | `values > interval > count`                | supported           |
| size                                     | `count` only; 3 representatives by default | ignored             |
| Categorical or binned swatches, shape    | ignored                                    | ignored             |

### Key object fields

| Object field          | Type                                             | Default            | Purpose                                                      |
| --------------------- | ------------------------------------------------ | ------------------ | ------------------------------------------------------------ |
| `ticks.values`        | `Array<string \| number>`                        | —                  | Explicit ramp tick values                                    |
| `ticks.interval`      | `{ kind:'number' \| 'time' \| 'category'; ... }` | —                  | Fixed numeric, temporal, or categorical ramp interval        |
| `ticks.count`         | `number`                                         | scale/form default | Target ramp tick count or number of size representatives     |
| `tickLabels.format`   | `string`                                         | automatic format   | Numeric or UTC temporal ramp format                          |
| `style.swatchSize`    | `number`                                         | `14`               | Baseline swatch side length                                  |
| `style.rampLength`    | `number`                                         | `100`              | Ramp long edge                                               |
| `style.rampThickness` | `number`                                         | `12`               | Ramp short edge                                              |
| `style.symbolSize`    | `number`                                         | `14`               | Target visual box for shape and size legends                 |
| `style.symbolFit`     | <ApiValues name="LegendSymbolFit" />             | `'fit'`            | Fit a size radius into the box or preserve its original size |
| `style.symbolScale`   | `number`                                         | `1`                | Additional scale applied after symbol fitting                |
| `layer.zIndex`        | `number`                                         | `500`              | Override the whole legend scope's semantic layer             |
