---
title: PlotLegend
description: Use <PlotLegend> to explain color, size, opacity, shape, and custom non-positional channels; a color scale or channel definition determines the form.
---

`<PlotLegend>` is the visual counterpart of a non-positional scale. `channel` selects the visual channel to explain. Built-in channels include `color`, `size`, `opacity`, and `shape`; registered custom channels use the same component.

`<PlotLegend>` does not select its own form. Color channels derive it from the bound scale; other built-in or custom channels use the registered definition's `legend` declaration. Categorical color produces item swatches, continuous color and opacity produce smooth ramps, binned color produces interval blocks, and size / shape produce graduated-size or shape entries.

A legend only explains an existing data mapping. Bind a field to a channel on the mark before declaring `<PlotLegend>`. Also mark continuous fields as `continuous` through `model` so they are not treated as categories. Axes remain independent and still require explicit `<PlotAxis>` declarations.

Import the components from `@retikz/plot-react` and declare guides alongside the mark.

```tsx
import { Plot, PlotAxis, PlotLegend, PlotScale, PointMark } from '@retikz/plot-react';
import { createRoot } from 'react-dom/client';

const rows = [
  { gdp: 400, life: 76, region: 'A' },
  { gdp: 900, life: 81, region: 'B' },
  { gdp: 1600, life: 84, region: 'A' },
];

createRoot(document.getElementById('plot')!).render(
  <Plot data={rows} width={360} height={220}>
    <PlotScale dimension="x" type="linear" domainPadding={{ kind: 'ratio', lower: 0.15, upper: 0.15 }} />
    <PlotScale dimension="y" type="linear" domainPadding={{ kind: 'ratio', lower: 0.15, upper: 0.15 }} />
    <PointMark
      encodings={{
        position: { x: { field: 'gdp' }, y: { field: 'life' } },
        color: 'region',
      }}
      properties={{ size: 6 }}
    />
    <PlotAxis dimension="x" />
    <PlotAxis dimension="y" />
    <PlotLegend channel="color" />
  </Plot>,
);
```

Import the configuration type from `@retikz/plot` and pass the IR to the React `Plot` through `spec`.

```tsx
import { Plot } from '@retikz/plot-react';
import type { IRPlot } from '@retikz/plot';
import { createRoot } from 'react-dom/client';

const rows = [
  { gdp: 400, life: 76, region: 'A' },
  { gdp: 900, life: 81, region: 'B' },
  { gdp: 1600, life: 84, region: 'A' },
];

const spec: IRPlot = {
  namespace: 'plot',
  type: 'plot',
  data: { reference: 'rows' },
  scales: [
    { type: 'ordinal', name: 'color' },
    { type: 'linear', name: 'x', domainPadding: { kind: 'ratio', lower: 0.15, upper: 0.15 } },
    { type: 'linear', name: 'y', domainPadding: { kind: 'ratio', lower: 0.15, upper: 0.15 } },
  ],
  coordinate: { type: 'cartesian2D', x: 'x', y: 'y' },
  marks: [
    {
      type: 'point',
      encodings: {
        position: { x: { field: 'gdp' }, y: { field: 'life' } },
        color: { field: 'region', scale: 'color' },
      },
      properties: { size: 6 },
    },
  ],
  guides: [
    { type: 'legend', channel: 'color' },
    { type: 'axis', dimension: 'x' },
    { type: 'axis', dimension: 'y' },
  ],
};

createRoot(document.getElementById('plot')!).render(<Plot spec={spec} data={{ rows }} width={360} height={220} />);
```

## Basic usage

### Color forms

Categorical fields use ordinal scales and item swatches; continuous values use sequential scales and smooth ramps; discretizing scales such as quantize split continuous values into interval blocks. After switching forms, the controls only expose parameters relevant to the active legend.

### Symbols and opacity

#### Graduated size

Binding `size` to a continuous field maps radius through a square-root scale. The legend selects representative values for graduated symbols. Use `position="bottom"` to move it below the plot.

#### Shape and opacity

`shape` suits categorical fields, while `opacity` suits continuous fields. Each `<PlotLegend>` explains one channel, so a plot can contain several independent legends.

Opacity ramps and swatches inherit the associated marks' single color, including the default theme color. When a mark uses multiple colors or a gradient fill, or marks sharing the opacity scale have different colors, the legend uses a neutral color to show opacity changes.

## Errors and limitations

Bind a data-driven channel before declaring its legend. When a channel has multiple scales, select one by name with `scale`. Ramps accept full tick sources; size uses `ticks.count` only, while categorical swatches, bins and shape ignore ticks.

## Implementation

PlotLegend resolves a channel descriptor and an optional named scale from `channel` and `scale`. Color forms come from the scale; other channel forms come from `ChannelDefinition.legend` in the same registry, so custom channels do not need a separate PlotLegend branch. `Plot.defaultPlot.legend` provides visual defaults, and one legend can override them locally with `style`.

<ComponentPreview files="legend-lowering-flow" size="lg" hideCode type="flow" />

The selected form lowers into an independent PlotLegend scope inside the band reserved by `position`. Legends use zIndex `500` by default, above axes, facet labels, and marks; `layer={{ zIndex }}` moves the whole scope without changing entry order inside it.
