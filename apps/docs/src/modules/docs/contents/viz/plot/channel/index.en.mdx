title: Channels
description: 'Channels connect fields or fixed values to visual results such as position, color, and size.'
---

A channel describes two things: where a value comes from and which visual result it controls. For example, `x="gdp"` uses the `gdp` field for position, while `color="region"` uses the `region` field for color.

## Responsibilities

| Topic             | Problem it solves                                        | Reach for it when                                                        |
| ----------------- | -------------------------------------------------------- | ------------------------------------------------------------------------ |
| Channel binding   | How fields or fixed values are written on mark props     | You want to confirm what `x="date"`, `color="region"`, or `y={80}` means |
| Built-in channels | Which options control position, color, size, text, paths | You want to choose channels such as `color`, `size`, or `strokeWidth`    |

## How It Works (Optional On A First Read)

React mark props are assembled into `IRPlot`, a serializable drawing configuration. Position channels are interpreted by the coordinate system. Other channels use a shared channel registry to find their handling rules, then resolve into visible properties or legend information.

<ComponentPreview files="channel-flow" size="lg" hideCode />

`IRPlot` stores field or constant bindings, not functions. Built-ins and custom channels injected through `channelDefinitions` share the same registration, resolution, and delivery path, so extending channels does not require another configuration format.
