---
title: 自定义坐标系
description: 用 CoordinateDefinition 声明位置 role、比例尺和投影 frame，并通过 coordinates 注入 Plot 的统一坐标系注册表。
---

坐标系把位置值映射成屏幕几何。内置坐标系无法表达目标空间时，可以用 `defineCoordinate` 声明运行时投影；Plot IR 仍只保存自定义 `type` 和 JSON 配置。

## 适用边界

- 需要新的位置 role、投影函数、曲线轴或特殊空间时，定义自定义 coordinate。
- React `<PointMark>` 当前直接暴露 `x` / `y` / `z`；任意 `u` / `v` role 通过完整 `spec` 或 Vanilla 的 `encoding` 表达。
- 只改变值域映射而不改变空间投影时，使用[自定义比例尺](/viz/plot/scale/custom-scale)；只改变图元几何时，使用[自定义图元](/viz/plot/mark/custom-mark)。
- 坐标 definition 负责 frame 与 guides，不应直接生成业务图元或包含 renderer 专属对象。

## 定义能力

`defineCoordinate<TCoordinateOperation>` 接收以下契约：

| 字段           | 作用                                                                    |
| -------------- | ----------------------------------------------------------------------- |
| `schema`       | 校验自定义 coordinate operation；非内置字面量 `type` 是注册键           |
| `roles`        | 声明坐标系需要的位置通道及其顺序                                        |
| `scaleBinding` | 可选地把统一位置 role 映射到 operation 自有的命名比例尺字段             |
| `resolve`      | 从 operation、数据域、scales、画布和 guides 构造 `CoordinateResolution` |

`resolve` 返回的 `frame` 负责点与可选 Cell 投影；`plotArea` 描述绘图区；`axisLayers` 和 `gridLayers` 交付 guide 产物。

省略 `scaleBinding` 时，Plot 按 role 同名字段读取和写入比例尺，例如 `roles: ['x', 'y']` 对应 `operation.x` / `operation.y`。如果 operation 使用领域字段名，definition 通过同一 hook 完成双向映射：

```ts
scaleBinding: {
  read: operation => ({ x: operation.horizontalScale, y: operation.verticalScale }),
  bind: (operation, scaleNames) => ({
    ...operation,
    horizontalScale: scaleNames.x,
    verticalScale: scaleNames.y,
  }),
}
```

该 hook 只存在于运行时 Definition，不进入 JSON IR。Chart 用替换坐标系时也通过这份契约继承 recipe 的位置比例尺；显式 coordinate binding 和 encoding binding 仍按顺序覆盖。`bind` 必须保留 `archHeight` 等无关配置，返回值会再次通过 definition schema。

## 注入宿主

通过 `<Plot coordinates={[bridgeCoordinate]}>` 注入 definition，并在 coordinate operation 中引用它：

```tsx
<Plot coordinate={{ type: 'bridge', archHeight: 60 }} coordinates={[bridgeCoordinate]}>
  <PointMark x="x" y="y" />
</Plot>
```

任意位置 role 不受 React mark props 的名称集合约束，但需要写完整 spec：

```ts
const spec = {
  // ...
  coordinate: { type: 'uv' },
  marks: [{ type: 'point', encoding: { u: { field: 'u' }, v: { field: 'v' } } }],
};
```

此时仍要把 `roles: ['u', 'v']` 的 definition 作为 `<Plot coordinates>` 或 `renderPlot` options 注入。投影函数留在宿主，IR 只保存 type、配置和绑定。

## 执行机制

1. 宿主把内置与自定义 coordinate definitions 合并为 registry，并校验 role 名和重复 type。
2. lowering 按 `coordinate.type` lookup；未命中时直接报错，命中后用 definition schema 校验 JSON operation。
3. 需要跨 coordinate 保留命名比例尺时，宿主通过 `scaleBinding` 在统一 role 与 operation 字段之间读写，并再次校验 operation。
4. `CoordinateDefinitionResolveContext` 收集各 role 的数据域，解析 position scales，并提供画布与 guide 信息。
5. `resolve` 用 `createCoordinateFrame` 构造 frame，再返回 `plotArea`、轴和网格层。
6. mark 通过 `frame.projectRoles` 或可选的 `frame.projectCell` 投影；声明 placement 时则使用同源的 `mapRoles` / `projectMappedRoles` 两段能力。

`createCoordinateFrame` 可以接收 `roleScales`、`mapRoles`、`projectMappedRoles`、`placementBoundary`、`frameAlong` 和 `projectCell`。位置调整依赖前三项拆分 scale 映射与投影，自动 containment 再使用边界度量；`projectCell` 把逻辑 Cell 投影成 rect、sector 或 contour 等几何。

## 错误与限制

- 自定义 `type` 不能覆盖内置坐标系，也不能重复注册；IR 引用未注册 type 时，lowering 会要求通过本次宿主 options 注入 definition。
- 缺少必填 role、出现坐标系不支持的 encoding key，或 schema 校验失败时都会直接报错。
- `scaleBinding.bind` 返回不符合 schema 的 operation 时会直接失败；自定义字段映射必须保留其它 operation 配置。
- 示例使用 `z.strictObject`；`archHeigth` 之类未知键不会被静默剥离或回退默认值。
- 普通点类图元只需要 `projectRoles`；Point placement 需要 `roleScales`、`mapRoles` 与 `projectMappedRoles`，要求 containment 时还需要 `placementBoundary`。
- 区间类图元需要匹配的 `roleScales` 与 `projectCell`。
- 自定义坐标系使用 definition 返回的 `plotArea`，不会自动继承 cartesian 的 margin 与 legend 预留逻辑。
- 曲线轴可以通过 `lowerCustomAxis` 生成；网格、三维空间和多 plot 组合需要 definition 显式提供对应能力。

下面的 operation 会因拼错配置键而失败：

```ts
coordinate: { type: 'bridge', archHeigth: 60 }
```

## API 参考

公开导出：

| 从 `@retikz/plot` 导入               | 用途                                                   |
| ------------------------------------ | ------------------------------------------------------ |
| `defineCoordinate`                   | 从 schema、roles 与 resolve 构造 coordinate definition |
| `CoordinateDefinition`               | 查询 role 与 resolve 的完整运行时契约                  |
| `CoordinateScaleBinding`             | 声明 role 与 operation 比例尺字段之间的双向映射        |
| `CoordinateDefinitionResolveContext` | 查询数据域、scale、画布和 guide 解析入口               |
| `createCoordinateFrame`              | 构造统一的点、切向与可选 Cell 投影 frame               |
| `readCoordinateScaleNames`           | 按 Definition 读取统一 role 的命名比例尺               |
| `bindCoordinateScaleNames`           | 按 Definition 写回并重新校验 coordinate operation      |

宿主注入：

| 宿主                                   | 公开契约            | 注入字段                             |
| -------------------------------------- | ------------------- | ------------------------------------ |
| `@retikz/plot-react` 的 `<Plot>`       | `PlotProps`         | `coordinates`                        |
| `@retikz/plot-vanilla` 的 `renderPlot` | `RenderPlotOptions` | 继承 `LowerPlotsOptions.coordinates` |
