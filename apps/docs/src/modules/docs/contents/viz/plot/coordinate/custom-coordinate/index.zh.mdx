坐标系把位置值映射成屏幕几何。内置坐标系无法表达目标空间时，可以用 `defineCoordinate` 声明运行时投影；Plot IR 仍只保存自定义 `type` 和 JSON 配置。

## 适用边界

- 需要新的位置 role、投影函数、曲线轴或特殊空间时，定义自定义 coordinate。
- 只改变值域映射而不改变空间投影时，优先使用[自定义比例尺](/viz/plot/scale/custom-scale)。
- 只改变图元几何时，使用[自定义图元](/viz/plot/mark/custom-mark)。
- 坐标 definition 负责 frame 与 guides，不应直接生成业务图元或包含 renderer 专属对象。

## 定义能力

`defineCoordinate<TCoordinateOperation>` 接收以下契约：

| 字段      | 作用                                                                    |
| --------- | ----------------------------------------------------------------------- |
| `schema`  | 校验自定义 coordinate operation；非内置字面量 `type` 是注册键           |
| `roles`   | 声明坐标系需要的位置通道及其顺序                                        |
| `resolve` | 从 operation、数据域、scales、画布和 guides 构造 `CoordinateResolution` |

`resolve` 返回的 `frame` 负责点与逻辑 Cell 的投影；`plotArea` 描述绘图区；`axisLayers` 和 `gridLayers` 交付 guide 产物。

## 注入宿主

通过 `<Plot coordinates={[bridge]}>` 注入 definition，并在 `coordinate` operation 中引用它：

```tsx
<Plot coordinate={{ type: 'bridge', archHeight: 60 }} coordinates={[bridge]}>
  <PointMark x="x" y="y" />
</Plot>
```

Vanilla 入口通过 `renderPlot` options 注入相同 definitions。`roles` 和投影函数留在宿主；IR 中只保存 `{ type: 'bridge', archHeight: 60 }`。

## 执行机制

1. 宿主把内置与自定义 coordinate definitions 合并为 registry。
2. lowering 按 `coordinate.type` 找到 definition，并用其 schema 校验 operation。
3. `CoordinateResolveContext` 收集各 role 的数据域、解析 position scales，并提供画布与 guide 信息。
4. `resolve` 用 `createCoordinateFrame` 构造 frame，再返回 `plotArea`、轴和网格层。
5. mark 通过 `frame.projectRoles` 或 `frame.projectCell` 投影，而不感知具体坐标系实现。

`createCoordinateFrame` 的 capabilities 可提供 `roleScales` 和 `projectCell`。前者让自定义轴与区间图元读取每个 role 的 scale；后者把逻辑 Cell 投影成 rect、sector 或 contour 等几何。

## 错误与限制

- 自定义 `type` 不能覆盖内置坐标系，也不能重复注册。
- 缺少必填 role、出现坐标系不支持的 encoding key，或 definition schema 校验失败时，lowering 会直接报错。
- 点类图元只需要 `projectRoles`；区间类图元还需要匹配的 `roleScales` 与 `projectCell`。
- 自定义坐标系默认使用 definition 返回的 `plotArea`，不会自动继承 cartesian 的 margin 与 legend 预留逻辑。
- 曲线轴可以通过 `lowerCustomAxis` 生成；网格、三维空间和多 plot 组合需要 definition 提供对应能力，不能假设自动可用。

## API 参考

| API                        | 用途                                                   |
| -------------------------- | ------------------------------------------------------ |
| `defineCoordinate`         | 从 schema、roles 与 resolve 构造 coordinate definition |
| `CoordinateDefinition`     | 自定义坐标系的运行时契约                               |
| `CoordinateResolveContext` | 数据域、scale、画布和 guide 的解析上下文               |
| `createCoordinateFrame`    | 构造统一的点 / Cell 投影 frame                         |
| `coordinates`              | React / Vanilla 宿主的 definition 注入点               |
