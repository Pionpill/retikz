title: PathMark
description: 'PathMark is a one-dimensional trajectory made from ordered points; lines, closed paths, multi-series lines, and radar outlines are presentation forms of the same mark.'
---

`<PathMark>` produces one 1D trajectory from a set of data rows. It projects each row into a point, sorts the points by `order`, and lowers the result into a core `Path`. Under cartesian2D it is usually a line; under polar2D it can become a polar path or a radar outline.

`x` / `y` bind position channels, `order` decides connection order, `series` decides whether to split into multiple paths, `curve` decides how adjacent points connect, and `closure` decides whether the path closes by baseline or by cycle. PathMark currently supports cartesian2D and polar2D.

## Usage

```tsx
import { PathMark, Plot } from '@retikz/plot-react';
```

```tsx
<Plot data={revenue}>
  <PathMark x="month" y="revenue" order="month" />
</Plot>
```

Set `order` explicitly. Otherwise PathMark follows data array order, so a different row order changes the path shape.

### When to Use

PathMark is a low-level line mark: it only connects a set of ordered anchors into one 1D trajectory. It does not care whether the presentation layer calls that trajectory a line chart, trend line, outline, or radar outline; those are interpretations of the same PathMark.

The presentation form mainly changes through three groups of props: position channels decide where points come from, series channels decide how many paths are produced, and geometry props decide whether the path closes as a line or as a fillable area.

| Presentation form | Key props           | Behavior                                                                                                          |
| ----------------- | ------------------- | ----------------------------------------------------------------------------------------------------------------- |
| Line              | `x` / `y` / `order` | Project each row into a point, then connect the points in order                                                   |
| Multi-series line | `series` / `color`  | Split rows by series first, then produce one path per group                                                       |
| Radar outline     | `polar2D`           | Polar paths close by default; set `closed={false}` for an open path                                               |
| Path area         | `closure` / `fill`  | Close the path by cycle, constant baseline, or per-row stacked baseline; set `fill` explicitly to fill the result |

### Connection and Style

`curve` controls how neighboring points connect. Stroke color, width, dash, and opacity only change the path appearance. Gray points remain fixed references for checking whether a curve passes through the observations; `monotoneX` / `monotoneY` fall back to `linear` under polar2D.

### Closure and Fill

An open path only traces the trajectory. `cycle` joins the last point back to the first, while `baseline` returns the path to a fixed lower boundary. `closure` only constructs a fillable boundary; `fill` must still be set explicitly to reveal the area.

<ComponentPreview
  files={['line-closure', 'line-closure.data.ts']}
  controls={{ name: 'line-closure' }}
  size="lg"

When `baseline` is omitted, it follows the value axis: use 0 when 0 is inside the domain, otherwise use the domain edge nearest 0. Per-row stacked lower bounds use `closure={{ kind: 'stack', baselineField: ... }}`.

### Missing Values

When a row cannot project into a valid point, PathMark breaks there and lowers the surrounding runs into separate core `Path` elements. `connectNulls` can bridge the gap; area fills follow the same segmentation and do not cover missing intervals by default.

## How it works

<ComponentAlert
  type="tip"
  title="You can skip this section at first"
  description="Return when debugging series splitting, missing-value breaks, polar closure defaults, or anchorId output."
/>

`<PathMark>` is dispatched from `IRPlotSpec` through the mark registry to path lowering. It accepts cartesian2D and polar2D only because those frames provide an ordered trajectory for the required position roles; unsupported frames fail loudly.

| Stage               | Observable behavior                                                                                                                                    |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Order and group     | Rows split by `series` and then sort by `order`; without `series`, a categorical `color` field can split implicit series                               |
| Project and segment | Each row projects to a point; invalid points break the trajectory unless `connectNulls` is enabled                                                     |
| Connect and close   | `curve` controls adjacent segments; `closed` joins last to first, while `closure` creates cycle, baseline, or stack boundaries                         |
| Lower               | Every continuous segment becomes a core `Path`; series form child layers, and `anchorId` additionally creates referenceable core `Coordinate` vertices |

Series child layers preserve the same semantic grouping across renderers; missing values can further split each series into one or more continuous Path segments.

`fill` only paints an existing closed boundary; it does not close an open path. When missing values create multiple continuous segments, each segment closes and fills independently instead of spanning the gap.

## API Reference

This table keeps only PathMark-specific props and props whose meaning is redefined here. See [channel bindings](/viz/plot/channel/binding) for field and constant inputs, [transforms](/viz/plot/transform) for local `transform` and layer props, and [coordinates](/viz/plot/coordinate) for coordinate-view props. Shared stroke, fill, marks, dash, corner, and shadow props follow [Path styling](/kernel/components/draw/path#styling) and are not duplicated here.

| Prop            | Type                                                                                                                                      | Default                                                                       | Description                                                                                                                                                                                  |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id?`           | `string`                                                                                                                                  | —                                                                             | Mark handle; required with `resolveLabel`                                                                                                                                                    |
| `x` / `y`       | `PathMarkProps['x']`                                                                                                                      | Required                                                                      | Trajectory position roles; cartesian2D uses planar positions and polar2D uses angular / radial positions                                                                                     |
| `order?`        | `PathMarkProps['order']`                                                                                                                  | Data order                                                                    | Connection order within each series                                                                                                                                                          |
| `series?`       | `PathMarkProps['series']`                                                                                                                 | —                                                                             | Split rows into independent paths                                                                                                                                                            |
| `color?`        | `PathMarkProps['color']`                                                                                                                  | `series`                                                                      | Path color field; a categorical color field can also split series when `series` is absent                                                                                                    |
| `curve?`        | <ApiValues name="PathCurve" />                                                                                                            | `linear`                                                                      | Connection between adjacent points; `monotoneX` / `monotoneY` fall back to `linear` under polar2D                                                                                            |
| `connectNulls?` | `boolean`                                                                                                                                 | `false`                                                                       | Connect across rows that cannot be projected                                                                                                                                                 |
| `closed?`       | `boolean`                                                                                                                                 | cartesian2D: `false`<br />polar2D: `true`                                     | Join the last point back to the first                                                                                                                                                        |
| `closure?`      | `IRPlotPathClosure`<br />- `kind: 'cycle' \| 'baseline' \| 'stack'`<br />- `baseline?: number`<br />- `baselineField: PathMarkProps['x']` | —<br />Required<br />0 or the domain edge nearest 0<br />Required for `stack` | Build a fillable boundary<br />Choose cycle, constant baseline, or per-row baseline<br />Constant lower boundary used only by `baseline`<br />Per-row lower-bound field used only by `stack` |
| `label?`        | `PathMarkProps['label']`                                                                                                                  | —                                                                             | Path or segment labels; content and placement fields follow the TypeScript `PathMarkProps['label']` contract                                                                                 |
| `resolveLabel?` | `(row: ExternalRow) => string`                                                                                                            | —                                                                             | Runtime label resolver; excluded from IR and requires `id`                                                                                                                                   |
| `anchorId?`     | `IRPlotAnchorIdSpec`                                                                                                                      | —                                                                             | Generate a stable core Coordinate id for each valid path vertex                                                                                                                              |
