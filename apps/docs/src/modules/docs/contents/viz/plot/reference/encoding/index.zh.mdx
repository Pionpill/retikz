---
title: 契约 - 编码
description: 查询 Plot 字段、常量、位置、视觉通道与图元标签编码 schema。
---

编码把数据行映射到位置角色或视觉变量。通用 `ChannelSchema` 必须且只能指定 `field` 或 `value` 中的一个；位置通道的比例尺由坐标系拥有，非位置通道通常显式引用 scale。
