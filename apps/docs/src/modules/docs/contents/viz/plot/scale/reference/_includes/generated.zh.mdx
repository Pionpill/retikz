#### <ApiSourceLink label={"PositionScale"} path={"packages/viz/plot/src/contract/scale.ts"} startLine={35}>PositionScale</ApiSourceLink>

把「band 起点 vs 中心」「bandwidth 是否为 0」「类别 vs 数值刻度」收进一层；
下游（projector / guide / bar）只认 coordinate + bandwidth + ticks，不各自分支 scale 类型。
连续 scale 使用 bandwidth=0 + coordinate=scale(value)，与 band / point scale 对齐到同一接口

## 域留白与辅助值

#### <ApiSourceLink label={"IRPlotDomainPadding"} path={"packages/viz/plot/src/schemas/scale/types.ts"} startLine={35}>IRPlotDomainPadding</ApiSourceLink> / <ApiSourceLink label={"DomainPaddingSchema"} path={"packages/viz/plot/src/schemas/scale/schema.ts"} startLine={77}>DomainPaddingSchema</ApiSourceLink>


<DocTab value="schema" label="Schema">

连续位置比例尺共用 `domainPadding` 和 `singleValueSpan`。`domainPadding` 的裸数字与省略 kind 的对象使用 range 单位；`kind: 'ratio'` 才使用原始 domain 跨度比例。两种 domain 来源默认都不扩展。

`kind: 'mark'` 引用具名图元按外缘求解自动端，可选 `lower` / `upper` 固定一端。内置支持 linear/time 与无 placement 的 Cartesian2D；能力和失败边界见 [按图元外缘留白](/viz/plot/scale/position#按图元外缘留白)。

mark 分支的 `clearance` 是图元外缘到自动边界的最小净空，使用非负 range 单位，默认 `0`。例如 `{ kind: 'mark', marks: ['dots'], clearance: 8 }`。固定端不叠加净空；空有效点集不扩域，净空过大导致无解时会报错。

`clearance` 支持数值或 `{ lower?: number, upper?: number }`；数值同时用于两端，对象未指定端为 `0`。这里的 lower / upper 对应 domain 起止端，跟随 range 方向，不固定对应视觉左右；Chart 负责将四边净空转换为各轴的这两个端。
