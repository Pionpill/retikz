---
title: 一维坐标系
description: 一维坐标系把一个位置字段放到直线或圆周上，适合沿轴事件点、时间线与周期事件。
---

当数据只需要沿一条路径定位时，不必再补一个没有意义的第二位置字段。一维说的是参与定位的维度数量，不是坐标轴是否可见：`cartesian1D` 读取 `x` 并把值放到直线上，`polar1D` 则把值绕到圆周上。

## 映射之后继续组合

一维坐标不必成为最终图形，它也可以先把对象排到一条线上，再让这些结果参与连线。下图把 12 个上层对象排到横线上，每 4 个对象连接到下方同一个汇总点，最终形成 3 组。

在同一个 Plot 内，`PointMark` 先用 `thingX` 把单个位置字段映射为 core Node，再用局部 `summarize` 将重复的目标字段折叠成 3 个下层 Node。`anchorId` 为这些映射结果提供稳定 id，`RelationMark` 因而能让每 4 个来源 Node 引用同一个目标 Node。映射后的结果还可以继续参与汇聚连线、标注等二次操作。

## 选择与配置

| 目标     | 坐标配置                                              | 关键配置                        |
| -------- | ----------------------------------------------------- | ------------------------------- |
| 横向直线 | `coordinate="cartesian1D"`                            | `orientation: 'horizontal'`     |
| 纵向直线 | `{ type: 'cartesian1D', orientation: 'vertical' }`    | `orientation: 'vertical'`       |
| 完整圆周 | `coordinate="polar1D"`                                | `radius: 1`、角度 `0` 到 `360`  |
| 部分圆周 | `{ type: 'polar1D', startAngle: 180, endAngle: 360 }` | 使用 `startAngle` 和 `endAngle` |

两种对象写法都是 `<Plot>` 的 `PlotDslProps['coordinate']` 输入。底层 `InputPlotCoordinate` 是 `@retikz/plot-vanilla` 的 TypeScript 类型，不由 Plot React 重复定义；`cartesian1D` 默认横向，`polar1D` 的 `radius` 默认是 `1`，表示占满可用外半径，取值范围是 `0 < radius <= 1`，不是像素值。角度使用度数，默认从 `0` 到 `360`。

试验场中的“扫过角度”是便于探索的教学控件，不是 `PlotDslProps['coordinate']` 字段。它在内部换算为 `endAngle = startAngle + sweepAngle`。

坐标维度的数量不会限制比例尺类型；这个位置字段仍可使用 linear、log 或 time 等比例尺。示例显式把小时 domain 固定为 `[0, 24]`，因此 `22` 小时会落在完整圆周的 `330°`。

需要一维坐标直接投影位置的 mark 目前只有 `<PointMark>`，适合沿轴事件点、时间线节点或圆周事件点；`RelationMark` 可以像上图一样引用已经定位的目标。柱、扇区和面积需要二维区域，在一维坐标中会报错。
