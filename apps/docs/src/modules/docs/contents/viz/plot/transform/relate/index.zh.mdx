需要从每个分组中挑出两个代表行并建立关系时用 `relate`。它为 source 和 target 分别运行 selector，再投影端点字段并计算可选度量；每个分组输出零行或一行。

`relate` 常放在 `RelationMark.transform` 中，但不是 RelationMark 私有能力。它产生普通派生字段，也可以交给其它图元。

## 行配对

`relate` 把“选择哪两行”和“输出哪些端点字段”拆成两个独立端点配置。source 与 target 可以使用不同 selector，但都在同一个 `groupBy` 分组内运行。

### 动态示例

切换全局或按系列配对，并为 source 与 target 独立选择首行、末行、最低值或最高值。数据表保持展开，便于直接对照箭头端点、方向和差值标签。

<ComponentPreview files={['transform-relate', 'transform-relate.data.ts']} size="md" />

按系列配对时，每条序列各输出一条关系；切到全部数据时，只输出一条全局关系。示例投影 `sourceId` / `targetId`，再计算 `target.value - source.value`。`PathMark` 和 `PointMark` 继续读取源数据，只有 `RelationMark` 的局部 transform 读取配对结果。

### API 参考

`IRPlotRelateTransform` 的 `kind` 固定为 `'relate'`。

| prop        | 类型                                | 默认值   | 说明                                |
| ----------- | ----------------------------------- | -------- | ----------------------------------- |
| `groupBy?`  | `Array<string>`                     | 全局单组 | 每组独立生成零个或一个关系行        |
| `source`    | `IRPlotEndpointProjection`          | —        | source 端点 selector 与非空字段映射 |
| `target`    | `IRPlotEndpointProjection`          | —        | target 端点 selector 与非空字段映射 |
| `measures?` | `Array<IRPlotPairMeasureOperation>` | —        | source 与 target 之间的派生度量     |

`IRPlotEndpointProjection` 包含：

| prop       | 类型                      | 说明                            |
| ---------- | ------------------------- | ------------------------------- |
| `selector` | `IRDataSelectorOperation` | 在当前组内选择端点候选行        |
| `fields`   | `Record<string, string>`  | 非空“输出后缀 → 端点行字段”映射 |

例如 `source.fields: { id: 'id', x: 'month' }` 会输出 `sourceId` 和 `sourceX`。`measures` 当前内置 <ApiValues name="PairMeasureOperationKind" />；`difference` 计算 `target[field] - source[field]`，并可写出数值字段和标签字段。

### 技术原理

图中的 source 与 target 是并行选择，不是先后过滤。两端都选中后才汇合投影字段和计算度量，因此每组最多输出一条关系行。

<ComponentPreview files="transform-relate-logic" hideCode size="xl" />

执行过程分为四步：

1. `groupBy` 先建立独立分组；省略时所有输入行属于同一组。
2. source 与 target 各自调用共享 data selector，并各取 selector 结果的第一行。
3. `fields` 把端点字段写成 `sourceXxx` / `targetXxx`；`measures` 再读取两端原始行计算派生值。
4. 两端都存在时输出一行并记录二者来源；任一端点没有选中行时直接跳过该组，不输出空字段占位。

每个端点的 `fields` 必须是非空映射。`labelPrefix` 只在差值非负时添加到标签文本，不改变数值字段。
