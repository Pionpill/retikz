---
title: regression · Fitting
description: Fit prediction models with six built-in methods and compare curves with fitted values at the original observation positions.
---

Fitting estimates the coefficients of a chosen formula from $(x,y)$ observations and returns a callable prediction model. Call `resolveRegression(method).fit(rows)` to obtain the model, then `predict(x)` to calculate predictions. The model exists only at runtime and is not stored in IR. The curve need not pass through every observation.

Each method below has its own demo. The default graph shows gray observations and a blue fitted curve. In table mode, the left table keeps the original `x,y`; the right table adds a blue `fittedY` column to the same 9 observations. This column is a demo projection calculated from the model, not a field automatically added by the fitting operator. Orange marks the data used for fitting. Both views use the same model; sample count only changes the number of prediction points in the graph.

To use fitting through the [`smooth` host](/viz/data/transform/statistics), place the method declaration in `params.method`. `smooth` reads observations whose `x,y` are both finite numbers, without converting numeric strings, and generates separate prediction rows: 64 per group by default. Its default sampling range spans valid observed $x$ values and does not filter fitting observations. Prediction rows do not automatically preserve other original fields. Insufficient observations, a rank-deficient matrix or non-finite predictions cause computation to fail.

## linear · Linear

`linear` fits the line $y=a+bx$ by least squares. It describes relationships with an approximately constant rate of change. It requires at least two valid observations with varying $x$. Its Schema is `BuiltinRegressionMethodSchemas.Linear`. Parameters:

| Property | Type       | Description    |
| -------- | ---------- | -------------- |
| `kind`   | `'linear'` | Fitting method |

## quadratic · Quadratic

`quadratic` fits $y=a+bx+cx^2$ by least squares. It can describe curvature or a single turning point. It requires at least three distinct $x$ values. Its Schema is `BuiltinRegressionMethodSchemas.Quadratic`. Parameters:

| Property | Type          | Description    |
| -------- | ------------- | -------------- |
| `kind`   | `'quadratic'` | Fitting method |

## polynomial · Polynomial

`polynomial` fits $y=a_0+a_1x+\cdots+a_dx^d$ by least squares. `order` sets the degree $d$; the observations determine the coefficients. A degree-$d$ fit requires at least $d+1$ distinct $x$ values. Higher degrees can increase fluctuations between observations or outside their range and are not necessarily a better choice. Its Schema is `BuiltinRegressionMethodSchemas.Polynomial`. Parameters:

| Property | Type           | Description                                              |
| -------- | -------------- | -------------------------------------------------------- |
| `kind`   | `'polynomial'` | Fitting method                                           |
| `order`  | `number`       | Optional integer from 2 to 6, default 3; sets the degree |

## logarithmic · Logarithmic

`logarithmic` fits $y=a+b\ln x$, which can describe a gradually slowing change. It applies linear least squares after taking the logarithm of $x$ and predicts $y$ in the original space. It requires at least two valid observations with varying $x$. Observed and predicted $x$ values must be positive. Its Schema is `BuiltinRegressionMethodSchemas.Logarithmic`. Parameters:

| Property | Type            | Description    |
| -------- | --------------- | -------------- |
| `kind`   | `'logarithmic'` | Fitting method |

## exponential · Exponential

`exponential` fits $y=ae^{bx}$, which can describe proportional growth or decay. It applies linear least squares to the logarithm of $y$, then converts predictions back to the original space. It minimizes error in logarithmic space. It requires at least two valid observations with varying $x$ and positive observed $y$. Its Schema is `BuiltinRegressionMethodSchemas.Exponential`. Parameters:

| Property | Type            | Description    |
| -------- | --------------- | -------------- |
| `kind`   | `'exponential'` | Fitting method |

## power · Power

`power` fits $y=ax^b$ to describe power-law relationships. It applies linear least squares after taking the logarithm of both $x$ and $y$, then converts predictions back to the original space. It minimizes error in logarithmic space. It requires at least two valid observations with varying $x$, positive observed $x$ and $y$, and positive prediction positions. Its Schema is `BuiltinRegressionMethodSchemas.Power`. Parameters:

| Property | Type      | Description    |
| -------- | --------- | -------------- |
| `kind`   | `'power'` | Fitting method |
