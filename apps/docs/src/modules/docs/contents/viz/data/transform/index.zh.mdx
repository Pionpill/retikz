title: 数据变换
description: 数据变换在数据模型接入之后改写 canonical 行，覆盖排序、汇总、代表行选择、统计标注以及自定义 transform definition。
---

数据变换属于 `@retikz/data`：它们只读取 canonical 行并输出新的 canonical 行，不依赖 plot 的 mark、scale 或坐标系。plot 可以把这些 transform 放在 `<Transform>`、`dataTransforms` 或 mark-local `transform` 里使用；table / geo 后续也可以复用同一组数据能力。

plot 另外注册的绘图变换仍放在[绘图语法的变换](/viz/grammar/transform)里说明，例如 `stack`、`bin`、`normalize`、`derive-interval`、`jitter`、`density`、`smooth` 和 `relate`。这一页只讲 data 包自带的数据变换能力。

## 能力一览

| kind        | 行数       | 数据语义                            | 常见消费者                 |
| ----------- | ---------- | ----------------------------------- | -------------------------- |
| `sort`      | N → N      | 按字段稳定重排行                    | 折线顺序、堆叠前置整理     |
| `summarize` | N → G      | 按组生成统计行                      | 分组柱、汇总表、统计摘要   |
| `select`    | N → K      | 按组选择原始代表行                  | 极值点、top-N、异常样本    |
| `annotate`  | N → N      | 把组统计或代表值广播回每一条明细行  | 均值线、阈值标签、上下文层 |
| custom      | 取决于定义 | 由 `defineTransform` 注册运行时逻辑 | 业务专用派生或长尾数据形态 |

这些 operation 本身是 JSON 可序列化配置；真正的运行函数来自 data 包内置定义或运行时注入的 definition。变换读取字段会参与 model 校验，变换产出的字段不需要提前写进 model。

## 排序 sort

`sort` 按一个字段稳定重排行。等值时保留原始相对顺序，适合在折线连接、时间序列展示或后续分组处理前固定行序。

注意把它和数据模型里的 [`order`](/viz/data/model#分类顺序) 分开：`sort` 排的是数据行，`order` 排的是分类域。

<ComponentPreview name="transform-sort" sourceFiles={['transform-sort.data.ts']} />

| prop    | 类型                           | 默认值        | 说明     |
| ------- | ------------------------------ | ------------- | -------- |
| `field` | `string`                       | —             | 排序字段 |
| `order` | `'ascending' \| 'descending'?` | `'ascending'` | 排序方向 |

## 汇总 summarize

`summarize` 按 `groupBy` 分组，并用 `metrics` 把每组明细规约成一行。输出行保留组键，每个 reducer 都必须显式写 `as` 字段名。

<ComponentPreview name="transform-summarize" sourceFiles={['transform-summarize.data.ts']} />

| prop      | 类型             | 默认值   | 说明                                   |
| --------- | ---------------- | -------- | -------------------------------------- |
| `groupBy` | `Array<string>?` | 全局单组 | 分组键字段，支持复合键                 |
| `metrics` | `Array<Reducer>` | —        | 组内统计指标，每个 reducer 必须写 `as` |

```tsx
<Transform
  kind="summarize"
  groupBy={['region']}
  metrics={[
    { op: 'sum', field: 'revenue', as: 'total' },
    { op: 'median', field: 'revenue', as: 'median' },
    { op: 'count', as: 'orders' },
  ]}
/>
```

## 代表行选择 select

`select` 按组运行 selector，并输出被选中的原始行。它不会把数值规约成新的统计值，适合保留城市名、id、锚点等原始字段，同时只保留组内极值或 top-N。

<ComponentPreview name="transform-select" sourceFiles={['transform-select.data.ts']} />

| prop       | 类型             | 默认值   | 说明                         |
| ---------- | ---------------- | -------- | ---------------------------- |
| `groupBy`  | `Array<string>?` | 全局单组 | 分组键字段                   |
| `selector` | `Selector`       | —        | 组内代表行选择规则           |
| `rankAs`   | `string?`        | —        | 可选，把一基 rank 写入该字段 |

```tsx
<Transform kind="select" groupBy={['region']} selector={{ op: 'top', by: 'revenue', n: 3 }} rankAs="rank" />
```

## 统计标注 annotate

`annotate` 先按 `groupBy` 分组，再把 reducer 结果或 selector 选中的代表值回填到组内每一行。它适合在明细点旁边画组均值线、组中位数带、分组阈值等上下文层。

<ComponentPreview name="transform-annotate" sourceFiles={['transform-annotate.data.ts']} />

| prop        | 类型                                         | 默认值   | 说明                                                                                                              |
| ----------- | -------------------------------------------- | -------- | ----------------------------------------------------------------------------------------------------------------- |
| `groupBy`   | `Array<string>?`                             | 全局单组 | 分组键，支持复合键                                                                                                |
| `metrics`   | `Array<Reducer>?`                            | —        | 要广播回每行的统计指标                                                                                            |
| `selectors` | `Array<{ selector: Selector; as: string }>?` | —        | 要广播回每行的代表行取值；`min` / `max` / `top` / `bottom` 读取 selector 的 `by` 字段，其余 selector 回填选中名次 |

```tsx
<Transform
  kind="annotate"
  groupBy={['store']}
  metrics={[{ op: 'mean', field: 'revenue', as: 'storeMean' }]}
  selectors={[{ selector: { op: 'max', by: 'revenue' }, as: 'storeMax' }]}
/>
```

## reducer 与 selector

`summarize`、`annotate` 和 plot 注册的 `bin` 会复用 reducer；`select`、`annotate` 和 plot 注册的 `relate` 会复用 selector。

| 子算子   | 返回什么 | 典型 op                                                                               |
| -------- | -------- | ------------------------------------------------------------------------------------- |
| reducer  | 字段片段 | `count` / `sum` / `mean` / `median` / `min` / `max` / `quantile-band`                 |
| selector | 原始行   | `min` / `max` / `first` / `last` / `top` / `bottom` / `nth` / `outside-quantile-band` |

`quantile-band` 用 `lowerP` 和 `upperP` 定义任意分位区间，不固定成 q1 / q3。`outside-quantile-band` 是 selector，所以它输出原始行，适合保留 id、标签和 provenance。

<ComponentPreview name="transform-boxplot" sourceFiles={['transform-boxplot.data.ts']} />

上面的箱线图没有专用 `BoxPlotMark`。data transform 负责产出箱体、中位数、须线和区间外原始点；plot 只用 `IntervalMark`、`ReferenceMark` 和 `PointMark` 消费这些字段。

## 自定义 transform

输入 / 输出行结构不属于现有 transform 形态时，用 `defineTransform` 注册完整运行时 definition。definition 不进入 JSON IR；IR 只保存 `{ kind, ...config }`，运行时通过 transform definition 集合注入执行逻辑。

<ComponentPreview name="transform-custom" sourceFiles={['transform-custom.data.ts']} />

| definition 字段 | 负责声明                                              | 进入 IR |
| --------------- | ----------------------------------------------------- | ------- |
| `schema`        | 校验 `{ kind, ...config }` 并提取注册键               | 否      |
| `inputFields`   | 读取哪些源字段，参与 strict model 校验                | 否      |
| `outputFields`  | 产生哪些派生字段，从 strict model 中排除              | 否      |
| `apply`         | 运行时行处理逻辑 `(rows, operation, context) => rows` | 否      |
