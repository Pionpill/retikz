---
title: Data Model
description: The data model binds external rows to a stable field contract and produces canonical rows reusable by data transforms and different consumers.
---

The data model answers four questions: which fields the configuration references, how external data binds to those fields, how bad values are diagnosed, and how to extend built-in behavior. Real rows stay outside the serializable configuration and arrive at runtime, so one field contract can be reused across data sources.

## Overall flow

<ComponentPreview files="data-model-pipeline" size="sm" hideCode />

Solid arrows show the data path: external rows are normalized before data transforms and consumer modules use them. The field contract feeds normalization with logical names, types, parsing formats, and category order; it describes data without containing rows or depending on a particular consumer.

## Responsibilities

| Topic                    | Responsibility                                             | Read it when                                       |
| ------------------------ | ---------------------------------------------------------- | -------------------------------------------------- |
| Field Contract           | Logical fields, measurement types, inference, and order    | You need stable, self-describing configuration     |
| Data Intake              | Physical paths, parsing, and canonical-row normalization   | You switch APIs, use nested data, or parse formats |
| Validation & Diagnostics | Skip, sample-check, or reject invalid participating values | You debug blank charts or enforce intake contracts |
| Extension Mechanisms     | Register field formats and runtime field resolution        | Built-in intake cannot express a storage format    |

The data model stops after producing canonical rows. [Data transforms](/viz/data/transform) own sorting, aggregation, and filtering, while each consumer decides how the result enters a view. In a Plot application, [Plot scales](/viz/plot/scale) own mappings to position, color, or size.
