---
title: 数据溯源
description: 数据溯源把数据行的来源、变换过程与 Plot 图元语义连接起来，让宿主能够回查、解释和审计一次可视化运行。
---

数据溯源从 Data 建立的来源身份与运行链路开始，再由 Plot 等消费模块补充自己的宿主语义。Data 负责回答“数据从哪里来、经历了什么”，Plot 负责回答“这些数据怎样成为图元”；两层产物保持各自的包边界和公开入口。

这组能力只在需要回查、诊断或审计时启用。运行时链路不会写入 JSON IR，Plot 的完整审计产物也不会自动进入 Scene 元数据。

## 职责一览

| 层级          | 职责                                       | 何时查阅                                 |
| ------------- | ------------------------------------------ | ---------------------------------------- |
| Data 来源追溯 | 传播行级来源，记录变换与统计操作的运行事件 | 解释数据行来源或检查数据处理过程         |
| Plot 溯源     | 补充图元、编码、比例尺、布局与定位语义     | 审计可视化运行或从命中图元回查到原始数据 |
