---
title: 数据模型
description: 数据模型把外部数据行接到稳定的字段契约上，生成供数据变换与不同消费模块复用的规范化行。
---

数据模型负责回答四个问题：配置里引用的字段是什么、外部数据怎样接入这些字段、遇到坏值时怎样诊断、内置能力不够时怎样扩展。真实数据行始终在运行时传入，不写进可序列化配置；同一份字段契约因此可以复用到不同数据源。

如果还不熟悉字段与测量类型，先读[字段类型](/viz/data/model/field-types)。

图中的实线表示数据主链：外部行经规范化后，才交给数据变换与消费模块。字段契约是规范化阶段的输入，负责提供逻辑字段名、类型、解析格式与分类顺序；它描述数据，不包含数据行，也不绑定某一种消费模块。

## 职责一览

| 主题     | 负责什么                                   | 何时阅读                         |
| -------- | ------------------------------------------ | -------------------------------- |
| 字段类型 | 声明字段、选择类型、理解推断与解析         | 首次使用数据模型时               |
| 数据接入 | 映射字段、解析格式、指定分类顺序与校验策略 | 接外部数据、排查空图或严格检查时 |
| 扩展机制 | 注册字段格式与运行时字段解析               | 内置接入能力无法表达存储格式时   |

数据模型负责到生成规范化行为止：数据怎样排序、汇总或筛选，由[数据变换](/viz/data/transform)负责；结果怎样进入具体视图，由消费模块决定。在 Plot 应用中，字段进入位置、颜色或尺寸后的映射由 [Plot 比例尺](/viz/plot/scale)负责。
