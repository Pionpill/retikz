---
title: Data Traceability
description: Data traceability connects row provenance, transformation history, and Plot semantics so hosts can inspect, explain, and audit a visualization run.
---

Data traceability begins with source identity and runtime lineage established by Data, then lets consumers such as Plot add their own host semantics. Data answers where data came from and what happened to it; Plot explains how that data became marks. Each layer keeps its own package boundary and public entry points.

Enable these capabilities only for trace-back, diagnostics, or audits. Runtime lineage does not enter JSON IR, and Plot's complete audit artifact is not automatically written into Scene metadata.

## Responsibilities

| Layer           | Responsibility                                                        | Reach for it when                                            |
| --------------- | --------------------------------------------------------------------- | ------------------------------------------------------------ |
| Data Provenance | Propagate row sources and record transform and statistical operations | Explaining row origins or inspecting data processing         |
| Plot Lineage    | Add mark, encoding, scale, layout, and locator semantics              | Auditing visualization runs or tracing marks back to sources |
