Data contracts store JSON-safe configuration only. Real rows, parsers, Definitions, registries, and callbacks are injected at runtime and never enter these schemas. See [Field Types](/viz/data/model/field-types) and [Transform Operations](/viz/data/transform/operations) for task-oriented behavior and usage.

Data-model definitions are documented in [Schema Reference](/viz/data/model/schema-reference).

## DataTransformSchema

<ZodSchema name="DataTransformSchema" />

Built-in transforms share a `kind` discriminator and execute in declaration order. See [Transform Operators](/viz/data/transform/statistics) for the reducer and selector contracts used by `metrics` and `selector`. A custom operation must stay JSON-serializable, while its runtime Definition supplies the precise schema and implementation.

Every transform operation uses `{ kind, params }`: `kind` selects its definition and `params` is a required JSON parameter object. Each `XxxParamsSchema` describes the parameters; `createTransformSchema` combines them with the kind into the complete schemas below. `defineTransform` uses the same factory. Statistical sub-operations retain their own formats.

### ReducerOperationSchema

<ZodSchema name="ReducerOperationSchema" />

| `kind`          | Fields                                                     | Result                                                           |
| --------------- | ---------------------------------------------------------- | ---------------------------------------------------------------- |
| `count`         | `as`                                                       | Output the row count                                             |
| `sum` / `mean`  | `field`, `as`                                              | Output a numeric-field sum or arithmetic mean                    |
| `median`        | `field`, `as`                                              | Output the numeric-field median                                  |
| `min` / `max`   | `field`, `as`                                              | Output the numeric-field minimum or maximum                      |
| `extent`        | `field`, `as`                                              | Output the numeric-field minimum/maximum extent                  |
| `quantile`      | `field`, `p`, `as`                                         | Output the quantile at probability `p`                           |
| `quantile-band` | `field`, `lowerP`, `upperP`, `outputs`, optional `whisker` | Output a band, extra quantiles, spread, and whiskers             |
| Custom `kind`   | JSON-safe config                                           | Parse and run through the matching `StatisticsReducerDefinition` |

## SelectorOperationSchema

<ZodSchema name="SelectorOperationSchema" />

| `kind`                  | Fields                                           | Selection result                                           |
| ----------------------- | ------------------------------------------------ | ---------------------------------------------------------- |
| `min` / `max`           | `by`, optional `tie`                             | Rows with the minimum or maximum numeric value             |
| `first` / `last`        | Optional `orderBy`                               | The first or last row in current or explicit order         |
| `top` / `bottom`        | `by`, `n`, optional `tie`                        | The highest- or lowest-ranked N rows                       |
| `nth`                   | `orderBy`, `index`                               | The zero-based row after explicit ordering                 |
| `outside-quantile-band` | `field`, `lowerP`, `upperP`, optional `boundary` | Rows outside a quantile band or spread fence               |
| Custom `kind`           | JSON-safe config                                 | Parse and run through the matching `RowSelectorDefinition` |

### AnnotateSelectorSchema

<ZodSchema name="AnnotateSelectorSchema" />

Annotate excludes `outside-quantile-band`. For `top` / `bottom`, `n` is fixed to `1`, and ties may select only the first or last row, so each annotation field maps to at most one source row.
