`@retikz/data` 内置四种通用 operation。它们只处理规范化行，不知道结果最终会进入图形、表格还是其它消费模块；本页用 Plot 作为默认示例宿主。

## 能力一览

| kind        | 行数  | 数据语义                         | 常见用途                   |
| ----------- | ----- | -------------------------------- | -------------------------- |
| `sort`      | N → N | 按字段稳定重排行                 | 固定时间顺序、整理后续输入 |
| `summarize` | N → G | 按组生成统计行                   | 分组汇总、统计摘要         |
| `select`    | N → K | 按组选择原始代表行               | 极值、top-N、异常样本      |
| `annotate`  | N → N | 把组统计或代表值广播回每条明细行 | 均值线、阈值标签、上下文层 |

## 排序 sort

`sort` 按一个字段稳定重排行。等值时保留原始相对顺序，适合在折线连接、时间序列展示或后续分组处理前固定行序。

`null`、`undefined`、`NaN` 与无穷值按 missing 处理，无论升序还是降序都稳定排在有效值之后。

注意把它和字段契约里的 [`order`](/viz/data/model/contract#分类顺序) 分开：`sort` 排的是数据行，`order` 排的是分类域。

<ComponentPreview files={['transform-sort', 'transform-sort.data.ts']} />

`IRDataSortTransform` 的 `kind` 固定为 `'sort'`。

| prop     | 类型                               | 默认值        | 说明     |
| -------- | ---------------------------------- | ------------- | -------- |
| `field`  | `string`                           | —             | 排序字段 |
| `order?` | <ApiValues name="DataSortOrder" /> | `'ascending'` | 排序方向 |

## 汇总 summarize

`summarize` 按 `groupBy` 分组，并用 `metrics` 把每组明细规约成一行。输出行保留组键，每个 reducer 都必须显式写 `as` 字段名。

同一个 operation 内的输出名必须唯一：reducer 输出不能与 `groupBy` 重名，也不能互相重名。内置 reducer 的静态字段冲突会在 schema 解析阶段报错；自定义 reducer 由 Definition `outputFields()` 声明的动态字段冲突会在执行 reducer 前报错。

<ComponentPreview files={['transform-summarize', 'transform-summarize.data.ts']} />

`IRDataSummarizeTransform` 的 `kind` 固定为 `'summarize'`。

| prop       | 类型                   | 默认值   | 说明                                      |
| ---------- | ---------------------- | -------- | ----------------------------------------- |
| `groupBy?` | `Array<string>`        | 全局单组 | 分组键字段，支持复合键                    |
| `metrics`  | `IRDataReducerMetrics` | —        | 组内统计指标，每个 reducer 必须写输出字段 |

```tsx
<Transform
  kind="summarize"
  groupBy={['region']}
  metrics={[
    { kind: 'sum', field: 'revenue', as: 'total' },
    { kind: 'median', field: 'revenue', as: 'median' },
    { kind: 'count', as: 'orders' },
  ]}
/>
```

## 代表行选择 select

`select` 按组运行 selector，并输出被选中的原始行。它不会把数值规约成新的统计对象，因此会保留城市名、id、锚点等原始字段，同时只留下组内极值、top-N 或异常行。

<ComponentPreview files={['transform-select', 'transform-select.data.ts']} />

`IRDataSelectTransform` 的 `kind` 固定为 `'select'`。

| prop       | 类型                      | 默认值   | 说明                   |
| ---------- | ------------------------- | -------- | ---------------------- |
| `groupBy?` | `Array<string>`           | 全局单组 | 分组键字段             |
| `selector` | `IRDataSelectorOperation` | —        | 组内代表行选择规则     |
| `rankAs?`  | `string`                  | —        | 把一基 rank 写入该字段 |

```tsx
<Transform kind="select" groupBy={['region']} selector={{ kind: 'top', by: 'revenue', n: 3 }} rankAs="rank" />
```

## 统计标注 annotate

`annotate` 先按 `groupBy` 分组，再把 reducer 结果或 selector 选中的代表值回填到组内每一行。它适合在明细点旁边画组均值线、组中位数带或分组阈值。

selector 标注只接受至多选中一行的内置规则：`min` / `max`、`first` / `last` / `nth`，以及固定 `n: 1` 的 `top` / `bottom`。平局策略可以用默认的 `first` 或 `last`，不能用 `all`。多行选择与 `outside-quantile-band` 应改用 `select`，其它单值统计应写成 reducer。

<ComponentPreview files={['transform-annotate', 'transform-annotate.data.ts']} />

`IRDataAnnotateTransform` 的 `kind` 固定为 `'annotate'`，并且至少提供 `metrics` 或 `selectors`。

| prop         | 类型                            | 默认值   | 说明                   |
| ------------ | ------------------------------- | -------- | ---------------------- |
| `groupBy?`   | `Array<string>`                 | 全局单组 | 分组键，支持复合键     |
| `metrics?`   | `IRDataReducerMetrics`          | —        | 要广播回每行的统计指标 |
| `selectors?` | `Array<IRDataAnnotateSelector>` | —        | 广播单行代表值         |

```tsx
<Transform
  kind="annotate"
  groupBy={['store']}
  metrics={[{ kind: 'mean', field: 'revenue', as: 'storeMean' }]}
  selectors={[{ selector: { kind: 'max', by: 'revenue' }, as: 'storeMax' }]}
/>
```

`annotate` 的 metric 输出与 selector `as` 也不能重名。reducer 与 selector 的完整子算子范围见[统计子算子](/viz/data/transform/statistics)。

## TypeScript 类型

transform schema 派生类型统一使用 `IRDataXxx`。

| 范围       | 类型                                                                                                  |
| ---------- | ----------------------------------------------------------------------------------------------------- |
| 整体 union | `IRDataTransform`、`IRDataBuiltinTransform`                                                           |
| 内置变换   | `IRDataSortTransform`、`IRDataSummarizeTransform`、`IRDataSelectTransform`、`IRDataAnnotateTransform` |
| 嵌套配置   | `IRDataOrderBy`、`IRDataAnnotateSelector`                                                             |

需要在 Plot React 中声明这些 operation 时，见 [`Transform`](/viz/data/transform/overview)；需要注册自定义 kind 时，见[扩展机制](/viz/data/transform/extensions)。
