This page covers shared transform and operator configuration contracts from `@retikz/data`. Find built-in parameters in the Schema tabs under [Computation operators](/viz/data/operators) and [Data transforms](/viz/data/transforms). See [Transform operations](/viz/data/transform/operations) for usage and [API Reference](/viz/data/transform/api-reference) for runtime types and functions.

Configuration is separate from computation implementations. Defaults described below may be applied at runtime; only a schema-level `.default()` materializes a value during validation.

## DataExecutionSchema

Configuration is inherited from executor defaults, host configuration, then the individual declaration. mode and external inherit independently; the schema does not materialize the builtin default.
