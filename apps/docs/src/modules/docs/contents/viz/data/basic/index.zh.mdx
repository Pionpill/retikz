Data 接收数据源在运行时提供的行，真实数据会更新，也可能换一个来源。要让后续配置在这些变化中继续工作，先要回答两个问题：值从哪里取得，以及这个字段表示什么。基础概念分别解释这两层含义。

## 职责一览

| 章节           | 回答的问题                     | 何时阅读                   |
| -------------- | ------------------------------ | -------------------------- |
| 数据行与字段   | 数据源怎样接入稳定字段         | 数据源切换或字段变化时     |
| 字段与测量类型 | 字段表示数值距离、类别还是时间 | 原始值类型不足以说明含义时 |

## 同一行数据，两层约定

例如，外部数据行是 `{ stage: 10, pricing: { amount: '12' } }`。第一层约定把物理路径 `pricing.amount` 对齐到逻辑字段 `revenue`；第二层约定说明 `revenue` 是可求和的连续量，而数字编码的 `stage` 是类别。归一化后，后续处理可读取逻辑字段 `revenue: 12` 和类别值 `stage: 10`，不必重新猜测原始路径或值的含义。

字段声明可以写入可序列化的 `model`，真实数据行在运行时传入。概念页只解释这些名称与语义如何协作；字段映射、解析格式和校验的具体配置留在[数据模型](/viz/data/model)。

## 从哪里开始

先读“数据行与字段”，弄清外部路径与逻辑名称；再读“字段与测量类型”，判断字段的测量含义。需要排序和汇总时进入[数据变换](/viz/data/transform)。
