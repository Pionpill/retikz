**计算算子**是 transform 内部使用的计算单元。当前提供 reducer 和 selector 两类：reducer 返回计算出的字段片段，selector 返回所选记录及可选排名。transform 负责组织输入与输出，算子负责完成其中的具体计算。

[变换操作](/viz/data/transform/operations)解释整条链如何推进。本页进入单个变换内部，追踪一组数据如何交给算子处理，再由调用它的 transform（即**宿主变换**）组织最终结果。宿主决定分组边界和输出行的形状；算子完成局部计算，不自行推进整条变换链。本文聚焦 reducer 与 selector 的协作机制，不列举全部算子及参数。

## 整体流程

- **Reducer**（归约器）：接收一组行，返回声明的字段片段，例如 `{ total: 40, count: 2 }` 中的一个或多个字段。
- **Selector**（行选择器）：接收一组行，返回所选原始行的引用，以及可选排名信息。
- **宿主变换**：决定把字段片段组装为新行、广播回明细，或把选择结果组织为输出行。

两类算子按返回结果区分，各有对应的定义、实现和注册入口。selector 也会进行比较、排序或排名计算，最终返回的是行选择结果。自定义算子可通过对应入口扩展，宿主按各自契约消费结果。

下图用同一组数值对照两条独立链路：上方 reducer 归约得到字段片段，下方 selector 选出已有记录。两条链路都把结果交回宿主。

<ComponentPreview files="statistics-overview" hideCode type="flow" size="md" />

算子也用于聚合之外的变换：`annotate` 将计算结果回填到明细并保留行数，`select` 输出选中的记录，`relate` 用 selector 选择关系的起点与终点记录。相同算子可被不同宿主复用，最终行数由宿主的输出语义决定。

对于图中的分组调用，宿主先根据组键构造每组的行集合，再把当前组的行与算子参数交给计算调度。算子定义声明读取哪些字段；reducer 定义还声明输出字段，让外层在执行前推导模型、检查输出名冲突。

语义定义与计算实现分别注册。调度时不仅匹配 `kind`，还核对实现绑定的 Definition，避免用同名但不同语义的计算替换已解析契约。内置与自定义子算子经过相同的定义和实现匹配机制。

## reducer 算子

观察下方左右表：四条明细变成两个统计行，`item` 与 `value` 消失，新增 `total` 与 `count`。结果通过实际汇总变换计算。

<ComponentPreview files="reducer-example" hideCode type="illustration" size="md" />

以 A 组为例，宿主传入值为 10、30 的两条明细。两个 reducer 分别返回 `{ total: 40 }` 与 `{ count: 2 }`，宿主将字段片段合并，再加上组键 `{ team: 'A' }`，得到完整输出行。

reducer 的返回值不是完整的数据表，也不一定只是一个数。多输出的 reducer 可以返回多个声明字段。合并前要检查字段名：两个 metric 不能写同一个输出名，统计输出也不能覆盖宿主保留的组键。

这里每组一行来自汇总宿主。如果宿主将同一统计字段广播到每条明细，输入行数可以保持不变；无需为此另造一套“回填版 reducer”。

## selector 算子

下面使用相同输入，每组选择 `value` 最大的行。右侧仍保留 `item`，因为选择器返回的是原始记录，而不是只返回最大数值。

<ComponentPreview files="selector-example" hideCode type="illustration" size="md" />

A 组选择 a2，B 组选择 b2。selector 返回的选择记录包含 `row`，还可以带 `rank`；宿主读取这些记录，复制所选行，并在声明需要时写入排名字段。不要把子算子的选择记录直接当作最终输出行。

选择结果可以是零行、一行或多行。并列如何处理由具体 selector 决定；宿主消费选择结果，不能假定每组永远只有一个代表。相同的“最大值”字样也不能抹平两类契约的差别：归约得到统计字段，选择保留记录身份及其其它字段。

## 数值与执行边界

是否读取字段、如何筛选缺失值、空输入返回什么，由具体子算子语义规定，不由宿主统一填零。例如计数可以统计记录数，数值归约则需要决定哪些字段值参与计算；两者不能共用“有效数值个数”这一假设。具体规则属于各算子的用法与契约说明。

分组算法通过共享计算调度调用子算子。同步入口使用同步实现；异步路径可以等待子计算完成，再继续组装结果。共享的是分组和组装逻辑，而不是让同步入口隐式接收 Promise。

子算子失败会终止当前宿主计算，并由外层变换链标记失败阶段。这里没有跳过失败组并返回部分统计表的默认机制。
