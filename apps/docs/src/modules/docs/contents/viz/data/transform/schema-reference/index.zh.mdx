本页保留 `@retikz/data` 的公共变换与算子配置契约。具体内置参数见[计算算子](/viz/data/operators)和[数据变换](/viz/data/transforms)各小节的 Schema 页签。用法见[变换操作](/viz/data/transform/operations)，运行时类型和函数见 [API 参考](/viz/data/transform/api-reference)。

配置与计算实现分开保存。下文说明中的“默认”可能由运行时补齐；只有 Schema 声明的 `.default()` 才会在校验时物化。

## DataExecutionSchema

配置优先级为执行器默认值、宿主根配置、单条声明。mode 和 external 分别继承；Schema 不会物化 builtin 默认值。

<ZodSchema
  name="DataExecutionSchema"
  description="继承后的阶段执行策略。"
  descriptions={{
    mode: '阶段执行模式：builtin、external 或 hybrid；继承后仍省略时使用 builtin',
    external: '具名外接 Provider 的注册名称',
  }}
/>

<ZodSchema
  name="DataTransformDeclarationSchema"

  }}
/>

## TransformSchema

所有变换使用 `{ kind, params }`。自定义参数必须是 JSON 对象；行数据、函数和源句柄由运行时提供。

<ZodSchema
  name="DataTransformSchema"
  description="内置或自定义变换操作。"
  descriptions={{
    kind: '内置或已注册的自定义变换名称',
    params: '必填参数对象；具体字段由对应变换的参数 Schema 校验',
  }}
/>

## ExternalTransformSchema

这里检查 JSON 形态。注册的 Definition 还会用自己的 paramsSchema 校验精确参数。

<ZodSchema
  name="ExternalTransformSchema"
  description="自定义变换的可序列化参数。"
  descriptions={{
    kind: '自定义变换名称，不能与内置名称冲突',
    params: '自定义变换的 JSON 参数对象',
  }}
/>

## SelectorOperationSchema

各分支只接受对应参数。自定义选择器的额外字段必须是 JSON 值。

<ZodSchema
  name="SelectorOperationSchema"
  description="内置或自定义行选择操作。"
  descriptions={{
    kind: '行选择算子名称',
    by: '数值排名字段',
    tie: '并列策略；默认 first',
    orderBy: '选择前的排序规则；first、last 省略时保留当前顺序',
    n: 'top、bottom 选择的正整数行数',
    index: 'nth 的零基行下标',
    field: '分位区间筛选的数值源字段',
    lowerP: '下界分位概率，必须小于 upperP',
    upperP: '上界分位概率',
    boundary: '分位区间外筛选的边界策略；默认 band',
  }}
/>

## ReducerOperationSchema

公共归约操作配置；自定义算子的额外字段必须是 JSON 值。具体参数见[规约算子](/viz/data/operators/reducer)。

<ZodSchema
  name="ReducerOperationSchema"
  description="内置或自定义归约操作。"
  descriptions={{
    kind: '归约算子名称',
    field: '数值源字段；count 不读取字段',
    as: '单值算子的输出字段名；extent 使用包含 min、max 的对象',
    p: '分位概率，取值 0..1',
    lowerP: '下界分位概率，必须小于 upperP',
    upperP: '上界分位概率',
    outputs: '结果的输出字段映射',
    whisker: '可选须线策略',
  }}
/>
