---
title: 数据变换
description: 理解 transform 如何组织规范化数据行、消费算子结果，并按顺序推进输出字段与行粒度。
---

画地区收入图需要地区汇总行，展示商品明细需要保留每件商品，绘制趋势则可能需要一组新的采样点。数据变换（transform）将输入数据行处理为适合下一步使用的数据行。

Data 的变换读取已经规范化的行。字段名称对齐、值解析和接入校验先由[数据模型](/viz/data/model)完成。变换后的行可以继续交给另一项变换，也可以供图形、表格或其它消费模块使用。

## 输出粒度

粒度表示一条输出行代表什么，例如一件商品、一个地区或一个采样位置。选择变换时，先确定需要哪种粒度，再决定哪些字段应保留或新建。

| 任务             | 变换示例    | 输出如何变化                         |
| ---------------- | ----------- | ------------------------------------ |
| 改变展示顺序     | `sort`      | 行重排，保留原有字段                 |
| 得到地区汇总     | `summarize` | 每组一行，保留组键并写入统计字段     |
| 保留代表商品     | `select`    | 输出所选原始行，可增加排名字段       |
| 在明细旁对照统计 | `annotate`  | 保留明细行数，增加统计或选择标注字段 |
| 生成趋势采样     | `smooth`    | 输出采样位置及预测值组成的新行       |

有些变换保留行数，有些减少行数或生成新行。字段集合也可能变化，因此下一步可读取的字段取决于前一步的输出。

## 变换与算子

以商品 A 收入 120、商品 B 收入 80 为例，求和算子返回总收入 200。`summarize` 可以把这个结果放入一条地区汇总行，`annotate` 可以把它附加到两条商品明细。

算子负责局部计算，变换负责选择输入、组织计算及形成输出行。求和逻辑因此能服务多种表结构。同样，行选择算子可以供 `select` 使用，拟合模型可以供 `smooth` 采样。

一项变换也可以直接处理行，例如 `sort` 按排序键重排行，无需把它拆成归约或行选择。算子是可复用的计算能力，不是每项变换都必须具备的固定步骤。

## 变换链

变换声明使用可序列化的 `kind` 与 `params`，分别标明操作名称和参数。声明数组按顺序执行，后一个阶段读取前一个阶段产生的行与字段模型。

例如先按地区汇总收入，再按总收入降序排序，就能得到地区排名。汇总之后一条行代表一个地区，字段来自组键和声明的统计输出；后续排序应读取总收入，不能继续假定商品明细字段仍然存在。

执行前，Definition 提供参数约束、输入字段和预期输出模型，数据层据此检查整条链的字段关系。计算阶段由对应 Implementation 或外接计算入口完成。更换执行方式时，声明所表达的行处理语义仍须一致。

## 消费边界

变换处理数据空间中的行和字段。坐标、颜色、线条和单元格布局由消费模块解释，变换本身不决定最终视图。相同的地区汇总数据可以用于柱状图，也可以用于汇总表。

内置与自定义变换通过同一套定义和注册机制接入。具体参数、可用算子范围、默认值及失败条件属于各操作的契约；总览中的结果形态不能代替完整配置说明。
