Data 契约只保存 JSON-safe 配置。真实 rows、parser、Definition、registry 和回调在运行时注入，不进入这些 schema；字段行为与 transform 用法分别见[字段契约](/viz/data/model/contract)和[变换操作](/viz/data/transform/operations)。

## TransformSchema

<ZodSchema name="DataTransformSchema" description="内置或运行时注册的通用 Data transform operation 联合。" />

内置 transform 共用 `kind` 判别字段，并按数组声明顺序执行。`metrics` 和 `selector` 的统计子算子契约见[统计子算子](/viz/data/transform/statistics)；自定义 operation 必须保持 JSON 可序列化，并由运行时 Definition 提供精确 schema 与实现。

### ReducerOperationSchema

<ZodSchema name="ReducerOperationSchema" description="内置或运行时注册的 reducer operation 联合。" />

| `kind`          | 字段                                                   | 作用                                            |
| --------------- | ------------------------------------------------------ | ----------------------------------------------- |
| `count`         | `as`                                                   | 输出组内行数                                    |
| `sum` / `mean`  | `field`、`as`                                          | 输出数值字段的总和或算术平均值                  |
| `median`        | `field`、`as`                                          | 输出数值字段的中位数                            |
| `min` / `max`   | `field`、`as`                                          | 输出数值字段的最小值或最大值                    |
| `extent`        | `field`、`as`                                          | 输出数值字段的最小值与最大值区间                |
| `quantile`      | `field`、`p`、`as`                                     | 输出概率 `p` 对应的分位点                       |
| `quantile-band` | `field`、`lowerP`、`upperP`、`outputs`、可选 `whisker` | 一次输出分位区间、附加分位点、spread 与 whisker |
| 自定义 `kind`   | JSON-safe 配置                                         | 由匹配的 `StatisticsReducerDefinition` 解析执行 |

## SelectorOperationSchema

<ZodSchema name="SelectorOperationSchema" description="内置或运行时注册的 row selector operation 联合。" />

| `kind`                  | 字段                                         | 选择结果                                  |
| ----------------------- | -------------------------------------------- | ----------------------------------------- |
| `min` / `max`           | `by`、可选 `tie`                             | 选择数值字段最小或最大的行                |
| `first` / `last`        | 可选 `orderBy`                               | 按当前顺序或显式排序选择首行或末行        |
| `top` / `bottom`        | `by`、`n`、可选 `tie`                        | 选择最高或最低的 N 行                     |
| `nth`                   | `orderBy`、`index`                           | 按显式排序选择零基下标行                  |
| `outside-quantile-band` | `field`、`lowerP`、`upperP`、可选 `boundary` | 选择分位区间或 spread fence 外的行        |
| 自定义 `kind`           | JSON-safe 配置                               | 由匹配的 `RowSelectorDefinition` 解析执行 |

### AnnotateSelectorSchema

<ZodSchema
  name="AnnotateSelectorSchema"
  description="为 annotate transform 选择至多一行，并把结果写入具名字段。"
  descriptions={{
    selector: '单行 selector；支持 min、max、first、last、top、bottom 与 nth。',
    as: '注释输出字段。',
  }}
/>

annotate 不接受 `outside-quantile-band`；`top` / `bottom` 的 `n` 固定为 `1`，平局只允许选择第一行或最后一行，确保每个注释字段至多对应一条源行。
