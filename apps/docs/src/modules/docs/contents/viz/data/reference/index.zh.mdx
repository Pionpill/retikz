API 参考用于查询稳定契约，不承担入门教学。契约页集中列出数据执行与 transform schema；数据模型的公开接口和校验结构分别见 [API 参考](/viz/data/model/api-reference)与 [Schema 参考](/viz/data/model/schema-reference)；运行时页说明外部 rows、函数型 Definition、registry 与 lineage 如何接入同一条纯数据管线。

> 这里是参考层，不是组件文档；开始处理数据请从[简介](/viz/data/introduction)阅读，按任务学习字段与变换请查看[数据模型](/viz/data/model)和[数据变换](/viz/data/transform)。

## 职责一览

| 主题   | 职责                                              | 何时查阅                             |
| ------ | ------------------------------------------------- | ------------------------------------ |
| 契约   | 数据执行与内置 transform 的 JSON-safe schema      | 生成、持久化或校验 Data 配置         |
| 运行时 | Definition、registry、规范化、执行与 lineage 结果 | 接入宿主、注册扩展或诊断数据处理链路 |
