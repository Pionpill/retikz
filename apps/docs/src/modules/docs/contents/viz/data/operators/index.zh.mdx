---
title: 计算算子
description: 了解归约、行选择与拟合分别返回什么，以及宿主如何把局部计算结果组织为数据行。
---

查看销售数据时，“总收入是多少”“哪条记录收入最高”和“给定时间的收入趋势是多少”需要不同的结果：统计字段、原始记录或预测值。计算算子为这类局部计算规定输入、参数和结果。

这里的算子指 Data 中可由宿主调用的归约、行选择与拟合能力。宿主是使用算子结果的数据处理操作，例如汇总变换或趋势采样变换；它决定本次计算处理哪些输入，以及结果怎样进入输出行。

## 归约

归约算子（reducer）读取一批行，返回由统计字段组成的结果片段。例如收入为 120 和 80 的两条明细，求和结果可以是 `total: 200`，计数结果可以是 `orders: 2`。

结果可以包含一个或多个字段。分位区间计算可以同时提供上下边界、分位点和计数，具体字段由算子声明。不能把所有归约结果都理解成一个数值。

这份统计片段也没有决定最终表有多少行：`summarize` 将它与组键合并，每组输出一行；`annotate` 将它附加到组内明细，保留原有行数。分组和输出粒度属于宿主的职责。

## 行选择

行选择算子（selector）返回选择记录。每条选择记录包含选中的原始行，也可以带有排名，因此能保留商品名等其它字段，而不仅是用于比较的收入数值。

以商品 A 收入 120、商品 B 收入 80 为例，最大值归约返回收入统计字段；按收入选择最大行则返回商品 A 的记录。选择结果可以为空、一条或多条，并列结果的处理取决于具体算子的规则。

宿主决定怎样消费这些选择记录。`select` 将所选记录组织为输出行，也可以写入排名字段；支持选择统计的 `annotate` 则把选择结果用于明细标注。每个宿主支持的算子范围有自己的约束，不能据此假定所有 selector 都可用于所有变换。

## 拟合

拟合算子读取有限数值观测对，例如时间与收入，返回可预测的运行时模型。模型通过 `predict(x)` 给出某个输入位置的预测值。

模型本身不是一张采样结果表。`smooth` 这类宿主决定预测范围和采样位置，再调用模型生成新的数据行。拟合方法与采样方式因此可以分别表达。

## 结果与宿主

| 算子   | 计算结果                       | 宿主需要完成的工作             |
| ------ | ------------------------------ | ------------------------------ |
| 归约   | 声明的统计字段片段             | 合并组键、形成汇总行或回填明细 |
| 行选择 | 原始行及可选排名组成的选择记录 | 组织输出行、排名字段或选择标注 |
| 拟合   | 可预测的运行时模型             | 确定采样位置并生成预测行       |

这些能力各有结果契约，没有一个统一的“算子返回表”。输入如何分组、最终行数和字段集合怎样变化，要结合消费它的[数据变换](/viz/data/transforms)理解。

## 声明与计算

算子声明保存计算名称和参数，可以进入 JSON IR。运行时的 Definition 规定参数与结果语义，Implementation 提供具体计算；函数和预测模型留在运行时。

内置与自定义算子通过相应注册表解析。更换计算实现时仍需遵守同一 Definition 的语义，不能仅凭相同名称认定两份计算等价。同步与异步入口也有各自的结果要求，具体接入见[计算契约](/viz/data/transform/computation)。
