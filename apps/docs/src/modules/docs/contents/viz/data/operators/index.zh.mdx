title: 计算算子
description: 查看选择、规约与拟合三类计算算子的用途和内置算子。
---

计算算子负责数据变换中的具体计算，用于统计数值、选择记录或拟合趋势；它与变换的协作方式见[数据能力 · 计算算子](/viz/data/transform/statistics)。

| 类型       | 名称 | 特点                                                 |
| ---------- | ---- | ---------------------------------------------------- |
| selector   | 选择 | 从已有记录中选行，保留原始字段值，不产生新的观测数据 |
| reducer    | 规约 | 对一组数据做统计，生成新的统计字段                   |
| regression | 拟合 | 从观测数据拟合模型，供变换生成预测数据               |

这里需要区分原始明细与变换结果。内置宿主不会原地修改传入的明细：selector 的结果用于生成所选记录，reducer 的结果用于生成统计行或带统计字段的明细行，regression 则返回模型，再由 `smooth` 生成预测行。放入变换链后，下一阶段读取这些输出行；它们不会自动追加到原始明细中。

## 选择

选择算子按数值、顺序或排名选出原始记录，参数与示例见[selector · 选择](/viz/data/operators/selector)。

| 算子                    | 名称           | 介绍                                         |
| ----------------------- | -------------- | -------------------------------------------- |
| `min`                   | 最小值记录     | 选择指定数值字段最小的记录                   |
| `max`                   | 最大值记录     | 选择指定数值字段最大的记录                   |
| `first`                 | 首行选择       | 选择当前顺序或显式排序后的第一行             |
| `last`                  | 末行选择       | 选择当前顺序或显式排序后的最后一行           |
| `top`                   | 最高 N 行      | 按数值降序取前 N 行，支持截断边界的并列策略  |
| `bottom`                | 最低 N 行      | 按数值升序取前 N 行，支持截断边界的并列策略  |
| `nth`                   | 指定位置记录   | 排序后选择零基下标对应的行，越界时返回空结果 |
| `outside-quantile-band` | 分位区间外记录 | 选择严格落在分位区间或扩展围栏之外的记录     |

## 规约

规约算子把一组数据计算成一个或多个统计字段，参数与示例见[reducer · 规约](/viz/data/operators/reducer)。

| 算子            | 名称               | 介绍                                             |
| --------------- | ------------------ | ------------------------------------------------ |
| `count`         | 行数统计           | 统计输入行数                                     |
| `sum`           | 数值求和           | 累加指定字段的有限数值                           |
| `mean`          | 算术平均值         | 计算指定字段有限数值的均值                       |
| `median`        | 中位数             | 排序后取中间值，偶数个值时取中间两数的均值       |
| `min`           | 最小值             | 返回指定字段的最小有限数值                       |
| `max`           | 最大值             | 返回指定字段的最大有限数值                       |
| `extent`        | 最小值与最大值区间 | 同时计算最小值和最大值，写入两个连续型字段       |
| `quantile`      | 分位数             | 计算指定概率位置的分位点，必要时线性插值         |
| `quantile-band` | 分位区间           | 计算上下分位点，可附加区间宽度、计数和须线等字段 |

## 拟合

拟合算子根据数值观测对生成预测模型，供数据变换计算趋势上的采样值。参数和示例见 [regression · 拟合](/viz/data/operators/regression)。

| 算子          | 名称           | 介绍                                                 |
| ------------- | -------------- | ---------------------------------------------------- |
| `linear`      | 线性回归       | 拟合自变量与因变量之间的直线关系                     |
| `quadratic`   | 二次多项式回归 | 拟合二次曲线                                         |
| `polynomial`  | 多项式回归     | 按指定次数拟合多项式曲线                             |
| `logarithmic` | 对数回归       | 拟合因变量与自变量对数之间的线性关系，要求自变量为正 |
| `exponential` | 指数回归       | 拟合指数曲线，要求因变量为正                         |
| `power`       | 幂函数回归     | 拟合幂函数曲线，要求自变量与因变量均为正             |
