---
title: Aggregation and annotation
description: Summarize each group into one row, or annotate detail rows with statistics and selected values.
---

Use `summarize` for one statistics row per group, and `annotate` to place group statistics beside detail rows. Both reuse [reducer](/viz/data/operators/reducer) operations; annotation also supports single-row [selector](/viz/data/operators/selector) results.

## summarize

`summarize` runs one or more reducers per group and emits one row containing the group keys and metric fields. Other detail fields are dropped. Multiple group fields form a hierarchy in list order, preserving first-seen keys at each level. Metric output fields must be distinct and must not overwrite group keys. ## annotate

`annotate` preserves detail fields and row count, broadcasting each group result to every member. Output follows group order and may differ from input order. Provide metrics, selectors or both, with distinct output names. Results can overwrite existing fields, so choose names that preserve any detail fields you still need.

Supported selectors are min/max, first/last, top/bottom and nth. Min/max allow only first/last tie handling; top/bottom require n = 1. A selector with by writes that field from the selected row; otherwise it writes the selection rank. If no row is selected, that annotation field is not written.
