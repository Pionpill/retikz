查询 `@retikz/data` 的数据引用、字段模型、字段声明与格式名 Schema。用法见[字段类型](/viz/data/model/field-types)，运行时定义见 [API 参考](/viz/data/model/api-reference)。

这些 Schema 只描述可序列化配置，真实数据行、解析函数与比较器保留在消费侧运行时代码中。省略 `type` 时保留类型推断；省略 `format` 时使用最终类型的默认转换；省略 `order` 时按类别首次出现顺序排列。这些行为由运行时解析应用，不会在 Schema 校验时补写为字段值。

## FieldDefinitionSchema

字段声明按 `type` 分支：`categorical` 支持类别 `order`；`continuous` 与 `temporal` 禁止 `order`。省略 `type` 时保留推断，若声明了 `order`，最终解析出的字段类型必须是分类类型。

`order` 接受内置或自定义的非空白名称，或非空类别数组。内置顺序包含 `naturalAscending` / `naturalDescending`；自定义顺序须在消费请求中注册，比较函数不进入 JSON。
