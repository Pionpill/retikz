`<Transform>` is a declarative component from `@retikz/plot-react`. It places one JSON-serializable transform operation into the current `<Plot>` data pipeline and renders no graphics of its own.

The Data transform contract does not depend on Plot; this component is only a Plot React authoring entry point for that contract. Other consumers can call `@retikz/data` operations and runtime functions directly without going through `<Transform>`.

## Usage

```tsx
import { Plot, Transform } from '@retikz/plot-react';
```

```tsx
<Plot data={rows}>
  <Transform kind="sort" field="date" order="ascending" />
  {/* marks */}
</Plot>
```

One `<Transform>` represents one operation. For a multi-step pipeline, declare components in dependency order: the output rows of one step become the input rows of the next.

### Choose an entry point

All three forms belong to the Plot application layer, but their scope differs.

| Entry                    | Best for                                    | Scope                                            |
| ------------------------ | ------------------------------------------- | ------------------------------------------------ |
| `<Transform ... />`      | Reading and composing operations in JSX     | Shared pipeline of the current Plot              |
| `dataTransforms={[...]}` | Programmatically generated operation arrays | Shared pipeline, before component declarations   |
| mark-local `transform`   | A local data view for one mark              | That mark only; other mark inputs stay unchanged |

Plot-registered drawing kinds use the same component; see [Drawing Grammar transforms](/viz/plot/transform). The four Data built-ins live under [Transform Operations](/viz/data/transform/operations).

## How it works

<ComponentAlert
  type="tip"
  title="Optional for everyday use"
  description="Revisit this section when debugging why the component renders nothing, how multiple entry points are ordered, or how automatic transforms are deduplicated."
/>

The `Transform` function returns `null`. While building the plot spec, `Plot` synchronously walks its children, recognizes `Transform` elements, and collects their props as `IRPlotTransform` values. It is therefore a configuration carrier rather than a visible layer, and it accepts no children.

The shared pipeline is assembled in this order:

1. the `dataTransforms` array
2. `<Transform>` elements in JSX declaration order
3. operations generated by mark shortcuts

When an explicit `stack` has the same signature as an automatic `stack`, the automatic operation is suppressed to avoid double stacking. Other operations keep their assembled order.

## API Reference

### TransformProps

`TransformProps` equals `IRPlotTransform`, a union discriminated by `kind`. After choosing a `kind`, TypeScript requires the configuration of that operation branch.

| prop                | type                      | default | description                                                        |
| ------------------- | ------------------------- | ------- | ------------------------------------------------------------------ |
| `kind`              | `IRPlotTransform['kind']` | —       | Operation discriminator                                            |
| kind-specific props | Selected union branch     | —       | JSON-serializable config documented on the matching Data/Plot page |

### kind coverage

| Owner  | kinds                                                                                   | Documentation                                          |
| ------ | --------------------------------------------------------------------------------------- | ------------------------------------------------------ |
| Data   | `sort`, `summarize`, `select`, `annotate`                                               | [Transform Operations](/viz/data/transform/operations) |
| Plot   | `stack`, `bin`, `normalize`, `derive-interval`, `relate`, `jitter`, `density`, `smooth` | [Drawing Grammar transforms](/viz/plot/transform)      |
| Custom | A registered string that does not collide with a built-in name                          | [Extension Mechanisms](/viz/data/transform/extensions) |

### Exports

| export           | type                 | default | description                                              |
| ---------------- | -------------------- | ------- | -------------------------------------------------------- |
| `Transform`      | `FC<TransformProps>` | —       | Declares one operation and returns `null`                |
| `TransformProps` | `IRPlotTransform`    | —       | Type alias between component props and Plot transform IR |
