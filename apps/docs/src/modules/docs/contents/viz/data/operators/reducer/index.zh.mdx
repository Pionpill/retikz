---
title: reducer · 规约
description: 使用内置 reducer 计算行数、总和、集中趋势、极值、范围和分位区间，并通过 summarize 形成汇总行。
---

一批订单可以规约成总收入，也可以规约成中位数或一个数值区间。reducer 读取一组行，返回声明的统计字段；本页用 `summarize` 把这些字段与组键合成汇总行。两者的职责区别见[计算算子总览](/viz/data/operators)。

内置 reducer 共九个，下文按同类能力合并小节。各 demo 用左右表格比较同一批订单的输入与实际输出；“按组统计”对应宿主的 `params.groupBy`，关闭后全部订单属于一组。橙色标记支撑当前结果的原始 value，蓝色标记统计列；排序统计遇到并列端点时，所有同值单元格都会标记。

## quantile · 分位数

`quantile` 输出指定概率位置的分位点。有限数值排序后，位置为 $h=(m-1)p$，其中 $m$ 是参与计算的数值个数；位置落在两个数之间时线性插值，结果可以不是输入中的某个值。`p=0` 和 `p=1` 分别得到最小值和最大值。参数与校验约束可在下方页签中切换查看。

<DocTabs defaultValue="api">
<DocTab value="api" label="API">

| 属性    | 类型         | 说明                                    |
| ------- | ------------ | --------------------------------------- |
| `kind`  | `'quantile'` | 计算类型                                |
| `field` | `string`     | 必填，读取的数值字段名，不能为空        |
| `p`     | `number`     | 必填，分位概率，范围为 0 到 1，包含端点 |
| `as`    | `string`     | 必填，分位点输出字段名，不能为空        |

## quantile-band · 分位区间

`quantile-band` 一次计算上下分位点，也可输出额外分位点、区间宽度、有限值计数和须线。各结果通过 `outputs` 单独命名。

令上下分位点为 $L$、$U$，区间宽度为 $S=U-L$。`minMax` 须线取观测最小值与最大值；`spread` 先构造围栏 $[L-fS,U+fS]$，再从围栏内的实际观测取须线端点。围栏与须线是不同结果。参数与校验约束可在下方页签中切换查看。

<DocTabs defaultValue="api">
<DocTab value="api" label="API">

| 属性                  | 类型                               | 说明                                             |
| --------------------- | ---------------------------------- | ------------------------------------------------ |
| `kind`                | `'quantile-band'`                  | 计算类型                                         |
| `field`               | `string`                           | 必填，读取的数值字段名，不能为空                 |
| `lowerP`              | `number`                           | 必填，范围为 0 到 1，必须小于 upperP             |
| `upperP`              | `number`                           | 必填，范围为 0 到 1                              |
| `outputs`             | `object`                           | 必填，输出字段映射；所有字段名不能为空且不可重复 |
| `outputs.lower`       | `string`                           | 必填，下分位点输出字段名                         |
| `outputs.upper`       | `string`                           | 必填，上分位点输出字段名                         |
| `outputs.points`      | `Array<{ p: number; as: string }>` | 可选，非空的额外分位点列表                       |
| `outputs.points[].p`  | `number`                           | 必填，分位概率，范围为 0 到 1                    |
| `outputs.points[].as` | `string`                           | 必填，该分位点的输出字段名                       |
| `outputs.spread`      | `string`                           | 可选，区间宽度输出字段名                         |
| `outputs.lowerFence`  | `string`                           | 可选，spread 策略的下围栏输出字段名              |
| `outputs.upperFence`  | `string`                           | 可选，spread 策略的上围栏输出字段名              |
| `outputs.whiskerMin`  | `string`                           | 可选，须线最小值输出字段名                       |
| `outputs.whiskerMax`  | `string`                           | 可选，须线最大值输出字段名                       |
| `outputs.min`         | `string`                           | 可选，全部有限观测的最小值输出字段名             |
| `outputs.max`         | `string`                           | 可选，全部有限观测的最大值输出字段名             |
| `outputs.count`       | `string`                           | 可选，有限数值个数输出字段名                     |
| `whisker`             | `object`                           | 可选，须线策略；省略时不计算须线                 |
| `whisker.kind`        | `'minMax' \| 'spread'`             | 提供 whisker 时必填，选择须线策略                |
| `whisker.factor`      | `number`                           | 可选，非负数，默认 1.5；仅 spread 策略使用       |

</DocTab>
