`@retikz/data` 适合把来自文件、接口或应用状态的外部行整理成可复用的数据结果：声明逻辑字段，归一化值，并按顺序运行可序列化的数据变换。它不决定图形怎样呈现，因此同一份处理结果可以交给 Plot、Table 或其它消费模块。

## 何时使用

当一个数据准备规则会被多个视图复用，或你需要将字段类型、映射和变换保存为 JSON 时，先在 Data 中建立契约。真实数据行仍在运行时传入；它们、parser 函数和自定义 Definition 都不进入持久化 IR。

| 文档                             | 任务                                       |
| -------------------------------- | ------------------------------------------ |
| [数据模型](/viz/data/model)      | 声明字段类型、格式、分类顺序或来源字段映射 |
| [数据变换](/viz/data/transform)  | 排序、汇总、代表行选择或统计标注           |
| [数据溯源](/viz/data/provenance) | 回查处理前后的来源行与下游图元             |
| [API 参考](/viz/data/reference)  | 查阅 schema、Definition 与运行时入口       |

## 数据如何流动

真实数据行不进入可序列化契约。配置只描述读哪些字段、字段类型，以及要执行哪些处理和变换；消费方在运行数据管线时传入行数据。这样同一份配置可以复用于不同数据源，也能保存为 JSON 或由 AI 生成。

<ComponentPreview files="data-pipeline" size="sm" hideCode />

数据管线先收集消费方真正使用的字段，再将外部行整理为规范化行：对齐字段、解析值、归一化类型，并用逻辑字段名写回结果。后续变换和消费模块读取规范化行，不再反复直接读取原始数据。

| 步骤         | 做什么                                                         | 主要配置                          |
| ------------ | -------------------------------------------------------------- | --------------------------------- |
| 数据引用     | 选择当前视图使用哪份外部数据，数据本身不进入 IR                | `data` / `data.reference`         |
| 字段契约     | 确定逻辑字段名、类型、分类顺序与声明式格式；未声明时按样本推断 | `model`                           |
| 源字段对齐   | 把逻辑字段映射到真实数据路径，支持字段改名与嵌套路径           | `fieldMap` / `fieldMaps`          |
| 解析与归一化 | 按字段契约与格式解析值，并写回逻辑字段名                       | `model` / `format` / 字段类型     |
| 数据校验     | 对参与字段做抽样或全量校验，决定非法值跳过还是报错             | `validateData` / `invalid`        |
| 变换与交付   | 数据变换改写规范化行，再把结果交给具体消费模块                 | `sort` / `summarize` / 消费方配置 |

`model`、`format` 和数据变换操作可持久化；函数只在运行时参与处理，不进入 IR。自定义字段格式与字段解析见[数据模型扩展](/viz/data/model/extensions)，自定义变换、规约器（reducer）与行选择器（selector）见[数据变换扩展](/viz/data/transform/extensions)。

## 模块边界

Data 的输出是规范化行及其字段语义，而不是图元或渲染结果。Plot 拥有通道、比例尺、图元和布局；Table 拥有二维表格结构与单元格呈现。它们可以读取同一份 Data 结果，却不会让 Data 依赖任何一个可视化模块。

数据只在一个特定图表中使用时，仍可由该图表的宿主在运行时直接提供。只有字段处理或变换语义需要独立复用、审计或持久化时，才需要把它们写入 Data 契约。

在 Plot 应用中，图元、变换与比例尺可按逻辑字段名读取结果；字段或常量如何进入 `x` / `y` / `color` / `size` / `text`，由[绘图语法的通道](/viz/plot/channel)说明。其它消费模块可用自己的契约读取同一份规范化行。
