`<PlotTransform>` 是 `@retikz/plot-react` 的声明组件。它把一个 JSON 可序列化的变换操作（transform operation）放进当前 `<Plot>` 的数据管线，自身不渲染任何图形。

Data 的变换契约并不依赖 Plot；这个组件只是 Plot React 对这些契约的一个创作入口。其它消费模块可以直接使用 `@retikz/data` 的操作配置与运行函数，不需要经过 `<PlotTransform>`。

## 用法

```tsx
import { Plot, PlotTransform } from '@retikz/plot-react';
```

```tsx
<Plot data={rows}>
  <PlotTransform operation={{ kind: 'sort', field: 'date', order: 'ascending' }} />
  {/* 图元 */}
</Plot>
```

一个 `<PlotTransform>` 对应一个变换操作。需要多步处理时，按实际依赖顺序声明多个组件：前一步的输出行会成为后一步的输入行。

### 选择入口

以下三种写法都属于 Plot 应用层，但作用范围不同。

| 入口                     | 适合场景                     | 作用范围                               |
| ------------------------ | ---------------------------- | -------------------------------------- |
| `<PlotTransform ... />`  | JSX 中逐步阅读、组合变换操作 | 当前 Plot 的共享数据管线               |
| `dataTransforms={[...]}` | 程序化生成变换操作数组       | 当前 Plot 的共享数据管线，排在组件之前 |
| 图元局部 `transform`     | 只为某个图元建立局部数据视图 | 该图元，不改写其它图元的输入           |

十二种内置 `kind` 都由 Data 定义和执行，并使用同一个组件。完整契约见 [Data 参考](/viz/data/reference/contract#datatransformschema)，绘图组合示例见[绘图语法的变换](/viz/plot/transform)。

## 技术原理

`PlotTransform` 的函数体直接返回 `null`。`Plot` 在构建绘图规范（spec）时同步遍历子元素（children），识别 `PlotTransform` 元素并把它的属性（props）原样收集为 `IRDataTransformDeclaration`；因此它是配置载体，不是可见图层，也没有子元素。

共享管线按下面的顺序装配：

1. `dataTransforms` 数组
2. 按 JSX 声明顺序收集的 `<PlotTransform>`
3. 图元简写自动生成的操作

显式 `stack` 与自动 `stack` 的签名相同时，自动项会被抑制，避免重复堆叠。其它操作仍按装配后的顺序执行。

## API 参考

#### PlotTransform / PlotTransformProps

`PlotTransformProps` 复用 `IRDataTransformDeclaration`。必填 `operation` 按 `kind` 判别；可选 `dataExecution` 只改变这一阶段的计算入口。

| 属性            | 类型              | 说明                                                                               |
| --------------- | ----------------- | ---------------------------------------------------------------------------------- |
| `operation`     | `IRDataTransform` | 运算参数，完整分支见 [Data 契约](/viz/data/reference/contract#datatransformschema) |
| `dataExecution` | `IRDataExecution` | 稀疏 `mode` 与 `external` 名称，分别继承                                           |

组件、`dataTransforms` 和图元局部 `transform` 都使用 `{ operation, dataExecution? }`，不直接传裸 operation。十二种内置操作与自定义操作共用此声明。

执行器默认配置 < Plot 根 `dataExecution` < 单条声明 `dataExecution`，从左到右优先级升高。`builtin` 为最终缺省模式；`external` 要求外接入口支持全部阶段；`hybrid` 只在外接预检明确不支持时使用本地实现。外接注册与 Promise 宿主接线见[扩展机制](/viz/data/transform/extensions)。
