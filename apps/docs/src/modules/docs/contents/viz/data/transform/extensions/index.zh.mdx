---
title: 扩展机制
description: 用运行时定义扩展数据变换与统计子算子，同时保持操作配置可序列化。
---

数据变换的扩展点负责增加新的行处理操作（operation），或补充现有统计变换可调用的规约器（reducer）与行选择器（selector）。操作只保存 `{ kind, ...config }`；Schema 与执行函数保留在运行时定义（Definition）中，不进入可序列化配置。

## 适用边界

优先使用内置操作。只有新的行处理语义需要稳定名称、配置校验和跨宿主复用时，才注册定义。transform、reducer 与 selector 的 `kind` 是开放字符串：内置常量提供常用提示，不是自定义键的白名单。

| 扩展入口                  | 解决什么                         | 配置保存什么    |
| ------------------------- | -------------------------------- | --------------- |
| `defineTransform`         | 重排、过滤、增删行或生成派生字段 | `{ kind, ... }` |
| `defineStatisticsReducer` | 把一组行规约为输出字段片段       | 规约器操作      |
| `defineRowSelector`       | 从一组行中选择保留的原始行       | 行选择器操作    |

当 `summarize` 或 `annotate` 只缺一种统计计算时，扩展规约器；当 `select` 或宿主明确支持行选择器的变换只缺选行规则时，扩展行选择器。Data 的 `annotate` 行选择器入口只接受内置的单行子集，不接受自定义行选择器。需要新的分组方式、多阶段处理或不同的行结构时，应定义完整变换。

## 定义数据操作

`defineTransform` 通过 `schema` 提取唯一 `kind`，用 `inputFields` 声明读取字段，以 `outputFields` 列出生成字段名，并可通过 `outputModel` 说明变换后的完整字段类型图。`apply` 必须纯且确定，不能修改输入数组或输入行。

内置与自定义变换会合并到同一个注册表（registry），并按 `kind` 走同一套查找、Schema 校验和执行流程。

示例 Definition 还声明了 preserve `outputModel` 与 field-derive `schedule`：前者让下游知道 `scaledX` 是 continuous 字段，后者让兼容的 Chart slot 可以复用同一 Definition 做字段映射。

### 来源追溯

保留行数的变换通常通过展开原行自然保留来源标记。改变行数且输出行代表一组源行时，应使用 `TransformContext.groupProvenance` 关联成员行；全新生成且没有对应源行的结果可以不附加来源。

| 场景             | 推荐处理                                      |
| ---------------- | --------------------------------------------- |
| 重排或保留原始行 | 返回原行对象，或在展开原行后补充派生字段      |
| 汇总多行生成一行 | 用 `groupProvenance(out, members)` 包装输出行 |
| 生成无源数据     | 直接返回新行，并接受来源为空                  |

每个 lowering、locator 或 lineage 调用都是独立运行请求，因此 Definition 仍应保持纯且确定；不同请求不会共享执行缓存。在一次带 lineage 的数据链内，每个 operation 只执行一次，行结果、字段类型证据与 lineage 共用同一次输出。

## 定义统计子算子

规约器与行选择器不是独立的管线步骤。`summarize`、`annotate` 可调用内置或自定义规约器；`select` 与明确声明支持它的宿主变换可调用内置或自定义行选择器。Data `annotate` 的行选择器入口只接受内置单行子集。

| 子算子   | 核心函数 | 返回值               | 常见用途                 |
| -------- | -------- | -------------------- | ------------------------ |
| 规约器   | `reduce` | 写入输出行的字段片段 | 自定义统计量、聚合字段   |
| 行选择器 | `select` | 原始行与可选一基排名 | 代表行、极值行、排名选择 |

规约器应通过 `inputFields` 与 `outputFields` 声明读写字段，并用 `outputs` 为可静态描述的 scalar 输出提供字段类型证据；行选择器通过 `inputFields` 声明读取字段，并返回选中的原始行。若逻辑需要同时改变多种字段或组合多个阶段，应升级为完整变换。

## 注入宿主

消费宿主负责把自定义定义注入数据变换管线。以 Plot 为例：

| 能力           | 注入入口                       | 操作引用方式          |
| -------------- | ------------------------------ | --------------------- |
| 自定义变换     | `transformDefinitions`         | `kind`                |
| 自定义规约器   | `statisticsReducerDefinitions` | 规约器操作的 `kind`   |
| 自定义行选择器 | `rowSelectorDefinitions`       | 行选择器操作的 `kind` |

其它消费模块可以在自己的适配器（adapter）中提供等价入口；定义与操作契约本身属于 Data。

## 执行机制

```text
注入定义 → 合并内置与自定义注册表 → 按 kind 查找 → Schema 校验 → 执行
```

字段收集与实际执行使用同一注册表。每一步先用 Definition schema 解析 operation，再读取 `outputModel`、执行 `apply`，并把 `{ rows, fieldTypes, fieldTypeEvidence }` 一起推进到下一步。`inputFields` 让严格数据模型校验扩展操作读取的源字段，`outputFields` 则标记管线生成的派生字段，避免要求它们预先出现在源数据模型中。

### 字段映射能力门

开放 `kind` 只表示 Source 可以保存自定义 operation，不表示它自动适合 encoding 字段映射。Chart 等宿主要把 Definition 用在 encoding 内，还需要完整调度描述：

| Definition | 必需声明                                                                   | 不满足时                                       |
| ---------- | -------------------------------------------------------------------------- | ---------------------------------------------- |
| transform  | `schedule` 的 phase / binding class / field effect，以及完整 `outputModel` | 继续用于完整 transform；不能进入字段映射       |
| reducer    | `outputs()` 恰好返回一个已类型化 scalar descriptor                         | 可用于完整统计变换；不能作为 compact aggregate |

宿主还会检查 Definition 的阶段、字段影响、输出字段与目标 consumer 是否兼容。自定义键与内置键共用同一 registry、Schema 和能力检查，不靠宿主复制内置枚举。

## 错误与限制

| 情况                                                     | 结果                   |
| -------------------------------------------------------- | ---------------------- |
| `kind` 与内置或另一自定义键重复                          | 注册表构建立即报错     |
| 操作使用未注册 `kind`                                    | 执行前报未注册错误     |
| 操作不满足定义的 Schema                                  | Schema 校验失败        |
| 操作含函数等非 JSON 值                                   | 可序列化校验失败       |
| 自定义规约器的输出声明与分组键或其它统计输出冲突         | 执行规约器前报错       |
| `outputModel` 引用不存在的来源字段或与实际字段影响不一致 | 推进 DataView 前报错   |
| 字段映射缺少完整调度或输出描述                           | 宿主解析字段映射时报错 |

定义只应实现数据行与统计语义。颜色、图元或布局等消费侧语义应放到对应模块的扩展点。

## API 参考

以下定义与定义函数都从 `@retikz/data` 包根导出。

### `TransformDefinition`

| 字段            | 类型                                                                                                 | 描述                                                 |
| --------------- | ---------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| `schema`        | `z.ZodType<TTransform>`                                                                              | 含非空字面量 `kind` 的完整 operation schema          |
| `inputFields?`  | `(operation: TTransform, context: TransformContext) => Array<string>`                                | 返回 operation 读取的源字段                          |
| `outputFields?` | `(operation: TTransform, context: TransformContext) => Array<string>`                                | 返回生成字段名；供 strict model 与冲突检查使用       |
| `outputModel?`  | `(operation: TTransform, context: TransformContext) => DataTransformOutputModel \| undefined`        | 返回变换后的完整字段类型影响；省略时不保留旧类型证据 |
| `schedule?`     | `DataTransformSchedule`                                                                              | 声明可用于字段映射的阶段、binding class 与字段影响   |
| `apply`         | `(rows: Array<ExternalRow>, operation: TTransform, context: TransformContext) => Array<ExternalRow>` | 纯且确定地执行变换                                   |

使用 `defineTransform(definition)` 保留这些字段之间的泛型关联。

### 输出与调度契约

| 类型                            | 关键字段                               | 职责                                                        |
| ------------------------------- | -------------------------------------- | ----------------------------------------------------------- |
| `DataTransformOutputDescriptor` | `field`、`type`                        | 给输出字段固定类型，或用 `{ from }` 复用现有字段类型        |
| `DataTransformOutputModel`      | `preserve.outputs` \| `replace.fields` | 保留并增补当前字段图，或用完整字段清单替换当前字段图        |
| `DataTransformSchedule`         | `phase`、`bindingClass`、`fieldEffect` | 让宿主在闭合阶段顺序中判断该 Definition 能否绑定到字段 slot |

### `StatisticsReducerDefinition`

| 字段            | 类型                                                                                                 | 描述                                                                     |
| --------------- | ---------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| `schema`        | `z.ZodType<TReducerOperation>`                                                                       | 含非空字面量 `kind` 的 schema                                            |
| `inputFields?`  | `(operation: TReducerOperation) => Array<string>`                                                    | 返回读取的源字段                                                         |
| `outputFields?` | `(operation: TReducerOperation) => Array<string>`                                                    | 返回生成字段并作为动态冲突检查依据；必须完整声明 `reduce` 可能写入的字段 |
| `outputs?`      | `(operation: TReducerOperation) => Array<DataTransformOutputDescriptor>`                             | 返回可静态描述的已类型化 scalar 输出                                     |
| `reduce`        | `(rows: Array<ExternalRow>, operation: TReducerOperation, context: TransformContext) => ExternalRow` | 返回写入输出行的字段片段                                                 |

使用 `defineStatisticsReducer(definition)` 定义 reducer。

### `RowSelectorDefinition`

| 字段           | 类型                                                                               | 描述                          |
| -------------- | ---------------------------------------------------------------------------------- | ----------------------------- |
| `schema`       | `z.ZodType<TSelectorOperation>`                                                    | 含非空字面量 `kind` 的 schema |
| `inputFields?` | `(operation: TSelectorOperation) => Array<string>`                                 | 返回读取的源字段              |
| `select`       | `(rows: Array<ExternalRow>, operation: TSelectorOperation) => Array<RowSelection>` | 返回原始行与可选一基 rank     |

使用 `defineRowSelector(definition)` 定义 selector。

自定义 selector 可用于 `select`，也可用于明确声明支持它的宿主 transform（例如 Plot `relate`）；Data `annotate` 不接受自定义 selector。
