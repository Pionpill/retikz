Data 用 Definition 声明操作含义，用 Implementation 提供计算。操作 `{ kind, params }` 和执行配置可以保存为 JSON；schema、函数、执行器与数据源句柄留在运行时。

## 适用边界

需要新的行处理语义时定义 transform；已有 `summarize` 或 `annotate` 只缺统计方法时定义 reducer；已有 `select` 只缺选行规则时定义 selector。替换计算引擎时复用已有 Definition，不创建含义不同的同名操作。

`kind` 是开放字符串，但自定义名称不能覆盖内置名称。所有入口都从 `@retikz/data` 根目录导出。

## 定义能力

`defineTransform` 接收 `kind`、精确 `paramsSchema`、可选 `inputFields` 和必填 `outputModel`。它通过统一的 `createTransformSchema` 组装完整操作 schema；内置与自定义变换遵守同一外壳。回调接收完整 operation，通过 `operation.params` 读取解析后的参数。语义回调只读取参数与字段模型，不读取行或执行计算。需要变换算子的操作通过 `dependencies` 声明完整依赖；`validate` 检查模型相关不变量。

`outputModel` 使用 `preserve.outputs` 增补字段，或用 `replace.fields` 替换完整模型。输出字段可以省略类型表示尚无类型证据；`{ from: field }` 沿用已有字段的类型与适用分类顺序。派生字段名由该模型投影。

`defineTransformImplementation({ definition, apply })` 引用同一个 Definition。下面的 `scale-field` 读取 `x`，按 `factor` 生成 `scaledX`：

实现应遵守 Definition 的语义，不修改输入数组或输入行。保留原行的展开可以保留来源 Symbol；汇总行通过计算 context 的 `groupProvenance(out, members)` 关联源行。语义 Definition 不持有这些来源 helper。

### 变换算子

`defineStatisticsReducer` 用 `schema`、`inputFields` 和必填 `outputs` 声明全部输出；非标量或未知类型输出只声明字段名。计算由 `defineStatisticsReducerImplementation({ definition, reduce })` 提供。

`defineRowSelector` 声明 schema 与输入字段；`defineRowSelectorImplementation({ definition, select })` 返回原始行和可选一基排名。`defineRegression` 与 `defineRegressionImplementation({ definition, fit })` 使用相同分离方式。

## 注入与使用

定义与本地实现分别注册。以下是 Plot 的入口；Chart 使用 `lowerOptions` 中的同名选项，Table 使用各自的 lowering options。

| 能力       | 语义数组                       | 同步本地实现数组                   |
| ---------- | ------------------------------ | ---------------------------------- |
| transform  | `transformDefinitions`         | `transformImplementations`         |
| reducer    | `statisticsReducerDefinitions` | `statisticsReducerImplementations` |
| selector   | `rowSelectorDefinitions`       | `rowSelectorImplementations`       |
| regression | `regressionDefinitions`        | `regressionImplementations`        |

宿主声明使用 `{ operation, dataExecution? }`。`operation` 只保存运算参数，`dataExecution` 选择执行方式：

```tsx
<Plot data={rows} transformDefinitions={[scaleField]} transformImplementations={[scaleFieldImplementation]}>
  <PlotTransform operation={{ kind: 'scale-field', params: { field: 'x', as: 'scaledX', factor: 2 } }} />
  <PointMark x="scaledX" y="y" />
</Plot>
```

直接调用 Data 的同步 `applyTransforms` 时，仍传 operation 数组。执行器的异步路径先用 `resolveDataTransforms` 解析 declaration 与输入模型，再用 `executeDataTransforms` 执行。

外接 Provider、执行模式、异步宿主与数据绑定见[计算契约](/viz/data/transform/computation)。

## 错误与限制

- 重复语义键、重复实现或 Implementation 引用不同 Definition 时立即失败。
- 只有 Definition 的扩展可以交给外接入口执行；本地执行必须提供相应 Implementation。
