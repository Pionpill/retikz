Use `smooth` to convert observations into sampled trend data. It fits a model, then emits prediction rows for charts, tables or further transforms.

## smooth

`smooth` reads finite (x, y) pairs per group, fits a [regression](/viz/data/operators/regression) model, and predicts at evenly spaced positions. Output contains group keys, sampled x and predicted y; input detail fields are dropped. The regression operation returns a model, while smooth turns that model into new rows.

The chosen method determines fitting requirements, such as sufficient distinct x values for quadratic fitting. Inferring an extent requires at least two distinct finite x values; an explicit extent does not replace the model’s input requirements. Output field names must differ and avoid group keys. Its Schema is `SmoothTransformSchema`; parameters are listed below:

<DocTabs defaultValue="api">
<DocTab value="api" label="API">

| Property             | Type                 | Description                                                           |
| -------------------- | -------------------- | --------------------------------------------------------------------- |
| `kind`               | `'smooth'`           | Transform kind                                                        |
| `params.groupBy`     | `Array<string>`      | Optional group fields; omitted or empty means one group               |
| `params.x`           | `string`             | Required numeric independent-variable field                           |
| `params.y`           | `string`             | Required numeric dependent-variable field                             |
| `params.method`      | `IRRegressionMethod` | Optional registered regression method; default linear                 |
| `params.sampleCount` | `number`             | Optional samples per group; integer ≥ 2; default 64                   |
| `params.extent`      | `[number, number]`   | Optional increasing sampling extent; default finite x range per group |
| `params.xAs`         | `string`             | Required sampled x output field                                       |
| `params.yAs`         | `string`             | Required predicted y output field                                     |
