`TableLayoutManifest` is the JSON-safe, detached, recursively frozen typed-artifact payload produced by the same Table compile. See [Runtime](/viz/table/reference/runtime#table-compile-api) for exact-root selection; this page lists only output shapes and nested DTOs.

## Root manifest

### TableLayoutManifestSchema

<ZodSchema name="TableLayoutManifestSchema" />

The manifest `style` region also records effective Core `style`, `themeMode`, the complete resolved Table `tokens` map, and one `sources` entry per token. Here `themeMode` is output metadata from the same compile, identifying the selected preset; TableSpec inputs remain the host `theme` and local `tableThemeTokens`, which belong to a different layer.
