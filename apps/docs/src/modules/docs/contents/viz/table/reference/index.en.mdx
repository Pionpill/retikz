API Reference is a contract dictionary rather than an introductory guide. TableSpec and Cell content, detail-only structure, layout inputs, compile outputs, and runtime wiring each have a dedicated page.

> This is the reference layer. Start with [Detail Table](/viz/table/detail) to build a table, or [Table Model](/viz/table/model) to understand the shared abstractions.

## Responsibilities

| Topic                   | Responsibility                                  | Reach for it when                         |
| ----------------------- | ----------------------------------------------- | ----------------------------------------- |
| Contract - Detail Table | Data references, columns, and detail Structure  | Generating or validating detail IR        |
| Contract - Table        | TableSpec, manual Cells, and canonical payloads | Generating or validating Table IR         |
| Contract - Layout       | Cell span/layout, tracks, and border inputs     | Configuring layout and content fitting    |
| Contract - Artifact     | Resolved tracks, Cell boxes, borders, locators  | Reading same-compile layout artifacts     |
| Runtime                 | React / Vanilla, compile, and artifact wiring   | Integrating a host, SSR, or Table runtime |
