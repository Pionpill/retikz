API Reference is a contract dictionary rather than an introductory guide. Base and detail tables have separate contract pages; Runtime collects how React, Vanilla, and SSR construct, lower, and render the same specification.

> This is the reference layer. Start with [Detail Table](/viz/table/detail) to build a table, or [Table Model](/viz/table/model) to understand the shared abstractions.

## Responsibilities

| Topic                   | Responsibility                                    | Reach for it when                          |
| ----------------------- | ------------------------------------------------- | ------------------------------------------ |
| Contract - Table        | TableSpec, Cells, tracks, spans, and borders      | Generating generic or explicit-grid IR     |
| Contract - Detail Table | Data reference, columns, and the detail Structure | Generating or validating detail-table IR   |
| Runtime                 | React / Vanilla, compile, and typed manifests     | Integrating a host, SSR, or layout outputs |
