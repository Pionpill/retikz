布局契约描述 Cell 如何占据轨道、内容如何适配 Cell box，以及 Table 如何配置轨道和 border。这里列输入配置；compile 后的 resolved geometry 与来源见[产物契约](/viz/table/reference/manifest)。

## Table 布局

### TableLayoutSchema

<ZodSchema
  name="TableLayoutSchema"
  description="Table 默认/稀疏覆盖轨道尺寸、非负 gap 与全表 border 策略。"
  descriptions={{
    columnSize: '默认列轨道尺寸；省略时使用 fixed 120。',
    rowSize: '默认正文行轨道尺寸；省略时使用 fixed 32。',
    headerRowSize: '默认列头行尺寸；省略时跟随解析后的 rowSize。',
    columns: '按 canonical 零基索引声明的稀疏列尺寸覆盖。',
    rows: '按 canonical 零基索引声明的稀疏行尺寸覆盖。',
    columnGap: '相邻列之间的非负间距；省略时使用 0。',
    rowGap: '相邻行之间的非负间距；省略时使用 0。',
    borders: '可选的 Table border 拓扑与默认候选。',
  }}
/>

省略字段时，列为 fixed `120`、正文行为 fixed `32`、列头行跟随正文行，行列 gap 为 `0`。`auto` 与 `minmax` 可以消费内容 contribution；fraction 只在有限父宽约束下扩展列，行轴当前按自然 contribution 求值。

## 轨道尺寸原语

以下尺寸原语直接用于 `TableLayoutSchema.columnSize` / `rowSize` / `headerRowSize` 和稀疏覆盖，表达固定尺寸、内容自然尺寸、剩余空间份额与带上下界的轨道。

轨道尺寸的判别值为 <ApiValues name="TableTrackSizeKind" />。

### TableFixedTrackSizeSchema

<ZodSchema
  name="TableFixedTrackSizeSchema"
  description="显式固定轨道尺寸；允许 0 表达折叠轨道。"
  descriptions={{
    kind: '固定轨道尺寸的判别值。',
    value: '有限非负的固定尺寸。',
  }}
/>

### TableAutoTrackSizeSchema

<ZodSchema
  name="TableAutoTrackSizeSchema"
  description="从 canonical 内容贡献确定自然尺寸的轨道。"
  descriptions={{
    kind: '内容自然尺寸轨道的判别值。',
  }}
/>

### TableFractionTrackSizeSchema

<ZodSchema
  name="TableFractionTrackSizeSchema"
  description="在有限轴约束下按权重分配剩余空间的轨道。"
  descriptions={{
    kind: '弹性份额轨道的判别值。',
    weight: '有限正权重；省略时运行时使用 1。',
  }}
/>

### TableMinmaxTrackSizeSchema

<ZodSchema
  name="TableMinmaxTrackSizeSchema"
  description="由下界和上界变体约束的轨道尺寸。"
  descriptions={{
    kind: '带上下界轨道的判别值。',
    min: '固定或内容自然下界。',
    max: '固定、内容自然或弹性份额上界。',
  }}
/>

当上下界都是 fixed 时，`min.value` 不能大于 `max.value`。`min` 不接受 fraction；`max` 接受 fixed、auto 或 fraction。

### TableTrackOverrideSchema

<ZodSchema
  name="TableTrackOverrideSchema"
  description="通过 canonical 零基索引覆盖单个轨道的尺寸。"
  descriptions={{
    index: '要覆盖的 canonical 零基轨道索引。',
    size: '替换该索引轴默认值的轨道尺寸。',
  }}
/>

### TableTrackOverridesSchema

<ZodSchema name="TableTrackOverridesSchema" description="canonical 索引必须唯一的稀疏轨道尺寸覆盖列表。" />

列表允许只声明需要覆盖的索引，不要求复制其余轨道。同一列表中的重复索引会被 schema 拒绝；相对于实际行列数量的越界检查由后续 layout resolve 执行。

## Border 配置

border 候选类型为 <ApiValues name="TableBorderKind" />；全表拓扑模式为 <ApiValues name="TableBorderMode" />。`collapse` 把共享边候选放入同一冲突解析，`separate` 保留每个真实 Cell side。

### TableBordersSchema

<ZodSchema
  name="TableBordersSchema"
  description="全表 border 拓扑与外框、横向内线、纵向内线默认候选。"
  descriptions={{
    mode: '共享边 collapse 或逐 Cell separate 模式；省略时为 collapse。',

/>

Cell side 的候选优先于全表默认；同一共享原子边先比较 `priority`，再比较来源 specificity 与 canonical source order。`kind: 'none'` 可以显式压制低优先级线条。
