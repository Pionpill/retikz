API 参考用于查稳定合同，不承担入门教学。TableSpec 与 Cell 内容、detail 专有结构、布局配置、compile 输出和运行时接线分别进入独立页面。

> 这里是参考层。开始制作表格请阅读[明细表](/viz/table/detail)，理解共享抽象请阅读[表格模型](/viz/table/model)。

## 职责一览

| 主题          | 职责                                           | 何时查阅                    |
| ------------- | ---------------------------------------------- | --------------------------- |
| 契约 - 明细表 | data reference、columns 与 detail Structure    | 生成或校验明细表 IR         |
| 契约 - 表格   | TableSpec、manual Cell 与 canonical payload    | 生成或校验 Table IR         |
| 契约 - 布局   | Cell span/layout、轨道与 border 输入配置       | 配置表格布局与内容适配      |
| 契约 - 产物   | resolved tracks、Cell boxes、border 与 locator | 读取同次 compile 的布局产物 |
| 运行时        | React / Vanilla、compile 与 artifact 接线      | 集成宿主、SSR 或执行 Table  |
