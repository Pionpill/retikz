API 参考用于查稳定合同，不承担入门教学。基础表格与明细表使用各自的契约页；React、Vanilla、SSR 如何构造、下沉和渲染同一份规格集中在运行时页。

> 这里是参考层。开始制作表格请阅读[明细表](/viz/table/detail)，理解共享抽象请阅读[表格模型](/viz/table/model)。

## 职责一览

| 主题          | 职责                                             | 何时查阅                       |
| ------------- | ------------------------------------------------ | ------------------------------ |
| 契约 - 表格   | TableSpec 根、Cell、Layout 与 manual/custom 变体 | 生成通用或显式网格 Table IR    |
| 契约 - 明细表 | data reference、columns 与 detail Structure      | 生成或校验 `IRDetailTableSpec` |
| 运行时        | React / Vanilla 入口、lowering 与 manifest       | 集成宿主、SSR 或读取布局产物   |
