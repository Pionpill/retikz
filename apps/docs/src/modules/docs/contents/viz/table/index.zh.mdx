---
title: 表格
description: 从明细表开始，将数据组织成可阅读、可持久化并能接入 Kernel 渲染的表格。
---

Table 是独立的 Tier 2 能力：它负责行列结构、Cell 语义、内容驱动轨道、span、fit/overflow、border 与 typed manifest，而[数据](/viz/data)负责记录、字段模型与数据变换。表格不是 Plot 上再包一层的“图表类型”。

使用 `DetailTable` 可以把一条记录映射为一行。

## 如何阅读

| 你想做什么                          | 从哪里开始                       |
| ----------------------------------- | -------------------------------- |
| 展示名单、流水或逐行记录            | [明细表](/viz/table/detail)      |
| 理解 Structure、Cell 与约束布局     | [表格模型](/viz/table/model)     |
| 查询完整 spec、React 或 Vanilla API | [API 参考](/viz/table/reference) |
