Table is an independent Tier 2 capability. It owns row-and-column structure, Cell semantics, content-sized tracks, spans, fit/overflow, borders, and typed manifests, while [Data](/viz/data/introduction) owns records, field models, and transforms. A table is not another chart type layered over Plot.

Use `DetailTable` to map one record to one row.

## Where to start

| Goal                                                | Start here                            |
| --------------------------------------------------- | ------------------------------------- |
| Show lists, ledgers, or record-per-row data         | [Detail Table](/viz/table/detail)     |
| Understand Structure, Cells, and constrained layout | [Table Model](/viz/table/model)       |
| Look up complete specs or React and Vanilla APIs    | [API Reference](/viz/table/reference) |
