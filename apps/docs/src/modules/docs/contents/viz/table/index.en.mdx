Table is an independent Tier 2 capability. It owns row-and-column structure, Cell semantics, deterministic layout, and lowering, while [Data](/viz/data) owns records, field models, and data transforms. A table is not another chart type layered over Plot, and each table type does not need a duplicated low-level grammar.

Use `DetailTable` to map one record to one row.

## Where to start

| Goal                                              | Start here                            |
| ------------------------------------------------- | ------------------------------------- |
| Show lists, ledgers, or record-per-row data       | [Detail Table](/viz/table/detail)     |
| Understand Structure, Cells, layout, and lowering | [Table Model](/viz/table/model)       |
| Look up complete specs or React and Vanilla APIs  | [API Reference](/viz/table/reference) |
