基础表格契约定义所有表型共享的顶层身份与 Cell 内容，并提供 manual / custom 精确根变体。detail 专有的数据引用与列结构见[明细表契约](/viz/table/reference/contract-detail)；Cell box、轨道和 border 配置见[布局契约](/viz/table/reference/contract-layout)。

## TableSpec 根

`IRTableSpec` 是 `IRDetailTableSpec | IRManualTableSpec | IRCustomTableSpec` 的聚合类型。三个变体共享 `namespace + type`，再分别约束 `data` 与 `structure`。

| 字段                | 类型                                | 默认值     | 描述                                   |
| ------------------- | ----------------------------------- | ---------- | -------------------------------------- |
| `namespace`         | `'table'`                           | —          | Tier 2 composite 命名空间              |
| `type`              | <ApiValues name="TableComposite" /> | —          | 顶层 Table node type                   |
| `id?`               | `string`                            | —          | 可选稳定 id                            |
| `layout?`           | `IRTableLayout`                     | 轨道默认值 | 轨道、稀疏覆盖、gap 与 border          |
| `meta?`             | `IRJsonObject`                      | —          | lowering 原样保留的 JSON-safe 元数据   |
| `rules?`            | `Array<IRTableCellRule>`            | `[]`       | 按声明顺序应用的 Cell 覆盖             |
| `encodings?`        | `Array<IRTableCellVisualEncoding>`  | `[]`       | 按顺序把原始值映射到颜色通道           |
| `tableThemeTokens?` | `IRTableThemeTokenOverrides`        | `{}`       | 当前 TableSpec 的稀疏 Table token 覆盖 |
| `data?`             | `IRDataReference`                   | —          | detail 必需、manual 禁止、custom 可选  |
| `structure`         | `IRTableStructureOperation`         | —          | detail、manual 或 custom Structure     |

## Cell 内容

`IRManualTableCell` 是 manual `rows` 中可直接持久化的非空 entry。`string | number | boolean` 是 value 简写；rich object 可保存 value/content、span 与 layout。`null` 属于 rows 的空槽哨兵，不是这个 Cell union；真正的 null scalar 写成 `{ value: null }`。

## Table Theme token

Core Theme 的 `style` / `mode` 由宿主 `Layout` 或 `renderTable(..., { theme })` 提供。Table 按同名 `TableThemeStyleDefinition` 解析 owner-local baseline，再投影 Core shared `colors.categorical` 到 `data.categorical`，最后应用 TableSpec 的局部 sparse `tableThemeTokens`。因此 Table 不维护第二份 shared palette 输入，也不会把完整 token map 持久化进 Theme IR。

内置 `neutral`、`academic`、`vibrant`、`clean` 已同时注册 Core 与 Table definition。自定义 style 必须在实际消费它的两个 owner 中注册同名 definition：standalone `compileTable` 通过 `compile.themeStyles` 注入 Core definition，并通过 `lower.tableThemeStyles` 注入 Table definition；缺少 Table 同名 definition 会在 Table resolver fail-loud。
