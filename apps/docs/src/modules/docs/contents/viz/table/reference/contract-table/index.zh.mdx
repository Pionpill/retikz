基础表格契约定义所有表型共享的顶层身份、Cell 内容和布局字段，并提供 manual / custom 精确根变体。detail 专有的数据引用与列结构见[明细表契约](/viz/table/reference/contract-detail)。

## TableSpec 根

`IRTableSpec` 是 `IRDetailTableSpec | IRManualTableSpec | IRCustomTableSpec` 的聚合类型。三个变体共享 `namespace + type`，再分别约束 `data` 与 `structure`。

| 字段        | 类型                                | 默认值         | 描述                                  |
| ----------- | ----------------------------------- | -------------- | ------------------------------------- |
| `namespace` | `'table'`                           | —              | Tier 2 composite namespace            |
| `type`      | <ApiValues name="TableComposite" /> | —              | 顶层 Table node type                  |
| `id?`       | `string`                            | —              | 可选稳定 id                           |
| `layout?`   | `IRTableLayout`                     | 固定轨道默认值 | 列宽、正文/列头行高与行列 gap         |
| `meta?`     | `IRJsonObject`                      | —              | lowering 原样保留的 JSON-safe 元数据  |
| `data?`     | `IRDataReference`                   | —              | detail 必需、manual 禁止、custom 可选 |
| `structure` | `IRTableStructureOperation`         | —              | detail、manual 或 custom Structure    |

## Cell

`IRTableCell` 是 manual Structure 中可直接持久化的 Cell。地址从 `0` 开始；省略 `id`、`location` 或 `roles` 时，运行时会从地址和所在行语义派生。

### TableCellSchema

<ZodSchema
  name="TableCellSchema"
  description="显式 Cell：包含零基地址、value/content payload，以及可选身份与语义角色。"
/>

### TableCellPayloadSchema

<ZodSchema
  name="TableCellPayloadSchema"
  description="Cell 内容联合：value 交给 presentation provider，content 直接保存 JSON-safe Core/Tier 2 child。"
/>

`{ kind: 'value', value: 'Score' }` 中的 `kind: 'value'` 表示“标量值呈现”分支；它不是 JavaScript 字符串类型的别名。直接放置 Node、Path 或 Tier 2 child 时使用 `kind: 'content'`。

## Layout

### TableLayoutSchema

<ZodSchema name="TableLayoutSchema" description="v0.1 固定轨道布局：统一列宽、正文/列头行高，以及非负的行列间距。" />

省略字段时，`columnWidth` 为 `120`、`rowHeight` 为 `32`、`headerHeight` 跟随正文行高，行列 gap 为 `0`。Cell 内容不会反向改变轨道尺寸。
