基础表格契约定义所有表型共享的顶层身份、Cell 内容和布局字段，并提供 manual / custom 精确根变体。detail 专有的数据引用与列结构见[明细表契约](/viz/table/reference/contract-detail)。

## TableSpec 根

`IRTableSpec` 是 `IRDetailTableSpec | IRManualTableSpec | IRCustomTableSpec` 的聚合类型。三个变体共享 `namespace + type`，再分别约束 `data` 与 `structure`。

| 字段        | 类型                                | 默认值     | 描述                                  |
| ----------- | ----------------------------------- | ---------- | ------------------------------------- |
| `namespace` | `'table'`                           | —          | Tier 2 composite 命名空间             |
| `type`      | <ApiValues name="TableComposite" /> | —          | 顶层 Table node type                  |
| `id?`       | `string`                            | —          | 可选稳定 id                           |
| `layout?`   | `IRTableLayout`                     | 轨道默认值 | 轨道、稀疏覆盖、gap 与 border         |
| `meta?`     | `IRJsonObject`                      | —          | lowering 原样保留的 JSON-safe 元数据  |
| `data?`     | `IRDataReference`                   | —          | detail 必需、manual 禁止、custom 可选 |
| `structure` | `IRTableStructureOperation`         | —          | detail、manual 或 custom Structure    |

## Cell

`IRTableCell` 是 manual Structure 中可直接持久化的 Cell。地址从 `0` 开始；省略 `id`、`location` 或 `roles` 时，运行时会从地址和所在行语义派生。

## Layout

### TableLayoutSchema

  name="TableLayoutSchema"
  description="Table 默认/稀疏覆盖轨道尺寸、非负 gap 与全表 border 策略。"
  descriptions={{
    columnSize: '默认列轨道尺寸；省略时使用 fixed 120。',
    rowSize: '默认正文行轨道尺寸；省略时使用 fixed 32。',
    headerRowSize: '默认列头行尺寸；省略时跟随解析后的 rowSize。',
    columns: '按 canonical 零基索引声明的稀疏列尺寸覆盖。',
    rows: '按 canonical 零基索引声明的稀疏行尺寸覆盖。',
    columnGap: '相邻列之间的非负间距；省略时使用 0。',
    rowGap: '相邻行之间的非负间距；省略时使用 0。',
    borders: '可选的 Table border 拓扑与默认候选。',
  }}
/>

省略字段时，列为 fixed `120`、正文行为 fixed `32`、列头行跟随正文行，行列 gap 为 `0`。`auto` 与 `minmax` 可以消费内容 contribution；fraction 只在有限父宽约束下扩展列，行轴当前按自然 contribution 求值。

## 轨道尺寸原语

以下尺寸原语直接用于 `TableLayoutSchema.columnSize` / `rowSize` / `headerRowSize` 和稀疏覆盖，表达固定尺寸、内容自然尺寸、剩余空间份额与带上下界的轨道。

## Border

border 候选类型为 <ApiValues name="TableBorderKind" />；全表拓扑模式为 <ApiValues name="TableBorderMode" />。`collapse` 把共享边候选放入同一冲突解析，`separate` 保留每个真实 Cell side。
