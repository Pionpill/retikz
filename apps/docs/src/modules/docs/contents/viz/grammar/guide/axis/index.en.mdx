---
title: Axis
description: Customize ticks, labels, and grid with <Axis>; dimension picks which dimension to decorate — cartesian x / y or polar x / y.
---

`<Axis>` declares one axis. `dimension` picks which dimension it decorates: under cartesian it's `x` (horizontal) / `y` (vertical), under polar it still uses `x` (angular) / `y` (radial), under ternary it's `x` / `y` / `z` (the three triangle edges). The dimension must match the current coordinate system — a wrong one errors (no silent empty axis). Axis line, ticks, tick labels, title, and grid are slots on the same Axis guide.

`<Plot>` is a thin container and draws no axes on its own — without `<Axis>` there are no axes, and only the `<Axis>` you list get drawn. When you only need to switch an axis to a log, time, or square-root scale, put `scale` on the same `<Axis>` instead of adding a separate `<Scale>`.

## Usage

The smallest structure is to list the x / y axes you want inside `<Plot>`. In the demo below, the y axis adds a grid and a target tick count; use the preview panel to inspect the source, IR, and Vanilla form.

## Examples

### Style Slots

`line` controls the axis line; `ticks` controls the tick source, length, and tick-line style; `tickLabels` controls whether tick text renders and how it is styled; `title` is the axis title and accepts a string or structured text; `grid` can be a boolean or a line-style object. `dashOffset` pairs with `dashPattern` when you need to shift the dash phase.

<ComponentPreview name="axis-style-slots" sourceFiles={['axis-style-slots.data.ts']} />

### Tick Density

`ticks.count` is a target hint for the scale, not a guaranteed final count. Use `ticks.interval` for fixed-step candidates, `ticks.density` to sample visible ticks, and `ticks.mark` to replace line ticks with builtin shapes or a custom core shape.

| Config | Main forms | Purpose |
| ------ | ---------- | ------- |
| `interval` | `{ kind:'number', step, anchor? }` / `{ kind:'time', unit, step?, anchor? }` / `{ kind:'category', step, offset? }` | Generate fixed-step candidate ticks |
| `density` | `{ kind:'all' }` / `{ kind:'sample', maxCount?, minGap?, preserveEnds? }` | Sample candidate ticks into visible ticks |
| `mark` | `false` / `{ kind:'line', length?, line? }` / `{ kind:'circle' \| 'square' \| 'triangle' \| 'diamond', ... }` / `{ kind:'custom', shape, ... }` | Control tick marker appearance |

<ComponentPreview name="axis-tick-density" sourceFiles={['axis-tick-density.data.ts']} />

### Tick Label Layout

`tickLabels.layout` only adjusts label nodes; it does not change ticks, tick marks, or grid lines. Omit it to use the builtin adaptive strategy, or set `layout: false` when exact label placement is more important than automatic rotation, hiding, and boundary handling.

| Config | Main forms | Purpose |
| ------ | ---------- | ------- |
| `layout.rotate` | `false` / `{ angles?, recoverWhenFailed? }` | Pick an automatic tick-label rotation angle; explicit `tickLabels.rotate` takes priority |
| `layout.hide` | `false` / `{ strategy:'greedy' \| 'parity', preserveEnds?, separation? }` | Hide overlapping labels while keeping ticks, tick marks, and grid lines |
| `layout.bounds` | `false` / `{ overflow:'allow' \| 'hide' \| 'flush', tolerance? }` | Handle labels that overflow the axis span |
| `layout.sampleSize` | `number` | Limit how many labels are scanned while estimating auto rotation |

### Origin Axes

Under cartesian coordinates, an axis can cross a data value from the other dimension. `placement.kind="origin"` only changes where the axis baseline sits; it does not expand the domain automatically. Configure `domain` or `domainPadding` when the origin needs to be visible. `crossing` controls the tick and label at the crossing value, `line.arrow` uses `positive` / `negative` for axis-direction endpoints, `ticks.endpoint` hides tick marks near arrows, and `title.placement` places the title along the visible baseline.

| Config | Common values | Purpose |
| ------ | ------------- | ------- |
| `crossing.tick` | `'show' \| 'hide'` | Show or hide the tick mark at the crossing value |
| `crossing.label` | `'show' \| 'hide' \| 'corner'` | Show, hide, or move the crossing label to a corner |
| `crossing.corner` | `'top-left' \| 'top-right' \| 'bottom-left' \| 'bottom-right'` | Corner used when `label:'corner'` |
| `ticks.endpoint` | `false \| { hideWhenArrow?, distance?, affect? }` | Control tick avoidance near arrow endpoints; `false` disables the default avoidance, and `affect:'mark-and-label'` also hides the label |
| `title.placement` | `'at-start'` / `'near-start'` / `'midway'` / `'near-end'` / `'at-end'` / `0..1` | Place the title from negative to positive axis direction |
| `title.orientation` | `'auto'` / `'horizontal'` / `'axis'` | Control title rotation; math axes often use `horizontal` for the y title |

### Polar axes

Under polar, use `dimension="x"` (angular tick labels) and `dimension="y"` (radial ticks + concentric grid rings). Radar / polar charts usually use both together.

## API

| Prop         | Type                                               | Default            | Description                                                                                                                                       |
| ------------ | -------------------------------------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------- |
| `dimension`  | `'x' \| 'y' \| 'z'`                                | —                  | Which dimension to decorate: cartesian x / y, polar x / y, ternary x / y / z (triangle edges); must match the coordinate's valid set or it errors |
| `scale`      | `'linear' \| 'time' \| 'point' \| 'log' \| 'sqrt' \| 'symlog' \| 'radial'` | auto-derived       | Positional scale shortcut; equivalent to `<Scale dimension="..." type="..." />` for the same dimension, and only applies to x / y / z |
| `placement`  | `{ kind:'auto' } \| { kind:'side', side, offset? } \| { kind:'edge', edge, offset? } \| { kind:'origin', origin?, tickSide?, offset? }` | inferred | Axis placement; `origin` only supports cartesian axes. For an x axis, `origin` is a y value; for a y axis, it is an x value |
| `line`       | `false \| { stroke?, strokeWidth?, drawOpacity?, dashPattern?, dashOffset?, lineCap?, extent?, arrow? }` | default line | Axis-line style and endpoint geometry; `extent` controls the data span, and `arrow.positive/negative` controls axis-direction arrows; `extent` / `arrow` currently only support cartesian axes |
| `crossing`   | `false \| { value?, tick?, label?, corner? }` | normal ticks | Tick and label policy at an axis crossing value; `label:'corner'` can move a shared origin label to one corner |
| `ticks`      | `{ count?, values?, interval?, density?, endpoint?, mark?, length?, line? }` | default ticks      | `values > interval > count` creates candidate ticks; `density` samples visible ticks; `endpoint` hides tick artifacts near arrows without changing grid source; `mark` controls line / shape marks |
| `tickLabels` | `false \| { format?, gap?, font?, textColor?, opacity?, align?, lineHeight?, maxTextWidth?, rotate?, layout? }` | `true` | Tick-label config; `format` accepts d3-format / d3-time-format; `rotate` is fixed rotation and takes priority over `layout.rotate`; `layout:false` disables adaptive layout |
| `title`      | `string \| { text, gap?, placement?, orientation?, font?, textColor?, opacity?, align?, lineHeight?, maxTextWidth?, rotate? }` | — | Axis title; `placement` supports path-label-like keywords or a `0..1` ratio; `orientation` controls title rotation, and explicit `rotate` takes priority |
| `grid`       | `boolean \| { stroke?, strokeWidth?, drawOpacity?, dashPattern?, dashOffset? }` | `false` | Draw grid lines aligned to this axis's ticks (concentric rings for polar y); object form overrides line style |
| `id`         | `string?`                                          | —                  | Optional handle (reserved, not yet resolved)                                                                                                      |
