plot 的变换运行在[数据](/viz/data)整理出的 canonical 行之后、比例尺和图元之前。这里讲的是 plot 额外注册的绘图能力：它们服务于“怎么画”，例如区间柱、百分比堆叠、直方图、密度面积、趋势线和关系边。

`@retikz/data` 自带的数据变换（`sort`、`summarize`、`select`、`annotate`、`defineTransform`）放在[数据 / 数据变换](/viz/data/transform)说明。plot 可以消费它们，但不在本分组重复定义。

## 职责一览

| 分类       | plot 注册的成员              | 行数  | 适合场景                          |
| ---------- | ---------------------------- | ----- | --------------------------------- |
| 区间与抖动 | `derive-interval` / `jitter` | N → N | 甘特条、非零基线柱、散点抖开      |
| 堆叠与占比 | `stack` / `normalize`        | N → N | 堆叠柱、堆叠面积、百分比堆叠      |
| 分箱统计   | `bin`                        | N → B | 直方图、箱线图统计字段组合        |
| 采样统计   | `density` / `smooth`         | N → S | 密度曲线、密度面积、趋势线        |
| 行配对     | `relate`                     | N → P | 从 source / target 行生成关系字段 |

这些变换的输出仍然是普通数据行。变换产生的字段（如 `y0` / `y1`、`binStart` / `binEnd`、`density`、`sourceId` / `targetId`）不需要提前写进 model；被变换读取的输入字段仍然要走数据模型和校验。

## 声明方式

用 `<Transform kind="...">` 声明 plot 级变换，`kind` 判别类型，其它 props 对应该变换字段。多个 `<Transform>` 按声明顺序折叠成管线：

```tsx
<Plot data={rows} model={model}>
  <Transform kind="bin" field="value" count={12} />
  <IntervalMark x0="binStart" x1="binEnd" y="binCount" />
</Plot>
```

同样的 transform 数组也可以写到任意 mark 上，让这一层图元拿到自己的局部数据视图：

```tsx
<Plot data={rows} model={model}>
  <PointMark x="x" y="y" />
  <PathMark
    x="trendX"
    y="trendY"
    order="trendX"
    transform={[{ kind: 'smooth', x: 'x', y: 'y', xAs: 'trendX', yAs: 'trendY' }]}
  />
</Plot>
```

程序化构造时，也可以用 `<Plot dataTransforms={[...]}>` 直传 transform 数组。它和 `<Transform>` 子组件共用同一管线；直传数组排在子组件之前。

> 用 `dataTransforms` 而不是 `transforms`，是为了和 core 容器的几何 `transforms`（平移 / 旋转）区分。

React DSL 里的高级快捷写法也会落成普通 transform。例如 `IntervalMark` 的 `angle` / `stack` / `percent` 会生成 `stack` 或 `normalize + stack`；自定义创作层语法可以通过 `markTransformShortcuts` 生成同样的 transform operation。快捷入口不引入新的数据语义，只是少写样板。

## 技术原理

lowering 时，Plot 先收集 transform 读取的源字段，同时登记 transform 派生出来的输出字段。这样 strict model 只校验真实输入字段，不要求你把派生字段提前声明。

plot 级 transform 会影响整张图的 scale、guide 和所有 mark。mark-local transform 只影响当前图元看到的 rows，适合派生局部统计层或 relation 行。

`bin`、`density`、`smooth` 和 `relate` 会复用 data 包提供的 reducer / selector 等统计子能力；完整数据 transform 和自定义 transform definition 见[数据变换](/viz/data/transform)。
