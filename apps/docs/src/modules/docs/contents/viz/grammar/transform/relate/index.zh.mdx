---
title: 行配对
description: relate 会从每个分组中选择 source 和 target 行，并投影成普通关系行，供 RelationMark 或其它 mark 消费。
---

`relate` 用 selector 先选出 source 行和 target 行，再把这些行上的字段投影成 `sourceXxx` / `targetXxx`。它常放在 `RelationMark.transform` 里，但不是 RelationMark 私有能力；输出字段只是普通 transform 派生字段，可以继续被任意 mark 使用。

| 步骤        | 配置                              | 输出                               |
| ----------- | --------------------------------- | ---------------------------------- |
| 选择 source | `source.selector`                 | 一个源端原始行                     |
| 选择 target | `target.selector`                 | 一个目标端原始行                   |
| 投影字段    | `source.fields` / `target.fields` | `sourceId` / `targetId` 等端点字段 |
| 计算度量    | `measures`                        | `delta` / `deltaLabel` 等关系字段  |

## 极值配对 relate

`relate` 的输入仍然是普通数据行。demo 中 `PathMark` 和 `PointMark` 消费原始行；`RelationMark` 的局部 transform 只为当前关系层生成一行配对数据。
source / target 使用的 selector 与 `select` 共用同一套[统计子算子](/viz/grammar/transform/statistics)，因此也可以选择 top-N、排序后的首尾行或自定义代表行。

| prop              | 类型                    | 默认值   | 说明                           |
| ----------------- | ----------------------- | -------- | ------------------------------ |
| `groupBy`         | `Array<string>?`        | 全局单组 | 每组独立生成一条或多条配对行   |
| `source.selector` | `Selector`              | —        | source 端代表行选择规则        |
| `source.fields`   | `Record<string,string>` | —        | 输出字段后缀 → source 行字段   |
| `target.selector` | `Selector`              | —        | target 端代表行选择规则        |
| `target.fields`   | `Record<string,string>` | —        | 输出字段后缀 → target 行字段   |
| `measures`        | `Array<PairMeasure>?`   | —        | source / target 之间的派生度量 |

```tsx
<RelationMark
  transform={[
    {
      kind: 'relate',
      source: { selector: { op: 'min', by: 'value' }, fields: { id: 'id' } },
      target: { selector: { op: 'max', by: 'value' }, fields: { id: 'id' } },
      measures: [{ op: 'difference', field: 'value', as: 'delta', labelAs: 'deltaLabel', labelPrefix: '+' }],
    },
  ]}
  source={{ anchorId: { prefix: 'trend', field: 'sourceId' } }}
  target={{ anchorId: { prefix: 'trend', field: 'targetId' } }}
/>
```

## 字段命名

`fields` 的 key 会作为输出后缀，并自动加上 `source` 或 `target` 前缀。比如 `source.fields: { id: 'id', x: 'month' }` 会输出 `sourceId` 和 `sourceX`。

`measures` 当前内置 `difference`，语义是 `target[field] - source[field]`。如果需要更复杂的配对度量，可以用自定义 transform 先产出关系行，或后续扩展 pair measure definition。
