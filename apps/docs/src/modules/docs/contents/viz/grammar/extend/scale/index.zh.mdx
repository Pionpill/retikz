内置的位置 / 颜色 scale 覆盖不了的长尾（品牌色阶、领域专用映射、自定义离散化…）用 `defineScale` 注册运行时 definition，经 `scaleDefinitions` 注入。它和坐标系的 `defineCoordinate` 同一套范式：IR 只存 `{ type, name, ...config }` 的纯 JSON op，函数留在运行时 definition 里、不进 IR。

## 两族判别

scale 按 **family 两族**判别，产出契约不同：

- **`position`**：值 → 坐标，喂坐标投影与坐标轴。`resolve(def, values, range)` 返回一个 `PositionScale`（实现 `coordinate` / `bandwidth` / `ticks` / `range` / `setRange`）；`isFieldCompatible(fieldType)` 决定可绑字段类型、`allowsBaseline` 决定能否作 interval / area 值轴。
- **`channel`**：值 → 视觉量（颜色），喂 color 通道与图例。`resolve(def, values, ctx)` **单次**返回 `{ of, legendForm, domain, range, edges? }`——`of` 逐值取色、`legendForm`（`'ramp'` / `'swatch'`）决定图例形态，实绘与图例同源不漂移。`ctx` 提供 `toNumber` / `coerceTimestamp` 强转与 `resolveColorScheme` 配色解析。

## 自定义配色

自定义命名配色单独走 `colorSchemes`（`name → interpolator` 纯函数表，不进 IR；IR 只存 scheme 名串）。内置 / 离散化色阶都能引用自定义 scheme 名，求值期先查内置、再查 `colorSchemes`，未注册即报错：

```tsx
<Plot spec={spec} data={datasets} colorSchemes={{ brand: t => `hsl(210, 80%, ${100 - t * 60}%)` }} />
```

几条约束：

- **未注册 type / scheme 名 → lowering 期 fail-loud**；自定义 type 撞内置、两个自定义同 type → 报错。
- 自定义 scale **不参与 React 字段类型自动派生**（避免歧义），只在 spec 显式引用。
- scale `type` 字段排除内置判别串：含自定义 type 的 spec 仍能过 `PlotSpecSchema.parse` 并 JSON round-trip 不丢字段，配置精确校验延到 lowering（按 definition 的 schema）。
