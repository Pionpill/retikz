---
title: Density & Trend
description: Density and trend are plot-registered sampled-statistic transforms that turn raw samples into rows drawn as curves or areas by PathMark.
---

Some statistics do not return one value per group; they generate a batch of sampled rows. `density` reads one continuous field and emits `xAs` / `densityAs` fields from KDE. `smooth` reads `(x, y)` samples and emits predicted `xAs` / `yAs` fields from a regression model. Both produce ordinary rows, then `PathMark` draws curves or areas.

General reducers / selectors, `summarize`, `select`, and custom transform definitions are documented under [Data Transforms](/viz/data/transform).

## density

<ComponentPreview name="transform-density" sourceFiles={['transform-density.data.ts']} />

| prop                | type                                                            | default       | description                                  |
| ------------------- | --------------------------------------------------------------- | ------------- | -------------------------------------------- |
| `field`             | `string`                                                        | —             | One-dimensional continuous field to estimate |
| `groupBy`           | `Array<string>?`                                                | one global group | Estimate density per group                |
| `bandwidth`         | `{ kind: 'silverman' }`<br />`{ kind: 'value'; value: number }` | `silverman`   | KDE bandwidth; explicit values must be positive |
| `sampleCount`       | `number?`                                                       | `64`          | Number of sampled output rows per group; at least 2 |
| `extent`            | `[number, number]?`                                             | expanded observed range | Sampling interval                 |
| `xAs` / `densityAs` | `string`                                                        | —             | Output fields for sample position and density |

`density` outputs ordinary rows. Draw a density curve with `PathMark`; draw a density area with the same `PathMark` plus `closure={{ kind: 'baseline' }}` and `fill`. Do not add a dedicated mark just for density.

## smooth

`smooth` fits `(x, y)` samples from a scatterplot or time series into sampled trend-line rows. The first method is `{ kind: 'linear' }`; it does not extrapolate unless you provide `extent`. Output rows usually go to `PathMark` with `order`.

<ComponentPreview name="transform-smooth" sourceFiles={['transform-smooth.data.ts']} />

| prop          | type                  | default              | description                                  |
| ------------- | --------------------- | -------------------- | -------------------------------------------- |
| `x` / `y`     | `string`              | —                    | Regression input fields                      |
| `groupBy`     | `Array<string>?`      | one global group     | Fit a separate trend per group               |
| `method`      | `{ kind: 'linear' }?` | `linear`             | Smoothing method; first release supports linear regression only |
| `sampleCount` | `number?`             | `64`                 | Number of predicted samples per group; at least 2 |
| `extent`      | `[number, number]?`   | finite observed x range | Sampling interval; explicit values can extrapolate |
| `xAs` / `yAs` | `string`              | —                    | Output fields for predicted x and y values   |

`smooth` fails loudly for non-fit inputs: every group needs at least two finite `(x, y)` points, and x cannot be constant. Keep original points and the trend line as separate mark layers: points read source data, while the trend line reads rows generated by `smooth`.

## Relationship To Data Flow

`density` and `smooth` stay under Drawing Grammar because their main output is sampled fields consumed by plot curves / areas. They still run on data canonical rows and follow data-layer parsing, validation, and provenance rules.
