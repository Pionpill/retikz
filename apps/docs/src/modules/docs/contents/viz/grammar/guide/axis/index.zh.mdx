title: 坐标轴
description: 用 <Axis> 定制刻度、标签和网格；dimension 选择装饰哪个维度——cartesian 的 x / y 或 polar 的 x / y。
---

`<Axis>` 声明一条坐标轴。`dimension` 选它装饰哪个维度：cartesian 下是 `x`（水平）/ `y`（垂直），polar 下仍写 `x`（角向）/ `y`（径向），ternary 下是 `x` / `y` / `z`（三角三边）。维度须匹配当前坐标系，给错会报错（不静默画空轴）。轴线、刻度、刻度文字、轴标题和网格是同一个 Axis guide 的几个槽位。

`<Plot>` 是薄容器、自己不画轴——不写 `<Axis>` 就没有轴，你列出哪些 `<Axis>` 就画哪些。若只是想给某个轴换成对数、时间或平方根比例尺，也可以在同一个 `<Axis>` 上写 `scale`，不用再额外放一个 `<Scale>`。

## 例子

### 样式槽位

`line` 控制轴线；`ticks` 控制刻度来源、长度和刻度线样式；`tickLabels` 控制刻度文字是否显示和文字样式；`title` 是轴标题，支持字符串或结构化文本；`grid` 可以是布尔值，也可以带线条样式。

## API

| 属性         | 类型                                               | 默认值     | 描述                                                                                                             |
| ------------ | -------------------------------------------------- | ---------- | ---------------------------------------------------------------------------------------------------------------- |
| `dimension`  | `'x' \| 'y' \| 'z'`                                | —          | 装饰哪个维度：cartesian 的 x / y，polar 的 x / y，ternary 的 x / y / z（三角三边）；须匹配坐标系合法集、否则报错 |
| `scale`      | `'linear' \| 'time' \| 'point' \| 'log' \| 'sqrt' \| 'symlog' \| 'radial'` | 自动派生   | 位置 scale 快捷类型；等价于同维度的 `<Scale dimension="..." type="..." />`，仅适用于 x / y / z |
| `line`       | `false \| { stroke?, strokeWidth?, drawOpacity?, dashPattern? }` | 默认轴线 | 轴线样式；设为 `false` 只隐藏轴线，不影响刻度、标签和网格 |
| `ticks`      | `{ count?, values?, length?, line? }`              | 默认刻度   | 目标刻度数或显式刻度值；`line` 可设刻度线样式，`line: false` 隐藏刻度线 |
| `tickLabels` | `false \| { format?, gap?, font?, textColor?, opacity?, align?, lineHeight?, maxTextWidth?, rotate? }` | `true` | 刻度文字配置；设为 `false` 隐藏刻度文字；`format` 支持 d3-format / d3-time-format 风格字符串 |
| `title`      | `string \| { text, gap?, font?, textColor?, opacity?, align?, lineHeight?, maxTextWidth?, rotate? }` | — | 轴标题；`text` 复用 core 文本块能力，可写多行或带 run 的结构化文本 |
| `grid`       | `boolean \| { stroke?, strokeWidth?, drawOpacity?, dashPattern? }` | `false` | 是否画对齐本轴刻度的网格线（polar 的 y 轴即同心环），对象写法可覆盖网格线样式 |
| `id`         | `string?`                                          | —          | 可选句柄（预留，暂不解析）                                                                                       |
