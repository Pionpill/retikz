---
title: 坐标轴
description: 用 <Axis> 定制刻度、标签和网格；dimension 选择装饰哪个维度——cartesian 的 x / y 或 polar 的 x / y。
---

`<Axis>` 声明一条坐标轴。`dimension` 选它装饰哪个维度：cartesian 下是 `x`（水平）/ `y`（垂直），polar 下仍写 `x`（角向）/ `y`（径向），ternary 下是 `x` / `y` / `z`（三角三边）。维度须匹配当前坐标系，给错会报错（不静默画空轴）。轴线、刻度、刻度文字、轴标题和网格是同一个 Axis guide 的几个槽位。

`<Plot>` 是薄容器、自己不画轴——不写 `<Axis>` 就没有轴，你列出哪些 `<Axis>` 就画哪些。若只是想给某个轴换成对数、时间或平方根比例尺，也可以在同一个 `<Axis>` 上写 `scale`，不用再额外放一个 `<Scale>`。

## 例子

### 样式槽位

`line` 控制轴线；`ticks` 控制刻度来源、长度和刻度线样式；`tickLabels` 控制刻度文字是否显示和文字样式；`title` 是轴标题，支持字符串或结构化文本；`grid` 可以是布尔值，也可以带线条样式。`dashOffset` 与 `dashPattern` 配合时，可以调整虚线起点。

<ComponentPreview name="axis-style-slots" sourceFiles={['axis-style-slots.data.ts']} />

### 刻度密度

`ticks.count` 是给 scale 的目标数量提示，不保证最终数量。需要固定间隔时用 `ticks.interval`，需要从候选 tick 中抽稀时用 `ticks.density`；`ticks.mark` 可以把短线换成内置形状或自定义 core shape。

| 配置 | 主要形态 | 用途 |
| ---- | -------- | ---- |
| `interval` | `{ kind:'number', step, anchor? }` / `{ kind:'time', unit, step?, anchor? }` / `{ kind:'category', step, offset? }` | 生成固定间隔候选 tick |
| `density` | `{ kind:'all' }` / `{ kind:'sample', maxCount?, minGap?, preserveEnds? }` | 从候选 tick 中抽稀可见 tick |
| `mark` | `false` / `{ kind:'line', length?, line? }` / `{ kind:'circle' \| 'square' \| 'triangle' \| 'diamond', ... }` / `{ kind:'custom', shape, ... }` | 控制刻度标记外观 |

<ComponentPreview name="axis-tick-density" sourceFiles={['axis-tick-density.data.ts']} />

### 刻度文字避让

`tickLabels.layout` 只调整文字节点，不改变 tick、tick mark 或 grid 的来源。省略时会使用内置自适应策略；需要精确排版时，可以写 `layout: false` 关闭自动旋转、隐藏和边界处理。

| 配置 | 主要形态 | 用途 |
| ---- | -------- | ---- |
| `layout.rotate` | `false` / `{ angles?, recoverWhenFailed? }` | 自动选择刻度文字旋转角度；显式 `tickLabels.rotate` 优先 |
| `layout.hide` | `false` / `{ strategy:'greedy' \| 'parity', preserveEnds?, separation? }` | 隐藏重叠文字，保留 tick、tick mark 和 grid |
| `layout.bounds` | `false` / `{ overflow:'allow' \| 'hide' \| 'flush', tolerance? }` | 处理首尾文字超出轴范围的情况 |
| `layout.sampleSize` | `number` | 限制自动旋转估算时扫描的 label 数量 |

### 原点轴

cartesian 下可以让轴线穿过另一维的指定值。`placement.kind="origin"` 只改变轴线摆放，不会自动扩展 domain；需要原点可见时，请显式配置 `domain` 或 `domainPadding`。`crossing` 控制交叉值处的 tick 与 label，`line.arrow` 用 `positive` / `negative` 表达轴方向端点，`ticks.endpoint` 避让箭头附近的刻度标记，`title.placement` 控制标题沿可见轴线的位置。

| 配置 | 常用取值 | 作用 |
| ---- | -------- | ---- |
| `crossing.tick` | `'show' \| 'hide'` | 显示或隐藏交叉值处的 tick mark |
| `crossing.label` | `'show' \| 'hide' \| 'corner'` | 显示、隐藏或把交叉值 label 放到角落 |
| `crossing.corner` | `'top-left' \| 'top-right' \| 'bottom-left' \| 'bottom-right'` | `label:'corner'` 时的角落位置 |
| `ticks.endpoint` | `false \| { hideWhenArrow?, distance?, affect? }` | 控制箭头端点附近的 tick 避让；`false` 关闭默认避让，`affect:'mark-and-label'` 会同时隐藏 label |
| `title.placement` | `'at-start'` / `'near-start'` / `'midway'` / `'near-end'` / `'at-end'` / `0..1` | 沿轴线从负方向到正方向放置标题 |
| `title.orientation` | `'auto'` / `'horizontal'` / `'axis'` | 控制标题旋转；数学坐标系常用 `horizontal` 让 y 标题正向显示 |

## API

| 属性         | 类型                                               | 默认值     | 描述                                                                                                             |
| ------------ | -------------------------------------------------- | ---------- | ---------------------------------------------------------------------------------------------------------------- |
| `dimension`  | `'x' \| 'y' \| 'z'`                                | —          | 装饰哪个维度：cartesian 的 x / y，polar 的 x / y，ternary 的 x / y / z（三角三边）；须匹配坐标系合法集、否则报错 |
| `scale`      | `'linear' \| 'time' \| 'point' \| 'log' \| 'sqrt' \| 'symlog' \| 'radial'` | 自动派生   | 位置 scale 快捷类型；等价于同维度的 `<Scale dimension="..." type="..." />`，仅适用于 x / y / z |
| `placement`  | `{ kind:'auto' } \| { kind:'side', side, offset? } \| { kind:'edge', edge, offset? } \| { kind:'origin', origin?, tickSide?, offset? }` | 自动推断 | 坐标轴摆放；`origin` 仅支持 cartesian，x 轴的 `origin` 是 y 值，y 轴的 `origin` 是 x 值 |
| `line`       | `false \| { stroke?, strokeWidth?, drawOpacity?, dashPattern?, dashOffset?, lineCap?, extent?, arrow? }` | 默认轴线 | 轴线样式与端点几何；`extent` 控制数据范围，`arrow.positive/negative` 控制轴方向箭头；`extent` / `arrow` 目前仅支持 cartesian |
| `crossing`   | `false \| { value?, tick?, label?, corner? }` | 正常刻度 | 控制轴线交叉值处的 tick 与 label；`label:'corner'` 可把共用原点 label 放到角落 |
| `ticks`      | `{ count?, values?, interval?, density?, endpoint?, mark?, length?, line? }` | 默认刻度   | `values > interval > count` 生成候选 tick；`density` 抽稀可见 tick；`endpoint` 避让箭头附近的刻度标记且不改变 grid 来源；`mark` 控制短线 / 形状刻度 |
| `tickLabels` | `false \| { format?, gap?, font?, textColor?, opacity?, align?, lineHeight?, maxTextWidth?, rotate?, layout? }` | `true` | 刻度文字配置；`format` 支持 d3-format / d3-time-format；`rotate` 是固定旋转，优先于 `layout.rotate`；`layout:false` 关闭自动避让 |
| `title`      | `string \| { text, gap?, placement?, orientation?, font?, textColor?, opacity?, align?, lineHeight?, maxTextWidth?, rotate? }` | — | 轴标题；`placement` 支持 path label 同类关键字或 `0..1` 比例，`orientation` 控制标题旋转，显式 `rotate` 优先 |
| `grid`       | `boolean \| { stroke?, strokeWidth?, drawOpacity?, dashPattern?, dashOffset? }` | `false` | 是否画对齐本轴刻度的网格线（polar 的 y 轴即同心环），对象写法可覆盖网格线样式 |
| `id`         | `string?`                                          | —          | 可选句柄（预留，暂不解析）                                                                                       |
