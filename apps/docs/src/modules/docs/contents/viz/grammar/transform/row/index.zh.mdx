---
title: 派生与抖动
description: 派生与抖动保持输入行数不变，只按单行字段补出区间或在数据空间生成确定性偏移。
---

这一组是 plot 注册的保行绘图变换。它们不会做分组统计，也不会挑代表行；如果后续 mark 需要的是更统一的区间字段，或确定性的点位偏移，就放在这一组。

数据行排序是共享数据能力，见[共享变换 / sort](/viz/data/transform#排序-sort)。

| kind              | 行数  | 常见用途                            |
| ----------------- | ----- | ----------------------------------- |
| `derive-interval` | N → N | 把单行数值整理成 `[start,end]` 区间 |
| `jitter`          | N → N | 在数据空间抖开重叠散点              |

## 派生区间 derive-interval

`derive-interval` 给每一行独立算出一个区间。它不看其它行，适合甘特条、显式区间、非零基线柱。

<ComponentPreview name="transform-derive-interval" sourceFiles={['transform-derive-interval.data.ts']} />

它和 `stack` 都默认产出 `y0` / `y1`，但语义不同：`derive-interval` 是单行派生，`stack` 是跨行累积。

| prop                      | 类型      | 默认值      | 说明                           |
| ------------------------- | --------- | ----------- | ------------------------------ |
| `from`                    | `string?` | —           | baseline 到 value 模式的值字段 |
| `baseline`                | `number?` | `0`         | `from` 模式的起点              |
| `startFrom` / `endFrom`   | `string?` | —           | 两字段区间模式，必须成对出现   |
| `startField` / `endField` | `string?` | `y0` / `y1` | 输出字段名                     |

## 抖动 jitter

`jitter` 给连续数值位置字段加一个伪随机偏移，把重叠散点抖开。偏移发生在数据空间、进入比例尺之前；`seed` 是整数，确保 SSR 和浏览器 hydration 得到一致结果。

<ComponentPreview name="transform-jitter" sourceFiles={['transform-jitter.data.ts']} />

当前 `jitter` 只作用于连续数值字段。分类 band 内部的屏幕空间抖动不属于这层 transform。

| prop                | 类型                    | 默认值    | 说明                         |
| ------------------- | ----------------------- | --------- | ---------------------------- |
| `axis`              | `'x' \| 'y' \| 'both'?` | `'x'`     | 抖动作用轴                   |
| `xField` / `yField` | `string?`               | `x` / `y` | 被抖动的连续数值字段         |
| `amount`            | `number?`               | `1`       | 最大绝对偏移，单位是数据单位 |
| `seed`              | `number?`               | `0`       | 确定性 PRNG 种子             |
