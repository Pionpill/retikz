title: ReferenceMark
description: ReferenceMark 表达参考约束：常量或字段值可以展开成线、单轴带或坐标区域。
---

`<ReferenceMark>` 在数据空间声明参考约束。默认绑 `y` 得到水平参考，绑 `x` 得到竖直参考；只给下界是线，配 `xTo` / `yTo` 是单轴带。设 `kind="region"` 时，ReferenceMark 会按当前坐标系消费的 role 构造区域：笛卡尔 / 极坐标使用 `x` / `xTo` 与 `y` / `yTo`，三元坐标再加 `z` / `zTo`。`number` 表示常量，`FieldName` 表示字段名或字段路径，并按每行数据生成一条参考。

它和 `<PointMark>` / `<IntervalMark>` 一样参与同一坐标系内的叠放顺序，但不从点、线、面维度出发，而是先确定一个固定轴值，再沿对侧轴域展开。

## 用法

```tsx
import { Plot, ReferenceMark } from '@retikz/plot-react';
```

```tsx
<Plot data={scores}>
  <ReferenceMark y={60} color="crimson" />
  <ReferenceMark y={60} yTo={80} color="#fde68a" />
</Plot>
```

默认 line / band 写法里 `x` 和 `y` 必须二选一。`xTo` 只能和 `x` 配对，`yTo` 只能和 `y` 配对；对侧部分长度则用 `extentField` / `extentToField` 成对声明。区域写法要显式设 `kind="region"`，并给齐当前坐标系 role 对应的下界 / 上界；例如 `ternary2D` 需要同时给 `x` / `xTo`、`y` / `yTo`、`z` / `zTo`。

## 表现层

ReferenceMark 是底层参考 mark：它负责把一个固定轴值解释成 line，把单轴区间解释成 band，或把双轴区间解释成 region。表现层看到的“阈值线”“容差带”“参考环”“扇形楔”“框选区域”不是不同 mark，而是同一个 ReferenceMark 在不同坐标系和边界配置下的显示形态。

取向由绑定的轴决定，形态由是否给上界决定：

| 表现形态     | 关键属性                                                  | 说明                                      |
| ------------ | --------------------------------------------------------- | ----------------------------------------- |
| 水平参考线   | `y`                                                       | 固定 y 值，跨满 x 域                      |
| 竖直参考线   | `x`                                                       | 固定 x 值，跨满 y 域                      |
| 水平参考带   | `y` / `yTo`                                               | 固定 y 区间，填充 `y∈[y,yTo]`             |
| 竖直参考带   | `x` / `xTo`                                               | 固定 x 区间，填充 `x∈[x,xTo]`             |
| 二维参考区域 | `kind="region"` + `x` / `xTo` / `y` / `yTo`               | 同时固定 x 与 y 区间，填充二者交集        |
| 三元参考区域 | `kind="region"` + `x` / `xTo` / `y` / `yTo` / `z` / `zTo` | 同时固定三个分量区间，并裁剪到 simplex 内 |

在 `polar2D` 下，同一组属性会被坐标系重解释：`y` 是常半径参考环，`y` / `yTo` 是环带；`x` 是径向参考线，`x` / `xTo` 是扇形楔；`kind="region"` 同时限制角度和半径，得到一个环扇区。在 `ternary2D` 下，`kind="region"` 使用 `x/y/z` 三个分量区间，并通过三元坐标的 `projectCell` 裁剪成 contour。

## 技术原理

`ReferenceMark` 是一个内置注册图元。React 里的 `<ReferenceMark>` 本身不渲染 DOM；`<Plot>` 会把扁平 props 装配成 `type: 'reference'` 的 mark IR，把 `x` / `y` / `z` 放进 `encoding`，并把 `kind` / `xTo` / `yTo` / `zTo` / `extentField` / `extentToField` 保留在 mark 顶层。

编译时，`lowerMark` 按 `mark.type` 查询 `MARK_REGISTRY`，`ReferenceMark` 命中 `PlotMark.Reference` 对应的 `lowerReferenceLayer`。默认 line / band 只接受 cartesian2D / polar2D；`kind="region"` 走 cell 路径，接受所有带 `projectCell` 的坐标帧。line 下沉成 core `Path`，band / region 先构造坐标系无关的 `Cell`，再通过 `frame.projectCell(...)` 下沉成 core `Node` 几何。`label` 会按实际形态推断宿主：line 使用 geometry label 字段，band / region 使用 node label 字段，用户不需要写 `kind`。

注册部分只需要看 `ReferenceMark` 对应的注册行，以及真正执行下沉的 `lowerReferenceLayer` / `lowerReference`：

```ts
[PlotMark.Reference]: { type: PlotMark.Reference, lower: lowerReferenceLayer },

const lowerReferenceLayer = (mark: Mark, rows: Array<ExternalRow>, frame: CoordinateFrame, channels: MarkChannels, markProvenance: MarkProvenance | undefined): IRChild | null => {
  if (mark.type !== PlotMark.Reference) return null;
  const shape = referenceShape(mark);
  if (shape.kind === 'region') {
    if (!hasProjectCell(frame)) throw new Error(failLoudMessage(mark.type, frame.type));
  } else if (frame.type !== PlotCoordinate.Cartesian2D && frame.type !== PlotCoordinate.Polar2D) {
    throw new Error(failLoudMessage(mark.type, frame.type));
  }
  const layer = lowerReference(mark, rows, frame, channels.colorOf, channels.defaultColor, markProvenance);
  return layer === null ? null : attachMarkLayer(layer, mark, markProvenance);
};

const lowerReference = (mark: ReferenceMark, rows: Array<ExternalRow>, frame: CoordinateFrame, colorOf: ColorOf | undefined, defaultColor: string | undefined, markProvenance: MarkProvenance | undefined): IRScope | null => {
  const shape = referenceShape(mark);
  const effectiveRows = referenceRows(mark, rows, shape, frame);

  if (shape.kind === 'region' || shape.band) {
    for (const row of effectiveRows) {
      const cell = referenceCell(mark, row, frame);
      if (!cell) continue;
      const geometry = frame.projectCell(cell);
      // band / region: cell geometry -> core Node layer
    }
    return cellLayer;
  }

  for (const row of effectiveRows) {
    const steps = referenceLineSteps(mark, row, frame, shape.orientation);
    if (!steps) continue;
    // line: reference steps -> core Path layer
  }
  return lineLayer;
};
```

这段逻辑可以拆成四步：

| 步骤      | 说明                                                                                                                     |
| --------- | ------------------------------------------------------------------------------------------------------------------------ |
| 取向校验  | 默认 line / band 要求 `encoding.x` / `encoding.y` 恰好存在一个；`kind="region"` 要求当前坐标系消费的 role 都有下界和上界 |
| 形态判断  | 默认写法按上界判断 line / band；region 直接进入 cell 路径                                                                |
| 行迭代    | 完全常量参考只生成一条；字段轴值、字段上界或 extent 字段按数据行生成                                                     |
| core 下沉 | line 生成 core `Path`；band / region 通过坐标系 `projectCell` 生成可填充几何 Node                                        |

## API

`ReferenceMark` 的 API 同时覆盖 line、band 和 region，并按位置、专属、路径、节点、标签、通用和自定义分组：位置字段绑定参考轴，专属字段描述参考范围，路径字段服务参考线，节点字段服务参考带 / 区域。表里的 `FieldName` 表示字段名或字段路径，例如 `threshold` / `limits.lo`；`number` 表示直接写入的常量轴值。`label` 不写 `kind`，由 line / band / region 形态决定使用 core geometry label 还是 node label。

| 分类          | 属性                                           | 类型                                                                                                                      | 默认值             | 描述                                                                                                          |
| ------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | ------------------ | ------------------------------------------------------------------------------------------------------------- |
| 位置          | `x`                                            | `number`<br />`FieldName?`                                                                                                | —                  | 竖直参考的常量轴；数字为常量，字段为 per-datum 参考                                                           |
|               | `y`                                            | `number`<br />`FieldName?`                                                                                                | —                  | 水平参考的常量轴；数字为常量，字段为 per-datum 参考                                                           |
|               | `z`                                            | `number`<br />`FieldName?`                                                                                                | —                  | z role 的区域下界；仅 `kind="region"` 且坐标系消费 z 时使用                                                   |
| 专属          | `kind`                                         | `'region'?`                                                                                                               | —                  | 设为 `region` 时按当前坐标系 role 构造区域；省略时推断 line / band                                            |
|               | `color`                                        | `string?`                                                                                                                 | 默认图层色         | 常量参考时是颜色字符串；per-datum 参考时是颜色字段名                                                          |
|               | `xTo`                                          | `number`<br />`FieldName?`                                                                                                | —                  | x 方向上界；默认与 `x` 配对生成竖直 band，region 中作为区域右边界                                             |
