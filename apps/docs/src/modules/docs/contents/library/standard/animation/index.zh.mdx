Standard 提供可选的动画效果，复用 [Kernel 动画](/kernel/visual/animation)的轨道与播放机制。它们都是纯函数：输入参数，返回关键帧数据，不创建播放器，也不需要注册。

## 接入方式

在已有 Retikz 项目中安装 `@retikz/standard`，从包根导入效果工厂。React、Vanilla 与直接 IR 使用同一个工厂，将结果放入目标的 animations 数组；不需要为了动画引入 Standard 的 React 或 Vanilla adapter。

```ts
import { fadeIn, loop } from '@retikz/core';
import { pulse, wiggle } from '@retikz/standard';

const entrance = fadeIn();
const emphasis = pulse({ peak: 1.15 });
const repeatedWiggle = loop(wiggle({ angle: 8 }), { iterations: 2 });
```

## 选择动画效果

| 效果   | 属性变化                              | 默认行为                   |
| ------ | ------------------------------------- | -------------------------- |
| grow   | scale 0 → 1                           | 400ms，缩放入场            |
| growUp | scaleY 0 → 1                          | 500ms，从底部支点长出      |
| pulse  | scale 1 → peak → 1                    | 1000ms，peak=1.1，无限循环 |
| spin   | rotate 0 → 360                        | 1000ms，匀速无限循环       |
| flash  | opacity 1 → dim → 1                   | 300ms，dim=0，默认 2 次    |
| blink  | opacity 1 → dim → 1                   | 800ms，dim=0，默认无限循环 |
| wiggle | rotate 0 → angle → −angle → angle → 0 | 400ms，angle=5°，默认 3 次 |

下面各图元使用默认效果。生长与有限次数动画结束后可点击重播；旋转使用矩形，便于看清朝向变化。

<ComponentPreview files="animation-presets" size="lg" controls={{ animation: true }} />

grow 等价于 `scaleIn({ from: 0 })`，但作为便捷效果从 Standard 导入。pulse、spin 的无限循环可用 Core 的 loop 包装为有限次数；stagger 可让多个效果错峰开始。

## 参数与播放保持同一契约

所有效果接受 duration、delay、easing、trigger；grow、growUp、pulse、spin、wiggle 还支持 origin。flash / blink 提供 dim 与 iterations，wiggle 提供 angle 与 iterations，pulse 提供 peak。专属参数详见 [API 参考](/library/standard/animation/api-reference)。

工厂不会读取目标的当前样式，也不会改变布局或连接关系。Node、Path 与 Scope 的动画目标范围见[组件对接](/kernel/visual/animation/integration)。触发、截帧与减少动态效果策略继续遵循[扩展用法](/kernel/visual/animation/extended-usage)。

导出的轨道只包含普通 JSON 数据，不保存预设名称。保存后的 IR 可以直接播放，无需在播放端再次导入 Standard。原先从 Core 导入这些效果的代码需改为从 Standard 导入；旧入口不再转导出。
