---

`Surface` 是 Standard 的单盒呈现容器。它测量一个 Core 或已注册 Tier 2 child，在外侧加入 padding、可选背景与边框，并把完整结果保持为 renderer-neutral Scene。Chart、Table 与其它领域能力可以复用它，不需要各自在 adapter 或 renderer 中重写画布外壳。

## 用法

```tsx
import { Layout, Node } from '@retikz/react';
import { Surface } from '@retikz/standard-react';
```

```tsx
<Layout width={320} height={180}>
  <Surface padding={16} background={{ fill: '#f8fafc' }} border={{ stroke: '#64748b' }}>
    <Node position={[0, 0]} text="Content" />
  </Surface>
</Layout>
```

| 场景        | 公开入口                                                                                       |
| ----------- | ---------------------------------------------------------------------------------------------- |
| React       | `Surface`（`@retikz/standard-react`）                                                          |
| Vanilla     | `surface`、`surfaceChild`、`SurfaceInputEmbedAdapter`（`@retikz/standard-vanilla`）            |
| IR / 持久化 | `SurfaceSchema`、`IRSurfaceSchema`、`createSurface`、`SurfaceDefinition`（`@retikz/standard`） |

## 示例

### 基础表面

`Surface` 只要求一个可转换为 IR 的直接 child；child 本身可以是容纳多个图元的 Core `Scope`。padding 参与布局，背景、内容与边框按固定层次绘制。

### Overflow 与圆角裁剪

`overflow="visible"` 保留 child 的视觉溢出；`overflow="clip"` 只裁剪内容层，不裁剪背景或边框。圆角同时作用于边界 Path 和内容 clip，半径会限制到短边的一半。

## 技术原理

`SurfaceDefinition` 先根据 parent proposal 和 padding 探测唯一 child，再回放 child 并输出背景 Path、内容 Scope 和边框 Path。`overflow="clip"` 的 clip 只挂在内容 Scope；Surface 自身的 Core `clip` 仍作用于完整外层。

```text
standard.surface → SurfaceDefinition → Core Scope(Path + child replay + Path)
```

未注入 `SurfaceDefinition` 的手写 `standard.surface` 会得到 `COMPOSITE_NOT_REGISTERED` 诊断。React 与 Vanilla adapter 都贡献 `SurfaceProvider`；嵌套 Tier 2 child 的 provider 依赖按 authored order 一并进入 Core resolver。

Surface 还在 authored 外层 Scope 发布 key 为 `surface` 的 qualified spatial handle。handle 继承最终 placement 与 transform；child 自己的 handle 保持原 key、role、tags 与 payload，只增加真实 owner path。

## API 参考

### SurfaceSchema

| 属性            | 类型                              | 默认值    | 描述                                                  |
| --------------- | --------------------------------- | --------- | ----------------------------------------------------- |
| `child`         | `IRChild`                         | —         | 唯一 Core 或已注册 Tier 2 child                       |
| `padding?`      | `number \| IRBoxSpacing`          | `0`       | 非负内边距；规范化为 top/right/bottom/left            |
| `overflow?`     | `'visible' \| 'clip'`             | `visible` | child 视觉溢出策略                                    |
| `background?`   | `{ fill; fillOpacity? }`          | —         | 覆盖完整 allocation box 的背景                        |
| `border?`       | `IRStandardPathStrokeStyle`       | —         | 沿 allocation boundary 绘制的边框                     |
| `cornerRadius?` | `number`                          | `0`       | 非负圆角半径，最大有效值为短边一半                    |
| Scope props     | `Omit<IRScope, 'type\|children'>` | —         | 作用于包含背景、内容和边框的 authored 外层 Core Scope |

`IRSurfaceSchema` 校验已经规范化的持久化结果：四侧 padding、`overflow` 与 `cornerRadius` 都是必填 canonical 字段。有限 range 或 exact proposal 小于对应轴 padding 时，Surface 在探测 child 前同步失败，不会回退到 intrinsic。

### React 与 Vanilla

React `SurfaceProps` 用 `children` 代替 IR 的 `child`，并要求最终恰好一个 IR child。Vanilla 使用 `surfaceChild(node)` 标记唯一的嵌套 child；嵌套 Tier 2 的 provider contribution 由同一次归一化自动收集，不进入 IR 或 Scene。
