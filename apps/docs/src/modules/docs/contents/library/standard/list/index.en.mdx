`List` draws one-dimensional content as equal-sized cells by default, with horizontal or vertical ordering and optional indices. Each cell accepts one Node, Scope, or registered composite.

## Using this component

After [installation](/library/standard/get-start), choose one of the four entry points. JSX and Vanilla adapters collect required definitions; direct IR supplies the component definition explicitly. Cell clipping additionally requires `PathClipDefinition` from `@retikz/extension`.

## Data and composition

A string item supplies both cell `content` and `id`: `'A'` is equivalent to `{ content: 'A', id: 'A' }`. Strings must be nonblank and ids must be unique. Use objects for blank or repeated text and custom styles. Objects without an id do not derive one from content.

An object item has a string `content` and optional `id`, `style`, and `layout`. Use ListItem for complex content. Choose one of `data`, `items` or `children`; data arrays do not contain JSX.

Each cell accepts either `text` or exactly one drawable child. IR preserves strings; Standard expands them during compilation into text nodes with zero padding and margin, no background, and no stroke; cell font and text color still apply. Wrap multiple drawables in a Scope.

## Display JSON data directly

`data` accepts a JSON array, mutually exclusive with `items` and React `children`. Objects render recursively as Map and arrays as List, without handwritten nested components.

<ComponentPreview files="list-data" />

Object keys display their original text without added quotes. String values use quoted, escaped JSON literals, distinguishing `"null"` from `null`. Numbers, booleans and null remain visible. Nested empty containers display `{}` or `[]`; empty root structures retain zero natural size. Objects follow own enumerable string-key order, with integer-index keys first. Use entries for custom order or repeated display keys.

Data never infers cell ids, so repeated values and empty strings are valid. Fields such as `id`, `style` and `type` are ordinary data. Use explicit cells for references and per-cell styling, optionally nesting a component with data inside them.

Style and layout affect only the current cells; nested structures use their own defaults while fonts and text colors inherit through content. Fixed dimensions clip the whole nested drawing without resizing each descendant cell. Pass JSON value trees, excluding instances, cycles and functions; project data before rendering when only selected fields matter.

React and Vanilla assemble nested dependencies automatically. Direct IR with data requires `ListDefinition`, `MapDefinition` and `PathClipDefinition`. Vanilla and persisted Source IR retain the same data property.

## Style the structure and individual cells

Root `style` supplies common cell styling. A cell's own `style` overrides only that cell. Use `layout.gap` for spacing and `layout.padding` for common padding; each cell may override width, height, padding and overflow.

Precedence is **structural defaults → overall style → cell style**. Font fields merge independently. `fillOpacity` affects only backgrounds; text remains opaque. Use `fill: 'none'` or `stroke: 'none'` to disable painting. Explicit zero values remain effective.

## Ordering and dimensions

`layout.direction` defaults to `row`; use `column` for vertical ordering, without wrapping. `layout.width` / `height` set default fixed border-box dimensions including padding; zero is valid. Omitted axes or `'auto'` use automatic sizing. Cell dimensions override the shared defaults independently; explicit `'auto'` clears an inherited fixed dimension. Automatic axes use the maximum effective cell requirement; fixed axes keep their specified dimensions and align to the track start.

`showIndex` puts indices above rows or left of columns; `indexStart` sets the first label, not identity.

Content is centered inside the padding. Extra parent space remains at the end, without stretching cells. Empty arrays have zero natural size. Fixed cells retain their dimensions and clip oversized content by default, including when padding exceeds the available size. Text is not scaled or automatically wrapped to fit. An insufficient parent allocation for the whole structure still fails.

## Reference individual cells

Assign a cell `id` to target its boundary from `Draw`, such as `'selected.right'`. The target is the allocated rectangle, excluding gaps, indices, and visual overflow. Disabling the background does not change it. A content id continues to identify the content geometry.

Transforms and `localNamespace` follow [Scope](/kernel/components/scope/usage). Cell ids must be unique within a component. Unnamed cells do not acquire index-based identities. Inspection separately exposes `container` and `cell:<id>` spatial handles; these do not replace named references.

## Additional notes

Defaults are gap 2, padding 8, and no stroke or corner radius. Automatic cells default to visible overflow; fixing either axis defaults to clip unless explicitly overridden. List cells and Map values use gray / 0.14; Map keys use gray / 0.4. When fixing dimensions or setting `layout.overflow: 'clip'`, direct IR must also supply `PathClipDefinition` from `@retikz/extension` through `clips`.

Direct IR content also accepts a string or one drawable child. Nested composites need their definitions, or their Vanilla adapters. JSON contains neither callbacks nor JSX. Root `style` is specific to cell visuals; other Scope props apply to the root container. General matrices, merged cells, and data processing belong to table capabilities.

## Container labels

`label` attaches text to the whole container. It accepts one object or an array and shares the defaults, positioning, distance, rotation, and leader-line rules of [Node labels](/kernel/components/node/labels). The data example above omits label styling and uses the Core defaults.

```tsx
<List data={['a', 'b']} label={{ text: 'values', position: 'top' }} />
```

Labels attach to the container allocation rectangle without enlarging cells or allocation, but contribute to the final drawing bounds. Empty containers can also display labels. List includes its index strip in the attachment rectangle. Container transforms and root clipping apply to labels; cell clipping does not.

Shared `style.font`, `style.textColor`, `style.color`, and `style.opacity` supply the label host appearance. `defaults.label` and explicit label styles follow Node rules. Role and cell styles do not affect container labels, and `defaults.node` does not apply to the label host. Nested containers generated from `data` do not inherit the root label.
