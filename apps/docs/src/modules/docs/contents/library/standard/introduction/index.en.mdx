Standard is Retikz's standard component library. When you already know you need a list, reference axes, or a border around content, describe that object's parameters without calculating every path, text position, or outer dimension.

Use it for mathematical and algorithmic illustrations, structural diagrams, and general drawing interfaces. React and Vanilla share the same component semantics. Corresponding JSON IR lets you persist or transmit the drawing intent.

## Start with the content

This List expresses order through cells, with a Map inside one cell to represent a record. You specify which content belongs in each cell; the components handle their own arrangement and boundaries.

<ComponentPreview files="/library/standard/container/list/list-composition" size="sm" />

You do not need to position each cell manually. Similarly, Frame updates a group border around Nodes, while Surface adds padding, appearance, and clipping around one child drawing. Shape components draw an outline directly when its center, radii, or angles are known.

## Choose the right capability

| Task                                                      | Choose                | Why                                                          |
| --------------------------------------------------------- | --------------------- | ------------------------------------------------------------ |
| Draw an independent outline from geometry                 | Standard shapes       | Preserve rectangle, circle, star, and other geometric intent |
| Display sequential or keyed content                       | Standard List / Map   | Cells own content, identity, and nesting                     |
| Add axes, a background, grouping, or a symbol explanation | Standard presentation | Add presentation information around an existing drawing      |
| Arrange arbitrary child drawings                          | Layout                | Organize content using sizing and arrangement policies       |
| Map values from data domains and generate data ticks      | Plot                  | Own data and scale semantics                                 |
| Define arbitrary paths or node connections                | Kernel Node / Path    | Control drawing primitives directly                          |

Standard does not infer domain meaning. You supply Axes tick labels and Legend samples; List and Map visualize structures rather than implementing runtime collections. For data visualization, let a domain package process data before reusing these generic components.

## Choose a host syntax

React components come from family subpaths of `@retikz/standard-react`, Vanilla functions from `@retikz/standard-vanilla`, and JSON contracts and Definitions from `@retikz/standard`. All three expose `/shape`, `/container`, and `/presentation`. Each component page provides four equivalent forms in its integration section.

Start with the quick start for first use. Read basic usage and limitations for everyday configuration, or jump to API and Schema references for parameters. Save implementation details for diagnosis.
