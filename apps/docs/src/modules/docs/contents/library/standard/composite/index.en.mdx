---
title: Presentation
description: Standard provides optional, dynamically loaded Tier 2 capabilities that extend Core horizontally.
---

Standard does not add default primitives or renderer semantics to Core. Each component owns JSON-safe high-level IR and lowers through a loaded composite definition into Core primitives.
