---
title: Presentation
description: Standard provides general Tier 2 presentation composites assembled through rooted providers and lowered uniformly into Core primitives.
---

Standard adds no default primitives or renderer semantics to Core. Grid, Axes, Frame, Surface, and Legend each own JSON-safe high-level IR, one exact-key provider, and one Definition. React and Vanilla adapters only root the authored capability; Core resolves its reachable dependencies.

Direct-IR hosts may still pass a complete Definition array through `CompileOptions.composites`. Cross-owner composition uses the provider graph instead of guessing packages or definitions from child IR.

## Responsibilities

| Topic   | Responsibility                                                            | Reach for it when                                              |
| ------- | ------------------------------------------------------------------------- | -------------------------------------------------------------- |
| Grid    | Produces regular Cartesian grids, major lines, and borders                | A figure needs background references or regular points         |
| Axes    | Combines axis lines, arrows, ticks, labels, and optional grid             | A domain-neutral two-dimensional reference plane is needed     |
| Frame   | Measures direct Node content and places a title and description around it | A measurable border should organize drawing nodes              |
| Surface | Adds padding, appearance, and overflow to one arbitrary child             | Chart, Table, or a custom composite needs a reusable box shell |
| Legend  | Arranges resolved discrete samples, continuous variation, and meaning     | Plot, Table, or another domain has resolved scales and labels  |
