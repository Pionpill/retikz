`MapSchema` describes persistent input with `namespace: 'standard'` and `type: 'map'`. Choose entries, data, or skeleton. Factories preserve sparse input; explicit `schema.parse` materializes declared static defaults. Cell inheritance and the dynamic clipping default are resolved after settings merge.
