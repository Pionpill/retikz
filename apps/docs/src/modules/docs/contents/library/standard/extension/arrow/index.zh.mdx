箭头扩展在 Core 提供的基础箭头之上，补充了更多可选内容：

| 包名             | 提供内容                                                                                                                                     |
| ---------------- | -------------------------------------------------------------------------------------------------------------------------------------------- |
| `core`           | `normal` — 实心三角、`open` — 空心三角、`stealth` — 实心 Stealth、`openStealth` — 空心 Stealth、`circle` — 实心圆点、`openCircle` — 空心圆点 |
| `standard/arrow` | `diamond` — 实心菱形、`openDiamond` — 空心菱形                                                                                               |

## 用法

本页支持两种导入方式：

- 按需导入特定 Definition，例如 `DiamondArrowDefinition`，只把当前图需要的官方扩展传入 `Layout` 或 `compile`
- 整体使用官方扩展，例如 `StandardArrowDefinitions`，一次包含本子入口提供的全部 Standard Definition；组装 provider graph 时，对应使用 `StandardArrowProviders`

两种方式都只是当前图的显式装配，不会因为 import 自动全局注册箭头。

### React 用法

从 `@retikz/standard/arrow` 导入图中实际使用的 Standard Definition，传给 React `Layout` 的 `arrows` 属性。Core 箭头无需额外注入；导入子入口不会全局注册 Standard 箭头，Definition 只对当前图生效。

```tsx
import { Draw, Layout } from '@retikz/react';
import { DiamondArrowDefinition, OpenDiamondArrowDefinition } from '@retikz/standard/arrow';

<Layout arrows={[DiamondArrowDefinition, OpenDiamondArrowDefinition]}>
  <Draw
    way={[
      [0, 0],
      [160, 0],
    ]}
    arrow="->"
    arrowDetail={{ end: { shape: 'openDiamond' } }}
  />
</Layout>;
```

### Vanilla 用法

在 `@retikz/vanilla` 中，把同一个 Definition 放进 `compile.arrows`。`input` 可以是已有的 Core IR 或 Vanilla plain spec；`mount` 使用完全相同的 `compile` 配置。

```ts
import { renderToSvgString } from '@retikz/vanilla';
import { DiamondArrowDefinition, OpenDiamondArrowDefinition } from '@retikz/standard/arrow';

const svg = renderToSvgString(input, {
  compile: {
    arrows: [DiamondArrowDefinition, OpenDiamondArrowDefinition],
  },
});
```

路径 IR 只保存箭头名称和 JSON-safe 配置。若名称没有对应的内置或本次注入的 Definition，Core 会在 lookup 时明确报错并列出可用项，不会替换成默认箭头。
