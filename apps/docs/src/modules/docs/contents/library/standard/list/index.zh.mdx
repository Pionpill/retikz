`List` 把数组、队列等一维内容默认画成等大槽位，支持横排、竖排与显示索引。每格可以放一个 Node、Scope 或已注册的复合组件。

## 接入方式

[安装与首次渲染](/library/standard/get-start)后，可从以下四种入口接入。JSX 与 Vanilla adapter 自动收集所需定义；直接 IR 显式注入组件定义；启用单元格裁切时还需从 `@retikz/extension` 注入 `PathClipDefinition`。

## 数据配置与组件组合

`items` 中的字符串同时作为单元格的 `content` 和 `id`，例如 `'A'` 等价于 `{ content: 'A', id: 'A' }`。字符串必须非空白且 id 不能重复；空白文本、重复文字或单独设置样式时使用对象形式。对象省略 id 时不自动从 content 生成。

对象形式的单元格 `content` 是字符串，`id`、`style`、`layout` 均可选。复杂内容使用 `ListItem`；`data`、`items` 与 `children` 三选一，数据数组中不嵌 JSX。

单格用 `text` 写文字，或用 `children` 放恰好一个 drawable，二者互斥。字符串保留在 IR 中，由 Standard 在编译时转为零内边距、无背景、无描边的文本节点，仍继承单格字体与文字颜色。多个图元先用 Scope 组合。

## 直接展示 JSON 数据

`data` 接受 JSON 数组，与 `items`、React `children` 三选一。对象递归画成 Map，数组递归画成 List；无需手写嵌套组件。

<ComponentPreview files="list-data" />

对象键直接显示原始文本，不额外添加引号。字符串值显示为带引号、转义的 JSON 字面量，因此 `"null"` 与 `null` 不会混淆。数字、布尔值、null 原样显示；嵌套空对象和数组显示为 `{}`、`[]`，空根结构保持零自然尺寸。对象按自有可枚举字符串键的顺序展示，整数索引键优先；需要自定顺序或重复键时使用 entries。

数据不会生成单元格 id，重复值和空字符串均可使用；`id`、`style`、`type` 等对象字段也只是数据。要连线或逐格设置样式，使用显式单元格，并在其中嵌套带 data 的组件。

整体 style / layout 只控制当前层单元格，嵌套结构使用自身默认；字体与文字颜色沿内容继承。固定宽高裁切整个嵌套图，不会把每个后代格改成同样尺寸。只传入 JSON 值树，不传运行时实例、循环引用或函数；需要简化展示时先投影数据。

React / Vanilla 自动装配嵌套依赖；直接 IR 的 data 入口需注入 `ListDefinition`、`MapDefinition` 以及 `PathClipDefinition`。Vanilla 保留同名 data 属性，Source IR 也保留原数据。

## 整体与单元格样式

`style` 设置所有格的共同样式；单元格自己的 `style` 只覆盖当前格。`layout.gap` 设置间隙，`layout.padding` 设置每格内边距；单格可通过自己的 `layout.width`、`height`、`padding` 和 `overflow` 覆盖整体值。

覆盖顺序是 **结构默认 → 整体 style → 单格 style**。字体按字段合并；`fillOpacity` 只降低背景透明度，文字保持原透明度。`fill: 'none'` 关闭背景，`stroke: 'none'` 关闭边框，零值保持生效。

## 排列与尺寸

`layout.direction` 默认为 `row`，改为 `column` 即竖排；不自动换行。`layout.width` / `height` 为所有格设置固定边框尺寸（含 padding），数字可以为零；省略或 `'auto'` 时自适应。单格同名字段覆盖整体，显式 `'auto'` 可解除继承的固定尺寸。自适应轴取各格有效需求的最大值，固定轴保持指定值，较小的格从行列起点对齐。

`showIndex` 在横排上方或竖排左侧显示索引，`indexStart` 设置起点；索引不是身份。

内容在内边距区域居中。父容器提供额外空间时，槽位仍从起点排列，剩余空间留在末端。空数组自然尺寸为零。固定单格尺寸小于内容或内边距时仍保留尺寸，默认裁切超出内容，不缩放文字或为了适配槽位自动折行；父容器无法容纳整组槽位与间隙时仍会报错。

## 引用具体单元格

给单元格设置 `id` 后，可以用 `Draw` 的 `way` 引用，例如 `'selected.right'`。引用区域是该格分配到的矩形，不包含间隙、索引或内容的视觉溢出；关闭背景也不改变它。content 自己的 id 仍指向内容几何。

整体变换与 `localNamespace` 沿 [Scope](/kernel/components/scope/usage) 规则生效。组件内单元格 id 不能重复；未设置 id 的格不会按数组下标生成稳定身份。Inspection 另行提供 `container` 与 `cell:<id>` 空间 handle，不替代命名引用。

## 补充说明

默认 gap 为 2、padding 为 8，无描边、无圆角，自适应单元格的 `overflow` 默认为 `visible`，固定任一轴时默认为 `clip`，可显式覆盖。List 与 Map value 背景为 gray / 0.14，Map key 为 gray / 0.4。使用固定尺寸或 `layout.overflow: 'clip'` 时，直接 IR 还需在 `clips` 中注入 `@retikz/extension` 的 `PathClipDefinition`。

直接 IR 的 content 同样支持字符串或一个可绘制 child。嵌套组件需要自己的 Definition；Vanilla 使用相应 adapter，JSON 不保存函数或 JSX。整体 `style` 专用于单元格视觉，其他 Scope 属性仍由根容器消费。任意矩阵、合并格与数据处理请使用表格能力。

## 容器标签

`label` 为整个容器添加附属文字，接受单个对象或数组，与 [Node label](/kernel/components/node/labels) 共用默认样式及位置、间距、旋转、引线规则。上面的 data 示例省略标签样式，直接使用 Core 默认值。

```tsx
<List data={['a', 'b']} label={{ text: 'values', position: 'top' }} />
```

标签以容器 allocation 矩形为边界，不撑大单元格或容器布局尺寸，但计入最终绘制范围；空容器也能显示标签。List 开启索引时，附着边界包含索引条。容器的变换和整体 clip 同样作用于标签，单元格裁切不影响它。

共用 `style.font`、`style.textColor`、`style.color`、`style.opacity` 作为标签宿主外观；`defaults.label` 和标签自身样式沿 Node 规则解析。键值角色与单元格样式不影响标签，`defaults.node` 不作用于标签宿主。`data` 中的嵌套容器不会继承根 label。
