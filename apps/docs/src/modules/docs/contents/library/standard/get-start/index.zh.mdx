## 安装与使用

<DocTabs defaultValue="react">
<DocTab value="react" label="React">

<DocStep title="绘制并挂载网格">

在已有 React 应用中渲染下面的 `Example` 组件。`react` / `react-dom` 是宿主对等依赖，版本至少为 18。

```tsx
import type { FC } from 'react';
import { Layout } from '@retikz/react';
import { Grid } from '@retikz/standard-react/presentation';

export const Example: FC = () => (
  <Layout>
    <Grid bounds={{ start: [0, 0], end: [240, 120] }} line={{ spacing: 20 }} />
  </Layout>
);
```

结果是一块宽 240、高 120、线间距为 20 的参考网格。`Grid` 在当前 `Layout` 中自动贡献所需能力；不需要手工注册。

将上面的组件保存为 `Example.tsx`，在已有 React 应用入口挂载（HTML 中准备 `<div id="root"></div>`）：

```tsx
import { createRoot } from 'react-dom/client';
import { Example } from './Example';

const root = document.getElementById('root');
if (root) createRoot(root).render(<Example />);
```

根 `Layout` 默认输出 SVG，本例无需配置 renderer。尺寸和间距使用相同的图形用户单位；默认原尺寸显示时，1 单位对应 1 CSS 像素。

<DocStep title="绘制并导出 SVG">

从 Standard 子入口导入 `grid` 与它的 adapter，再用 Vanilla 的场景与渲染函数生成结果。

```ts
import { grid, GridInputEmbedAdapter } from '@retikz/standard-vanilla/presentation';
import { renderToSvgString, scene } from '@retikz/vanilla';

const input = scene({
  children: [
    grid({
      bounds: { start: [0, 0], end: [240, 120] },
      line: { spacing: 20 },
    }),
  ],
});
const svg = renderToSvgString(input, { adapters: [GridInputEmbedAdapter] });
console.log(svg);
```

`svg` 是可保存为 `.svg` 文件或交给页面宿主展示的完整 SVG 字符串。`GridInputEmbedAdapter` 让 `grid(...)` 能作为 `scene` 的子项使用，请保留 `adapters` 选项。

## 确认结果

两端应得到同一块宽 240、高 120、间距 20 的网格。修改 `bounds.end` 会改变范围，修改 `line.spacing` 会改变疏密。React 负责把 SVG 挂到页面；Vanilla 返回 SVG 字符串，打印到控制台不会自动显示成图。
