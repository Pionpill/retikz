---
title: Extensions
description: Explicitly select Standard drawing Definitions from capability subpaths for direct IR, tooling, and different hosts while reusing Core definitions and registries.
---

The Standard extension layer answers which optional official drawing Definitions a figure needs. It does not redefine Core capabilities or create a second registry. Callers pass Definitions imported from exact subpaths to existing Core compile entry points.

## Responsibilities

| Topic              | Responsibility                                                | Reach for it when                                        |
| ------------------ | ------------------------------------------------------------- | -------------------------------------------------------- |
| Shapes             | Supply optional node outlines                                 | A figure needs an outline beyond Core's basic shapes     |
| Arrows             | Supply optional path endpoint markers                         | A figure needs a marker beyond Core's basic solid arrows |
| Clips              | Supply optional recursive compound clipping                   | One clipping region combines child clips                 |
| Path generators    | Supply optional step-expansion rules                          | A path needs a rule such as a parabola                   |
| Capability loading | Explain Definition, provider-graph, and host responsibilities | Integrating React, Vanilla, or a custom toolchain        |
