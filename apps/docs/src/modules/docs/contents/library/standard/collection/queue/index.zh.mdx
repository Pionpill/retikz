`Queue` 展示队列的当前快照。输入从队首到队尾排列，第一项始终是队首，最后一项是队尾，默认向右排列。它适合任务队列、算法教学和操作前后的状态图。

## 接入方式

[安装与首次渲染](/library/standard/get-start)后，从 collection 入口导入。

## 基础用法

### 选择输入方式

items、data、skeleton 三选一。items 字符串原样显示，显式 Cell 使用 `{ content?, id?, style?, layout? }`。data 接受 JSON 数组，字符串显示引号，嵌套对象与数组默认展开为 Map／Array；dataExpand 仅对 data 有效，可用 false 或 map/array 数组选择展开范围。

| 骨架形式                                | 效果                   |
| --------------------------------------- | ---------------------- |
| `skeleton={{ count: 3 }}`               | 三个无内容单元格       |
| `skeleton={{ labels: ['A', '', 'C'] }}` | 三个符号格，中间为空格 |

空数组或 count 为零表示空队列。默认仅保留 16×16 的开放容器，没有占位格或进出箭头；padding 为零时自然尺寸为零。骨架格是真正的示意内容，不代表容量。

### 调整排列与边框

layout.direction 支持 up、down、left、right，分别朝上、下、左、右排列，首尾两端均开放。改变方向不会改变输入顺序。layout.width／height 始终是单格物理宽高；主轴保留每格尺寸，交叉轴 auto 格填满最大需求，固定小格居中且不拉伸。

layout.gap 默认 8，比嵌套 Array／Map 的默认间距 2 更大，便于区分外层元素。layout.padding 控制格内留白，根 padding 控制容器留白，默认均为 8。border 默认绘制两条独立侧边：横向排列绘制上下边，纵向排列绘制左右边，可以用 `border={{ style: { stroke: 'dodgerblue', dashPattern: [4, 3] } }}` 设置线型；false 只隐藏边框，padding 仍有效。根 frame 保留通用容器装饰语义，与开放边框独立。

arrow 默认 false，设为 true 同时开启两根箭头；对象形式通过 input、output 分别配置，省略的一侧隐藏。队列从队尾进入、队首出去，两根箭头均为直线。 两个字段分别接受 true、false 或外观对象；对象的 style 配置颜色、线宽和虚线，arrowDetail 配置箭头形状、大小和颜色。箭头不改变单格与容器布局，空集合隐藏箭头；label 仍用于整体文字标签。

下面示例默认开启进入和出去两根箭头，可通过开关分别隐藏。

```tsx
<Queue
  items={['A', 'B', 'C']}
  arrow={{
    input: { style: { stroke: 'dodgerblue', dashPattern: [4, 3] }, arrowDetail: { shape: 'openStealth' } },
    output: { style: { stroke: 'darkorange', strokeWidth: 2 } },
  }}
/>
```

## 扩展用法

### 嵌套内容与单格引用

React 组合使用以下层级；Vanilla 的 items.content 接受对应绘图输入，IR 接受单个可序列化 child。

```text
Queue
├── QueueItem
└── QueueItem
    └── Matrix
```

QueueItem 的 text 与唯一 drawable children 互斥，都省略时为空格。嵌套集合默认免去外层 Cell 背景与 padding，普通文字保留默认浅灰背景。单格 style 和 layout 覆盖整体默认，可以精确指定虚线、无填充或尺寸；固定尺寸默认裁切内容，overflow 可显式覆盖。

给格子设置 id 后，外部 Draw 可引用整个格子的实际边界。Queue 不自动生成下标 id，不提供 enqueue/dequeue 状态或复杂连接规则；额外操作标注、曲线与多帧状态由已有绘图和布局能力组合。本例给队尾格设置 selected，并从外部连接它。
