容器组件把结构化内容画成可识别的单元格。List 按顺序组织项目，Map 按键和值组织条目；单元格也可以承载另一个组件，用来表达嵌套结构。

## 职责一览

| 组件 | 职责                                 | 何时阅读                   |
| ---- | ------------------------------------ | -------------------------- |
| 列表 | 按顺序排列内容，支持横排、竖排与索引 | 表达数组、队列等顺序结构   |
| 映射 | 将键与值组织为条目                   | 表达记录、属性表或键值集合 |

## 选择与边界

这里的容器负责可视表达，不是运行时的数据结构实现。为任意图形添加背景或分组边框，应选择[展示组件](/library/standard/presentation)中的 Surface 或 Frame；只需通用排列时，阅读[布局包](/library/layout)。
