title: Standard · 标准包
description: 用标准组件组合网格、坐标轴、表面、图例与几何图形。
---

Standard 为常见绘图任务提供标准组件。你可以为一张图放置参考网格，用表面包裹内容，再添加说明符号的图例；每个组件以自己的参数描述一个完整任务。

## 职责一览

| 入口                   | 用途                                 |
| ---------------------- | ------------------------------------ |
| 三包的 `/presentation` | 网格、坐标轴、分组框、表面与图例     |
| 三包的 `/container`    | 列表、映射及后续结构化内容容器       |
| 三包的 `/shape`        | 圆、矩形、正多边形、星形、圆弧与扇形 |

## 安装与使用

React 项目安装作者入口及宿主：

<PackageManagerInstall packages="@retikz/standard-react @retikz/react react react-dom" />

无需 React 时安装 `@retikz/standard-vanilla` 与 `@retikz/vanilla`，并按所选组件使用对应子入口。[快速开始](/library/standard/get-start)展示两种入口绘制相同网格的完整步骤。

需要排列多个内容时阅读 [Layout](/library/layout)；需要可选节点形状、箭头、裁剪或流带时阅读 [Extension](/library/extension)。
