Standard 提供通用绘图组件：形状组件把几何参数变成轮廓，集合组件组织列表与键值内容，展示组件补充参考线、分组边界和图例。它们可以与 Kernel 的 Node、Path 和 Scope 放在同一张图中。

## 职责一览

| 家族                | 职责                                                   | 何时阅读                           |
| ------------------- | ------------------------------------------------------ | ---------------------------------- |
| shape · 形状        | Circle、Ellipse、Rectangle、Polygon、Star、Arc、Sector | 已知中心、尺寸或角度，需要独立轮廓 |
| collection · 集合   | List 与 Map 的单元格、索引和嵌套内容                   | 需要表达顺序或键值关系             |
| presentation · 展示 | Grid、Axes、Frame、Surface 与 Legend                   | 为已有图形补充参考、外观和含义     |

## 将组件组合成一张图

下面把 Grid 与 Axes 放在同一个 Layout 中：网格提供等距参考，坐标轴提供方向。两者保留各自参数，修改格距无需重写坐标轴。

<ComponentPreview files="/library/standard/presentation/presentation-composition" />

这两个组件都使用普通绘图坐标放置，不改变其它图元的坐标系。需要内容背景时再包一层 Surface，需要符号说明时再添加 Legend；每个组件承担自己的绘图任务。

## 安装与使用

React 项目安装组件入口与宿主：

<PackageManagerInstall packages="@retikz/standard-react @retikz/react react react-dom" />

无需 React 时安装 Vanilla 入口与宿主：

<PackageManagerInstall packages="@retikz/standard-vanilla @retikz/vanilla" />

组件从对应包的 `/shape`、`/collection` 或 `/presentation` 子入口导入。需要直接操作 JSON 契约或 Definition 时，显式安装 `@retikz/standard` 并使用相同家族子入口。[快速开始](/library/standard/get-start)提供安装、挂载与 SVG 输出的完整步骤；每个组件页进一步对照 React + JSX、React + IR、Vanilla API 与 Vanilla + IR。

## 选择与边界

首次接入从快速开始进入；已有具体图形目标时，直接选择下面的组件家族。组件页先介绍可运行的接入方式，再展开使用场景、限制、原理与参考，查参数不需要先读内部实现。

Standard 不处理数据 domain 或业务含义。数据可视化使用 [Plot](/viz/plot)，通用排列使用 [Layout](/library/layout)，可选节点形状、箭头和裁剪定义使用 [Extension](/library/extension)。
