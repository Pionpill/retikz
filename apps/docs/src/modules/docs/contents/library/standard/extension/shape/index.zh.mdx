形状扩展在 Core 提供的基础形状之上，补充了更多可选内容：

| 包名             | 提供内容                                                                                                     |
| ---------------- | ------------------------------------------------------------------------------------------------------------ |
| `core`           | `rectangle` — 矩形、`ellipse` — 椭圆、`polygon` — 多边形                                                     |
| `standard/shape` | `cross`、`sector`、`star`、`contour`、`trapezoid`、`parallelogram`、`hexagon`、`cylinder`、`ellipticCapsule` |

## 用法

本页支持两种导入方式：

- 按需导入特定 Definition，例如 `CrossShapeDefinition`，只把当前图需要的官方扩展传入 `Layout` 或 `compile`
- 整体使用官方扩展，例如 `StandardShapeDefinitions`，一次包含本子入口提供的全部 Standard Definition；组装 provider graph 时，对应使用 `StandardShapeProviders`

两种方式都只是当前图的显式装配，不会因为 import 自动全局注册形状。

### React 用法

从 `@retikz/standard/shape` 导入当前图需要的 Definition，传给 React `Layout` 的 `shapes` 属性。Definition 与参数分离：Node 只保存 `shape` 名称和 JSON-safe `params`，导入模块不会全局注册形状。

```tsx
import { Layout, Node } from '@retikz/react';
import { CrossShapeDefinition } from '@retikz/standard/shape';

<Layout shapes={[CrossShapeDefinition]}>
  <Node position={[0, 0]} shape="cross" minimumSize={{ width: 80, height: 80 }}>
    十字形
  </Node>
</Layout>;
```

### Vanilla 用法

在 `@retikz/vanilla` 中，把 Definition 放进 `compile.shapes`。`input` 可以是已有的 Core IR 或 Vanilla plain spec；`mount` 使用完全相同的 `compile` 配置。

```ts
import { renderToSvgString } from '@retikz/vanilla';
import { CrossShapeDefinition } from '@retikz/standard/shape';

const svg = renderToSvgString(input, {
  compile: {
    shapes: [CrossShapeDefinition],
  },
});
```

当 IR 形状既不是 Core 默认项，也没有在本次 `shapes` 中注册时，Core 会在 lookup 时明确失败，不会以相近形状静默替代。`polygon` 是 Core 最小内置形状，详见 [Polygon](/kernel/components/shapes/polygon)。

下面先并列九个扩展形状，便于比较基本外观，再进入各自的几何参数。

### 十字形

`cross` 支持独立控制水平臂、垂直臂的宽度，以及上、右、下、左四个方向的高度。它适合删除、禁用、交叉点和不对称十字架等 glyph。

<ComponentPreview files="cross-example" size="sm" />

使用 `shape={{ type: 'cross', params }}` 并注入 `CrossShapeDefinition`。`width` 或 `height` 可以直接使用数字，也可以使用对象；对象字段按“方向 > 轴向 > default”解析，即 `top/right/bottom/left` 优先于 `horizontal/vertical`，再回退到 `default`。

| 字段      | 类型                                                                                                                                  | 说明                                       |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| `width?`  | `number \| { default: number; horizontal?: number; vertical?: number }`                                                               | 水平臂与垂直臂宽度；数字同时应用于两个轴向 |
| `height?` | `number \| { default: number; horizontal?: number; vertical?: number; top?: number; right?: number; bottom?: number; left?: number }` | 四个方向高度，并支持轴向和 default 回退    |

### 梯形

`trapezoid` 用 `shortSide` 选择短边，并用短边与相对长边的比例控制收窄程度。内容外接会为斜边和圆角留出空间；比例为 `1` 时退化为矩形。

<ComponentPreview files="trapezoid-example" size="sm" />

#### API

节点注入 `TrapezoidShapeDefinition`，参数类型为 `TrapezoidShapeParams`：

| 字段              | 类型                                     | 说明                                           |
| ----------------- | ---------------------------------------- | ---------------------------------------------- |
| `shortSide?`      | `'top' \| 'right' \| 'bottom' \| 'left'` | 短边方向；默认为 `top`                         |
| `shortSideRatio?` | `number`                                 | 短边与相对长边之比，范围 `(0, 1]`；默认 `0.72` |
| `cornerRadius?`   | `number`                                 | 非负圆角半径；默认为 `0`                       |

### 平行四边形

`parallelogram` 通过斜边方向和角度控制水平错位。角度是斜边与水平边的夹角；`90` 度时轮廓退化为矩形，纵向形态可继续使用 Node 旋转。

<ComponentPreview files="parallelogram-example" size="sm" />

#### API

节点注入 `ParallelogramShapeDefinition`，参数类型为 `ParallelogramShapeParams`：

| 字段              | 类型                | 说明                                  |
| ----------------- | ------------------- | ------------------------------------- |
| `slantDirection?` | `'left' \| 'right'` | 顶边错位方向；默认为 `right`          |
| `slantAngle?`     | `number`            | 斜边角度，范围 `(0, 90]`；默认为 `70` |
| `cornerRadius?`   | `number`            | 非负圆角半径；默认为 `0`              |

### 长六边形

`hexagon` 是可独立调整宽高的长六边形：上下边保持水平，左右各保留一个侧向顶点。`shoulderDepth` 使用固定 user-unit 长度，因此内容变长只延长中间水平边，不会继续放大两侧尖角。它不是 Core 正多边形 `polygon { sides: 6 }` 的别名。

<ComponentPreview files="hexagon-example" size="sm" />

#### API

节点注入 `HexagonShapeDefinition`，参数类型为 `HexagonShapeParams`：

| 字段             | 类型     | 说明                                          |
| ---------------- | -------- | --------------------------------------------- |
| `shoulderDepth?` | `number` | 单侧水平肩深，使用非负 user-unit；默认为 `12` |
| `cornerRadius?`  | `number` | 非负圆角半径；默认为 `0`                      |

### 圆柱形

`cylinder` 用一个闭合外轮廓和一条端盖分隔弧表达圆柱。`capDepth` 会在内容区两端预留空间；分隔弧只参与描边，不会成为第二个节点或连接边界，也不会挖空近端端盖的填充。

<ComponentPreview files="cylinder-example" size="sm" />

#### API

节点注入 `CylinderShapeDefinition`，参数类型为 `CylinderShapeParams`：

| 字段        | 类型                         | 说明                        |
| ----------- | ---------------------------- | --------------------------- |
| `axis?`     | `'vertical' \| 'horizontal'` | 主轴方向；默认为 `vertical` |
| `capDepth?` | `number`                     | 非负端盖深度；默认为 `8`    |

### 半椭圆端胶囊形

`ellipticCapsule` 由顶部半椭圆、两侧直线和底部半椭圆组成一个闭合外轮廓。它与 `cylinder` 共享端部几何，但不绘制内部端盖分隔弧，因此顶部不会形成一个完整椭圆。与 Core 圆角矩形形成的 capsule 相比，`capDepth` 可以独立控制端部深度，半椭圆始终覆盖整个横截面。

<ComponentPreview files="elliptic-capsule-example" size="sm" />

#### API

节点注入 `EllipticCapsuleShapeDefinition`，参数类型为 `EllipticCapsuleShapeParams`：

| 字段        | 类型                         | 说明                        |
| ----------- | ---------------------------- | --------------------------- |
| `axis?`     | `'vertical' \| 'horizontal'` | 主轴方向；默认为 `vertical` |
| `capDepth?` | `number`                     | 非负端部深度；默认为 `8`    |

### 扇形

`sector` 用内外半径和角度范围构成实心扇片、环楔或开放弧，`cornerRadius` 可把正厚度 Sector 的径向转角变圆。将 `innerRadius` 与 `outerRadius` 设为相同的正数即可退化为可连接的开放弧；它适合角度范围、环形进度和扇区状态节点。

<ComponentPreview files="sector-example" size="md" />

#### API

节点使用 `shape={{ type: 'sector', params }}`，并注入 `SectorShapeDefinition`。`params` 类型为 `SectorShapeParams`：

| 字段            | 类型     | 说明                                                   |
| --------------- | -------- | ------------------------------------------------------ |
| `innerRadius`   | `number` | 非负内半径；`0` 表示实心扇片                           |
| `outerRadius`   | `number` | 正数外半径，必须大于等于 `innerRadius`；相等时为开放弧 |
| `startAngle`    | `number` | 起始角度，单位为度                                     |
| `endAngle`      | `number` | 结束角度，单位为度                                     |
| `cornerRadius?` | `number` | 正厚度 Sector 的转角圆角半径；省略或为 `0` 时保持尖角  |

### 星形

`star` 通过尖角数量、内外半径、旋转和圆角生成星形，并提供 `tip-N` 与 `notch-N` 命名 anchor。它适合强调、评分或需要语义锚点的图节点。

<ComponentPreview files="star-example" size="md" />

#### API

节点使用 `shape={{ type: 'star', params }}`，并注入 `StarShapeDefinition`。`params` 类型为 `StarShapeParams`：

| 字段            | 类型     | 说明                               |
| --------------- | -------- | ---------------------------------- |
| `points`        | `number` | 整数，范围为 3–1024                |
| `innerRadius`   | `number` | 正数内半径                         |
| `outerRadius`   | `number` | 正数外半径，必须大于 `innerRadius` |
| `rotate?`       | `number` | 形状自身旋转角度，单位为度         |
| `cornerRadius?` | `number` | 每个顶点的圆角半径                 |

### 任意轮廓

`contour` 接受一组闭合顶点环，并会以包围盒中心对齐 Node 位置；`cornerRadius` 对每个转角应用可行的圆角。这里用预设点集避免编辑 JSON，同时展示标签、盾牌和缺口等非标准轮廓。

<ComponentPreview files="contour-example" size="md" />

#### API

节点使用 `shape={{ type: 'contour', params }}`，并注入 `ContourShapeDefinition`。`params` 类型为 `ContourShapeParams`：

| 字段            | 类型                      | 说明                                                                     |
| --------------- | ------------------------- | ------------------------------------------------------------------------ |
| `points`        | `Array<[number, number]>` | 至少 3 个顶点，按给定顺序组成闭合顶点环；Node 会按顶点包围盒中心对齐位置 |
| `cornerRadius?` | `number`                  | 每个转角的圆角半径；省略或为 `0` 时保持尖角                              |
