title: Collections

Collection components draw structured content as identifiable cells. Array organizes items in sequence; Map organizes entries as keys and values; Matrix aligns two-dimensional cells on shared row and column tracks. A cell can also contain another component to represent nested structures.

## Responsibilities at a glance

| Component | Responsibility                                            | When to read                                        |
| --------- | --------------------------------------------------------- | --------------------------------------------------- |
| Array     | Arrange sequential items with direction and index options | Show arrays, queues, or other ordered structures    |
| Map       | Organize entries into keys and values                     | Show records, property tables, or keyed collections |

| Matrix | Arrange cells on shared row/column tracks | Show two-dimensional arrays and schematic matrices |

## Show a record inside a sequence

This example from the Array page places a Map inside one ArrayItem. The outer Array establishes item order, while the inner Map represents the fields of a record.

Nesting changes the content of a cell without obscuring the sequence. The Array and Map pages cover cell styling, indices, and references in detail.

Pass a JSON array as Array data or a JSON object as Map data. Use explicit items / entries or React composition when individual cells need ids, styles, or drawable children. These inputs serve different authoring needs and cannot be mixed on one instance.

## Choosing the right family

These collection components visualize structures; they are not runtime data structure implementations. Use Surface or Frame from [Presentation](/library/standard/presentation) to decorate arbitrary graphics. For general arrangement, see [Layout](/library/layout).
