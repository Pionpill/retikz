集合组件把数据结构的当前状态画出来。你可以展示一组项目、键值记录、二维格子，或用连接表达进出、分支与父子关系。它们适合算法教学、结构说明和状态对比；输入变化由应用提供，组件负责绘制。

## 如何选择

先看需要强调的结构：普通顺序用 Array，键值配对用 Map，二维行列用 Matrix；需要突出进出端时用 Stack 或 Queue，有分叉汇合或父子关系时用 Chain 或 Tree。

| 集合                                                 | 什么时候用               | 图中重点                 |
| ---------------------------------------------------- | ------------------------ | ------------------------ |
| [Array · 数组](/library/standard/collection/array)   | 展示有序项目或索引位置   | 一维单元格               |
| [Map · 映射](/library/standard/collection/map)       | 展示记录、属性与配置     | 键和值成对排列           |
| [Matrix · 矩阵](/library/standard/collection/matrix) | 展示二维数组或矩阵       | 共享行列轨道             |
| [Stack · 栈](/library/standard/collection/stack)     | 展示后进先出的状态       | 栈顶、开放边框与进出箭头 |
| [Queue · 队列](/library/standard/collection/queue)   | 展示先进先出的状态       | 队首、队尾与进出箭头     |
| [Chain · 链](/library/standard/collection/chain)     | 展示顺序连接、分叉与汇合 | 单元格和串并联连接       |
| [Tree · 树](/library/standard/collection/tree)       | 展示父子层级             | 文字节点和有序子树       |

## 输入与使用边界

Array、Map、Matrix、Chain、Stack 和 Queue 都支持显式内容、JSON 数据与示意骨架，各自的字段和结构有所不同。显式内容适合逐项样式、身份与图形组合；data 展示现有数据；skeleton 只描述示意格子。三种入口不能混用，具体写法见子页。

Tree 使用单一 root 入口，节点可以是字符串或带 children、样式与连接配置的对象；它绘制文字节点，不承载任意图形。

这些组件不执行入栈、出队、搜索或平衡等数据操作。需要任意图形排版时使用[布局包](/library/layout)，需要包装背景或边框时使用[展示组件](/library/standard/presentation)。首次使用可从[安装与首次渲染](/library/standard/get-start)开始。
