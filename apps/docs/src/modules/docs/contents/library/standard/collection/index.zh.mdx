---
title: collection · 集合
description: 用数组、映射和矩阵展示顺序集合、键值记录、二维单元格与嵌套结构。
---

集合组件把结构化内容画成可识别的单元格。Array 按顺序组织项目，Map 按键和值组织条目，Matrix 让二维内容共享行列轨道；单元格也可以承载另一个组件，用来表达嵌套结构。

## 职责一览

| 组件         | 职责                                 | 何时阅读                   |
| ------------ | ------------------------------------ | -------------------------- |
| Array · 数组 | 按顺序排列内容，支持横排、竖排与索引 | 表达数组、队列等顺序结构   |
| Map · 映射   | 将键与值组织为条目                   | 表达记录、属性表或键值集合 |

| Matrix · 矩阵 | 按共享行列轨道排列二维内容 | 表达二维数组与矩阵示意 |

下面复用数组页的组合示例：外层 Array 表达先后顺序，其中一个 ArrayItem 放入 Map 展示记录字段。外层负责项目排列，内层负责键值关系。

<ComponentPreview files="/library/standard/collection/array/array-composition" size="sm" />

嵌套改变的是单元格内容，数组的顺序仍然清楚。单元格样式、索引和引用方式分别在 Array、Map 子页展开。

同一个 JSON 数组可以直接作为 Array 的 `data`，JSON 对象可以作为 Map 的 `data`；需要给单格设置身份、样式或嵌套可绘制内容时，使用显式 items / entries 或 React 组合子项。两种入口分别承担数据展示与逐格控制，不要在同一实例混用。

## 选择与边界

这里的集合组件负责可视表达，不是运行时的数据结构实现。为任意图形添加背景或分组边框，应选择[展示组件](/library/standard/presentation)中的 Surface 或 Frame；只需通用排列时，阅读[布局包](/library/layout)。
