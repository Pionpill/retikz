---
title: 扩展
description: 为直接 IR、工具链和不同宿主从能力子入口显式选择 Standard 绘图定义，并继续复用 Core 的 Definition 与 registry。
---

Standard 扩展层回答“这幅图要接入哪些官方可选绘图定义”。它不重新定义 Core capability，也不建立第二套 registry；调用方把从精确子入口导入的 Definition 交给既有 Core 编译入口。

## 职责一览

| 主题     | 职责                                         | 何时查阅                           |
| -------- | -------------------------------------------- | ---------------------------------- |
| 形状     | 承载可选节点轮廓                             | 需要基础 Core 形状以外的轮廓       |
| 箭头     | 承载可选路径端点标记                         | 需要基础实心箭头以外的标记         |
| 裁剪     | 承载可选的递归组合裁剪                       | 一个裁剪区域由多个子裁剪组合而成   |
| 能力装载 | 说明 Definition、provider graph 与宿主的分工 | 集成 React、Vanilla 或自定义工具链 |
