`Star` alternates vertices between inner and outer radii to draw a closed star. Use it for ratings, emphasis markers, and decorative outlines.

## Using this topic

After [installation and first rendering](/library/standard/get-start), choose a host from the three `/shape` subpaths. All four forms draw the same minimal shape. React and Vanilla adapters supply the required definitions; direct IR requires explicit Definition injection.

## Basic usage

`<Star>` alternates points on an outer and inner radius, connects them into a closed path, and expands to an underlying `<Path>`. Useful for rating stars, emphasis marks, and decorative multi-point shapes.

```tsx
import { Star } from '@retikz/standard-react/shape';
```

```tsx
<Star center={[0, 0]} outerRadius={36} innerRadius={16} points={5} />
```

### Choose the inner radius and point count

`points` is the number of star points and must be an integer of at least 2. Give `innerRadius` directly, or use `innerRatio` to derive it from the outer radius.

| Form                                           | Best for                         |
| ---------------------------------------------- | -------------------------------- |
| `{ center, outerRadius, innerRadius, points }` | Control both radii               |
| `{ center, outerRadius, points, innerRatio? }` | Derive inner radius from a ratio |

## Errors and limitations

Choose either innerRadius or innerRatio to describe the inner radius. Radii must be finite and nonnegative, the inner radius cannot exceed the outer radius, and the ratio must lie in [0, 1]. center requires a literal coordinate; rotate defaults to −90° and is applied once when generating vertices.

### Star vertex expansion

Star alternates inner and outer radii to produce `2 × points` vertices, then emits one move, `2 × points - 1` lines and one cycle. Rotation is baked into the vertices and is not forwarded as a Path transform, avoiding double rotation.
