title: Standard
description: Extend Core with domain-neutral composites and explicitly assembled optional drawing Definitions while preserving one Core compile and registry path.
---

Standard has two public kinds of content: domain-neutral composites at its root entry and optional official drawing Definitions at capability subpaths. Both reuse Core's Definition, registry, and compile path; Standard does not create another drawing kernel.

Layout containers belong to the independent [Layout](/library/layout) package family. Standard only reuses Layout's public composition surface inside its own capabilities, such as Legend, and no longer exports layout APIs.

## Boundary with Core

Standard extends Core horizontally rather than replacing it:

- Kernel installation, compilation, and rendering stay unchanged when Standard is unused
- Definitions are assembled explicitly per figure, never registered globally, and never written into persisted JSON
- Standard content still compiles through the Core registry to the existing Scene consumed by SVG, Canvas, and other renderers

## Three packages and capability subpaths

| Entry                           | Responsibility                                                        | Use it when                                              |
| ------------------------------- | --------------------------------------------------------------------- | -------------------------------------------------------- |
| `@retikz/standard`              | Schemas, factories, Definitions, and lowering for Standard composites | Using Grid, Axes, Frame, Surface, or Legend              |
| `@retikz/standard-react`        | React DSL for presentation components                                 | Authoring inside a React `Layout`                        |
| `@retikz/standard-vanilla`      | Plain-spec helpers and Vanilla Tier 2 adapters                        | Authoring in browsers or scripts without React           |
| `@retikz/standard/<capability>` | Definitions for one optional drawing capability family                | A figure needs an optional shape, arrow, clip, or ribbon |

React and Vanilla only connect authoring inputs to the same capabilities. For optional drawing content, import a single Definition from the precise `@retikz/standard/<capability>` subpath and pass it to Core compile options; the `@retikz/standard` root does not forward it.
