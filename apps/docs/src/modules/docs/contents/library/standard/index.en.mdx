Standard provides generic drawing components. Shapes turn geometric parameters into outlines, containers organize sequential and keyed content, and presentation components add references, group boundaries, and legends. Combine them with Kernel Nodes, Paths, and Scopes in the same drawing.

## Responsibilities at a glance

| Family       | Responsibility                                             | When to read                                                 |
| ------------ | ---------------------------------------------------------- | ------------------------------------------------------------ |
| Shapes       | Circle, Ellipse, Rectangle, Polygon, Star, Arc, and Sector | Draw an independent outline from its center, size, or angles |
| Containers   | List and Map cells, indices, and nested content            | Express sequential or keyed relationships                    |
| Presentation | Grid, Axes, Frame, Surface, and Legend                     | Add references, appearance, and meaning to existing drawings |

## Combine components in one drawing

This example places Grid and Axes in the same Layout. The grid supplies equally spaced references, while the axes indicate direction. Each keeps its own parameters, so changing grid spacing does not require rewriting the axes.

<ComponentPreview files="/library/standard/presentation/presentation-composition" />

Both use ordinary drawing coordinates for placement and do not change the coordinate system of other primitives. Add Surface when content needs a background or Legend when symbols need an explanation. Each component owns its own drawing task.

## Installation and usage

For React, install the component entry and its host:

<PackageManagerInstall packages="@retikz/standard-react @retikz/react react react-dom" />

Without React, install the Vanilla entry and its host:

<PackageManagerInstall packages="@retikz/standard-vanilla @retikz/vanilla" />

Import components from the corresponding package's `/shape`, `/container`, or `/presentation` subpath. To work directly with JSON contracts or Definitions, explicitly install `@retikz/standard` and use the same family subpaths. The [quick start](/library/standard/get-start) covers installation, mounting, and SVG output. Each component page also compares React + JSX, React + IR, Vanilla API, and Vanilla + IR.

## Choosing the right capability

Start with the quick start for initial setup. If you already know the desired drawing, choose a component family below. Component pages begin with runnable integration, then cover usage, limitations, implementation, and references. Looking up a parameter does not require reading internals first.

Standard does not own data domains or business meaning. Use [Plot](/viz/plot) for data visualization, [Layout](/library/layout) for general arrangement, or [Extension](/library/extension) for optional node shapes, arrows, and clip definitions.
