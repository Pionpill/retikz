title: Standard

---

Standard provides components for common drawing tasks. Add a reference grid, wrap content in a surface, and explain symbols with a legend. Each component describes a complete task through its own parameters.

## Responsibilities at a glance

| Entry                      | Purpose                                                                           |
| -------------------------- | --------------------------------------------------------------------------------- |
| `@retikz/standard`         | Presentation data contracts, factories, and definitions                            |
| `@retikz/standard-react`   | Compose drawing components in React JSX                                           |
| `@retikz/standard-vanilla` | Create drawing inputs and connect rendering in TypeScript                         |
| Each package's `/shape`    | Draw circles, rectangles, polygons, stars, arcs, and sectors                      |

## Installation and usage

Install the authoring entry and host for React:

<PackageManagerInstall packages="@retikz/standard-react @retikz/react react react-dom" />

Without React, use `@retikz/standard-vanilla` and `@retikz/vanilla`. The [quick start](/library/standard/get-start) shows complete steps for drawing the same grid through both entries.

For arranging multiple items, see [Layout](/library/layout). For optional node shapes, arrows, clips, or ribbons, see [Extension](/library/extension).
