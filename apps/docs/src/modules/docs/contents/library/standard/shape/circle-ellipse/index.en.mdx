`Circle` and `Ellipse` draw circular outlines from a center, radii, or a bounding box. Use them for circular markers, elliptical borders, and partially closed regions.

## Using this topic

After [installation and first rendering](/library/standard/get-start), choose a host from the three `/shape` subpaths. All four forms draw the same minimal shape. React and Vanilla adapters supply the required definitions; direct IR requires explicit Definition injection.

## Basic usage

### Choose circle geometry

`<Circle>` / `<Ellipse>` draw a circle / ellipse outline at a position, expanding to an underlying `<Path>`. They fit cases where you know the center and radius, or only have a box.

```tsx
import { Circle, Ellipse } from '@retikz/standard-react/shape';
```

```tsx
<Circle center={[0, 0]} radius={32} style={{ fill: "none" }} />
<Ellipse center={[0, 0]} radius={{ x: 48, y: 28 }} style={{ fill: "none" }} />
```

The common form is `center + radius`. If you already have a rectangular area, you can also use `corner1 + corner2` or `box`.

| Form                         | Best for                                                   |
| ---------------------------- | ---------------------------------------------------------- |
| `{ center, radius }`         | Known center and radius                                    |
| `{ center, diameter }`       | Known diameter                                             |
| `{ from, to }`               | Diameter endpoints                                         |
| `{ corner1, corner2 }`       | Fit inside a box                                           |
| `{ box }`                    | Describe the box with `x/y/origin + width + height`        |
| + `fit="contain" \| "cover"` | Fit the circle inside or outside the box                   |
| + `inset` / `outset`         | Shrink or expand the box before fitting                    |
| + angles + `closed="sector"` | Draw a partial circle whose arc ends connect to the center |

### Choose ellipse geometry

Ellipse works like Circle, but the radius is split into `radius: { x, y }`. It also supports `corner1 + corner2` and `box`.

| Form                               | Best for                                                    |
| ---------------------------------- | ----------------------------------------------------------- |
| `{ center, radius }`               | Known center and radii                                      |
| `{ center, diameterX, diameterY }` | Known diameters                                             |
| `{ corner1, corner2 }`             | Fit inside a box                                            |
| `{ box }`                          | Describe the box with `x/y/origin + width + height`         |
| + `inset` / `outset`               | Shrink or expand the box before fitting                     |
| + angles + `closed="sector"`       | Draw a partial ellipse whose arc ends connect to the center |

## Errors and limitations

Choose exactly one geometry description. Radii, diameters, side lengths and dimensions must be finite and nonnegative. Adjusted boxes must retain positive dimensions. Partial arcs require exactly two of startAngle, endAngle and sweepAngle, preserving signed sweeps and revolutions.

### Circle and ellipse path expansion

The upper route preserves a `Circle center` target, so a node id, polar point, or `[x, y]` coordinate can resolve later during Path compilation. The lower route must compute a center and radii in the Standard lowering first, so it accepts literal `[x, y]` geometry only:

<ComponentPreview files="circle-ellipse-lowering-flow" size="md" hideCode type="illustration" />

`Circle` from / corner / box forms and `Ellipse` corner / box forms take the lower route. Ellipse center forms preserve Target references. Both routes expand to an equivalent `<Path>` plus a `circlePath` / `ellipsePath` Step. With angles present, `closed` then chooses a chord (`chord`, the default), a return to the center (`sector`), or an open arc (`open`).
