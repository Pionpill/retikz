以下 Schema 从 `@retikz/extension` 的公开入口导出。`RibbonPathSchema` 校验完整 Path，`RibbonPathOptionsSchema` 校验 `kindOptions`；共享 Path 字段的详细含义见 [Path Schema 参考](/kernel/components/path/schema-reference)。

## RibbonPathOptionsSchema

<ZodSchema
  shallow
  name="RibbonPathOptionsSchema"
  description="Ribbon 专属配置；centerline 与 boundary 模式使用互斥字段。"
  descriptions={{
    mode: '构造模式；省略时使用 centerline。',
    sampling: '中心线采样策略，默认 64 个基础样本。',
    width: '由 kind 区分的四种宽度规则，必须选择一种。',
    start: '起点端面方向、端帽与标签。',
    end: '终点端面方向、端帽与标签。',
    align: '生成带状轮廓时，中心线位于哪一侧。',
    upper: 'boundary 模式的开放上边界 Step 序列。',
    lower: 'boundary 模式的开放下边界 Step 序列。',
  }}
/>

`centerline` 必须提供带 `kind` 的 `width` 对象。`boundary` 必须提供 `upper` 与 `lower`，且不能使用中心线宽度字段。
