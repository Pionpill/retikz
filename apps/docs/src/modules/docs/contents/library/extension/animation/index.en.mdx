description: Generate ready-to-play tracks with growth, pulse, spin, flash, blink, and wiggle factories, with options for each preset.

Animation presets are pure functions: options go in, JSON animation tracks come out. They create no player and need no registration. Put the result in a Node, Path, or Scope `animations` array.

## Using this topic

Import the needed factory from `@retikz/extension`. React, Vanilla, and direct IR use the same track data. The minimal example imports `pulse` from the package root.

<DocTab value="react-jsx" label="React + JSX">

```tsx
import { pulse } from '@retikz/extension';
import { Layout, Node } from '@retikz/react';

export const Example = () => (
  <Layout>
    <Node layout={{ minimumSize: { width: 72, height: 52 } }} animations={[pulse({ peak: 1.25 })]} />
  </Layout>
);
```

## Growth entrance

`grow` scales the entire element from zero to full size. `growUp` scales only vertically and defaults to the bottom-center origin, suitable for bars growing from a baseline.

<ComponentPreview files="growth" size="sm" controls={{ animation: true }} />

<DocTabs defaultValue="api">
<DocTab value="api" label="API reference">

#### `Omit<ScaleInOptions, 'from'>`

`grow(options)` returns a track for the target `animations` array.

#### GrowUpOptions

`growUp(options)` returns a track for the target `animations` array.

| Field       | Type                | Description                                       |
| ----------- | ------------------- | ------------------------------------------------- |
| `duration?` | `number`            | Duration; grow defaults to 400ms, growUp to 500ms |
| `origin?`   | `IRAnimationOrigin` | Scale origin; growUp defaults to bottom           |

All presets also accept `delay?`, `easing?`, and `trigger?` for initial delay, easing, and trigger.

</DocTab>
</DocTabs>

The demo starts both effects at 500ms with a bottom origin; these control values are not the `grow` API defaults. Switch the effect, duration, and origin to compare uniform and bottom-anchored growth.

## Continuous emphasis

`pulse` scales between full size and a peak, while `spin` rotates a full turn at constant speed. Both repeat indefinitely by default.

<ComponentPreview files="continuous" size="sm" controls={{ animation: true }} />

<DocTabs defaultValue="api">
<DocTab value="api" label="API reference">

#### PulseOptions

`pulse(options)` returns a track for the target `animations` array.

#### SpinOptions

`spin(options)` returns a track for the target `animations` array.

| Field       | Type                | Description                                                   |
| ----------- | ------------------- | ------------------------------------------------------------- |
| `duration?` | `number`            | Per-cycle duration, default 1000ms                            |
| `peak?`     | `number`            | Pulse peak scale, default 1.1                                 |
| `origin?`   | `IRAnimationOrigin` | Optional transform origin, defaulting to the geometric center |

All presets also accept `delay?`, `easing?`, and `trigger?` for initial delay, easing, and trigger.

</DocTab>
</DocTabs>

The demo sets the pulse peak to 1.3. Switch between pulse and spin and change cycle duration; the peak control appears only for pulse.

## Opacity flashing

Both `flash` and `blink` move between full opacity and a minimum. Flash runs twice by default; blink loops indefinitely.

<ComponentPreview files="opacity" size="sm" controls={{ animation: true }} />

<DocTabs defaultValue="api">
<DocTab value="api" label="API reference">

#### FlashOptions

`flash(options)` returns a track for the target `animations` array.

#### BlinkOptions

`blink(options)` returns a track for the target `animations` array.

| Field         | Type                   | Description                                             |
| ------------- | ---------------------- | ------------------------------------------------------- |
| `duration?`   | `number`               | Cycle duration; flash defaults to 300ms, blink to 800ms |
| `dim?`        | `number`               | Minimum opacity, default 0                              |
| `iterations?` | `number \| 'infinite'` | Iteration count; flash defaults to 2, blink to infinite |

All presets also accept `delay?`, `easing?`, and `trigger?` for initial delay, easing, and trigger.

</DocTab>
</DocTabs>

The demo sets both effects to a 500ms cycle. Change the minimum opacity and compare finite flashing with continuous blinking. Replay the finite effect in the preview.

## Wiggle emphasis

`wiggle` rotates back and forth between positive and negative angles, then returns to its original orientation. It runs three times by default.

<ComponentPreview files="wiggle" size="sm" controls={{ animation: true }} />

<DocTabs defaultValue="api">
<DocTab value="api" label="API reference">

#### WiggleOptions

`wiggle(options)` returns a track for the target `animations` array.

| Field         | Type                   | Description                                                  |
| ------------- | ---------------------- | ------------------------------------------------------------ |
| `angle?`      | `number`               | Maximum angle on either side, default 5°                     |
| `duration?`   | `number`               | Cycle duration, default 400ms                                |
| `iterations?` | `number \| 'infinite'` | Iteration count, default 3                                   |
| `origin?`     | `IRAnimationOrigin`    | Optional rotation origin, defaulting to the geometric center |

All presets also accept `delay?`, `easing?`, and `trigger?` for initial delay, easing, and trigger.

</DocTab>
</DocTabs>

The demo starts at 12° and 500ms, rather than the preset defaults of 5° and 400ms. Adjust angle and duration to compare amplitude and speed; the node returns to its original orientation.

Presets do not read the target's current style or change layout or connections. Generated IR stores tracks rather than preset names, so playback does not need another Extension import.
