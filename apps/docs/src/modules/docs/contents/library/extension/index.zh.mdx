---

Extension 提供可直接使用的绘图定义。比如一张连接图可以使用圆柱节点、菱形箭头和流带；每类能力独立选择，显式加入当前图。

## 职责一览

| 能力     | 用途             |
| -------- | ---------------- |
| 节点形状 | 定义节点轮廓     |
| 箭头     | 标记路径端点     |
| 裁剪     | 限制内容显示范围 |
| 流带     | 绘制带宽度的路径 |
| 动画预设 | 生成动画轨道     |

## 安装与使用

<PackageManagerInstall packages="@retikz/extension" />

所有能力统一从包根导入，将所选定义传给当前图的绘图入口：

```ts
import { CrossShapeDefinition, DiamondArrowDefinition } from '@retikz/extension';
```

React 的 `Layout.extensions` 与 Vanilla 渲染选项的 `compile` 均接受这些定义。[快速开始](/library/extension/get-start)包含宿主安装、完整代码和结果说明。
