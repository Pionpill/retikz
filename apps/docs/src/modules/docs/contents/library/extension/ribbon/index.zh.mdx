Ribbon 将开放中心线或两条预计算边界绘制成可填充的带状路径，可表达连接的方向、强度与变化。它由 `@retikz/extension` 提供；使用前需在当前图显式装配 `RibbonPathKindDefinition`。

<ComponentPreview files="/library/extension/ribbon/usage/ribbon-basic" size="xs" />

## 选择构造方式

| 模式         | 输入                           | 适用场景                             |
| ------------ | ------------------------------ | ------------------------------------ |
| `centerline` | 开放中心线与宽度规则           | 从一条路径生成变化的带宽、端点与标签 |
| `boundary`   | 预计算的 `upper`、`lower` 边界 | 上下边界已由数据或其它几何过程确定   |

宽度曲线、轮廓与端帽由 Ribbon 生成。填充、描边、标签和变换沿用 Path 的共享能力；渲染器最终接收普通 Scene Path。
