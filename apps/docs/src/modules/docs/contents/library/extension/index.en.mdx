Extension provides ready-to-use drawing definitions. A connection diagram can combine cylinder nodes, diamond arrows, and ribbons; select each capability and explicitly enable it for the current drawing.

## Responsibilities at a glance

| Capability        | Purpose                   |
| ----------------- | ------------------------- |
| Node shapes       | Define node outlines      |
| Arrows            | Mark path endpoints       |
| Clips             | Restrict visible content  |
| Ribbons           | Draw paths with width     |
| Animation presets | Generate animation tracks |

## Installation and usage

<PackageManagerInstall packages="@retikz/extension" />

Import all capabilities from the root and pass selected definitions to your drawing entry:

```ts
import { CrossShapeDefinition, DiamondArrowDefinition } from '@retikz/extension';
```

Both React's `Layout.extensions` and Vanilla's `compile` rendering options accept these definitions. The [quick start](/library/extension/get-start) includes host installation, complete code, and the expected result.
