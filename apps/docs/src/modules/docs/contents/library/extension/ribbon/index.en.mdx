Ribbon turns an open centerline or two precomputed boundaries into a fillable band. It comes from `@retikz/extension`; explicitly assemble `RibbonPathKindDefinition` for each drawing that uses it.

<ComponentPreview files="/library/extension/ribbon/usage/ribbon-basic" size="xs" />

## Choose a construction mode

| Mode         | Input                                      | Use when                                                     |
| ------------ | ------------------------------------------ | ------------------------------------------------------------ |
| `centerline` | An open centerline and width rule          | One path determines changing width, endpoints, and labels    |
| `boundary`   | Precomputed `upper` and `lower` boundaries | Data or another geometry process already supplies both sides |

Ribbon generates widths, outlines, and caps. Fill, stroke, labels, and transforms use shared Path behavior; the renderer receives an ordinary Scene Path.
