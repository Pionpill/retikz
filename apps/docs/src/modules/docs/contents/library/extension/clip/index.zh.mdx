裁剪限制 Scope 内内容的可见区域。每种区域由 `kind` 和 JSON 参数描述，使用前需在当前编译入口装配相应 Definition。

## 接入方式

从 `@retikz/extension` 按需导入 Definition，例如 `CircleClipDefinition`；也可以使用包含本页全部类型的 `ExtensionClipDefinitions`。导入不会全局注册裁剪。下例把圆形裁剪限制在当前 `Layout` 内。

<ComponentPreview files="entry" size="sm" hideCode />

<DocTabs defaultValue="react-jsx">
<DocTab value="react-jsx" label="React + JSX">

```tsx
import { CircleClipDefinition } from '@retikz/extension';
import { Layout, Node, Scope } from '@retikz/react';

export const Example = () => (
  <Layout extensions={{ clips: [CircleClipDefinition] }}>
    <Scope clip={{ kind: 'circle', cx: 0, cy: 0, r: 50 }}>
      <Node layout={{ minimumSize: { width: 160, height: 120 } }} />
    </Scope>
  </Layout>
);
```

</DocTab>
<DocTab value="react-ir" label="React + IR">

```tsx
import type { IRScene } from '@retikz/core';
import { CircleClipDefinition } from '@retikz/extension';
import { Layout } from '@retikz/react';

const ir: IRScene = {
  type: 'scene',
  version: 1,
  children: [
    {
      type: 'scope',
      clip: { kind: 'circle', cx: 0, cy: 0, r: 50 },
      children: [{ type: 'node', layout: { minimumSize: { width: 160, height: 120 } } }],
    },
  ],
};
export const Example = () => <Layout ir={ir} extensions={{ clips: [CircleClipDefinition] }} />;
```

</DocTab>
<DocTab value="vanilla-api" label="Vanilla API">

```ts
import { CircleClipDefinition } from '@retikz/extension';
import { node, renderToSvgString, scene, scope } from '@retikz/vanilla';

const input = scene({
  children: [
    scope({ clip: { kind: 'circle', cx: 0, cy: 0, r: 50 } }, [
      node({ layout: { minimumSize: { width: 160, height: 120 } } }),
    ]),
  ],
});
const svg = renderToSvgString(input, { compile: { clips: [CircleClipDefinition] } });
console.log(svg);
```

## 圆形与椭圆

`circle` 用单个半径裁剪；`ellipse` 分别设置横向、纵向半径。两者都以指定中心定位。

<ComponentPreview
  files={['circle-ellipse-clip', 'circle-ellipse-clip.preview.tsx']}
  size="sm"
  defaultSourceFile="circle-ellipse-clip.preview.tsx"
/>

<DocTabs defaultValue="api">
<DocTab value="api" label="API 参考">

#### IRCircleClip

注入 `CircleClipDefinition`：

| 字段       | 类型       | 说明                     |
| ---------- | ---------- | ------------------------ |
| `kind`     | `'circle'` | 选择圆形裁剪             |
| `cx`、`cy` | `number`   | 圆心坐标                 |
| `r`        | `number`   | 正数半径，单位为用户坐标 |

#### IREllipseClip

注入 `EllipseClipDefinition`：

| 字段       | 类型        | 说明               |
| ---------- | ----------- | ------------------ |
| `kind`     | `'ellipse'` | 选择椭圆裁剪       |
| `cx`、`cy` | `number`    | 椭圆中心坐标       |
| `rx`、`ry` | `number`    | 正数横向、纵向半径 |

</DocTab>

## 路径

`path` 接收结构化路径命令，可描述曲线或多个子路径；命令需形成有效的可填充区域。

<ComponentPreview files={['path-clip', 'path-clip.preview.tsx']} size="md" defaultSourceFile="path-clip.preview.tsx" />

<DocTabs defaultValue="api">
<DocTab value="api" label="API 参考">

#### IRPathClip

注入 `PathClipDefinition`。命令格式可在[自定义路径](/kernel/components/path/custom-path)中查阅。

| 字段        | 类型                     | 说明                         |
| ----------- | ------------------------ | ---------------------------- |
| `kind`      | `'path'`                 | 选择路径裁剪                 |
| `commands`  | `Array<PathCommand>`     | 至少一条结构化路径命令       |
| `fillRule?` | `'nonzero' \| 'evenodd'` | 填充规则；省略时为 `nonzero` |

</DocTab>
<DocTab value="schema" label="Schema 参考">

#### PathClipSchema

</DocTab>

演示保持命令结构不变，初始使用 `evenodd`；用控件改变命令坐标与 `fillRule`。

## 组合裁剪

`compound` 按输入顺序累积子区域的路径，再用一个 `fillRule` 解释最终区域。它组合轮廓，不计算子区域之间的几何交集。

<ComponentPreview
  files={['compound-clip', 'compound-clip.preview.tsx']}
  size="sm"
  defaultSourceFile="compound-clip.preview.tsx"
/>

<DocTabs defaultValue="api">
<DocTab value="api" label="API 参考">

#### IRCompoundClip

注入 `CompoundClipDefinition`，并同时注入每个 child 对应的 Definition。几何交集可通过嵌套多个 `<Scope clip>` 实现。

| 字段        | 类型                     | 说明                                   |
| ----------- | ------------------------ | -------------------------------------- |
| `kind`      | `'compound'`             | 选择组合裁剪                           |
| `children`  | `Array<IRClip>`          | 至少一个子区域，按顺序累积             |
| `fillRule?` | `'nonzero' \| 'evenodd'` | 组合路径的填充规则；省略时为 `nonzero` |

</DocTab>
