本页的箭头 Definition 为路径端点提供六组可选几何形状。选择实心、空心或开放线条后，仍可通过路径的 `arrowDetail` 调整尺寸和颜色。

## 接入方式

按需从 `@retikz/extension` 导入 Definition，例如 `DiamondArrowDefinition`；或使用包含全部端点的 `ExtensionArrowDefinitions`。导入不会全局注册端点。React 传给 `Layout.extensions.arrows`，Vanilla 传给 `compile.arrows`。

<ComponentPreview files="entry" size="xs" hideCode />

<DocTabs defaultValue="react-jsx">
<DocTab value="react-jsx" label="React + JSX">

```tsx
import { DiamondArrowDefinition } from '@retikz/extension';
import { Draw, Layout } from '@retikz/react';

export const Example = () => (
  <Layout extensions={{ arrows: [DiamondArrowDefinition] }}>
    <Draw
      way={[
        [0, 0],
        [160, 0],
      ]}
      arrow="->"
      arrowDetail={{ end: { shape: 'diamond' } }}
    />
  </Layout>
);
```

</DocTab>
<DocTab value="react-ir" label="React + IR">

```tsx
import type { IRScene } from '@retikz/core';
import { DiamondArrowDefinition } from '@retikz/extension';
import { Layout } from '@retikz/react';

const ir: IRScene = {
  type: 'scene',
  version: 1,
  children: [
    {
      type: 'path',
      arrow: '->',
      arrowDetail: { end: { shape: 'diamond' } },
      children: [
        { type: 'step', kind: 'move', to: [0, 0] },
        { type: 'step', kind: 'line', to: [160, 0] },
      ],
    },
  ],
};
export const Example = () => <Layout ir={ir} extensions={{ arrows: [DiamondArrowDefinition] }} />;
```

## 菱形箭头

`diamond` 与 `openDiamond` 分别是实心和空心的对称菱形。默认尺寸均为 11 × 6；空心版本只描边。

<ComponentPreview
  files={['diamond-arrows', 'diamond-arrows.preview.tsx']}
  size="sm"
  defaultSourceFile="diamond-arrows.preview.tsx"
/>

<DocTabs defaultValue="api">
<DocTab value="api" label="API 参考">

#### DiamondArrowDefinition / OpenDiamondArrowDefinition

将下列 Definition 传入 `Layout.extensions.arrows` 或 `compile.arrows`，用 `arrowDetail.end.shape` 选择端点：

| Definition                   | `shape`       | 默认长 × 宽 |
| ---------------------------- | ------------- | ----------- |
| `DiamondArrowDefinition`     | `diamond`     | 11 × 6      |
| `OpenDiamondArrowDefinition` | `openDiamond` | 11 × 6      |

#### IRArrowEndDetail

| 字段         | 类型               | 说明                                   |
| ------------ | ------------------ | -------------------------------------- |
| `shape`      | `string`           | 本节列出的端点名称                     |
| `length?`    | `number`           | 沿路径方向的非负长度                   |
| `width?`     | `number`           | 垂直于路径的非负宽度                   |
| `color?`     | `string \| number` | 端点颜色；省略时继承路径描边           |
| `lineWidth?` | `number`           | 空心或开放轮廓的描边宽度；实心形状忽略 |

</DocTab>
</DocTabs>

调整颜色、缩放和空心描边，对照两种填充方式。

## 阻断线端点

`bar` 在端点绘制垂直于路径的开放线段，默认尺寸为 8 × 8。名称不预设业务含义。

将下列 Definition 传入 `Layout.extensions.arrows` 或 `compile.arrows`，用 `arrowDetail.end.shape` 选择端点：

| Definition           | `shape` | 默认长 × 宽 |
| -------------------- | ------- | ----------- |
| `BarArrowDefinition` | `bar`   | 8 × 8       |

#### IRArrowEndDetail

| 字段         | 类型               | 说明                                   |
| ------------ | ------------------ | -------------------------------------- |
| `shape`      | `string`           | 本节列出的端点名称                     |
| `length?`    | `number`           | 沿路径方向的非负长度                   |
| `width?`     | `number`           | 垂直于路径的非负宽度                   |
| `color?`     | `string \| number` | 端点颜色；省略时继承路径描边           |
