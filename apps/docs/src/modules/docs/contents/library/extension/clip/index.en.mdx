Clips restrict the visible content inside a Scope. Each region uses a `kind` and JSON parameters; assemble its Definition at the current compile entry point before use.

All clip specs use `{ kind, params }`: `kind` selects the definition and the required `params` object holds its geometry. Compound clips store children in `params.children`; each child has its own `kind` and `params`.

## Using this topic

Import a Definition such as `CircleClipDefinition` from `@retikz/extension`, or use `ExtensionClipDefinitions` for the complete family. Importing does not register clips globally.

<ComponentPreview files="entry" size="sm" hideCode />

The four forms below clip the same node to a circle. React uses `Layout.extensions.clips`; Vanilla uses `compile.clips`.

<DocTabs defaultValue="react-jsx">
<DocTab value="react-jsx" label="React + JSX">

```tsx
import { CircleClipDefinition } from '@retikz/extension';
import { Layout, Node, Scope } from '@retikz/react';

export const Example = () => (
  <Layout extensions={{ clips: [CircleClipDefinition] }}>
    <Scope clip={{ kind: 'circle', params: { cx: 0, cy: 0, r: 50 } }}>
      <Node layout={{ minimumSize: { width: 160, height: 120 } }} />
    </Scope>
  </Layout>
);
```

</DocTab>
<DocTab value="react-ir" label="React + IR">

```tsx
import type { IRScene } from '@retikz/core';
import { CircleClipDefinition } from '@retikz/extension';
import { Layout } from '@retikz/react';

const ir: IRScene = {
  type: 'scene',
  version: 1,
  children: [
    {
      type: 'scope',
      clip: { kind: 'circle', params: { cx: 0, cy: 0, r: 50 } },
      children: [{ type: 'node', layout: { minimumSize: { width: 160, height: 120 } } }],
    },
  ],
};
export const Example = () => <Layout ir={ir} extensions={{ clips: [CircleClipDefinition] }} />;
```

</DocTab>
<DocTab value="vanilla-api" label="Vanilla API">

```ts
import { CircleClipDefinition } from '@retikz/extension';
import { node, renderToSvgString, scene, scope } from '@retikz/vanilla';

const input = scene({
  children: [
    scope({ clip: { kind: 'circle', params: { cx: 0, cy: 0, r: 50 } } }, [
      node({ layout: { minimumSize: { width: 160, height: 120 } } }),
    ]),
  ],
});
const svg = renderToSvgString(input, { compile: { clips: [CircleClipDefinition] } });
console.log(svg);
```

## Circles and ellipses

`circle` uses one radius; `ellipse` sets horizontal and vertical radii separately. Both are positioned by their center.

| ------------------------ | ---------- | ----------------------------- |
| `kind`                   | `'circle'` | Selects a circular clip       |

| Field                    | Type        | Description                            |
| ------------------------ | ----------- | -------------------------------------- |
| `kind`                   | `'ellipse'` | Selects an elliptical clip             |
| `params.cx`, `params.cy` | `number`    | Center coordinates                     |

## Paths

`path` takes structured commands for curves or multiple subpaths. They must form a fillable region.

## Compound clips

`compound` accumulates child paths in input order and applies one `params.fillRule` to the final region. It combines contours without computing their geometric intersection.
