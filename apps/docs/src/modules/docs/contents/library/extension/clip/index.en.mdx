Clips restrict the visible content inside a Scope. Each region uses a `kind` and JSON parameters; assemble its Definition at the current compile entry point before use.

## Using this topic

Import a Definition such as `CircleClipDefinition` from `@retikz/extension`, or use `ExtensionClipDefinitions` for the complete family. Importing does not register clips globally.

<ComponentPreview files="entry" size="sm" hideCode />

The four forms below clip the same node to a circle. React uses `Layout.extensions.clips`; Vanilla uses `compile.clips`.

<DocTabs defaultValue="react-jsx">
<DocTab value="react-jsx" label="React + JSX">

```tsx
import { CircleClipDefinition } from '@retikz/extension';
import { Layout, Node, Scope } from '@retikz/react';

export const Example = () => (
  <Layout extensions={{ clips: [CircleClipDefinition] }}>
    <Scope clip={{ kind: 'circle', cx: 0, cy: 0, r: 50 }}>
      <Node layout={{ minimumSize: { width: 160, height: 120 } }} />
    </Scope>
  </Layout>
);
```

</DocTab>
<DocTab value="react-ir" label="React + IR">

```tsx
import type { IRScene } from '@retikz/core';
import { CircleClipDefinition } from '@retikz/extension';
import { Layout } from '@retikz/react';

const ir: IRScene = {
  type: 'scene',
  version: 1,
  children: [
    {
      type: 'scope',
      clip: { kind: 'circle', cx: 0, cy: 0, r: 50 },
      children: [{ type: 'node', layout: { minimumSize: { width: 160, height: 120 } } }],
    },
  ],
};
export const Example = () => <Layout ir={ir} extensions={{ clips: [CircleClipDefinition] }} />;
```

</DocTab>
<DocTab value="vanilla-api" label="Vanilla API">

```ts
import { CircleClipDefinition } from '@retikz/extension';
import { node, renderToSvgString, scene, scope } from '@retikz/vanilla';

const input = scene({
  children: [
    scope({ clip: { kind: 'circle', cx: 0, cy: 0, r: 50 } }, [
      node({ layout: { minimumSize: { width: 160, height: 120 } } }),
    ]),
  ],
});
const svg = renderToSvgString(input, { compile: { clips: [CircleClipDefinition] } });
console.log(svg);
```

## Circles and ellipses

`circle` uses one radius; `ellipse` sets horizontal and vertical radii separately. Both are positioned by their center.

<ComponentPreview files="circle-ellipse-clip" size="sm" />

<DocTabs defaultValue="api">
<DocTab value="api" label="API reference">

#### IRCircleClip

Inject `CircleClipDefinition`:

| Field      | Type       | Description                   |
| ---------- | ---------- | ----------------------------- |
| `kind`     | `'circle'` | Selects a circular clip       |
| `cx`, `cy` | `number`   | Center coordinates            |
| `r`        | `number`   | Positive radius in user units |

#### IREllipseClip

Inject `EllipseClipDefinition`:

| Field      | Type        | Description                            |
| ---------- | ----------- | -------------------------------------- |
| `kind`     | `'ellipse'` | Selects an elliptical clip             |
| `cx`, `cy` | `number`    | Center coordinates                     |
| `rx`, `ry` | `number`    | Positive horizontal and vertical radii |

## Polygons

`polygon` connects at least three authored vertices in order and closes the region.

| -------- | ------------------------- | ------------------------------- |

## Paths

`path` takes structured commands for curves or multiple subpaths. They must form a fillable region.

<ComponentPreview files="path-clip" size="md" />

<DocTabs defaultValue="api">
<DocTab value="api" label="API reference">

#### IRPathClip

Inject `PathClipDefinition`. See [Custom Paths](/kernel/components/path/custom-path) for command authoring.

| Field       | Type                     | Description                      |
| ----------- | ------------------------ | -------------------------------- |
| `kind`      | `'path'`                 | Selects a path clip              |
| `commands`  | `Array<PathCommand>`     | At least one structured command  |
| `fillRule?` | `'nonzero' \| 'evenodd'` | Fill rule; defaults to `nonzero` |

</DocTab>
<DocTab value="schema" label="Schema reference">

#### PathClipSchema

<ZodSchema name="PathClipSchema" />

</DocTab>
</DocTabs>

The demo keeps its command structure and starts with `evenodd`; controls change coordinates and `fillRule`.

## Compound clips

`compound` accumulates child paths in input order and applies one `fillRule` to the final region. It combines contours without computing their geometric intersection.

<ComponentPreview files="compound-clip" size="sm" />

<DocTabs defaultValue="api">
<DocTab value="api" label="API reference">

#### IRCompoundClip

Inject `CompoundClipDefinition` and the Definitions of its children. Nest `<Scope clip>` elements when you need geometric intersections.

| Field       | Type                     | Description                               |
| ----------- | ------------------------ | ----------------------------------------- |
| `kind`      | `'compound'`             | Selects a compound clip                   |
| `children`  | `Array<IRClip>`          | At least one child, accumulated in order  |
| `fillRule?` | `'nonzero' \| 'evenodd'` | Combined fill rule; defaults to `nonzero` |

</DocTab>
<DocTab value="schema" label="Schema reference">

#### CompoundClipSchema

<ZodSchema name="CompoundClipSchema" />

</DocTab>
</DocTabs>

Both children remain circles and start with `evenodd` in the demo. Change their radius, distance, and `fillRule` to compare the combined region.
