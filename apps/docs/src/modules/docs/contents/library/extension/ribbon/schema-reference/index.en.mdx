title: Schema reference
description: Ribbon Path, width, endpoint, and sampling input fields and constraints
---

These schemas are public exports from `@retikz/extension`. `RibbonPathSchema` validates a complete Path and `RibbonPathOptionsSchema` validates `kindOptions`. See the [Path schema reference](/kernel/components/path/schema-reference) for shared Path fields.

## RibbonPathSchema

<ZodSchema
  shallow
  name="RibbonPathSchema"
  description="Complete Ribbon Path input; mode determines the centerline or boundary constraints."
/>

## RibbonPathOptionsSchema

<ZodSchema
  shallow
  name="RibbonPathOptionsSchema"
  description="Ribbon-specific configuration with mutually exclusive centerline and boundary fields."
/>

`centerline` requires a `width` object discriminated by `kind`. `boundary` requires `upper` and `lower` and excludes centerline width fields.

## CenterlineRibbonPathOptionsSchema

<ZodSchema
  shallow
  name="CenterlineRibbonPathOptionsSchema"
  description="Centerline mode: width is required; endpoints can set direction, cap, and label. Mode may be omitted."
/>

## BoundaryRibbonPathOptionsSchema

<ZodSchema
  shallow
  name="BoundaryRibbonPathOptionsSchema"
  description="Boundary mode requires mode, upper, and lower and rejects centerline-only fields."
/>

## RibbonWidthSchema

<ZodSchema
  shallow
  name="RibbonWidthSchema"
  description="Discriminated union of fixed, taper, stops, and profile. Strict branches reject mixed fields."
/>

## FixedRibbonWidthSchema

<ZodSchema
  shallow
  name="FixedRibbonWidthSchema"

## TaperRibbonWidthSchema

<ZodSchema
  shallow

## RibbonEndpointSchema
