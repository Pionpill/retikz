title: animation · 动画预设
description: 用生长、脉冲、旋转、闪烁和摆动工厂生成可直接播放的动画轨道，并查阅各预设参数。
---

动画预设是纯函数：输入参数，返回 JSON 动画轨道。它们不创建播放器，也不需要注册；把结果放进 Node、Path 或 Scope 的 `animations` 即可播放。

## 接入方式

从 `@retikz/extension` 导入所需工厂。React、Vanilla 和直接 IR 共用同一轨道数据。下面的脉冲示例从包根导入 `pulse`。

<DocTab value="react-jsx" label="React + JSX">

```tsx
import { pulse } from '@retikz/extension';
import { Layout, Node } from '@retikz/react';

export const Example = () => (
  <Layout>
    <Node layout={{ minimumSize: { width: 72, height: 52 } }} animations={[pulse({ peak: 1.25 })]} />
  </Layout>
);
```

```tsx
import type { IRScene } from '@retikz/core';
import { pulse } from '@retikz/extension';

const ir: IRScene = {
  type: 'scene',
  version: 1,
  children: [
    {
      type: 'node',
      layout: { minimumSize: { width: 72, height: 52 } },
      animations: [pulse({ peak: 1.25 })],
    },
  ],
};
export const Example = () => <Layout ir={ir} />;
```

## 生长入场

`grow` 从 0 倍整体放大到原尺寸；`growUp` 只放大纵向，默认以底边中点为支点，适合柱状图从基线长出。

<ComponentPreview files="growth" size="sm" controls={{ animation: true }} />

<DocTabs defaultValue="api">
<DocTab value="api" label="API 参考">

#### `Omit<ScaleInOptions, 'from'>`

`grow(options)` 生成一条可直接放入 `animations` 的动画轨道。

#### GrowUpOptions

`growUp(options)` 生成一条可直接放入 `animations` 的动画轨道。

| 字段        | 类型                | 说明                                         |
| ----------- | ------------------- | -------------------------------------------- |
| `duration?` | `number`            | 单次时长；grow 默认 400ms，growUp 默认 500ms |
| `origin?`   | `IRAnimationOrigin` | 缩放支点；growUp 默认为 bottom               |

所有预设也支持 `delay?`、`easing?`、`trigger?`，分别控制首次延迟、缓动与触发方式。

</DocTab>
</DocTabs>

演示将两种效果的时长设为 500ms、支点设为底边；这些是控件初始值，不是 `grow` 的 API 默认值。切换效果并改变时长与支点，可对比整体放大和沿底边长出。

## 持续强调

`pulse` 在原尺寸与峰值之间往返缩放；`spin` 匀速旋转一周。两者默认无限循环。

<ComponentPreview files="continuous" size="sm" controls={{ animation: true }} />

<DocTabs defaultValue="api">
<DocTab value="api" label="API 参考">

#### PulseOptions

`pulse(options)` 生成一条可直接放入 `animations` 的动画轨道。

#### SpinOptions

`spin(options)` 生成一条可直接放入 `animations` 的动画轨道。

| 字段        | 类型                | 说明                              |
| ----------- | ------------------- | --------------------------------- |
| `duration?` | `number`            | 每轮时长，默认 1000ms             |
| `peak?`     | `number`            | 仅 pulse 使用，峰值缩放，默认 1.1 |
| `origin?`   | `IRAnimationOrigin` | 可选变换支点，默认几何中心        |

所有预设也支持 `delay?`、`easing?`、`trigger?`，分别控制首次延迟、缓动与触发方式。

</DocTab>
</DocTabs>

演示把脉冲峰值设为 1.3；切换脉冲与旋转、改变单轮时长，峰值控件只在脉冲下出现。

## 透明度闪烁

`flash` 与 `blink` 都在完整显示和最低透明度之间往返。前者默认播放两次，后者默认无限循环。

<ComponentPreview files="opacity" size="sm" controls={{ animation: true }} />

<DocTabs defaultValue="api">
<DocTab value="api" label="API 参考">

#### FlashOptions

`flash(options)` 生成一条可直接放入 `animations` 的动画轨道。

#### BlinkOptions

`blink(options)` 生成一条可直接放入 `animations` 的动画轨道。

| 字段          | 类型                   | 说明                                         |
| ------------- | ---------------------- | -------------------------------------------- |
| `duration?`   | `number`               | 单轮时长；flash 默认 300ms，blink 默认 800ms |
| `dim?`        | `number`               | 最低透明度，默认 0                           |
| `iterations?` | `number \| 'infinite'` | 播放次数；flash 默认 2，blink 默认无限       |

所有预设也支持 `delay?`、`easing?`、`trigger?`，分别控制首次延迟、缓动与触发方式。

</DocTab>
</DocTabs>

演示将两种效果的单轮时长都设为 500ms。改变最低透明度，对比有限闪动与持续闪烁；有限效果可用预览中的重播按钮再次查看。

## 摆动强调

`wiggle` 在正负角度间往返旋转，并回到初始朝向。它默认播放三次，适合短时提示。

<ComponentPreview files="wiggle" size="sm" controls={{ animation: true }} />

<DocTabs defaultValue="api">
<DocTab value="api" label="API 参考">

#### WiggleOptions

`wiggle(options)` 生成一条可直接放入 `animations` 的动画轨道。

| 字段          | 类型                   | 说明                       |
| ------------- | ---------------------- | -------------------------- |
| `angle?`      | `number`               | 单侧最大角度，默认 5°      |
| `duration?`   | `number`               | 单轮时长，默认 400ms       |
| `iterations?` | `number \| 'infinite'` | 播放次数，默认 3           |
| `origin?`     | `IRAnimationOrigin`    | 可选旋转支点，默认几何中心 |

所有预设也支持 `delay?`、`easing?`、`trigger?`，分别控制首次延迟、缓动与触发方式。

</DocTab>
</DocTabs>

演示以 12°、500ms 开始，区别于预设的 5°、400ms 默认值。拖动角度和时长可观察摆动幅度与速度；结束后节点回到原朝向。

预设不会读取目标的当前样式，也不改变布局或连接关系。生成后的 IR 只保存动画轨道，不保存预设名；播放端无需再次导入 Extension。
