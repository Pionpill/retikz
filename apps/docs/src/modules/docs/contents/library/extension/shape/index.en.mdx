Node shape definitions provide crosses, sectors, stars, contours, trapezoids, parallelograms, hexagons, cylinders, and elliptic capsules. Set the node size, fill, and stroke after choosing its outline.

## Using this topic

This page supports two import styles:

- Import specific Definitions on demand, such as `CrossShapeDefinition`, and pass only the official extensions used by the figure to `Layout` or `compile`
- Use the complete official extension set through `ExtensionShapeDefinitions`, which includes every Extension Definition from this capability family; use `ExtensionShapeProviders` when assembling a provider graph

Both styles explicitly assemble capabilities for the current figure. Importing the package does not register shapes globally.

All four entries draw the same cross. React passes the Definition through `Layout.extensions.shapes`; Vanilla passes it through `compile.shapes`. The shape name and JSON parameters belong to the node data, while the Definition is configured for this rendering invocation.

```tsx
import { CrossShapeDefinition } from '@retikz/extension';
import { Layout, Node } from '@retikz/react';

export const Example = () => (
  <Layout extensions={{ shapes: [CrossShapeDefinition] }}>
    <Node
      shape="cross"
      layout={{ minimumSize: { width: 80, height: 80 } }}
      style={{ fill: '#dbeafe', stroke: '#2563eb' }}
    />
  </Layout>
);
```

## Cross

`cross` is a cross marker whose arm widths and four directional heights can be controlled independently. It fits concise glyphs for deletion, disabling, intersections, and asymmetric cross marks.

## Trapezoid

`trapezoid` selects its short side with `shortSide` and controls the taper through the short-to-opposite-side ratio. Content circumscription reserves room for slanted and rounded corners; ratio `1` degenerates to a rectangle.

## Elongated hexagon

`hexagon` is an independently resizable elongated hexagon with horizontal top/bottom edges and one lateral tip on each side. `shoulderDepth` uses a fixed user-unit length, so longer content extends only the middle horizontal edges instead of enlarging the tips. It is not an alias for Core's regular `polygon { sides: 6 }`.

## Cylinder

`cylinder` uses one closed outer contour plus one cap-divider arc. `capDepth` reserves content room at both ends; the divider is stroke-only, does not become a second node or connection boundary, and does not cut a hole out of the near cap's fill.

## Elliptic Capsule

`ellipticCapsule` forms one closed outer contour from a top half-ellipse, two straight sides, and a bottom half-ellipse. It shares its cap geometry with `cylinder` but omits the internal cap-divider arc, so the top does not form a complete ellipse. Unlike a capsule made from a Core rounded rectangle, `capDepth` independently controls cap depth and each half-ellipse spans the full cross-section.

## Sector

`sector` combines inner/outer radii with an angle range to form a pie slice, ring wedge, or open arc. Set `innerRadius` equal to `outerRadius` to get a connectable open arc; `cornerRadius` rounds radial corners only for positive-thickness sectors. It suits angle ranges, ring progress, and sector state nodes.
