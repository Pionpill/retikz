---
title: 网格布局
description: 用显式与隐式二维轨道、跨轨道范围和确定性自动放置排布任意子图形。
---

`GridLayout` 把内容区域划分为物理列轨道和行轨道。轨道可以固定、按最小或自然内容贡献求值、按份额吸收有限剩余空间，或用 `minmax` 组合上下界；子项可以显式指定连续的跨轨道范围，也可以按 `autoFlow` 放入下一处空位。

## 用法

```tsx
import { Layout, Node } from '@retikz/react';
import { GridLayout, LayoutItem } from '@retikz/layout-react';
```

```tsx
<Layout width={420} height={220}>
  <GridLayout
    columns={[
      { kind: 'fixed', value: 100 },
      { kind: 'fraction', factor: 1 },
    ]}
    columnGap={8}
  >
    <LayoutItem kind="grid">
      <Node position={[0, 0]} text="标签" />
    </LayoutItem>
    <LayoutItem kind="grid">
      <Node position={[0, 0]} text="42%" />
    </LayoutItem>
  </GridLayout>
</Layout>
```

JSON/IR 路径使用 `createGridLayout()` 与 `GridLayoutDefinition`；Vanilla 使用 `gridLayout()` 与 `GridLayoutInputEmbedAdapter`。完整布局家族可在 `composites` 中传入三个 layout Definition，或使用 `LayoutInputEmbedAdapters` 装载 Vanilla embed

| 场景        | 公开入口                                                                                           |
| ----------- | -------------------------------------------------------------------------------------------------- |
| React       | `GridLayout`、`LayoutItem`（`@retikz/layout-react`）                                               |
| Vanilla     | `gridLayout`、`GridLayoutInputEmbedAdapter`（`@retikz/layout-vanilla`）                            |
| 可选检查    | `InspectGridLayout`（`@retikz/layout-react/inspect`）、`inspectGridLayout`（Vanilla）              |
| IR / 持久化 | `GridLayoutSchema`、`createGridLayout`、`IRGridLayout`、`GridLayoutDefinition`（`@retikz/layout`） |

## 技术原理

<ComponentAlert
  type="tip"
  title="上手阶段可跳过本节"
  description="只有在排查轨道贡献、自动放置或文字重排高度时，才需要理解求解顺序。"
/>

GridLayout 使用固定的物理 x→y 求解顺序：

1. 校验显式放置，按 `autoFlow` 解析未完整指定的子项，并据此物化隐式轨道。
2. 沿 x 轴测量最小和自然内容贡献，求列尺寸轮廓与有限宽度分配。
3. 把最终列分配区域传给子图形，再沿 y 轴测量文本重排后的高度并求行尺寸轮廓。
4. 按 `justifyItems`、`alignItems` 或子项覆盖值放置真实占用，最后回放被选中的测量候选。

这个物理 x→y 顺序使文本在列宽确定后再决定行高，不需要 DOM 回读或循环猜测。`GridLayoutArtifact` 公开已求解的列与行、隐式轨道标记，以及每个子项最终的跨轨道范围。

## API 参考

### 可选 React 检查组件

| 属性       | 类型                                            | 默认值 | 描述                                                                   |
| ---------- | ----------------------------------------------- | ------ | ---------------------------------------------------------------------- |
| `inspect?` | `false` \| `true` \| `GridLayoutInspectOptions` | `true` | `InspectGridLayout` 为当前 occurrence 声明请求；`false` 只取消当前实例 |

基础 `GridLayout` 没有 `inspect` 属性。可选的 `InspectGridLayout` 对象形式可分别控制 `tracks`、`cells`、固定 `gaps`、`distributedSpace` 与 `spans`。完整通用字段和宿主 / Scope 规则见[运行时参考](/library/layout/reference/runtime#布局检查器)。

### `GridLayoutInput`

| 属性              | 类型                                        | 默认值       | 描述                                |
| ----------------- | ------------------------------------------- | ------------ | ----------------------------------- |
| `columns`         | `Array<GridTrackInput>`                     | —            | 至少一条显式物理列轨道              |
| `rows?`           | `Array<GridTrackInput>`                     | `[]`         | 显式行轨道；不足部分由隐式定义补齐  |
| `implicitColumn?` | `GridTrackInput`                            | 内容自然尺寸 | 自动放置扩展列时使用                |
| `implicitRow?`    | `GridTrackInput`                            | 内容自然尺寸 | 自动放置扩展行时使用                |
| `autoFlow?`       | <ApiValues name="GridAutoFlow" />           | `'row'`      | 非密集的确定性自动放置方向          |
| `overlap?`        | <ApiValues name="GridOverlap" />            | `'reject'`   | 完全显式放置子项的重叠策略          |
| `columnGap?`      | `number`                                    | `0`          | 物理列间距                          |
| `rowGap?`         | `number`                                    | `0`          | 物理行间距                          |
| `justifyItems?`   | `'start' \| 'center' \| 'end' \| 'stretch'` | `'stretch'`  | 默认水平子项对齐                    |
| `alignItems?`     | <ApiValues name="LayoutAlignment" />        | `'stretch'`  | 默认垂直子项对齐                    |
| `justifyContent?` | <ApiValues name="LayoutDistribution" />     | `'start'`    | 列组的水平剩余空间分布              |
| `alignContent?`   | <ApiValues name="LayoutDistribution" />     | `'start'`    | 行组的垂直剩余空间分布              |
| `size?`           | `LayoutSizeInput`                           | 内容 / 内容  | 容器双轴分配策略                    |
| `padding?`        | `number` \| `IRBoxSpacing`                  | `0`          | 从分配区域到内容区域的内边距        |
| `overflow?`       | <ApiValues name="LayoutOverflow" />         | `'visible'`  | 是否在容器分配区域上裁切视觉输出    |
| `children?`       | `Array<GridLayoutItemInput>`                | `[]`         | 作者声明的子项；显式 `key` 必须唯一 |

### `GridTrackInput`

| 形态       | 关键字段                       | 含义                           |
| ---------- | ------------------------------ | ------------------------------ |
| `fixed`    | `{ kind: 'fixed', value }`     | 固定非负尺寸                   |
| `content`  | `{ kind: 'content', mode }`    | 子图形最小或自然内容贡献       |
| `fraction` | `{ kind: 'fraction', factor }` | 有限空间中的正份额权重         |
| `minmax`   | `{ kind: 'minmax', min, max }` | 非份额下界与固定/内容/份额上界 |

### `GridLayoutItemInput`

| 属性           | 类型                                        | 默认值         | 描述                                     |
| -------------- | ------------------------------------------- | -------------- | ---------------------------------------- |
| `kind`         | `'grid'`                                    | —              | 网格布局子项判别字段                     |
| `key?`         | `string`                                    | 内部生成       | 可选稳定身份；省略时按 source index 生成 |
| `child`        | `IRChild`                                   | —              | 任意可 JSON 序列化的 Core 子图形         |
| `column?`      | `{ start?: number, span?: number }`         | 自动 / 跨 1 轨 | 列放置范围                               |
| `row?`         | `{ start?: number, span?: number }`         | 自动 / 跨 1 轨 | 行放置范围                               |
| `margin?`      | `number` \| `IRBoxSpacing`                  | `0`            | 轨道区域内缩前的子项外边距               |
| `justifySelf?` | `'start' \| 'center' \| 'end' \| 'stretch'` | 容器值         | 覆盖水平对齐                             |
| `alignSelf?`   | <ApiValues name="LayoutAlignment" />        | 容器值         | 覆盖垂直对齐                             |

React 中把可选 `key` 写成 `itemKey`，并用一个可绘制子元素或 `ir` 提供 `child`。省略 `itemKey` 时，自动身份只在内部产物中生成，不写回 Source IR。
