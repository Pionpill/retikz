## LayoutItem 联合

### LayoutItemSchema

<ZodSchema
  name="LayoutItemSchema"
  description="由 kind 判别的 FlexLayoutItem、GridLayoutItem 与 OverlayLayoutItem 闭合联合。"
/>

所有子项共享以下基础字段；具体容器页记录各自增加的分配字段。

| 字段      | 类型                            | 默认值   | 描述                                                   |
| --------- | ------------------------------- | -------- | ------------------------------------------------------ |
| `kind`    | `'flex' \| 'grid' \| 'overlay'` | —        | 选择拥有该子项的布局容器                               |
| `key?`    | `string`                        | 内部生成 | 可选的容器局部稳定身份；显式值必须唯一                 |
| `child`   | `IRChild`                       | —        | 参与布局、可 JSON 序列化的 Core 或已注册 Tier 2 子图形 |
| `margin?` | `number` \| `IRBoxSpacing`      | `0`      | 分配区域外围间距，不进入子图形的空间提案               |

React 中把可选 JSON `key` 写成 `itemKey`，并通过一个可绘制子元素或 `ir` 提供 `child`。省略时，Layout 按 source index 生成确定且唯一的有效 key；自动 key 只存在于内部产物，不写回 Source IR。若插入、删除或重排子项，按位置生成的身份可能变化；需要跨重排保持稳定身份时应显式传入 `key`。`LayoutItem` 只表达容器直属子项，不会单独生成图元。
