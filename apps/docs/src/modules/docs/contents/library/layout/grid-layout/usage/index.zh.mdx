`GridLayout` 把内容区域划分为物理列轨道和行轨道。轨道可以固定、按最小或自然内容贡献求值、按份额吸收有限剩余空间，或用 `minmax` 组合上下界；子项可以显式指定连续的跨轨道范围，也可以按 `autoFlow` 放入下一处空位。

React + JSX 中，`GridLayout` 的直属子元素使用 `GridLayoutItem`，每个子项承载一个可绘制内容：

```text
GridLayout
└── GridLayoutItem
    └── Node / GridLayout
```

```tsx
import { Layout, Node } from '@retikz/react';
import { GridLayout, GridLayoutItem } from '@retikz/layout-react';

export const Example = () => (
  <Layout>
    <GridLayout
      columns={[
        { kind: 'fixed', value: 80 },
        { kind: 'fixed', value: 80 },
      ]}
      columnGap={12}
    >
      <GridLayoutItem>
        <Node text="A" />
      </GridLayoutItem>
      <GridLayoutItem>
        <Node text="B" />
      </GridLayoutItem>
    </GridLayout>
  </Layout>
);
```

React 中把可选 `key` 写成 `itemKey`，并用一个可绘制子元素或 `ir` 提供 `child`。省略 `itemKey` 时，自动身份只在内部产物中生成，不写回 Source IR。

## 列宽与容器空间

列轨道决定每列分到多少宽度。固定列保留指定宽度，份额列按比例分享容器中剩余的空间。

| 属性                 | 可用值                                                                      | 解释                                                           |
| -------------------- | --------------------------------------------------------------------------- | -------------------------------------------------------------- |
| `columns`            | 轨道数组；本节用 `{ kind: "fixed", value }`、`{ kind: "fraction", factor }` | 至少一列；固定值非负，份额系数大于 0。内容与有界轨道见扩展用法 |
| `size.x / size.y`    | `{ kind: "content" }`, `{ kind: "fixed", value }`, `{ kind: "fill" }`       | 容器的物理宽、高：按内容求尺寸、固定尺寸或接收父级有限空间     |
| `padding`            | 非负数，或按 `x` / `y` / 四边配置的对象                                     | 从容器四边留出内边距，剩余部分为内容区                         |
| `columnGap / rowGap` | 非负数                                                                      | 分别控制列间距和行间距；跨度区域包含内部间距                   |

demo 的第一列固定为 100，后两列分配余量。调整末列份额，比较后两列宽度；再缩小容器，观察文字换行。改变内边距和列间距会减少可分配宽度。未指定行轨道时，行高由内容决定；槽位宽度不等于 Node 边框宽度。

## 子项行列放置

子项可以占一个格子，也可以跨越相邻行列。没有指定起始位置的子项，会按行或按列自动排列，并跳过已占用区域。

| 属性           | 可用值                   | 解释                                                                     |
| -------------- | ------------------------ | ------------------------------------------------------------------------ |
| `column / row` | `{ start?, span? }`      | 子项的列、行位置；`start` 是从 0 开始的非负整数，`span` 是正整数，默认 1 |
| `autoFlow`     | `row`, `column`          | 容器按行或按列搜索空位，不进行 `dense` 回填                              |
| `rows`         | 轨道数组；本节用固定轨道 | 声明已有行；本例保留两行以比较自动排列方向                               |

切换 demo 的自动排列方向，观察子项顺序如何映射到格子；再将首项跨度从 1 改为 2，查看后续子项如何避开已占用区域。跨列区域包含中间间距，但不会合并列轨道。

## 轨道分布与子项对齐

轨道分布控制整组行列的位置，子项对齐控制图形在各自格子里的位置。两者作用在不同层级。

| 属性                            | 可用值                                                                               | 解释                                           |
| ------------------------------- | ------------------------------------------------------------------------------------ | ---------------------------------------------- |
| `justifyContent / alignContent` | `start`, `center`, `end`, `stretch`, `space-between`, `space-around`, `space-evenly` | 容器属性：分别分布整组列和整组行；默认 `start` |
| `justifyItems`                  | `start`, `center`, `end`, `stretch`                                                  | 容器属性：子项默认水平对齐；默认 `stretch`     |
| `alignItems`                    | `start`, `center`, `end`, `stretch`, `first-baseline`, `last-baseline`               | 容器属性：子项默认垂直对齐；默认 `stretch`     |

demo 使用固定轨道并预留空白，初始居中便于观察。先改变列组或行组分布，查看轨道整体移动；再改变子项对齐，查看轨道不动而 Node 改变位置。`stretch` 提供尺寸约束，不保证固定几何发生变形。

## 子项外边距与独立对齐

单个子项可以留出外边距，也可以覆盖容器的默认对齐，不影响其他子项的配置。

| 属性          | 可用值                                                                         | 解释                                       |
| ------------- | ------------------------------------------------------------------------------ | ------------------------------------------ |
| `margin`      | 非负数，或按 `x` / `y` / 四边配置的对象                                        | 子项外边距，减少槽位内可供子图形使用的空间 |
| `justifySelf` | `start`, `center`, `end`, `stretch`；可省略                                    | 子项水平对齐；省略时继承 `justifyItems`    |
| `alignSelf`   | `start`, `center`, `end`, `stretch`, `first-baseline`, `last-baseline`；可省略 | 子项垂直对齐；省略时继承 `alignItems`      |

demo 只改变 First Node。增大它的外边距，再切换水平和垂直对齐，观察它与其他居中子项的差别。外边距属于布局输入；空间不足时，子图形仍可能超出槽位，槽位边界不代表裁切边界。
