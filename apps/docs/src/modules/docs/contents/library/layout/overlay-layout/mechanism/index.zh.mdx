## 局部目标点如何确定位置

容器的固有尺寸轮廓仅聚合 include 项，最终放置仍处理全部子项。定位先确定 slot，再把子图形的真实占用平移进去。下图中蓝色边界是分配区域，目标点贴住其右上角；视觉超出时是否裁切由 overflow 决定。

<ComponentPreview files="allocation-figure" hideCode type="illustration" size="md" />

图中内容区为 200 × 100，目标点 `at=(150,20)`，分配尺寸为 40 × 20，`anchor=(1,0)` 选择分配区域右上角。分配区域原点因此是 `(150−40,20−0)=(110,20)`，最后再应用 `offset`。锚点取自分配区域，而不是描边与标签形成的视觉包络。

## 为什么排除尺寸后仍然可见

`offset` 在放置后平移。按基线对齐的子项，其纵向偏移必须为零；定位子项必须采用边缘对齐，避免把局部点定位和跨子项基线求解混为一件事。

`sizeParticipation="exclude"` 只排除最小和自然尺寸轮廓，不隐藏子项、不跳过回放，也不改变绘制顺序。即使子项位于容器分配区域外，类型化产物仍保留其父级分配区域、真实占用、视觉边界和可见边界。
