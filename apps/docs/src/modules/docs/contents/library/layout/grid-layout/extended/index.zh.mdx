本页在[基础用法](/library/layout/grid-layout/usage)之上组合约束、观察边界并检查布局结果。先调整一个变量，再对照分配区域和真实占用。

## 显式轨道与自动放置

先声明 columns / rows，再给需要固定位置的子项设置 start 与 span。start 从 0 开始，span 必须是正整数。省略的轴由 autoFlow 补齐；超出显式轨道范围时，由 implicitColumn / implicitRow 提供隐式轨道规则。

固定轨道用于保留稳定区域，content 读取内容贡献，fraction 按有限剩余空间分配份额，minmax 表达上下界。只有父级提供有限空间时，份额轨道才有确定的分配依据。不要把 fraction 当作固定像素。

## 自动放置与显式重叠

自动放置使用非 dense 的稳定游标搜索，不提供回填早期空洞的 dense 选项。完全显式的区域默认拒绝重叠，只有 overlap="allow" 才允许这类重叠。几何位置不会重排源数组或绘制顺序。跨轨道项的区域包含中间 gap；margin 从该区域内扣除，再应用子项对齐。

## 交互比较

切换非密集自动放置方向、份额权重、间距与单元格对齐。固定 `viewBox` 让轨道比例、跨轨道范围和放置位置的变化可以直接比较。

基础 `GridLayout` 没有 `inspect` 属性。可选的 `InspectGridLayout` 对象形式可分别控制 `tracks`、`cells`、固定 `gaps`、`distributedSpace` 与 `spans`。完整通用字段和宿主 / Scope 规则见[运行时参考](/library/layout/reference/runtime#布局检查器)。

```tsx
import { Layout, Node } from '@retikz/react';
import { LayoutItem } from '@retikz/layout-react';
import { LayoutInspectLayout, InspectGridLayout } from '@retikz/layout-react/inspect';
export const Inspected = () => (
  <Layout>
    <LayoutInspectLayout>
      <InspectGridLayout
        columns={[
          { kind: 'fixed', value: 80 },
          { kind: 'fixed', value: 80 },
        ]}
        columnGap={12}
        inspect={{ bounds: { content: true, slot: true } }}
      >
        <LayoutItem kind="grid">
          <Node position={[0, 0]} text="A" />
        </LayoutItem>
      </InspectGridLayout>
    </LayoutInspectLayout>
  </Layout>
);
```

## 读取布局结果

编译结果通过 occurrence 标识具体容器实例；不要只用公开 id 区分嵌套实例。先定位产物信封，再用对应 Schema 校验 value。下面只检查同次编译的结果，不重新求解。

```ts
import { compileToScene } from '@retikz/core';
import { GridLayoutDefinition, GridLayoutArtifactSchema, createGridLayout } from '@retikz/layout';
const output = compileToScene(
  {
    type: 'scene',
    version: 1,
    children: [createGridLayout({ columns: [{ kind: 'content', mode: 'natural' }], children: [] })],
  },
  { composites: [GridLayoutDefinition] },
);
const envelope = output.artifacts.find(
  item => item.kind === 'composite' && item.namespace === 'layout' && item.type === 'gridLayout',
);
if (envelope) {
  const result = GridLayoutArtifactSchema.parse(envelope.value);
  console.log(result.container, result.items);
}
```

`items[]` 增加 `column`、`row`、`columnSpan` 与 `rowSpan`。`columns[]` 和 `rows[]` 按物理起点排序，并记录连续 `index`、`start`、`size`、`sourceKind` 与 `implicit`。必填的 `spacing[]` 使用完整 content height 记录列间距，使用完整 content width 记录行间距；两种 band 的交叉区域会保留并按 x 后 y 的顺序稳定叠加。
