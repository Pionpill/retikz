title: FlexLayout
description: Express grow, shrink, wrap, and baselines in one-dimensional Box layout and arrange children during host-independent compilation.
---

`FlexLayout` arranges arbitrary graphical children along one main axis. It distributes free space, shrinks or wraps when space is tight, keeps fixed geometry at its real size, and lets text reflow against its allocated width.

## Usage

```tsx
import { Layout, Node } from '@retikz/react';
import { FlexLayout, LayoutItem } from '@retikz/layout-react';
```

```tsx
<Layout width={360} height={120}>
  <FlexLayout gap={8}>
    <LayoutItem kind="flex" itemKey="label" grow={1}>
      <Node position={[0, 0]} text="Label" />
    </LayoutItem>
    <LayoutItem kind="flex" itemKey="value" shrink={0}>
      <Node position={[0, 0]} text="42%" />
    </LayoutItem>
  </FlexLayout>
</Layout>
```

`itemKey` is the authored identity local to the layout container and never reads React's reserved `key`. Each `LayoutItem` accepts exactly one drawable child or one explicit `IRChild` through `ir`.

`gap` accepts either a number or a `{ column, row }` object. A number applies to both physical axes; the object sets column and row spacing independently, without changing field meaning when `direction` changes.

| Scenario         | Public entry                                                                                      |
| ---------------- | ------------------------------------------------------------------------------------------------- |
| React            | `FlexLayout`, `LayoutItem` (`@retikz/layout-react`)                                               |
| Vanilla          | `flexLayout`, `FlexLayoutVanillaAdapter` (`@retikz/layout-vanilla`)                               |
| Optional inspect | `InspectFlexLayout` (`@retikz/layout-react/inspect`), `inspectFlexLayout` (Vanilla)               |
| IR / persistence | `FlexLayoutSchema`, `createFlexLayout`, `IRFlexLayout`, `FlexLayoutDefinition` (`@retikz/layout`) |

## Examples

### Basic allocation

The three items keep authored paint order. The middle label receives remaining main-axis space, the side items do not shrink, and `gap.column` and `gap.row` always mean physical horizontal and vertical spacing respectively.

`direction` selects the main axis and traversal direction, while `wrap` decides whether lines form. Reverse modes change traversal and placement without changing `children`, item keys, or paint order.

### Controls

Switch the main axis, wrapping, and cross-axis alignment, then adjust item basis, grow, and shrink. The preview uses a fixed viewBox. Raising the basis or disabling wrapping makes negative free space and shrink directly observable.

### Overflow and clipping

A slot and the real allocation are distinct quantities. When fixed geometry refuses a smaller slot, `visible` keeps the complete visual output; `clip` changes only visibility, while the typed artifact preserves real bounds and the `clipped` state.

## How it works

<ComponentAlert
  type="tip"
  title="Optional for everyday use"
  description="Revisit this section when diagnosing text reflow, fixed-geometry overflow, or baseline behavior."
/>

FlexLayout first probes each child with `intrinsic.minimum` and `intrinsic.natural`, then probes again with an exact main slot after distribution freezes. Text can become taller at a narrower width; fixed geometry can keep allocation larger than its slot without triggering another main-axis pass.

Each line runs bounded grow/shrink independently. An item freezes when it reaches `min` or `max`, and remaining space is redistributed among unfrozen items. Only the selected result is replayed; discarded probes publish no primitives, resources, namespaces, or artifacts.

## API Reference

`FlexLayoutInput` is the factory authoring input. `IRFlexLayout` is the JSON-safe persisted form after defaults are applied.

React `FlexLayoutProps` mirrors the container fields below but changes `children` to direct `LayoutItem` elements. `FlexLayoutItemProps` renames JSON `key` to `itemKey` and requires exactly one of `children` or `ir`.

### Optional React inspection component

| Prop       | Type                                            | Default | Description                                                                             |
| ---------- | ----------------------------------------------- | ------- | --------------------------------------------------------------------------------------- |
| `inspect?` | `false` \| `true` \| `FlexLayoutInspectOptions` | `true`  | `InspectFlexLayout` requests this occurrence; `false` only cancels the current instance |

Base `FlexLayout` has no `inspect` prop. After installing the optional package, import `InspectFlexLayout` from `@retikz/layout-react/inspect`. Its object form controls `lines`, fixed `gaps`, and `distributedSpace` in addition to shared bounds, box spacing, overflow, and alignment guides. See [Runtime Reference](/library/layout/reference/runtime#layout-inspector) for every field and host or Scope rules.

### `FlexLayoutInput`

| Prop              | Type                                               | Default                       | Description                                                                               |
| ----------------- | -------------------------------------------------- | ----------------------------- | ----------------------------------------------------------------------------------------- |
| `size?`           | `LayoutSizeInput`                                  | `content` / `content`         | Per-axis allocation policy; `fill` requires finite parent space                           |
| `padding?`        | `number` \| `IRBoxSpacing`                         | `0`                           | Insets from the allocation box to the content box                                         |
| `overflow?`       | <ApiValues name="LayoutOverflow" />                | `'visible'`                   | `clip` creates one Scope clip at the container allocation                                 |
| `direction?`      | <ApiValues name="FlexLayoutDirection" />           | `'row'`                       | Main axis and forward or reverse traversal                                                |
| `wrap?`           | <ApiValues name="FlexLayoutWrap" />                | `'nowrap'`                    | One line, wrapping, or reversed cross placement                                           |
| `gap?`            | `number`<br />or `{ column: number; row: number }` | `0` → `{ column: 0, row: 0 }` | A number applies to both physical axes; the object sets column and row gaps independently |
| ↳ `column`        | `number`                                           | `0`                           | Physical horizontal gap when `gap` is an object                                           |
| ↳ `row`           | `number`                                           | `0`                           | Physical vertical gap when `gap` is an object                                             |
| `justifyContent?` | `FlexMainDistributionValue`                        | `'start'`                     | Main-axis free-space distribution within each line                                        |
| `alignItems?`     | <ApiValues name="LayoutAlignment" />               | `'stretch'`                   | Default cross alignment; column directions reject baseline                                |
| `alignContent?`   | <ApiValues name="LayoutDistribution" />            | `'start'`                     | Cross-axis free-space distribution between multiple lines                                 |
| `children?`       | `Array<FlexLayoutItemInput>`                       | `[]`                          | Authored items with keys unique within this container                                     |

### `FlexLayoutItemInput`

| Prop         | Type                                 | Default       | Description                                                                          |
| ------------ | ------------------------------------ | ------------- | ------------------------------------------------------------------------------------ |
| `kind`       | `'flex'`                             | —             | Item discriminator; use `LayoutItemKind.Flex`                                        |
| `key`        | `string`                             | —             | Stable non-empty authored identity within this container                             |
| `child`      | `IRChild`                            | —             | Any JSON-safe Core child participating in layout                                     |
| `margin?`    | `number` \| `IRBoxSpacing`           | `0`           | Spacing outside the slot and excluded from the child proposal                        |
| `basis?`     | `'content'` \| `number`              | `'content'`   | Natural main contribution or finite non-negative authored base slot                  |
| `grow?`      | `number`                             | `0`           | Finite non-negative factor for receiving positive free space                         |
| `shrink?`    | `number`                             | `1`           | Factor multiplied by unclamped basis when reclaiming negative free space             |
| `min?`       | `number`                             | child minimum | Explicit values replace automatic child minimum; refusal becomes allocation overflow |
| `max?`       | `number`                             | unbounded     | Authored hard maximum for the main slot                                              |
| `alignSelf?` | <ApiValues name="LayoutAlignment" /> | `alignItems`  | Overrides cross alignment for this item                                              |
