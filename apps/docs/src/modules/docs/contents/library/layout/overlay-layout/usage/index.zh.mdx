`OverlayLayout` 让多个子图形共享同一区域。对齐子项跟随容器对齐；定位子项用局部 `at` 和 `anchor` 放置徽标、标注框等浮层。`sizeParticipation` 决定子项是否影响容器尺寸，`zIndex` 只决定稳定绘制层级。

## 接入方式

安装见[快速开始](/library/layout/get-start)。容器直属元素必须使用匹配 kind 的 LayoutItem；一个子项负责一个可绘制 child。

```text
OverlayLayout
└── LayoutItem (kind="overlay")
    └── Node / OverlayLayout
```

JSON/IR 路径使用 `createOverlayLayout()` 与 `OverlayLayoutDefinition`；Vanilla 使用 `overlayLayout()` 与 `OverlayLayoutInputEmbedAdapter`。

| 场景        | 公开入口                                                                                                       |
| ----------- | -------------------------------------------------------------------------------------------------------------- |
| React       | `OverlayLayout`、`LayoutItem`（`@retikz/layout-react`）                                                        |
| Vanilla     | `overlayLayout`、`OverlayLayoutInputEmbedAdapter`（`@retikz/layout-vanilla`）                                  |
| 可选检查    | `InspectOverlayLayout`（`@retikz/layout-react/inspect`）、`inspectOverlayLayout`（Vanilla）                    |
| IR / 持久化 | `OverlayLayoutSchema`、`createOverlayLayout`、`IROverlayLayout`、`OverlayLayoutDefinition`（`@retikz/layout`） |

## 对齐与定位

| 模式         | 分配区域来源                                             | 常见用途                     |
| ------------ | -------------------------------------------------------- | ---------------------------- |
| `aligned`    | 内容区域扣除外边距后按对齐方式分配                       | 背景、居中内容、底部说明文字 |
| `positioned` | `at` 决定目标点，`anchor` 决定分配区域的哪一点贴到目标点 | 徽标、标注框、局部注释       |

## 容器的分配与对齐

所有子项共享同一个内容区。容器默认对齐适合大多数图层，单项可用自身对齐或局部目标点覆盖；定位和绘制先后是两个独立选择。

## 子项约束

每个子项使用一个 `child`，由容器决定它的空间与位置。`margin` 留在分配区域外围；`justifySelf` / `alignSelf` 只覆盖当前子项，省略时继承容器。

## 定位形式

| `kind`       | 字段                                 | 语义                                 |
| ------------ | ------------------------------------ | ------------------------------------ |
| `aligned`    | 无                                   | 使用容器与子项对齐                   |
| `positioned` | `at`、`anchor?`、`width?`、`height?` | 内容区域局部目标点与可选精确分配尺寸 |

React 中把可选 `key` 写成 `itemKey`，并用一个可绘制子元素或 `ir` 提供 `child`。省略 `itemKey` 时，自动身份只在内部产物中生成，不写回 Source IR。
