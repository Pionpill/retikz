当标签数量、内容尺寸或可用空间发生变化时，逐个维护坐标很容易失效。Layout 让你声明容器尺寸、间距、对齐和子项约束，再根据子图形的测量结果计算它们的位置与尺寸。

## 三种容器

| 容器          | 排版方式                         | 典型用途                   |
| ------------- | -------------------------------- | -------------------------- |
| FlexLayout    | 沿一个方向分配空间，可伸缩、换行 | 标签带、图例条目、线性注释 |
| GridLayout    | 用行列轨道分配二维区域，可跨行列 | 多面板、矩阵、结构化区域   |
| OverlayLayout | 在同一区域内对齐和叠放           | 徽标、浮层、局部注释       |

容器可以递归组合，例如先用 Flex 排列面板，再在面板内用 Grid 分区。布局负责排版，不决定图表数据含义，也不提供图关系的自动算法布局。

## 两种 Layout

`@retikz/react` 的 `Layout` 是承载和渲染整张图的根容器；`@retikz/layout-react` 的 `FlexLayout` 等组件是放在其中的排版容器。通常两者配合使用。

`LayoutItem` 为一个子图形声明布局约束。例如，在 Flex 中设置 `grow` 可以让该子项获得剩余空间。容器根据测量尺寸与约束求解，文字测量仍受字体及字体加载状态影响。

## 选择入口

- `@retikz/layout-react`：在 JSX 中组合容器与子项
- `@retikz/layout-vanilla`：用普通 TypeScript 输入声明布局，通过 adapter 接入 Vanilla
- `@retikz/layout`：布局数据校验、定义与宿主无关的求解能力

需要观察布局边界时可使用可选的检查能力；日常排版不需要先接入检查器。
