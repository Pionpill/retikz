`FlexLayout` 沿一个主轴排布任意子图形。它可以把剩余空间分给可伸展项、在空间不足时收缩或换行，同时让固定几何保持真实尺寸、让文本按分配宽度重新排版。

## 接入方式

安装见[快速开始](/library/layout/get-start)。容器直属元素必须使用匹配 kind 的 LayoutItem；一个子项负责一个可绘制 child。

```text
FlexLayout
└── LayoutItem (kind="flex")
    └── Node / FlexLayout
```

`itemKey` 可以省略；Layout 会在内部生成容器局部有效 key，且不会把它写回 Source IR。只有需要跨重排保持稳定身份时才显式传入 `itemKey`；它不读取 React 保留的 `key`。每个 `LayoutItem` 恰好接受一个可绘制子元素，或用 `ir` 显式传入一个 `IRChild`。

`gap` 可以写成数字，也可以写成 `{ column, row }` 对象。数字同时设置两个物理轴；对象允许分别设置列间距与行间距，且不随 `direction` 改变字段含义。

| 场景        | 公开入口                                                                                           |
| ----------- | -------------------------------------------------------------------------------------------------- |
| React       | `FlexLayout`、`LayoutItem`（`@retikz/layout-react`）                                               |
| Vanilla     | `flexLayout`、`FlexLayoutInputEmbedAdapter`（`@retikz/layout-vanilla`）                            |
| 可选检查    | `InspectFlexLayout`（`@retikz/layout-react/inspect`）、`inspectFlexLayout`（Vanilla）              |
| IR / 持久化 | `FlexLayoutSchema`、`createFlexLayout`、`IRFlexLayout`、`FlexLayoutDefinition`（`@retikz/layout`） |

## 分配一行空间

下面三个子项保持作者声明的绘制顺序。中间标签接收剩余主轴空间；两侧子项不参与收缩，`gap.column` 与 `gap.row` 始终分别表示物理水平方向和垂直方向的间距。

<ComponentPreview files="flex-layout-basic" size="sm" />

`direction` 决定主轴与遍历方向，`wrap` 决定是否形成多条布局行。反向模式只改变布局遍历和放置位置，不改变 `children`、子项 `key` 或绘制顺序。

`FlexLayoutInput` 是工厂函数接受的作者输入；`IRFlexLayout` 允许省略字段与简写。工厂保留原始写法，`FlexLayoutSchema.parse()` 则会补齐 schema 声明的静态默认值；编译期 resolver 复用这些默认值并展开简写。

React 的 `FlexLayoutProps` 对应下表容器字段，但把 `children` 改为直属 `LayoutItem`；`FlexLayoutItemProps` 把可选 JSON `key` 命名为 `itemKey`，并要求在 `children` 与 `ir` 中二选一。

## 容器的分配与对齐

先确定主轴方向和容器可用尺寸，再选择主轴剩余空间如何分布。`gap` 是固定间距，`justifyContent` 分配的是扣除子项与 gap 后的剩余空间；两者可以同时使用。

## 子项约束

`basis` 提供主轴基础尺寸，`grow` 和 `shrink` 决定空间有余或不足时如何调整，`min` / `max` 限定结果。先使用内容尺寸，确认需要固定比例后再加入权重。
