`FlexLayout` 沿一个主轴排布任意子图形。它可以把剩余空间分给可伸展项、在空间不足时收缩或换行，同时让固定几何保持真实尺寸、让文本按分配宽度重新排版。

## 接入方式

容器的 `children` 是一组子项，每项通过 `child` 承载图形。React 用 `FlexLayoutItem` 表达子项，Vanilla 与 IR 使用 `{ kind: 'flex', child: ... }`。下面先展示分配空间后的效果，四种接入代码则从两个内容尺寸的子项开始，说明最小组合关系。

<DocTab value="react-jsx" label="React + JSX">

React + JSX 中，`FlexLayout` 的直属子元素使用 `FlexLayoutItem`，每个子项承载一个可绘制内容：

```text
FlexLayout
└── FlexLayoutItem
    └── Node / FlexLayout
```

```tsx
import { Layout, Node } from '@retikz/react';
import { FlexLayout, FlexLayoutItem } from '@retikz/layout-react';

export const Example = () => (
  <Layout>
    <FlexLayout gap={12}>
      <FlexLayoutItem>
        <Node text="A" />
      </FlexLayoutItem>
      <FlexLayoutItem>
        <Node text="B" />
      </FlexLayoutItem>
    </FlexLayout>
  </Layout>
);
```

`itemKey` 可以省略；Layout 会在内部生成容器局部有效 key，且不会把它写回 Source IR。只有需要跨重排保持稳定身份时才显式传入 `itemKey`；它不读取 React 保留的 `key`。每个 `FlexLayoutItem` 恰好接受一个可绘制子元素，或用 `ir` 显式传入一个 `IRChild`。

## 设置方向、尺寸与间距

方向决定子项横着排还是竖着排，尺寸决定容器有多少空间，内边距和间距负责留白。以下都是容器属性。

| 属性              | 可用值                                                                | 解释                                                       |
| ----------------- | --------------------------------------------------------------------- | ---------------------------------------------------------- |
| `direction`       | `row`, `row-reverse`, `column`, `column-reverse`                      | 横向或纵向主轴；反向模式只改变放置方向，不改变绘制顺序     |
| `size.x / size.y` | `{ kind: "content" }`, `{ kind: "fixed", value }`, `{ kind: "fill" }` | 容器的物理宽、高：按内容求尺寸、固定尺寸或接收父级有限空间 |
| `padding`         | 非负数，或按 `x` / `y` / 四边配置的对象                               | 从容器四边留出内边距，剩余部分为内容区                     |
| `gap`             | 非负数，或 `{ column, row }` 非负间距对象                             | 相邻子项的固定间隔，在分配剩余空间前扣除                   |

在 demo 中切换方向和尺寸策略，再调整内边距与间距。`size.x` / `size.y` 始终是物理宽、高：改为纵向排列后，应调整 y 轴的可用空间。初次使用可让两轴按内容求尺寸；需要指定行宽时只固定 x 轴。`fill` 需要父级提供有限空间。

## 分配子项空间

子项先取得基础尺寸，再根据容器剩余空间伸展或收缩。以下属性设置在子项上。

| 属性     | 可用值                     | 解释                                                       |
| -------- | -------------------------- | ---------------------------------------------------------- |
| `basis`  | `content` 或非负数         | 子项的主轴基础尺寸；`content` 从内容测量取得               |
| `grow`   | 非负数                     | 子项分配剩余空间的权重；`0` 不参与伸展，不表示最终尺寸比例 |
| `shrink` | 非负数                     | 子项收缩权重；`0` 不收缩，实际权重还要乘以未约束基础尺寸   |
| `size.x` | `{ kind: "fixed", value }` | 容器的固定宽度，`value` 为非负数                           |

demo 中三个子项使用相同基础尺寸，并保留最小分配 32。减小基础尺寸，调整第一项的 `grow`，观察它如何分走余量；再增大基础尺寸或缩小容器，调整第二项的 `shrink`，观察收缩。第三项保持 `grow=1`、`shrink=1` 作为对照，固定几何不会自动缩放到槽位大小。

## 对齐容器与子项

对齐决定剩余空间放在哪里，以及子项在另一条轴上靠哪一边。容器默认值可以被单个子项覆盖。

| 属性             | 可用值                                                                         | 解释                                             |
| ---------------- | ------------------------------------------------------------------------------ | ------------------------------------------------ |
| `justifyContent` | `start`, `center`, `end`, `space-between`, `space-around`, `space-evenly`      | 容器属性：分布每行主轴上的剩余空间               |
| `alignItems`     | `start`, `center`, `end`, `stretch`, `first-baseline`, `last-baseline`         | 容器属性：默认交叉轴对齐；基线模式仅用于横向主轴 |
| `alignSelf`      | `start`, `center`, `end`, `stretch`, `first-baseline`, `last-baseline`；可省略 | 子项属性：覆盖 `alignItems`；省略时继承容器      |

demo 保持横向排列，子项不伸展。先改变主轴分布，再把默认交叉轴对齐从居中改为起点，最后调整第二项的单独覆盖。`gap` 始终保留固定间隔；若伸展已经耗尽余量，改变主轴分布可能没有效果。`stretch` 提供尺寸约束，不保证固定图形变形。
