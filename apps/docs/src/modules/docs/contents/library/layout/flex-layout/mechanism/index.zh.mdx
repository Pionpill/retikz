## 为什么重新测量不会反复改主轴

先用最小与自然测量建立约束，再冻结主轴 slot，最后用 exact 测量获取文字换行后的交叉轴尺寸。固定几何可以拒绝较小的 slot，此时以真实占用和溢出反映差异，不重新启动一轮主轴分配。图中两行沿用同一尺度，显示基础贡献如何成为最终分配。

<ComponentPreview files="allocation-figure" hideCode type="illustration" size="md" />

图中内容宽 200、gap 为 12、两个 basis 都为 40。剩余 108 按 grow=1:3 分配，得到 67 与 121；虚线始终标记同一容器边界。真实子图形随后才接收这两个 slot，主轴分配与绘制结果因此不能混为一个尺寸。

## 约束如何成为位置

FlexLayout 先用 `intrinsic.minimum` 与 `intrinsic.natural` 测量子图形，再在主轴分配区域冻结后使用 `exact` 重新测量。文本可以据此在较窄宽度下增加高度；固定几何也可以让真实占用超出父级分配区域，而不会触发第二轮主轴分配。

每条布局行独立执行有界伸展和收缩：子项命中 `min` 或 `max` 后冻结，剩余空间继续分给未冻结项。最终只回放被选中的测量候选；未选候选不会发布图元、资源、命名空间或产物。
