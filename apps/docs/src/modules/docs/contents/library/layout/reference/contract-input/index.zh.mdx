本页是 Layout 布局持久化输入的权威契约。React 属性与 Vanilla 构造器最终都会生成这里的规范 JSON；三个容器共享尺寸、内边距、溢出和子项基础语义，再分别增加弹性分配、二维轨道或叠加定位字段。

> 这里说明可保存和校验的输入结构。Definition、Core 编译与宿主接线见[运行时](/library/layout/reference/runtime)，求解后的可观察结果见[产物契约](/library/layout/reference/contract-artifact)。

## LayoutItem 联合

### LayoutItemSchema

<ZodSchema
  name="LayoutItemSchema"
  description="由 kind 判别的 FlexLayoutItem、GridLayoutItem 与 OverlayLayoutItem 闭合联合。"
/>

所有子项共享以下基础字段；具体容器页记录各自增加的分配字段。

| 字段      | 类型                            | 默认值 | 描述                                                   |
| --------- | ------------------------------- | ------ | ------------------------------------------------------ |
| `kind`    | `'flex' \| 'grid' \| 'overlay'` | —      | 选择拥有该子项的布局容器                               |
| `key`     | `string`                        | —      | 当前容器内唯一且非空、由作者声明的标识                 |
| `child`   | `IRChild`                       | —      | 参与布局、可 JSON 序列化的 Core 或已注册 Tier 2 子图形 |
| `margin?` | `number` \| `IRBoxSpacing`      | `0`    | 分配区域外围间距，不进入子图形的空间提案               |

React 中把 JSON 的 `key` 写成 `itemKey`，并通过一个可绘制子元素或 `ir` 提供 `child`。`LayoutItem` 只表达容器直属子项，不会单独生成图元。
