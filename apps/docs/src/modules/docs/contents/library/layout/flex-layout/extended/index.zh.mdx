本页在[基础用法](/library/layout/flex-layout/usage)之上组合约束、观察边界并检查布局结果。先调整一个变量，再对照分配区域和真实占用。

## 伸展、收缩与硬边界

容器主轴固定为 200、间距为 12，两个子项的 basis 都为 40，grow 分别为 1 和 3。扣除基础尺寸与间距后剩余 108，因此分得 27 和 81，最终 slot 为 67 和 121。这是分配尺寸，不保证固定几何会缩放到相同大小。

max 会让命中上限的子项冻结，剩余空间继续交给其它项。负剩余空间按 shrink × 未约束基础尺寸分摊；shrink=0 保留该项的基础分配。不要用 grow 控制绘制顺序。

## 换行与基线的边界

换行先分组，再对每行分配空间。justifyContent 调整行内主轴自由空间，alignContent 调整多行之间的交叉轴空间；只有一行或没有剩余空间时，不应期待它们产生同样效果。横向主轴可使用 first-baseline / last-baseline；纵向主轴的交叉轴为 x，不接受基线对齐。

## 交互比较

切换主轴、换行与交叉轴对齐，并调节子项的基础尺寸（`basis`）、伸展系数（`grow`）和收缩系数（`shrink`）。预览使用固定 `viewBox`；当基础尺寸增大或取消换行时，可以直接观察负剩余空间如何触发收缩。

### 溢出与裁切

父级分配区域（slot）与真实占用是两个量。固定几何拒绝较小的分配区域时，`visible` 保留完整视觉；`clip` 只改变可见区域，类型化产物仍保留真实边界与 `clipped` 状态。

基础 `FlexLayout` 没有 `inspect` 属性。安装可选包后，从 `@retikz/layout-react/inspect` 导入 `InspectFlexLayout`；对象形式在通用边界、盒模型间距、溢出和对齐参考线之外，还可分别控制 `lines`、固定 `gaps` 与 `distributedSpace`。完整字段和宿主 / Scope 规则见[运行时参考](/library/layout/reference/runtime#布局检查器)。

```tsx
import { Layout, Node } from '@retikz/react';
import { LayoutItem } from '@retikz/layout-react';
import { LayoutInspectLayout, InspectFlexLayout } from '@retikz/layout-react/inspect';
export const Inspected = () => (
  <Layout>
    <LayoutInspectLayout>
      <InspectFlexLayout gap={12} inspect={{ bounds: { content: true, slot: true } }}>
        <LayoutItem kind="flex">
          <Node position={[0, 0]} text="A" />
        </LayoutItem>
      </InspectFlexLayout>
    </LayoutInspectLayout>
  </Layout>
);
```

## 读取布局结果

编译结果通过 occurrence 标识具体容器实例；不要只用公开 id 区分嵌套实例。先定位产物信封，再用对应 Schema 校验 value。下面只检查同次编译的结果，不重新求解。

```ts
import { compileToScene } from '@retikz/core';
import { FlexLayoutDefinition, FlexLayoutArtifactSchema, createFlexLayout } from '@retikz/layout';
const output = compileToScene(
  { type: 'scene', version: 1, children: [createFlexLayout({ children: [] })] },
  { composites: [FlexLayoutDefinition] },
);
const envelope = output.artifacts.find(
  item => item.kind === 'composite' && item.namespace === 'layout' && item.type === 'flexLayout',
);
if (envelope) {
  const result = FlexLayoutArtifactSchema.parse(envelope.value);
  console.log(result.container, result.items);
}
```
