## 组合伸缩与尺寸边界

伸缩决定空间如何分配，尺寸边界决定每个子项最多和最少拿到多少空间。达到边界后，剩余调整由其他可伸缩子项承担。

| 属性              | 可用值                                                                | 解释                                                       |
| ----------------- | --------------------------------------------------------------------- | ---------------------------------------------------------- |
| `size.x / size.y` | `{ kind: "content" }`, `{ kind: "fixed", value }`, `{ kind: "fill" }` | 容器的物理宽、高：按内容求尺寸、固定尺寸或接收父级有限空间 |
| `basis`           | `content` 或非负数                                                    | 子项的主轴基础尺寸；`content` 从内容测量取得               |
| `grow`            | 非负数                                                                | 子项分配剩余空间的权重；`0` 不参与伸展，不表示最终尺寸比例 |
| `shrink`          | 非负数                                                                | 子项收缩权重；`0` 不收缩，实际权重还要乘以未约束基础尺寸   |
| `min / max`       | 可省略的非负数，`min ≤ max`                                           | 子项主轴槽位的硬下限与上限；不强迫固定图形缩小             |

demo 只调整第一项的伸缩和边界，第二项保持可伸缩。增大第一项的 `grow` 后降低 `max`，观察它何时停止增长；再缩小容器并调整 `min`，观察下限如何限制收缩。达到下限后，内容仍可能溢出。

## 换行与多行对齐

换行把放不下的子项分到多条布局行。每行内部的排列与多行整体的排列分别控制。

| 属性             | 可用值                                                                               | 解释                                             |
| ---------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------ |
| `wrap`           | `nowrap`, `wrap`, `wrap-reverse`                                                     | 不换行、换行或反向排列布局行；不改写子项声明顺序 |
| `basis`          | `content` 或非负数                                                                   | 子项的主轴基础尺寸；`content` 从内容测量取得     |
| `justifyContent` | `start`, `center`, `end`, `space-between`, `space-around`, `space-evenly`            | 分配每一行主轴上的剩余空间                       |
| `alignContent`   | `start`, `center`, `end`, `stretch`, `space-between`, `space-around`, `space-evenly` | 分布多行整体的交叉轴空间；需要多行且交叉轴有余量 |
| `size.x`         | `{ kind: "fixed", value }`                                                           | 控制横向可用空间，影响一行能容纳多少子项         |

demo 固定横向主轴。切换换行方式并调整基础尺寸或容器宽度，先形成至少两行；再分别改变 `alignContent` 和 `justifyContent`，比较行与行之间、每行子项之间的变化。`wrap-reverse` 反转行的交叉轴放置方向，主轴反向则由 `direction` 决定。

## 基线对齐

字号或行数不同时，边框居中不一定能让文字排齐。基线对齐让子项按首行或末行文字的参考线对齐。

| 属性                   | 可用值                                               | 解释                                                     |
| ---------------------- | ---------------------------------------------------- | -------------------------------------------------------- |
| `alignItems`           | 本节比较 `center`, `first-baseline`, `last-baseline` | 容器的默认对齐；首基线或末基线模式仅用于横向主轴         |
| `alignSelf`            | 省略，或同类对齐值                                   | 覆盖单个子项的对齐；省略时跟随容器                       |
| `Node.style.font.size` | `number`                                             | 节点字号，本例分别控制两项，用于比较不同文字高度下的基线 |

demo 的第一项显式分成两行，第二项随宽度排版。调整两项字号，比较居中、首基线与末基线；第二项选择跟随容器时才继承默认对齐。没有提供对应参考线的子图形会回退到边缘对齐。纵向主轴应使用普通边缘对齐。

## 处理溢出与裁切

内容放不下时，可以保留超出的部分，也可以将它隐藏。裁切只影响可见内容，不改变空间分配。

| 属性                            | 可用值                     | 解释                                                             |
| ------------------------------- | -------------------------- | ---------------------------------------------------------------- |
| `overflow`                      | `visible`, `clip`          | 保留超出容器的内容，或在容器分配区域裁切；不重新求解布局         |
| `size.x`                        | `{ kind: "fixed", value }` | 容器固定宽度，决定裁切区域的宽度                                 |
| `basis / min / max`             | `number`                   | 子项基础尺寸和边界；本例由同一控件设置为相同非负值，固定槽位宽度 |
| `Node.layout.minimumSize.width` | `number`                   | 节点自身的最小宽度，可大于槽位；非负数                           |

在 demo 中缩小容器或增大节点最小宽度，让节点超出边界；再切换 `visible` 与 `clip`，比较可见部分。调整基础尺寸时，槽位宽度会变化，但不强迫节点缩小。若希望内容真正放得下，应调整尺寸、换行或子项约束；只在需要隐藏外部内容时使用裁切。
