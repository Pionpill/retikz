`FlexLayout` arranges arbitrary graphical children along one main axis. It distributes free space, shrinks or wraps when space is tight, keeps fixed geometry at its real size, and lets text reflow against its allocated width.

## Using this topic

See [Quick start](/library/layout/get-start) for installation. Direct children must use LayoutItem with a matching kind; each item owns one drawable child.

```text
FlexLayout
└── LayoutItem (kind="flex")
    └── Node / FlexLayout
```

`itemKey` may be omitted. Layout creates a container-local effective key internally without writing it back to Source IR. Pass `itemKey` only when identity must remain stable across reordering; it never reads React's reserved `key`. Each `LayoutItem` accepts exactly one drawable child or one explicit `IRChild` through `ir`.

`gap` accepts either a number or a `{ column, row }` object. A number applies to both physical axes; the object sets column and row spacing independently, without changing field meaning when `direction` changes.

| Scenario         | Public entry                                                                                      |
| ---------------- | ------------------------------------------------------------------------------------------------- |
| React            | `FlexLayout`, `LayoutItem` (`@retikz/layout-react`)                                               |
| Vanilla          | `flexLayout`, `FlexLayoutInputEmbedAdapter` (`@retikz/layout-vanilla`)                            |
| Optional inspect | `InspectFlexLayout` (`@retikz/layout-react/inspect`), `inspectFlexLayout` (Vanilla)               |
| IR / persistence | `FlexLayoutSchema`, `createFlexLayout`, `IRFlexLayout`, `FlexLayoutDefinition` (`@retikz/layout`) |

## Allocating a row

The three items keep authored paint order. The middle label receives remaining main-axis space, the side items do not shrink, and `gap.column` and `gap.row` always mean physical horizontal and vertical spacing respectively.

<ComponentPreview files="flex-layout-basic" size="sm" />

`direction` selects the main axis and traversal direction, while `wrap` decides whether lines form. Reverse modes change traversal and placement without changing `children`, item keys, or paint order.

`FlexLayoutInput` is the factory authoring input; `IRFlexLayout` permits omissions and shorthand. Factories preserve authored values, while `FlexLayoutSchema.parse()` materializes schema-declared static defaults. Compilation resolution reuses those defaults and expands shorthand.

React `FlexLayoutProps` mirrors the container fields below but changes `children` to direct `LayoutItem` elements. `FlexLayoutItemProps` renames optional JSON `key` to `itemKey` and requires exactly one of `children` or `ir`.

## Container allocation and alignment

Choose the main axis and available size first. `gap` reserves fixed spacing; `justifyContent` distributes space remaining after items and gaps. They can be combined.

## Item constraints

`basis` sets the main-axis basis, `grow` and `shrink` distribute surplus or deficit, and `min` / `max` bound the result. Start from content sizing and add weights when proportional allocation is needed.
