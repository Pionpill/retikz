This page presents three authoring paths for the same horizontal container. React and Vanilla suit code-first authoring; persisted IR suits layouts restored from a database, file, or `localStorage`.

## React

<PackageManagerInstall packages="@retikz/layout-react @retikz/react react react-dom" />

`FlexLayout` and its direct `LayoutItem` children describe the container and ordered items. The component contributes the Layout family Definitions locally to the current React `Layout`.

```tsx
import { Layout, Node } from '@retikz/react';
import { FlexLayout, LayoutItem } from '@retikz/layout-react';

<Layout width={320} height={120}>
  <FlexLayout size={{ x: { kind: 'fixed', value: 280 }, y: { kind: 'fixed', value: 72 } }} gap={8} padding={8}>
    <LayoutItem kind="flex" itemKey="label" grow={1}>
      <Node position={[0, 0]} text="Label" />
    </LayoutItem>
    <LayoutItem kind="flex" itemKey="value" shrink={0}>
      <Node position={[0, 0]} text="42%" />
    </LayoutItem>
  </FlexLayout>
</Layout>;
```

## Vanilla

<PackageManagerInstall packages="@retikz/layout-vanilla @retikz/vanilla" />

`flexLayout()` creates a plain-spec embed. `FlexLayoutVanillaAdapter` contributes the same Layout family while normalizing the figure. Use `LayoutVanillaAdapters` when the host wants the three-layout convenience catalog.

```ts
import { flexLayout, FlexLayoutVanillaAdapter } from '@retikz/layout-vanilla';
import { figure, mountSvg, node } from '@retikz/vanilla';

const input = figure({
  children: [
    flexLayout('row', {
      size: { x: { kind: 'fixed', value: 280 }, y: { kind: 'fixed', value: 72 } },
      gap: 8,
      padding: 8,
      children: [
        { kind: 'flex', key: 'label', grow: 1, child: node({ text: 'Label' }) },
        { kind: 'flex', key: 'value', shrink: 0, child: node({ text: '42%' }) },
      ],
    }),
  ],
});

const container = document.querySelector('#diagram');
if (container === null) throw new Error('Missing #diagram container');

mountSvg(container, input, { adapters: [FlexLayoutVanillaAdapter], output: { width: 320, height: 120 } });
```

## Load persisted JSON

<PackageManagerInstall packages="@retikz/layout @retikz/core @retikz/vanilla" />

Persist a complete `IRFlexLayout`, not only its authoring input. The schema identifies `namespace: 'layout'` and `type: 'flexLayout'`; the function-bearing Definition must be injected by the host when loading the JSON.

```ts
import { SceneSchema } from '@retikz/core';
import { createFlexLayout, FlexLayoutDefinition, FlexLayoutSchema } from '@retikz/layout';
import { mountSvg } from '@retikz/vanilla';

const raw = JSON.stringify(
  createFlexLayout({
    size: { x: { kind: 'fixed', value: 280 }, y: { kind: 'fixed', value: 72 } },
    gap: 8,
    padding: 8,
    children: [],
  }),
);
const storedLayout = FlexLayoutSchema.parse(JSON.parse(raw));
const scene = SceneSchema.parse({ type: 'scene', version: 1, children: [storedLayout] });

const container = document.querySelector('#diagram');
if (container === null) throw new Error('Missing #diagram container');

mountSvg(container, scene, {
  compile: { composites: [FlexLayoutDefinition] },
  output: { width: 320, height: 120 },
});
```

Without `FlexLayoutDefinition`, Core reports `COMPOSITE_NOT_REGISTERED` and skips that child; other registered composites and native Core children can continue compiling.
