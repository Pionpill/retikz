---
title: 契约 - 产物
description: 查询 Layout 布局容器的类型化编译产物、边界语义、溢出状态和容器专属求解结果。
---

布局产物记录同一次 Core 编译中已经求解的可观察结果。它描述父级分配区域、子图形真实占用、视觉包络与裁切结果，但不保存空间提案、测量候选、回放令牌、求解器对象或子图形私有 IR。

> Core 产物信封负责实例出现位置（`occurrence`）、命名空间（`namespace`）与复合组件类型（`type`）；本页的 Layout schema 只解析信封中的 `value`。如何装载能力、执行编译和定位产物见[运行时](/library/layout/reference/runtime)。

## 通用字段

### LayoutArtifactSchema

<ZodSchema name="LayoutArtifactSchema" description="由 kind 判别的三个 Layout 类型化布局产物联合。" />

每个具体产物的 `container` 都包含：

| 字段               | 类型                         | 描述                                            |
| ------------------ | ---------------------------- | ----------------------------------------------- |
| `allocationBounds` | `LayoutArtifactRect`         | 容器最终的分配矩形                              |
| `contentBounds`    | `LayoutArtifactRect`         | 扣除内边距后的内容矩形                          |
| `visualBounds`     | `LayoutArtifactRect`         | 所有已平移子项视觉边界的并集                    |
| `visibleBounds`    | `LayoutArtifactRect \| null` | 应用溢出策略后仍可见的并集；无正面积时为 `null` |

每个 `items[]` 条目共享：

| 字段               | 类型                              | 描述                                                   |
| ------------------ | --------------------------------- | ------------------------------------------------------ |
| `key`              | `string`                          | 对应作者声明的子项标识                                 |
| `sourceIndex`      | `number`                          | 连续且从零开始的声明顺序                               |
| `marginBounds`     | `LayoutArtifactRect`              | 包含已求解外边距的完整父级分配区域                     |
| `slotBounds`       | `LayoutArtifactRect`              | 不含外边距、由父级分配的区域                           |
| `allocationBounds` | `LayoutArtifactRect`              | 子图形接受或拒绝分配区域后的真实布局占用               |
| `visualBounds`     | `LayoutArtifactRect`              | 包含描边或标签等效果的保守视觉包络                     |
| `visibleBounds`    | `LayoutArtifactRect \| null`      | 裁切后仍可见的视觉区域                                 |
| `translation`      | `{ x: number, y: number }`        | 回放前应用的容器局部平移                               |
| `overflow`         | `{ allocation, visual, clipped }` | 双轴真实占用、视觉包络与裁切状态                       |
| `alignmentGuide?`  | `{ name, position, fallback }`    | 实际用于放置的基线参考线，或基线不可用时的边缘回退结果 |

`slotBounds`、`allocationBounds` 与 `visualBounds` 不能互换：固定几何可以拒绝父级分配的区域，而描边或标签还可能让视觉包络继续扩大。

### LayoutSpacingArtifactSchema

<ZodSchema
  name="LayoutSpacingArtifactSchema"
  description="FlexLayout 与 GridLayout 产物共用的固定 gap 或分布式自由空间片段。"
  descriptions={{
    kind: '间距片段的语义判别字段。',
    axis: '间距片段的物理主轴。',
    bounds: '当前容器 allocation 坐标中的最终矩形。',
    'bounds.x': '间距矩形的水平原点。',
    'bounds.y': '间距矩形的垂直原点。',
    'bounds.width': '间距矩形的非负宽度；x 主轴时必须为正。',
    'bounds.height': '间距矩形的非负高度；y 主轴时必须为正。',
  }}
/>

主轴长度必须为正，正交轴长度可以为零。`axis: 'x'` 使用 `bounds.x/width` 作为主坐标与长度；`axis: 'y'` 使用 `bounds.y/height`。数组按 x → y、主坐标、正交坐标、gap → distributed 和生成顺序稳定排列。

相邻 item 或 track 的物理间隔同时包含 gap 与 distribution 时，固定 gap 在间隔中居中，剩余正空间平分在两侧。leading / trailing 只记录内容边缘与首末 outer box 或 track 之间的正空间；负 free space、重叠与零长度不会生成 distributed segment。
