Logic nodes are foundational graph elements that can be placed directly in a diagram. `GraphNode` uses `role` for terminal, stage, decision, and junction semantics while keeping a stable `id`; `GraphConnector` links those authored identities. Use them independently or combine them into a complete local logic flow.

## Responsibilities

| Member     | Expresses                                          | Useful for                                |
| ---------- | -------------------------------------------------- | ----------------------------------------- |
| `GraphNode` | `role`: terminal, stage, decision, or junction     | Starts, ends, steps, decisions, and joins |
| GraphConnector  | Explicit relationships between authored identities | Flows, dependencies, and labeled links    |
