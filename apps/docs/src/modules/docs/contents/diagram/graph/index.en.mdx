Graph is the unified entry point for reusable elements in the Diagram domain. Its first set covers common logic links: `GraphFrame` owns a reusable shell and regions; `GraphNode` uses `role` for terminals, stages, decisions, and junctions; `GraphConnector` expresses relationships.

Graph owns each element's diagram meaning and drawing contract. It does not own a `GraphModel`, automatic layout, obstacle avoidance, hit testing, or interaction state. Place units with Core positions or Layout containers, then use stable `id` values for explicit targets.

## Responsibilities at a glance

| Member       | Owns                                                          | Does not own                            |
| ------------ | ------------------------------------------------------------- | --------------------------------------- |
| `GraphFrame` | A shell, header, ordered sections, and reusable region layout | Graph topology or automatic placement   |
| `GraphNode` | Neutral shape, content, sizing, and semantic role             | Domain-specific state machines          |
| `GraphConnector`  | One Core Path route and an optional final-step label          | Automatic routing or obstacle avoidance |

All members lower to existing Core primitives and can be authored through React, direct JSON/IR, or Vanilla embeds. Definitions are injected per figure; they never enter persisted JSON.
