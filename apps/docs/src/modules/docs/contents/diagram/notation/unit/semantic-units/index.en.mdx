title: Base units

---

Base units are lightweight semantic IR values that retain the `notation` namespace. Terminal, Stage, Decision, and Junction remain distinguishable in persisted data for tools, LLMs, and future Graph presentations. At compile time, each unit uses its own Definition to lower one-to-one into a same-id Core `Node`

## Usage

```tsx
import { Layout, Text } from '@retikz/react';
import { Decision, Junction, Stage, Terminal } from '@retikz/notation-react';
```

```tsx
<Layout width={440} height={180}>
  <Terminal id="start" position={[20, 70]}>
    Start
  </Terminal>
  <Stage id="step" position={[130, 70]}>
    Process
  </Stage>
  <Decision id="check" position={[250, 70]}>
    <Text>Ready?</Text>
  </Decision>
  <Junction id="join" position={[380, 80]} />
</Layout>
```

String children become Node text, and `<Text>` works as it does with Core `Node`. Applicable Node props such as `fill`, `padding`, `minimumSize`, and `position` pass through, while the unit owns its `namespace`, semantic `type`, and fixed `shape`

| Unit       | Fixed shape                    | Logic responsibility               | Defaults                                          |
| ---------- | ------------------------------ | ---------------------------------- | ------------------------------------------------- |
| `Terminal` | Capsule (rounded rectangle)    | Start or end of a flow             | minimum `48 × 24`, padding `{ x: 12, y: 6 }`      |
| `Stage`    | Rounded rectangle, radius `8`  | Process or action in a flow        | padding `8`                                       |
| `Decision` | Flattened diamond, ratio `1.8` | Condition or branch                | padding `{ x: 3, y: 2 }`                          |
| `Junction` | Circle                         | Fork, merge, or continuation point | minimum `8 × 8`, padding `0`, fill `currentColor` |

Direct IR uses the matching factory and explicitly injects each used Definition through Core compile options:

```ts
import { compileToScene } from '@retikz/core';
import { createStage, StageDefinition } from '@retikz/notation';

const stage = createStage({ id: 'step', position: [0, 0], text: 'Process' });
// stage.namespace === 'notation'; stage.type === 'stage'
const scene = compileToScene({ version: 1, type: 'scene', children: [stage] }, { composites: [StageDefinition] });
```

A Vanilla builder returns an embed instead of prematurely erasing the semantic identity into a Core Node. Its adapter creates a same-id canonical `IRStage` and contributes `StageDefinition`:

```ts
import { StageVanillaAdapter, stage } from '@retikz/notation-vanilla';

const step = stage('step', { position: [0, 0], text: 'Process' });
const adapters = [StageVanillaAdapter];
```

## Semantic boundary

Base units own only their persisted notation identity, fixed shape, and defaults. They do not own a graph store, automatic layout, obstacle avoidance, interaction, or domain recipes. Core continues to own Node layout, style, theme, targets, compilation, and Scene output
