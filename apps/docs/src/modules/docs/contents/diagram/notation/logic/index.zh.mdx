---
title: 逻辑单元
description: 使用语义单元表达逻辑对象，以连接器表达关系，并用标注补充局部说明。
---

逻辑单元是一组可以直接放进图中的基础图式元素。语义单元承担逻辑职责并提供稳定的 `id`；Connector 连接这些 authored identity；Callout 相对已有 target 放置解释。三者可以独立使用，也可以组合成完整的局部逻辑链路。

## 职责一览

| 成员      | 表达什么                              | 适合场景                       |
| --------- | ------------------------------------- | ------------------------------ |
| 语义单元  | Terminal、Stage、Decision 与 Junction | 起止、步骤、判断与汇合         |
| Connector | authored identity 之间的显式关系      | 流向、依赖与带 label 的连接    |
| Callout   | 相对已有 target 的说明与可选 leader   | 注释、解释与不进入主链路的信息 |
