逻辑节点是保留 `notation` namespace 的轻量语义 IR。Terminal、Stage、Decision 和 Junction 在持久化数据中仍可被工具、LLM 与未来 Graph presentation 明确识别；编译时，每个单元通过自己的 Definition 一对一下沉为同 id 的 Core `Node`

## 用法

```tsx
import { Layout, Text } from '@retikz/react';
import { Decision, Junction, Stage, Terminal } from '@retikz/notation-react';
```

```tsx
<Layout width={440} height={180}>
  <Terminal id="start" position={[20, 70]}>
    Start
  </Terminal>
  <Stage id="step" position={[130, 70]}>
    Process
  </Stage>
  <Decision id="check" position={[250, 70]}>
    <Text>Ready?</Text>
  </Decision>
  <Junction id="join" position={[380, 80]} />
</Layout>
```

字符串 children 会成为 Node 文本，也可以像 Core `Node` 一样使用 `<Text>`。适用的 Node props（例如 `color`、`fill`、`padding`、`minimumSize` 和 `position`）继续透传，但 `namespace`、语义 `type` 和固定 `shape` 由逻辑节点拥有

| 单元       | 固定 shape           | 逻辑职责           | 默认几何                                     |
| ---------- | -------------------- | ------------------ | -------------------------------------------- |
| `Terminal` | capsule（圆角矩形）  | 流程起点或终点     | minimum `48 × 24`，padding `{ x: 12, y: 6 }` |
| `Stage`    | 圆角矩形，radius `8` | 流程中的处理或动作 | padding `8`                                  |
| `Decision` | 扁菱形，宽高比 `1.8` | 条件或分支         | padding `{ x: 3, y: 2 }`                     |
| `Junction` | circle               | 分叉、汇合或延续点 | minimum `8 × 8`，padding `0`                 |

## 例子

### LogicNodeVariant

逻辑节点使用 Notation 自有的五值 `LogicNodeVariant`，不消费 Core 或 Viz 的全局 Theme Style。`variant` 是单个逻辑节点的显式基线；省略时使用最近 `LogicFrame.logicNodeVariant`，没有 Frame 作用域时使用 `default`

| variant     | 文本           | 边框             | 背景             |
| ----------- | -------------- | ---------------- | ---------------- |
| `default`   | `currentColor` | `currentColor`   | `none`           |
| `primary`   | `contrast`     | `currentColor`   | `currentColor`   |
| `secondary` | `currentColor` | `none`           | 主要色预合成 10% |
| `outline`   | `currentColor` | 主要色预合成 60% | `none`           |
| `vibrant`   | `currentColor` | `currentColor`   | 主要色预合成 15% |

`secondary` 不带边框。10% / 15% / 60% 是在 Light 的 `#ffffff` 或 Dark 的 `#000000` 上预合成的颜色，不会生成 renderer opacity。`primary` 的文本使用 Core `contrast`，根据填充选择黑色或白色。逻辑节点的 `color` 是主要色；省略时 Light 为 `#000000`、Dark 为 `#ffffff`

显式 `textColor`、`stroke`、`fill` 按字段覆盖 variant 基线，显式 `opacity`、`fillOpacity`、`strokeOpacity` 也原样保留。需要预合成或计算对比色的 variant 若主要色无法静态解析，会明确报错；Notation 不读取 Core categorical palette，也不把 variant 写入 Core Scene 或 renderer

### LogicFrame 继承

`LogicFrame.logicNodeVariant` 为 header、sections、嵌套 `LogicFrame` 和 Core `Scope` 子树中的逻辑节点设置默认值。嵌套 Frame 的值会建立新的作用域，逻辑节点显式 `variant` 优先；`variant="default"` 可以重置外层值。Frame 外壳、divider、Connector 和兄弟分支不受影响

```tsx
import { LogicFrame, LogicFrameSection, Stage } from '@retikz/notation-react';

<LogicFrame id="order" logicNodeVariant="secondary">
  <LogicFrameSection sectionKey="input">
    <Stage id="load" position={[0, 0]} />
  </LogicFrameSection>
  <LogicFrameSection sectionKey="important">
    <Stage id="validate" position={[0, 0]} variant="primary" />
  </LogicFrameSection>
</LogicFrame>;
```

### Direct、React 与 Vanilla 接线

三种入口共享同一份 Notation IR 和 variant lowering 逻辑。直接 IR 使用 package assembly；React 与 Vanilla adapter 不需要传入 ThemeStyle 或额外的 variant registry

```ts
import { compileToScene } from '@retikz/core';
import { createNotationDefinitions, createStage } from '@retikz/notation';

const stage = createStage({
  id: 'step',
  position: [0, 0],
  text: 'Process',
  color: '#2563eb',
  variant: 'primary',
});
const scene = compileToScene(
  { version: 1, type: 'scene', children: [stage] },
  { composites: createNotationDefinitions() },
);
```

## 技术原理

逻辑节点拥有可持久化的图式身份、固定 shape、主要色解释和 `LogicNodeVariant`。它不拥有 graph store、自动布局、障碍规避、交互或领域 recipe。Core 负责 Node 布局、target、编译和 Scene 输出；Notation 只在 lowering 时把有效 variant 投影为普通 Node paint

## API 参考

| API                                        | 包                         | 作用                                                                |
| ------------------------------------------ | -------------------------- | ------------------------------------------------------------------- |
| `variant?: LogicNodeVariantValue`          | 四个逻辑节点组件与 IR      | 设置单个逻辑节点的视觉变体；省略时继承 Frame 默认值或使用 `default` |
| `logicNodeVariant?: LogicNodeVariantValue` | `LogicFrame`               | 设置后代逻辑节点的默认变体；嵌套 Frame 建立新的作用域               |
| `color?: string`                           | 四个逻辑节点组件与 IR      | 设置主要色；省略时 Light 为 `#000000`、Dark 为 `#ffffff`            |
| `createNotationDefinitions()`              | `@retikz/notation`         | 为直接 IR 创建完整的 Notation Definition 集合                       |
| `createNotationReactAdapters()`            | `@retikz/notation-react`   | 创建供 React InputScene 归一化使用的六个 adapter                    |
| `createNotationVanillaAdapters()`          | `@retikz/notation-vanilla` | 创建供 Vanilla runtime 归一化使用的六个 adapter                     |
