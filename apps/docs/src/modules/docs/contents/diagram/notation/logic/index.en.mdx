title: Logic Units

Logic units are foundational notation elements that can be placed directly in a diagram. Semantic units carry logical responsibilities and stable `id` values; Connector links those authored identities; Callout places an explanation relative to an existing target. Use each independently or combine them into a complete local logic flow.

## Responsibilities

| Member         | Expresses                                          | Useful for                                |
| -------------- | -------------------------------------------------- | ----------------------------------------- |
| Semantic units | Terminal, Stage, Decision, and Junction            | Starts, ends, steps, decisions, and joins |
| Connector      | Explicit relationships between authored identities | Flows, dependencies, and labeled links    |
| Callout        | Target-relative content with an optional leader    | Notes, explanations, and off-flow details |
