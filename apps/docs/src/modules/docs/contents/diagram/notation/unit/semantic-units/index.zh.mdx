title: 语义单元
description: Terminal、Stage、Decision 和 Junction 是带逻辑职责说明的 Core Node sugar
---

语义单元是 Core `Node` 的轻量封装：输出始终是 `type: 'node'`。每个组件只固定自己的 shape，并通过 Schema `describe` 说明逻辑职责，便于阅读和 LLM 感知

## 用法

```tsx
import { Layout, Node, Scope, Text } from '@retikz/react';
import { Decision, Junction, Stage, Terminal } from '@retikz/notation-react';
```

```tsx
<Layout width={440} height={180}>
  <Terminal id="start" position={[20, 70]}>
    Start
  </Terminal>
  <Stage id="step" position={[130, 70]}>
    Process
  </Stage>
  <Decision id="check" position={[250, 70]}>
    <Text>Ready?</Text>
  </Decision>
  <Junction id="join" position={[380, 80]} />
</Layout>
```

字符串 children 会成为 Node 的文本；也可以像 Core `Node` 一样使用 `<Text>`。其它 Node props（例如 `fill`、`padding`、`minimumSize` 和 `position`）继续透传，但 `shape` 由语义单元固定

| 单元       | 固定 shape           | 逻辑职责           | 默认样式                                          |
| ---------- | -------------------- | ------------------ | ------------------------------------------------- |
| `Terminal` | capsule（圆角矩形）  | 流程起点或终点     | minimum `48 × 24`，padding `{ x: 12, y: 6 }`      |
| `Stage`    | 圆角矩形，radius `8` | 流程中的处理或动作 | padding `8`                                       |
| `Decision` | 扁菱形，宽高比 `1.8` | 条件或分支         | padding `{ x: 3, y: 2 }`                          |
| `Junction` | circle               | 分叉、汇合或延续点 | minimum `8 × 8`，padding `0`，fill `currentColor` |

直接 IR 使用 `createTerminal`、`createStage`、`createDecision` 或 `createJunction`，结果可直接放入 Core scene，不需要注入 Definition

```ts
import { createStage } from '@retikz/notation';

const stage = createStage({ id: 'step', position: [0, 0], text: 'Process' });
```

Vanilla builder 同样直接返回 canonical Node

```ts
import { stage } from '@retikz/notation-vanilla';

const step = stage('step', { position: [0, 0], text: 'Process' });
```

## 语义边界

语义单元不拥有 graph store、自动布局、障碍规避、交互或领域 recipe。需要布局容器时使用 `LogicFrame`，需要关系时使用 `Connector`，需要旁注时使用 `Callout`
