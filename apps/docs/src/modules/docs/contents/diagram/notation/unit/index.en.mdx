Logic nodes are foundational notation elements that can be placed directly in a diagram. Terminal, Stage, Decision, and Junction carry logical responsibilities and stable `id` values; Connector links those authored identities. Use each independently or combine them into a complete local logic flow.

## Responsibilities

| Member     | Expresses                                          | Useful for                                |
| ---------- | -------------------------------------------------- | ----------------------------------------- |
| Logic Node | Terminal, Stage, Decision, and Junction            | Starts, ends, steps, decisions, and joins |
| Connector  | Explicit relationships between authored identities | Flows, dependencies, and labeled links    |
