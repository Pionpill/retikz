---
title: Composite Units
description: Use reusable composite notation elements to organize multiple children, regions, and local structures.
---

Composite units organize multiple children into one reusable notation element. Each composite owns its composition meaning and internal structure while continuing to reuse Core primitives and Standard layouts instead of introducing separate geometry or layout mechanisms.

`LogicFrame` currently provides a logic shell with a header and ordered sections. Future compositions that reuse several foundational units also belong in this group.
