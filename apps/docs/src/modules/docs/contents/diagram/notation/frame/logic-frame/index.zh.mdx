title: LogicFrame

`LogicFrame` 是分组逻辑节点的通用外壳。它接受一个可选 header 与零个或多个带 key 的 section。外壳复用 Layout 的 FlexLayout 引擎完成区域测量、padding、gap、放置、裁剪与 replay，不另造布局系统。

## 用法

```tsx
import { Layout, Node } from '@retikz/react';
import { LogicFrame, LogicFrameHeader, LogicFrameSection } from '@retikz/notation-react';
```

```tsx
<Layout width={360} height={180}>
  <LogicFrame id="order" logicNodeVariant="secondary">
    <LogicFrameHeader>
      <Node position={[0, 0]} text="Order" />
    </LogicFrameHeader>
    <LogicFrameSection sectionKey="input">
      <Node position={[0, 0]} text="Input" />
    </LogicFrameSection>
    <LogicFrameSection sectionKey="output">
      <Node position={[0, 0]} text="Output" />
    </LogicFrameSection>
  </LogicFrame>
</Layout>
```

marker 必须是 `LogicFrame` 的直接子节点，且每个 marker 只拥有一个可绘制 child。脱离 JSX 时，可以传 JSON-safe 的 `header` 与 `sections` props。

`logicNodeVariant` 只为后代逻辑节点提供默认变体，不改变 Frame 外壳或 divider。嵌套 Frame 的值覆盖外层作用域，单元显式 `variant` 优先；`variant="default"` 可以重置继承值。完整的五种 recipe 见[逻辑节点](/diagram/notation/unit/logic-node#logicnodevariant)

## 示例

<ComponentPreview files="logic-frame-basic" size="md" />

直接 IR 使用同一套 canonical child 契约，并显式注入 Definition：

```ts
import { createLogicFrame, LogicFrameDefinition } from '@retikz/notation';

const block = createLogicFrame({
  id: 'order',
  header: { child: { type: 'node', position: [0, 0], text: 'Order' } },
  sections: [{ key: 'body', child: { type: 'node', position: [0, 0], text: 'Body' } }],
});
const compile = { composites: [LogicFrameDefinition] };
```

Vanilla 使用 embed id 编写，adapter 会在内部派生 canonical `id`：

```ts
import { LogicFrameInputEmbedAdapter, logicFrame } from '@retikz/notation-vanilla';

const embed = logicFrame('order', {
  sections: [{ key: 'body', child: { type: 'node', position: [0, 0], text: 'Body' } }],
});
const adapters = [LogicFrameInputEmbedAdapter];
```

同一外壳可以容纳 Core child、Notation 逻辑节点或其它嵌套 composite。逻辑节点保留自己的 Notation IR，因此直接 IR 中包含 `Stage` 时需要同时注入 `LogicFrameDefinition` 与 `StageDefinition`；React 组件和 Vanilla adapter 会为实际使用的元素自动贡献对应 Definition。

## 技术原理

<ComponentAlert
  type="tip"
  title="日常使用可跳过"
  description="只有排查区域测量、divider 几何或编译 artifact 时才需要阅读本节"
/>

### 复用 canonical FlexLayout

编译器为 header 与 sections 创建合成的 column FlexLayout 区域，再把 Flex artifact 投影到 block artifact。它复用 canonical Flex 的 proposal、size、gap、放置、裁剪与 replay 语义，不另造布局引擎。区域 child 仍是 JSON-safe IR，并通过已注入的 Definition 进入同一 Core compile 主链。

### Divider artifact 投影

外壳与 divider 输出为 Core 视觉图元。divider 矩形记录在 `dividerVisualBounds` 中，是视觉投影，不是 layout child，也不是第二套 authored graph。注入 Definition 后，区域 child 可以是 `Node`、`Path`、其它 composite 或嵌套 block。

## API 参考

| 字段                | 类型                                     | 默认值                                               | 说明                                         |
| ------------------- | ---------------------------------------- | ---------------------------------------------------- | -------------------------------------------- |
| `id`                | `string`                                 | —                                                    | 供 target 使用的稳定 authored block identity |
| `logicNodeVariant?` | `LogicNodeVariantValue`                  | 省略                                                 | 后代逻辑节点的默认变体                       |
| `header?`           | `{ child: IRChild; padding? }`           | 省略                                                 | 一个可选 header 区域                         |
| `sections`          | `Array<{ key, role?, child, padding? }>` | `[]`                                                 | 有序且 key 唯一的区域                        |
| `size?`             | `LayoutSizeInput`                        | `{ x: { kind: 'content' }, y: { kind: 'content' } }` | 外层 allocation 策略                         |
| `padding?`          | `number` 或 `IRBoxSpacing`               | `8`                                                  | 区域默认内边距                               |
| `rowGap?`           | `number`                                 | `0`                                                  | 相邻区域之间的空白                           |
| `overflow?`         | `'visible'` 或 `'clip'`                  | `'visible'`                                          | 外层内容可见性策略                           |
| `appearance?`       | `LogicFrameAppearanceInput`              | 中性 shell、圆角 `8`、divider 开启、`zIndex: 0`      | 外壳、divider、圆角与 stacking 外观          |

section key 为空或重复时会 fail-loud。Connector 接受 section target 语法，但当前会在 lowering 前拒绝 section target；请使用 whole block target。
