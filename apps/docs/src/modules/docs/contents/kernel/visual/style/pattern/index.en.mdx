## Choose a motif

| shape | Motif                                        | Useful options                                  |
| ----- | -------------------------------------------- | ----------------------------------------------- |
| lines | Horizontal lines; rotation produces hatching | lineWidth, dashes, lineStyleCycle               |
| dots  | Circles                                      | lineWidth sets the radius; defaults to size / 5 |
| grid  | Horizontal and vertical lines                | horizontalStyle, verticalStyle                  |

<ComponentPreview files="pattern-builtins" size="sm" />

`size` is the base spacing in drawing units and defaults to 8. `rotation` rotates the entire pattern in degrees. Omitted `background` is transparent. Motif line styles and the geometry outline are configured separately.

## Directional grids and line cycles

Directional grid settings override the base line style for the corresponding direction.

<ComponentPreview files="pattern-directional-grid" size="sm" />

For lines, `lineStyleCycle` repeats styles across adjacent lines. `period` is an integer from 2 through 512. Override indices start at zero, must be unique, and must be less than period. The final tile size is size × period, while spacing remains size. Grid and dots do not consume this cycle.

<ComponentPreview files="pattern-line-cycle" size="sm" />

Dash selection follows `dashPattern` → `dashed` → `dotted`. Compare motif settings with the unchanged geometry outline below.

## Component integration

| Component   | Entry                                                               |
| ----------- | ------------------------------------------------------------------- |
| Scope       | `style.fill / stroke`, `defaults.node/path.style`, or `frame.style` |
| Node        | `style.fill / stroke`                                               |
| Path / Draw | `style.fill / stroke`                                               |

### Scope propagation and overrides

Scope `style.fill` and `style.stroke` cascade to Node and Path. Use `defaults.node.style` or `defaults.path.style` for one kind only. In the demo, the left Node and closed Path inherit a line pattern, while the right Node overrides it with dots. `fill: 'none'` disables fill; `frame.style` decorates the enclosing frame and does not cascade.

<ComponentPreview files="pattern-integration" size="sm" />

### Drawing surfaces of Node and Path

The same pattern can fill or stroke a Node shape and can also paint a Path. The demo compares a circular Node with a closed triangular Path: Path `fill` needs an enclosed area, while `stroke` follows the outline; a two-point line has no visible fill area.
