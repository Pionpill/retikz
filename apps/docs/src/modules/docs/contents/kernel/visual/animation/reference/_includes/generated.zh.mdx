轨道以 `property` 区分关键帧值类型，TypeScript 类型与运行时校验保持一致：

- `opacity`、`fillOpacity`、`strokeOpacity`、`pathDraw`：0..1
- `strokeWidth`：非负数值；`dashOffset`、位移、旋转与缩放：有限数值
- `fill`、`stroke`：非空颜色字符串，不接受渐变或图像资源对象
- Scene 根的 `viewBox`：`[x, y, width, height]` 数值四元组，宽高必须为正数

属性名使用 `AnimationProperty`，缓动预设使用 `AnimationEasing`。未知名称在 schema 入口被拒绝。

#### <ApiSourceLink label={"AnimationProperty"} path={"packages/kernel/core/src/schemas/scene/animation.ts"} startLine={21}>AnimationProperty</ApiSourceLink>

`viewBox` 仅在 scene 根合法（镜头），元素级 viewBox track 由 compile / render 拒；
