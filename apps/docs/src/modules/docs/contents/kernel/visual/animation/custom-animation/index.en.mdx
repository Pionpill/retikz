## Custom easing

Register a name-to-cubic-bezier tuple mapping through Layout.easings, then reference the name in a preset or track easing.

<ComponentPreview files="custom-easing" size="sm" controls={{ animation: true }} />

Vanilla uses animation.easings. Easing maps time progress; it does not add animatable properties.

## Custom property channels

Import AnimationPropertyDefinition from `@retikz/render/animation` and provide interpolate and applyCanvas. Register the name-to-definition mapping through Layout.animationProperties; Vanilla uses canvas.animationProperties.

The blur channel interpolates a radius and updates the Canvas context before the current primitive is drawn.

<ComponentPreview files="custom-property" size="md" controls={{ animation: true }} />

## Support boundary

Custom property values must be JSON values interpreted by the definition. applyCanvas runs within save / restore and does not change layout. This contract provides a Canvas application function, not automatic SVG property animation. Unsupported or unregistered channels are not portable across backends.
