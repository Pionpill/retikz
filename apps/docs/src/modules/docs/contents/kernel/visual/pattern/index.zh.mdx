---
title: 图案
description: 用重复的线条、圆点、网格或自定义纹理填充图形与描边区域
---

图案适合用纹理区分区域，例如给流程图中的一组节点加斜线填充，或给几何示意中的路径区域加网格。它是一种填充与描边样式：Node、Path 决定轮廓，图案决定轮廓内重复出现的纹理。

## 整体认识

下面通过 Scope 为子图设置共同图案。观察节点与路径区域中的重复纹理，以及子节点显式设置填充后对继承样式的覆盖：图案配置可以共享，图形轮廓仍由各个组件负责。

<ComponentPreview files="/kernel/visual/pattern/integration/pattern-integration" size="sm" />

Scope 通过 `style` 传递样式，通过显式 `frame` 绘制包络外框。Node 将图案用于形状区域，Path 将它用于路径形成的区域；同样的图案也能用于描边区域。重复的是纹理单元，不是节点或路径本身。

## 选择与边界

先从内置 `lines`、`dots`、`grid` 开始，用颜色、间距和旋转满足常见纹理需求；需要新的重复单元时，再定义自定义图案。内置与自定义图案共用同一套填充、描边入口。

图案不会改变几何轮廓、布局或命中区域。需要改变节点外形时查看[节点形状](/kernel/components/node/shape)，需要绘制新的区域时使用 [Path](/kernel/components/path/usage)。对仅有两个点的线段，应给描边设置图案，填充不会产生可见面积。
