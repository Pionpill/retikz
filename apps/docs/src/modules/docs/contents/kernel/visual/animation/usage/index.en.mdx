title: Basic usage
description: Animation describes property changes with keyframes. Built-in presets return the same track data used by handwritten animation.
---

Core provides `fadeIn`, `scaleIn`, `slideIn`, and `drawOn`, plus the `colorShift`, `cameraTo`, `loop`, and `stagger` utilities. Import `grow`, `growUp`, `pulse`, `spin`, `flash`, `blink`, and `wiggle` from `@retikz/standard`; see [Standard animation presets](/library/standard/animation). Both layers return the same track data without additional registration.

## Using this topic

All four forms render the same result. Vanilla requires `<div id="diagram"></div>` in the page; call `view.dispose()` before removing the host.

```tsx
import { Layout, Node } from '@retikz/react';
import type { FC } from 'react';

const Demo: FC = () => (
  <Layout>
    <Node
      position={[0, 0]}
      layout={{ minimumSize: 80 }}
      animations={[
        {
          property: 'opacity',
          keyframes: [
            { at: 0, value: 0 },
            { at: 1, value: 1 },
          ],
          duration: 800,
        },
      ]}
    />
  </Layout>
);
export default Demo;
```

## Entrance and emphasis

| Purpose              | Core presets / utilities | Optional Standard effects         |
| -------------------- | ------------------------ | --------------------------------- |
| Opacity entrance     | fadeIn                   | —                                 |
| Scale entrance       | scaleIn                  | grow, growUp                      |
| Translation entrance | slideIn                  | —                                 |
| Stroke reveal        | drawOn                   | —                                 |
| State emphasis       | colorShift, loop         | pulse, spin, flash, blink, wiggle |

<ComponentPreview files="entrance" size="md" controls={{ animation: true }} />

A Node with text or rotation attaches animations to its wrapper group, so its text moves with it. Use Scope to animate several independent elements together; see [Component integration](/kernel/visual/animation/integration). Consult API signatures for preset options. Duration and delay use milliseconds.

## Write a track

One track describes one property. Keyframe at values range from 0 to 1 in nondecreasing order; value is absolute. Duration must be positive. Easing can be set on the track or a keyframe, where it applies to the segment leading to the next frame.
