## Choose a preset

`none`, `sm`, `md`, `lg`, `xl`, and `2xl` cover common projection scales. `none` explicitly disables a Scope default. See [Custom shadows](/kernel/visual/style/custom-shadow) for object configuration.

## Component integration

| Component   | Entry                                         |
| ----------- | --------------------------------------------- |
| Scope       | `defaults.node.style` / `defaults.path.style` |
| Node        | `style.shadow`                                |
| Path / Draw | `style.shadow`                                |

### Scope defaults

`Scope.style` does not accept `shadow`; defaults pass it to descendant primary geometry. In the demo, both the Node and closed Path inherit the Scope projection, while the Node on the right explicitly disables it with `none`.

<ComponentPreview files="shadow-integration" size="sm" />

### Node primary geometry

Node text, labels, and pins are separate outputs and do not receive the shape shadow. Adjust the controls below to change only the blue rectangle's offset, blur, colour, and opacity; its top label remains crisp.

<ComponentPreview files="shadow-node" size="lg" />

### Shared Path and arrow boundary

A Path and its arrow belong to the same primary geometry, so they share one projection; the path label remains independent. This demo uses the same control values to compare the effect boundary with Node.
