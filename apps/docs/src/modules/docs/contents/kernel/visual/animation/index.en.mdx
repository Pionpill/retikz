Animation introduces elements, emphasizes states, and guides attention through a drawing. Keyframes describe property values over time, components determine the target, and playback controls decide when to start, pause, or seek. Static exports also need a deliberate frame selection.

> **Note:** The site follows your system's animation preference by default. If animations are disabled or reduced motion is enabled, examples will not play their animations. To view them, open the “…” menu on the right of the header and choose “Animation playback → On”.

Core provides `fadeIn`, `scaleIn`, `slideIn`, and `drawOn`, plus the `colorShift`, `cameraTo`, `loop`, and `stagger` utilities. Import `grow`, `growUp`, `pulse`, `spin`, `flash`, `blink`, and `wiggle` from `@retikz/standard`; see [Standard animation presets](/library/standard/animation). Both layers return the same track data without additional registration.

## The overall picture

The example places nodes, a path, and text inside one Scope, then moves them together with a vertical translation track. During playback, observe their relative positions: animation changes the group's presentation without recalculating its internal layout.

Keyframes specify the change, Scope specifies which elements change together, and the preview controls manage time. Use a Layout `viewBox` track to move the viewing window instead of the elements. Add triggers and playback handles when interaction should start the animation.

## Choosing an approach and its boundaries

Start with presets for common entrances or emphasis. Write keyframes when you need precise timing and values. Use Scope to animate several independent elements together; consult component integration for the target boundaries of individual Node and Path animations.

Tracks are serializable data, while playback handles and custom functions belong to the runtime. Animation does not rerun automatic layout. Static output and reduced-motion policies also need consideration. A custom Canvas property channel does not automatically provide equivalent SVG support; check backend capabilities before extending it.
