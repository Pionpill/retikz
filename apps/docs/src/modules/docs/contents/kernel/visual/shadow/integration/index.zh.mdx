| 组件        | 接入方式                                  |
| ----------- | ----------------------------------------- |
| Scope       | defaults.node.style / defaults.path.style |
| Node        | style.shadow                              |
| Path / Draw | style.shadow                              |

## Scope

Scope.style 不接受 shadow。用 defaults.node.style.shadow 和 defaults.path.style.shadow 分别提供默认值；子元素通过 style.shadow 覆盖，none 关闭阴影。

<ComponentPreview files="shadow-integration" size="sm" />

## Node

Node 的阴影只作用于主形状，节点文字、标签和引脚是独立输出，不随主形状投影。调整偏移与模糊，观察主体投影移动，而文字和顶部标签保持清晰。

示例显式使用蓝色投影和较高不透明度，便于在明暗背景下观察；这不是阴影预设的默认颜色。

<ComponentPreview files="shadow-node" size="lg" />

## Path

Path 的主路径与端点箭头属于同一效果边界，路径标签独立输出。调整偏移或将模糊设为 0，可以观察线条与箭头的投影；关闭阴影时，路径与标签的位置不变。示例沿用上方的蓝色投影以突出边界。
