## 定义与注册

从 `@retikz/core` 导入 definePattern。定义提供 name、可选 defaultSize 和 emit；emit 接收已经解析的尺寸、颜色与线型，返回局部坐标中的 MarkerPrimitive。

下面定义 cross，将它传给 Layout.extensions.patterns，并通过 fill.shape 引用同一名称。

<ComponentPreview files="custom-pattern-basic" size="sm" />

React 使用 `extensions={{ patterns: [cross] }}`；Vanilla 在 mount / renderToSvgString 的 `compile: { patterns: [cross] }` 中注入。Core 编译时使用 CompileOptions.patterns。定义属于宿主配置，不能把 emit 函数写进 IR。

## 控制重复周期

返回几何 iterable 时周期等于 context.size。若基础间距与最终重复周期不同，返回 `{ tileSize, motif }`；tileSize 必须是有限正数。可用 context.round 保持精度一致。

<ComponentPreview files="custom-pattern-size" size="md" controlPanelDefaultSize={50} />

## 错误与限制

名称必须在当前编译 registry 中可用。重复单元使用结构化 MarkerPrimitive，不接受 DOM、函数或任意文本图元。emit 的异常和非法输出会在编译边界报告；不要依赖静默回退。background、方向样式和周期样式由定义按需要消费，收到参数并不意味着编译器会自动替自定义图案绘制它们。
