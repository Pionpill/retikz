## 接入方式

四种写法绘制相同结果。Vanilla 需要页面已有 `<div id="diagram"></div>`；移除容器前调用 `view.dispose()`。

<ComponentPreview files="shadow-basic" size="xs" hideCode />

<DocTabs defaultValue="react-jsx">
<DocTab value="react-jsx" label="React + JSX">

```tsx
import { Layout, Node } from '@retikz/react';
import type { FC } from 'react';

const Demo: FC = () => (
  <Layout>
    <Node position={[0, 0]} layout={{ minimumSize: 80 }} style={{ fill: 'steelblue', shadow: 'md' }} />
  </Layout>
);
export default Demo;
```

</DocTab>
<DocTab value="react-ir" label="React + IR">

```tsx
import type { IRScene } from '@retikz/core';
import { Layout } from '@retikz/react';
import type { FC } from 'react';

const ir: IRScene = {
  version: 1,
  type: 'scene',
  children: [
    { type: 'node', position: [0, 0], layout: { minimumSize: 80 }, style: { fill: 'steelblue', shadow: 'md' } },
  ],
};
const Demo: FC = () => <Layout ir={ir} />;
export default Demo;
```

</DocTab>
<DocTab value="vanilla-api" label="Vanilla API">

```tsx
import { node, scene } from '@retikz/vanilla';
import { mount } from '@retikz/vanilla/dom';

const input = scene({
  children: [node({ position: [0, 0], layout: { minimumSize: 80 }, style: { fill: 'steelblue', shadow: 'md' } })],
});
const view = mount(document.getElementById('diagram')!, input);
```

## 精确设置投影

对象可用 `{ preset: 'md', blur: 6 }` 覆盖预设，或显式提供 offsetX 与 offsetY。没有 preset 时两个偏移都必须提供。blur 为非负数；屏幕坐标中 offsetY 为正时向下。opacity 乘到解析后阴影颜色的透明度上。

<ComponentPreview files="shadow-object" size="sm" />

`shadow: 'none'` 关闭继承的阴影。阴影不改变节点连接面；固定 viewBox 过小时仍会裁掉投影，需预留输出空间。
