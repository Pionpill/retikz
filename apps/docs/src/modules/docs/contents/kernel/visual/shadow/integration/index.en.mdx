## Scope

Scope.style does not accept shadow. Supply defaults.node.style.shadow and defaults.path.style.shadow separately; children override with style.shadow, and none disables the effect.

<ComponentPreview files="shadow-integration" size="sm" />

## Node

A Node shadow applies only to its primary shape. Text, labels, and pins are separate outputs. Adjust offset and blur: the shape shadow moves while the text and top label remain crisp.

This example explicitly uses a blue shadow with higher opacity for visibility on light and dark backgrounds; this is not the preset's default color.

<ComponentPreview files="shadow-node" size="lg" />

## Path

Path geometry and endpoint arrows share the effect boundary, while the path label is a separate output. Change the offset or set blur to 0 to inspect both the line and arrow shadows. Disabling the shadow leaves the path and label positions unchanged. This example uses the same explicit blue shadow as above.
