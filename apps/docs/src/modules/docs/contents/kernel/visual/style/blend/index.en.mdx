## Choose a mode

Multiply commonly darkens overlapping colors; screen combines lighter colors. The demo places multiply on the left and screen on the right, with both overlap regions visible for comparison.

<ComponentPreview files="blend-modes" size="sm" />

`zIndex` and declaration order determine what is already beneath an element. White, black, and transparent backgrounds can produce different results.

## Parameter playground

Change the mode and inspect the overlap. Each element is composited separately; the setting does not create an isolated group layer.

## Component integration

| Component   | Entry                                         |
| ----------- | --------------------------------------------- |
| Scope       | `defaults.node.style` / `defaults.path.style` |
| Node        | `style.blendMode`                             |
| Path / Draw | `style.blendMode`                             |

### Scope default modes

Blending does not apply to Scope itself. Scope defaults only pass a mode to each descendant, whose primary geometry then composites with the backdrop available at draw time; they do not create one group layer. The demo compares Nodes and Paths inheriting `multiply`, then shows a child restoring ordinary source-over drawing with `normal`.

<ComponentPreview files="blend-integration" size="sm" />

### Node primary-shape blending

The demo compares `normal` and `multiply` over the same orange backdrop. Only the blue rectangle's primary shape composites; Node text and its top label do not inherit the setting. zIndex and declaration order alter the available backdrop, so they can change the result of the same mode.

<ComponentPreview files="blend-node" size="sm" />

### Path and arrow blending

A Path and its arrow use the same mode and composite together, while the path label remains separate. The `normal` and `multiply` comparison below makes the colour change visible only where the arrow crosses the orange backdrop.
