---

| 组件        | 接入方式                                  |
| ----------- | ----------------------------------------- |
| Scope       | defaults.node.style / defaults.path.style |
| Node        | style.blendMode                           |
| Path / Draw | style.blendMode                           |

## Scope

混合效果不作用于 Scope 本身。Scope 在这里仅负责通过 `defaults.node.style.blendMode` 和 `defaults.path.style.blendMode` 向下层 Node、Path 传递默认混合模式，实际混合由各个子图元在绘制时分别完成，不会将整个 Scope 作为一个图层统一混合。

`Scope.style` 不接受 `blendMode`。子元素可以通过自己的 `style.blendMode` 覆盖默认值，设置为 `normal` 即恢复普通覆盖合成。

## Node

Node 通过 `style.blendMode` 控制主形状的混合，文字、标签与引脚不自动继承主形状的效果。下面保持橙色背景与蓝色节点不变：左侧为 normal，右侧为 multiply。观察右侧重叠区域变暗，而节点文字与独立标签仍按各自样式绘制。

<ComponentPreview files="blend-node" size="sm" />

## Path

Path 通过 `style.blendMode` 控制主路径及端点箭头的混合，路径标签独立输出。下面左侧为 normal，右侧为 multiply；蓝色路径进入橙色背景后，线条与箭头一起参与混合，标签仍保持独立样式。

<ComponentPreview files="blend-path" size="sm" />

改变 zIndex 或声明顺序可能改变绘制时已有的背景，因此也会改变混合结果。
