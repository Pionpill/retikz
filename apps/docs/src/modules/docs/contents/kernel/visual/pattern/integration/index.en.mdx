## Scope

Scope.style.fill / stroke can supply both Node and Path. Use defaults.node.style or defaults.path.style to target one family. Explicit child fill / stroke overrides inherited paint; fill: 'none' disables filling.

<ComponentPreview files="pattern-integration" size="sm" />

### Independent frame

Set `frame.style.fill` to decorate the group envelope without cascading paint to children. Unlike the cascading fill above, the frame stays beneath all content and its spacing does not change layout or anchors.

<ComponentPreview files="/kernel/components/scope/usage/scope-frame" size="sm" />

See [Scope usage](/kernel/components/scope/usage#envelope-frame) for shape, clipping, and empty-scope behavior.

## Node and Path

Node paints its shape with style.fill; text has its own styling. Path fills the enclosed area; use cycle to close it explicitly. A two-point line has no visible area to fill. A patterned stroke paints the stroke area rather than repeating the path geometry.
