## 接入方式

四种写法绘制相同结果。Vanilla 需要页面已有 `<div id="diagram"></div>`；移除容器前调用 `view.dispose()`。

<ComponentPreview files="blend-basic" size="xs" hideCode />

<DocTabs defaultValue="react-jsx">
<DocTab value="react-jsx" label="React + JSX">

```tsx
import { Layout, Node } from '@retikz/react';
import type { FC } from 'react';

const Demo: FC = () => (
  <Layout>
    <Node position={[25, 0]} layout={{ minimumSize: 80 }} style={{ fill: 'dodgerblue' }} />
    <Node position={[0, 0]} layout={{ minimumSize: 80 }} style={{ fill: 'darkorange', blendMode: 'multiply' }} />
  </Layout>
);
export default Demo;
```

</DocTab>
<DocTab value="react-ir" label="React + IR">

```tsx
import type { IRScene } from '@retikz/core';
import { Layout } from '@retikz/react';
import type { FC } from 'react';

const ir: IRScene = {
  version: 1,
  type: 'scene',
  children: [
    { type: 'node', position: [25, 0], layout: { minimumSize: 80 }, style: { fill: 'dodgerblue' } },
    {
      type: 'node',
      position: [0, 0],
      layout: { minimumSize: 80 },
      style: { fill: 'darkorange', blendMode: 'multiply' },
    },
  ],
};
const Demo: FC = () => <Layout ir={ir} />;
export default Demo;
```

</DocTab>
<DocTab value="vanilla-api" label="Vanilla API">

```tsx
import { node, scene } from '@retikz/vanilla';
import { mount } from '@retikz/vanilla/dom';

const input = scene({
  children: [
    node({ position: [25, 0], layout: { minimumSize: 80 }, style: { fill: 'dodgerblue' } }),
    node({ position: [0, 0], layout: { minimumSize: 80 }, style: { fill: 'darkorange', blendMode: 'multiply' } }),
  ],
});
const view = mount(document.getElementById('diagram')!, input);
```

</DocTab>

## 选择模式

multiply 常用于让重叠部分变暗，screen 常用于叠加亮色。下面左侧为 multiply，右侧为 screen，保留各自的重叠区域以便比较。

<ComponentPreview files="blend-modes" size="sm" />

`zIndex` 和声明顺序决定下方已经画了什么。白色、黑色和透明背景可能产生很不同的结果，不能脱离背景单独判断一个模式。
