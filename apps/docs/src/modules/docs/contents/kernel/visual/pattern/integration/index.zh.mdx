| 组件        | 接入方式                                                   |
| ----------- | ---------------------------------------------------------- |
| Scope       | style.fill / stroke；defaults.node/path.style；frame.style |
| Node        | style.fill / stroke                                        |
| Path / Draw | style.fill / stroke                                        |

## Scope

Scope.style.fill / stroke 可同时传给 Node 与 Path；只影响某类图元时使用 defaults.node.style 或 defaults.path.style。子元素显式 fill / stroke 覆盖继承值，关闭填充可写 fill: 'none'。

<ComponentPreview files="pattern-integration" size="sm" />

### 独立外框

把图案放入 `frame.style.fill` 可装饰整组包络，子图元不会继承它。与上面的级联填充不同，外框位于所有内容下面，间距也不改变布局或锚点。

<ComponentPreview files="/kernel/components/scope/usage/scope-frame" size="sm" />

外框的轮廓、裁剪和空组行为见 [Scope 基础用法](/kernel/components/scope/usage#包络外框)。

## Node 与 Path

Node 的 shape 接收 style.fill，文字使用自己的文字样式。Path 的 style.fill 填充路径区域，建议用 cycle 显式闭合；仅两点构成的线段没有可见面积。style.stroke 的图案沿描边区域绘制，不是让路径自身重复。
