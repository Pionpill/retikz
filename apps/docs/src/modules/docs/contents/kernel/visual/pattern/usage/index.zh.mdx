## 接入方式

以下以 Node 为例，四种写法绘制相同结果。Path 与 Scope 也支持图案，具体用法见[组件对接](/kernel/visual/pattern/integration)。Vanilla 需要页面已有 `<div id="diagram"></div>`；移除容器前调用 `view.dispose()`。

<DocTabs defaultValue="react-jsx">
<DocTab value="react-jsx" label="React + JSX">

```tsx
import { Layout, Node } from '@retikz/react';
import type { FC } from 'react';

const Demo: FC = () => (
  <Layout>
    <Node
      position={[0, 0]}
      layout={{ minimumSize: 80 }}
      style={{ fill: { kind: 'pattern', shape: 'lines', color: 'steelblue', size: 10 } }}
    />
  </Layout>
);
export default Demo;
```

<DocTab value="react-ir" label="React + IR">

```tsx
import type { IRScene } from '@retikz/core';
import { Layout } from '@retikz/react';
import type { FC } from 'react';

const ir: IRScene = {
  version: 1,
  type: 'scene',
  children: [
    {
      type: 'node',
      position: [0, 0],
      layout: { minimumSize: 80 },
      style: { fill: { kind: 'pattern', shape: 'lines', color: 'steelblue', size: 10 } },
    },
  ],
};
const Demo: FC = () => <Layout ir={ir} />;
export default Demo;
```

## 选择重复单元

| shape | 图案                        | 常用配置                                |
| ----- | --------------------------- | --------------------------------------- |
| lines | 水平线；rotation 可变为斜线 | lineWidth、虚线、lineStyleCycle         |
| dots  | 圆点                        | lineWidth 指定点半径；省略时为 size / 5 |
| grid  | 横线与竖线                  | horizontalStyle、verticalStyle          |

<ComponentPreview files="pattern-builtins" size="sm" />

`size` 是基础间距，单位与图形坐标一致，默认 8；`rotation` 以度旋转整个图案。`background` 省略时透明。图案线型与外轮廓的线型分别配置，不会互相替代。

## 网格与周期线条

网格的方向配置在顶层线型上覆盖，只改变相应方向。

<ComponentPreview files="pattern-directional-grid" size="sm" />

lines 的 `lineStyleCycle` 按相邻线条循环：`period` 为 2–512 的整数，覆盖项的 `index` 从 0 开始、不可重复且必须小于 period。最终重复单元边长为 size × period，线条间距仍为 size。grid 和 dots 不消费此周期配置。

<ComponentPreview files="pattern-line-cycle" size="sm" />

虚线选择优先级为 `dashPattern` → `dashed` → `dotted`。调整下面参数观察重复单元与轮廓的区别。
