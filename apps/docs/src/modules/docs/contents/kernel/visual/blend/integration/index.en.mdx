| Component   | Entry                                     |
| ----------- | ----------------------------------------- |
| Scope       | defaults.node.style / defaults.path.style |
| Node        | style.blendMode                           |
| Path / Draw | style.blendMode                           |

## Scope

Blending does not apply to Scope itself. Here, Scope only passes default blend modes to descendant Node and Path elements through `defaults.node.style.blendMode` and `defaults.path.style.blendMode`. Each child primitive blends separately when drawn; the entire Scope is not blended as a single layer.

`Scope.style` does not accept `blendMode`. Children can override the default through their own `style.blendMode`; setting it to `normal` restores source-over compositing.

## Node

Node applies `style.blendMode` to its primary shape. Text, labels, and pins do not automatically inherit that effect. Both examples keep the same orange backdrop and blue node: normal on the left, multiply on the right. The right overlap darkens while node text and the independent label keep their own styles.

<ComponentPreview files="blend-node" size="sm" />

## Path

Path applies `style.blendMode` to its geometry and endpoint arrows, while path labels remain separate outputs. The left uses normal and the right uses multiply. Both the blue line and its arrow blend where they enter the orange backdrop; the label retains its independent style.

<ComponentPreview files="blend-path" size="sm" />

Changing zIndex or declaration order can change the existing backdrop at draw time and therefore the blend result.
