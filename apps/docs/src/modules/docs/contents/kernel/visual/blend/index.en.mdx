Blending communicates overlaps and color relationships, such as a blue node intersecting an orange path. The element supplies the foreground color, previously drawn content supplies the backdrop, and the blend mode determines how they combine.

## The overall picture

The left node and path inherit `multiply`, producing a blended overlap. The right node overrides the mode with `normal`, compositing against the blue backdrop using ordinary opacity. Compare the overlapping areas rather than only the unobstructed colors.

Scope shares defaults for Node and Path here; it does not establish an isolated layer. Each primary geometry combines with the existing backdrop in sequence, so opacity, background color, and drawing order all affect the result.

## Choosing an approach and its boundaries

Use `normal` for ordinary compositing. Try `multiply` for darker overlaps and `screen` for lighter ones. Compare on the actual background before adjusting opacity; a mode name does not specify a fixed output color.

Blending creates no intersection geometry and changes no layout. Use [patterns](/kernel/visual/pattern/usage) for repeating textures and [shadows](/kernel/visual/shadow/usage) for offset projections. Scope defaults do not provide layer isolation or whole-group offscreen compositing.
