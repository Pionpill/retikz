Core IR stores declarative animation data only: property names, keyframes, timing, and triggers. Playback state, event callbacks, and interpolation execution remain in the renderer runtime, keeping the full schema serializable.

## AnimationTrackSchema

<ZodSchema name="AnimationTrackSchema" />

Tracks discriminate keyframe values by `property`, keeping TypeScript types and runtime validation aligned:

- `opacity`, `fillOpacity`, `strokeOpacity`, and `pathDraw`: values from 0 to 1
- `strokeWidth`: nonnegative numbers; `dashOffset`, translation, rotation, and scale: finite numbers
- `fill` and `stroke`: nonempty color strings, excluding gradient and image resource objects
- Scene-root `viewBox`: a numeric `[x, y, width, height]` tuple with positive width and height

Property names use `AnimationProperty`; easing presets use `AnimationEasing`. Unknown names are rejected by the schema.
