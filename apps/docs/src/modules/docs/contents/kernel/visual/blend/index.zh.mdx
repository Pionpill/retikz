混合适合表现区域重叠或叠色关系，例如让蓝色节点与橙色路径交叠处产生不同颜色。图元提供前景颜色，已经绘制的内容提供背景，混合模式决定两者如何组合。

## 整体认识

下面左侧节点与路径继承 `multiply`，重叠区域出现叠色；右侧节点覆盖为 `normal`，与蓝色背景按普通透明度合成。比较重叠部分，而不是只看图元未重叠处的颜色。

<ComponentPreview files="/kernel/visual/blend/integration/blend-integration" size="sm" />

Scope 在这里共享 Node 和 Path 的默认配置，不建立隔离图层。每个主几何依次与已有背景合成，因此透明度、背景颜色和绘制顺序都会影响结果。

## 选择与边界

普通覆盖使用 `normal`；需要重叠处变暗时尝试 `multiply`，需要变亮时尝试 `screen`。先在实际背景上比较，再调整透明度，避免把模式名称当成固定输出颜色。

混合不会生成新的交集几何，也不会改变布局。需要重复纹理时使用[图案](/kernel/visual/pattern/usage)，需要偏移投影时使用[阴影](/kernel/visual/shadow/usage)。Scope 的默认值不能替代图层隔离或整组离屏合成。
