title: 基础用法
description: 动画用关键帧描述属性随时间的变化。内置预设返回同样的轨道数据，可与手写轨道组合。
---

Core 提供 `fadeIn`、`scaleIn`、`slideIn`、`drawOn` 基础预设，以及 `colorShift`、`cameraTo`、`loop`、`stagger` 通用工具。`grow`、`growUp`、`pulse`、`spin`、`flash`、`blink`、`wiggle` 从 `@retikz/extension` 导入，详见 [Extension 动画预设](/library/extension/animation)。两层返回相同的轨道数据，不需要额外注册。

## 接入方式

四种写法绘制相同结果。Vanilla 需要页面已有 `<div id="diagram"></div>`；移除容器前调用 `view.dispose()`。

## 入场与强调

| 目的       | Core 基础预设 / 工具 | Extension 可选效果                |
| ---------- | -------------------- | --------------------------------- |
| 透明度入场 | fadeIn               | —                                 |
| 缩放入场   | scaleIn              | grow、growUp                      |
| 位移入场   | slideIn              | —                                 |
| 描边揭示   | drawOn               | —                                 |
| 状态强调   | colorShift、loop     | pulse、spin、flash、blink、wiggle |

带文本或旋转的 Node 会把动画挂到包裹整个节点的组上，文字随节点一起运动。跨多个独立图元的整体动画使用 Scope，详见[组件对接](/kernel/visual/animation/integration)。预设参数以 API 签名为准，时长与延迟的单位都是毫秒。

## 手写轨道

一条轨道描述一个 property。keyframes 的 at 为 0..1 且按非递减顺序排列；value 是绝对值。duration 必须大于 0。easing 可以放在轨道或某个关键帧上，关键帧的 easing 作用于到下一帧的区间。

属性名仅接受支持的动画属性。缓动可以使用 `linear`、`ease`、`ease-in`、`ease-out`、`ease-in-out`，也可以直接传入贝塞尔四元组，例如 `easing: [0.34, 1.56, 0.64, 1]`，无需注册名称。

矩形、椭圆和路径还支持 `fillOpacity`、`strokeOpacity` 和 `dashOffset`。例如，让虚线连续移动：

```ts
import type { IRAnimationTrack } from '@retikz/core';

const movingDash = {
  property: 'dashOffset',
  keyframes: [
    { at: 0, value: 0 },
    { at: 1, value: 12 },
  ],
  duration: 1000,
  iterations: 'infinite',
} satisfies IRAnimationTrack;
```

<ComponentPreview files="visual-properties" size="sm" controls={{ animation: true }} />

图元需同时设置静态虚线样式，例如 `dashPattern: [8, 4]`。填充／描边透明度与整体透明度相乘。文本支持文字填充、整体透明度与变换，编组支持整体透明度与变换；不适用的轨道会告警并跳过。

这些目标指编译后的 Scene 图元。带正文或旋转的 Node、带整体旋转或缩放的 Path 可能把轨道挂到编组上，此时按编组的支持范围处理。

`pathDraw` 会占用虚线模式和偏移。同一图元同时声明 `dashOffset` 动画时，优先使用 `pathDraw`，跳过偏移动画并告警，结果与轨道声明顺序无关。
