title: 基础用法
description: 动画用关键帧描述属性随时间的变化。内置预设返回同样的轨道数据，可与手写轨道组合。
---

Core 提供 `fadeIn`、`scaleIn`、`slideIn`、`drawOn` 基础预设，以及 `colorShift`、`cameraTo`、`loop`、`stagger` 通用工具。`grow`、`growUp`、`pulse`、`spin`、`flash`、`blink`、`wiggle` 从 `@retikz/standard` 导入，详见 [Standard 动画预设](/library/standard/animation)。两层返回相同的轨道数据，不需要额外注册。

## 接入方式

四种写法绘制相同结果。Vanilla 需要页面已有 `<div id="diagram"></div>`；移除容器前调用 `view.dispose()`。

```tsx
import { Layout, Node } from '@retikz/react';
import type { FC } from 'react';

const Demo: FC = () => (
  <Layout>
    <Node
      position={[0, 0]}
      layout={{ minimumSize: 80 }}
      animations={[
        {
          property: 'opacity',
          keyframes: [
            { at: 0, value: 0 },
            { at: 1, value: 1 },
          ],
          duration: 800,
        },
      ]}
    />
  </Layout>
);
```

## 入场与强调

| 目的       | Core 基础预设 / 工具 | Standard 可选效果                 |
| ---------- | -------------------- | --------------------------------- |
| 透明度入场 | fadeIn               | —                                 |
| 缩放入场   | scaleIn              | grow、growUp                      |
| 位移入场   | slideIn              | —                                 |
| 描边揭示   | drawOn               | —                                 |
| 状态强调   | colorShift、loop     | pulse、spin、flash、blink、wiggle |

<ComponentPreview files="entrance" size="md" controls={{ animation: true }} />

带文本或旋转的 Node 会把动画挂到包裹整个节点的组上，文字随节点一起运动。跨多个独立图元的整体动画使用 Scope，详见[组件对接](/kernel/visual/animation/integration)。预设参数以 API 签名为准，时长与延迟的单位都是毫秒。

## 手写轨道

一条轨道描述一个 property。keyframes 的 at 为 0..1 且按非递减顺序排列；value 是绝对值。duration 必须大于 0。easing 可以放在轨道或某个关键帧上，关键帧的 easing 作用于到下一帧的区间。
