## Configure a shadow

Use an object such as `{ preset: 'md', blur: 6 }` to override a preset, or provide both offsetX and offsetY. Both offsets are required without a preset. Blur is nonnegative; positive offsetY points downward in screen coordinates. Opacity multiplies the resolved shadow color's alpha.

<ComponentPreview files="shadow-object" size="sm" />

`shadow: 'none'` disables an inherited shadow. Shadows do not change node connection boundaries. A fixed viewBox can still clip them, so leave sufficient output space.
