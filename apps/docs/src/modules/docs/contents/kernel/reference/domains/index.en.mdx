Domain modules are standalone Tier 2 packages that solve complete domain problems on top of Kernel. They own their IR, schemas, algorithms, and lowering, then translate results into base primitives that Core can continue compiling and rendering. Kernel does not directly embed visualization, table, or flowchart semantics.

> This is the reference layer, not component documentation. Start with the relevant module when using a domain capability. See [Composite Design](/kernel/concepts/design/composite) and [Runtime Extensions](/kernel/reference/runtime/extensions) for the underlying integration mechanism.
