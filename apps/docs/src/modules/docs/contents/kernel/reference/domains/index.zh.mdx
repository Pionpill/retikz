领域模块是在 Kernel 之上解决完整领域问题的独立 Tier 2 包。它们拥有自己的 IR、schema、算法与 lowering，并把结果转换为 Core 可以继续编译和渲染的基础图元；Kernel 不直接内置可视化、表格或流程图等领域语义。

> 这里是参考层，不是组件文档；使用具体领域能力时，从对应模块文档开始。底层接入机制见 [Composite 设计](/kernel/concepts/design/composite)与[扩展运行时](/kernel/reference/runtime/extensions)。
