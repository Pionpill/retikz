这一分组是 IR（中间表示）的数据契约：一份 retikz 图最终被序列化成的 JSON 结构。AI 生成、数据库存储、自定义转换器都基于这套 schema。这里覆盖可独立查询的公开契约；嵌套的辅助 schema 会收在其所属页面，不按源码目录逐一拆页。

> 这里是参考层，不是组件文档；写图请从 [组件](/kernel/components/layout) 开始。

## 职责一览

| 主题      | 职责                                          | 何时查阅                  |
| --------- | --------------------------------------------- | ------------------------- |
| Scene     | IR 根、视框与顶层 child 联合                  | 生成或校验整张图          |
| Scope     | 子树分组、样式默认值、变换与裁剪              | 生成嵌套结构或局部上下文  |
| Entity    | Node、Coordinate、文字、形状与连接边界        | 生成节点、坐标或文本      |
| Path      | Path、step、target、ribbon 与箭头             | 生成路径、连线或几何关系  |
| Placement | position 与 target 共用的定位形态             | 解析或生成位置引用        |
| 绘制      | 共享视觉字段、渐变、图案、图片与阴影          | 生成 fill / stroke 等外观 |
| Animation | JSON 安全的关键帧、时间参数、触发器与变换原点 | 生成声明式动画 track      |
