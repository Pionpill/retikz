`ScopeSchema` 是 Tier 1 的容器节点。它不绘制新的视觉图元，而是给一组 children 建立局部变换、样式默认值、裁剪、层级与引用边界；Scope 本身仍可通过 `id` 被引用。

`Scope.theme` 是传给后代 Composite 的稀疏覆盖。`style`、`mode` 与 token key 分别继承；`tokens` 只覆盖 Scope 声明的 namespace/key，并由 Core registry 按 owner schema 校验。Theme 是环境交接，不会自动给 Core 图元着色。

## Scope 定位

`ScopePlacementSchema` 是 Scope 自身锚点到父坐标系 target 的闭合定位契约。`target` 只允许笛卡尔 `[x, y]` 或此前已完成的 `NodeTarget`；Polar、Offset、Between 与 path-relative target 不进入该字段。

<ZodSchema
  name="ScopePlacementSchema"
  description="把 transforms 后的 Scope 自身点对齐父坐标系 target。"
  descriptions={{
    target: '父坐标系笛卡尔点，或此前已完成的 Node / Coordinate / Scope target',
    selfAnchor: 'Scope 自身点；缺省 center',
  }}
/>

NodeTarget 的 `offset` 先按世界 user-units 叠加，再投影回父 frame。forward、self、descendant 或未闭合 Scope placeholder 会同步失败，不进行拓扑排序。

<span id="scopeselfpoint"></span>

### Scope 自身点

<ZodSchema name="ScopeSelfPointSchema" description="Scope 固有局部原点、包络 anchor 或显式局部坐标。" />

`origin` 固定为固有局部 `[0, 0]`；其它 anchor 复用标准名称、数字角度和 `{ side, fraction }`。空 Scope 的 origin、center、边、角与数字角度都退化到 `[0, 0]`，但 `{ side, fraction }` 在零尺寸包络上仍 fail-loud。

<span id="default-channels"></span>

### 四个默认值通道

Scope 把默认值拆成四个互不混用的通道。它们只覆盖对应宿主未显式设置的字段；`resetStyle` 可以按通道阻断父 Scope 的继承。

| 字段           | 复用的契约                                               | 不负责                           |
| -------------- | -------------------------------------------------------- | -------------------------------- |
| `nodeDefault`  | [Node](/kernel/reference/schema/entity#node) 的视觉字段  | id、位置、文字、标签与实例元数据 |
| `pathDefault`  | [Path](/kernel/reference/schema/path#path) 的视觉字段    | kind、step、mark 与实例元数据    |
| `labelDefault` | label 的 color、textColor、opacity、font                 | 文本、位置与宿主关系             |
| `arrowDefault` | [ArrowDetail](/kernel/reference/schema/path#arrowdetail) | 箭头是否存在与沿路径的位置       |

## 变换

`TransformSchema` 是 `Scope.transforms` 的联合类型。数组第 0 项最外层、最后一项先作用。位移类在编译期解析为笛卡尔 translate；rotate pivot lower 为 Scene `cx/cy`，非原点 scale pivot lower 为 `translate(p) → scale → translate(-p)`。

<ZodSchema name="TransformSchema" description="Scope 局部变换：位移、旋转或缩放。" />

| `kind`              | 核心字段                       | 作用                         |
| ------------------- | ------------------------------ | ---------------------------- |
| `translate`         | `x`、`y`                       | 笛卡尔位移                   |
| `polar-translate`   | `origin?`、`angle`、`radius`   | 从原点按极坐标求位移         |
| `at-translate`      | `direction`、`of`、`distance?` | 相对已命名实体求位移         |
| `offset-translate`  | `of`、`offset?`                | 基准点加二维偏移             |
| `between-translate` | `between`、`fraction`          | 两个绝对端点之间按比例求位移 |
| `rotate`            | `degrees`、`pivot?`            | 绕 Scope 自身点旋转          |
| `scale`             | `x`、`y?`、`pivot?`            | 绕 Scope 自身点缩放          |

`pivot` 缺省 `origin`，接受 [Scope 自身点](#scopeselfpoint)。v0.5 已移除 IR rotate 的 `cx` / `cy`；旧写法迁移为 `pivot: [cx, cy]`。Scene transform 的 `cx` / `cy` 仍是 lowering 输出。

## 裁剪

`ClipSchema` 是 `Scope.clip` 接受的 Core 契约。内置几何直接使用下面的 JSON 形状。其他任意 `kind` 都是 JSON-safe 的自定义裁剪 spec：Core 保留可序列化字段，再通过贡献给 `CompileOptions.clips` 的对应 Definition 校验和解析。

| 分支              | 判别方式               | 内容                                     |
| ----------------- | ---------------------- | ---------------------------------------- |
| 内置几何          | `rect` / `circle` 等   | 使用下方固定字段 schema                  |
| 自定义 Definition | 其它非空 `kind` 字符串 | JSON-safe 字段由其贡献的 Definition 校验 |

多边形与路径裁剪 schema 由 `@retikz/standard/clip` 提供，并通过注入的 Definition 校验，不属于 Core schema registry。详见[裁剪扩展](/library/standard/extension/clip)。

`compound` 是可选的 Standard 裁剪，不是 Core schema 分支。从 `@retikz/standard/clip` 导入 `CompoundClipDefinition` 并贡献给 `CompileOptions.clips`；该 Definition 拥有递归 `children` 契约，并与其他自定义 kind 一样走同一条 Core 裁剪 registry 解析路径。

自定义裁剪的 Definition、registry 与 renderer 边界见 [自定义裁剪](/kernel/components/layout/custom-clip)。
