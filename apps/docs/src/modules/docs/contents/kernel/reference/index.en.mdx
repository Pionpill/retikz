Reference pages are contract dictionaries rather than tutorials. Use them when checking how Tier 2 domain capabilities integrate, which values an IR field accepts, or which Scene primitives compilation produces.

> This is the reference layer, not component documentation. Start with [Components](/kernel/components) when authoring figures.

## Responsibilities

| Group          | Responsibility                                       | Reach for it when                           |
| -------------- | ---------------------------------------------------- | ------------------------------------------- |
| Domain Modules | Domain semantics, dependencies, and Core integration | Looking up standalone packages such as Plot |
| Schema         | Define IR structures and field contracts             | Generating, persisting, or validating IR    |
| Runtime        | Compile IR to Scene and expose parsers               | Driving compilation or low-level tooling    |
