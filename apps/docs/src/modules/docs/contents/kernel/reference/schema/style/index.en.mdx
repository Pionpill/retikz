Core separates common appearance into two layers: `GraphicStyleSchema` defines fields used directly by a host, while `PaintSpecSchema` describes structured paints that a single CSS color cannot express. Node, Path, and Scope reuse these schemas instead of maintaining parallel color and opacity semantics.

<span id="graphicstyle"></span>

## GraphicStyle

`GraphicStyleSchema` applies to an individual node / drawable. `CascadingGraphicStyleSchema` is the subset that Scope can inherit downward; it intentionally excludes shadow and blend mode.
