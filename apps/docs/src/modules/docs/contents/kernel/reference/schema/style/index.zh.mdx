---
title: 绘制
description: Node、Path 与 Scope 共用的视觉字段，以及渐变、图案、图片和阴影的 JSON 契约
---

Core 把通用视觉外观拆成两层：`GraphicStyleSchema` 定义宿主可直接使用的字段，`PaintSpecSchema` 定义不能用单个 CSS color 表达的结构化 paint。Node、Path 与 Scope 复用这些 schema，不各自维护一套颜色和透明度语义。

以下四个 schema 是可复用的严格字段片段，用于让 Standard、Plot 和其它 Tier 2 owner 按自己的默认值与字段边界组合 Core 语义。它们不是新的绘图能力、compile / lowering 入口或 preset bundle；完整图元仍须使用对应的聚合契约。

<span id="graphicpaint"></span>

## 图形 paint

`GraphicPaintSchema` 收拢主几何共用的颜色、填充和描边 paint 字段。它只描述 JSON 字段边界，不改变 `GraphicStyleSchema` 的现有聚合语义。

<ZodSchema
  name="GraphicPaintSchema"
  description="主几何共用的颜色、填充和描边 paint 字段。"
  descriptions={{
    color: '主色；stroke、fill、label 与 arrow 未单独设置时可回退到它',
    fill: '填充 paint：CSS color 字符串或 PaintSpec',
    stroke: '描边 paint：CSS color 字符串或 PaintSpec',
  }}
/>

<span id="graphicopacity"></span>

## 图形透明度

`GraphicOpacitySchema` 收拢主几何的整体、填充和描边透明度。各字段仍是可选的 0..1 数值，并由宿主决定默认值与继承方式。

<ZodSchema
  name="GraphicOpacitySchema"
  description="主几何共用的整体、填充和描边透明度字段。"
  descriptions={{
    opacity: '作用于主要几何整体的透明度 0..1',
    fillOpacity: '只作用于填充的透明度 0..1',
    strokeOpacity: '只作用于描边的透明度 0..1',
  }}
/>

<span id="graphiceffects"></span>

## 图形效果

`GraphicEffectsSchema` 收拢主几何的阴影与混合模式。Scope 的级联样式仍按既有契约排除这两个字段。

<ZodSchema
  name="GraphicEffectsSchema"
  description="主几何共用的阴影和混合模式字段。"
  descriptions={{
    shadow: '阴影 preset，或显式 DropShadowSpec',
    blendMode: '与已绘制内容的混合模式；省略或 normal 使用普通 source-over',
  }}
/>

<span id="strokestyle"></span>

## 描边样式

`StrokeStyleSchema` 是跨 drawable 几何复用的描边片段，包含宽度与虚线参数；Path 额外的端点和拐角字段见 [PathStroke](/kernel/reference/schema/path#pathstroke)。

<ZodSchema
  name="StrokeStyleSchema"
  description="可绘制几何共用的描边宽度与虚线字段。"
  descriptions={{
    strokeWidth: '描边宽度（用户单位）',
    dashPattern: 'dash/gap 长度序列（如 [4, 2]）；省略 = 实线',
    dashOffset: '虚线起点偏移（用户单位），可为正数、0 或负数；省略 = 0',
  }}
/>

<span id="strokewidth"></span>

### 描边宽度值

`StrokeWidthSchema` 是描边聚合与上层领域样式共同复用的非负用户单位值，不携带字段默认、继承或 token 语义。

<ZodSchema name="StrokeWidthSchema" description="非负的用户单位描边宽度。" />

<span id="graphicstyle"></span>

## 图形样式

`GraphicStyleSchema` 用于单个 node / drawable；`CascadingGraphicStyleSchema` 是 Scope 可向下继承的子集，不包含 shadow 与 blend mode。

<ZodSchema
  name="GraphicStyleSchema"
  description="单个 node / drawable 的共享视觉字段。"
  descriptions={{
    color: '主色；stroke、fill、label 与 arrow 未单独设置时可回退到它',
    fill: '填充 paint：CSS color 字符串或 PaintSpec',
    fillOpacity: '只作用于填充的透明度 0..1',
    stroke: '描边 paint：CSS color 字符串或 PaintSpec',
    strokeWidth: '描边宽度（用户单位）',
    strokeOpacity: '只作用于描边的透明度 0..1',
    opacity: '作用于主要几何整体的透明度 0..1',
    shadow: '阴影 preset，或显式 DropShadowSpec',
    blendMode: '与已绘制内容的混合模式；省略或 normal 使用普通 source-over',
  }}
/>

<span id="paintvalue"></span>

## 绘制值

`fill` 与 `stroke` 接收 `PaintValueSchema`：纯色保持 CSS color 字符串；需要渐变、pattern 或图片时才使用带 `kind` 的 `PaintSpec` 对象。

<ZodSchema name="PaintValueSchema" description="CSS color 字符串或结构化 PaintSpec。" />

<span id="dropshadow"></span>

## 阴影

`DropShadowSchema` 可单独给出 preset，也可显式给出偏移；显式字段会覆盖 preset 提供的对应值。

<ZodSchema
  name="DropShadowSchema"
  description="preset 加可选字段覆盖，或显式偏移定义的投影。"
  descriptions={{
    preset: 'Tailwind 风格尺寸 preset，为 offset、blur 与 color 提供初值',
    offsetX: '水平偏移（用户单位）；覆盖 preset',
    offsetY: '垂直偏移（用户单位，屏幕向下为正）；覆盖 preset',
    blur: '模糊半径（用户单位）；0 表示硬边阴影',
    color: '阴影 CSS color；覆盖 preset',
    opacity: '作用于解析后阴影颜色的透明度乘数 0..1',
  }}
/>

阴影、混合模式与 pattern 的组件写法和视觉效果分别见 [Shadow](/kernel/components/effects/shadow)、[Blend](/kernel/components/effects/blend) 与 [Pattern](/kernel/components/effects/pattern)。
