参考分组用于查契约，不承担入门教学。需要确认 Tier 2 领域能力如何接入、IR 字段允许什么值，或编译后会得到哪些 Scene Primitive 时，从这里进入对应词典页。

> 这里是参考层，不是组件文档；写图请从 [组件](/kernel/components) 开始。

## 职责一览

| 分组     | 职责                                      | 何时查阅                   |
| -------- | ----------------------------------------- | -------------------------- |
| 领域模块 | Tier 2 包的领域语义、依赖与 Core 接入边界 | 查询 Plot 等独立能力包     |
| 模型契约 | IR schema 与字段约束                      | 生成、持久化或校验 JSON IR |
| 运行时   | IR → Scene 编译、Primitive 与 parser      | 自己驱动编译或集成底层工具 |
