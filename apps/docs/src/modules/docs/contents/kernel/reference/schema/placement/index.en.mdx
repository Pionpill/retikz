Node and Coordinate share five `position` forms. Node additionally supports anchor-to-anchor placement based on actual layout. Non-Cartesian forms resolve to a final position at compile time.

## Position

`PositionSchema` is a tuple — the simplest position form.

`PolarPositionSchema` is recursive — the `origin` field may itself be another `PolarPosition` (chained polars).

## AtPosition

`AtPositionSchema` describes relative positioning between named entities.

## OffsetPosition

`OffsetPositionSchema` describes an arbitrary `(dx, dy)` offset from a base point; the `of` union shape matches `PolarPosition.origin`.

<ZodSchema name="OffsetPositionSchema" />

<Comparison target="tikz" title="Offset Positioning">

`OffsetPositionSchema` maps to TikZ `calc` library syntax `($(of) + (dx, dy)$)`.

</Comparison>

## BetweenPosition

`BetweenPositionSchema` takes a point along the segment between two endpoints at proportion `fraction` (0..1) — `lerp(A, B, fraction)`. Endpoints use the self-contained `AbsoluteTarget`.

<ZodSchema name="BetweenPositionSchema" />

## AnchorPosition

`AnchorPositionSchema` is valid only in `Node.position`. The compiler completes the current Node's text, shape, padding, margin, scale, and rotation layout before translating the whole Node until its selected anchor coincides with the target anchor plus offset.

<ZodSchema name="AnchorPositionSchema" />

<span id="absolutetarget"></span>

## AbsoluteTarget

`AbsoluteTargetSchema` is the endpoint type used by `between`: Cartesian / polar / node reference / offset / nested between, **excluding** path-relative (`{ relative }` / `{ relativeAccumulate }`) — which avoids a `Position` ↔ `Target` schema cycle.

<ZodSchema name="AbsoluteTargetSchema" />

<span id="nodetarget"></span>

## NodeTarget

`NodeTargetSchema` references a named Node, Coordinate, or Scope. Its consumer defines what an omitted `anchor` means: a path endpoint enables automatic boundary clipping, while `AnchorPositionSchema.target` defaults to `center`. Explicit anchor, offset, and boundary overrides affect this reference only.

<ZodSchema name="NodeTargetSchema" />
