`entity` 涵盖**有 id**、**放在某个位置**、**自身不画线**的 IR 元素。两者注册到同一个 nodeIndex，所以 Node 的 id 与 Coordinate 的 id 共享命名空间。

<span id="node"></span>

## 节点

`NodeSchema` 描述一个被定位的视觉原件。它是 IR 里字段最多的实体 —— 30+ 字段覆盖形状、填充 / 描边、padding、文本、字体、缩放、附加标签。

## Node 文字颜色关键字

`NodeSchema.textColor` 保持普通字符串契约。`NodeTextColor.Contrast` 是 Node 宿主保留关键字，也可用于由 Node schema 派生的 `Scope.nodeDefault.textColor`；它按最终静态不透明 fill 选择纯黑或纯白。

Core 只解析确定的 named / hex / `rgb()` / `hsl()` 颜色，不读取 DOM 或 renderer 状态。透明 / 缺省 fill、gradient、pattern、image 或动态 CSS color 使用固定 `currentColor`，同时发出 `TEXT_AUTO_CONTRAST_UNRESOLVED`。

## 坐标

`CoordinateSchema` 必须有 `id`（这是它存在的全部意义），不参与 layout 扩展，与 Node 共享 nodeIndex。

`position: { boundary, fraction }` 目前用于 box-like 节点边界：`boundary` 取 `'top'` / `'right'` / `'bottom'` / `'left'`，`fraction` 是该边上的 0..1 比例位置，缺省 `0.5`。非 `center` 标签沿摆放方向用 `distance + 旋转视觉框投影半径` 求中心；pin 终点则是同一射线与旋转视觉框的精确交点。

## 文本块

`TextBlockSchema` 是节点文本块的结构：单字符串表示单行；非空数组表示多行。每个 `LineSpec` 可是普通字符串、行级样式对象，或 `{ runs }` 形式的混合文本 / 公式行。

## 字体

`FontSchema` 复用于节点文本、节点标签和行级文本覆盖；所有字段均可选。`size` 可写正数、Web 风格 preset（如 `sm` / `lg`）或 `em` / `rem` 字符串；TikZ 风格字号由上层 sugar 处理，不进入 core IR。
