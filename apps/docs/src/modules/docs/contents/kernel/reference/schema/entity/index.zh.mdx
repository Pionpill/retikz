`entity` 涵盖**有 id**、**放在某个位置**、**自身不画线**的 IR 元素。两者注册到同一个 nodeIndex，所以 Node 的 id 与 Coordinate 的 id 共享命名空间。

<span id="node"></span>

## 节点

`NodeSchema` 描述带位置与边界的视觉实体。`style` 收纳视觉覆盖，`layout` 收纳尺寸、间距和文本排布；位置、形状、变换、文本与标签保持根层。

完整字段见 [NodeSchema](/kernel/components/node/schema-reference#nodeschema)。

<Comparison target="tikz" title="Node 字段对照">

`strokeOpacity` 表示描边透明度；`dashed` / `dotted` 对应 TikZ 的虚线 / 点线预设；`label` 的 `{ text, position }` 形态对应 `[label=top:foo]` / `[label=30:foo]`。`placement: 'inside'` 是 retikz 对节点内部标签的结构化扩展。

</Comparison>

<span id="node-text-color"></span>

## Node 文字颜色关键字

`NodeSchema.style.textColor` 保持普通字符串契约。`NodeTextColor.Contrast` 是 Node 宿主保留关键字，也可用于由 Node schema 派生的 `Scope.defaults.node.style.textColor`；它按最终静态不透明 fill 选择纯黑或纯白。

Core 只解析确定的 named / hex / `rgb()` / `hsl()` 颜色，不读取 DOM 或 renderer 状态。透明 / 缺省 fill、gradient、pattern、image 或动态 CSS color 使用固定 `currentColor`，同时发出 `TEXT_AUTO_CONTRAST_UNRESOLVED`。

<span id="boundary"></span>

## 连接边界

`BoundarySchema` 决定 path 端点和方向锚点贴在哪条连接面。字符串 `shape` 使用视觉 shape 自身；其它字符串或 `ShapeRef` 选择内置 / 注册的 boundary provider。

完整字段见 [BoundarySchema](/kernel/components/node/schema-reference#boundaryschema)。

<span id="coordinate"></span>

## 坐标

`CoordinateSchema` 必须有 `id`（这是它存在的全部意义），不参与 layout 扩展，与 Node 共享 nodeIndex。

<Comparison target="tikz" title="Coordinate 对照">

`{ type: 'coordinate', id: 'm', position: [3, 2] }` 对应 TikZ 的 `\coordinate (m) at (3,2);`。

</Comparison>

完整字段见 [CoordinateSchema](/kernel/components/node/schema-reference#coordinateschema)。

<span id="nodelabel"></span>

## 节点标签

`NodeLabelSchema` 描述节点的附加文本；`Node.label` 可填单个对象或数组。

完整字段见 [NodeLabelSchema](/kernel/components/node/schema-reference#nodelabelschema)。

`position: { boundary, fraction }` 目前用于 box-like 节点边界：`boundary` 取 `'top'` / `'right'` / `'bottom'` / `'left'`，`fraction` 是该边上的 0..1 比例位置，缺省 `0.5`。非 `center` 标签沿摆放方向用 `distance + 旋转视觉框投影半径` 求中心；pin 终点则是同一射线与旋转视觉框的精确交点。

<span id="textblock"></span>

## 文本块

`TextBlockSchema` 是节点文本块的结构：单字符串表示单行；非空数组表示多行。每个 `IRLine` 可是普通字符串、行级样式对象，或 `{ runs }` 形式的混合文本 / 公式行。

## 字体

`FontSchema` 复用于节点文本、节点标签和行级文本覆盖；所有字段均可选。family、size、weight 与 style 分别复用 Core 的命名 value schema；`size` 可写正数、Web 风格 preset（如 `sm` / `lg`）或 `em` / `rem` 字符串。TikZ 风格字号由上层 sugar 处理，不进入 core IR。
