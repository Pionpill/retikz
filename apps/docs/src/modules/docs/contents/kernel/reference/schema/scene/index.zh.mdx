## Theme

`ThemeSchema` 是 Scene 与 Scope 共用的稀疏环境，字段为 `style`、`mode` 与 `tokens`。`tokens` 按 owner namespace 保存 sparse token key；每层只覆盖自己声明的 namespace/key，Core 内置 `core` namespace，Plot、Chart、Table 等 owner 通过 `themeTokenDefinitions` 注册各自 schema。未知 namespace、key、值或冲突 Definition 会 fail-loud。

编译后 Composite 收到完整、冻结的 `ResolvedTheme`：除了继承后的 `style`、`mode`、`tokens`，还包含 detached/frozen 的 `colors.semantic` 与非空 `colors.categorical`。这些 colors 是 Core shared view；普通 Core 图元、最终 Scene 与 renderer 不会自动读取 Theme 或替换自身颜色。

## 视框

`ViewBoxSchema` 显式固定最终取景范围。省略时 compile 从 emitted primitives 的 AABB 与 padding 自动计算；设置后不再叠加自动 padding。

## 子节点

`ChildSchema` 是 scene 顶层子节点的联合类型：Tier 1 按 `type` 判别的 node / path / coordinate / scope 四类，再并上带 `namespace` 的 Tier 2 composite 节点（精确字段校验在 compile 期由 lowering 用注册 schema 完成）。scope 与 composite 的逐字段 schema 不在本组单列。

## Tier 2 Composite

`CompositeNodeSchema` 只固定跨领域共用的 `namespace` 与 `type`。其余 JSON 字段由对应 Tier 2 Definition 的 schema 校验，并在 compile 的 lowering 阶段转换为 Tier 1 children。

## JSON 对象

`JsonObjectSchema` 表示键为字符串、值为递归 JSON value 的对象。它用于 `meta`、自定义 provider 参数与 composite 扩展字段；函数、class 实例、ReactNode 等运行时值不属于 IR。

<span id="jsonvalue"></span>

`JsonValueSchema` 是递归联合：string、number、boolean、null、JsonValue 数组或 JsonObject。
