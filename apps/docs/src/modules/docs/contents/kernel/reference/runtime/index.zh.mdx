title: 运行时
description: 查询从宿主规格到 Core IR、Scene 与渲染后端的运行时合同，以及可复用解析和扩展入口。
---

这一分组描述一份图如何穿过运行时边界：React / Vanilla adapter 先把宿主规格整理成 Core IR，`compileToScene` 完成下沉、布局与解析并返回 `{ scene, artifacts }`，再由 `@retikz/render` 把 Scene 物化为 SVG 或 Canvas。解析工具只是 adapter 可复用的 Sugar → IR 辅助入口，并不是每份 IR 都必须经过的独立阶段。

> 这里是参考层，不是组件文档；写图请从 [组件](/kernel/components/layout) 开始。

## 职责一览

| 主题     | 职责                                                    | 何时查阅                             |
| -------- | ------------------------------------------------------- | ------------------------------------ |
| 编译     | IR → Scene 的编译入口、布局选项、文字度量、warning 合同 | 自己驱动编译、配置布局、接收 warning |
| 场景原语 | compile 输出的渲染目标无关绘制模型                      | 写自定义 renderer / 导出器           |
| 解析工具 | Sugar 输入到 IR 片段的可复用纯函数                      | 编写 adapter 或自定义 DSL            |
| 扩展机制 | Definition、registry 与 host lowerer 的注入模型         | 写第三方包或宿主集成                 |
