This group is the runtime pipeline from IR to picture. `compile` is the entry point, Primitive is the renderer-agnostic drawing model, Parser turns sugar input into IR fragments, and Extension Mechanisms explains how hosts inject custom definitions, registries, and lowerers. Look here when you drive compilation, build extension packages, or write a custom renderer.

> This is the reference layer, not component docs; to author figures, start from [Components](/kernel/components/layout).

## What each part covers

| Topic      | Responsibility                                                               | Reach for it when                                                    |
| ---------- | ---------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| Compile    | The IR → Scene entry point, layout options, text measuring, warning contract | Driving compilation yourself, configuring layout, receiving warnings |
| Primitive  | The renderer-agnostic drawing model produced by compile                      | Writing a custom renderer / exporter                                 |
| Parser     | Pure conversion from sugar input to IR fragments                             | Reusing sugar parsing such as relative coordinates                   |
| Extensions | Injection models for definitions, registries, and host lowerers              | Building third-party packages or host integrations                   |
