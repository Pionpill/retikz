This group follows a figure across runtime boundaries. React and Vanilla adapters normalize host specifications into Core IR, `compileToScene` performs lowering, layout, and resolution and returns `{ scene, artifacts }`, and `@retikz/render` materializes the Scene as SVG or Canvas. Parsing helpers are reusable Sugar-to-IR utilities for adapters, not a mandatory stage for every IR input.

> This is the reference layer, not component docs; to author figures, start from [Components](/kernel/components/layout).

## What each part covers

| Topic            | Responsibility                                                               | Reach for it when                                                       |
| ---------------- | ---------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| Compile          | The IR → Scene entry point, layout options, text measuring, warning contract | Driving compilation yourself, configuring layout, or receiving warnings |
| Scene Primitives | The renderer-agnostic drawing model produced by compile                      | Writing a custom renderer or exporter                                   |
| Parsing Helpers  | Reusable pure functions from Sugar input to IR fragments                     | Building an adapter or custom DSL                                       |
| Extensions       | Injection models for definitions, registries, and host lowerers              | Building third-party packages or host integrations                      |
