Core IR stores declarative animation data only: property names, keyframes, timing, and triggers. Playback state, event callbacks, and interpolation execution remain in the renderer runtime, keeping the full schema serializable.

<span id="animationtrack"></span>

## AnimationTrack

<ZodSchema name="AnimationTrackSchema" />

Built-in properties further refine `value`: opacity, strokeWidth, translation, rotation, scale, and pathDraw use numbers; fill / stroke use color strings; scene-root viewBox uses `[x, y, width, height]`. Custom properties are interpreted by renderer-registered interpolators.

## Trigger

`TriggerSchema` accepts `load`, `visible`, `manual`, or an object carrying an event name. The IR stores the name, never a callback function.
