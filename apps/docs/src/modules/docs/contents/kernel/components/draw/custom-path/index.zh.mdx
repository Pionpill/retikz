自定义 Path kind 扩展的是**整条路径如何输出**。IR 只保存开放的 `kind` 与 JSON-safe `kindOptions`；宿主注入 `PathKindDefinition` 后，core 从统一 registry 找到 provider，并由它生成 Scene 图元。

下面的 `highlight` kind 复用内置描边编译器，只改写线宽与输出颜色。definition、`<Layout pathKinds>` 注入和使用方式都包含在同一个示例中。

## 适用边界

先判断扩展发生在“一个段”还是“整条路径”：

| 需求                                 | 选择                                                 |
| ------------------------------------ | ---------------------------------------------------- |
| 新增一种参数化曲线段                 | [路径生成器](/kernel/components/draw/path-generator) |
| 改变整条 Path 的图元、轮廓或组合方式 | 自定义 Path kind                                     |
| 只增加新的端点造型                   | [自定义箭头](/kernel/components/draw/custom-arrow)   |

如果只是换描边色、线宽、虚线、箭头或流带参数，直接使用现有 Path props；不要为样式组合创建新的 kind。

## 定义能力

用 `definePathKind` 声明一个含非空 `kind` literal 的 Path schema、可选配置 schema，以及整条路径的 compile 函数。

```tsx
const highlight = definePathKind({
  schema: z.strictObject({ kind: z.literal('highlight') }),
  optionsSchema: z.strictObject({ strokeWidth: z.number().positive() }),
  compile: context =>
    context.emitStroke({
      ...context.path,
      strokeWidth: context.options.strokeWidth,
    }),
});
```

`schema.shape.kind.value` 是 registry key。`kindOptions` 会先经过 `optionsSchema`，并保持 JSON-safe；definition 与 compile 函数只存在于运行时，不进入 IR。

## 注入宿主

React 通过 `<Layout pathKinds>` 注入；直接调用 core 时使用 `CompileOptions.pathKinds`。Path 只引用注册名与实例配置。

```tsx
<Layout pathKinds={[highlight]}>
  <Path kind="highlight" kindOptions={{ strokeWidth: 12 }}>
    <Step kind="move" to="A" />
    <Step kind="line" to="B" />
  </Path>
</Layout>
```

## 执行机制

内置 `stroke`、`ribbon` 与自定义 kind 先合并到同一个 registry。编译 Path 时，core 按 `kind` 查找 definition、校验 `kindOptions`，再把标准描边与流带 emitter 一起交给 provider。

provider 可以完全创建新的 Scene primitive，也可以调用 `emitStroke` / `emitRibbon` 复用现有端点解析、路径命令、箭头与流带逻辑。返回的 `primitives` 与 `boundsPoints` 都使用当前 Path 的局部坐标，外层 Scope 变换随后统一应用。

## 错误与限制

| 情况                                 | 结果                                            |
| ------------------------------------ | ----------------------------------------------- |
| `kind` literal 为空或不是字符串      | `definePathKind` 立即拒绝                       |
| 与 `stroke`、`ribbon` 或自定义项重名 | registry 合并时报重复注册                       |
| Path 引用未注册 kind                 | 编译列出可用名称与 `options.pathKinds` 注入提示 |
| `kindOptions` 不符合 schema          | 错误包含 kind 名和对应 IR 路径                  |
| provider 返回 `null`                 | 该 Path 不产生图元                              |
| `boundsPoints` 不覆盖真实输出边界    | 自动布局与 Path 级 rotate / scale 依据会失真    |

自定义 kind 返回的是后端中立 Scene primitive，不能把 SVG element、Canvas 实例、ReactNode 或函数塞进结果，也不能要求 renderer 识别自定义 `kind`。

## API 参考

### PathKindDefinition

| 字段            | 类型                                         | 默认值                   | 描述                                  |
| --------------- | -------------------------------------------- | ------------------------ | ------------------------------------- |
| `schema`        | `ZodObject<{ kind: ZodLiteral<string> }>`    | —                        | 声明 Path 形态并提供 registry key     |
| `optionsSchema` | `ZodType<IRJsonObject>`                      | 原始 `kindOptions ?? {}` | 校验自定义实例配置                    |
| `compile`       | `(context) => PathKindCompileResult \| null` | —                        | 为整条 Path 生成 Scene 图元与边界依据 |

### compile 上下文

| 字段         | 类型                                       | 默认值    | 描述                                                |
| ------------ | ------------------------------------------ | --------- | --------------------------------------------------- |
| `path`       | `IRPathBase`                               | —         | 当前 Path 的完整 IR                                 |
| `options`    | `TOptions`                                 | —         | `kindOptions ?? {}` 经 `optionsSchema` 解析后的结果 |
| `emitStroke` | `(path?) => PathKindCompileResult \| null` | 当前 Path | 复用标准描边编译                                    |
| `emitRibbon` | `(path?) => PathKindCompileResult \| null` | 当前 Path | 复用标准流带编译                                    |

### PathKindCompileResult

| 字段           | 类型                    | 默认值 | 描述                                   |
| -------------- | ----------------------- | ------ | -------------------------------------- |
| `primitives`   | `Array<ScenePrimitive>` | —      | 当前 Path 局部坐标中的实际输出         |
| `boundsPoints` | `Array<Position>`       | —      | 自动布局与 Path 级变换使用的关键边界点 |
