`<Coordinate>` 给位置一个稳定的 `id`，但不画形状或文字。路径可以把它当端点，其它节点也能通过相对、偏移、比例或锚点定位引用它。

先阅读[基础用法](/kernel/components/node/usage)，再按本页组织辅助位置。

## 接入方式

四种写法都声明两个不可见的坐标点，再让路径连接它们。`Coordinate` 的真实 IR 是 `{ type: 'coordinate', id, position }`；它本身不绘制，画面中只有引用两个 id 的连线。完整坐标模型见[坐标系](/kernel/components/basic/coordinate-system)；Vanilla 示例需要页面已有 `<div id="diagram"></div>`。

`Coordinate.position` 接受五种中心 / 点定位形态：笛卡尔 `[x, y]` / 极坐标 `{ angle, radius, origin? }` / 相对定位 `{ direction, of, distance? }` / 偏移定位 `{ of, offset }` / 比例定位 `{ between, fraction }`。Node 额外支持依赖自身真实尺寸的 `{ kind: 'anchor', target, selfAnchor? }`；Coordinate 可以作为它的 target，但自身没有 `selfAnchor` 定位。

## 何时使用

需要汇合点、辅助定位或不可见锚点时使用 Coordinate；需要形状、文字或方向性边界时使用 Node。不要用透明 Node 模拟坐标点：它仍有尺寸和 padding，会扩大布局范围。

| 目标                   | 选择           |
| ---------------------- | -------------- |
| 只命名位置             | `<Coordinate>` |
| 显示圆点或其它标记     | `<Node>`       |
| 显示文字或 label       | `<Node>`       |
| 使用不同方向的真实锚点 | `<Node>`       |

Coordinate 的方向与角度 anchor 都退化到中心；它也不提供文字字段。零尺寸语义见[实现原理](/kernel/components/node/mechanism)。

<Comparison target="tikz" title="Coordinate 对照">

`<Coordinate id="hub" position={[0, 0]} />` 对应 TikZ 的 `\coordinate (hub) at (0,0);`：只命名一个点，不渲染形状。

`{ between: [A, B], fraction }` 对应 TikZ `($(A)!t!(B)$)`，都表示在两个端点之间按比例取点。

## 例子

### 命名虚拟锚点

用 coordinate 命名一个虚拟中心，让多个节点围绕它定位、多条 path 终止于它。浅色坐标轴固定在世界原点；通过面板调整 hub 的 `position` 与节点的 `distance`，观察 hub 相对原点移动、所有引用一起更新。

### 偏移定位链

Coordinate 用 `{ of, offset }` 派生下一个 coordinate——靠一个根 coordinate 驱动整组节点的相对位置，移动根点其它点全跟着走。浅色坐标轴固定在世界原点；用控件移动根点或调整水平步长，观察整组位移与偏移沿引用链传播：

<ComponentPreview files="coordinate-offset-chain" size="lg" />

### 比例定位

`{ between: [A, B], fraction }` 在 A、B 之间按 `fraction`（0..1）取点——`lerp(A, B, fraction)`。面板实际移动的是不可见的 Coordinate Q，橙色 q 只是引用 Q 的可视标记；端点变化时 Q 仍自动保持比例。

端点必须是不依赖路径当前位置就能求出的位置（`AbsoluteTarget`）（笛卡尔 / 极坐标 / 节点引用 `{ id, anchor? }` / `{ of, offset }` / 嵌套 between，**不含** path-relative）。同一形态可用于 `<Coordinate position>` / `<Node position>` / `<Step to>`：

<ComponentPreview files="coordinate-between" size="xs" />

> `fraction` 严格 [0,1]（外插暂不支持）；端点引用未定义节点时，Coordinate / Node 位置解析失败抛错、path `Step.to` 发 warn 跳过——与其它定位形态同口径。

## 错误与限制

定位引用的对象必须已完成布局并登记（通常是前面声明的同级对象）；路径端点可以引用后声明的同级 Coordinate。Coordinate 不输出图元，不撑大自动视框；命名方位与角度锚点都落在中心，边上比例点需要真实边界，不能用于 Coordinate。

## 相关属性

Coordinate 只有命名与定位两个公开输入；完整字段与类型见 [API 参考](/kernel/components/node/api-reference)。
