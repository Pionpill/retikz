先熟悉[基础用法](/kernel/components/path/usage)，再定义并注入新的能力。

## 适用边界

Core 默认提供 `normal`、`open`、`stealth`、`openStealth`、`circle` 与 `openCircle` 六种基础箭头；实心 / 空心菱形由 [箭头扩展](/library/extension/arrow) 按需提供。只有 Core 与已装配 Standard 造型都不够用时，才注册新的 definition。

| 需求                           | 选择                                              |
| ------------------------------ | ------------------------------------------------- |
| 调整现有箭头尺寸、颜色或透明度 | `arrowDetail`                                     |
| 起末端使用不同已注册造型       | `arrowDetail.start` / `end`                       |
| 增加新的端点轮廓               | 自定义箭头                                        |
| 改变整条关系线的输出           | [自定义路径](/kernel/components/path/custom-path) |

ArrowDefinition 同时服务 Path 端点与 `marks[].mark.shape`。它不负责箭头方向、沿线位置、路径描边或 renderer 实例。

## 最小结果

自定义箭头扩展的是**端点 marker 几何**。IR 只保存开放的 shape 名与视觉参数；宿主注入 `ArrowDefinition` 后，core 从统一 registry 解析名称，在 compile 阶段生成后端中立的 `MarkerPrimitive`。

## 定义能力

最小 definition 需要稳定 `name`、视觉后缘 `backX`、路径接合点 `lineContactX`，以及返回 marker 局部几何的 `emit`。

```tsx
import { defineArrow } from '@retikz/core';

const bracket = defineArrow({
  name: 'bracket',
  hollow: true,
  backX: 2,
  lineContactX: 2,
  tipX: 8,
  emit: ({ stroke, lineWidth }) => [
    {
      type: 'path',
      commands: [
        { kind: 'move', to: [8, 1] },
        { kind: 'line', to: [2, 1] },
        { kind: 'line', to: [2, 9] },
        { kind: 'line', to: [8, 9] },
      ],
      stroke: typeof stroke === 'string' ? stroke : { kind: 'contextStroke' },
      strokeWidth: lineWidth,
    },
  ],
});
```

`emit` 使用 `baseSize` 局部坐标。`backX` 承诺箭头轴向包络的基础后缘，`lineContactX` 定义主描边接入 marker 的基准，`tipX` 描述视觉尖端；三者必须满足 `backX <= lineContactX <= tipX`。Core 会让路径越过接合基准半个自身描边宽度，再由 marker 覆盖接头；端点重叠则结合最终 `length × scale` 和空心 `lineWidth` / `outerInset`，让比例 `1` 的最终视觉后缘对齐逻辑端点。

## 箭头接合

箭头 definition 提供三个不同位置：`backX` 是轮廓后缘，`lineContactX` 是主描边的接合位置，`tipX` 是尖端。它们决定箭头放在哪里，以及主描边需要缩短多少；不能用同一个“箭头长度”替代。

<ComponentPreview files="arrow-contact" size="lg" hideCode type="illustration" />

`overlap: 1` 对齐的是最终视觉后缘，尺寸缩放与空心轮廓都会参与计算。改变重叠比例只移动端点装饰及其接合处，不重写节点锚点或路径逻辑采样。中间的 mark 只按局部切线定向，不作为端点缩短路径。

未显式指定箭头颜色时，marker 使用 `contextStroke`，即在绘制时继承所属路径的描边色；带渐变等资源型描边时，需要给箭头显式纯色。内置与注入的箭头共用同一注册与解析路径。

## 注入与使用

React 通过 `<Layout extensions={{ arrows }}>` 注入；直接调用 core 时使用 `CompileOptions.arrows`。随后在端点或沿线 mark 中引用注册名。

<DocTabs defaultValue="react">
<DocTab value="react" label="React">

```tsx
import { Draw, Layout } from '@retikz/react';

<Layout extensions={{ arrows: [bracket] }}>
  <Draw
    way={[
      [0, 0],
      [120, 0],
    ]}
    arrow="->"
    arrowDetail={{ shape: 'bracket' }}
  />
</Layout>;
```

</DocTab>
<DocTab value="vanilla" label="Vanilla">

definition 不进入 IR。相同的 shape 字符串可以由 React、Vanilla 或持久化 IR 引用，只要编译宿主注入同一 definition。

Vanilla 使用相同 definition，通过 `mount` 的 `compile` 选项注入；HTML 中先准备 `<div id="diagram"></div>`。下例沿用上方 definition。

```ts
import { path, scene } from '@retikz/vanilla';
import { mount } from '@retikz/vanilla/dom';

const input = scene({
  children: [
    path({
      way: [
        [0, 0],
        [120, 0],
      ],
      arrow: '->',
      arrowDetail: { shape: 'bracket' },
    }),
  ],
});
const view = mount(document.getElementById('diagram')!, input, {
  compile: { arrows: [bracket] },
});
// Dispose when the host is removed.
// view.dispose();
```

## 错误与限制

| 情况                                        | 结果                                            |
| ------------------------------------------- | ----------------------------------------------- |
| 名称为空                                    | registry 拒绝非空 key 约束                      |
| 与已注册的 Core、Extension 或自定义箭头重名 | registry 合并时报重复注册                       |
| `arrowDetail.shape` 未注册                  | 编译列出可用名称与 `options.arrows` 注入提示    |
| `baseSize`、back / contact / tip 或尺寸非法 | 编译拒绝无效 marker 几何                        |
| `emit` 产出未知 primitive 或无限坐标        | marker 校验拒绝，不让坏几何进入 Scene           |
| marker 内递归箭头、clip 或文本              | `MarkerPrimitive` 窄契约拒绝                    |
| Path 使用 IRPaint 描边                      | marker 无法继承资源 paint；需显式给纯色箭头颜色 |

MarkerPrimitive 只允许 `path`、`ellipse`、`rect` 与可递归包含这些图元的 `group`。不要返回 SVG `<marker>`、Canvas 对象、文本布局或外部 paint resource 引用。
