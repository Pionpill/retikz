在已有的 Vite 或同类 TypeScript 项目中接入 Kernel。发布包使用 ES modules，Node.js 要求 22.12 或更高；React 接入要求 React / React DOM 18 或更高。

## 安装与使用

将以下代码放进应用的 TSX 入口。已有 React 应用可把 `Layout` 子树放进自己的组件，无需再次调用 `createRoot`。

```tsx
import { Draw, Layout, Node } from '@retikz/react';
import { createRoot } from 'react-dom/client';

createRoot(document.getElementById('diagram')!).render(
  <Layout>
    <Node id="a" position={[0, 0]}>
      A
    </Node>
    <Node id="b" position={[100, 0]}>
      B
    </Node>
    <Node id="c" position={[200, 0]}>
      C
    </Node>
    <Draw way={['a', 'b']} arrow="->" />
    <Draw way={['b', 'c']} arrow="->" />
  </Layout>,
);
```

将以下代码放进应用的 TypeScript 入口。根入口提供图形构造函数，`/dom` 子入口负责在浏览器中挂载 SVG。

```ts
import { layer, node, path, scene } from '@retikz/vanilla';
import { mount } from '@retikz/vanilla/dom';

const input = scene({
  id: 'first-diagram',
  layers: [
    layer({
      id: 'main',
      children: [
        node({ id: 'a', position: [0, 0], text: 'A' }),
        node({ id: 'b', position: [100, 0], text: 'B' }),
        node({ id: 'c', position: [200, 0], text: 'C' }),
        path({ id: 'ab', way: ['a', 'b'], marks: [{ pos: 1, mark: { kind: 'arrow' } }] }),
        path({ id: 'bc', way: ['b', 'c'], marks: [{ pos: 1, mark: { kind: 'arrow' } }] }),
      ],
    }),
  ],
});

const view = mount(document.getElementById('diagram')!, input);
```

`scene` 表示整张图，`layer` 把一组 `node` / `path` 放在同一层；每个 `node` 的 `position` 决定位置。`marks` 为路径添加标记，`pos: 1` 表示路径末端，`kind: 'arrow'` 选择箭头。

容器移除前调用 `view.dispose()`，释放本次挂载的资源。

## 一步步搭建

### 1. 容器 `<Layout />` + 一个 `<Node />`

最小图形从容器和基础图元开始。`<Layout>` 负责承载整张图，提供 SVG 视口并显示内部图元；视口默认按内容计算；`<Node>` 负责画一个有位置、有名字、可显示文字的节点。这里先放一个节点，确认画布和基础图元都能工作。

<ComponentPreview files="get-start-step-1" size="xs" />

### 2. 多个 `<Node />`

继续添加多个 `<Node>`，相当于先把图里的实体摆好。`id` 在当前命名空间内保持唯一——初学时可以先把整张 `<Layout>` 视为一个命名空间；后面 `<Draw>` 会按 id 找到节点。`position` 是节点中心在画布里的坐标。

| Prop       | 含义                                                  |
| ---------- | ----------------------------------------------------- |
| `id`       | 当前命名空间内的唯一标识，供 `<Path>` / `<Draw>` 引用 |
| `position` | `[x, y]` 用户单位坐标，表示节点中心位置               |
| children   | 节点的可见内容（label）                               |

<ComponentPreview files="get-start-step-2" size="xs" />

### 3. 用 `<Draw />` 连起来

`<Draw>` 负责画连接线。`way` 数组按顺序写要经过的节点 id，retikz 会自动把线贴到节点边界，而不是连到文字中心；`arrow="->"` 给末端加箭头。

<ComponentPreview files="get-start-final" size="xs" />

3 个节点用 2 条带箭头的线串起，静态结构已经与最上方的例子一致。

到这里先记住 4 个规则：

- 画布坐标 x 向右、y 向下；`[0, 0]` 是 retikz 内部 user units 的原点
- `<Layout>` 默认按内容原尺寸显示，1 个用户单位对应 1 个 CSS 像素，通常不需要设置宽高或 `viewBox`
- 节点 `id` 是连线的名字，`<Draw way={['a', 'b']}>` 引用的是节点边界，不是文本中心
- 预览的源码区可查看等价写法；IR 是可保存的图形声明，Scene 才是编译结果
