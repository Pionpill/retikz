title: 形状

---

形状（圆、椭圆、弧、扇形、矩形、多边形、星形、任意轮廓）是 retikz 的一类几何原语，大多有**两副面孔**：

- **作为 Path 图形（Sugar）**——`<Circle>` `<Sector>` 这类组件是官方提供的一组形状快捷写法，在指定位置画一条形状线、展开成底层 `<Path>`。它们让你不必为常见图形手写 Path / Step。
- **作为 Node 形状**——`<Node shape="circle">` 让节点以该形状为边界：能装文字、能被 `<Path>` / `<Draw>` 用 id 引用、连线端点自动贴边。

每个形状页把这两副面孔分两大块写全：先「作为 Path 图形」，再「作为 Node 形状」。简单说：要画一条形状线，用 Sugar；要一个可连接、可标注的形状节点，用 `<Node shape>`。

Node 形状注册表也对扩展开放。想要内置之外的形状（cylinder / cloud…），在本分组最后的[自定义形状](/kernel/components/shapes/custom-shape)页注册；想补充 `parabola` 之外的曲线 step，则转到绘制分组的[路径生成器](/kernel/components/draw/path-generator)。

## 职责一览

表中的 Sugar 指编译时展开为 Path 的快捷组件；Kernel 指由 Node / Path 核心契约直接消费的形状能力。

| 页面             | 类型           | 职责                                               | 适合场景                            |
| ---------------- | -------------- | -------------------------------------------------- | ----------------------------------- |
| Circle / Ellipse | Sugar + Kernel | 画圆 / 椭圆 Path；提供圆 / 椭圆 Node 边界          | 圆形标记、椭圆容器、可连接节点      |
| Arc / Sector     | Sugar + Kernel | 画弧 / 扇形 Path；提供带参数的弧 / 扇形 Node 边界  | 角度标记、环楔、扇区图标图元        |
| Rectangle        | Sugar + Kernel | 画矩形 Path；提供 Node 的默认矩形边界              | 矩形框、流程节点、圆角节点          |
| Polygon          | Sugar + Kernel | 画正多边形 Path；提供正多边形 / 菱形 Node 边界     | 多边形标记、决策节点                |
| Star             | Sugar + Kernel | 画星形 Path；提供带几何 anchor 的星形 Node 边界    | 评级、强调标记、可连接星形          |
| Contour          | Kernel         | 把任意闭合顶点环变成可连接、可圆角的 Node 边界     | 自由轮廓节点；只画线时改用 `<Path>` |
| 自定义形状       | 扩展指南       | 用 `ShapeDefinition` 扩展布局、边界、anchor 与绘制 | 内置形状无法表达的业务图元          |
