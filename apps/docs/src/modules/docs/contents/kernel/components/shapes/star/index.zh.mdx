星形在外半径和内半径之间交替取点，有两副面孔：用 `<Star>` 画一个星形轮廓（Sugar），或用 `shape={{ type:'star', params }}` 让节点带上星形边界。完整定义见 [形状](/kernel/components/shapes)。要画一个星形，用 Sugar；要一个可连接的星形图元，用 `<Node shape>`。

## 作为 Path 图形（Sugar）

`<Star>` 在外半径和内半径之间交替取点，连成闭合路径、展开成底层 `<Path>`。适合评级星、强调标记、装饰性多角形。

### 用法

```tsx
import { Star } from '@retikz/react';
```

```tsx
<Star center={[0, 0]} outerRadius={36} innerRadius={16} points={5} />
```

### 例子

`points` 是星角数量。你可以显式给 `innerRadius`，也可以用 `innerRatio` 按比例自动算内半径。

| 写法                                           | 适合                 |
| ---------------------------------------------- | -------------------- |
| `{ center, outerRadius, innerRadius, points }` | 自己控制内外半径     |
| `{ center, outerRadius, points, innerRatio? }` | 用比例自动计算内半径 |

playground 中两条虚线圆分别是内、外半径。调整星角数量、`innerRatio` 与起始角，可以直接看到凹角深度和整体朝向如何共同塑造轮廓。

### API 参考

| 属性          | 类型               | 默认值 | 描述                                          |
| ------------- | ------------------ | ------ | --------------------------------------------- |
| `center`      | `[number, number]` | —      | 星形中心                                      |
| `outerRadius` | `number`           | —      | 外半径                                        |
| `innerRadius` | `number`           | —      | 内半径；显式给出时优先                        |
| `innerRatio`  | `number`           | `0.5`  | 未给 `innerRadius` 时，内半径相对外半径的比例 |
| `points`      | `number`           | —      | 星角数量                                      |
| `rotate`      | `number`           | `-90`  | 起始角度                                      |

这个形状 Sugar 也会透传共享的 Path 属性，例如 `stroke`、`fill`、`opacity`、`animations` 和 `onClick`。完整列表见 [Path](/kernel/components/draw/path)；事件如何在渲染后绑定，见 [Hydration](/kernel/packages/render/hydration)。

## 作为 Node 形状

当你要的是一个星形**节点**（可被连线引用、当图标 glyph）而不是一条线时，给 `<Node>` 设 `shape={{ type:'star', params }}`。尺寸由半径参数定、**不依赖文字内容**。

### 用法

```tsx
import { Node } from '@retikz/react';
```

```tsx
<Node shape={{ type: 'star', params: { points: 5, innerRadius: 16, outerRadius: 40 } }} />
```

### 例子

| shape | params                                          | 说明               |
| ----- | ----------------------------------------------- | ------------------ |
| star  | `{ points, innerRadius, outerRadius, rotate? }` | 内外半径交替的星形 |

> Node `star` 的约束：`points` 为 ≥3 的整数，`outerRadius` 必须 > `innerRadius`（违反编译期 refine 报错）。注意与 Sugar `<Star>` 的最小值不同——`<Star>` 允许 `points ≥ 2`。

playground 固定目标星形在原点。调整 `cornerRadius` 会同时磨圆外凸尖角和内凹槽；自动贴边随轮廓内移，而 `tip-0` / `notch-0` 仍固定在原始逻辑顶点。也可切换方位或数字 anchor，并通过轨道角度与距离移动来源节点，比较自动落点。

<ComponentPreview files="node-connection-playground" size="md" />

完整命名格式为 `tip-N`（第 N 个尖角）/ `notch-N`（第 N 个凹角）。Node 的通用尺寸、边界与 anchor 见 [Node 几何](/kernel/components/node/overview)。

### API 参考

| `shape`                    | params                                                                 | 边界 / 用途        |
| -------------------------- | ---------------------------------------------------------------------- | ------------------ |
| `{ type: 'star', params }` | `points` / `innerRadius` / `outerRadius` / `rotate?` / `cornerRadius?` | 可连接的星形 glyph |

`cornerRadius`（用户单位）同时给尖角与凹角倒角，省略 / `0` = 硬角，逐角夹紧。

### 内外半径交替取点（两者）

设 `p = points`。图中的橙色尖角落在外圆 `R` 上，蓝色凹角落在内圆 `r` 上；两类点按索引交替排列。

<ComponentPreview files="star-vertex-construction" size="sm" hideCode />

轮廓总共有 `2p` 个顶点，相邻顶点的角度步进是 `180° / p`。Sugar 显式传入 `innerRadius` 时直接使用，否则按 `outerRadius × innerRatio` 计算；Node star 则要求同时提供内外半径。`rotate` 只改变第一个尖角的起始方向，后续顶点继续按固定步进展开。

### 同一轮廓，两种消费方式（两者）

两种入口都先得到交替顶点轮廓，区别从这里开始：Sugar 把轮廓变成一条可绘制的 Path，Node shape 则把它变成可布局、可连接的命名几何。

<ComponentPreview files="star-output-flow" size="sm" hideCode />

Sugar 把 `rotate` 直接烘焙进顶点坐标，再输出 `move + line × (2p - 1) + cycle`；底层 Path 不再携带 `rotate`，避免绕包围盒中心二次旋转。Node star 会从顶点求外接盒，并复用轮廓处理自动贴边、`tip-N` / `notch-N` anchor 与 Scene 路径；`cornerRadius` 改变圆角轮廓和自动贴边点，但命名 anchor 仍固定在原始逻辑顶点。

图左同时标出了两种旋转基准：Sugar 的 `rotate:-90` 与 Node star 的 `rotate:0` 都让第一个尖角朝上。若要让显式角度下的两种写法保持同一朝向，Node 的值应比 Sugar 大 `90°`。此外，Sugar 允许 `points ≥ 2`，Node star 要求 `points ≥ 3`。
