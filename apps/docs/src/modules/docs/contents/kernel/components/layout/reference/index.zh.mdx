本页收录 React 的 `Layout` 与执行配置、Vanilla 的 `scene` / `layer` 与场景输入，以及 Core 的 `IRScene` / `IRViewBox`。Vanilla 使用 `scene` 构造输入，再交给 `mount` 等宿主入口；没有同名 `layout` 构造函数。

首次调用见[基础用法](/kernel/components/layout/usage)，持久化字段见下方 Schema 页签，挂载、更新与释放见 [Vanilla](/kernel/packages/vanilla)。

场景根的 `animations` 接受只读轨道数组。解析 Scene 时只浅冻结输出的数组，不冻结调用方的数组。
