画图首先要回答两个问题：一个点在哪里，以及多个对象之间怎样保持位置关系。坐标系给整张图提供共同的方向与尺度，定位则用这些规则放置具体对象。这里从看得见的位置变化开始，不要求编译器知识。

## 职责一览

| 章节   | 职责                     | 何时阅读                 |
| ------ | ------------------------ | ------------------------ |
| 坐标系 | 统一方向、单位与显示范围 | 确定坐标含义或调整取景   |
| 定位   | 描述点与对象的位置关系   | 对齐、偏移或跟随其他对象 |

## 从位置到关系

最直接的方式是为每个对象填写 `[x, y]`。x 向右增大，y 向下增大；知道了这个方向，就能把草图中的位置放进画布。圆周上的位置也可以用角度和距离表达，最终仍落在同一张二维图里。

但很多图更关心关系：标题在图形上方，说明跟着节点移动，标记始终位于两个端点之间。这时应描述“相对谁、怎样放”，让位置由关系计算，而不是反复修改几个互相依赖的数字。

## 两点之间的标记

下图先确定 A、B 的位置，再把三个标记放在两点之间的 25%、50%、75% 处。观察中间的 50%：它表达的是“A、B 的中点”，不是某个固定坐标。

<ComponentPreview files="/kernel/components/basic/position/positioning-between" size="sm" hideCode />

如果把 B 移远，这三个标记仍保持各自的比例位置。A、B 的坐标确定基础位置，比例定位维护对象之间的关系；这正是本组两个章节的分工。沿路径走过长度的 50% 则是另一个问题，不能把直线上的比例点与曲线路径上的点混为一谈。

## 图内位置与显示范围

对象位置属于图形内部，显示范围决定用户看到哪一块。`viewBox` 可以理解为观察图形的窗口：改变窗口不等于把节点移动到新的坐标。

普通图形通常使用自动取景，先把对象的位置关系写正确即可。需要固定观察范围、对齐多张图的视图时，再深入了解用户单位、显示尺寸与 `viewBox` 的关系。

## 阅读建议

先读坐标系，建立方向和尺度；需要对齐、偏移或跟随其他对象时，再读定位。连线为什么停在节点边缘、怎样固定连接点，属于[核心概念](/kernel/components/core)，不需要在这里提前掌握。继续阅读时，先通过核心概念总览理解对象与连接的关系，再按任务进入 Node、Draw 或 Layout 的用法文档。
