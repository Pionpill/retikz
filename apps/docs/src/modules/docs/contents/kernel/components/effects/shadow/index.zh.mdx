---
title: 阴影
description: 为 Node 或 Path 的主几何添加投影，可用预设快速设置，也可用对象精确控制。
---

`shadow` 是图元级的视觉效果属性，`<Node>` 和 `<Path>` 都能直接写。它作用于**该图元本身**——Node 的 shape、Path 的主路径（含其端点箭头）。Node 的文字 / 标签 / 引脚是独立图元，不带投影。它是 renderer 无关的：SVG 与 Canvas 两端各自翻译成原生能力，并把视觉口径校准到接近。

## 用法

```tsx
import { Node } from '@retikz/react';
```

```tsx
<Node shape="rectangle" fill="white" shadow="md" />
```

## 例子

`shadow` 给主几何加一层 drop shadow。预设字符串与对象是同一个字段的两种填法。

### 预设档位

最简写法是 Tailwind 风格的预设字符串：`'sm'` / `'md'` / `'lg'` / `'xl'` / `'2xl'` / `'none'`。档位越大，投影越远、越柔。`'none'` 表示显式无阴影（等价于不写）。

<ComponentPreview files="shadow-presets" size="sm" caption="同一张白卡分设五个预设档位。" />

### 对象写法

需要精确控制时，用对象 `{ preset?, offsetX?, offsetY?, blur?, color?, opacity? }`：

- 给了 `preset`，就以该档位为**默认基底**，任意同时出现的字段逐项覆盖——`{ preset: 'md', color: '#3b82f6' }` 就是「md 的位移和模糊 + 换个颜色」的快捷调色。
- 不给 `preset`，则必须自定 `offsetX` + `offsetY`（完整显式）。

优先级始终是：**显式字段 > preset > 默认**。颜色默认是半透明黑 `rgba(0,0,0,0.5)`；给了 `opacity` 会相乘到颜色的有效 alpha 上。

### 图元级，不是组级

`shadow` 跟随图元本身。Node 的文字 / 标签 / 引脚是**独立图元**，不带投影——需要「整张卡片连文字一起浮起」时，本字段做不到（它是图元级、不是组级效果）。但 Path 的端点箭头属于主路径这一图元，会**随主路径一起投影**（与 SVG 元素级 filter / Canvas 同一绘制过程的原生语义一致）。

### 从输入到主几何

`shadow` 的两种写法只存在于输入阶段。编译时，预设先展开为位移、模糊和颜色，随后由对象中的显式字段逐项覆盖；最终结果收敛为一份统一的阴影描述，再附着到 Node shape 或 Path 主路径。renderer（渲染后端）因此不需要理解预设名称。

### 自动布局与固定裁切

阴影会伸出原始几何边界。自动布局会按“每侧 `blur` + 朝该侧偏移的部分”扩展包围盒（bbox，能包住图元的最小轴对齐矩形），再把结果并入 Scene 的可视范围；显式 `viewBox` 则始终代表用户指定的固定窗口。

| 布局方式           | 编译行为                   | 用户可见结果                 |
| ------------------ | -------------------------- | ---------------------------- |
| 未设置 `viewBox`   | 合并几何与阴影外溢范围     | 画布自动给阴影留出空间       |
| 显式设置 `viewBox` | 固定窗口覆盖自动布局的结果 | 窗口外的阴影仍可能被画布裁掉 |

### SVG 与 Canvas 如何映射

Scene 保留的是 renderer-agnostic（不绑定渲染后端）的用户单位。SVG 与 Canvas 消费同一份阴影描述，但会翻译到不同的原生能力：

| 后端   | 原生映射       | 校准与资源策略                                      |
| ------ | -------------- | --------------------------------------------------- |
| SVG    | `feDropShadow` | `userSpaceOnUse` 外扩滤镜区域<br />相同阴影复用 def |
| Canvas | `ctx.shadow*`  | 按当前变换换算位移与模糊<br />绘制后恢复 context    |

SVG 把 `blur` 映射为高斯标准差，并以扩展后的 Scene 窗口作为滤镜区域，避免细 Path 或大阴影被元素自身的包围盒裁掉；配置完全相同的阴影只生成一个 filter def。Canvas 则读取当前变换矩阵（CTM），把位移和模糊校准到实际绘制尺度；`opacity` 会在 CSS 颜色归一后烘焙进 `shadowColor`。两端不承诺逐像素相同。

## API 参考

`shadow` 是 `<Node>` 与 `<Path>` 共有的样式属性，写法一致。

| 属性     | 类型                                                | 默认值 | 描述                                         |
| -------- | --------------------------------------------------- | ------ | -------------------------------------------- |
| `shadow` | <ApiValues name="ShadowPreset" /> \| `IRDropShadow` | —      | 主几何的投影配置；对象优先级与作用边界见上文 |

### shadow 对象字段

| 属性      | 类型                              | 默认值             | 描述                                                                                |
| --------- | --------------------------------- | ------------------ | ----------------------------------------------------------------------------------- |
| `preset`  | <ApiValues name="ShadowPreset" /> | —                  | Tailwind 风格档位，作为 offsetX / offsetY / blur / color 的默认基底；显式字段覆盖之 |
| `offsetX` | `number`                          | `0`（preset 提供） | 水平位移（用户单位）                                                                |
| `offsetY` | `number`                          | preset 提供        | 垂直位移（用户单位，正值向下）                                                      |
| `blur`    | `number`（≥0）                    | preset 提供        | 模糊半径（用户单位）；`0` = 硬边                                                    |
| `color`   | `string`                          | `rgba(0,0,0,0.5)`  | 阴影颜色，任意 CSS 颜色                                                             |
| `opacity` | `number`（0~1）                   | —                  | 阴影不透明度，相乘到 color 的有效 alpha 上                                          |
