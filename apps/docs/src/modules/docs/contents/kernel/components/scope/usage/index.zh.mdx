title: 基础用法
description: 使用 Scope 组织局部坐标、整体引用、样式默认值与裁剪
---

用 Scope 让一组图元一起移动、共享默认值或接受裁剪。它放在 Layout 内，也可以嵌套；每个 Scope 只改变自己包含的子树。

`defaults.style` 可统一设置后代节点和路径的 `lineCap`、`lineJoin`、`shadow` 与 `blendMode`。阴影和混合模式逐个作用于后代的主体几何，不会把 Scope 合成为一张图层。

## 接入方式

选择宿主与输入形式：React 使用 JSX 或 `ir` 属性；Vanilla 使用构造函数或直接传入 IR。四种写法都保留左侧 `x = 0` 参照，并让 Scope 内的 A、B 整体向右平移 80。

```text
Layout
├── Node

    ├── Node
```

从 `@retikz/react` 导入组件，直接声明 Scope 及其子树。

```tsx
import { Draw, Layout, Node, Scope } from '@retikz/react';
import type { FC } from 'react';

const Demo: FC = () => (
  <Layout>
    <Node id="origin" position={[0, 0]}>
      x = 0
    </Node>
    <Scope position={[80, 0]}>
      <Node id="A" position={[0, 0]}>
        A
      </Node>
      <Node id="B" position={[100, 0]}>
        B
      </Node>
      <Draw way={['A', 'B']} arrow="->" />
    </Scope>
  </Layout>
);

export default Demo;
```

从 `@retikz/core` 导入 IR 类型，把 Scope 子树交给 `<Layout ir>`，无需 JSX children。

```tsx
import type { IRScene } from '@retikz/core';
import { Layout } from '@retikz/react';
import type { FC } from 'react';

const ir: IRScene = {
  version: 1,
  type: 'scene',
  children: [
    { type: 'node', id: 'origin', position: [0, 0], text: 'x = 0' },
    {
      type: 'scope',
      position: [80, 0],
      children: [
        { type: 'node', id: 'A', position: [0, 0], text: 'A' },
        { type: 'node', id: 'B', position: [100, 0], text: 'B' },
        {
          type: 'path',
          arrow: '->',
          children: [
            { type: 'step', kind: 'move', to: { id: 'A' } },
            { type: 'step', kind: 'line', to: { id: 'B' } },
          ],
        },
      ],
    },
  ],
};

const Demo: FC = () => <Layout ir={ir} />;

export default Demo;
```

从 `@retikz/vanilla` 构造 Scope，通过 `/dom` 的 `mount` 挂载到已有的 `diagram` 容器。

```ts
import { node, path, scene, scope } from '@retikz/vanilla';

const input = scene({

      node({ id: 'A', position: [0, 0], text: 'A' }),
      node({ id: 'B', position: [100, 0], text: 'B' }),
      path({ way: ['A', 'B'], arrow: '->' }),
    ]),
  ],
});

const view = mount(document.getElementById('diagram')!, input);
```

Scope 的后代不能通过命名引用使用任一祖先 Scope 的中心、锚点或边界，包括嵌套 Node、Coordinate、Scope 和 Path；这类引用会抛出错误，即使 Path 延迟到包络完成后求值也不例外。外部 Path 仍可连接该 Scope，Scope 也仍可引用合法的外部 Node 定位，并用自身包络确定 pivot 或 selfAnchor。同名局部节点按命名空间正常解析，不因名称与祖先相同而被禁止。

## 何时使用

| 分类       | 属性                   | 作用                                            |
| ---------- | ---------------------- | ----------------------------------------------- |
| 整体对象   | `position`             | 设置父坐标系位置，或按自身锚点对齐整组          |
|            | `id` + `boundingShape` | 让整组可从外部引用；包络不计入 path 走线        |
| 子树上下文 | `transforms`           | 整体变换子图；不计算子元素原始位置              |
|            | `localNamespace`       | 隔离可复用子图 id；`scope.id` 仍注册到外层      |
|            | `theme`                | 切换局部领域主题；Core 图元不会自动着色         |
|            | `defaults`             | 统一默认值；元素显式值仍然优先                  |
|            | `clip`                 | 限制子树可见区域；不定义 renderer 专属语义      |
|            | `zIndex`               | 调整整组相对父级内容的栈序；不重排组内 children |

## 变换输入

五种平移写法与 Node 的相对定位模型一致；`rotate` 与 `scale` 负责局部坐标系的方向和尺度。数组顺序沿用 SVG transform list：最后一项先作用到局部点。

| kind                | 核心字段                       | 作用                          |
| ------------------- | ------------------------------ | ----------------------------- |
| `translate`         | `x`, `y`                       | 固定笛卡尔平移                |
| `polar-translate`   | `origin?`, `angle`, `radius`   | 从原点或参照对象的极坐标落点  |
| `at-translate`      | `direction`, `of`, `distance?` | 落到参照对象的某个方向        |
| `offset-translate`  | `of`, `offset?`                | 在参照对象上叠加局部偏移      |
| `between-translate` | `between`, `fraction`          | 落到两个端点的比例位置        |
| `rotate`            | `degrees`, `pivot?`            | 绕 Scope 自身点旋转           |
| `scale`             | `x`, `y?`, `pivot?`            | 绕 Scope 自身点等比或分轴缩放 |

## 局部坐标

`position` 有两种形式，`transforms` 则始终表示附加局部变换：

| 形式     | 示例                                                                      | 结果                                                   |
| -------- | ------------------------------------------------------------------------- | ------------------------------------------------------ |
| 原点位置 | `position={[100, 50]}`                                                    | 在父坐标系放置局部原点；自身旋转和缩放不改变这段主位置 |
| 锚点对齐 | `position={{ kind: 'anchor', target: { id: 'T' }, selfAnchor: 'right' }}` | 将变换后的右侧锚点精确对齐 T                           |

省略位置与 `[0, 0]` 的几何结果相同。原点位置 `[100, 50]` 加局部 `translate(10, 0)` 后，原点在 `[110, 50]`；锚点形式则会抵消影响精确对齐的平移，要继续偏移应修改 target 或 target.offset。

`O` / `T` 是固定参照点，`q` 提供固有包络。在面板中调整原点位置和七种 transform，或开启锚点对齐，观察两种定位形式的区别。

锚点形式的 `position.target` 只接受父坐标系 `[x, y]` 或此前完成的 `{ id, anchor?, offset? }`；`selfAnchor` 缺省为 `center`，也可写标准 anchor、数字角度、`{ side, fraction }`、`origin` 或显式局部坐标。

`rotate.pivot` 与 `scale.pivot` 使用同一套自身点并缺省为 `origin`。pivot 只读取 position 之前的固有包络，因此移动 Scope 不会反过来改变旋转或缩放中心。其它相对方向仍在当前局部坐标系中解释，Scope 旋转后，`right` 的视觉方向会随坐标轴旋转。

## 裁剪与层级

所有裁剪都使用 `{ kind, params }`：`kind` 选择裁剪定义，必填的 `params` 对象保存该类型的参数，例如 `{ kind: 'rect', params: { x: 0, y: 0, width: 100, height: 80 } }`。

`clip` 使用 Scope 局部坐标，并把裁剪结果作为渲染无关的 Scene 资源交给下游。面板展示 Core 的 `rect`，以及由 Extension 提供并注入的 `circle` / `ellipse` / `polygon` / `path` / `compound`；需要业务 operation 或几何 kind 时再注册[自定义裁剪区](/kernel/components/scope/custom)。

## 补充说明

**局部 Theme。** `<Scope theme>` 把稀疏的 `name` / `mode` selector 写入 `IRScope.theme`，只影响其后代 Composite。字段逐项继承：例如 `{ mode: ThemeMode.Dark }` 只切换明暗环境，仍保留外层的 `name`。编译时 Core 根据当前 theme registry 重新生成 shared colors；未注册的主题 会立即报错。完整示例见 [Layout 的可继承 Theme](/kernel/components/layout/extend#主题配置)。

Theme 与样式默认值是两条独立通道：`defaults.reset` 不重置 Theme，Theme 也不直接填充 Node / Path 的颜色。省略 `name` 时使用所属包的默认基线；在嵌套 `Scope` 中省略 `name` 会继承外层风格，不能重置为基线。

**样式默认值。** Scope 同时提供 `defaults.style.color`、`defaults.style` 中的共享视觉属性与 `defaults.node` / `defaults.path`。这些值逐字段向内继承，元素显式值优先；`defaults.reset` 只切断指定通道的外层继承。

标签默认归宿主所有：`defaults.node.label` 支持节点标签的位置、对齐、距离、旋转、引线及视觉配置；`defaults.path.label` 支持路径和步骤标签的沿线位置、倾斜、断线及视觉配置；`defaults.path.arrow` 配置已有箭头及其两端覆盖。这些片段不包含标签正文，也不创建标签或箭头。

`font` 在嵌套 Scope 与实例之间按字段继承，只改字号不会清除字体族或字重。`reset: ['node']` 同时切断节点与其标签默认；`reset: ['path']` 同时切断路径、标签和箭头默认；`true` 切断两个宿主通道，当前层配置仍然生效。

共享描边包含 `stroke`、`strokeWidth`、`dashPattern` 和 `dashOffset`。例如 `defaults: { style: { dashPattern: [6, 2], dashOffset: -2 } }` 同时影响后代 Node 边框和 Path。当前层的通道默认覆盖共享默认，元素显式样式再覆盖通道默认；虚线数组整体替换，`dashOffset: 0` 可覆盖继承相位。省略字段继续继承，使用 `defaults: { reset: ['node'] }` 可切断 Node 通道的外层虚线而保留 Path 通道；空虚线数组不合法。

样式是 Scope 的辅助职责，不改变局部坐标、引用或裁剪语义。需要查字段时查看 [API 参考](/kernel/components/scope/reference)，不必为颜色、线宽或透明度建立额外 Scope。

## 可见容器

Scope 保留内容包络与引用，但不绘制自身外框。需要背景、边框或内边距时使用 [Surface](/library/standard/presentation/surface)；需要标题框时使用 [Frame](/library/standard/presentation/frame)。

## 错误与限制

- anchor 形式的 `position` 只能引用此前已完成的目标，不能引用自身、后代或尚未完成的 Scope。
- 零缩放可以用于视觉效果，但跨越它反算局部坐标会失败。
- 同一命名空间的重复 id 会警告并采用后定义；可复用子图用 `localNamespace` 隔离内部 id。
- 基础 Scope 不提供布局检查属性；需要检查子树时使用 Layout 包的 `LayoutInspectScope`。

## 按宿主设置标签与箭头默认值

节点标签和路径标签分别配置。下面的标签只提供内容，其位置、间距、字体和箭头外观从宿主默认继承；没有 label 或 arrow 的图元不会因此产生装饰。

```tsx
<Scope
  defaults={{
    node: { label: { position: 'bottom', distance: 12, font: { size: 14 } } },
    path: {
      label: { side: 'top', distance: 8, sloped: true },
      arrow: { length: 10 },
    },
  }}
>
  <Node id="a" position={[0, 0]} label={{ text: 'A' }} />
  <Node id="b" position={[100, 0]} label={{ text: 'B' }} />
  <Draw way={['a', 'b']} arrow="->" label={{ text: 'A → B' }} />
</Scope>
```
