---
title: 绘制
description: 用 Draw 快速连接目标，或用 Path 与 Step 精确描述路径；同一模型还支持扩展曲线段、整条路径与箭头端点。
---

这一组解决“如何把目标连成一条可渲染路径”。日常连线从 Sugar（便捷写法）`<Draw>` 开始；需要逐段控制或多次移动时，改用 Kernel（底层契约）`<Path>` + `<Step>`；需要表达可变宽带状关系时使用 `<Path kind="ribbon">`。这些入口最终进入同一套 Path 语义，箭头也由 Draw 与 Path 共享。

绘制家族只负责路径的结构、几何、样式和端点，不负责节点本身的形状与定位，也不负责 flow / graph 等领域布局。内置能力不够时，再从分组末尾选择路径生成器、自定义路径或自定义箭头。

## 职责一览

| 组件       | 类型               | 职责                                                                  | 适合场景                           |
| ---------- | ------------------ | --------------------------------------------------------------------- | ---------------------------------- |
| Draw       | Sugar              | 用 way 数组声明目标、段算子、标注与整条路径样式，并展开为 Path + Step | 日常连线、流程图边、带箭头连接     |
| Way        | Sugar              | 定义 Draw 数组里的目标、折角、闭合、曲线与相对坐标写法                | 查询 way 数组里能写什么            |
| Path       | Kernel             | 路径容器，由 Step 子节点定义折线、曲线与弧形                          | 多次 move、逐段精确控制、贴近 IR   |
| Ribbon     | Standard Path kind | 用 Path 中心线或预计算边界生成可填充的可变宽带状关系                  | 流向、桑基关系或其它带宽编码       |
| Step       | Kernel             | 一个 step = 一个动作：move / line / curve / arc / cycle 等            | 逐段控制每一段路径动作语义         |
| Arrow      | 通用               | Path / Draw 共享的箭头方向与视觉规格                                  | 精细控制形状、尺寸、颜色与起末差异 |
| 路径生成器 | 扩展               | 为 generator step 注册新的曲线生成器                                  | 添加波形、参数曲线等新曲线段       |
| 自定义路径 | 扩展               | 注册接管整条 Path 的 kind provider                                    | 双线、高亮线或业务关系线           |
| 自定义箭头 | 扩展               | 注册新的箭头端点样式                                                  | bracket 或领域专用箭头             |
