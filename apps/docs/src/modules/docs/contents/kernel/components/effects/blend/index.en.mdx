---
title: Blend
description: Blend a Node or Path's primary geometry with painted content beneath it through the same mode set in SVG and Canvas.
---

`blendMode` is an element-level visual-effect prop you can set directly on `<Node>` and `<Path>`. It applies to **the primitive itself** — the Node shape, the Path main path (including its endpoint arrows). A Node's text / label / pin are separate primitives and are not blended. It is renderer-agnostic: SVG and Canvas each translate it to native capabilities with the same result.

## Usage

```tsx
import { Node } from '@retikz/react';
```

```tsx
<Node shape="circle" fill="magenta" blendMode="multiply" />
```

## Examples

`blendMode` blends the primary geometry with the **content already drawn beneath it** using the standard W3C modes: `multiply` darkens, `screen` lightens, `overlay` boosts contrast, and so on. The value is one of these 16 modes:

`normal` / `multiply` / `screen` / `overlay` / `darken` / `lighten` / `color-dodge` / `color-burn` / `hard-light` / `soft-light` / `difference` / `exclusion` / `hue` / `saturation` / `color` / `luminosity`.

Omitted or `'normal'` = ordinary source-over, unchanged.

With two or more overlapping elements, set `blendMode` on the upper one to see the blend in the overlap. `multiply` darkens the overlap over a light backdrop:

## How it works

  type="tip"
  title="Optional for everyday use"
  description="Revisit when you need to understand why drawing order, opacity, or group boundaries change a blend."

### Source and backdrop

Blending happens where the current primitive overlaps previously drawn pixels. The current primitive is the source; the accumulated result of primitives before it in the Scene's final painting order is the backdrop:

| Role     | Meaning                       | Purpose                   |
| -------- | ----------------------------- | ------------------------- |
| Backdrop | Earlier Scene output          | Pixels beneath the source |
| Source   | Current primary geometry      | Supplies color and alpha  |
| Result   | `B(Cb, Cs)`, then source-over | Mixes only the overlap    |

`blendMode` selects the color-mixing function; it does not replace `opacity`. After mixing, ordinary `source-over` compositing still combines both alpha values, so a transparent backdrop weakens the blend. Changing declaration order or `zIndex` changes which primitive is the source and which is the backdrop. Modes such as `overlay` and `hard-light`, which assign different roles to the two inputs, can therefore produce a different result.

The first 12 modes (`normal` through `exclusion`) are separable and operate per color channel. `hue` / `saturation` / `color` / `luminosity` are non-separable and consider hue, saturation, and luminosity together. `normal` performs no extra mixing, so it is equivalent to omitting `blendMode`.

### Primitive boundary and backend mapping

Compilation does not create an extra group for blending. It keeps the mode on the Node's primary shape or the Path's primary-path primitive, then each renderer maps the same value to its native blend capability:

| Contract         | SVG                  | Canvas                     |
| ---------------- | -------------------- | -------------------------- |
| Non-normal value | `mix-blend-mode`     | `globalCompositeOperation` |
| Omitted / normal | No extra blend style | Keep `source-over`         |
| State boundary   | Current geometry     | Save → draw → restore      |

This explains the element boundary: SVG marker / filter output follows the current geometry element, while Canvas switches state only while drawing the current primitive. A Node's text, labels, and pins are later independent primitives and do not inherit the primary shape's blend. A Path's endpoint arrows are drawn inside the main path's effect boundary. `opacity` and `shadow` can coexist with blending; together they form the current source before it is blended with the backdrop.

## API Reference

`blendMode` is a shared style prop on `<Node>` and `<Path>`, written the same way on both.

| Prop        | Type                                                                                                                                                                                                                                                       | Default    | Description                                   |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- | --------------------------------------------- |
| `blendMode` | `'normal' \| 'multiply'`<br />`'screen' \| 'overlay'`<br />`'darken' \| 'lighten'`<br />`'color-dodge' \| 'color-burn'`<br />`'hard-light' \| 'soft-light'`<br />`'difference' \| 'exclusion'`<br />`'hue' \| 'saturation'`<br />`'color' \| 'luminosity'` | `'normal'` | Blends primary geometry; see boundaries above |
