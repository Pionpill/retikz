`text` 是节点正文，`label` 是附在节点边界或中心的独立文字。先看[基础用法](/kernel/components/node/usage)，本页只讲附加标签；标签不会撑大节点形状。

## 接入方式

在 Node 上写一个 `label` 对象，就能把独立文字附到节点边界。下面四种写法都把 `status` 附到同一个节点上；Vanilla 示例需要页面已有 `<div id="diagram"></div>`。

## 添加标签

`label` 接受一个对象或对象数组。先选择附着位置，再按需调整样式：

- `position` 默认 `'top'`，支持 `'top'`、`'top-right'`、`'right'`、`'bottom-right'`、`'bottom'`、`'bottom-left'`、`'left'`、`'top-left'` 八个方向
- 还可写中心 `'center'`、角度 `30`，或边界比例 `{ boundary: 'right', fraction: 0.25 }`；中心标签不做重叠避让
- `placement` 默认 `'outside'`，写 `'inside'` 可放在边框内侧
- `font` / `textColor` 优先使用标签显式值，再使用 `Scope.defaults.label`，仍未提供的值从节点继承
- `opacity` 为 0..1，与节点透明度相乘

## 标签位置

在同一个标签上选择命名方位、数字角度、边界比例或中心；中心标签会隐藏无效的位置字段。

<ComponentPreview files="node-label-position" size="md" />

需要同时附加多个标签时，把同一份对象写法放进数组：

```tsx
import type { IRScene } from '@retikz/core';
<Node
  position={[0, 0]}
  label={[
    { text: 'status', position: 'top' },
    { text: 'owner', position: 'bottom' },
  ]}
/>;
```

## 间距与内外侧

`distance` 是节点边界与**旋转后标签视觉框**之间沿摆放方向的净距，省略时使用 `<Layout labelDistance>`（默认 `12`）；写 `0` 时视觉框恰好贴住边界。`placement: 'inside'` 会把方向转向节点内部，并在边界内侧保留同样的净距；矩形节点还可以写 `position: { boundary, fraction }`，把标签附着到某条边界的比例位置上。`position: 'center'` 始终使用最终节点矩形中心，会忽略 `placement` 与 `distance`。

- `boundary` 接 `'top'` / `'right'` / `'bottom'` / `'left'`
- `fraction` 是边界上的 0..1 比例位置，缺省 `0.5`
- `placement: 'inside'` 不能和 `pin` 同时使用；需要引线时请保持外侧标签

## 旋转与引线

`label.rotate` 让标签文字绕**自身中心**自旋：`'radial'` 沿 `position` 定义的方向，边界比例位置使用所选边的外法向；`'tangent'` 取其切向（radial + 90°），数字为显式角度（度）。`placement: 'inside'` 只反转标签偏移，不反转该朝向；`keepUpright` 在文字会倒置时翻 180° 保持可读。旋转会改变视觉框沿摆放方向的投影，所以编译器会相应移动标签中心，保证 `distance` 仍是同一个净距。

`label.pin` 给标签加一条**引线**连回节点边界：`pin: true` 是默认细实线（继承标签色）；`pin: { stroke, strokeWidth, dashPattern, dashOffset }` 自定义引线样式；不写 / `false` 则无引线。引线终点是摆放射线与旋转后视觉框的精确交点，没有额外隐藏留白；标签摆放仍只由前述盒几何决定。

## 标签样式

位置固定为右侧外置标签，用面板单独调整文字颜色、字号和透明度。
