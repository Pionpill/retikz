Read [Layers](/kernel/components/design/layers) first. This page follows one synchronous call to `compileToScene(IRScene, options)`: validated drawing input becomes Scene, domain artifacts, and a spatial index. DOM mounting and subsequent incremental updates are outside this execution.

| Input / output          | Purpose                                         |
| ----------------------- | ----------------------------------------------- |
| `IRScene` input         | Validated, savable drawing declaration          |
| `result.scene`          | Laid-out drawing for renderers                  |
| `result.artifacts`      | Domain data from the same call for applications |
| `result.spatialHandles` | Named-region index from the same call for tools |

The last two are additional results outside Scene.

## Create the call context

The context holds measurement functions, a warning collector, and capability registries for this call. A registry selects an implementation by name; built-in and caller-provided Definitions share the same consumers. `createCompileContext` prepares these inputs and handles expandable high-level nodes.

## Lay out entities and resolve paths

A namespace maps ids to objects in the current group. Traversal positions and registers Nodes and Coordinates. A Path can reserve its output position until dependencies in its group are ready. This supports paths to later nodes in the same group; it does not permit arbitrary forward references in entity positioning.

Composites that need child measurements run isolated trials here and commit the chosen result. See [Composite implementation](/kernel/components/composite/mechanism) for proposals, probes, and replay.

## Assemble the result

`compileCoreSnapshot` collects primitives, paint resources, and root animations. An explicit viewBox sets the visible range; otherwise layout bounds and padding determine it. Spatial indexes and domain artifacts accompany Scene, but are not drawing declarations for renderers to reinterpret. The synchronous entry dispatches collected warnings after success; a fatal error ends the call without returning a partially successful Scene.
