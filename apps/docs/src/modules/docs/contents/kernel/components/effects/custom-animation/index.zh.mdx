内置动画已经覆盖常见的透明度、颜色、变换、描边与镜头变化。需要新的运动节奏时注册缓动；需要动画驱动新的 Canvas 属性时注册属性通道。

下面给 `scaleIn()` 注册一个带回弹感的 `spring` 缓动。动画轨道仍只保存字符串名称。

## 适用边界

先判断要扩展的是“时间曲线”还是“被改变的属性”：

| 需求             | 扩展入口              | 后端                   |
| ---------------- | --------------------- | ---------------------- |
| 改变快慢节奏     | `easings`             | SVG + Canvas（四元组） |
| 使用 JS 缓动函数 | `easings`             | Canvas 实时；两端截帧  |
| 驱动新的属性     | `animationProperties` | Canvas                 |

如果内置通道已经能表达属性，只需换 easing 或手写关键帧，不必新增属性通道。自定义属性通道当前依赖 Canvas 2D context，因此不适合需要 SVG 等价输出的内容。

## 定义能力

### 缓动曲线

缓动注册值直接使用 cubic-bezier 四元组或 `(t) => number` 函数，不需要额外的 Definition 对象：

```tsx
import type { EasingRegistry } from '@retikz/render/animation';

const easings = {
  spring: [0.34, 1.56, 0.64, 1],
} satisfies EasingRegistry;
```

四元组可进入 SVG CSS 与共享求值器。函数需要 JavaScript：Canvas 可实时播放，SVG 与 Canvas 的 `snapshotAt` 都能静态求值；SVG 实时播放无法把函数写进 CSS。四元组的 y 值可以超出 `[0, 1]`，用于回弹或越界效果。

### 属性通道

新的属性通道需要 `AnimationPropertyDefinition`：`interpolate` 计算相邻关键帧之间的值，`applyCanvas` 把当前值应用到正在绘制的图元。

```tsx
import type { AnimationPropertyDefinition } from '@retikz/render/animation';

const blur = {
  interpolate: (from, to, t) => Number(from) + (Number(to) - Number(from)) * t,
  applyCanvas: (ctx, _primitive, value) => {
    ctx.filter = `blur(${Number(value)}px)`;
  },
} satisfies AnimationPropertyDefinition;
```

下面的示例注册 `blur`，并用一条普通 `AnimationTrack` 从模糊过渡到清晰。可以调整起始模糊与时长，属性定义本身仍完整保留在代码中：

## 注入宿主

两个注册表都由 `<Layout>` 注入。轨道通过名称引用注册项；函数和 Canvas context 不会进入 IR。

```tsx
<Layout renderer="canvas" easings={easings} animationProperties={{ blur }}>
  <Node animations={[scaleIn({ easing: 'spring' }), blurIn]} />
</Layout>
```

只注册 easing 时无需强制 Canvas：cubic-bezier 四元组在 SVG 与 Canvas 都能实时播放。函数 easing 仅限制 SVG 实时播放，静态截帧仍由共享 JavaScript 求值器处理；`animationProperties` 才始终依赖 Canvas。

## 执行机制

轨道中的 `easing` 与 `property` 都是开放字符串，但查找阶段不同：

| 扩展     | 查找时机              | 消费方式                  |
| -------- | --------------------- | ------------------------- |
| easing   | 每段关键帧求值前      | 把时间进度映射为缓动进度  |
| property | Canvas 绘制当前图元时 | 插值后写入 Canvas context |

SVG 实时播放可把 cubic-bezier 转为 CSS timing function；函数无法序列化到 CSS，因此会告警并退回 `linear`。`snapshotAt` 不生成 CSS，而是通过共享求值器采样，所以 SVG 静态帧也能使用函数 easing。自定义属性没有通用 SVG 映射，SVG 会跳过该轨道并保留图元的静止状态。

内置 easing 名称会先于自定义记录解析，内置属性通道也会先分类；自定义注册项不能覆盖内置语义。这两类扩展没有统一的 `defineXxx`：easing 的值本身足够简单，而属性通道是 renderer 专属的运行时定义。

## 错误与限制

| 情况                        | SVG                 | Canvas            |
| --------------------------- | ------------------- | ----------------- |
| 未注册 easing（实时）       | 告警并退回 `linear` | 静默退回 `linear` |
| 函数 easing（实时）         | 告警并退回 `linear` | 正常求值          |
| 函数 easing（`snapshotAt`） | 正常求值            | 正常求值          |
| 未注册 property             | 告警并跳过轨道      | 告警并跳过轨道    |
| 已注册自定义 property       | 告警并跳过轨道      | 正常求值与应用    |

跳过轨道不会丢失图元，只会渲染它的静止状态。注册表键应使用非空、稳定且不会与内置名称混淆的字符串；当前轻量注册表不会替你诊断同名覆盖。

## API 参考

### Layout 注册属性

| 属性                  | 类型                        | 默认值 | 描述                         |
| --------------------- | --------------------------- | ------ | ---------------------------- |
| `easings`             | `EasingRegistry`            | —      | 缓动名称到四元组或函数的映射 |
| `animationProperties` | `AnimationPropertyRegistry` | —      | 属性名称到 Canvas 定义的映射 |

### AnimationPropertyDefinition

| 属性          | 类型                         | 默认值 | 描述                     |
| ------------- | ---------------------------- | ------ | ------------------------ |
| `interpolate` | `(from, to, t) => unknown`   | —      | 计算当前关键帧值         |
| `applyCanvas` | `(ctx, prim, value) => void` | —      | 在图元绘制期间应用当前值 |
