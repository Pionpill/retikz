---
title: 效果
description: 为已有图元添加阴影、混合模式与动画，而不改变图元本身的结构和关系。
---

效果能力附着在 Node、Path 等已有图元上：阴影补充空间层次，混合模式控制图层如何合成，动画描述属性随时间的变化。它们不会引入另一套图元模型，而是继续沿用同一份 IR 与 Scene。

## 职责一览

| 能力 | 职责                         | 适合场景                   |
| ---- | ---------------------------- | -------------------------- |
| 阴影 | 为图元增加偏移、模糊与颜色   | 强调层次、悬浮感或空间关系 |
| 混合 | 控制图元与背景的颜色合成方式 | 叠色、高亮与特殊视觉合成   |
| 动画 | 描述属性轨道、触发方式与播放 | 入场、状态变化与交互反馈   |
