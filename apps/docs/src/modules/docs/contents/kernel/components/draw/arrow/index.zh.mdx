---

箭头由三个独立的 prop 控制：

- **`arrow`**——方向枚举：`'->'` 终点 / `'<-'` 起点 / `'<->'` 两端 / `'none'`（缺省）= 无
- **`arrowDetail`**——视觉详细配置对象，8 个顶层字段 + 可选 `start` / `end` 子对象。**省略时使用默认的 `stealth` 倒钩形状，颜色与透明度继承路径本身**
- **`arrowPlacement`**——端点放置对象，用归一化 `overlap` 控制箭头进入逻辑端点的比例，并支持 `start` / `end` 单端覆盖

三个 prop 同时挂在 `<Draw>` 和 `<Path>` 上，写法和效果完全一致——下文示例用 `<Draw>` 演示，`<Path>` 写法等价。

缺省时箭头尖端附着在路径解析后的起点 / 终点，也不会在中间节点重复出现。需要让空心圆等箭头跨过 Node 边界时，用 `arrowPlacement` 调整端点放置；它不改变 NodeTarget、anchor、boundary 或路径的逻辑采样位置。

## 用法

```tsx
import { Draw } from '@retikz/react';
```

```tsx
<Draw way={['a', 'b']} arrow="->" />
```

## 例子

### 方向、形状与外观

一个面板集中控制 `arrow` 方向、六种 Core 基础箭头与两种 Standard 可选箭头、颜色、透明度和尺寸。开启“分别配置起末”后，`start` / `end` 会逐字段覆盖顶层形状与颜色；关闭时两端共用顶层配置。面板已显式注入它使用的 Standard 定义。省略 `arrowDetail` 的默认值是继承路径颜色的 `stealth`，长度和宽度都是 8。

<ComponentPreview files="arrow-appearance" size="md" />

Core 默认提供六种基础箭头，其中包括空心三角、空心 Stealth 与圆点箭头。其余实心 / 空心菱形箭头由 [`@retikz/standard/arrow`](/library/standard/extension/arrow) 提供；使用 Standard 名称时，需要把对应 Definition 注入当前 `<Layout arrows>` 或 `CompileOptions.arrows`：

| 实心                          | 空心                              | 典型用途             |
| ----------------------------- | --------------------------------- | -------------------- |
| `'normal'` Core 实心三角      | `'open'` Core 空心三角            | 基础三角 / UML 泛化  |
| `'stealth'` Core 倒钩三角     | `'openStealth'` Core 空心倒钩     | 默认箭头、现代流程图 |
| `'diamond'` Standard 实心菱形 | `'openDiamond'` Standard 空心菱形 | UML 组合 / 聚合      |
| `'circle'` Core 实心圆点      | `'openCircle'` Core 空心圆点      | 连接点 / 空心端点    |

> 多节点路径（如 a → b → c）按段独立 clip，但箭头**只**贴在整体起点 / 终点——中间节点不会出现额外箭头。

> **合并语义**：`start` / `end` 子对象的字段优先；子对象未填的字段回退到顶层默认；顶层未填的字段回退到内置默认。例：`arrowDetail={{ shape: 'stealth', start: { color: 'red' } }}` → 起末都用 `stealth`，起端用红色，末端继承路径描边色。

> **空心形状会静默忽略 `fill`**：`shape ∈ { open / openStealth / openDiamond / openCircle }` 时，`fill` 字段被静默丢弃——空心形状由 `color`（描边色） + `lineWidth`（描边粗细）共同决定视觉，写 `fill='red'` 不会渲染红色填充。

`scale` 乘到 `length` / `width` 之后，例如 `length=10, scale=1.5` 的实际长度是 15。

### 端点重叠

`arrowPlacement.overlap` 在箭头的两种最终位置间归一化：`0` 保持现有默认放置，`0.5` 位于默认位置与完整进入位置的中点，`1` 让最终视觉后缘与逻辑端点对齐。后缘、路径接合点和尖端是三个不同的几何事实，因此带倒钩的 `stealth` 在比例为 `1` 时也会完整进入。

计算使用解析后的 `length × scale`，空心箭头还会计入 `lineWidth` 与外轮廓补偿。放大、缩小或覆盖长度后，`1` 仍表示整枚箭头的最终视觉后缘对齐，不是固定移动一段 user units。

<ComponentPreview
  files="arrow-endpoint-overlap"

  caption="切换 Core 内置箭头并拖动进入比例；重点观察放大的 stealth 尾翼在比例为 1 时完整进入 Pattern 矩形边界。"

顶层 `overlap` 只应用到 `arrow` 实际创建的端点；`start.overlap` / `end.overlap` 可逐端覆盖共享值，显式 `0` 会被保留。例如 `arrow="<->" arrowPlacement={{ overlap: 0.5, start: { overlap: 0 } }}` 只让末端进入一半。

<ComponentAlert
  type="warn"
  title="重叠不会改变绘制顺序"
  description="箭头进入节点后是否被遮挡仍由既有 zIndex 与声明顺序决定；arrowPlacement 不会自动创建裁剪、抬高箭头或改变节点填充。"
/>

`arrowPlacement` 必须对应实际端点箭头。没有箭头、配置未创建的单端、直接 IR 中的中段 mark、同侧未选中的重复端点 mark，以及非内置 Stroke Path 上的 `endpointOverlap` 都会明确报错，不会静默忽略。

### 方向与端点样式如何解析

`<Draw>` 先展开为等价的 `<Path>`。`arrow` 决定只创建起点、终点还是两端标记；每一端再分别合并 `arrowDetail` 的视觉字段与 `arrowPlacement` 的放置字段。两类对象彼此独立。

### 路径本体为什么会缩短

缺省时箭头尖端仍落在逻辑端点；compiler 根据定义里的尖端与线条接触点反向缩短路径本体，并让描边越过接触边半个自身宽度，再由 marker 覆盖接头。这样相切边界不会留下抗锯齿缝，空心箭头不会被线条贯穿，实心或半透明箭头下也不会透出多余线段。

Core 用 definition 的 `backX`、`lineContactX` 与 `tipX` 分别解析视觉后缘、主描边接合点和尖端，再让 `overlap` 在默认 shrink 与后缘对齐所需的 shrink 之间插值。端点引用 Node 且由边界自动裁切时，箭头外轮廓保护按 `1 - overlap` 衰减；用于遮住抗锯齿接缝的半线宽覆盖仍由默认位置保留。Scene 不新增 placement 字段，SVG 与 Canvas 继续执行同一份最终 commands。

### 整体端点与描边继承边界

多节点路径可能在 compile 后变成多个子路径，但起点箭头只属于第一段，终点箭头只属于最后一段，中间段不会获得端点箭头。这里的“起末”始终指整条 `<Path>`，不是每个视觉折点。

## API 参考

### arrow、arrowDetail 与 arrowPlacement

| 属性             | 类型                                    | 默认值 | 描述                                                                       |
| ---------------- | --------------------------------------- | ------ | -------------------------------------------------------------------------- |
| `arrow`          | `'none'` \| `'->'` \| `'<-'` \| `'<->'` | —      | 路径级箭头方向                                                             |
| `arrowDetail`    | `IRArrowDetail`                         | —      | 箭头详细配置；顶层 8 个视觉字段均可选，并支持 `start` / `end` 单端覆盖     |
| `arrowPlacement` | `InputPathArrowPlacement`               | —      | 端点放置配置；共享 `overlap` 与 `start` / `end` 单端覆盖，取值均为 `[0,1]` |

### arrowDetail 字段

`arrowDetail` 对象包含 8 个视觉字段 + 可选 `start` / `end` 子对象。`start` / `end` 子对象使用相同字段集（不递归），并与顶层默认逐字段合并：

| 字段        | 类型                                               | 默认值               | 描述                                                                                                                                                                  |
| ----------- | -------------------------------------------------- | -------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `shape`     | <ApiValues name="BuiltinArrowShape" /> \| `string` | `'stealth'`          | Core 基础箭头为 `normal` / `open` / `stealth` / `openStealth` / `circle` / `openCircle`；Standard 可选或自定义名称经 `<Layout arrows>` / `CompileOptions.arrows` 注册 |
| `scale`     | `number > 0`                                       | `1`                  | 等比缩放因子；乘到 `length` / `width` 之后（`length=10, scale=1.5` → 实际 15）                                                                                        |
| `length`    | `number ≥ 0`                                       | Definition / `8`     | 尖长（用户单位，沿路径方向）；Definition 未提供时使用 `8`                                                                                                             |
| `width`     | `number ≥ 0`                                       | Definition / `8`     | 尖宽（用户单位，垂直路径方向）；Definition 未提供时使用 `8`                                                                                                           |
| `color`     | `string`                                           | —                    | 描边色覆盖；缺省继承路径描边色                                                                                                                                        |
| `fill`      | `string`                                           | `color` 或路径描边色 | 填充色覆盖；**空心形状上静默无效**（写了被静默丢弃）                                                                                                                  |
| `opacity`   | `number ∈ [0, 1]`                                  | —                    | 箭头独立透明度；缺省继承路径透明度                                                                                                                                    |
| `lineWidth` | `number ≥ 0`                                       | `1.5`                | 空心形状描边粗细；实心形状忽略                                                                                                                                        |
| `start`     | `IRArrowEndDetail`（同字段集，无 `start` / `end`） | —                    | 起端覆盖配置（仅 `arrow` 含起端时生效：`'<-'` / `'<->'`）                                                                                                             |
| `end`       | `IRArrowEndDetail`（同字段集，无 `start` / `end`） | —                    | 末端覆盖配置（仅 `arrow` 含末端时生效：`'->'` / `'<->'`）                                                                                                             |

### arrowPlacement 字段

| 字段      | 类型                            | 默认值 | 描述                                              |
| --------- | ------------------------------- | ------ | ------------------------------------------------- |
| `overlap` | `number ∈ [0, 1]`               | `0`    | 从现有默认位置到最终视觉后缘对齐位置的共享比例    |
| `start`   | `{ overlap?: number ∈ [0, 1] }` | —      | 起端覆盖；仅 `arrow` 为 `'<-'` / `'<->'` 时可配置 |
| `end`     | `{ overlap?: number ∈ [0, 1] }` | —      | 末端覆盖；仅 `arrow` 为 `'->'` / `'<->'` 时可配置 |
