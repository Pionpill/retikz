---
title: Path
description: Kernel 路径容器——`<Step>` 子节点序列定义折线 / 曲线 / 弧形，最少 2 个 step；Sugar 的 `<Draw>` 编译后就是它。
---

`<Path>` 是底层路径容器：children 必须是若干 `<Step>`（至少 2 个），定义路径的 move / line / fold（折角）/ cycle（闭合）/ curve / cubic / bend（曲线）/ smooth / generator（路径生成器）/ arc / circlePath / ellipsePath（圆 / 椭圆）/ rectangle（矩形）等动作序列。日常连线用 `<Draw>` 更简洁，需要折角、闭合、曲线、自定义 stroke、不同 step kind 时回到 `<Path>`。

它最适合三类场景：一条 path 里有多个子路径（多次 `move`）、不同段要混用不同 `kind` / label / 控制点、或者你希望 JSX 结构和 IR `path.children` 几乎一一对应，方便调试和生成。

## 用法

```tsx
import { Path, Step } from '@retikz/react';
```

```tsx
<Path stroke="currentColor">
  <Step kind="move" to="a" />
  <Step kind="line" to="b" />
</Path>
```

`<Draw>` 编译后就是 `<Path>`，覆盖日常连线的 step / 折角 / 曲线 / 弧形需求；但 `<Path>` 还多出 `color` / `rotate` / `scale` / `marks` / `id` / `meta` / `animations` 等元素级能力，`<Draw>` 不暴露这些。日常连线用 `<Draw>` 一行 way 数组更省，需要显式 Step 序列、多次 `move`、逐段混用 `kind` / label / 控制点，或要用上述 Path 专属能力时用 `<Path>`：

|                                                                       | `<Draw>`      | `<Path>` + `<Step>`        |
| --------------------------------------------------------------------- | ------------- | -------------------------- |
| 写法                                                                  | 一行 way 数组 | 容器 + 子节点              |
| step / 曲线 / 折角 / 弧形                                             | 支持          | 支持                       |
| `color` / `rotate` / `scale` / `marks` / `id` / `meta` / `animations` | 不暴露        | 支持                       |
| 适用                                                                  | 90% 连线场景  | 显式 Step 序列、元素级能力 |

## 组合

`<Path>` 必须搭配 `<Step>` 子节点（至少 2 个）；首个非 `move` 时编译器会强制改成 `move`：

```tsx
<Path>
  <Step kind="move" to={...} />     {/* 第 1 个：必为 move */}
  <Step kind="line" to={...} />     {/* 之后任意多个 line / move / step */}
  ...
</Path>
```

`<Step>` 支持 13 种 kind——`move` / `line` 处理直线，`fold` 走直角折角，`cycle` 闭合回起点，`curve` / `cubic` 画贝塞尔曲线，`bend` 是弧形简记（可带 out/in 角与自环），`smooth` 画穿过点列的平滑曲线，`generator` 调用内置或自定义路径生成器，`arc` / `circlePath` / `ellipsePath` 以游标为圆心画弧 / 整圆 / 整椭圆，`rectangle` 画对角矩形，详见 [Step](/kernel/components/draw/step) 与 [路径生成器](/kernel/components/extend/path-generator)。

`arrow` 控制方向（`'->'` / `'<-'` / `'<->'` / `'none'`），`arrowDetail` 一个对象统管全部视觉规格（shape / scale / length / width / color / fill / opacity / lineWidth）+ 可选 `start` / `end` 起末分别配置。详细规则、8 种内置 shape、起末 merge、颜色 / 缩放 / 半透明配置以及完整 API 参考见 **[Arrow](/kernel/components/draw/arrow)** 专页。

### 端点连接面

端点引用节点时（`{ id }` 对象形态，或 way 里的 id），可加 `boundary` 字段，**只对这一个端点**覆盖目标节点的 [`boundary`](/kernel/components/node/overview)（连接面）。取值与节点 `boundary` 同形：`'shape'`（视觉形状自身）/ `'circle'`（真圆）/ 任意注册 shape 名 / `{ type, params }`。

```tsx
<Path arrow="->">
  <Step kind="move" to="a" />
  <Step kind="line" to={{ id: 'star', boundary: 'shape' }} />
</Path>
```

`boundary` 只在"连接面有意义"的地方生效：端点自动贴边（未显式给 `anchor`）以及该端点的标准方位 / 角度锚点。在没有方向引用的场合——`between` 端点、`offset` 的 `of`、节点中心——它是 no-op。节点默认连接面写在 [`<Node boundary>`](/kernel/components/node/overview)，端点 `boundary` 是单边覆盖。

下例同一五角星（未设节点 `boundary`），两条边各自在端点选连接面：实线默认贴真实尖端，虚线 `boundary="circle"` 改贴外接圆——连接面由边自己决定。

### 曲线与变换

#### 出 / 入射角与自环

`<Step kind="bend">` 除对称的 `bendDirection` + `bendAngle` 外，还可用 `outAngle` / `inAngle` 指定起点出射角与终点入射角，画非对称曲线（对应 TikZ `out=` / `in=`）；`looseness` 调控制点距离（松紧，缺省 ≈1）。**out/in 给定时优先于 `bendDirection`**。当 `from == to`（同节点 / 同坐标）时退化为**自环**——这是 out/in 最大价值场景（状态机自跳转），对称 bend 画不出。

<ComponentPreview name="path-outin-loop" size="sm" />

#### 整体变换（rotate / scale）

`rotate`（度）/ `scale`（数字等比，或 `{ x, y }` 非等比）把整条 path 绕**包围盒中心**变换，免去为单条 path 包一层 `<Scope transforms>`。变换顺序有硬契约：path 端点先 resolve、箭头 shrink 在**未变换的几何**上算，最后整体包进 group——故箭头方向随变换正确、不错位。

<ComponentPreview name="path-transform" size="sm" />

#### 中段标记（marks）

`marks` 沿路径放方向标记：每项 `{ pos, mark }`，`pos ∈ [0, 1]`（越界 schema 拒），`mark` 首批为 `{ kind: 'arrow', shape, ... }`（复用已注册箭头名 + 视觉子集，见 [自定义箭头](/kernel/components/extend/custom-arrow)），**朝向由该点切线决定**（不是固定方向）。直线 / 贝塞尔 / 弧段都按切线定向。尺寸与端点箭头同口径**随 `strokeWidth` 缩放**（TikZ 语义）：线越粗、标记越大。

<ComponentPreview name="path-marks" size="xs" />

#### 折线圆角（roundedCorners）

`roundedCorners` 给整条 path 的每个 **line↔line 内拐角**倒一个半径相同的圆角弧——画流程图、布线、折线连接时把硬尖角磨圆。缺省 / 省略 = 全尖角（行为不变）。首点 / 末点保持尖；接缝一侧是曲线 / 弧 / 贝塞尔 / 折角（`fold`）时该接缝也保持尖。半径过大时按相邻段长**逐拐角夹紧**到可行最大值。`cycle` 闭合后，闭合接缝也参与倒圆。

<ComponentPreview name="path-rounded-corners" size="sm" />

`roundedCorners` 改的是**路径几何**——它把拐角顶点回退并插入一段相切圆弧，因此影响包围盒、弧长、路径级 `marks` 的归一化定位和连接点解析。这和 `lineJoin` 是两码事：`lineJoin` 只改**描边视觉**，路径中心线仍是尖折。（注：step 边标注 `label` 当前仍定位在该 step 自身线段上，不随接缝倒角缩短重算。）下例用很粗的描边对照——上方 `lineJoin="round"`（只磨描边、中心线仍尖），下方 `roundedCorners`（中心线本身就是圆弧）：

<ComponentPreview name="path-rounded-vs-linejoin" size="sm" />

<Comparison target="tikz" title="roundedCorners">

`roundedCorners` 对应 TikZ 的路径选项 `rounded corners=<r>`，一个半径管全路径所有合格拐角。

</Comparison>

### 流带路径

`<Path kind="ribbon">` 用同一个 Path 宿主绘制可填充的带状关系。中心线仍然由 `<Step>` 描述，带宽、端帽、采样和边界模式放进 `ribbon={{ ... }}`；`fill`、`stroke`、`opacity`、`label`、`zIndex` 等宿主字段仍然写在 Path 顶层。

```tsx
<Path kind="ribbon" ribbon={{ start: { width: 32 }, end: { width: 12 } }} fill="#60a5fa">
  <Step kind="move" to={[-120, 0]} />
  <Step kind="cubic" control1={[-40, -48]} control2={[40, 48]} to={[120, 0]} />
</Path>
```

#### 基础流带

中心线模式会把开放路径两侧按 `width` 偏移，生成闭合 Path primitive。`stroke` 描的是流带外轮廓，不会绘制中心线。

<ComponentPreview name="ribbon-basic" size="xs" />

#### 宽度与插值

`width` 可以是固定值、起末端宽度，或 `kind: 'stops'` 的沿路径宽度表；`interpolation` 控制宽度变化方式。

<ComponentPreview name="ribbon-interpolation" size="md" />

<ComponentPreview name="ribbon-width-stops" size="xs" />

内置 `bulge` profile 用 `base` 表示两端宽度、`peak` 表示中点宽度；`peak` 小于 `base` 时会变成中间收窄。

<ComponentPreview name="ribbon-width-profile" size="xs" />

#### 标签位置

Ribbon label 使用同一套 GeometryLabel 契约。`position` 支持关键字或 `0..1` 数值；`side` 默认像普通 Path label 一样带固定外侧距离；`placement="inside"` 可把标签放入带状面内部，`sloped: true` 会沿中心线切线旋转。

<ComponentPreview name="ribbon-label" size="sm" />

#### 端点与端帽

`start` / `end` 可以配置端点宽度、方向和 cap。`align` 决定中心线在带宽中的对齐位置，`samples` 可让复杂曲线走采样构造。

<ComponentPreview name="ribbon-direction" size="md" />

<ComponentPreview name="ribbon-align-cap" size="md" />

#### 预计算边界

当布局算法已经算好上下边界时，用 `ribbon.mode = 'boundary'`，并把 `upper` / `lower` 写成两条开放 step 序列。该模式不需要 `children`，也不会接受 `width`。

<ComponentPreview name="ribbon-boundary" size="sm" />

#### 样式

Ribbon 是闭合面，样式重点是 `fill`、外轮廓 `stroke`、透明度、阴影和混合模式。`pathDefault` 会把 Path 共享的 drawable 样式传给 ribbon kind；箭头、虚线、lineCap 等 stroke-only 语义只属于默认 `stroke` kind。
