## 用法

```tsx
import { Path, Step } from '@retikz/react';
```

```tsx
<Path stroke="currentColor">
  <Step kind="move" to="a" />
  <Step kind="line" to="b" />
</Path>
```

`<Draw>` 编译后就是 `<Path>`，覆盖日常连线的 step / 折角 / 曲线 / 弧形需求；但 `<Path>` 还多出 `color` / `rotate` / `scale` / `marks` / `id` / `meta` / `animations` 等元素级能力，`<Draw>` 不暴露这些。日常连线用 `<Draw>` 一行 way 数组更省，需要显式 Step 序列、多次 `move`、逐段混用 `kind` / label / 控制点，或要用上述 Path 专属能力时用 `<Path>`：

|                                                                       | `<Draw>`      | `<Path>` + `<Step>`        |
| --------------------------------------------------------------------- | ------------- | -------------------------- |
| 写法                                                                  | 一行 way 数组 | 容器 + 子节点              |
| step / 曲线 / 折角 / 弧形                                             | 支持          | 支持                       |
| `color` / `rotate` / `scale` / `marks` / `id` / `meta` / `animations` | 不暴露        | 支持                       |
| 适用                                                                  | 90% 连线场景  | 显式 Step 序列、元素级能力 |

## 组合

`<Path>` 必须搭配 `<Step>` 子节点（至少 2 个）；首个非 `move` 时编译器会强制改成 `move`：

```tsx
<Path>
  <Step kind="move" to={...} />     {/* 第 1 个：必为 move */}
  <Step kind="line" to={...} />     {/* 之后任意多个 line / move / step */}
  ...
</Path>
```

`<Step>` 支持 13 种 kind——`move` / `line` 处理直线，`fold` 走直角折角，`cycle` 闭合回起点，`curve` / `cubic` 画贝塞尔曲线，`bend` 是弧形简记（可带 out/in 角与自环），`smooth` 画穿过点列的平滑曲线，`generator` 调用内置或自定义路径生成器，`arc` / `circlePath` / `ellipsePath` 以游标为圆心画弧 / 整圆 / 整椭圆，`rectangle` 画对角矩形，详见 [Step](/kernel/components/draw/step) 与 [路径生成器](/kernel/components/draw/path-generator)。

### 端点连接面

端点引用节点时（`{ id }` 对象形态，或 way 里的 id），可加 `boundary` 字段，**只对这一个端点**覆盖目标节点的 [`boundary`](/kernel/components/node/overview#连接面-boundary)（连接面）。取值与节点 `boundary` 同形：`'shape'`（视觉形状自身）/ `'circle'`（真圆）/ 任意注册 shape 名 / `{ type, params }`。

```tsx
<Path arrow="->">
  <Step kind="move" to="a" />
  <Step kind="line" to={{ id: 'star', boundary: 'shape' }} />
</Path>
```

`boundary` 只在"连接面有意义"的地方生效：端点自动贴边（未显式给 `anchor`）以及该端点的标准方位 / 角度锚点。在没有方向引用的场合——`between` 端点、`offset` 的 `of`、节点中心——它是 no-op。节点默认连接面写在 [`<Node boundary>`](/kernel/components/node/overview#连接面-boundary)，端点 `boundary` 是单边覆盖。

下例同一五角星（未设节点 `boundary`），两条边各自在端点选连接面：实线默认贴真实尖端，虚线 `boundary="circle"` 改贴外接圆——连接面由边自己决定。

`stroke` 除纯色字符串外还接 `PaintSpec`。线性 / 径向渐变、pattern、image 会进入同一份 paint 资源表；`dashPattern`、`dashOffset`、`lineCap`、`strokeOpacity` 等描边样式照常作用在这条线本身。

`lineCap` 控制描边端点形状：`'butt'` 默认（直角端）/ `'round'` 半圆 / `'square'` 方头外扩半个 stroke。`lineJoin` 控制拐点形状：`'miter'` 默认（尖角）/ `'round'` 圆角 / `'bevel'` 切角。

<ComponentPreview files="path-line-style" />

`strokeOpacity` 使用与 Scene primitive 一致的描边透明字段名，并与 `<Node>` 的描边透明字段保持一致。

### 曲线与变换

#### 出 / 入射角与自环

`<Step kind="bend">` 除对称的 `bendDirection` + `bendAngle` 外，还可用 `outAngle` / `inAngle` 指定起点出射角与终点入射角，画非对称曲线；`looseness` 调控制点距离（松紧，缺省 ≈1）。**out/in 给定时优先于 `bendDirection`**。当 `from == to`（同节点 / 同坐标）时退化为**自环**——这是 out/in 最大价值场景（状态机自跳转），对称 bend 画不出。

<ComponentPreview files="path-outin-loop" size="sm" />

#### 整体变换（rotate / scale）

`rotate`（度）/ `scale`（数字等比，或 `{ x, y }` 非等比）把整条 path 绕**包围盒中心**变换，免去为单条 path 包一层 `<Scope transforms>`。变换顺序有硬契约：path 端点先 resolve、箭头 shrink 在**未变换的几何**上算，最后整体包进 group——故箭头方向随变换正确、不错位。

<ComponentPreview files="path-transform" size="sm" />

#### 中段标记（marks）

`marks` 沿路径放方向标记：每项 `{ pos, mark }`，`pos ∈ [0, 1]`（越界 schema 拒），`mark` 首批为 `{ kind: 'arrow', shape, ... }`（复用已注册箭头名 + 视觉子集，见 [自定义箭头](/kernel/components/draw/custom-arrow)），**朝向由该点切线决定**（不是固定方向）。直线 / 贝塞尔 / 弧段都按切线定向。尺寸与端点箭头同口径**随 `strokeWidth` 缩放**：线越粗、标记越大。

<ComponentPreview files="path-marks" size="xs" />

#### 折线圆角（roundedCorners）

`roundedCorners` 给整条 path 的每个 **line↔line 内拐角**倒一个半径相同的圆角弧——画流程图、布线、折线连接时把硬尖角磨圆。缺省 / 省略 = 全尖角（行为不变）。首点 / 末点保持尖；接缝一侧是曲线 / 弧 / 贝塞尔 / 折角（`fold`）时该接缝也保持尖。半径过大时按相邻段长**逐拐角夹紧**到可行最大值。`cycle` 闭合后，闭合接缝也参与倒圆。

<ComponentPreview files="path-rounded-corners" size="sm" />

`roundedCorners` 改的是**路径几何**——它把拐角顶点回退并插入一段相切圆弧，因此影响包围盒、弧长、路径级 `marks` 的归一化定位和连接点解析。这和 `lineJoin` 是两码事：`lineJoin` 只改**描边视觉**，路径中心线仍是尖折。（注：step 边标注 `label` 当前仍定位在该 step 自身线段上，不随接缝倒角缩短重算。）下例用很粗的描边对照——上方 `lineJoin="round"`（只磨描边、中心线仍尖），下方 `roundedCorners`（中心线本身就是圆弧）：

<ComponentPreview files="path-rounded-vs-linejoin" size="sm" />

### 流带路径

`<Path kind="ribbon">` 用同一个 Path 宿主绘制可填充的带状关系。中心线仍然由 `<Step>` 描述，带宽、端帽、采样和边界模式放进 `ribbon={{ ... }}`；`fill`、`stroke`、`opacity`、`label`、`zIndex` 等宿主字段仍然写在 Path 顶层。

```tsx
<Path kind="ribbon" ribbon={{ start: { width: 32 }, end: { width: 12 } }} fill="#60a5fa">
  <Step kind="move" to={[-120, 0]} />
  <Step kind="cubic" control1={[-40, -48]} control2={[40, 48]} to={[120, 0]} />
</Path>
```

#### 基础流带

中心线模式会把开放路径两侧按 `width` 偏移，生成闭合 Path primitive。`stroke` 描的是流带外轮廓，不会绘制中心线。

`width` 可以是固定值、起末端宽度，或 `kind: 'stops'` 的沿路径宽度表；`interpolation` 控制宽度变化方式。

<ComponentPreview files="ribbon-width-stops" size="xs" />

Ribbon label 使用同一套 GeometryLabel 契约。`position` 支持关键字或 `0..1` 数值；`side` 默认像普通 Path label 一样带固定外侧距离；`placement="inside"` 可把标签放入带状面内部，`sloped: true` 会沿中心线切线旋转。

#### 端点与端帽

`start` / `end` 可以配置端点宽度、方向和 cap。`align` 决定中心线在带宽中的对齐位置，`samples` 可让复杂曲线走采样构造。

当布局算法已经算好上下边界时，用 `ribbon.mode = 'boundary'`，并把 `upper` / `lower` 写成两条开放 step 序列。该模式不需要 `children`，也不会接受 `width`。

Ribbon 是闭合面，样式重点是 `fill`、外轮廓 `stroke`、透明度、阴影和混合模式。`pathDefault` 会把 Path 共享的 drawable 样式传给 ribbon kind；箭头、虚线、lineCap 等 stroke-only 语义只属于默认 `stroke` kind。

### 端点引用为什么支持后定义

编译器遍历到 `<Path>` 时不会立刻生成图元，而是加入待处理队列；需要保持当前输出层级时，还会留下绘制顺序占位。它继续注册当前 scope 内的 `<Node>` 与 `<Coordinate>`，待该 scope 扫描完成后再统一解析 `Step.to`、控制点和连接面。普通 scope 会把图元回填到占位处；带变换 scope 的全局投影规则见 [`<Scope>` 技术原理](/kernel/components/layout/scope#技术原理)。

因此 path 端点可以引用同一 scope 内稍后声明的 id，同时仍保持原来的绘制顺序。这个能力只属于延迟生成的 path；`Node.position` 与 scope transform 仍在遍历到自身时解析，不能据此假设所有 id 引用都支持后定义。

### kind 如何选择整条路径的输出

`kind` 不是 renderer 的绘制开关，而是整条 Path 的编译 provider（处理器）名称，缺省为 `stroke`。编译器从统一注册表找到 definition；如果该 provider 声明了 `optionsSchema`，就先校验 `kindOptions`，否则保留原始 JSON 对象。随后由 provider 决定复用标准描边、复用标准 ribbon，还是直接生成自定义 Scene 图元。

下图在 Path 的职责边界停止：输入仍是一条 `<Path>`，provider 分派后只输出与 renderer 无关的 Scene 图元。

### 描边与流带如何物化几何

| 模式                | 核心处理               | Scene 输出     |
| ------------------- | ---------------------- | -------------- |
| `stroke`            | step → 命令 → 装饰     | 描边与附属图元 |
| `ribbon` centerline | 命令 → 按宽度偏移两侧  | 闭合填充轮廓   |
| `ribbon` boundary   | 采样上下边界并连接端帽 | 闭合填充轮廓   |

默认描边会先把 relative、节点引用和 generator 解析成路径命令（`PathCommand`，即物化后的 move / line / arc 等几何）。`roundedCorners` 随后改写命令，再计算路径标记与端点箭头收缩；`rotate` / `scale` 最后把主路径、标签和标记包装成同一个 group。于是标记会跟随倒圆后的弧长与切线，整体变换也不会让装饰脱离路径。

中心线 ribbon 复用同一套 step 解析口径，再按宽度函数求两侧轮廓；固定宽度且线段可解析时优先直接构造轮廓，其余情况按横截面采样。Boundary 模式则直接采样已给出的上下边界。两种模式最终都变成普通的闭合 Path 图元，SVG / Canvas 无需各自实现一套 ribbon 语义。

| `roundedCorners` | `number`（≥0）                                                                                                | —              | 几何圆角半径：把每个 line↔line 内拐角倒成相切圆弧，改路径几何（区别于 `lineJoin`）；非 line 接缝保持尖，逐拐角按段长夹紧；省略 = 尖角                                                                             |
| `thickness`      | `'ultraThin' \| 'veryThin' \| 'thin' \| 'semithick' \| 'thick' \| 'veryThick' \| 'ultraThick'`                | —              | 组件 / builder 语法糖：生成 IR 前解析成 `strokeWidth`；显式 `strokeWidth` 始终优先                                                                                                                                |
| `arrow`          | `'none' \| '->' \| '<-' \| '<->'`                                                                             | —              | 路径级箭头方向（详见 [Arrow](/kernel/components/draw/arrow)）                                                                                                                                                     |
| `arrowDetail`    | `ArrowDetail` 对象                                                                                            | —              | 箭头视觉详细配置；字段详见 [Arrow](/kernel/components/draw/arrow)                                                                                                                                                 |
| `fill`           | `string \| PaintSpec`                                                                                         | `'none'`       | 闭合区域填充：任意 CSS 颜色，或 PaintSpec（渐变 / 图案 / 图片）                                                                                                                                                   |
| `fillRule`       | `'nonzero' \| 'evenodd'`                                                                                      | `'nonzero'`    | 填充规则；环形 / 孔洞场景用 `'evenodd'`                                                                                                                                                                           |
| `opacity`        | `number`                                                                                                      | —              | 整 path 透明度 0~1（同时作用于 stroke 与 fill）                                                                                                                                                                   |
| `fillOpacity`    | `number`                                                                                                      | —              | 仅 fill 透明度 0~1                                                                                                                                                                                                |
| `strokeOpacity`  | `number`                                                                                                      | —              | 仅 stroke 透明度 0~1                                                                                                                                                                                              |
| `shadow`         | `'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl' \| 'none' \| { preset?, offsetX?, offsetY?, blur?, color?, opacity? }` | —              | 主路径投影：预设字符串或对象；图元级，端点箭头随主路径一起投影。详见 [视觉效果](/kernel/components/effects)                                                                                                       |
| `blendMode`      | `'normal' \| 'multiply' \| 'screen' \| ...`（16 个 W3C 分离模式）                                             | `'normal'`     | 主路径与其下方已绘内容的混合模式；图元级，端点箭头随主路径一起混合。详见 [视觉效果](/kernel/components/effects)                                                                                                   |
| `zIndex`         | `number`（整数）                                                                                              | `0`            | 显式栈序：大者在上；同值保持声明顺序；只在同层子节点间生效                                                                                                                                                        |
| `rotate`         | `number`                                                                                                      | —              | 整条 path 旋转角（度，绕包围盒中心）                                                                                                                                                                              |
| `scale`          | `number \| { x, y }`                                                                                          | —              | 整条 path 缩放（数字等比 / `{ x, y }` 非等比，绕包围盒中心）                                                                                                                                                      |
| `marks`          | `Array<{ pos, mark }>`                                                                                        | —              | 沿路径标记：`pos∈[0,1]`、`mark.kind:'arrow'` + 已注册箭头名，朝向随该点切线                                                                                                                                       |
| `animations`     | `Array<AnimationTrack>`                                                                                       | —              | 时间轴动画 tracks，透传进本 path emit 的图元，renderer 播放或降级静态；见 [动画](/kernel/components/effects/animation)                                                                                            |
| `children`       | `Array<<Step>>`                                                                                               | —              | `stroke` 与中心线 `ribbon` 必填；boundary `ribbon` 省略。首个非 `move` 时编译器会强制改成 `move`                                                                                                                  |
