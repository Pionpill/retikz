This page includes only input schemas owned by the node family, exported by `@retikz/core`. Shared position, shape, text, font, paint, and geometry schemas remain named references. React Text is line syntax with no separate persistent schema. Start with [Basic usage](/kernel/components/node/usage).

Node.position is optional and resolves to the local origin [0, 0] in Core; direct schema parsing materializes this default. Provide Node style / layout and label options as needed. Omitted fields remain subject to inheritance and compile defaults; they are not materialized fixed values. Explicit fields override inherited values, and label distance also depends on compile labelDistance. Default columns show only defaults declared by the schema.
