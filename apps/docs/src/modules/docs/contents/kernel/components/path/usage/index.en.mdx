Draw a line from A to B. `Node.id` names each target, and `Draw.way` references them in order. For shaped nodes, the line attaches to the connection boundary rather than passing through the center.

## Using this topic

All four forms produce the same result. React accepts components or IR; Vanilla accepts authoring helpers or IR. The Vanilla snippets require `<div id="diagram"></div>` in HTML. Call `view.dispose()` before removing the host. For installation, see [Quick start](/kernel/components/get-start).

## Choose a route

A straight line goes directly from A to B. To turn or curve, add an action between A and B. Try the panel below: a one-axis projection moves in only one direction, so it may miss B; a fold really connects to B. See [Path syntax](/kernel/components/path/draw) for complete usage.

| Route                            | Enum / Step value                                        | `way` form                                      |
| -------------------------------- | -------------------------------------------------------- | ----------------------------------------------- |
| Straight                         | `kind: 'line'`                                           | `['a', 'b']`                                    |
| Horizontal axis                  | `kind: 'axis-line'`<br />`axis: 'horizontal'`            | `['a', { horizontalTo: 'b' }]`                  |
| Vertical axis                    | `kind: 'axis-line'`<br />`axis: 'vertical'`              | `['a', { verticalTo: 'b' }]`                    |
| Horizontal, then vertical        | `DrawWay.Hv = '-\|'`<br />`kind: 'fold'`                 | `['a', '-\|', 'b']`                             |
| Vertical, then horizontal        | `DrawWay.Vh = '\|-'`<br />`kind: 'fold'`                 | `['a', '\|-', 'b']`                             |
| Horizontal, vertical, horizontal | `DrawWay.Hvh = '-\|-'`<br />`kind: 'fold'`               | `['a', '-\|-', 'b']`                            |
| Vertical, horizontal, vertical   | `DrawWay.Vhv = '\|-\|'`<br />`kind: 'fold'`              | `['a', '\|-\|', 'b']`                           |
| Quadratic Bezier                 | `kind: 'curve'`                                          | `['a', { curve: [50, -40] }, 'b']`              |
| Cubic Bezier                     | `kind: 'cubic'`                                          | `['a', { cubic: [[30, -40], [70, -40]] }, 'b']` |
| Bend shortcut                    | `kind: 'bend'`<br />`bendDirection: 'left'` or `'right'` | `['a', { bend: 'left' }, 'b']`                  |

Curves use control points or a bend direction. Control points steer the curve; the curve does not have to pass through them.

## Set appearance

Put colors, stroke width, dashes, and fill in `style`. Arrow direction, rounded corners, and `zIndex` stay at the root. Adjust one path in the preview below.

<ComponentPreview files="draw-style" size="lg" />

Closed routes can fill an area, and `zIndex` controls sibling stacking. Compare both in one preview.

<ComponentPreview files="draw-fill-stack" size="lg" />

For a closed Path / Draw, `style.fill` also accepts pattern objects such as `{ kind: 'pattern', shape: 'lines' }` to fill the area with lines, dots, or a grid. See [Patterns](/kernel/visual/style/pattern).

## When to use Path

Use Path with explicit Steps for clearer control over multiple subpaths or individual segments. Draw exposes common route and appearance props; use Path for whole-path `label`, `marks`, `rotate`, and `scale`. These forms draw the same fold; Step makes each action explicit.

```tsx
<Draw way={['a', '-|', 'b']} />

<Path>
  <Step kind="move" to="a" />
  <Step kind="fold" via="-|" to="b" />
</Path>
```

Import `Path` and `Step` from `@retikz/react` and replace Draw inside the existing Layout. Path also accepts `way`, but it cannot be supplied together with explicit steps.

## Additional notes

- Referenced names must be available in the current scope; see [Scope](/kernel/components/scope/usage).
- Shared positioning syntax belongs to [Positioning](/kernel/components/basic/position); drawing explains only path-specific cursor and connection rules.
- See [Arrows](/kernel/components/path/arrow) for endpoints and [Path labels](/kernel/components/path/label) for text.
