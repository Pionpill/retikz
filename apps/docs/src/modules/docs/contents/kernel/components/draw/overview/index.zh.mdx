title: Draw
description: 用一个 way 数组声明日常连线、折角、曲线、闭合与边标注，并展开为等价的 Path 与 Step。
---

`<Draw>` 是大多数连线的首选入口。它接受一个 `way` 数组，按顺序把目标点、折角、闭合、曲线、形状和边标注展开成 Kernel（底层）`<Path>` + `<Step>`。描边、填充、箭头等样式字段与 `<Path>` 保持一致。

选择建议：普通关系线、流程图边、带箭头连接默认用 `<Draw>`；需要多次 `move`、逐段精确控制 `kind`、或调试最贴近 IR 的结构时，用 `<Path>` + `<Step>`；画单个几何形（圆 / 矩形 / 扇形等）用下方**形状 sugar**；画背景参考线用 [Grid](/kernel/components/helpers/grid)。只是在 AI / 数据库存储层交换图形时，直接处理 IR。

## 用法

```tsx
import { Draw } from '@retikz/react';
```

```tsx
<Draw way={['a', 'b']} />
```

### 曲线

Draw 里的曲线分两类：`curve` / `cubic` / `bend` 连接前后两个目标点，`arc` 则以上一个点为圆心画一段圆弧。贝塞尔曲线里的控制点不是曲线必须经过的点，而是用来"拉动"曲线方向和弯曲程度的手柄。

| 写法        | 直觉                                        | 适合场景                       |
| ----------- | ------------------------------------------- | ------------------------------ |
| `{ curve }` | 一个控制点拉出一段简单弯曲                  | 普通单弧连线                   |
| `{ cubic }` | 两个控制点分别控制起点和终点附近的方向      | S 形、复杂连接、需要更精确切线 |
| `{ bend }`  | 只指定向左 / 向右弯和角度，由编译器算控制点 | 两节点之间的快捷弧形连线       |
| `{ arc }`   | 以上一点为圆心，按角度和半径画圆弧          | 角度标注、圆周片段、几何示意   |

用面板切换二次 / 三次贝塞尔、bend、arc、circle 与 ellipse。贝塞尔控制点以 `[x, y]` 成组编辑，画布上的虚线手柄会同步移动；其他类型只显示当前操作真正使用的角度或半径。连接类操作消费前后两个目标；arc / circle / ellipse 以上一项为中心，不消费下一项。

`{ curve: [cx, cy] }` 对应 TikZ 的 `.. controls (B) ..` 路径控制点写法。

</Comparison>

过点平滑曲线是 `<Step kind="smooth">` 的专属能力，不是 `way` 操作；它需要同时消费一组点，见 [Step 曲线](/kernel/components/draw/step#几何与曲线)。

### 边标注

`{ label }` 修饰下一段产生的 `step.label`，不自己产生路径段。用面板切换直线与两种折角，拖动 `position`，再调整 side、sloped 与文字颜色；折角会把 t 平均分配给两段，因此 `0.5` 固定落在拐角。

<ComponentPreview files="draw-label" size="md" />

7 个 position keyword、曲线与圆弧的 t 语义见 [Step 边标注](/kernel/components/draw/step#边标注label)。

### 样式

同一条开放折线可以直接试验 stroke、dash、圆角与箭头。`roundedCorners` 改变路径几何，`lineJoin` 只改变描边视觉；更细的箭头 shape、尺寸与单端配置见 [Arrow](/kernel/components/draw/arrow)。

#### 填充与栈序

`DrawWay.Cycle` 闭合区域后，`fill` 与 `fillOpacity` 控制填充外观，嵌套子路径的填充规则由 `fillRule` 决定；`zIndex` 则覆盖默认声明顺序，只在同层子节点间比较。面板里的蓝色 Draw 先声明、红色 Draw 后声明：保持蓝色 `zIndex` 为 0 时红色在上，调到 1 后蓝色会移到上层。

### 与 Draw 共用 Path 语义的几何 sugar

需要画几何形而不是连接关系时，使用 [Shapes](/kernel/components/shapes) 分组的一行式 sugar。它们在编译期同样展开为 Path，并与 Draw / Path 共用填充、描边、效果和栈序语义：

| 组件               | 画什么                |
| ------------------ | --------------------- |
| `<Circle>`         | 圆 / 半圆 / 弓形      |
| `<Ellipse>`        | 椭圆 / 部分椭圆       |
| `<Arc>`            | 不闭合的圆弧 / 椭圆弧 |
| `<Sector>`         | 扇形（经圆心闭合）    |
| `<Rectangle>`      | 矩形 / 圆角矩形       |
| `<RegularPolygon>` | 正多边形              |
| `<Star>`           | 星形                  |

网格底纹不属于几何 shape；这类成片参考线收在 [辅助](/kernel/components/helpers) 分组。几何图形可从 [圆与椭圆](/kernel/components/shapes/circle-ellipse) 开始，规则参考线见 [Grid](/kernel/components/helpers/grid)。

## 技术原理

<ComponentAlert type="tip" title="日常使用可以跳过本节" description="需要排查 way 的展开结果或结构错误时再回来读。" />

`<Draw>` 只负责把便于书写的 `way` 转成底层组件树。本节停在 `<Path>` + `<Step>` 这一职责边界；完整的 JSX → IR（中间表示）→ Scene（渲染场景）管线见[架构](/kernel/concepts/design/principles)。

### 从路径写法到步骤序列

`way` 会从左到右扫描。第一项必须是目标点，并固定生成 `move`；后续项根据自身角色生成路径动作，或修饰紧随其后的动作。

| 输入角色                          | 归一化结果                               | 扫描行为                   |
| --------------------------------- | ---------------------------------------- | -------------------------- |
| 第一个目标点                      | `move` step                              | 消费当前项                 |
| 普通目标点 / 相对目标             | `line` step                              | 消费当前项                 |
| 折角 / `curve` / `cubic` / `bend` | 对应的 `fold` / 曲线 step                | 与后一个目标点一起消费     |
| `arc` / `circle` / `ellipse`      | `arc` / `circlePath` / `ellipsePath`     | 只消费自身，不吞掉后续目标 |
| `label`                           | 写入下一段的 `step.label`，不单独成 step | 消费自身，等待下一段       |
| `cycle`                           | `cycle` step                             | 消费当前项并闭合当前子路径 |

扫描同时完成结构校验：`way` 少于两项、首项不是目标、中缀算子后缺目标、连续 `label` 或末尾悬空 `label` 都会在 Draw 展开时直接报错，而不会生成一棵含糊的 Kernel 子树。

### 等价展开

例如下面的 Sugar：

```tsx
<Draw way={['a', { label: 'ok' }, '-|', 'b']} arrow="->" />
```

会展开为等价的 Kernel 组件树：

```tsx
<Path arrow="->">
  <Step kind="move" to="a" />
  <Step kind="fold" via="-|" to="b" label={{ text: 'ok' }} />
</Path>
```

Draw 把描边、填充、箭头和层级等整条路径的属性透传给 `<Path>`，再把归一化后的每个动作映射为 `<Step>`。因此两种写法进入同一套 Kernel 语义和后续几何流程；从 Draw 切到手写 Path + Step 只改变控制粒度，不会引入另一套路径行为。

## API 参考

### Props

| 属性             | 类型                                                                                                          | 默认值         | 描述                                                                                                                                       |
| ---------------- | ------------------------------------------------------------------------------------------------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `way`            | `Array<WayItem>`                                                                                              | —              | 至少 2 个点；首项总是 `move`，其余按 item 形态决定 `line` / `fold` / `cycle` 等动作                                                        |
| `stroke`         | `string \| PaintSpec`                                                                                         | `currentColor` | 描边 paint：CSS 颜色或 PaintSpec（渐变 / 图案 / 图片）；使用 PaintSpec 时需给箭头显式 CSS 颜色                                             |
| `strokeWidth`    | `number`                                                                                                      | `1`            | 描边宽度                                                                                                                                   |
| `dashPattern`    | `Array<number>`                                                                                               | —              | dash / gap 长度序列，如 `[4, 2]`                                                                                                           |
| `dashOffset`     | `number`                                                                                                      | —              | 虚线起点偏移，单位同路径 user units                                                                                                        |
| `lineCap`        | `'butt' \| 'round' \| 'square'`                                                                               | `'butt'`       | 描边端点形状                                                                                                                               |
| `lineJoin`       | `'miter' \| 'round' \| 'bevel'`                                                                               | `'miter'`      | 描边拐点形状（仅视觉，不改几何）                                                                                                           |
| `roundedCorners` | `number`                                                                                                      | —              | 折线 line-line 接缝**几何**圆角半径；改路径几何，区别于 `lineJoin`。详见 [Path §圆角](/kernel/components/draw/path#折线圆角roundedcorners) |
| `thickness`      | `'ultraThin' \| 'veryThin' \| 'thin' \| 'semithick' \| 'thick' \| 'veryThick' \| 'ultraThick'`                | —              | 语义化 stroke 档位；显式 `strokeWidth` 优先                                                                                                |
| `arrow`          | `'none' \| '->' \| '<-' \| '<->'`                                                                             | —              | 路径级箭头方向                                                                                                                             |
| `arrowDetail`    | `{ shape?, scale?, length?, width?, color?, fill?, opacity?, lineWidth?, start?, end? }`                      | —              | 箭头详细配置；详见 [Arrow](/kernel/components/draw/arrow)                                                                                  |
| `fill`           | `string \| PaintSpec`                                                                                         | `'none'`       | 闭合区域填充色：纯色或 PaintSpec（渐变 / 图案 / 图片）                                                                                     |
| `fillRule`       | `'nonzero' \| 'evenodd'`                                                                                      | `'nonzero'`    | 填充规则                                                                                                                                   |
| `opacity`        | `number`                                                                                                      | —              | 整 path 透明度 0..1                                                                                                                        |
| `fillOpacity`    | `number`                                                                                                      | —              | 仅 fill 透明度 0..1                                                                                                                        |
| `strokeOpacity`  | `number`                                                                                                      | —              | 仅 stroke 透明度 0..1                                                                                                                      |
| `shadow`         | `'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl' \| 'none' \| { preset?, offsetX?, offsetY?, blur?, color?, opacity? }` | —              | 主路径投影；端点箭头随主路径一起投影。详见 [视觉效果](/kernel/components/effects)                                                          |
| `blendMode`      | `'normal' \| 'multiply' \| 'screen' \| ...`（16 个 W3C 分离模式）                                             | `'normal'`     | 主路径与下方内容的混合模式；端点箭头随主路径一起混合。详见 [视觉效果](/kernel/components/effects)                                          |
| `zIndex`         | `number`（整数）                                                                                              | `0`            | 显式栈序：大者在上；同值保持声明顺序；只在同层子节点间生效（透传到底层 `<Path>`）                                                          |

<Comparison target="tikz" title="样式命名">

`lineCap` / `lineJoin` 对应 TikZ 的 `line cap` / `line join`，`roundedCorners` 对应 `rounded corners=`；`strokeOpacity` 表示描边透明度；`thickness` 的档位沿用 `ultra thin` 到 `ultra thick` 的语义化描边厚度。

</Comparison>

### 曲线 / 形状 / 标注 way item

| Way item          | 参数                               | 消耗下一项 | 等价 Step            | 描述                                  |
| ----------------- | ---------------------------------- | ---------- | -------------------- | ------------------------------------- |
| `{ curve }`       | `[cx, cy]`                         | 是         | `kind="curve"`       | 二次贝塞尔控制点                      |
| `{ cubic }`       | `[[c1x, c1y], [c2x, c2y]]`         | 是         | `kind="cubic"`       | 三次贝塞尔两个控制点                  |
| `{ bend }`        | `'left' \| 'right'`                | 是         | `kind="bend"`        | 弯曲方向，角度默认 30                 |
| `{ bend, angle }` | `number`                           | 是         | `kind="bend"`        | 覆盖 bend 角度                        |
| `{ arc }`         | `{ startAngle, endAngle, radius }` | 否         | `kind="arc"`         | 以当前点为圆心画弧段                  |
| `{ circle }`      | `{ radius }`                       | 否         | `kind="circlePath"`  | 以当前点为圆心画整圆                  |
| `{ ellipse }`     | `{ radius: { x, y } }`             | 否         | `kind="ellipsePath"` | 以当前点为中心画整椭圆                |
| `{ label }`       | `string \| StepLabel`              | 是         | `step.label`         | 标注下一段；字符串短写等价 `{ text }` |

### StepLabel

| 字段        | 类型                                     | 默认值     | 描述                                                                                                                                                          |
| ----------- | ---------------------------------------- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `text`      | `string`                                 | —          | 标注文本（单行）                                                                                                                                              |
| `position`  | 7 keyword 之一 或 `number`（0..1）       | `'midway'` | 段上归一化位置 t；keyword 是 t 的语义糖（at-start=0 / very-near-start=0.125 / near-start=0.25 / midway=0.5 / near-end=0.75 / very-near-end=0.875 / at-end=1） |
| `side`      | `'top' \| 'bottom' \| 'left' \| 'right'` | `'top'`    | 边标注相对段方向的侧；也接受 compass 别名 `north` / `south` / `east` / `west`                                                                                 |
| `sloped`    | `boolean`                                | `false`    | 是否沿切线旋转贴线                                                                                                                                            |
| `textColor` | `string`                                 | —          | 标签文字色；缺省回退 scope `labelDefault` → 宿主 path 主色 → currentColor                                                                                     |
| `opacity`   | `number`                                 | —          | 标签独立透明度 0..1；与所属 path opacity 相乘                                                                                                                 |
| `font`      | `object`                                 | —          | 标签字体覆盖（family / size / weight / style）                                                                                                                |
