## 用法

```tsx
import { Path, Step } from '@retikz/react';
```

```tsx
<Path>
  <Step kind="move" to="a" />
  <Step kind="line" to="b" />
</Path>
```

当你需要逐段控制 Kernel 路径动作时使用 `<Step>`：例如多次 `move`、混合直线 / 折角 / 曲线 / 圆弧，或排查 `<Draw>` 展开后的结构。日常连线优先用 [Draw](/kernel/components/draw/overview)。

## 例子

### 基本动作

在同一个面板中切换 `line`、多次 `move`、`fold`、`cycle` 与 `rectangle`。多次 `move` 可以在同一个 `<Path>` 中开始彼此独立的子路径；`fold` 可改变折角方向，`rectangle` 可调圆角，`cycle` 会闭合回最近一次 `move` 的起点。

<ComponentPreview files="step-actions" size="sm" />

### 目标定位

`to` 除了绝对坐标，还接受 `{ of, offset }`、`{ relative }` 与 `{ relativeAccumulate }`。在面板中切换定位方式并调整 x / y，可以直接观察三者的锚点差异：

- `offset`：以节点、坐标或 PolarPosition 为基准再偏移
- `relative`：基于前一终点，但不推进 `prevEnd`
- `relativeAccumulate`：基于前一终点，并推进 `prevEnd`

相对坐标也可写成 sugar 字符串 `'+dx,dy'` / `'++dx,dy'`。

<ComponentPreview files="step-targeting" size="sm" />

### 几何与曲线

`curve`、`cubic`、`bend`、`smooth`、`arc`、`circlePath` 与 `ellipsePath` 都在下面的面板中切换。贝塞尔控制点以 `[x, y]` 成组编辑，并在画布中显示对应的虚线手柄；其他 kind 只显示相关的弯曲角、tension、角度或半径，便于比较它们如何推进游标并生成几何。

### 边标注（label）

给 `<Step>` 挂 `label`，即可把文字放在该段的任意归一化位置。prop 形态 `<Step label={{...}} />` 与 sugar 形态 `<Step><EdgeLabel>...</EdgeLabel></Step>` 的基础位置字段等价；两者并存时 prop 优先。

<ComponentPreview files="step-label" size="md" />

面板统一调整 `position`、`side`、`sloped` 与文字颜色。`position` 接受七个关键字或 `[0, 1]` 数值 t；关键字映射与完整字段放在下方 [API 的边标注表](#边标注)，避免在示例区重复列举。

### 样式

`<Step>` 自身没有 stroke 类视觉属性。`stroke`、虚线、圆角、填充与栈序都属于父 `<Path>`；直接在 [Path 的样式面板](/kernel/components/draw/path#样式) 中调整即可，本页不再复制同一条静态路径。

| `kind="fold"` + `via="-\|"` / `"\|-"`     | `(A) -\| (B)` / `(A) \|- (B)`         |
| `kind="cycle"`                            | `cycle`                               |

| `kind="rectangle"`                        | `(a) rectangle (b)`                   |

### 从标记到有序 Step

`<Step>` 是返回 `null` 的标记组件，本身不创建 DOM 或图形。父 `<Path>` 按 JSX 顺序收集这些标记，把字符串 target、缺省 `kind` 和 `<EdgeLabel>` child 归一成可序列化的 `IRStep`；显式 `label` prop 比 child 优先。

除单个自包含的 `rectangle` 外，一条 Path 至少需要两个 Step。首段不是 `move` 时，React 适配层会把它改成 `move`：有 `to` 就保留该目标，没有 `to` 就回退到 `[0, 0]`。因此首段写成 `line` 只会定位游标，不会画出这条线。

### 游标驱动的几何编译

进入默认 `kind="stroke"` 的 core 编译后，Step 不会各自独立渲染。编译器先把相对 target 归一为当前 scope 的坐标，再按声明顺序推进游标、解析节点引用与边界连接，最后把每个 `kind` 降级为统一的路径命令和边标注几何：

<ComponentPreview files="step-compile-flow" size="xs" hideCode />

| Step 家族                                                        | 编译行为                                                   | 用户可见结果                                             |
| ---------------------------------------------------------------- | ---------------------------------------------------------- | -------------------------------------------------------- |
| `move` / `cycle`                                                 | 维护游标与最近一次子路径起点                               | `move` 不画线；`cycle` 闭合回最近一次 `move`             |
| `line` / `curve` / `cubic`<br />`fold` / `bend`                  | 解析前后目标并按节点边界裁切<br />再发射直线或 Bezier 命令 | 节点 id 自动接到边界；`fold` / `bend` 最终仍是普通路径段 |
| `smooth` / `generator`<br />`arc` / `circlePath` / `ellipsePath` | 生成一组路径命令，并记录画完后的真实笔位                   | 下一段从生成结果的终点续接；整圆 / 整椭圆画完回到圆心    |
| `rectangle`                                                      | 独立解析 `from` / `to`，不要求前置游标                     | 可以作为 Path 中唯一的 Step                              |

这套顺序让 JSX、直接写 IR 和 `<Draw>` sugar 最终复用同一条几何编译路径；renderer 只消费降级后的命令，不需要理解十三种 Step 写法。

### t 在每种 step kind 上的几何含义

`label.position` 会先换算成 `0..1` 的参数 t。编译器再向当前 kind 的几何采样器索取该处的坐标与切线：`side` 根据坐标偏移，`sloped` 根据切线旋转。因此 t 表示的是“该 kind 的参数进度”，不一定是视觉弧长进度。

| Step kind             | t 的参数化方式                                             | `t=0.5` 的含义                        |
| --------------------- | ---------------------------------------------------------- | ------------------------------------- |
| `'line'`              | 归一化弧长                                                 | 直线中点                              |
| `'fold'`              | 两段折线各占一半 `t`，与各段长度无关                       | `t=0.5` 正好落在拐角                  |
| `'curve'` / `'cubic'` | Bezier 参数，**不是弧长**                                  | 通常不是视觉中点                      |
| `'bend'`              | 降级成 cubic 后使用 Bezier 参数                            | 与 cubic 相同                         |
| `'smooth'`            | 每个生成的 cubic 等分 t 区间<br />区间内再使用 Bezier 参数 | 取决于生成段数，不按整条曲线弧长      |
| `'generator'`         | 当前按进入 step 时的游标到最终笔位做直线插值               | 两端点的中点，不跟随中间命令          |
| `'arc'`               | 在 `startAngle..endAngle` 间线性插值                       | 起末角的中间角度                      |
| `'circlePath'`        | 整圆按角度 0→360；0 在 +x                                  | 180°（-x）                            |
| `'ellipsePath'`       | 同 circlePath，按参数角而非等弧长采样                      | 180°（-x）；任意 `t` 不按弧长均匀分布 |

整圆和椭圆的角度递增遵循屏幕坐标，因此 90° 位于视觉下方。

| `via`          | `'-\|' \| '\|-'`                                                                                                                                            | —        | 仅 `kind="fold"` 必填：`-\|` 先水平后垂直；`\|-` 先垂直后水平                                                                                                                                                                                                                                                                          |

| `params`       | `IRJsonObject`                                                                                                                                              | —        | 仅 `kind="generator"` 必填：传给路径生成器的 JSON-safe 参数；如内置 `parabola` 使用 `{ control }`                                                                                                                                                                                                                                      |
| `cornerRadius` | `number`                                                                                                                                                    | —        | 仅 `kind="rectangle"` 可选：矩形圆角半径                                                                                                                                                                                                                                                                                               |

### kind 的十三种取值

| kind            | 行为                                              | 底层路径类比    |
| --------------- | ------------------------------------------------- | --------------- |
| `'move'`        | 移动游标，**不画线**                              | path "M"        |
| `'line'`        | 从当前游标画直线到目标点                          | path "L"        |
| `'fold'`        | 经一个直角拐点折到目标点                          | 两段 path "L"   |
| `'cycle'`       | 闭合回最近一次 move 起点（无 `to`）               | path "Z"        |
| `'curve'`       | 二次贝塞尔（一个控制点）                          | path "Q"        |
| `'cubic'`       | 三次贝塞尔（两个控制点）                          | path "C"        |
| `'bend'`        | 弧形简记（方向 + 角度），编译期退到 cubic         | path "C"        |
| `'smooth'`      | 过游标 + `points` 的平滑曲线，编译期退到 cubic 链 | path "C"×N      |
| `'generator'`   | 调用内置或注册的路径生成器                        | provider 产命令 |
| `'arc'`         | 以游标为圆心，按起末角度 + 半径画弧               | path "A"        |
| `'circlePath'`  | 以游标为圆心画整圆，画完回到圆心                  | path "A"×2      |
| `'ellipsePath'` | 以游标为圆心画整椭圆，画完回到圆心                | path "A"×2      |
| `'rectangle'`   | 用 `from` 和 `to` 作为两对角画矩形                | 独立矩形子路径  |

### via 的两种取值

仅 `kind="fold"` 时生效，决定折角中间点的位置。设当前游标 `(px, py)`，目标 `(tx, ty)`：

| via     | 中间点     | 走向                         |
| ------- | ---------- | ---------------------------- |
| `'-\|'` | `(tx, py)` | 先水平到 `tx`，再垂直到 `ty` |
| `'\|-'` | `(px, ty)` | 先垂直到 `ty`，再水平到 `tx` |

### to 的形态

| 形态                          | 例                                                                                        | 行为                                                                                                       |
| ----------------------------- | ----------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 节点 id                       | `'a'`                                                                                     | 自动贴 Node 边界（参看 [图元关系](/kernel/concepts/core/primitive-relations)）                             |
| 节点 + 连接面                 | `{ id: 'a', boundary: 'circle' }`                                                         | 单边覆盖目标节点 [连接面](/kernel/components/node/overview#连接面-boundary)（贴边形状），不改节点占位      |
| 笛卡尔                        | `[60, 0]`                                                                                 | 直接坐标                                                                                                   |
| 极坐标                        | `{ origin: 'a', angle: 30, radius: 50 }`                                                  | 极坐标（参看 [定位](/kernel/concepts/basic/position)）                                                     |
| 偏移定位                      | `{ of: 'a', offset: [10, 5] }`                                                            | 基准 + `(dx, dy)`；`of` 三态——节点 id / 笛卡尔字面值 / PolarPosition                                       |
| 比例定位                      | `{ between: [{ id: 'a' }, { id: 'b' }], fraction: 0.5 }`                                  | A 到 B 连线上的比例点；端点必须是可独立解析的 absolute target（`{ id, anchor? }` 形态，或笛卡尔 / 极坐标） |
| 比例定位（显式锚点）          | `{ between: [{ id: 'a', anchor: 'right' }, { id: 'b', anchor: 'left' }], fraction: 0.5 }` | 端点可带显式 `anchor`，从锚点而非自动贴边解析                                                              |
| 相对偏移 (relative)           | `{ relative: [10, 0] }` 或 `'+10,0'`                                                      | 基于前一 step 终点 + `[dx, dy]`；**不**更新 prevEnd                                                        |
| 相对偏移 (relativeAccumulate) | `{ relativeAccumulate: [10, 0] }` 或 `'++10,0'`                                           | 基于前一 step 终点 + `[dx, dy]`；**更新** prevEnd                                                          |

### 曲线与圆弧

| 属性            | 类型                                                                                                                                                        | 默认值   | 描述                                                                                                                                                                                                      |
| --------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `kind`          | `'move' \| 'line' \| 'fold' \| 'cycle' \| 'curve' \| 'cubic' \| 'bend' \| 'smooth' \| 'generator' \| 'arc' \| 'circlePath' \| 'ellipsePath' \| 'rectangle'` | `'line'` | 见下方"十三种取值"表                                                                                                                                                                                      |
| `control`       | `[number, number]`                                                                                                                                          | —        | 仅 `kind="curve"` 必填：二次贝塞尔的单个控制点                                                                                                                                                            |
| `control1`      | `[number, number]`                                                                                                                                          | —        | 仅 `kind="cubic"` 必填：三次贝塞尔的第一控制点（影响起点切线）                                                                                                                                            |
| `control2`      | `[number, number]`                                                                                                                                          | —        | 仅 `kind="cubic"` 必填：三次贝塞尔的第二控制点（影响终点切线）                                                                                                                                            |
| `points`        | `Array<IRTarget>`（≥1）                                                                                                                                     | —        | 仅 `kind="smooth"` 必填：游标之后依次穿过的点（顺序敏感）。游标是隐式首 knot，单点 = 一段曲线，游标终于末点。元素形态同 `to`                                                                              |
| `tension`       | `number`（>0）                                                                                                                                              | `1`      | 仅 `kind="smooth"` 可选：切线长度乘子；缺省 1（标准 centripetal Catmull-Rom），`<1` 更紧、`>1` 更鼓                                                                                                       |
| `bendDirection` | `'left' \| 'right'`                                                                                                                                         | —        | 仅 `kind="bend"` 可选：相对 from→to 路径方向的视觉左 / 右；配 `bendAngle` 画对称弯。**给定 `outAngle` / `inAngle` 时它们优先**，此项被忽略                                                                |
| `bendAngle`     | `number`                                                                                                                                                    | `30`     | 仅 `kind="bend"` 可选：弯角度（度），限 (-180, 180)                                                                                                                                                       |
| `outAngle`      | `number`                                                                                                                                                    | —        | 仅 `kind="bend"` 可选：起点出射角（度）；配 `inAngle` 画非对称曲线 / 自环，优先于 `bendDirection` / `bendAngle`                                                                                           |
| `inAngle`       | `number`                                                                                                                                                    | —        | 仅 `kind="bend"` 可选：终点入射角（度）；与 `outAngle` 配套                                                                                                                                               |
| `looseness`     | `number`                                                                                                                                                    | `≈1`     | 仅 `kind="bend"` 可选：控制点距离的松紧因子，越大曲线越松；`from == to` 时同时缩放默认自环大小                                                                                                            |
| `startAngle`    | `number`                                                                                                                                                    | —        | `kind="arc"` 必填；`'circlePath'` / `'ellipsePath'` 可选（与 `endAngle` 配套画部分圆 / 椭圆）：起始角度（度，0° 朝 +x，90° 视觉朝下）                                                                     |
| `endAngle`      | `number`                                                                                                                                                    | —        | `kind="arc"` 必填；`'circlePath'` / `'ellipsePath'` 可选：终止角度（度），扫向由起末角度推断                                                                                                              |
| `radius`        | `number \| { x: number; y: number }`                                                                                                                        | —        | `kind="arc"`（圆弧）/ `'circlePath'` 时给：圆 / 弧半径。arc 上 `radius` 与 `radius: { x, y }` **二选一**（互斥）；circlePath 必填                                                                         |
| `center`        | `IRTarget`                                                                                                                                                  | 游标     | 仅 `kind="arc"` 可选：显式弧心，缺省取游标（前一 step 终点）；显式给定可让弧脱离游标独立定位（`<Sector>` 借此画正确扇形）                                                                                 |
| `closed`        | `'closed' \| 'chord' \| 'open' \| 'sector'`                                                                                                                 | 见下     | 仅 `kind="circlePath"` / `'ellipsePath'` 可选：闭合方式。无角度时 `'closed'`（整圆 / 整椭圆，默认）；有角度时 `'chord'`（两弧端连弦，默认）/ `'sector'`（两弧端连到圆心再闭合）/ `'open'`（不闭合的纯弧） |

| `label` | `IRStepLabel` | —      | 边标注（`'move'` / `'cycle'` / `'rectangle'` 外的 kind 通用）：`{ text, position?, side?, textColor?, opacity?, font? }`；`<EdgeLabel>` sugar 覆盖文字 / position / side / sloped，冲突时 prop 优先 |

### label 的字段

`label` 是单个对象，对所有可挂 label 的 kind 透明：

| 字段        | 类型                                     | 默认       | 描述                                                                                                                                                                                      |
| ----------- | ---------------------------------------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `text`      | `string`                                 | —          | 必填，标签文字（单行）                                                                                                                                                                    |
| `position`  | 7 keyword 之一 或 `number`（0..1）       | `'midway'` | 段上归一化位置 t——keyword 是 t 的语义糖（at-start=0 / very-near-start=0.125 / near-start=0.25 / midway=0.5 / near-end=0.75 / very-near-end=0.875 / at-end=1）；超出 [0, 1] 由 schema 拒绝 |
| `side`      | `'top' \| 'bottom' \| 'left' \| 'right'` | `'top'`    | 边标注相对段方向的侧；也接受 compass 别名 `north` / `south` / `east` / `west`                                                                                                             |
| `sloped`    | `boolean`                                | `false`    | 是否按段切线方向旋转；为 true 时仍可配合 `side` 控制偏移侧                                                                                                                                |
| `textColor` | `string`                                 | —          | 标签文字色；缺省回退 scope `labelDefault` → 宿主 path 主色 `color` → currentColor（跟主色不跟 stroke）                                                                                    |
| `opacity`   | `number`                                 | —          | 标签独立透明度 0..1；与所属 path opacity 相乘（跨 scope 不复合）                                                                                                                          |
| `font`      | `object`                                 | —          | 标签字体覆盖（family / size / weight / style）；逐字段回退 `labelDefault` → 渲染端默认                                                                                                    |

不同 step kind 上 t 的几何解释与 `smooth` / `generator` 边界见上方 "[t 在每种 step kind 上的几何含义](#t-在每种-step-kind-上的几何含义)" 表。
