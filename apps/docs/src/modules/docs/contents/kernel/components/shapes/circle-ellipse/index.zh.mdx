圆和椭圆是 retikz 的几何形状，有两副面孔：用 `<Circle>` / `<Ellipse>` 画一条轮廓线（Sugar），或用 `shape="circle"` / `"ellipse"` 让节点带上圆 / 椭圆边界。完整定义见 [形状](/kernel/components/shapes)。要画一条线，用 Sugar；要一个可连接、可标注的节点，用 `<Node shape>`。

## 作为 Path 图形（Sugar）

`<Circle>` / `<Ellipse>` 在指定位置画一条圆 / 椭圆轮廓，展开成底层 `<Path>`。适合「我知道中心和半径」「我只有一个包围盒」这类场景。

### 用法

```tsx
import { Circle, Ellipse } from '@retikz/react';
```

```tsx
<Circle center={[0, 0]} radius={32} fill="none" />
<Ellipse center={[0, 0]} radius={{ x: 48, y: 28 }} fill="none" />
```

### 例子

最常见的是 `center + radius`。如果手上是一个矩形范围，也可以直接用 `corner1 + corner2` 或 `box`。

| 写法                         | 适合                                              |
| ---------------------------- | ------------------------------------------------- |
| `{ center, radius }`         | 已知圆心和半径                                    |
| `{ center, diameter }`       | 已知直径                                          |
| `{ from, to }`               | 直径两端点                                        |
| `{ corner1, corner2 }`       | 放进一个包围盒                                    |
| `{ box }`                    | 用 `x/y/origin + width + height` 直接描述矩形范围 |
| + `fit="contain" \| "cover"` | 让圆取范围短边之半（内切）或长边之半              |
| + `inset` / `outset`         | 在原范围基础上先收缩或扩展再绘制                  |
| + angles + `closed="sector"` | 画 1/4 圆、30° 圆这类连回圆心的残缺圆             |

<ComponentPreview files="circle-basic" size="sm" />

椭圆和圆很像，只是半径拆成了 `radius: { x, y }`。它也支持 `corner1 + corner2` 和 `box`。

| 写法                               | 适合                                              |
| ---------------------------------- | ------------------------------------------------- |
| `{ center, radius }`               | 已知中心和两个半轴                                |
| `{ center, diameterX, diameterY }` | 已知两个直径                                      |
| `{ corner1, corner2 }`             | 放进一个包围盒                                    |
| `{ box }`                          | 用 `x/y/origin + width + height` 直接描述矩形范围 |
| + `inset` / `outset`               | 先收缩或扩展范围再画椭圆                          |
| + angles + `closed="sector"`       | 画连回中心的部分椭圆                              |

### API 参考

| 组件        | 组合                                                                     | 含义                                              |
| ----------- | ------------------------------------------------------------------------ | ------------------------------------------------- |
| `<Circle>`  | `center` + `radius`                                                      | 用圆心和半径画圆                                  |
|             | `center` + `diameter`                                                    | 用圆心和直径画圆                                  |
|             | `from` + `to`                                                            | 用两点画圆                                        |
|             | `corner1` + `corner2`                                                    | 用包围盒画内切圆                                  |
|             | `box`                                                                    | 用矩形范围描述圆，配合 `fit` / `inset` / `outset` |
|             | + `fit?`                                                                 | `contain` 取短边之半（内切），`cover` 取长边之半  |
|             | + `inset?` / `outset?`                                                   | 收缩或扩展 box 范围后再计算                       |
|             | + angles (`startAngle` / `endAngle` / `sweepAngle`, any two) + `closed?` | 部分圆：`chord` / `sector` / `open`               |
| `<Ellipse>` | `center` + `radius`                                                      | 用中心和两个半轴画椭圆                            |
|             | `center` + `diameterX` + `diameterY`                                     | 用中心和两个直径画椭圆                            |
|             | `corner1` + `corner2`                                                    | 用包围盒画内切椭圆                                |
|             | `box`                                                                    | 用矩形范围描述椭圆，配合 `inset` / `outset`       |
|             | + `inset?` / `outset?`                                                   | 收缩或扩展 box 范围后再计算                       |
|             | + angles + `closed?`                                                     | 部分椭圆：`chord` / `sector` / `open`             |

这些形状 Sugar 也会透传共享的 Path 属性，例如 `stroke`、`fill`、`opacity`、`animations` 和 `onClick`。完整列表见 [Path](/kernel/components/draw/path)；事件如何在渲染后绑定，见 [Hydration](/kernel/packages/render/hydration)。

## 作为 Node 形状

当你要的不是一条线、而是一个圆形 / 椭圆形的节点时（装文字、被连线引用），给 `<Node>` 设 `shape`。

### 用法

```tsx
import { Node } from '@retikz/react';
```

```tsx
<Node shape="circle">label</Node>
<Node shape="ellipse">label</Node>
```

### 例子

在 playground 中切换 `circle` / `ellipse`：前者是 `circumscribe:'equal'` 的等轴预设，后者默认按各轴 × √2 外接「文字 + padding」。调整轨道角度与距离移动来源节点；保持自动贴边，或切换命名 / 数字 anchor，直接比较端点在两种边界上的落点。

<ComponentPreview files="node-connection-playground" size="sm" />

节点中心与 8 个方位 anchor（`center` / `top` …）照常可用。`position` / `fill` / `padding` / `label` 等通用属性见 [Node](/kernel/components/node/overview)。

### API 参考

| `shape`                                     | 边界                                                             | 参数                                                                                          |
| ------------------------------------------- | ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `"circle"`                                  | 能容纳文字的外接圆（= `ellipse` 的 `circumscribe:'equal'` 预设） | 无                                                                                            |
| `"ellipse"` 或 `{ type:'ellipse', params }` | 外接椭圆                                                         | `circumscribe?`：`'proportional'`（默认，各轴 × √2）/ `'equal'`（等轴，半径取内框对角线之半） |

### Node 如何得到连接边界

`<Node>` 先把文字测量结果与 `padding` 合成内容框，再让 shape 定义从这个内框计算可见边界。下图给两边相同的内容框，只切换外接策略：

<ComponentPreview files="circle-ellipse-circumscription" size="md" hideCode />

默认 `ellipse` 把两个半轴分别乘以 √2；`circle` 则在编译时解析成 `ellipse + circumscribe:'equal'`，把内容框半对角线作为统一半径。解析后的同一份几何既产出可见的 ellipse 图元，也提供 anchor 与连接边界，所以 `<Draw>` / `<Path>` 的端点会贴到外轮廓。
