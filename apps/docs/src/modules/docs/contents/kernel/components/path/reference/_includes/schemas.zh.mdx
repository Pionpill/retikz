本页收录绘制拥有的输入契约。`PathSchema` 接受开放的 `kind`；实际 kind 的完整 schema 再校验该路径。内置 `stroke` 通常需要至少两个步骤；单个自包含的 rectangle 步骤是例外，自定义 kind 的要求由其 definition 决定。

`way` 由 Vanilla 转换成步骤。`arrow` 与 `marks` 在作者 API 和持久化 IR 中使用相同结构；`ArrowDetailSchema` 用于共享箭头默认配置。
