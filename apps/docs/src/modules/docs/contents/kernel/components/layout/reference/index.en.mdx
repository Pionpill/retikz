This page covers React Layout and execution options, Vanilla `scene` / `layer` builders and scene input, and Core `IRScene` / `IRViewBox`. Vanilla builds input with `scene` and passes it to a host entry such as `mount`; there is no `layout` builder.

See [Basic usage](/kernel/components/layout/usage) for integration, the Schema tabs below for persisted fields, and [Vanilla](/kernel/packages/vanilla) for mounting, updating, and disposal.

Scene-level `animations` accepts a readonly track array. Parsing a scene shallow-freezes the output array, not the array supplied by the caller.
