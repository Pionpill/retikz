---
title: 节点
description: 用 Node、Text、Coordinate 与连接面扩展建立可命名、可定位、可连接的图元系统。
---

节点家族解决的是“图里的对象怎样被命名、摆放和连接”。`Node` 提供可见主体，`Text` 细化节点内的行级文字，`Coordinate` 只保留可引用的位置；当视觉轮廓不等于连线应接触的几何时，再用自定义连接面扩展。第一次使用请从 [Node](/kernel/components/node/overview) 开始。

<ComponentPreview files="node-family" size="xs" hideCode />

## 职责一览

| 组件         | 类型   | 职责                               | 适合场景                        |
| ------------ | ------ | ---------------------------------- | ------------------------------- |
| Node         | Kernel | 声明带位置、内容和边界的可引用图元 | 需要可见主体或连线端点          |
| Text         | Sugar  | 覆盖 Node 中某一整行的文字样式     | JSX 中按行混排文字样式          |
| Coordinate   | Kernel | 命名位置，不输出可见图元           | 汇合点、辅助定位或不可见锚点    |
| 自定义连接面 | 扩展   | 独立定义连线贴边与方位锚点         | 视觉 shape 与连接规则需要分离时 |
