title: Node · 节点
description: 用 Node、Text 与 Coordinate 组织可定位、可连接的图元

节点家族解决图中对象怎样摆放、显示内容和被连线引用。Node 表示带形状与文字的对象；Text 是 Node 内一整行文字的 React 写法；Coordinate 只命名一个位置。三者协作，让可见对象和辅助位置各有明确用途。

## 职责一览

| 成员       | 职责                         | 何时使用                    |
| ---------- | ---------------------------- | --------------------------- |
| Node       | 提供位置、文字与形状         | 绘制可见对象或连接端点      |
| Text       | 覆盖一整行的文字样式         | 在 JSX 中为某一整行设置样式 |
| Coordinate | 命名不可见位置               | 组织定位参照与路径汇聚      |
| 形状扩展   | 定义占位、轮廓与默认连接几何 | 内置形状无法表达目标        |
| 连接面扩展 | 定义连线停在哪里             | 连接规则不同于可见轮廓      |

## 整体认识

下图把可见节点、节点中的文字和不可见引用点放在同一个场景中。先看节点本身，再看连线如何借助命名位置组织关系。两条线的汇合点表示 Coordinate 的位置，Coordinate 自身不绘制标记。

<ComponentPreview files="node-family" size="sm" type="illustration" hideCode />

位置决定对象放在哪里，形状决定可见轮廓，文字提供内容。路径通过 id 找到节点，通常停在其边界；Coordinate 则提供一个没有面积的端点。改变一个被引用的位置，可以带动依赖它的对象，而无需逐一修改坐标。

## 选择与边界

第一次使用从基础用法开始，再按任务阅读定位、文字和标签。正文与附加标签分开配置：正文参与节点尺寸，标签附着在已经确定的节点边界或中心。只需要定位参照时使用 Coordinate；需要文字、可见标记或有方向的边界时使用 Node。

内置轮廓见[节点形状](/kernel/components/node/shape)，新轮廓的定义与注册见[自定义形状](/kernel/components/node/custom-shape)；一组对象的局部坐标和共享默认值由 [Scope](/kernel/components/scope) 负责。只有连线接触位置需要与外观分离时，才考虑自定义连接面。原理和参考页供后续排查、扩展与字段查询，不是开始绘图的前置知识。
