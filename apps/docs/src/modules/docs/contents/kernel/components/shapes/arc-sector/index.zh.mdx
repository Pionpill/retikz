弧和扇形都围绕「角度范围」工作，有两副面孔：用 `<Arc>` / `<Sector>` 画一段角度片段（Sugar），或用 `shape={{ type:'sector', params }}` 让节点带上扇形 / 弧形边界。完整定义见 [形状](/kernel/components/shapes)。要画一段弧 / 扇形线，用 Sugar；要一个可连接的扇形 / 弧形图元，用 `<Node shape>`。

## 作为 Path 图形（Sugar）

`<Arc>`（开放弧）/ `<Sector>`（闭合扇形）在指定位置画一段角度片段，展开成底层 `<Path>`。适合角度标记、圆环片段、扇区高亮这类图。

### 用法

```tsx
import { Arc, Sector } from '@retikz/react';
```

```tsx
<Arc center={[0, 0]} radius={40} startAngle={0} endAngle={90} />
<Sector center={[0, 0]} radius={40} startAngle={0} endAngle={90} fill="darkorange" />
```

### 例子

#### Arc

`<Arc>` 默认画一段不闭合的弧。它适合做箭头弧线、环形标记或装饰线。

| 写法                                   | 适合   |
| -------------------------------------- | ------ |
| `{ center, radius: number, angles }`   | 圆弧   |
| `{ center, radius: { x, y }, angles }` | 椭圆弧 |

角度从 +x 方向开始；`90` 指向屏幕下方。角度三选二：`startAngle` / `endAngle` / `sweepAngle`（扫掠角）任给两个即可，例如 `{ startAngle: 30, sweepAngle: 90 }`。`center` 接任意 target（节点 id / 极坐标 / 笛卡尔）。

<ComponentPreview files="arc-basic" size="sm" />

**视觉属性**

`<Arc>` 透传整套 `<Path>` 视觉属性：`stroke` / `strokeWidth` / `dashPattern` / `dashOffset` / `arrow` / `marks` / `opacity` / `rotate` / `scale` 等。常见的有箭头弧（`arrow="->"`）、虚线弧（`dashPattern` / `dashOffset`）和中段方向标记（`marks`，朝向随切线）。

<ComponentPreview files="arc-visual" size="sm" />

**闭合方式**

默认是开放弧；给 `close` 可把弧闭合成可填充区域：

| `close`         | 含义                   |
| --------------- | ---------------------- |
| 缺省 / `'open'` | 开放弧，不闭合、不填充 |
| `'chord'`       | 两端点连弦闭合，成弓形 |
| `'sector'`      | 两端连回圆心，成扇形   |

<ComponentPreview files="arc-close" size="sm" />

**弧上标注**

`label` 透传到底层弧 step，文字沿弧定位（`position` 缺省 `midway`，按 `startAngle..endAngle` 线性映射），用法与边标注一致。Sector 同样支持，见下方饼图示例。

#### Sector

`<Sector>` 会从圆心出发，画弧，再回到圆心。给 `innerRadius` 可以画空心扇形；圆使用 `number`，椭圆使用 `{ x, y }`。

| 写法                                   | 适合         |
| -------------------------------------- | ------------ |
| `{ center, radius: number, angles }`   | 圆扇形       |
| `{ center, radius: { x, y }, angles }` | 椭圆扇形     |
| 加 `innerRadius: number`               | 空心圆扇形   |
| 加 `innerRadius: { x, y }`             | 空心椭圆扇形 |

<ComponentPreview files="sector-basic" size="sm" />

**圆心接节点、扇区标注**

实心扇形的圆心就是游标，所以 `center` 可以直接接节点 id（或极坐标），把扇形钉在某个节点上；配合 `sweepAngle` 和 `label`，几段就能拼出带标签的饼图。

> 空心扇形（给了内半径）需要计算内 / 外弧端点，`center` 仍须 literal 笛卡尔 `[x, y]`。

<ComponentPreview files="sector-label" size="sm" />

**整体变换**

`rotate` / `scale` 透传到 `<Path>`，把整条扇形绕包围盒中心变换（免包 `<Scope>`）。`rotate` 让轴对齐椭圆扇形倾斜——这是目前画"斜椭圆扇形"的方式。

<ComponentPreview files="sector-transform" size="sm" />

Arc 与 Sector 共用椭圆半径和角度模型。掌握上面的基础写法后，可以用 playground 同时调整两者：左侧观察 Arc 的开放 / 闭合方式，右侧观察 Sector 的内弧如何改变环宽。

<ComponentPreview files="arc-sector-playground" size="sm" />

### API 参考

| 组件       | 组合                                 | 含义                       |
| ---------- | ------------------------------------ | -------------------------- |
| `<Arc>`    | `center` + `radius: number` + 角度   | 圆弧（默认开放；角度必填） |
|            | `center` + `radius: { x, y }` + 角度 | 椭圆弧                     |
| `<Sector>` | `center` + `radius: number` + 角度   | 圆扇形（角度必填）         |
|            | `center` + `radius: { x, y }` + 角度 | 椭圆扇形                   |
|            | + `innerRadius?: number`             | 空心圆扇形                 |
|            | + `innerRadius?: { x, y }`           | 空心椭圆扇形               |

共用属性（透传到底层 `<Path>`）：

| 属性               | 类型                                                                                     | 适用              | 说明                                                         |
| ------------------ | ---------------------------------------------------------------------------------------- | ----------------- | ------------------------------------------------------------ |
| 角度               | `startAngle` / `endAngle` / `sweepAngle`                                                 | Arc / Sector      | 三选二，单位度；`0`=+x、`90`=屏幕下方                        |
| `center`           | target                                                                                   | Arc / 实心 Sector | 接节点 id / 极坐标 / 笛卡尔；空心 Sector 须 literal `[x, y]` |
| `close`            | `'open' \| 'chord' \| 'sector'`                                                          | Arc               | 闭合方式，缺省 `'open'`                                      |
| `label`            | 边标注对象                                                                               | Arc / Sector      | 沿弧定位，`position` 缺省 `midway`                           |
| `rotate` / `scale` | `number` / `{ x, y }`                                                                    | Arc / Sector      | 绕包围盒中心整体变换                                         |
| `marks`            | `{ pos, mark }[]`                                                                        | Arc / Sector      | 沿路径中段放方向标记                                         |
| 视觉               | `stroke` / `strokeWidth` / `dashPattern` / `dashOffset` / `arrow` / `fill` / `opacity` … | Arc / Sector      | 透传 `<Path>` 全套视觉属性                                   |

## 作为 Node 形状

当你要的是一个扇形 / 弧形的**节点**（可被连线引用、可当图标 glyph）而不是一条线时，给 `<Node>` 设 `shape={{ type, params }}`。这类形状尺寸由 `params` 里的半径 / 角度定，**不依赖文字内容**。

### 用法

```tsx
import { Node } from '@retikz/react';
```

```tsx
<Node shape={{ type: 'sector', params: { innerRadius: 0, outerRadius: 40, startAngle: 0, endAngle: 90 } }} />
<Node shape={{ type: 'arc', params: { radius: 40, startAngle: 0, endAngle: 90 } }} />
```

### 例子

在 playground 中切换 Arc / Sector：Arc 是单半径弧，Sector 是环楔。选择 Sector 时可调整 `cornerRadius`，比较硬角与圆角后的连接边界；再通过轨道角度与距离移动来源节点，观察自动贴边如何跟随当前曲线或轮廓。`弧中点` 对应 Sector 的外弧中点，`内弧中点` 在 Sector 下对应 `inner-arc-mid`，切到 Arc 时安全回退到 `arc-mid`。

<ComponentPreview files="node-connection-playground" size="sm" />

除节点的中心与 8 个方位 anchor（`center` / `top` …）外，这两个形状还提供按几何命名的 anchor，可用 `{ id, anchor }` 精确连线：

- **sector**：`outer-arc-mid` / `inner-arc-mid` / `apex` / `centroid` / `start-edge-mid` / `end-edge-mid`
- **arc**：`arc-mid` / `start` / `end` / `center`

Node 的形状、尺寸、边界与 anchor 见 [Node 几何](/kernel/components/node/overview)。

### API 参考

| `shape`                      | params                                                                      | 边界 / 用途                                |
| ---------------------------- | --------------------------------------------------------------------------- | ------------------------------------------ |
| `{ type: 'sector', params }` | `innerRadius` / `outerRadius` / `startAngle` / `endAngle` / `cornerRadius?` | 环楔（可连接，`innerRadius:0` 为实心扇片） |
| `{ type: 'arc', params }`    | `radius` / `startAngle` / `endAngle` / `close?`                             | 弧形 glyph（可连接）                       |

sector 的 `cornerRadius`（用户单位）给环楔四角倒角，省略 / `0` = 硬角，逐角夹紧；`apex` / `*-arc-mid` 等命名锚点不随它移动。

> Node sector 约束：`outerRadius` 必须 > `innerRadius`（`innerRadius:0` 为实心扇片），违反编译期 refine 报错。

### 角度范围如何确定

先看图中的坐标轴和橙色箭头：角度从 `startAngle` 出发，沿屏幕坐标中的递增方向扫到 `endAngle`，两者之差就是 `sweepAngle`。

<ComponentPreview files="arc-sector-angle-model" size="md" hideCode />

屏幕坐标的 x 向右、y 向下，所以 `0°` 指向右侧，`90°` 指向下方，角度递增看起来是顺时针。Sugar 接受 `startAngle` / `endAngle` / `sweepAngle` 中恰好两个，再补出第三个；Node 形状的 params 则直接保存 `startAngle` 与 `endAngle`，但两者使用同一视觉约定。

### Sugar 如何形成 Path

图右侧不是三种渲染特效，而是三种等价的 `<Path>` / `<Step>` 拓扑。`<Arc>` 与 `<Sector>` 先解析角度和半径，再根据开放、闭合或空心选择其中一条分支。

<ComponentPreview files="arc-sector-sugar-flow" size="sm" hideCode />

- 开放 `<Arc>` 从圆心开始，用一个 `arc` Step 画弧，游标停在弧终点。
- 闭合 `<Arc>` 与实心 `<Sector>` 使用 `circlePath` / `ellipsePath`；`closed` 决定两端连弦，还是连回圆心。
- 空心 `<Sector>` 依次画外弧、径向边、反向内弧和回起点的径向边。它必须先算出内外弧端点，因此 `center` 只能是字面量 `[x, y]`。

描边、填充、箭头和整体变换统一落在外层 `<Path>`；`label` 挂在承担可见弧线的 Step 上。Sugar 到这里就结束，不引入另一套路径或渲染语义。

### Node 如何共享一份几何

`<Node shape={{ type, params }}>` 不经过上面的 Sugar 组件树，而是把形状交给 core 的 shape 定义。图中间的“形状几何 / 轮廓”是关键：轴对齐包围盒（AABB）、anchor、连接点和最终 path 都从同一组 params 派生。

<ComponentPreview files="arc-sector-node-geometry" size="sm" hideCode />

Arc 是没有内部面积的曲线。普通连线会把目标方向投影成弧上的角度；若方向落在缺口中，连接点夹到更近的起点或终点。Sector 是闭合轮廓，连线从填充区域内部朝目标发射射线，命中内弧、外弧、径向边或圆角后的真实轮廓。

因此 `cornerRadius` 会同时改变 Sector 的可见轮廓与自动连接点，但不会移动精确 AABB 和 `apex` / `outer-arc-mid` 等命名 anchor。要固定语义位置就显式选 anchor；要让连线自动贴合当前轮廓就使用普通节点引用。
