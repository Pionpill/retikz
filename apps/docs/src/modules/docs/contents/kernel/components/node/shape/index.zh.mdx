在[基础用法](/kernel/components/node/usage)之上，`shape` 同时决定节点的视觉轮廓、内容占位和默认连接边界。Core 内置 rectangle、ellipse、polygon；circle 与 diamond 分别是 ellipse 与 polygon 的预设。只绘制轮廓时见 [Path 形状绘制](/library/standard/shape/circle-ellipse)。

## 接入方式

四种写法都在原点绘制同一个圆形 Hello 节点。React 示例默认导出可挂载组件；Vanilla 示例需要页面已有 `<div id="diagram"></div>`。

## Rectangle

`shape` 省略时先继承 `Scope.defaults.node.shape`，没有继承值时才使用矩形。显式写 `shape="rectangle"` 可覆盖继承；矩形边界由文字、padding 和尺寸约束共同决定。

```tsx
import { Node } from '@retikz/react';
```

```tsx
<Node position={[0, 0]}>label</Node>
<Node position={[0, 0]} shape={{ type: 'rectangle', params: { cornerRadius: 10 } }}>rounded</Node>
```

playground 固定目标矩形在原点。调整 `cornerRadius` 比较直角与圆角边界，再通过轨道角度与距离移动来源节点；自动贴边会落在真实边界上，命名 / 数字 anchor 则给出稳定的显式位置。

<ComponentPreview files="rectangle-node-connection-playground" size="sm" />

圆角既可以用顶层 `cornerRadius`，也可以写成 `shape={{ type:'rectangle', params:{ cornerRadius } }}`（两者并存时 params 优先）。Node 的通用尺寸、边界与 anchor 见 [Node 几何](/kernel/components/node/usage)。

### 形状选项

| `shape`              | 边界                         | 参数                        |
| -------------------- | ---------------------------- | --------------------------- |
| 缺省 / `"rectangle"` | 包住「文字 + padding」的内框 | `cornerRadius?`（圆角半径） |

## Circle / Ellipse

当你要的不是一条线、而是一个圆形 / 椭圆形的节点时（装文字、被连线引用），给 `<Node>` 设 `shape`。

```tsx
import { Node } from '@retikz/react';
```

```tsx
<Node position={[0, 0]} shape="circle">label</Node>
<Node position={[0, 0]} shape="ellipse">label</Node>
```

在 playground 中切换 `circle` / `ellipse`：前者是 `circumscribe:'equal'` 的等轴预设，后者默认按各轴 × √2 外接「文字 + padding」。调整轨道角度与距离移动来源节点；保持自动贴边，或切换命名 / 数字 anchor，直接比较端点在两种边界上的落点。

<ComponentPreview files="circle-ellipse-node-connection-playground" size="sm" />

节点中心与 8 个方位 anchor（`center` / `top` …）照常可用。`position` / `fill` / `padding` / `label` 等通用属性见 [Node](/kernel/components/node/usage)。

### 形状选项

| `shape`                                     | 边界                                                             | 参数                                                                                          |
| ------------------------------------------- | ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| `"circle"`                                  | 能容纳文字的外接圆（= `ellipse` 的 `circumscribe:'equal'` 预设） | 无                                                                                            |
| `"ellipse"` 或 `{ type:'ellipse', params }` | 外接椭圆                                                         | `circumscribe?`：`'proportional'`（默认，各轴 × √2）/ `'equal'`（等轴，半径取内框对角线之半） |

## Polygon / Diamond

当你要的是一个多边形**节点**（装文字、被连线引用）而不是一条线时，给 `<Node>` 设 `shape={{ type:'polygon', params }}`。边界取能容纳「文字 + padding」的正多边形外接圆，尺寸由文字驱动。

```tsx
import { Node } from '@retikz/react';
```

```tsx
<Node position={[0, 0]} shape={{ type: 'polygon', params: { sides: 6 } }}>label</Node>
<Node position={[0, 0]} shape="diamond">label</Node>
<Node position={[0, 0]} shape={{ type: 'diamond', params: { aspectRatio: 1.8 } }}>label</Node>
```

playground 把六边形与 `diamond` 预设放在同一场景比较；字符串 `diamond` 保持正菱形，对象形式可通过 `aspectRatio` 调整宽高比。选择六边形时可调整 `cornerRadius`，再通过轨道角度与距离移动来源节点，观察自动贴边如何跟随尖角或圆角轮廓，并与命名 / 数字 anchor 对照。

<ComponentPreview files="polygon-node-connection-playground" size="sm" />

Node 的通用尺寸、边界与 anchor 见 [Node 几何](/kernel/components/node/usage)。

### 形状选项

| `shape`                       | 边界                                  | 参数                                                                     |
| ----------------------------- | ------------------------------------- | ------------------------------------------------------------------------ |
| `{ type: 'polygon', params }` | 能容纳文字的正多边形外接圆            | `sides`（≥3） / `rotate?` / `cornerRadius?` / `aspectRatio?`（仅四边形） |
| `"diamond"`                   | = `polygon{ sides:4, rotate:0 }` 预设 | 无                                                                       |
| `{ type: 'diamond', params }` | 可参数化的四边形菱形                  | `aspectRatio?`（宽 / 高，缺省 `1`）                                      |

`cornerRadius`（用户单位）给每个顶点倒角，省略 / `0` = 直角，逐角夹紧到不自交的最大半径。

## Extension 形状

星形、扇形、任意轮廓、十字形、圆柱等由 [Extension 形状扩展](/library/extension/shape)提供，需要按该页说明装配。这里不重复其参数与示例。内置形状无法表达目标时，见[自定义形状](/kernel/components/node/custom-shape)；只改变连接规则时，见[自定义连接面](/kernel/components/node/custom)。
