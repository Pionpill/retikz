`text` is the node body; `label` is separate text attached to the border or center. Start with [Basic usage](/kernel/components/node/usage). Labels do not enlarge the node shape.

## Using this topic

Put one `label` object on a Node to attach separate text to its border. The four forms below attach `status` to the same node; Vanilla needs an existing `<div id="diagram"></div>`.

## Adding labels

`label` accepts one object or an array. Choose the attachment point, then adjust its style:

- `position` defaults to `'top'` and accepts `'top'`, `'top-right'`, `'right'`, `'bottom-right'`, `'bottom'`, `'bottom-left'`, `'left'`, and `'top-left'`
- It also accepts the center `'center'`, an angle such as `30`, or a boundary fraction such as `{ boundary: 'right', fraction: 0.25 }`; centered labels have no collision avoidance
- `placement` defaults to `'outside'`; use `'inside'` to place the label inside the border
- `font` / `textColor` use explicit label values first, then `Scope.defaults.label`, and finally inherit missing values from the node
- `opacity` is 0..1 and multiplies the node opacity

## Label position

Choose a named direction, numeric angle, boundary fraction, or the center on one label. Center labels hide ineffective position fields.

<ComponentPreview files="node-label-position" size="md" />

To attach multiple labels, place the same object form in an array:

```tsx
import { Node } from '@retikz/react';

<Node
  position={[0, 0]}
  label={[
    { text: 'status', position: 'top' },
    { text: 'owner', position: 'bottom' },
  ]}
/>;
```

## Spacing and placement

`distance` is the net gap, along the placement direction, between the node boundary and the **rotated label visual box**. When omitted, it uses `<Layout labelDistance>` (default `12`); `0` makes the visual box touch the boundary. `placement: 'inside'` turns the direction inward and preserves the same gap on the inner side. Rectangle nodes can also use `position: { boundary, fraction }` to attach to a proportional point on a specific side. `position: 'center'` always uses the final node rectangle center and ignores `placement` and `distance`.

- `boundary` accepts `'top'` / `'right'` / `'bottom'` / `'left'`
- `fraction` is the 0..1 proportional position on that side and defaults to `0.5`
- `placement: 'inside'` cannot be combined with `pin`; keep labels outside when a leader line is needed

## Rotation and leader lines

`label.rotate` spins the label text around **its own center**: `'radial'` follows the direction defined by `position`, using the selected side's outward normal for a boundary-fraction position; `'tangent'` is its tangent (radial + 90°), and a number is an explicit angle in degrees. `placement: 'inside'` reverses only the label offset, not this orientation. `keepUpright` flips it 180° when it would otherwise read upside-down. Rotation changes the visual box projection along the placement direction, so the compiler adjusts the label center to preserve the same `distance` gap.

`label.pin` adds a **leader line** from the node border to the label: `pin: true` is a default thin solid line (inherits the label color); `pin: { stroke, strokeWidth, dashPattern, dashOffset }` customizes it; omitted / `false` = no leader. Its endpoint is the exact intersection of the placement ray and the rotated visual box, with no hidden padding; the preceding box geometry still owns label placement.
