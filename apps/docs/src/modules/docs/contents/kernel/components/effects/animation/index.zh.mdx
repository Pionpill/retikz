title: 动画
description: 给节点 / 路径 / 镜头按时间打关键帧——入场、强调、循环、镜头与错峰，声明式书写、能优雅降级；preset 与底层 AnimationTrack 等价，静止末帧约定支持完整降级。
---

动画让固定图元**按时间从一个样子过渡到另一个样子**：淡入、画线、放大、旋转、变色、镜头推拉。你不用手写关键帧——调一个 **preset 工厂**（`fadeIn()` / `spin()` …）得到一条动画描述，挂到元素的 `animations` 数组即可。

## 用法

```tsx
import { fadeIn, scaleIn } from '@retikz/core';
import { Node } from '@retikz/react';
```

```tsx
<Node position={[0, 0]} animations={[fadeIn(), scaleIn()]}>
  hi
</Node>
```

## 例子

`animations` 可挂在 `<Node>` / `<Path>` / `<Scope>`（元素动画）与 `<Layout>`（镜头）。一个元素能挂多条，互不干扰。除包装器 `loop` 与编排 `stagger` 外，每个 preset 都接受公共项 `{ duration, delay, easing, trigger }`，部分另有专有项（`scaleIn.from` / `slideIn.axis,offset` / `growUp.origin` / `pulse.peak` …）。

### 全部动画一览

| 动画         | 家族 | 底层通道      | 说明                              |
| ------------ | ---- | ------------- | --------------------------------- |
| `fadeIn`     | 入场 | opacity       | 渐入（0→1）                       |
| `drawOn`     | 入场 | pathDraw      | 描边沿路径画出                    |
| `scaleIn`    | 入场 | scale         | 从略小弹入（0.8→1）               |
| `grow`       | 入场 | scale         | 从无到有放大（0→1）               |
| `growUp`     | 入场 | scaleY        | 从基线长出（柱状图）              |
| `slideIn`    | 入场 | translateX/Y  | 从偏移滑入                        |
| `colorShift` | 强调 | fill / stroke | 颜色过渡（oklch 插值）            |
| `flash`      | 强调 | opacity       | 闪一下（默认 2 次）               |
| `blink`      | 强调 | opacity       | 持续闪烁（无限）                  |
| `wiggle`     | 强调 | rotate        | 左右抖动（默认 3 次）             |
| `pulse`      | 循环 | scale         | 脉冲缩放（无限）                  |
| `spin`       | 循环 | rotate        | 匀速旋转（无限，loader）          |
| `loop`       | 循环 | 任意          | 把任意 track 变成无限循环         |
| `cameraTo`   | 镜头 | viewBox       | 镜头推拉 / 平移（挂 `<Layout>`）  |
| `stagger`    | 编排 | —             | 给一组动画依次叠加延迟            |
| `snapshot`   | 控制 | —             | `snapshotAt` 把某时刻烘焙成静态帧 |

### 入场

入场动画在**页面加载时播一次**，把元素从透明 / 偏移 / 缩小状态带到最终样子。它们都是元素动画，挂在 `<Node>` / `<Path>` / `<Scope>` 的 `animations` 上。

| 动画      | 说明                                                                     | 专有项                                                                                                        |
| --------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------- |
| `fadeIn`  | 透明度 0→1，最常用的入场                                                 | —（仅公共项）                                                                                                 |
| `scaleIn` | 均匀缩放 `from`→1，绕支点弹入                                            | `from`（起始缩放，缺省 `0.8`，末帧恒为 `1`）、`origin`（缩放支点，缺省几何中心）                              |
| `grow`    | `scaleIn` 的 `from: 0` 别名，从无到有放大                                | `origin`（同 `scaleIn`）                                                                                      |
| `growUp`  | `scaleY` 0→1，支点底边——柱状图从基线长出                                 | `origin`（缺省 `'bottom'` 底边中点；也可写其它 canonical anchor 或 `[x, y]`）                                 |
| `slideIn` | `translateX`/`translateY` `offset`→0，从偏移滑回原位                     | `axis`（`'x'`→`translateX` / `'y'`→`translateY`，缺省 `'x'`）、`offset`（起始位移，缺省 `-20`，末帧恒为 `0`） |
| `drawOn`  | `pathDraw` 0→1，描边沿路径逐渐画出；仅对**有描边**的 `<Path>` / 形状有效 | —（仅公共项）                                                                                                 |

### 强调与循环

强调动画**吸引注意**——变色、闪烁、抖动；循环动画**持续播放**——脉冲、旋转、把任意 track 变成无限循环。它们都是元素动画。强调多用 `0 → 0.5 → 1` 三帧往返（末帧仍回 base，一次播完元素停在原样）；`flash` 默认重复 2 次、`wiggle` 3 次，`blink` / `pulse` / `spin` 用 `iterations: 'infinite'` 持续播。

<span style={{ color: '#888' }}>
  flash / blink / wiggle / pulse 四个节点，spin 旋转条、loop 往返、colorShift 变色三块形状。
</span>

| 动画         | 说明                                                                                                                      | 专有项                                                                                                       |
| ------------ | ------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `colorShift` | `fill` / `stroke` 在 **oklch** 空间过渡（感知均匀、无灰带）；作用于形状自身的填充 / 描边                                  | `from` / `to`（起止色，**均必填**——纯工厂取不到 base 色）、`channel`（`'fill'` / `'stroke'`，缺省 `'fill'`） |
| `flash`      | `opacity` 1→dim→1 闪一下，默认闪 2 次；末帧回 base                                                                        | `dim`（谷值不透明度，缺省 `0`）、`iterations`（闪烁次数，缺省 `2`）                                          |
| `blink`      | 无限版 `flash`（`opacity` 持续闪烁）                                                                                      | `dim`（谷值不透明度，缺省 `0`）、`iterations`（缺省 `'infinite'`）                                           |
| `wiggle`     | `rotate` 0→+a→−a→+a→0 左右抖动强调，绕几何中心                                                                            | `angle`（抖动幅度，度，缺省 `5`）、`iterations`（缺省 `3`）、`origin`（旋转支点，缺省几何中心）              |
| `pulse`      | `scale` 1→peak→1 无限脉冲（强调 / 心跳）                                                                                  | `peak`（峰值缩放，缺省 `1.1`）、`origin`（缩放支点，缺省几何中心）                                           |
| `spin`       | `rotate` 0→360 无限匀速，绕几何中心——典型 loader                                                                          | `origin`（旋转支点，缺省几何中心）                                                                           |
| `loop`       | `loop(track, { direction })`：把任意一次性 track 包成无限循环；不产新 track，给传入 track 叠加 `iterations` / `direction` | `iterations`（缺省 `'infinite'`）、`direction`（如 `'alternate'`，往返播）                                   |

### 镜头与编排

镜头与编排是**作用于整体、而非单个元素外观**的两类动画：`cameraTo` 动的是 scene 的取景框，`stagger` 调的是一组动画的起始时间。

`cameraTo({ from, to })`：动 scene 的取景框 `[x, y, w, h]`，实现推拉 / 平移。挂在 `<Layout animations>`（镜头属 scene 根，不是某个元素）；起止取景都要显式给。默认 `duration` 800ms、`easing` `ease-in-out`，与其他公共项一样可覆盖。展开后是一条 `viewBox` 通道的 track。

<ComponentPreview files="camera" size="md" />

<span style={{ color: '#888' }}>镜头从全景推到右下角局部。</span>

`stagger(tracks, stepMs, startMs = 0)`：把一组 track 的 `delay` **统一改写为 `startMs + i×stepMs`**（覆盖各 track 原有 `delay`），实现「依次入场」。第三参 `startMs` 缺省 0，是整组的起始偏移。它编排的是元素动画的起始时间，本身不改变单个动画的形态。

### 轨道如何进入渲染

preset 与手写轨道最终都是同一种 `AnimationTrack`。preset 只负责填好常用的属性通道、关键帧和时序默认值；它产出的仍是可序列化 JSON，不携带回调、DOM 对象或播放状态。

轨道挂到元素或 `<Layout>` 后，compile（从 IR 生成 Scene 的阶段）只校验职责边界并保留合法数据：`viewBox` 只能作为 Scene 根镜头动画，其它通道只能落在元素上。越界轨道会给出 warning 并被丢弃，renderer 不需要重新判断这条归属规则。

因此 React DSL、直接写 IR 与 Vanilla spec 共用一份动画语义；后端只决定如何播放，不会把 preset 解释成另一种模型。

### 时间如何变成一帧

关键帧的 `at` 是 `[0, 1]` 内的归一化位置，`duration` 才把它映射到毫秒。对任意时刻，求值器依次扣除 `delay`、确定迭代次数与方向、按 `fill` 处理活动区间外的值，再定位相邻关键帧并应用该段 easing，最后按值类型插值。

实时播放时，两种 renderer 选择不同载体，但消费的是同一条轨道：

- SVG 把 `load` 轨道展开成内联 CSS `@keyframes`，静态 HTML 就能零 JS 自播；`visible` / `manual` / 事件轨道则序列化为描述，再由运行时接到 WAAPI
- Canvas 用一个 Scene 级 rAF 时钟推进绝对时间，每帧调用共享求值器，把结果应用到图元属性或画布变换后重绘
- `snapshotAt` 不启动时钟，而是直接用同一求值器采样指定时刻，生成静态属性与 transform

### 触发与控制

`trigger` 只决定轨道**何时被激活**，不会改变关键帧和时序本身。默认值是 `load`：

| trigger                | 行为                       | 后端支持                                                            |
| ---------------------- | -------------------------- | ------------------------------------------------------------------- |
| `load`（默认）         | 渲染即播                   | SVG（内联 CSS 自播，SSR 零 JS）/ Canvas（起 rAF）                   |
| `visible`              | 进视口才播                 | SVG（IntersectionObserver）；Canvas（按 id 的 bbox 与视口相交判定） |
| `manual`               | 不自动播，由运行时句柄控制 | SVG / Canvas                                                        |
| `{ onEvent: 'click' }` | 命中事件才播               | SVG / Canvas（水合命中后激活）                                      |

给 `<Layout animationRef={ref}>` 传一个 ref，挂载后拿到 `AnimationControls`（`play` / `pause` / `seek`），即可在组件外用自己的按钮控制（配 `trigger: 'manual'` 最常见）：

```tsx
const ref = useRef<AnimationControls | null>(null);

<Layout animationRef={ref}>
  <Node position={[0, 0]} animations={[{ ...spin(), trigger: 'manual' }]} />
</Layout>
<button onClick={() => ref.current?.play()}>播放</button>
```

`animationRef` / vanilla `view.animation` 是 Scene 级时钟句柄：SVG 控制整图交互动画的 WAAPI 句柄，Canvas 控制共享 rAF 时钟。handler 内要控制命中的具体图元时，用水合的 [`context.animation`](/kernel/packages/render/hydration#handler-的-context)，两后端都是 per-id 控制。

播放总开关是三态的。React 与 Vanilla 的写法不同，但优先级一致：

| 意图     | React             | Vanilla                         |
| -------- | ----------------- | ------------------------------- |
| 跟随系统 | 省略 `animate`    | 省略 `animation.enabled`        |
| 强制开启 | `animate={true}`  | `animation: { enabled: true }`  |
| 强制关闭 | `animate={false}` | `animation: { enabled: false }` |

### 静态帧与降级

给 `<Layout snapshotAt={毫秒}>`（或 `renderToSvgString(ir, { animation: { snapshotAt } })` / `mountSvg(…, { animation: { snapshotAt } })`）会渲染**定格在该时刻的一帧**：不播放、不输出动画规则，只把自动播轨道在该时刻的值烘焙成静态属性或 transform。它适合 SSR 海报帧、缩略图和社交卡片预览。

<ComponentPreview files="snapshot" size="xs" />

```tsx
// grow（0→1，300ms）定格在 150ms ≈ 半大
<Layout snapshotAt={150}>
  <Node position={[0, 0]} animations={[grow({ duration: 300 })]}>
    150ms
  </Node>
</Layout>
```

`snapshotAt` 的优先级高于播放总开关，但只采样 `load` / 缺省触发的轨道；`manual` / `visible` / 事件轨道保持 base，因为静态海报代表「加载后、尚未发生交互」。未指定截帧且动画关闭、系统要求减少动态效果或后端不支持播放时，也会直接渲染 base，不报错、不丢图。

默认 `fill="forwards"` 会在播放结束后保留末帧。内置入场与往返类 preset 把末帧设计成常见 base 值，`spin` 的 360° 也与 0° 等价；`colorShift` / `cameraTo` 无法读取元素或镜头的 base，因此要求你显式给出终点。`AnimationTrackSchema` 只把「末帧应是静止态」写成约定、不会替你比较 base；手写轨道和显式终点若希望优雅降级，也应落到预期静止态。

<ComponentAlert
  title="末帧回到静止态是一条作者约定"

## API 参考

### 组件属性

| 属性           | 类型                             | 默认值      | 描述                                        |
| -------------- | -------------------------------- | ----------- | ------------------------------------------- |
| `animations`   | `Array<IRAnimationTrack>`        | —           | 挂到 Node、Path、Scope 或 Layout 的动画轨道 |
| `animate`      | `boolean`                        | `undefined` | Layout 播放总开关；省略时跟随系统偏好       |
| `snapshotAt`   | `number`                         | —           | Layout 静态截帧时间，单位毫秒               |
| `animationRef` | `Ref<AnimationControls \| null>` | —           | Layout 的 scene 级播放控制句柄              |

### AnimationTrack

| 属性         | 类型                                                                 | 默认值       | 描述                                  |
| ------------ | -------------------------------------------------------------------- | ------------ | ------------------------------------- |
| `property`   | `string`                                                             | —            | 动画属性通道；`viewBox` 只用于 Layout |
| `keyframes`  | `Array<{ at, value, easing? }>`                                      | —            | 按 `at` 升序的绝对值关键帧            |
| `duration`   | `number`                                                             | —            | 单次迭代时长，单位毫秒                |
| `delay`      | `number`                                                             | `0`          | 首次迭代前延迟，单位毫秒              |
| `easing`     | `string \| [number, number, number, number]`                         | `'linear'`   | track 级缓动；关键帧可覆盖下一段      |
| `iterations` | `number \| 'infinite'`                                               | `1`          | 播放次数                              |
| `direction`  | `'normal' \| 'reverse' \| 'alternate'`<br />`\| 'alternate-reverse'` | `'normal'`   | 每轮播放方向                          |
| `fill`       | `'none' \| 'forwards' \| 'backwards' \| 'both'`                      | `'forwards'` | 活动区间外采用的值                    |
| `trigger`    | `'load' \| 'visible' \| 'manual'`<br />`\| { onEvent: string }`      | `'load'`     | 播放触发方式                          |
| `origin`     | `Anchor \| [number, number]`                                         | 几何中心     | scale、scaleX/Y 与 rotate 的支点      |
