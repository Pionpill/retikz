This page covers React Layout and execution options, Vanilla `scene` / `layer` builders and scene input, and Core `IRScene` / `IRViewBox`. Vanilla builds input with `scene` and passes it to a host entry such as `mount`; there is no `layout` builder.

See [Basic usage](/kernel/components/layout/usage) for integration, [Schema reference](/kernel/components/layout/schema-reference) for persisted fields, and [Vanilla](/kernel/packages/vanilla) for mounting, updating, and disposal.
