从 A 到 B 画一条线。`Node.id` 是引用名，`Draw.way` 按顺序引用这些目标；节点已有形状时，连线会附着到连接面，而不是穿过节点中心。

## 接入方式

四种写法绘制同一结果。React 使用组件或 IR；Vanilla 使用作者侧构造函数或 IR。Vanilla 示例需要 HTML 容器 `<div id="diagram"></div>`，容器移除前调用 `view.dispose()`。安装见[快速开始](/kernel/components/get-start)。

import type { IRScene } from '@retikz/core';
import { Layout } from '@retikz/react';
import type { FC } from 'react';

const ir: IRScene = {
  version: 1,
  type: 'scene',
  children: [
    { type: 'node', id: 'a', position: [0, 0], text: 'A' },
    { type: 'node', id: 'b', position: [100, 0], text: 'B' },
    {
      type: 'path',
      children: [
        { type: 'step', kind: 'move', to: { id: 'a' } },
        { type: 'step', kind: 'line', to: { id: 'b' } },
      ],
    },
  ],
};

const Demo: FC = () => <Layout ir={ir} />;
export default Demo;

## 选择路线

直线就是从 A 直接连到 B。想拐弯或画曲线，就在 A 和 B 中间加一个动作。下面可以切换看看：单轴投影只往一个方向走，所以不一定能连到 B；折线会真的连到 B。完整写法见[路径写法](/kernel/components/path/draw)。

| 连接方式         | 枚举 / Step 值                                           | `way` 写法                                      |
| ---------------- | -------------------------------------------------------- | ----------------------------------------------- |
| 直连             | `kind: 'line'`                                           | `['a', 'b']`                                    |
| 水平单轴         | `kind: 'axis-line'`<br />`axis: 'horizontal'`            | `['a', { horizontalTo: 'b' }]`                  |
| 垂直单轴         | `kind: 'axis-line'`<br />`axis: 'vertical'`              | `['a', { verticalTo: 'b' }]`                    |
| 水平后垂直       | `DrawWay.Hv = '-\|'`<br />`kind: 'fold'`                 | `['a', '-\|', 'b']`                             |
| 垂直后水平       | `DrawWay.Vh = '\|-'`<br />`kind: 'fold'`                 | `['a', '\|-', 'b']`                             |
| 水平、垂直、水平 | `DrawWay.Hvh = '-\|-'`<br />`kind: 'fold'`               | `['a', '-\|-', 'b']`                            |
| 垂直、水平、垂直 | `DrawWay.Vhv = '\|-\|'`<br />`kind: 'fold'`              | `['a', '\|-\|', 'b']`                           |
| 二次贝塞尔       | `kind: 'curve'`                                          | `['a', { curve: [50, -40] }, 'b']`              |
| 三次贝塞尔       | `kind: 'cubic'`                                          | `['a', { cubic: [[30, -40], [70, -40]] }, 'b']` |
| 弯曲简写         | `kind: 'bend'`<br />`bendDirection: 'left'` 或 `'right'` | `['a', { bend: 'left' }, 'b']`                  |

<ComponentPreview files="draw-orthogonal" size="md" />

## 何时使用 Path

需要多个子路径或逐段控制时，用 Path 组织显式 Step 更清楚。Draw 只暴露常用路径写法与外观属性；整条路径的 `label`、`marks`、`rotate` 和 `scale` 需要使用 Path。下面两种写法画同一条折线；Step 把每个动作写得更明确。

```tsx
<Draw way={['a', '-|', 'b']} />

<Path>
  <Step kind="move" to="a" />
  <Step kind="fold" via="-|" to="b" />
</Path>
```

从 `@retikz/react` 导入 `Path`、`Step`，在现有 Layout 内替换 Draw 即可。Path 也接受 `way`，但不能与显式步骤同时提供。
