## 用法

```tsx
import { Node } from '@retikz/react';
```

```tsx
<Node id="a" position={[0, 0]}>
  Label
</Node>
```

需要可见主体、文字或真实边界时使用 Node；只需要一个不可见引用点时使用 [Coordinate](/kernel/components/node/coordinate)。

## 例子

### 基础

<ComponentPreview files="node-basic" size="xs" />

一个 Node 把位置、内容与形状边界收在同一声明里。流程图节点通常只需默认矩形；纯文字可去掉 `stroke` / `fill`；需要稳定尺寸时再加 `minimumSize`。

### 定位

`position` 可以写笛卡尔、极坐标、方向相对、引用点偏移或两点比例位置。用面板切换输入形态并调整参数，观察同一个 `q` 如何围绕固定参照节点 `a` / `b` 移动。

<ComponentPreview files="node-position" size="md" />

引用 id 必须先声明；方向定位的默认距离来自 `<Layout nodeDistance>`，`between` 的 `fraction: 0.5` 表示中点。完整输入类型见下方 [API 参考](#定位)，需要不可见辅助点时使用 [Coordinate](/kernel/components/node/coordinate)。

### 形状

节点的视觉轮廓和连线端点分三层控制：`shape` 选择画出来的形状，`boundary` 选择自动贴边使用的连接面，path 端点的 `anchor` 则指定一个命名连接点。分别修改 A / B，观察同一条边如何落到两端。

<ComponentPreview files={['node-shape-connection', 'node-shape-connection-boundary.ts']} size="xl" />

`anchor` 省略时，连线朝另一个端点自动贴边；标准命名 anchor（如 `top` / `right`）按 `boundary` 解析。`center` 会直接连到节点中心。形状专属 anchor 仍属于视觉 `shape`，具体名称见对应形状页。

`shape` 有两种写法：无必填参数的形状可用裸字符串；`polygon` / `sector` / `arc` / `star` 等带参形状必须写成 `{ type, params }`。按尺寸来源，它们又分为包住「文字 + padding」的文本容器形状，以及由半径 / 角度决定尺寸的几何形状。

每种形状的参数和专属 anchor 见对应页面：

| shape             | 写法                                       | 文档                                                         |
| ----------------- | ------------------------------------------ | ------------------------------------------------------------ |
| rectangle         | 默认 / `'rectangle'`                       | [Rectangle](/kernel/components/shapes/rectangle)             |
| circle / ellipse  | `'circle'` / `'ellipse'`                   | [Circle / Ellipse](/kernel/components/shapes/circle-ellipse) |
| sector / arc      | `{ type:'sector' \| 'arc', params }`       | [Arc / Sector](/kernel/components/shapes/arc-sector)         |
| polygon / diamond | `{ type:'polygon', params }` / `'diamond'` | [Polygon](/kernel/components/shapes/polygon)                 |
| star              | `{ type:'star', params }`                  | [Star](/kernel/components/shapes/star)                       |

`shape` 也接受经 `<Layout shapes>` / `CompileOptions.shapes` 注册的名称，带参注册形状继续用 `{ type, params }`。详情见 [自定义形状](/kernel/components/shapes/custom-shape)。

`boundary` 默认为 `'shape'`，也可选 `'circle'` / `'rectangle'` / `'ellipse'` 或注册的连接面。它只改变自动端点与标准 anchor 的解析，不改节点占位和视觉轮廓；三个内置替代面都会覆盖视觉外接框，playground 中的浅色虚线显示当前连接面。单条边也可在端点对象中覆盖节点默认值，注册方式见 [自定义连接面](/kernel/components/node/custom-boundary)，端点写法见 [Path](/kernel/components/draw/path)。

### 尺寸与变换

尺寸与变换采用同一套节点几何：padding 撑开内容盒，minimumSize 设置下限，scale / rotate 再改变最终边界；margin 不改节点外观，只让连线提前停下。用面板调整同一个 `q`，连接线提供边界参照。

- 内边距：`padding={N}` 或 `padding={{ default, x, y, left, right, top, bottom }}`
- 外边距：`margin={N}` 或 `margin={{ default, x, y, left, right, top, bottom }}`
- `cornerRadius`——圆角半径。`rectangle` / `polygon` / `star` / `sector` 支持圆角（`ellipse` 等不支持），写在形状 params 里：`shape={{ type:'polygon', params:{ sides:6, cornerRadius:8 } }}`、`star` / `sector` / `rectangle` 同理。顶层 `cornerRadius` 只对 `rectangle` 形状生效（默认或显式 `'rectangle'` 都算），且仅在 params 未显式给 `cornerRadius` 时合入；两者并存时 params 优先
- `minimumSize`——撑开 bbox（不缩水 text 自然宽度）
- `scale`——均匀 / 分轴缩放，影响 bbox + 字号 + padding + 路径附着点
- `rotate`——绕节点中心旋转，连线跟随旋转后的边界贴附

### 文本

在面板里直接输入多行内容；换行符形成硬分行，第 1、2、3 行及以后可分别调整颜色、强调方式与透明度。`shape`、`align`、`lineHeight` 和 `maxTextWidth` 也在同一场景比较，节点位置与取景保持不变。

<ComponentPreview files="node-text" size="lg" />

- `text` 接字符串或 LineSpec 数组；字符串里的 `'\n'` 是硬换行，数组则让每行拥有独立样式
- `align` 控制多行块内的水平对齐，`lineHeight` 控制行距；两者都是块级属性
- `maxTextWidth` 是折行阈值，不是固定段落宽；西文按词、CJK 按字折行，不可断长词会整体溢出
- 每行可覆盖 `fill` / `opacity` / `font`，也可以用 [`<Text>` 子元素](/kernel/components/node/text)表达相同结构
- 多行内容换到不同 `shape` 后，外接边界继续遵循各形状自己的外接规则

`text` prop 优先于 `children`；二者同时提供时使用 `text`。块级 `font` 是 `{ family?, size?, weight?, style? }`，其它通用视觉属性可在本页末尾的[样式 playground](#样式)调整。

### 节点标签

`label` 在节点边界附加额外文字。单对象或数组形态；`position` 接 8 方向枚举（缺省 `'top'`）、`'center'`、数字角度，或 `{ boundary, fraction }` 这种边界比例点；`placement` 控制标签在附着点外侧还是内侧，默认 `'outside'`；`'center'` 会把 label 直接画在节点中心，不做重叠避让；`font` / `textColor` 缺省时从 node 继承，`opacity` 可单独控制标签透明度（0~1，与 node `opacity` 相乘）。

下面的 playground 聚焦一个标签，统一尝试命名方位、数字角度、边界比例、内外侧、朝向、文字样式与引线。

<ComponentPreview files="node-label" size="lg" />

需要同时附加多个标签时，把同一份对象写法放进数组：

```tsx
<Node
  label={[
    { text: 'status', position: 'top' },
    { text: 'owner', position: 'bottom' },
  ]}
/>
```

`distance` 控制标签从节点边界继续偏移的距离，省略时默认为 `12`。`placement: 'inside'` 会把偏移方向转向节点内部；矩形节点还可以写 `position: { boundary, fraction }`，把标签附着到某条边界的比例位置上。

- `boundary` 接 `'top'` / `'right'` / `'bottom'` / `'left'`
- `fraction` 是边界上的 0..1 比例位置，缺省 `0.5`
- `placement: 'inside'` 不能和 `pin` 同时使用；需要引线时请保持外侧标签

`label.rotate` 让标签文字绕**自身中心**自旋：`'radial'` 沿"节点中心 → 标签中心"方向、`'tangent'` 取其切向（radial + 90°）、数字为显式角度（度）；`keepUpright` 在文字会倒置时翻 180° 保持可读。`rotate` 只改朝向，不改由 `position` / `distance` 决定的位置。

`label.pin` 给标签加一条**引线**连回节点边界：`pin: true` 是默认细实线（继承标签色）；`pin: { stroke, strokeWidth, dashPattern, dashOffset }` 自定义引线样式；不写 / `false` 则无引线。标签摆放仍由 `position` / `distance` 决定，pin 只是多画一条引线。

### 栈序（zIndex）

默认渲染层叠 = 声明顺序（SVG 只认绘制顺序）。`zIndex` 显式覆盖：大者在上、缺省 0、同值保持声明顺序；只在同层（同 scope / 顶层）子节点间生效。下例始终按 a → b → c 声明，只用控件改变三者层级。`<Path>` / `<Scope>` 同样支持 `zIndex`（scope 的 `zIndex` 作用于整组在父层的位置，不影响 scope 内部相对栈序）。

### 从属性到可引用节点

编译器先把样式继承后的 `position`、内容与几何 props 收敛成一份 Node 布局。它同时服务两条输出：形状、文字与标签变成 Scene 图元；`id`、锚点和连接面变成 `<Path>` / `<Draw>` 可以查询的命名几何。

<ComponentPreview files="node-layout-flow" size="md" hideCode />

节点尺寸按固定顺序收敛：文本先测量与折行，`padding` 再形成内容内框，shape definition 根据内框与 params 算出视觉外接盒，`minimumSize` 只负责托底。`scale` 从前面开始同步影响字体、间距和形状参数，`rotate` 最后附着到几何结果。

`label` 不参与视觉形状尺寸计算，而是作为附属图元单独布局；它不会撑大节点边框，但会与 `margin`、阴影一起进入自动 viewBox 的内容范围。

### 视觉形状与连接几何

`shape` 决定画出来的轮廓，也拥有形状专属锚点；`boundary` 则只在解析自动连线端点、标准方位锚点和数字角度锚点时参与。`boundary` 省略或写成 `'shape'` 时，两条几何路径才重合。

| 引用方式                        | 实际采用的几何              |
| ------------------------------- | --------------------------- |
| 自动连线、`.top`、`.30`         | `boundary`，再外扩 `margin` |
| 形状专属锚点（如 `tip-0`）      | 视觉 `shape`                |
| `{ side, fraction }` 边上比例点 | 视觉 `shape`                |

因此，`margin` 会外推连接端点与标准 border anchor，并扩大节点布局占位，却不会重画视觉形状。形状专属锚点与边上比例点保持在原轮廓上；某个 shape 没实现标准方位锚点时，core 会回退到它的外接矩形。

### 命名引用为何受顺序影响

Node 定位是在遍历到该节点时立即解析的：编译器先查询当前命名空间，得到布局后才注册这个节点的 `id`。所以 `position` 引用同一作用域里后声明的 Node / Coordinate 会失败，循环定位也无法成立。

Path / Draw 的端点采用另一种时机。路径先保留绘制顺序占位，等当前作用域的 Node 与 Coordinate 都注册完成后再统一解析，因此路径端点可以引用后声明的同级节点。

## API 参考

| 属性   | 类型                      | 默认值 | 描述                                                                                                                                                                                                      |
| ------ | ------------------------- | ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`   | `string`                  | —      | 唯一标识；被 `<Path>` / `<Draw>` 用来引用                                                                                                                                                                 |
| `meta` | `Record<string, JSON 值>` | —      | provenance 元数据：随该节点原样透传到渲染产物，renderer 忽略、不参与布局 / 连接 / 样式；典型由 plot 等高层注入（标记来自哪个 datum / series / layer），供交互层命中图元后反查来源。须为 JSON 可序列化对象 |

其余 props 按职责列在下方四个 API 主题；每个小节都能独立查阅对应默认值和示例。

### 定位

| 属性       | 类型                                                                                                 | 默认值 | 描述                                                                                                      |
| ---------- | ---------------------------------------------------------------------------------------------------- | ------ | --------------------------------------------------------------------------------------------------------- |
| `position` | `[x, y] \| PolarPosition \| { direction, of, distance? } \| { of, offset } \| { between, fraction }` | —      | 节点中心位置：笛卡尔 / 极坐标 / 相对定位 / 偏移定位 / 比例定位；`of` 三态：节点 id、笛卡尔、PolarPosition |

### 几何

| 属性           | 类型                                                                                     | 默认值        | 描述                                                                                                                                                                                                                                                                                                                                                                         |
| -------------- | ---------------------------------------------------------------------------------------- | ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `shape`        | `'rectangle' \| 'circle' \| 'ellipse' \| 'diamond' \| string`<br />`\| { type, params }` | `'rectangle'` | 节点形状：裸字符串仅限无必填参数的形状（`rectangle` / `circle` / `ellipse` / `diamond` / 无参注册名）；`polygon` / `sector` / `arc` / `star` 等带必填参数的形状必须用 `{ type, params }`（裸字符串会编译期抛错）；内置见上，或经 `<Layout shapes>` / `CompileOptions.shapes` 注册                                                                                            |
| `boundary`     | `'shape' \| 'circle' \| string \| { type, params }`                                      | `'shape'`     | 连接面：边在此节点如何贴边、标准方位锚点如何解析，独立于视觉 `shape`；`'shape'` = 视觉形状自身；内置 `'rectangle'` = 视觉外接框，`'circle'` = 视觉外接框的外接圆（半径 = 半对角线），`'ellipse'` = 经过视觉外接框四角的外接椭圆。其它值先查自定义连接面，再 fallback 到已注册 shape 边界。不改节点占位；形状专属锚点与边上比例点仍走视觉形状。单条边可用端点 `boundary` 覆盖 |
| `rotate`       | `number`                                                                                 | `0`           | 绕中心旋转角度（度，正值顺时针）                                                                                                                                                                                                                                                                                                                                             |
| `padding`      | `number \| { default?, x?, y?, left?, right?, top?, bottom? }`                           | `8`           | 内容到边框的内边距；对象字段按 `left/right/top/bottom` → `x/y` → `default` → 默认值解析                                                                                                                                                                                                                                                                                      |
| `margin`       | `number \| { default?, x?, y?, left?, right?, top?, bottom? }`                           | `0`           | 边框外推距离；对象字段按 `left/right/top/bottom` → `x/y` → `default` → 默认值解析；作用于**所有 border 锚点**（显式 `.top` / `.30` 与自动连线端点一致），并**计入节点布局占位 / viewBox**；不改视觉形状                                                                                                                                                                      |
| `cornerRadius` | `number`                                                                                 | —             | 顶层圆角半径；仅对 `rectangle` 形状生效（默认或显式 `'rectangle'`），且仅在 params 未给 `cornerRadius` 时合入。各形状的圆角写在 params 里：`shape={{ type, params:{ ..., cornerRadius } }}`（params 优先）                                                                                                                                                                   |
| `minimumSize`  | `number \| { default?: number; width?: number; height?: number }`                        | —             | 撑开最小 bbox 宽高；数字表示宽高相同，对象可分别指定宽高，轴字段优先于 `default`                                                                                                                                                                                                                                                                                             |
| `scale`        | `number \| { default?: number; x?: number; y?: number }`                                 | `1`           | 均匀或分轴缩放；轴字段优先于 `default`，并影响 bbox、字号、padding、margin 与路径附着点                                                                                                                                                                                                                                                                                      |

### margin 与 padding 的区别

|           | 影响什么             | 视觉表现                                                                 |
| --------- | -------------------- | ------------------------------------------------------------------------ |
| `padding` | 文字到 border 的距离 | 视觉形状变大                                                             |
| `margin`  | 连接面外的外偏移     | 视觉形状不变；所有 border 锚点与连线端点外移 margin，节点占位也含 margin |

`padding` 撑大节点本身；`margin` 不动视觉形状，而是把节点的连接/引用边界外推（含显式 `.top` 这类锚点），并让节点在布局里多占 margin 的空间。`margin` 缺省 0，不设则零影响。

| `align`             | `'start' \| 'middle' \| 'end'`        | `'middle'`        | 多行文本块内各行水平对齐方式                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `lineHeight`        | `number`                              | `font.size × 1.2` | 多行块的行高（user units）                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `maxTextWidth`      | `number`                              | —                 | 折行阈值（user units）；超过才折行（西文按词 / CJK 按字），短文本盒宽收缩；非固定段落宽                                                                                                                                                                                                                                                                                                                                                                                                              |
| `font`              | `{ family?, size?, weight?, style? }` | —                 | 字体规格；嵌套对象，所有字段可选                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `textColor`         | `string`                              | `currentColor`    | 文字颜色（块级默认；行级覆盖通过 LineSpec.fill）                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `label`             | `NodeLabel \| Array<NodeLabel>`       | —                 | 边挂标签；单对象或数组；`position` 接 8 方向枚举（缺省 `'top'`）、`'center'`、数字角度或 `{ boundary, fraction }`（矩形边界比例点），`placement` 缺省 `'outside'`，可设 `'inside'` 放到节点内部；`distance` 缺省 12，`font` / `textColor` 缺省继承 node，`opacity` 单独控制标签 0~1；`rotate`（`'none'` / `'radial'` / `'tangent'` / 数字度数）+ `keepUpright` 控制标签自旋；`pin`（`true` 默认线 / `{ stroke, strokeWidth, dashPattern, dashOffset }` 带样式 / 省略无引线）画引线，且仅支持外侧标签 |

### 视觉样式 API

| 属性            | 类型                                                                                                          | 默认值         | 描述                                                                                                                                                                                    |
| --------------- | ------------------------------------------------------------------------------------------------------------- | -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `color`         | `string`                                                                                                      | —              | 主色；`stroke` / `fill` / `textColor` 未单设则随它，并级联到内部文字与边 label                                                                                                          |
| `fill`          | `string \| PaintSpec`                                                                                         | —              | 背景填充：纯色 CSS 串，或 PaintSpec（渐变 linear / radial / conic、图案 pattern、图片 image）                                                                                           |
| `stroke`        | `string \| PaintSpec`                                                                                         | `currentColor` | 边框 paint：CSS 颜色或 PaintSpec（渐变 / pattern / image）                                                                                                                              |
| `strokeWidth`   | `number`                                                                                                      | `1`            | 边框宽度（user units）                                                                                                                                                                  |
| `opacity`       | `number`                                                                                                      | —              | 整节点 0~1，同时作用于 shape + text                                                                                                                                                     |
| `fillOpacity`   | `number`                                                                                                      | —              | 仅填充透明 0~1                                                                                                                                                                          |
| `strokeOpacity` | `number`                                                                                                      | —              | 仅描边透明 0~1                                                                                                                                                                          |
| `shadow`        | `'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl' \| 'none' \| { preset?, offsetX?, offsetY?, blur?, color?, opacity? }` | —              | 形状投影：预设字符串或对象；只作用于 shape，不作用于文字 / 标签。详见 [视觉效果](/kernel/components/effects)                                                                            |
| `blendMode`     | `'normal' \| 'multiply' \| 'screen' \| ...`（16 个 W3C 分离模式）                                             | `'normal'`     | 形状与其下方已绘内容的混合模式；只作用于 shape。详见 [视觉效果](/kernel/components/effects)                                                                                             |
| `dashed`        | `boolean`                                                                                                     | —              | 虚线预设（`[4, 2]`）                                                                                                                                                                    |
| `dotted`        | `boolean`                                                                                                     | —              | 点线预设（`[1, 2]`）                                                                                                                                                                    |
| `dashPattern`   | `Array<number>`                                                                                               | —              | 显式 dash/gap 长度序列；优先级最高                                                                                                                                                      |
| `dashOffset`    | `number`                                                                                                      | —              | 边框虚线起点偏移，单位同 user units                                                                                                                                                     |
| `zIndex`        | `number`（整数）                                                                                              | `0`            | 显式栈序：大者在上；同值保持声明顺序；只在同层子节点间生效                                                                                                                              |
| `animations`    | `Array<AnimationTrack>`                                                                                       | —              | 时间轴动画 tracks：每条 track 动一个 renderer 无关 property，base = 动画终态；透传进 Scene 图元，renderer 播放或降级到静态。不参与布局。见 [动画](/kernel/components/effects/animation) |
