---
title: 混合
description: 让 Node 或 Path 的主几何与下方已绘内容混合，并在 SVG 与 Canvas 中保持同一组模式。
---

`blendMode` 是图元级的视觉效果属性，`<Node>` 和 `<Path>` 都能直接写。它作用于**该图元本身**——Node 的 shape、Path 的主路径（含其端点箭头）。Node 的文字 / 标签 / 引脚是独立图元，不参与混合。它是 renderer 无关的：SVG 与 Canvas 两端各自翻译成原生能力，结果一致。

## 用法

```tsx
import { Node } from '@retikz/react';
```

```tsx
<Node shape="circle" fill="magenta" blendMode="multiply" />
```

## 例子

`blendMode` 让主几何与它**下方已经画好的内容**按 W3C 标准模式混合：`multiply` 压暗、`screen` 提亮、`overlay` 增强对比……取值是以下 16 种模式之一：

`normal` / `multiply` / `screen` / `overlay` / `darken` / `lighten` / `color-dodge` / `color-burn` / `hard-light` / `soft-light` / `difference` / `exclusion` / `hue` / `saturation` / `color` / `luminosity`。

省略或 `'normal'` = 普通叠放（source-over），逐字不变。

两个或多个重叠图元，给上层设 `blendMode` 就在重叠处看到混合效果。`multiply` 在浅底上把重叠处压暗：

### 源图层与背景图层

混合发生在当前图元与已绘内容重叠的像素上。当前图元是 source（源图层），Scene 最终绘制顺序中位于它之前的累计结果是 backdrop（背景图层）：

| 角色     | 含义                       | 作用               |
| -------- | -------------------------- | ------------------ |
| backdrop | 此前累计的 Scene 内容      | 提供源图层下方像素 |
| source   | 当前图元的主几何           | 提供颜色与透明度   |
| 最终结果 | `B(Cb, Cs)` 后 source-over | 只在重叠区混色     |

`blendMode` 只决定混色函数，不替代 `opacity`：混色后仍会结合双方透明度做普通 `source-over` 叠放，透明背景会减弱混合影响。调整声明顺序或 `zIndex` 会改变谁是 source、谁是 backdrop；对 `overlay`、`hard-light` 等区分两者角色的模式，结果也会随之改变。

前 12 种（`normal` 到 `exclusion`）是分离模式，会逐颜色通道计算；`hue` / `saturation` / `color` / `luminosity` 是非分离模式，会联合处理色相、饱和度与明度。`normal` 不做额外混色，所以与省略 `blendMode` 等价。

### 图元边界与后端映射

编译阶段不会为混合额外创建组，而是把模式保留在 Node 主形状或 Path 主路径图元上。渲染阶段再把同一个值映射到各后端的原生混合能力：

| 契约          | SVG                | Canvas                     |
| ------------- | ------------------ | -------------------------- |
| 非 normal 值  | `mix-blend-mode`   | `globalCompositeOperation` |
| 省略 / normal | 不输出额外混合样式 | 保持 `source-over`         |
| 状态边界      | 当前几何元素       | 保存 → 绘制 → 恢复         |

这解释了元素边界：SVG 的 marker / filter 输出跟随当前几何元素，Canvas 只在当前图元绘制期间切换状态。Node 的文字、标签和引脚是后续独立图元，不继承主形状的混合；Path 端点箭头则在主路径的同一效果边界内绘制。`opacity` 与 `shadow` 可以同时存在，它们共同形成当前图元的 source，再与 backdrop 混合。

## API 参考

`blendMode` 是 `<Node>` 与 `<Path>` 共有的样式属性，写法一致。

| 属性        | 类型                                                                                                                                                                                                                                                       | 默认值     | 描述                                       |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- | ------------------------------------------ |
| `blendMode` | `'normal' \| 'multiply'`<br />`'screen' \| 'overlay'`<br />`'darken' \| 'lighten'`<br />`'color-dodge' \| 'color-burn'`<br />`'hard-light' \| 'soft-light'`<br />`'difference' \| 'exclusion'`<br />`'hue' \| 'saturation'`<br />`'color' \| 'luminosity'` | `'normal'` | 主几何与已绘内容的混合模式；作用边界见上文 |
