title: Text
description: Text 在 Node 内声明一整行文字，并按行覆盖颜色、透明度与字体。
---

`<Text>` 给 `<Node>` 中的某一整行覆盖文字样式，并与普通字符串 children 按 JSX 顺序混排。它是 Sugar（语法糖）：写法只存在于 React DSL，随后会归一成 `Node.text` 中的一条 LineSpec（单行文本规格）。

它和直接把 LineSpec 对象写进 `text` prop 是**等价**的两条路径：

| 路径           | 写法                                                | 优点                                  |
| -------------- | --------------------------------------------------- | ------------------------------------- |
| `<Text>` Sugar | `<Node><Text fill="red">x</Text>...</Node>`         | JSX 顺手，混排字符串 children 自然    |
| `text` 数组    | `<Node text={[{ text: 'x', fill: 'red' }, ...]} />` | JSON 友好；AI 直接生成 IR（中间表示） |

> 块级属性（`align` / `lineHeight`）写在 `<Node>` 上；行级覆盖（`fill` / `opacity` / `font`）写在 `<Text>` 上。

<ComponentAlert
  type="warn"
  title="一个 Text 是一整行，不是 inline span"
  description="Text 本身不能表达同一行里的多段样式；需要一行多色时，改用 Node text prop 的 { runs } LineSpec。只有各段本就应独占一行时才拆成多个 Text。"
/>

## 用法

```tsx
import { Node, Text } from '@retikz/react';
```

```tsx
<Node>
  <Text fill="red" font={{ weight: 'bold' }}>
    Heading
  </Text>
  body line
</Node>
```

### 行归一化与优先级

`<Text>` 是一个返回 `null` 的标记组件，本身不创建 DOM 或图形。只有 `<Node>` 收集 children 时会识别这个标记，并把不同 JSX 输入归一到同一份 `Node.text` 契约：

<ComponentPreview files="text-normalization" size="sm" hideCode />

显式 `text` prop 优先；只要它存在，children 就不再参与文本收集。没有 `text` prop 时，适配层按 JSX 顺序递归读取字符串、数字、数组、Fragment 与 `<Text>`：

| 输入            | 归一规则                                     | `Node.text` 结果 |
| --------------- | -------------------------------------------- | ---------------- |
| 字符串 / 数字   | 相邻内容拼接，按 Node 文本规则处理 `\n`      | 普通字符串行     |
| 无样式 `<Text>` | 先结束当前普通行，再把自身作为独立一行       | 普通字符串行     |
| 有样式 `<Text>` | 先结束当前普通行，再保留当前行的样式覆盖字段 | LineSpec 对象行  |

这也解释了两个边界：`<Text>` 只能在 `<Node>` 内生效，而且它表达的是一整行，不是行内 span。

### 行颜色解析

归一完成后，每一行沿同一套颜色优先级进入 Core。`<Text fill>` 是显式行色，直接覆盖 Node 默认；没有 `fill` 的行才继承 `Node.textColor`：

<ComponentPreview files="text-contrast-flow" size="sm" hideCode />

当 Node 使用 `NodeTextColor.Contrast` 时，Core 在样式级联后读取最终 `fill`。只有静态且有效不透明度为 1 的颜色参与 WCAG 相对明度比较，并解析成 `#000000` 或 `#ffffff`；缺省、半透明、gradient、`var()` 等无法闭合求值的背景使用固定 `currentColor`，同时发出 `TEXT_AUTO_CONTRAST_UNRESOLVED`。Node 的整体 `opacity` 不参与背景判断。

行级 `font` 仍参与当前行的宽度测量；换行、`align` 与 `lineHeight` 继续由 Node 的块级配置负责。同一行需要多段样式时，使用 `text` prop 的 `{ runs }` LineSpec。

## API 参考

| 属性       | 类型                                                                                                                                                                                                                                | 默认值 | 描述                                                                                                                                                                |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `children` | `string` \| `number`                                                                                                                                                                                                                | —      | 行内容；单个字符串或数字（数字按文本渲染）；其它子项忽略                                                                                                            |
| `fill`     | `string`                                                                                                                                                                                                                            | —      | 行颜色覆盖；不填走 Node `textColor` 块级默认                                                                                                                        |
| `opacity`  | `number`                                                                                                                                                                                                                            | —      | 单行透明度 0~1                                                                                                                                                      |
| `font`     | `IRFont`<br />- `family?: string`<br />- `size?: number` \| <ApiValues name="WebFontSizePreset" /> \| `string`<br />- `weight?:` <ApiValues name="FontWeightKeyword" /> \| `number`<br />- `style?:` <ApiValues name="FontStyle" /> | —      | 行级字体覆盖；缺字段继承 Node 块级 `font`<br />- CSS 字体族<br />- 字号；`WebFontSizePreset` 提供预设，`string` 仅支持正数 `em` / `rem`<br />- 字重<br />- 字体样式 |

### 限制

- **只能放在 `<Node>` 里**：放到 `<Layout>` 顶层会被静默忽略。
- **children 必须是字符串或数字**：嵌套元素或其它类型不行（数字按文本渲染）。这是 Node 多行块的语义——一行就是一行。
- **块级属性不能行级覆盖**：`align` / `lineHeight` 只能写在 `<Node>` 上。
