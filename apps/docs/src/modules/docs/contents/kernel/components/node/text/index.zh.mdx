节点正文由 `text` 或 children 提供；显式 `text` 优先。多行排布由 Node 管理，React 的 `<Text>` 只为其中一整行设置样式。同一行需要多段样式时使用 `{ runs }`，不能把 Text 当成行内 span。

先阅读[基础用法](/kernel/components/node/usage)，再按本页组织节点正文。

## 接入方式

`<Text>` 只在 React JSX 中作为 Node 的行级标记；四种写法最终都得到同一份两行正文，其中 A 加粗、B 继承 Node 的块级文字样式。Vanilla 示例需要页面已有 `<div id="diagram"></div>`。

## 多行与折行

上面的最小写法确定了行级与块级职责；下面再用面板比较多行内容。换行符形成硬分行，第 1、2、3 行及以后可分别调整颜色、强调方式与透明度。`shape`、`align`、`lineHeight` 和 `maxTextWidth` 也在同一场景比较，节点位置与取景保持不变。

选择“长句折行”预设，再调整 `maxTextWidth`，比较折行数量和节点边框的变化。

<ComponentPreview files="node-text" size="md" />

- `text` 接字符串或 IRLine 数组；字符串里的 `'\n'` 是硬换行，数组则让每行拥有独立样式
- `layout.align` 控制多行块内的水平对齐，`layout.lineHeight` 控制行距；两者都是块级属性
- `layout.maxTextWidth` 是折行阈值，不是固定段落宽；西文按词、CJK 按字折行，不可断长词会整体溢出
- 每行可覆盖 `fill` / `opacity` / `font`，也可以用 [`<Text>` 子元素](/kernel/components/node/text)表达相同结构
- 多行内容换到不同 `shape` 后，外接边界继续遵循各形状自己的外接规则

`text` prop 优先于 `children`；二者同时提供时使用 `text`。块级 `style.font` 是 `{ family?, size?, weight?, style? }`，其它通用视觉属性可在[基础用法](/kernel/components/node/usage)调整。

## 行内混排

下面两段文字仍在同一行；Vanilla API 和 IR 也使用同一 `text` 数据结构。公式接入见 [TeX](/kernel/packages/tex)。

```tsx
<Node position={[0, 0]} text={[{ runs: [{ text: 'Status: ' }, { text: 'ready', fill: 'green' }] }]} />
```

## 自动黑白对比色

把 `textColor` 设为 `NodeTextColor.Contrast`，Core 会根据 Node 最终的静态不透明 `fill` 选择对比度更高的纯黑或纯白。关键字在样式级联后按每个 Node 独立解析，因此也可以放进 `Scope.defaults.node.style`。

<ComponentPreview files="node-auto-contrast" size="sm" />

```tsx
import { NodeTextColor } from '@retikz/core';

<Node position={[0, 0]} style={{ fill: '#1e293b', textColor: NodeTextColor.Contrast }}>
  Status
</Node>;
```

- Core 静态支持 CSS named color、3/4/6/8 位 hex，以及 legacy / modern `rgb()`、`hsl()`；不读取 DOM、主题变量或页面像素
- 透明 / 缺省 fill、`fillOpacity < 1`、gradient、pattern、image、`var()`、`currentColor` 等无法闭合求值的背景使用固定 `currentColor` fallback，并发出 `TEXT_AUTO_CONTRAST_UNRESOLVED`
- 行 / run 的 `fill`、label 的显式颜色和 `defaults.label` 仍优先；关键字只影响最终继承 Node 文字颜色的正文、label 与 pin

## 错误与限制

Text 只在 Node 中生效，每个 Text 的 children 是字符串或数字。块级对齐、行距与折行宽度分别写在 `Node.layout.align`、`lineHeight` 与 `maxTextWidth`；行级字体写在 Text 的 `font`。
