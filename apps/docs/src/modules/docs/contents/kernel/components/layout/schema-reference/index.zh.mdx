## 补充说明

- **必填与缺省**：`type`、`version`、`children` 必填；`theme`、`viewBox`、`animations` 可省略。校验不会为后三项补值；自动取景和主题继承在编译时处理。
- **主题继承**：场景根未指定主题时，从默认浅色环境开始；子级 Scope 只覆盖显式提供的主题字段，其余继续继承。
- **取景与尺寸**：坐标向右、向下递增，使用场景坐标单位，与宿主 CSS 宽高不同。显式视框不再叠加自动留白；省略时由内容范围与编译配置的留白决定。
- **镜头动画**：动画可以改变播放时的取景范围；静态布局保留动画结束后的取景范围。
