### ScopeProps

本类型额外带容器 / 命名空间 / 局部变换 / 屏障 / 栈序 / 裁剪等 scope 专属字段

| ----------------- | -------------------------- | ------ | ------------------------------------------------------------------------------------------------------------------------------------- |
