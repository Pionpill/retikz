---
title: Custom clipping
description: Define a JSON-safe clip shape for Scope, then register and use it from a React or Vanilla host
---

When Core's built-in `rect` and Extension's circle / ellipse / polygon / path / compound clips do not fit, define a new shape with one `ClipDefinition`. The Definition stays out of IR; IR stores only a `kind` and serializable parameters, while renderers, visual bounds, and hit testing share the same lowered result.

A clip spec uses `{ kind, params }`: `kind` selects the registered definition and `params` holds JSON parameters. Use `{}` when there are no parameters. `schema` validates the complete spec, and `lower` consumes the parsed parameters and returns a `SceneClipPath` directly.

For compound clips, call `context.lower(child)` inside `lower` to generate child paths and combine their commands. Keep temporary functions and class instances inside the callback; return only structured path commands and a fill rule.

The built-in rectangle uses `IRRectClip`, derived from `RectClipSchema`, and generates its path through the same `lower` callback.

## Applicability boundary

This page assumes [basic Scope clipping](/kernel/components/scope/usage#clipping-and-stacking). First decide whether an existing capability already expresses the requirement:

| Need                                                | Choose                                                              |
| --------------------------------------------------- | ------------------------------------------------------------------- |
| One-off rectangle                                   | Write the Core built-in `rect` clip spec                            |
| Circle, ellipse, polygon, path, or combined regions | Inject a Definition from [Clip Extensions](/library/extension/clip) |
| New static 2D clipping geometry                     | Define one complete `ClipDefinition` that lowers to `SceneClipPath` |
| Renderer-specific mask / filter behavior            | Outside Clip; use an explicit backend capability                    |

## Define the capability

Keep the Definition in a reusable module, such as `rounded-rect-clip.ts`. Each definition provides `kind`, `schema`, and `lower`; `lower` returns a structured path.

```ts
import type { PathCommand } from '@retikz/core';
import { defineClip } from '@retikz/core';
import { z } from 'zod';

const roundedRectClipSchema = z.strictObject({
  kind: z.literal('rounded-rect'),
  params: z.strictObject({
    x: z.number(),
    y: z.number(),
    width: z.number().positive(),
    height: z.number().positive(),
    radius: z.number().nonnegative(),
  }),
});
export const roundedRectClip = defineClip({
  kind: 'rounded-rect',
  schema: roundedRectClipSchema,

  lower: shape => {
    const right = shape.params.x + shape.params.width;
    const bottom = shape.params.y + shape.params.height;
    const radius = Math.min(shape.params.radius, shape.params.width / 2, shape.params.height / 2);
    const commands: Array<PathCommand> = [
      { kind: 'move', to: [shape.params.x + radius, shape.params.y] },
      { kind: 'line', to: [right - radius, shape.params.y] },
      { kind: 'quad', control: [right, shape.params.y], to: [right, shape.params.y + radius] },
      { kind: 'line', to: [right, bottom - radius] },
      { kind: 'quad', control: [right, bottom], to: [right - radius, bottom] },
      { kind: 'line', to: [shape.params.x + radius, bottom] },
      { kind: 'quad', control: [shape.params.x, bottom], to: [shape.params.x, bottom - radius] },
      { kind: 'line', to: [shape.params.x, shape.params.y + radius] },
      { kind: 'quad', control: [shape.params.x, shape.params.y], to: [shape.params.x + radius, shape.params.y] },
      { kind: 'close' },
    ];
    return { commands, fillRule: 'nonzero' };
  },
});
```

## Register and use

The Definition is a shared React / Vanilla runtime object and never becomes persistent scene data. In the chosen host, register it in `clips`, then reference it through `Scope.clip.kind`.

Register the Definition through `Layout.extensions.clips`; Scope contains only its persistent `kind` and parameters.

```tsx
import { Layout, Node, Scope } from '@retikz/react';
import { roundedRectClip } from './rounded-rect-clip';

const Demo = () => (
  <Layout extensions={{ clips: [roundedRectClip] }}>
    <Scope clip={{ kind: 'rounded-rect', params: { x: -150, y: -72, width: 300, height: 144, radius: 36 } }}>
      <Node
        position={[-88, -8]}
        shape="circle"
        style={{ fill: 'skyblue', stroke: 'none' }}
        layout={{ minimumSize: { width: 160, height: 160 } }}
      />
      <Node
        position={[84, 8]}
        shape="circle"
        style={{ fill: 'darkorange', stroke: 'none' }}
```

```ts
import { renderToSvgString } from '@retikz/vanilla';
import { roundedRectClip } from './rounded-rect-clip';

const input: InputScene = {
  type: 'scene',
  children: [
    {
      type: 'scope',
      clip: {
        kind: 'rounded-rect',
        params: {
          x: -150,
          y: -72,
          width: 300,
          height: 144,
          radius: 36,

        {
          type: 'node',
```

Pass the JSON in the IR panel to Core as `ir`, and still supply the Definition at compile time:

```ts
import { compileToScene } from '@retikz/core';
import { roundedRectClip } from './rounded-rect-clip';

const { scene } = compileToScene(ir, { clips: [roundedRectClip] });
```

A `{ capability: 'clip', name: kind }` provider in a provider graph likewise creates a complete Definition and participates in the same conflict checks as explicit `clips`.

## Errors and limits

| Case                             | Result                                                                                                   |
| -------------------------------- | -------------------------------------------------------------------------------------------------------- |
| Duplicate kind                   | The registry reports a definition conflict and never overwrites it                                       |
| Unknown `clip.kind`              | Reports the kind and suggests Core `options.clips`, React `extensions.clips`, or Vanilla `compile.clips` |
| Definition / spec kind differs   | Fails as a provider contract violation before `lower`                                                    |
| Spec fails its schema            | Reports the provider key, schema phase, and validation cause                                             |
| Recursion exceeds `maxClipDepth` | Fails; the root and recursive children share a budget of 32 conversions, one per invocation              |

A compound shape appends child commands in authored order and applies its outer `fillRule`; it is not a geometric intersection. Use nested `<Scope clip>` elements for intersection.

For registry resolution, path snapshots, path canonicalization, and resource deduplication, see the [Scope mechanism](/kernel/components/scope/mechanism).
