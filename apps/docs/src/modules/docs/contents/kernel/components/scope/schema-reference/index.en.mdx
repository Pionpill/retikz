This page selects Scope-owned and directly clipping-related schemas from `@retikz/core` by name and reads their fields from source. Shared drawable-default and transform schemas stay as named field types on Scope instead of being repeated here. See [API reference](/kernel/components/scope/api-reference) for React props and [Basic usage](/kernel/components/scope/usage) to get started.

`ScopeSchema` is the Tier 1 container node. It does not draw a new visual primitive; it establishes local transforms, style defaults, clipping, stacking, and reference boundaries for a child subtree. A Scope can still be referenced through its own `id`.
