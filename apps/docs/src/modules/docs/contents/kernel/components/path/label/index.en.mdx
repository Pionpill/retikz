## Choose the label scope

| Syntax               | Scope                        | When to use               |
| -------------------- | ---------------------------- | ------------------------- |
| `<Path label>`       | Whole path                   | Name a relationship       |
| `<Step label>`       | One step                     | Name a particular segment |
| `{ label }` in `way` | Following connection segment | Add a label in Draw       |

## Label a path

`{ label }` annotates the next connection segment without creating a segment itself. The panel supports a line, two fold directions, and a quadratic Bezier: adjust `position`, then `side`, `sloped`, and text color. A fold allocates t evenly across its legs, so 0.5 lands at its corner; a curve samples at its Bezier parameter.

<ComponentPreview files="draw-label" size="lg" />

`position` accepts a number from 0 to 1: 0 is the start and 1 is the end. The keywords `at-start`, `very-near-start`, `near-start`, `midway`, `near-end`, `very-near-end`, and `at-end` map to 0, 0.125, 0.25, 0.5, 0.75, 0.875, and 1. `side` chooses a side of the line; `sloped: true` rotates text with the tangent. To center text on the line, omit `side` and set `sloped: true`. Do not pass `side: 'center'` to the public input.

With Draw, put `{ label }` before the connection segment it annotates in `way`:

```tsx
<Draw way={['A', { label: { text: 'status', position: 0.5 } }, { curve: [180, -110] }, 'B']} />
```

With Path, pass the same object directly to the target `<Step>` through `label`:

```tsx
<Path>
  <Step kind="move" to="A" />
  <Step kind="curve" control={[180, -110]} to="B" label={{ text: 'status', position: 0.5 }} />
</Path>
```

Whole-path placement uses path length. A Step follows its own action parameter: Bézier parameter for curves, angular progress for arcs, and allocation across legs for folds. See [Implementation](/kernel/components/path/mechanism#from-label-bounds-to-a-cut-interval).

## Multiline text and stroke gaps

`<Path label>` belongs to the whole path, while `<Step label>` belongs only to its step. Observe how the same text block creates a gap: the text keeps its position and the stroke stops on either side of its bounds.

`label.text` reuses the same text-block input (TextBlock) as Node text: use one string (`\n` is a hard line break), or an array of lines with per-line `fill` / `font`. All lines remain one label block with one anchor, `position`, `side`, `sloped`, and `interrupt`; a gap uses the whole block's visual bounds rather than treating lines as separate labels.

<ComponentPreview files="path-label-interruption" size="lg" />

With the upper-left and lower-right nodes fixed, switch the connection route, `side`, and the label position from 0 to 1 to observe sampling and gaps on the same host Path. “Automatic center” omits `side` and enables only `sloped`, so it still follows the centered-label default gap rule.

<ComponentPreview
  files={['path-label-route-playground', 'path-label-route-playground.tsx', 'path-label-route-playground.controls.ts']}
  size="md"
  caption="Switch the route and label position: automatic center gaps the stroke; the other side values stay continuous by default."
/>

When `interrupt` is omitted, only that unfilled built-in Stroke + centered combination gets an automatic gap. `interrupt: false` forces a continuous stroke; `interrupt: true` can also gap a non-centered label. The gap extends by `4` user units beyond each side of the label's visual bounds by default; use `gap` to override it, and `gap: 0` for no extra clearance.

Any effective `fill` — including `style.fill: 'transparent'`, or setting fill and then `style.fillOpacity: 0` — disables the automatic gap, and `interrupt: true` then reports an error. Any explicit boolean on Ribbon, a custom Path kind, or another non-built-in Stroke host also reports an error. The gap does not move labels, marks, dash phase, or endpoint arrows, and does not avoid label / arrow or mark collisions.

Sampling a curve at a parameter, inverting distance, and taking a shape-preserving slice belong to the [`@retikz/math` curve-segment algorithms](/kernel/packages/math/algorithms#curve-slicing). They operate on plain geometry only; Core still decides label interruption, gap clearance, and Path output.
