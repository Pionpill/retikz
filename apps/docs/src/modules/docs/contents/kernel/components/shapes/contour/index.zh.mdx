---

`contour` 是一个吃**任意闭合顶点环**的内置 Node 形状：给一圈点（`params.points`），节点边界就是这圈点连成的闭合轮廓。它和 `polygon` / `star` 走同一条轮廓引擎，区别只是顶点来源——`polygon` 由边数推导正多边形，`contour` 直接取你给的点。完整定义见 [形状](/kernel/components/shapes)。

它和其它形状不同的一点：**只作为 Node 形状**，没有对应的 Sugar 画线组件。要画一条任意闭合轮廓线，直接用 [`<Path>`](/kernel/components/draw/path) 的 `line` step；`contour` 解决的是另一件事——让这块任意轮廓**仍是一个可连接的节点**（能被别的线按 id 连过来、取边界交点）。

## 作为 Node 形状

给 `<Node>` 设 `shape={{ type: 'contour', params: { points } }}`，节点就以这圈点的闭合轮廓为边界。

### 用法

```tsx
import { Node } from '@retikz/react';
```

```tsx
<Node
  shape={{
    type: 'contour',
    params: {
      points: [
        [-30, 44],
        [30, 30],
        [30, -44],
        [-30, -44],
      ],
      cornerRadius: 8,
    },
  }}
  fill="steelblue"
/>
```

### API 参考

| `shape`                       | 边界                                            | 参数                             |
| ----------------------------- | ----------------------------------------------- | -------------------------------- |
| `{ type: 'contour', params }` | `points` 连成的闭合轮廓（自动按 AABB 中心居中） | `points`（≥3） / `cornerRadius?` |

| 参数           | 类型                            | 默认值 | 描述                                                                            |
| -------------- | ------------------------------- | ------ | ------------------------------------------------------------------------------- |
| `points`       | `Array<[number, number]>`（≥3） | —      | 闭合局部系顶点环（任意原点，core 按 AABB 中心自动居中），隐式闭合，边为直线     |
| `cornerRadius` | `number`（≥0）                  | —      | 逐顶点统一 fillet 半径（用户单位），省略 / `0` = 尖角，逐角夹紧到最大不自交半径 |

## 技术原理

<ComponentAlert type="tip" title="日常使用可跳过本节" description="想理解自动居中或 anchor 回退时再回来读。" />

本节只放大 `contour` 自己负责的顶点归一与连接面解析；完整的 JSX → IR（中间表示） → Scene 编译管线见[架构](/kernel/concepts/design/principles)。

### 任意原点如何归一到节点位置

图从左到右展示同一圈 `points` 如何摆脱调用方选取的局部原点，最终围绕 `Node.position` 形成世界坐标轮廓。

<ComponentPreview files="contour-normalization" size="xs" hideCode />

core 先求 `points` 的 AABB 中心 `c`，再把每个顶点改写为 `pᵢ - c`。这一步只消除整圈点的平移，不改变边长、夹角或凹凸结构；随后才把居中顶点环投影到以 `Node.position` 为中心的世界坐标。

因此，整体平移全部输入点不会改变最终图形。归一后的同一组轮廓段同时供渲染与连接面求交使用，视觉边界和自动连线不会各算一套几何。

### 自动连接与标准方位名称为何不同

上排是沿真实轮廓求交的路径，下排是标准方位名称的回退路径。两者都从同一份节点几何出发，但回答的问题不同。

<ComponentPreview files="contour-attachment" size="sm" hideCode />

按 id 自动连接时，编译器已经知道连线从哪个方向靠近节点，因此 `boundaryPoint` 可以从节点中心朝来向发出射线，与尖角或圆角后的轮廓求交。数字角度 anchor 同样有明确方向，也走真实轮廓。

`top` / `right` 等标准方位名称请求的是固定方位点，并不携带某条连线的实际来向。任意凹凸轮廓在同一方位可能出现多个局部极值，`contour` 不为它虚构一组命名点；形状查询未命中后，编译器才使用外接 AABB 的矩形方位点。`center` 始终是节点中心，不受该回退影响。
