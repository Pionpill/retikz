`contour` 是一个吃**任意闭合顶点环**的内置 Node 形状：给一圈点（`params.points`），节点边界就是这圈点连成的闭合轮廓。它和 `polygon` / `star` 走同一条轮廓引擎，区别只是顶点来源——`polygon` 由边数推导正多边形，`contour` 直接取你给的点。完整定义见 [形状](/kernel/components/shapes)。

它和其它形状不同的一点：**只作为 Node 形状**，没有对应的 Sugar 画线组件。要画一条任意闭合轮廓线，直接用 [`<Path>`](/kernel/components/draw/path) 的 `line` step；`contour` 解决的是另一件事——让这块任意轮廓**仍是一个可连接的节点**（能被别的线按 id 连过来、取边界交点）。

## 作为 Node 形状

给 `<Node>` 设 `shape={{ type: 'contour', params: { points } }}`，节点就以这圈点的闭合轮廓为边界。

### 用法

```tsx
import { Node } from '@retikz/react';
```

```tsx
<Node
  shape={{
    type: 'contour',
    params: {
      points: [
        [-30, 44],
        [30, 30],
        [30, -44],
        [-30, -44],
      ],
      cornerRadius: 8,
    },
  }}
  fill="steelblue"
/>
```

`points` 是一圈**局部系顶点**（至少 3 个，隐式闭合，边为直线）。你**不需要预居中**——core 按这圈点的 AABB 中心自动归一化，把 Node 的 `position` 对齐到轮廓的几何中心。下例两个节点用同一形状，但右侧的点整体偏了一段：自动居中后两者渲染完全一致。

<ComponentPreview files="node-contour" size="sm" />

`cornerRadius` 给**每个顶点**统一倒一个圆角（用户单位），省略 / `0` = 尖角，逐角夹紧到不自交的最大半径——复用与 `polygon` / `roundedCorners` 同一套 fillet 引擎。

### 可连接

`contour` 的关键价值是它**仍然是 Node**：另一条 `<Path>` / `<Draw>` 能按 id 连到它，连线端点经 `boundaryPoint` 落在轮廓边上的精确交点（射线 ∩ 轮廓），而不是外接矩形。

### API 参考

| `shape`                       | 边界                                            | 参数                             |
| ----------------------------- | ----------------------------------------------- | -------------------------------- |
| `{ type: 'contour', params }` | `points` 连成的闭合轮廓（自动按 AABB 中心居中） | `points`（≥3） / `cornerRadius?` |

| 参数           | 类型                            | 默认值 | 描述                                                                            |
| -------------- | ------------------------------- | ------ | ------------------------------------------------------------------------------- |
| `points`       | `Array<[number, number]>`（≥3） | —      | 闭合局部系顶点环（任意原点，core 按 AABB 中心自动居中），隐式闭合，边为直线     |
| `cornerRadius` | `number`（≥0）                  | —      | 逐顶点统一 fillet 半径（用户单位），省略 / `0` = 尖角，逐角夹紧到最大不自交半径 |

## 技术原理

> 日常使用可跳过本节；想理解自动居中或 anchor 回退时再回来读。

### 自动居中

`points` 可以在任意局部原点给出。core 在内部对每个顶点减去这圈点的 **AABB 中心**，再投到世界系，使轮廓的几何中心落在 Node 的 `position` 上。所以无论你把点画在原点附近还是偏出去一大截，结果都一样——schema 防不住的「未居中」隐患从此不存在。

### anchor 回退、boundaryPoint 精确

`contour` 是几何驱动的曲边块，命名 / 标准方位（`top` / `right` …）没有稳定语义，故 `anchor` 不提供具名锚点，compile 回退到外接 AABB 矩形。指向式连接走 `boundaryPoint`——它对**任意**顶点环（凸 / 凹 / 圆角后）都求射线 ∩ 轮廓的精确交点，是连接到 contour 节点的可靠方式。
