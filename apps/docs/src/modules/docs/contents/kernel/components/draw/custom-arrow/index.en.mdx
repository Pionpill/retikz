A custom arrow extends **endpoint marker geometry**. IR stores only an open shape name and visual parameters. After the host injects an `ArrowDefinition`, core resolves it from the shared registry and emits renderer-neutral `MarkerPrimitive` geometry during compilation.

The example below registers a hollow `bracket` arrow through `<Layout arrows>`. Its definition, injection, and Draw usage live in one runnable file.

## Applicability

The eight built-ins already cover solid and hollow triangles, stealth tips, diamonds, and circles. Register a definition only when the endpoint outline itself is missing.

| Need                                    | Choose                                              |
| --------------------------------------- | --------------------------------------------------- |
| Resize or recolor an existing arrow     | `arrowDetail`                                       |
| Use different built-ins at each end     | `arrowDetail.start` / `end`                         |
| Add a new endpoint outline              | Custom Arrow                                        |
| Change the output of the whole relation | [Custom Paths](/kernel/components/draw/custom-path) |

An ArrowDefinition serves both Path endpoints and `marks[].mark.shape`. It does not own arrow direction, mark position, path stroke, or renderer instances.

## Define the capability

A minimal definition needs a stable `name`, the path-to-arrow contact point `lineContactX`, and an `emit` function that returns marker-local geometry.

```tsx
const bracket = defineArrow({
  name: 'bracket',
  hollow: true,
  lineContactX: 2,
  emit: ({ stroke, lineWidth }) => [
    {
      type: 'path',
      commands: bracketCommands,
      stroke,
      strokeWidth: lineWidth,
    },
  ],
});
```

`emit` uses `baseSize` local coordinates. `lineContactX` tells the path body where to stop, while `tipX` describes the visual tip. Hollow arrows also account for `lineWidth` and `outerInset` when compensating the outer outline.

## Inject into the host

React injects definitions through `<Layout arrows>`; direct core calls use `CompileOptions.arrows`. Endpoints and path marks then reference the registered name.

```tsx
<Layout arrows={[bracket]}>
  <Draw way={['A', 'B']} arrow="->" arrowDetail={{ shape: 'bracket' }} />
</Layout>
```

The definition never enters IR. React, Vanilla, or persisted IR can reference the same shape string as long as the compile host injects the same definition.

## Execution

The eight built-ins and custom definitions first enter one registry. Compilation merges path defaults, `arrowDetail`, and per-end overrides before resolving the shape. It then shortens the path from the resolved size, line width, and contact point, and calls `emit` for marker geometry.

The `fill` / `stroke` values passed to `emit` are `MarkerFill`. Without an explicit color they use `{ kind: 'contextStroke' }`, allowing one definition to follow each Path stroke instead of freezing a color at registration time.

## Errors and limits

| Case                                       | Result                                                          |
| ------------------------------------------ | --------------------------------------------------------------- |
| Empty name                                 | Registry rejects the non-empty key contract                     |
| Duplicate built-in or custom name          | Registry merge reports a duplicate registration                 |
| Unknown `arrowDetail.shape`                | Compile lists available names and `options.arrows`              |
| Invalid `baseSize`, contact, or dimensions | Compile rejects invalid marker sizing                           |
| Unknown primitive or non-finite geometry   | Marker validation prevents invalid Scene output                 |
| Recursive arrows, clips, or text in marker | The narrow `MarkerPrimitive` contract rejects them              |
| Path uses a PaintSpec stroke               | Marker cannot inherit a resource paint; set a solid arrow color |

MarkerPrimitive allows only `path`, `ellipse`, `rect`, and groups containing the same subset. Do not return SVG `<marker>` elements, Canvas objects, text layout, or external paint resource references.

## API Reference

### ArrowDefinition

| Field           | Type                                 | Default                           | Description                                   |
| --------------- | ------------------------------------ | --------------------------------- | --------------------------------------------- |
| `name`          | `string`                             | —                                 | Registry key and shape reference              |
| `lineContactX`  | `number`                             | —                                 | Path contact point used for body shortening   |
| `emit`          | `(ctx) => Iterable<MarkerPrimitive>` | —                                 | Generates marker-local geometry               |
| `baseSize`      | `number`                             | `10`                              | Marker-local reference size                   |
| `tipX`          | `number`                             | `baseSize`                        | Visual tip x                                  |
| `hollow`        | `boolean`                            | `false`                           | Uses stroke for a hollow outline              |
| `defaultLength` | `number`                             | `6`                               | Fallback arrow length                         |
| `defaultWidth`  | `number`                             | `6`                               | Fallback arrow width                          |
| `outerInset`    | `number`                             | Hollow `lineWidth / 2`, solid `0` | Outer-outline compensation at node boundaries |

### Emit context

| Field       | Type                 | Default | Description                                 |
| ----------- | -------------------- | ------- | ------------------------------------------- |
| `fill`      | `MarkerFill`         | —       | Solid-arrow fill; may be `contextStroke`    |
| `stroke`    | `MarkerFill`         | —       | Hollow-arrow stroke; may be `contextStroke` |
| `lineWidth` | `number`             | —       | Marker-local stroke width                   |
| `round`     | `(number) => number` | —       | Compile/render precision rounding function  |
