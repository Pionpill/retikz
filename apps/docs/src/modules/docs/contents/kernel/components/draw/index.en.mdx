---
title: Draw
description: Connect targets quickly with Draw or describe paths precisely with Path and Step, then extend segments, whole paths, or arrow tips through the same model.
---

This group solves one problem: turning targets into a renderable path. Start with the `<Draw>` Sugar for everyday links; switch to Kernel `<Path>` + `<Step>` for per-segment control or multiple moves; use `<Path kind="ribbon">` for variable-width relations. These entry points converge on the same Path semantics, while Draw and Path share the arrow model.

The drawing family owns path structure, geometry, style, and endpoints. It does not own node shape or positioning, nor domain layouts such as flow or graph. When the built-ins are not enough, use the final pages to add a path generator, a whole-path kind, or an arrow definition.

## What each part does

| Component       | Type               | Responsibility                                                                                                | Use it when                                               |
| --------------- | ------------------ | ------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------- |
| Draw            | Sugar              | Declares targets, segment operators, labels, and whole-path style in a way array, then expands to Path + Step | Everyday connections, flowchart edges, and arrowed links  |
| Way             | Sugar              | Defines target, fold, cycle, curve, and relative-coordinate forms in a Draw array                             | Looking up what a way array can contain                   |
| Path            | Kernel             | Path container whose Step children define polylines, curves, and arcs                                         | Multiple moves, explicit per-step control, closest to IR  |
| Ribbon          | Standard Path kind | Builds a fillable variable-width relation from a Path centerline or precomputed boundaries                    | Flow magnitude, Sankey relations, or other width encoding |
| Step            | Kernel             | One step = one action (move / line / curve / arc / cycle…)                                                    | Controlling each segment's path action semantics          |
| Arrow           | Shared             | Direction and visual specifications shared by Path and Draw                                                   | Fine-grained shape, size, color, and per-end config       |
| Path Generators | Extension          | Register new curve generators for generator steps                                                             | Adding waves, parametric curves, or other segment types   |
| Custom Paths    | Extension          | Register a kind provider that owns the whole Path                                                             | Double lines, highlights, or domain-specific relations    |
| Custom Arrows   | Extension          | Register new endpoint arrow styles                                                                            | Brackets or domain-specific arrow tips                    |
