This group is about _drawing lines_: node to node, folds, curves, arcs, and closed fills. Reach for the Sugar `<Draw>` for everyday connections; drop to the Kernel `<Path>` + `<Step>` when you need step-by-step control or the closest match to the IR. Arrow specs get their own page and are shared by both Draw and Path. The final pages extend curve segments, whole Path providers, and arrow tips when the built-ins are not enough.

## What each part does

| Component       | Type      | Responsibility                                                                                                    | Use it when                                                                |
| --------------- | --------- | ----------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| Draw            | Sugar     | A way array threads targets / folds / curves / cycle / edge labels / styling, expanding to Path + Step            | Everyday connections, flowchart edges, arrowed links (the default)         |
| Way             | Sugar     | Draw's way item forms, DrawWay constants, folds, cycle, relative coordinates                                      | Looking up what a way array can contain                                    |
| Path            | Kernel    | Path container, a sequence of Step children defining a polyline / curve / arc; `kind="ribbon"` draws filled bands | Multiple moves, step-by-step control, closest to the IR, or relation bands |
| Step            | Kernel    | One step = one action (move / line / curve / arc / cycle…)                                                        | Controlling each segment's path action semantics                           |
| Arrow           | Shared    | Arrows shared by Path / Draw: `arrow` sets direction, `arrowDetail` covers visual specs                           | Fine-grained arrow shape / size / color / per-end config                   |
| Path Generators | Extension | Register new curve generators for generator steps                                                                 | Adding waves, parametric curves, or other segment types                    |
| Custom Paths    | Extension | Register a kind provider that owns the whole Path                                                                 | Double lines, highlights, or domain-specific relations                     |
| Custom Arrows   | Extension | Register new endpoint arrow styles                                                                                | Brackets or domain-specific arrow tips                                     |
