本页从 `@retikz/react`、`@retikz/vanilla` 与 `@retikz/core` 公开入口生成绘制家族的局部查询视图。第一次使用见[基础用法](/kernel/components/path/usage)，持久化字段见 [Schema 参考](/kernel/components/path/schema-reference)。

[自定义路径](/kernel/components/path/custom-path#相关属性)汇总了 `definePathKind` 的扩展入口；生成器对该可调用类型保留源码类型名，不能以此推断它只有一个调用形式。

形状快捷组件与 Props（Circle、Ellipse、Rectangle、RegularPolygon、Star、Arc、Sector）也收录在 React 入口下。
