`way` 是 `<Draw>` 的核心。前几种 item 是 target，后续形态是改变下一段或上一点的算子。

可以把 `way` 看成一个很小的 path 语言：target 产生点，`'-|'` / `'|-'` 改写前后两个点之间的段，`{ label }` 修饰下一段，`{ curve }` / `{ cubic }` / `{ bend }` 消耗下一项生成曲线，`{ arc }` / `{ circle }` / `{ ellipse }` 围绕上一点画形状而不消耗下一项。

## 用法

```tsx
import { DrawWay } from '@retikz/core';
import { Draw } from '@retikz/react';
```

```tsx
<Draw way={['a', DrawWay.Hv, 'b']} />
```

### WayItem 如何变成 Step

`<Draw>` 从左到右扫描 `way`。首项必须是 target，并固定产出 `move`；后续 item 先按角色分类，再按各自的消费规则产出等价 Step。这里的“消费”是指当前规则会从数组中取走哪些 item。

<ComponentPreview files="way-parser-flow" size="sm" hideCode />

| 类别                           | 扫描如何前进           | 产出                          |
| ------------------------------ | ---------------------- | ----------------------------- |
| target                         | 消费当前项             | 首项 `move`，其余 `line`      |
| `-\|` / `\|-`、curve / bend 等 | 消费算子 + 下一 target | 一个对应的折角或曲线 Step     |
| arc / circle / ellipse         | 只消费当前算子         | 一个形状 Step；下一项仍会扫描 |
| `{ label }`                    | 暂存到下一段           | 自身不产出 Step               |
| `DrawWay.Cycle`                | 消费当前项             | `cycle`，且不能挂 label       |

因此，折角和曲线算子后面必须紧跟 target；形状算子不会吞掉下一项。`{ label }` 则先进入一个待挂状态，由下一个真正产出路径段的 item 消费，所以它要写在 target 或段算子之前。连续 label、末尾 label，以及给 cycle 挂 label 都会被拒绝。

最后，`<Draw>` 把 Step 序列逐项展开为 `<Path>` 的 `<Step>` children，并把描边、填充和箭头等视觉属性交给 `<Path>`。它只是更紧凑的语法糖（Sugar），不引入另一套路径语义。

### 相对坐标在 Path 编译时求值

`parseWay` 只把 `'+10,0'` / `'++10,0'` 和对应对象写法归一为 `relative` / `relativeAccumulate` target，不会提前算成绝对坐标。Path 编译逐段处理时，两者都以上一个有效终点 `prevEnd` 为基准；首项没有基准时回退到 `[0, 0]`。

`Relative` 只借用 `prevEnd` 算出本次终点，不替换这个基准；`Accumulate` 会把结果写回 `prevEnd`，所以下一个相对项从新位置继续。若当前处在变换后的 [Scope](/kernel/components/layout/scope) 中，偏移会先在该 Scope 的局部坐标中相加，再投影回全局。

## API 参考

### WayItem

| 形态               | 例                                                                                              | 含义                                                       |
| ------------------ | ----------------------------------------------------------------------------------------------- | ---------------------------------------------------------- |
| 节点 id            | `'a'`                                                                                           | 引用同一张图内的 Node；端点自动贴 border                   |
| 显式锚点           | `{ id: 'a', anchor: 'top' }` 或 `'a.top'`                                                       | 锁定命名 anchor / 角度 / 边上比例点；对象形态是 IR 主契约  |
| 笛卡尔             | `[120, 0]`                                                                                      | 直接给坐标                                                 |
| 极坐标             | `{ origin: 'a', angle: 60, radius: 80 }`                                                        | 极坐标，详见 [定位](/kernel/concepts/basic/position)       |
| 偏移定位           | `{ of: 'a', offset: [10, 5] }`                                                                  | 基准 + `(dx, dy)`，与 `<Node position>` 的 offset 形态一致 |
| 比例定位           | `{ between: [{ id: 'a' }, { id: 'b' }], fraction: 0.5 }`                                        | A 到 B 连线上的比例点                                      |
| Relative           | `{ position: [10, 0], type: DrawWay.Relative }` 或 `'+10,0'`                                    | 基于前一 step 终点偏移，不更新 prevEnd                     |
| Accumulate         | `{ position: [10, 0], type: DrawWay.Accumulate }` 或 `'++10,0'`                                 | 基于前一 step 终点偏移，并更新 prevEnd                     |
| 折角算子           | `'-\|'` / `'\|-'`                                                                               | 把上一项到下一项改成折角                                   |
| 闭合               | `DrawWay.Cycle`                                                                                 | 闭合回 way 起点                                            |
| 曲线 / 形状 / 标注 | `{ curve }` / `{ cubic }` / `{ bend }` / `{ arc }` / `{ circle }` / `{ ellipse }` / `{ label }` | 详见 [Draw](/kernel/components/draw/overview)              |

### DrawWay

| 常量                 | 等价裸字面量 | 含义                           |
| -------------------- | ------------ | ------------------------------ |
| `DrawWay.Cycle`      | 仅常量       | 闭合关键字；避免与节点 id 撞车 |
| `DrawWay.Hv`         | `'-\|'`      | 先水平后垂直                   |
| `DrawWay.Vh`         | `'\|-'`      | 先垂直后水平                   |
| `DrawWay.Relative`   | 仅常量       | 非累积相对偏移                 |
| `DrawWay.Accumulate` | 仅常量       | 累积相对偏移                   |
