先完成[基础用法](/kernel/components/path/usage)。同一句文字可以附着在整条 Path，也可以只附着在一个 Step；先选宿主，再调整位置。

## 接入方式

Path 与 Node 标签、Node 正文共用文本能力。标签直接设置 `textAlign`、`lineHeight` 和 `maxTextWidth`；正文对应字段位于 `Node.layout`。内部对齐默认 `middle`，行高默认有效字号的 1.2 倍，实际内容更高时扩展行槽。自动折行优先词边界，过长单词按字素拆分，公式不拆分；空行保留。宿主、标签、行和片段的透明度逐层相乘，省略的因子为 1，显式 0 保留。

下面四种写法都在同一条线段上附加 `status` 标签；Vanilla 示例需要页面已有 `<div id="diagram"></div>`。

## 选择标签范围

| 写法                   | 作用范围       | 何时使用           |
| ---------------------- | -------------- | ------------------ |
| `<Path label>`         | 整条路径       | 为一条关系命名     |
| `<Step label>`         | 当前步骤       | 标注其中一段       |
| `way` 中的 `{ label }` | 紧接着的连接段 | 在 Draw 中快速标注 |

## 标注路径

`{ label }` 修饰下一段产生的 `step.label`，不自己产生路径段。面板支持直线、折角、二次贝塞尔与两段直线圆角：拖动 `position`，再调整 `side`、`sloped` 与文字颜色。默认 step 模式下，折角把 t 平均分配给各腿，因此 `0.5` 固定落在拐角；曲线则按贝塞尔参数取点。

`position` 可以直接写 0–1 数值：0 为起点、1 为终点；也可使用 `at-start`、`very-near-start`、`near-start`、`midway`、`near-end`、`very-near-end`、`at-end`，分别对应 0、0.125、0.25、0.5、0.75、0.875、1。`side` 选择文字位于线的哪一侧；`sloped: true` 让文字沿切线旋转。使用 `side: 'center'` 将文字居中放在线上，`sloped` 独立控制是否沿切线旋转；省略 `side` 且设置 `sloped: true` 也会默认居中。在上方示例中选择“居中”，再切换“沿路径旋转”可比较两种效果。

Draw 在 `way` 里把 `{ label }` 放在要标注的连接段之前：

```tsx
<Draw way={['A', { label: { text: 'status', position: 0.5 } }, { curve: [180, -110] }, 'B']} />
```

Path 则直接把同一个对象传给目标 `<Step>` 的 `label`：

```tsx
<Path>
  <Step kind="move" to="A" />
  <Step kind="curve" control={[180, -110]} to="B" label={{ text: 'status', position: 0.5 }} />
</Path>
```

Path 和 Step 标签都默认使用 `positionMode: 'step'`。改为 `'length'` 后，`position: 0.5` 表示宿主范围内累计长度的一半；Path 使用全路径，Step 只使用当前步骤。

`positionGeometry` 独立选择圆角前的 `'original'` 或圆角后的 `'rounded'`。省略时，`step` 默认 original，`length` 默认 rounded。继承的显式几何仍有效，实例只修改模式不会覆盖它。`step + rounded` 保留原始段的参数份额，并将原拐点映射到圆弧中点。上方试验场选择“两段直线圆角”，把位置拖到 1，可以比较第一段末端的原拐点与圆弧中点。

`move` 跳跃和零长段不占份额，非零闭合段参与定位。定位发生在箭头截短、标签断线和整体变换之前。若 original 标签落在被圆角移除的区间，仍显示在原位置，但不产生断口。

## 多行文字与描边断口

`<Path label>` 作用于整条路径，`<Step label>` 只作用于当前步骤。下面观察同一块文字如何形成断口：文字仍在原位置，线在文字边界两侧停止。

`label.text` 与 Node 复用同一种文字块输入（TextBlock）：可写单个字符串（其中 `\n` 是硬换行），也可写行数组并给每行单独设置 `fill` / `font` / `opacity`。只有一行时这些覆盖仍然生效，行级字号也参与测量和断口计算。行或片段的透明度再乘标签与 Path 的透明度。所有行仍是同一个标签块，共享锚点、`position`、`side`、`sloped` 与 `interrupt`；断口按整个文字块的视觉边界计算，不会把每一行拆成独立标签。

省略 `interrupt` 时，只有这个无填充内置 Stroke + 居中的组合自动断线。`interrupt: false` 强制保留连续描边；`interrupt: true` 则可让非居中标签也断线。断口默认从标签视觉边界向两侧各额外留出 `4` user units；用 `gap` 覆盖该值，`gap: 0` 表示不加额外留白。

任意有效 `fill`（包括 `style.fill: 'transparent'`，以及设置 fill 后再令 `style.opacity.fill: 0`）都会关闭自动断线，且 `interrupt: true` 会明确报错。Ribbon、custom Path 与其它非内置 Stroke Path 上的任意显式布尔值同样明确报错。断口不移动标签、marks、dash 或端点箭头，也不处理标签与箭头 / mark 的碰撞。

曲线在参数处取点、按距离反解参数和保形裁切是 [`@retikz/math` 的曲线段算法](/kernel/packages/math/algorithms#曲线切片)。它只处理 纯几何数据；标签是否断线、断口间距和 Path 输出仍由 Core 决定。
