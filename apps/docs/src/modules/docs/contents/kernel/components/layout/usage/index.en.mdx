`<Layout>` is the top-level React drawing entry. Place Node, Path, or other drawing components inside it. Framing is automatic by default, so ordinary figures need no explicit size or viewBox. See [Quick start](/kernel/components/get-start) for setup.

## Integration options

Choose a host and input format: React accepts JSX or an `ir` prop; Vanilla accepts builder output or IR directly. All four variants draw the same three-node triangle with automatic framing. IR is a serializable drawing description that can come from an editor, an LLM, or a database.

<DocTab value="react-jsx" label="React + JSX">

Import components from `@retikz/react` and declare primitives directly.

```tsx
import { Draw, Layout, Node } from '@retikz/react';
import type { FC } from 'react';

const Demo: FC = () => (
  <Layout>
    <Node id="a" position={[0, 0]}>
      A
    </Node>
    <Node id="b" position={[120, 0]}>
      B
    </Node>
    <Node id="c" position={[60, 60]}>
      C
    </Node>
    <Draw way={['a', 'b', 'c', 'a']} />
  </Layout>
);

export default Demo;
```

</DocTab>
<DocTab value="react-ir" label="React + IR">

Import the IR type from `@retikz/core` and pass data to `<Layout ir>`, without JSX children.

```tsx
import type { IRScene } from '@retikz/core';
import { Layout } from '@retikz/react';
import type { FC } from 'react';

const ir: IRScene = {
  version: 1,
  type: 'scene',
  children: [
    { type: 'node', id: 'a', position: [0, 0], text: 'A' },
    { type: 'node', id: 'b', position: [120, 0], text: 'B' },
    { type: 'node', id: 'c', position: [60, 60], text: 'C' },
    {
      type: 'path',
      children: [
        { type: 'step', kind: 'move', to: { id: 'a' } },
        { type: 'step', kind: 'line', to: { id: 'b' } },
        { type: 'step', kind: 'line', to: { id: 'c' } },
        { type: 'step', kind: 'line', to: { id: 'a' } },
      ],
    },
  ],
};

const Demo: FC = () => <Layout ir={ir} />;

export default Demo;
```

</DocTab>
<DocTab value="vanilla-api" label="Vanilla API">

Build a scene with `@retikz/vanilla`, then mount it into an existing `diagram` container using the `/dom` entry.

```ts
import { scene, node, path } from '@retikz/vanilla';
import { mount } from '@retikz/vanilla/dom';

const input = scene({
  children: [
    node('a', { position: [0, 0], text: 'A' }),
    node('b', { position: [120, 0], text: 'B' }),
    node('c', { position: [60, 60], text: 'C' }),
    path({ way: ['a', 'b', 'c', 'a'] }),
  ],
});

const view = mount(document.getElementById('diagram')!, input);
```

Call `view.dispose()` before removing the container to release mounted resources.

Pass IR directly to `mount`, without React or rebuilding primitives through Vanilla builders. This example uses an existing `diagram` container.

```ts
import type { IRScene } from '@retikz/core';
import { mount } from '@retikz/vanilla/dom';

const ir: IRScene = {
  version: 1,
  type: 'scene',
  children: [
    { type: 'node', id: 'a', position: [0, 0], text: 'A' },
    { type: 'node', id: 'b', position: [120, 0], text: 'B' },
    { type: 'node', id: 'c', position: [60, 60], text: 'C' },
    {
      type: 'path',
      children: [
        { type: 'step', kind: 'move', to: { id: 'a' } },
        { type: 'step', kind: 'line', to: { id: 'b' } },
        { type: 'step', kind: 'line', to: { id: 'c' } },
        { type: 'step', kind: 'line', to: { id: 'a' } },
      ],
    },
  ],

const view = mount(document.getElementById('diagram')!, ir);
```

Call `view.dispose()` before removing the container to release mounted resources.

When React receives both `ir` and `children`, `ir` takes precedence. See [Architecture](/kernel/components/design/principles) and [Composite](/kernel/components/design/composite) for IR generation, persistence, and conversion.

## Output Boundary

**Without `viewBox`, Layout automatically computes the output bounds from the content.** The demo initially contains only two circles. The gray dashed outline follows their combined extent, with no manual origin or dimensions.

Pass `viewBox={{ x, y, width, height }}` only when a fixed frame is needed. The specified range then determines the output bounds instead of expanding with the content. It can add whitespace or narrow the frame to show only part of the drawing.

Enable “Set explicit viewBox” to adjust the origin and dimensions and compare manual framing with automatic bounds. Disable it to return to automatic framing. This example sets no separate display dimensions, so both circles keep their size when switching modes.

## Whole-figure defaults

Whole-figure defaults are defined by a root [Scope](/kernel/components/scope/usage) wrapping all primitives, available in React, Vanilla and IR. Layout provides the `rootScope` shorthand for JSX: it creates this Scope and passes through `style` and `defaults`. In Vanilla, use `scope(...)`; in IR, declare `type: 'scope'` in the scene's `children` and wrap all primitives in it.

| Property    | Type                                      | Description                                                                |
| ----------- | ----------------------------------------- | -------------------------------------------------------------------------- |
| `rootScope` | `Pick<InputScope, 'style' \| 'defaults'>` | Figure-wide visual cascade, four default channels and inheritance barriers |

The three Nodes and three Paths (declared with Draw) have no local styles. Change the stroke and opacity in `rootScope.style` to update every primitive; fill and padding in `rootScope.defaults.node` affect only the nodes. The blue color, stroke width and padding are chosen for this demo, not library defaults.

<ComponentPreview files="layout-defaults" size="md" />

Omission, empty groups, optional undefined-only overrides and isolated `defaults.reset: false` / `[]` create no wrapper or identity. Existing `font: {}` follows its font-field override contract. Explicit Scopes retain their structure; `Layout.style` always means host CSS.

## Inherited Theme

`theme` selects the theme for descendant Composites; it does not automatically style ordinary Node / Path primitives. Use `style` on primitives and `rootScope` for figure-wide defaults.

<ComponentPreview files="theme-inheritance" size="sm" />

Explicit `theme` fields override the root theme in existing IR; omitted fields keep their values. See [Theme](/kernel/components/design/theme) for inheritance rules.

## Capability Injection

A `ShapeDefinition` first supplies the folded file's footprint, connection boundary, and emitted primitives, then enters through `<Layout shapes>`. Both Nodes reference only the registered `drawio-file` name; the graphConnector stops on the custom outline, showing that definition, registry, and compile share one path.

<ComponentPreview files={['layout-shape-injection', 'layout-file-shape.ts']} size="sm" />

Boundary, clip, arrow, pattern, and path-kind definitions enter their own core registries through `<Layout>` in the same way. `<Layout>` only exposes the React injection point and does not maintain another adapter-side built-in allowlist; see each extension guide and the [API reference](/kernel/components/layout/api-reference) for the full contracts.

## Reading Compile Artifacts

To display node layout measurements outside a figure, request node-layout snapshots with `artifacts={{ nodeLayouts: true }}` and read them through `onArtifacts`. The callback reports the corresponding compilation result after React commits; later updates do not mutate a prior snapshot.

<ComponentPreview files="layout-artifacts" size="sm" />

The example displays the node count and text width outside the drawing. These snapshots describe compiled geometry, not live DOM measurements, and cannot modify drawing input.

## Execution Modes And Update Strategies

Retained mode keeps processing state for later updates; static mode processes the current figure afresh. `auto` allows incremental updates, while `full` recomputes the figure when inputs change.

```tsx
<Layout /> {/* retained + auto */}
<Layout runtime={{ mode: 'retained', updateStrategy: 'full' }} />
<Layout runtime={{ mode: 'static' }} />
```

The default `retained + auto` combines local updates with transactional rollback. Choose `retained + full` to exclude incremental Program updates while retaining Session capabilities, or choose `static` to reduce resident Runtime state.

SVG is the default output. Set `renderer="canvas"` for Canvas. See [Animation](/kernel/components/effects/animation) for playback and static snapshots.

## Errors and limitations

When both `ir` and children are supplied, `ir` takes precedence. With complete `ir`, declare the root Scope in the IR itself. Layout does not apply `rootScope` and warns in development when it contains effective settings. `runtime.mode: 'static'` cannot be combined with `updateStrategy` or `onDiagnostic`.

Use [Inspect](/kernel/packages/inspect) for inspection overlays and the [Layout package](/library/layout) for automatic arrangement.
