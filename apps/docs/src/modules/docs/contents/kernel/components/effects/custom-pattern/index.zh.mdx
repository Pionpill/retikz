当内置的斜线、圆点与网格不能表达所需纹理时，可以注册自己的重复图案。下面的 `cross` 定义会在每个方格中绘制一个十字，再作为普通 `fill` 使用。

## 适用边界

如果只需改变疏密、颜色、背景、线宽或旋转，继续使用[内置图案](/kernel/components/effects/pattern)并调整 `size` 等字段即可。只有重复单元的几何本身不同，才需要自定义 `PatternDefinition`。

图元数据只保存 `{ kind: 'pattern', shape: 'cross' }` 这类可序列化配置。生成重复单元的 `emit` 函数留在定义中，通过宿主注入，不进入 IR（中间表示）。

## 定义能力

使用 `definePattern()` 创建一个带名称的图案定义。`emit` 接收已解析的尺寸与颜色，并在 `0..size` 的局部坐标中返回结构化图元。

```tsx
import { definePattern } from '@retikz/core';

const cross = definePattern({
  name: 'cross',
  defaultSize: 12,
  emit: ({ size, color }) => {
    const center = size / 2;
    return [
      {
        type: 'path',
        commands: [
          { kind: 'move', to: [center, 2] },
          { kind: 'line', to: [center, size - 2] },
        ],
        stroke: color,
      },
      {
        type: 'path',
        commands: [
          { kind: 'move', to: [2, center] },
          { kind: 'line', to: [size - 2, center] },
        ],
        stroke: color,
      },
    ];
  },
});
```

内置图案与自定义图案都实现同一份 `PatternDefinition`，并进入同一注册表。`definePattern()` 只帮助 TypeScript 检查定义形状，不会把函数写进图元数据。

## 注入宿主

把定义传给 `<Layout patterns>`，再在 Node 或 Path 的 `fill` 中引用它的 `name`：

```tsx
<Layout patterns={[cross]}>
  <Node fill={{ kind: 'pattern', shape: 'cross', color: 'darkorange' }} />
</Layout>
```

直接调用 `compileToScene()` 时，对应入口是 `CompileOptions.patterns`。定义属于本次编译宿主；同一份 IR 可以在不同宿主中注入不同的图案集合。

`pattern.size` 会覆盖定义的 `defaultSize`。下面两个节点复用同一个完整定义：左侧固定为 `size: 6` 作为参照，右侧从 `size: 16` 开始，并允许调整周期、旋转、颜色与背景。

## 执行机制

编译时，内置与自定义定义先合并成一个注册表。编译器随后按 `shape` 查找定义、调用 `emit`，并把结果写成 Scene 中已解析的图案资源；SVG 与 Canvas 只负责物化这个资源，不再接触定义函数。

| 阶段 | 输入                  | 产物                          |
| ---- | --------------------- | ----------------------------- |
| 注册 | 内置定义 + `patterns` | 按名称索引的统一注册表        |
| 解析 | `shape`、尺寸与颜色   | 局部重复单元图元              |
| 输出 | 已解析重复单元        | Scene 图案资源                |
| 渲染 | Scene 图案资源        | SVG pattern 或 Canvas pattern |

这条路径保证内置与自定义图案拥有相同的名称冲突、查找、校验与渲染语义。

## 错误与限制

| 情况                        | 结果                     | 处理方式                |
| --------------------------- | ------------------------ | ----------------------- |
| 名称为空或重复              | 注册时报错               | 使用非空且唯一的 `name` |
| `shape` 未注册              | 编译时报错并列出可用名称 | 注入定义或修正名称      |
| `size` / `lineWidth` 非正数 | 编译时报错               | 传有限正数              |
| `rotation` 不是有限数       | 编译时报错               | 传有限角度              |
| `emit` 抛错                 | 编译包装并报告图案名     | 检查定义逻辑            |
| 产物含非法图元或坐标        | 编译校验失败             | 只返回允许的结构化图元  |

重复单元只接受 Scene 可序列化的结构化几何；不要返回函数、DOM 节点、文本、外部资源引用或非有限坐标。

## API 参考

### PatternDefinition

| 属性          | 类型                                 | 默认值 | 描述                               |
| ------------- | ------------------------------------ | ------ | ---------------------------------- |
| `name`        | `string`                             | —      | `pattern.shape` 使用的注册名       |
| `defaultSize` | `number?`                            | `8`    | 可选；未传 `pattern.size` 时的周期 |
| `emit`        | `(ctx) => Iterable<MarkerPrimitive>` | —      | 生成局部重复单元几何               |

### PatternEmitContext

| 属性         | 类型            | 默认值         | 描述                 |
| ------------ | --------------- | -------------- | -------------------- |
| `size`       | `number`        | 已解析         | 重复单元周期         |
| `color`      | `string`        | `currentColor` | 重复单元主色         |
| `background` | `string?`       | —              | 省略时背景透明       |
| `lineWidth`  | `number?`       | —              | 省略时由图案定义决定 |
| `round`      | `(n) => number` | —              | 使用编译精度取整     |
