title: Layout
description: 'The layout family establishes figure-level and local coordinate contexts: Layout connects the compile host, Scope owns sub-figure context, and custom clips extend Scope visibility.'
---

This group only answers where graphic content lives and how a group enters downstream stages as one unit. `<Layout>` is the single required top-level entry; `<Scope>` establishes a local context so its children share transforms, defaults, reference bounds, and clipping.

It does not define Node / Path geometry or provide domain layout algorithms such as plot or table. When Scope needs new clipping vocabulary, a Clip Definition joins the same registry and compile path.

<ComponentPreview files="layout-family" size="sm" hideCode />

## What each part does

| Component    | Type      | Responsibility                                      | Use it when                         |
| ------------ | --------- | --------------------------------------------------- | ----------------------------------- |
| Layout       | Kernel    | Converge JSX / IR, capability injection, and output | Every figure needs its entry        |
| Scope        | Kernel    | Establish local context and a group reference       | Transform, isolate, or clip a group |
| Custom Clips | Extension | Register domain clip kinds resolved into Scene      | Built-in clips are not enough       |
