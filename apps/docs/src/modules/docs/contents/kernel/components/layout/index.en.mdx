This group is the figure's _container_ layer. `<Layout>` is the mandatory outermost wrapper of every figure: it takes a component tree or IR, compiles a Scene, and hands it to the current renderer. `<Scope>` gathers children into one unit, applies a shared translate / rotate / scale, and can be referenced or positioned as a whole through its `id`. Together they establish coordinate context; the last page extends Scope's `clip` kinds when the built-ins are not enough.

<ComponentPreview files="layout-family" size="md" hideCode />

## What each part does

| Component    | Type      | Responsibility                                                                                                               | Use it when                                                                       |
| ------------ | --------- | ---------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| Layout       | Kernel    | The one required top-level container: children / IR entry, compiles and emits the Scene; `width` / `height` set display size | The outermost wrapper of every figure                                             |
| Scope        | Kernel    | Local transform container: translates / rotates / scales a group of children as a unit, referenceable as a whole by `id`     | Transforming a sub-figure as one, local coordinate frames, id namespace isolation |
| Custom Clips | Extension | Register reusable clip kinds for Scope                                                                                       | Host or extension packages need domain-specific clipping primitives               |
