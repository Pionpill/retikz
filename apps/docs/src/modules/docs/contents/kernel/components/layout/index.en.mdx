`<Layout>` is the entry for a complete React drawing. Place Node, Path, and other primitives inside it to compile and present a result. Automatic framing follows visible content, so a fixed canvas size is not required.

## How the pieces work together

Start with the small node-and-connection figure below. Node describes each node, Draw describes the connection, and Layout presents them as one figure. Moving a node changes its geometry; Layout updates the displayed result.

<ComponentPreview files="/kernel/components/layout/usage/layout-basic" size="sm" />

Layout accepts a component tree or saved IR, the serializable description of a drawing. Shapes, arrows, and formulas can be injected here. Component props and persisted scene data have separate API and Schema references.

## Choosing the right capability

Layout is a drawing entry, not an automatic arrangement algorithm. Primitives and positioning rules determine node positions. Use the [Layout package](/library/layout) for Flex, Grid, and other arrangement capabilities.

Use [Scope](/kernel/components/scope) for local transforms, defaults, and clipping within a figure; see [Custom clipping](/kernel/components/scope/custom) to extend clip shapes. Use [Inspect](/kernel/packages/inspect) to display control points and boundary overlays.

Read Basic usage first. Implementation explains root scopes, framing, display sizing, and theme overlays; the reference pages are available for precise lookups without reading them end to end.
