---

这一分组只解决「图形内容放在哪个坐标语境中、怎样作为整体进入下游」的问题。`<Layout>` 是每张图唯一必需的顶层入口；`<Scope>` 在图内建立局部上下文，让一组 children 共享变换、默认值、引用边界与裁剪。

它不负责定义 Node / Path 的几何语义，也不提供 plot / table 等领域布局算法。需要扩展 Scope 的裁剪词汇时，再通过 Clip Definition 接入同一条 registry 与编译路径。

## 职责一览

| 组件         | 类型   | 职责                                    | 适合场景             |
| ------------ | ------ | --------------------------------------- | -------------------- |
| Layout       | Kernel | 汇合 JSX / IR、能力注入、编译与宿主输出 | 每张图的最外层入口   |
| Scope        | Kernel | 建立子图的局部上下文与整体引用句柄      | 整组变换、隔离、裁剪 |
| 自定义裁剪区 | 扩展   | 注册业务 clip kind，并解析为 Scene 资源 | 内置裁剪原语不足时   |
