`<Layout>` 是 React 中整张图的入口。把 Node、Path 等图元放入其中，Layout 接入编译并呈现结果；默认根据可见内容自动取景，无需先确定画布尺寸。

## 整体认识

下面从一张最小的节点连线图开始：Node 描述节点，Draw 描述连接，Layout 负责把这些内容作为一张图显示出来。调整节点位置时，图元决定几何变化，Layout 更新显示结果。

<ComponentPreview files="/kernel/components/layout/usage/layout-basic" size="sm" />

Layout 可以接收组件树，也可以显示已经保存的 IR（可序列化的图形描述）。形状、箭头、公式等扩展从这里注入；组件属性与可保存的场景数据分别在 API 和 Schema 参考中查询。

## 选择与边界

Layout 是绘图入口，不是自动排版算法：节点位置仍由图元与定位规则描述。需要 Flex、Grid 等排列能力时，使用 [Layout 布局包](/library/layout)。

一张图中的局部分组使用 [Scope](/kernel/components/scope) 管理变换、默认样式和裁剪；扩展裁剪形状阅读[自定义裁剪区](/kernel/components/scope/custom)。观察控制点和边界等辅助信息使用 [Inspect](/kernel/packages/inspect)。

初次使用先阅读基础用法。只有排查更新、视框或渲染行为时才需要进入实现原理；完整属性和场景字段按需查表，无需先通读。
