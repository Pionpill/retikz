---

组件分组是日常写图的主要入口。先用布局建立画布和局部坐标语境，再放置节点与坐标、绘制路径关系；形状和效果页面用于补充更具体的表达能力。各领域的自定义能力放在对应分组末尾，跨领域机制则集中在[扩展机制](/kernel/reference/runtime/extensions)。

## 职责一览

| 分组 | 主要内容                           | 职责                       |
| ---- | ---------------------------------- | -------------------------- |
| 布局 | Layout、Scope、Clip                | 承载整图与局部坐标语境     |
| 节点 | Node、Text、Coordinate、Boundary   | 描述可见对象与可引用位置   |
| 绘制 | Draw、Way、Path、Arrow、Step       | 描述连接方式与路径动作     |
| 形状 | Circle、Arc、Rectangle、Polygon 等 | 用高层参数生成常见几何路径 |
| 效果 | Shadow、Blend、Pattern、Animation  | 控制视觉合成与动态表现     |
