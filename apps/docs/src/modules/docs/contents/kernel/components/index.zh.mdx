---

组件分组是日常写图的主要入口。先用布局建立画布和局部坐标语境，再放置节点与坐标、绘制路径关系；形状、辅助、效果和扩展页面用于补充更具体的表达能力。

## 职责一览

| 分组 | 主要内容                           | 职责                         |
| ---- | ---------------------------------- | ---------------------------- |
| 布局 | Layout、Scope                      | 承载整图与局部坐标语境       |
| 节点 | Node、Text、Coordinate             | 描述可见对象与可引用位置     |
| 绘制 | Draw、Way、Path、Arrow、Step       | 描述连接方式与路径动作       |
| 形状 | Circle、Arc、Rectangle、Polygon 等 | 用高层参数生成常见几何路径   |
| 辅助 | Grid                               | 提供可复用的辅助绘制能力     |
| 效果 | Shadow、Blend、Animation           | 控制视觉合成与动态表现       |
| 扩展 | Registry 与自定义 Definition       | 注册形状、路径、箭头等新能力 |
