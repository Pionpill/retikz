---
title: Ribbon
description: Use Path's ribbon kind to turn a Step centerline or precomputed boundaries into a fillable band with controllable width, interpolation, caps, and labels.
---

`<Path kind="ribbon">` describes a band-shaped relation with one Path. Centerline mode keeps using `<Step>` for the route and generates both sides from a width rule; boundary mode accepts two already-computed outlines.

Ribbon owns width, sampling, alignment, and caps. Shared fields such as `fill`, outline `stroke`, opacity, shadow, labels, and `zIndex` remain on the `<Path>` host. See [Path](/kernel/components/draw/path) for ordinary stroked paths.

## Usage

```tsx
import { Path, Step } from '@retikz/react';
```

```tsx
<Path kind="ribbon" ribbon={{ start: { width: 32 }, end: { width: 12 } }} fill="#60a5fa">
  <Step kind="move" to={[-120, 0]} />
  <Step kind="cubic" control1={[-40, -48]} control2={[40, 48]} to={[120, 0]} />
</Path>
```

Use the default centerline mode when layout supplies only a route. Use boundary mode when layout already owns the upper and lower outlines.

## Examples

### Basic band

Centerline mode offsets both sides of an open path and emits a closed Path primitive. `stroke` outlines the band instead of drawing its centerline again.

### Width and appearance

`width` can be fixed, split across endpoints, described by stops, or supplied by a registered width profile. Compare width models and interpolation while adjusting fill, outline, and shadow in one panel.

### Label placement

Ribbon labels reuse GeometryLabel. `placement="inside"` puts text inside the band; outside mode selects a side, and `sloped` follows the centerline tangent.

<ComponentPreview files="ribbon-label" size="sm" />

### Endpoints and caps

`start` / `end` can override endpoint width, tangent direction, and cap. `align` controls where the centerline sits inside the band width.

<ComponentPreview files="ribbon-endpoints" size="md" />

### Precomputed boundaries

When layout already owns both outlines, set `mode: 'boundary'` and pass two open step sequences through `upper` / `lower`. This mode does not use `children`, and the schema rejects `width`, `align`, `start`, `end`, and `interpolation`; `label` is centerline-only too.

### How the two modes build an outline

| Mode         | Input                   | Construction                               |
| ------------ | ----------------------- | ------------------------------------------ |
| `centerline` | Path `children` + width | Resolve the route and offset both sides    |
| `boundary`   | `upper` / `lower` steps | Sample both sides and close them with caps |

Centerline mode reuses Path target, curve, and generator resolution before applying its width function. Analytic fixed-width segments use a direct outline when possible; other cases sample cross-sections.

Boundary mode samples the supplied upper and lower paths directly. Both modes finish as ordinary closed Path primitives, so SVG and Canvas renderers do not need ribbon-specific semantics.

## API Reference

### Path entry points

| Prop       | Type                                    | Default        | Description                                                                                  |
| ---------- | --------------------------------------- | -------------- | -------------------------------------------------------------------------------------------- |
| `kind`     | `'ribbon'`                              | —              | Selects the built-in Ribbon Path kind                                                        |
| `ribbon`   | `PathRibbonOptions`                     | —              | Required construction mode, width, sampling, alignment, endpoints, and boundaries            |
| `label`    | `GeometryLabel \| Array<GeometryLabel>` | —              | Host labels supported by centerline mode                                                     |
| `children` | `Array<<Step>>`                         | —              | Required in centerline mode; omitted in boundary mode                                        |
| `fill`     | `string \| PaintSpec`                   | `currentColor` | Band fill. See [Path](/kernel/components/draw/path#api-reference) for the shared Path fields |

### ribbon options

| Field             | Type                                               | Default        | Description                                                                  |
| ----------------- | -------------------------------------------------- | -------------- | ---------------------------------------------------------------------------- |
| `mode`            | `'centerline' \| 'boundary'`                       | `'centerline'` | Generate from a centerline or close precomputed boundaries                   |
| `width`           | `number \| RibbonWidthStops \| RibbonWidthProfile` | —              | Whole-centerline width rule; exclusive with endpoint widths                  |
| `start` / `end`   | `{ width?, direction?, cap? }`                     | —              | Endpoint width, tangent, and cap; cap defaults to `'butt'`                   |
| `interpolation`   | `'linear' \| 'smooth'`                             | `'linear'`     | Interpolation between endpoint widths                                        |
| `align`           | `'left' \| 'center' \| 'right'`                    | `'center'`     | Where the centerline sits inside the band width                              |
| `samples`         | `boolean \| number`                                | —              | Fixed-sampling shorthand shared by both modes; `true` uses 64 cross-sections |
| `sampling`        | `{ kind: 'fixed' \| 'adaptive', ... }`             | —              | Explicit strategy; cannot be combined with `samples`                         |
| `upper` / `lower` | `Array<IRStep>`                                    | —              | Required open boundaries in boundary mode                                    |

See the [PathRibbonOptions schema](/kernel/reference/schema/path#pathribbonoptions) for complete validation constraints.
