---

`<Layout>` 是 retikz 唯一必需的顶层包装，所有 Kernel / Sugar 组件都必须放在它里面。

它是 DSL 与渲染器之间的入口：传 children 时把组件树转成 IR，传 `ir` 时直接采用这份 IR；随后把 IR 编译为 Scene，交给当前渲染器输出。

`width` / `height` 只决定渲染结果在页面上的显示尺寸；内部坐标仍用 retikz 用户单位，可见范围由编译阶段按布局边界自动算。

## 用法

```tsx
import { Layout } from '@retikz/react';
```

```tsx
<Layout width={300} height={80}>
  {/* Kernel / Sugar children */}
</Layout>
```

## 组合

`<Layout>` 是容器；children 是任意 Kernel / Sugar 组件树：

```tsx
<Layout>
  <Node id="..." position={...}>label</Node>
  <Path>
    <Step kind="move" to="..." />
    <Step kind="line" to="..." />
  </Path>
  <Draw way={[...]} />
</Layout>
```

### 全图默认样式

`<Layout>` 直接接受 [`<Scope>`](/kernel/components/layout/scope) 的级联样式子集（`color` / `stroke` / `fill` / `strokeWidth` / `opacity` / `fillOpacity` / `strokeOpacity` + `nodeDefault` / `pathDefault` / `labelDefault` / `arrowDefault`）。设了任一样式 prop，Layout 会把 children 包进一个**隐式根 `<Scope>`**，省掉每张图都套一层根 `<Scope>` 的样板。内层 `<Scope>` 与图元显式属性照常级联覆盖。

<ComponentPreview files="layout-scope-style" size="sm" />

```tsx
// 给整张图设默认样式：不用再手写嵌套 <Scope>
<Layout stroke="gray" nodeDefault={{ shape: 'circle', fill: 'white', dashed: true }} pathDefault={{ lineCap: 'round' }}>
  <Node id="A" position={[0, 0]}>A</Node>
  <Draw way={['A', 'B']} arrow="->" />
</Layout>

// 等价于手写一层根 <Scope>
<Layout>
  <Scope stroke="gray" nodeDefault={{ shape: 'circle', fill: 'white', dashed: true }} pathDefault={{ lineCap: 'round' }}>
    {/* ... */}
  </Scope>
</Layout>
```

包裹的具体条件、以及与 `ir` prop 并用时的取舍见下方「技术原理」。

### 从 IR 渲染

`<Layout>` 接受 `ir` prop——直接把一段已持久化的 IR JSON 渲染成图，**不写一行 JSX children**。来源不限：LLM 生成、JSON 编辑器、URL 反序列化、数据库存档都可以。

<ComponentPreview files="layout-from-ir" size="xs" />

需要在 DSL 与 IR 之间互转时，配 `convertReactNodeToIR` / `convertIRToReactNode` 做双向桥。Tier 1 IR 往返后保持结构等价；Tier 2 composite 会先按传入的 `composites` definitions 展开，因此往返结果与展开后的 Kernel IR 语义等价，不会还原成原始自定义组件：

```tsx
import { Layout, Node, convertIRToReactNode, convertReactNodeToIR } from '@retikz/react';

const ir = convertReactNodeToIR(
  <Node id="a" position={[0, 0]}>
    A
  </Node>,
);
// 序列化、传 LLM、存数据库……
<Layout ir={ir} width={200} height={80} />;

const kernelChildren = convertIRToReactNode(tier2IR, {
  composites: [panelDefinition],
});
```

Tier 2 缺少对应 definition、payload 不合法或递归展开超限时，`convertIRToReactNode` 会直接抛错，并在错误中保留 composite key 与 IR 路径，避免静默丢失节点。

`ir` 与 `children` 互斥；同时传时优先 `ir`。

### 自定义 viewBox

默认 `viewBox` 由内容自动算（AABB + padding）。传 `viewBox={{ x, y, width, height }}` 显式定死视框——固定尺寸、故意裁剪、多图对齐、排除溢出都靠它。有 viewBox 则覆盖自动算、忽略 padding；`width` / `height` 必须 > 0。

<ComponentPreview files="layout-viewbox" size="md" />

### 渲染后端（SVG / Canvas）

`renderer` 选择输出后端：默认 `'svg'`，设 `'canvas'` 则用同一份 Scene 画到 `<canvas>`。

缺省 `renderer` prop 时，`<Layout>` 回退读取最近的 `RendererModeProvider`。这适合「外层想统一切换一棵无法逐个改 `renderer` 的子树」的场景，比如把一个交互式（含 hooks / 异步）子树整体在 svg / canvas 间切——你改不到它内部的 `<Layout renderer>`，但用 Provider 一包就行：

```tsx
import { Layout, RendererModeProvider } from '@retikz/react';

// 子树内未写 renderer 的 <Layout> 随 Provider 切换；写了 renderer 的不受影响
<RendererModeProvider mode="canvas">
  <SomeInteractiveChart />
</RendererModeProvider>;
```

### 统一控制一棵子树的动画

通常应让每个 `<Layout>` 通过 `animate` 表达自己的动画意图。如果编辑器、文档预览或测试工具需要统一控制一整棵组件树，可在外层使用 `AnimationModeProvider`：

```tsx
import { AnimationModeProvider } from '@retikz/react';

<AnimationModeProvider mode="enabled">
  <SomeInteractiveChart />
</AnimationModeProvider>;
```

| `mode`       | 行为                                   |
| ------------ | -------------------------------------- |
| `'system'`   | 整棵子树跟随系统的「减少动态效果」偏好 |
| `'enabled'`  | 整棵子树强制播放动画                   |
| `'disabled'` | 整棵子树强制显示静态结果               |

动画 Provider 是宿主级覆盖：最近的 `AnimationModeProvider` 优先于后代 `<Layout animate>`，包括相反的显式值。未使用 Provider 时，`animate` 仍保持原有三态语义；`snapshotAt` 始终优先，提供后只渲染静态截帧。

### 两种输入如何汇合

`children` 与 `ir` 最终都会变成同一份 JSON IR，再交给 core 编译。区别只发生在进入 IR 之前：JSX 分支需要遍历组件树，`ir` 分支直接采用已有契约。

<ComponentPreview files="layout-input-flow" size="md" hideCode />

JSX 分支仅在样式 prop 真正携带指令时包一层根 `<Scope>`；空 default 不改变 IR。直接传 `ir` 时，全图样式 props 被忽略并在开发模式提示，因为这份 IR 已经包含完整根语义。

### 视框如何确定

上半部分决定内部坐标范围：显式 `viewBox` prop 优先，其次是 IR 自带的 `viewBox`，两者都没有时才使用内容边界加 padding。下半部分的 `width` / `height` 只控制页面显示尺寸，不参与内部坐标计算。

<ComponentPreview files="layout-viewbox-resolution" size="sm" hideCode />

图形被裁或留白过多时，先看 **View Code → IR**：显式 viewBox 可能小于可见图元，自动模式则可能被远离主体的可见边界拉大。只有 coordinate 而没有可见边界时，它不会单独扩展自动范围。

### 宿主策略如何回退

图中数字就是查找顺序；只有当前项未提供时才继续向下，命中第一个有效值即停止。左列是 **`renderer` prop > 最近的 `RendererModeProvider` > `'svg'`**；右列是 **`snapshotAt` > 最近的 `AnimationModeProvider` > `animate` > 系统偏好**。

<ComponentPreview files="layout-runtime-priority" size="lg" hideCode />

渲染 Provider 只补充缺省的 renderer，后代显式 prop 仍可覆盖；动画 Provider 则用于宿主统一控制整棵树，会覆盖后代 `animate`。一旦传入 `snapshotAt`，SVG 与 Canvas 都只输出指定时刻的静态帧。

## API 参考

| 属性                                                                                      | 类型                                            | 默认值  | 描述                                                                                                                                                                               |
| ----------------------------------------------------------------------------------------- | ----------------------------------------------- | ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `width`                                                                                   | `number \| string`                              | —       | 渲染结果宽度                                                                                                                                                                       |
| `height`                                                                                  | `number \| string`                              | —       | 渲染结果高度                                                                                                                                                                       |
| `viewBox`                                                                                 | `{ x, y, width, height }`                       | —       | 显式视框，覆盖自动算的范围（忽略 padding）；注入 IR 根、prop 优先于 IR 内置                                                                                                        |
| `children`                                                                                | `ReactNode`                                     | —       | Kernel / Sugar 组件树（与 `ir` 二选一）                                                                                                                                            |
| `ir`                                                                                      | `IRScene`                                       | —       | 已构造好的 IR JSON（与 `children` 二选一）                                                                                                                                         |
| `className`                                                                               | `string`                                        | —       | 透传到渲染根元素                                                                                                                                                                   |
| `style`                                                                                   | `CSSProperties`                                 | —       | 透传到渲染根元素                                                                                                                                                                   |
| `idPrefix`                                                                                | `string`                                        | —       | 覆盖 `<defs>` 资源 id 前缀；SSR 输出和客户端 `<Layout>` 传同一值时可保持引用 id 一致                                                                                               |
| `renderer`                                                                                | `'svg' \| 'canvas'`                             | `'svg'` | 渲染后端；缺省时回退最近 `RendererModeProvider` 的 context 值（prop > context > svg）                                                                                              |
| `nodeDistance`                                                                            | `number`                                        | `24`    | 节点相对定位（`position = { direction, of }`）的默认距离，节点自带 `distance` 优先                                                                                                 |
| `fontSize`                                                                                | `number`                                        | `16`    | 默认字号；同时作为字号 preset 与 `rem` 的根字号，显式数字字号不受影响                                                                                                              |
| `shapes`                                                                                  | `ReadonlyArray<ShapeDefinition>`                | —       | 自定义形状 definition 数组；透传到 `CompileOptions.shapes`。常见用法见 [自定义形状](/kernel/components/shapes/custom-shape)                                                        |
| `boundaries`                                                                              | `ReadonlyArray<BoundaryDefinition>`             | —       | 自定义连接面 definition 数组；透传到 `CompileOptions.boundaries`。常见用法见 [自定义连接面](/kernel/components/node/custom-boundary)                                               |
| `clips`                                                                                   | `ReadonlyArray<ClipDefinition>`                 | —       | 自定义裁剪区 definition 数组；透传到 `CompileOptions.clips`。常见用法见 [自定义裁剪区](/kernel/components/layout/custom-clip)                                                      |
| `arrows`                                                                                  | `ReadonlyArray<ArrowDefinition>`                | —       | 自定义箭头 definition 数组；透传到 `CompileOptions.arrows`。常见用法见 [自定义箭头](/kernel/components/draw/custom-arrow)                                                          |
| `patterns`                                                                                | `ReadonlyArray<PatternDefinition>`              | —       | 自定义 pattern motif definition 数组；透传到 `CompileOptions.patterns`。常见用法见 [自定义图案](/kernel/components/effects/custom-pattern)                                         |
| `pathGenerators`                                                                          | `ReadonlyArray<PathGeneratorDefinition>`        | —       | 自定义 path generator definition 数组；透传到 `CompileOptions.pathGenerators`，可补充内置 `parabola` 之外的生成器。常见用法见 [路径生成器](/kernel/components/draw/path-generator) |
| `pathKinds`                                                                               | `ReadonlyArray<PathKindDefinition>`             | —       | 自定义 Path kind provider 数组；透传到 `CompileOptions.pathKinds`。常见用法见 [自定义路径](/kernel/components/draw/custom-path)                                                    |
| `ribbonWidthProfiles`                                                                     | `ReadonlyArray<RibbonWidthProfileDefinition>`   | —       | 自定义 ribbon 宽度 profile 数组；透传到 `CompileOptions.ribbonWidthProfiles`。见 [compile 选项](/kernel/reference/runtime/compile)                                                 |
| `composites`                                                                              | `ReadonlyArray<CompositeDefinition>`            | —       | 运行时注入的 Tier 2 composite 展开逻辑（透传 `CompileOptions.composites`）；compile 第一步展开成 Tier 1，未注册 namespace/type 警告并跳过                                          |
| `lowerTex`                                                                                | `LowerTex`                                      | —       | 公式渲染能力注入；传给 `CompileOptions.lowerTex`，让 `<Node>` 文本中的 LaTeX 公式降解为字形路径。见 [TeX 公式](/kernel/packages/tex)                                               |
| `onNodeLayouts`                                                                           | `(layouts: Array<CompiledNodeLayout>) => void`  | —       | 节点布局测量回调；commit 后批量返回内容盒 `content.size` 与全局 AABB `content.bounds`，可在渲染前读取含 TeX 文本的内容尺寸，不在 render 阶段触发                                   |
| `embeddables`                                                                             | `Array<EmbeddableTier2Adapter>`                 | —       | 可选逃生舱：显式注入可嵌入 Tier 2 adapter；主路径是组件静态标记，按 displayName 匹配并覆盖标记。见 [复合](/kernel/concepts/design/composite#可嵌入-tier2把-tier2-组件写进-layout)  |
| `color` / `stroke` / `fill` / `strokeWidth` / `opacity` / `fillOpacity` / `strokeOpacity` | 同 [`<Scope>`](/kernel/components/layout/scope) | —       | 全图级联 graphic state；设值则把 children 包进隐式根 `<Scope>`                                                                                                                     |
| `nodeDefault` / `pathDefault` / `labelDefault` / `arrowDefault`                           | 同 [`<Scope>`](/kernel/components/layout/scope) | —       | 全图 every-X 默认样式（四通道）；同上挂隐式根 scope                                                                                                                                |
| `animate`                                                                                 | `boolean`                                       | 系统    | 未传跟随系统；`true` 强制开启，`false` 强制关闭。见 [动画](/kernel/components/effects/animation)                                                                                   |
| `snapshotAt`                                                                              | `number`                                        | —       | 静态截帧时刻（毫秒）：定格在该时刻的一帧、不播放，覆盖 `animate`；SSR 海报帧 / 缩略图                                                                                              |
| `animations`                                                                              | `Array<AnimationTrack>`                         | —       | scene 根（镜头）动画 tracks（`viewBox` 通道），配 [`cameraTo()`](/kernel/components/effects/animation)                                                                             |
| `animationRef`                                                                            | `Ref<AnimationControls \| null>`                | —       | 命令式动画句柄出口：挂载后写入 `play` / `pause` / `seek`（svg=WAAPI、canvas=rAF 时钟），无动画为 `null`                                                                            |
| `easings`                                                                                 | `EasingRegistry`                                | —       | 自定义缓动注册表（名 → cubic-bezier 四元组 / 函数）。见 [自定义动画](/kernel/components/effects/custom-animation)                                                                  |
| `animationProperties`                                                                     | `AnimationPropertyRegistry`                     | —       | 自定义动画属性通道插值器（如 `blur`）；当前仅 Canvas。见 [自定义动画](/kernel/components/effects/custom-animation)                                                                 |
| `handlers`                                                                                | `HydrationHandlers`                             | —       | `ir` 模式按 id 提供的水合 handler 注册表（JSX 模式用组件 `on<Event>` props）。见 [水合](/kernel/packages/render/hydration)                                                         |
