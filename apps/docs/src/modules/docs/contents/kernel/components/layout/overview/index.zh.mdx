title: Layout

---

`<Layout>` 是 React 绘图树的顶层运行时入口，所有 Kernel / Sugar 组件都从这里进入同一条图形管线。

它解决两类输入的汇合：传 children 时由 React adapter 构造 Core IR，传 `ir` 时直接采用已有 IR；随后在 retained Runtime Session 中由 `@retikz/core` 发布 Scene Snapshot / Patch，再由 `@retikz/render` 更新 SVG 或 Canvas。

`<Layout>` 只拥有 React 侧的构造、能力注入和宿主接线，不定义 IR / Scene 语义、几何规则或自动布局算法。节点定位与通用约束由 core 表达，plot / table 等领域布局属于各自上层能力。

`width` / `height` 只决定渲染结果在页面上的显示尺寸；内部坐标仍用 retikz 用户单位，可见范围由编译阶段按布局边界自动算。

## 用法

```tsx
import { Draw, Layout, Node } from '@retikz/react';
```

```tsx
<Layout width={300} height={80}>
  <Node id="A" position={[0, 0]}>
    A
  </Node>
  <Node id="B" position={[120, 0]}>
    B
  </Node>
  <Draw way={['A', 'B']} arrow="->" />
</Layout>
```

children 直接放 Kernel / Sugar 组件树即可，没有额外的固定组合协议。

## 例子

### JSX 输入

日常写图直接传 children；`<Layout>` 负责把组件树转成 Core IR，并接入后续编译与渲染。

### IR 输入

`<Layout>` 接受 `ir` prop——直接把一段已持久化的 IR JSON 渲染成图，**不写一行 JSX children**。来源不限：LLM 生成、JSON 编辑器、URL 反序列化、数据库存档都可以。

<ComponentPreview files="layout-from-ir" size="sm" />

`ir` 与 `children` 是两种入口；同时传入时采用 `ir`。需要生成、持久化或转换 IR 时，继续阅读[架构](/kernel/concepts/design/principles)与[复合](/kernel/concepts/design/composite)。

### 读取编译产物

这里的 DTO 是 Data Transfer Object（数据传输对象）：`CompiledNodeLayout` 是 Core 完成 Node 布局后复制并冻结的数据快照。它记录 Node id、正文盒的中心 / 尺寸 / 全局边界、外框的位置 / 尺寸 / 旋转，以及正文行数和是否包含 TeX；artifact 外层的 `occurrence` 另行标识该 Node 在本次编译中的来源。

它不是 IR、Scene 图元或实时 DOM 测量对象，也不暴露编译器内部的可变状态。用 `artifacts={{ nodeLayouts: true }}` 按需请求这些快照，再通过 `onArtifacts` 在 React commit 后读取同次编译结果；下面的回调把真实 Node 数量和正文宽度显示在图外。

### 能力注入

`ShapeDefinition` 先定义折角文件的占位、连接边界与输出图元，再通过 `<Layout shapes>` 注入。两个 Node 只引用注册名 `drawio-file`；连线端点停在自定义轮廓上，说明 definition、registry 与 compile 共用同一条路径。

<ComponentPreview files={['layout-shape-injection', 'layout-file-shape.ts']} size="sm" />

boundary、clip、arrow、pattern、path kind 等 definition 也从 `<Layout>` 进入各自的 core registry。`<Layout>` 只提供 React 注入入口，不在 adapter 内维护另一套内置白名单；完整契约见对应自定义指南与下方 API。

本节只放大 `<Layout>` 自己负责的 React 接线、视框与宿主策略；各包的完整职责见[架构](/kernel/concepts/design/principles)。

### 职责如何闭环

`<Layout>` 把 JSX children 转成 Core IR，或直接采用 `ir` prop；definitions 与 runtime options 也由这里接入。每当 `ir` 或 Core options 改变，render 阶段会完整编译一次 SSR-safe Scene seed；React commit 后，Core Program 与 retained Render participant 再在 Runtime Session 中处理同一输入。输入和 renderer 配置在一次 transaction 中提交，成功后才一起发布 Scene、DOM / bitmap、事件、动画句柄与 artifacts。

<ComponentPreview files="layout-input-flow" size="sm" hideCode />

这条链路的语义所有权不会随入口漂移：React 只声明稳定的 `<svg>` / `<canvas>` host shell，Render participant 独占 SVG descendants 或 Canvas bitmap；core 不拥有 DOM 或 Canvas 实例，render 不反向定义新的图形语义。失败的 transaction 不发布新 revision；rollback 成功只保证错误向 React 传播前把宿主恢复到上一 committed revision，不能保证当前 React 子树继续可用。调用方应让 Error Boundary 捕获错误并重新挂载 `<Layout>`；rollback 自身失败时 Session 还会进入 broken。

### 视框如何确定

上半部分决定内部坐标范围：显式 `viewBox` prop 优先，其次是 IR 自带的 `viewBox`，两者都没有时才使用内容边界加 padding。下半部分的 `width` / `height` 只控制页面显示尺寸，不参与内部坐标计算。

<ComponentPreview files="layout-viewbox-resolution" size="sm" hideCode />

图形被裁或留白过多时，先看 **View Code → IR**：显式 viewBox 可能小于可见图元，自动模式则可能被远离主体的可见边界拉大。只有 coordinate 而没有可见边界时，它不会单独扩展自动范围。

### 高级宿主策略

普通页面直接使用 `renderer`、`animate` 与 `snapshotAt` 即可。编辑器、测试工具等宿主需要统一控制整棵子树时，才使用 Provider；图把 renderer 的“缺省时回退”与动画的“宿主策略覆盖”分开。

<ComponentPreview files="layout-runtime-priority" size="md" hideCode />

渲染 Provider 只补充缺省的 renderer，后代显式 prop 仍可覆盖；动画 Provider 则用于宿主统一控制整棵树，会覆盖后代 `animate`，其中 `system` 直接跟随系统偏好。`snapshotAt` 不参与这条回退链：一旦传入，SVG 与 Canvas 都直接输出指定时刻的静态帧。

## API 参考

### 输入与视框

| 属性       | 类型                 | 默认值 | 描述                                         |
| ---------- | -------------------- | ------ | -------------------------------------------- |
| `children` | `ReactNode`          | —      | Kernel / Sugar 组件树；未传 `ir` 时使用      |
| `ir`       | `IRScene`            | —      | 已构造的 Core IR；同时传 children 时采用本项 |
| `width`    | `number` \| `string` | —      | SVG / Canvas 在页面上的显示宽度              |
| `height`   | `number` \| `string` | —      | SVG / Canvas 在页面上的显示高度              |
| `viewBox`  | `IRViewBox`          | —      | 内部坐标范围；覆盖 IR viewBox 与自动范围     |

### 编译基础

这些 props 统一进入 `CompileOptions`；具体 definition 的定义、注册与错误契约见对应自定义指南。

| 属性           | 类型                                                         | 默认值 | 描述                                                                    |
| -------------- | ------------------------------------------------------------ | ------ | ----------------------------------------------------------------------- |
| `nodeDistance` | `number`                                                     | `24`   | 相对定位默认距离；节点自带值优先                                        |
| `fontSize`     | `number`                                                     | `16`   | 默认字号，也是 preset 与 `rem` 的根字号                                 |
| `artifacts`    | `CompileArtifactOptions`                                     | `{}`   | 请求 opt-in 产物；`nodeLayouts:true` 返回 `CompiledNodeLayout` 布局快照 |
| `onArtifacts`  | `(artifacts:`<br />`ReadonlyArray<CompileArtifact>) => void` | —      | React commit 后通知同次 compile 的 immutable artifacts                  |

### 图元与资源注入

| 属性         | 类型                                        | 默认值 | 描述                                                                  |
| ------------ | ------------------------------------------- | ------ | --------------------------------------------------------------------- |
| `shapes`     | `ReadonlyArray`<br />`<ShapeDefinition>`    | —      | 注入形状；见[自定义形状](/kernel/components/shapes/custom-shape)      |
| `boundaries` | `ReadonlyArray`<br />`<BoundaryDefinition>` | —      | 注入连接面；见[自定义连接面](/kernel/components/node/custom-boundary) |
| `clips`      | `ReadonlyArray`<br />`<ClipDefinition>`     | —      | 注入裁剪区；见[自定义裁剪区](/kernel/components/layout/custom-clip)   |
| `arrows`     | `ReadonlyArray`<br />`<ArrowDefinition>`    | —      | 注入箭头；见[自定义箭头](/kernel/components/draw/custom-arrow)        |
| `patterns`   | `ReadonlyArray`<br />`<PatternDefinition>`  | —      | 注入图案；见[自定义图案](/kernel/components/effects/custom-pattern)   |

### 高级能力与宿主接入

| 属性                  | 类型                                                  | 默认值 | 描述                                                                                   |
| --------------------- | ----------------------------------------------------- | ------ | -------------------------------------------------------------------------------------- |
| `pathGenerators`      | `ReadonlyArray`<br />`<PathGeneratorDefinition>`      | —      | 注入路径生成器；见[路径生成器](/kernel/components/draw/path-generator)                 |
| `pathKinds`           | `ReadonlyArray`<br />`<PathKindDefinition>`           | —      | 注入 Path kind；见[自定义路径](/kernel/components/draw/custom-path)                    |
| `ribbonWidthProfiles` | `ReadonlyArray`<br />`<RibbonWidthProfileDefinition>` | —      | 注入 ribbon 宽度曲线；见[编译选项](/kernel/reference/runtime/compile)                  |
| `composites`          | `ReadonlyArray`<br />`<AnyCompositeDefinition>`       | —      | 注入 Tier 2 expand / layout-aware compile；见[复合](/kernel/concepts/design/composite) |
| `lowerTex`            | `LowerTex`                                            | —      | 注入公式 lowering；见[TeX 公式](/kernel/packages/tex)                                  |
| `embeddables`         | `Array`<br />`<EmbeddableTier2Adapter>`               | —      | 显式注入 Tier 2 adapter；主路径使用组件静态标记                                        |

### 全图默认值

这些属性复用 [`<Scope>`](/kernel/components/layout/scope) 的级联契约，不是另一套样式系统。children 模式下有值才合成根 Scope；直接传 `ir` 时忽略并在开发环境提示。

| 属性                                                                                      | 类型         | 默认值 | 描述                               |
| ----------------------------------------------------------------------------------------- | ------------ | ------ | ---------------------------------- |
| `color` / `stroke` / `fill` / `strokeWidth` / `opacity` / `fillOpacity` / `strokeOpacity` | 同 `<Scope>` | —      | 全图 graphic state 默认值          |
| `nodeDefault` / `pathDefault` / `labelDefault` / `arrowDefault`                           | 同 `<Scope>` | —      | node / path / label / arrow 默认值 |

### 渲染与宿主

| 属性        | 类型                      | 默认值  | 描述                                                                        |
| ----------- | ------------------------- | ------- | --------------------------------------------------------------------------- |
| `renderer`  | `'svg'` \| `'canvas'`     | `'svg'` | 输出后端；缺省时读取最近的 `RendererModeProvider`                           |
| `className` | `string`                  | —       | 透传到 SVG / Canvas 根元素                                                  |
| `style`     | `CSSProperties`           | —       | 透传到 SVG / Canvas 根元素                                                  |
| `idPrefix`  | `string`                  | —       | 覆盖资源 id 前缀，用于多实例或 SSR 水合稳定性                               |
| `handlers`  | `LayoutProps['handlers']` | —       | `ir` 模式的事件 handler 注册表；见[水合](/kernel/packages/render/hydration) |
| `runtime`   | `LayoutRuntimeOptions`    | `{}`    | retained renderer factory 与 Runtime diagnostic 出口                        |

`runtime.rendererFactory` 可注入实现同一 retained renderer contract 的第三方后端；省略时使用内置 SVG / Canvas factory。`runtime.onDiagnostic` 按 Runtime queue 顺序接收成功提交和失败 transaction 的诊断；callback 自身抛错会被隔离，不改变 Runtime 的提交或失败结果。

### React 宿主导出

- `RendererModeProvider` / `RendererModeProviderProps`：用 `mode: 'svg' | 'canvas'` 给子树提供缺省 renderer；`useRendererMode` 读取最近值，`RendererModeContext` 留给自定义桥接
- `AnimationModeProvider` / `AnimationModeProviderProps`：用 `mode: 'system' | 'enabled' | 'disabled'` 统一控制子树动画；`useAnimationMode` 读取最近值，`AnimationModeContext` 留给自定义桥接
- `collectHydrationHandlers(children, embeddables?)`：按元素 `id` 收集 `on<Event>`；普通 `<Layout>` children 模式会自动调用，仅自定义水合宿主需要直接使用

### 动画

| 属性                  | 类型                                 | 默认值 | 描述                                                                    |
| --------------------- | ------------------------------------ | ------ | ----------------------------------------------------------------------- |
| `animate`             | `boolean`                            | 系统   | 播放开关；见[动画](/kernel/components/effects/animation)                |
| `snapshotAt`          | `number`                             | —      | 静态截帧时刻，覆盖 `animate`                                            |
| `animations`          | `Array<IRAnimationTrack>`            | —      | scene 根动画 tracks，例如 viewBox 镜头动画                              |
| `animationRef`        | `LayoutProps['animationRef']`        | —      | `play` / `pause` / `seek` 命令式句柄                                    |
| `easings`             | `LayoutProps['easings']`             | —      | 自定义缓动；见[自定义动画](/kernel/components/effects/custom-animation) |
| `animationProperties` | `LayoutProps['animationProperties']` | —      | 自定义动画属性插值器；当前仅 Canvas                                     |
