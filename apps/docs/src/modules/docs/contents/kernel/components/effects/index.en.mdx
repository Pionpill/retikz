---
title: Effects
description: Add shadows, blending, patterns, and animation to existing primitives, with custom extensions collected at the end.
---

Effects attach to existing primitives such as Node and Path. Shadows add visual depth, blend modes control layer composition, patterns provide reusable fills, and animation describes how properties change over time. They keep the same primitive model; start with the built-ins, then use the final pages to register custom patterns or animation behavior.

## Responsibilities

| Capability       | Responsibility                               | Use it when                                |
| ---------------- | -------------------------------------------- | ------------------------------------------ |
| Shadow           | Add offset, blur, and color                  | Showing depth or spatial hierarchy         |
| Blend            | Control color composition with layers        | Creating overlays and highlights           |
| Animation        | Describe tracks, triggers, and playback      | Adding entrances or interaction feedback   |
| Custom Patterns  | Register new pattern motifs                  | Stripes, crosses, or domain-specific fills |
| Custom Animation | Register easing curves and property channels | Spring, blur, or other custom behavior     |
