Effects attach to existing primitives such as Node and Path. Shadows add depth, blending controls how layers combine, patterns provide reusable fills, and animation describes properties changing over time. They keep the same primitive model.

Start with shadows, blending, animation, and patterns for everyday work. Use the final extension guides only when built-in patterns or animation channels cannot express the result you need.

In the figure, solid arrows follow primitives through compile, the Scene, and the renderer. The dashed arrows mark different injection stages: pattern definitions produce Scene resources during compile, while easing and property registries consume Scene tracks during rendering.

## Responsibilities

| Capability       | Type            | Responsibility               | Use it when                 |
| ---------------- | --------------- | ---------------------------- | --------------------------- |
| Shadow           | Shared prop     | Add a drop shadow            | Showing depth or elevation  |
| Blend            | Shared prop     | Compose with painted content | Creating overlays           |
| Animation        | Track model     | Describe tracks and playback | Adding motion or feedback   |
| Patterns         | Fill spec       | Reuse lines, dots, or grids  | Distinguishing regions      |
| Custom Patterns  | Extension guide | Register repeating fills     | Built-ins cannot express it |
| Custom Animation | Extension guide | Register easing or channels  | Built-ins cannot express it |
