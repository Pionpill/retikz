---
title: Effects
description: Add shadows, blend modes, and animation to existing primitives without changing their structure or relationships.
---

Effects attach to existing primitives such as Node and Path. Shadows add visual depth, blend modes control layer composition, and animation describes how properties change over time. They reuse the same IR and Scene instead of introducing another primitive model.

## Responsibilities

| Capability | Responsibility                          | Use it when                              |
| ---------- | --------------------------------------- | ---------------------------------------- |
| Shadow     | Add offset, blur, and color             | Showing depth or spatial hierarchy       |
| Blend      | Control color composition with layers   | Creating overlays and highlights         |
| Animation  | Describe tracks, triggers, and playback | Adding entrances or interaction feedback |
