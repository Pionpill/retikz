### WayItem

<p>
  <ApiSourceLink label={'WayItem'} path={'packages/kernel/core/src/parse/way.ts'} startLine={123}>
    Sugar 层 way 数组 DSL 元素
  </ApiSourceLink>
</p>

节点 id 字符串/笛卡尔/极坐标 → line（首项 move）；`{position,type}` 相对偏移对象 → IR relative/relativeAccumulate；horizontalTo/verticalTo → axis-line；四种裸 via 或 `{via,fraction}` 与下一项合并 fold；DrawWay.Cycle → cycle；curve/cubic/bend infix 与下一项合并；arc/circle/ellipse infix 以上一项为圆心不消耗下一项。Cycle/Relative/Accumulate 底层字符串刻意写丑避节点 id 撞结构

```ts
export type WayItem =
  | IRTarget
  | string
  | WayRelativeItem
  | WayVia
  | WayFoldOp
  | WayCycle
  | WayCurveOp
  | WayCubicOp
  | WayBendOp
  | WayArcOp
  | WayCircleOp
  | WayEllipseOp
  | WayLabelOp
  | WayAxisLineOp;
```

### DrawWay

<p>
  <ApiSourceLink label={'DrawWay'} path={'packages/kernel/core/src/parse/way.ts'} startLine={33}>
    Sugar 层 way 数组的关键字常量
  </ApiSourceLink>
</p>

Cycle 闭合到 way 起点（底层字符串故意写丑避节点 id 冲突，只通过 DrawWay.Cycle 引用）；Hv/Vh/Hvh/Vhv 是两段或三段折角算子；Relative/Accumulate 相对偏移 way item 的 type 鉴别值（Relative=TikZ `(+x,+y)` 不推进 prevEnd，Accumulate=TikZ `(++x,++y)` 累积更新）。用 const + as const 而非 TS enum 避免 reverse-mapping 与字面量不互通

```ts
export const DrawWay = {
  Cycle: 'retikz-keyword_cycle',
  Hv: '-|',
  Vh: '|-',
  Hvh: '-|-',
  Vhv: '|-|',
  Relative: 'retikz-keyword_relative',
  Accumulate: 'retikz-keyword_accumulate',
} as const;
```
