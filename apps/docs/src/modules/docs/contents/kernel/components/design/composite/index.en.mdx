A composite represents several basic primitives as one meaningful object. Saving bar-chart data, for example, makes later edits easier than saving dozens of rectangles. Kernel primitives form Tier 1; higher-level objects form Tier 2. During compilation, those objects become primitives that share the same layout and rendering capabilities.

For example, a bar chart saves the data `[4, 7]` in a high-level node (Tier 2). Expansion produces two rectangular Nodes (Tier 1). Converting a high-level declaration into primitives is called lowering; compilation then produces Scene for SVG / Canvas rendering. The savable drawing declaration is called IR.

## Why composites exist

Saving dozens of rectangles and lines loses the higher-level fact that the result is a chart or a tree. A composite preserves domain fields in serializable IR, then delays concrete geometry until compilation:

The `lower` edge in the figure is the key boundary. Upstream systems can store, transfer, diff, or generate a high-level node; downstream systems receive uniform Tier 1 output, so every renderer shares one canonical Core compile result.

A capability usually belongs in a composite when all three are true:

- one high-level node generates a data- or algorithm-dependent number of Tier 1 primitives;
- the domain schema expresses user intent better than expanded geometry;
- React, Vanilla, SVG, Canvas, and other entries should share the same result.

## Compared with Sugar

|         | Sugar (such as `<Draw>`)  | Tier 2 composite                                            |
| ------- | ------------------------- | ----------------------------------------------------------- |
| In IR   | Already flattened         | Preserves the high-level node                               |
| Lowered | During adapter building   | During core compilation                                     |
| For     | Directly mapped shorthand | Structural generation or content-aware layout / aggregation |

## Choose an expansion strategy

Use `expand` when data can directly generate primitives. Use `compile` when children must be measured before space is assigned. These are mutually exclusive callbacks in a composite definition, not two steps for users to call in sequence. Ordinary users call the domain component; extension authors implement the callback.
