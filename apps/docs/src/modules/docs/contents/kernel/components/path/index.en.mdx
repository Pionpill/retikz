---
title: Drawing
description: Connect with Draw or control paths with Path and Step, sharing arrows and labels
---

Drawing connects positions into lines, curves, or closed outlines. Use `<Draw way>` for everyday connections. Choose `<Path>` and `<Step>` for multiple subpaths, explicit actions, or whole-path transforms. Both use the same path semantics and can produce arrows and labels alongside the path.

## See how the parts fit

The diagram shows how way shorthand reaches Path through Draw. Explicit Steps describe individual actions; arrow and label add direction and text. Arrows indicate inputs or configuration contributing to the path.

<ComponentPreview files="draw-anatomy" size="xs" hideCode type="flow" />

The Draw `way` value is convenient authoring input, not a separate persistent element. Store a graph as Path and Step IR without retaining React components. Explicit Step control does not require compiler knowledge.

## Responsibilities at a glance

| Member                | Responsibility                                   | When to read                           |
| --------------------- | ------------------------------------------------ | -------------------------------------- |
| Draw and way          | Describe a route compactly                       | Everyday connections                   |
| Path and Step         | Compose paths from individual actions            | Moves, closure, or precise control     |
| Arrows and labels     | Express direction and relationship names         | Annotating a path                      |
| Three extension types | Add segments, whole-path output, or arrow shapes | Built-in capabilities are insufficient |

## Choosing an entry and its boundaries

Read Basic usage first, then choose syntax, composition, arrows, or labels for your task. `way` describes a route compactly; Step specifies actions explicitly. Look up full contracts in the API and Schema references.

[Nodes](/kernel/components/node) own shape and positioning; [Scope](/kernel/components/scope) owns group transforms and clipping. Use [Extension Ribbon](/library/extension/ribbon) for variable-width bands and domain components for automatic layout.

Changing color, width, or an existing arrow requires no extension. A generator adds a segment, a custom path changes whole-path output, and a custom arrow adds endpoint geometry. Each tutorial covers definition, registration, and use; internal processing is explained separately.
