---
title: Scope
description: Scope 是 Kernel 的局部上下文容器：让一组图元共享坐标变换、样式默认、命名空间、整体引用和裁剪，但不负责绘制或自动布局。
---

`<Scope>` 把一组 children 放进同一个局部上下文。它不画新的图元，也不替你计算 plot / table 布局；它只管理这组内容怎样变换、怎样按自身包络定位、怎样被引用，以及怎样进入 Scene。

把 Scope 当作「子图边界」：只有一组内容确实需要共享几何或运行时语义时才使用。单纯为了整理 JSX，请拆普通 React 组件。

## 用法

```tsx
import { Scope } from '@retikz/react';
```

```tsx
<Scope id="cluster" transforms={[{ kind: 'translate', x: 80, y: 0 }]}>
  {/* Node / Path / Coordinate / nested Scope */}
</Scope>
```

### 何时使用

| 任务               | 使用入口               | Scope 的边界             |
| ------------------ | ---------------------- | ------------------------ |
| 整体变换一个子图   | `transforms`           | 不计算子元素原始位置     |
| 按自身锚点对齐子图 | `placement`            | 只引用此前完成的目标     |
| 从外部引用整组     | `id` + `boundingShape` | 不把 path 走线计入包络   |
| 隔离可复用子图 id  | `localNamespace`       | `scope.id` 仍注册到外层  |
| 统一默认值         | `color` / `*Default`   | 元素显式值仍然优先       |
| 限制可见区域       | `clip`                 | 不定义 renderer 专属语义 |
| 调整整组栈序       | `zIndex`               | 不重排组内 children      |

### 变换输入

五种平移写法与 Node 的相对定位模型一致；`rotate` 与 `scale` 负责局部坐标系的方向和尺度。数组顺序沿用 SVG transform list：最后一项先作用到局部点。

| kind                | 核心字段                       | 作用                          |
| ------------------- | ------------------------------ | ----------------------------- |
| `translate`         | `x`, `y`                       | 固定笛卡尔平移                |
| `polar-translate`   | `origin?`, `angle`, `radius`   | 从原点或 referent 极坐标落点  |
| `at-translate`      | `direction`, `of`, `distance?` | 落到 referent 的某个方向      |
| `offset-translate`  | `of`, `offset?`                | 在 referent 上叠加局部偏移    |
| `between-translate` | `between`, `fraction`          | 落到两个端点的比例位置        |
| `rotate`            | `degrees`, `pivot?`            | 绕 Scope 自身点旋转           |
| `scale`             | `x`, `y?`, `pivot?`            | 绕 Scope 自身点等比或分轴缩放 |

## 例子

### 局部坐标

`O` / `T` 是 Scope 外的固定参照点，`q` 提供 Scope 的固有包络。面板选择七种 transform 之一，并可在任意模式下独立开关 `placement`；`placement` 不是 transform kind，而是 transforms 完成后的最外层定位。

<ComponentPreview
  files="scope-translate-basic"
  size="sm"
  caption="正方形 q 是唯一包络主体，小圆点只标记局部原点。“自身定位”默认关闭；开启后可在 O / T 间切换定位目标，selfAnchor 会把方形的对应锚点锁定到该目标。此时五种纯平移 transform 的位移会被最终定位抵消，因此面板隐藏无效的 transform 引用点。"
/>

`placement.target` 只接受父坐标系 `[x, y]` 或此前完成的 `{ id, anchor?, offset? }`；`selfAnchor` 缺省为 `center`，也可写标准 anchor、数字角度、`{ side, fraction }`、`origin` 或显式局部坐标。

`rotate.pivot` 与 `scale.pivot` 使用同一套自身点并缺省为 `origin`。pivot 只读取 placement 之前的固有包络，因此移动 Scope 不会反过来改变旋转或缩放中心。其它相对方向仍在当前局部坐标系中解释，Scope 旋转后，`right` 的视觉方向会随坐标轴旋转。

<ComponentAlert
  type="warn"
  title="v0.5 rotate 写法迁移"
  description="IR Scope transform 不再接受 rotate.cx / rotate.cy；请改成 pivot: [cx, cy]。Scene Transform 的 cx / cy 仍是 Core lowering 输出，不受影响。"
/>

### 整体引用与命名空间

设置 `id` 后，Scope 会根据 children 的包围盒生成一个可引用的整体目标。用面板切换 `boundingShape` 与连接 anchor，观察边界形状和连接落点如何独立变化；children 本身不会改变。

<ComponentPreview files="scope-id-reference" size="sm" />

`localNamespace` 只在确实要复用带固定 id 的子图时使用。面板默认让内外 Node 同为 `A`；关闭隔离时外部箭头会改连内部 Node，把内部 id 改成 `B` 可消除冲突。

<ComponentPreview files="scope-local-namespace-basic" size="sm" />

### 裁剪与层级

`clip` 使用 Scope 局部坐标，并把裁剪结果作为渲染无关的 Scene 资源交给下游。用面板切换六种内置裁剪区；内置类型不够时再注册[自定义裁剪区](/kernel/components/layout/custom-clip)。

<ComponentPreview files="scope-clip" size="xs" previewClassName="!p-3 !pt-[52px]" />

`zIndex` 调整整个 Scope 在父层的栈序，不会重排 Scope 内部 children。用面板分别修改四个 Node 与两个 Scope，比较组内排序和整组排序。

<ComponentPreview files="scope-z-index" size="sm" />

### 样式默认值

Scope 同时提供 `color`、共享 graphic state 与 `nodeDefault` / `pathDefault` / `labelDefault` / `arrowDefault`。这些值逐字段向内继承，元素显式值优先；`resetStyle` 只切断指定通道的外层继承。

样式是 Scope 的辅助职责，不改变局部坐标、引用或裁剪语义。需要查字段时直接看下方 API，不必为颜色、线宽或透明度建立额外 Scope。

<ComponentAlert
  type="tip"
  title="共享默认值也能缩小配置"
  description="把真正共享的局部样式写在 Scope 上，可以避免为每个 child 重复同一组字段，通常能显著减小配置对象和持久化 JSON。Plot 等 Tier 2 包也常在 lowering 时把系列或图层样式集中为 Scope 默认值，以压缩生成 IR 的体积。"
/>

## 技术原理

<ComponentAlert type="tip" title="上手阶段可跳过本节" description="遇到变换投影、id 冲突、包络或裁剪边界时再回来读。" />

本节只解释用户能观察到的 Scope 机制；完整 JSX → IR → Scene 管线见[架构](/kernel/concepts/design/principles)。

### 变换与相对定位

Scope 先完成 children 的固有局部布局和 rectangle / circle 包络，再在该包络上解析 pivot、lower transforms，最后计算 `placement` 的最外层平移。数组第 0 项最外层、最后一项先作用；placement 会插到第 0 项，成为最后作用的变换。

<ComponentPreview files="scope-coordinate-flow" size="sm" hideCode />

不依赖包络的既有 transform 仍保持「全局 referent → 反投影到局部 → 叠加 relative → 投影回全局」语义；anchor pivot 则在固有包络完成后解析。最终同一条 chain 同时驱动 Group、namespace、layout observer 与自动 viewBox，children 不重复应用 own transform。

zero scale 作为纯视觉变换合法；需要跨该 chain 反投影目标时会同步抛出 `non-invertible scope transform`。Scope placement 的 NodeTarget 只能引用遍历到当前位置以前已完成的 Node、Coordinate 或 Scope；forward、self、descendant 和未闭合 Scope placeholder 都会 fail-loud。

### 命名空间与 id 冲突

默认 Scope 复用当前 namespace frame。`localNamespace` 才会新增 frame；lookup 从内向外返回第一个命中，register 只写当前 frame。

<ComponentPreview files="scope-namespace-resolution" size="md" hideCode />

因此跨 frame 同名是合法 shadowing；同一 frame 重复 id 会发出 `DUPLICATE_NODE_ID` 警告，并采用后定义。`scope.id` 在子 frame 入栈前注册到父 frame，所以外部始终能引用 Scope 整体。

### 整体句柄与 Scene 输出

`scope.id` 与 `clip` 是两条独立链路：前者把子树 layout 汇总成可引用句柄，后者把 JSON clip spec 解析成 Scene 资源。两者都在 Core 编译边界结束。

<ComponentPreview files="scope-boundary-clip" size="sm" hideCode />

Scope 包络只收集 node、coordinate 与嵌套 Scope layout，不包含 path 走线。默认结果是全局 AABB；圆形模式使用最小外接圆。子树有输出，或 Scope 带 `transforms` / `id` / `clip` 时才生成 `GroupPrim`；空且无这些语义的 Scope 会被剪枝。

## API 参考

### 上下文与输出

| 属性             | 类型                                    | 默认值        | 描述                                                                                    |
| ---------------- | --------------------------------------- | ------------- | --------------------------------------------------------------------------------------- |
| `children`       | `ReactNode`                             | —             | Node / Path / Coordinate / 嵌套 Scope                                                   |
| `transforms`     | `Array<IRTransformInput>`               | —             | 七种局部变换；数组最后一项先作用                                                        |
| `placement`      | `IRScopePlacement`                      | —             | 把 transforms 后的 `selfAnchor`（缺省 center）对齐父坐标系 target                       |
| `id`             | `string`                                | —             | 把 Scope 包络注册成外部可引用句柄                                                       |
| `localNamespace` | `boolean`                               | `false`       | 隔离内部 id；`scope.id` 仍对外可见                                                      |
| `boundingShape`  | <ApiValues name="ScopeBoundingShape" /> | `'rectangle'` | `scope.id` 的矩形或圆形包络                                                             |
| `clip`           | `IRClipSpec`                            | —             | Scope 局部坐标中的内置或自定义裁剪区                                                    |
| `zIndex`         | `number`（整数）                        | `0`           | Scope 整体在父层的稳定栈序                                                              |
| `meta`           | `Record<string, JSON 值>`               | —             | 透传到 GroupPrim，不参与布局或继承                                                      |
| `animations`     | `Array<IRAnimationTrack>`               | —             | Scope 整体动画，不下传 children                                                         |
| `on<Event>`      | `ScopeProps['onClick']`                 | —             | 与 `onClick` 同签名；需要 `id`，完整事件列表见[水合](/kernel/packages/render/hydration) |

### 样式默认值

| 属性                                                            | 类型                               | 默认值  | 描述                              |
| --------------------------------------------------------------- | ---------------------------------- | ------- | --------------------------------- |
| `color`                                                         | `string`                           | —       | 跨元素级联的主色                  |
| `stroke` / `fill`                                               | `string` \| `IRPaintSpec`          | —       | 跨元素逐字段级联的描边与填充      |
| `strokeWidth` / opacity 字段                                    | `number`                           | —       | 线宽与逐字段级联的透明度          |
| `nodeDefault` / `pathDefault` / `labelDefault` / `arrowDefault` | 对应默认值对象                     | —       | 四类元素各自独立的默认通道        |
| `resetStyle`                                                    | `boolean` \| `Array<StyleChannel>` | `false` | 全部或按通道切断外层 Scope 的继承 |
