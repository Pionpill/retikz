## 用法

```tsx
import { Scope } from '@retikz/react';
```

```tsx
<Scope transforms={[{ kind: 'translate', x: 50, y: 0 }]}>{/* Node / Path / Coordinate / 嵌套 Scope */}</Scope>
```

scope 子树产出任何 primitive，或带有 `transforms` / `id` / `clip` 之一 → 发 `GroupPrim`；否则（子树无产物且无这三项）被剪枝，不发任何 Scene primitive，不留空容器开销。仅给样式默认 / `meta` 而子树无产物的 scope 同样会被剪掉。

### 何时用 Scope

设计上有"分组"概念时——一组节点 / path 在意图上属于同一个子图，需要作为整体应用 transform，或需要让外层通过 `scope.id` 把它们当作一个单元引用 / 定位。

第一次读 Scope，先抓住三件事：

| 目标                           | 用法                                                                      |
| ------------------------------ | ------------------------------------------------------------------------- |
| 整体移动 / 旋转 / 缩放一组图元 | `transforms`                                                              |
| 给一组图元统一默认样式         | `color` / `nodeDefault` / `pathDefault` / `labelDefault` / `arrowDefault` |
| 让外部连到整组图元边界         | `id`                                                                      |

## 组合

`<Scope>` 的 children 可以是 `<Node>`、`<Coordinate>`、`<Path>` 或嵌套 `<Scope>`。Scope 自己不画形状；当子树产出任何 primitive，或带有 `transforms` / `id` / `clip` 之一时，才在 Scene 里形成一个 group（仅有样式默认 / `meta` 而无子产物的 scope 会被剪掉）。

把 Scope 当成“子图容器”而不是“普通 div”：它适合承载几何关系、局部坐标和整组引用；如果只是想让 JSX 更好看，优先用普通 React 组件拆分代码。

### transforms 7 变体

5 个 translate 变体一一镜像 `<Node position>` 的 5 种形态（笛卡尔 / 极坐标 / 方向相对 / 偏移 / 两端点比例）。

| kind                | 字段                           | 语义                                                                                           |
| ------------------- | ------------------------------ | ---------------------------------------------------------------------------------------------- |
| `translate`         | `{ x, y }`                     | 笛卡尔平移，user units                                                                         |
| `polar-translate`   | `{ origin?, angle, radius }`   | 极坐标平移，`origin` 为 `id` / `[x,y]` / `PolarPosition`，缺省 = 原点                          |
| `at-translate`      | `{ direction, of, distance? }` | 落到 referent 节点的某方向 distance 处，`distance` 缺省走 `<Layout nodeDistance>`              |
| `offset-translate`  | `{ of, offset? }`              | scope 原点 = referent 全局坐标 + `[dx, dy]`，`offset` 缺省 = `[0, 0]`                          |
| `between-translate` | `{ between, fraction }`        | scope 原点 = 两个端点按 `fraction` 插值的位置，端点支持坐标 / 节点引用 / offset / 嵌套 between |
| `rotate`            | `{ degrees, cx?, cy? }`        | 旋转 degrees 度，`cx/cy` 缺省 = scope 局部原点                                                 |
| `scale`             | `{ x, y? }`                    | 缩放，`y` 缺省 = `x`（等比）                                                                   |

数组顺序应用——第 0 个是最外层（最后作用到局部点），最后一个是最内层（最先作用），与 SVG transform list 语义一致。`transforms: [translate, rotate]` 等价 SVG `transform="translate(...) rotate(...)"`：rotate 先作用、translate 后作用；compile 展平 / 下沉细节见[技术原理：变换与相对定位如何落到全局](#变换与相对定位如何落到全局)。

<Comparison target="tikz" title="Scope 对照">

`<Scope transforms={[{ kind: 'translate', x: 50, y: 0 }]}>...</Scope>` 对应 TikZ 的 `\begin{scope}[shift={(50,0)}] ... \end{scope}`：在子图开始处压一层局部 transform，结束时弹出。TikZ 多个 option 写一起按出现顺序叠加 CM；retikz `transforms` 数组按 index 顺序应用，复用 SVG / Scene 约定。

</Comparison>

#### Recipe：轨道 + 自转朝向中心

单 `polar-translate` 只平移 scope 原点、**不旋转**坐标系——动画过程 scope 内容朝向恒定，"像沿圆轨自由飘浮的卫星"。要让 scope 自身随轨道角度旋转（"潮汐锁定"，前方始终对准圆心），chain 一个 `rotate(angle + 180)`：

<ComponentPreview files="scope-orbit-facing-hub" size="md" />

chain 应用顺序：数组 `[t0, t1]` 里 `t1` 先生效（innermost），所以先 `rotate` 把局部 +x 转到指向 hub 的方向，再 `polar-translate` 推到轨道位置。`+ 180` 让 scope 的 +x 从"指外"翻转到"指 hub"；想让 +x 指外（前方背离圆心），去掉 `+ 180` 即可。

### 样式继承

Scope 兼作样式默认值挂点，给内部元素提供三组样式表面：**主色 `color`** + 跨类共享分项级联到全部元素；**四类默认** `nodeDefault` / `pathDefault` / `labelDefault` / `arrowDefault` 按元素类型分发、扁平独立；**`resetStyle`** 切外层继承。

#### 主色级联

`<Scope color>` 把当前色下传给内部全部元素——节点边 / 文字、path stroke / 箭头 / 边标注都默认随它；分项（`stroke` / `fill` / `textColor`）显式给则覆盖主色：

<ComponentPreview files="scope-style-cascade" size="xs" />

主色同样会染节点 `fill`；上例锚点节点显式 `fill="white"` 截断填充让文字可读。颜色跟随的是**主色 `color`** 而非 `stroke`——`<Path color>` 标注 / 箭头同色，`<Path stroke>` 只染线、标注不跟。

#### 分类默认

`nodeDefault` / `pathDefault` / `labelDefault` / `arrowDefault` 各给一类元素挂默认样式，扁平独立、互不干涉。`nodeDefault` 含形状 / 间距等节点专属字段（直接写 `color` 染不到 `shape`，得走 `nodeDefault`）；`pathDefault` 会作用到 Path，也会把共享几何样式字段传给 Ribbon；箭头走独立 `arrowDefault`，`pathDefault` 不含箭头：

<ComponentPreview files="scope-style-typed-defaults" size="xs" />

#### resetStyle 继承屏障

`resetStyle` 切外层 scope 的继承（主色级联 + 四类默认），回内置基线；本 scope 自己的值 + 内层照常生效。`true` 全切，或传通道数组（`['node' | 'path' | 'label' | 'arrow']`）按类切：

<ComponentPreview files="scope-style-reset" size="xs" />

`resetStyle` 只切 scope 的继承、**不碰元素与宿主的结构关系**——label / arrow 仍跟所属 path / node 的已解析颜色：`resetStyle={['label']}` 只忽略外层 `labelDefault`、label 仍跟它的线。逐字段优先级、按存在性回退与继承屏障见[技术原理：样式如何逐字段解析](#样式如何逐字段解析)。

<Comparison target="tikz" title="样式继承对照">

主色 `color` 对应 TikZ 的 `color=`（设当前色，draw / fill / text 跟随）；`nodeDefault` / `pathDefault` / `labelDefault` / `arrowDefault` 对应 `every node` / `every path` 等的 `.style`。差异：retikz 嵌套是 **per-field 合并**（≈ TikZ `.append style`），不是字面 `.style=` 整体替换。

### scope 边界多态

`boundingShape` 让 scope.id 句柄按指定形状取包络，而非默认的轴对齐矩形（AABB）。缺省 / `'rectangle'` 逐字不变；`'circle'` 取子树点集的**最小外接圆**——`cluster.<anchor>` / `cluster.<deg>` 与连线端点都落在**圆周**上，适合圆形 / polar 面板的连接：

<ComponentPreview files="scope-bounding-shape" size="sm" />

`boundingShape` 是受控枚举：只接受 `'rectangle'`（默认）与 `'circle'`，枚举外的值由 schema 在 parse 边界直接拒绝。`'polygon'` / `'ellipse'` 缓做（各需独立的最小外接算法）；这是有意设计为闭集，而非 Node `shape` / `boundary` 那种开放 shape 引用。

### clip 裁切

`<Scope clip={...}>` 把 scope 内所有子元素裁剪到一个区域内——区域内可见、区域外裁掉。内置裁剪区支持 `rect` / `circle` / `ellipse` / `polygon` / `path` / `compound`，也可以通过 [自定义裁剪区](/kernel/components/layout/custom-clip) 注册自己的 `kind`；坐标用 scope 局部坐标系：

```tsx
<Scope clip={{ kind: 'circle', cx: 0, cy: 0, r: 60 }}>{/* children */}</Scope>
```

图的上半部分把 7 种 IR transform 收敛为 renderer 可直接消费的 `translate` / `rotate` / `scale`，下半部分展示相对定位如何借同一条 scope chain 在全局与局部之间往返。

<ComponentPreview files="scope-coordinate-flow" size="sm" hideCode />

`transforms` 的列表顺序与 SVG 一致；相对定位则遵循 `全局 referent → 反投影到当前局部 → 叠加 relative → 正向投影回全局`。因此 rotate / scale 会改变 relative 的视觉方向或长度，单纯 translate 不会。

带 transform 的 scope 中，path 端点在 emit 前已经变成全局坐标，因此会 hoist 到顶层以避免 transform 二次应用。这也意味着它的跨 frame z-order 不能完全保留 IR 顺序，且不会被该 scope 的 clip 裁切。

### 命名空间与 id 冲突如何处理

`localNamespace` 决定是否新增 frame；lookup 永远从当前 frame 向外查找，只有当前候选未命中时才继续。register 则只写当前 frame，并在同 frame 重名时进入警告分支。

<ComponentPreview files="scope-namespace-resolution" size="md" hideCode />

默认 scope 不创建边界，子 id 会落入现有 frame。启用 `localNamespace` 后，内层仍能看到外层 id；同名 id 会 shadow 外层且不警告，frame 退出后外层 id 恢复可见。

同一 frame 内重复 id 会对每次覆盖发出 `DUPLICATE_NODE_ID`，compile 继续并采用后定义。`scope.id` 在子 frame 入栈前先注册到父 frame，所以它始终是外部可见的 scope 句柄。

### 样式如何逐字段解析

从左到右是单个样式字段的回退顺序：只有当前来源没有提供值时才继续向后。同一来源内，显式分项优先于该来源的 `color` 展开。

<ComponentPreview files="scope-style-resolution" size="xs" hideCode />

解析按字段存在性判断，因此显式 `none` / `0` / `false` 都会在当前层停止回退。`resetStyle` 只切断所选通道的外层 scope 继承；当前 scope、元素显式值和内置默认仍参与解析。

label 与 arrow 仍沿宿主轴取色：例如 reset arrow 默认后，箭头仍可跟随已解析的 path 主色，不会变成孤立样式。

### scope.id 边界与 clip 如何进入 Scene

上半行把 scope 子树变成可引用的 synthetic layout；下半行把 renderer-agnostic 的 clip IR 变成 Scene 资源与 group 引用。两条链都在 compile 边界结束，具体绘制交给 adapter。

<ComponentPreview files="scope-boundary-clip" size="xs" hideCode />

`scope.id` 只收集 node、coordinate 与嵌套 scope layout，不把 path 走线计入边界。默认用全局角点求轴对齐 AABB；`boundingShape="circle"` 改用最小外接圆；空 scope 退化为局部原点投影出的 0×0 句柄。

clip provider 先解析出 JSON 可序列化的 `ClipShape`，registry 再按 shape 去重并生成稳定 `clipRef`。SVG 会物化 `<clipPath>`，Canvas 使用同一份 Scene 资源执行裁切；前述 hoist path 不在 group children 内，因此不受该 group 的 clip 影响。

| `transforms` | `Array<Transform>`        | —      | 局部 transform 列表，7 变体；数组顺序应用（第 0 个最外层、最后一个最内层，同 SVG transform list）；展平 / 下沉细节见[技术原理：变换与相对定位如何落到全局](#变换与相对定位如何落到全局)    |
| `children`   | `ReactNode`               | —      | scope 内子元素：`<Node>` / `<Path>` / `<Coordinate>` / 嵌套 `<Scope>`                                                                                                                      |
| `meta`       | `Record<string, JSON 值>` | —      | provenance 元数据：原样透传进本 scope emit 的 `GroupPrim`，renderer 忽略、不参与布局、**不下传子元素**；典型由 plot 等高层 lowering 注入（标记 series / layer 层）。须为 JSON 可序列化对象 |
| `animations` | `Array<AnimationTrack>`   | —      | 作用于 scope 整体（其 GroupPrim）的时间轴动画 tracks；不下传子元素、不参与布局。见 [动画](/kernel/components/effects/animation)                                                            |

### 引用与定位

| 属性             | 类型      | 默认值  | 描述                                                                                                                                                                                                                                                                       |
| ---------------- | --------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `id`             | `string`  | —       | 可选 scope 引用 id；设值后 scope 子树全部 layout 的**轴对齐全局 bbox**注册为 synthetic rectangle layout 到**父 frame**；外部可用 `'X'` / `'X.<anchor>'` / `'X.<deg>'` 引用，包络计算见[技术原理：scope.id 边界与 clip 如何进入 Scene](#scopeid-边界与-clip-如何进入-scene) |
| `localNamespace` | `boolean` | `false` | 是否创建本地命名空间：`true` 时 scope 推一个子 frame，内部 id 与外部隔离；详见[技术原理：命名空间与 id 冲突如何处理](#命名空间与-id-冲突如何处理)                                                                                                                          |

`scope.id` 的包络计算与 `boundingShape` 见 [Scope 裁切](/kernel/components/layout/scope)。

### 边界与裁切

| 属性            | 类型                      | 默认值        | 描述                                                                                                                                                                                                                        |
