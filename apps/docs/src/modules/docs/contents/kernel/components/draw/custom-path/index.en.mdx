A custom Path kind extends **how the whole path is emitted**. IR stores only an open `kind` and JSON-safe `kindOptions`. After the host injects a `PathKindDefinition`, core resolves it from the shared registry and lets it produce Scene primitives.

The `highlight` kind below reuses the built-in stroke emitter and changes only line width and output color. Its definition, `<Layout pathKinds>` injection, and usage live in one runnable example.

## Applicability

First decide whether the extension owns one segment or the whole path:

| Need                                     | Choose                                                    |
| ---------------------------------------- | --------------------------------------------------------- |
| Add a parameterized curve segment        | [Path Generators](/kernel/components/draw/path-generator) |
| Change whole-Path primitives or outlines | Custom Path kind                                          |
| Add only a new endpoint shape            | [Custom Arrows](/kernel/components/draw/custom-arrow)     |

If you only need another stroke color, width, dash, arrow, or ribbon option, use the existing Path props instead of inventing a kind for a style preset.

## Define the capability

Use `definePathKind` to declare a Path schema with a non-empty `kind` literal, an optional options schema, and a compile function that owns the whole path.

```tsx
const highlight = definePathKind({
  schema: z.strictObject({ kind: z.literal('highlight') }),
  optionsSchema: z.strictObject({ strokeWidth: z.number().positive() }),
  compile: context =>
    context.emitStroke({
      ...context.path,
      strokeWidth: context.options.strokeWidth,
    }),
});
```

`schema.shape.kind.value` is the registry key. `kindOptions` passes through `optionsSchema` and remains JSON-safe. The definition and compile function are runtime capability and never enter IR.

### Optional Inspector

When this Path kind needs development-only auxiliary content, the Path-kind Definition declares only a schema-backed `ownerOutput`; an Inspector is defined and registered independently in `@retikz/inspect`. This example reuses standard stroke compilation, publishes final commands on demand, and returns an ordinary Node from the external Inspector.

```tsx
const InspectInputSchema = z.strictObject({ summary: z.boolean().optional() });
const InspectOptionsSchema = InspectInputSchema.transform(value => ({
  summary: value.summary ?? true,
}));

const highlightInspector = defineInspector({
  namespace: 'demo',
  name: 'highlight-summary',
  owner: { kind: 'pathKind', name: 'highlight' },
  subjectSchema: StrokePathOwnerOutputSchema,
  optionsInputSchema: InspectInputSchema,
  optionsSchema: InspectOptionsSchema,
  inspect: (subject: StrokePathOwnerOutput, context) =>
    context.options.summary
      ? {
          type: 'node',
          position: [0, 0],
          text: `${subject.commands.length} commands`,
          textColor: context.appearance.scopeColor,
        }
      : [],
});

const highlight = definePathKind({
  schema: z.strictObject({ kind: z.literal('highlight') }),
  ownerOutput: { schema: StrokePathOwnerOutputSchema },
  compile: context =>
    context.ownerOutput.requested
      ? context.emitStroke(context.path, { captureOwnerOutput: context.ownerOutput.publish })
      : context.emitStroke(context.path),
});

const registry = createInspectorRegistry([highlightInspector]);
```

`ownerOutput.requested` is true only when an observer selected this owner. A non-null result must publish exactly one schema-valid value, while a null result must publish none. The Inspector's `subjectSchema` validates the external agreement again, and `inspect()` returns `IRChild | ReadonlyArray<IRChild>` without an `outputSchema`. See [`@retikz/inspect`](/kernel/packages/extension/inspect) for registry, selection, and host wiring.

## Inject into the host

React injects definitions through `<Layout pathKinds>`; direct core calls use `CompileOptions.pathKinds`. A Path references only the registered name and instance options.

```tsx
<Layout pathKinds={[highlight]}>
  <Path kind="highlight" kindOptions={{ strokeWidth: 12 }}>
    <Step kind="move" to="A" />
    <Step kind="line" to="B" />
  </Path>
</Layout>
```

## Execution

Built-in `stroke`, `ribbon`, and custom kinds first merge into one registry. When compiling a Path, core resolves `kind`, validates `kindOptions`, and passes the provider both standard stroke and ribbon emitters.

A provider may create new Scene primitives directly, or call `emitStroke` / `emitRibbon` to reuse endpoint resolution, path commands, arrows, and ribbon logic. Returned `primitives` and `boundsPoints` use current Path-local coordinates; the outer Scope transform is applied afterward.

## Errors and limits

| Case                                           | Result                                                    |
| ---------------------------------------------- | --------------------------------------------------------- |
| Empty or non-string `kind` literal             | `definePathKind` rejects it immediately                   |
| Duplicate `stroke`, `ribbon`, or custom key    | Registry merge reports a duplicate registration           |
| Path references an unknown kind                | Compile lists available names and `options.pathKinds`     |
| `kindOptions` fails its schema                 | Error includes kind name and the relevant IR path         |
| Provider returns `null`                        | The Path produces no primitives                           |
| Selected non-null result omits owner output    | Core observation fails loudly                             |
| Owner output or Inspector subject fails schema | The corresponding validation stage fails loudly           |
| Inspector returns an invalid Core child        | Error includes owner, occurrence, and output index        |
| `boundsPoints` misses actual output bounds     | Auto layout and Path-level rotate/scale become inaccurate |

A custom kind must return renderer-neutral Scene primitives. It cannot embed SVG elements, Canvas instances, ReactNode values, or functions, and it cannot require renderers to understand the custom `kind`.

## API Reference

### PathKindDefinition

| Field           | Type                            | Default                 | Description                                     |
| --------------- | ------------------------------- | ----------------------- | ----------------------------------------------- |
| `schema`        | `PathKindDefinition['schema']`  | —                       | Declares Path shape and provides registry key   |
| `optionsSchema` | `ZodType<IRJsonObject>`         | Raw `kindOptions ?? {}` | Validates custom instance options               |
| `compile`       | `PathKindDefinition['compile']` | —                       | Emits whole-Path Scene primitives and bounds    |
| `ownerOutput`   | `CompileOwnerOutputDefinition`  | —                       | Declares an on-demand final owner-output schema |

### InspectorDefinition

| Field                | Type                             | Default | Description                                               |
| -------------------- | -------------------------------- | ------- | --------------------------------------------------------- |
| `namespace`          | `string`                         | —       | Forms an independent registry key with `name`             |
| `name`               | `string`                         | —       | Forms an independent registry key with `namespace`        |
| `owner`              | `CompileObservationOwner`        | —       | Targets the observed Path kind                            |
| `subjectSchema`      | `ZodType<JsonValue>`             | —       | Validates the owner-output agreement                      |
| `optionsInputSchema` | strict `ZodObject`               | —       | Validates sparse runtime input and must accept `{}`       |
| `optionsSchema`      | `ZodType<IRJsonObject>`          | —       | Resolves sparse input into complete JSON-safe options     |
| `inspect`            | `InspectorDefinition['inspect']` | —       | Returns one ordinary Core child or a dense readonly array |

### Compile context

| Field         | Type                                   | Default      | Description                                            |
| ------------- | -------------------------------------- | ------------ | ------------------------------------------------------ |
| `path`        | `IRPathBase`                           | —            | Complete IR for the current Path                       |
| `options`     | `TOptions`                             | —            | `kindOptions ?? {}` parsed by `optionsSchema`          |
| `ownerOutput` | `CompileOwnerOutputPublisher`          | —            | Publishes a schema-backed final owner output on demand |
| `emitStroke`  | `PathKindCompileContext['emitStroke']` | Current Path | Reuses standard stroke compilation                     |
| `emitRibbon`  | `PathKindCompileContext['emitRibbon']` | Current Path | Reuses standard ribbon compilation                     |

### PathKindCompileResult

| Field          | Type                    | Default | Description                                     |
| -------------- | ----------------------- | ------- | ----------------------------------------------- |
| `primitives`   | `Array<ScenePrimitive>` | —       | Actual output in current Path-local coordinates |
| `boundsPoints` | `Array<Position>`       | —       | Key points for auto layout and Path transforms  |
