A node is what the rest of a figure _references_: it has an id, a position, and a shape boundary, and connectors auto-attach to that boundary by id. This group gathers the node itself, its per-line text styling, placeholder points that draw nothing, and custom connection boundaries that are independent of visual shape.

<ComponentPreview files="node-family" size="md" hideCode />

## What each part does

| Component         | Type      | Responsibility                                                                   | Use it when                                                            |
| ----------------- | --------- | -------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| Node              | Kernel    | Named primitive with position / shape / text; paths attach to its boundary by id | Flowchart nodes, shapes with text, anything a connector must reference |
| Text              | Sugar     | Lives inside a Node and overrides fill / opacity / font for a single line        | Mixing several styles within one line of text                          |
| Coordinate        | Kernel    | Names a point without drawing any shape                                          | Pure reference anchors, helper positioning, no visible geometry needed |
| Custom Boundaries | Extension | Register node connection geometry independently of visual shape                  | Visual outline and connector attachment rules need to differ           |
