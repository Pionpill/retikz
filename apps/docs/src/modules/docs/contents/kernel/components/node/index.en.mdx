The node family answers how objects in a figure are named, positioned, and connected. `Node` provides the visible subject, `Text` refines individual text lines, and `Coordinate` keeps only a referenceable position. Add a custom boundary only when the visual outline and graphConnector geometry must differ. Start with [Node](/kernel/components/node/overview) on your first visit.

<ComponentPreview files="node-family" size="xs" hideCode />

## What each part does

| Component         | Type      | Responsibility                               | Use it when                                 |
| ----------------- | --------- | -------------------------------------------- | ------------------------------------------- |
| Node              | Kernel    | Declares a visible primitive with a boundary | You need a visible subject or endpoint      |
| Text              | Sugar     | Overrides one whole text line inside Node    | JSX needs per-line text styling             |
| Coordinate        | Kernel    | Names a position without visible output      | You need a junction or invisible anchor     |
| Custom Boundaries | Extension | Defines attachment and directional anchors   | Visual shape and connection rules must vary |
