The node family controls where objects sit, what they show, and how connections reference them. Node represents a shape with text; Text is the React syntax for one styled line inside Node; Coordinate names a position without drawing anything.

## Responsibilities at a glance

| Member             | Responsibility                | When to use                                      |
| ------------------ | ----------------------------- | ------------------------------------------------ |
| Node               | Position, text, and shape     | Visible objects and connection endpoints         |
| Text               | Style a complete text line    | Style individual lines in JSX                    |
| Coordinate         | Name an invisible position    | Position references and path junctions           |
| Boundary extension | Choose where connections stop | Connection rules differ from the visible outline |

## Overall picture

The figure combines visible nodes, their text, and an invisible reference point. Look first at the objects, then at the named positions used to organize connections. The two converging lines locate Coordinate; Coordinate itself draws no marker.

<ComponentPreview files="node-family" size="sm" type="illustration" hideCode />

Position places the object, shape defines its visible outline, and text supplies content. Paths look up node IDs and normally stop at their borders. Coordinate supplies an endpoint with no area. Moving a referenced position can move dependent objects without editing every coordinate.

## Choices and boundaries

Begin with Basic usage and continue to positioning, text, or labels as needed. Body text contributes to node size; labels attach to the completed border or center. Choose Coordinate for a pure positioning reference, and Node for visible marks, text, or directional borders.

See [node shapes](/kernel/components/node/shape) for built-in outlines and [custom shapes](/kernel/components/node/custom-shape) for defining and registering new outlines. [Scope](/kernel/components/scope) owns local coordinates and shared defaults for groups. Define a custom boundary only when connection placement must differ from appearance. Implementation and references support later diagnosis, extension, and field lookup; they are not prerequisites for drawing.
