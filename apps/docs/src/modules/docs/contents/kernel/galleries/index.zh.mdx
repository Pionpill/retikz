画廊展示从目标到完整图形的组合过程。每篇作品聚焦不同结构：几何示意、学习路线图和电路关系；适合在掌握基础组件后，用来观察多个能力如何在一张图里协作。

## 职责一览

| 作品          | 学习重点                     | 适合场景             |
| ------------- | ---------------------------- | -------------------- |
| Karl 单位圆   | 坐标、圆弧、标注与几何关系   | 学习几何示意图的拆解 |
| AI 专家路线图 | 节点布局、层级关系与复杂连线 | 学习结构化知识图     |
| 欧姆定律电路  | 元件、导线、公式与关系标注   | 学习技术示意图       |
