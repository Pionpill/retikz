title: Custom inspectors
description: Define inspectors over Scene primitives or domain artifacts and produce guides with ordinary drawing input

Custom and built-in inspectors share defineInspector, the registry, and the compilation flow. The subject selects a Scene primitive type or a Composite artifact namespace/type. The key identifies the inspector itself.

## Endpoint markers

This inspector reads final path commands and creates ordinary Nodes at explicit endpoints. Inspect applies the Scene group transform chain to local fragments; the author supplies no transform.

Callbacks return fragment arrays with coordinateSpace and child. An empty array means no guides. optionsSchema can declare options and defaults; omitting it permits only an empty object. Callbacks read isolated, read-only results and should not mutate the primary drawing or depend on authoring input.

## Domain artifacts

An artifact subject uses its Composite namespace/type. The callback receives the complete artifact, including value and occurrence. The domain contract owns value structure and coordinates; occurrence cannot establish a spatial transform.

Artifact fragments only support scene coordinates. If placement cannot be established, call context.warn('UnsupportedGeometry', message) and skip that item. Do not draw local boxes at the primary origin. Domain optional entry points own these semantics; Inspect has no domain whitelist.

## Failure boundaries

Callback or auxiliary compilation failure rejects the entire inspection; no partial plane is delivered. Errors retain their original cause. Auxiliary warnings remain separate from primary warnings. Guide IR cannot reference primary objects, and any required providers must be supplied through its independent compile configuration.
