---
title: Base packages
description: Base packages provide cross-package contracts and zero-dependency geometry for the rest of Kernel.
---

Base packages answer the question, “Which stable primitives can every other package share?” `@retikz/foundation` owns cross-package types, assertions, and error contracts; `@retikz/math` provides renderer-independent geometry primitives and algorithms. Neither package owns figure composition, compilation orchestration, or final rendering.

<ComponentPreview files="math-pipeline" size="xs" hideCode />

## Responsibilities

| Package              | Responsibility                                                              | Reach for it when                                              |
| -------------------- | --------------------------------------------------------------------------- | -------------------------------------------------------------- |
| `@retikz/foundation` | Cross-package types, schemas, assertions, and errors                        | Reusing a public contract or diagnosing low-level input errors |
| `@retikz/math`       | Pure computation for points, vectors, transforms, curves, and intersections | Constructing or deriving geometry data                         |
