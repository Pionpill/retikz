---
title: 内置检查
description: 观察最终 Scene 路径的控制柄、分组坐标系和裁剪边缘
---

默认注册表包含三个检查器。请求省略 target 时，按 Scene 树顺序检查所有匹配的图元；没有请求时不绘制。

| 注册键        | 对象                      | 默认显示                     |
| ------------- | ------------------------- | ---------------------------- |
| inspect/path  | Scene path                | 二次、三次曲线控制柄与控制点 |
| inspect/group | Scene group               | 局部原点                     |
| inspect/clip  | 带 clipRef 的 Scene group | 完整裁剪边缘                 |

## 二次曲线

控制柄来自最终 path 命令。移动控制点会先更新主图，再生成对应辅助层。

## 裁剪

裁剪检查显示资源在当前 group 中使用的完整路径，包括孔洞。它不求嵌套裁剪的交集，辅助边缘自身不受主图裁剪。

## 分组坐标

分组检查显示实际 Scene group 的原点与可选坐标轴。Scene group 不等同于作者 Scope，辅助层不恢复布局包络或逻辑祖先链。

<ComponentPreview
  files={['inspect-group', 'inspect-group.controls.ts', 'inspect-group.i18n.ts']}
  size="xl"
  controlPanelDefaultOpen
/>

圆弧中心、椭圆轴、Node 测量、连接边界和 Coordinate 点位不属于当前内置能力。所有辅助尺寸使用绘图单位，不保证固定屏幕像素。
