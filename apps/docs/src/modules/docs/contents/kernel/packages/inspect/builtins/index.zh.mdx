内置观测用于快速查看 Core 已经发布的最终结果。先在[安装与使用](/kernel/packages/inspect#安装与使用)完成 React 或 Vanilla 宿主接入，再请求下表中的 Inspector；它们不会改变主图。

## 内置检查

默认 registry 目前包含五类内置 Inspector。每一类都读取 Core 已经完成解析的最终产物：

| 观测器定义             | 对应组件     | 说明                                  |
| ---------------------- | ------------ | ------------------------------------- |
| `PATH_INSPECTOR`       | `Path`       | 控制柄、顶点、圆弧几何与标签          |
| `NODE_INSPECTOR`       | `Node`       | 局部几何、正文排版、关键点与场景 AABB |
| `CLIP_INSPECTOR`       | `Clip`       | 最终路径的子路径、孔洞边缘与标签      |
| `SCOPE_INSPECTOR`      | `Scope`      | 固有包络、原点、轴和层级标签          |
| `COORDINATE_INSPECTOR` | `Coordinate` | 坐标点与作者指定的 id                 |

`createDefaultInspectorRegistry()` 会自动加入这五项。没有匹配的最终 owner 或没有请求对应 key 时，不会生成辅助片段。

“图形参数”改变主体，“检查选项”只影响辅助层。

内置观测标签与所标记点或边缘的纵向偏移统一为 12 个单位，保留各自的上方或下方标注方向；坐标轴名称沿轴方向距末端 12 个单位。

## 曲线

`PATH_INSPECTOR` 读取 Core 解析完成的 Path 命令。每个示例只保留一条曲线，分别调整主图参数和辅助内容。

顶点按首次出现的顺序标为 `V0`、`V1`……，重合点只编号一次；圆弧和椭圆弧的两个不同端点显示为 `V0`、`V1`。

`controlPoints`、`vertices`、`arcGeometry` 分别控制控制柄、有效顶点和圆弧几何，默认依次为 `true`、`false`、`true`；`labels` 默认关闭。为方便观察，以下示例预先打开相关辅助项。

## 节点边界

`NODE_INSPECTOR` 统一展示形状轮廓、连接边界、布局外框、文本框、基线、关键点与场景轴对齐包围框（AABB）。`outline`、`boundary`、`box`、`content`、`baselines`、`keyPoints`、`bounds` 和 `labels` 默认全部开启，可分别关闭。

AABB 由外框四角经过最终变换后计算，不包含 stroke、shadow 或外置 label，也不因 Clip 缩小。为避免文字重叠，示例默认关闭标签，其他几何辅助项全部开启。

## 层级

`SCOPE_INSPECTOR` 读取 Scope 的固有包络，并在局部坐标中标出原点、坐标轴和层级标签。下面放置两个错开的子节点，包络围住两者，便于观察 Scope 变换和包络的关系。

局部坐标轴固定长 40 个局部单位，以虚线、末端箭头和 `x` / `y` 标注表示正方向，并随 Scope 变换。轴名随 `axes` 开关显示；`labels` 只控制 `scope N` 层级标签。
