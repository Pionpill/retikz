## Definition mechanism

An `InspectorDefinition` specifies what to observe, which options to accept, and how to generate auxiliary content. A Core owner identifies the capability publishing the compiled result; the example's `stroke` owner publishes final path output.

| Interface                   | Responsibility                                                                                 |
| --------------------------- | ---------------------------------------------------------------------------------------------- |
| `namespace` / `type`        | Form the Inspector registry key used by requests                                               |
| `owner`                     | Identify the Core owner to observe                                                             |
| `subjectSchema`             | Validate the owner's final output and determine the `subject` type                             |
| `mergeOptionsInput`         | Optionally merge raw options from scene, subtree, and current-occurrence scopes                |
| `optionsSchema`             | Define this Inspector's custom input contract; validate, default, and transform merged options |
| `resolveOptions`            | Resolve parsed options into `context.options`                                                  |
| `inspect(subject, context)` | Read output and context, returning Core IR or coordinate-space wrappers around it              |

`owner` and `subjectSchema` must match the output Core actually publishes. Derive raw input and parsed output from `optionsSchema` with `z.input` and `z.output`: merge raw configuration first, then parse and resolve options.

The figure shows how output and options feed `inspect()`. The Definition supplies the contracts and callbacks inside the dashed boundary; the Inspect driver executes them. The two branches express data dependencies, not parallel execution.

Core compiles the resulting auxiliary content into Scenes in isolation; the callback does not introduce a separate rendering mechanism.

## inspect callback

The following excerpts show the callback signature and related types, with source comments omitted:

```ts
inspect: (subject: TSubject, context: InspectorContext<TResolvedOptions>) => InspectorOutput;
```

### Input context

`subject` is final output validated by `subjectSchema`; `TResolvedOptions` is the output type of `resolveOptions`. The `context` supplies options, provenance, and appearance for the observed instance (occurrence).

```ts
export type InspectorContext<TOptions extends JsonObject = JsonObject> = Readonly<{
  inspectorKey: InspectorKey;
  owner: CompileObservationOwner;
  occurrence: CompileOccurrenceLocator;
  provenance: Readonly<{ origin: CompileOccurrenceLocator; final: CompileOccurrenceLocator }>;
  transform: AffineMatrix;
  ancestors: ReadonlyArray<CompileObservationAncestor>;
  options: TOptions;
  appearance: InspectionAppearanceContext;
  warn: (code: string, message: string) => void;
}>;

export type InspectionAppearanceContext = Readonly<{
  colorScope: number;
  scopeColor: CssColorValue;
  semanticColors: CoreSemanticColors;
}>;
```

| Parameter / property          | Responsibility                                                                                    |
| ----------------------------- | ------------------------------------------------------------------------------------------------- |
| `subject`                     | Validated final Core output; read only the geometry actually provided                             |
| `context.inspectorKey`        | The current Inspector's `namespace` and `type`                                                    |
| `context.owner`               | The Core owner publishing this output                                                             |
| `context.occurrence`          | The final occurrence being observed                                                               |
| `context.provenance`          | The original `origin` and final `final` occurrences                                               |
| `context.transform`           | Affine matrix from local coordinates to the primary Scene                                         |
| `context.ancestors`           | The outside-in Scope / composite container chain                                                  |
| `context.options`             | Custom options after parsing and resolution                                                       |
| `context.appearance`          | `colorScope`: request index; `scopeColor`: regular color; `semanticColors`: theme semantic colors |
| `context.warn(code, message)` | Report a nonfatal warning, such as omitted unavailable geometry                                   |

Some geometry may be unavailable; for example, a Node's outline or key points may be `null`. Process only the available information and use `context.warn()` when an omission needs explaining.

### Return content

```ts
export type InspectorCoordinateSpace = 'local' | 'scene';

export type InspectorFragment = Readonly<{
  type: 'fragment';
  coordinateSpace: InspectorCoordinateSpace;
  child: IRChild;
}>;

export type InspectorOutput = IRChild | InspectorFragment | ReadonlyArray<IRChild | InspectorFragment>;
```

| Return form / property              | Responsibility                                                                        |
| ----------------------------------- | ------------------------------------------------------------------------------------- |
| Ordinary `IRChild`                  | Return an auxiliary primitive directly, using occurrence-local coordinates by default |
| `InspectorFragment.type`            | The fixed `'fragment'` discriminator identifies a coordinate-space wrapper            |
| `InspectorFragment.coordinateSpace` | `local` uses local coordinates; `scene` uses primary Scene coordinates                |
| `InspectorFragment.child`           | The ordinary Core IR child to compile                                                 |
| Array                               | Return multiple items, mixing ordinary children and explicit fragments if needed      |

Usually, return Core children directly. Use `InspectorFragment` when an output item needs an explicit coordinate space. Inspect applies `context.transform` to `local` fragments; `scene` fragments do not receive that transform.
