### createLowerTex

<p>
  <ApiSourceLink label={'createLowerTex'} path={'packages/kernel/tex/src/lower/lower-tex.ts'} startLine={24}>
    Adapts a synchronous SVG engine to Core `LowerTex` and caches deterministic results
  </ApiSourceLink>
</p>

Accepts an engine that emits the supported SVG subset and an optional diagnostic callback, then returns a synchronous lowerer that can be injected directly into Core text compilation. This function performs TeX-to-SVG-to-path lowering and result caching; it does not initialize the engine or render formulas.

```ts
(engine: MathJaxSvgEngine, options?: LowerTexOptions) => LowerTex;
```

#### Parameters

| Parameter | Type               | Description                                                |
| --------- | ------------------ | ---------------------------------------------------------- |
| `engine`  | `MathJaxSvgEngine` | An engine that provides synchronous TeX-to-SVG conversion. |
| `options` | `LowerTexOptions`  | Optional configuration for lowering-failure diagnostics.   |

#### Returns

A synchronous `LowerTex` that can be injected into Core text compilation.

#### Usage

```ts
import { createLowerTex, createMathJaxEngine, MathJaxProfile } from '@retikz/tex';

const engine = await createMathJaxEngine({ profile: MathJaxProfile.Math });
const lowerTex = createLowerTex(engine, {
  onDiagnostic: diagnostic => console.warn(diagnostic.message),
});
```

### createMathJaxEngine

<p>

Asynchronously loads and configures `mathjax-full`, returning an engine that `createLowerTex` can invoke synchronously and repeatedly. Input configuration affects only enabled TeX extensions; the returned value handles TeX-to-SVG only, not SVG path lowering, caching, or Core injection.

```ts

```

#### Parameters

| Parameter | Type                   | Description                                                                    |
| --------- | ---------------------- | ------------------------------------------------------------------------------ |
| `options` | `MathJaxEngineOptions` | Optional configuration for the built-in profile and additional TeX extensions. |

#### Returns

A `MathJaxSvgEngine` that can synchronously perform TeX-to-SVG conversion.

#### Throws

- When `mathjax-full` cannot be loaded or initialized.

> **Notes:** Uses a literal dynamic import to support bundler code splitting; `fontCache: 'none'` outputs glyphs as inline paths.

#### Usage

```ts
import { createMathJaxEngine, MathJaxExtension } from '@retikz/tex';

const engine = await createMathJaxEngine({
  extensions: [MathJaxExtension.Ams],
});
const svg = engine.convert('\\frac{1}{2}', { display: false });
```

### useLowerTex

  </ApiSourceLink>

Accepts the same MathJax configuration as the root-entry factories, reuses an engine for the same effective extension set, and returns a discriminated initialization state. Pass the lowerer in ready state to React authoring entry points such as `Layout`; this Hook does not render formulas or handle application-level error UI.

```ts
(options?: MathJaxLowerTexOptions) => MathJaxLowerTexState;
```

#### Parameters

| Parameter | Type                     | Description                                                             |
| --------- | ------------------------ | ----------------------------------------------------------------------- |
| `options` | `MathJaxLowerTexOptions` | Optional configuration for MathJax extensions and lowering diagnostics. |

#### Returns

The initialization state of the MathJax lowerer for the current component configuration.

#### Usage

```ts
import type { FC } from 'react';

import { Layout } from '@retikz/react';
import { MathJaxProfile } from '@retikz/tex';
import { useLowerTex } from '@retikz/tex/react';

const Formula: FC = () => {
  const lowerTexState = useLowerTex({ profile: MathJaxProfile.Math });
  if (lowerTexState.status !== 'ready') return <Layout />;

  return <Layout lowerTex={lowerTexState.lowerTex}>{'公式：$x^2$'}</Layout>;
};
```
