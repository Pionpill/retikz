`@retikz/math` exposes the complete geometry-computation surface. `@retikz/core` only provides convenience re-exports for values commonly used while drawing and aliases `lerp` to `lerpPoint`. Import the `Position` / `Vector2` types, bounds, ellipse, and arc APIs from `@retikz/math`.

```ts
import { point, vector2, lerpPoint, localToWorld } from '@retikz/core';
import { type Position, lerp, boundsOf, ellipse } from '@retikz/math';
```

- `@retikz/core`: `DEFAULT_EPSILON`, `point`, `vector2`, `lerpPoint`, `localToWorld`, and `worldToLocal`.
- `@retikz/math`: every type and value on this page, plus the higher-level computations in [Algorithms](/kernel/packages/math/algorithms).

## Points and vectors

```ts
type Vector2 = [number, number];
type Position = Vector2;

isFiniteNumber(value: unknown): value is number;
isFinitePoint(value: unknown): value is Position;
isInfiniteNumber(value: unknown): value is number;
```

`point` handles the basic operations shared by points and 2D vectors. Every method returns a new tuple without mutating its inputs.

```ts
point.add(a, b); // a + b
point.sub(a, b); // a - b
point.scale(a, k); // a * k
point.dot(a, b); // dot product
point.cross(a, b); // 2D cross-product scalar
point.length(a); // vector length
point.distance(a, b); // distance between two points
point.along(origin, direction, length); // move along direction
point.against(origin, direction, length); // move against direction
point.normalize(a, fallback?, epsilon?);
point.shiftToward(p, target, distance);
point.equal(a, b); // exact comparison
```

`vector2` adds vector-specific construction and normal-vector operations:

```ts
vector2.fromPosition(p: Position): Vector2;
vector2.fromAngleDegrees(angle: number): Vector2;
vector2.normalize(v: Vector2, fallback?: Vector2, epsilon?: number): Vector2;
vector2.normalizeOrNull(v: Vector2, epsilon?: number): Vector2 | null;
vector2.normal(v: Vector2): Vector2;

lerp(a: Position, b: Position, t: number): Position;
```

`normalize` defaults to `[1, 0]` for a zero-length vector. `normalizeOrNull` returns `null` for zero-length or non-finite vectors. `lerp` does not clamp `t`, so it can extrapolate outside `[0, 1]`.

## Affine transforms

```ts
type CenteredShape = {
  x: number;
  y: number;
  rotate?: number; // radians about the center
};

localToWorld(shape: CenteredShape, local: Position): Position;
worldToLocal(shape: CenteredShape, world: Position): Position;
```

With `rotate` omitted or set to `0`, the transform is translation only. Otherwise it rotates about the center while converting between local and world coordinates. The two functions are inverses.

## Bounds

Bounds use `minX` / `minY` / `maxX` / `maxY`. The rectangle form uses a top-left position plus width and height.

```ts
type AxisAlignedBounds = { minX: number; minY: number; maxX: number; maxY: number };
type BoundsRect = { x: number; y: number; width: number; height: number };
type BoundsHalfAxes = { halfWidth: number; halfHeight: number };
type BoundsInsets = { left: number; right: number; top: number; bottom: number };

boundsOf(points: ReadonlyArray<Position>): AxisAlignedBounds | undefined;
mergeBounds(a?: AxisAlignedBounds, b?: AxisAlignedBounds): AxisAlignedBounds | undefined;
boundsToRect(bounds: AxisAlignedBounds): BoundsRect;
rectToBounds(rect: BoundsRect): AxisAlignedBounds;
isFiniteBoundsRect(rect: BoundsRect): boolean;
isPositiveBoundsRect(rect: BoundsRect): boolean;
boundsCenter(bounds: AxisAlignedBounds): Position;
boundsHalfAxes(bounds: AxisAlignedBounds): BoundsHalfAxes;
expandBounds(bounds: AxisAlignedBounds, insets: BoundsInsets): AxisAlignedBounds;
boundsCorners(bounds: AxisAlignedBounds): Array<Position>;
```

`boundsOf([])` and `mergeBounds(undefined, undefined)` return `undefined`, leaving skip, fallback, or error handling to the caller.

## Ellipses

```ts
type Ellipse = CenteredShape & { rx: number; ry: number };
type CenteredBox = CenteredShape & { width: number; height: number };
type EllipseCircumscribeMode = 'proportional' | 'equal';

ellipse.center(value: Ellipse): Position;
ellipse.inscribedInBox(box: CenteredBox): Ellipse;
ellipse.circumscribedHalfAxes(
  inner: BoundsHalfAxes,
  mode?: EllipseCircumscribeMode,
): BoundsHalfAxes;
ellipse.contains(value: Ellipse, point: Position): boolean;
ellipse.boundaryPoint(value: Ellipse, toward: Position): Position;
```

`contains` includes the boundary and returns `false` for a zero-radius axis. `boundaryPoint` follows a ray from the ellipse center toward the target; it returns the center for a degenerate ellipse or a target at the center.

## Arcs

Angles follow SVG coordinates: y points down, `0°` points along +x, `90°` points along +y, and positive angles increase clockwise on screen.

```ts
arcEndPoint(center: Position, radius: number, angleDeg: number): Position;
ellipseArcPoint(input: EllipseArcPointInput): Position;
arcAngleInRange(input: ArcAngleInRangeInput): boolean;
rayArc(input: RayArcInput): Array<number>;
arcBoundingPoints(input: ArcBoundingPointsInput): Array<Position>;
ellipseArcBoundingPoints(input: EllipseArcBoundingPointsInput): Array<Position>;
```

`@retikz/math` also exports the corresponding `ArcBoundingPointsInput`, `ArcAngleInRangeInput`, `RayArcInput`, `EllipseArcPointInput`, and `EllipseArcBoundingPointsInput` types. The bbox helpers return endpoint and in-range axis-extrema candidates without de-duplication.
