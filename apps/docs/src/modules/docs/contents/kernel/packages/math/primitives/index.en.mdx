Primitives answer what a coordinate is and where it goes after a transform. Every API on this page works on plain data without IR or a renderer, and none mutates its input tuples.

```ts
import { boundsOf, ellipse, point, vector2, type Position } from '@retikz/math';
```

## Points and vectors

Both `Position` and `Vector2` are `[number, number]`. `point` provides addition, subtraction, scaling, dot and cross products, distance, and directed movement. `vector2` adds angle construction, normalization, and normals.

`DEFAULT_EPSILON = 1e-9` is the default tolerance for several degeneracy checks in the package. `isFiniteNumber` rejects `NaN` and both infinities, while `isInfiniteNumber` accepts only the infinities; `isFinitePoint` accepts only an array of exactly two finite coordinates.

```ts
const origin: Position = [0, 0];
const direction = vector2.fromAngleDegrees(-30);
const end = point.along(origin, direction, 120);
const normal = point.scale(vector2.normal(direction), 50);

point.dot(direction, normal); // approximately 0
point.distance(origin, end); // 120
```

Change the angle and length to see that the vector and its left-hand normal stay perpendicular. `normalize` defaults to `[1, 0]` for zero length, while `normalizeOrNull` returns `null` for zero-length or non-finite vectors.

`point.shiftToward(p, target, distance)` moves a point toward a target and leaves it in place when both points coincide. `point.equal` uses strict coordinate equality without a tolerance. `lerp(a, b, t)` does not clamp `t`: values from `0` to `1` interpolate, and values outside that range extrapolate.

## Coordinate transforms

`localToWorld` and `worldToLocal` convert between a shape's local coordinates and world coordinates. A shape has a center and an optional rotation in radians.

```ts
const shape = { x: 100, y: 60, rotate: Math.PI / 4 };
const world = localToWorld(shape, [20, 0]);
const local = worldToLocal(shape, world); // approximately [20, 0]
```

With zero rotation, the transform is translation only. Otherwise it rotates about the shape center. The functions are inverses, making them useful for moving connection, boundary, and hit-test coordinates into one coordinate system.

## Bounds

`boundsOf` derives axis-aligned bounds from points. `mergeBounds` combines two optional bounds, while the remaining helpers convert among bounds, rectangles, centers, half-axes, and corners.

```ts
const bounds = boundsOf([
  [10, 20],
  [80, -5],
  [45, 30],
]);

if (bounds) {
  const center = boundsCenter(bounds);
  const expanded = expandBounds(bounds, { left: 8, right: 8, top: 4, bottom: 4 });
}
```

`boundsOf([])` and `mergeBounds(undefined, undefined)` return `undefined`. The caller deliberately chooses whether empty geometry should be skipped, given fallback bounds, or treated as an error.

`boundsToRect` / `rectToBounds` convert between min/max bounds and a top-left-plus-size rectangle. `isFiniteBoundsRect` requires all four fields to be finite, while `isPositiveBoundsRect` additionally requires strictly positive width and height. `boundsCorners` always returns top-left, top-right, bottom-left, then bottom-right.

## Ellipses and arcs

**Ellipse boundaries.** `ellipse` covers centers, inscribed and circumscribed ellipses, containment, and the boundary point toward a target.

```ts
const value = { x: 20, y: 10, rx: 80, ry: 40, rotate: Math.PI / 6 };

ellipse.contains(value, [20, 10]); // true; the boundary is included
ellipse.boundaryPoint(value, [160, 10]);
ellipse.inscribedInBox({ x: 0, y: 0, width: 160, height: 80 });
ellipse.circumscribedHalfAxes({ halfWidth: 80, halfHeight: 40 }, 'proportional');
```

The default `proportional` mode of `circumscribedHalfAxes` preserves the inner box's aspect ratio, while `equal` returns an equal-axis circle enclosing the box. `contains` returns `false` for a zero semi-axis. `boundaryPoint` returns the center for a degenerate ellipse or a target at its center, avoiding non-finite coordinates.

**Circular and elliptical arcs.** Angles follow SVG coordinates: y points down, `0°` points along +x, `90°` along +y, and positive angles increase clockwise on screen.

```ts
const end = arcEndPoint([0, 0], 40, 90); // [0, 40]
const candidates = arcBoundingPoints({
  center: [0, 0],
  radius: 40,
  startAngleDeg: 20,
  endAngleDeg: 220,
});
```

`arcEndPoint` / `ellipseArcPoint` select a curve point. An ellipse's `angleDeg` is a parameter angle and does not necessarily equal the polar angle observed from its center. `arcAngleInRange` uses the sign of `startAngleDeg → endAngleDeg`: positive spans run clockwise on screen and negative spans run counter-clockwise.

`arcBoundingPoints` / `ellipseArcBoundingPoints` return endpoints plus axis extrema in the numeric angular interval. They accept no extra `sweep` field and do not de-duplicate candidates. Elliptical-arc helpers only handle axis-aligned ellipses; compute a rotated ellipse in local space, then map it to world space with the coordinate-transform helpers.

## API summary

| Group             | Public types / values                                                                                     | Key behavior                                                                 |
| ----------------- | --------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| Numbers           | `Position`, `Vector2`, `DEFAULT_EPSILON`, `point`, `vector2`, `lerp`, three numeric guards                | Pure functions; explicit zero-length fallback; lerp extrapolates             |
| Transforms        | `CenteredShape`, `localToWorld`, `worldToLocal`                                                           | Rotate about center and convert between local and world space                |
| Bounds            | Four bounds types plus derivation, merge, conversion, guard, center, half-axis, expansion, corner helpers | Empty point sets and all-empty merges return `undefined`                     |
| Ellipses and arcs | `Ellipse`, `CenteredBox`, `ellipse`, five arc input types, and point / interval / ray / bbox helpers      | Elliptical arcs are axis-aligned only; bbox candidates are not de-duplicated |
