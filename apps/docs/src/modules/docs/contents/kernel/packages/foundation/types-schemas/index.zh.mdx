Foundation 将可在多个包之间复用的类型工具与运行时 schema 放在一起。它们只表达通用数据契约；领域对象应由各自 owner 的 schema 定义和校验。

## 类型工具

这些类型仅在编译期生效，用来描述或收窄跨包契约。

| 类型                              | 作用                                   |
| --------------------------------- | -------------------------------------- |
| `ValueOf<T>`                      | 取得对象所有 value 的联合类型          |
| `AssertEqual<TActual, TExpected>` | 双向检查两个类型是否等价               |
| `OpenString<T>`                   | 保留已知字符串提示，同时接受任意字符串 |
| `WithRequiredProperties<T, TKey>` | 将指定属性收窄为必填，同时保留其余属性 |
| `NonEmptyReadonlyArray<T>`        | 表示至少包含一个元素的只读数组         |

例如，在局部流程已经保证 `id` 存在后，可以用 `WithRequiredProperties` 将该事实传递给后续函数：

```ts
type NodeInput = { id?: string; label: string };
type IdentifiedNode = WithRequiredProperties<NodeInput, 'id'>;

const useNode = (node: IdentifiedNode) => node.id.toUpperCase();
```

## JSON 数据契约

`JsonValue` 和 `JsonObject` 是递归 JSON 数据的 TypeScript 类型；`JsonValueSchema` 与 `JsonObjectSchema` 则用于接收 `unknown` 的 parse 边界。readonly 数组让 `as const` Source 能直接通过 parse，但 parse 不负责 clone、freeze 或再次遍历已类型化的数据。

已有领域 Source schema 时，应直接使用该 owner 的 `parse()` 结果；不要先用 Foundation JSON schema 再叠加一轮通用校验。

## 标量 schema

以下 schema 用于 owner 需要运行时 parse 的通用标量边界。它们不替代领域范围、几何或对象 schema。

| Schema                     | 接受的值                        |
| -------------------------- | ------------------------------- |
| `NonBlankStringSchema`     | 至少包含一个非空白字符的 string |
| `PositiveNumberSchema`     | 大于 `0` 的有限 number          |
| `NonNegativeNumberSchema`  | 大于或等于 `0` 的有限 number    |
| `PositiveIntegerSchema`    | 大于 `0` 的安全整数             |
| `NonNegativeIntegerSchema` | 大于或等于 `0` 的安全整数       |
| `NormalizedFractionSchema` | 闭区间 `0..1` 内的 number       |

```ts
PositiveNumberSchema.parse(1.5);
NormalizedFractionSchema.parse(0.5);
```

## 开放字符串

`createOpenStringSchema(values)` 将 const object enum 的内置值与非空白自定义字符串合并。它适合协议允许扩展值、但仍希望编辑器提示内置值的字段。

```ts
const Role = {
  Participant: 'participant',
  Activity: 'activity',
} as const;

const RoleSchema = createOpenStringSchema(Role);

RoleSchema.parse('participant');
RoleSchema.parse('custom.role');
```
