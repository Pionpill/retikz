---
title: Extension packages
description: Extension packages connect optional capabilities to Kernel contracts, including LaTeX formula lowering and compile observation.
---

Extension packages answer the question, “How can optional capabilities plug in without changing the Kernel main path?” `@retikz/tex` connects formulas to text lowering; `@retikz/inspect` provides selection, observation, and auxiliary-layer capabilities. Both remain optional and leave Core IR ownership unchanged.

## Responsibilities

| Package | Responsibility | Reach for it when |
| --- | --- | --- |
| `@retikz/tex` | Lowering LaTeX formulas into glyph paths | Rendering formulas inside node text |
| `@retikz/inspect` | Compile-result selection, observation, and host wiring | Inspecting layout, paths, or auxiliary layers |
