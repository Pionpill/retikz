`@retikz/math` 负责零依赖的数学和几何计算，不包含绘图领域语义或渲染逻辑。

## 安装与使用

<PackageManagerInstall packages="@retikz/math" />

```ts
import { point, vector2, type Position, type Vector2 } from '@retikz/math';

const start: Position = [20, 10];
const offset: Vector2 = [40, -15];
const end = vector2.add(start, offset); // [60, -5]
const distance = point.distance(start, end); // 约为 42.7
```

上面的代码展示了根入口提供的点和向量运算。几何原语、坐标变换与算法的具体语义和边界，请继续阅读对应文档。
