`@retikz/math` 是 retikz 的**零依赖纯计算几何**包：向量运算、仿射变换、arc 原语、求交、三角形内外接圆、点在多边形、凸包、样条曲线。全是纯函数 + 普通 `Position = [number, number]` 数组，不写 class、零 IR、零 zod、零运行时依赖。

`@retikz/core` 依赖它做底层计算，并便捷转出 `DEFAULT_EPSILON`、`point`、`vector2`、`localToWorld` 和 `worldToLocal`；`lerp` 在 core 中以 `lerpPoint` 公开。`Position` 等类型、外接范围、椭圆、圆弧和高阶算法仍直接从 `@retikz/math` 导入。

> 这里是包文档，不是组件教程；写图请从 [组件](/kernel/components/layout) 开始。

## 安装

```bash
pnpm add @retikz/math
```
