`@retikz/vanilla` 是所有框架适配器共用的 API 基础包。它用普通 TypeScript 数据组织 `InputScene`，将其归一为 Core `IRScene`，再运行共享的 processing；React、Vue 等框架包只需要负责各自的输入收集和宿主接线。

包根不依赖浏览器 DOM：可用于 SSR、构建脚本或其它框架。浏览器 SVG / Canvas 挂载位于 `@retikz/vanilla/dom` 子入口。IR、schema、几何与编译规则属于 `@retikz/core`，后端输出属于 `@retikz/render`。

## 安装与使用

```bash
pnpm add @retikz/vanilla
```

```ts
import { layer, node, path, renderToSvgString, scene } from '@retikz/vanilla';
import { mount } from '@retikz/vanilla/dom';

const input = scene({
  id: 'flow',
  layers: [
    layer('main', [
      node('a', { position: [0, 0], text: 'A' }),
      node('b', { position: [120, 0], text: 'B' }),
      path('edge', {
        way: ['a', 'b'],
        marks: [{ pos: 1, mark: { kind: 'arrow' } }],
      }),
    ]),
  ],
});

const svg = renderToSvgString(input);
const view = mount(document.querySelector('#diagram')!, input);
```

`renderToSvgString` 不依赖 DOM，适合 SSR、构建期生成或保存 SVG；`mount` 用于浏览器宿主，默认创建 SVG，也可以通过 `renderer: 'canvas'` 切换到 Canvas。返回的 `view` 负责后续 `update`、交互水合、动画控制与释放。

`scene({ theme: { style, mode } })` 会把稀疏 Theme 写入 Input 根，`scope({ theme }, children)` 复用同一局部继承写法。归一化复制 Theme 对象，不修改调用方输入；最终两条路径都交给同一份 Core Theme 与 compile 契约。

## 输入归一与 processing

### 为什么需要 InputScene

直接构造 `@retikz/core` IR 是可行的，但应用经常需要更便于书写的 Path、Scope、Layer、Tier 2 embed 与运行时 metadata。`scene`、`layer`、`node`、`path`、`scope` 与 `embed` 用普通数据构造这些作者输入，不要求 JSX、React runtime 或组件生命周期。

`InputScene` 不是第二套图形语义：`normalizeScene()` 只在 Vanilla 集中处理输入简写、作者来源与 embed 下沉，并产生唯一的 Core `IRScene`。最终 IR 保持 JSON 可序列化；`authoring` 与 `embed.props` 是否可序列化由调用方和对应的领域 adapter 决定。

### 从 Input 到 Scene

下图中蓝色节点属于 Vanilla 的输入与 processing，橙色节点属于 Core。无论调用方是 Vanilla、React 还是其它框架，都会经过同一条 Input 归一化路径。

| 输入             | 所有者            | processing 如何处理                                     |
| ---------------- | ----------------- | ------------------------------------------------------- |
| `InputScene`     | `@retikz/vanilla` | normalize 输入、下沉 embed、收集贡献与 runtime metadata |
| Core `IRScene`   | `@retikz/core`    | 跳过 Input 归一，直接准备 Core 编译                     |
| 已编译的 `Scene` | `@retikz/core`    | 跳过归一与编译，只能由 DOM 子入口进行 static 完整重绘   |

`InputScene` 先由 `normalizeScene()` 生成 Core Source IR、Composite dependency contributions、作者来源与 metadata；`prepareProcessingInput()` 再合并唯一的 Core resolver 选项。`createProcessingController()` 在 retained 模式保存 Core Program 与 Runtime session，`prepareStaticProcessing()` 则只返回一次无生命周期的成功结果。

## Runtime 与 DOM 边界

| API                 | 用途                                 | 返回                         |
| ------------------- | ------------------------------------ | ---------------------------- |
| `renderToSvgString` | SSR / 构建期产出 `<svg>` 字符串      | `string`                     |
| `mount`             | 按 `renderer` 挂载 SVG 或 Canvas     | `VanillaView` / `CanvasView` |
| `mountSvg`          | 显式挂载 SVG DOM                     | `VanillaView`                |
| `mountCanvas`       | 显式挂载 Canvas                      | `CanvasView`                 |
| `hydrate`           | 对 SSR / 已有 SVG 根节点绑定 handler | `HydrationHandle`            |

后四项都从 `@retikz/vanilla/dom` 导入。默认情况下，`InputScene` 与 `IRScene` 创建 `VanillaViewMode.Retained` view：`update(next, options?)` 通过同一个 processing transaction 原子发布 Scene、artifacts、只读图层、runtime metadata、事件与动画。失败 transaction 不发布新 revision；若 rollback 自身失败，view 进入 broken 状态，必须 dispose 后 remount。

显式传 `runtime: { mode: 'static' }` 时，`InputScene` 或 `IRScene` 的每次 `update()` 都会完整归一、编译与重绘，不创建 Session、Snapshot、Patch、transaction 或 rollback。预编译 `Scene` 也总是 static，只接受下一份 `Scene`。

`mode` 与 `updateStrategy` 在 mount 时固定。`VanillaRetainedRuntimeOptions` 允许注入 `rendererFactory`；这是 DOM retained 后端的可选扩展点，static 模式不能传它。需要改变 renderer、DPR、compile topology 或 retained 策略时，先 dispose，再 remount。

## 分层与嵌入

`scene({ children })` 使用 id 为 `default` 的隐式 Layer。需要明确绘制顺序、稳定 Layer id 或缓存提示时，再用 `layers` 与 `layer()`。`zIndex` 只决定 Layer stack 排序，相同值保持声明顺序；`cache` 只进入 `InputRuntimeMeta`，由 DOM retained renderer 保守折叠为 Render cache policy，不进入 Core IR。

Tier 2 能力通过 `embed(kind, id, props)` 接入。Vanilla 不解析组件，也不执行 hooks；它按 `kind` 查找调用方注入的 `InputEmbedAdapter`，将已类型化 props 下沉为 Core child 与 Composite dependency contribution。

```ts
import type { InputEmbedAdapter } from '@retikz/vanilla';
import { embed, layer, node, renderToSvgString, scene } from '@retikz/vanilla';

type BadgeProps = { label: string };

const BadgeInputEmbedAdapter: InputEmbedAdapter<BadgeProps> = {
  kind: 'badge',
  lower: (props, context) => ({
    node: node(`${context.id}/label`, { position: [0, 0], text: props.label }),
    providerDependencies: { roots: [], providers: [] },
  }),
};

const input = scene({
  layers: [layer('content', [embed('badge', 'sales', { label: 'Sales' })])],
});

const svg = renderToSvgString(input, { adapters: [BadgeInputEmbedAdapter] });
```

`normalizeScene()` 从包根导出；`adapters` 是 render / mount / processing 选项的顶层字段，不放在 `compile` 内。需要检查归一结果时，可直接调用 `normalizeScene(input, { adapters })`，读取 `ir`、`contributions`、`runtimeMeta` 与 `authoringSites`。

adapter、Composite definition 和 compile topology 在 retained mount 生命周期内固定。领域 adapter 可以在同一输入位置处理新的 props；需要改变 adapter 集合、Composite schema、definition 数量或执行分支时，dispose 后 remount。

## 职责边界

| 能力            | `@retikz/vanilla` 负责什么                                | 能力真源 / 边界                    |
| --------------- | --------------------------------------------------------- | ---------------------------------- |
| 无框架输入      | 构造 InputScene、Layer、embed 与 Core 图元输入            | `@retikz/core` IR                  |
| 输入归一        | 将 Input 下沉为 IR，收集 adapter contribution 与 metadata | `@retikz/core` compile 契约        |
| 共享 processing | 准备输入、管理 Core Program 与处理结果                    | `@retikz/core` / `@retikz/runtime` |
| DOM 宿主        | 在 `/dom` 输出 SVG / Canvas、更新、水合与动画生命周期     | `@retikz/render` 后端执行          |
| Tier 2 嵌入     | 按 `kind` 调用 Input adapter 并聚合 lowering contribution | 各领域包拥有 props 与 lowering     |

React 应用使用 [`@retikz/react`](/kernel/packages/framework/react) 收集 JSX；其它框架同样应复用本包的 Input 与 processing。需要 SSR 字符串或直接 DOM / Canvas 挂载时，直接使用本包的对应入口。

## API 摘要

| API                                  | 类型          | 说明                                                    |
| ------------------------------------ | ------------- | ------------------------------------------------------- |
| `scene` / `layer`                    | Input helper  | 构造 Scene 与具名 Layer                                 |
| `node` / `coordinate` / `path`       | Input helper  | 构造 Core 图元或作者侧 Path 输入                        |
| `scope` / `embed`                    | Input helper  | 构造作用域与 Tier 2 embed 输入                          |
| `InputLayerCache`                    | const object  | Layer cache 提示                                        |
| `InputScene` / `InputChild`          | type          | 框架无关的作者输入根与子项                              |
| `InputLayer` / `InputNode`           | type          | Layer 与 Node 输入                                      |
| `InputPath` / `InputScope`           | type          | 可带作者侧语法糖或载荷的路径和作用域输入                |
| `InputEmbed`                         | type          | Tier 2 embed 输入                                       |
| `InputEmbedAdapter`                  | type          | 将 `InputEmbed` 下沉为 Core contribution                |
| `isInputScene` / `normalizeScene`    | normalization | 判别并归一 InputScene                                   |
| `NormalizedInputScene`               | type          | IR、contributions、metadata 与作者来源                  |
| `ProcessingSource`                   | type          | 可进入 processing 的 InputScene 或 IRScene              |
| `ProcessingOptions`                  | type          | compile、adapter、driver 与 retained 更新策略           |
| `ProcessingResult`                   | type          | 同 revision 的 Scene、artifacts、图层与 metadata        |
| `createProcessingController`         | processing    | 无框架 retained processing controller                   |
| `prepareStaticProcessing`            | processing    | 一次无生命周期 processing                               |
| `renderToSvgString`                  | SSR           | 渲染 InputScene、IRScene 或 Scene 为 SVG 字符串         |
| `mount` / `mountSvg` / `mountCanvas` | DOM           | 从 `@retikz/vanilla/dom` 挂载浏览器 view                |
| `VanillaRuntimeOptions`              | type          | InputScene / IRScene 的 retained 或 static runtime 配置 |
| `VanillaRetainedRuntimeOptions`      | type          | retained 模式、更新策略与可选 renderer factory          |
| `VanillaStaticRuntimeOptions`        | type          | 只允许 `mode: 'static'` 的封闭配置                      |
| `RetainedVanillaView`                | runtime       | IRScene / InputScene 的事务式 retained view             |
| `StaticVanillaView`                  | runtime       | Scene、IRScene 或 InputScene 的完整重绘 view            |
