---
title: Framework packages
description: Framework packages provide authoring adapters: Vanilla supplies framework-free input, while React supplies JSX and React host wiring.
---

Framework packages answer the question, “How does authored input enter the same Kernel processing path?” `@retikz/vanilla` provides framework-free InputScene, processing, and host entry points; `@retikz/react` collects JSX and connects it to the same input, compilation, and rendering contracts. Neither package redefines Core IR or rendering semantics.

## Responsibilities

| Package | Responsibility | Reach for it when |
| --- | --- | --- |
| `@retikz/vanilla` | Framework-free input, processing, SSR, and DOM mounts | Using ordinary TypeScript or implementing another adapter |
| `@retikz/react` | JSX components, the React adapter, and host wiring | Authoring and rendering figures in React |
