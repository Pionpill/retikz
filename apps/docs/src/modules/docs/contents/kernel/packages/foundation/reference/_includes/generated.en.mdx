This page lists the domain-neutral schemas exported from the `@retikz/foundation` root entry. They define JSON parse boundaries and scalar validation; domain objects such as Nodes and Paths should use schemas owned by their domain package. See [Types & Schemas](/kernel/packages/foundation/types-schemas) for compile-time utilities and open-string builders, and the [API reference](/kernel/packages/foundation/reference) for assertions and other public signatures.

Foundation schemas do not fill defaults: `parse()` validates input and returns the parsed value without coercion, trimming, or other transformation. JSON schemas retain recursive structure, while scalar schemas return the original number or string.

**JSON value schemas**

`JsonValueSchema` accepts any JSON value, while `JsonObjectSchema` requires an object at the root.
