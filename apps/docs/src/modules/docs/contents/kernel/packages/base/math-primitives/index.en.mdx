## Contents

### Vector operations

2D geometric data can represent either a coordinate point or a vector: a point describes a position, while a vector describes direction and displacement. `Position` and `Vector2` both use the `[x, y]` form, but the method group should match the meaning of the data.

| Member     | Category     | Purpose                                                                                                                      |
| ---------- | ------------ | ---------------------------------------------------------------------------------------------------------------------------- |
| `Position` | Type         | Represents a 2D coordinate point in `[x, y]` form                                                                            |
| `Vector2`  | Type         | Represents a 2D vector in `[x, y]` form                                                                                      |
| `point`    | Method group | Provides point distance, movement along a vector, movement toward a target, and equality                                     |
| `vector2`  | Method group | Provides vector addition, subtraction, scaling, dot and cross products, length, normalization, angle conversion, and normals |

Change the angle and length to see that the vector and its left-hand normal stay perpendicular.

#### API reference

| API                                                                                  | Category | Purpose                                    |
| ------------------------------------------------------------------------------------ | -------- | ------------------------------------------ |
| `Position`, `Vector2`                                                                | Type     | 2D coordinate-point and vector types       |
| `point.distance`, `point.along`, `point.against`, `point.shiftToward`, `point.equal` | Method   | Point distance, movement, and equality     |
| `vector2.add`, `vector2.sub`, `vector2.scale`, `vector2.dot`, `vector2.cross`        | Method   | Vector arithmetic and dot/cross products   |
| `vector2.length`, `vector2.normalize`, `vector2.normalizeOrNull`                     | Method   | Vector length and normalization            |
| `vector2.fromAngleDegrees`, `vector2.normal`                                         | Method   | Construct vectors and compute left normals |
| `lerp`                                                                               | Method   | Linearly interpolate between two points    |

### Bounds calculations

Bounds calculations find the axis-aligned rectangle occupied by a set of geometry. Although the calculation directly consumes a set of `Position` points, general shapes such as ellipses and arcs can first derive boundary candidates and then join the same bounds calculation.

The demo adds the arc's boundary candidates to the point set, so the dashed rectangle covers the three points and the arc. Change a point coordinate or either arc angle to observe the bounds update in real time.

### Ellipses and arcs

**Ellipse boundaries.** `ellipse` covers centers, inscribed and circumscribed ellipses, containment, and the boundary point toward a target.

**Circular and elliptical arcs.** Angles follow SVG coordinates: y points down, `0°` points along +x, `90°` along +y, and positive angles increase clockwise on screen.

<ComponentPreview
  files="ellipse-arc-playground"
  size="sm"
  caption="Adjust the radii and angles to compare the shapes and their bounds"
/>

`arcEndPoint` / `ellipseArcPoint` select a curve point. An ellipse's `angleDeg` is a parameter angle and does not necessarily equal the polar angle observed from its center. `arcAngleInRange` uses the sign of `startAngleDeg → endAngleDeg`: positive spans run clockwise on screen and negative spans run counter-clockwise.

`arcBoundingPoints` / `ellipseArcBoundingPoints` derive endpoints and axis-extrema candidates for bounds. Elliptical-arc helpers only handle axis-aligned ellipses; compute a rotated ellipse in local space, then map it to world space with the [coordinate transforms](/kernel/packages/base/math-transforms).

#### API reference

| API                                                                                                       | Category | Purpose                                                                  |
| --------------------------------------------------------------------------------------------------------- | -------- | ------------------------------------------------------------------------ |
| `Ellipse`, `CenteredBox`, `EllipseCircumscribeMode`                                                       | Type     | Ellipse, centered-box, and circumscription types                         |
| `ellipse.center`, `ellipse.inscribedInBox`, `ellipse.circumscribedHalfAxes`                               | Method   | Derive an ellipse center, inscribed ellipse, and circumscribed half-axes |
| `ellipse.contains`, `ellipse.boundaryPoint`                                                               | Method   | Test containment and find a boundary point                               |
| `ArcBoundingPointsInput`, `ArcAngleInRangeInput`, `EllipseArcPointInput`, `EllipseArcBoundingPointsInput` | Type     | Circular- and elliptical-arc input types                                 |
| `arcEndPoint`, `ellipseArcPoint`                                                                          | Method   | Select a point on a circular or elliptical arc                           |
| `arcBoundingPoints`, `ellipseArcBoundingPoints`                                                           | Method   | Derive arc boundary candidates                                           |
| `arcAngleInRange`                                                                                         | Method   | Test whether an angle lies in a directed interval                        |
