---
title: 拓展包
description: 拓展包把可选能力接入 Kernel 的统一契约，包括 LaTeX 公式 lowering 与编译观察能力。
---

拓展包解决的是“可选能力如何接入而不改变 Kernel 主路径”。`@retikz/tex` 把公式接入文本 lowering；`@retikz/inspect` 提供选择、观察和辅助图层能力。两者都是可选扩展，不改变 Core IR 的基础职责。

## 职责一览

| 包 | 职责 | 适合何时查阅 |
| --- | --- | --- |
| `@retikz/tex` | LaTeX 公式到字形路径的 lowering | 需要在节点文本中渲染公式时 |
| `@retikz/inspect` | 编译结果选择、观察和宿主接线 | 需要检查布局、路径或辅助图层时 |
