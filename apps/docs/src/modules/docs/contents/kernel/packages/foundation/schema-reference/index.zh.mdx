本页收录 `@retikz/foundation` 根入口公开的通用 schema。它们用于 JSON parse 边界和无领域标量校验；Node、Path 等领域对象应使用所属领域包拥有的 schema。编译期类型工具与开放字符串构造器见 [类型与契约](/kernel/packages/foundation/types-schemas)，断言与其他公开签名见 [API 参考](/kernel/packages/foundation/api-reference)。

所有 Foundation schema 都没有填充默认值：`parse()` 只校验输入并返回已解析值，不做 coercion、trim 或其他变换。JSON schema 保留递归结构；标量 schema 返回原始 number 或 string。

## JSON 值 schema

`JsonValueSchema` 接受任意 JSON 值；`JsonObjectSchema` 要求根值为对象。
