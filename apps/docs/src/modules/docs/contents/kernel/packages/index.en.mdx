Kernel packages are organized into five responsibility groups. Choose the problem you are solving first, then enter the relevant package to understand its boundaries, dependencies, and documentation

## Groups at a glance

| Group     | Responsibility                                       | Packages         |
| --------- | ---------------------------------------------------- | ---------------- |
| Base      | Cross-package contracts and dependency-free geometry | foundation, math |
| Core      | IR, Scene compilation, and incremental runtime       | core, runtime    |
| Extension | Optional formula and inspection capabilities         | tex, inspect     |
| Framework | React and framework-free host adapters               | vanilla, react   |
| Rendering | SVG, Canvas, and hydration materialization           | render           |
