Kernel packages are organized into five responsibility groups. Choose the problem you are solving first, then use the group overview to understand package boundaries, dependencies, and the recommended reading order

## Groups at a glance

| Group     | Responsibility                                       | Reach for it when                                           |
| --------- | ---------------------------------------------------- | ----------------------------------------------------------- |
| Base      | Cross-package contracts and dependency-free geometry | Reusing foundational types, schemas, or geometry algorithms |
| Core      | IR, Scene compilation, and incremental runtime       | Understanding compilation, execution, and state ownership   |
| Extension | Optional formula and inspection capabilities         | Adding TeX formulas or a runtime Inspector                  |
| Framework | React and framework-free host adapters               | Using Kernel from React or plain JavaScript                 |
| Rendering | SVG, Canvas, and hydration materialization           | Choosing a backend or binding client-side interaction       |
