The packages section helps when choosing an installation entry or understanding package ownership. `@retikz/core` is the shared subject of the full Kernel documentation, so it is not duplicated here. This section uses real npm package names for the React, framework-free, formula, pure computational geometry, and rendering entries that share the same core contract.

## Responsibilities

| Package           | Responsibility                         | Reach for it when                                |
| ----------------- | -------------------------------------- | ------------------------------------------------ |
| `@retikz/react`   | JSX components, IR adapter, React host | Authoring and rendering figures in React         |
| `@retikz/vanilla` | Plain specs, browser mounts, SSR       | Working without React or rendering strings       |
| `@retikz/tex`     | Lower formulas into glyph paths        | Rendering mathematics inside node text           |
| `@retikz/math`    | Pure computational geometry            | Reusing vectors, affine, arcs, and intersections |
| `@retikz/render`  | Scene to SVG / Canvas and hydration    | Integrating or choosing a render backend         |
