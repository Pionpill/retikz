`@retikz/foundation` provides domain-neutral contracts that every package can reuse.

## From configuration to a shared snapshot

A Retikz extension needs contracts for its configuration, stable snapshots for registered data, and errors that identify the responsible package. These correspond to types and schemas, snapshot utilities, and structured errors. They are independent tools, not mandatory consecutive stages for every call.

The example below freezes a detached copy. Editing the original configuration leaves the registered snapshot unchanged. A readonly Map protects only collection structure: its values retain their original identity, so shallow readonly access is not deep freezing.

## Scope

Foundation supplies shared atomic capabilities within the ecosystem. Core owns drawing schemas, Math owns geometry, and theme consumers own inheritance behavior. Use an existing domain schema directly without adding another JSON validation pass. Choose snapshot utilities when data must be copied and frozen independently.

## Installation and usage

<PackageManagerInstall packages="@retikz/foundation" />

```ts
import { cloneAndFreezeJson } from '@retikz/foundation';

const source = { id: 'diagram', settings: { grid: true } };
const snapshot = cloneAndFreezeJson(source, 'diagram config');

source.settings.grid = false;
snapshot.settings.grid; // true
Object.isFrozen(snapshot.settings); // true
```

The example above illustrates one utility. Foundation provides reusable, business-domain-neutral capabilities for the Retikz ecosystem.
