`@retikz/foundation` provides domain-neutral contracts that every package can reuse.

## Install and use

<PackageManagerInstall packages="@retikz/foundation" />

```ts
import { cloneAndFreezeJson } from '@retikz/foundation';

const source = { id: 'diagram', settings: { grid: true } };
const snapshot = cloneAndFreezeJson(source, 'diagram config');

source.settings.grid = false;
snapshot.settings.grid; // true
Object.isFrozen(snapshot.settings); // true
```

The example above illustrates one utility. Foundation provides reusable, business-domain-neutral capabilities for the Retikz ecosystem.
