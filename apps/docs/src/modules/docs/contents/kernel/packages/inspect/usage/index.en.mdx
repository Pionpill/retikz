To inspect final path control points or similar results, create a registry and declare a runtime request at the host you use. Requests never enter IR, Scene, or runtime snapshots, so they do not change primary bounds, resources, hit testing, animation, or public identity.

## React

React uses optional wrappers from `@retikz/inspect/react`. `InspectLayout` receives a registry, and `InspectPath` adds a request to the current Path:

```tsx
import { createDefaultInspectorRegistry, STROKE_PATH_INSPECTOR_KEY } from '@retikz/inspect';
import { InspectLayout, InspectPath } from '@retikz/inspect/react';
import { Step } from '@retikz/react';

const registry = createDefaultInspectorRegistry();

<InspectLayout registry={registry}>
  <InspectPath request={{ inspector: STROKE_PATH_INSPECTOR_KEY, options: { controlPoints: true, labels: true } }}>
    <Step kind="move" to={[0, 0]} />
    <Step kind="cubic" control1={[20, -30]} control2={[80, 30]} to={[100, 0]} />
  </InspectPath>
</InspectLayout>;
```

`InspectLayout` reuses the ordinary `<Layout>` static or retained runtime. `InspectPath` and `InspectScope` add selection only at the authoring site of their base components.

## Vanilla

Vanilla creates an authoring marker and a compile driver separately. The marker names the inspection site; the driver connects the registry, selection, and readonly layers to ordinary rendering:

```ts
import { createDefaultInspectorRegistry, STROKE_PATH_INSPECTOR_KEY } from '@retikz/inspect';
import { createInspectionVanillaAuthoring, createInspectionVanillaDriver } from '@retikz/inspect/vanilla';
import { path, renderToSvgString, scene } from '@retikz/vanilla';

const registry = createDefaultInspectorRegistry();
const input = scene({
  children: [
    path('curve', {
      authoring: createInspectionVanillaAuthoring({ inspector: STROKE_PATH_INSPECTOR_KEY, options: { labels: true } }),
      way: [
        [0, 0],
        {
          cubic: [
            [20, -30],
            [80, 30],
          ],
        },
        [100, 0],
      ],
    }),
  ],
});

const svg = renderToSvgString(input, { compileDriver: createInspectionVanillaDriver({ registry }) });
```

## Selection scope

Inspect observes only explicitly selected final occurrences. A request can come from the whole scene, an authored subtree, or the current occurrence; it is runtime selection, not persistent diagram data.

### React selection sites

| Target           | React entry                      | Result                                                         |
| ---------------- | -------------------------------- | -------------------------------------------------------------- |
| Whole scene      | `<InspectLayout request={...}>`  | Select every final occurrence with a matching owner            |
| Authored subtree | `<InspectScope request={...}>`   | Select matching occurrences under that Scope                   |
| Current Path     | `<InspectPath request={...}>`    | Select only the final occurrence for the current Path          |
| Hard barrier     | `<InspectScope request={false}>` | Prevent descendants from inheriting or reopening any Inspector |

### Scope and barriers

The playground puts two curves in separate subtrees, with each curve requesting inspection locally through `InspectPath`. Change the target, control points, and labels, then enable the right-side barrier to observe how local requests select paths:

  files="inspect-selection"

  caption="A and B are ordinary independent paths. After the right barrier is enabled, B cannot reopen inspection with its local request."
/>

One site may request several Inspectors. Sparse options for the same Inspector merge from scene to subtree to self. An ordinary `false` disables one Inspector at the current site, while a barrier prevents descendants from reopening any Inspector.

### Selection structures

| Structure                           | Meaning                                                                                           |
| ----------------------------------- | ------------------------------------------------------------------------------------------------- |
| `InspectionSelection`               | `rules: ReadonlyArray<InspectionSelectionRule>`, the complete runtime selection for a compile     |
| `InspectionSelectionRule` request   | `inspector`, `target`, and `options` select an Inspector with switch or sparse options            |
| `InspectionSelectionRule` barrier   | `target` allows a scene or authored subtree and prevents descendants from reopening any Inspector |
| `InspectionSelectionTarget` scene   | `{ kind: 'scene' }` matches the whole scene                                                       |
| `InspectionSelectionTarget` subtree | `{ kind: 'subtree', sourcePath }` matches one authored subtree                                    |
| `InspectionSelectionTarget` self    | `{ kind: 'self', locator }` locates the current object by authored source or final occurrence     |

`resolveInspectionSelection()` validates targets and owners, sorts final occurrences stably, and merges options. An invalid source path, out-of-range occurrence, or owner mismatch fails during selection before an Inspector callback runs.

## Host entries

| Entry                     | Responsibility                                                                      |
| ------------------------- | ----------------------------------------------------------------------------------- |
| `@retikz/inspect`         | Definitions, registry, selection, diagnostics, compilation, and built-in Inspectors |
| `@retikz/inspect/react`   | `InspectLayout`, `InspectPath`, and `InspectScope`                                  |
| `@retikz/inspect/vanilla` | Authoring markers and the Vanilla compile driver                                    |
| `@retikz/inspect/render`  | Turns the auxiliary plane into ordinary readonly Render layers                      |

Layout inspection comes from `@retikz/layout/inspect`, `@retikz/layout-react/inspect`, and `@retikz/layout-vanilla/inspect`. They explicitly depend on this package; the Layout root entry still works without Inspect.
