Path 声明描述一条路径怎样生成，不只是一个待转换成 SVG d 的字符串。Core 先确定路径定义与有效语义，在引用就绪后绑定目标，再调用所选 Definition。内置 stroke 复用标准几何、装饰与输出链，自定义 kind 也通过同一宿主契约接入。

## 整体流程

Reconciler 遍历时保存路径及所属环境，延迟到引用可查时执行。Core 的 compilePath 负责目标绑定与 Definition 调用；返回的图元、边界点由调度方回填到原输出位置。

## 从 A 到 B 的声明怎样变化

贯穿示例的 A、B 中心为 [0, 0]、[180, 0]，矩形外框为 60 × 40、margin 为零。路径写 move 到 A、line 到 B。目标查询先知道中心与绑定几何，stroke 再沿连线方向求边界交点，得到 [30, 0] → [150, 0]。

```ts
const path = {
  type: 'path',
  children: [
    { type: 'step', kind: 'move', to: { id: 'A' } },
    { type: 'step', kind: 'line', to: { id: 'B' } },
  ],
} satisfies import('@retikz/core').IRPathBase;
```

以下另用两个圆对照最终效果：左侧显式连接中心坐标，右侧引用节点边界并添加标签与端点箭头。它展示几何消费差异，不改变前述矩形案例的数值。

## 语义解析与目标绑定

`resolvePath` 先合并继承并处理上下文颜色，再按 kind 选择 Path Definition，用其完整 Schema 解析有效输入；省略 kind 时选择 stroke。之后继续补齐其余 Canonical 字段、文本、资源与能力绑定。PathResolution 同时保留 canon、定义及必要的 provider 绑定；它还不是最终命令。

`bindPathTargets` 使用当前 Scope 链读取位置与世界参考点，记录目标的几何和连接面。普通相对目标和累积相对目标采用不同基点更新规则；轴向线或平滑步骤后的表达可能要留给几何游标，不能一律在绑定阶段展开。

## 通用 Path 宿主与内置 stroke

PathDefinition.compile 接收受控宿主上下文：有效 path / appearance、结构化路径物化、标准 emitStroke、标签服务与输出包装。自定义路径可以选择复用标准描边或生成自身几何，不能据此取得整棵树的可变工作区。

内置 stroke 的 compile 就是 `context.emitStroke()`。其内部先 lower 几何，再 layout 标签和标记、准备端点接触与断线区间，最后 emit。自定义 kind 不必经过所有 stroke 专属阶段；图中的 stroke 分支只代表这条内置路径或显式复用它的实现。

`emitStroke()` 的输出已完成宿主包装，不应再调用 wrapOutput 包装一次。自定义输出需要按契约应用包装并返回所属路径局部空间中的图元和边界点；Definition 不得自己声明 resources，绘制资源经宿主登记。

## 几何、边界与游标

stroke 几何阶段消费步骤游标，生成 move / line / curve / arc 等结构化命令及来源记录。裸节点引用按段方向求连接表面；显式 anchor 直接选择锚点，offset 在世界空间叠加后转回所属空间。折线还需要去掉节点内部的前后缀。

<ComponentPreview files="path-clipping" size="md" hideCode type="illustration" />

曲线使用控制点方向确定附着点，再生成曲线；这里不是求整条贝塞尔与节点轮廓的精确交集。圆角在适用直线接缝处插入几何，后续装饰消费这份路径。找不到目标不会自动连到原点，应由该段及宿主的失败 / 诊断规则处理。

## 标签、标记与端点箭头

标签和沿线 Mark 根据路径采样点及方向放置。步骤级与路径级标签的采样范围不同，参数位置也不总等于弧长比例。支持断线的 stroke 标签把视觉范围和 gap 转为留白区间；显式断线仅允许无填充的内置 stroke，不能推广到任意 kind。

箭头定义提供尖端、接合位置和尺寸。Core 从原路径向内寻找接合点，保留原曲线的子段，使尖端仍落在目标，线条与箭头尾部接合。标签留白与箭头保护区共同决定可见主线。

<ComponentPreview files="path-shortening" size="lg" hideCode type="illustration" />

短路径可能需要缩小端点箭头；没有有效长度时不会输出该端点箭头。Arrow 与沿线 Mark 的视觉定义可共享，但沿线标记不执行端点收缩逻辑。

## 输出与阶段复用

CompiledPath 的 emit 可以是合法空结果 null；undefined 的 prepared 字段才表示尚未提供。targets、完整 emit，以及实际使用的源路径 stroke 局部产物可分别交接。Core 消费已确认有效的部分，补算其余部分；引用依赖、配套资源和诊断的复用由 Reconciler 管理。

最终宿主会物化可迭代图元与边界点、快照化输出并检查资源引用许可。图元可能包含分组、标签和标记，不保证“一条 Path 对应一个 PathPrimitive”。延迟只改变求值时机，原槽位回填和同层 zIndex 排序保留绘制语义。
