这些是 `@retikz/core` **未**转出的高阶计算，直接从 `@retikz/math` 导入。公开类型还包括 `Circle`、`LineLineInput`、`LineCircleInput`、`CircleCircleInput` 和 `CubicSegment`。

```ts
import { intersect, circle, triangle, polygon, convexHull, curve } from '@retikz/math';
```

退化输入不抛错：求交返回 `null` / `[]`，三角形圆退化返回 `null`。容差为朴素 `DEFAULT_EPSILON = 1e-9`（类型见[几何原语](/kernel/packages/math/primitives)）。

## 类型

```ts
/** 圆：圆心 + 半径 */
type Circle = { center: Position; radius: number };

type LineLineInput = {
  a1: Position;
  a2: Position;
  b1: Position;
  b2: Position;
};

type LineCircleInput = {
  origin: Position;
  dir: Position;
  center: Position;
  radius: number;
};

type CircleCircleInput = {
  centerA: Position;
  radiusA: number;
  centerB: Position;
  radiusB: number;
};
```

## intersect 求交

返回**点**：单交点用 `Position | null`，可能多解用 `Array<Position>`。

```ts
// 两条无限直线（各由两点定）；平行 / 共线 → null
intersect.lineLine(input: LineLineInput): Position | null;

// 两线段；不相交 / 平行 / 共线（含重叠）→ null
intersect.segmentSegment(input: LineLineInput): Position | null;

// 直线（origin + 方向 dir，dir 不必单位化）∩ 圆；0 / 2 个交点
intersect.lineCircle(input: LineCircleInput): Array<Position>;

// 圆 ∩ 圆；相离 / 内含 / 重合 → []
intersect.circleCircle(input: CircleCircleInput): Array<Position>;
```

| 函数             | 返回 / 退化                                                                    |
| ---------------- | ------------------------------------------------------------------------------ |
| `lineLine`       | 交点 `Position`；平行或共线 → `null`                                           |
| `segmentSegment` | 真交叉的交点；不相交 / 平行 / 共线（含重叠）→ `null`（首切不细分共线重叠区间） |
| `lineCircle`     | 0 个（相离）或 2 个交点；相切时返回 2 个重合点                                 |
| `circleCircle`   | 2 个交点；相离 / 内含 / 重合 → `[]`；相切时返回 2 个重合点                     |

射线 ∩ 圆弧用 [`rayArc`](/kernel/packages/math/primitives)（在原语页，返回参数而非点）。

## triangle 三角形圆

返回 `Circle`；三点共线（面积≈0）→ `null`。

```ts
triangle.circumCircle(a: Position, b: Position, c: Position): Circle | null;  // 外接圆（过三顶点）
triangle.inCircle(a: Position, b: Position, c: Position): Circle | null;      // 内切圆（与三边相切）
```

## circle 圆算法

```ts
// Welzl 迭代式；空点集 → null，单点 → 半径 0 的圆
circle.minimalEnclosing(points: Array<Position>, epsilon?: number): Circle | null;
```

`circle.minimalEnclosing` 返回覆盖全部输入点的最小圆。它的计算结果确定，复杂度为时间最坏 `O(n^3)`、空间 `O(1)`。

## polygon 点在多边形

```ts
// ray-casting 奇偶规则；顶点按序，不要求凹凸 / 绕向
polygon.containsPoint(vertices: Array<Position>, p: Position): boolean;
```

**边界点结果未定义**（落边界由调用方处理）；顶点数 < 3 返回 `false`。

## convexHull 凸包

```ts
convexHull(points: Array<Position>): Array<Position>;
```

Andrew monotone chain，返回 **CCW 顺序**顶点、**剔除共线中间点**；点数 < 3 或全共线时返回排序去重后的端点。

## curve 过点平滑曲线

给一串 knot，返回一条**穿过每个 knot** 的三次贝塞尔段链——`<Step kind="smooth">` 的底层算法。用 centripetal Catmull-Rom（α=0.5）：点距不均时不产生 cusp / 自交回环。

```ts
// 一段三次贝塞尔：两控制点 + 终点（起点为上一段终点 / 首段为第一个 knot）
type CubicSegment = { control1: Position; control2: Position; to: Position };

// centripetal Catmull-Rom：穿过 knots 的 cubic 段链
// 至少 2 个 knot；返回 knots.length - 1 段，段[i].to 严格命中 knots[i+1]（过点）
curve.catmullRomToCubic(knots: Array<Position>, tension: number): Array<CubicSegment>;
```

`tension` 是切线长度乘子：`1` 为标准值，`<1` 更紧，`>1` 更鼓。开放曲线两端使用单侧切线；重合 knot 的间距回退到 `DEFAULT_EPSILON`，避免除零并保证输出有限。`knots.length < 2` 返回 `[]`。
