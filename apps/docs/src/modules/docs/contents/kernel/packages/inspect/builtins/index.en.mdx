---
title: Built-in inspection
description: Inspect final Scene path handles, group coordinates, and clip edges
---

The default registry contains three inspectors. Omitting target selects all matching primitives in Scene tree order. No request means no guides.

| Key           | Subject                  | Default output                                 |
| ------------- | ------------------------ | ---------------------------------------------- |
| inspect/path  | Scene path               | Quadratic and cubic control handles and points |
| inspect/group | Scene group              | Local origin                                   |
| inspect/clip  | Scene group with clipRef | Complete clip boundary                         |

## Quadratic curves

Handles come from final path commands. Moving a control point updates the primary drawing before generating its guides.

## Clipping

Clip inspection shows the complete resource path at its current group, including holes. It does not compute nested clip intersections, and the guides do not inherit primary clipping.

## Group coordinates

Group inspection shows the origin and optional axes of actual Scene groups. A Scene group is not an authored Scope; inspection does not reconstruct layout envelopes or logical ancestry.

<ComponentPreview
  files={['inspect-group', 'inspect-group.controls.ts', 'inspect-group.i18n.ts']}
  size="xl"
  controlPanelDefaultOpen
/>

Arc centers, ellipse axes, Node measurements, connection boundaries, and Coordinate positions are not built-in inspection capabilities. Guide sizes use drawing units, not fixed screen pixels.
