Built-in inspection gives a quick view of final output that Core already publishes. Complete React or Vanilla host setup in [Install and use](/kernel/packages/inspect#installation-and-usage), then request one of the Inspectors below; none changes the primary figure.

## Built-in checks

The default registry contains five built-in Inspectors. Each reads final output already settled by Core:

| Inspector Definition   | Component    | Description                                                   |
| ---------------------- | ------------ | ------------------------------------------------------------- |
| `PATH_INSPECTOR`       | `Path`       | Handles, vertices, arc geometry, and labels                   |
| `NODE_INSPECTOR`       | `Node`       | Local geometry, text layout, key points, and Scene AABB       |
| `CLIP_INSPECTOR`       | `Clip`       | Every subpath and hole edge in the lowered path, plus a label |
| `SCOPE_INSPECTOR`      | `Scope`      | Intrinsic envelope, origin, axes, and hierarchy label         |
| `COORDINATE_INSPECTOR` | `Coordinate` | Point marker and authored id                                  |

`createDefaultInspectorRegistry()` adds all five. No auxiliary fragment is produced when no final owner matches or the corresponding key is not requested.

Shape parameters change the subject; inspection options affect only the auxiliary layer.

Built-in inspection labels use a consistent vertical offset of 12 units from their reference point or edge, preserving their above or below placement. Axis names sit 12 units beyond the axis endpoint along its direction.

## Curves

`PATH_INSPECTOR` reads Path commands resolved by Core. Each example contains one curve, with separate controls for geometry and auxiliary content.

Vertices are labeled `V0`, `V1`, and so on in first-occurrence order, with coincident points numbered once. The two distinct endpoints of an arc or elliptical arc are labeled `V0` and `V1`.

`controlPoints`, `vertices`, and `arcGeometry` control handles, valid vertices, and arc geometry; their defaults are `true`, `false`, and `true`. `labels` defaults to off. These examples enable relevant helpers for exploration.

## Node bounds

`NODE_INSPECTOR` displays the shape outline, connection boundary, layout box, text box, baselines, key points, and Scene axis-aligned bounding box (AABB). `outline`, `boundary`, `box`, `content`, `baselines`, `keyPoints`, `bounds`, and `labels` all default to `true` and can be disabled separately.

The AABB projects the outer-box corners through the final transform. It excludes stroke, shadow, and external labels, and is not reduced by Clip. To avoid overlapping text, this demo starts with labels off and all geometry helpers on.

## Hierarchy

`SCOPE_INSPECTOR` reads the Scope's intrinsic envelope and marks its origin, axes, and hierarchy label in local coordinates. Two offset child nodes share one enclosing envelope, making the relationship between the Scope transform and its envelope easier to see.

Local axes have a fixed length of 40 local units, with dashed lines, arrowheads, and `x` / `y` labels indicating their positive directions. They follow the Scope transform. Axis names follow the `axes` switch; `labels` controls only the `scope N` hierarchy label.
