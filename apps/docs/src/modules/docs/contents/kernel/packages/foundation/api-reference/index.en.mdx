`@retikz/foundation` provides cross-package atomic types, base schemas, assertions, readonly collections, JSON utilities, static color computation, and structured-error contracts.

The package provides only its root entry. Import public APIs from `@retikz/foundation`; internal owner files are not stable subpaths.

For first use, read [the usage topic](/kernel/packages/foundation/utilities). See the [Schema reference](/kernel/packages/foundation/schema-reference) for base-schema fields, defaults, and validation structure.
