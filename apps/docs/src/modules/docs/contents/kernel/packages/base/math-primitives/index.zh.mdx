几何原语用于描述点、向量和基本几何图形。`@retikz/math` 只负责数学与几何关系的计算。

## 内容

### 向量运算

二维几何数据可以表示为坐标点或向量：点表示位置，向量表示方向与位移。`Position` 与 `Vector2` 都使用 `[x, y]` 形式，但应根据语义选择对应的方法集合。

| 成员       | 类别     | 作用                                                           |
| ---------- | -------- | -------------------------------------------------------------- |
| `Position` | 类型     | 表示二维坐标点，格式为 `[x, y]`                                |
| `Vector2`  | 类型     | 表示二维向量，格式为 `[x, y]`                                  |
| `point`    | 方法集合 | 提供点之间的距离、沿向量移动、朝目标移动和相等比较             |
| `vector2`  | 方法集合 | 提供向量加减、缩放、点积、叉积、长度、单位化、角度转换和法向量 |

拖动角度和长度可以观察向量与左手法向量始终正交。

#### API 参考

| API                                                                                  | 类别 | 作用                           |
| ------------------------------------------------------------------------------------ | ---- | ------------------------------ |
| `Position`、`Vector2`                                                                | 类型 | 二维坐标点与向量类型           |
| `point.distance`、`point.along`、`point.against`、`point.shiftToward`、`point.equal` | 方法 | 点之间的距离、移动和相等比较   |
| `vector2.add`、`vector2.sub`、`vector2.scale`、`vector2.dot`、`vector2.cross`        | 方法 | 向量的加减、缩放、点积和叉积   |
| `vector2.length`、`vector2.normalize`、`vector2.normalizeOrNull`                     | 方法 | 向量长度和单位化               |
| `vector2.fromAngleDegrees`、`vector2.normal`                                         | 方法 | 由角度构造向量和计算左手法向量 |
| `lerp`                                                                               | 方法 | 在两个坐标点之间进行线性插值   |

### 边界计算

边界计算用于得到一组几何数据所占据的轴对齐矩形。它虽然直接从 `Position` 点集计算，但椭圆、圆弧等一般图元也会先转换为边界候选点，再间接纳入同一套 bounds 计算。

本 demo 同时把圆弧的边界候选点并入点集，因此虚线矩形会覆盖三个点和圆弧。调整点坐标或圆弧起始、终止角度，可以观察 bounds 实时变化。

#### API 参考

| API                                                                 | 类别 | 作用                         |
| ------------------------------------------------------------------- | ---- | ---------------------------- |
| `AxisAlignedBounds`、`BoundsRect`、`BoundsHalfAxes`、`BoundsInsets` | 类型 | 边界、矩形、半轴和内边距类型 |
| `boundsOf`、`mergeBounds`                                           | 方法 | 从点集构造边界或合并两个边界 |
| `boundsToRect`、`rectToBounds`                                      | 方法 | 在边界与矩形表示之间转换     |
| `isFiniteBoundsRect`、`isPositiveBoundsRect`                        | 方法 | 检查矩形范围是否合法         |
| `boundsCenter`、`boundsHalfAxes`                                    | 方法 | 取得边界中心和半轴           |
| `expandBounds`、`boundsCorners`                                     | 方法 | 外扩边界和取得四个角点       |

### 椭圆与圆弧

**椭圆边界。** `ellipse` 统一处理椭圆中心、内接 / 外接关系、包含判断和朝向某点的边界交点。

**圆弧与椭圆弧。** 角度遵循 SVG 坐标：y 轴向下，`0°` 指向 +x，`90°` 指向 +y；正角度在屏幕上顺时针增加。

<ComponentPreview files="ellipse-arc-playground" size="sm" caption="调整半轴、半径和角度，观察椭圆、圆弧及其边界" />

`arcEndPoint` / `ellipseArcPoint` 取曲线上一点；椭圆的 `angleDeg` 是参数角，不一定等于从中心观察到的真实极角。`arcAngleInRange` 按 `startAngleDeg → endAngleDeg` 的符号判断有向区间：正跨度在屏幕上顺时针，负跨度逆时针

`arcBoundingPoints` / `ellipseArcBoundingPoints` 取得端点与轴向极值等边界候选点。椭圆弧方法只处理轴对齐椭圆弧；旋转椭圆应先在局部坐标计算，再用[坐标变换](/kernel/packages/base/math-transforms)映射到世界坐标。

#### API 参考

| API                                                                                                       | 类别 | 作用                               |
| --------------------------------------------------------------------------------------------------------- | ---- | ---------------------------------- |
| `Ellipse`、`CenteredBox`、`EllipseCircumscribeMode`                                                       | 类型 | 椭圆、中心盒和外接策略类型         |
| `ellipse.center`、`ellipse.inscribedInBox`、`ellipse.circumscribedHalfAxes`                               | 方法 | 构造椭圆中心、内接椭圆和外接半轴   |
| `ellipse.contains`、`ellipse.boundaryPoint`                                                               | 方法 | 判断包含关系和取得朝向目标的边界点 |
| `ArcBoundingPointsInput`、`ArcAngleInRangeInput`、`EllipseArcPointInput`、`EllipseArcBoundingPointsInput` | 类型 | 圆弧与椭圆弧的输入类型             |
| `arcEndPoint`、`ellipseArcPoint`                                                                          | 方法 | 取得圆弧或椭圆弧上的点             |
| `arcBoundingPoints`、`ellipseArcBoundingPoints`                                                           | 方法 | 取得弧段的边界候选点               |
| `arcAngleInRange`                                                                                         | 方法 | 判断角度是否落在有向圆弧区间内     |
