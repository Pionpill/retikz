---
title: 核心包
description: 核心包拥有 Kernel 的编译契约与增量执行基础，负责把输入转成可消费的 Scene 和运行结果。
---

核心包解决的是“图形语义如何被编译和执行”。`@retikz/core` 拥有领域中立的 IR、解析与编译契约；`@retikz/runtime` 管理 identity、Program、Session、revision 和 transaction。上层 API 通过这些公开契约接入，而不是各自维护平行执行路径。

## 职责一览

| 包 | 职责 | 适合何时查阅 |
| --- | --- | --- |
| `@retikz/core` | IR、编译、Scene 和领域中立的 lowering | 需要理解图元如何编译成 Scene 时 |
| `@retikz/runtime` | Program、Session、revision 和 transaction | 需要管理增量执行或状态所有权时 |
