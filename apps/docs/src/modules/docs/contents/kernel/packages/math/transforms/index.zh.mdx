当一个图形移动或旋转时，图形内部使用的点仍然可以保持不变。坐标变换就是把这个点从图形自己的坐标系转换到整个画布的坐标系，或者再转换回来。

本页先介绍最常见的局部坐标与世界坐标，再介绍可以连续组合平移、缩放和旋转的二维仿射矩阵。第一次阅读时，可以先看懂前一节，再按需要使用仿射矩阵。

## 基础用法

从根入口导入，返回普通数值或几何数据，不负责绘图。

```ts
import {
  localToWorld,
  worldToLocal,
  applyAffine,
  multiplyAffine,
  type CenteredShape,
  type AffineMatrix,
} from '@retikz/math';

const shape: CenteredShape = { x: 100, y: 60, rotate: 0 };
const world = localToWorld(shape, [20, 0]); // [120, 60]
const local = worldToLocal(shape, world); // [20, 0]
```

## 局部坐标与世界坐标

先想象一个带方向的图形：整个画布有一套固定的坐标，图形自己也有一套坐标。图形的中心是局部坐标的原点，局部的 `x` 轴和 `y` 轴会跟着图形一起旋转；画布坐标则不会跟着图形移动。

| 坐标系   | 原点和坐标轴                     | 常见用途                         |
| -------- | -------------------------------- | -------------------------------- |
| 局部坐标 | 原点在图形中心，坐标轴随图形旋转 | 描述图形内部的顶点、连接点和边界 |
| 世界坐标 | 原点和坐标轴固定在整个画布上     | 绘制图形、计算图形之间的位置关系 |

下面的图中，虚线是固定的世界坐标轴，橙色图形和橙色坐标轴属于同一个局部坐标系。调整控制面板中的图形中心、旋转角和局部点，可以观察同一个局部点如何变成不同的世界坐标。

<ComponentPreview files="coordinate-spaces" size="lg" caption="调整图形中心、旋转角和局部点，观察世界点随之变化" />

演示控件用角度（°）输入，调用前按 `角度 × Math.PI / 180` 转成弧度；API 的 `rotate` 始终接收弧度。

`CenteredShape` 用图形中心和旋转角描述这套局部坐标系：`x`、`y` 是图形中心在世界坐标中的位置，`rotate` 是图形绕中心旋转的弧度。`Math.PI / 4` 就是 45°；在屏幕坐标中，正角度沿顺时针方向增加。

```ts
const shape: CenteredShape = { x: 100, y: 60, rotate: Math.PI / 4 };
const world = localToWorld(shape, [20, 0]); // 约为 [114.1, 74.1]
const local = worldToLocal(shape, world); // 约为 [20, 0]
```

这里的 `[20, 0]` 不是画布上的固定位置，而是“图形中心右侧 20 个单位”。`localToWorld` 先按照图形的旋转方向转动它，再加上图形中心的位置；`worldToLocal` 执行相反的过程。

可以按手里的数据选择方法：

| 已知数据                     | 需要得到的结果     | 使用方法       |
| ---------------------------- | ------------------ | -------------- |
| 图形内部的点、连接点或边界点 | 它在画布中的位置   | `localToWorld` |
| 画布中的鼠标点或命中点       | 它在图形内部的位置 | `worldToLocal` |

两个方法互为逆变换，都会返回新的点，不会修改输入的 tuple。

### 算法解析

上方从局部点到世界点：`localToWorld` 先按 `rotate` 绕局部原点旋转，再加上图形中心。下方则反向执行：`worldToLocal` 先减去图形中心，再按负旋转角旋转。中心图形（`CenteredShape`）位于中间，同时为两条链提供中心位置与旋转角；当 `rotate` 为 `0` 或省略时，旋转保持点不变。图中两条链用不同颜色区分转换方向。

## 二维仿射矩阵

前一节的局部到世界坐标转换，本质上也是“旋转后平移”的仿射变换；`CenteredShape` 将这一常见场景压缩为中心和角度。当还需要缩放、镜像、错切，或连续组合多个变换时，可以使用二维仿射矩阵。它可以理解为一张“坐标计算配方”：输入一个点 `[x, y]`，按照配方计算出新的点 `[x', y']`。

`AffineMatrix` 沿用 SVG / Canvas 的表示法：它是一个包含六个数的 tuple，顺序固定为 `[a, b, c, d, e, f]`。这六项分为两部分：

| 部分           | 直观作用                                   |
| -------------- | ------------------------------------------ |
| `[a, b, c, d]` | 组合旋转、缩放、镜像和错切等方向或尺寸变化 |
| `[e, f]`       | 把结果整体移动到新的位置                   |

其中前四项组成线性部分：

$$
\begin{bmatrix}
a & c \\
b & d
\end{bmatrix}
$$

按输入坐标的来源看，每一项的含义是：

| 参数 | 作用                        |
| ---- | --------------------------- |
| `a`  | 输入 `x` 对输出 `x'` 的贡献 |
| `b`  | 输入 `x` 对输出 `y'` 的贡献 |
| `c`  | 输入 `y` 对输出 `x'` 的贡献 |
| `d`  | 输入 `y` 对输出 `y'` 的贡献 |

按照这套六元组顺序，对点的计算公式是：

$$
\begin{aligned}
x' &= ax + cy + e \\
y' &= bx + dy + f
\end{aligned}
$$

例如，下面的两个矩阵先把点的横坐标放大为 2 倍、纵坐标放大为 3 倍，再把结果向右移动 10、向下移动 20：

```ts
const translate: AffineMatrix = [1, 0, 0, 1, 10, 20];
const scale: AffineMatrix = [2, 0, 0, 3, 0, 0];
const matrix = multiplyAffine(translate, scale);

applyAffine(matrix, [4, 5]); // [18, 35]：先缩放，再平移
```

也就是说，这个点依次经过 `[4, 5] → [8, 15] → [18, 35]`；中间结果 `[8, 15]` 是缩放后的坐标。

`multiplyAffine(outer, inner)` 中，`inner` 是先执行的内层变换，`outer` 是后执行的外层变换。因此上例先执行 `scale`，再执行 `translate`；交换两个参数，得到的结果也会改变。

### 算法解析

二维仿射计算分成“组合配方”和“应用配方”两步。内层矩阵 `inner` 先处理原始点，外层矩阵 `outer` 再处理内层的结果；它们不是按书写顺序从左到右作用。因此，合成矩阵 `combined` 满足：

$$
\operatorname{apply}(OI,p)=\operatorname{apply}(O,\operatorname{apply}(I,p))
$$

若 `outer = [A, B, C, D, E, F]`、`inner = [a, b, c, d, e, f]`，并记合成结果为 `combined = [a', b', c', d', e', f']`，则：

$$
\begin{aligned}
a' &= Aa + Cb & b' &= Ba + Db \\
c' &= Ac + Cd & d' &= Bc + Dd \\
e' &= Ae + Cf + E & f' &= Be + Df + F
\end{aligned}
$$

前四项组合旋转、缩放、镜像或错切，最后两项先变换内层的平移 `[e, f]`，再加上外层平移 `[E, F]`。`multiplyAffine` 只合成配方，不处理点；随后 `applyAffine` 才让输入点的 `x`、`y` 参与两条线性组合，得到新点。

可以这样选择两种能力：只需要围绕图形中心处理局部点时，使用 `localToWorld` / `worldToLocal`；需要表达任意二维仿射变换或组合多步变换时，使用 `AffineMatrix`、`multiplyAffine` 和 `applyAffine`。

如果需要在消费仿射矩阵前检查它是否由有限数值组成且可逆，可以使用 `isFiniteNonSingularAffine`。对于描边等要求保持统一缩放的场景，可以使用 `getAffineSimilarityScale` 获取缩放因子；矩阵不是相似变换时会返回 `undefined`。

### 调用速查

| 类别 | API                         | 作用                                                 |
| ---- | --------------------------- | ---------------------------------------------------- |
| 类型 | `AffineMatrix`              | 按 `[a, b, c, d, e, f]` 顺序表示二维仿射矩阵         |
