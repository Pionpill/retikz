`@retikz/math` owns dependency-free math and geometry computation, without drawing-domain or rendering semantics.

## Responsibilities

| Document   | Responsibility                            | Reach for it when                 |
| ---------- | ----------------------------------------- | --------------------------------- |
| Primitives | Points, vectors, bounds, and curves       | Constructing or reading geometry  |
| Transforms | Moving geometry between coordinate spaces | Working with layout or transforms |
| Algorithms | Intersection, clipping, and construction  | Deriving geometric results        |
