`@retikz/math` is retikz's **zero-dependency pure computational geometry** package: vector math, affine transforms, arc primitives, intersections, triangle in-circle / circum-circle helpers, point-in-polygon, convex hull, and splines. Everything is a pure function over plain `Position = [number, number]` arrays — no classes, no IR, no zod, no runtime dependencies.

`@retikz/core` depends on it for low-level computation. Core provides convenience re-exports for `DEFAULT_EPSILON`, `point`, `vector2`, `localToWorld`, and `worldToLocal`, and exposes math's `lerp` as `lerpPoint`. Import types such as `Position`, bounds, ellipses, arcs, and higher-level algorithms directly from `@retikz/math`.

> This is package documentation, not component docs; to draw, start from [Components](/kernel/components/layout).

## Install

```bash
pnpm add @retikz/math
```
