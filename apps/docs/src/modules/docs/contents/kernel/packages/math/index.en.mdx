`@retikz/math` owns dependency-free math and geometry computation, without drawing-domain or rendering semantics.

## From geometry to a computed result

Suppose a connection must meet the boundary of a rotated shape. Primitives describe points, directions, and bounds; transforms put them into a shared space; intersection algorithms find candidate attachment points. These capabilities cooperate through numbers and geometry, without constructing drawing elements or SVG.

The figure shows coordinate conversion: the local point stays fixed while moving or rotating its shape changes world coordinates. Callers can use the result for layout, hit testing, or drawing; Math does not choose that purpose.

## Choosing capabilities

Start with points and vectors for displacement and length. Convert different coordinate spaces before testing intersections or containment. Check angle units per function: affine and centered-shape rotations use radians, while methods named Degrees take degrees. Empty, collinear, or zero-length inputs may return a sentinel rather than throw; follow each method’s contract.

## Installation and usage

<PackageManagerInstall packages="@retikz/math" />

```ts
import { point, vector2, type Position, type Vector2 } from '@retikz/math';

const start: Position = [20, 10];
const offset: Vector2 = [40, -15];
const end = vector2.add(start, offset); // [60, -5]
const distance = point.distance(start, end); // approximately 42.7
```
