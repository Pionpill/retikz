当 Node 文本需要使用 LaTeX 时，仍然通过 `$...$`、`$$...$$` 或显式 math run 编写公式。完成 [安装与接入](/kernel/packages/tex) 后，`@retikz/tex` 会把它们转换为 Core 能消费的字形路径，让 SVG 与 Canvas 复用同一份公式结果。

## 基础用法

先看最常见的三种写法：字符串中的行内公式、字符串中的 display 公式，以及可以逐段设置样式的显式 math run。下面的静态 demo 把它们放在同一个 Layout 中，先观察公式在文本中的实际效果：

<ComponentPreview
  files="tex-formula-basics"
  size="sm"
  caption="同一个 Layout 中同时展示 inline、显式 math run 和 display 公式。"
/>

字符串中的公式 sugar 会由 Core 解析为 text run 和 math run：

| 写法                    | 含义                                       |
| ----------------------- | ------------------------------------------ |
| `$...$`                 | 行内公式，使用 inline 度量并和文字基线对齐 |
| `$$...$$`               | display 公式，使用更舒展的上下度量         |
| `\\$`                   | 字面美元符号，不作为公式分隔符             |
| `{ tex, displayMode? }` | 显式 math run；可逐段控制颜色或透明度      |

显式 run 可以和普通 text run 混排：

<DocTab value="react" label="React">

等待公式引擎就绪后，将 lowerTex 注入 Layout：

```tsx
import { Layout, Node } from '@retikz/react';
import { useLowerTex } from '@retikz/tex/react';

export const Formula = () => {
  const state = useLowerTex({ profile: 'math' });
  if (state.status === 'loading') return <div>Loading MathJax…</div>;
  if (state.status === 'error') return <div>{state.diagnostic.message}</div>;

  return (
    <Layout lowerTex={state.lowerTex}>
      <Node text={[{ runs: [{ tex: '\\sin\\alpha = \\frac{1}{2}', fill: 'red' }, { text: '（长度）' }] }]} />
    </Layout>
  );
};
```

</DocTab>
<DocTab value="vanilla" label="Vanilla">

创建公式引擎，将 Node 放入 scene，得到 SVG 字符串：

```ts
import { createMathJaxLowerTex } from '@retikz/tex';
import { node, renderToSvgString, scene } from '@retikz/vanilla';

const lowerTex = await createMathJaxLowerTex({ profile: 'math' });
const input = scene({
  children: [
    node('formula', {
      text: [{ runs: [{ tex: '\\sin\\alpha = \\frac{1}{2}', fill: 'red' }, { text: '（长度）' }] }],
    }),
  ],
});
const svg = renderToSvgString(input, { compile: { lowerTex } });
```

</DocTabs>

`displayMode` 只控制公式度量，不会把一个 Node 拆成多个 Node；多行 LaTeX 环境仍然作为一个公式片段参与同一行布局。中文注释建议使用 text run，由普通文本测量负责，不要依赖 MathJax 的 `\\text{}` 提供 CJK 字体覆盖。
