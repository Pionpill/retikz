When Node text needs LaTeX, continue to author formulas with `$...$`, `$$...$$`, or explicit math runs. After [installation and integration](/kernel/packages/tex), `@retikz/tex` converts them into glyph paths that Core consumes, so SVG and Canvas share the same formula result.

## Basic usage

Start with the three common forms: an inline formula in a string, a display formula in a string, and an explicit math run whose style can be controlled independently. The static demo below puts all three in one Layout so you can see their behavior in text:

<ComponentPreview
  files="tex-formula-basics.en"
  size="sm"
  caption="One Layout shows an inline formula, an explicit math run, and a display formula together."
/>

Core parses formula sugar in a string into text runs and math runs:

| Form                    | Meaning                                          |
| ----------------------- | ------------------------------------------------ |
| `$...$`                 | An inline formula aligned to the text baseline   |
| `$$...$$`               | A display formula with roomier vertical metrics  |
| `\\$`                   | A literal dollar sign, not a formula delimiter   |
| `{ tex, displayMode? }` | An explicit math run with local color or opacity |

An explicit run can mix with ordinary text runs:

```tsx
<Node
  text={[
    {
      runs: [{ tex: '\\sin\\alpha = \\frac{1}{2}', fill: 'red' }, { text: ' (red-line length)' }],
    },
  ]}
/>
```

`displayMode` changes formula metrics; it does not split one Node into several Nodes. A multiline LaTeX environment remains one formula fragment in the same line layout. Use a text run for CJK annotations instead of relying on MathJax `\\text{}` for CJK font coverage.
