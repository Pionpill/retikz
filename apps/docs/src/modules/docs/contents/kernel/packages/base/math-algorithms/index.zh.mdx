几何算法从已有点、线、圆和圆弧推导新的几何结果。它们不创建 IR，也不会抛出专门的几何异常；退化输入通过 `null`、空数组或布尔值表达。

```ts
import { circle, convexHull, curve, intersect, polygon, rayArc, triangle } from '@retikz/math';
import type { RayArcInput } from '@retikz/math';
```

默认容差是朴素的 `DEFAULT_EPSILON = 1e-9`，适合绘图尺度坐标，但不是任意数量级下的鲁棒几何谓词。

## 如何选择

| 问题                       | API                       | 结果                       |
| -------------------------- | ------------------------- | -------------------------- |
| 两条线、线段或圆在哪里相交 | `intersect.*`             | 单个交点、交点数组或无结果 |
| 射线与圆弧在哪里相交       | `rayArc`                  | 按升序排列的正向参数       |
| 三角形的内切圆或外接圆     | `triangle.*`              | `Circle` 或 `null`         |
| 覆盖一组点的最小圆         | `circle.minimalEnclosing` | `Circle` 或 `null`         |
| 一个点是否位于多边形内部   | `polygon.containsPoint`   | `boolean`                  |
| 一组点的最小凸边界         | `convexHull`              | 逆时针排列的边界顶点       |
| 一组 knot 的过点平滑曲线   | `curve.catmullRomToCubic` | 三次贝塞尔段数组           |

## 求交

`intersect` 按输入几何返回坐标点。直线由两点或原点加方向定义；方向向量不必单位化。

```ts
const hit = intersect.lineLine({
  a1: [-40, -20],
  a2: [60, 30],
  b1: [0, -50],
  b2: [0, 50],
});

const circleHits = intersect.lineCircle({
  origin: [-80, 0],
  dir: [1, 0],
  center: [0, 0],
  radius: 40,
});
```

用面板切换直线、直线与圆、两个圆，并选择相交、平行、相切和相离预设。紫色点就是 API 返回的坐标；面板中的 `|I|` 表示结果数组长度。

<ComponentPreview files="intersection-playground" size="sm" caption="求交结果与退化输入" />

| 函数             | 返回与退化行为                                                    |
| ---------------- | ----------------------------------------------------------------- |
| `lineLine`       | 两条无限直线的交点；平行或共线返回 `null`                         |
| `segmentSegment` | 两线段的单个交点；不相交、平行、共线或重叠返回 `null`             |
| `lineCircle`     | 0 或 2 个点；相切返回两个坐标相同的点                             |
| `circleCircle`   | 0 或 2 个点；相离、内含或重合返回空数组，相切返回两个坐标相同的点 |

射线与圆弧求交使用 `rayArc`；它返回射线参数而不是坐标点。

## 包围与包含

`triangle.circumCircle` 求过三个顶点的外接圆，`triangle.inCircle` 求与三边相切的内切圆；三点共线时两者返回 `null`。

`circle.minimalEnclosing(points)` 返回覆盖全部输入点的最小圆。空点集返回 `null`，单点返回半径为 `0` 的圆；实现是确定性的迭代式 Welzl，最坏时间复杂度 `O(n³)`、额外空间 `O(1)`。

`polygon.containsPoint(vertices, point)` 使用奇偶规则，支持凹多边形和任意绕向；顶点少于三个时返回 `false`。边界点结果未定义，需要调用方在重要场景中单独处理落边判断。

`convexHull(points)` 使用 Andrew monotone chain，返回逆时针顶点并剔除共线中间点。点数少于三个或全共线时，返回排序去重后的端点。

## 过点平滑曲线

`curve.catmullRomToCubic` 把 knot 序列转换为穿过每个 knot 的三次贝塞尔段链，也是 `<Step kind="smooth">` 使用的底层算法。

```ts
const segments = curve.catmullRomToCubic(
  [
    [-80, 20],
    [-20, -40],
    [30, 30],
    [90, -10],
  ],
  1,
);
```

它使用 centripetal Catmull-Rom（α=0.5），相较均匀参数化能降低点距不均时出现尖点或回环的风险，但不承诺任意 knot 和任意 `tension` 下都无自交。`tension = 1` 是标准值，较小值缩短手柄，较大值会放大弯曲。

<ComponentPreview files="curve-playground" size="sm" caption="knot、张力与三次贝塞尔结果" />

至少两个 knot 才会产生结果；返回 `knots.length - 1` 段，每段终点严格命中下一个 knot。开放曲线两端使用单侧切线，重合 knot 以 `DEFAULT_EPSILON` 作为间距回退以保持有限输出。

<Comparison target="tikz">
  TikZ 也用 `tension` 表达曲线松紧。迁移时可以从相同数值开始，再根据实际点距和是否出现过度弯曲调整。
</Comparison>

## API 摘要

| 分组       | 公开类型 / API                                                                        | 无结果或退化行为                                 |
| ---------- | ------------------------------------------------------------------------------------- | ------------------------------------------------ |
| 求交       | 三种输入类型、`intersect.lineLine` / `segmentSegment` / `lineCircle` / `circleCircle` | `null` 或空数组；相切保留两个重合点              |
| 射线与圆弧 | `RayArcInput`、`rayArc`                                                               | 零方向或无交点返回空数组；正向参数按升序返回     |
| 圆与三角形 | `Circle`、`triangle.inCircle`、`triangle.circumCircle`、`circle.minimalEnclosing`     | 共线三角形与空点集返回 `null`                    |
| 多边形     | `polygon.containsPoint`、`convexHull`                                                 | 少于三个顶点的包含判断为 `false`；凸包保留端点   |
| 曲线       | `CubicSegment`、`curve.catmullRomToCubic`                                             | 少于两个 knot 返回空数组；重合 knot 保持有限结果 |
