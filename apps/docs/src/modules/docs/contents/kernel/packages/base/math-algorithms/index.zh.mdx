几何原语负责描述点、向量、圆和圆弧；几何算法则把这些已有数据组合起来，回答“它们在哪里相交”“哪些点能被一个圆覆盖”或“怎样得到一条平滑曲线”等问题。算法只处理数学与几何关系，不创建 IR，也不依赖 renderer。

## 内容

### 求交

求交用于找出两条直线、两条线段、直线与圆，或两个圆之间的交点。结果是坐标点；没有交点或输入退化时，函数会返回 `null` 或空数组。

用面板切换直线、线段、直线与圆、两个圆，并尝试相交、平行、相切和相离情况。选择“显示段外的直线交点”时，画面中的实线只是为了适配画布而截取的有限显示段，但 `lineLine` 仍按无限延长线计算，因此两段实线没有碰到时也会显示紫色交点；选择“不相交线段”可以对比 `segmentSegment` 的有限范围。

<ComponentPreview files="intersection-playground" size="md" caption="切换几何关系，观察交点和退化结果" />

#### API 参考

本节的输入类型包括 `LineLineInput`（两条由端点定义的直线或线段）、`LineCircleInput`（直线与圆）和 `CircleCircleInput`（两个圆）。下表列出实际执行求交的方法

| API                        | 复杂度               | 作用                                                             |
| -------------------------- | -------------------- | ---------------------------------------------------------------- |
| `intersect.lineLine`       | 时间 O(1)，空间 O(1) | 计算两条无限直线的交点；平行或共线时返回 `null`                  |
| `intersect.segmentSegment` | 时间 O(1)，空间 O(1) | 计算两条线段的交点；不相交、平行、共线或重叠时返回 `null`        |
| `intersect.lineCircle`     | 时间 O(1)，空间 O(1) | 计算直线与圆的交点；返回 0 或 2 个点，相切时保留两个重合点       |
| `intersect.circleCircle`   | 时间 O(1)，空间 O(1) | 计算两个圆的交点；相离、内含或重合时返回空数组，相切时返回重合点 |

### 射线与圆弧求交

射线与圆弧的输入包含圆弧的圆心、半径、起始角度和终止角度。`rayArc` 返回射线参数 `s`，实际交点可按 `origin + s * dir` 得到；它只保留射线正方向上的交点。

#### 射线与圆弧 API

输入类型 `RayArcInput` 描述射线起点、方向和圆弧范围。下表列出求交方法

| API      | 复杂度               | 作用                                               |
| -------- | -------------------- | -------------------------------------------------- |
| `rayArc` | 时间 O(1)，空间 O(1) | 返回射线与圆弧交点的正向参数，并按参数从小到大排列 |

### 圆与三角形

这一组算法从三角形或点集构造圆。通过“构造方式”切换只查看一种方案：外接圆经过三角形的三个顶点，内切圆与三条边相切，最小包围圆则覆盖给定点集。面板中的二维控制点就是算法输入，移动它们可以观察圆如何随几何关系变化；三点共线等退化情况返回 `null`。

下方示意只展示当前选中的圆构造方案，避免把不同问题的结果混在一起。

<ComponentPreview files="circle-constructions" size="md" caption="比较三角形外接圆、内切圆和点集最小包围圆" />

#### API 参考

相关类型 `Circle` 用圆心和半径表示一个圆。下表列出三种圆构造方法

| API                       | 复杂度                   | 作用                                                |
| ------------------------- | ------------------------ | --------------------------------------------------- |
| `triangle.circumCircle`   | 时间 O(1)，空间 O(1)     | 根据三个顶点构造外接圆；三点共线或退化时返回 `null` |
| `triangle.inCircle`       | 时间 O(1)，空间 O(1)     | 根据三个顶点构造内切圆；三角形退化时返回 `null`     |
| `circle.minimalEnclosing` | 平均时间 O(n)，空间 O(1) | 构造覆盖全部输入点的最小圆；空点集返回 `null`       |

### 多边形与凸包

多边形包含判断回答一个点是否位于多边形内部，支持凹多边形和不同的顶点绕向。凸包则从一组点中筛出最外层的边界点，得到一个按逆时针排列的凸多边形。两者用途不同：包含判断保留原多边形形状，凸包会包住凹陷区域。

下方示意中，浅灰线是原多边形，橙色线是凸包。面板提供多个可移动测试点：点在多边形内部时显示为绿色，点在外部时显示为红色；默认点集同时展示普通内部点、外部点和凹陷区域外的点。

<ComponentPreview files="polygon-containment" size="md" caption="同时观察多边形包含判断与凸包边界" />

`polygon.containsPoint` 的边界点结果未定义；如果边界归属会影响业务结果，应在调用方补充点在线段上的判断。`convexHull` 会去重并剔除共线的中间点，少于三个点或全部共线时返回排序后的端点集合。

#### API 参考

| API                     | 复杂度                     | 作用                                   |
| ----------------------- | -------------------------- | -------------------------------------- |
| `polygon.containsPoint` | 时间 O(n)，空间 O(1)       | 用奇偶规则判断点是否在简单多边形内部   |
| `convexHull`            | 时间 O(n log n)，空间 O(n) | 从点集构造逆时针凸包，并去除共线中间点 |

### 过点曲线

过点曲线把一组 knot 转换为连续的三次贝塞尔段。曲线会经过输入 knot，而不是只在它们附近平滑；`tension` 用来控制控制点距离和弯曲程度。这个算法也是 `<Step kind="smooth">` 的底层实现。

切换点集和张力，并移动面板中的控制点，观察点距不均、折返和重合点时的曲线变化。源码视图中的 `CubicSegment` 展示了每段三次贝塞尔曲线的两个控制点和终点。

<ComponentPreview files="curve-playground" size="md" caption="比较点集、张力与三次贝塞尔段" />

至少需要两个 knot；返回的段数为 `knots.length - 1`，每段终点严格命中下一个 knot。开放曲线两端使用单侧切线，重合 knot 仍保持有限输出，但不保证任意输入下都没有自交。

#### API 参考

相关类型 `CubicSegment` 表示一段三次贝塞尔曲线的两个控制点和终点。下表列出过点曲线转换方法

| API                       | 复杂度               | 作用                                 |
| ------------------------- | -------------------- | ------------------------------------ |
| `curve.catmullRomToCubic` | 时间 O(n)，空间 O(n) | 把 knot 序列转换为连续的三次贝塞尔段 |
