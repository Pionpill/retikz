---
title: Inspection flow
description: Follow ordinary results through selection, auxiliary compilation, and independent presentation
---

Inspect runs after primary compilation. It registers no compiler observer.

```text
Ordinary input → Core compile → CompileResult → Primary commit and display
                                    ↓
                             Inspect requests
                                    ↓
                             Ordinary guide IR
                                    ↓
                             Core compile
                                    ↓
                             Independent read-only layer
```

## Results and selection

A primitive target path starts at scene.primitives and continues through group.children. An artifact target index addresses the artifacts array of that result. Both identify positions in the current snapshot, not stable identities across revisions.

Requests validate options and targets before callbacks run. Duplicate requests for one inspector and target fail; different inspectors may share a target. Omitting target selects every matching object. Authored self, subtree, inheritance, and barrier rules are not supported.

## Coordinates and resources

Local primitive guides use the actual group transform chain. Scene-space guides use an identity matrix. Artifacts have no implicit transform: their domain contract must establish Scene coordinates, or report UnsupportedGeometry.

Auxiliary content uses an independent ordinary compilation environment. It cannot access private primary layout, themes, or named references. Auxiliary Scenes remove public identity, meta, and animation while preserving their own resource references.

## Updates and failures

After a primary update, remove old guides before inspecting the new result. Guides are not required participants in the primary transaction. Inspection failures leave the primary drawing visible, without stale guides. Unmounting releases auxiliary surfaces.

The synchronous compile API throws RetikzInspectError with its original cause. Host preparation returns a separate error. UnsupportedGeometry is non-fatal; supported inspection output may still be drawn.
