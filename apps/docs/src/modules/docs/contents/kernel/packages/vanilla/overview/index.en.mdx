`@retikz/vanilla` is the API foundation shared by all framework adapters. It organizes ordinary TypeScript data as an `InputScene`, normalizes that input into Core `IRScene`, and runs shared processing. React, Vue, and other framework packages only collect their framework input and host the result.

The package root works safely in SSR, build scripts, and other frameworks. Its default text measurer probes browser Canvas when measurement is requested. Browser SVG and Canvas mounting live at `@retikz/vanilla/dom`. IR, schemas, geometry, and compile rules belong to `@retikz/core`; backend output belongs to `@retikz/render`.

Applications use `SceneRuntime` or `compileToScene` from the package root.

Use `runtime.diagnostics()` to read retained session diagnostics.

One-shot compilation and retained updates share input preparation. One-shot compilation returns a `CompileResult` directly. In retained mode, `runtime.read()` and subscribers receive the same committed `ReconcilerResult` snapshot. Read the frame’s output from `snapshot.compilation.result` and pass the snapshot itself as `expected` for incremental updates. Subscribers may read the new result, but cannot start another synchronous update during that notification. A precompiled Scene goes straight to Render without creating a compilation session.

To export an already compiled Scene, call `renderToSvgString(scene)`. It serializes the scene without recompiling it.

## One-shot compilation

Pass Core IR or a Vanilla InputScene to `compileToScene` to obtain a Scene and artifacts without creating or disposing a session. Compile configuration stays under `options.compile`.

```ts
import { compileToScene } from '@retikz/vanilla';

const result = compileToScene(ir);
const configured = compileToScene(ir, { compile: { padding: 10 } });

console.log(result.scene, result.artifacts);
```

One-shot compilation returns a `CompileResult` with the scene and artifacts; use `compileLayers` for a separate ordered list of named results. Use `SceneRuntime` for subsequent updates and subscriptions, or `normalizeXxx` when only assembling typed Input into Core IR.

## Update a single drawing

Create a session with `SceneRuntime.fromInput(input, options)` or `SceneRuntime.fromIR(ir, options)`.

```ts
import { SceneRuntime } from '@retikz/vanilla';

const runtime = SceneRuntime.fromInput(input);
try {
  runtime.replace(nextSource);
  const svg = runtime.renderToSvgString();
} finally {
  runtime.dispose();
}
```

A full replacement may switch between authored input and IR; it does not infer a diff. In incremental mode, read the current version with `expected = runtime.read()`, resolve addresses with `runtime.getScopeId(path, expected)`, then submit `runtime.update(batch, expected)`. Stale versions are rejected. Exporting reads the last committed frame.

## Default text measurement

An explicit `compile.measureText` takes precedence. Otherwise, Vanilla lazily uses Canvas 2D, falling back to the Core estimator when the environment or context is unavailable. Measurement failures and invalid metrics still fail. React's `Layout` uses the same default path.

When text has no explicit font family, the default browser measurer uses the computed font of the page’s `body`, then `sans-serif`. Host CSS affects display, not the geometry of an existing Scene. See [Text Metrics](/kernel/components/runtime-mechanics/text-metrics).

## Submit ready input

Await external data before constructing the input and calling `compileToScene` or the runtime’s `replace`. Updates follow submission order. The application decides whether to ignore an older request that finished late. Each embed adapter’s `lower` synchronously returns its node, dependencies and per-instance runtime inputs; those inputs stay outside JSON IR.

For example, submit a Plot that uses an external executor alongside an ordinary node in one update:

```ts
import { preparePlotData } from '@retikz/plot';
import { plotInputEmbedAdapter } from '@retikz/plot-vanilla';
import { embed, node, scene } from '@retikz/vanilla';

const task = await preparePlotData(spec, { dataBindings, dataTransformExecutor });
const preparedData = await task.execute();
runtime.replace(
  scene({
    children: [
      node({ id: 'origin', position: [0, 0] }),
      embed({ adapter: plotInputEmbedAdapter, props: { spec, preparedData } }),
    ],
  }),
);
```

## Install and use

```bash
pnpm add @retikz/vanilla
```

```ts
import { compileToScene, node, path, renderToSvgString, scene } from '@retikz/vanilla';
import { mount } from '@retikz/vanilla/dom';

const input = scene({
  children: [
    node({ id: 'a', position: [0, 0], text: 'A' }),
    node({ id: 'b', position: [120, 0], text: 'B' }),
    path({ id: 'edge', way: ['a', 'b'], arrow: { end: {} } }),
  ],
});

const compileResult = compileToScene(input);
const svg = renderToSvgString(compileResult.scene);
const view = mount(document.querySelector('#diagram')!, input);
```

`renderToSvgString` needs no DOM, so it suits SSR, build-time generation, and saving SVG. `mount` hosts a browser view, creating SVG by default or Canvas with `renderer: 'canvas'`. The returned `view` owns later `update`, interaction hydration, animation controls, and disposal.

`scene({ theme: { name, mode } })` writes a sparse Theme to the Input root, while `scope({ theme }, children)` uses the same local-inheritance form. Normalization reuses the Theme reference without mutating caller input; both routes finally use the same Core Theme and compile contract.

## Input normalization and processing

### Declare identity in the configuration

Node, Path, and Scope objects written directly in `children` must declare their `type`. The `node()`, `path()`, and `scope()` helpers and their JSX counterparts supply it for you.

Vanilla path configurations require exactly one of `way` and `children`. The `way` parser checks operator and target order. Explicit `children` expand shorthand without a minimum step count: Core diagnoses short paths during compilation, whether or not `authoring` is set. Both components of a relative offset string must be finite. Three-leg folds (`-|-` or `|-|`) accept `fraction` to position the middle leg.

Vanilla constructors do not take a separate ID string argument. `node({ id, position })`, `path({ id, way })`, `coordinate({ id, position })`, and `layer({ name, scene })` read identity from their configuration. Each input contract still determines whether `id` is required.

Domain builders also take their configuration directly, such as `shape.circle({ id, center, radius })` and `entity({ id, role, position })`. Inputs with a domain `id` reuse it as the embed identity; anonymous inputs do not gain a referenceable graphic ID. Layout inputs have no domain `id`, so use entries such as `flexLayout({ children })` directly.

Use the embed factory to pair `adapter` with `props`, and optional `id` and `authoring` fields: `embed({ adapter, props })`. Plot and Table use `embedPlot(source, datasets, lowerOptions?)` and `embedTable(spec, options?)`, without an extra embed ID argument.

### Why InputScene exists

Directly building `@retikz/core` IR is valid, but applications often need authoring-friendly Path, Scope, Layer, Tier 2 embeds, and authoring payloads. `scene`, `layer`, `node`, `path`, `scope`, and `embed` construct those inputs as ordinary data, without JSX, a React runtime, or component lifecycles.

`InputScene` is not a second graphics semantic. `normalizeScene()` centrally handles input sugar, authoring provenance, and embed lowering, then produces the only Core `IRScene`. The resulting IR remains JSON-serializable; callers and their domain adapters decide whether `authoring` and `embed.props` are serializable.

## Execution and DOM boundary

| API                 | Purpose                             | Returns                      |
| ------------------- | ----------------------------------- | ---------------------------- |
| `renderToSvgString` | Produce an `<svg>` string for SSR   | `string`                     |
| `mount`             | Mount SVG or Canvas by `renderer`   | `VanillaView` / `CanvasView` |
| `mountSvg`          | Explicitly mount SVG DOM            | `VanillaView`                |
| `mountCanvas`       | Explicitly mount Canvas             | `CanvasView`                 |
| `hydrate`           | Bind handlers to SSR / existing SVG | `HydrationHandle`            |

The last four APIs are imported from `@retikz/vanilla/dom`. By default, `InputScene` and `IRScene` create a `VanillaViewMode.Retained` view. `update(next, options?)` atomically publishes the same processing transaction's Scene, artifacts, events, and animation. A failed transaction publishes no new revision; if rollback itself fails, the view becomes broken and must be disposed and remounted.

With `runtime: { mode: 'static' }`, every `update()` of an `InputScene` or `IRScene` fully normalizes, compiles, and redraws without a Session, Snapshot, Patch, transaction, or rollback. A precompiled `Scene` is always static and accepts only another `Scene`.

`mode` and `updateStrategy` are fixed when mounting. `VanillaRetainedRuntimeOptions` permits `rendererFactory`; it is an optional DOM retained-backend extension point, and static mode rejects it. Dispose and remount to change the renderer, DPR, compile topology, or retained strategy.

## Layers and embeds

Direct children use an implicit main layer and return a single result. `compileLayers(layers)` always returns an ordered list of named results, even for zero or one layer. The default stacking values for background, main, and overlay are 0, 10, and 100; custom names default to 10. Ties keep declaration order. References and element stacking stay within a layer.

Each layer owns its scene, including its theme and viewBox. Create a stack with `createLayerController(layers, options)`. Layers inherit the shared compile and reconciler options; use `layer.config` to override them. The background preset selects full compilation; settings on the instance override that preset. Use `controller.replaceLayer` to update an overlay without resubmitting the background. Rendering still accepts one graph: pass an retained entry’s `result.compilation.result.scene` to render it individually. The renderer does not composite the list.

Tier 2 capabilities enter through `embed({ adapter, id, props })`. Vanilla does not parse components or run hooks. It calls the adapter bound to that node, lowering typed props into a Core child and Composite dependency contribution.

```ts
import type { InputEmbedAdapter } from '@retikz/vanilla';
import { compileLayers, embed, layer, node, scene } from '@retikz/vanilla';

type BadgeProps = { label: string };

const BadgeInputEmbedAdapter: InputEmbedAdapter<BadgeProps> = {
  kind: 'badge',
  lower: (props, context) => ({
    node: node({ id: `${context.id}/label`, position: [0, 0], text: props.label }),
    providerDependencies: { roots: [], providers: [] },
  }),
};

const layers = [
  layer({
    name: 'content',
    scene: scene([embed({ adapter: BadgeInputEmbedAdapter, id: 'sales', props: { label: 'Sales' } })]),
  }),
];

const [{ name, result }] = compileLayers(layers);
console.log(name, result.scene);
```

`normalizeScene()` is exported from the package root. Hosts do not register adapters. To inspect a normalized result, call `normalizeScene(input)` and read the single result for `ir`, `contributions`, `runtimeInputs`, and `authoringSites`. Nodes without an `authoring` payload do not produce a site; sites explicitly contributed by adapters are retained.

Callers must keep compile and render options, composite definitions, and registered handler maps stable while in use. In-place mutation is unsupported; Vanilla does not guarantee isolation from its effects. A domain adapter can process new props at the same authored position; dispose and remount to change a Composite schema, definition count, or execution branch.

## Responsibility boundaries

| Capability              | What `@retikz/vanilla` owns                                 | Source of truth / boundary           |
| ----------------------- | ----------------------------------------------------------- | ------------------------------------ |
| Framework-neutral input | Builds InputScene, Layers, embeds, and Core primitive input | `@retikz/core` IR                    |
| Input normalization     | Lowers Input to IR and collects adapter contributions       | `@retikz/core` compile contract      |
| Shared processing       | Prepares input and manages the reconciler and results       | `@retikz/reconciler`                 |
| DOM host                | `/dom` SVG / Canvas output, updates, hydration, animation   | `@retikz/render` backend execution   |
| Tier 2 embeds           | Dispatches Input adapters and collects lowering results     | Domain packages own props / lowering |

React applications use [`@retikz/react`](/kernel/packages/react/overview) to collect JSX. Other frameworks should reuse this package's Input and processing in the same way. Use the relevant Vanilla entry directly for SSR strings or direct DOM / Canvas mounting.
