`@retikz/math` provides zero-dependency, deterministic two-dimensional numeric and computational-geometry utilities, including points, bounds, affine transforms, arcs, intersections, and curve algorithms.

The package provides only its root entry. Import public APIs from `@retikz/math`; the `algorithms`, `primitives`, and `transforms` directories are package-internal organization only.

For first use, read [the usage topic](/kernel/packages/math/primitives).
