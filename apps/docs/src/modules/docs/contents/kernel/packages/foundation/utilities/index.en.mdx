These utilities carry no drawing-domain semantics and can be reused by Retikz internal packages and extensions.

## Readonly collection snapshots

`createReadonlyMap(entries)` copies input entries into an independent shallow snapshot. The result preserves native Map lookup, iteration, and insertion order without exposing `set`, `delete`, or `clear`; entry values retain their original identity and are not deep-copied or frozen.

```ts
const definition = { kind: 'point' };
const source = new Map([['point', definition]]);
const definitions = createReadonlyMap(source);

source.clear();
definitions.has('point'); // true
```

## JSON data snapshots

`cloneAndFreezeJson(value, path)` validates JSON-safe plain data and returns a detached deeply frozen copy. Cycles, accessors, symbol keys, sparse arrays, extra array properties, non-finite numbers, and class instances throw `RetikzFoundationError`.

```ts
const snapshot = cloneAndFreezeJson({ filters: [{ field: 'age', value: 18 }] });

Object.isFrozen(snapshot); // true
Object.isFrozen(snapshot.filters); // true
```

`assertPlainDataContainers(value, path)` checks container structure without copying data or reading accessors. It is reserved for runtime Definition boundaries that have no persisted schema but still need plain-container isolation. Source inputs with an owner schema consume the Zod `parse()` result directly instead of using this assertion as a generic preflight.

## Static CSS colors

`parseStaticCssColor(input)` parses a CSS color that needs no host environment into normalized sRGB channels `{ r, g, b, a }`; `compositeOpaqueColor(foreground, backdrop, weight)` precomposes a static foreground at a `0..1` weight over an opaque backdrop and returns lowercase `#rrggbb`.

```ts
parseStaticCssColor('darkorange');
compositeOpaqueColor('#336699', '#ffffff', 0.2); // '#d6e0eb'
```

The normal path validates the weight, parses foreground and backdrop, requires an opaque backdrop, then uses `foreground.a × weight` as the effective alpha for source-over sRGB precomposition. Any validation or parsing failure throws `RetikzFoundationError`.
