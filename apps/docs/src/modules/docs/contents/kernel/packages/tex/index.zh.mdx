`@retikz/tex` 负责把 LaTeX 公式降解成 `@retikz/core` 可渲染的 glyph `PathPrim`。公式不是独立内容字段，而是**文本的一部分**：任意文本字符串里的 `$...$`（行内）/ `$$...$$`（display）在编译期解析成公式段；也可显式写 `{ runs: [...] }` 做文字 + 公式混排。降解能力经 `lowerTex` 注入，**core 不依赖 MathJax**。

## 安装与启用

`@retikz/tex` 提供 TeX → 字形路径的能力；MathJax 是 optional peerDependency，由应用安装并控制版本：

```bash
pnpm add @retikz/tex mathjax-full
```

React 里用 `useLowerTex` 启动 MathJax 并把能力注入 `<Layout lowerTex>`，然后在任意 `<Node>` 文本里写 `$...$`：

```tsx
import { Layout, Node } from '@retikz/react';
import { useLowerTex } from '@retikz/tex/react';

const Diagram = () => {
  const lowerTex = useLowerTex();

  return (
    <Layout lowerTex={lowerTex}>
      <Node position={[0, 0]}>{'$\\frac{a}{b} = c$'}</Node>
    </Layout>
  );
};
```

## 行内与 display 公式

`$...$` 用 inline 度量，贴着文字基线；`$$...$$` 用 display 度量（分式 / 求和 / 积分等更舒展）。一个 node 的内容整体就是一个 `$$...$$` 时，它等价于一块独立公式，按字形 bbox 定尺寸：

## 行内混排

最自然的数学叙述是文字夹公式。直接在字符串里混写即可——`$...$` 外是文字、内是公式，同一行共基线：

```tsx
<Node>{'当 $v = d/t$ 时，位移 $s = v t$'}</Node>
```

需要**逐段单独着色 / 样式**时，写显式 `runs`：每个 run 是 `{ text, fill?, font? }` 或 `{ tex, displayMode?, fill? }`：

```tsx
<Node text={[{ runs: [{ tex: '\\sin\\alpha = \\frac{1}{2}', fill: 'red' }, { text: '（红线长度）' }] }]} />
```

## Vanilla

`createMathJaxEngine(options?)`（await 启动）→ `createLowerTex` → 注入 vanilla `compile.lowerTex`；节点文本照常写 `$...$`。`options.packages` 会透传给 MathJax TeX input，默认是 `['base']`：

```ts
import { figure, node, renderToSvgString } from '@retikz/vanilla';
import { createMathJaxEngine, createLowerTex } from '@retikz/tex';

const lowerTex = createLowerTex(await createMathJaxEngine());
const spec = figure({
  children: [node('eq', { position: [0, 0], text: '$\\frac{a}{b} = c$' })],
});

const svg = renderToSvgString(spec, { compile: { lowerTex } });
```

## 语法

| 写法              | 含义                                                           |
| ----------------- | -------------------------------------------------------------- |
| `$...$`           | 行内公式（inline 度量，贴文字基线）                            |
| `$$...$$`         | display 公式（block 度量；独占一个 node 时 = 独立 / 带框公式） |
| `\$`              | 字面美元符号（不作分隔符）                                     |
| `{ runs: [...] }` | 显式 run 序列（canonical）；每 run 可单独 `fill` / `font`      |

## API 参考

| API                                  | 类型                                      | 描述                                                                                      |
| ------------------------------------ | ----------------------------------------- | ----------------------------------------------------------------------------------------- |
| `useLowerTex`（`@retikz/tex/react`） | `() => LowerTex \| undefined`             | React hook：启动 MathJax，返回可注入 `<Layout lowerTex>` 的函数；未就绪时为 `undefined`。 |
| `createMathJaxEngine`                | `(options?) => Promise<MathJaxSvgEngine>` | 创建 MathJax SVG 引擎；`packages` 透传给 MathJax TeX input，默认 `['base']`。             |
| `createLowerTex`                     | `(engine) => LowerTex`                    | 把引擎转换成 core 的 `lowerTex` 注入函数，按 `fontSize\|display\|tex` 缓存。              |
| `LowerTex`（`@retikz/core`）         | `(content, style) => LoweredTex \| null`  | core 注入点类型；失败返回 `null`，compile 发出 `TEX_INVALID`。                            |
