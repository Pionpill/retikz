`@retikz/tex` 是可选公式能力包，负责把 TeX 公式接入既有文本与渲染流程。

## 公式怎样进入图形

公式写法决定内容，MathJax 配置决定可识别的语法，接入函数将排版结果交回 Core 的文本布局。最终输出是普通字形路径，因此 SVG 与 Canvas 共用公式几何，不需要各自再解析 LaTeX。

下面同时展示行内、显式片段与展示公式。先确认目标排版效果，再按下方步骤启用公式能力；缓存和 SVG 转换细节留在实现原理中。

## 安装与使用

`mathjax-full` 是可选 peer dependency。使用内置 MathJax engine 时，应用需要和 `@retikz/tex` 一起安装它：

<PackageManagerInstall packages="@retikz/tex mathjax-full" />

按宿主选择注入入口。公式只有在 lowerer 注入后才会进入 MathJax lowering；未注入时，`$...$` 仍按普通文字兼容处理，显式 math run 会被跳过并产生 Core warning。

| 宿主    | 入口               | 接入位置                                                           |
| ------- | ------------------ | ------------------------------------------------------------------ |
| React   | `useLowerTex()`    | 在 `<Layout lowerTex={lowerTex}>` 注入 ready 状态的 lowerer        |
| Vanilla | `createLowerTex()` | 将 `{ compile: { lowerTex } }` 传给 `renderToSvgString` 等编译入口 |

<DocTabs defaultValue="react">
<DocTab value="react" label="React">
<DocSteps>
<DocStep title="导入内容">

`@retikz/tex/react` 导出 `useLowerTex`，用于管理公式引擎生命周期并提供 ready 状态的 lowerer。

```tsx
import { useLowerTex } from '@retikz/tex/react';
```

</DocStep>
<DocStep title="接入渲染">

只有 `ready` 时才把同步 lowerer 注入最外层 `Layout`，子级文本会复用这项编译能力。

```tsx
import { Layout, Node } from '@retikz/react';
import { useLowerTex } from '@retikz/tex/react';

const Diagram = () => {
  const lowerTexState = useLowerTex({ profile: 'math' });

  if (lowerTexState.status === 'loading') return <div>Loading MathJax…</div>;
  if (lowerTexState.status === 'error') return <div>{lowerTexState.diagnostic.message}</div>;

  return (
    <Layout lowerTex={lowerTexState.lowerTex}>
      <Node position={[0, 0]}>{'$\\frac{a}{b} = c$'}</Node>
    </Layout>
  );
};
```

`@retikz/tex/react` 只负责 React 生命周期和共享 engine，不改变 Core 的文本写法。

</DocStep>
</DocSteps>
</DocTab>
<DocTab value="vanilla" label="Vanilla">
<DocSteps>
<DocStep title="导入内容">

`@retikz/tex` 导出 `createMathJaxEngine` 和 `createLowerTex`：前者创建公式引擎，后者将引擎适配为可注入编译流程的 lowerer。

```ts
import { createLowerTex, createMathJaxEngine } from '@retikz/tex';
```

</DocStep>
<DocStep title="接入渲染">

通过 `compile.lowerTex` 将公式能力传给 `renderToSvgString`，得到 SVG 字符串。

```ts
import { node, renderToSvgString, scene } from '@retikz/vanilla';
import { createLowerTex, createMathJaxEngine } from '@retikz/tex';

const lowerTex = createLowerTex(await createMathJaxEngine({ profile: 'math' }));
const input = scene({
  children: [node('formula', { position: [0, 0], text: '$\\frac{a}{b} = c$' })],
});

const svg = renderToSvgString(input, { compile: { lowerTex } });
```

如果不需要拆开 engine 和 lowerer，也可以直接等待 `createMathJaxLowerTex(options)`。Vanilla 不需要安装 React，也不使用 `@retikz/tex/react`。

</DocStep>
</DocSteps>
</DocTab>
</DocTabs>
