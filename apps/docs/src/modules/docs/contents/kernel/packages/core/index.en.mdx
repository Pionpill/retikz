`@retikz/core` compiles authored input into deterministic Scenes and owns Core IR and extension contracts.

## Responsibilities

| Document                 | Responsibility                                      | Reach for it when                                                  |
| ------------------------ | --------------------------------------------------- | ------------------------------------------------------------------ |
| Compilation Flow         | Full compilation from IR to Scene                   | Understanding node layout, deferred paths, and result assembly     |
| Configuration resolution | From sparse declarations to layout input            | Understanding inheritance, colors, and Definition binding          |
| Coordinate resolution    | From position expressions to local and world points | Understanding references, anchors, namespaces, and Scope placement |
