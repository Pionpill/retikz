`@retikz/core` compiles authored input into deterministic Scenes and owns Core IR and extension contracts.

## Responsibilities

| Document                 | Responsibility                                       | Reach for it when                                                           |
| ------------------------ | ---------------------------------------------------- | --------------------------------------------------------------------------- |
| Compilation Flow         | Full compilation from IR to Scene                    | Understanding node layout, deferred paths, and result assembly              |
| Configuration resolution | From sparse declarations to layout input             | Understanding inheritance, colors, and Definition binding                   |
| Coordinate resolution    | From position expressions to local and world points  | Understanding references, anchors, namespaces, and Scope placement          |
| Node Compilation         | From text metrics to shape and text layout           | Understanding node dimensions, baselines, labels, and connection boundaries |
| Path Compilation         | From targets and steps to path primitives            | Understanding cursors, boundary intersections, arrows, and labels           |
| Composite Compilation    | From composite declarations to selected child output | Understanding proposals, isolated probes, and replay                        |
| Compilation Output       | Assembly and delivery of Scene and side results      | Resources, canvas, spatial data and observation outlets                     |
