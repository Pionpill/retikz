---
title: Core packages
description: Core packages own Kernel compilation contracts and incremental execution, turning authored input into consumable Scenes and runtime results.
---

Core packages answer the question, “How are graphics semantics compiled and executed?” `@retikz/core` owns domain-neutral IR, parsing, and compilation contracts; `@retikz/runtime` manages identity, Programs, Sessions, revisions, and transactions. Upper-level APIs consume these contracts instead of maintaining parallel execution paths.

## Responsibilities

| Package | Responsibility | Reach for it when |
| --- | --- | --- |
| `@retikz/core` | IR, compilation, Scene, and domain-neutral lowering | Understanding how primitives become a Scene |
| `@retikz/runtime` | Programs, Sessions, revisions, and transactions | Managing incremental execution or state ownership |
