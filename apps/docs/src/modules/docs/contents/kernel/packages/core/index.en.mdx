`@retikz/core` owns IR, Definitions, registries, compilation, and Scene semantics. `compileToScene()` remains the stateless full-compile entry; for state across revisions, `CoreOwnerDefinition` and `createCoreProgram()` connect the same compile semantics to `@retikz/runtime`.

## Complete Snapshots And The Core Program

Callers always submit a complete IR Snapshot. The Core owner copies, freezes, and compares the document. The Core Program reads that typed Snapshot, produces a complete `CompileResult`, `SceneRuntimeSnapshot`, and optional `ScenePatch`, then lets the Runtime Session publish them atomically.

<ComponentPreview files="core-runtime-program" size="xxl" hideCode />

Runtime does not interpret Nodes, Paths, Scopes, Composites, or Scenes. Core decides domain identities, compile diagnostics, and full-fallback `replaceScene` Patches; Runtime only constrains dependency order, candidate isolation, revisions, and publication.

## Basic Wiring

`CoreOwnerDefinition` and `createCoreProgram()` are ordinary Runtime Definitions, so they can share one Session with other domain Owners and Programs. The initial full run has no `patch`; a renderer mounts from the complete `snapshot`.

```ts
import { CORE_OWNER_KEY, CORE_PROGRAM_ID, CoreOwnerDefinition, createCoreProgram } from '@retikz/core';
import {
  createRuntimeOwnerInput,
  createRuntimeOwnerRegistry,
  createRuntimeProgramRegistry,
  createRuntimeSession,
} from '@retikz/runtime';

const ir = {
  version: 1,
  type: 'scene',
  children: [{ type: 'node', id: 'hello', position: [0, 0], text: 'Hello' }],
} as const;

const coreProgram = createCoreProgram({ padding: 16 });
const owners = createRuntimeOwnerRegistry({ builtins: [CoreOwnerDefinition] });
const programs = createRuntimeProgramRegistry({ owners, builtins: [coreProgram] });
const session = createRuntimeSession({
  owners,
  programs,
  initialSnapshots: [createRuntimeOwnerInput(CoreOwnerDefinition, ir)],
});

const { output, snapshot, patch } = session.artifact(coreProgram).value;
// output.result: complete CompileResult
// snapshot.revision: 0
// patch: undefined
```

The fixed identities are `CORE_OWNER_KEY = '@retikz/core/document'` and `CORE_PROGRAM_ID = { owner: CORE_OWNER_KEY, key: 'compile' }`. Do not copy the strings into a parallel owner.

## Artifact Contract

| Field                | Role                                                                                              |
| -------------------- | ------------------------------------------------------------------------------------------------- |
| `output.result`      | Complete Scene and typed artifacts equivalent to fresh `compileToScene()` for the same IR/options |
| `output.diagnostics` | Core compile warnings in canonical order; dispatched to `onWarn` only after a successful commit   |
| `snapshot`           | Deeply immutable Scene, document root identity, and topology for the current Session revision     |
| `patch`              | Atomic Scene Patch relative to the base revision; absent on the initial full run                  |

The initial run performs a full compile. When an update cannot be proven locally safe, the Program falls back to a full compile and publishes one `replaceScene` in `patch.operations`. Callers still consume the same Snapshot / Patch envelope instead of switching protocols.

Core cross-checks an optional ChangeSet against the complete previous and next Snapshots. The stable identity order must be identical, and one unique `update` hint must cover each changed value owned by the Scene root or a stable root child. Missing changes, reordering, anonymous or duplicate entities, Scopes, Composites, and add/remove/move hints are mismatches.

The current implementation takes the full fallback path for both matching and mismatching updates. An exact match only suppresses the mismatch diagnostic; it does not mean local incremental compilation has started.

On a mismatch, `CORE_CHANGESET_MISMATCH` is published once as a Runtime diagnostic only after the fallback commits successfully. It never enters `output.diagnostics` or `onWarn`. A failed fallback compile publishes neither that diagnostic nor a new revision or artifact.

The private Core Program read currently stores the immutable source Snapshot used by the next update. Dependency Programs, participants, and `session.artifact()` only receive the public read above; they cannot access that internal source state.

## Immutable Program Options

`createCoreProgram(options)` copies the option record, registry arrays, and Definition records at factory time while fixing callback references. Later mutations to the original arrays or Definition fields do not alter an existing Program.

To replace a measurer, lowerer, provider callback, or external state captured by one, dispose the old Session and create a new Program with new options. A new Program always starts with a full run. Runtime injects tracing through the Program context, so `trace` is not part of `CoreProgramOptions`.

## Public API

| Export                                                 | Role                                                                         |
| ------------------------------------------------------ | ---------------------------------------------------------------------------- |
| `CORE_OWNER_KEY` / `CORE_PROGRAM_ID`                   | Fixed identities for the Core document owner and compile Program             |
| `CoreOwnerDefinition`                                  | Capture/read/equality Definition for complete IR Snapshots                   |
| `createCoreProgram(options)`                           | Create a Runtime Program Definition while preserving composite artifacts     |
| `CoreChange`                                           | `add` / `update` / `remove` / `move` change-hint union                       |
| `CoreProgramOptions<TComposites>`                      | Program-lifetime `CompileOptions` without `trace`                            |
| `CoreProgramOutput<TComposites>`                       | Complete compile result and warnings                                         |
| `CoreProgramPublicRead<TComposites>`                   | Public `output`, `snapshot`, and optional `patch`                            |
| `CoreProgramDefinition<TComposites>`                   | Artifact-input, owned-artifact, and private/public read generic relationship |
| `RuntimeScene` / `SceneRuntimeSnapshot` / `ScenePatch` | Deeply readonly Scene and atomic Patch DTOs                                  |
