`@retikz/render` materializes renderer-agnostic Scenes into graphics and owns interactive hydration.

## Responsibilities

| Document  | Responsibility                            | Reach for it when                                |
| --------- | ----------------------------------------- | ------------------------------------------------ |
| Overview  | Shared rendering runtime and commit model | Understanding backend-shared rendering semantics |
| SVG       | SVG DOM or string materialization         | Needing inspectable vector output                |
| Canvas    | Immediate bitmap drawing and hit testing  | Drawing many primitives or updating frequently   |
| Hydration | Client event and animation binding        | Adding interaction to static output              |
