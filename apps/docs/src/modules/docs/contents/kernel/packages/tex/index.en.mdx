`@retikz/tex` is the optional formula package that integrates TeX into the existing text and rendering flow.

## How formulas enter a drawing

Authoring determines formula content, configuration selects available syntax, and integration returns typeset paths to Core text layout. SVG and Canvas share the resulting geometry without parsing LaTeX again.

Compare inline, explicit-run, and display formulas below. Choose the intended result before enabling formula support. Caching and SVG conversion details belong in Implementation.

## Installation and usage

`mathjax-full` is an optional peer dependency. Applications using the built-in MathJax engine install it together with `@retikz/tex`:

<PackageManagerInstall packages="@retikz/tex mathjax-full" />

Choose the injection entry for your host. Formulas enter MathJax lowering only after a lowerer is injected; without it, `$...$` strings stay compatible ordinary text and explicit math runs are skipped with a Core warning.

| Host    | Entry              | Integration point                                                                |
| ------- | ------------------ | -------------------------------------------------------------------------------- |
| React   | `useLowerTex()`    | Inject the ready lowerer with `<Layout lowerTex={lowerTex}>`                     |
| Vanilla | `createLowerTex()` | Pass `{ compile: { lowerTex } }` to `renderToSvgString` or another compile entry |

<DocTabs defaultValue="react">
<DocTab value="react" label="React">
<DocSteps>
<DocStep title="Imports">

`@retikz/tex/react` exports `useLowerTex` to manage the formula engine lifecycle and provide a ready lowerer.

```tsx
import { useLowerTex } from '@retikz/tex/react';
```

</DocStep>
<DocStep title="Integrate and render">

Inject the synchronous lowerer into the outer `Layout` only when ready. Descendant text reuses the capability.

```tsx
import { Layout, Node } from '@retikz/react';
import { useLowerTex } from '@retikz/tex/react';

const Diagram = () => {
  const lowerTexState = useLowerTex({ profile: 'math' });

  if (lowerTexState.status === 'loading') return <div>Loading MathJax…</div>;
  if (lowerTexState.status === 'error') return <div>{lowerTexState.diagnostic.message}</div>;

  return (
    <Layout lowerTex={lowerTexState.lowerTex}>
      <Node position={[0, 0]}>{'$\\frac{a}{b} = c$'}</Node>
    </Layout>
  );
};
```

`@retikz/tex/react` owns the React lifecycle and shared engine; it does not change Core’s text syntax.

</DocStep>
</DocSteps>
</DocTab>
<DocTab value="vanilla" label="Vanilla">
<DocSteps>
<DocStep title="Imports">

`@retikz/tex` exports `createMathJaxEngine` and `createLowerTex`: the former creates the formula engine, and the latter adapts it into a lowerer for injection into compilation.

```ts
import { createLowerTex, createMathJaxEngine } from '@retikz/tex';
```

</DocStep>
<DocStep title="Integrate and render">

Pass the lowerer as `compile.lowerTex` to `renderToSvgString` to produce an SVG string.

```ts
import { node, renderToSvgString, scene } from '@retikz/vanilla';
import { createLowerTex, createMathJaxEngine } from '@retikz/tex';

const lowerTex = createLowerTex(await createMathJaxEngine({ profile: 'math' }));
const input = scene({
  children: [node({ id: 'formula', position: [0, 0], text: '$\\frac{a}{b} = c$' })],
});

const svg = renderToSvgString(input, { compile: { lowerTex } });
```

If the engine and lowerer do not need separate configuration, await `createMathJaxLowerTex(options)` instead. Vanilla does not require React or `@retikz/tex/react`.

</DocStep>
</DocSteps>
</DocTab>
</DocTabs>
