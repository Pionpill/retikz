`@retikz/tex` provides optional TeX formula parsing, SVG glyph lowering, and MathJax integration for the Core text pipeline.

The package has two entry points. Import runtime-neutral engines, lowerers, and configuration from `@retikz/tex`; import `useLowerTex` from `@retikz/tex/react` inside React components. React is an optional peer dependency, so the Hook lives on a separate subpath and non-React consumers do not statically depend on React.
