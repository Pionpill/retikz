`@retikz/foundation` 提供不属于特定绘图领域、但可被所有包复用的基础契约。

## 从配置到共享快照

假设你正在编写一个 Retikz 扩展：配置需要用类型或 schema 表达边界，注册后又要避免外部修改影响运行结果，失败时还要让调用方知道由哪个包负责。这三件事分别对应基础契约、快照工具和结构化错误。它们可以独立使用，不要求每次调用都经过全部步骤。

下面的例子把配置复制为冻结快照。随后修改原始配置，快照仍保持注册时的值；这适合将一份配置交给多个消费者读取。若只需保护集合结构，可以使用只读 Map；集合中的对象仍保留原身份，不能把浅只读当作深冻结。

## 使用边界

Foundation 只提供生态内共享的原子能力。图元字段由 Core 校验，几何计算由 Math 负责，主题继承由消费主题的能力处理。已有领域 schema 时直接使用其解析结果，不要额外套一轮 JSON 校验。需要复制并冻结独立数据时，再选择快照工具。

## 安装与使用

<PackageManagerInstall packages="@retikz/foundation" />

```ts
import { cloneAndFreezeJson } from '@retikz/foundation';

const source = { id: 'diagram', settings: { grid: true } };
const snapshot = cloneAndFreezeJson(source, 'diagram config');

source.settings.grid = false;
snapshot.settings.grid; // true
Object.isFrozen(snapshot.settings); // true
```

上面的代码只是一个示例。Foundation 提供 Retikz 生态内可复用、与业务领域无关的基础能力。
