title: Vanilla Runtime
description: Author figures outside React with a plain spec, then render the same description to SVG, Canvas, or an SSR string.

`@retikz/vanilla` is the framework-free entry. It does not require JSX or a React runtime. You describe a figure as a plain spec, then render it with `mount`, `mountSvg`, `mountCanvas`, or `renderToSvgString`.

This package is only an adapter. Geometry, paths, composite lowering, and rendering still come from `@retikz/core` and `@retikz/render`.

## Basic Shape

```ts
import { figure, layer, mount, node, path, renderToSvgString, VanillaLayerCache } from '@retikz/vanilla';

const spec = figure({
  id: 'flow',
  layers: [
    layer('main', { cache: VanillaLayerCache.Static }, [
      node('a', { position: [0, 0], text: 'A' }),
      node('b', { position: [120, 0], text: 'B' }),
      path('edge', {
        way: ['a', 'b'],
        marks: [{ pos: 1, mark: { kind: 'arrow' } }],
      }),
    ]),
  ],
});

const svg = renderToSvgString(spec);
const view = mount(document.querySelector('#diagram')!, spec);
```

`figure({ children })` creates a default layer. Use explicit `layers` when you need draw ordering, stable layer ids, or `cache` metadata. Updates in v0.4 still rerender the full figure and do not provide local invalidation.

## From Spec To Output

A plain spec first goes through `normalizeFigureSpec` to produce core IR (the JSON drawing contract), then through `compileToScene` to create the `Scene` consumed by renderers. `renderToSvgString`, `mountSvg`, and `mountCanvas` run this pipeline automatically when their input is a plain spec.

## Runtime Entries

| API                 | Purpose                                   | Returns                      |
| ------------------- | ----------------------------------------- | ---------------------------- |
| `renderToSvgString` | Produce an `<svg>` string for SSR         | `string`                     |
| `mount`             | Mount SVG or Canvas by `renderer`         | `VanillaView` / `CanvasView` |
| `mountSvg`          | Mount an SVG DOM explicitly               | `VanillaView`                |
| `mountCanvas`       | Mount a Canvas explicitly                 | `CanvasView`                 |
| `hydrate`           | Bind handlers to SSR / existing SVG roots | `HydrationHandle`            |

`view.update(nextSpec)` still rerenders the whole figure, while keeping the root element identity stable. Layer order, layer ids, the `cache` hint, and child identities are retained in `view.runtimeMeta`; this metadata does not mean local patching or invalidation is available.

## Options Shape

Render options are grouped by the stage that consumes them:

```ts
renderToSvgString(spec, {
  output: { width: 640, height: 360, idPrefix: 'flow' },
  compile: { composites, measureText },
  animation: { enabled: true },
});

mount(canvasRoot, spec, {
  renderer: 'canvas',
  output: { width: 640, height: 360 },
  canvas: { devicePixelRatio: 2 },
});
```

`figure()` describes the figure. `output` controls display size and resource ids, `compile` injects core compile capabilities, `animation` controls playback or snapshots, and `canvas` is only for the Canvas backend.

Omit `animation.enabled` to follow the system's reduced-motion preference. Explicit `true` forces playback on, and explicit `false` forces it off. `snapshotAt` still overrides playback and produces a static frame.

## Layers And Embeds

`layer(id, options, children)` is an authoring boundary. `cache` is a hint retained in runtime metadata and does not enter core IR. `zIndex` only orders the layer stack; equal values keep declaration order.

Tier 2 capabilities enter through `embed(kind, id, props)`. Vanilla does not parse components or run hooks. It finds an injected adapter by `kind` and statically lowers props into a core IR child, datasets, and composite definitions.

```ts
import type { VanillaTier2Adapter } from '@retikz/vanilla';
import { embed, figure, layer, node, renderToSvgString } from '@retikz/vanilla';

type BadgeProps = { label: string };

const badgeAdapter: VanillaTier2Adapter<BadgeProps> = {
  kind: 'badge',
  namespace: 'badge',
  lower: (props, context) => ({
    node: node(`${context.id}/label`, { position: [0, 0], text: props.label }),
    datasets: {},
    makeComposites: () => [],
  }),
};

const spec = figure({
  layers: [layer('content', [embed('badge', 'sales', { label: 'Sales' })])],
});

const svg = renderToSvgString(spec, { adapters: [badgeAdapter] });
```

`normalizeFigureSpec` is exported from the `@retikz/vanilla` package root. `adapters` is a top-level render / mount option, not a field inside `compile`. To inspect normalization before rendering, call `normalizeFigureSpec(spec, { adapters })` directly and read its `ir`, `composites`, and `runtimeMeta` result.

## API Summary

| API                   | Kind          | Description                                        |
| --------------------- | ------------- | -------------------------------------------------- |
| `figure`              | authoring     | Builds the plain spec root                         |
| `layer`               | authoring     | Builds a layer with ordering and metadata          |
| `node`                | authoring     | Builds a named or anonymous node                   |
| `coordinate`          | authoring     | Builds a named coordinate with a required id       |
| `path`                | authoring     | Builds a path; `way` reuses Draw way DSL           |
| `scope`               | authoring     | Builds a style and namespace scope                 |
| `embed`               | authoring     | Builds a Tier 2 embed node                         |
| `VanillaLayerCache`   | authoring     | Provides the layer `cache` metadata values         |
| `isVanillaFigureSpec` | normalization | Checks for a version 1 plain spec                  |
| `normalizeFigureSpec` | normalization | Produces core IR, composites, and runtime metadata |
| `VanillaTier2Adapter` | type          | Defines lowering for `embed()`                     |
