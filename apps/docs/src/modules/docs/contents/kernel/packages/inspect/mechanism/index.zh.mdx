---
title: 检查流程
description: 理解普通结果、目标选择、辅助编译和独立呈现之间的数据流
---

Inspect 在主图编译之后工作，不注册编译观察者。

```text
普通输入 → Core compile → CompileResult → 主图提交与显示
                              ↓
                       Inspect requests
                              ↓
                       普通辅助 IR
                              ↓
                       Core compile
                              ↓
                       独立只读辅助层
```

## 结果与选择

primitive target 的 path 从 scene.primitives 开始，后续下标进入 group.children；artifact target 的 index 指向同次结果的 artifacts。它们都是当前快照的位置，不是跨 revision 的稳定身份。

请求先验证选项与目标，再执行回调。同一 Inspector 重复选择同一对象会失败；不同 Inspector 可以检查同一对象。省略 target 表示所有匹配对象，不再支持作者 self、subtree、继承覆盖或 barrier。

## 坐标与资源

图元的 local 辅助内容使用真实 group 链的组合变换，scene 内容使用单位矩阵。artifact 没有隐式变换，只能在领域契约足以确定 Scene 坐标时绘制；缺少映射应报告 UnsupportedGeometry。

辅助内容使用独立的普通编译环境，不读取主图私有布局、主题或命名引用。辅助 Scene 移除公共身份、meta 和动画，保留自身资源引用。

## 更新与失败

主图结果更新后撤下旧辅助层，再检查新结果。宿主不把辅助内容放进主图必需的提交事务；检查失败时主图仍显示，旧层不会留在新主图上。卸载时释放辅助表面。

同步编译入口抛出 RetikzInspectError 并保留 cause；宿主准备入口返回独立 error。UnsupportedGeometry 是非致命缺口，其他可支持的检查仍可绘制。
