`@retikz/render` 将 renderer-agnostic Scene 物化为具体图形，并承载交互水合。

## 职责一览

| 文档   | 职责                     | 适合何时查阅             |
| ------ | ------------------------ | ------------------------ |
| 概览   | 共享渲染运行时与提交模型 | 理解后端共用的渲染语义时 |
| SVG    | 物化为 SVG DOM 或字符串  | 需要可检查的矢量输出时   |
| Canvas | 即时位图绘制与命中查询   | 需要高频或大量图元绘制时 |
| 水合   | 绑定客户端事件与动画状态 | 需要为静态结果增加交互时 |
