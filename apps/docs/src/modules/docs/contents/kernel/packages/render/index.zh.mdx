---
title: 渲染包
description: 渲染包把统一的 Scene 落到 SVG、Canvas 和水合宿主，并保持不同后端共享同一份图形语义。
---

渲染包解决的是“编译后的 Scene 如何在宿主中物化”。`@retikz/render` 拥有 SVG、Canvas、事件和水合等后端契约；包内各文档分别说明通用渲染入口、具体后端和客户端水合边界。它不负责定义上层组件或领域 IR。

## 职责一览

| 文档 | 职责 | 适合何时查阅 |
| --- | --- | --- |
| `render` | 渲染入口、Scene 物化和通用 runtime | 需要理解后端共同契约时 |
| `render · SVG` | Scene 到 SVG DOM 或 SVG 字符串 | 需要默认矢量后端时 |
| `render · Canvas` | Scene 到 Canvas 位图和命中查询 | 需要高频重绘或大量图元时 |
| `render · 水合` | 静态输出后的事件与客户端绑定 | 需要给图元添加交互时 |
