Algorithms derive new geometry from existing points, lines, and circles. They create no IR and throw no geometry-specific exceptions; degenerate inputs are expressed as `null`, empty arrays, or booleans.

```ts
import { circle, convexHull, curve, intersect, polygon, triangle } from '@retikz/math';
```

The default tolerance is a naive `DEFAULT_EPSILON = 1e-9`. It suits drawing-scale coordinates but is not a robust predicate at arbitrary magnitudes.

## Choosing an algorithm

| Problem                                      | API                       | Result                                       |
| -------------------------------------------- | ------------------------- | -------------------------------------------- |
| Intersect lines, segments, or circles        | `intersect.*`             | One point, an array of points, or no result  |
| Find a triangle's in-circle or circum-circle | `triangle.*`              | `Circle` or `null`                           |
| Find the smallest circle enclosing points    | `circle.minimalEnclosing` | `Circle` or `null`                           |
| Test whether a point is inside a polygon     | `polygon.containsPoint`   | `boolean`                                    |
| Find the smallest convex boundary            | `convexHull`              | Boundary vertices in counter-clockwise order |
| Fit a smooth curve through knots             | `curve.catmullRomToCubic` | An array of cubic Bézier segments            |

## Intersections

`intersect` returns coordinate points for the selected geometry. A line is defined either by two points or by an origin plus direction; direction vectors need not be normalized.

```ts
const hit = intersect.lineLine({
  a1: [-40, -20],
  a2: [60, 30],
  b1: [0, -50],
  b2: [0, 50],
});

const circleHits = intersect.lineCircle({
  origin: [-80, 0],
  dir: [1, 0],
  center: [0, 0],
  radius: 40,
});
```

Use the panel to switch among line-line, line-circle, and circle-circle cases, then try crossing, parallel, tangent, and disjoint presets. Purple points are the returned coordinates; `|I|` is the result-array length.

| Function         | Returns and degeneracy                                                                                                 |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `lineLine`       | Infinite-line hit; parallel or collinear lines return `null`                                                           |
| `segmentSegment` | One segment hit; disjoint, parallel, collinear, or overlapping segments return `null`                                  |
| `lineCircle`     | 0 or 2 points; tangency returns two points with identical coordinates                                                  |
| `circleCircle`   | 0 or 2 points; disjoint, contained, or coincident circles return an empty array; tangency returns two identical points |

For ray-arc intersections, use `rayArc` from [Primitives](/kernel/packages/math/primitives); it returns ray parameters rather than coordinates.

## Enclosure and containment

`triangle.circumCircle` finds the circle through three vertices, while `triangle.inCircle` finds the circle tangent to all three sides. Both return `null` for collinear points.

`circle.minimalEnclosing(points)` returns the smallest circle covering every input. An empty set returns `null`, and one point returns a radius-zero circle. The deterministic iterative Welzl implementation has worst-case `O(n³)` time and `O(1)` auxiliary space.

`polygon.containsPoint(vertices, point)` uses the even-odd rule, supports concave polygons and either winding, and returns `false` for fewer than three vertices. Boundary points are undefined; handle on-edge tests separately when they matter.

`convexHull(points)` uses Andrew's monotone chain, returns counter-clockwise vertices, and drops collinear middle points. For fewer than three points or all-collinear input, it returns sorted, de-duplicated endpoints.

## Smooth curves through points

`curve.catmullRomToCubic` turns knots into a chain of cubic Bézier segments that passes through every knot. It is also the algorithm behind `<Step kind="smooth">`.

```ts
const segments = curve.catmullRomToCubic(
  [
    [-80, 20],
    [-20, -40],
    [30, 30],
    [90, -10],
  ],
  1,
);
```

It uses centripetal Catmull-Rom (α=0.5), which reduces the risk of cusps and loops with uneven spacing compared with uniform parameterization. It does not guarantee freedom from self-intersections for arbitrary knots and `tension`. `tension = 1` is standard; lower values shorten handles, while higher values amplify bends.

<ComponentPreview files="curve-playground" size="sm" caption="Knots, tension, and cubic Bézier output" />

At least two knots are required. The function returns `knots.length - 1` segments, and each endpoint lands exactly on the next knot. Open ends use one-sided tangents; coincident knots fall back to `DEFAULT_EPSILON` spacing to keep output finite.

<Comparison target="tikz">
  TikZ also uses `tension` for curve looseness. Start with the same value when migrating, then adjust for the actual
  spacing and any excessive bends.
</Comparison>

## API summary

| Group         | Public types / APIs                                         | No-result or degenerate behavior                                     |
| ------------- | ----------------------------------------------------------- | -------------------------------------------------------------------- |
| Intersections | Three input types plus four `intersect` methods             | `null` or empty array; tangency preserves two coincident hits        |
| Circles       | `Circle`, two `triangle` methods, `circle.minimalEnclosing` | Collinear triangles and empty point sets return `null`               |
| Polygons      | `polygon.containsPoint`, `convexHull`                       | Containment is `false` below three vertices; hull keeps endpoints    |
| Curves        | `CubicSegment`, `curve.catmullRomToCubic`                   | Below two knots returns an empty array; coincident knots stay finite |
