title: Algorithms
description: Full signatures for intersections, circle / triangle algorithms, point-in-polygon, convex hull, and splines — not re-exported by core; import from @retikz/math.
---

These are higher-level computations `@retikz/core` does **not** re-export; import them directly from `@retikz/math`:

```ts
import { intersect, circle, triangle, polygon, convexHull, curve } from '@retikz/math';
```

Degenerate inputs do not throw: intersections return `null` / `[]`, triangle circles return `null` on degeneracy. Tolerance is the naive `DEFAULT_EPSILON = 1e-9` (types in [Primitives](/kernel/packages/math/primitives)).

## Types

```ts
/** Circle: center + radius */
type Circle = { center: Position; radius: number };

type LineLineInput = {
  a1: Position;
  a2: Position;
  b1: Position;
  b2: Position;
};

type LineCircleInput = {
  origin: Position;
  dir: Position;
  center: Position;
  radius: number;
};

type CircleCircleInput = {
  centerA: Position;
  radiusA: number;
  centerB: Position;
  radiusB: number;
};
```

## intersect

Returns **points**: a single hit as `Position | null`, multiple as `Array<Position>`.

```ts
// two infinite lines (each by two points); parallel / collinear → null
intersect.lineLine(input: LineLineInput): Position | null;

// two segments; disjoint / parallel / collinear (incl. overlap) → null
intersect.segmentSegment(input: LineLineInput): Position | null;

// line (origin + direction dir, dir need not be unit) ∩ circle; 0 / 2 hits
intersect.lineCircle(input: LineCircleInput): Array<Position>;

// circle ∩ circle; disjoint / contained / coincident → []
intersect.circleCircle(input: CircleCircleInput): Array<Position>;
```

| Function         | Returns / degeneracy                                                                                                           |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `lineLine`       | the intersection `Position`; parallel or collinear → `null`                                                                    |
| `segmentSegment` | the crossing point; disjoint / parallel / collinear (incl. overlap) → `null` (no collinear-overlap interval in this first cut) |
| `lineCircle`     | 0 (disjoint) or 2 hits; tangency returns 2 coincident points                                                                   |
| `circleCircle`   | 2 hits; disjoint / contained / coincident → `[]`; tangency returns 2 coincident points                                         |

For ray ∩ arc use [`rayArc`](/kernel/packages/math/primitives) (in Primitives; returns parameters, not points).

## triangle

Returns `Circle`; collinear vertices (area ≈ 0) → `null`.

```ts
triangle.circumCircle(a: Position, b: Position, c: Position): Circle | null;  // circum-circle (through all three vertices)
triangle.inCircle(a: Position, b: Position, c: Position): Circle | null;      // in-circle (tangent to all three sides)
```

## circle

```ts
// iterative Welzl; empty point set → null, single point → radius-0 circle
circle.minimalEnclosing(points: Array<Position>, epsilon?: number): Circle | null;
```

`circle.minimalEnclosing` returns the smallest circle covering all input points. It is deterministic, with worst-case time `O(n^3)` and space `O(1)`.

## point-in-polygon

```ts
// ray-casting even-odd rule; vertices in order, convex or concave, any winding
polygon.containsPoint(vertices: Array<Position>, p: Position): boolean;
```

**Boundary points are undefined** (handle on-boundary cases yourself); fewer than 3 vertices returns `false`.

## convexHull

```ts
convexHull(points: Array<Position>): Array<Position>;
```

Andrew's monotone chain; returns **CCW vertices** with **collinear middle points dropped**; for fewer than 3 points or all-collinear input, returns the sorted, de-duplicated endpoints.

## curve (smooth curve through points)

Given a list of knots, returns a chain of cubic Bézier segments that **passes through every knot** — the algorithm behind `<Step kind="smooth">`. It uses centripetal Catmull-Rom (α=0.5), which produces no cusps / self-intersecting loops when the points are unevenly spaced.

```ts
// one cubic Bézier: two control points + endpoint (start = previous endpoint / first knot for the first segment)
type CubicSegment = { control1: Position; control2: Position; to: Position };

// centripetal Catmull-Rom: chain of cubics through knots
// at least 2 knots; returns knots.length - 1 segments, segment[i].to lands exactly on knots[i+1]
curve.catmullRomToCubic(knots: Array<Position>, tension: number): Array<CubicSegment>;
```

`tension` is a tangent-length multiplier (TikZ `tension`): `1` is standard, `<1` tauter, `>1` loopier. Open curves use a one-sided tangent at each end (endpoint knots duplicate the adjacent point); coincident knots fall back to `DEFAULT_EPSILON` spacing to avoid division by zero, so output is always finite. `knots.length < 2` returns `[]`.
