---
title: Result inspection · inspect
description: Read ordinary compilation results and draw independent guides for final paths, groups, and clips
---

`@retikz/inspect` is optional. Compile the primary drawing first, then pass its `CompileResult` to inspectors. Inspectors generate ordinary auxiliary IR and compile it independently. Disabling inspection or an inspection failure does not change the primary result.

## Installation and usage

<PackageManagerInstall packages="@retikz/inspect" />

The registry describes available inspectors; requests select what to inspect. Registration alone produces no guides.

```ts
import { compileToScene } from '@retikz/core';
import { compileInspectionToScene, createDefaultInspectorRegistry, PATH_INSPECTOR_KEY } from '@retikz/inspect';

const primary = compileToScene({
  version: 1,
  type: 'scene',
  children: [
    {
      type: 'path',
      children: [
        { type: 'step', kind: 'move', to: [0, 0] },
        { type: 'step', kind: 'curve', control: [40, -50], to: [80, 0] },
      ],
    },
  ],
});
const auxiliary = compileInspectionToScene(primary, {
  registry: createDefaultInspectorRegistry(),
  requests: [{ inspector: PATH_INSPECTOR_KEY }],
});
```

`auxiliary.inspection` contains an independent plane, or null for empty output. The primary result stays in primary; inspection never recompiles its authoring input.

## Host integration

React's `InspectionOverlay` consumes a completed result. Vanilla's `mountInspection` creates a separate SVG or Canvas surface. Position that surface over the primary drawing using the same viewport, width, and height. Guides do not affect fitting, hit testing, or animation.

<DocTabs defaultValue="react">
<DocTab value="react" label="React">

```tsx
import { InspectionOverlay } from '@retikz/inspect/react';

<InspectionOverlay
  result={primary}
  options={{
    registry: createDefaultInspectorRegistry(),
    requests: [{ inspector: PATH_INSPECTOR_KEY }],
    idPrefix: 'inspection',
    viewport: primary.scene.layout,
  }}
/>;
```

</DocTab>
<DocTab value="vanilla" label="Vanilla">

```ts
import { mountInspection } from '@retikz/inspect/vanilla';

const overlay = mountInspection(overlayContainer, 'svg');
const presentation = overlay.update(primary, {
  registry: createDefaultInspectorRegistry(),
  requests: [{ inspector: PATH_INSPECTOR_KEY }],
  idPrefix: 'inspection',
});
if (presentation.error) console.error(presentation.error);
// After a successful primary update, call overlay.update(...) with the new result.
overlay.dispose();
```

Use a unique idPrefix for each surface on a page. A Scene-only consumer can pass `{ scene, artifacts: [] }`; it has no domain artifacts.

## Available facts

Built-ins inspect final Path handles, Group coordinates, and Clip edges. See [built-in inspection](/kernel/packages/inspect/builtins). Node layout boxes, connection boundaries, Coordinate positions, authored Scope envelopes, and layout solver state are not exposed by the ordinary Scene and have no corresponding inspector.

[Custom inspectors](/kernel/packages/inspect/custom) can consume Composite artifacts with reliable coordinate semantics. An occurrence identifies a location within one compilation; it does not establish world coordinates.
