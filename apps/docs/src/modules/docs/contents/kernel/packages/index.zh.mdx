能力包分组面向需要选择安装入口或理解包职责的读者。`@retikz/core` 是领域中立编译真源；其它包围绕同一份 Core 契约提供可选观测、宿主、计算与渲染能力。

## 职责一览

| 能力包               | 职责                               | 何时查阅                        |
| -------------------- | ---------------------------------- | ------------------------------- |
| `@retikz/foundation` | 跨包类型、断言与结构化错误基础契约 | 复用原子契约或迁移底层导入      |
| `@retikz/inspect`    | 编译结果选择、辅助内容与宿主接线   | 显示路径控制点或布局辅助层      |
| `@retikz/runtime`    | identity、ownership 与执行观测     | 定义跨 revision 状态所有权      |
| `@retikz/react`      | JSX 组件、IR 适配与 React 宿主     | 在 React 中声明并渲染图形       |
| `@retikz/vanilla`    | Plain spec、浏览器挂载与 SSR       | 不使用 React 或需要服务端字符串 |
| `@retikz/tex`        | LaTeX 公式到字形路径的 lowering    | 在节点文字中渲染数学公式        |
| `@retikz/math`       | 零依赖纯计算几何                   | 复用向量、仿射、弧与求交算法    |
| `@retikz/render`     | Scene 到 SVG / Canvas 与水合能力   | 自己选择或集成渲染后端          |
