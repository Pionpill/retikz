能力包分组面向需要选择安装入口或深入底层能力的读者。日常 React 写图从 `@retikz/react` 开始；这里重点介绍无框架运行时、公式接入、纯计算几何和渲染后端，它们都围绕同一份 core 契约协作。

## 职责一览

| 能力包            | 职责                             | 何时查阅                        |
| ----------------- | -------------------------------- | ------------------------------- |
| `@retikz/vanilla` | Plain spec、浏览器挂载与 SSR     | 不使用 React 或需要服务端字符串 |
| `@retikz/tex`     | LaTeX 公式到字形路径的 lowering  | 在节点文字中渲染数学公式        |
| `@retikz/math`    | 零依赖纯计算几何                 | 复用向量、仿射、弧与求交算法    |
| `@retikz/render`  | Scene 到 SVG / Canvas 与水合能力 | 自己选择或集成渲染后端          |
