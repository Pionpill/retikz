内核包按职责分成五组。先选择你要解决的问题，再进入分组页了解包之间的边界、依赖关系和推荐阅读顺序

## 分组一览

| 分组   | 职责                            | 适合何时查阅                             |
| ------ | ------------------------------- | ---------------------------------------- |
| 基础包 | 跨包契约与零依赖几何计算        | 复用基础类型、schema 或几何算法          |
| 核心包 | IR、Scene 编译与增量运行时      | 理解图形如何编译、执行和管理状态         |
| 拓展包 | 可选的公式与检查能力            | 接入 TeX 公式或运行时 Inspector          |
| 框架包 | React 与无框架宿主适配          | 在 React 或原生 JavaScript 中使用 Kernel |
| 渲染包 | Scene 的 SVG、Canvas 物化与水合 | 选择后端或绑定客户端交互                 |
