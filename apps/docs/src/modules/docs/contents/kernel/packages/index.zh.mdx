内核包按职责分成五组。先选择要解决的问题，再进入具体包了解它的边界、依赖关系和文档

## 分组一览

| 分组   | 职责                            | 包               |
| ------ | ------------------------------- | ---------------- |
| 基础包 | 跨包契约与零依赖几何计算        | foundation、math |
| 核心包 | IR、Scene 编译与增量运行时      | core、runtime    |
| 拓展包 | 可选的公式与检查能力            | tex、inspect     |
| 框架包 | React 与无框架宿主适配          | vanilla、react   |
| 渲染包 | Scene 的 SVG、Canvas 物化与水合 | render           |
