能力包分组面向需要选择安装入口或理解包职责的读者。`@retikz/core` 是整套 Kernel 文档共同讲解的主体，不在这里重复设页；本组按真实 npm 包名介绍 React、无框架、公式、纯计算几何和渲染入口，它们都围绕同一份 core 契约协作。

## 职责一览

| 能力包            | 职责                             | 何时查阅                        |
| ----------------- | -------------------------------- | ------------------------------- |
| `@retikz/react`   | JSX 组件、IR 适配与 React 宿主   | 在 React 中声明并渲染图形       |
| `@retikz/vanilla` | Plain spec、浏览器挂载与 SSR     | 不使用 React 或需要服务端字符串 |
| `@retikz/tex`     | LaTeX 公式到字形路径的 lowering  | 在节点文字中渲染数学公式        |
| `@retikz/math`    | 零依赖纯计算几何                 | 复用向量、仿射、弧与求交算法    |
| `@retikz/render`  | Scene 到 SVG / Canvas 与水合能力 | 自己选择或集成渲染后端          |
