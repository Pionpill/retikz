`@retikz/inspect` 为已经完成的 Core 编译提供可选观测：Inspector 读取最终实例与所属者产物，再生成独立的只读辅助内容。控制点、布局边界和对齐参考线都是这种观测的具体用法。

它只解释最终结果，不修正输入、不参与布局求解，也不改变主图。普通绘图、编译和渲染不需要安装本包；没有匹配的 Inspector 时也不会创建辅助片段。

## 安装与使用

<PackageManagerInstall packages="@retikz/inspect" />

两种宿主都需要 registry，但 React 在 JSX 编排位置附加 request，Vanilla 则分别创建路径标记和编译驱动：

| 宿主    | 入口                                                                    | 接入位置                                              |
| ------- | ----------------------------------------------------------------------- | ----------------------------------------------------- |
| React   | `InspectLayout`、`InspectPath`                                          | 在 Layout 注入 registry，并在 JSX Path 上附加 request |
| Vanilla | `createInspectionVanillaAuthoring()`、`createInspectionVanillaDriver()` | 创建路径标记，并在渲染入口接入 inspection driver      |

### React

React 从 `@retikz/inspect/react` 导入包装组件。`InspectLayout` 接收 registry，`InspectPath` 把 request 附加到当前路径：

```tsx
import { createDefaultInspectorRegistry, STROKE_PATH_INSPECTOR_KEY } from '@retikz/inspect';
import { InspectLayout, InspectPath } from '@retikz/inspect/react';
import { Step } from '@retikz/react';

const registry = createDefaultInspectorRegistry();

export const InspectExample = () => (
  <InspectLayout registry={registry}>
    <InspectPath request={{ inspector: STROKE_PATH_INSPECTOR_KEY, options: { controlPoints: true, labels: true } }}>
      <Step kind="move" to={[0, 0]} />
      <Step kind="cubic" control1={[20, -30]} control2={[80, 30]} to={[100, 0]} />
    </InspectPath>
  </InspectLayout>
);
```

`InspectLayout` 在普通 Layout 运行时接入可选 inspection compile driver；`InspectPath` 保持普通 Path 的内容写法，只把 request 转成 runtime-only authoring 标记。

### Vanilla

Vanilla 分别创建 authoring 标记和编译驱动：前者说明当前路径需要观测，后者在普通渲染入口接入 registry 与辅助图层：

`authoring` 不是 Path 的绘图字段，而是 Vanilla adapter 的运行时附加槽。`createInspectionVanillaAuthoring()` 用带私有 token 的标记包住 request，让同一次 `compileDriver` 把当前 authored Path 转成 Inspector 的选择规则；它不进入 Core IR，因此不会改变 `way`、路径几何或布局。

```ts
import { createDefaultInspectorRegistry, STROKE_PATH_INSPECTOR_KEY } from '@retikz/inspect';
import { createInspectionVanillaAuthoring, createInspectionVanillaDriver } from '@retikz/inspect/vanilla';
import { path, renderToSvgString, scene } from '@retikz/vanilla';

const registry = createDefaultInspectorRegistry();
const input = scene({
  children: [
    path('curve', {
      // 将当前 authored Path 标为要观测的目标；不会进入 Core IR
      authoring: createInspectionVanillaAuthoring({
        inspector: STROKE_PATH_INSPECTOR_KEY,
        options: { controlPoints: true, labels: true },
      }),
      way: [
        [0, 0],
        {
          cubic: [
            [20, -30],
            [80, 30],
          ],
        },
        [100, 0],
      ],
    }),
  ],
});

const svg = renderToSvgString(input, { compileDriver: createInspectionVanillaDriver({ registry }) });
```

根入口只提供 Definition、注册表、选择与辅助编译；React 与 Vanilla 适配分别从 `/react` 与 `/vanilla` 子入口导入，渲染仍由 `@retikz/render` 负责。先从“内置观测”看到第一个结果，再按需阅读拓展或解析原理。配置字段见 [Schema 参考](/kernel/packages/inspect/schema-reference)。
