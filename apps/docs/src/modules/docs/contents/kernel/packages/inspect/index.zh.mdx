`@retikz/inspect` 是可选包。主图先完成普通编译，检查器再读取 `CompileResult`，生成辅助 IR 并独立编译。关闭检查、无匹配目标或检查失败，都不改变主图。

## 安装与使用

<PackageManagerInstall packages="@retikz/inspect" />

注册表定义可以使用哪些检查器，requests 决定本次检查什么。仅创建注册表不会显示辅助图形。

```ts
import { compileToScene } from '@retikz/core';
import { compileInspectionToScene, createDefaultInspectorRegistry, PATH_INSPECTOR_KEY } from '@retikz/inspect';

const primary = compileToScene({
  version: 1,
  type: 'scene',
  children: [
    {
      type: 'path',
      children: [
        { type: 'step', kind: 'move', to: [0, 0] },
        { type: 'step', kind: 'curve', control: [40, -50], to: [80, 0] },
      ],
    },
  ],
});

const auxiliary = compileInspectionToScene(primary, {
  registry: createDefaultInspectorRegistry(),
  requests: [{ inspector: PATH_INSPECTOR_KEY }],
});
```

`auxiliary.inspection` 是独立辅助平面，空输出为 null。主图保持在 primary 中，Inspect 不再次编译主图输入。

## 宿主接入

React 的 `InspectionOverlay` 接收已经完成的结果；Vanilla 的 `mountInspection` 创建独立的 SVG 或 Canvas 辅助表面。调用方将它们叠放在主图上，提供相同 viewport、width 和 height。辅助层不参与主图 fit、命中或动画。

<DocTabs defaultValue="react">
<DocTab value="react" label="React">

```tsx
import { InspectionOverlay } from '@retikz/inspect/react';

<InspectionOverlay
  result={primary}
  options={{
    registry: createDefaultInspectorRegistry(),
    requests: [{ inspector: PATH_INSPECTOR_KEY }],
    idPrefix: 'inspection',
    viewport: primary.scene.layout,
  }}
/>;
```

</DocTab>
<DocTab value="vanilla" label="Vanilla">

```ts
import { mountInspection } from '@retikz/inspect/vanilla';

const overlay = mountInspection(overlayContainer, 'svg');
const presentation = overlay.update(primary, {
  registry: createDefaultInspectorRegistry(),
  requests: [{ inspector: PATH_INSPECTOR_KEY }],
  idPrefix: 'inspection',
});
if (presentation.error) console.error(presentation.error);
// 主图更新成功后，再用新结果调用 overlay.update(...)
overlay.dispose();
```

</DocTab>
</DocTabs>

同一主图页面上的 idPrefix 应保持唯一。只拿到 Scene 时，可传入 `{ scene, artifacts: [] }`；它不包含领域产物。

## 可检查的事实

内置支持最终 Path 控制柄、Group 坐标系与 Clip 边缘，详见[内置检查](/kernel/packages/inspect/builtins)。Node 布局盒、连接边界、Coordinate 点位、作者 Scope 包络以及布局求解过程不在普通 Scene 中，因此不提供对应检查器。

Composite artifact 可供[自定义检查器](/kernel/packages/inspect/custom)消费，但必须有可靠的坐标语义。occurrence 只是同次结果的来源定位，不能用它推导世界坐标。
