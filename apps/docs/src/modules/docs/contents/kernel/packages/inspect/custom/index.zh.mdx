自定义检查器与内置检查器使用同一 defineInspector、registry 和编译流程。subject 声明消费哪种 Scene 图元，或哪个 namespace/type 的 Composite artifact；key 标识检查器自身。

## 端点标记

下面的检查器读取最终 path 命令，为显式端点生成普通 Node。local 片段由 Inspect 应用 Scene group 链变换，不需要作者提供 transform。

回调返回 fragment 数组，每项包含 coordinateSpace 和 child；空数组表示没有辅助几何。optionsSchema 可声明选项及默认值，省略时仅允许空对象。回调读取隔离的只读结果，不应改写主图或依赖作者输入。

## 领域产物

artifact subject 使用领域 Composite 的 namespace/type。回调接收完整 artifact，包括 value 和 occurrence。value 的结构与坐标由领域契约决定；occurrence 不能推导空间变换。

artifact 片段只允许 scene 坐标。无法确定位置时调用 context.warn('UnsupportedGeometry', message) 并跳过该项，不将局部盒误画到主图原点。领域的可选入口负责这些语义，Inspect 不内置领域白名单。

## 失败边界

回调或辅助编译抛错会让本次检查整体失败，不交付半份平面；错误保留原始 cause。辅助警告与主图警告分开。辅助 IR 不允许引用主图对象，所需 provider 必须由独立编译配置提供。
