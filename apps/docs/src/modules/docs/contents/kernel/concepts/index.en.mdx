The concepts section explains why retikz organizes figures this way and how its layers work together. Start with basic concepts for coordinates and positioning, continue with core concepts for primitives and relationships, then use design philosophy when deciding where a capability belongs.

## Responsibilities

| Group             | Responsibility                              | Start here when                              |
| ----------------- | ------------------------------------------- | -------------------------------------------- |
| Design Philosophy | Explain the DSL, IR, Scene, and composition | Deciding which layer should own a capability |
| Basic Concepts    | Establish coordinates and positioning       | Learning retikz spatial rules                |
| Core Concepts     | Explain primitives and their relationships  | Understanding references and connections     |
