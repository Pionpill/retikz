title: 自定义变换
description: 自定义扩展可以注册完整 transform，也可以只扩展 reducer 或 selector，让内置统计 transform 复用新的子算子。
---

内置 transform 覆盖常见统计流程；长尾逻辑有三种扩展层级。能表达成“统计值”的逻辑优先写 reducer，能表达成“代表行”的逻辑优先写 selector；只有输入/输出形态本身不同，才注册完整 transform。

| 扩展层级 | 用在哪里 | 适合场景 |
| --- | --- | --- |
| `defineStatReducer` | `bin` / `summarize` / `annotate` 的 `metrics` | 加权平均、业务分位、风险分数 |
| `defineRowSelector` | `select` / `relate` 的 `selector` | 最近点、阈值穿越点、自定义排名 |
| `defineTransform` | 独立 `kind` | 自定义行结构、跨数据源派生、特殊输出形态 |

## 完整 transform

下面的 `double-x` 把 `field` 字段翻倍写进 `as` 字段。它在 `transformDefinitions` 里注册，spec 用 `<Transform kind="double-x" field="x" as="x2" />` 引用。

`x2` 没有写进 `model`，因为它是 `double-x` 产生的派生字段。`outputFields` 会把它登记为 transform 输出，strict model 只校验真正来自输入数据的 `x` 和 `y`。

## reducer 扩展

reducer 是统计值子算子。注册后，它可以被 `summarize`、`annotate` 和 `bin.metrics` 复用，不需要再写新的 transform kind。

```tsx
const weightedMean = defineStatReducer({
  schema: z.object({
    op: z.literal('weighted-mean'),
    field: z.string().min(1),
    weight: z.string().min(1),
    as: z.string().min(1),
  }),
  inputFields: operation => [operation.field, operation.weight],
  outputFields: operation => [operation.as],
  reduce: (rows, operation) => {
    const totalWeight = rows.reduce((sum, row) => sum + Number(row[operation.weight]), 0);
    const total = rows.reduce((sum, row) => sum + Number(row[operation.field]) * Number(row[operation.weight]), 0);
    return { [operation.as]: totalWeight === 0 ? 0 : total / totalWeight };
  },
});
```

然后在 `<Plot statReducerDefinitions={[weightedMean]}>` 里注入，并在 `metrics` 中写 `{ op: 'weighted-mean', ... }`。

## selector 扩展

selector 是代表行子算子。注册后，它可以被 `select` 和 `relate` 复用；输出仍然是被选中的原始行，所以 id、标签、锚点字段都会保留。

```tsx
const nearest = defineRowSelector({
  schema: z.object({
    op: z.literal('nearest'),
    field: z.string().min(1),
    target: z.number(),
  }),
  inputFields: operation => [operation.field],
  select: (rows, operation) => {
    const ranked = [...rows].sort(
      (left, right) =>
        Math.abs(Number(left[operation.field]) - operation.target) -
        Math.abs(Number(right[operation.field]) - operation.target),
    );
    return ranked.length === 0 ? [] : [{ row: ranked[0], rank: 1 }];
  },
});
```

在 `<Plot rowSelectorDefinitions={[nearest]}>` 里注入后，就可以写：

```tsx
<Transform kind="select" selector={{ op: 'nearest', field: 'value', target: 50 }} />
```

## 定义契约

| 字段 | 作用 |
| --- | --- |
| `schema` | 校验 `{ kind/op, ...config }` operation；配置必须保持 JSON 可序列化 |
| `inputFields` | 返回会读取的源字段，这些字段会进入 model 和字段解析流程 |
| `outputFields` | 返回会产生的派生字段，下游消费时不需要提前写进 `model` |
| `apply` / `reduce` / `select` | 执行逻辑，必须确定性，避免渲染和 locator 结果不一致 |

完整 transform 的 `apply` 第三个参数是 transform context。保行数 transform 通常 `{ ...row, newField }` 就能保留行级来源；改行数 transform 如果输出行代表一组源行，需要用 `context.groupProvenance(out, members)` 给输出行挂上 `sourceIndices`。
