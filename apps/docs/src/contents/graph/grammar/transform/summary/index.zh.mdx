---
title: 规约与选择
description: 规约与选择会改变数据粒度，把明细行变成分箱、分组统计行，或组内代表行。
---

这一组 transform 会从明细数据生成新的行。`bin` 和 `summarize` 产出统计行，`select` 保留被选中的原始代表行；它们都适合在 mark 之前先把“要画的行”准备好。

| kind | 输出行 | 常见用途 |
| --- | --- | --- |
| `bin` | 每个区间一行 | 直方图、分布概览 |
| `summarize` | 每个分组一行 | 分组柱、均值线、汇总表 |
| `select` | 每组一个或多个原始行 | 极值点、top-N、组内第 N 个点 |
| `density` | 每组一批采样行 | 密度曲线、密度面积 |
| `smooth` | 每组一批预测采样行 | 趋势线、回归路径 |

## 分箱 bin

`bin` 把连续字段切成区间，每个区间产出一行。输出行包含箱下界、箱上界和 metric 字段；默认 metric 是 `{ op: 'count', as: 'binCount' }`。

<ComponentPreview name="transform-histogram" sourceFiles={['transform-histogram.data.ts']} />

`IntervalMark` 用 `x0` / `x1` 读取箱边，画出连续 x 轴上紧贴排列、宽度随箱边变化的直方图柱；`y` 读取 `binCount` 或自定义 metric 字段作为高度。

| prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `field` | `string` | — | 被分箱的连续源字段 |
| `count` | `number?` | `10` | 目标箱数；与 `step` / `thresholds` 互斥 |
| `step` | `number?` | — | 固定箱宽；与 `count` / `thresholds` 互斥 |
| `thresholds` | `Array<number>?` | — | 显式内部边界；与 `count` / `step` 互斥 |
| `extent` | `[number, number]?` | 观测 min/max | 覆盖分箱域 |
| `metrics` | `Array<Reducer>?` | `count → binCount` | 每箱统计指标 |
| `startField` / `endField` | `string?` | `binStart` / `binEnd` | 箱边输出字段名 |

## 汇总 summarize

`summarize` 按 `groupBy` 分组，并用 `metrics` 把每组明细规约成一行。输出行保留组键，每个 reducer 都必须显式写 `as` 字段名。

<ComponentPreview name="transform-summarize" sourceFiles={['transform-summarize.data.ts']} />

`count` 不需要 `field`；`sum` / `mean` / `median` / `min` / `max` / `quantile` / `quantile-band` 需要 `field`。`groupBy` 可以省略或写空数组，表示全局单组。完整 reducer 列表见[统计子算子](/graph/grammar/transform/statistics)。

| prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `groupBy` | `Array<string>?` | 全局单组 | 分组键字段，支持复合键 |
| `metrics` | `Array<Reducer>` | — | 组内统计指标，每个 reducer 必须写 `as` |

```tsx
<Transform
  kind="summarize"
  groupBy={['region']}
  metrics={[
    { op: 'sum', field: 'revenue', as: 'total' },
    { op: 'median', field: 'revenue', as: 'median' },
    { op: 'count', as: 'orders' },
  ]}
/>
```

## 代表行选择 select

`select` 按组运行 selector，并输出被选中的原始行。它不会把数值规约成新的统计值，适合保留城市名、id、锚点等原始字段，同时只画组内极值或 top-N。

<ComponentPreview name="transform-select" sourceFiles={['transform-select.data.ts']} />

内置 selector 包括 `min` / `max` / `first` / `last` / `top` / `bottom` / `nth` / `outside-quantile-band`。`rankAs` 可以把被选中的名次写回输出行。完整 selector 列表见[统计子算子](/graph/grammar/transform/statistics)。

| prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `groupBy` | `Array<string>?` | 全局单组 | 分组键字段 |
| `selector` | `Selector` | — | 组内代表行选择规则 |
| `rankAs` | `string?` | — | 可选，把一基 rank 写入该字段 |

```tsx
<Transform
  kind="select"
  groupBy={['region']}
  selector={{ op: 'top', by: 'revenue', n: 3 }}
  rankAs="rank"
/>
```

## 密度 density

`density` 把一维连续样本变成 KDE 采样行，输出 `xAs` 和 `densityAs` 两个字段。它适合接 `PathMark`：普通路径画密度曲线，`closure={{ kind: 'baseline' }}` 加 `fill` 画密度面积。

完整字段和 demo 见[统计子算子](/graph/grammar/transform/statistics)。

## 趋势 smooth

`smooth` 从 `(x, y)` 样本生成趋势线采样行，首轮 `method` 只有 `{ kind: 'linear' }`。它适合接 `PathMark` 画 regression path；原始散点可用另一层 `PointMark` 保留。

完整字段和 demo 见[统计子算子](/graph/grammar/transform/statistics)。
