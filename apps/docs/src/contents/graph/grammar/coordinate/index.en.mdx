title: Coordinates
description: Coordinates decide how data values land on the canvas: 2D covers cartesian and polar charts, 1D covers single-axis data, ternary handles three-part mixtures, and custom coordinates inject projection functions at runtime.
---

The coordinate system is the last step `<Plot>` takes to place field values on the canvas. Scales first map data values into continuous or discrete spaces; the coordinate then decides whether those values become points on a plane, points around a circle, sectors, points inside a triangle, or positions under a custom projection.

If you only need ticks, labels, or grid lines, see [Axis](/graph/grammar/guide/axis). If you want to understand how `coordinate` turns the same mark into a flat chart, radial chart, rug, or ternary plot, start here.

## What each part covers

| Topic | Coordinates | Responsibility | Use it when |
| --- | --- | --- | --- |
| 2D coordinates | `cartesian2D` / `polar2D` | Regular x/y charts and polar charts | Bars, lines, areas, pies, donuts, radar |
| 1D coordinates | `cartesian1D` / `polar1D` | Project one position channel | Rug plots, timelines, cyclic event dots |
| Ternary coordinates | `ternary2D` | Project three components into a triangle | Compositions and three-way trade-offs |
| Custom coordinates | `{ type: 'bridge', ...config }` | Inject your own runtime definition | Curved axes, special spaces, experimental projections |
