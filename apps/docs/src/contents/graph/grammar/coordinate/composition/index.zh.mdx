title: 坐标组合
description: composition 让一张 Plot 同时表达双轴、分面和共享轨道这类多区域图。
---

当一张图只有一个投影方式时，用 `coordinate` 就够了。需要把同一份数据放进多个坐标区域、多个面板或上下轨道时，仍然会落到同一套 `composition` 模型，但日常写法不必手写 `composition` 对象：双轴用 `Axis id` + `xAxisId` / `yAxisId`，分面用 `<Facet>` + `facetId`，共享轨道用 `<Scaffold>` / `<Track>` + `trackId` / `scaffoldId`。

`composition` 解决的是“坐标区域怎么组织”，不是新的图元类型。mark 仍然是 `PathMark`、`PointMark`、`IntervalMark`；scale 仍然由字段和显式 `<Scale>` 推断；guide 仍然用 `<Axis>` 声明。

## 双轴

双轴图是最常见的多坐标场景：一边共享，另一边放两套刻度。多轴快捷写法目前面向 `cartesian2D`，也就是常见的 x / y 笛卡尔坐标。

每个维度都会先有一根默认轴。没有写 `id` 的 `<Axis dimension="x">` 或 `<Axis dimension="y">` 属于对应维度的默认轴；mark 省略 `xAxisId` / `yAxisId` 时，也会使用对应维度的默认轴。只有额外轴需要显式 `id`，再由 mark 用 `xAxisId` 或 `yAxisId` 选择。

### 多 y 轴

多 y 轴适合 x 位置相同、y 单位不同的图。下面的天气例子里，温度使用默认 y 轴，降雨量绑定到右侧 y 轴。

<ComponentPreview name="coordinate-composition-scopes" sourceFiles={['coordinate-composition-scopes.data.ts']} size="md" />

`rainfall` 是额外 y 轴的 `id`。temperature 折线省略 `yAxisId`，rainfall 折线和点用 `yAxisId="rainfall"` 选择右侧轴。

| 写法 | 作用 |
| --- | --- |
| `<Axis id="rainfall" dimension="y">` | 声明降雨量这根额外 y 轴 |
| `yAxisId="rainfall"` | 让 mark 使用降雨量轴 |
| `placement={{ kind: 'side', side: 'right' }}` | 把额外 y 轴放到右侧 |

多 x 轴适合 y 度量相同，但横向刻度有两套解释的图。下面的例子底部显示“发布第几天”，顶部显示“日历日期”；两条线共享 y 轴。

<ComponentPreview name="coordinate-composition-x-axis" sourceFiles={['coordinate-composition-x-axis.data.ts']} size="md" />

`calendar` 是额外 x 轴的 `id`。completed 折线使用默认 x 轴，forecast 折线和点用 `xAxisId="calendar"` 选择上方轴。

| 写法 | 作用 |
| --- | --- |
| `<Axis id="calendar" dimension="x">` | 声明日历日期这根额外 x 轴 |
| `xAxisId="calendar"` | 让 mark 使用日历日期轴 |
| `placement={{ kind: 'side', side: 'top' }}` | 把额外 x 轴放到上方 |

## 分面

facet 会按数据字段把一张图拆成多个面板。常规写法是声明一个 `<Facet>`，然后让 mark 和 axis 用 `facetId` 指向它；每个面板会拿到自己对应的数据行。

### API

表里的 `FacetValue` 表示 `string | number | boolean | null`。

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `id` | `string` | 必填 | facet 身份，供 `facetId` 引用 |
| `row` | `string`<br />`{ field: string; order?: FacetValue[] }` | 省略 | 拆行字段 |
| `column` | `string`<br />`{ field: string; order?: FacetValue[] }` | 省略 | 拆列字段 |
| `row.order`<br />`column.order` | `FacetValue[]` | 数据首次出现顺序 | 面板顺序；未列出的值按首次出现追加 |
| `facetId` | `string` | 省略 | 让 mark / axis 进入 facet 面板 |
| `empty` | `'drop' \| 'show'` | `'drop'` | 空面板是丢弃还是保留 |
| `scales.roles` | `Record<string, 'shared' \| 'independent'>` | 未写 role 为 `'shared'` | 指定每个坐标 role 的 domain 是否跨面板共享 |
| `layout.panelGap` | `number` | `0` | 面板间距，单位是用户坐标单位 |
| `guidePolicy.axes` | `'perScope' \| 'outerShared'` | `'outerShared'` | 轴逐面板绘制，或收敛到外侧 |
| `guidePolicy.gridPlacement` | `'self' \| 'sharedRole'` | `'self'` | `Axis grid` 默认投放目标；facet 中会投到每个面板 |

## 共享轨道

共享轨道用一套坐标骨架管理多条 track。常见用途是多条对齐的小图：共享一个 role，另一个 role 被切成多段 band。常规写法是用 `<Scaffold>` 包住多个 `<Track>`，mark 用 `trackId` 选择轨道，跨轨道共享的轴用 `scaffoldId` 选择整套 scaffold。

### 笛卡尔轨道

<ComponentPreview name="coordinate-composition-tracks" sourceFiles={['coordinate-composition-tracks.data.ts']} size="md" />

这个例子里两个 track 共用 `week` 的 x 位置。`incidents` 和 `load` 各自占用 y band，所以它们能上下对齐但保持自己的垂直空间。x 轴的 `grid` 由 `<Axis>` 开启；共享轨道默认把同一组 x 刻度投放到所有共享 track。`trackGap` 打开轨道之间的空隙。

### 极坐标轨道

<ComponentPreview name="coordinate-composition-tracks-polar" sourceFiles={['coordinate-composition-tracks-polar.data.ts']} size="lg" />

共享轨道也可以放在 `polar2D` 下。这里 `x` 被坐标系解释为角向 role，`y` 被解释为径向 role；`sharedRoles={['x']}` 让两条径向 track 共用同一组角度刻度，而各自使用不同的半径 band。

### API

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `Scaffold.id` | `string` | 必填 | scaffold 身份，供 `scaffoldId` 与 `trackId` 生成的 scope 引用 |
| `Scaffold.sharedRoles` | `Array<string>` | 必填 | 由 scaffold 统一管理的坐标 role，例如共享 `x` |
| `Scaffold.coordinate` | `CoordinateOperation` | 继承 `<Plot coordinate>` | scaffold 使用的坐标系 |
| `Scaffold.frame` | `'shared' \| 'independent'` | `'shared'` | track 是否共享 scaffold 的 frame |
| `Track.id` | `string` | 必填 | track 身份，供 `trackId` 引用 |
| `Track.band` | `{ role: string; start: number; end: number }` | 必填 | track 在非共享 role 上占用的比例区间，`start` / `end` 取 `0` 到 `1` |
| `Track.order` | `number` | 声明顺序 | track 排序提示 |
| `trackId` | `string` | 省略 | 让 mark / axis 进入某条 track |
| `scaffoldId` | `string` | 省略 | 让 axis 绑定整套 scaffold，常用于共享轴 |
| `layout.trackGap` | `number` | `0` | track 之间的间距，单位是用户坐标单位 |
| `guidePolicy.axes` | `'perScope' \| 'outerShared'` | `'outerShared'` | 轴逐 track 绘制，或收敛到外侧 |
| `guidePolicy.gridPlacement` | `'self' \| 'sharedRole'` | `'sharedRole'` | `Axis grid` 默认投放目标；共享轨道中会投到同 role 的 track |

## 怎么选择

| 场景 | 推荐结构 |
| --- | --- |
| 一条折线 + 一组柱，共享 x 但 y 单位不同 | 双轴 |
| 按地区 / 类别拆成多列或多行 | 分面 |
| 几个指标沿同一时间轴上下对齐 | 共享轨道 |
| 几张图只是摆在同一个大画布里 | 父级 `<Layout>` 里放多个 `<Plot>`，不用 composition |
