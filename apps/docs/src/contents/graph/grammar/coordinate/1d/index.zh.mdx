有时数据只有一个位置维度：一串采样值、一天里的事件时刻、某条轴上的分布。二维图会浪费一条轴；一维坐标系只绑定一个位置通道，另一维塌缩成基线或绕成圆。

## 两种形态

| coordinate | 形状 | 绑定 | 典型用途 |
| --- | --- | --- | --- |
| `"cartesian1D"` | 直线 | 只绑 `x` | rug 刻记、timeline、一维散布 |
| `"polar1D"` | 圆周 | 只绑 `x`（作角向） | 24 小时钟面、星期轮等周期数据 |

一维坐标系与 scale 无关：和二维轴一样可以配 linear / log / time。下面左边是 `cartesian1D` rug，右边是 `polar1D` 把一天的事件时刻绕成圆。

## 配置项

`cartesian1D` 可以用对象形态控制轴向：

```tsx
<Plot coordinate={{ type: 'cartesian1D', orientation: 'horizontal' }}>
```

`polar1D` 可以控制圆周半径占比与角向区间：

```tsx
<Plot coordinate={{ type: 'polar1D', radius: 0.8, startAngle: 180, endAngle: 360 }}>
```

| 坐标系 | 字段 | 说明 |
| --- | --- | --- |
| `cartesian1D` | `orientation` | `'horizontal'` 或 `'vertical'`，决定那条一维轴横放还是竖放 |
| `polar1D` | `radius` | 圆周半径占绘图区半径的比例 |
| `polar1D` | `startAngle` / `endAngle` | 角向区间，单位度 |

## 限制

本轮一维坐标系只支持 `<PointMark>`，用来画 rug 刻记、timeline 点或圆周事件点。柱、扇形、面积等需要二维 cell 或区域的 mark 在一维下没有对应几何，会直接报错而不是画出误导性的图。
