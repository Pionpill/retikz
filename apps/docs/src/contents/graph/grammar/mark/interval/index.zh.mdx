---
title: IntervalMark
description: IntervalMark 表达各位置维度上的区间积；柱、直方、热图、径向柱、饼图和环图都是它的不同投影。
---

`<IntervalMark>` 不是“柱图元”，而是区间图元。它为每条数据构造一个或多个位置维度上的区间，再交给坐标系投影：cartesian 下常是矩形，polar 下可以是径向柱或扇区。

默认写 `x` / `y` 时，`x` 走 band 区间、`y` 从 baseline `0` 延伸到数值；显式写 `bounds` 时，可以把任一维声明为 `band` / `span` / `extent` / `proportional` / `full`。表里的 `FieldName` 表示数据字段名或字段路径，例如 `quarter` / `sales.revenue`。

## 用法

```tsx
import { IntervalMark, Plot } from '@retikz/plot-react';
```

```tsx
<Plot data={revenue}>
  <IntervalMark x="quarter" y="value" />
</Plot>
```

普通柱只需要 `x` / `y`。可变宽柱使用 `width` 表达比例宽度区间；直方图使用 `x0` / `x1` 表达连续区间；热图用 `bounds` 声明双 band；饼图 / 环图用 `angle` 让 React DSL 自动累积角区间。

## 表现层

IntervalMark 是底层 cell mark：它只负责把每行数据变成一个正交区间 cell，再由坐标系把 cell 投影成矩形、扇区或轮廓。柱、直方、热图、径向柱、饼图和环图不是不同的底层 mark，而是同一个 IntervalMark 在不同 `bounds`、`series`、`stack` 和 `coordinate` 下的表现形态。

| 表现形态 | 关键属性 | 说明 |
| --- | --- | --- |
| 柱 | `x` / `y` | `x` 分类槽给宽度，`y` 从 `0` 延伸到数值 |
| 横向柱 | `direction="horizontal"` | `x` 改为数值长度，`y` 改为分类 band |
| 可变宽柱 | `x` / `width` | `width` 按数据顺序累加成连续比例区间，`x` 提供轴标签 |
| 分组柱 | `arrangement="dodge"` / `group` | 同一分类槽内按分组字段切子带 |
| 堆叠柱 | `arrangement="stack"` / `group` | stack transform 产出 `y0` / `y1`，数值 role 改为 extent |
| 百分比堆叠柱 | `arrangement="normalize-stack"` / `group` | 先按分类归一化为百分比，再堆叠 |
| 直方 | `x0` / `x1` / `y` | `x0` / `x1` 提供连续 x 区间，`y` 提供高度 |
| 热图 / 网格 | `bounds` | `bounds.x` 和 `bounds.y` 都声明为 `band` |
| 饼 / 环 | `angle` / `coordinate` | `angle` 累积成角向 extent，半径方向使用 full |

## 例子

### 位置属性

`x` / `y` 是最小柱形写法：`x` 绑定分类字段，`y` 绑定数值字段。坐标系会把分类字段解释为 band，把数值字段解释为从 `0` 到值的 span。

`direction="horizontal"` 会交换柱形角色：`x` 仍然绑定数值字段，但解释为从 `0` 到值的长度；`y` 绑定分类字段，并自动推断为 band。横向多系列编排会由 `arrangement` 入口统一表达。

`width` 是比例宽度快捷入口：它把非负数值字段累加成 band role 上的连续区间，因此柱宽可以表达另一项度量，`y` 仍然控制高度。若同时写 `x`，该字段会作为每段比例区间中心处的轴标签。

### 连续区间

`x0` / `x1` 是连续区间写法。下面左侧直方图先用 bin transform 产出 `binStart` / `binEnd`，再由 IntervalMark 把它们作为 `bounds.x=extent(x0,x1)`；右侧示例使用 `width` 表达按 GDP 比例分配的柱宽，并用 `x` 显示国家标签。

### 区间属性

`bounds` 用来覆盖默认推断。热图需要两个方向都是 band，因此显式写 `bounds={{ x: { kind: 'band' }, y: { kind: 'band' } }}`。

缺少 `color` 时，同一套双 band 区间会画成固定网格；它仍然是 IntervalMark，只是没有把单元格值映射成填充色。

<ComponentPreview name="rect-bounds" sourceFiles={['rect-heatmap.data.ts', 'rect-grid.data.ts']} interactive />

### 系列属性

`arrangement` 控制多系列区间如何放进同一个分类槽：`dodge` 并排、`stack` 堆叠、`normalize-stack` 百分比堆叠。`group` 是编排字段，决定子带或堆叠段；`color` 是着色字段，可以与 `group` 相同，也可以单独指定。`series` 仍可作为兼容快捷写法：未写 `group` / `color` 时，它会同时作为默认编排字段和颜色字段。
`arrangement="stack"` 可配 `stackOffset`：`zero` 从 0 累加，`normalize` 把每个分类堆叠归一到 0..1，`diverging` 正负分离，`center` 居中，`overlap` 让每段都从 0 起画。若需要百分比堆叠，直接写 `percent` 或 `arrangement="normalize-stack"`，它会先把分类内值归一化到 0..100，再堆叠。

### 角度属性

同一个 `x` / `y` 区间切到 `coordinate="polar2D"` 后，`x` band 会被解释成角向 band，`y` span 会被解释成半径方向长度。

`angle` 是饼图 / 环图的便捷入口：它会把份额字段累积成角向 extent，半径方向使用 full。环图不是新的 mark，只是 polar 坐标系配置了 `innerRadius`。

### 样式属性

IntervalMark 的视觉样式会下沉到每个 cell 的 core `Node`。常用入口包括 `cornerRadius`、`stroke`、`strokeWidth`、`fillOpacity`、`shadow` 和标签样式；极坐标 sector 还可以用 `padAngle` 留出真实角向间隔。左侧是笛卡尔柱，右侧是同一份数据切到极坐标后的圆角环形图。

## 技术原理

`IntervalMark` 是一个内置注册图元。React 里的 `<IntervalMark>` 本身不渲染 DOM；`<Plot>` 会在构造 `PlotSpec` 时把它收集成 `type: 'interval'` 的 mark IR，并根据便捷 props 补出 `bounds`、自动 stack transform 和颜色 scale。

编译时，`lowerMark` 按 `mark.type` 查询 `MARK_REGISTRY`。`IntervalMark` 命中 `PlotMark.Interval` 对应的 `lowerIntervalLayer`；该函数要求当前坐标帧提供 `projectCell`，然后逐行调用 `markCell` 与当前坐标系的 `projectCell`。cartesian2D / polar2D 会额外构造 `IntervalContext` 处理 band、分组子带与比例宽度区间；自定义坐标系若要支持 interval，需要在 frame 上同时提供 `roleScales` 与 `projectCell`。坐标系决定 cell 最后是矩形、扇区还是 contour，IntervalMark 本身不分叉处理这些形态。

注册行和核心下沉函数的关键部分如下：

```ts
[PlotMark.Interval]: { type: PlotMark.Interval, buildCell: (mark, row, frame, ctx) => markCell(mark, row, frame, ctx), lower: lowerIntervalLayer },

const lowerIntervalLayer = (mark: Mark, rows: Array<ExternalRow>, frame: CoordinateFrame, channels: MarkChannels, markProvenance: MarkProvenance | undefined): IRChild | null => {
  if (mark.type !== PlotMark.Interval) return null;
  if (!hasProjectCell(frame)) {
    throw new Error(failLoudMessage(mark.type, frame.type));
  }
  const ctx = buildIntervalContext(mark, frame, rows);
  const layer = lowerCells(mark, rows, frame, frame.projectCell, ctx, channels.colorOf, channels.defaultColor, markProvenance, channels.labelOf);
  return layer === null ? null : attachMarkLayer(layer, mark, markProvenance);
};

const lowerCells = (
  mark: Mark,
  rows: Array<ExternalRow>,
  frame: CoordinateFrame,
  projectCell: (cell: Cell) => CellGeometry,
  ctx: IntervalContext | undefined,
  colorOf: ColorOf | undefined,
  defaultColor: string | undefined,
  markProvenance: MarkProvenance | undefined,
  labelOf: LabelOf | undefined,
): IRScope | null => {
  const placed: Array<{ color: string | undefined; node: IRNode }> = [];
  let kind: CellGeometry['kind'] | undefined;
  for (let transformedIndex = 0; transformedIndex < rows.length; transformedIndex++) {
    const row = rows[transformedIndex];
    const cell = markCell(mark, row, frame, ctx);
    if (!cell) continue;
    const geometry = projectCell(cell);
    if (!isRenderableCellGeometry(geometry)) continue;
    kind = geometry.kind;
    const node = attachDatumLabel(
      decorateDatum(cellGeometryNode(geometry), row, transformedIndex, mark.type, markProvenance, cellSeriesValue(mark, row)),
      mark,
      row,
      labelOf,
    );
    placed.push({ color: colorOf?.(row), node });
  }
  return placed.length === 0 || kind === undefined ? null : cellLayer(placed, kind, colorOf, defaultColor);
};
```

| 步骤 | 说明 |
| --- | --- |
| 坐标系守卫 | IntervalMark 需要坐标帧提供 `projectCell`；无 cell 投影能力时 fail-loud |
| 区间构造 | `markCell` 根据 `bounds`、位置通道、`series` 和 stack 派生字段构造逻辑 cell；自定义 frame 还需提供 `roleScales` |
| 坐标投影 | `frame.projectCell` 把逻辑 cell 投影成 `rect`、`sector` 或 `contour` |
| core 下沉 | `cellGeometryNode` 把可渲染几何装配成 core Node，空 contour 会被跳过，颜色通道按颜色分组上提到 Scope |

## API

`IntervalMark` 的 API 按位置、专属、节点、标签、通用和自定义分组：位置字段决定 cell 的角色值，专属字段负责区间构造和系列关系，节点字段下沉到 core `Node`。表里的 `FieldName` 表示数据字段名或字段路径，例如 `quarter` / `sales.revenue`。

| 分类 | 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- | --- |
| 位置 | `x` / `y` / `z` | `FieldName?` | — | 坐标角色字段；cartesian2D / polar2D 用 `x` / `y`，ternary2D 还需要 `z` |
| 专属 | `color` | `FieldName?` | `series` | 颜色字段；字段绑定会生成颜色通道和图例 |
|  | `x0` / `x1` | `FieldName?` | — | 连续 x 区间上下界；组件层会构造 `bounds.x = extent(x0, x1)` |
|  | `width` | `FieldName?` | — | 比例宽度字段；组件层会构造 `bounds.<bandRole> = proportional(width)`；同 role 的 `x` / `y` 字段可作为轴标签 |
|  | `direction` | `'vertical' \| 'horizontal'` | `vertical` | 普通柱方向；`horizontal` 使用 x 数值 span 与 y 分类 band |
|  | `angle` | `FieldName?` | — | 饼图 / 环图入口：份额字段会累积成角区间 |
|  | `padAngle` | `number?` | — | 极坐标 sector 的角向间隔（度）；每个扇区两侧各收半个间隔角 |
|  | `bounds` | `IntervalBounds?` | 按 role 推断 | 显式声明每个 role 的 band / span / extent / proportional / full |
|  | `group` | `FieldName?` | `series` | 编排分组字段；dodge 按它切子带，stack 按它生成堆叠段 |
|  | `arrangement` | `'dodge' \| 'stack' \| 'normalize-stack'` | 由 `group` / `series` / `stack` 推断 | 多系列区间编排方式 |
|  | `stackOffset` | `'zero' \| 'normalize' \| 'diverging' \| 'center' \| 'overlap'` | `zero` | stack transform 的基线偏移；仅直接作用于 `arrangement="stack"` |
|  | `percent` | `boolean?` | `false` | 百分比堆叠快捷入口；等价于 `arrangement="normalize-stack"` |
|  | `series` | `FieldName?` | — | 兼容快捷字段；未写 `group` / `color` 时作为默认编排和颜色字段 |
|  | `stack` | `boolean?` | `false` | 兼容快捷字段；`true` 等价于 `arrangement="stack"` |
| 节点 | `fill` / `stroke` | `FieldName`<br />`IRPaintSpec`<br />`PointFillStyle?` / `PointStrokeStyle?` | `currentColor` / — | cell Node 填充和描边样式 |
|  | `opacity` / `fillOpacity` | `PointOpacityStyle?` | — | cell Node 整体和填充透明度 |
|  | `strokeWidth` | `PointNonnegativeNumberStyle?` | — | cell Node 描边宽度 |
|  | `padding` / `minimumSize` | `MarkValueProp<number>`<br />`PointNonnegativeNumberStyle` | — | cell Node 内边距和最小视觉尺寸 |
|  | `minimumWidth` / `minimumHeight` | `MarkValueProp<number>`<br />`PointNonnegativeNumberStyle` | — | cell Node 最小视觉宽 / 高 |
|  | `align`<br />`lineHeight` / `maxTextWidth` | `MarkValueProp<NodeTextAlignValue>`<br />`NodeTextAlignStyle`<br />`MarkValueProp<number>`<br />`NodePositiveNumberStyle` | —<br />— | 文本排版通道 |
|  | `cornerRadius`<br />`scale` / `xScale` / `yScale` | `MarkValueProp<number>`<br />`PointNonnegativeNumberStyle`<br />`MarkValueProp<number>`<br />`NodePositiveNumberStyle` | —<br />— | cell Node 圆角与缩放 |
|  | `innerXSep` / `innerYSep`<br />`outerSep` / `margin` | `MarkValueProp<number>`<br />`PointNonnegativeNumberStyle` | — | cell Node 间距通道 |
|  | `dashed` / `dotted`<br />`dashPattern` | `MarkValueProp<boolean>`<br />`NodeBooleanStyle`<br />`MarkValueProp<Array<number>>`<br />`NodeDashPatternStyle` | —<br />— | cell Node 描边虚线 |
|  | `font`<br />`boundary`<br />`shadow`<br />`blendMode` | `NodeFontStyle?`<br />`NodeBoundaryStyle?`<br />`ShadowStyle?`<br />`BlendModeStyle?` | —<br />—<br />—<br />— | 字体、边界、阴影和混合模式 |
| 标签 | `label` / `labelDisplayFormat` | `FieldName?`<br />`string?` | —<br />— | 给每个 cell 挂标签 |
|  | `labelPosition`<br />`labelDistance`<br />`labelPin` | `string / number`<br />`number`<br />`boolean / LabelPin` | `above`<br />`12`<br />`false` | 标签方位、距离和引线 |
| 通用 | `id` | `string?` | — | 可选 mark 句柄，用于图层 id / 运行时标签解析 |
|  | `transform` | `Array<Transform>?` | — | 当前图元局部的数据变换；在 plot 级 transform 之后执行，只影响这一层看到的 rows |
| 自定义 | `channels` | `Record<string, Channel>` | — | 自定义通道入口；交给注册的 channel definition 解析 |
