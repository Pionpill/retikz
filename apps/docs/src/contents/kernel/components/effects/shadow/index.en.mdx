`shadow` is an element-level visual-effect prop you can set directly on `<Node>` and `<Path>`. It applies to **the primitive itself** — the Node shape, the Path main path (including its endpoint arrows). A Node's text / label / pin are separate primitives and get no shadow. It is renderer-agnostic: SVG and Canvas each translate it to native capabilities and calibrate the visual contract to stay close.

## Usage

```tsx
import { Node, Path, Step } from '@retikz/react';
```

```tsx
<Node shape="rectangle" fill="white" shadow="md" />
```

`shadow` adds a drop shadow to the primary geometry. The two writings are two ways of filling the same field.

## Presets

The simplest form is a Tailwind-style preset string: `'sm'` / `'md'` / `'lg'` / `'xl'` / `'2xl'` / `'none'`. Larger steps push the shadow farther and softer. `'none'` means an explicit no-shadow (equivalent to omitting it).

## Object form

For precise control, use an object `{ preset?, offsetX?, offsetY?, blur?, color?, opacity? }`:

- With a `preset`, that step is the **default base**, and any field you also set overrides it field by field — `{ preset: 'md', color: '#3b82f6' }` is "md's offset and blur, recolored".
- Without a `preset`, you must give `offsetX` + `offsetY` yourself (fully explicit).

Priority is always: **explicit field > preset > default**. The default color is translucent black `rgba(0,0,0,0.5)`; `opacity` (when given) multiplies onto the color's effective alpha.

## Element-level, not group-level

`shadow` follows the primitive itself. A Node's text / label / pin are **separate primitives** and get no shadow — there is no "lift the whole card including its text" (this is an element-level effect, not a group-level one). But a Path's endpoint arrows belong to the main-path primitive and **cast a shadow together with it** (matching the native semantics of SVG's element-level filter / Canvas's single draw pass).

## API Reference

`shadow` is a shared style prop on `<Node>` and `<Path>`, written the same way on both.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `shadow` | `'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl' \| 'none'`<br />`\| { preset?, offsetX?, offsetY?, blur?, color?, opacity? }` | — | Drop shadow on the primary geometry: a preset string, or an object (preset seeds defaults, explicit fields override; without a preset you must give offsetX + offsetY). Priority: explicit > preset > default; color defaults to `rgba(0,0,0,0.5)`, `opacity` multiplies onto the color alpha. Element-level: a Node's text / label / pin (separate primitives) get none; a Path's endpoint arrows cast a shadow with the main path |

### shadow object fields

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `preset` | `'sm' \| 'md' \| 'lg' \| 'xl' \| '2xl' \| 'none'` | — | Tailwind-style step seeding offsetX / offsetY / blur / color as defaults; explicit fields override it |
| `offsetX` | `number` | `0` (from preset) | Horizontal offset (user units) |
| `offsetY` | `number` | from preset | Vertical offset (user units, positive = downward) |
| `blur` | `number` (≥0) | from preset | Blur radius (user units); `0` = hard edge |
| `color` | `string` | `rgba(0,0,0,0.5)` | Shadow color, any CSS color |
| `opacity` | `number` (0–1) | — | Shadow opacity, multiplied onto the color's effective alpha |
