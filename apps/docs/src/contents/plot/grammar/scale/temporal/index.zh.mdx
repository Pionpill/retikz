时间字段（`temporal`）的位置通道默认走 `time`。它本质是连续映射，但刻度不取等距数值，而是落在**人类可读的时间边界**（月初、季度、整点……），标签也按时间格式化，而不是把日期当裸数字。

## time scale

把字段在 model 里声明为 `temporal`，x 就自动走 time scale，无需手写 `<Scale>`：

<ComponentPreview name="scale-time" sourceFiles={['scale-time.data.ts']} />

<p className="text-sm text-muted-foreground">date 声明为 temporal → x 自动走 time；刻度落季度边界，标签按时间格式化。</p>

也可以不声明字段类型、直接显式覆盖维度的 scale 类型：

```tsx
<Plot data={visits}>
  <PathMark x="date" y="value" order="date" />
  <Scale dimension="x" type="time" />
  {/* 或快捷写法：<Axis dimension="x" scale="time" /> */}
  <Axis dimension="x" />
</Plot>
```

日期值可以喂 ISO 字符串（如 `'2024-01-01'`）或时间戳；time scale 负责把它们解析成时间轴上的位置。日期字段的解析格式细节见[数据处理](/plot/grammar/data/processing)。

## 时间字段映射颜色

时间也是连续量，所以把 `color` 绑一个时间字段会派生 `sequential`（连续色带）——和连续数值字段同一条路径，配色走命名 scheme。完整的连续色阶与配色规则见[连续比例尺](/plot/grammar/scale/continuous#连续值映射颜色)。
