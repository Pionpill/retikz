title: Scales
description: A scale maps a data value to a visual quantity — position, length, radius, color. Every channel goes through a scale, auto-picked from the field; this group splits into continuous / temporal / categorical by the field type they act on, plus custom scales.
---

A scale decides how a data value becomes a visual quantity. Position channels (`x` / `y`, or `angle` / `radius` under polar) turn into canvas coordinates, the `size` channel into a radius, the `color` channel into a color — each goes through a scale. `<Plot>` auto-picks a scale from the field's measurement type, so common charts need none by hand.

Axes are the most common place to configure positional scales, but scales and axes stay layered: scales map values, axes display ticks. Explaining a color scale to the reader is the job of the [legend](/plot/grammar/guide/legend).

## Derived from the field type

Once a field's measurement type is declared, the default scale follows directly from it — which is also how this group is split:

| Field type | Positional default | Color (per-datum marks) | Page |
| --- | --- | --- | --- |
| `continuous` | `linear` (swap for `log` / `sqrt` / `pow`) | `sequential` / `diverging` + binned scales | [Continuous](/plot/grammar/scale/continuous) |
| `temporal` | `time` | `sequential` (time is continuous too) | [Temporal](/plot/grammar/scale/temporal) |
| `categorical` | `band` (`point` for lines) | `ordinal` | [Categorical](/plot/grammar/scale/categorical) |

See [Data Model](/plot/grammar/data/model) for how to declare field types. The long tail beyond the 13 built-ins (symlog, brand ramps…) goes through [Custom scales](/plot/grammar/scale/custom).

## Overriding explicitly

`<Scale>` is a declarative child of `<Plot>` that overrides the default for one coordinate dimension; you can also put the common positional scale directly on the axis:

```tsx
<Plot data={rows}>
  <PathMark x="date" y="value" order="date" />
  <Scale dimension="x" type="time" />
  {/* or the shortcut: <Axis dimension="x" scale="time" /> */}
  <Axis dimension="x" />
</Plot>
```

Under polar, use `dimension="angle"` / `dimension="radius"`; `x` / `y` aliases are accepted. `Axis.scale` supports the positional shortcuts `linear` / `time` / `point` / `log` / `sqrt`. For finer control — log base, power exponent — write the full spec `scales`.
