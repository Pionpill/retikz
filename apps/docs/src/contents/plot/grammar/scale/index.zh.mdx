---
title: 比例尺
description: 比例尺（scale）把数据值映射成视觉量——位置、长度、半径、颜色。每个通道都过一个 scale，类型按字段自动选；本组按作用的字段类型分连续 / 时间 / 分类三页，外加自定义比例尺。
---

比例尺决定「数据值 → 视觉量」怎么算。位置通道（`x` / `y`，polar 下对应 `angle` / `radius`）的值要变成画布坐标、`size` 通道要变成半径、`color` 通道要变成颜色——中间都隔着一个 scale。`<Plot>` 会按字段的测量类型自动选 scale，常见图表不用手写。

坐标轴是位置比例尺最常见的配置入口，但 scale 与 axis 分层：scale 负责映射，axis 负责显示刻度。把颜色 scale 解释给读者看则是[图例](/plot/grammar/guide/legend)的活。

## 按字段类型派生

声明字段测量类型后，默认 scale 直接由类型决定——这也是本组分页的依据：

| 字段类型 | 位置默认 | 颜色（按 datum 着色） | 子页 |
| --- | --- | --- | --- |
| `continuous` | `linear`（可换 `log` / `sqrt` / `pow`） | `sequential` / `diverging` + 离散化色阶 | [连续比例尺](/plot/grammar/scale/continuous) |
| `temporal` | `time` | `sequential`（时间也是连续量） | [时间比例尺](/plot/grammar/scale/temporal) |
| `categorical` | `band`（折线用 `point`） | `ordinal` | [分类比例尺](/plot/grammar/scale/categorical) |

字段类型怎么声明见[数据模型](/plot/grammar/data/model)。内置 13 个 scale 之外的长尾（symlog、品牌色阶……）走[自定义比例尺](/plot/grammar/scale/custom)。

## 显式覆盖

`<Scale>` 是 `<Plot>` 的声明式子组件，覆盖对应坐标维度的默认选型；也可以把最常用的位置 scale 直接写在坐标轴上：

```tsx
<Plot data={rows}>
  <PathMark x="date" y="value" order="date" />
  <Scale dimension="x" type="time" />
  {/* 或快捷写法：<Axis dimension="x" scale="time" /> */}
  <Axis dimension="x" />
</Plot>
```

polar 图里用 `dimension="angle"` / `dimension="radius"`，也可用 `x` / `y` 作为别名。`Axis.scale` 只支持 `linear` / `time` / `point` / `log` / `sqrt` 这类位置 scale 快捷类型；要调对数底、幂指数等更细参数时，写完整 spec 的 `scales`。
