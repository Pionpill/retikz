`transform` 是图形语法里的**统计（Statistics）**层：数据进来后、喂给比例尺和图元之前，先按统计规则把数据行重写一遍。它和图元正交——同一份变换后的数据可以同时喂柱、线、点。

变换分两类：

| 类别 | 成员 | 行数 |
| --- | --- | --- |
| **改变行数** | `bin`（连续分箱）、`aggregate`（分组聚合） | N 行 → M 箱 / 组 |
| **保持行数** | `sort`（排序）、`stack`（堆叠）、`normalize`（归一化）、`derive-interval`（派生区间）、`jitter`（抖动） | N 行 → N 行（只重排 / 改字段） |

## 声明方式：`<Transform>`

用 `<Transform kind="...">` 声明一个变换，`kind` 判别类型，其余 props 直接对应该变换的字段。多个 `<Transform>` 按**声明顺序**折叠成管线：

```tsx
<Plot data={rows} model={model}>
  <Transform kind="aggregate" groupBy={['region']} reduce="sum" field="revenue" as="total" />
  <IntervalMark x="region" y="total" />
</Plot>
```

变换的产出字段（如 bin 的 `binStart` / `binEnd` / `binValue`、aggregate 的 `total`）是**派生字段**——它们由变换生成、不需要在 `model` 里声明，图元直接按名引用即可。被变换**消费**的输入字段（`aggregate` 的 `region` / `revenue`）仍然要在 `model` 里声明、参与严格校验。

程序化构造变换链时，也可以用 `<Plot dataTransforms={[...]}>` 直传一个 IR 数组——它和 `<Transform>` 子组件共用同一管线、可混用，直传的拼在子组件之前：

```tsx
<Plot data={rows} dataTransforms={[{ kind: 'aggregate', groupBy: ['region'], reduce: 'sum', field: 'revenue', as: 'total' }]}>
  <IntervalMark x="region" y="total" />
</Plot>
```

> 用 `dataTransforms` 而非 `transforms`，是为了和 core 容器的几何 `transforms`（平移 / 旋转）区分开。

> `<IntervalMark stack>` / `<IntervalMark angle>` 的自动堆叠是历史便利写法；当管线里已经显式存在一个**同款**（相同 `x` / `y` / `groupBy`）的 `stack` 时，那条自动堆叠会被抑制，不会对同一组数据堆叠两次（签名不同的堆叠柱不受影响）。

## bin：连续分箱（直方图）

`bin` 把一个连续字段切成若干区间，每个区间产出一行——携带箱的下界 `binStart`、上界 `binEnd`，以及箱内规约值 `binValue`（默认是频数 `count`）。这是直方图的底座。

`<IntervalMark>` 用 `x0` / `x1` 读箱边，画出**连续 x 轴上紧贴排列、宽度随箱边变化**的直方柱（区别于分类柱的等宽 band），`y` 读 `binValue` 作高度：

<ComponentPreview name="transform-histogram" sourceFiles={['transform-histogram.data.ts']} />

<p className="text-sm text-muted-foreground">连续 measurement 分成 8 个等宽箱，空箱（频数 0）也保留柱位。</p>

边界策略三选一（互斥）：

- `count`：目标箱数（默认 10），`nice` 把边界对齐到友好刻度（默认开）。
- `step`：固定箱宽（数据单位），从域下界平铺。
- `thresholds`：显式内部边界，K 条阈值产 K+1 个箱。

规约器 `reduce` 默认 `count`（频数）；`sum` / `mean` / `min` / `max` 需配 `reduceField` 指定被规约的数值字段。空箱的规约值为 `0`。

## aggregate：分组聚合

`aggregate` 把明细按 `groupBy`（一或多个字段）分组，每组用 `reduce`（`sum` / `mean` / `count` / `min` / `max`）规约成一行——产出行携带组键 + 规约值（`as` 命名，缺省如 `sumRevenue`）。N 笔明细 → M 组。

<ComponentPreview name="transform-aggregate" sourceFiles={['transform-aggregate.data.ts']} />

<p className="text-sm text-muted-foreground">8 笔订单明细按 region 求 revenue 总和 → 每地区一根柱。</p>

`count` 不需要 `field`；`sum` / `mean` / `min` / `max` 缺 `field` 会报错。多键 `groupBy` 形成复合键。

## normalize：组内归一化

`normalize` 把同组内各行的某数值字段除以组总和，得到组内占比。`basis` 选 `fraction`（[0,1]）或 `percent`（[0,100]）；`groupBy` 指定分组（缺省按全局总和）；`as` 命名输出字段（缺省原位覆盖）。

normalize 本身保持行数，和 `stack` 正交组合即得**百分比堆叠**——先归一化、再堆叠归一化后的值：

<ComponentPreview name="transform-normalize" sourceFiles={['transform-normalize.data.ts']} />

<p className="text-sm text-muted-foreground">每季度内各产品占比累叠，柱顶恒为 100%。</p>

组总和为 0 时该组占比输出 0，不产生 `NaN`。

## derive-interval：单行派生区间

`derive-interval` 给每行独立算出一个 `[start, end]` 区间，写进 `startField` / `endField`（缺省 `y0` / `y1`，对接 interval 的区间消费方）。两种模式：

- **baseline→value**：给 `from` 字段，区间为 `[baseline, from 值]`（`baseline` 缺省 0）——画基线不为 0 的柱、误差棒底座。
- **两字段**：给 `startFrom` + `endFrom`，区间为 `[startFrom 值, endFrom 值]`——画甘特条、显式区间。

```tsx
// 甘特：每个任务用 start / end 两字段算出区间
<Transform kind="derive-interval" startFrom="start" endFrom="end" />
```

它和 `stack` 的区别在于：`stack` 是**跨行累积**（同组各行首尾相接成累积链），`derive-interval` 是**单行独立**（行间无依赖）。两者都产 `y0` / `y1`，但语义正交——累积用 `stack`，单行区间用 `derive-interval`，不要用一个去做另一件事。

## jitter：确定性抖动

`jitter` 给连续数值位置字段加一个伪随机偏移，把重叠的散点抖开。`axis` 选 `x` / `y` / `both`，`amount` 是最大偏移（数据单位，均匀分布在 `[-amount, +amount]`）。

关键约束：IR 必须 JSON 可序列化、不能塞函数，所以随机性靠一个**整数 `seed` + 固定 PRNG**（mulberry32）在运行时重建——同一个 seed 在服务端渲染（SSR）和浏览器 hydration 抖出**逐字节相同**的坐标，不破坏确定性。

v1 的 jitter 只作用于**连续数值字段**（在字段值上加偏移再进比例尺）；它对字符串 / 分类字段无意义。散点「落在分类带内抖开」属于屏幕空间机制，不在本版范围。

## API

### `<Transform>`

| prop | 类型 | 说明 |
| --- | --- | --- |
| `kind` | `'sort' \| 'stack' \| 'bin' \| 'aggregate' \| 'normalize' \| 'derive-interval' \| 'jitter'` | 变换类型判别字段；其余 props 随 `kind` 取对应字段 |

### `kind="bin"`

| prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `field` | `string` | — | 被分箱的连续源字段 |
| `count` | `number?` | `10` | 目标箱数；与 `step` / `thresholds` 互斥 |
| `step` | `number?` | — | 固定箱宽；与 `count` / `thresholds` 互斥 |
| `thresholds` | `Array<number>?` | — | 显式内部边界（升序）；与 `count` / `step` 互斥 |
| `extent` | `[number, number]?` | 观测 min/max | 覆盖分箱域 |
| `nice` | `boolean?` | `true` | 边界对齐友好刻度（仅 `count` 策略） |
| `reduce` | `'count' \| 'sum' \| 'mean' \| 'min' \| 'max'?` | `'count'` | 每箱规约器 |
| `reduceField` | `string?` | — | 被规约字段（`sum` / `mean` / `min` / `max` 必填） |
| `startField` / `endField` / `valueField` | `string?` | `binStart` / `binEnd` / `binValue` | 输出字段名 |

### `kind="aggregate"`

| prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `groupBy` | `Array<string>` | — | 分组键字段（多键 = 复合键） |
| `reduce` | `'sum' \| 'mean' \| 'count' \| 'min' \| 'max'` | — | 组内规约器 |
| `field` | `string?` | — | 被规约字段（`count` 外必填） |
| `as` | `string?` | `reduce`+大写`field` | 规约值输出字段 |

### `kind="normalize"`

| prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `field` | `string` | — | 求组内占比的数值字段 |
| `groupBy` | `Array<string>?` | 全行单组 | 分组键（复合键）；缺省按全局总和 |
| `basis` | `'fraction' \| 'percent'?` | `'fraction'` | 输出比例尺度 |
| `as` | `string?` | 原位覆盖 | 输出字段名 |

### `kind="derive-interval"`

| prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `from` | `string?` | — | baseline→value 模式的值字段 |
| `baseline` | `number?` | `0` | `from` 模式的区间起点 |
| `startFrom` / `endFrom` | `string?` | — | 两字段模式的起 / 止字段（成对） |
| `startField` / `endField` | `string?` | `y0` / `y1` | 输出字段名 |

### `kind="jitter"`

| prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `axis` | `'x' \| 'y' \| 'both'?` | `'x'` | 抖动作用轴（被抖字段须为连续数值） |
| `xField` / `yField` | `string?` | `x` / `y` | 被抖动的连续数值字段 |
| `amount` | `number?` | `1` | 最大绝对偏移（数据单位，均匀 `[-amount,+amount]`） |
| `seed` | `number?` | `0` | 确定性 PRNG 整数种子（同 seed 复现同偏移） |
