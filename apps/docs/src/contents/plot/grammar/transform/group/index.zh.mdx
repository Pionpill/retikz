---
title: 分组规约
description: 分组规约会改变行数，把明细行按连续区间或分组键汇总成新的统计行。
---

分组规约用于从明细数据得到统计结果。它们会改变行数：`bin` 把连续字段切成箱，`aggregate` 把同组明细规约成一行。

下面按 transform 类型分别说明用途、示例和配置项。

| kind | 输入 | 输出 | 常见图形 |
| --- | --- | --- | --- |
| `bin` | 连续观测值 | 每个区间一行 | 直方图 |
| `aggregate` | 明细行 | 每个分组一行 | 分组柱、汇总线、排行 |

## 分箱-bin

`bin` 把一个连续字段切成若干区间，每个区间产出一行。输出行包含箱下界、箱上界和箱内规约值，默认字段名是 `binStart` / `binEnd` / `binValue`。

`IntervalMark` 用 `x0` / `x1` 读取箱边，画出连续 x 轴上紧贴排列、宽度随箱边变化的直方柱；`y` 读取 `binValue` 作高度。

<p className="text-sm text-muted-foreground">连续 measurement 分成 8 个等宽箱，空箱（频数 0）也保留柱位。</p>

边界策略三选一，互斥：

- `count`：目标箱数，默认 10；`nice` 默认开启，把边界对齐到友好刻度。
- `step`：固定箱宽，单位是数据单位。
- `thresholds`：显式内部边界，K 条阈值产 K+1 个箱。

`reduce` 默认 `count`。使用 `sum` / `mean` / `min` / `max` 时需要 `reduceField` 指定被规约的数值字段。空箱规约值为 `0`。

配置项：

| prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `field` | `string` | — | 被分箱的连续源字段 |
| `count` | `number?` | `10` | 目标箱数；与 `step` / `thresholds` 互斥 |
| `step` | `number?` | — | 固定箱宽；与 `count` / `thresholds` 互斥 |
| `thresholds` | `Array<number>?` | — | 显式内部边界；与 `count` / `step` 互斥 |
| `extent` | `[number, number]?` | 观测 min/max | 覆盖分箱域 |
| `nice` | `boolean?` | `true` | 边界对齐友好刻度，仅 `count` 策略 |
| `reduce` | `'count' \| 'sum' \| 'mean' \| 'min' \| 'max'?` | `'count'` | 每箱规约器 |
| `reduceField` | `string?` | — | 被规约字段；`sum` / `mean` / `min` / `max` 必填 |
| `startField` / `endField` / `valueField` | `string?` | `binStart` / `binEnd` / `binValue` | 输出字段名 |

## 聚合-aggregate

`aggregate` 按 `groupBy` 分组，并用 `reduce` 把每组明细规约成一行。输出行保留组键，并把规约值写到 `as` 字段；`as` 省略时使用默认字段名，例如 `sumRevenue` 或 `count`。

<ComponentPreview name="transform-aggregate" sourceFiles={['transform-aggregate.data.ts']} />

<p className="text-sm text-muted-foreground">8 笔订单明细按 region 求 revenue 总和，得到每地区一根柱。</p>

`count` 不需要 `field`；`sum` / `mean` / `min` / `max` 必须提供 `field`。`groupBy` 支持多个字段，多个字段会形成复合分组键。

配置项：

| prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `groupBy` | `Array<string>` | — | 分组键字段，支持复合键 |
| `reduce` | `'sum' \| 'mean' \| 'count' \| 'min' \| 'max'` | — | 组内规约器 |
| `field` | `string?` | — | 被规约字段；`count` 以外必填 |
| `as` | `string?` | `reduce`+大写`field` | 规约值输出字段 |

## 技术原理

分组规约的输出行不再是一条原始明细，因此 provenance 开启时会记录这一组输出来自哪些源行。locator 命中这类 datum 时，可以拿到组级来源，而不是伪造某一条明细行。

`bin` 会保留空箱；这让直方图的视觉结构稳定，不会因为某个区间没有样本就让相邻柱子挤在一起。`aggregate` 的组顺序按数据中首次出现的分组顺序保留。
