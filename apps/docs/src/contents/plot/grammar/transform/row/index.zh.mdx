---
title: 行级变换
description: 行级变换保持输入行数不变，用于排序、堆叠、组内归一化、单行区间派生和确定性抖动。
---

行级变换不会把多行合并成一行，也不会把一行拆成多行。它们只改变行顺序或给每行写入新的字段，适合放在 mark lowering 前做结构整理。

下面按 transform 类型分别说明用途、示例和配置项。

| kind | 作用 | 常见产出 |
| --- | --- | --- |
| `sort` | 按字段稳定排序 | 行顺序改变 |
| `stack` | 同组内跨行累积 | `y0` / `y1` |
| `normalize` | 同组内求占比 | 原字段或 `as` 字段 |
| `derive-interval` | 每行派生 `[start,end]` 区间 | `y0` / `y1` |
| `jitter` | 给连续位置字段加确定性偏移 | 覆盖 `x` / `y` 或指定字段 |

## 排序-sort

`sort` 按一个字段重排行，等值时保持原始相对顺序。它常用于在 line/path 前控制连接顺序，或在 stack 前固定输入顺序。

<ComponentPreview name="transform-sort" sourceFiles={['transform-sort.data.ts']} />

<p className="text-sm text-muted-foreground">输入行故意按 3、1、4、2、6、5 月乱序，sort 后折线按月份顺序连接。</p>

配置项：

| prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `field` | `string` | — | 排序字段 |
| `order` | `'ascending' \| 'descending'?` | `'ascending'` | 排序方向 |

## 堆叠-stack

`stack` 在每个 `x` 分组内按 `groupBy` 系列累加 `y`，给每行派生下界 / 上界。默认输出字段是 `y0` / `y1`，正好对接 `IntervalMark` 的区间消费方。

<ComponentPreview name="transform-stack" sourceFiles={['transform-stack.data.ts']} />

<p className="text-sm text-muted-foreground">每个季度内按产品累积 revenue，生成堆叠柱所需的 y0 / y1 区间。</p>

`<IntervalMark stack>` / `<IntervalMark angle>` 的自动堆叠是便利写法；当管线里已经存在相同 `x` / `y` / `groupBy` 的显式 `stack` 时，自动堆叠会被抑制，避免二次堆叠。

配置项：

| prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `x` | `string?` | 单组累积 | 分组键；同一值内累积 |
| `y` | `string` | — | 被累加的数值字段 |
| `groupBy` | `string?` | 数据行顺序 | 系列字段；按系列出现序决定段顺序 |
| `startField` / `endField` | `string?` | `y0` / `y1` | 输出上下界字段 |

## 归一化-normalize

`normalize` 把每行的数值除以所在组的总和，得到组内占比。`basis` 可以是 `fraction`（0 到 1）或 `percent`（0 到 100）；`as` 省略时原位覆盖输入字段。

normalize 和 stack 组合就是百分比堆叠：先把每组转成占比，再对占比做堆叠。

<ComponentPreview name="transform-normalize" sourceFiles={['transform-normalize.data.ts']} />

<p className="text-sm text-muted-foreground">每季度内各产品占比累叠，柱顶恒为 100%。</p>

配置项：

| prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `field` | `string` | — | 求组内占比的数值字段 |
| `groupBy` | `Array<string>?` | 全行单组 | 分组键；支持复合键 |
| `basis` | `'fraction' \| 'percent'?` | `'fraction'` | 输出比例尺度 |
| `as` | `string?` | 原位覆盖 | 输出字段名 |

## 派生区间-derive-interval

`derive-interval` 给每行独立算出一个 `[start,end]` 区间。它不看其它行，适合甘特条、显式区间或非零基线柱。

<ComponentPreview name="transform-derive-interval" sourceFiles={['transform-derive-interval.data.ts']} />

<p className="text-sm text-muted-foreground">每个任务行独立读取 start / end，并派生出统一的 y0 / y1 区间字段。</p>

它和 `stack` 的区别在于：`stack` 是跨行累积，`derive-interval` 是单行派生。两者默认都产出 `y0` / `y1`，但语义不同。

配置项：

| prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `from` | `string?` | — | baseline 到 value 模式的值字段 |
| `baseline` | `number?` | `0` | `from` 模式的起点 |
| `startFrom` / `endFrom` | `string?` | — | 两字段区间模式，必须成对出现 |
| `startField` / `endField` | `string?` | `y0` / `y1` | 输出字段名 |

## 抖动-jitter

`jitter` 给连续数值位置字段加一个伪随机偏移，把重叠散点抖开。偏移发生在数据空间、进入比例尺之前；`seed` 是整数，确保 SSR 和浏览器 hydration 得到一致结果。

<ComponentPreview name="transform-jitter" sourceFiles={['transform-jitter.data.ts']} />

<p className="text-sm text-muted-foreground">三个剂量上各 4 个重叠点，沿 x 抖开后可见分布。</p>

v1 的 jitter 只作用于连续数值字段。分类 band 内部的屏幕空间抖动不是这层 transform 处理的事情。

配置项：

| prop | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `axis` | `'x' \| 'y' \| 'both'?` | `'x'` | 抖动作用轴 |
| `xField` / `yField` | `string?` | `x` / `y` | 被抖动的连续数值字段 |
| `amount` | `number?` | `1` | 最大绝对偏移，单位是数据单位 |
| `seed` | `number?` | `0` | 确定性 PRNG 种子 |
