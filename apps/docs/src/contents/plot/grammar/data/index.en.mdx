---
title: Data
description: Data grammar aligns external datasets with the fields Plot consumes, and normalizes field names, types, and parsing rules before compilation.
---

Plot data does not enter IR. The configuration describes which fields to read, what types they have, and how they should be parsed; the actual dataset is passed at compile time. That keeps one grammar reusable across multiple data sources.
