---
title: 数据
description: 数据语法负责把外部数据源对齐到 Plot 可以消费的字段模型，并在编译前完成字段名、类型和解析规则的统一。
---

Plot 的数据不进入 IR。配置描述“要读哪些字段、字段是什么类型、需要怎样解析”，真实数据在编译时传入；这样同一份图形语法可以复用到不同数据源上。
