2D coordinates handle two positional dimensions. The default `cartesian2D` maps `x` to the horizontal axis and `y` to the vertical axis; switching to `polar2D` keeps the same field bindings but changes their geometric roles to angular and radial.

## Role Mapping

In cartesian, `x` is horizontal and `y` is vertical. In polar, the same channels take different geometric roles while the binding syntax stays the same:

| Channel | cartesian2D | polar2D |
| --- | --- | --- |
| `x` | horizontal position | angular, around the center |
| `y` | vertical position | radial, away from the center |

So polar charts still use `x` / `y`. The coordinate system decides whether those values become cartesian positions or angle / radius; marks do not split into flat and polar variants.

## Polar Options

`coordinate="polar2D"` is shorthand for a polar config with defaults. To adjust the angular range or carve a center hole, pass the object form:

```tsx
<Plot coordinate={{ type: 'polar2D', innerRadius: 0.5, startAngle: 0, endAngle: 360 }}>
```

| Field | Type | Default | Description |
| --- | --- | --- | --- |
| `innerRadius` | `number?` | `0` | Inner radius as a fraction `0..1` of the outer radius; `0` is a solid pie, `> 0` carves a center hole into a donut |
| `startAngle` | `number?` | `0` | Starting angle in degrees |
| `endAngle` | `number?` | `360` | Ending angle in degrees; together with `startAngle` it controls full or partial rings |

## Common Shapes

The same polar coordinate system pairs with different marks to cover common round charts.

### Radial Bars

`<BarMark>` becomes a radial bar under polar: the angular axis is categorical, the radial axis is the value. Just switch the coordinate; no new component.

### Pie And Donut

`<BarMark angle="value" />` accumulates the `angle` value field into sector angular bounds. Add `innerRadius` to turn a pie into a donut.

### Radar

`<LineMark closed />` connects the last point back to the first, closing into a polygon outline. In polar this is a radar chart: dimensions spread along the angular axis, values map to radius.

<ComponentPreview name="coordinate-radar" sourceFiles={['coordinate-radar.data.ts']} />

### Polar Line

An open `<LineMark>` under polar is a polar line plot: `x` as angle, `y` as radius, connected by `order`. It fits wind direction and cyclic data.
