`<PathMark>` 是一维轨迹 mark；cartesian 下常表现为折线。它把数据点按顺序连成一条路径。`x` / `y` 绑位置字段，`order` 决定连接顺序（缺省按数据数组顺序）。给 `series` 拆成多条路径，给 `closed` 首尾相接闭合。

## 用法

```tsx
import { PathMark, Plot } from '@retikz/plot-react';
```

```tsx
<Plot data={revenue}>
  <PathMark x="month" y="revenue" order="month" />
</Plot>
```

`order` 推荐显式写——否则折线按数据行顺序连，数据顺序一变折线就乱跳。

## API

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `x` | `string` | — | 绑 x 通道的字段路径（polar 下作角向） |
| `y` | `string` | — | 绑 y 通道的字段路径（polar 下作径向） |
| `order` | `string?` | 数据顺序 | 驱动连接顺序的字段 |
| `series` | `string?` | — | 系列字段：拆成多条折线；缺省单线 |
| `closed` | `boolean?` | `false` | 末点回连首点闭合成多边形（polar 下即雷达轮廓） |
| `color` | `string?` | `series` | 颜色字段（categorical，自动 ordinal 色 scale）；无显式 `series` 时按此字段隐式拆系列；缺省取 `series`。连续 / 时间字段会报错（连续色阶待后续） |
| `id` | `string?` | — | 可选句柄（预留，暂不解析） |
