---

`<ReferenceMark>` 在数据空间声明一个轴向约束。绑 `y` 得到水平参考，绑 `x` 得到竖直参考；只给下界是线，配 `xTo` / `yTo` 是带。`number` 表示常量，`FieldName` 表示字段名或字段路径，并按每行数据生成一条参考。

它和 `<PointMark>` / `<IntervalMark>` 一样参与同一坐标系内的叠放顺序，但不从点、线、面维度出发，而是先确定一个固定轴值，再沿对侧轴域展开。

## 用法

```tsx
import { Plot, ReferenceMark } from '@retikz/plot-react';
```

```tsx
<Plot data={scores}>
  <ReferenceMark y={60} color="crimson" />
  <ReferenceMark y={60} yTo={80} color="#fde68a" />
</Plot>
```

`x` 和 `y` 必须二选一。`xTo` 只能和 `x` 配对，`yTo` 只能和 `y` 配对；对侧部分长度则用 `extentField` / `extentToField` 成对声明。

## 表现层

ReferenceMark 是底层参考 mark：它只负责把一个固定轴值解释成 line，或把两个固定轴值解释成 band。表现层看到的“阈值线”“容差带”“参考环”“扇形楔”不是不同 mark，而是同一个 ReferenceMark 在不同坐标系和边界配置下的显示形态。

取向由绑定的轴决定，形态由是否给上界决定：

| 表现形态 | 关键属性 | 说明 |
| --- | --- | --- |
| 水平参考线 | `y` | 固定 y 值，跨满 x 域 |
| 竖直参考线 | `x` | 固定 x 值，跨满 y 域 |
| 水平参考带 | `y` / `yTo` | 固定 y 区间，填充 `y∈[y,yTo]` |
| 竖直参考带 | `x` / `xTo` | 固定 x 区间，填充 `x∈[x,xTo]` |

在 `polar2D` 下，同一组属性会被坐标系重解释：`y` 是常半径参考环，`y` / `yTo` 是环带；`x` 是径向参考线，`x` / `xTo` 是扇形楔。

## 技术原理

`ReferenceMark` 是一个内置注册图元。React 里的 `<ReferenceMark>` 本身不渲染 DOM；`<Plot>` 会把扁平 props 装配成 `type: 'reference'` 的 mark IR，把 `x` / `y` 放进 `encoding`，并把 `xTo` / `yTo` / `extentField` / `extentToField` 保留在 mark 顶层。

编译时，`lowerMark` 按 `mark.type` 查询 `MARK_REGISTRY`，`ReferenceMark` 命中 `PlotMark.Reference` 对应的 `lowerReferenceLayer`。`lowerReferenceLayer` 只接受 cartesian2D / polar2D，然后调用 `lowerReference`：line 下沉成 core `Path`，band 通过 `frame.projectCell(...)` 下沉成 core `Node` 几何。

注册部分只需要看 `ReferenceMark` 对应的注册行，以及真正执行下沉的 `lowerReferenceLayer` / `lowerReference`：

```ts
[PlotMark.Reference]: { type: PlotMark.Reference, lower: lowerReferenceLayer },

const lowerReferenceLayer = (mark: Mark, rows: Array<ExternalRow>, frame: ResolvedCoordinate, channels: MarkChannels, markProvenance: MarkProvenance | undefined): IRChild | null => {
  if (mark.type !== PlotMark.Reference) return null;
  if (frame.type !== PlotCoordinate.Cartesian2D && frame.type !== PlotCoordinate.Polar2D) {
    throw new Error(failLoudMessage(mark.type, frame.type));
  }
  const layer = lowerReference(mark, rows, frame, channels.colorOf, channels.defaultColor, markProvenance);
  return layer === null ? null : attachMarkLayer(layer, mark, markProvenance);
};

const lowerReference = (mark: ReferenceMark, rows: Array<ExternalRow>, frame: CartesianCoordinate | PolarCoordinate, colorOf: ColorOf | undefined, defaultColor: string | undefined, markProvenance: MarkProvenance | undefined): IRScope | null => {
  const orientation = referenceOrientation(mark);
  const band = isReferenceBand(mark, orientation);
  const effectiveRows = referenceRows(mark, rows, orientation);

  if (band) {
    for (const row of effectiveRows) {
      const cell = referenceBandCell(mark, row, frame, orientation);
      if (!cell) continue;
      const geometry = frame.projectCell(cell);
      // band: cell geometry -> core Node layer
    }
    return bandLayer;
  }

  for (const row of effectiveRows) {
    const steps = referenceLineSteps(mark, row, frame, orientation);
    if (!steps) continue;
    // line: reference steps -> core Path layer
  }
  return lineLayer;
};
```

这段逻辑可以拆成四步：

| 步骤 | 说明 |
| --- | --- |
| 取向校验 | `referenceOrientation` 要求 `encoding.x` / `encoding.y` 恰好存在一个 |
| 形态判断 | `isReferenceBand` 检查上界是否和绑定轴匹配；有上界走 band，无上界走 line |
| 行迭代 | 完全常量参考只生成一条；字段轴值、字段上界或 extent 字段按数据行生成 |
| core 下沉 | line 生成 core `Path`；band 通过坐标系 `projectCell` 生成可填充几何 Node |

## API

`ReferenceMark` 同时有常量轴值和数据通道。表里的 `FieldName` 表示字段名或字段路径，例如 `threshold` / `limits.lo`；`number` 表示直接写入的常量轴值。

| 分类 | 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- | --- |
| 取向 | `y` | `number \| FieldName?` | — | 绑定水平参考的常量轴；数字为常量，字段为 per-datum 参考 |
| | `x` | `number \| FieldName?` | — | 绑定竖直参考的常量轴；数字为常量，字段为 per-datum 参考 |
| 上界 | `yTo` | `number \| FieldName?` | — | 水平 band 上界；与 `y` 配对生成 `y∈[y,yTo]` |
| | `xTo` | `number \| FieldName?` | — | 竖直 band 上界；与 `x` 配对生成 `x∈[x,xTo]` |
| 部分长度 | `extentField` | `FieldName?` | 对侧轴满域 | 对侧维部分长度起点字段，必须与 `extentToField` 成对 |
| | `extentToField` | `FieldName?` | 对侧轴满域 | 对侧维部分长度终点字段，必须与 `extentField` 成对 |
| 样式 | `color` | `string?` | 默认图层色 | 常量参考时是颜色字符串；per-datum 参考时是颜色字段名 |
| 通用 | `id` | `string?` | — | 可选句柄（预留，暂不解析） |
