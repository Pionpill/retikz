`<IntervalMark>` 不是“柱图元”，而是区间图元。它为每条数据构造一个或多个位置维度上的区间，再交给坐标系投影：cartesian 下常是矩形，polar 下可以是径向柱或扇区。

默认写 `x` / `y` 时，`x` 走 band 区间、`y` 从 baseline `0` 延伸到数值；显式写 `bounds` 时，可以把任一维声明为 `band` / `span` / `extent` / `full`。表里的 `FieldName` 表示数据字段名或字段路径，例如 `quarter` / `sales.revenue`。

## 用法

```tsx
import { IntervalMark, Plot } from '@retikz/plot-react';
```

```tsx
<Plot data={revenue}>
  <IntervalMark x="quarter" y="value" />
</Plot>
```

普通柱只需要 `x` / `y`。直方图使用 `x0` / `x1` 表达连续区间；热图用 `bounds` 声明双 band；饼图 / 环图用 `angle` 让 React DSL 自动累积角区间。

## 表现层

IntervalMark 是底层 cell mark：它只负责把每行数据变成一个正交区间 cell，再由坐标系把 cell 投影成矩形、扇区或轮廓。柱、直方、热图、径向柱、饼图和环图不是不同的底层 mark，而是同一个 IntervalMark 在不同 `bounds`、`series`、`stack` 和 `coordinate` 下的表现形态。

| 表现形态 | 关键属性 | 说明 |
| --- | --- | --- |
| 柱 | `x` / `y` | `x` 分类槽给宽度，`y` 从 `0` 延伸到数值 |
| 分组柱 | `series` | 同一分类槽内按系列切子带 |
| 堆叠柱 | `series` / `stack` | stack transform 产出 `y0` / `y1`，`bounds.y` 改为 extent |
| 直方 | `x0` / `x1` / `y` | `x0` / `x1` 提供连续 x 区间，`y` 提供高度 |
| 热图 / 网格 | `bounds` | `bounds.x` 和 `bounds.y` 都声明为 `band` |
| 饼 / 环 | `angle` / `coordinate` | `angle` 累积成角向 extent，半径方向使用 full |

`series` 把数据拆成多组。没有 `stack` 时，每个 x band 会按系列字段切成并排子带。

同一个 `x` / `y` 区间切到 `coordinate="polar2D"` 后，`x` band 会被解释成角向 band，`y` span 会被解释成半径方向长度。

## 技术原理

`IntervalMark` 是一个内置注册图元。React 里的 `<IntervalMark>` 本身不渲染 DOM；`<Plot>` 会在构造 `PlotSpec` 时把它收集成 `type: 'interval'` 的 mark IR，并根据便捷 props 补出 `bounds`、自动 stack transform 和颜色 scale。

编译时，`lowerMark` 按 `mark.type` 查询 `MARK_REGISTRY`。`IntervalMark` 命中 `PlotMark.Interval` 对应的 `lowerIntervalLayer`；该函数要求当前坐标帧提供 `projectCell`，然后逐行调用 `markCell` 与当前坐标系的 `projectCell`。cartesian2D / polar2D 会额外构造 `IntervalContext` 处理 band 与分组子带；自定义坐标系若要支持 interval，需要在 frame 上同时提供 `roleScales` 与 `projectCell`。坐标系决定 cell 最后是矩形、扇区还是 contour，IntervalMark 本身不分叉处理这些形态。

注册行和核心下沉函数的关键部分如下：

```ts
[PlotMark.Interval]: { type: PlotMark.Interval, buildCell: (mark, row, frame, ctx) => markCell(mark, row, frame, ctx), lower: lowerIntervalLayer },

const lowerIntervalLayer = (mark: Mark, rows: Array<ExternalRow>, frame: CoordinateFrame, channels: MarkChannels, markProvenance: MarkProvenance | undefined): IRChild | null => {
  if (mark.type !== PlotMark.Interval) return null;
  if (!hasProjectCell(frame)) {
    throw new Error(failLoudMessage(mark.type, frame.type));
  }
  const ctx = isCartesianCoordinateFrame(frame) || isPolarCoordinateFrame(frame) ? buildIntervalContext(mark, frame, rows) : isGenericCoordinateFrame(frame) ? buildGenericIntervalContext(mark, frame, rows) : undefined;
  const layer = lowerCells(mark, rows, frame, frame.projectCell, ctx, channels.colorOf, channels.defaultColor, markProvenance, channels.labelOf);
  return layer === null ? null : attachMarkLayer(layer, mark, markProvenance);
};

const lowerCells = (
  mark: Mark,
  rows: Array<ExternalRow>,
  frame: CoordinateFrame,
  projectCell: (cell: Cell) => CellGeometry,
  ctx: IntervalContext | undefined,
  colorOf: ColorOf | undefined,
  defaultColor: string | undefined,
  markProvenance: MarkProvenance | undefined,
  labelOf: LabelOf | undefined,
): IRScope | null => {
  const placed: Array<{ color: string | undefined; node: IRNode }> = [];
  let kind: CellGeometry['kind'] | undefined;
  for (let transformedIndex = 0; transformedIndex < rows.length; transformedIndex++) {
    const row = rows[transformedIndex];
    const cell = markCell(mark, row, frame, ctx);
    if (!cell) continue;
    const geometry = projectCell(cell);
    if (!isRenderableCellGeometry(geometry)) continue;
    kind = geometry.kind;
    const node = attachDatumLabel(
      decorateDatum(cellGeometryNode(geometry), row, transformedIndex, mark.type, markProvenance, cellSeriesValue(mark, row)),
      mark,
      row,
      labelOf,
    );
    placed.push({ color: colorOf?.(row), node });
  }
  return placed.length === 0 || kind === undefined ? null : cellLayer(placed, kind, colorOf, defaultColor);
};
```

| 步骤 | 说明 |
| --- | --- |
| 坐标系守卫 | IntervalMark 需要坐标帧提供 `projectCell`；无 cell 投影能力时 fail-loud |
| 区间构造 | `markCell` 根据 `bounds`、位置通道、`series` 和 stack 派生字段构造逻辑 cell；自定义 frame 还需提供 `roleScales` |
| 坐标投影 | `frame.projectCell` 把逻辑 cell 投影成 `rect`、`sector` 或 `contour` |
| core 下沉 | `cellGeometryNode` 把可渲染几何装配成 core Node，空 contour 会被跳过，颜色通道按颜色分组上提到 Scope |

## API

`IntervalMark` 的大多数属性都是数据通道。表里的 `FieldName` 表示数据字段名或字段路径，例如 `quarter` / `sales.revenue`。

| 分类 | 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- | --- |
| 位置 | `x` | `FieldName?` | — | x 位置字段；普通柱、热图、径向柱使用 |
| | `y` | `FieldName?` | — | y 位置字段；普通柱、热图、径向柱使用 |
| | `x0` / `x1` | `FieldName?` | — | 连续 x 区间的上下界字段；用于直方图等显式区间 |
| | `angle` | `FieldName?` | — | 饼图 / 环图入口：份额值字段，自动累积成角区间 |
| 区间 | `bounds` | `IntervalBounds?` | 按 scale 推断 | 高级区间来源；热图写 `{ x: { kind: 'band' }, y: { kind: 'band' } }` |
| 系列 | `series` | `FieldName?` | — | 系列字段；拆成多系列区间 |
| | `stack` | `boolean?` | `false` | 多系列时改为堆叠；省略时多系列并排 |
| 样式通道 | `color` | `FieldName?` | `series` | 颜色字段；缺省时取 `series` |
| 标签 | `label` | `FieldName?` | — | 宿主 datum 标签字段 |
| | `labelFormat` | `string?` | — | 标签格式串 |
| | `labelPosition` | `CompassAnchor \| number?` | `above` | 标签相对宿主 Node 的方位 |
| | `labelDistance` | `number?` | `12` | 标签与宿主边框的距离 |
| | `labelPin` | `boolean?` | `false` | 是否从宿主边框拉引线到标签 |
| | `resolveLabel` | `(row) => string?` | — | 运行时生成标签；不进 IR，需要配 `id` |
| 通用 | `id` | `string?` | — | 可选句柄 |
