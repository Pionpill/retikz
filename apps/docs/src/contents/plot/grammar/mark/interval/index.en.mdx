title: IntervalMark
description: "IntervalMark expresses interval products across position roles; bars, histograms, heatmaps, radial bars, pies, and donuts are different projections of it."
---

`<IntervalMark>` is not a "bar mark"; it is the interval mark. It builds intervals across one or more position roles for each datum, then lets the coordinate system project them: rectangles under cartesian coordinates, radial bars or sectors under polar coordinates.

With plain `x` / `y`, `x` is a band interval and `y` spans from baseline `0` to the value. With explicit `bounds`, each role can be declared as `band` / `span` / `extent` / `full`.

## Interval Rules

| Form | x bounds | y bounds | Meaning |
| --- | --- | --- | --- |
| Bar | `band` | `span` | Category slot × numeric height |
| Grouped bar | `band{group}` | `span` | Split one category slot into sub-bands |
| Stacked bar | `band` | `extent(y0,y1)` | Bounds produced by stack transform |
| Histogram | `extent(x0,x1)` | `span` | Continuous x interval × frequency / aggregate |
| Heatmap | `band` | `band` | Double category slot × color value |
| Pie / donut | `extent(start,end)` | `full` | Polar angular extent × full radius |

## Continuous Intervals

A histogram is not a band bar. It uses explicit continuous x bounds: `x0` / `x1` become `bounds.x=extent(x0,x1)`, while `y` remains the interval height.

## API

| prop | type | description |
| --- | --- | --- |
| `x` | `string?` | x position field; used by bars, heatmaps, and radial bars |
| `y` | `string?` | y position field; used by bars, heatmaps, and radial bars |
| `x0` / `x1` | `string?` | Continuous x interval bounds; used by histograms and other explicit intervals |
| `angle` | `string?` | Polar pie / donut shortcut: share-value field, accumulated into angular extents |
| `bounds` | `IntervalBounds?` | Advanced interval source; heatmaps use `{ x: { kind: 'band' }, y: { kind: 'band' } }` |
| `series` | `string?` | Series field; omit for a single series |
| `stack` | `boolean?` | Stack multiple series; omit for side-by-side grouping |
| `color` | `string?` | Color field; falls back to `series` |
| `label` | `string?` | Host datum-label field |
| `id` | `string?` | Optional handle |
