title: Marks
description: Marks are the registered layer from data to geometry: each mark declares a low-level geometry, while scales and coordinates decide its final form.
---

Marks are the geometry layer of the graphic grammar. They do not hard-code pixel positions; they declare which kind of low-level geometry the data should produce: point, path, region, interval, reference, or link.

Each built-in mark is a registered entry. During compilation, field mappings become channels and are then lowered by the matching mark; the coordinate system interprets those channels, so the same mark can produce different shapes in different coordinates.

## Mechanism

| Mark | Type | Mechanism | Common forms |
| --- | --- | --- | --- |
| `PointMark` | dimensional | A 0D glyph at a coordinate tuple | Scatter, bubbles, text points |
| `PathMark` | dimensional | Ordered points connected into a 1D trajectory | Lines, paths, radar outlines |
| `RegionMark` | dimensional | A 2D region enclosed by a boundary | Areas, filled radar |
| `IntervalMark` | dimensional | Orthogonal interval products across position roles | Bars, histograms, heatmaps, radial bars, pies / donuts |
| `ReferenceMark` | special | Reference constraints at fixed positions or intervals | Threshold lines, reference rings, tolerance bands |
| `LinkMark` | special | Relational geometry from source to target | Ribbons, alluvial bands |

Chart forms are not separate low-level marks. A heatmap is a double-band `IntervalMark`, a pie is an angular `IntervalMark` under polar coordinates, and scatter / bubble / text points are different presentation settings of `PointMark`.

## Lowering to Core

plot marks do not own renderer primitives directly; after lowering, they become Kernel IR from [@retikz/core](/core/introduction). The geometric body usually lowers to [Node](/core/components/node/overview) or [Path](/core/components/draw/path), while color groups, series groups, and shared defaults are carried by [Scope](/core/components/layout/scope).

| Mark | Core implementation | Notes |
| --- | --- | --- |
| `PointMark` | [Node](/core/components/node/overview) | Each row produces one point Node; text points are borderless text Nodes |
| `PathMark` | [Path](/core/components/draw/path) | Ordered projected points become move / line steps, then one or more Paths |
| `RegionMark` | [Path](/core/components/draw/path) | The upper outline plus baseline return forms a closed Path, filled as an area / region |
| `IntervalMark` | [Node](/core/components/node/overview) | The coordinate frame projects each cell into rect / sector / contour geometry, then packs it into a sized or shaped Node |
| `ReferenceMark` | [Path](/core/components/draw/path) / [Node](/core/components/node/overview) | Reference lines lower to Paths; reference bands lower to interval Nodes |
| `LinkMark` | [Path](/core/components/draw/path) | Source / target endpoints form a closed cubic Path, filled as a flow band |
