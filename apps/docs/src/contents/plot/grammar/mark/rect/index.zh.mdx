`<RectMark>` 把每行数据画成一个矩形格：`x` 和 `y` **都绑分类字段**（`<Plot>` 自动给两条轴都用 band 比例尺），每格大小固定为 `bandwidth_x × bandwidth_y`；数据的值不进位置，而是经 `color` 通道映射成格子的填充色。这是画热图、混淆矩阵、日历热图的基础。

## 与柱（interval）的区别

热图和柱的本质区别在「第二维是什么」：

- **柱**（`<BarMark>`）：`x` 来自 band 比例尺（取 `bandwidth` 当柱宽），`y` 是**连续值**——柱高随数据伸缩，格子是「一段带 × 一段连续区间」。
- **矩形格**（`<RectMark>`）：`x` **和** `y` **都来自 band 比例尺**，格子是 `bandwidth_x × bandwidth_y` 的固定网格；值经 `color` 通道映射成填充色，不进位置。

因此 `<RectMark>` 同时把 x 轴和 y 轴都强制成 band 比例尺——若你显式声明了连续的 `<Scale dimension="y">` 与之冲突，会直接报错。

## 缺 color：纯网格

不给 `color` 时，每格回退到统一默认填充——得到一张「无值映射的纯网格」，可作底格再叠加 `<PointMark>` / 文本等：

## API

| prop | 类型 | 说明 |
| --- | --- | --- |
| `x` | `string` | 绑 x 通道的字段路径（分类，自动 band 比例尺，定格宽） |
| `y` | `string` | 绑 y 通道的字段路径（分类，自动 band 比例尺，定格高） |
| `color` | `string?` | 颜色字段：值映射成格子填充。连续字段需 `model` 声明 → 自动 sequential 色阶（viridis），按 datum 着色；缺省时为纯网格（统一默认填充） |
| `id` | `string?` | 可选句柄（预留，暂不解析） |
