---

`<LinkMark>` 描述两组投影端点之间的关系。每行数据会从源端点（`sourceX` / `sourceY`）弯到目标端点（`targetX` / `targetY`），两条长边是 cubic 曲线、两端是直线封口，围成一个可填充区域。

`value` 是宽度通道，经内建线性宽度比例尺映射成源端带宽；`endWidth` 可给目标端独立宽度。sankey、alluvial 流量图只是它的常见表现形态，LinkMark 本身只消费已经算好的端点位置和宽度字段。

## 用法

```tsx
import { LinkMark, Plot } from '@retikz/plot-react';
```

```tsx
<Plot data={flows}>
  <LinkMark sourceX="sourceX" sourceY="sourceY" targetX="targetX" targetY="targetY" value="value" color="channel" />
</Plot>
```

端点必须是同一坐标系里的字段对。当前 LinkMark 只支持 `cartesian2D`；跨 facet / inset / scope 的具名节点连线属于后续能力。

## 表现层

LinkMark 是底层关系 mark：它只负责把每行数据下沉成一条可填充曲带。表现层看到的 sankey、alluvial、流量迁移图，不是新的底层 mark，而是同一个 LinkMark 配合外部布局和分组后的显示形态。

流带默认 `orientation="horizontal"`：出 / 入切向沿水平轴、半宽沿垂直轴，得到左右流（封口竖直）。设 `orientation="vertical"` 时，流向自上而下，半宽沿水平轴。带宽可以从源端到目标端平滑渐变。

| 表现形态 | 关键属性 | 说明 |
| --- | --- | --- |
| 等宽流带 | `sourceX` / `sourceY` / `targetX` / `targetY` / `value` | 每行连接一对端点，源端和目标端等宽 |
| 喇叭流带 | `value` / `endWidth` | 源端宽度和目标端宽度不同，沿程平滑渐变 |
| 分组流带 | `color` | 按字段分组上色；不改变几何，只改变填充层 |

<ComponentAlert title="流带只画带，不算布局" description="节点排在哪、多条流怎么堆叠、交叉怎么最小化，这些是 sankey / alluvial 布局算法，不在 <LinkMark> 里。每行的 sourceX/Y、targetX/Y、value 须由你预先算好（或后续的布局 transform 产出）写回数据，<LinkMark> 只消费这些已算好的位置和宽度。" />

## 例子

### 端点字段对与宽度

`sourceX` / `sourceY` 给源端字段对，`targetX` / `targetY` 给目标端字段对。`value` 决定带宽，`color` 决定填充颜色分组。

### 目标端宽度

给 `endWidth` 后，目标端使用独立宽度字段。源端半宽来自 `value`，目标端半宽来自 `endWidth`，中间由曲带几何平滑过渡。

<ComponentPreview name="ribbon-flared" sourceFiles={['ribbon-flared.data.ts']} />

### 几何属性

`curvature` 调两条 cubic 长边的 S 形张力，范围是 `0..1`，缺省 `0.5`。`orientation` 决定主轴：`horizontal` 是左右流，`vertical` 是上下流。

当前 demo 复用上面的喇叭带：`curvature={0.6}` 让弯曲更明显。`orientation` 不需要新数据，只是在同样的端点字段上改变半宽方向和控制点方向。

## 技术原理

`LinkMark` 是一个内置注册图元。React 里的 `<LinkMark>` 本身不渲染 DOM；`<Plot>` 会把扁平 props 装配成 `type: 'link'` 的 mark IR，把 `sourceX` / `sourceY` 和 `targetX` / `targetY` 变成嵌套的 `source` / `target` 字段对，并把 `value` / `endWidth` / `curvature` / `orientation` 保留在 mark 顶层。

编译时，`lowerMark` 按 `mark.type` 查询 `MARK_REGISTRY`，`LinkMark` 命中 `PlotMark.Link` 对应的 `lowerLinkLayer`。`lowerLinkLayer` 只接受 cartesian2D，然后调用 `lowerLink`：它为每行数据投影源端和目标端，计算源 / 目标半宽，再生成一条闭合 cubic core `Path`。

注册部分只需要看 `LinkMark` 对应的注册行，以及真正执行下沉的 `lowerLinkLayer` / `lowerLink`：

```ts
[PlotMark.Link]: { type: PlotMark.Link, lower: lowerLinkLayer },

const lowerLinkLayer = (mark: Mark, rows: Array<ExternalRow>, frame: CoordinateFrame, channels: MarkChannels, markProvenance: MarkProvenance | undefined): IRChild | null => {
  if (mark.type !== PlotMark.Link) return null;
  if (frame.type !== PlotCoordinate.Cartesian2D) {
    throw new Error(failLoudMessage(mark.type, frame.type));
  }
  const layer = lowerLink(mark, rows, frame, channels.colorOf, channels.defaultColor);
  return layer === null ? null : attachMarkLayer(layer, mark, markProvenance);
};

const lowerLink = (mark: LinkMark, rows: Array<ExternalRow>, frame: CoordinateFrame, colorOf: ColorOf | undefined, defaultColor: string | undefined): IRScope | null => {
  const halfWidthOf = linkHalfWidthOf(mark, rows);
  const curvature = mark.curvature ?? LINK_DEFAULT_CURVATURE;
  const placed: Array<{ color: string | undefined; steps: Array<IRStep> }> = [];
  for (const row of rows) {
    const value = linkValueOf(row, mark.value);
    if (value === null) continue;
    const endValue = mark.endWidth !== undefined ? linkValueOf(row, mark.endWidth) : value;
    if (endValue === null) continue;
    const halfSource = halfWidthOf(value);
    const halfTarget = halfWidthOf(endValue);
    const endpoints = linkEndpoints(mark, row, frame);
    if (endpoints === null) continue;
    const geometry = linkBandGeometry(endpoints.source, endpoints.target, halfSource, halfTarget, curvature, mark.orientation ?? 'horizontal');
    if (geometry === null) continue;
    placed.push({
      color: colorOf?.(row),
      steps: [
        { type: 'step', kind: 'move', to: geometry.sourceTop },
        { type: 'step', kind: 'cubic', to: geometry.targetTop, control1: geometry.topControl1, control2: geometry.topControl2 },
        { type: 'step', kind: 'line', to: geometry.targetBottom },
        { type: 'step', kind: 'cubic', to: geometry.sourceBottom, control1: geometry.bottomControl1, control2: geometry.bottomControl2 },
        { type: 'step', kind: 'cycle' },
      ],
    });
  }
  // no color channel: one scope; color channel: group paths by fill
};
```

这段逻辑可以拆成四步：

| 步骤 | 说明 |
| --- | --- |
| 坐标系校验 | 本轮只在 cartesian2D 下下沉；其他坐标系 fail-loud |
| 宽度映射 | `linkHalfWidthOf` 用 `value` / `endWidth` 的最大值合成线性宽度映射 |
| 端点投影 | `linkEndpoints` 把 source / target 字段对投影成屏幕点 |
| core 下沉 | `linkBandGeometry` 生成四角和控制点，最后下沉为闭合 core `Path` |

## API

`LinkMark` 的 API 按位置、专属、路径、通用和自定义分组：端点字段决定 source / target 位置，专属字段描述宽度和几何，路径字段下沉到 core `Path`。表里的 `FieldName` 表示字段名或字段路径，例如 `source.x` / `amount`；`curvature` / `orientation` 是常量几何配置。

| 分类 | 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- | --- |
| 位置 | `sourceX` / `sourceY` | `FieldName` | — | 源端位置字段对；当前只在 cartesian2D 下投影 |
|  | `targetX` / `targetY` | `FieldName` | — | 目标端位置字段对；当前只在 cartesian2D 下投影 |
| 专属 | `value` | `FieldName` | — | 源端流量字段，经合成线性比例尺映射为带宽 |
|  | `endWidth` | `FieldName?` | `value` | 目标端宽度字段；缺省时目标端与源端等宽 |
|  | `curvature` | `number?` | `0.5` | cubic 控制点沿主轴外推比例，范围 `0..1` |
|  | `orientation` | `'horizontal' / 'vertical'?` | `'horizontal'` | 主轴取向：水平左右流或垂直上下流 |
|  | `color` | `FieldName?` | 默认图层色 | 绑定颜色通道字段，按字段值分组填充 |
| 路径 | `fill` / `stroke` | `FieldName`<br />`IRPaintSpec`<br />`PointFillStyle?` / `PointStrokeStyle?` | `currentColor` / — | 流带填充和描边样式 |
|  | `opacity` / `fillOpacity`<br />`drawOpacity` | `PointOpacityStyle?`<br />`PointOpacityStyle?` | —<br />— | 流带整体、填充和描边透明度 |
|  | `zIndex` / `rotate` | `PointZIndexStyle?`<br />`PointNumberStyle?` | —<br />— | 绘制顺序和旋转 |
|  | `scale`<br />`fillRule` / `thickness` | `PathScaleStyle?`<br />`PathFillRuleStyle?`<br />`PathThicknessStyle?` | —<br />—<br />— | 路径缩放、填充规则和厚度预设 |
|  | `arrow` / `arrowDetail` | `PathArrowStyle?`<br />`PathArrowDetailStyle?` | —<br />— | 箭头方向与细节 |
|  | `dashPattern`<br />`shadow` / `blendMode` | `NodeDashPatternStyle?`<br />`ShadowStyle?`<br />`BlendModeStyle?` | —<br />—<br />— | 虚线、阴影和混合模式 |
| 通用 | `id` | `string?` | — | 可选 mark 句柄，用于图层 id |
| 自定义 | `channels` | `Record<string, Channel>` | — | 自定义通道入口；交给注册的 channel definition 解析 |
