`<RuleMark>` 在数据空间的某个常量位置画一条参考标注：绑 `y` 得到一条**水平线**（`y=const`，跨满 x 域），绑 `x` 得到一条**竖直线**（`x=const`，跨满 y 域）。给数字得到常量单条、给字段名得到每行一条（per-datum）。它和 `<BarMark>` / `<PointMark>` 并列，参与同一坐标系内的叠放顺序。

## 阈值线

最常见用法：在散点 / 柱图上叠一条阈值线。`y={60}` 是数字常量，画一条跨满 x 域的水平线。

## 容差带

给上界 `yTo` 就从线变成**填充带** `y∈[y, yTo]`——画容差区间、合格范围、高亮区段。带是一块可填充区域，先声明它再叠数据，让数据点画在带之上。

<ComponentPreview name="rule-band" sourceFiles={['rule-threshold.data.ts']} />

<p className="text-sm text-muted-foreground">水平容差带 y∈[60,80]，跨满 x 域；给 yTo → 填充区域。</p>

`xTo` 与 `yTo` 同理：绑 `x` 时用 `xTo` 得到竖直带。上界要与所绑维度匹配——绑 `x` 却给 `yTo`（或反之）会直接报错。

## 每行一条

`y` 给**字段名**而非数字时，按行驱动：每行一条水平 rule。配 `color` 字段按类别分别上色。

## 取向与形态

| 给了什么 | 取向 | 形态 |
| --- | --- | --- |
| `y`（数字 / 字段） | 水平（跨满 x 域） | 线 |
| `x`（数字 / 字段） | 竖直（跨满 y 域） | 线 |
| `y` + `yTo` | 水平 | 带 `y∈[y,yTo]` |
| `x` + `xTo` | 竖直 | 带 `x∈[x,xTo]` |

数字 → 常量、字符串 → 字段。`x` 和 `y` 必须二选一：两个都给或都不给会报错。

## 部分长度

默认线 / 带跨满对侧轴域。给一对 `extentField` / `extentToField`（对侧维的起止字段）把它截成线段 / 局部带——如甘特图里的时间游标段。两者须成对出现，只给一个会报错。

## 极坐标

`coordinate="polar2D"` 下取向被重解释：

- 绑 `y`（常量半径）→ 常半径**参考环**（弧 / 整圆，按角域）；配 `yTo` → **环带**。
- 绑 `x`（常量角度）→ **径向参考线**（从内到外）；配 `xTo` → **扇形楔**。

## API

| prop | 类型 | 说明 |
| --- | --- | --- |
| `y` | `number \| string?` | 水平 rule 的常量轴：数字 → 常量、字符串 → 字段（每行一条）。与 `x` 二选一 |
| `x` | `number \| string?` | 竖直 rule 的常量轴：数字 → 常量、字符串 → 字段（每行一条）。与 `y` 二选一 |
| `yTo` | `number \| string?` | 水平 band 上界（与 `y` 配对 → `y∈[y,yTo]`）；缺省为线 |
| `xTo` | `number \| string?` | 竖直 band 上界（与 `x` 配对 → `x∈[x,xTo]`）；缺省为线 |
| `extentField` | `string?` | 对侧维部分长度起点字段（与 `extentToField` 成对）；缺省满铺对侧轴域 |
| `extentToField` | `string?` | 对侧维部分长度终点字段（与 `extentField` 成对）；缺省满铺对侧轴域 |
| `color` | `string?` | 常量 rule → 颜色串（线描边 / 带填充）；per-datum → 字段名按类别上色 |
| `id` | `string?` | 可选句柄（预留，暂不解析） |
