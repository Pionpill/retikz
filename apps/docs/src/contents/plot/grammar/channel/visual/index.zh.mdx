---
title: 通道分组
description: 通道按消费面分为 position、mark、scope、node、path；内置与自定义通道共用同一套 definition registry。
---

通道不是按“看起来像什么”分组，而是按“由谁消费、最终落到哪里”分组。这样内置通道和自定义扩展会走同一条路径：它们都是 `ChannelDefinition`，只是在 `kind` 上声明不同消费面。

## 五类通道

| 分组 | 消费方 | 示例 | 用途 |
| --- | --- | --- | --- |
| `position` | coordinate definition | `x` / `y` / `z` | 坐标角色；由坐标决定必需角色和投影含义 |
| `mark` | mark lowering | `color` / `fill` / `stroke` / `label` | 同一个通道在不同 mark 上映射到不同可见面 |
| `scope` | core `IRScope` | layer-level `color` / `nodeDefault` / `pathDefault` | 整个 layer 共享的级联属性或默认属性 |
| `node` | core `IRNode` | `size` / `shape` / `opacity` / `strokeWidth` | 直接写入已有 node 属性 |
| `path` | core `IRPath` | path-level `opacity` / `strokeWidth` 等扩展面 | 直接写入已有 path 属性 |

`color` 是 mark 通道，不是 node 或 path 通道。point glyph 会把它转成 node fill，text point 会把它转成文本颜色，path mark 会把它转成 path stroke，region / link / reference mark 也可能把它转成 path fill 或 stroke。这个语义选择属于 mark。

`scope` 通道对应 core 的另一类样式面：`IRScope` 可以承载级联的 `color`、`stroke`、`fill`、`strokeWidth`、`opacity` 等属性，也可以承载 `nodeDefault` / `pathDefault` / `labelDefault` / `arrowDefault`。当一个值属于整个 layer 时，把它交给 scope 比逐个写入 node 或 path 更贴近 core 模型。

## 内置可见属性

| 通道 | 分组 | 输出 | 图例 |
| --- | --- | --- | --- |
| `color` / `fill` / `stroke` | `mark` | color | swatch / ramp |
| `label` | `mark` | text | 无 |
| `size` | `node` | numeric radius | size |
| `opacity` | `node` | numeric opacity | ramp |
| `shape` | `node` | glyph name | symbol |
| `strokeWidth` | `node` | numeric stroke width | 无 |
| `fillOpacity` / `drawOpacity` / `rotate` / `padding` / `minimumSize` / `minimumWidth` / `minimumHeight` / `zIndex` | `node` | core node property value | 无 |

node 通道读取同一份 canonical row，可以使用显式 scale，最后通过 `deliver` 写入 core `IRNode`。scope 通道写入 layer Scope 上的共享默认值；path 通道写入生成出来的 `IRPath` 元素。

## Definition 决定能力

直接落到 core node 属性的通道属于统一 registry 中的 `ChannelDefinitionKind.Node` 分支，通常用 `NodeChannelDefinition` 声明：

| 字段 | 作用 |
| --- | --- |
| `channel` | 注册名，也是 `encoding.channels.<name>` 的 key |
| `output` | 输出空间：颜色、数值范围或 symbol 调色板 |
| `legend` | 图例形式：`swatch` / `ramp` / `size` / `symbol` |
| `resolve` | 读取 mark 绑定，生成 resolved value 和可选 scale descriptor |
| `deliver` | 把 resolved value 写入已有 core scope / node / path 属性 |

内置 position / mark / scope / node / path 通道都会先进入同一个 channel registry，再由 lowering 解析每个 mark。node / path / scope 通道没有私有白名单，它们只是在 definition 的来源上不同。

## 与 scale 的关系

通道回答“这个属性叫什么、由谁消费、落到哪里”。scale 回答“字段值如何变成输出值”。例如 `size="population"` 会读取 `population` 字段，并默认使用 sqrt scale 生成半径；`shape="region"` 会使用 ordinal scale 把分类映射为 glyph 名称。

如果只想改变映射方式，先看[比例尺](/plot/grammar/scale)。如果想让某个字段驱动新的 scope / node / path 属性，继续看[自定义通道](/plot/grammar/channel/custom)。
