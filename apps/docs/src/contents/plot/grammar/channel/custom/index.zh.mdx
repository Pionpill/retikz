---
title: 自定义通道
description: 用 channelDefinitions 注册新的通道 definition，让自定义通道与内置通道共用同一套解析、registry 和交付路径。
---

常用 node 通道（`size`、`opacity`、`shape`、`strokeWidth`）有命名属性。要扩展自己的通道，用 `defineNodeChannel`、`definePathChannel` 或 `defineChannel` 声明运行时 definition，再通过 `<Plot channelDefinitions={...}>` 注册；spec 的 `encoding.channels.<name>` 仍只保存字段或常量绑定。

```tsx
import { defineNodeChannel } from '@retikz/plot';

const intensity = defineNodeChannel<number>({
  channel: 'intensity',
  output: { outputKind: 'number', range: [0.3, 1], clamp: true },
  resolve: ctx => mark => {
    const binding = mark.type === 'point' ? mark.encoding.channels?.intensity : undefined;
    if (binding?.field === undefined) return undefined;
    const values = ctx.rows.map(row => Number(row[binding.field])).filter(Number.isFinite);
    const min = Math.min(...values);
    const max = Math.max(...values);
    return {
      resolver: row => {
        const value = Number(row[binding.field]);
        if (!Number.isFinite(value)) return undefined;
        return 0.3 + (max === min ? 0.5 : (value - min) / (max - min)) * 0.7;
      },
    };
  },
  deliver: (node, value) => {
    node.opacity = value;
  },
});
```

绑定位置仍然是 JSON 安全的 PlotSpec：

```tsx
<Plot
  data={{ points }}
  spec={{
    namespace: 'plot',
    type: 'plot',
    data: { reference: 'points' },
    scales: [
      { type: 'linear', name: 'x' },
      { type: 'linear', name: 'y' },
    ],
    coordinate: { type: 'cartesian2D', x: 'x', y: 'y' },
    marks: [
      {
        type: 'point',
        encoding: {
          x: { field: 'x' },
          y: { field: 'y' },
          channels: { intensity: { field: 'score' } },
        },
      },
    ],
  }}
  channelDefinitions={[intensity]}
/>;
```

definition 是运行时能力，不写进 PlotSpec；PlotSpec 只保存通道绑定。内置通道和自定义通道合并进同一个 registry，再按 definition kind 统一进入 position / mark / scope / node / path 的消费路径。

`encoding.channels` 现在主要服务 spec / 程序化入口；React `<PointMark>` 仍把常用通道暴露成命名属性。自定义通道名不能覆盖内置通道名，绑定了未注册的通道会在 lowering 时报错。

## 契约边界

| 规则 | 原因 |
| --- | --- |
| `channel` 不能撞内置通道名 | 内置和自定义共享 registry，避免同名覆盖 |
| `resolve` 只构造逐行求值器 | 保持渲染值、图例 descriptor 与数据行同源 |
| `deliver` 只写 core scope / node / path 既有属性 | 新渲染能力应先补 core，不在 plot 绕开底层能力 |
| definition 不进 IR | 函数不可序列化；IR 只保存字段 / 常量绑定 |

如果你要扩展的是字段解析或具名格式，回到[自定义数据](/plot/grammar/data/custom)。如果你要扩展值到颜色 / 半径的映射方式，优先看[自定义比例尺](/plot/grammar/scale/custom)。
