`@retikz/tex` 给 retikz 补上数学排版：用 LaTeX 写公式，经 **MathJax SVG 模式**（字形 = SVG path，非字体）降解成 `@retikz/core` 的字形 `PathPrim`，SVG / 浏览器 Canvas / Node 位图三端一致、无需注入字体。公式是**节点内容**（`node.math`，与 `text` 平行）：直接把对象 `{ tex }` 写进 `<Node>` children（或用 `math` prop）即可，无 shape 时是独立公式块，配 shape 即带框公式。

## 安装与启用

`@retikz/tex` 提供 tex→字形引擎；MathJax 是它的 **optional peerDependency**（你自装、掌控版本与 macro）：

```bash
pnpm add @retikz/tex mathjax-full
```

公式渲染能力经 `lowerMath` 注入 compile。React 用 `useLowerMath`（`@retikz/tex/react` 子入口）一行启动 MathJax 并注入，公式写进 `<Node>` children：

```tsx
import { Layout, Node } from '@retikz/react';
import { useLowerMath } from '@retikz/tex/react';

const Diagram = () => {
  const lowerMath = useLowerMath(); // 进程级单例启动 MathJax，startup 完成后返回注入函数

  return (
    <Layout lowerMath={lowerMath}>
      <Node id="eq" position={[0, 0]}>
        {{ tex: '\\frac{a}{b} = c' }}
      </Node>
    </Layout>
  );
};
```

> `@retikz/tex/react` 是 tex 的可选子入口，仅它依赖 React（optional peer）——主入口 `@retikz/tex` 仍是无 React 的纯引擎，`@retikz/react` 也不会因此依赖 tex。想自己掌控启动时机，也可手写 `createMathJaxEngine` + `createLowerMath`（见下 Vanilla）后传 `<Layout lowerMath>`。

## 独立公式块

无 `shape` 的公式节点是独立公式块：复用节点的全套几何能力——可定位、可被 `<Path>` 连线、可加 [视觉效果](/core/components/effects/shadow) `shadow` / `blendMode`：

<ComponentPreview name="math-standalone" interactive />

`displayMode`（`{{ tex, displayMode: true }}`）用块级（display）度量（更大的分数 / 求和号），缺省行内度量。

## Vanilla

`createMathJaxEngine`（await 启动）→ `createLowerMath` → 注入 `toScene` 的 `lowerMath`；节点用 `math` 内容：

```ts
import { figure, node, renderToString } from '@retikz/vanilla';
import { createMathJaxEngine, createLowerMath } from '@retikz/tex';

const lowerMath = createLowerMath(await createMathJaxEngine());
const fig = figure([
  node('eq', { position: [0, 0], math: { tex: '\\frac{a}{b} = c' } }),
]);
const svg = renderToString(fig, { lowerMath });
```

## API 参考

### 节点公式内容

公式是节点内容，两种等价写法：写进 `<Node>` children 的对象 `<Node>{{ tex }}</Node>`，或 `math` prop（vanilla 用 `node(..., { math })`）。与 `text` 互斥，`math` 优先。

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `math` | `{ tex: string; displayMode?: boolean }` | — | 节点公式内容。`tex` = LaTeX 源；`displayMode` = 块级度量（缺省行内）。经注入 `lowerMath` 渲染成字形路径；节点尺寸由公式 bbox 决定。 |
| children 对象 | `{ tex: string; displayMode?: boolean }` | — | 同 `math`，直接写进 `<Node>` children 的便捷写法，如 `<Node>{{ tex: 'E=mc^2' }}</Node>`。 |

### 注入 API（`@retikz/tex`）

| 名称 | 签名 | 描述 |
| --- | --- | --- |
| `useLowerMath`（`@retikz/tex/react`） | `() => LowerMath \| undefined` | React 钩子：进程级单例启动 MathJax，返回注入函数（未就绪 = `undefined`）。把手写 startup effect 收进一行 |
| `createMathJaxEngine` | `(opts?) => Promise<MathJaxSvgEngine>` | 基于 `mathjax-full`（optional peer）构造同步 tex→SVG 引擎；startup 异步。也可自备等价 `MathJaxSvgEngine` |
| `createLowerMath` | `(engine) => LowerMath` | 引擎 → core 的 `lowerMath` 注入函数，按 `fontSize\|display\|tex` 缓存 |

## 降级与诊断

- **未注入 `lowerMath`** → 节点降级（不渲染公式）+ 警告 `MATH_LOWERER_MISSING`，不崩。
- **非法 tex / 渲染失败** → 警告 `MATH_TEX_INVALID` + 占位，不崩。
- **未装 `mathjax-full`** → `createMathJaxEngine` 抛带安装提示的错误；`useLowerMath` 内部已捕获 → `lowerMath` 保持 `undefined`，公式节点降级。
