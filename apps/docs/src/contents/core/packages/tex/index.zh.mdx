`@retikz/tex` 负责把 LaTeX 公式降解成 `@retikz/core` 可渲染的 glyph `PathPrim`。公式在 IR 里是节点内容 `node.tex`，和 `text` 平行：没有 `shape` 时是独立公式块，配 `shape` 时就是带框公式。React 侧推荐直接使用 `@retikz/tex/react` 的 `<TexNode>`。

## 安装与启用

`@retikz/tex` 提供 TeX → 字形路径的能力；MathJax 是 optional peerDependency，由应用安装并控制版本：

```bash
pnpm add @retikz/tex mathjax-full
```

React 里用 `useLowerTex` 启动 MathJax 并把能力注入 `<Layout lowerTex>`。公式可以直接写在 `<TexNode>` 的 children 里：

```tsx
import { Layout } from '@retikz/react';
import { TexNode, useLowerTex } from '@retikz/tex/react';

const Diagram = () => {
  const lowerTex = useLowerTex();

  return (
    <Layout lowerTex={lowerTex}>
      <TexNode id="eq" position={[0, 0]}>
        {'\\frac{a}{b} = c'}
      </TexNode>
    </Layout>
  );
};
```

## 多行公式

`TexNode` 是一个节点，而不是多行文本容器。多行公式建议写成一个 LaTeX 环境，并作为同一个 children 或 `tex` prop 传入；这样公式块仍然只有一个 bbox、一个连接目标：

## 封装与手写

`<TexNode>` 只是 `@retikz/tex/react` 提供的封装组件。它把 `tex` prop 或字符串 children 变成 `<Node tex={{ tex }} />`，同时透传 `<Node>` 的定位、shape、样式、label 和 hydration 事件字段。

不想引入 `@retikz/tex/react` 时，也可以只用 `@retikz/tex` 主入口手动创建 `lowerTex`，再直接写 `<Node tex={{ tex }}>`：

## Vanilla

`createMathJaxEngine`（await 启动）→ `createLowerTex` → 注入 `toScene` / `renderToString` 的 `lowerTex`；IR 或 vanilla 节点使用 `tex` 内容：

```ts
import { figure, node, renderToString } from '@retikz/vanilla';
import { createMathJaxEngine, createLowerTex } from '@retikz/tex';

const lowerTex = createLowerTex(await createMathJaxEngine());
const fig = figure([
  node('eq', { position: [0, 0], tex: { tex: '\\frac{a}{b} = c' } }),
]);

const svg = renderToString(fig, { lowerTex });
```

## API 参考

### TexNode

| 属性 | 类型 | 默认值 | 描述 |
| --- | --- | --- | --- |
| `tex` | `string` | - | LaTeX 源。若同时传入字符串 children，`tex` prop 优先。 |
| `children` | `string` | - | 直接把公式写成 children 的便捷写法。 |
| `displayMode` | `boolean` | `false` | 使用 display 度量，适合分式、求和、积分等块级公式。 |
| 其它 Node 字段 | `Omit<IRNode, 'type' \| 'tex' \| 'text'>` + hydration 事件 | - | 透传定位、`shape`、`fill`、`stroke`、`padding`、`label`、事件等节点能力。 |

### 底层接口

| API | 类型 | 描述 |
| --- | --- | --- |
| `useLowerTex`（`@retikz/tex/react`） | `() => LowerTex \| undefined` | React hook：启动 MathJax，返回可注入 `<Layout lowerTex>` 的函数；未就绪时为 `undefined`。 |
| `createMathJaxEngine` | `() => Promise<MathJaxSvgEngine>` | 创建 MathJax SVG 引擎。 |
| `createLowerTex` | `(engine) => LowerTex` | 把引擎转换成 core 的 `lowerTex` 注入函数，按 `fontSize|display|tex` 缓存。 |
| `LowerTex`（`@retikz/core`） | `(content, style) => LoweredTex \| null` | core 注入点类型；失败返回 `null`，compile 发出 `TEX_INVALID`。 |
