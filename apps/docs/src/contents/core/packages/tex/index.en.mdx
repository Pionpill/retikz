`@retikz/tex` brings math typesetting to retikz: write formulas in LaTeX, lowered via **MathJax SVG mode** (glyphs as SVG paths, not fonts) into `@retikz/core` glyph `PathPrim`s — consistent across SVG / browser Canvas / Node bitmap with no font injection. Math is **node content** (`node.math`, parallel to `text`): write an object `{ tex }` directly into `<Node>` children (or use the `math` prop) — no shape = a standalone formula block, with a shape = a framed formula.

## Install & enable

`@retikz/tex` provides the tex→glyph engine; MathJax is its **optional peerDependency** (you install it, controlling version & macros):

```bash
pnpm add @retikz/tex mathjax-full
```

The rendering capability is injected into compile via `lowerMath`. In React, `useLowerMath` (the `@retikz/tex/react` subpath) starts MathJax and injects it in one line; write the formula into `<Node>` children:

```tsx
import { Layout, Node } from '@retikz/react';
import { useLowerMath } from '@retikz/tex/react';

const Diagram = () => {
  const lowerMath = useLowerMath(); // starts MathJax (process-level singleton); returns the injection once ready

  return (
    <Layout lowerMath={lowerMath}>
      <Node id="eq" position={[0, 0]}>
        {{ tex: '\\frac{a}{b} = c' }}
      </Node>
    </Layout>
  );
};
```

> `@retikz/tex/react` is tex's optional subpath — only it depends on React (optional peer); the main `@retikz/tex` entry stays React-free, and `@retikz/react` never depends on tex. For manual control over startup timing, wire `createMathJaxEngine` + `createLowerMath` yourself (see Vanilla) and pass `<Layout lowerMath>`.

## Standalone formula

A math node without a `shape` is a standalone formula block, reusing the node's full geometry — positionable, connectable via `<Path>`, and able to take [visual effects](/core/components/effects/shadow) `shadow` / `blendMode`:

`displayMode` (`{{ tex, displayMode: true }}`) uses display (block) metrics (larger fractions / sums); omitted = inline metrics.

## Vanilla

`createMathJaxEngine` (await startup) → `createLowerMath` → inject as the `lowerMath` option of `toScene`; nodes use `math` content:

```ts
import { figure, node, renderToString } from '@retikz/vanilla';
import { createMathJaxEngine, createLowerMath } from '@retikz/tex';

const lowerMath = createLowerMath(await createMathJaxEngine());
const fig = figure([
  node('eq', { position: [0, 0], math: { tex: '\\frac{a}{b} = c' } }),
]);
const svg = renderToString(fig, { lowerMath });
```

## API reference

### Node math content

Math is node content, two equivalent forms: the object written into `<Node>` children `<Node>{{ tex }}</Node>`, or the `math` prop (vanilla uses `node(..., { math })`). Mutually exclusive with `text`, `math` wins.

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `math` | `{ tex: string; displayMode?: boolean }` | — | Node math content. `tex` = LaTeX source; `displayMode` = block metrics (default inline). Rendered to glyph paths via the injected `lowerMath`; the node is sized by the formula bbox. |
| children object | `{ tex: string; displayMode?: boolean }` | — | Same as `math`, written straight into `<Node>` children, e.g. `<Node>{{ tex: 'E=mc^2' }}</Node>`. |

### Injection API (`@retikz/tex`)

| Name | Signature | Description |
| --- | --- | --- |
| `useLowerMath` (`@retikz/tex/react`) | `() => LowerMath \| undefined` | React hook: starts MathJax as a process-level singleton, returns the injection (`undefined` until ready). Collapses the manual startup effect into one line |
| `createMathJaxEngine` | `(opts?) => Promise<MathJaxSvgEngine>` | Builds a synchronous tex→SVG engine on top of `mathjax-full` (optional peer); startup is async. You may also supply your own `MathJaxSvgEngine` |
| `createLowerMath` | `(engine) => LowerMath` | Engine → the core `lowerMath` injection, cached by `fontSize\|display\|tex` |

## Degradation & diagnostics

- **`lowerMath` not injected** → the node degrades (no formula) + warning `MATH_LOWERER_MISSING`; no crash.
- **Invalid tex / render failure** → warning `MATH_TEX_INVALID` + placeholder; no crash.
- **`mathjax-full` not installed** → `createMathJaxEngine` throws with an install hint; `useLowerMath` catches it internally → `lowerMath` stays `undefined` and math nodes degrade.
