title: TeX Formulas
description: Write formulas in LaTeX, lower them through MathJax SVG into renderer-agnostic glyph paths, and inject the capability into core with lowerTex.
---

`@retikz/tex` turns LaTeX formulas into glyph `PathPrim`s that `@retikz/core` can render. In IR, a formula is node content named `node.tex`, parallel to `text`: without a `shape` it is a standalone formula block; with a `shape` it becomes a framed formula. In React, prefer `<TexNode>` from `@retikz/tex/react`.

## Install And Enable

`@retikz/tex` provides the TeX-to-glyph capability. MathJax is an optional peer dependency so the application controls the installed version:

```bash
pnpm add @retikz/tex mathjax-full
```

In React, `useLowerTex` starts MathJax and injects the capability through `<Layout lowerTex>`. The formula source can be written directly as `<TexNode>` children:

```tsx
import { Layout } from '@retikz/react';
import { TexNode, useLowerTex } from '@retikz/tex/react';

const Diagram = () => {
  const lowerTex = useLowerTex();

  return (
    <Layout lowerTex={lowerTex}>
      <TexNode id="eq" position={[0, 0]}>
        {'\\frac{a}{b} = c'}
      </TexNode>
    </Layout>
  );
};
```

## Wrapper Or Manual

`<TexNode>` is only a wrapper from `@retikz/tex/react`. It converts the `tex` prop or string children into `<Node tex={{ tex }} />`, while passing through `<Node>` positioning, shape, style, label, and hydration event fields.

If you do not want to import `@retikz/tex/react`, use the main `@retikz/tex` entry to create `lowerTex` yourself, then write `<Node tex={{ tex }}>` directly:

## Vanilla

`createMathJaxEngine` (await startup) -> `createLowerTex` -> inject as the `lowerTex` option of `toScene` / `renderToString`; IR or vanilla nodes use `tex` content:

```ts
import { figure, node, renderToString } from '@retikz/vanilla';
import { createMathJaxEngine, createLowerTex } from '@retikz/tex';

const lowerTex = createLowerTex(await createMathJaxEngine());
const fig = figure([
  node('eq', { position: [0, 0], tex: { tex: '\\frac{a}{b} = c' } }),
]);

const svg = renderToString(fig, { lowerTex });
```

## API Reference

### TexNode

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `tex` | `string` | - | LaTeX source. When string children are also present, the `tex` prop wins. |
| `children` | `string` | - | Convenience form for writing the formula directly inside the component. |
| `displayMode` | `boolean` | `false` | Uses display metrics, useful for fractions, sums, integrals, and block formulas. |
| Other Node fields | `Omit<IRNode, 'type' \| 'tex' \| 'text'>` + hydration events | - | Passes through positioning, `shape`, `fill`, `stroke`, `padding`, `label`, events, and the rest of the node surface. |

### Lowering API

| API | Type | Description |
| --- | --- | --- |
| `useLowerTex` (`@retikz/tex/react`) | `() => LowerTex \| undefined` | React hook: starts MathJax and returns the function injected into `<Layout lowerTex>`; `undefined` until ready. |
| `createMathJaxEngine` | `() => Promise<MathJaxSvgEngine>` | Creates the MathJax SVG engine. |
| `createLowerTex` | `(engine) => LowerTex` | Converts the engine into core's `lowerTex` injection, cached by `fontSize|display|tex`. |
| `LowerTex` (`@retikz/core`) | `(content, style) => LoweredTex \| null` | Core injection type; failures return `null`, and compile emits `TEX_INVALID`. |
