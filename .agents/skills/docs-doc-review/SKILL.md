# 文档评审

先确认授权是只读审查还是同时改稿。按 [文档总则](../docs-doc-principle/SKILL.md) 选择页型和实际涉及的共享规则；不要把全部页型清单塞进一次评审。

- 正文、图与示例审查读 [检查与输出](references/checklist.md)。
- 机械和视觉检查读 [验证规则](../docs-doc-principle/references/validation.md)。
- 独立读者 reviewer 仅在计划已授权时调度，按验证规则限制输入；本 skill 的源码与规范审查由主 agent 执行。

报告具体位置、读者影响和可执行修订建议。未读源码就标“仅文档审查”，未开页面就标“视觉未验证”；不把局部抽样说成全量通过。
