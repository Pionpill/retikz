# 外部只读评审通道

仅当会话内调度不可用且外部通道属于获批计划时使用。先通过 Get-Command（PowerShell）或 command -v（POSIX）确认实际 CLI，再读取该版本 --help，核对模型选择、只读模式、输入与输出参数；不把旧版命令示例当作保证。

- Codex：优先专用 review 能力处理 git 范围；固定文档/代码块使用支持的只读 exec。
- Claude 或其他 CLI：确认权限与只读限制实际生效；仅在 prompt 写“只读”不等于权限隔离。
- 将同一冻结材料分别交给每个 fresh 实例，使用适合当前 shell 的参数与 UTF-8 编码。命令行传参不暴露 secrets。
- 输出按模型/实例区分，保存在已忽略报告目录；核对原始输出、exit code、超时与工作区变化。
- 无法确保只读、独立上下文或固定输入时停止，不绕过环境限制。选择替代模型不得越过已批准阵容。
