# 博客写作

先读 [文档总则](../docs-doc-principle/SKILL.md)，再读 [博客写作](references/writing.md)；翻译或添加元数据时读 [发布元数据与引用](references/publishing.md)。

博客允许作者第一人称、主观判断与有依据的平实比较，第三方链接允许；zh 必需，en 可选。不要把常规教程的固定章节强套进作者文章。

默认按作者给定主线逐节协作；用户已明确授权整篇起草或重写时按其范围连续完成，不再逐节索取许可。不得编造作者经历或未经依据的历史。

外站转换使用 [docs-blog-converter](../docs-blog-converter/SKILL.md)，写作本身不授权发布。
