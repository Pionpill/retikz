# Demo 视觉语义

仅在 demo 包含位置、引用、边界、控制柄、投影、测量线或多个视觉层级时读取。它定义静态 demo 与 controls playground 共用的视觉语言；controls 的交互契约仍由 `docs-doc-control` 拥有。

## 层级

| 元素                   | 视觉语义                                                   |
| ---------------------- | ---------------------------------------------------------- |
| 主要对象               | 使用页面主强调色；同一 demo 通常只有一个主强调色           |
| 次要但真实的关系       | 灰色、常规线宽、实线                                       |
| 实际不存在的教学辅助   | 浅灰 dotted：`dashPattern={[1, 4]}` + `lineCap="round"`    |
| 真实但降级的对象或边界 | 灰色 dashed                                                |
| 文字                   | 主体文字保持默认色；辅助标注用灰色，不用颜色承担第二套分类 |

dotted 只表示坐标轴、投影、控制柄、测量线等“实际不存在”的教学辅助；dashed 表示真实但非重点的边界或对象，不能混用。

## 位置与引用

- 优先用 `<Draw way={['A', 'B']} />` 表达关系，除非页面本身在讲 `<Path>` / `<Step>`
- 引用 id 使用大写 `A/B/C`，可见短标签使用小写 `a/b/c`
- 位置数值和坐标说明放正文、caption 或边标注，不塞进 Node 主体
- 一个 demo 只讲一个关系；两个对象能讲清就不放四个
- 变化需要比较边界、顺序、变换或引用时，主动保留固定参照物，让差异在默认尺寸下一眼可见
