# 相关属性

## 何时出现

除 API 参考、Schema 参考、实现原理页外，页面只要使用或解释了需要集中回查的公开成员，就添加“相关属性 / Related props”。这包括基础、专题、扩展用法和自定义页；没有相关成员时不造空节，不为凑节补无关 API。

放在补充说明或错误与限制之后、延伸阅读之前；没有前一节时直接放在收尾导航前。分组页若需要此节，放在“章节内容”之前。完整 API 参考由脚本生成；本节由作者或 LLM 按章节语境精选，不复制完整字段字典。

## 组件与字段

使用已注册的 `<ComponentProps items={[...]} />`，description 是按 MDX 渲染的字符串，不是 ReactNode。不手写平行属性表。

| 字段           | 内容                                                      |
| -------------- | --------------------------------------------------------- |
| `name`         | 本页实际使用的公开属性、函数、常量或类型名                |
| `kind`         | `property`、`function`、`constant`、`type`                |
| `type`         | 真实公开类型；函数使用完整调用签名                        |
| `description`  | MDX 字符串：结合 JSDoc 说明本章何时用、影响什么、必要约束 |
| `required`     | 按公开调用契约填写，不从 demo 是否传入推断                |
| `defaultValue` | 有真实缺省时填写；继承或计算规则准确描述，不填假常量      |
| `value`        | 常量的实际值，不把常量值自动当作配置默认值                |

展示由组件负责：值在最后一列，用常规文本；有默认值显示默认值，无值且必填显示 `REQUIRED`。条目之间有分隔线，顶部和底部不额外加线，描述使用正文颜色。

## 内容核对

- 节首说明本节只收录本页相关成员，并链接完整 API 参考；无需逐字套固定句式。
- 从 package exports / owner barrel 追到声明和 JSDoc，再核对默认值应用处；按本章叙述顺序选取，不把内部实现成员收进来。
- 描述补充章节上下文，不凭名称猜行为，不扩写 JSDoc 没有依据的保证；共享属性只收本章确实讲解的部分。
- zh/en 同步成员、签名、必要性、值与描述语义；标识符不翻译。
- 组件契约以 `apps/docs/src/modules/docs/components/mdx-content/component-props/` 为准；本任务不修改组件行为时不要为文案扩展 props。

- `type` 不得只写别名：当前页需要据此编写代码时，必须同时展开必要的数组元素、对象字段、union 分支或泛型结构。`description` 必须列出本页涉及的枚举 / 常量值及其可观察差异；未涉及的完整分支仍链接 API 参考
