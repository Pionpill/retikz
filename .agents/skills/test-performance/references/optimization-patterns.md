# 通用优化原则

用于已获授权的性能诊断与优化。先定位实际成本，再选择适用原则；下表是排查方向，不是必然提速的改写规则。保持行为契约，以同条件前后测量验证收益及退化，采样与报告遵循 [主 skill](../SKILL.md)。

| 优化原则                 | 检查重点                                                   | 边界与代价                                           |
| ------------------------ | ---------------------------------------------------------- | ---------------------------------------------------- |
| 按需计算                 | 将仅少数分支需要的数据、错误信息和辅助结构推迟到使用时构造 | 不改变副作用、错误语义及执行顺序                     |
| 提前退出                 | 尽早排除不匹配分支，在结果已确定时结束搜索或遍历           | 不跳过必要校验、清理及后续必须执行的操作             |
| 缩小计算范围             | 剪去不影响结果的数据与候选分支，避免重复扫描已处理范围     | 剪枝需有正确性依据，不擅自降低精度或输入需求         |
| 消除重复计算             | 提取循环不变量，复用单次操作中的解析结果与公共子表达式     | 衡量准备成本；跨调用缓存、失效和生命周期归实际拥有方 |
| 避免无用计算与分配       | 检查未消费的初始化表达式、中间结果及过长的引用保留         | 变量名本身通常不是成本，不以减少变量数代替性能分析   |
| 减少分配与复制           | 减少临时对象、数组、字符串和非必要完整副本                 | 保留所有权、不可变性、引用隔离及可重入性             |
| 简化常见路径             | 避免常见输入承担复杂输入才需要的递归、集合维护或分派成本   | 快路径与通用路径行为一致，覆盖分界及异常输入         |
| 选择合适的算法与数据结构 | 结合操作类型、输入规模与分布检查复杂度及退化路径           | 同时衡量构建、查询、维护、内存成本；不只验证受益输入 |
| 利用运行时特性           | 检查对象形态、属性访问等是否影响引擎优化                   | 记录引擎与版本，实测完整使用过程，不推广为跨环境规律 |

例如，错误路径字符串可延迟到失败时生成；循环中不变的系数可在进入循环前计算。这些分别属于按需计算与消除重复计算，不需要为具体算法另建规则。

## 代码成本检查

- 检查缓存判定前的解析器、索引、key 和副本构造；仅供未命中分支使用的准备推迟到实际执行时，不能跳过必要副作用与诊断
- 复用单次操作已得到的事实前，核对数值舍入、退化输入和边界归属；数学等价不能代替程序行为等价
- 减少复制前区分内部结果、扩展回调可变输入与最终输出的所有权；优先缩小复制范围或延后复制，保留隔离与可重入契约
- 同时衡量准备成本和小输入固定成本；减少分配、调用或代码行数仅是收益假设，不能用大输入收益掩盖已确认的小输入退化

## 整体流程检查

1. 沿真实入口列出各阶段的调用次数、输入输出和状态生命周期，分别定位单次计算、重复调度、阶段交接与结果组装成本；内部优化保持阶段职责和必要执行顺序
2. 检查同一事实是否跨阶段反复编码、建索引和还原；只有消费契约允许时才简化交接，不为减少转换向源模型增加可推导的长期状态
3. 检查批处理循环内的全量搜索与数组移动，例如逐项 `indexOf` / `splice`；考虑按容器集中处理，并验证顺序、空输出、多输出、容器身份、异常行为及临时内存代价
4. 检查缓存命中后的调度、依赖维护和输出组装，不能把跳过核心计算等同于整次操作低成本
5. 复用旧产物须依据真实输入依赖和扩展契约；外层字段变化不能证明回调内部计算不变。需要新增依赖声明或所有权约束时转契约设计，不以内置白名单绕过统一扩展机制

运行时特性的一个例子：本次 Node 22 / V8 12.4 实验中，`Object.create(null)` 仅创建空对象更快，而 `Object.setPrototypeOf({}, null)` 在创建后写入固定字段并冻结的场景受益。此结论只针对新建且尚未对外暴露的对象和已测负载，不据此批量替换对象创建方式，也不推广到修改现有对象原型。
