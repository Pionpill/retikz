# 成品展示

用于展示完整图表、表格、Diagram、Standard 等能力，可作为现有页型的展示模式，不单独改变页型或难度。

## 功能与载体

先确定读者要观察的能力，再选择能体现该能力的数据或场景。图表使用可追溯的真实数据快照，非数据型成品使用可识别的场景；几何、错误边界或固定解释图可用最小构造数据并如实标注。

基础示例使用无需行业背景即可理解的主题、字段和单位。样本量以显露目标关系且图元标签可读为准，不固定凑 100 行，不用整齐合成点伪装真实趋势。数据保存在同级 data 文件，避免运行时第三方请求；确认允许分发，记录来源及影响结论的筛选、清洗、缺失值、单位换算和派生过程。

## 示例组织

- 首个基础示例只传必要配置，不带 controls/presets；根组件提供完整配置时先展示根级 authoring。
- 后续同结构参数变化才用 controls，读取 [Controls](../../docs-doc-principle/references/controls.md)。
- 最简不等于删除成品原生 title/subtitle/source；说明真实支持的源码/IR 切换，不承诺未提供的模式。
- 高度按 [实测](../../docs-doc-principle/references/preview-sizing.md)，不默认强套 xxl。

## 外层说明与成品叙事

外层 title/description/caption 说明“本例展示什么能力、观察什么交互”；成品内部说明具体主题、时间范围、单位与来源。

| 成品原生元信息 | 内容                           |
| -------------- | ------------------------------ |
| title          | 主题、问题或可观察结论         |
| subtitle       | 范围、时间、样本、单位或方法   |
| source         | 可追溯出处及影响理解的数据处理 |

组件有原生能力时由组件渲染；没有时由页面说明，不能声称这些文案是组件输出。不为一个展示任务新增公开属性。

## 验证

无需行业背景即可理解默认例子；数据确实体现目标能力；来源与处理可复现；zh/en 的功能、单位与来源一致。检查真实页面的图形、面板和源码，不能把“能渲染”当作已讲清功能。
